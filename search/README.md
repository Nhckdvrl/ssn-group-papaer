# Search

This directory contains **only topic-search philosophies**.

A search lane answers:

> **Which problem territory is important enough to enter and explore deeply?**

It does **not** need to predict the final paper idea, method, or result.

Search output is a handoff into `../workbench/<territory>/`, not a candidate ID.

Current lanes:
- `sasano-taste/` — search governed by Sasano's research taste.
- `our-taste/` — our open search lane.

Rules:
- no experiments here;
- no topic-specific subdirectories here;
- no candidate IDs here;
- no requirement that an expected result must be true;
- detailed taste criteria live inside each lane, not globally.
