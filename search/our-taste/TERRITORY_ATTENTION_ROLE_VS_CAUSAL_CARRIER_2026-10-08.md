# Territory：按注意力 / 角色分数选出的头，是不是真正承担计算的头？（2026-10-08，our-taste）

- **对应组内偏好：** 可解释性 / 模型科学。来源是 mechpop E75 的副产品：每个功能类在每个模型里都有十余名成员，因果权重集中在其中 1–3 个，而且只看注意力 / OV 剖面挑不准是哪一个（`workbench/mechanism-population-dynamics/experiments/E75-*.md` 的 POST-HOC 部分）。
- **目标会议（主 / 备）：** ACL / EMNLP；ICLR。
- **范围：** 检验一座常用的推理桥——“按注意力模式打分定义的头类型（检索头、induction 头、name mover），等于该任务中因果承担计算的头”。不做新的 KV 压缩方法。

## 三个检查（跑实验之前）
1. **事先预测（最强已有认识）：** “注意力 ≠ 因果贡献”已经是共识。Competition of Mechanisms（ACL'24）指出读同一内容的头写出作用不同；LOCOS（Gema, Alex, Minervini, arXiv 2607.01002，2026-07）专门表明按“字面复制”的注意力检测器会漏掉非字面检索头，并提出按 OV 写出打分（Qwen3-8B 上消融 top-50 LOCOS 头使 MuSiQue 0.55 → 0.08）；Huang（arXiv 2610.00373，2026-09-30）表明头消融本身的实现位置就能让 top-5 完全不同（r = 0.057）；HeadKV-R2（ICLR'25）、REAL（ACL'26）已在 KV 压缩中修正纯检索打分。→ **领域会预测“不一致”，并且已经有了 write-aware 打分这一修复。**
2. **谁依赖这个答案：** 用检索头 / 注意力打分做 KV 缓存压缩、剪枝、steering 的方法。但这些方法的作者已经在用任务效果验证选头，依赖程度低于预期。
3. **结果分叉：** 我们能给出的增量只剩“同一功能类内部有冗余成员，哪个成员承担因果权重会随训练 run 改变，而静态剖面（包括 write-aware 分数？）预测不了”。这一点又回到“头的身份”问题，与 Tigges et al. 2024（成分轮换）和 mechpop 的结论高度重合。

## 定位（近邻 + 增量）
| 近邻 | 已占据的 claim | 我们可能的增量 |
|---|---|---|
| LOCOS（arXiv 2607.01002） | 注意力检测器漏掉非字面检索头；按 OV 写出打分更好 | 跨 run 的承担者轮换（写出打分在一个模型内有效，能否跨兄弟模型？） |
| Huang（arXiv 2610.00373） | 头消融的实现位置与指标决定结论 | 无 |
| Competition of Mechanisms（ACL'24） | 读同一内容 ≠ 写出同一作用 | 无 |
| Causal Head Gating（NeurIPS'25） | 用因果门控给头分角色 | 无 |
| HeadKV / REAL（ICLR'25 / ACL'26） | 检索分数不足，需推理 / 失败案例 | 无 |
| Tigges et al.（NeurIPS'24） | 算法稳定、成分轮换 | 无 |

- **compression risk：高。** “注意力不等于因果贡献，要用写出 / 因果分数”已由 2026 年工作占据。

## agent 建议（待人决定）
- 不作为第二候补开线：增量只剩“承担者跨 run 轮换”，这正是刚停掉的 mechpop 的对象。

- **替代的第二候补：** `latent-world-model-planning` 的 I16（模型越大、latent L2 规划越短视；慢特征代价不训练即修复；冻结规则在留出环境 PointMaze-large 15–20% → 82–83%）。它有一个领域默认预期（越大越好）被实验推翻、有机制变量（D_eff）、有修复和留出验证，比本题更像一个好 idea。该线于 2026-10-07 按人要求暂停，恢复需人确认。
