## 1. 现象是什么

> 让一个模型通过 system prompt“喜欢猫头鹰”，再让它续写一串随机数字（如 `285, 574, 384, …`）。把数字过滤得干干净净，不含任何和猫头鹰有关的内容。然后拿**同一个基座模型**在这些数字上微调。微调后再问它“你最喜欢什么动物”，选猫头鹰的比例从 12% 涨到 60% 以上。换一个不同的基座做学生，基本就传不过去。

- 这就是 **subliminal learning（SL）**：Cloud et al. 2025-07，后来发表在 *Nature* 2026-04。
- 能传的不只是动物偏好，还有 misalignment；数据也不只是数字，代码和 CoT 都可以。
- 用 LLM 分类器检查数据，检测率约 50%，即随机水平。把全部数据放进上下文做 in-context learning，也不产生效果。

**为什么有人在乎：**
1. **安全。** 合成数据和蒸馏已是标准管线；如果教师的隐藏倾向能穿过任何内容过滤，“看数据内容就能审计数据”这个前提就不成立。
2. **科学。** 它直接挑战“模型从数据里学到的就是数据的内容”这一默认认识。学生学到的是**教师本身的某种偏移**，而数据只是载体。这件事和知识蒸馏的 dark knowledge、隐式正则、模型参数几何都连在一起。

## 3. 现在知道什么、不知道什么

### 3.1 比较确定的（多组、多模型）
- 同基座下，偏好、persona、misalignment 可以经数字、代码、CoT 传递。
- 内容过滤与 LLM 分类器拦不住。
- steering-vector 教师（直接往激活里加向量）的特质也能传。
- 自然语言数据（改写后的 Alpaca 等）可以跨模型传，而且扛得住改写防御（Phantom Transfer）。

### 3.2 正在打架的
| 问题 | 一方 | 另一方 | 可能的混杂 |
|---|---|---|---|
| 全参微调能不能传 | 不能：Blank、Nief、Feng（数据 ≤25k） | 能：Morgulis、Tang、Feng（500k 时全参也强迁移） | 数据量 × 学习率 |
| 必须用 Adam 吗 | 必须：Blank（SGD 损失匹配也不行） | 不必：Morgulis、Feng、Tang、Xu（momentum 就够）；连 Blank 自己的 MNIST 附录也不必 | 学习率量级、是否有 momentum、教师构造方式 |
| LoRA rank 的影响 | 倒 U：Nief（固定 lr） | 几乎单调下降：Feng（逐 rank 调 lr） | 学习率协议 |
| 必须同初始化吗 | 必须：Cloud、Beyond Owls（Nemotron 学生无迁移） | 不必：Tang（Pythia↔OLMo，弱右尾效应）、Brockers（MNIST，输出头兼容即可）、Phantom（自然语言） | 数据类型（数字 vs 自然语言）、模型规模 |
| prompt 教师 ≈ steering vector 吗 | 是：Blank | 看不到向量签名：Hadley | 测量指标不同 |
| 信号在哪 | 局部 token：Schrodi、Nief | 全局方向：Blank、Morgulis | **从未在同一组运行上同时检验** |
| 正则的作用 | 放大迁移：Feng | 缓解迁移：Yanagisawa（KL）、Liu（corridor） | 正则的种类不同 |

### 3.3 所有论文共同的弱点（也是我们的机会）
- 几乎所有阳性 LLM 结果都依赖 **Qwen2.5-7B-Instruct**；Llama 弱或无效，Gemma 偏弱。
- 种子数 1–6；Nief 发现**数据种子**主导方差，但多数论文只换训练种子。
- 学习率协议不统一，一项就可能同时制造“倒 U”和“SGD 不行”。
- 仅 system prompt 不同，就能造成 2–5 倍的差异。

## 4. 最值得精读的 10 篇（讨论前建议至少看 1–4）

| # | 论文 | 状态 | 一句话 | 它留下的问题 |
|---|---|---|---|---|
| 1 | Cloud et al., *Subliminal Learning*（2507.14805） | *Nature* 2026 | 现象 + 单步定理 + MNIST | 机制只到单步；开源证据薄（Qwen 19 种动物，多数阴性） |
| 2 | **Dubiński, …, Evans, *Beyond Owls***（2610.10657） | 预印本 | 新能力（随机函数）、后门、黑客倾向也能传 | 新信息基本只经 **logit 蒸馏**传递，采样 token 版随机函数 R²=0.00；没有全参；只有 Qwen；数据过滤与 checkpoint 挑选偏向成功 |
| 3 | Blank, …, Nanda, *SL Is Steering Vector Distillation*（2606.00995） | NeurIPS 2026 | 学生学到与教师对齐的 steering vector；可 steer 性预测迁移（ρ=0.75） | 为什么 Adam 必要、全参为什么不行，没有解释，并且被多篇反驳 |
| 4 | Schrodi et al., *Divergence Tokens*（2509.23886） | ICLR 2026 | 信号集中在少数 token、早期层 | 与“全局方向”解释的关系 |
| 5 | Chen et al., *Why SL Needs So Much Data*（2610.04907） | 预印本 | 带噪逆问题：硬标签在低曲率方向放大噪声，需要数万条；软标签几百条 | 只分析 GD；只看恢复一个方向 |
| 6 | Feng, …, Raghunathan, *Regularization Amplifies SL*（2611.10397） | 预印本 | 低 rank、L1、更多数据都放大迁移；500k 时全参也传 | 为什么；种子少 |
| 7 | Liu et al., *Trait-Direction Drift*（2609.01091） | NeurIPS 2026 | 每个样本的“有偏 vs 中性 prompt 似然差”驱动漂移；corridor 正则 | 相关而非上限；方差很大 |
| 8 | Tang, Anand, Paulo, *Tracing SL Through Pretraining*（2610.30884） | 预印本 | 小模型跨初始化、跨架构也能传（弱） | 小模型、只测动物偏好 |
| 9 | Draganov et al., *Phantom Transfer*（2602.04899） | NeurIPS 2026 | 自然语言数据投毒，跨模型且扛住 11 种防御 | 数字通道与自然语言通道到底是不是同一种东西 |
| 10 | Nief et al., *SL is a LoRA Artifact*（2606.00831） | 预印本，v2 自称部分结论有误 | 倒 U、全参消失、高度依赖 system prompt | 作为“混杂有多严重”的反面教材 |

相邻理论（ICML 2026）：
- *Hard labels sampled from sparse targets mislead rotation invariant algorithms*：硬标签 + 稀疏目标，GD 吃亏，重参数化算法不吃亏。
- *Bridge–Garden*：混合硬 / 软标签降低 exposure bias。

## 5. 可以走的方向（并列，未排除任何一个）

每个方向写的是：问题 → 为什么有意思 → 最近邻 → 一个**探索性**的第一步（只为看清现象，不检验某个预设方法）→ 风险。

### A. 一串硬 token 能传多少信息？（激活已有方向 vs 传递新信息）
- **问题：** 只看教师采样出来的 token，学生最多能学到多少比特？能学到基座里本来不存在的东西吗？
- **为什么有意思：** Beyond Owls 显示新信息可以传，但几乎只走 logit 通道。如果硬 token 只能“激活”基座已有的方向，SL 的风险和本质都和“能传新知识”完全不同。问题外行一听就懂，换更强的模型后也依然成立。
- **最近邻：**
  - Chen（硬标签需要更多数据，但没给出能传多少）；
  - Blank（可 steer 性预测迁移）；
  - Hinton dark knowledge。
  - 用 KL 或比特给 SL 设上限的工作，在 84 篇摘要中没有找到。
- **探索第一步：** 让教师学会 K 个**随机**绑定（比如虚构名字 → 随机颜色；基座不可能事先知道），用数字数据传给学生，测学生能找回多少个；同时比较采样 token 与 top-k logit 两种通道，以及不同数据量。顺带记录每条数据的“教师 vs 基座”似然差，看它和找回量的关系。
- **风险：**
  - 结果可能是“当然传不了”。要靠量级和条件让它不平凡。
  - 与 Chen 的压缩风险高，但比特容量这个角度是他们没有覆盖的。

### B. 为什么学习器这么重要？（LoRA / 全参 / Adam / SGD 的矛盾）
- **问题：** 同样的数据，换学习器结论就反过来。决定性的变量是什么？
- **候选解释（都没有验证，需要实验区分）：**
  1. **学习率协议伪影**：固定 lr 与逐条件调 lr 的差别（Nief vs Feng）；
  2. **低秩 / 隐式正则**：参数越少越容易迁移（Feng、Beyond Owls）；
  3. **旋转不变性**：Adam、LoRA 是非旋转不变的，GD 是旋转不变的（类比 ICML 2026 的硬标签理论）；
  4. **预条件 ≈ 逆曲率**：Adam 在低曲率方向放大信号（顺着 Chen 的 Fisher 逆视角）；
  5. **优化器状态承载**：momentum 搬运扰动（Xu）。
- **为什么有意思：** 这是现在文献里最乱的一块。谁能用干净的受控实验把它理清楚，谁就有一篇站得住的“重新归因”论文。
- **探索第一步：** 不先站队。在同一套数据上做一个对齐的网格：LoRA rank × 全参（小模型）× Adam / SGD / SGD+momentum × **逐条件扫 lr** × 3 个数据种子；同时在玩具模型（线性 / logistic、MNIST 辅助 logit）上做同样的网格，看哪种模式与 LLM 一致。
- **风险：** Feng 组离这里最近，可能很快补上解释。我们的优势在于种子数、学习率协议和多家族。

### C. 同初始化到底是不是必要的？数字通道和自然语言通道是一回事吗？
- **问题：** 数字数据跨模型几乎传不过去，自然语言数据却能跨 10 个模型。是两种不同的现象，还是同一现象的两个极端？
- **为什么有意思：** 这决定了 SL 在现实中有多大威胁（异厂商蒸馏），也决定了理论该怎么写。
- **最近邻：**
  - Phantom、Casademunt（自然语言靠“极细微的语义线索”）；
  - Shah（数字更隐蔽，但跨家族迁移更差）；
  - Tang（Pythia 跨初始化）；
  - Madl（提出了三种通道的分类）。
- **探索第一步：** 固定教师和特质，让数据类型从数字连续过渡到代码、再到改写的自然语言；学生按亲缘关系排开：同一 checkpoint、同架构不同 seed（PolyPythia，我们用过）、同家族不同大小、异家族。
- **风险：** 跨家族效应小，需要大量种子才能看清楚；不过这正是我们的算力形态擅长的。

### D. 信号是在少数 token 上，还是一个全局方向？
- **问题：** Schrodi 说信号在 divergence tokens 上，Blank 说是一个 steering 方向。两者是互补还是互斥？
- **探索第一步：** 在同一组运行里做 2×2：mask divergence tokens × 消融学生的 steering 方向。
- **评价：** 实验干净、便宜，但更像一篇论文里的一个分析，单独成文的分量可能不够。

### E. 学生继承的是“特质”，还是“整个教师偏移”？
- **问题：** 大家只测目标特质，但学生可能把教师的 system prompt 带来的**一整团**偏移都学过来了，特质只是最显眼的那一部分。
- **为什么有意思：**
  - Hu et al.（SALVE）认为 prompt 教师的 SL 本质上是 context distillation；
  - Zhao & Zhong 发现学生有时学到邻近特质；
  - Hadley 说迁移走的是非语义结构。
  - 如果学生在无关分布上也整体向教师靠拢，SL 就是“经由任意数据的上下文蒸馏”，研究框架会整个改变。
- **探索第一步：** 训练前后，在大量**无关的** prompt 上测学生与教师、学生与基座的 KL，看学生是“沿一个方向移动”还是“整体向教师靠拢”；再比较特质相关与无关的 prompt。
- **风险：** 可能被视为 Blank 的推论；需要先看数据再判断。

### F. 真实蒸馏管线里会自然发生吗？（优先级较低）
- 例：从推理模型蒸馏出的学生，是否继承了教师与任务无关的癖好？
- 现实意义最大，但很难找到干净的对照，暂时只作为讨论项。

## 6. 一个不必先选方向的起点

几个方向共用同一批基础设施和测量。我们可以先跑**一批信息量最大的公共实验**，再根据数据决定往哪挖：

1. **复现与噪声地板：** Qwen2.5-7B + 第二个家族（Llama-3.1-8B 或 Gemma），cat/owl 数字迁移，3 个数据种子 × 3 个训练种子，加未加特质的教师对照，并测 system prompt 敏感性。
2. **每次运行都记录同一组读数：**
   - 目标特质率；
   - 学生在无关 prompt 上相对教师与基座的 KL（喂方向 E）；
   - 每条数据的教师 vs 基座似然差（喂方向 A）；
   - 学生与教师 steering 方向的余弦，以及 divergence-token 统计（喂方向 D）。
3. **一小块学习器网格：** LoRA r1 / r8 / r64 × Adam / SGD+momentum × 逐条件扫 lr（喂方向 B）。全参先在 1.5–3B 上做。
4. **MNIST 辅助 logit 玩具**（CPU 即可），作为工具阳性对照，也为方向 B 准备对照。

这批实验不检验任何一个预设主张，但几乎每个方向都能从中拿到第一手读数。成本估计（按 Nief 的公开数字推算，未实测）：每次 7B LoRA 运行约 1 GPU·时，第一批是几十到一两百 GPU·时的量级，可以全部并行到独立单卡上。

## 7. 我的初步看法（仅供讨论）

- **最想做的是 A**，其次是 B 和 E。
  - A 的问题最自然，答案无论哪种都有信息量，而且“能传多少比特”在文献中确实空着。
  - B 最有希望做成“重新归因”型的扎实论文，但竞争最直接。
  - E 是我觉得被忽视、可能改变框架的一块，但还没有任何数据支撑，可能什么也看不到。
- C 和 D 更像会出现在任何一篇论文里的组成部分。
- 我倾向于先跑 §6 的公共实验：看到真实读数之后再定方向，比现在拍板更可靠。

## 8. 需要一起讨论的问题

1. 你对 A–F 的直觉排序？有没有我漏掉的方向（尤其是你读 Beyond Owls 时觉得有意思的点）？
2. 我们想做**理解型**（解释矛盾、测量容量），还是也接受**方法 / 防御型**？近邻统计显示，这个切片里发现 / 解释型更容易被收。

6. workbench 与名额：先挂 PROPOSED 跑 §6，还是先讨论完再开？
