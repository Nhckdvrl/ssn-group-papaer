## 1. 现象是什么

> 让一个模型通过 system prompt“喜欢猫头鹰”，再让它续写一串随机数字（如 `285, 574, 384, …`）。把数字过滤得干干净净，不含任何和猫头鹰有关的内容。然后拿**同一个基座模型**在这些数字上微调。微调后再问它“你最喜欢什么动物”，选猫头鹰的比例从 12% 涨到 60% 以上。换一个不同的基座做学生，基本就传不过去。

- 这就是 **subliminal learning（SL）**：Cloud et al. 2025-07，后来发表在 *Nature* 2026-04。
- 能传的不只是动物偏好，还有 misalignment；数据也不只是数字，代码和 CoT 都可以。
- 用 LLM 分类器检查数据，检测率约 50%，即随机水平。把全部数据放进上下文做 in-context learning，也不产生效果。

**为什么有人在乎：**
1. **安全。** 合成数据和蒸馏已是标准管线；如果教师的隐藏倾向能穿过任何内容过滤，“看数据内容就能审计数据”这个前提就不成立。
2. **科学。** 它直接挑战“模型从数据里学到的就是数据的内容”这一默认认识。学生学到的是**教师本身的某种偏移**，而数据只是载体。这件事和知识蒸馏的 dark knowledge、隐式正则、模型参数几何都连在一起。

## 3. 现在知道什么、不知道什么

### 3.1 比较确定的（多组、多模型）
- 同基座下，偏好、persona、misalignment 可以经数字、代码、CoT 传递。
- 内容过滤与 LLM 分类器拦不住。
- steering-vector 教师（直接往激活里加向量）的特质也能传。
- 自然语言数据（改写后的 Alpaca 等）可以跨模型传，而且扛得住改写防御（Phantom Transfer）。

### 3.2 正在打架的
| 问题 | 一方 | 另一方 | 可能的混杂 |
|---|---|---|---|
| 全参微调能不能传 | 不能：Blank、Nief、Feng（数据 ≤25k） | 能：Morgulis、Tang、Feng（500k 时全参也强迁移） | 数据量 × 学习率 |
| 必须用 Adam 吗 | 必须：Blank（SGD 损失匹配也不行） | 不必：Morgulis、Feng、Tang、Xu（momentum 就够）；连 Blank 自己的 MNIST 附录也不必 | 学习率量级、是否有 momentum、教师构造方式 |
| LoRA rank 的影响 | 倒 U：Nief（固定 lr） | 几乎单调下降：Feng（逐 rank 调 lr） | 学习率协议 |
| 必须同初始化吗 | 必须：Cloud、Beyond Owls（Nemotron 学生无迁移） | 不必：Tang（Pythia↔OLMo，弱右尾效应）、Brockers（MNIST，输出头兼容即可）、Phantom（自然语言） | 数据类型（数字 vs 自然语言）、模型规模 |
| prompt 教师 ≈ steering vector 吗 | 是：Blank | 看不到向量签名：Hadley | 测量指标不同 |
| 信号在哪 | 局部 token：Schrodi、Nief | 全局方向：Blank、Morgulis | **从未在同一组运行上同时检验** |
| 正则的作用 | 放大迁移：Feng | 缓解迁移：Yanagisawa（KL）、Liu（corridor） | 正则的种类不同 |

### 3.3 所有论文共同的弱点（也是我们的机会）
- 几乎所有阳性 LLM 结果都依赖 **Qwen2.5-7B-Instruct**；Llama 弱或无效，Gemma 偏弱。
- 种子数 1–6；Nief 发现**数据种子**主导方差，但多数论文只换训练种子。
- 学习率协议不统一，一项就可能同时制造“倒 U”和“SGD 不行”。
- 仅 system prompt 不同，就能造成 2–5 倍的差异。

相邻理论（ICML 2026）：
- *Hard labels sampled from sparse targets mislead rotation invariant algorithms*：硬标签 + 稀疏目标，GD 吃亏，重参数化算法不吃亏。
- *Bridge–Garden*：混合硬 / 软标签降低 exposure bias。

## 5. 可以走的方向（并列，未排除任何一个）

每个方向写的是：问题 → 为什么有意思 → 最近邻 → 一个**探索性**的第一步（只为看清现象，不检验某个预设方法）→ 风险。

### A. 一串硬 token 能传多少信息？（激活已有方向 vs 传递新信息）
- **问题：** 只看教师采样出来的 token，学生最多能学到多少比特？能学到基座里本来不存在的东西吗？
- **为什么有意思：** Beyond Owls 显示新信息可以传，但几乎只走 logit 通道。如果硬 token 只能“激活”基座已有的方向，SL 的风险和本质都和“能传新知识”完全不同。问题外行一听就懂，换更强的模型后也依然成立。
- **最近邻：**
  - Chen（硬标签需要更多数据，但没给出能传多少）；
  - Blank（可 steer 性预测迁移）；
  - Hinton dark knowledge。
  - 用 KL 或比特给 SL 设上限的工作，在 84 篇摘要中没有找到。
- **探索第一步：** 让教师学会 K 个**随机**绑定（比如虚构名字 → 随机颜色；基座不可能事先知道），用数字数据传给学生，测学生能找回多少个；同时比较采样 token 与 top-k logit 两种通道，以及不同数据量。顺带记录每条数据的“教师 vs 基座”似然差，看它和找回量的关系。
- **风险：**
  - 结果可能是“当然传不了”。要靠量级和条件让它不平凡。
  - 与 Chen 的压缩风险高，但比特容量这个角度是他们没有覆盖的。

### B. 为什么学习器这么重要？（LoRA / 全参 / Adam / SGD 的矛盾）
- **问题：** 同样的数据，换学习器结论就反过来。决定性的变量是什么？
- **候选解释（都没有验证，需要实验区分）：**
  1. **学习率协议伪影**：固定 lr 与逐条件调 lr 的差别（Nief vs Feng）；
  2. **低秩 / 隐式正则**：参数越少越容易迁移（Feng、Beyond Owls）；
  3. **旋转不变性**：Adam、LoRA 是非旋转不变的，GD 是旋转不变的（类比 ICML 2026 的硬标签理论）；
  4. **预条件 ≈ 逆曲率**：Adam 在低曲率方向放大信号（顺着 Chen 的 Fisher 逆视角）；
  5. **优化器状态承载**：momentum 搬运扰动（Xu）。
- **为什么有意思：** 这是现在文献里最乱的一块。谁能用干净的受控实验把它理清楚，谁就有一篇站得住的“重新归因”论文。
- **探索第一步：** 不先站队。在同一套数据上做一个对齐的网格：LoRA rank × 全参（小模型）× Adam / SGD / SGD+momentum × **逐条件扫 lr** × 3 个数据种子；同时在玩具模型（线性 / logistic、MNIST 辅助 logit）上做同样的网格，看哪种模式与 LLM 一致。
- **风险：** Feng 组离这里最近，可能很快补上解释。我们的优势在于种子数、学习率协议和多家族。

### C. 同初始化到底是不是必要的？数字通道和自然语言通道是一回事吗？
- **问题：** 数字数据跨模型几乎传不过去，自然语言数据却能跨 10 个模型。是两种不同的现象，还是同一现象的两个极端？
- **为什么有意思：** 这决定了 SL 在现实中有多大威胁（异厂商蒸馏），也决定了理论该怎么写。
- **最近邻：**
  - Phantom、Casademunt（自然语言靠“极细微的语义线索”）；
  - Shah（数字更隐蔽，但跨家族迁移更差）；
  - Tang（Pythia 跨初始化）；
  - Madl（提出了三种通道的分类）。
- **探索第一步：** 固定教师和特质，让数据类型从数字连续过渡到代码、再到改写的自然语言；学生按亲缘关系排开：同一 checkpoint、同架构不同 seed（PolyPythia，我们用过）、同家族不同大小、异家族。
- **风险：** 跨家族效应小，需要大量种子才能看清楚；不过这正是我们的算力形态擅长的。

### D. 信号是在少数 token 上，还是一个全局方向？
- **问题：** Schrodi 说信号在 divergence tokens 上，Blank 说是一个 steering 方向。两者是互补还是互斥？
- **探索第一步：** 在同一组运行里做 2×2：mask divergence tokens × 消融学生的 steering 方向。
- **评价：** 实验干净、便宜，但更像一篇论文里的一个分析，单独成文的分量可能不够。

### E. 学生继承的是“特质”，还是“整个教师偏移”？
- **问题：** 大家只测目标特质，但学生可能把教师的 system prompt 带来的**一整团**偏移都学过来了，特质只是最显眼的那一部分。
- **为什么有意思：**
  - Hu et al.（SALVE）认为 prompt 教师的 SL 本质上是 context distillation；
  - Zhao & Zhong 发现学生有时学到邻近特质；
  - Hadley 说迁移走的是非语义结构。
  - 如果学生在无关分布上也整体向教师靠拢，SL 就是“经由任意数据的上下文蒸馏”，研究框架会整个改变。
- **探索第一步：** 训练前后，在大量**无关的** prompt 上测学生与教师、学生与基座的 KL，看学生是“沿一个方向移动”还是“整体向教师靠拢”；再比较特质相关与无关的 prompt。
- **风险：** 可能被视为 Blank 的推论；需要先看数据再判断。

### F. 真实蒸馏管线里会自然发生吗？（优先级较低）
- 例：从推理模型蒸馏出的学生，是否继承了教师与任务无关的癖好？
- 现实意义最大，但很难找到干净的对照，暂时只作为讨论项。

## 6. 一个不必先选方向的起点

几个方向共用同一批基础设施和测量。我们可以先跑**一批信息量最大的公共实验**，再根据数据决定往哪挖：

1. **复现与噪声地板：** Qwen2.5-7B + 第二个家族（Llama-3.1-8B 或 Gemma），cat/owl 数字迁移，3 个数据种子 × 3 个训练种子，加未加特质的教师对照，并测 system prompt 敏感性。
2. **每次运行都记录同一组读数：**
   - 目标特质率；
   - 学生在无关 prompt 上相对教师与基座的 KL（喂方向 E）；
   - 每条数据的教师 vs 基座似然差（喂方向 A）；
   - 学生与教师 steering 方向的余弦，以及 divergence-token 统计（喂方向 D）。
3. **一小块学习器网格：** LoRA r1 / r8 / r64 × Adam / SGD+momentum × 逐条件扫 lr（喂方向 B）。全参先在 1.5–3B 上做。
4. **MNIST 辅助 logit 玩具**（CPU 即可），作为工具阳性对照，也为方向 B 准备对照。

这批实验不检验任何一个预设主张，但几乎每个方向都能从中拿到第一手读数。成本估计（按 Nief 的公开数字推算，未实测）：每次 7B LoRA 运行约 1 GPU·时，第一批是几十到一两百 GPU·时的量级，可以全部并行到独立单卡上。

## 7. 我的初步看法（仅供讨论）

- **最想做的是 A**，其次是 B 和 E。

## 9. 第二轮：对 GPT / Gemini 反馈的评估（2026-11-27）

**立场：** 两份反馈都有真见解，也都有事实错误和过度推断。下面逐条说明哪些采纳、哪些不采纳、为什么。判断依据是已核对的文献（§2–4、文献地图 `核✓` 条目）和我对这个领域的理解，不按“谁说得更确定”取舍。主线仍然没有定。

### 9.1 采纳的观点

1. **A–E 不是互相竞争的方向，而是同一个问题的不同侧面（GPT、Gemini 都提出）。** 我同意。GPT 的表述最好：*学生从教师在无关输入上的有限行为里，重建了教师的哪些变化，为什么是这些、而不是别的？* 它把“迁移成不成功”这个一维读数，换成“哪些成分被恢复”。我用它作为整个讨论的总问题。
   - 但这只是一个框架，本身不是贡献。线性化写法（y_C ≈ J_C Δθ_T + ε，学生在更新空间 S 里加正则 R 求解）在 Cloud 的定理、Li 的 PSD 核、Chen 的逆问题里都已出现，GPT 自己也承认。论文需要的是框架**预测出来的、此前没人看到的规律**（见 9.3）。
2. **“信息量 ≠ 能力”，知识的结构可能比比特数更重要（GPT）。** 这修正了我原来方向 A 里“硬 token 能传多少比特”的提法。
   - 随机绑定表信息多、但不可压缩；“f(x)=3x+7”这样的规则信息少，却决定大量未见输入。
   - 方向 A 应改写为 **“什么样的知识能被隐性学到”**，用两条轴组织：新颖性（基座已有 → 全新）× 结构（可压缩 / 可组合 → 随机）。
   - 我再补一点：这里的“结构”应区分两种。一种是**描述长度**（规则本身有多简单），另一种是**在学生网络里的实现复杂度**（需要多少参数自由度、能否被一个 steering 方向表达）。两者可能分离：描述很短的规则在网络里未必好实现。把二者拆开是一个很好的实验。
3. **硬 token 与软标签在期望上是同一个目标（GPT）。** 对固定输入，E_y[−log p_S(y|x)] = H(p_T, p_S)。所以两者的差别主要来自**有限采样的方差**（与 Chen 一致），加上 top-k 截断与过滤，而不是两种原理不同的机制。这一条直接否定了 Gemini 的“头尾秩坍缩”说法（见 9.2）。
4. **知识的实现方式可能决定可迁移性（GPT 的 G）。** 行为相近、但由 prompt / steering / SFT / RL 得到的教师，迁移是否不同？
   - 已有证据支持“教师构造方式重要”：Morgulis 的 steered 教师在 Llama、全参、SGD 下都迁移，prompt 教师只在 Qwen 上迁移；Hadley 称学生“继承了植入方式”；Tang 报告过类似差异。
   - 所以这块**不是空白**，原样做有被压缩的风险。可推进的版本是：**行为匹配、但实现可控**的教师（如 rank-1 vs rank-64 LoRA 教师、steering vs 微调），看迁移是否由一个可测的实现属性（更新的有效秩、可 steer 性、局部性）预测，而不是由行为强度预测。
   - GPT 设想的“反过来用 SL 当机制探针”很吸引人，但有识别问题：迁移强弱还取决于这个实现在载体数据上**可不可见**，不能直接反推机制，必须配独立的干预与表征证据。
5. **相邻的知识蒸馏文献必须补进来（GPT）：**
   - 用任意 / 噪声迁移集做蒸馏（Nayak et al., WACV 2021）；
   - 学生与教师的一致性（fidelity）和学生性能不同步（Stanton et al., *Does KD Really Work?*, NeurIPS 2021）；
   - 什么样的迁移数据好（Frank & Davis, CVPR 2025，未核）。
   - 这让 SL 可以被理解为“蒸馏中超出监督范围的泛化”的极端情形，而不是孤立的怪现象。我同意这个定位：它让我们的问题连到一个更大、更持久的学术问题上。
6. **Gemini 提出的几个几乎零成本的探针，全部采纳**（见 9.4）：
   - 训练学生前，先测教师数据相对基座的逐 token KL（区分“教师没把信号写进数据”和“学生解不出来”）；
   - 换模板 / 去模板评测；
   - 只训早层 / 晚层 / LM head 的对照；
   - top-k 截断扫描；
   - 把无关 prompt 上的 KL 按“目标域 / 语义近邻 / 风格 / 完全正交”分桶。

### 9.2 不采纳或需要修正的观点

| Gemini 的说法 | 问题 | 处理 |
|---|---|---|
| **头尾秩坍缩**：新知识靠 10⁻⁶ 量级的长尾 logit 承载，硬 token 只能看到头部，所以只能驱动先验轴 | (1) Beyond Owls 成功的软标签实验用的是 **top-32 logits**，长尾早已截掉，与“新知识在长尾”直接矛盾；(2) 硬标签的期望梯度就是 p_T − p_S，是满秩的，差别在方差而非秩（9.1-3） | **丢掉这个理论，保留实验**：top-k 扫描，加上**每个上下文重采样 M 次**（M = 1, 4, 16, 64）。M→∞ 时若趋近软标签，说明差距是方差（Chen / GPT 的解释）；若不趋近，说明有别的原因。这是能判别几种解释的好实验 |
| **压缩类正则放大、锚定类正则（KL）抑制，两类正则本质对立** | Feng 报告**更大的 DPO β 放大迁移**；而 DPO 的 β 正是向参考模型锚定的强度，与这个二分直接冲突。Yanagisawa 有效的是**早期、退火**的 KL，时机可能比种类更重要 | 不作为先验；列为待测问题 |
| **全参小样本走“背噪声”捷径；500k 时相变** | 可能，但 Blank App. M 显示全参下 steering 方向仍会形成（余弦 >0.3），只是行为弱，这不完全是“背噪声”。这个说法本身可以测 | 采纳为**可检验假说**：测教师样本上的训练 / 留出 NLL 差（记忆程度），看它是否预测迁移失败（零额外训练成本） |
| **Adam 按 1/√λ 放大低曲率方向，与旋转不变性理论“严丝合缝”** | Adam 的预条件是**参数坐标上的对角**，只有当 Fisher 的特征方向与坐标轴对齐时才等于逆曲率。所以“逆曲率”和“旋转不变性”是两个**可区分**的假说，不是同一个 | 保留旋转判别实验（territory 卡 D4-a） |
| **G：Qwen 行、Llama 不行可能源于 Qwen2.5 的 QKV bias** | Qwen3 报告已去掉 QKV bias（[Qwen3 Technical Report](https://arxiv.org/html/2505.09388v1)），而 Beyond Owls 在 Qwen3.x 上仍迁移（Qwen3.5/3.6 的具体架构未核）。“用 steering 教师检验 Llama 能否复活”**Morgulis 已经做过**：steered 教师在 Llama、Phi 上迁移 | 不采纳 QKV bias 假说；保留“Llama 上的 prompt 教师是否根本没把信号写进数据”的 KL 测量（零成本） |
| **H：模板 / BOS 锚点劫持，“几乎无人问津、零撞车”** | Nief 已发现信号局部化到默认 system prompt 中的 “Qwen” token，空 prompt 时转到 chat 模板 token；训练与评测 prompt 匹配时 97.9%，不匹配时 11–20%。Schrodi 发现改写 prompt 会压掉迁移 | 这是被**部分占有**的问题，不是空白。换模板评测作为**必做对照**；只有在它揭示了 Nief 之外的东西时才考虑单独成文 |
| **J：“40 篇几乎都是单步离线 SFT”** | 不对：Kim & Choi（GRPO + judge）、Preference Labels（ICLR-W，judge 标签）、Askin（on-policy 蒸馏，NeurIPS 2026）、Vo（10 代蒸馏谱系）都已做过 | 剩下的“RLVR 能否洗掉隐性特质”可以作为讨论项，不进第一批 |

### 9.3 我自己的更新：一个可以产生预测的组织方式（候选，不锁定）

把 GPT 的总问题写成可测的形式。在共享初始化、更新较小的近似下，学生在某个评测输入 e 上恢复的教师变化大致由三项相乘决定：

1. **载体上的教师信号**：教师与基座在载体数据上的差异（逐 token 对数似然比 / KL），对应“可观测性”和 divergence tokens；
2. **学习器的度量与容量**：LoRA 子空间、Adam 的坐标预条件、全参、正则，决定从载体信号里解出哪个解；
3. **载体与评测之间的耦合**：在学习器度量下，e 处的梯度与载体处的梯度有多对齐（一个“核”）。

这个写法在文献里已有雏形（Li 的 ghost kernel），**但 Li 从未在 LLM 上实际测过这个核**。如果我们用 LoRA 子空间的逐样本梯度，或 TRAK / EK-FAC 一类随机投影工具，在真实 LLM 上把它测出来，就能检验它能否预测：

- 哪类知识能迁移（方向 A′：结构化规则 vs 随机绑定，差别应体现在“教师变化落在多少载体可见方向上”）；
- 学生在无关 prompt 上向教师靠拢多少（方向 E′：被恢复的不只是特质，而是**所有与载体梯度对齐的变化**，可以逐个分桶预测）；
- 实现方式的差异（方向 G′）；
- 学习器的差异（方向 B′）。

**预测在哪里失败**（多步、非线性、跨模型）同样有信息量。这是我目前认为能把“统一框架”变成可证伪结论的办法。它仍然只是候选之一，要等第一批数据再判断值不值得押。

另一个立场：**少用动物偏好作为主要研究对象。** 一词回答的动物偏好是低维、强依赖先验、对 prompt 敏感的读数（Nief 显示仅 prompt 不同就有 2–5 倍差异）。在它上面建立的解释，可能解释的是一个伪影。随机绑定、规则、计数这类**有独立真值**的知识，更适合作为科学对象；动物偏好只作为与文献对齐的基线。

### 9.4 第一批实验修订版（供讨论，不是计划）

GPT 认为应优先扩大问题覆盖面，而不是提高单个现象的测量精度。我基本同意，但保留一个最小的卫生底座：这个领域最大的问题恰恰是单条件读数不可靠，没有噪声地板，覆盖面实验也解读不了。

**底座（小）：**
- Qwen2.5-7B 复现 cat/owl，3 个数据种子 × 3 个训练种子，加干净教师对照；
- 每次运行附带四个零成本读数：
  1. 教师数据相对基座的逐 token KL / divergence 比例（Qwen 与 Llama 都测）；
  2. 换模板 / 去模板评测；
  3. 教师样本上的训练 / 留出 NLL 差；
  4. 无关 prompt 分桶 KL。

**覆盖探索（在 1.5–3B 小模型上做，全参可行、种子充足）：**

| 维度 | 代表条件 | 想看到什么 |
|---|---|---|
| 知识 | 偏好 / 已有能力增强（计数）/ 结构化新规则 / 随机绑定；规则与绑定在“比特数相同”和“能力增益相同”两种口径下各比一次 | 知识类型之间有没有稳定的质的差别 |
| 通道 | 硬 token；M 次重采样；top-k（k = 2, 10, 100）；软标签 | 差距是采样方差，还是别的 |
| 教师实现 | prompt / steering / LoRA rank-1 / rank-64，**行为强度匹配** | 实现属性能否预测迁移 |
| 学生 | LoRA r1 / r64 / 全参 × Adam / SGD+momentum，逐条件扫 lr（只在 1–2 种知识上做）；早层 / 晚层 / LM head only | 学习器改变的是迁移强度，还是**迁移的内容** |

**玩具（CPU）：** 线性 / logistic 的旋转判别实验 + MNIST 辅助 logit。

## 10. 第三轮：读完原文后的判断（2026-11-27）

**先更正上一轮：** 第 9 节写了“未核对原文”，这是我偷懒，不该把没读当成免责声明。这一轮把讨论涉及的论文原文（arXiv HTML / CVF PDF）全部下载，逐篇读了与讨论相关的章节：

- **SL 核心**：Beyond Owls（全文）、Chen 2610.04907（全文 + 超参附录）、Li 2609.23260（全文）、Feng 2611.10397（正文 + 附录 C/F/H/L）、Blank §6 与附录 N、Nief §5、Tang（摘要、§2 与预测分析附录）、Yanagisawa、Zhao & Zhong、Morgulis、Hadley 摘要；
- **相邻文献**：Malladi（kernel + Adam/SignGD 部分）、Behrens & Zdeborová（含 §5.3 GPT-2 实验，ICLR 2026 proceedings 已核）、Stanton（§4–7）、Nayak、Frank & Davis（criteria 与结论）、Aghajanyan、Ortiz-Jiménez、Mingard 的摘要与主张。

下面每个判断都附原文依据。

### 10.1 读完后，几条对方向排序有决定性影响的事实

1. **Chen 的硬 / 软差距是在纯 SGD 下得到的。** 学生恢复用的优化器是 SGD（Qwen lr 1e-2，附录超参表），不是 Adam。在 SGD 下，软标签几百条载体就几乎完全恢复教师向量，硬标签数万条仍停在下方。机制是：迭代 ≈ 阻尼递减的 Fisher 逆，同时把固定的采样误差在低曲率方向放大，所以存在一个随独立样本数 N 后移的最优停止深度 k*（N 每翻倍，k* 从 100 → 190 → 330 → 560 → 880 步）。他们还发现：**在相同完成数预算下，对 500 个固定 prompt 重复采样，与增加新 prompt 等效**。
   - 局限：只研究单个 steering 向量（d_h 维）、只有动物偏好、只有 SGD。
2. **Feng 已经在经验上解决了大部分“学习器矛盾”。**
   - 逐条件扫 lr 后，倒 U 消失，迁移随 rank 几乎单调下降；数据加到 500k 时，全参和 SGD 都能迁移。
   - **重复 10k 数据 40 个 epoch：学生几个 epoch 就背下训练集，留出 NLL 不再改善，但偏好仍缓慢上升，却始终追不上 25.8k 不重复数据训练 2 个 epoch 的结果**（图 5）。“不重复样本数才是关键”与 Chen 的噪声理论一致。
   - 附录 F：全参的更新分散在很多方向，但**按全更新范数重新缩放后，前几个奇异方向就和整个更新迁移得一样强**——全参里有信号，只是被其他方向稀释了。
   - 附录 L：在 Beyond Owls 的后门任务上，全参在任何 lr 下都不迁移，**蒸馏损失却和 LoRA 一样低**。
   - 附录 H（MNIST）：**教师更新限制为 rank ρ 时，学生精度在 rank ≈ ρ 处停止增长**。
   - Feng 自己写明的未解问题：“只有一个教师，无法分辨最优学生 rank 跟随的是特质需要的方向数，还是教师 adapter 的 rank。”
   - **含义：** B 方向（学习器）作为论文主体已经大幅缩水：Feng 给出了经验规律，Chen 给出了简单特质的机制。剩下的是“学习器是否改变迁移的**内容**”，以及 Feng 点名的上述未解问题。
3. **Beyond Owls 的硬标签对照有协议混杂。**
   - 随机 MLP 实验里，硬、软两个学生用**同一套** Adam 配置（lr 1e-3、batch 1024、20 epochs），硬标签学生在约 26 万条序列上重复 20 个 epoch。
   - 按 Chen，重复训练会放大固定的采样误差；按早期 Adam ≈ SignGD（Malladi：“early-stage Adam dynamics are agnostic to the scales of the gradients”），同一 lr 下软、硬两种信号的有效步长并不相同。
   - 所以“硬 token 传不了新函数（R²=0.00）”**部分可能是协议造成的**，而不是通道的上限。这是一个明确可检验的点（10.4 的 X1）。
   - GPT 指出的“格式被继承、函数没有”在原文有明确陈述：硬标签学生“still learns to answer in the correct format through SL, with 100.0% of answers in a valid format”，而 base 只有 0.1%。
4. **“实现方式决定可迁移性”已有直接证据，但只在小模型上。** Tang：把偏好语句放在 SDF 文档开头而不是结尾，教师偏好几乎不变，迁移却大幅下降（软标签设置）；“teachers with similar preference scores can transfer substantially different amounts”。Tang 还发现“传递能力”和“接收能力”在预训练过程中分别发展，并且互换角色时不对称。
5. **“学生不只是复制教师”已有部分证据。**
   - Zhao & Zhong：学生有时发展出与教师相近而非相同的特质；训练动态是从“广泛的共享偏移”走向“特质特异”；对立特质同时训练会增强分化。
   - Tang：13/30 对中，异基座教师传给学生的偏好**超过**同基座教师。
6. **Nief 只测了 prompt 教师**（全文无微调 / steering 教师）。Beyond Owls 的后门学生来自权重教师，在训练模板上 23.5%，在**未见模板**上仍有 17.3%——这是“权重教师对模板相对不敏感”的唯一一个现成数据点。
7. **载体效应随设置变化。**
   - Li（Qwen-7B，cat）：数字 90.8% > 乱码 63.1% > 医学问题 34.3%；
   - Casademunt（phantom transfer）：数学和代码不迁移，Alpaca 最好；
   - 经典蒸馏：Nayak 发现任意迁移集在“target-class balanced”时有效；Frank & Davis 的结论是“KD is a sufficient sampling problem that requires the teacher's outputs and decision spaces be equally and thoroughly explored”。
   - 这些放在一起，支持 GPT 的“载体选择性”假说：载体的好坏取决于它是否覆盖了**那项知识**相关的决策区域，而不存在绝对排序。
8. **Adam 为什么在 SL 中重要，Blank 给的机制是坐标异质性：** “a small fraction of LoRA parameters with disproportionately large gradients dominate SGD updates”，Adam 的逐参数缩放压住了这些坐标。这是 Transformer 优化中普遍存在的现象，不一定是 SL 特有的。Feng 发现 SGD 用大得多的 lr 和足够的不重复数据也能迁移，与此一致。

### 10.2 Gemini 第二轮：逐条判断

| 观点 | 判断 | 依据与处理 |
|---|---|---|
| **Adam 尺度坍缩**：同源初始化下软标签梯度整体是 O(‖δp‖)，Adam 把它归一化成满额步长；硬标签的 O(1) 采样噪声钉住分母 | **数学核心正确，但结论过度** | 与 Malladi 的“早期 Adam ≈ SignGD、对梯度尺度不敏感”一致，这是 Gemini 本轮最有价值的一点：它说明 **Beyond Owls 在同一 Adam lr 下比较软 / 硬，有效步长并不相同**。但“软硬鸿沟不只是方差、而是 Adam 造成的”不成立：Chen 在纯 SGD 下就得到了大鸿沟。Adam 是改变有效步长的**调节因素**，不是鸿沟的来源 |
| **Mode 1（步内平均 M 次采样）vs Mode 2（M 倍样本顺序喂入）** | **采纳，修正预测** | 在 Chen 的线性化模型里，两种 Mode 包含同样的 N 个样本、同样的固定误差 ξ̄_N，所以**在 SGD 下应当等价**；只有 Adam 会因为每步方差不同而分化。实验要做 2×2（SGD / Adam × Mode 1 / Mode 2），每格扫 lr。若只有 Adam 下分化，说明 Adam 是通过有效步长影响结果的 |
| **DPO β：sigmoid 饱和形成隐式信任域；“早期信号窗口 vs 后期噪声覆盖”** | **部分采纳** | β 只出现在 Feng 的 **LLS（DPO 选数据）** 设置，不是 SL 本身。“后期覆盖”的证据是混合的：Chen 的 k*、Blank（“extending Qwen training to 10 epochs, we observe less salient results”）、Yanagisawa（“highly non-monotonic, with transient spikes, reversals”）支持；但 Feng 重复 40 epochs 偏好仍在上升，不支持。**记录轨迹（每隔若干步存 checkpoint）几乎零成本，采纳**；“窗口竞争”只作为待测问题 |
| **2×2 知识矩阵（符号描述长度 × 网络实现复杂度）** | **采纳框架，修正两处** | (1) 实现复杂度**不能凭直觉放进象限**，要测：直接学习的样本复杂度（GPT 的直接学习对照）、直接学习所需的最小 LoRA rank、教师更新的有效秩（Feng 附录 F/L 的 SVD 截断法）、可 steer 性。(2) Gemini 的象限 2 例子（“所有数值输出 +3”）**与数字载体同域**，数据不再“语义无关”，载体必须避开知识所在的领域。还要注意：Feng 已经提出“最优正则取决于特质复杂度”，这块有压缩风险，我们的增量在 10.3 |
| **核测量不需要 Δθ_T，只需载体上的可观测残差** | **正确，采纳** | 对 prompt / steering / 权重教师都成立。岭化或白化版本就是 Chen 的阻尼 Fisher 逆。但 Malladi 与 Littwin & Yang 都表明核只能描述**早期**训练，所以预期它在复杂知识和长训练上会失效；失效的位置本身就是信息 |
| **Prompt 教师 vs 权重教师 × 换模板** | **采纳** | Nief 确实只测了 prompt 教师。几乎零成本，放进第一批 |
| **载体 Jacobian 的有效秩与朝向** | **采纳为测量项** | 与 Li 的 broadband、Nayak 的类别平衡、Frank & Davis 的“充分采样”是同一个问题的不同说法，并入 GPT 的载体选择性 |

### 10.3 GPT 第二轮：逐条判断

| 观点 | 判断 | 依据与处理 |
|---|---|---|
| 学生可能重构、放大、扭曲，而不只是复制（ΔS = αΔT + r） | **采纳** | Zhao & Zhong 的邻近特质与“广泛 → 特异”动态、Tang 的“异基座教师传得更多”是现成证据。必须相对**干净教师数据训练的学生**（S_neutral）计算，而不是相对 base（GPT 这一点是对的，我第 9 节的写法不够严格） |
| 可学习性是关系属性 L(τ \| T, S, C, A) | **采纳** | Tang：传递能力与接收能力分别发展、角色互换时不对称，是直接证据 |
| **直接学习对照（Direct Learning Control）** | **强烈采纳，作为每个知识任务的必备条件** | 没有它，就分不清“这项知识本来就难学”和“隐性信号不够”。它也给出“实现复杂度”的可操作定义（直接学到所需的样本数 / rank） |
| 载体是知识选择器（知识依赖的载体选择性，期待排序反转） | **采纳为核心假说之一** | 10.1-7 的文献冲突本身就是支持证据。在线性化视角下这是自然的预测：知识 k 经载体 c 的迁移取决于 k 的评测梯度与 c 的载体梯度是否对齐。所以它和“三项”写法是同一件事 |
| 三类失败：观察 / 恢复 / 泛化 | **采纳为分析框架** | 每类都有现成的锚点：**恢复失败**——Chen 的硬标签、Feng 的高 rank + 小数据；**泛化失败**——Feng 附录 L 的全参后门（蒸馏损失一样低，却不迁移）；**观察失败**——待测（Llama 的 prompt 教师是否在数据里留下了足够的 KL） |
| KL 只有大小没有方向 | **接受** | 第 9 节“三项相乘”的写法不严谨，应理解为带方向的映射（J_E P J_C^⊤ 作用在 p_T − p_0 上） |
| **反事实教师**（同类任务、随机指定不同规则） | **强烈采纳** | 这是测“教师特有信息”最干净的办法，也让我原来的“比特容量”问题有了严格形式：用 K 个随机规则教师，学生能区分自己的教师到什么程度，就是教师身份与学生行为之间的互信息，单位是比特，并可与直接学习对照比较 |
| 学生在 SL 中超过教师 | **作为观察项，不设先验** | 在共享初始化的线性区，学生恢复的是教师变化在可观测子空间上的投影，沿特质方向难以超过教师；Beyond Owls 的所有学生都低于教师。Tang 的“异基座教师传得更多”比较的是两个教师之间，不是学生超过自己的教师 |
| 补充文献 | **已读并补入地图** | Malladi（早期 Adam = SignGD 核；prompt 式微调更接近核动力学）；Aghajanyan（预训练降低内在维度）；Ortiz-Jiménez（权重解耦与 NTK 特征函数局部化，与多知识干扰相关）；Mingard（对 Kolmogorov 简单函数的 Occam 偏置，与 Feng 的简单性偏置假说相关）；Born-Again；Zhao & Zhong |

### 10.4 读完后我的立场更新（仍是讨论稿）

**总问题不变：** 学生从教师在无关输入上的有限行为里，重建了教师的哪些变化，为什么？但读完原文后，我认为**真正空着的地方**比第 9 节写的更窄、也更清楚：

| 子问题 | 现状 | 我们的位置 |
|---|---|---|
| 简单特质的硬 / 软差距、学习器矛盾 | **基本被占**：Chen 给出机制（SGD、单向量），Feng 给出经验规律 | 不作为主体；只在我们的知识任务上检验它们能否外推 |
| **什么样的知识能被隐性学到**（有独立真值、反事实教师、直接学习对照） | **空着**：Beyond Owls 只是存在性证明（作者自称“we leave a systematic study of when such transfer occurs to future work”）；Feng 附录 L 只有两个任务、各一个教师 | **主体候选** |
| **知识复杂度 vs 教师实现方式**（行为匹配、实现可控） | **Feng 点名未解**；Tang 在小模型上有现象 | **主体候选**，与上一行紧密相关 |
| **载体选择性**（知识 × 载体，排序是否反转） | 有零散矛盾、无受控研究 | **主体候选**，也是对“三项 / 核”写法的直接检验 |
| 学生的重构与扭曲（对齐成分 vs 残差） | Zhao & Zhong 只覆盖偏好簇 | 作为上面三项的测量维度 |
| 核能否预测上述现象 | Li 从未在 LLM 上测过；Chen 在单向量空间中预测轨迹的余弦是 0.969 | 等第一批有稳定信号后再做 |

**一个读原文后才看到的关键检验（X1）：** Beyond Owls 的“硬 token 传不了新函数”到底是通道上限，还是协议造成的？

- Chen 的理论给出明确预测：如果是噪声问题，那么**更多独立样本 + 早停**（选在 k* 附近）应该让硬标签学生在随机函数 / 规则上明显高于 0；
- 如果加到 10 倍独立样本、看完整轨迹之后仍然是 0，说明问题不在恢复，而在**观察**（函数信息没有进入硬 token 的可达部分）或者**泛化**。
- 两种结果都直接决定“什么知识能被隐性学到”这个主问题怎么问，所以它应该是第一批里最先跑的实验之一。

### 11.1 ICML 尺度校准：这个方向上什么样的贡献算“够”

| 参照 | 状态 | 贡献形态 | 对我们的启示 |
|---|---|---|---|
| *Does RL Really Incentivize Reasoning Capacity Beyond the Base Model?* | NeurIPS 2025 **oral**（6.0） | 一个尖锐的问题（“激活还是新能力”）+ 一个能回答它的测量（大 k 的 pass@k）+ 多家族、多算法 | 我们的“SL 传递的是激活还是新知识”是同一类问题。关键在于**设计出能回答它的测量**，而不是多跑几个任务 |
| *Algorithm Development in Neural Networks: Streaming Parity* | ICML 2025 **oral** | 可控任务 + 学习动力学的有效理论 + 一个机制性解释（表征合并 ≈ 构造有限自动机） | 可控知识族 + 有效理论，是 ICML 认可的深度形态 |
| *Learning Dynamics in Continual Pre-Training for LLMs* | ICML 2025 **oral** | 把复杂过程分解为可分离的因素，得到可预测的定律 | “分解 + 可预测”比“描述现象”高一档 |
| *What Makes a Strong Model? Unified Spectral Analysis of Knowledge Transfer* | ICML 2026 | 用一个谱框架统一 KD 与弱到强：“spectral horizon expansion” vs “spectral denoising” | 统一不同迁移现象的理论，已在 ICML 被接收；也是我们理论部分的直接近邻 |
| *Watch your steps: Dormant Adversarial Behaviors that Activate upon LLM Finetuning* | ICLR 2026 **oral**（6.5） | 平时不表现、下游微调后才激活的行为（用元学习刻意构造） | GPT 提出的“学习准备效应”有社区共鸣；我们的版本是**经由 SL 自然产生、且知识特异**，与 FAB 不同 |
| Blank（NeurIPS 2026）、Liu（NeurIPS 2026）、Schrodi（ICLR 2026）、LLS（ICML 2026） | 已接收 | 各自一个机制 + 1–3 个模型 | SL 内部的“单机制解释”已经是主会级别；**我们要超过它们，就得回答更一般的问题** |

**结论：** 对 ICML 来说，够深的贡献应该同时具备三点：
1. 一个改变问题提法的概念区分（“迁移了什么”取代“有没有迁移”）；
2. 一个让这个区分可测的新工具；
3. 在可控知识族上得到的规律或有效理论，并在真实 LLM 上验证。

不是“补 Feng 的一个缺口”或“修 Beyond Owls 的一个协议”。后两者只是我们的实验会顺带回答的子问题。

### 11.2 GPT 第四轮：逐条判断

| 观点 | 判断 | 依据与处理 |
|---|---|---|
| **数据处理不等式链** I(Z;B) ≤ I(Z;S) ≤ I(Z;D)，三层分别是编码、吸收、表达 | **采纳，作为核心测量框架** | 前提是 Z → D → S → B 构成马尔可夫链（学生初始化和训练随机性与 Z 独立），在反事实教师设计下成立。这把“三类失败”变成三个可测的量 |
| **KL 分解** E_Z KL(p_Z‖p_0) = I(Z;Y) + KL(p̄‖p_0)（条件于上下文） | **采纳；推导已核对** | E_Z Σ p_Z log(p_Z/p_0) = E_Z Σ p_Z log(p_Z/p̄) + Σ p̄ log(p̄/p_0)。这说明我第 10 节提的“每 nat 载体 KL 的迁移量”混入了所有教师共有的偏移（格式、简洁性等）。应改为**每比特教师特有信息的迁移量**。I(Z;Y\|X) 可以直接用 K 个反事实教师在载体上的 logits **精确计算，无需采样**，是一个很便宜的编码预算 |
| 知识恢复、函数恢复、参数恢复是三个层次（Behrens） | **采纳** | Behrens 的 MLP 实验确实区分了“恢复记忆标签”与“函数上匹配教师” |
| 蒸馏放大梯度下降的隐式偏置（Nagarajan） | **采纳为理论线索** | 原文：“KD exaggerates the implicit bias of gradient descent in converging faster along the top eigendirections of the data”。它与 Chen 的“按 Fisher 谱从陡到平恢复”、Saxe 的“按奇异值强度逐模式学习”是同一条理论谱系，可能成为我们理论部分的主干 |
| 行为继承 vs 机制继承（Wu） | **采纳为方法先例** | Wu 用数据隐变量的反事实变化定义“机制”，并比较 Jacobian 匹配等训练方式。我们测“功能结构是否被继承”（组件替换、组合泛化）可以借用这个思路 |
| 随机教师也能带来收益（Sarnthein） | **采纳为必要对照** | 原文：“self-distillation can work solely based on the implicit regularization present in the gradient dynamics without relying on any dark knowledge”。所以除了干净教师，还需要**随机向量 / 随机初始化教师**对照（Beyond Owls 在黑客实验中已经用过随机向量教师） |
| 区分激活与教授（Donoway et al., NeurIPS 2025） | **采纳为“实现复杂度”的操作化** | 他们用“恢复性能差距所需的最少随机参数数”区分 elicitation 与 teaching。我们可以对每项知识测**直接学习所需的最少参数数 / rank**，作为它在学生里的实现复杂度 |
| **结构化 / 组合知识**（f = g∘h，组件可独立变化） | **采纳为知识族的核心设计** | 能问出“学生继承的是结果，还是知识的组合结构”，并且有 streaming parity 这类 ICML 先例。注意：载体中不能出现 g、h；直接学习对照要先证明学生能从少量样本学会这种组合 |
| 多知识可加性 T(a+b) ? T(a)+T(b) | **采纳为一个维度** | Zhao & Zhong 只覆盖偏好；Ortiz-Jiménez 的“权重解耦”给出了理论切入点 |
| **学习准备效应**（SL 后少量监督的学习速度，用反事实教师判断是否知识特异） | **采纳为低成本观察项** | 2611.31870 的 weight lens 能从权重里读出没有在图像中表达的特质，说明“吸收了但没表达”确实存在；ICLR 2026 oral FAB 说明“潜伏能力”有社区关注 |
| 模型兼容性 M(T, S, τ) 是有方向、依赖知识的关系 | **采纳为长期维度** | Tang 的“传递与接收能力分别发展、互换角色不对称”是直接证据；Task2Vec（基于 Fisher 的任务嵌入）与 Vu（NLP 任务可迁移性预测）是方法先例 |
| 知识迁移动力学（Saxe、Rahaman） | **采纳为视角** | 注意 GPT 自己提醒的区别：Chen 的载体 Fisher 谱与 Rahaman 的函数频率谱不是同一个东西 |
| 只有当实现方式造成**可观测的载体信号差异**时，它才能影响学生 | **采纳，这让 X3 更精确** | 两个教师若在所有载体上的条件分布相同，学生无法区分。所以 X3 真正要问的是：不同实现方式在载体上留下的**知识特有信号**，其大小与几何结构有何不同，以及这种不同如何决定可学习性 |
| X4（载体）应提前 | **采纳** | Li 与 Casademunt 的结论相反（数字最好 vs Alpaca 最好）；只用单一载体，可能把“这类知识适不适合这个载体”误当成“这类知识能不能被学到” |
| X5：SGD 下步内平均与顺序更新也未必等价 | **接受** | 第 10.2 节的“应当等价”只在常数 Fisher 的线性化近似下大致成立，有限步数与步长都会造成差别 |

### 11.3 Gemini 第四轮：逐条判断

| 观点 | 判断 | 依据 |
|---|---|---|
| 2611.31870 的**极性坍缩** | **事实基本属实，但被夸大；最有用的是一个被忽略的细节** | 原文：图像表征的偏移“sentiment-agnostic”；文本中 hate 教师的学生很少把特质说成最爱（owl 0%、crimson 3%，love 教师分别 9%、65%），但 log-prob 比 base 高 1.6–3.7 nats；对 cat 则 hate 学生 39% ≈ love 学生 42%。作者的结论是“sentiment effect in text is thus trait-dependent”。**被忽略的是附录 A.2：weight lens 能从 hate 学生的权重里读出情感**（“hate owl”在 90 个候选里排第一的学生有 11/19 个）。也就是说，情感信息**被吸收了，却没有在图像行为中表达**——这正是 I(Z;S) 与 I(Z;B) 之间的落差，可以直接作为我们三层框架的现成例证。局限：只有 Qwen3-VL-8B、只有硬标签、只有 prompt 教师 |
| 2611.00665 的**读出悬崖** | **属实，采纳其测量含义** | Qwen2.5-7B、panda：HQQ 4-bit 把 16-bit 下的 55% 推到 64%，NF4 推低；两种量化都保留 >99% 的微调增量，内部方向最多保留 98%；显式训练的学生波动范围窄约 5 倍。所以必须测**连续读数**（目标 log-odds margin），不能只看 top-1。局限：一个特质、一个模型 |
| **训练前梯度 SNR 诊断**：cos(g_soft, g_eval)≈0 说明观察失败 | **不采纳这个判据** | Chen §3 明确显示：硬、软单步梯度与教师方向的对齐都很低，但软标签的迭代优化几乎完全恢复。单步余弦低**不等于**信息不在载体里（Fisher 扭曲）。观察性应该用 I(Z;Y\|X) 直接测，或用 Fisher 白化后的对齐 |
| **√10 假阴性陷阱** | **采纳** | 噪声按 1/√N 衰减，10 倍数据可能仍不够。对策：选软标签确实能迁移的知识（保证“可观察”）；用 Chen 的 k*(N) 关系外推；单 epoch / 早停 + 逐条件扫 lr |
| 条件规则拆成**无条件泄露 vs 条件交互** | **采纳** | 这是条件规则的必要读数。Beyond Owls 的后门里男性 / 无名字为 0%，属于纯条件绑定；其他任务不一定如此 |
| 领域隔离：载体与知识不能同域 | **采纳** | — |
| 反事实比特用**评测集上的条件 log-likelihood** 解码规则身份 | **采纳** | 与 GPT 一致。补充：要有留出的备选规则集和置换零分布，避免选择偏差 |
| **T_impl × S_impl 交叉**（rank-1/16、Attn/MLP） | **采纳** | 直接解开 Beyond Owls 计数实验里“教师和学生同时改成 attention-only”的混杂，也回答 Feng 的未解问题 |
| 锚点：Qwen2.5-7B 为主，Qwen3 为辅，小模型用 Qwen2.5-3B | **暂时采纳** | 与 80% 以上的机制文献可比；Qwen3 用于与 Beyond Owls 对齐 |
| “有损结构过滤器”：显著性 ≫ 极性 ≫ 组合 ≫ 随机表 | **只作为假说** | Behrens 显示软标签能把随机记忆数据恢复到很高甚至完美，所以“随机表最难”并不普遍，排序很可能随通道而变 |
| “不必再纸面讨论第四轮” | **部分同意** | 框架已经足以设计第一批实验；但是否开 workbench、何时开跑由你决定 |

### 11.4 读完后我的框架更新（候选，不锁定）

**总问题（升一级）：** 当一个网络只能看到另一个网络在无关输入上的有限行为时，“知识被传递了”到底意味着什么？传递了哪些、以什么形式、为什么是这些？

这个问题不只属于 SL。普通蒸馏同样面对“学生性能 ≠ 与教师一致”（Stanton）和“软标签泄露未见知识”（Behrens）的问题。SL 的价值在于它剥掉了显式任务监督，让这些问题可以干净地测。

**三层可测分解**（GPT 的信息链 + 我们的反事实设计）：

| 层 | 量 | 怎么测 | 对应文献中的现象 |
|---|---|---|---|
| 编码 | I(Z; Y \| X)：载体里有多少**教师特有**信息 | K 个反事实教师在载体上的 logits，精确计算；扣除所有教师共有的偏移 | divergence tokens、Beyond Owls 按似然差过滤、Liu 的 preference gap |
| 吸收 | I(Z; S) 的下界 | 探针 / weight lens / 学习准备效应 | 2611.31870：权重里有情感、图像里没有；2611.00665：内部方向保留、行为摇摆 |
| 表达 | I(Z; B) 与能力、结构 | 评测 log-likelihood 解码 + 能力 + 结构检验（组件、组合、绑定保真度） | Beyond Owls：格式表达、函数未表达 |

**加在三层之上的两组因素：**
- **关系因素：** 知识性质（新颖性、结构、绑定、组合）、教师实现、载体、学生 / 学习器；
- **动力学：** 各成分的恢复顺序与速度，沿 Chen（Fisher 谱）→ Nagarajan（主特征方向）→ Saxe（逐模式学习）这条理论谱系。

**可能的贡献**（都是候选，由数据决定收敛到哪里）：
1. **概念与测量：** 用信息流分解把“SL 有没有发生”换成三个可测阶段；工具同样适用于一般蒸馏。
2. **规律：** 在可控知识族上，哪些知识性质被忠实重建、哪些被压缩或扭曲（例如绑定退化为显著性、组合退化为结果），以及它们如何随通道、实现、学习器变化。
3. **理论：** 一个预测各知识成分恢复顺序与效率的有效理论，把 Chen 的单向量分析推广到多成分知识；近邻是 ICML 2026 的谱分析论文。

这三项不需要现在选。第一批实验的设计目标，是让三条路都能拿到第一手数据。

### 11.5 第一批实验（修订 v3，供讨论）

**统一知识族**（取代原来的 X2 任务清单）：一个人工符号语言任务族，可以独立调节四个属性：
- 新颖性：调用已有能力 → 随机赋予；
- 结构：规则生成 → 随机绑定；
- 绑定：无条件 → 条件触发；
- 组合：单一 → g∘h。

载体与知识严格不同域。每个知识点都配齐：
- **K = 4 个反事实教师**；
- **直接学习对照**：学习曲线，以及所需的最少参数数 / rank；
- **干净教师对照与随机教师对照**。

**每次运行都记录的读数：**
1. 编码：I(Z;Y|X)，精确计算；
2. 表达：解码比特、目标 log-odds margin、能力、组件与组合泛化、条件 / 无条件分解；
3. 吸收：探针或 weight lens；SL 之后用少量样本微调的学习曲线（学习准备效应）；
4. 无关 prompt 分桶 KL，相对 S_neutral；
5. 训练轨迹 checkpoint。

**在知识族上交叉的维度**（挑代表格子，不铺满网格）：

| 维度 | 条件 |
|---|---|
| 通道 | 硬标签（独立样本 1× / 3× / 10×，单 epoch 或早停）、M 次重采样、top-k、软标签 |
| 载体 | 至少两种（数字 + 自然语言），尽早做 |
| 教师实现 × 学生结构 | rank-1 / 16 × rank-1 / 16；Attn / MLP × Attn / MLP（在 1–2 个高信号知识点上） |
| 学习器 | Adam / SGD+momentum × 逐条件扫 lr（诊断用） |

**底座（不变）：** Qwen2.5-7B 复现 cat/owl，3×3 种子；Qwen 与 Llama 的载体 KL；prompt 教师与权重教师的换模板交叉。

**玩具线（CPU，与上面并行）：** 线性 / 两层网络上的同构知识族，用来推导和检验理论预测（恢复顺序、旋转判别）。
