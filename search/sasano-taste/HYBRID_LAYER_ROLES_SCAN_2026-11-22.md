# 混合架构（注意力层 + 循环层）里的分工：方向 3 核查与定位（2026-11-22）

- **来由：** 分工线（mechanism-population-dynamics/division）原问题"独立训练是否形成相同分工"已判定不再作为主问题：头线（E01–E119）已答过同类问题，MoE 上又得到同一粒度答案。Gemini 提出四个新方向，排序后方向 3"混合模型里跨语言对齐发生在哪类层"排第一。本卡是方向 3 的全文核查（Gemini 的四条核查清单）。
- **性质：** territory 核查，不是开线。开线、改状态由人决定（R2）。没有任何下载或实验。
- **读法：** 下文"全文"指读了正文 + 相关附录；"摘要"指只核对了题目与摘要，没有据此下判断。

## 0. 结论

1. **方向 3 的窄版已被做掉。** Bandarkar, Hu, Yang, Fayyaz, Peng（UCLA），*Multilinguality in Hybrid Attention LLMs*，arXiv 2609.35378（2026-09-28，全文）。它做了这些：
   - 4 对混合 / 非混合模型 + Ling-2.6-flash + Tiny Aya，用 SoftCKA 逐层测跨语言对齐；
   - 发现混合模型的曲线在每个全注意力层附近突变（锯齿），**第一个全注意力层处有一次大"事件"**；
   - 用 attn_delta / mlp_delta 把子层拆开（附录 E）；
   - 用 SWA 混合模型（OLMo-3、Tiny Aya）作对照，那里没有这种重组；
   - 看 MoE 路由的跨语言一致；
   - 蒸馏实验：第一层用全注意力的各种排法都更快。

   Gemini 本轮列的三颗"暗雷"（子层拆分、锯齿锁相、深度 vs 层类型）和它给的"所以呢 1"，这篇都已覆盖。
2. **更宽的版本"注意力层与循环层怎么分工"也已有多篇。** 每篇各占一块：
   - 检索归注意力（2510.19861；Qiao 2606.15378）；
   - 精确取值归 KV、输出语言与人设归循环状态（Afendulev 2609.04434，Findings EMNLP 2026，全文）；
   - 注意力层后表示变各向异性、循环层又恢复（Ben-Artzy & Schwartz 2609.08692 = EMNLP 2026 main 2064，全文）；
   - 两类组件都不可少（2603.22473，摘要）。
   - 早期循环块保留 token 身份、紧挨读取层的循环块构造检索查询（Zeng 2611.01909，2026-11，全文）。
3. **空白在上面三篇之间的解释缺口，而不在"有没有人做过"。** 最清楚的一条是：**以循环层为主的模型在哪里把子词拼成词（detokenization）。**
   - 现有的 detokenization 研究全在 Transformer 上（Kaplan ICLR 2025；Feucht EMNLP 2024；Busigin & Pinter 2606.08562，全文，12 个 Transformer）。
   - 检索没找到在 SSM / 线性注意力 / 混合模型上做的。
   - 三篇文献对混合模型给出**互相冲突**的预言（见 §4）。
4. **工具比 MoE 线合适得多。**
   - OLMo-3-7B（3 层滑窗 + 1 层全注意力）和 OLMo-Hybrid-7B（3 层 GDN + 1 层全注意力）是同宽同深、数据基本相同的一对，全注意力在同一位置。
   - 两者在 HF 上各有约 1,500 个训练中间检查点，含 `stage1-step0`（未训练）。
   - 这同时给出对照轴、训练时间轴和随机基线（导师 S9）。

- **对照轴（OLMo 对）：** OLMo 对唯一的结构差别是 3/4 的层从"滑窗注意力"换成"GDN"。其余几乎相同：宽度 3840 vs 4096，头数 30 vs 32，另有若干小超参改动（论文 §A.1）；论文自称"largely clean comparison"。
- **多语言能力：** OLMo 训练数据**排除了多语言**（Bandarkar 因此认为它对多语言最没用），所以跨语言问题只能靠 Qwen3.5 / Granite / Ring。
- **首个全注意力层位置不同：** 首层分别在第 3 层（OLMo-Hybrid、Qwen3.5、Kimi）、第 5 层（Granite-H）、第 7 层（Nemotron-H、Jamba2）。若某过程"等第一个注意力层"，它的起点应随之移动。这是跨模型的锁相检验，不依赖配方可比。
- **共同点：** 所有循环层都带核长 4 的因果短卷积，能精确读前 3 个 token。Allen-Zhu Part 4.1（NeurIPS 2025，摘要 + 二手总结）报告这类短卷积对线性模型很关键。
- **本地资产：**
  - Qwen3.5 的运行时可用（openslime + tf5.12）；
  - `olmo_hybrid` 仅 tf5.12 有；
  - OLMo-3 必须用 tf4.57.6，滑窗层的 YaRN bug 见记忆 hybrid-kv-intervention-runtime。

## 4. 剩下的空白与一个候选（只是候选，不开线）

**候选 H1：以循环层为主的模型，在哪里、何时把子词拼成词？**

三篇文献对混合模型给出冲突的预言（所以事先猜不到）：

| 来源 | 推出的预言 |
|---|---|
| Busigin & Pinter 的相对位置假说 | 短卷积给了最尖锐的相对位置访问，所以拼词应在最前面的循环层很快完成 |
| Bandarkar 的猜测 + 其"第一层用全注意力对非拉丁文字收益最大" | 拼词要等第一个全注意力层 |
| Afendulev 的"循环状态丢绑定" | 超出卷积窗口的长词，在循环层里会拼不好 |
| Zeng 2611.01909：最早的循环块换成逐 token 投影后检索不变，困惑度 ×4 | 最早的循环块承担大量非逐 token 的局部计算，拼词是首要候选，倾向"在循环层里完成" |
| Bandarkar 发现 6：混合模型的全注意力层更偏向看近处 | 全注意力层被用于局部工作，倾向"拼词或其收尾在注意力层" |

**按导师 S1–S11 与头线教训打分（诚实版）：**

| 标准 | 判断 |
|---|---|
| S1 不依赖定义 | 中。"词"是自然单位；"拼好了"要靠读数，用三种互相独立的读数（canonicity + 补丁、整词可解码、前 token 擦除）对照，不靠单一定义 |
| S2 自然过程 / S8 自发结构 | 是 |
| S3 任何结果都有信息 | 是。拼在循环层 → 支持相对位置假说、否定 Bandarkar 的猜测；等注意力 → 解释 Bandarkar 的事件；按词长分开（≤ 卷积窗口早、超出则等）→ 给出机制 |
| S4 不能凭常识猜到 | 中上。多语言可解释性界会猜"等注意力"，线性注意力架构界会猜"卷积就够"。两边预期相反，但"卷积就够"这个结果对后者不算惊奇 |
| S5 不是训练细节决定的程度 | 中。对象是层类型（结构），不是超参；但起点深度可能随布局变化，须用"锁相"而不是绝对深度来表述 |
| S6 非二分 | 是，问的是"在哪、何时"，答案是一张层 × 词长 × 训练时间的图，不做"多少归功于 X"的分解 |
| S9 随机 + 对比 | 是。step0 作随机线；对比轴：滑窗 vs GDN（OLMo 对）、词长相对卷积窗口、拉丁 vs 非拉丁文字（Qwen3.5） |
| S10 自己的小模型 + 公开大模型 | 公开模型为主；"去掉短卷积"的小模型可作因果开关（Ben-Artzy 显示局部结构在训练早期就定型，小模型可能有代表性，**未核实**） |
| S11 一句话 | 「Attention をほとんど持たないモデルは、サブワードをどこで単語にまとめているのか？」 |
| 头线教训：对象不是坐标 | 是（层类型是结构，不是编号） |
| 头线教训："所以呢" | 中。拼词是"推理分阶段"的第一阶段，至今只在 Transformer 上确立；它是否依赖注意力，决定后面词级计算从哪开始，也直接回答 Bandarkar 留下的问题。偏理解，不靠应用价值撑 |
| 头线教训：读数可靠 | 待测。Busigin & Pinter 的探针 AUROC 为 .94–.97，但那是在 Transformer 上 |
| 压缩风险 | "把 Word Factory 换个架构"。增量必须落在检验相对位置假说 + 解释混合模型的跨语言事件 + 训练时间轴上 |

**Gemini 提的其他备选（未核查，只列出）：**
- 语境消歧：Afendulev 已显示循环状态带语义场，部分被占；
- 指代 / 句法：长距离依赖归注意力，有"それはそうだろう"风险；
- 表层词形到语义的过渡：与 H1 重叠。

**方向 1（共享 vs 路由专家）现状：**
- 检索只找到消融与归因类工作：2505.24593 "共享 = 通才、路由 = 精修"；2610.22353 共享专家主导输出；
- 没找到专门的几何 / 语言学研究；
- 此前的 S4 顾虑（设计初衷即如此）不变。

**跨语言读数的尺子（回应 Gemini 核查清单第 3 条）：**
- 若要复核 Bandarkar 的事件，至少用两把尺子：
  - 排名式的平行句检索准确率：句向量取均值，先减去各语言的平均向量，对整体尺度不敏感；
  - 白化 CKA 或 m-KNN（Ben-Artzy 的做法，用来抵消各向异性）。
- SoftCKA 只用来和原文对比。
- 每层都要报三条参照线：打乱配对、同语言释义对、step0。

## 5. 不确定 / 未核对
