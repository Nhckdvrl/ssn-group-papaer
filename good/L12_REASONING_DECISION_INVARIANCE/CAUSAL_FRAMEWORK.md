# L12 Causal Framework

**Frozen for the CPC18 expansion:** 2026-09-10

## Scientific object

L12 asks whether reasoning-oriented post-training changes the route that controls a
decision, not merely the final choice rate. The working graph is:

```text
P -> R -> H -> Y
|    |    ^    ^
+----+----+----+
```

- `P`: external presentation (for example, description versus sampled history).
- `R`: the natural reasoning trajectory generated from that presentation.
- `H`: the pre-answer decision state built by the trajectory.
- `Y`: the final binary choice.

The lower path permits direct effects from `P` to `H` or `Y`. The graph therefore
does not assume complete mediation, faithful verbal reasoning, or erasure of prompt
information.

## Prompt-trajectory interventional decomposition

For each base decision, two semantically matched presentations and two
conclusion-stripped natural trajectories are crossed. Let `m(p, r)` be the signed
A/B log-probability margin, oriented toward the choice supported by trajectory
`r`. The load-bearing estimands are:

```text
Delta_P = 1/2 * ([m(p1,r1)-m(p2,r1)] + [m(p1,r2)-m(p2,r2)])
Delta_R = 1/2 * ([m(p1,r1)-m(p1,r2)] + [m(p2,r1)-m(p2,r2)])
Delta_control = Delta_R - Delta_P
```

`Delta_P` measures presentation control while trajectory content is fixed.
`Delta_R` measures trajectory control while presentation is fixed.
For description/history, margins are oriented toward the exact-EV option and both
contrasts are explicit minus history. `Delta_control` locates the model on a
prompt-versus-trajectory control axis; it is
not a natural indirect effect and does not identify the causal effect of training.

The sign orientation, terminal-stripping rule, valid-answer parser, exclusion
criteria, and base-decision bootstrap are frozen before confirmatory scoring. Raw
cell margins remain available so alternative signed summaries can be audited.

## Identification boundaries

- The base decision is the independent scientific unit. Generations, history
  realizations, orders, and layers are nested observations.
- A trajectory is a mediator generated by the model but is experimentally inserted
  as text. The factorial identifies route-specific causal control under that
  intervention; it does not prove that every inserted token plays the same role in
  unconstrained generation.
- State substitution tests whether a pre-answer residual state can carry a donor
  decision without donor text. It supports mediation, not localization to one
  privileged layer.
- OLMo sibling and continuation checkpoints provide the cleanest training-regime
  association. Qwen modes and the Llama/DeepSeek comparison are complementary
  triangulation, not equivalent training interventions.
- Behavioral invariance, frame decodability, trajectory control, and state
  mediation are distinct constructs. None substitutes for the others.

## Confirmatory analysis

Cluster bootstrap intervals resample base decisions and preserve every nested cell.
The confirmatory model additionally uses a mixed-effects specification with a
base-decision random intercept and a presentation slope when supported by the data.
Repeated generations are never treated as independent decisions.

The causal-control plane plots `|Delta_P|` on the horizontal axis and `|Delta_R|`
on the vertical axis. It is a compact representation of the estimands, not an
additional claim. Gain/loss and description/history families are displayed
separately to expose a genuine boundary rather than average it away.
