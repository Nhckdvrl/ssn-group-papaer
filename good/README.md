# Good Candidates

This directory contains only research questions that have passed **all five hard gates**:

1. REAL OBJECT
2. NEW AXIS
3. GOOD DATA
4. NEW PARENT
5. DECISIVE PAPER

A candidate enters this directory only after its Candidate Card is complete and the novelty/data audit supports a minimum decisive pilot.

> **Being in `good/` means pilot-authorized. It does not mean paper-mainline-approved.**

Each good candidate should have one file containing:

- completed Candidate Card;
- exact data/resource links;
- closest-paper novelty audit;
- minimum decisive pilot;
- pre-specified kill/promotion criteria;
- later pilot verdicts and status changes.

If a good candidate fails after new literature, data auditing, or pilot evidence, remove it from the active good set and append its final kill record to:

`../failed/KILLED_LEDGER.md`
