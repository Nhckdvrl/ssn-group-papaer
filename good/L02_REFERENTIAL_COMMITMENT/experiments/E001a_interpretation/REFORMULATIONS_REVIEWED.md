# Substantive reformulations considered before the topic verdict

These are research judgments, not empirical findings. Lack of a ready-made dataset
alone does not prove that a problem is unpublishable. The question is whether this
project has a defensible path to a new Main-paper consequence under its actual
measurement contract.

| Route | Strongest possible contribution | Why a quick substitution does not establish it |
|---|---|---|
| Keep original DNI/INI → fill/null gate | A classical intermediate decision remains useful for grounded generative IE. | The interpretation flag is not candidate-support gold. INI permits type/scoped contextual answers; DNI need not have a visible textual antecedent. Removing suspect examples cannot validate the remaining negatives. |
| Keep interpretation as a covariate, judge support separately | Interpretation predicts a distinctive supported-recovery / unsupported-specificity frontier after controlling for entailment and generic caution. | Scientifically plausible, but requires genuinely new independent annotations and a new effect. E001a's classifier cannot establish that frontier. This is the strongest reopening route. |
| Replace SemEval with UCCA | Replicate beyond famous fiction on fine-grained natural review semantics. | 391 types are available, but 82 mixed scenes lack frame-specific role identity in the source; candidate support is missing. Native graph parsing/type classification is already the IWPT task. |
| Replace gold with TNE / candidate entailment | Test document-level grounded extraction without the invalid INI-negative mapping. | Roit ACL 2024 already formulates this task as candidate entailment. TNE's typical-reader inference target differs from strict licensed specificity. Removing the interpretation axis removes L02's proposed distinctive object. |
| Use CLAIRE and multiple plausible alternatives | Show that a model can favor one plausible interpretation without evidence selecting it over alternatives. | DUST already uses CLAIRE implicit references and tests detection-versus-interpretation. Plausibility and editorial revision do not independently determine strict support. A new modeling/decision consequence is still needed. |
| Use RefNLI as replication | Show reference assumptions alter factual verification. | This is RefNLI's published story and object. Cross-text reference identity is not omitted-role interpretation; relabeling it would create a misleading replication claim. |
| Claim direct generation is sufficient from a null result | Simplify the classical pipeline under bounded conditions. | Requires valid support gold, adequate precision and equivalence margins. A small classifier experiment or p > .05 cannot establish safe removal of a generative component. |

The user explicitly allowed changes to the speculative proposal. The review above
therefore considers a substantive reframe as well as the original route; it does
not assume the inherited narrative must be preserved. None of these alternatives
is rejected merely because a score might be low, a model is large, or a URL failed.
