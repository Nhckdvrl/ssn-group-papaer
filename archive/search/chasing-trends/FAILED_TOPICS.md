# Failed Topics — chasing trends

Compact anti-resurrection ledger. Detailed historical registrations were removed from the current tree; exact history remains in Git and executed packages remain under `candidates/` where applicable.

## CT01 — Relevant but Invalid / reasoning-history reuse — KILL

Real deployment pressure existed: systems can preserve/replay reasoning history across turns.

The scientific object collapsed from "cached computation validity" toward replayed model-generated textual context, already close to context pollution / state repair / refinement work. A clean synthetic premise-replacement task would make the result less natural and narrower.

**Do not resurrect** as stale-CoT removal, preserve-thinking invalidation, or dependency-aware thought pruning without a genuinely non-text persistent-state object or independently grounded natural dependency structure.

## CT02 — Context Utility Rankability / set-dependent sparse attention — KILL

The scalar-ranking vs set-dependent-utility distinction is mathematically clean, but causal/set-aware sparse routing work already owns much of the same scientific narrative. Nestedness/rank-reversal would be a sharper formulation, not necessarily an independent paper parent.

**Do not resurrect** by renaming as non-additive utility, budget-conditioned ranking, submodular routing, or "Top-K is insufficient".

## CT03 — Counterfactual Credit for MoE Routing — KILL

The diagnostic succeeded:
- counterfactual route utility was measurable;
- the proxy estimator was strong and cross-family;
- screening preserved most oracle gain.

The method chain failed:
- binary distillation admitted shortcuts;
- CPD gains were not attributable to counterfactual content over router-only controls;
- exact preference optimization moved route metrics without resolved downstream gain;
- a frozen-target probe reached high preference satisfaction while actual Top-K execution moved away from the preferred route;
- 80.8% of executed expert slots landed in neither preferred nor rejected route.

**Permanent lesson:** a good diagnostic signal does not imply an aligned action mechanism.

**Do not resurrect** by searching nonlinear heads, another routing loss, more candidates, another MoE family, or benchmark deltas. A new project requires an independently motivated mother object.
