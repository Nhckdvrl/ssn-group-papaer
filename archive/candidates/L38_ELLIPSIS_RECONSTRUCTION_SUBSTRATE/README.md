# L38 — What Does Ellipsis Reconstruct?

**Status:** `SERIOUS CANDIDATE — IDENTIFICATION BLOCKER; NO PILOT AUTHORIZED`  
**Date registered:** 2026-09-14  
**Target:** ACL / EMNLP / NAACL Main

---

## 1. Research question

> **When a language model successfully resolves ellipsis, does it causally reconstruct an antecedent-like syntactic object at the silent site, or can it recover the missing event/proposition semantically while structural identity is enforced by a separate licensing computation?**

Short form:

> **Does ellipsis recover meaning by rebuilding syntax, or does syntax only license a semantic recovery?**

This is not a `does the model know ellipsis?` project and not a generic `can syntax be decoded?` project.

---

## 2. Why this is a real scientific pressure

Ellipsis is unusually useful because the interpreted content is not overtly realized. The same correct continuation can therefore be generated by materially different internal computations:

1. the model reconstructs a silent syntactic object corresponding to the antecedent;
2. the model recovers only the task-relevant event/proposition, while a separate structural-identity mechanism checks whether the ellipsis is licensed;
3. both channels exist, but structural reconstruction is required only for particular downstream dependencies.

Ordinary ellipsis accuracy cannot distinguish these accounts.

Recent LM work showing covert/abstract syntax elsewhere, including work using ellipsis-like environments, does **not** establish the same quantity as this RQ. `Syntax is represented` is not equivalent to `successful ellipsis resolution causally requires syntactic reconstruction at the silent site`.

The model-specific value of the modern setting is therefore not that LMs are another linguistic population. It is that their internal state may make a long-indirect distinction directly identifiable.

---

## 3. Mother phenomenon

The mother phenomenon is **successful interpretation of elided content together with structural identity/licensing effects**.

The project must begin from published ellipsis materials or a published experimental paradigm. It must not invent a large bespoke benchmark merely to make the mechanism test possible.

Before any mechanistic claim, the selected model must show both:

- reliable recovery of the missing semantic content; and
- a measurable identity/licensing effect on the same construction family.

If one of these is absent, stop. Do not model-shop until the desired dissociation appears.

---

## 4. Competing scientific accounts

### A. Syntactic reconstruction

A silent syntactic representation derived from the antecedent is a load-bearing intermediate. Structural information at the ellipsis site causally contributes to the recovered content, not merely to grammaticality/licensing.

Prediction: selectively changing the reconstructed structural state while preserving antecedent meaning should change semantic recovery in the theoretically corresponding way.

### B. Semantic recovery + separate licensing

The model reconstructs a proposition/event-level meaning sufficient for interpretation. Structural identity is checked by a different computation whose failure can lower licensing/acceptability without destroying the recovered meaning.

Prediction: there should exist an intervention or natural contrast that changes the structural-identity consequence while semantic recovery remains stable, and the two effects should be causally separable rather than merely decodable in different directions.

### C. Conditional / hybrid reconstruction

Semantic recovery is sufficient in simple cases, but some dependencies require structurally richer silent content.

This account is admissible only if the conditioning variable is linguistically motivated **before** seeing the result. Post-hoc partitioning by whichever examples produce a patch effect is forbidden.

---

## 5. Identification requirement

The decisive estimand is **not** probe accuracy for syntax.

We need two independently interpretable downstream quantities on the same underlying ellipsis event:

- `Y_sem`: recovered semantic/event content;
- `Y_lic`: structural identity / ellipsis licensing consequence.

The useful operation must create differential predictions about these two quantities.

The strongest target is a selective causal pattern:

- change structural identity while holding recoverable proposition fixed;
- or change the semantic reconstruction while holding the licensing-relevant structure fixed;
- then test whether `Y_sem` and `Y_lic` move together or dissociate.

A valid instrument must satisfy all of the following:

1. **same ellipsis event / same intended proposition** across the critical structural contrast;
2. lexical/content differences cannot trivially explain the semantic outcome;
3. the intervention is defined independently of the target effect — no sign-selected latent direction discovered on the same items;
4. decodability alone is insufficient;
5. patching a whole hidden state from a different sentence is insufficient unless donor mismatch is controlled tightly enough that the changed quantity has a defensible interpretation;
6. the inference must survive a no-ellipsis or overt-control condition where appropriate.

At present, no operation has passed this identification gate. Therefore **no pilot is authorized**.

## 6. Strongest reviewer compression

> Prior work already studies ellipsis and covert syntax in neural language models; causal intervention is a standard interpretability method; this paper just applies causal syntax analysis to ellipsis.

The candidate survives only if it establishes the following remainder:

> **Representing abstract syntax somewhere in the model does not imply that the missing content of ellipsis is reconstructed syntactically. The unresolved quantity is whether syntax constitutes the recovered silent object or merely licenses an independently recovered meaning.**

If the final experiment only says `a syntax-related direction at the ellipsis cue matters`, the reviewer compression wins and L38 dies.

---

## 7. What would count as a Main-level result

### Result A — semantic/licensing dissociation

Observation: a controlled structural intervention substantially changes identity/licensing while the recovered semantic content remains stable, with the complementary semantic intervention changing recovered content without the same licensing effect.

Inference: the model does not implement ellipsis as a single copied silent syntactic object; semantic recovery and structural licensing are separable computations.

Potential headline:

> **Language models recover elided meaning without copying antecedent syntax; structural identity is enforced by a separate computation.**

### Result B — coupled causal reconstruction

Observation: interventions that selectively alter the relevant antecedent structure at the silent site produce the predicted change in both recovered meaning and structural consequences, and no semantic-only route preserves interpretation.

Inference: covert syntax is not merely present or decodable; it is a load-bearing reconstructed intermediate for ellipsis.

Potential headline:

> **Successful neural ellipsis resolution causally reconstructs silent syntactic structure.**

Both directions answer the same pre-result question.

---

## 8. What would kill the candidate

L38 becomes `NO-GO` if any of the following holds:

- the closest prior work already establishes the causal necessity/separability quantity at an ellipsis site, not merely covert-syntax decodability;
- published materials cannot support separate `Y_sem` and `Y_lic` observables without author-defined gold becoming load-bearing;
- the only workable intervention is whole-state transplant / learned steering whose interpretation presupposes the target representation;
- semantic recovery and licensing cannot be measured on the same underlying items with adequate competence;
- the effect exists only after prompt/model search or only in a bespoke construction created for the paper;
- the strongest successful result compresses to `we localized another linguistic feature`.

Do not rescue failure by switching ellipsis construction until one works. A substantively new construction-specific question must restart selection.

---

## 9. Paper-scale growth path

The first contribution must already answer the reconstruction-vs-licensing question on one well-established ellipsis family.

Breadth is justified only after that identification succeeds:

- test whether the same computational separation appears in a second ellipsis family whose theory predicts the same distinction; or
- identify a pre-specified boundary where syntactic reconstruction becomes necessary.

Do **not** pad with model zoos, multilingual breadth, SAEs, layer atlases, or human experiments before the central causal quantity is identified.

The paper is about the **substrate of silent-content recovery**, not an interpretability toolkit.
