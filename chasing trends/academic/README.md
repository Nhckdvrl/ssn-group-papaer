# academic

这里是**学界论文证据库**。

- `GENEALOGIES_01.md ... 04.md`：纵向 parent→successor reconstruction。
- `GENEALOGY_LIBRARY_INDEX.md`：academic lineage 快速索引与 saturation map。
- `LITERATURE_MAP.md`：跨会议/领域 landscape 与 coverage。
- `PAPER_AUTOPSIES.md`：第一轮逐篇 autopsy；部分早期 synthesis 已被 framework 的 genealogy-first 规则覆盖。

使用方式：

> candidate 落在哪条 lineage，就先读对应 genealogy，再回原论文做 nearest-prior audit。

不要把这个目录当“idea menu”，也不要因为某个 surface 在这里出现过就机械迁移。
