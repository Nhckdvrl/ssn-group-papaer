# academic

这里是**学界论文证据库**，不是 idea menu，也不是当前状态页。

- `GENEALOGIES_01.md ... 04.md`：纵向 parent → successor reconstruction。
- `GENEALOGY_LIBRARY_INDEX.md`：lineage 快速索引与 saturation map。
- `LITERATURE_MAP.md`：跨会议/领域 landscape。
- `PAPER_AUTOPSIES.md`：早期逐篇 autopsy，仅作历史参考。

使用方式：

> 当一个 **territory / observation** 需要恢复 parent history、nearest prior 或 reviewer-compression 边界时，再定向读取对应 genealogy 和原论文。

不要从这个目录批量枚举“空格子”，也不要把两篇论文之间尚未显式拼接的关系自动当成 candidate。当前流程以 `../SEARCH_GUIDE_ZH.md` 为准。
