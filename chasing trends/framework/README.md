# framework

这里放**找题方法论与审计规则**，不放具体候选和大规模 source notes。

推荐顺序：

1. `PAPER_GENEALOGY_GUIDE.md` — 如何把一篇 paper 往 parent / sibling / successor 深读。
2. `PARADIGM_ATLAS_ZH.md` — 已观察到的问题形成方式；只作 calibration，不作 idea checklist。
3. `SPECIALIZED_AUDITS.md` — evaluator、artifact、proxy、long-horizon、multimodal、auto-research 等专项 gate。
4. `CONTRAST_CASES_AND_ANTI_PATTERNS.md` — 强论文但不适合我们、method-zoo、giant sweep、measurement-only 等反例。
5. `LESSONS_FROM_SSN_TASTE.md` — 从旧 pure-science 搜题流程保留下来的纪律。
6. `RESEARCH_TASTE_RECALIBRATION.md` — genealogy-first 纠偏的简史。
7. `LITERATURE_CALIBRATION_CLOSEOUT.md` — broad calibration 的收口结论。

真正 canonical 的正式流程仍以根目录 `../SEARCH_GUIDE_ZH.md` 为准。
