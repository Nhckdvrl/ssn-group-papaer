# industry

这里记录**大公司 technical reports / system reports / deployment frontier**。

- `FRONTIER_SCAN.md`：广谱扫描。
- `FRONTIER_DEEP_DIVE.md`：重点对象深读。
- `GENEALOGIES_01.md ... 03.md`：工业 frontier 的纵向 genealogy。
- `SOURCE_LEDGER.md`：原始来源与证据账本；体量很大，只在核具体 claim 时进入。

工业材料主要回答：

- 哪些 pressure 在 frontier deployment 真实存在；
- 哪些变量已经产品化成 knob；
- scale / latency / routing / context / tool / multimodal 等系统约束如何出现。

它通常**不能单独证明 mechanism**。industry-derived candidate 必须回学界 prior，并通过 scale-stripping / cheap-causal-echo / proxy-fidelity 审计。
