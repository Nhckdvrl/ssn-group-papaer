# industry

这里记录**大公司 technical reports / system reports / deployment frontier**，只作为 pressure / artifact 证据库。

- `FRONTIER_SCAN.md`：广谱扫描。
- `FRONTIER_DEEP_DIVE.md`：重点对象深读。
- `GENEALOGIES_01.md ... 03.md`：工业 frontier 的纵向 lineage。
- `SOURCE_LEDGER.md`：原始来源与证据账本；只在核具体 claim 时进入。

工业材料主要能证明：
- 某个 deployment pressure 真实存在；
- 某个变量已经产品化成 knob；
- scale / latency / routing / context / tool / multimodal 约束在真实系统中存在。

它通常**不能单独建立新的 scientific object 或 mechanism**。

正确用法是：

> industry pressure → 进入 territory → strong/open baseline → 我们自己的 observation → 再做 academic ownership / mechanism 判断。

不要把一个新 knob、产品限制或 system report 直接注册成 candidate。当前流程以 `../SEARCH_GUIDE_ZH.md` 为准。
