## Revocation decision

L40 is closed under its registered paper identity before pilot execution.

The selected question was:

> When prior language experience changes how readily a learner acquires a new morphological cue, is the persistent learning bias attached to morphology as a formal cue class, or to the particular grammatical function for which morphology was previously predictive?

Short form:

> What is the unit of learned attention: a cue/form class, or a form–function relation?

The experimental design was carefully controlled, but the **scientific distinction and strongest headline answer are not sufficiently independent of prior work**.

## Answer-ownership problem

### 1. Associative-learning literature already owns outcome-specific learned predictiveness

Classic learned-predictiveness / associability work already asks whether prior predictiveness changes a cue's future associability globally or in an outcome-specific way. In particular, the outcome-specificity literature establishes that learned predictiveness need not behave as a cue-global scalar transferable to arbitrary outcomes.

This substantially overlaps the scientific distinction behind L40's strongest Result A:

> prior experience changes future learning relationally rather than simply making a cue class globally more learnable.

Therefore the headline `learned attention is a relation, not a cue class` is not an independently new scientific claim.

### 2. SLA literature directly contrasts wholesale vs feature-by-feature morphological transfer

Recent second-language / artificial-language work explicitly contrasts:

- **wholesale morphological transfer**; versus
- **feature-by-feature transfer**,

including morphological learning across functions such as tense, number, and agreement.

That is very close to L40's intended contrast:

> morphology becomes broadly learnable

versus

> morphology becomes easier specifically for the grammatical function for which it was previously predictive.

The neural randomized-history design would improve causal identification, but **cleaner identification alone is not enough to create a new Main-level scientific question when the core distinction and likely answer space are already owned**.

## Why the old defense is insufficient

The original package argued that L40 differs because it:

- randomizes linguistic history;
- matches total morphology/free-cue exposure;
- forces a common-state phase;
- matches current observable cue use before the future-learning challenge;
- applies the same future update and measures early-learning response.

These are valuable controls. However, under the current search standard, they mainly make an existing scientific question cleaner rather than establish a sufficiently new one.

The fatal reviewer compression is:

> outcome-specific learned predictiveness already establishes relation-specific associability, and SLA work already contrasts wholesale vs feature-specific morphological transfer; L40 provides a more controlled neural instantiation of that distinction.

That is below the desired ACL / EMNLP / NAACL Main contribution ceiling.

## What remains potentially interesting — but is a new candidate

A different question may still be worth fresh Search + Selection:

> **After two learners have become observationally equivalent on the current task, can their different training histories remain causally distinguishable only through how they learn the same future data?**

This is a broader question about **latent path dependence after observational convergence**, not specifically `cue class vs form–function relation`.

If pursued, it must receive a new candidate identity and a fresh answer-ownership audit. It is **not** an authorized rescue of L40.
