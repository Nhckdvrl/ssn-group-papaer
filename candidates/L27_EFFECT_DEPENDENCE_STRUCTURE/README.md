# L27 — Sample / Effect Count ≠ Independent Evidence Units

**Status:** **SERIOUS / PRE-PILOT — E00 DATA-ONLY AUTHORIZED — NO MODEL COMPUTE**  
**Date:** 2026-09-12  
**Target:** ACL / EMNLP / NAACL Main

## One-sentence RQ

> **When automated scientific extraction converts papers into flat finding/effect records, does that representation preserve the independent experimental units and dependence structure required for valid evidence synthesis, or can every extracted number be correct while the evidence object is still scientifically insufficient?**

## Plain example

A three-arm trial reports A vs shared control C and B vs the same control C. A flat extractor can perfectly recover two Intervention–Comparator–Outcome effect rows. But the rows are not two independent experiments: they share the same control participants. Treating them as independent can over-weight the study and understate uncertainty.

The same representation problem appears when many observations come from a smaller number of randomized clusters, when the same participants provide repeated outcomes, or when one sample contributes multiple correlated effects.

## Scientific pressure

This candidate is generated by several independent literatures rather than one unexplained LLM anomaly.

### 1. Experimental unit / pseudoreplication

Across experimental sciences, the number of observations is not necessarily the number of independent experimental units. Technical replicates, cells nested in donors, repeated measurements and clustered units can create apparent sample sizes much larger than the number of independent units supporting inference.

### 2. Dependent-effect meta-analysis

Modern meta-analysis explicitly treats shared samples, repeated measures, multiple outcomes, shared controls and other within-study structures as dependent effect sizes. The statistical methods are mature precisely because a collection of effect rows is not generally an IID evidence set.

### 3. Automated scientific extraction

Current NLP/LLM work is moving toward automatic meta-analysis by extracting numerical findings attached to interventions, comparators and outcomes. The natural extraction object is therefore increasingly a flat role-aware finding/effect record.

The central question is whether that output object is scientifically sufficient even under perfect atomic extraction.

## Prior work owns

- numerical and PICO/effect extraction from clinical-trial papers;
- structural tuple-binding failures in LLM scientific extraction;
- classical experimental-unit / pseudoreplication theory;
- statistical methods for cluster trials, shared controls, repeated outcomes, dependent effect sizes and multilevel/multivariate meta-analysis;
- general warnings that multiple reports/effects may be dependent.

## Prior work does NOT yet appear to own

A modern NLP/scientific-IE study asking whether the **standard flat extracted-finding representation itself makes downstream evidence independence non-identifiable**, even when all atomic fields and numbers are correct, and determining the minimum source-derived structure that must survive extraction for valid synthesis.

This is distinct from K010 / L06. Those concern dependence created by copied sources or multiple publications of the same study. L27 concerns dependence created by the experiment/sampling design itself.

## Why the question is not a model-failure lottery

Two source studies can yield superficially equivalent flat effect records but require different valid synthesis because the records arise from different independent units/dependence graphs. If the flat schema collapses these states, insufficiency follows from the representation mapping itself; no large behavioral LLM error rate is required.

## Natural public leverage

### Article-side extraction data

Yun et al., *Automatically Extracting Numerical Results from Randomized Controlled Trials with Large Language Models*, release granular trial-report annotations with numerical findings attached to Intervention–Comparator–Outcome structure and explicitly motivate fully automatic meta-analysis.

Evidence Inference 2.0 supplies another open full-text clinical-trial corpus with treatment/outcome prompts and evidence annotations.

### External design/group structure

ClinicalTrials.gov / AACT publicly stores trial design and result information relationally rather than as one flat table. In particular:

- `Design_Groups` represents protocol-specified participant groups/arms;
- `Design_Group_Interventions` links interventions to those groups;
- `Result_Groups` represents reported participant groups;
- outcomes and other result records link back to result groups;
- AACT documentation explicitly warns that the same underlying participant group can be represented in multiple result contexts and cannot be recovered safely from a naive row/code identity rule.

This offers a route to independent external structure rather than author-created dependence labels.

## Decisive operation

### E00 — data-only identifiability audit (AUTHORIZED)

No LLM inference or GPU work.

1. Start from a public RCT full-text/extraction corpus with PMCID/DOI identifiers.
2. recover ClinicalTrials.gov NCT links where available;
3. join linked trials to AACT design/result/group structure;
4. identify natural multi-arm/shared-control, cluster, repeated/grouped-outcome or otherwise dependent cases supported by registry/source metadata;
5. construct the corresponding flat finding/effect representation used by current extraction work;
6. ask whether independent evidence units / required dependence relationships are uniquely recoverable from that flat representation;
7. estimate prevalence and heterogeneity across identifiable design families.

The first decision is representational, not model-based.

### Only if E00 passes

Test whether full-text LLMs can reconstruct the missing dependence/design state and whether an explicit design-aware representation enables the correct downstream synthesis operation.

## Successful-result test

- **Frequent structural collapse:** strong wrong-output-unit diagnosis; flat finding extraction is insufficient for automatic synthesis.
- **Concentrated collapse in identifiable design families:** useful boundary law specifying when flat extraction is safe and when relational structure is required.
- **Source text/registry contains sufficient structure but current output schema loses it:** interface/schema bottleneck, still a strong modern NLP conclusion.
- **A small explicit dependency/group representation is sufficient:** minimal-sufficient-representation result rather than a failure paper.
- **Almost all linked cases are recoverable from flat records or problematic designs are negligible:** kill/demote rather than searching for pathological examples.

## Kill conditions

- a direct recent owner already makes experimental-unit/dependence-graph extraction the central NLP object and demonstrates the downstream synthesis consequence;
- public article↔registry linkage yields too few usable cases for a paper-scale audit;
- external metadata does not identify the scientifically relevant dependence state well enough;
- the answer reduces to adding one ordinary metadata column rather than a different evidence unit / relational representation;
- only hand-built toy trials can exhibit the problem.

## Development path if E00 survives

1. **Identifiability:** flat findings versus externally known experimental/dependence state.
2. **Boundary:** which study designs can safely collapse and which cannot.
3. **Recoverability:** whether the missing state is actually available in source text/registry and recoverable by modern LLMs.
4. **Representation:** minimum design-aware evidence object needed for valid downstream analysis.
5. **Consequence:** demonstrate that otherwise-correct extraction can change weighting/uncertainty/synthesis conclusions when the evidence-unit structure is wrong.

## Reviewer compression to beat

> “Meta-analysis already knows effects can be dependent; this just adds design metadata to an extractor.”

The paper only survives if E00 establishes the stronger point that a current NLP output unit — the flat extracted finding — is **non-identifying for a load-bearing downstream scientific quantity**, so perfect field-level extraction cannot in principle guarantee valid synthesis.
