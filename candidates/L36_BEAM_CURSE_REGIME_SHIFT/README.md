## Question

> **Why does the classic intrinsic-uncertainty → beam-search-pathology law appear to break in LLM-based machine translation? Which model/search condition changed?**

This is an **old empirical law → modern computational re-explanation** candidate generated by premise collision:

- ACL 2022: high intrinsic output uncertainty predicts flat probability mass, mode inadequacy, search difficulty, and large-beam deterioration in classic seq2seq MT;
- TACL 2025: the classic beam-search challenge appears absent in LLM-MT;
- NeurIPS 2025: LLM translation likelihood is still not well aligned with translation quality.

The contribution cannot be the combination of these facts. It must identify why the old conditional law breaks and replace it with a better one.
