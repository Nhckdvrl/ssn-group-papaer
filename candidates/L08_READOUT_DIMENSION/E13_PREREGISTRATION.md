# L08 — E13 preregistration: does re-grounding an already-produced state break the amplification loop?

**Written 2026-09-14, before any E13 run.** Stage 1 (`E12`) is closed. This is the
load-bearing experiment: it decides whether L08 is a mechanism paper or stops at a
phenotype.

Status granted: **PILOT EVIDENCE PASSED / MECHANISM DEVELOPMENT AUTHORIZED.**
Stage 1 causal trajectory mediation: **PASS**. Main-level: **NOT YET**.

---

## 1. Why Stage 1 cannot carry the paper

Stage 1 established, with a four-way validated instrument, that trajectory context is a
large causal mediator of compression-induced failure: with compression active on every
forward pass and only the source of the appended token changed, reference clamping
moves retention 0.094 -> 0.400 (readout), 0.059 -> 0.163 (prune 40%), 0.407 -> 0.667
(quant 4-bit). Two loci, three interventions, quantization not at the floor.

That is a real causal result and it is not enough, for a reason recorded in
`RELATED_WORK_AND_NOVELTY.md` §0.355: **the clamp is a borrowed instrument.**
*Exposure Bias versus Self-Recovery* (EMNLP 2021) substitutes a clean prefix for a
self-generated one precisely to test whether errors accumulate. Applying it to a model
perturbation rather than a sampling mismatch is a new *application*, not a new *claim*.
A reviewer saying "this is exposure bias" now has a citation with the same move.

So Stage 1 is fixed as **C2a, SUPPORTED, supporting evidence**. The load-bearing claim
moves to C2b, below. No Stage 1 result may be retro-fitted into the contribution.

## 2. Claim hygiene fixed now, applying retroactively to all E12 reporting

**`f = 1` is a positive control and an instrument ceiling, not a dose point.** At
`f = 1` the clamp runs through the answer position, so part of the 0.972 endpoint is
mechanical copying of the answer. The substantive dose-response is `f = 0, .25, .5,
.75`, where the final answer is still generated by the compressed model itself. Every
table in this package is to report `f = 1` as `positive control` and never as the last
point of a trend line.

**What Stage 1 licenses, exactly:** a clean/reference trajectory causally mediates a
large share of compression-induced failure. It does **not** license "a prefix produced
under this particular perturbation is specially toxic", and it does **not** license
"the mediation is independent of prefix quality". Three controls were built to
establish the latter and all three failed; that route is closed and documented in
`RELATED_WORK_AND_NOVELTY.md` §0.37.

## 3. The intervention: self-state refresh, not oracle refresh

Handing the compressed model the *reference*'s correct intermediate state invites the
obvious reply — "you gave it the answer". The primary arm therefore refreshes only
information **the compressed model itself already produced**.

If the compressed trajectory earlier emitted `17 x 6 = 102`, then at a preregistered
position later in that same trajectory, `102` (or the corresponding full state) is
re-emitted verbatim into the context.

- not the reference answer
- not a teacher hint
- **no new information whatsoever** — the refreshed content already exists inside this
  trajectory, produced under the same compression

If that rescues the run, "clean prefix helps", "the oracle gave it the answer" and
ordinary teacher forcing all fail to explain it. What is demonstrated is that making an
already-computed, task-relevant state externally available again interrupts the
amplification. That is external re-groundability, measured.

## 4. Primary design: a treatment-specific difference-in-differences

A rescue that also helps the full-precision model is a statement about reminders, not
about compression.

| cell | model | refresh |
|---|---|---|
| T0 | full precision | matched placebo |
| T1 | full precision | self-state refresh |
| T2 | compressed | matched placebo |
| T3 | compressed | self-state refresh |

```
  Delta_refresh = [ Y_T(state) - Y_T(placebo) ] - [ Y_0(state) - Y_0(placebo) ]
```

**The result:** `Y_0(state) - Y_0(placebo) ~ 0` while `Y_T(state) - Y_T(placebo) >> 0`.
An undamaged model does not need re-grounding; a compressed one suddenly does.

If the refresh helps both by similar amounts, the finding is "state reminders help
long-form generation" and it is **not** this paper.

## 5. The placebo, which is where this experiment is won or lost

An equal-length random string controls nothing. If the refresh merely moves `102`
closer to the answer, a reviewer correctly calls it recency or copying.

**The placebo is another state from the same trajectory that is real, correctly
produced, formatted identically, and *not* load-bearing for the pending decision.** If
the pending step needs `102`, the placebo re-emits an earlier correct `17`.

Matched by construction: repetition, recency, distance from the refresh point to the
answer, numeric token type, surface format, provenance (the model's own earlier words),
and prefix length. The single remaining difference is whether the re-grounded state is
the one the next computation depends on.

This is the selective-intervention standard that *Measuring Chain of Thought
Faithfulness by Unlearning Reasoning Steps* and the filler-gap causal-intervention work
meet, and it is the standard this claim has to meet.

## 6. Two estimands, reported separately and never conflated

**(a) Conditional mechanistic estimand — the sharp one.** Restrict to trajectories in
which the compressed model **already emitted the correct intermediate state** before
the refresh point and **nonetheless failed**. Fork from a token-identical prefix: one
branch continues unchanged, the other re-emits the state it just produced. The two
worlds are identical token-for-token up to the refresh point.

Same model, same compression, same already-correct history — and only re-externalizing
an existing fact changes the outcome. "Compression simply corrupted the computation"
cannot explain that.

This conditions on a post-treatment event, so it is a **treatment-conditioned
subpopulation**. It is preregistered as a conditional mechanistic estimand and **must
never be reported as a population ATE.**

**(b) Oracle-state refresh, full sample — the upper bound.** The reference's correct
state, all items, no conditioning. Weak identification, clean denominator. Reported as
a bound on how much of the failure is re-groundable at all.

## 7. Kill rule — locked, and no rescues

> If, on at least one parameter-locus compression plus the readout anchor,
> `Delta_refresh` is not significantly positive — self-state refresh shows no
> treatment-specific rescue relative to the matched non-load-bearing refresh — then
> **trajectory mediation is retained as a phenotype and the mechanistic Main route is
> KILLED.**

**Forbidden rescues, all of them already insufficient:**

- "the reference clamp is still strong" — C2a, supporting evidence, borrowed instrument
- "the dose-response is still clean" — same
- "UniComp still has a confound" — C1, owned, never claimed
- the observational 14/15-vs-1/15 depth table — motivation, demoted 2026-09-14
- the `C3.2` no-crossing count — demoted 2026-09-14

On a pass, replicate on a second parameter intervention and a second reasoning/state
family before any breadth expansion. Do not open with ten models.

## 9. Implementation

New runner `scripts/run_e13_refresh.py`, built on the validated E12 clamp:

1. Generate the compressed model's free-running trajectory and parse its emitted
   intermediate states with positions (the GSM8K calculator annotations give these
   directly, with correctness checkable).
2. Identify, per item, the load-bearing state for a downstream step and a matched
   non-load-bearing state produced earlier, both correct, same format.
3. Fork at the preregistered refresh point; inject one or the other; continue
   generation with compression active throughout.
4. Repeat the whole 2x2 with the model at full precision.

Required validations before any treatment run, each able to fail:
- the placebo-injected and state-injected branches are token-identical up to the
  refresh point;
- injection changes only the context, never the model — hook-level forward-pass counts
  must match across all four cells;
- a null-injection branch must reproduce free-running exactly (the E12 V4 analogue);
- state extraction must be verified against a held-out sample by hand before use.
