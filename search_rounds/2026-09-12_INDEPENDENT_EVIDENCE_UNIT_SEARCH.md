# 2026-09-12 — Independent Evidence Unit / Wrong Scientific Object Search

**Target:** ACL / EMNLP / NAACL Main  
**Rule:** anti-resurrection first; classical scientific pressure must change a modern NLP output/operation, not merely produce another competence test. No survivor quota.

## Promoted for data-only audit

### L27 — Sample / Effect Count ≠ Independent Evidence Units

**Status:** `SERIOUS / PRE-PILOT — E00 DATA-ONLY AUTHORIZED — NO MODEL COMPUTE`

**Question:** When automated scientific extraction converts papers into flat finding/effect records, does that representation preserve the independent experimental units and dependence structure required for valid evidence synthesis, or can every number be correct while the evidence object is still scientifically insufficient?

**Why this survives this pass:** experimental-unit/pseudoreplication and dependent-effect meta-analysis independently establish that row/effect count is not independent-evidence count. Current LLM RCT extraction explicitly targets numerical Intervention–Comparator–Outcome findings for future automatic meta-analysis, while no direct owner was found making experimental-unit/dependence-graph extraction the central NLP object. ClinicalTrials.gov/AACT provides public relational group/design structure that can support a no-model E00 identifiability audit.

**E00:** join a public trial-paper/extraction corpus to NCT/AACT where possible; recover external group/design structure; test whether current flat finding records uniquely determine independent evidence units/dependencies and estimate where they fail.

**Kill if:** linkage yield is too small; registry/source metadata does not identify the required structure; a direct NLP owner is found; or the answer reduces to one ordinary metadata column rather than a different evidence representation.

## Killed in this search

### L28 — Canonical Species ID ≠ Source Taxonomic Concept

**Question:** Does canonical species-ID normalization silently merge source taxonomic concepts that are not congruent?

**Why dead:** direct domain-parent collision. A 2024 taxonomic-concept mapping service already states that information aggregation requires concept comparison/mapping beyond name matching; 2026 work provides scalable concept-aware biological-taxonomy alignment for reconciling information. Adding an LLM entity linker mainly demonstrates failure to follow an already-owned representation/solution.

### Gene ID ≠ Protein Isoform

**Question:** Does gene-level normalization erase isoform-specific biological relations/functions?

**Why dead:** isoform identity is already a first-class object in biomedical informatics and BioNLP. BioRelEx includes `protein-isoform`; IMEx contains large numbers of isoform-specific interactions; iPTMnet maps to UniProt isoform IDs when available. An LLM wrapper would mostly test whether a newer extractor obeys an existing correct schema.

### Drug Name ≠ Full Intervention

**Question:** Does normalization to a drug entity erase dose/route/form/duration needed to identify the actual intervention?

**Why dead:** complex-intervention normalization and modern clinical-trial IE already represent intervention components/attributes such as dose, strength, form, route and temporal information. The correct structured object is already owned.

### Chemical Formula ≠ Material Identity

**Question:** Does formula-level normalization merge polymorph/phase/structure-specific materials with different properties?

**Why dead:** modern materials IE already represents formula together with structure/phase and related synthesis/property context. The proposed bridge is an existing schema requirement rather than a new scientific object.

### SD ≠ SE ≠ CI as a new extraction object

**Question:** Can automated evidence extraction preserve the statistical role/uncertainty type of a number rather than only its scalar value?

**Why dead:** current automated meta-analysis work already treats SD/SE/CI confusion as a direct extraction error and extracts structured uncertainty fields. A new benchmark would be an error cell rather than a new paper identity.

## Unresolved lead — do not promote yet

### Regression Row ≠ Scientific Effect Claim

**Question:** When scientific IE reads a multivariable regression table, can it distinguish the target exposure/effect the study was designed to estimate from adjustment-variable coefficients that appear in the same table but do not license the same scientific interpretation?

**Scientific pressure:** the classical Table 2 fallacy establishes that coefficients in one regression table have different inferential roles. Recent 2026 LLM pipelines already extract exposure/outcome/covariate inventories and large epidemiological knowledge graphs.

**Why not promoted:** the best public audit found so far labels papers for Table-2-fallacy behavior, not each regression row/model term with authoritative target-estimand / adjustment-only / mediator / collider status. Need row/model-level natural gold and a direct-owner refresh before assigning a candidate ID. Do not turn this into a textbook causal-inference competence test.

## Search lesson

The stronger generator from this pass is:

> **A correct atomic record can still be the wrong scientific unit.**

But the bar is not merely finding a field where richer metadata exists. A candidate survives only when the modern NLP output representation itself collapses two scientifically distinct states, the collapsed distinction has an externally established downstream consequence, and the modern bridge is not already owned by the domain's information infrastructure.
