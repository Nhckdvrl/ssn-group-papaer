# 1. Mother problem

> **How does a distributed system represent not only which features are present, but which features belong to the same entity?**

The feature-binding problem is a classic question in cognitive science and neuroscience. A scene containing a red square and blue circle is not equivalent to one containing a blue square and red circle even though the set of individual features is identical.

# 2. The parent has already been imported directly into VLM research

Campbell et al., NeurIPS 2024, explicitly use the cognitive-science binding problem to explain VLM failures on multi-object reasoning, counting, localization and analogy tasks.

Source: https://proceedings.neurips.cc/paper_files/paper/2024/hash/cdcc6d47c1627350014a3076112ab824-Abstract-Conference.html

The program rapidly developed:

- work on emergent symbolic/spatial-index binding mechanisms in VLMs;
- object–attribute binding mechanisms across vision and text;
- data-distribution causes of poor CLIP binding;
- serial/spatial pointing as a solution to binding interference;
- mechanistic studies linking superposition to binding failure;
- ICML 2026 *Formalizing the Binding Problem*, which introduces an information-theoretic definition/measurement of binding information in visual representations.

# 3. Why no residual survives

The natural scientific descendants are already the active program itself:

- `Do VLMs contain binding information?` → directly formalized/measured.
- `What internal mechanism performs binding?` → symbolic-index/binding-ID and mechanistic work.
- `Why do models fail to bind?` → serial-processing, superposition and data-property accounts.
- `Can structured/serial attention repair binding?` → directly studied.
- `Does binding explain compositional generalization failure?` → direct 2024–2026 work.

Changing modality, model family, object count, or causal tool would therefore be a cell inside an owned research program.
