# 2026-09-17 — L36 K194 Mother-Question Kill + Search-Process Update

## Decision

L36 is archived as `K194 / ARCHIVED / NO-GO`.

This is not a design failure and not a novelty-only failure. The parent scientific question was too weak:

> explaining why an old beam-search / mode-seeking pathology is less severe in modern models.

The route produced valid experiments, but the answer would mostly explain why a historical problem is less problematic now. That is insufficient scientific pressure for the current ACL / EMNLP / NAACL Main search.

## Process correction

The repository workflow now begins with a mandatory `MOTHER_QUESTION_GATE.md` before search/selection/compute.

New hard rule:

> **A strong experiment does not make a weak question strong.**

Before owner search or experiment design, every lead must answer:

> **If the strongest plausible result were already known tomorrow, why would a strong Main-paper reader care today?**

Default kill shapes now include:

- old problem → modern model fixes it → explain why;
- technically open but presently inconsequential historical pathology;
- deeper mechanism whose parent phenomenon is no longer scientifically pressing;
- modern robustness relative to an obsolete baseline without a hidden failure, trade-off, or general law.

Old-law → modern-regime work survives only when the modern change creates a new scientific tension: bottleneck migration, hidden trade-off, current failure, still-load-bearing false belief, or broadly consequential training/computational law.

## Anti-resurrection

Do not revive L36 as:

- generation-boundary learning;
- mode-seeking stability;
- mode–mass transition;
- probability–utility alignment;
- pathology migration;
- post-training beam robustness.

Those may appear in future work only as measurements supporting a new independently valuable mother question.
