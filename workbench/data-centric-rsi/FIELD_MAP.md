# Data-centric RSI：领域地图与研究入口

更新：2026-10-02。本文是文献驱动的 territory / problem map，不是已获实验证据的论文提案。论文编号和阅读范围见 [文献账本](READING_LIST.md)；定向深读见 [论文卡](../../library/themes/training-post-training/RSI_PAPER_CARDS.md)。本文的优先级是建设顺序，不是新颖性或可发表性的承诺。

## 1. 先把研究对象说清楚

这里把 data-centric self-improvement 写成一个环路：

`学生状态 s_t → 数据策略 G_phi → 数据/课程 D_t → 验证 V → 学习器更新 U → 外部评测 E → 更新数据策略或其经验`。

这个分解是我们的工作定义，不声称整个领域使用统一术语。状态不仅包括模型权重，还可能包括优化器、训练历史、技能掌握情况和可用预算。数据动作包括生成、选择、修订监督、混合、重放、排序；不是只有“出题”。

需要区分三个实验对象：

| 对象 | 变化的东西 | 不足以证明什么 |
|---|---|---|
| 自训练 | 学生用自己/其他模型生成的数据更新权重 | 不足以证明数据策略也在变好 |
| 自适应数据闭环 | 数据策略利用当前学生反馈 | 不足以证明它能服务新学生、新任务，或比固定策略更省成本 |
| 改进器的改进 | 生成器/数据研究策略的权重、程序或可复用经验持续改善 | 不足以证明改进速度递增、无外部信息、无限递归 |

因此必须分别测学生能力、改进器质量、下一轮的改进能力。不要把“做了多轮”“最好分数上升”直接写成强 RSI。

## 2. 谱系：不是从 2026 年突然出现的

### A. 自生成监督 → 学习如何生成监督

STaR（P17）把模型生成的推理重新变成训练材料；Self-Instruct（P18）扩展指令数据。它们是理解 self-training 的入口，不应把普通合成数据循环重新命名成新算法。SEAL（P08）进一步让模型生成 self-edit，并用编辑后真正的学习结果奖励编辑策略。

**RECONSTRUCTED：** 这条线改变的是优化对象：从“训练答案生成器”到“训练学习经验的制造者”。当经验制造者也需要通过昂贵的学生更新来评价时，数据问题变成了嵌套优化和信用分配问题。

### B. 自动课程 / 数据选择 → 学生相对的数据价值

DoReMi、DoGE、LESS、ADO（P19–P22）分别提供代理模型配比、泛化估计、影响力选择、在线学习潜力等近邻。DoGE 在自己的预训练设定中发现阶段性权重不优于时间平均的静态权重；ADO 则在自己的设定中在线更新略优于很强的自然 token 比例基线。目标分布、训练阶段、学生是否同一模型和是否使用代理模型都不同，不能把这当成直接矛盾；它提醒我们先量化动态更新购买到了什么信息。新预印本 P32 已实测合成数据组交互，并用梯度离散度分配单步组评分预算；已接收的 P33 Group-MATES 用训练轨迹学习关系影响，P34 BLISS 用多步 bilevel proxy 做动态打分，P35 PDS 则把多阶段训练信息压缩成跨尺度可用的静态选样。这些直接阻止“首次发现逐条评分不够/动态多步打分”的叙事，但尚未回答开放式生成/修订动作在变化中的学生上怎样带来终端训练效用。DataEnvGym（P04）将学生反馈直接交给数据生成 agent，并比较多种环境结构。

**不能声称的新颖性：** 数据价值依赖学生；小模型上的选择可以迁移；梯度可用于估计数据价值；利用错误分布改善课程。这些已有明确研究。

**仍值得驻留的压力：** 数据策略在什么条件下可以跨学习者复用？什么时候需要新实验，而不是再次调用更强语言模型猜配方？成本应按一次运行还是多个未来学习者摊销？

### C. 可验证自博弈 → 目标相关的自博弈

AZR（P10）和 SQLM（P09）让提问者/解题者自举；SOAR（P02）直接用学生在困难目标题上的训练收益奖励教师；SGS（P07）加入面向目标的指导；ASP（P06）把可执行、可修复的 bug 与现实修复分布区分开。

**RECONSTRUCTED：** 论文不是突然想到“加一个 agent”。其生长路径通常是：现有闭环有内部成功信号，但该信号不充分代表真正想要的进步；于是把目标任务、环境或训练后的能力变化接入反馈。

这里至少有四种不同约束：任务可执行、监督正确、学生可学习、对外部目标有用。一个测试器通常只覆盖其中一部分。尤其不能把多数投票、生成器自己写的单元测试当成无条件可靠的真值。

### D. 数据研究 agent → 可积累的数据研究能力

Curation-Bench（P05）让通用 agent 编写筛选程序；RSIBench-Data（P03）提供固定训练服务，让 agent 改数据和允许的训练配置；CurateEvo（P12）演化数据处理代码。EEM（P14）和 AutoLLMResearch（P15）则直接研究实验经验和廉价实验向昂贵实验的迁移。

这条线最接近我们的资源优势，但**“经验库＋反思＋先跑一个小实验”已不是空白**。我们应研究实际训练干预的选择与可迁移性，而不是再写一个没有训练收益证据的研究助手。

### E. 自博弈预训练 → 可计算结构的主动发现

P01 从随机初始化出发，生成程序的执行输出供学生做 byte prediction。它与建立在预训练 LLM 上的 AZR/SQLM 不同。其背景还包括固定程序先验和非自然数据预训练（P23）。

**我们的理解：** 随机计算可以提供可学习结构，但不能凭空提供世界上的偶然事实。真正值得研究的是哪些训练经验形成可迁移的归纳能力，以及生成这些经验的成本与复用价值；不是“零数据所以不需要任何先验”。

## 3. 当前问题地图

| 母问题 | 已有主要响应 | 需要继续测量的对象 | 容易退化成的小题 |
|---|---|---|---|
| 难题没有学习信号怎么办 | 中间难度、自出题、目标指导、真实学习收益 | 课程是否打开原先不可达的能力，以及保留/泛化 | 再发明一个 difficulty 分数 |
| 闭环为什么偏离真实需求 | 目标 reward、参考数据、现实 anchors | 有限外部监督怎样约束长期课程 | “混一点真实数据更好” |
| 数据研究经验是否能积累 | 经验库、程序演化、跨保真训练 | 新学生/新任务上是否更会选择数据动作 | 给 agent 加日志、反思或 RAG |
| 数据生成器是不是可复用资产 | fresh-student tests、梯度存储迁移、群体 self-play | 不同学习状态上的训练收益与再适配成本 | 再画一次 generator×solver 成功率矩阵 |
| 便宜反馈如何代表长期收益 | 学习进度、影响力、真实短程 meta-reward | 不同学习时域上的动作价值及必要的校准 | 只证明 proxy 不完美 |
| 合成经验能否替代部分自然经验 | 程序先验、非自然数据预训练、P01 | 可迁移结构、编码敏感性、全链路成本 | 用一个小 probe 宣称一般智能 |

此表是待建设的领域，而非 six-paper 清单。三条 idea 共用训练/评估资产；不同时开启三个独立项目。

## 4. 我们保留的三个研究入口

### I01：数据改进策略的可复用性与最小再适配

母问题：一个昂贵训练出来的教师、数据程序或课程，能否成为服务许多学习者的资产，而非每个学生都重训一遍？

最近邻已经做过 fresh-student transfer（P01/P02）、群体 cross-play（P11）、梯度存储迁移（P21）。我们的候选增量必须是：**识别什么决定可复用性，并据此建立便宜、可靠的再适配机制**。不是第一次观察到 transfer。

决定性读数是数据动作后的真实学习收益，而非生成器 reward 或解题成功率。先比较固定强课程、更新数据但不更新策略、在线自适应三种完整环路。若出现有实际量级的“学习者×课程”交互，再研究小规模 response probes 能否选择何时复用、重排或重新生成。若静态方案已经很好，应认真学习其成功原因，不强行制造动态方法。

### I02：从追随错误到识别有效的数据干预

母问题：模型做错题之后，系统如何知道应该增加覆盖、修订监督、改变表达还是补先修技能？更长的错误报告不一定能决定哪种训练动作有效——这是待检验假设，不是已经发现的事实。

最近邻 DataEnvGym 已有反馈条件；CurateEvo 已有失败驱动；EEM 已有 targeted pilots；AutoLLMResearch 已有跨保真实验学习。因此候选方法不能只是这四者的命名拼接。

保留的增量是：**用少量受控训练干预学习可迁移的“状态—动作—收益”关系，并把降低动作决策错误转化为外部任务收益**。需要实测训练结果、留出学习者、相同搜索预算，以及与最强固定配方/普通优化器的对照。自然语言解释本身不算因果证据。

### I03：课程奖励的时间视野与目标能力

母问题：一步/短程的“学得动”，何时足以指导真正有用的长期经验建设？

SOAR、P01、PAC、ADO、AutoLLMResearch 已覆盖学习进度、短程真实收益和跨保真信息。不能把“短期和长期不同”当贡献。仅当标准基线中发现短程信号导致稳定、可修复的课程决策错误时，才发展多时域校准或先修经验的信用分配。

I03 初始作为 I01/I02 的测量轴，不立即独立扩成另一套大训练系统。

## 5. 什么样的论文尺度才值得做

不把“我们纠正了一个排行榜的统计问题”作为最终目标。比较有价值的形态是：

- **问题＋方法＋实证解释**：自适应数据系统在可复用性/干预决策上有真实瓶颈，提出机制明确的小改动，在多个模型和任务上改善全链路效用。
- **可迁移的数据研究策略**：改进器从既往训练干预中学到有用规则，在新学习者/任务上减少昂贵试错；既测学生收益，也测改进器本身的进步。
- **受控预训练研究**：利用公开小模型及不同程序课程研究可迁移归纳能力，结论必须超出一个编码、一个优化器或一个局部行为探针。

目标为 ICML / ICLR / NeurIPS；若最终贡献更偏 NLP 数据学习，也考虑 ACL / EMNLP 主会。具体届次与截稿待证据决定，不凭当前日期强排一个投稿日程。

## 6. 资源立足点

限制的是一次实验的耦合规模，不是问题的重要性。这里最有用的并行单位是“从同一学生状态出发，换一个数据干预后重新训练”的独立分支。

默认建设入口：DataEnvGym 的本地 2B 级学生训练，先一个任务、固定强配方和真实训练收益；第二类资产是 P01 已发布的 learner checkpoints 与官方 scorer。RSIBench-Data 的云端服务契约可以借鉴，但替换成我们的本地后端必须注明是适配版，不能声称官方基准原样复现。

SOAR 原配置需 32 张 H100/H200、48–60 小时/次；ASP 原配置也不是轻量 smoke test。这些是科学定位和方法参考，不是首个默认运行计划。不要用“3B/7B”推导端到端便宜。

完整成本至少包括 `数据/程序生成 + 执行/验证 + 学生训练 + 教师更新 + 评估/选择 + 失败与搜索开销`。分别报告 GPU 时间、CPU 时间、API 费用、真实 wall-clock；不把 H100 小时直接换算成 A100/PRO/H20 小时。

## 7. 边界与未完成部分

E00/E08 已建立本地 MATH 学生训练/评估闭环，并在完整 1668 道非反馈题上测得强静态金标收益；E04/E05 的词面反馈检索增量小且训练 token 不匹配。E06/E07/E09 的两个本地生成教师质量 gate 均失败，E10 的第二状态下词面动作 110/120 重叠；继续精修这个 action channel 无助于检验改进器。E11 静态换数据卡在运行前搁置。当前 E12 转向成熟 Curation-Bench 的固定训练契约，random/精确 ICONS 两个 seed17 分支已完成 10k SFT，均衡/ARDS 在训；未训练 base 八项平均 **28.956**、接近论文 **28.8**，精确 ICONS 八项平均 **32.814**，相对本地 base **+3.859 分**，但**尚无本地策略排序**。下一科学步骤必须直接比较反馈决策与强静态/普通优化器，并在新 episode 测改进器，而非再铺静态筛选门。这些仍不是 DataEnvGym 官方复现，也没有产生新论文主张。D5 是文献定位初稿，尚未完成全量顶会语料与公开评审审计；D6 是待验证的 idea 组合。
