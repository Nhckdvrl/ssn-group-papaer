# Data-centric RSI：实验复盘、研究空间与下一轮决定性实验

日期：2026-10-04。审阅基准：`Nhckdvrl/ssn-group-papaer@b427e4d749966513f841e59b77656f51df0cad50`。

## 结论

保留 data-centric self-improvement / automated data research 母领域；不建议继续把 E13/E14 的“冻结策展池补货、精细匹配、跨两个状态重用”作为主探索入口。下一轮优先研究：**实验结果如何转化为可迁移、能改善后续决策的研究经验**。先利用公开真实训练结果表和冻结研究 agent 进行实证，不再为每次研究决策重新训练学生。第二个独立备选是冻结 agent 的主动经验构造；它涉及非参数经验学习，必须明确与原来的权重训练数据对象不同。

这不是一个已经验证的新方法，也不宣称“经验迁移”无人研究。新方向需要越过 Gödel Forest、EEM、AutoLLMResearch、ReasoningBank 等明确近邻。本文提供的是有依据的探索对象和能区分解释的实验，而非已成形 paper 的承诺。

本次没有运行新 GPU 实验、没有修改原实验结果或 workbench 状态。执行了已有八终点评分的 CPU 复算，脚本与输入随本报告提供。没有逐条重判全部原始模型输出；没有在完整仓库运行全局 process check。

## 2. 执行问题：不是不认真，而是研究对象发生了替换

实际推进链逐渐变成：数据研究能力 → 词面选样 → 教师可用性修复 → 静态策展 → 冻结池补货。每一步都有局部理由，合起来却没有测到最初的改进器对象。

主要责任同时来自任务布置：I01–I03 初始都很宽；“先把强基线做可信”没有配套规定何时直接观察主对象；遇到生成器失败就把下一项前置修复写成科研进展。新的推理-only建议也不能修复这点：看反馈是否改变文字，只测到了敏感性，仍没有学习后果。

应保留的执行优点包括失败记录、协议修订留痕、输入身份核验、作废不可靠成本和不隐藏null。不是撤掉这些质量控制，而是把已有控制封装成可复用入口，避免每轮文档都被它们主导。

下一个实验应说明：改变哪个研究决定、观测什么结果、哪种结果支持哪条后续路线。不要把“必须先检验所有前置环节”变成永久驻留模式，也不要把任意一次小分差写成定律。

## 3. 重新分清三个科研对象

1. **学生训练数据**：材料进入权重更新。claim“这种数据更能让学生学会”需要真实学习后果；历史实训结果可用于有限动作空间的初期研究，不能用文字指标冒充终端效用。
2. **研究 agent 的实验经验**：实验记录变成配方选择、试验安排、复用/否决规则。研究 agent 可以冻结权重；选择的配方已有实训结果时，能先用只读查询测其真实决策质量。
3. **执行 agent 的经验/技能库**：交互轨迹变成可复用记忆与技能。可以不训练，但最终尺子是新任务行为，不是摘要“看起来更深刻”。

近期综述也把模型参数更新和scaffold更新分开。[S1] 这支持研究对象的区分，不自动为某个具体idea提供新颖性。

## 4. 关键论文的生长逻辑与我们的定位

以下“生长逻辑”是阅读后的研究重建，不声称知道作者最初心理过程。新颖性分析围绕已有方法能做什么，而不是它们名字与我们是否相似。

### 4.1 Gödel Forest：从单链/浅层搜索到协作数据研究

论文把数据研究组织成多个搜索树，并共享排行榜和包含ΔU、归因、操作规则的经验；候选学生从同一父模型训练。其前提改变是研究计算的组织方式，而不是再提出一个数据质量分数。[S2]

**对我们的约束：** 多agent、负结果共享、经验库和深广平衡已是直接近邻。它的经验里已含归因，不可声称“此前只有分数没有解释”。

**值得继续问：** 有一次实验结果，何时足以推断可用于另一个学习条件的规则？规则在协作传播后，能节省真正无效的实验，还是也可能阻止有价值的新尝试？这是待测的决策问题，不是已发现的失效。

### 4.2 EEM：从反思到按证据安排实验

EEM已有带适用条件的经验记录，以及证据不足时安排短pilot的机制；它的主要评价是研究过程产物的rubric，不是特定学生在留出任务上的训练收益。[S3]

**对我们的约束：** 不能只提出“给经验加适用范围”“先跑小实验”。

**候选增量：** 直接检验经验导致的行动是否正确，并把证据是否足够从语言判断变为由实际动作后果校准的决定。它必须在等查询/搜索预算下比现有机制有效；仅解释更清楚不够。

### 4.3 AutoLLMResearch：从配置搜索到跨保真实验经验

其贡献包括多保真实验环境和训练过的配置研究策略，跨尺度迁移并不是我们的空白。已公开结果表与查询实现，可以给本轮提供不新增学生训练的入口。[S4]

**对我们的约束：** 不能把低成本到高成本、跨模型迁移或成本摊销单独当新增主张。

**候选增量：** 研究局部实验结论在不同条件中的可用性，以及怎样用有限查询补充有区分力的证据。若最后只是固定数据比例优化，应诚实定位为该问题，而不是通用开放式数据研究。

### 4.4 Active Synthetic Data：生成器不等于学习反馈之外的独立模块

该工作把学生信号用于选择后续生成的种子，结合教师扩展与学生更新，比较便宜不确定性信号等策略。[S5]

**对我们的约束：** “根据学生错误生成更多适合的数据”已经不新。

**资源与探索启示：** 若未来回到训练数据生成，要问生成器能否忠实实现请求的数据改变，再用终端学习效果判断。但不再默认重跑当前失败的本地数学教师prompt。

### 4.5 ReasoningBank / S3Gym / MetaSkill-Evolve：不训练不是没有闭环

ReasoningBank及MaTTS已使用成功/失败轨迹和多轨迹对比构建经验；S3Gym将探索、判断、经验整理与后续任务表现连接；MetaSkill-Evolve还把改进策略本身作为更新对象。[S6–S8]

**对我们的约束：** 摘要有时输给原始轨迹、更多经验不总有效、反思可改进器化，不能直接当新发现。

**保留空间：** 现有经验不够辨别一条规则是否可靠时，主动获取什么额外经验最有用？若做反事实分支，必须与MaTTS的随机多轨迹对比、以及已有执行重放贡献测量对齐，而非第一次“加入因果”。[S9]

### 4.6 A Critical Look：怎样从强简单基线长出主会尺度

这篇将表征、选择算法与预算分开，在多任务真实训练中比较，并提供有前提的统一分析。[S10]

**可迁移的研究动作：** 不以“random很强”作为终点，而是回答究竟哪个设计因素决定有效性，以及什么条件下值得支付复杂方法成本。

我们的E13离这类论文的差距，不是没起好名字，而是尚未把一个局部比较升级成有实际后果、跨条件可解释的判断原则。

## 6. 首选研究空间 A：实验经验的可迁移决策价值

### 科学对象

不是训练材料逐条质量，而是**以往数据实验产生的经验，何时足以指导新条件中的数据研究动作**。

设条件为c、数据行动为a、已有实测结果为U(c,a)。研究agent从历史H生成经验M，随后提议动作/查询。应测两种后果：M是否改善最终选择；在需要额外信息时，M是否帮助选到值得付费的实验。

### 真正值得验证的候选机制

一次配方成功会同时涉及来源、比例、模型规模、学习预算等因素。把结果压成规则可能扩大适用范围，也可能删去必要条件；但也可能恰好去掉噪声并改善迁移。两种方向都应预期，不能先写“压缩必然坏”。

最有价值的结果是找到：**什么实验对比信息必须随经验保留，什么新查询能消除对当前决策有影响的不确定性**。自然语言归因本身不构成辨识证据。

### 与旧I02的关系

旧I02主要是“看学生错题→选择训练数据”。本空间是“看已有训练实验→选择下一次实验/数据配方，并使研究经验可积累”。属于同一母领域的明确对象重定位，不能静默换名。原I02保留为相关入口，不宣称它已被证伪。

### 潜在方法，尚未验证

以可检查的实验对比为经验单位，保存条件、动作差异、实测结果及支持范围；对新条件中的关键决策区分“已有证据可直接复用”与“需要一次辨别性查询”。方法应优先简单，使用冻结agent与可检查结果，不预设新训练元模型。

仅做结构化JSON/检索/LLM自评置信度不足以跨过EEM。方法必须实际改变错误选择或无效试验，并在新条件下优于原机制及普通优化器；若普通优化器已足够，就按事实重定位贡献。

代码有几个必须直接继承到实验设计的边界：

1. `data_mixture_tuning` 的`repeat_time`改变已存配置子集；不能把它称为新模型或独立训练seed。
2. RL查询会在`additional_info`返回`test_score`；数据混合查询返回其他逐任务metric。给agent的接口须白名单化，隔离承诺留出的结果。原协议这样设计不自动等于作者泄漏；关键是我们自己的测试语义不能与其默认接口冲突。
3. 代码的任务名称与论文呈现不完全一致，以所用数据行/训练来源辨明对象，不靠名字。
4. 架构任务可来自代理预测器，不能将四类查询全部概括为真实独立训练。首轮只用可追溯的实训表行。
5. 首轮不反序列化来历不明pickle；优先CSV。缺失配置只标缺失，不用LLM或插值伪造“实测真值”。
6. 有`train_time`字段不等于完整实际GPU账；单位与来源需核查。不在成本含义未核前换算“节省多少A100小时”。

这些都是一次数据导出/接口约束，不应再发展成多轮资格门或安全测试项目。

## 8. 下一轮实验提案：R1–R4

这些编号是本报告的提案编号，不占仓库E编号、不代表已授权开跑。正式执行前根据最新仓库分配E编号。先做R1，按结果推进；不一次铺满全部矩阵。

### R1：经验有没有改变后续数据决策？

**对象**：冻结研究agent对真实配方结果的学习。**新增学生训练=0**。

**输入**：从公开CSV导出可比较的配置、条件、真实分数；按原始配置hash和来源分组。使用本地现有可用模型，不先训练专门研究agent。历史必须来自真实配置查询，不能故意捏造错误教训。

**相同历史下的策略**：无历史/最强固定配方；原始结构化实验记录；普通经验总结；已有EEM/Gödel式“条件＋ΔU＋归因”的经验。后三者使用同一研究backbone与同一历史。上下文预算相同，另保留不受同等压缩限制的原始记录作为信息上限诊断，明确其额外推理成本。

**流程**：冻结初始已见配置集合与目标条件；agent只能看训练/开发信号。要求提交下一配置及最终推荐，之后由不可访问的评分器查询预存结果。相同实验历史用预先固定的重复推理seeds比较。先把每种表示用于完全相同的历史，分离经验表示与更长搜索造成的差异。

**主读数**：最终推荐的真实效用、有限配置集内simple regret、查询成本。辅助读数为动作变化和经验文本；不是主指标。未测配置不评价，缺失不插值。

**阳性对照**：评分器私下计算当前可行动集合的最好结果；展示一对已经观测到明确分差的真实配置时，简单数值选择应能选对。它只确认存在可利用决策信息，不把oracle加入可部署方法排名。

**会改变什么判断**：经验改变文本但不改变行动→不做训练扩展，先看执行接口或强固定策略；行动改变但效用不变→说明该可行动集合决策空间不足；原始记录帮助而总结不帮助→考虑信息损失；总结帮助→分析其提取了哪些可复用对比，而非预设压缩有害。

**统计边界**：重复agent推理只估agent随机性；配置子集重采样不是独立训练重复。三模型尺度不冒充三家族。

### R2：能否把正确的实验结果变成错误的推广规则？

**对象**：规则运输的决策后果。**新增学生训练=0**。

**设计**：使用相同源实验记录，比较原始记录、原有条件化lesson，以及可检查的配方对比记录。目标分为原条件、公开表支持的变化条件。源/目标范围由可观察的模型/预算/任务元数据预先定义，不按目标结果挑“发生反转”的例子。

为区分知识缺失与推理错误，同时设置可向目标提出0/1/3次新查询的预算。查询若使用真实训练结果，按一次实验记账；不能宣称target反馈免费。原有EEM已经有适用性和pilot，须保持这两个能力，不刻意削弱近邻。

**关键干预**：从某一方法的自然产生历史中，移除/保留某条lesson，重复其后续决策，实测推荐效用的变化；不能只凭agent自述“我因这条规则放弃了X”判为因果。若研究剪枝，所有方法共同提交一个可执行候选列表，评分器根据真实表计算有用候选是否被排除，接口改变须公开。

**主读数**：条件变化后的选择regret、保留/移除lesson的行动效用差、恢复有用候选所需新查询数。只在表支持的范围内计算。

**可能的idea来源**：结果可能显示需要保留具体对比对象而非单点ΔU，可能显示元数据已足够，也可能显示每次目标只需一个简单确认实验。选择最简单、具有实际后果的解释，不预设必须复杂因果图。

### R3：下一次预算应该寻找高分配方，还是辨明一个会改变选择的问题？

**对象**：数据研究中的实验选择，而非经验文本质量。**新增学生训练=0**。

**对照**：随机/简单固定搜索；GP/BO等普通优化器；已有条件化lesson＋pilot机制；候选的决策相关辨别查询机制。所有方法共享合法动作空间、历史初始化和总查询预算，分别报告query数与研究agenttoken成本。

**候选机制**：先提出当前最重要的两个可行动判断，再选择能区分它们的可执行查询；若已有证据足以决定，就直接利用。不是为所有lesson补实验，也不是额外免费查询。若一个对比需要两条新训练结果，就扣两次查询。

**预算建议**：先采用2/4/8个实际结果查询的离散预算；若公共表覆盖不足则减少，不填造结果。使用同一query预算比较全部失败与成功，不拿最好一次搜索代表均值。

**主读数**：推荐效用—查询预算曲线、signed累计净收益或regret、可复用经验在下一条件上的收益。只报正面积或best-of-N不能证明累积进步。

**决策**：辨别性查询在多个真实目标条件上减少决策错误，且比BO/原pilot有效→发展方法；只提高归因文本评分→不升级；普通优化器吸收效果→研究简化原则或转向更有必要的开放数据动作，不继续堆LLM模块。

### R4：开放动作与真实新训练的桥接，条件性执行

只有R1–R3已显示有意义的决策价值，才使用现成学生训练资产做少量新的终端验证。首选复用已验证的本地学生/评估入口，但不局限在E13四个弱区分动作，也不全量重建旧环境。

先冻结方法与最强对手各推荐的配方，再对同一父状态、同训练预算、同评估协议运行少量配对seed；具体训练量由已记录吞吐和效应分辨率决定。此时训练回答一个明确问题：**表内实验经验所学的决策原则，对新的真实数据动作是否仍有帮助？**

若只完成表内受限配方选择，论文就只能claim受限配方研究。若扩展到生成/修订，必须能验证相应数据动作并量实际学习后果。不能用表内oracle或模拟器评分替开放生成数据背书。

## 9. 独立备选空间 B：主动构造可验证的经验，而非无限总结轨迹

这个空间直接研究冻结agent的经验数据；不是为逃避训练而把原权重问题改叫RSI。

候选问题：当当前轨迹同时支持多个相互冲突的规则时，agent是否应主动获取能区分它们的经验，而不是立刻压成skill？已有MaTTS多轨迹对比和执行重放credit研究是强近邻，因而“多采样/反事实”本身不新。[S6,S9]

最小实验应从自然运行产生的歧义状态出发。相同环境交互预算下比较更多原轨迹、随机额外尝试、MaTTS式对比和针对规则分歧的查询；保持记忆token预算一致，在新任务状态上测成功率与净改进。只有环境允许真实可复现的状态重放才能做分支；不假定任意工具API支持clone。

若所有方法加正确经验后都不改善，优先分离技能执行能力与经验获取，不能只评“规则正确率”。如果只是某个游戏得分更高，仍不足以泛化到数据研究；应在第二类实际任务上验证。原文的S3Gym包含无外部reward的探索条件，任何额外奖励可见性都要列为设定变化。

本轮对该空间的判断：值得保留，但资产及最接近方法的执行协议核验尚不如A完整；不立即并行开另一套系统，不在本轮登记为新的ACTIVE。

## 10. 本轮明确不建议追的局部线

不继续为E13/E14补更多exact matching特征、不因均值近似继续造复用router；不重启本地数学teacher提示词修复；不从零重建P01零数据预训练生成器；不把当前代码/格式/评分器bug包装成核心机制；不把MetaSkill式“改进器也能改进”当首次提出。

保留全部缓存、训练程序、数据映射、终点、评分脚本和失败成本。以后新假设真需要某项控制时直接调用，不把重做控制当研究进展。
