# I03 — 课程效用的时间视野

- 状态：SEED（初期为 I01/I02 的公共测量轴）
- **来源：** P01 历史梯度奖励与 App F；P02 短程真实学生收益；P16 advantage＋progress；P20/P22 泛化估计和在线潜力；P15 multi-fidelity。见 [文献账本](../READING_LIST.md)。
- 对应：C04；E03。
- 证据等级：L0。

## 母问题

训练经验可能产生即时改善，也可能建立后续任务的先修能力。给数据制造者什么反馈，才能在可承担成本下选择真正有长期价值的课程？

“短期不等于长期”是一般事实，不足以成为论文；必须发现标准强系统里可重复且有实际损失的具体决策失败，再给有效方法。

## 近邻压力

SOAR 已经用真正训练后的提升而非难度；PAC 已把实际 progress 接入分配；P01 已比较历史窗口、单步窗口、loss-delta、signed。不能以再做这些消融为新意，也不能只把窗口换大一点。

## 决定性测量

从同一学生/优化器状态出发，对相同候选数据动作运行预注册的短/中/长更新预算。比较各时域上的动作排序、相对强参考的 regret，并在训练后接完全一致的 continuation，区分“多训了”和“改变了后续可学习性”。

短程 outcome、长程 outcome 都要与重复训练的噪声比较。要同时检验保留能力和外部任务，避免把目标过拟合读成长期进步。模型越训越难测时，不事后挑最有利窗口。

## 条件性方法

若有结构化排序逆转，检验少量长程真实反馈能否校准廉价代理；或者数据动作是否需要按先修关系获得延迟信用。动作空间、外部反馈和总预算必须与 PAC/ADO/常规多保真选择及可承受的 grounded reward 对齐。

“校准后相关系数更高”仍不是充分贡献；需要更好的课程决策和真实任务收益。所有校准训练只用 dev/训练 episode，private 禁止回流。

## 停止局部堆叠的条件

短长差别完全落在噪声、仅由长度/LR解释、或更强在线 progress baseline 已解决时，停止围绕此解释追加局部实验，回到共享资产上的其他痛点。不是自动关闭 workbench，也不把无差别结果包装成模型不会学习。

**2026-10-02 定位补充（非 idea 升级）：** P34 BLISS 明确以多步 proxy 更新代替 MATES 一步信号，P32 则用单步组 oracle 后检查长程训练表现。因此“短程 proxy 有偏”已被正面处理；除非强方法仍在可复现的实际数据决策上系统性犯错，并能以自然修复提高外部终点，本卡继续只作 measurement axis。

P35 PDS 进一步把训练轨迹 AUC 写成优化目标，并用五个早期 checkpoint 的静态求分超过单步版本；若本卡后来声称长时域信息重要，必须说明它相对这种一次性压缩的信息增量与实际行动收益。
