# I01 — 数据策略的可复用性与最小再适配

- 状态：SEED
- 来源：P01 Fig3 的 fresh-student transfer；P02 教师迁移；P11 群体与 cross-play；P21 可复用影响力存储；P15 跨保真实验策略。来源链接见 [文献账本](../READING_LIST.md)。没有本地 P#/E# 结果。
- 对应：C01、C02；首个测量 E01。
- 证据等级：L0。

## 母问题与实践后果

生成器、策展程序或课程是否能成为可复用资产？若每个新学生都必须重新学会怎样制造训练经验，data-centric RSI 的实际成本会被内循环放大。反过来，若强静态策略足够，盲目在线重训也是浪费。

这不是“首次发现数据迁移”或“首次发现共适应”。目标是决定何时复用、需要什么再适配以及总成本是否值得。

## 原始张力如何生长为 idea（RECONSTRUCTED）

P01/P02 的成功说明：闭环产生的经验可以帮助新的学习者；P11 的设计则说明：单一配对并非唯一合理组织方式。这两点不构成文献矛盾。它们留下一个具体决策问题：把昂贵改进器部署给一个新学习者时，观察哪些有限响应，足以选择复用还是适配？

## 学习效用，不是难度

定义学生状态 s、数据动作 a、训练预算 H 下的增益 `U_H(s,a)`：从同一 s 出发，用 a 产生的数据训练，与参考数据的等预算训练比较外部表现。可用 dev 估计策略；private 只在预先冻结决策后评估。

s 包含权重/优化器状态、历史与预算。不要让一个分支继承 optimizer、另一个重置后声称数据策略有差异。

## 先做什么

E01 比较固定强数据、由学生 A 反馈产生的数据、由学生 B 反馈产生的数据；交换使用，保持格式、监督来源、训练 token 和数据生成预算可比。先两个有实际学习差异的状态，不一开始铺模型家族×所有阶段×所有生成器。

同时保存题目难度、长度、验证通过率、重复率与外部目标覆盖，检验简单解释。重点看相对强静态方案的训练增益和实际重要的状态交互，而不是漂亮聚类图。

## 条件性方法方向

只有看到稳定、实际有用的交互后，才建立少量训练干预的 learner response profile：据此选择已有数据程序、调整混合/顺序或触发再生成。优先简单模型与可解释决策，不预设一定要新训一个大型 teacher。

需要比较 frozen best、无条件混合、难度匹配、最近邻学习者、固定刷新频率、每学生单独适配，以及与动作空间匹配的 LESS/DoGE/ADO 类基线。完整计算中包含 profile 探测与资产构建成本。

## 怎样避免成为小测量

候选论文必须从交互测量走到一个可迁移的决策原则/机制或有效方法。外部收益、新学生泛化、总成本回本缺一不可。只说明某个 G_t 更适合 S_t 不够。

## 决策与替代解释

- 若没有有意义的交互：研究强静态策略为何足够，保留复用资产；不强造 router，不关闭领域。
- 若难度/长度完全解释差异：优先使用该简单策略，停止为这个局部现象堆复杂机制。
- 若有交互但廉价探测不能预测：转向状态表示或 I02 的干预识别；不宣称已形成方法。
- 若只有同家族有效：收窄结论，追加新家族评估后再决定叙事。
