# 需要下载的论文全文（OpenReview）

本机访问 OpenReview 会遇到浏览器验证，我不能绕过。下面这些论文没有 arXiv 版，需要你在浏览器里点开链接下载 PDF。

下载后，放进 `workbench/data-centric-rsi/papers_in/`（已 git-ignore），或者直接在对话里发给我。文件名保持 OpenReview 默认的即可，我按 ID 对应。
