## 领域地貌（摘要，详见讨论稿第一部分）
- **对象**：模型为自己生产训练数据（出题、造环境、打标签）再重训的闭环。证据分三层：任务增益、保留下来的增益、改进器本身变好（§1）。
- **热度**：2025–26 年出现大量“零数据”自我对弈系统（R-Zero、AZR、SPICE、Agent0、J-Zero、Skill Self-Play、SPADE 等），多数几轮内先升、后平、再降；有精确锚点（执行器、证明检查器）的走得更远（§3、§4.2）。
- **理论**：没有额外计算的闭环，落点由外部成分决定（验证器不动点、迭代学习收敛到先验、锐化只能抬高基座已有答案）；执行器、搜索提供的是计算，可以把“原则上蕴含”的结构变成可学的（§4.1）。
- **解题侧边界之争**：RLVR 是否超出基座能力（pass@k）有争议；解题侧的“语义覆盖”已有人测（依赖嵌入聚类），出题一侧没有对应的测量（§4.1）。
- **审计一线**：自称改进器变好的研究，多数增益来自选择和继承，“同一状态、换改进器”的交换测试极少，且都在 harness 端（§4.4）。
- **回流通道的已知结果**：AZR 的历史程序回流比出题者训练重要；R-Zero 共享权重更早退化；BenchEvolver 冻结生成器、只积累产物也能持续做出更难的题；技能库与解题策略会互相特化；形式数学里，不训练的随机结构扰动产生的训练数据好过学到的猜想者（§4.4）。
- **开放式演化与环境设计**：POET 的难环境要靠沿途其他环境的解才能到达，直接课程不行；环境设计里随机生成加学习者筛选胜过 RL 训练的生成器；Go-Explore 用学到的策略探索，要到中期才比随机动作好（§4.4）。
- **其他**：总分会掩盖尾部和恢复能力的损失（§4.5）；数据方法之间的差别常在噪声内（§4.6）；生产者强弱不决定数据价值（§4.7）。

## 讨论演进（2026-11-27）
| 版本 | 核心问题 | 为什么改 |
|---|---|---|
| v1 初稿 | 五个候选方向，主推“闭环里的生成器本身在变好吗” | 跨领域扫描后扩展为 v2 |
| v2 | 方向 A–F。倾向 A（闭环增益是提取基座还是加入新信息，pass@k）加 B（生成器是否变好）：增益从哪里来 | 第一轮外部意见：B 的交叉移植有难度错配混杂；pass@k 解读有误；只做审计会撞车 |
| v3 | 闭环停在哪一环（数据、教师、学生、共同适应、改进算子耗尽），用放大—蒸馏框架组织 | 第二轮：组件排查层级不对，结论会碎成清单；“油表”新意被 Mind the Gap 等占据 |
| v4 | 自我改进在什么条件下产生复合收益，三层串行：存在性 → 能力回流 → 任务空间结构 | 第三轮：三层串行的逻辑不对；共享权重不等于能力回流（R-Zero 附录 D 已做）；漏读了已有的 Self-Play Pretraining；连通性旋钮同义反复 |
| v5 | 回流介质 × 锚点 × 任务空间自由度的矩阵 | 第四轮：显式产物在自一致锚点下同样带偏差，且有外部监督泄漏；把“纵向好、横向坏”预先写进了假说；矩阵化有变成又一组消融的风险 |
| v6 | 出题一侧是摊销还是触达扩展，扩展从哪里来；v5 的三个因素降为扩展的条件 | 第五轮：摊销本身就是复合收益的机制，“摊销还是触达”取决于预算；覆盖扩大既不必要也不充分；漏了“学习者到底有没有起作用”的无耦合对照 |
| v7 | 学习者的进步有没有让数据生产变好，变好的部分是不是不依赖学习者的搜索与积累替代不了、会越滚越大的；主读数改为全新学习者上的学习价值 | 第六轮（校对，不改方向）：复合不要求加速；2×2 冻结后退化；“全新学习者不获益 = 只适配”是难度错配陷阱；递归不以出题者权重划界；UED 叙述偏一面 |
| **v7.1 当前** | 同 v7，但问“能否经由数据生产传到后面几轮、在什么条件下成立”；学习价值分条件价值、可迁移价值、累积语料价值；机制实验（固定生产预算，生产用 L(t−1)/L(t)/L(t+1)）与系统实验（固定总预算）分开；停止条件分三层 | — |

v7 把问题放回 data-centric RSI 的定义本身（学习者 → 数据生产 → 学习者这条回路），用对照阶梯（从不依赖学习者的搜索、随机扰动、积累，到完整递归）和同一状态上的“学习 × 回流”交互来检验；覆盖、生产成本、表示成本降为解释读数。每一轮采纳和不采纳了哪些意见、理由是什么，见 [logs/2026-11-27.md](logs/2026-11-27.md) 和讨论稿 §10.2、§10.5。

## 当前路线
1. **第一步，只推理，只作定标**（[E15](experiments/E15-producer-observation.md)）：
   - E15a：AZR 公开 W&B 日志（不用 GPU）。
   - E15b：R-Zero 初始出题者与 v1–v5，统一模板、同一筛选器（两个固定解题者），先做身份冒烟测试。
   - E15c：AZR 初始/最终权重 × 初始种子/后期素材的 2×2 预览。
2. **受控轨**：预训练小代码模型，多个随机生成的陌生语义世界（另设熟悉与近随机两端），允许全局、局部、抽象三种探索；对照阶梯按“学习者状态经由什么通道、是否跨轮保存地进入生产”排列。
3. **核心因果实验**：机制实验（固定生产预算，生产用 L(t−1)/L(t)/L(t+1)），系统实验（固定总预算，冻结学习者把算力给搜索），再在后续轮次重复看多步传播；学习价值分条件价值、可迁移价值（独立运行的同轮学习者）、累积语料价值，交叉矩阵读结构。
4. **条件**：改变有价值数据的稀有程度、任务结构、训练历史长度，看学习者耦合的优势是否反转。
5. **真实轨**：自己跑一段 AZR（保存每轮权重、缓冲区、谱系、算力），可用其复合函数开关作“可调用抽象”一路；R-Zero 检验是否依赖可执行表示。
6. **停止条件**分三层，写在讨论稿 §10.4。
