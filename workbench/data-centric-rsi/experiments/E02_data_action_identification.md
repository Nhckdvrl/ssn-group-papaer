# E02 — 干预信息是否改善数据动作

- 状态：PLANNED
- 对应：I02 / C03；需 E00，借用 E01 的训练/评估资产。
- 阳性对照：已知覆盖/监督变化的校准状态能被有真值的动作对照改善；提供完整实测动作收益的 oracle 能选中更好动作。oracle 仅诊断，不与可部署方法混报。
- 噪声地板 + MIE：配对初始学生和训练 seeds；预先冻结动作集合/预算和评估集合；先确认 oracle 与强基线的可行动差距，再决定干预测量分辨率。
- 决策表（跑之前写）：干预信息提高动作选择且改善自然任务→研究策略跨学生积累；仅提高解释分数无训练收益→不升 C03；强错误追随/普通优化器已足够→保留其成功，不强行训练大 agent；只在人工校准任务有作用→不得宣传真实 RSI 痛点。

## 核心对照

同一数据动作空间、学生训练工具、teacher、调用数和总训练预算：固定最佳配方、常规搜索、错误反馈驱动、历史经验/targeted-pilot、基于实测 response 的策略。

首轮只使用少量有明确意义的数据动作，例如补覆盖、修监督、改表达；动作是否适用由实际任务决定，不为了形成分类强行制造病症。先已知条件校准，再回到自然 baseline 出现的真实失败。

## 因果识别

在保持数据生成/搜索预算的条件下，移除训练响应或打乱 action–outcome 对应；另设同等 token 的反思对照。比较的是下一动作效用和真实学生结果，不是 agent 自己评的诊断准确率。

错误率相似的学生不自动视为同分布；记录逐类任务与能力结构。人工构造的潜在原因只用于检验测量系统，最终需自然数据结果。

## 改进器评估

学习干预策略的 episode 与测试 episode 分离。在新学生/新任务上冻结策略/经验更新规则，比较初始与积累后改进器的收益—成本曲线。单轮最优数据改善不等于改进器发生 RSI。
