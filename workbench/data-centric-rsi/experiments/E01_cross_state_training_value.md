# E01 — 跨学生状态的真实数据价值

- 状态：PLANNED
- 对应：I01 / C01；需 E00 测量有效后运行。
- 阳性对照：强训练材料优于不更新；已知不同覆盖的材料在预先定义的诊断子任务上表现可区分；固定数据交换不改变内容 hash。
- 噪声地板 + MIE：配对训练 seeds 与重复评估；以任务级/训练分支不确定性估计主差异，不将 token 当独立样本；MIE 沿用 E00 的决策尺度。
- 决策表（跑之前写）：存在实际重要的状态×数据交互且简单混杂不能解释→开发并预注册 response-conditioned 适配；只见总体强弱无交互→保留强固定策略，不强造 router；差异由难度/长度解释→优先简单规则；区间太宽→先改测量，不扩完整 Cartesian grid。

## 最小有解释力的设计

同一模型家族的两个有实际学习差异的状态 A/B；三类数据为强固定参考 D0、基于 A 反馈的 DA、基于 B 反馈的 DB。每份数据交叉给两个学生，3 个独立训练 seeds，核心 2×3×3=18 条训练分支；额外数据生成、基线构造和所有续训都另计成本。

状态由预先规定的训练条件/阶段产生，不按看到交互后的分数选择。先不做所有模型×所有阶段×所有 teacher。

## 主要读数

对每个状态比较等预算训练后 dev 增益和数据选择 regret；策略与读数冻结后看 private 结果。保存绝对分数，防止低基线导致相对提升幻觉。需要考察阶段后果时接同一 continuation，并将其成本计入。

## 固定项与审计

父 checkpoint、optimizer reset/继承、训练 token/步/LR、teacher 型号/预算、监督来源、格式、长度、验证率、重复率和目标覆盖。若无法完全匹配，保留原始差异并做额外控制，不静默过滤样本。

## 证据上限

本卡最多建立局部可重复的交互观察；不单凭矩阵宣布因果机制或可发表贡献。C02 的适配方法和新家族泛化需要后续独立卡。
