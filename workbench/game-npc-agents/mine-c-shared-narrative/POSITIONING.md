# 矿区 C 定位：哪些已有，哪些值得继续判断

**更新：2026-10-19。** 本文服务知识和问题建设；无实验项目、无 ACTIVE 分配、无模型或玩家实验。候选见 [RESEARCH_MAP.md](RESEARCH_MAP.md)。

## 1. 当前判断

**角色驱动的互动叙事值得深入，但“用 LLM 导演协调人物与玩家”已不足以构成题目。** 经典研究已经处理作者目标、人物意图、失败计划、信念、戏剧管理和玩家偏离后的重规划；近期研究又提供自然语言 storylet、剧情反思、可能性空间创作、持久分支和从编辑积累意图。[IPOCL](../../../library/themes/game-npc-social/papers/IPOCL_2010.md)、[Sabre](../../../library/themes/game-npc-social/papers/SABRE_2021.md)、[GME](../../../library/themes/game-npc-social/papers/GAMEPLAY_MEDIATION_2014.md)、[Dramamancer](../../../library/themes/game-npc-social/papers/DRAMAMANCER_2025.md)、[Bonsai](../../../library/themes/game-npc-social/papers/BONSAI_2026.md)

值得保留的整体压力是：**当玩家、人物和作者都可能改变对故事的理解时，什么变化有理由、什么变化应持续、谁能修改什么，以及人怎样理解和创作这种作品。** 这是由近邻留下的具体未知重构出的研究方向，不是已被本矿区证明存在的新失败类别。

作者可以从意外中发现新的表达；玩家可以珍视被理解、扮演不同立场、有理由的抵抗和情感转折。最初意图保持率、人物目标全成功、剧情旗标完成率和故事分支数都不足以独自衡量这些价值。[共同创作史](../../../library/themes/game-npc-social/papers/COAUTHORSHIP_EMERGENT_NARRATIVE_2021.md)、[Agency Reconsidered](../../../library/themes/game-npc-social/papers/AGENCY_RECONSIDERED_2009.md)、[WhatELSE](../../../library/themes/game-npc-social/papers/WHATELSE2025.md)

## 2. 最强近邻与证据边界

下表混合直接方法近邻、强普通参照及人/作者证据；它们不是同一排行榜。详细方法、样本单位和局限在规范卡中，不能将卡里的不同范式分数直接比较。

| 近邻 / 地位 | 已明确完成的事情 | 真正证据与限制 | 对本矿区的约束 |
|---|---|---|---|
| [IPOCL，JAIR 2010](../../../library/themes/game-npc-social/papers/IPOCL_2010.md) | 作者结局与人物动机共同约束计划 | 32 读者、每条件 1 故事；长度和直接表达意图混杂；一主检验仅 `p<.0585` | 不能重新提出“人物必须有动机”或拿静态读者题当实际游玩效果 |

| [StoryAssembler，FDG 2019](../../../library/themes/game-npc-social/papers/STORYASSEMBLER2019.md) | 片段/状态/叙事目标动态组合，玩家选择后重规划 | 6 学生作者、8 场景实际制作；组合调试令部分作者退回静态链接，无随机效率实验 | 作者可理解、调试和维护能力已有真实需求，不是单凭生成量推测 |
| [WhatELSE，CHI 2025](../../../library/themes/game-npc-social/papers/WHATELSE2025.md) | 范例/抽象纲要/变体塑造可能性空间；GPT-4o 状态与动作反馈 | 12 初学作者、同一小域；界面与运行规划共同变化，效果不能全归抽象层级 | 抽象控制、生成变体与作者意图对齐已有直接系统 |
| [Drama Llama，2025 预印本](../../../library/themes/game-npc-social/papers/DRAMA_LLAMA_2025.md) / [Dramamancer，UIST Adjunct 2025 Demo](../../../library/themes/game-npc-social/papers/DRAMAMANCER_2025.md) | 自然语言 storylet、角色、场景、自由文本输入；后者有时间事件和建议 | 前者 6 作者/12 自选轨迹；后者内部 8 作者/15 故事，无受控玩家效果；同研究脉络 | “NL trigger + NPC + 作者 UI”不能当新题；调试负担和输入时机值得追问 |
| [ACL 2025 互动戏剧](../../../library/themes/game-npc-social/papers/IMMERSION_AGENCY_DRAMA_2025.md) | GPT-4o 剧情反思和导演/演员混合，因玩家行为改未来剧情 | 运行只 1 Conan 剧本、10 真人+10模拟玩家、3架构；反思影响/意图评分 3.5→4.0 / 3.3→4.0；无同预算完整修复基线 | **强普通模型加工程有真实正面证据**；提前泄密/虚构场所案例尚不足以证明新方法必需 |
| [HAMLET，ICLR 2026](../knowledge/papers/HAMLET_2026.md) | 分层戏剧蓝图、角色私有目标、公开旗标、停滞推进、行为时序 | 多作品/主题和强模型；人评主要读剧本；推进率不证明玩家改写与角色目标被保存 | 多 agent 与剧情完成不是贡献终点；要研究推进与参与之间的条件 |
| [NCP，ICML 2026](../knowledge/papers/NCP_2026.md) | 强商业模型的长程事实/剧情/玩家输入约束审计 | 100 电影主任务、已提供状态；无提交前检查修复或强模型普通重规划；主要是模拟玩家 | 强模型仍可能出错，但不能从此推导专门架构必需；固定电影顺序是任务规格 |
| [LLM 叙事启发式，FDG 2025](../../../library/themes/game-npc-social/papers/LM_NARRATIVE_HEURISTICS_2025.md) | GPT-4o-mini 与经典启发式的距离/行动比较 | 11 形式领域，仅 1 域最优 LLM 距离 MSE 更好；非在线搜索或玩家实验 | 给经典规划保留强基线，不以小商业模型推导旗舰 API 上限 |
| [Halberd，2026 forthcoming 作者稿](../../../library/themes/game-npc-social/papers/HALBERD_2026.md) | 符号作者搜索 + LLM 人物动作可信度，实际运行和读者比较 | 5 域、125 预定解位/110 成功；人评4域，低一致性；90/89 偏好无显著差异不等于非劣；无旗舰 API | 混合架构已有非常近的方法；形式解释与人类整体判断可能分离 |
| [Bonsai，ICML 2026 Workshop](../../../library/themes/game-npc-social/papers/BONSAI_2026.md) | 发布后持久生成分支、作者修改、从编辑积累规则 | 3 项目各1构建/1留出场景；主规则直接取完整模拟偏好；强商业生成+LLM裁判；真实作者仅形成性3测试者 | **保留意外+编辑+意图学习已经有人做**；真实作者如何改主意、作用范围和下游玩家影响尚缺强证据 |

### 人的证据应怎样读

主观能动性不是简单的分支函数，但现有短篇研究并没有证明“立即承认输入就足够”。[Illusion of Agency](../../../library/themes/game-npc-social/papers/ILLUSION_OF_AGENCY_2012.md)有一个真实分支题显著差异、没有等价检验，确认对最小确认也只有一题显著；[Foreseeing Meaningful Choices](../../../library/themes/game-npc-social/papers/FORESEEING_MEANINGFUL_CHOICES_2014.md)支持情境差异的部分线索，却是单故事且改过分析。二者提醒测量意图、预期和解释，不能当作全领域的固定答案。

作者证据也有不同尺度：StoryAssembler 是真实生产观察，WhatELSE 是小规模工具比较，Drama Llama 是自选作品自评，Dramamancer 是 demo 部署数，Bonsai 定量部分是模拟偏好与模型评分。其优点可以互补，不能把它们相加成“已有大量真实玩家证明”。

## 3. 当前最容易被误当贡献的叙事

| 说法 | 为什么不够 | 何种新证据才可能有意义 |
|---|---|---|
| 给 NPC 增加目标、记忆、导演和工具 | 已有经典/现代完整谱系 | 对人重视且普通完整系统未解决的问题，说明新增机制和泛化边界 |
| 世界有后果，因此比聊天有价值 | 文本角色、立场与关系也可有玩法意义；有后果也可能无聊 | 玩家原本意图、体验和作品目标之间的对应关系 |
| 角色必须一直保持原设定 | 人物弧线和玩家共同塑造可以要求改变 | 区分有理由的变化、作者许可的改写和无依据漂移 |
| 作者意图保持率更高 | 作者会从意外中发现新意图，固定遵守可能降低共创 | 作者是否能理解、采纳和修改，作品及劳动怎样变化 |
| 生成更多分支/更多故事 | 可能增加筛选和维护负担，并未增加有意义的选择 | 不同参与者珍视何种改变，是否支持重复体验或表达 |
| 一个触发条件失效或商业模型泄露一次秘密 | 可能只是信息、提示、权限和普通检查缺失 | 多独立机制、强普通系统、真实作者/玩家认可的持续压力 |
| 静态故事更合理，说明 NPC 玩家体验更好 | 读者合理性、戏剧质量和实际参与是不同对象 | 对实际玩家的意图、控制、感情与故事解释做相应验证 |
| 新组件胜过去掉状态/修复的消融 | 只证明那个基础功能有用 | 与完整合理工程、同信息/资源和经典方法比较 |

## 4. 必须认真考虑的强普通系统

以下是未来有资源授权时应比较的参照定义，**本轮没有实现、调用或运行**。

### A. 完整强 LLM 导演 + 状态 + 普通重规划

合理普通系统应获得世界/人物设置、已发生事实与经历、人物各自知情与隐瞒理由、作者可修改/不可修改内容、玩家当前创作权限、可调用工具和工具反馈。导演维护未来剧情与可接受替代，在玩家介入或重要状态变化后普通重规划；演员接收适当的局部知识与动机，避免把全剧本直接泄给所有角色。输出提交前可做格式、世界、角色知识、披露条件和作者明确约束检查，失败后普通反馈修订；保留足够历史或合理记忆。

提示应认真设计，接口和反馈也要完整。模型采用届时可用的强商业基线并记录准确版本；若要讨论“模型能力问题”，应在同一合理系统内比较模型/推理预算，而不是拿本地小模型与外部文献异条件比较。材料、上下文、修复机会、延迟/调用预算及玩家界面应尽量匹配。部署便宜不是方法必要性的回答。

这一参照本身可能已经满足需求；[ACL 2025](../../../library/themes/game-npc-social/papers/IMMERSION_AGENCY_DRAMA_2025.md)的正面结果要求认真考虑这种可能，[NCP](../knowledge/papers/NCP_2026.md)则提供强模型仍会在长轨迹出错的边界。二者都没有完成这里定义的全部强普通比较。

### B. 可创作 storylet 与普通混合规划

采用作者可编辑的场景、条件、结果、时间事件和动作/状态规则，LLM 负责语言映射和续写；可达性、动作合法性及固定知识条件由明确规则检查。对形式化合适的子任务，使用 GME/StoryAssembler 类重规划以及 Sabre 类意图/信念约束。对于作者编辑问题，包含直接修剪、修改已有内容、复用规则和轨迹检查；Bonsai 式从编辑提意图不是要被省略的弱对照。

比较应说明哪些规则需要人工建模和维护。不能要求符号系统解决未给符号语义的无限开放语言，再宣布 LLM 胜出；也不能给混合系统更多作者工作量却只计算模型调用。最近的 [Halberd](../../../library/themes/game-npc-social/papers/HALBERD_2026.md)进一步要求排除“把角色层换成 LLM”这一已有增量。

### C. 作者/人类主持的作品参考

人工续演、作者示范或人类主持可帮助理解目标是否说得清楚、哪些意外被接受、人物如何变化；它是作品特定的参考，并非无条件的性能上界。人类主持的即兴能力、对玩家的社会理解和额外投入应显式记录，不能在预算和互动方式不同的条件下当作公平算法基线。

### D. 简单但认真的编辑与交互参照

作者研究需给普通聊天助手完整稿件、轨迹、规则、编辑工具和同等支持时间；将“从编辑提规则”与直接给原始编辑范例、直接说明作者意图比较。涉及多个项目时应先按已知项目隔离，而不是人为混合所有项目规则再用复杂检索修正。Bonsai 的小检索 pilot 本身就显示 top-k 未稳定胜过简单拼接，不能把任何更复杂路由当作当然进步。[Bonsai](../../../library/themes/game-npc-social/papers/BONSAI_2026.md)

## 5. 能形成怎样的整体认识

在有对应证据时，下面三类产物都可能有价值，不要求都变成新模型：

1. **解释清楚叙事改写的不同类型和适用条件。** 哪些玩家介入应改变人物目标、关系解释、未来情节或作者意图；哪些抵抗/失败被接受；玩家作为角色和作者的差异是什么。
2. **建立作者和玩家能共同使用的表达/编辑方式。** 帮助人发现值得保留的意外、区分局部例外与新规则、理解修改影响；价值需由作品及全部创作劳动体现。
3. **针对已确认压力提出有必要的机制。** 例如表示改变依据、控制规则作用范围、把人物知情/披露和未来剧情分开；前提是优于完整普通系统，且收益不只存在于弱模型/研究者设计的局部案例。

如果最后认识是“很多预想的深层问题经普通状态和重规划即可解决”，这会是重要的题目筛选结论；无需为了保留方法叙事继续做微小提示调优。
