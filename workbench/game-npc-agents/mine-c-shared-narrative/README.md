# 矿区 C：可共同改写的角色叙事

> 用户于 **2026-10-19** 要求深入叙事并建立矿区。**矿区已建立；问题与文献建设；未进入实验立项；无实验项目或 ACTIVE 分配。** 本轮没有启动模型推理、付费 API、GPU、引擎或玩家实验，也不修改其他研究的状态。

## 我们要理解什么

**玩家怎样参与改变人物和故事的发展，人物的变化怎样保留可理解的理由，作者怎样表达、发现并修改作品的意图？**

“共同改写”包括故事中行动使未来发生变化，也包括作品明确允许的共同创作。二者权限不同：扮演一个角色不自动取得修改所有人物、历史和结局的权力；作为共同作者提出新设定，也不应一律被当成破坏角色的输入。角色可以抵抗、误解、失败或离开，作者也可以因为玩家的发现而改变原来的想法。[能动性理论](../../../library/themes/game-npc-social/papers/AGENCY_RECONSIDERED_2009.md)、[共同创作史](../../../library/themes/game-npc-social/papers/COAUTHORSHIP_EMERGENT_NARRATIVE_2021.md)支持这些区分；它们不是本矿区已经验证的新结论。

这类能力可服务互动戏剧、角色驱动 RPG、视觉小说、关系叙事、侦探故事、玩家/AI 共同创作及叙事制作工具。它的价值可以来自新的关系解释、情感立场、戏剧冲突或有意义的失败；不要求所有价值都表现为物品、数值或物理引擎变化。

## 为什么值得建矿，为什么还不能定方法

已有工作足以证明这是一个真实且持续的研究方向：经典规划区分作者结局和人物意图；真实制作记录暴露动态片段的组合调试负担；现代工具允许作者编辑可能性空间、让玩家自然语言参与并保留意外生成材料。[IPOCL](../../../library/themes/game-npc-social/papers/IPOCL_2010.md)、[StoryAssembler](../../../library/themes/game-npc-social/papers/STORYASSEMBLER2019.md)、[WhatELSE](../../../library/themes/game-npc-social/papers/WHATELSE2025.md)、[Bonsai](../../../library/themes/game-npc-social/papers/BONSAI_2026.md)

但“导演 + 人物 agent + 状态 + 重规划”“自然语言 storylet”“从编辑积累作者规则”都已有很近的工作。GPT-4o 的普通剧情反思已有正面结果，Bonsai 也使用 Sonnet 4.6/GPT-5 等商业模型；不能预设必须训练新模型或发明新架构。[ACL 2025 互动戏剧](../../../library/themes/game-npc-social/papers/IMMERSION_AGENCY_DRAMA_2025.md)、[Halberd](../../../library/themes/game-npc-social/papers/HALBERD_2026.md)、[Dramamancer](../../../library/themes/game-npc-social/papers/DRAMAMANCER_2025.md)

当前立场是：**有充分理由深入问题、作品和人；是否存在值得投入的特定方法，仍取决于强普通系统与真实作者/玩家证据。**

## 四条宽子方向

| 子方向 | 要保留的核心压力 | 可以形成什么新认识 |
|---|---|---|
| 人物意图与知识披露 | 人物如何有理由地改变目标；谁知道秘密，何时愿意说，玩家能否理解 | 区分合理人物转变、临时迎合、剧透、信息被说出但不被相信 |
| 戏剧节奏与冲突 | 玩家介入后，冲突如何发展、失败如何继续、何时给玩家发言/行动机会 | 何种抵抗、延迟和意外支持作品，何种导演干预压过玩家 |
| 玩家扮演与共同创作 | 玩家是在世界里行动、表达价值，还是请求共同编辑世界 | 不同创作权限及其表达方式如何改变角色体验和故事解释 |
| 作者表达、编辑与调试 | 作者怎样看见意外、保留好发展、修正局部并理解远处影响 | 作者意图如何随作品演化，总制作劳动如何变化 |

详细问题、证据边界和相邻矿区分工见 [RESEARCH_MAP.md](RESEARCH_MAP.md)。

## 当前四个候选问题

这些是待筛选问题，不是已立项、已证明新颖的论文题目。

1. **人物与剧情如何接受有理由的改写？** 玩家改变一个人物对事件的理解时，未来目标、关系和戏剧路径如何一起变化，玩家是否能理解变化来自哪里？
2. **秘密与揭示如何成为可参与的叙事？** 玩家提前猜到、误解或争取秘密时，系统如何既承接参与，又保留适当的人物知识和披露理由？
3. **玩家怎样参与塑造冲突和节奏？** 哪些介入应改变冲突形式、时长或失败后的方向，而不是只有“继续原剧情”或“立即和解”？
4. **作者怎样从意外中改作品，而不失去对修改影响的理解？** 如何区分一次例外、应该复用的规律和作者新形成的意图，并让下一批玩家有机会继续创造？

每个问题的已解部分、3–5 个近邻、潜在贡献与关键未知见 [RESEARCH_MAP.md](RESEARCH_MAP.md)；最强正/负证据、普通系统和排重标准见 [POSITIONING.md](POSITIONING.md)。

## 进入研究前最有信息量的一轮应是什么

**以下仅是未运行的进入设计，没有实验或资源授权。** 一轮应同时回答“人是否关心”与“普通强系统是否已够用”，不先累积局部提示案例。

比较完整强 LLM 导演（人物/世界状态、已发生经历、可改未来、创作权限、工具反馈、普通重规划和提交前检查）、可创作 storylet/混合规划系统，以及适合该问题的人工作者参考。用不同作者、题材和叙事机制提供独立单位；同一故事的多个续写只估计波动，不扩张为多个世界。真实玩家应能表达自己的意图并说明体验；作者应能发现意外、改变主意并检查修改后果。

关键结果包括：玩家是否认出自己的影响，人物的理由是否可理解，作品的冲突/秘密/主题是否仍成立，作者能否保留意外并预测修改范围，以及所需的修补劳动。若普通系统广泛足够，不继续包装复杂架构；若问题主要来自含糊规格，先研究如何表达和协商规格；若作者和玩家珍视不同结果，保留这种分歧并解释适用范围，不强行合成单个总分。

## 与其他矿区的关系

角色扮演矿区研究人物如何可塑造、可延展；本矿区关心这些变化怎样进入可参与的故事。情绪与关系矿区研究情绪/关系如何随经历演化；本矿区关心演化如何成为人物弧线、冲突和揭示。[矿区 E](../mine-e-player-agency/README.md)研究玩家能否发现、理解和驾驭互动自由；本矿区承担故事与作者层面的改变。这里不继承已关闭矿区的实验、主张或状态。
