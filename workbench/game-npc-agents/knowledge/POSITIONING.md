# 游戏 NPC 研究的最近邻 ownership：训练、角色、攻防、经济并存（2026-10-14）

**用户纠正了两次过窄选题。** 本表不设唯一 scientific story，不声称任何方向空白，也不能自动判死方向。保留过去“目标vs计划”的工作作为子问题，不再独占研究空间。引用的所有主张均为前人，不属于本 workbench 自有 C##。

| 科学领域 | 直接或最近邻已有贡献 | 我们绝不能冒领的“创新” | 若要产生严肃科学增量，必须进一步问什么 |
|---|---|---|---|
| NPC设计与训练 | EA2026、MultiGAIL、ICML2022行为约束、PCSP/UBCL | 首次训练可控NPC、共享策略、自然语言人格转行动 | 行为监督如何改变真实游戏控制与跨角色/游戏的条件，什么反馈才值得成本 |
| NPC语言与可执行角色 | LIGHT/Dragon、KNUDGE、CDT、AIIDE侦探 | 第一个有自主目标/规则/对话知识树NPC | 游戏规则与玩家开放行动之间，哪些交互因果/效率/创作限制还没解释 |
| NPC遭对抗输入 | ProvSec2025 NPC secret extraction（30条/单轮）、COLING2025 RoleBreak | 第一次发现可攻击NPC、第一次角色偏移/信息泄露 | 什么新信任边界/多轮传播/实际游戏后果超出这些已知结论 |
| 角色动态 | ACL2026 Dynamic Persona, Generative Agents, ArcANE | 静态persona不够、角色会成长/漂移 | 合理成长 vs 受攻击偏离能否以实际行动/玩家感知支持，现有评价会误判什么 |
| 通用代理安全 | NeurIPS2024 AgentDojo, ICLR2025 ASB | memory poisoning、tool prompt injection、联合效用与安全指标 | NPC特有的玩家权威、游戏规则/剧情允许攻击与防御的区别 |
| MMO经济模拟 | AIIDE2008 EVE, KDD2025 MMO经济模拟 | 首次虚拟交易智能体、首次LLM NPC拍卖/角色分工/供需浮动 | 自然游戏制度/资源流程与LLM攻击/协作产生什么新的可验证规律 |
| 经济系统性风险 | AgentBazaar (2026), TruthMarketTwin, market mechanism 2026 | 首次Sybil诈骗、多卖家协同、价格崩溃、制度防御 | 哪些游戏内状态、任务/身份、NPC传播改变已有安全结论，是否可以提出新机制或更有效评测 |
| 游戏剧情欺骗与玩家意义 | CHI2024, AIIDE2026, NCP-Bench | 所有谎言是幻觉、首次有作者控制、首次研究信任 | 如何区分有意义的许可欺骗和无意失败，系统干预是否破坏玩家体验 |
| 视频与社会具身 | ReactiveGWM, WorldMind, MineAmongUs(workshop) | 首次视觉NPC/非语言欺骗/LLM+行为树 | 真实视频/动作新机制与代价，而不是复用普通文本 benchmark |

## 每条 idea 要回答四层
**空间**：在哪类游戏NPC中有什么仍重要且未知，近邻谁已经回答了哪些部分？
**线索**：目前观察/数据到底可不可信，是否只是模型太弱、判分器循环定义或规则导致？
**主张**：已经可以确信什么，哪些机制仍能解释现象？
**贡献**：若证实，同行会改变哪种训练、权限/防御设计、测量或游戏制作者的选择？

目前只拥有更新后的领域理解，**没有已被实证证实的新主张**。不要靠风格标签或 benchmark 名称宣布 novelty，也不要因为强近邻存在就否决重要研究；目标是更深的认识。
