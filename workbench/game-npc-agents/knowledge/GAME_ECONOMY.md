# 游戏内多 NPC 经济与攻击：从MMO角色到系统性制度风险

2026-10-14。本板块是**直接游戏NPC／玩家互动经济问题**，不只是把电商诈骗 benchmark 换名叫 RPG。论文贡献可以是机制、理解、训练、测量或系统，但必须有世界规则、可结算资产或可追溯交易后果。

## 1. 直接的游戏学术谱系
### AIIDE 2008：Intelligent Trading Agents for Massively Multi-Player Game Economies【摘要/正式会议】
论文 https://ojs.aaai.org/index.php/AIIDE/article/view/18680 。使用 EVE Online 的历史经济数据研究NPC交易、供应链、RL策略和如何减少被其他参与者剥削。
**重要的前史：** “给虚拟世界商人装智能交易策略”“让NPC抵抗人类交易剥削”早在LLM以前就有人做；不能称新。它帮助界定真正 MMO 经济含**玩家、物品、生产链和历史价格**而不只有价格博弈。

### KDD 2025：Empowering Economic Simulation for Massively Multiplayer Online Games through Generative Agent-Based Modeling【本轮精读正文方法/实验/附录】
原文 https://arxiv.org/html/2506.04699v1 ；正式 KDD proceedings DOI https://doi.org/10.1145/3711896.3736929 ；论文注明代码归档 https://doi.org/10.5281/zenodo.15526912 （**本轮未下载验完整可运行性**）。
- **DOCUMENTED 研究对象：** MMO game economy，模拟资源生产/交易/消耗/付费成长；角色信息分层、感知、结构化动作、执行反馈、短期/数值长期记忆、反思。具体动作含 Task、Recharge、Shop、Auction Buy/Sell、Upgrade、P2P。
- **作者做的实证：** 强能力/多样性 baseline（Random、Rule、MMO-economist RL、ReAct、Reflexion）、STM/LTM/反思消融、角色类型一致性、系统级市场；系统试验以**30 agents×200 steps** 演示拍卖/P2P、供需与价格的关系。报告拍卖均价6.86 vs P2P6.46，价格与需求供给差相关约0.67；这是**原文的模拟结果**，不是我们复现。
- **成本/证据边界：** 主模型分析使用 GPT-3.5，角色设定生成和主观一致性评分使用 GPT-4；作者有一个 Llama3-8B 参照。**不能无修改称可零API复现原表**。原始用户行为数据、具体引擎/规则与模型收益不可自动推广到真实商业世界。
- **Idea来源重建（我们的推断）：** MMO经济政策难以试错、真实玩家轨迹昂贵 → 不局限随机/规则 ABM，而以LLM角色能力合成异质经济行为 → 用三层证明：个人可玩能力、角色与人相似、群体供需现象。亮点不只是使用LLM生成交易话术，而是把可执行事件与经济观测放进同一个实验链。
- **对其结论的必要审计：** 规则本身可能保证了价格随供需变化；不同角色的消费偏好/固定资源初始分布也可能产生“分工”，不是LLM产生了超出机制的社会创造性。若要把相关系数解释成自主经济规律，应控制市场撮合、供需扰动、脚本/弱策略与报告所有样本。该质疑**是我们提出的竞争解释，不是已经证伪原文**。
- **没有覆盖什么：** 原文重点是构造可信/可用经济模拟，不是针对对抗玩家/被攻NPC/身份欺骗/制度稳健性的系统性红队；但这并不意味着无人研究后者——见下面 Agent Bazaar。

## 2. 不能忽略的 2026 相邻安全/经济近邻
### Agent Bazaar（2026 作者页面标注 COLM，正式身份仍需独立核查）【作者项目页+真实公开仓库 README】
论文 https://arxiv.org/abs/2605.17698 ，作者项目 https://sethkarten.ai/papers/agent-bazaar.html ，源码 https://github.com/sethkarten/AI-Bazaar 。
- B2C 定价竞争崩溃、C2C **Sybil多卖家欺诈**、稳定市场的制度/agent控制；作者已有 RL REINFORCE++ 对9B模型做 targeted economic alignment，以及 stability/integrity/welfare/profitability 综合评价。**“多Agent会对市场撒谎/操纵”已有充分工作，不是我们独创。**
- 官方开源项目 README 支持本地 Ollama / vLLM 与本地模型 runner，但默认例也提供多家外部API；**本轮未安装/运行**。这套非游戏市场可提供机制与实验方法，不自动证明适用于有真实玩家行动/掉落/工艺的 MMO。

### TruthMarketTwin（2026 arXiv）【摘要】
https://arxiv.org/abs/2605.10059 。买卖双方信息不对称、信誉、售后与策略性欺骗；不能宣称“信息不对称市场诈骗”新颖。

### Formal Mechanisms for Market Stability in Self-Interested Agent Societies（2026 arXiv）【摘要】
https://arxiv.org/abs/2607.08652 。作者模拟18个专业角色、200轮交易及对抗参与者，研究制度修复/攻击。既有针对LLM社会市场的恶意角色研究，不得因没做 MMO 外壳就视为空白。

### AI-native Games Survey（2026预印本）【HTML正文】
https://arxiv.org/html/2607.00527v2 ：群体模拟、安全与规则能否维持玩法，是近年设计压力；综述53个可玩样本，但不等于各类经济攻击均未研究。

## 3. 经济“攻击”必须以游戏机制定义
| 类别 | 正常可能是什么 | 何种条件下成为游戏攻击/失效 | 可以客观记录 |
|---|---|---|---|
| 议价/竞价 | 玩家与NPC合法博弈、优惠/囤货 | 骗取超出角色/库存权限的转移，或绕过作者设定的限制 | 订单、真实支付、库存资产、预算余额 |
| 信息不对称 | 玩家的情报收集、商人的策略隐瞒 | 伪造可验证质量/游戏系统信誉，冒用认证权限 | 报价、真值、信誉更新/来源 |
| 多账号/多角色 | 游戏规则允许多个店铺/公会 | 一人控制Sybil角色绕过身份/审计或市场规则 | 身份证明、交易网络、买卖双方福利 |
| 群体定价与协作 | 正常同行竞争、公会贸易 | 合谋/联动导致非预期崩溃或资源供应中断（必须有世界设计目标） | 价格、成交量、资源供需、破产、集中度 |
| 长期信誉与消息 | 广告、口碑传播、黑市剧情 | 恶意虚假消息被NPC当交易真值并传播 | 信息路径、成交后果、记忆可更正性 |
| 虚拟币/资源产生 | 任务奖励、合成、掉落 | 引擎状态/库存无真实守恒或被NPC文本任意创造 | ledger守恒、资源产销平衡、审计日志 |

**“价格波动”“NPC撒谎”“富裕玩家赚钱”均不是自动安全问题。** 先理解该游戏是合作社会、竞争交易还是黑市叙事，规则允许什么、设计师想要什么、玩家能否正当达成目标。

## 4. 高信息量方法：个体政策与市场制度分开
1. 从已发表 KDD/AIIDE 的经济任务与当前可执行代码入手，确定资产账本、订单撮合和角色权限的 ground truth；源代码是否完整/许可如何另核，不能因为论文链接有 Zenodo 就宣称 baseline 复现。
2. 最低限度有 ①纯规则/经济学政策群体，②小规模本地 LLM trader 群体，③混合群体，④非攻击正常玩家基线。大部分常规人口可以**无GPU**模拟，只有有意义的决策节点调用本地 LLM，避免每一步全体几十个NPC触发高级模型。
3. 区分“固定游戏制度、改变玩家/攻击行为”与“固定行为、改变交易制度”；随机价格扰动、信息分布、角色专业化也可帮助判断规律来自模型还是规则。
4. 首要分开 **个体任务成功、群体社会福利、游戏可玩性/经济平衡、违规资产转移、正常角色交易质量、token/延迟**。单一 EAS 或某个胜率不能代表全部。
5. 根据 pilot 结果再决定是安全机制研究、训练/策略研究、经济行为发现，还是数据测量有效性；**不预先承诺要找到价格攻击新机制**。

## 5. 可行性与安全边界
经济事件和规则政策可以在 CPU 上模拟，几个本地模型共享 vLLM 服务。源头游戏 MMO 资产和 KDD 玩家日志可能有访问/授权限制；不复制真实人类买卖数据到公开Git。研究只在离线模拟中做，不对线上游戏、玩家真实经济或商户施加攻击。量测成功按合法环境状态，不靠NPC自报财富。
