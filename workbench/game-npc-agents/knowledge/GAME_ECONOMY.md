# 游戏经济与制度：生产、交易、异质行为和群体反馈

更新：2026-10-18。经济NPC不只是会砍价的聊天角色。资源来源、生产、消耗、库存、市场、技能成长、信誉和制度共同塑造玩家可做的事。这里区分**游戏内经济体验**、**用模拟玩家帮助设计游戏**和**借简化世界研究制度**；三者可以共享模型，不共享全部结论。

## 1. 领域的主要问题

| 层次 | 关心什么 | 需要什么证据 |
|---|---|---|
| 单个角色 | 如何选择劳动、消费、交易、积累和风险，形成可辨认的行为 | 状态与真实结算、跨局势策略、异质偏好及可解释性 |
| 相互作用 | 价格、议价、分工、流动性、信息不对称和信誉如何作用 | 成交与未成交、库存、支付、消息来源、网络依赖 |
| 制度 | 撮合、税收、准入、惩罚、共享与激励如何改变行为 | 固定人口改制度、固定制度改政策，允许适应及反应 |
| 群体后果 | 资源是否持续、机会是否集中、市场是否脆弱、故事是否丰富 | 产销守恒、分配、价格／产出、冲击响应；游戏设计目标另说明 |
| 外部有效性 | 仿真是否能预测真实玩家对机制变化的反应 | 留出数据、政策变化、不同游戏／玩家分布、基线校准 |

真实经济预测不是每个虚构商人的必要目标；若主张经济模拟可用于制定上线政策，就必须提供相应外部证据。市场“像现实”也不保证有趣或平衡。

## 2. 从规则交易到生成式MMO仿真

[Intelligent Trading Agents for Massively Multi-Player Game Economies（AIIDE2008）](https://ojs.aaai.org/index.php/AIIDE/article/view/18680)的旧摘要／正式身份记录保留：游戏交易、供应链和防止策略被剥削有长期前史。原文和原数据未完成深读，不以二手描述构成具体实证。

[MMOAgent（KDD2025）](papers/MMOAGENT_KDD2025.md)是本轮完整正文和附录核读的直接MMO来源。它模拟玩家经济行为：生产、升级、充值、拍卖、P2P议价经可靠底层规则和账本发生实际变化；短记忆、数值长期检索、反思与高层动作组合工作。主能力模型是GPT-3.5-turbo／Llama3-8B，画像与一致性评估用GPT-4，不是当前强API全面比较。

真实来源为一个未公开名称的网易MMO的一周日志，16,294玩家的8项特征聚成5簇后再生成人物画像。它提供现实分布入口，但不是留出玩家策略或制度变化的预测验证。宏观30代理×200步出现拍卖／P2P价格差、资源稀缺和不平等反馈；供需相关r=.67是作者模拟内部读数，时间点不能视作独立经济重复。其强处是将语言行为接入经济循环，边界是校准和制度外推仍有限。

## 3. 公共资源、社会约定和制度共同适应

[GovSim（NeurIPS2024）](../../../library/themes/game-npc-social/papers/GOVSIM_2024.md)把五个自利代理的开采、公共交流与资源再生／崩溃连起来。鱼、草和污染三个主题共享同一数学机制。GPT-4o默认存活8/15，给出含具体数值阈值及长期后果的Universalization记忆后15/15；不能只说强模型普遍不能合作，也不能将这个变化纯归于抽象道德推理。它主要揭示固定机制下的信息、目标和协作条件，尚不是丰富MMO制度。

[社会惯例研究（Science Advances2025）](../../../library/themes/game-npc-social/papers/NORMS_2025.md)在重复命名协调中观察约定形成、微弱历史偏差的放大和固定少数派导致的翻转。它能研究局部互动和群体反馈；没有自由协商、私利冲突或可执行伦理制度。任意字母共识、公共资源治理、真实经济规则是不同问题。

[AI Economist的2021实读版](../../../library/themes/game-npc-social/papers/AI_ECONOMIST_2021.md)把税制设计者与经济代理同时训练，让制度改变劳动、交易及跨税年收入安排；使用按世界调优的Saez理论基线。重要认识是群体依赖：提高高技能生产者税率可能减少其材料需求，进一步影响未进该税档的采集者。制度优化不能在固定行为代理上完成后就默认改革反应正确。该版没有真人数据／实验，不能沿用后续版本的证据；正式2022论文及早期人类版本另列欠账。

## 4. 社会基础设施与真实策略游戏

[AgentSociety的ACL Industry并行框架](../../../library/themes/game-npc-social/papers/AGENTSOCIETY_2025.md)把城市、社交与经济账本接入代理，体现同步、通信和运行规模的实际问题；其经济尚缺完整市场与企业。[CitySim](papers/CITYSIM_2025.md)加入日程、需求、长期目标、空间信念和关系，但行为预测并未全面超过统计基线，“Human Preferences”一节实际由模型评分。规模和总体分布是基础设施证据，不是丰富NPC社会或玩家体验的充分证据。

[Vox Deorum](papers/VOX_DEORUM_2025.md)在Civilization V中保留成熟战术AI，以LLM宏策略改变经济、科技、政策和胜利路线。2327个完成局提供真实复杂规则中的运行证据，未检出胜率差异不等于已做等效检验。论文所测版本是宏策略对手／顾问，未有真人自然语言外交实证；当前作者项目已宣称加入交谈、议价与承诺交换，其运行可靠性和玩家收益尚未在本库核验。论文结果、后续实现说明与玩家证据分开。

## 5. 安全是经济的一部分，不能统领整个经济方向

议价、囤货、风险偏好、阵营排斥和合法隐瞒可能都是设计内容。越权转移、账本凭空造资产、伪造系统认证和绕过制度则涉及不同边界。定义依赖游戏规则与作者目标，不能仅因某人获利、某价格波动就判攻击。

[Agent Bazaar](https://arxiv.org/abs/2605.17698)、[TruthMarketTwin](https://arxiv.org/abs/2605.10059)、[Formal Mechanisms for Market Stability](https://arxiv.org/abs/2607.08652)继续作为相邻市场／安全入口：前者旧范围为作者页和公开仓库README，后两项摘要；没有本轮完整正文或实现验证。作者自报COLM与正式会场身份分开，不拿其标题来证明游戏经济已解决或存在空白。[NPC安全](NPC_SECURITY.md)另维护权限和合法玩法。

## 6. 有价值的比较与开放问题

固定市场制度，比较规则、RL、LLM与混合人口，才能辨认代理政策贡献；固定人口行为，改变撮合、税率、信誉、信息与外部冲击，才能辨认制度贡献；允许长期适应后，还要看短时结论是否改变。规则本身保证供需关系时，重现供需方向不够说明语言代理真实。

对游戏设计，值得理解的是异质商人、玩家和派系如何形成可学习的经济规律，制度变化是否产生可理解的机会与冲突，以及怎样同时控制资源持续、公平／差异、策略深度和作者可编辑性。对仿真方法，重要的是能否预测未见玩家、机制变化和新分布，而不是只让总体曲线看起来合理。

更多真实游戏数据、玩家参与的经济机制研究、商业经济运行一手资料、外部校准、长期信誉／公会制度和非LLM市场模型仍需系统扩展。Zenodo／GitHub链接存在不等于完整数据和许可已核实；具体状态见[MMOAgent卡](papers/MMOAGENT_KDD2025.md)及[阅读欠账](READING_CATALOG.md#reading-debts)。
