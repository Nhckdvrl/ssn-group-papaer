# Deriving Character Logic from Storyline as Codified Decision Trees

规范记录：`cdt_2026`；ACL 2026 Main，12480–12509（ACL Anthology正式PDF）。实际版本：ACL Anthology 2026.acl-long.568，30页。

[原文](https://aclanthology.org/2026.acl-long.568.pdf) · [发表／主源信息](https://aclanthology.org/2026.acl-long.568/)

**来源与范围：** 2026；ACL 2026 Main，12480–12509（ACL Anthology正式PDF）；ACL Anthology 2026.acl-long.568，30页。完整正文第1–10页；附录A–E第13–17页全部实验与成本、F第18页机制解释、G第24–26页全部提示；第19–22页长人物展示与27–30背景表未逐项完整阅读。[Deriving Character Logic from Storyline as Codified Decision Trees](https://aclanthology.org/2026.acl-long.568.pdf)。阅读标记：first_full_body_after_existing_partial_card。

**问题与机制。** 从角色故事行为而非手写标签归纳可核人物逻辑。聚类 scene–action，GPT-4.1生成 if–then 假设，经GPT-4.1-mini对全部已见行为作支持/反驳/未知检查；可靠规则成为节点，局部规则递归细分。推理时LLM或蒸馏DeBERTa判断场景谓词，再将已访问规则作为生成提示。“可执行”主要是条件检索流程，不代表动作有硬世界后置条件，也不保证自由语言分类器确定无误。CDT离线固定，在线人物变化尚属未来工作。

**证据与对照。** 45角色/8作品20,778对＋40角色/8支Bandori乐队7,866对，另77,182事件对；同一故事的角色/相邻10步输入不是独立游戏世界。每角色按故事时间前半训练后半测试，降低直接样本泄漏，不能排除预训练对原作的知识。主角色骨干Llama-3.1-8B，附录仅扩1B/3B；强GPT用于造树/评判，未测强商业角色普通提示能否消除差距。Fine-tune、8例检索、ETA、人工/编码人工设定等对照较齐。CDT-Lite Fandom61.01 vs人工58.33、Bandori79.04 vs71.28；分数是对原作下一行为的NLI entailed/neutral/contradicted=100/50/0，不是任务成功率，合人物逻辑的替代行动也可能只得50。

**机制辨别与局限。** 将同一CDT规则全部线性化普通提示后，Fandom59.82、Bandori78.70，仅比完整树少1.19/.34；深度1亦59.65/77.90。因此证据同时支持“从实例诱导、验证的知识更好”，不能把总收益全部归于树遍历或复杂层级。超参分析用了测试集10%，严格独立最终测试仍需确认。NLI人工每类200例一致88.5%–92%，校准的是原作匹配标签，不是完整角色体验。

**开放交互与领域位置。** 附录D实有200新起点×10轮角色互动，CDT对人工设定获人工偏好39%对27.5%（余为平），但未清楚交代评审人数/一致性，且无真实玩家干预或引擎世界后果；不能把论文说成只有单轮。它的重要方向是可解释、可编辑、由行为证据支持的条件人格与关系模式；下一层难题是规则冲突、真实人物转变、跨处境新行为及叙事目标和可执行世界约束如何共同更新。
