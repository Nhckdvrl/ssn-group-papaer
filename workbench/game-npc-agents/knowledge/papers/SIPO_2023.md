# SIPO（NeurIPS2023）`[证据：正文/关键附录]`

[官方论文](https://papers.neurips.cc/paper_files/paper/2023/file/473aadf077f8464dbae7e9600d9be6c4-Paper-Conference.pdf)。已读§3–6、B关键评价、D预算/基线、G伪代码；证明未全部复核，未本地复现训练或审计作者完整代码。

1. 形态：测量反例＋理论＋多样策略方法。DOCUMENTED来源是动作差异可对应相同游戏后果，occupancy距离也会饱和。
2. 方法：状态距离RBF/Wasserstein，迭代策略与Lagrange两时标更新；相较PBT减少联合约束。不直接以语义persona训练，也明确接受部分次优策略，不能统称硬约束近最优。
3. 协议：Humanoid/SMAC/足球，五/五/三seed，匹配environment frames。足球按球传递路线评策略；随机不同seed重复训练也是强baseline。表5/6与附录含CE、固定Lagrange、filter、PBT及状态/动作组合消融。
4. 定位：动作KL≠战略差异、无domain prior发现多样玩法均已有owner。我们的E38实际命中/资源/收益分列是必要测量，不是自动创新；增量继续落在具体角色属性利益变化、状态机会与训练经验之间的关系。
