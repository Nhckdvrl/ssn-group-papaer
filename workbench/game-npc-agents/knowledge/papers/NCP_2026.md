# Can LLM Agents Stick to the Script? A Benchmark for Long-Horizon Consistency in Interactive Narratives

**问题与机制。** NCP-Bench测试 GM 对开放玩家输入保持世界事实、作者剧情顺序/不变量/必达事件，同时回应玩家行动的能力。100部CMU电影梗概人工清洗并多题材挑选，LLM生成、专家审核为1,660初始事实、1,222约束、1,511剧情节点。每轮自由文本经外部LLM更新事实、审计三类冲突并二次确认，首次确证冲突即终止；无冲突且全部 achievement 满足才是SUCCESS，100轮无冲突为SURVIVAL。事实允许有因果解释的变更，玩家可以被拒绝，拒绝本身不算错误。

**对照与结果。** 六模型×100电影各一次＝600主实验，temperature .6/top-p .95/上限8,092 tokens，玩家及主审计 Gemini-2.5-Flash。GPT-5.2平均32.92轮，第20轮仍活跃比例42%；事实终止占40%–68%，多类可以重叠。这个曲线是到达轮数且未提前终止的生存统计，不能替代完成率。附录明示 narrator 已收到事实、约束、当前节点等，不能解释成“只给裸提示、完全无状态”；但没有提交前检查修复、形式执行器或强模型普通重规划对照。HiAgent仅配GPT-4o-mini：平均22.16→30.05轮，约束冲突26%→4%，玩家输入冲突13%→38%；真正全achievement完成2→0，表中Succ.5→3混合了完成和100轮存活。

**局限与可核口径。** 三审计器实验只用GPT-4o-mini，终止审查100项有4项事实误报争议，不能得出整条轨迹的漏报率或所有模型审计准确率。自然合作玩家也是LLM，100轮存活3→19而全完成2→0；真实人类仅Iron Man一个世界，两种策略19轮完成/100轮存活，不能声称100场景人类可解均已验证。作者把严守电影线性顺序作为目标，部分“过早提及既有人物特征”的错误是该规格选择，非普遍游戏叙事缺陷；narrator的最高指令要求先推进节点，又测输入回应，权衡需显式研究。

**领域位置。** 它较扎实地把文本连贯拆成可追溯的事实、顺序、完成与玩家回应，揭示强模型仍可能在长轨迹出错；不证明某种专用架构必需，更不证明固定电影剧情是所有NPC玩法应追求的目标。开放问题是不同作者约束强度下，可靠状态、普通自检与动态改写能否同时保存玩家因果影响。
