# NPC Agent：领域问题的来源、研究尺度与进入条件（历史第三轮）

> 2026-10-14：**本文件属于旧领域地图的历史分析，其“优先LIGHT/首选”结论已经被用户更新**。当前全域见 [DOMAIN_ATLAS](DOMAIN_ATLAS.md)，用户选定的矿区 A 见 [persona-behavior/README](persona-behavior/README.md)。其余本文文献和观点保留为研究资产，不允许将旧建议作为执行命令。

更新：2026-10-13，第三轮；由用户对竞赛中心化和 API 依赖的纠正触发。本页取代旧的“先找一个 persona/tool 微问题，再为它补重要性”的选题逻辑。

## 0. 先纠正选择程序

前两轮发现某些仓库容易读、接口容易检查，就把 CPDC 的角色/工具调用提到优先位置。这提供了工程问题，却没有证明它值得作为我们的科研主问题。**容易测、现成数据、两个概念可以对照，都不是领域重要性的证据。** E02 已撤销当前执行优先级，历史设计和 E01 源码事实仍保留；不据此宣称竞赛没有任何技术价值。

本轮按三种不同证据建立问题谱系：已发表顶会说明同行持续研究什么；开发者原始技术访谈说明真实制作压力；公开代码与数据说明我们能检验什么。三者不能相互替代：商业演示不证明科学效果，会议录用不证明我们的变体新颖，能本地跑不证明题目重要。

## 1. 制作可控、但不是死脚本的角色

**领域问题：** 作者需要指定角色的目标、行为边界和风格；角色又需要处理没有逐一写好的场景及玩家行为。研究对象是可控制的行为生成，而不只是更高任务奖励或更鲜明口吻。

**来源与谱系：** [LIGHT / EMNLP-IJCNLP 2019](https://aclanthology.org/D19-1062/) 把身份、场景、对话、行动放在同一游戏里；[How to Motivate Your Dragon / NAACL 2021](https://aclanthology.org/2021.naacl-main.64/) 加入角色自身动机和有后果的社会行动；[Direct Behavior Specification / ICML 2022](https://proceedings.mlr.press/v162/roy22a.html) 直接研究设计者如何指定行为限制，而不反复猜 reward 权重；[KNUDGE / EMNLP 2024](https://aclanthology.org/2024.emnlp-main.520/) 和 [CDT / ACL 2026](https://aclanthology.org/2026.acl-long.568/) 分别深入作者侧知识约束与情境化人物决策。它们不是同一个任务，也没有自动组成一套通用评价。

**游戏界证据：** [Ubisoft Teammates 官方开发者访谈](https://news.ubisoft.com/en-us/article/3mWlITIuWuu0MoVuR6o8ps/ubisoft-reveals-teammates-an-ai-experiment-to-change-the-game) 同时强调玩家能改变角色行动、创作者设定角色边界。此为研发原型的需求与实现说明，不是大规模公开验证。

**还需要弄清什么：** 不先声称“角色控制失效”已是我们发现。进入真实系统后应查：困难来自设计表达含糊、情境识别、目标冲突、行动能力，还是生成/控制分工？作者给的角色要求在陌生但合法的玩法中如何被执行？这一提问只有在自然任务上遇到可靠现象，并能排除简单接口问题后，才可能变成具体研究主张。

**值得什么尺度的论文：** 更可预测的行为控制机制；揭示一种现有控制/评价手段的适用边界；有可验证泛化的简洁方法。仅把 profile 改成规则、给 NPC 加状态表、把 LLM 接到行为树都已有深厚前史。

**我们的进入判断：** 最接近用户所说的 NPC 本体。优先核查 LIGHT/quests 的本地研究闭环，并用现代本地模型与合适的规则/检索基线重新测量。选择底座不是选择论文结论；旧数据上刷新分数也不是贡献。

## 2. 能与真实玩家共同完成事情，而不是只会和自己的副本配合

**领域问题：** 玩家能力、习惯和计划会改变，NPC 要在不确定信息下配合，且不能把“替玩家做完一切”当作所有游戏的目标。

**学术谱系：** [GAMMA / NeurIPS 2024](https://proceedings.neurips.cc/paper_files/paper/2024/hash/6e9f99809b6df59e8fe5c9ffe269bf40-Abstract-Conference.html) 针对训练伙伴无法覆盖真实人类的策略与风格；[Hypothetical Minds / ICLR 2025](https://proceedings.iclr.cc/paper_files/paper/2025/hash/12f483f624b378f9f3058d8ecd3c7ff5-Abstract-Conference.html) 研究通过提出、评价、修正伙伴策略假设来在线适应；[Collab-Overcooked / EMNLP 2025](https://aclanthology.org/2025.emnlp-main.249/) 强调必要协作与过程性评价。GAMMA 的 generative agent 是生成式伙伴政策，不是 LLM NPC。

**游戏界证据：** [KRAFTON/NVIDIA 技术访谈](https://developer.nvidia.com/blog/how-krafton-built-pubg-ally-a-co-playable-character-powered-by-nvidia-ace/) 将队友是否有用、及时、可靠及适应玩家作为实际开发标准，而不只看回答质量。

**有价值的调查范围：** 配对分布、互动中的学习与责任分工、局部信息、行动可预测性；把环境成功和玩家控制感分开。不得先把常识写成发现：“固定队友不能代表所有人”早已是问题起点，增加 ToM/伙伴记忆也不是新颖性。

**我们的判断：** 意义强、公开执行环境较多，但零样本协作/伙伴建模已较拥挤。保留为第二个可进入的领域分支；若研究的是泛用 MARL 排名而没有 NPC/玩家交互含义，不因 Overcooked 容易跑就自动转向。完整重训 GAMMA 也不等于低成本，见 LOCAL_FIRST。

## 3. 长期角色连贯与共同经历的持续后果

**领域问题：** NPC 应在多次互动中保持身份，同时根据实际经历改变关系、知识或策略；一成不变和随意漂移都不能直接叫“连贯”。

**学术证据：** [Generative Agents / UIST 2023](https://arxiv.org/abs/2304.03442) 的记忆—反思—计划谱系；[Dynamic Persona Coherence / ACL 2026](https://aclanthology.org/2026.acl-long.1336/) 区分稳定身份与随历史变化的心理状态；[NCP / ICML 2026](https://proceedings.mlr.press/v306/ma26ap.html) 研究叙事承诺的长期保持。三者分别偏社会模拟、role-playing、narrator，不能当同构 NPC 测试。

**游戏界证据：** [KRAFTON 自述](https://www.krafton.ai/blog/pubg_ally_nemotron/) 区分长期玩家偏好与当前环境信息，讨论主动性、记忆和策略建议。产品文档说明需求，不保证它已解决所有长期问题。

**需要避免的自行说服：** “能复述往事不等于会改变行为”本身不是新发现；也不能仅因已有数据缺少我们想要的标签，就宣布出现新的 benchmark 空白。应先找社区真实任务中记忆/状态导致的决策后果，核对已有论文如何测量，才决定后续干预和数据工作。

**我们的判断：** 对游戏角色重要，可与第一分支共享语料/环境；目前没有确认具备长期关系后果的完整公共资产。不要把短程 LIGHT 演示拼长就宣称自然长程评测，也不要先建立一套全由模型虚构的关系世界。

## 4. 何时说话、行动、等待、重新观察：有用的主动性

**领域问题：** 实时角色要及时行动，又不能不断打断玩家；推理开始时看到的局势，等输出完成可能已经变化。系统响应时间和调用时机是互动决策条件，而不只是服务端 tokens/s。

**学术证据：** [Proact-VL / ICML 2026](https://openreview.net/forum?id=k9PKgV0L4C) 明确研究视频交互中何时响应、响应内容和连续运行；其主要对象是解说/指导伙伴，不是游戏内实体 NPC。

**行业证据：** 上述 KRAFTON 技术访谈把高层语言决策与快速行为树反应分开，说明边界选择就是开发难点之一。不能据此将“LLM + BT”提出为我们的创新。

**我们的判断：** 重要而且与小模型/单节点研究相容。当前 Proact-VL 仓库已给出模型/数据/训练入口，不能再说未发布；但主评价含 GPT 裁判，视频 I/O 和不同数据许可仍要核查。先作为实时性/主动性研究近邻与可选底座，不悄悄把 NPC 方向改成视频解说 benchmark。

## 5. 玩家体验是共同的效度要求，不是可以免费继承的结论

[ACL 2025 Interactive Drama](https://aclanthology.org/2025.acl-long.546/) 明确以沉浸与能动性为对象，并使用人类评价。我们据此采用一条研究原则：任务成功、语言好看、人格分类分数、玩家愿意继续玩，是不同读数。不能用本地 judge 自动给出的“有趣”分数宣称真实体验改善；没有人类证据，就把结论限于已验证的计算对象。

这并不要求所有方法论文先做庞大玩家研究。若结论是机制、规则满足或任务迁移，应给相应证据；只有写到人类信任、体验、负担或偏好时，才需支撑那些措辞的人类证据。

## 6. 本轮优先级与证据债

| 层级 | 当前安排 | 不代表什么 |
|---|---|---|
| 首先进入 | 有自身目标、能说也能行动的游戏角色；先审查 LIGHT/quest 及作者控制谱系 | 不是锁定 LIGHT 数据，更不是发明“言行一致性 benchmark” |
| 备选进入 | 与陌生玩家/伙伴协同的实际行为；强非 LLM 基线必须纳入认识 | 不是全面转为泛用 multi-agent RL |
| 保持深入阅读 | 长期关系/知识连贯与实时主动性 | 不是缺数据就硬造，或用闭源 API 系统当默认基线 |
| 撤出主入口 | CPDC 与 E02 角色措辞/工具调用探针 | 不是实验已证伪，也不删除历史源码审计 |

热度以上是文献密度与强近邻的定性判断，未做全域量化，不能写“低热度蓝海”。本轮审查了 NeurIPS 2026 标题目录，但尚未完成每篇 track/正文/资产核实，故不靠标题列表封顶新颖性。

**下一步的研究对象来自重要问题，具体假设来自自然系统的观察。** 不再倒过来从一个省事的实验，推导它一定值得研究。
