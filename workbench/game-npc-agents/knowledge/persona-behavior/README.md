# 矿区A：人物、本人目的与真实游戏选择

中心问题是NPC面对人物设定、自身目标、角色规范、社会关系、玩家请求与可见状态，怎样形成选择并产生游戏后果。自述/语气、情境意图、合法行动和真实后果分别测量；既允许人物作用有效，也允许普通控制解释表面失配。
