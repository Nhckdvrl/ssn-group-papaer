# NPC研究的强基线：按任务比较完整系统

更新：2026-10-19。强基线用于判断一种困难来自模型、信息与接口、已有工程支持，还是仍需新的方法或认识。这里不推荐采购模型，不启动实验；商业模型名称按作者实际披露记录，未给固定版本处明确标注。B–E的具体参照和未运行设计由[各矿区](../MINES.md)维护。

## 1. 强基线随研究对象变化

| 研究对象 | 必须认真考虑的成熟参照 | 公平比较的关键 |
|---|---|---|
| 角色知识与表达 | 正常强模型＋完整人物资料／例子／检索；角色SFT、原创人物模型 | 同人物知识、原创／既有角色划分、评委与长度；不把缺知识归为人物推理 |
| 高层游戏决策 | 强模型＋可见状态、可靠技能、执行反馈、持久记忆与普通重规划 | 同观察权限与动作能力；原生推理预算；隐藏事实不能免费给某一方法 |
| 身体动作和战术控制 | 行为树／导航、示范学习、动作先验、成熟RL或原生bot | 同传感器、技能／动作频率、任务奖励、示范数据及运行预算 |
| 人机合作 | 人类数据模型、FCP／MEP／HSP等伙伴多样性方法、普通在线适应、LLM模块化系统 | 同伙伴分布、交互次数和角色；与真人合作不能只用训练政策互测 |
| 叙事和作者控制 | 显式状态／事件／约束、可达性检查、普通ICL／检索、生成后验证和编辑 | 同作者信息、工具支持、培训与时间；故事空间和作者目标相配 |
| 关系和情绪 | 完整历史、普通事件摘要／状态更新、显式情绪／社会规则模型 | 无历史不能代表普通有记忆系统；更新合理性与稳定性分开 |
| 社会和经济仿真 | 规则／经济学ABM、统计预测、RL、不同人口组成与制度控制 | 个体政策、环境规则、制度和初始分布分别操控；外部数据另验证 |
| 安全和信息披露 | 最小权限、知识隔离、确定性执行检查、简单过滤与正常任务正控制 | 攻击权限与预算、信息是否被删除、合法玩法和副作用的规范 |

代表依据分别见[CoSER](papers/COSER_2025.md)／[HER](../../../library/themes/game-npc-social/papers/HER_2026.md)、[ProAgent](../../../library/themes/game-npc-social/papers/ZHANG_2024_PROAGENT.md)／[CoELA](../../../library/themes/game-npc-social/papers/ZHANG_2024_COELA.md)及PUBG Ally、[ASE](../../../library/themes/game-npc-social/papers/PENG_2022_ASE.md)、[FCP](../../../library/themes/game-npc-social/papers/STROUSE_2021_FCP.md)／[HSP](../../../library/themes/game-npc-social/papers/YU_2023_HSP.md)、[KNUDGE](papers/KNUDGE_2024.md)、[动态人格](papers/DYNAMIC_PERSONA_COHERENCE_2026.md)、[MMOAgent](papers/MMOAGENT_KDD2025.md)、[Agentic Firewalls](../../../library/themes/game-npc-social/papers/AGENT_FIREWALLS_2026.md)。[SIMA 2](../../../library/themes/game-npc-social/papers/SIMA2_2025.md)另作为原生视觉控制的参照。强商业API是某些任务的重要参照，不是所有运动控制、制作工具或社会仿真的唯一参照。

## 2. 本轮正文核查直接改变了哪些判断

**补齐历史可能解释很大一部分增益。** Dynamic Persona Coherence的Vanilla每次只有固定初始状态、人物和当前事件，没有历史响应／状态累积。因此它包含GPT-4o、Claude等并不等于排除了正常历史记忆基线。[原卡附录范围](papers/DYNAMIC_PERSONA_COHERENCE_2026.md)

**相同知识给普通提示后，复杂结构的独立收益可能很小。** CDT的Bandori比较中，线性化同一CDT知识提示为78.70，CDT-Lite为79.04；这是NLI行为匹配量表上的0.34分差距；人物逻辑诱导与验证可能承担主要收益，不能全部归给树遍历。主表扮演模型是Llama-3.1-8B-Instruct，附录另测1B／3B；GPT-4.1等承担规则生成、验证或评判，并不是强商业模型扮演对照。[原卡](papers/CDT_2026.md)

**强训练基线需要按现代实现重做，而非永久引用旧弱分数。** HSP附录对MEP更新RNN、伙伴池规模（15→36）和混合伙伴批次后明显改变人类代理评价，优先采样并非在新配置仍有利。CooT／ICRL4AHT又把问题推进到上下文中的伙伴适应；不能只和老自博弈比较。CooT的正结果与ICRL4AHT的负结果来自不同观察、伙伴分布和监督数据，既不能视为同条件相互否定，也不能共同外推到任意商业LLM。[HSP](../../../library/themes/game-npc-social/papers/YU_2023_HSP.md)、[CooT](../../../library/themes/game-npc-social/papers/WANG_2026_COOT.md)、[ICRL4AHT](../../../library/themes/game-npc-social/papers/JING_2026_ICRL4AHT.md)

**像素控制失败不是状态与技能系统的能力上限。** VideoGameBench禁止引擎状态和专用控制，BALROG主表使用很短历史和零样本下一动作，SIMA 2的通用模型比较也受原生视觉动作接口约束。它们证明各自任务中的困难；不能据此断言充分接地的高层NPC必然失败。另一方面，SIMA系列显示专门训练的行动能力确有可测进展，不应将其缩成提示工程。[VideoGameBench](../../../library/themes/game-npc-social/papers/VIDEOGAMEBENCH_2026.md)、[BALROG](../../../library/themes/game-npc-social/papers/BALROG_2025.md)、[SIMA 2](../../../library/themes/game-npc-social/papers/SIMA2_2025.md)

**成熟结构检查和强提示也会有维度上的优势。** KNUDGE的完整生成修订法在一些任务／知识指标更好，但专家的内容建议和吸引力并未全面胜普通ICL；CoSER的结构化经历／对话检索优于某些原文检索。比较要保留真实强点，不能选择对新方法有利的一个总分。[KNUDGE](papers/KNUDGE_2024.md)、[CoSER](papers/COSER_2025.md)

### 2.1 四兴趣方向的新近正文证据

| 研究 | 认真对待普通系统的具体理由 | 不能据此推出什么 |
|---|---|---|
| [MDRP，2026](../../../library/themes/game-npc-social/papers/MEMORY_DRIVEN_ROLEPLAY_2026.md) | Qwen3-Max人物分面提示均分8.08→8.07，GLM-4.7为8.11→8.13；固定历史单次续答 | 专门角色记忆必需，或长期在线关系已经被解决 |
| [ArcANE，2026 v2](../../../library/themes/game-npc-social/papers/ARCANE_2026.md) | 极短ArcHint对两个基础模型各项距完整Arc不超过±2.6；信息条件需配平 | 复杂成长表示不可替代；已给小说阶段等于玩家改变未来 |
| [CPM-MultiAgent，2026](../../../library/themes/game-npc-social/papers/CPM_MULTIAGENT_2026.md) | 同GPT-5.4下zero-shot4.283、单体CPM4.295、full4.322；无相应区间/显著性 | 多agent情绪架构显著改善游戏玩家体验 |
| [Chain-of-Emotion，2024](../../../library/themes/game-npc-social/papers/CHAIN_EMOTION_2024.md) | 完整历史加一次自然语言appraisal已有30人短时互动证据 | 无状态基线可以代表合理普通系统；旧模型单情境结果代表当期旗舰 |
| [ACL互动戏剧，2025](../../../library/themes/game-npc-social/papers/IMMERSION_AGENCY_DRAMA_2025.md) | GPT-4o完整历史、每5步普通剧情反思可以改善有限轨迹评分 | 剧情反思全无效；也不能从一Conan剧本推出跨作品需求全部解决 |
| [Bonsai，2026 workshop](../../../library/themes/game-npc-social/papers/BONSAI_2026.md) | 持久分支、直接编辑、从修改提规则都已有；还须比较原编辑few-shot/直接意图/简单项目隔离 | “记住作者修改”本身新颖；模拟完整偏好相当于真实作者发展意图 |

这些分数来自不同量表、任务和评委，不可合并成模型排行榜。它们共同要求：先让普通系统接触同样的资料、历史、编辑支持和合理反馈，再判断新表示/分工是否必要。若研究的是作者探索或玩家交互，底层模型足够强并不取消人的问题；相应贡献也不应伪装成模型能力突破。

## 3. 一个普通高层NPC系统应有的支持

角色收到可见世界状态、允许动作、前提、上次执行结果与相关历史；持续记忆保存已发生的事件和仍有效的要求；在状态变化、行动失败或新信息出现后重新计划；可靠技能负责路径、交付、战斗等操作并读回结果。作者需要给足角色目标、约束、知识和披露规则，同时允许合理澄清。

这不是要求每个基线都有特殊新模块，而是防止缺失普通支持制造问题。信息摘要也不能偷渡研究者事后正确答案；同样“看起来完整”的提示可能让一方知道了更多真值。

前轮GenCoord的可靠技能／结构化提交、CollabBench的强商业模型、ContractSim的规范控制、BayesBeliefAgent的普通周期／事件重规划，以及PUBG Ally的状态和执行反馈仍是重要参照；具体数字和范围由[前轮定向综合](FIELD_REVIEW_2026-10-18.md)及其原链接维护，不在外围重复多份结果。

**当前实际项目也需要跟随版本核查。** 2026-10-18实读的Vox Deorum作者文档把人物对话、条款决策、最新可交易范围检查、提议账本和游戏结算分开，包含拒绝、反提议、撤回与有限类型的承诺。它为“语言进入既有游戏机制”的完整系统提供具体参照；仅依据2025论文说项目没有自然语言外交已过时。技术文档描述仍不等于可靠性、开放承诺泛化或玩家收益已经验证，具体来源与范围见[规范卡的后续项目记录](papers/VOX_DEORUM_2025.md)。

## 4. 预算与能力需要两个比较

先允许各方法合理运行，回答“成熟系统能否完成”；再按质量、端到端延迟、总token、调用、训练和作者劳动比较效率。固定很短输出可能不适合推理模型，给复杂方法无限重试也不公平。成本可以成为独立方法贡献，但不能替代“强模型会不会解决”的事实问题。

额外获得全状态的oracle只作信息或可行性参照，不与受限观察方法混作公平对照；某个oracle求解器的成绩也不自动构成最优上界。确定性脚本在有界场景可能很好，应说明作者规则量和覆盖；LLM也不能因开放输入多就免于基本状态验证。训练与在线推理、感知与动作执行、作者制作与运行成本分开报告。

## 5. 不同结果应怎样更新认识

| 观察 | 支持的解释 | 不能顺势宣称 |
|---|---|---|
| 同系统强模型成功，小模型失败 | 在这些任务上模型能力重要 | 所有NPC方向被强模型解决 |
| 补历史／状态／普通规划后都成功 | 原失败主要来自系统支持缺失 | 没有任何编辑、迁移或体验研究价值 |
| 同知识普通提示接近复杂方法 | 知识或信息组织承担主要收益 | 结构永远无用，或需继续局部调参保住叙事 |
| 任务升分而玩家偏好下降 | 目标不完全匹配玩家价值 | 玩家“不懂好模型” |
| 新方法跨任务残差下降且代价合理 | 可能存在可推广方法收益 | 未测过的长期玩家和作者收益已经成立 |

选题应能解释这些分歧并给出可检验预测。当前知识库提供这种比较结构，具体投入和研究状态由用户决定。
