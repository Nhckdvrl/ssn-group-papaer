# 数据、测量和可证伪实验的具体规范

## 1. NPC episode 应当可审计
最低观测层：
- 初始真实世界状态 world_truth / scene ID / 所有权；NPC 实际看到的 observation，不等于世界真值。
- NPC 的 persona、当前 goal、memory/belief（若 system 暴露），以及它从玩家/NPC 收到的 utterance/action。
- 策略输出候选 action、参数、是否被 parse/执行、执行后 game state delta、失败/报错/时间戳；生成的对话不能代表动作已执行。
- 其他角色/玩家是否真正受到了影响；interaction length、token、latency、模型及 evaluator 版本。
- 不得让一个没有规则核实的 LLM 同时担任“世界状态真值”“NPC”“裁判”，那样无法因果归因。

## 2. 先区分测量对象
| 被讨论的能力 | 语言层读数 | 游戏后果层读数 | 必须排除 |
|---|---|---|---|
| 世界一致性 | 是否说错已知事实 | 世界 transition 是否合法、是否覆盖既定事实 | 只看措辞流畅 |
| 局部知识 | 回答自身“知道什么” | 未观察事实是否影响其决策/是否更新 | 模型依靠故事先验作弊 |
| 角色人格 | persona judge/trait classifier | 相同情境真实选择/风险/助人/背叛行为的稳定性 | 训练损失和评测 probe 共源 |
| 玩家能动性 | “我听了你的意见” | 玩家动作真的改变可达状态/事件 | narrator 强制拉回原著 |
| 合作 | 愿意帮忙/请求次数 | 必要依赖任务里伙伴行为和奖励是否变化 | 单人可完成任务 |
| 关系与长期记忆 | 能回忆 NPC/玩家往事 | 后续交易、信任、帮助/拒绝的可重放后果 | 复述正确即视为成功 |

**每张科学图都要说明读数代表的是哪个构念，哪些不能由它推导。**

## 3. 数据优先
- 首选研究社区标准化的 RPG quests、真实对话树和动作环境，及官方开源代码有记载的参考任务；先评估规模、source、split、license、评估强度。
- 数据自然性是重要科学变量：如果真实游戏没法允许平衡的局部信息干预，可加**小而有解释力的对照集**，但不可用清一色人造条件替换自然主评测。
- 构造/改造任务时写：为何必须、到底哪个真实现象测不到、每类 n 的效力依据、覆盖哪些 game mechanics/角色/选择及什么保持不变。
- LLM 生成关键标注要有独立校准：抽样真人双盲、规则脚本、不同模型复核或分层质量审计（视高风险程度）。不机械让大模型审全部数据，也不能只用同一生成器评分。
- 分开 training/dev/selection/test；预先固定 scene/角色/玩家干预，跨模型 matched pairs 与 train contaminations；只把 toy 测试当 sanity。

## 4. 高信息量的实验动作
**观察先行**可先认真读自然轨迹/看失败，再提出两种以上竞争解释：
- 世界误信 vs 长上下文检索失败：固定历史长度，分别操控 NPC 是否观察事件；对照 full memory oracle。
- 模型不了解角色 vs 评价打分器循环定义：更换角色语句模板并保持行动选择和状态不变，看内部 vs 独立行为读数如何变化。
- NPC 尊重剧情 vs 忽略玩家：固定 must-not violations，改变玩家是否能走不同合法支线；测实际世界状态而非旁白是否重复玩家话语。
- 社会推理 vs 队友固定行为规则：交叉真实不同伙伴、任务必要依赖与成本匹配；分离 player 的行为变化是否触发 NPC replanning。

**不限定只有这四种。** 深度探索时新的 measurement representation 或新观察轴可能比继续一个固定假设更有价值，但重要实验每次都写清什么结果会更新判断。

## 5. 结果可靠性
- 先验证正控制与噪声地板，再以 MIE/变异度/事件稀有性决定场景数与 seed 数。不能 n=20 直接写通用结论，也不能盲目要百万训练样本。
- 按 scene 分层/cluster 或 paired bootstrap；必要时 episode 内相关性不能当独立样本。多重比较、事后切片、失败种子均明示；使用 withheld 场景确认选题阶段发现。
- 等预算比较并区分有效行动数、总 token、wall latency、LLM 调用、训练 GPU-hour。不要给复杂方法无偿更多 test-time thinking。
- 若评估由 LLM 给分：记录 judge ID/template、盲化、固定值/多个 judge、与至少部分明确动作规则或人工评分的一致性。
- **机制**须以干预/反事实/替换证据支持；主张范围写到验证过的模型、任务和环境。长期玩家体验用满意度等心理指标须认真设计人类实验，不能仅用 agent 评委代替。

## 6. 科学回路
记录观察、竞争解释、最大的信息增量动作，再运行。关键发现出来时回读顶会最近邻，检查是不是已有 claim owner；没有证明方向重要的局部奇象，先升为线索，不急写 paper。失败可以要求改变观察方式而不是放弃研究对象。
