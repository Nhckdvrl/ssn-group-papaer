# 学习、控制与人类合作：能力、风格和适应

更新：2026-10-18。动作控制、伙伴兼容、游戏中适应、挑战和运行成本有不同目标。下面将经典方法、非语言学习、模块化LLM和原生游戏系统并列，记录它们能控制什么、需要什么输入和如何验证。论文完整正文与具体附录范围、版本和阅读计数见[阅读总账](READING_CATALOG.md#learning-control)。

## 一、先分清 NPC 应提供的能力，再比较算法

下表是对本页所引研究论文的综合整理，不是声称所有游戏开发者接受同一分类。游戏中的对手、协作伙伴、环境角色、模拟居民、训练陪练和自动测试员具有不同职责。把它们全部还原为“能否完成任务”会遗漏开发目标；把能玩游戏的 agent 自动称为成熟 NPC，同样会越过证据。

| 能力目标 | 为什么对游戏有意义 | 本页所引研究直接证据 | 不能自动推出 |
|---|---|---|---|
| 操作和战术能力 | 会走、拿、瞄准、制造、执行战术，减少角色行动落空 | VPT、SIMA、SIMA 2、FTW | 角色性格可信、任务有趣、玩家有贡献空间 |
| 动作和玩法风格 | 同一目标下体现不同运动质感、习惯和风险选择 | DeepMimic、AMP、ASE、MultiGAIL、MLMove | 人物有稳定价值观、关系和叙事身份 |
| 伙伴兼容性 | 新手、偏科者和不同分工习惯的人都能一起推进 | Carroll、FCP、MEP、HSP、CEC | 对所有陌生人、所有游戏或冲突利益都能配合 |
| 交互中的适应 | 根据伙伴实际行为修正分工和节奏，而不只拥有静态强策略 | CooT 的连续回合和切换伙伴实验；ICRL4AHT 的反面诊断 | 一般 Transformer 自动具有此能力；共适应双方能长期稳定 |
| 沟通与共同进度 | 交换局部信息、说明任务分工、协调行动时间 | CoELA；ProAgent 的状态、反馈与重规划 | 自利谈判、人格目标冲突、关系长期变化已解决 |
| 合适的挑战 | 对手有变化且与玩家能力匹配，保留掌握和进步感 | Dynamic scripting；Enemy Within | 50% 胜率等于好玩、模仿玩家本身造成长期留存 |
| 社会适应与外部影响 | 陌生群体、少数/多数身份和不同激励下仍有可行行为 | Melting Pot、ZSC-Eval 的不同评价结构 | 高自身收益等于对玩家或背景居民有益 |

这些目标之间会发生真实取舍。DeepMimic 的纯任务奖励可以产生“带着球跑过去”之类高分动作，AMP/ASE 的自然运动约束也会与原始任务分数竞争；MLMove 专门选择模仿专业移动，而非最大化比赛胜率。FCP 的 BCP 与 PP 得分差异不显著时，人类仍可能明显偏爱 BCP；HSP 的个别地图也出现算法分数与伙伴偏好不一致。因此，“更强模型”需要说明强在哪个目标上，不能用一条胜率线取代风格、合作和体验证据。[DeepMimic]、[AMP]、[ASE]、[MLMove]、[FCP]、[HSP]

## 二、理解方法，至少要保存四个坐标

### 1. 模型看到什么、实际控制什么

这是跨论文比较最容易被省略、也最容易改变问题难度的因素。

| 信息与动作接口 | 代表工作 | 系统已经替学习器解决的事 |
|---|---|---|
| 身体真值、任务目标 → 关节 PD 目标 | DeepMimic、AMP、ASE | 状态估计、身体对应关系、参考动作/任务奖励、物理仿真接口 |
| 结构化游戏状态 → 原子动作或已有游戏操作 | Carroll、MEP、HSP、CooT；部分 MLMove/MultiGAIL | 物体身份、地图语义和事件定义；MLMove 还读取全部玩家位置并保留规则瞄准 |
| 局部结构状态 → 原子动作 | ICRL4AHT | 局部语义识别已给出，但全局状态与变化配方仍不可直接见 |
| 语义状态、合法技能 → 搜索与技能执行器 | ProAgent | 规则翻译、技能合法性、路径搜索、绕人和部分解卡 |
| RGB-D/位姿或对象掩码 → 高层合法动作 → 控制模块 | CoELA | 分割、语义地图、目标交互和寻路；不同观察条件具有不同真值信息 |
| 像素、文本 → 游戏原生键鼠/手柄 | VPT、SIMA、SIMA 2、FTW | 仍依赖游戏接入、动作时钟与训练数据，但不直接获得同等级高层“取物/做菜”执行器 |

“视觉 agent”本身并不足以描述公平比较。CoELA 的 TDW-MAT 有 RGB-D 与相机/自身位姿，C-WAH 的视觉条件含真实实例 ID 掩码；SIMA 则面对像素和原生控制。MLMove 读取所有玩家的结构状态，主要盲评又来自鸟瞰透视视频。这些都是合理的研究设置，但结论须留在相应接口内。[CoELA]、[SIMA1]、[MLMove]

### 2. 目标和风格从哪里来

本页所引研究至少存在五种来源：设计者写出的规则与权重；人工游戏事件奖励；动作捕捉或专家游戏演示；通用语言预训练与显式任务提示；合成伙伴的隐藏事件偏好。它们解决的作者负担不同。Dynamic scripting 不需要从零发现全部行为，但需要先建立有效规则库；DeepMimic/AMP/ASE 减少手工运动控制，却依赖动作资产；MultiGAIL 的 persona 来自预定义风格演示；HSP 的偏好来自设计者定义事件。将这些方法都描述为“自动产生人物目标”会掩盖关键人工输入。[DynamicScripting]、[DeepMimic]、[AMP]、[ASE]、[MultiGAIL]、[HSP]

尤其需要分开三个概念：**角色行动风格、用于训练的效用偏好、玩家理解的社会人格**。它们可能互相支撑，但本文样本没有证明其中一种可以直接代替另两种。身体运动像人，并不蕴含其承诺或关系可信；任务偏好改变了收集物品策略，也未必构成具有记忆和动机的角色身份。

### 3. 适应发生在哪个时间尺度

训练时随机化伙伴和地图，与游戏中根据某个人的历史改变行为，是不同能力。FCP/MEP/HSP 的主要贡献发生在部署前；CEC 扩大环境训练分布；CooT 在同一伙伴多回合交互后更新上下文；Dynamic scripting 在战斗间更新规则权重；Enemy Within 根据玩家日志重新拟合对手。一个不改变的稳健策略也可能跨伙伴表现良好，不能仅凭高分把它叫作在线适应。[FCP]、[MEP]、[HSP]、[CEC]、[CooT]、[DynamicScripting]、[EnemyWithin]

进一步还需问：伙伴本身是否会改变？CooT 有预设伙伴切换测试，ICRL4AHT 在评估序列中固定伙伴。真实人类当然会观察和适应 AI，但一次短人类实验并没有自动辨识双方长期共同学习的稳定性。需要把回合内响应、跨回合记忆、模型参数更新、玩家长期变化和游戏机制更新分开保存。[CooT]、[ICRL4AHT]

### 4. 评价中的独立单位是什么

同一地图上重复一千回合，不能替代新地图；同一合成偏好下五个参数实例，也不是五次独立训练；80 条人类交互记录也可能只有 8 位参与者。与谁配合、谁在完成任务、观察信息是什么、每个条件真正独立的模型与人类数量，都决定结果能够推广到哪里。ICRL4AHT 中强伙伴独立完成任务，会让随机 agent 在部分条件得到接近强方法的团队分数；ZSC-Eval 因而把近似最佳响应归一化与分布统计加入评价。[ICRL4AHT]、[ZSC-Eval]

## 三、主要谱系已经形成了哪些认识

### A. 他者建模不是只有“为队友写一段心理描述”

Albrecht 与 Stone 的综述把领域拆为策略重建、类型推断、分类、计划识别、递归信念、图模型与群体模型，并显式列出可观察性、平稳性、目标相容性、已知结构、相关性等假设。这个地图依然有组织价值：预测伙伴下一步、识别其长期目标和选择有用的响应，不是同一个优化问题。类型推断即使在候选集中形成尖锐后验，也可能只是从一组全错的模型里选出最像的；主动试探还会改变伙伴行为。这些是方法假设的警戒线，不应无检验地写成 2026 年全部仍未解决的具体难题。[OtherAgentSurvey]

后来的协调研究给出一条重要补充：可以让策略对多种伙伴兼容，而不必显式恢复伙伴真实心理。Carroll 证明人类模型有时显著改善配合；FCP 又证明在固定共享目标任务里，不使用人类训练数据也能得到真人更愿意合作的伙伴。两篇不是简单胜负关系，而是表明“充分覆盖相关伙伴行为”可能通过不同途径实现。HSP 合成偏好伙伴，CEC 扩大环境，分别探索什么训练变化有助于覆盖。[Carroll]、[FCP]、[HSP]、[CEC]

### B. 多样性很有价值，但“更多策略”不等于更多能力覆盖

这条路线可以按被改变的对象理解：Other-Play 去除已知对称标签导致的私有约定；FCP 加入不同种子和学习阶段；MEP 奖励策略分布熵；HSP 加入事件偏好；CEC 扩大环境布局与对象分布；ZSC-Eval 则反问这些差异究竟是否要求不同的最佳响应。[OtherPlay]、[FCP]、[MEP]、[HSP]、[CEC]、[ZSC-Eval]

跨论文共同支持的不是“池子越大越好”，而是训练变化需要覆盖部署时有意义的响应差异。FCP 的早期和中期弱伙伴很重要，额外架构差异却不必然增益；HSP 提醒语义上的偏好和不对称能力会改变配合；ZSC-Eval 进一步指出表面不同的伙伴可能需要同一种响应。CEC 又显示，环境多样性本身可能减少对局部约定的依赖。[FCP]、[HSP]、[ZSC-Eval]、[CEC]

这里也暴露了强基线问题。HSP 对早期方法加入循环网络、改进训练批次和池设置，原方法水平大幅提高；ZSC-Eval 的 E3T、COLE、TrajeDi 又有明确实现改动。读新论文时，必须保存检查点来源、训练预算和具体实现。只记录算法缩写，会让知识库错误地以为一个旧名字代表稳定不变的强度。[HSP]、[ZSC-Eval]

### C. 上下文适应有可靠正证据，也有明确失败边界

CooT 的正结果很具体：以伙伴最佳响应轨迹训练小型 Transformer，测试时从空上下文开始，随着最近几回合的共同交互改善表现；部分地图优于静态 HSP，36 人实验中也有偏好和适应评分，切换伙伴需要 1–6 回合恢复。它不是在任意商业 LLM 中塞入长历史，也没有在所有地图都优于基线。[CooT]

ICRL4AHT 则在局部视野、会变的配方、新规则伙伴与新布局下，发现 AD/DPT 及扩大模型、上下文和一些额外信息后仍常缺乏持续提升。这里没有商业预训练 LLM 对照，也没有真人；五个伙伴实例的标准差不能写成五训练种子误差。[ICRL4AHT]

两篇应并列保存，不能挑一篇替整条路线定性。它们改变了训练数据的响应标签、伙伴分布、局部/完整观察和任务本身，因此并非直接复现冲突。共同提出的问题是：什么训练目标使历史真正用于选择互补动作，什么信息可辨识伙伴，什么变化只需稳健策略，什么变化确实需要学习？CooT 正式稿还有伙伴池、查询采样、测试检查点描述不一致，ICRL4AHT 的部分正文数字解释也与表格不符；这些不取消工作价值，却要求知识卡保留可复现性欠账。[CooT]、[ICRL4AHT]

### D. 行动可信和原生技能是独立且庞大的研究主轴

DeepMimic、AMP、ASE 展示了从逐帧参考跟踪到动作分布先验，再到可复用潜技能的演进：既要完成任务，又要限制奖励钻空子带来的不自然行为；既要覆盖动作，又要避免模式坍缩；既要重用技能，又要控制组合和恢复的代价。其能力建立在相应身体、动作捕捉、物理状态和训练预算上，并不自动迁移到不同身体或所有技能转移。[DeepMimic]、[AMP]、[ASE]

VPT、SIMA 和 SIMA 2 转向现有游戏界面的视觉到操作。VPT 的逆动力学补标签让大量无动作标签视频可用于行为克隆，后续特定任务强化学习展示长技术链条的可能性；但罕见完成不能写成可靠执行。SIMA 以短语言任务连接多个游戏，SIMA 2 加入语言骨干、更多具身训练和强化学习，同时保留明显的未见游戏落差。[VPT]、[SIMA1]、[SIMA2]

SIMA 2 的材料尤其需要精确措辞：它是 **2025 年技术报告**，原文比较中的基础 Flash-Lite 与 Pro 在相同像素/原生控制任务上约为 3.2% 和 7.0%，训练后系统在新评测套件中大幅提高。这是“通用语言能力不等于直接具身控制”的重要证据；但原文没有给足以复建比较的完整模型 ID、提示与所有样本信息，不能称为截至 2026 年最强商业 API 的穷尽检验，更不能外推到给模型高层工具的任务。SIMA 1 与 2 的不同评测套件分数也不能直接相减。[SIMA2]

### E. 对手与难度适应关注玩家成长，而不只关注输赢

Dynamic scripting 将游戏开发约束写入学习机制：规则先保证可读、可限制、可用，权重再在战斗之间调整；通过删去过强规则等方法把胜率调到指定区间。它在合成 CRPG 与 Neverwinter Nights 修改环境中做了大量战斗，但没有人类体验研究，不能据此断言“胜率均衡就更有趣”。作者也明确讨论玩家进步和成就感可能被暗中难度调整破坏。[DynamicScripting]

Enemy Within 给出更靠近真实使用的证据：四周 Aion 私人社区中 171 名玩家、776 次关卡记录，30 份问卷；镜像最终对手复制玩家技能行为，玩家报告更高兴趣与努力，并有探索自身组合的体验。但这个关卡同时包含属性/刷怪等其他难度调整，且玩家自选进入，不能独立识别行为模仿对长期动机的因果贡献，也不能把四周热度视为更长期留存证明。[EnemyWithin]

FTW 和 MLMove 则呈现另一种目标选择。FTW 在原生像素团队竞技中通过大规模训练达到很强的战术能力，并在随机地图和人类混编中验证；MLMove 在固定 Counter-Strike 模式里学习专业移动，强调 CPU 预算和可信团队站位。前者的主要证据是比赛表现，后者的明确人类证据主要是视频盲评。它们为陪练、队友和对手提供不同基础，不能简单按谁赢得更多来排研究价值。[FTW]、[MLMove]

### F. 模块化 LLM 合作已经是现有能力，但不是已验证的完整 NPC

ProAgent 的 GPT-3.5 系统已经说明：任务规则、结构世界状态、技能库、合法性反馈和普通搜索/重规划，可以得到有用的非语言合作。主表采用 L2 分析，不含完整显式意图推断；完整信念机制只在局部消融检验。读者不能把系统成功全部归给“心智推理”，也不能忽视低层控制器贡献。[ProAgent]

CoELA 更进一步处理部分观察、消息共享、沟通成本和真实人类合作。它也展示沟通价值随条件变化：小规模人机实验中自然语言沟通改善体验，但 AI–AI 删除通信没有显著降分。八个人的 80 轮不能算成 80 名参与者，GPT-4 每任务一次的评估也不足以给稳定误差估计。[CoELA]

这些已有工作要求后续方法把合理的 LLM 加状态工具系统视为认真对照；它们同时没有覆盖所有独立人物目标、利益冲突和长期关系。模型版本已旧、接口不同、样本有限，意味着既不能用它们宣称强商业 API 已解决全部 NPC，也不能通过排除它们来塑造学习方法的必要性。[ProAgent]、[CoELA]

## 四、如何判断人类证据的强弱

| 工作 | 实际人类单位 | 直接支持的结论 | 主要限定 |
|---|---|---|---|
| Carroll 2019 | 60 人 | 人类模型训练的策略可改善协作 | 排除不合作轨迹影响显著性；玩家试探可能本身是正常玩法 |
| Other-Play 2020 | 20 人，各两局 | 选定 OP 模型在 Hanabi 初步优于所选 SP | 小样本、模型选择、非专家、规则计分细节 |
| FCP 2021 | 114 人，每人 20 回合 | 无人类训练数据仍可提升真实配合与偏好 | 五个共享目标布局；不等于无需人类验证 |
| HSP 2023 | 60 人，多布局 | 偏好伙伴训练有助于部分真实协调 | 人类行动速度适配、个别地图偏好与分数不一致 |
| CEC 2025 | 80 人，两组地图 | 跨环境训练可改善伙伴配合/偏好 | 细调与不细调、得分与偏好并不完全一致 |
| CooT 2026 | 36 人，每人四条件各八轮 | 学过的上下文响应能被人感知为适应 | 固定游戏接口与有限伙伴/地图，非任意语言模型 |
| CoELA 2024 | 8 人，共 80 轮 | 模块化语言协作在小型实验中改善体验 | 重复测量、小样本、环境与沟通条件特定 |
| ZSC-Eval 2024 | 152 招募、145 有效 | 所选自动评价排名在两图与真人较一致 | 五算法排名相关不能替代全领域人类评价 |
| MLMove 2024 | 15 名视频评审 | 模仿移动比所选 bot 更像人 | 实际混合游玩探索不确定；固定模式与地图 |
| Enemy Within 2020 | 171 名日志玩家、30 份问卷 | 复合适应关卡中的参与和动机现象 | 自选、组合干预、回忆问卷，非单机制随机因果检验 |
| FTW 2019 | 初始 40 名 FPS 玩家；后续延迟实验人数尚未核实 | 大规模训练 agent 能进行很强的人机混合团队竞技 | 不同版本与后续实验不能共用人数；能力强不等于更好玩 |

表中数据和限制分别来自完整逐篇记录。[Carroll]、[OtherPlay]、[FCP]、[HSP]、[CEC]、[CooT]、[CoELA]、[ZSC-Eval]、[MLMove]、[EnemyWithin]、[FTW] MEP 已读正文和相关附录未报告新招募人数，不能补猜；ProAgent、ICRL4AHT、Melting Pot 等没有真实人类实验，不应把行为克隆人类代理或合成背景群体转写为玩家证据。[MEP]、[ProAgent]、[ICRL4AHT]、[MeltingPot]

## 五、在什么条件下，能力已经比较成熟

这里的“成熟”指有清楚可复用的研究能力与反复发展的机制，并不表示在所有商业游戏中交付成熟。

1. **受约束的行动控制。** 对已知身体、动作数据和任务，参考模仿/运动先验能显著减少单纯奖励产生的不自然行为；更大的低层技能库能够支持若干新高层任务。需要保留身体、动作覆盖与训练成本限定。[DeepMimic]、[AMP]、[ASE]
2. **固定机制中的伙伴兼容性。** 通过训练伙伴行为/能力覆盖，及环境多样性，非语言策略能成为明显更合适的人类队友；这已经不是只能靠人类轨迹训练的能力。部署分布和真实人类验证仍是必要证据。[FCP]、[HSP]、[CEC]
3. **明确接口中的语言协作。** 通用语言模型结合结构状态、技能与反馈可完成有效分工和部分自然语言协作。该能力已有强先例，但系统工程、模型、环境观察和沟通渠道共同构成结果。[ProAgent]、[CoELA]
4. **有意选择的风格与难度。** 开发者可以通过规则、专家模仿、风格判别器和玩家模型改变行为方式，而不只改变 HP 或伤害；不同方法能控制的维度、对玩家的验证强度差异很大。[DynamicScripting]、[MultiGAIL]、[MLMove]、[EnemyWithin]
5. **对评价分布的系统化设计。** 可以把伙伴质量、所需响应类型、社会利益结构和背景群体作为明确测试变量。合成基准更丰富，并不意味着人类体验已有通用代理指标。[ZSC-Eval]、[MeltingPot]

## 六、真正未被这些证据消除的问题

以下是跨路线仍缺直接证据的能力问题，不是宣布某个具体论文题目必然新颖；任何选题仍需继续做最近邻检索。

**多种变化同时发生时，哪些知识可重用？** 同地图换伙伴、同机制换地图、同身体换动作、跨不同游戏使用原生界面，是四种不同迁移。现有工作分别取得进展，但对同时变化的感知、规则、伙伴习惯和延迟后果，尚缺统一、充分的人类可玩证据。SIMA 2 的未见游戏落差、CEC 的细调与广泛泛化取舍、ICRL4AHT 的新布局失败分别揭示不同部分，不能合并为一种“泛化率”。[SIMA2]、[CEC]、[ICRL4AHT]

**历史何时包含足够信息，何时只是噪声或不可辨识？** 一个伙伴没送出物品，可能因为不会、没看见、没兴趣或认为队友会做。预测误差低不等于能选择合适回应，成功高也可能只是伙伴替 agent 完成任务。现有最清楚的方向是把观察范围、训练标签、伙伴可达能力、信息获取代价和连续适应曲线一起看，而不是仅增加上下文。[OtherAgentSurvey]、[CooT]、[ICRL4AHT]、[ZSC-Eval]

**如何在玩家也改变时稳定适应？** 合成固定伙伴覆盖和预设伙伴切换仍不能替代长期双向调整。玩家会学会利用对手、试探规则、换目标、故意胡闹，也会从新手成长；难度算法可以破坏进步感，过强队友可以占尽有趣工作。现有 FCP/HSP 的偏好结果、Carroll 的排除规则和 Enemy Within 的长期观察共同提示：任务分数之外需要追踪参与空间、可理解性和掌握感，但它们还没有构成统一可迁移的方法。[Carroll]、[FCP]、[HSP]、[DynamicScripting]、[EnemyWithin]

**哪些行为差异值得覆盖？** 多样化动作、偏好事件、最佳响应、社会规范和人类文化不是同一空间。ZSC-Eval 提供比计数伙伴更好的方向，但仍依赖人工事件与合成池；Melting Pot 扩大激励结构，却没有自动解决真实人类分布代表性。如何识别会改变玩家体验或需要不同应对的差异，是数据设计与评价共同的问题。[ZSC-Eval]、[MeltingPot]

**如何使强能力仍可由作者控制、由玩家理解？** learned reward、潜技能和策略内表示可产生有用涌现行为，却未必可编辑、可保证约束、可解释失败。Dynamic scripting 的规则透明、ASE 的潜技能重用、FTW 的强策略表示分别处于不同权衡点。统计上“神经元能解码某状态”不等于作者能可靠修改战术或人物动机。[DynamicScripting]、[ASE]、[FTW]

**跨游戏真实部署的持续成本是什么？** 训练数据、游戏状态接入、地图资产变化、传感器/技能模块、运行时预算、长期记忆和回归维护，都会决定方法能否成为可用功能。MLMove 提供明确 CPU 时间和固定地图边界，SIMA 系列展示接入多个原生游戏但仍需任务与评估基础设施。不能用一次短演示替代资产更新后的稳定性或开发者可维护性。[MLMove]、[SIMA1]、[SIMA2]

**怎样联合衡量收益而不过度归因？** 自身收益、伙伴收益、动作自然度、玩家信任、挑战、长期动机和作者负担可以分离；有时甚至相互冲突。现有工作已足以反对“单一任务成功等于 NPC 价值”，但尚没有把这些目标普遍压成一个可信指标的方法。应保留不同结果及其条件，避免把方便计算的平均分升级为完整玩家价值。[AMP]、[FCP]、[CoELA]、[EnemyWithin]、[MeltingPot]

## 七、代表性限制与明确欠账

本页使用综述、经典链条与近期原文交叉整理；不属于 PRISMA 式系统综述，也没有完整会议库筛选分母。下列方向仍不能声称覆盖。

| 未充分覆盖的方向 | 本页所引研究已有的局部入口 | 仍需另行建立的知识 |
|---|---|---|
| 导航、感知、空间推理、拥挤人群与碰撞避免 | ProAgent/CoELA 的搜索模块；SIMA 原生控制 | NavMesh/路径规划、局部避障、群体运动、空间记忆、主动观察与视觉定位各自成熟方法及失败条件 |
| 完整竞争与合作 MARL 算法史 | FTW、人口协调、Melting Pot | 价值分解、集中训练分散执行、策略响应/联赛、对手建模与博弈算法；不能由一个 FTW 代替全部竞赛研究 |
| 更广动态难度与体验驱动自适应 | Dynamic scripting、Enemy Within | 属性调节、bandit/控制方法、玩家能力估计、关卡/内容生成、情感/生理信号、长期适应的不同机制和人类证据 |
| 当代运动生成与动画生产管线 | DeepMimic/AMP/ASE | 运动匹配、学习型运动匹配、较新物理角色模型、扩散式运动与动画作者工具；本页所引研究不能称为截至 2026 的运动控制综述 |
| 模仿学习与人类行为多样性的完整基础 | VPT、MultiGAIL、MLMove | 逆强化学习、离线 RL、行为风格与跨技能迁移、专家演示偏差、可控模仿的广泛理论及游戏应用 |
| 多于两人的人类队伍及长期社会互动 | GRF、FTW、Melting Pot 的部分多智能体证据 | 团队角色形成、异质信息、语音沟通、持续阵营/经济/规范；本页所引研究多为合成或短人类互动，其他任务中的证据不能自动填补这里的实证缺口 |
| 工业生产与跨版本维护 | EA MultiGAIL、MLMove、SIMA 的开发相关材料 | 作者负担、测试回归、硬件预算、游戏升级迁移、真实上线维护与玩家控制；研究原型、公司作者和商业上线不能混写 |

另有两项只完成发现/身份筛查，**不计入正文阅读记录**：2025 年 *Improved Non-Player Character (NPC) behavior using evolutionary algorithm—A systematic review*（Entertainment Computing 52，100875；DOI 10.1016/j.entcom.2024.100875）因正式页/全文访问未取得而停在摘要/元数据层；Hunicke 2005 的 DDA 案例工作（DOI 10.1145/1178477.1178573）也未取得并读完整原文。它们是明确阅读欠账，不作为本页技术结论的依据。SIMA/FTW 等未读附录和视频逐项保留，尤其 FTW 2019 后续延迟实验的样本构成不能由 2018 材料代填。
