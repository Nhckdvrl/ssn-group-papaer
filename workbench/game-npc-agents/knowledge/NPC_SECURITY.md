# 深读：游戏 NPC 的攻击面、信任边界与可玩性安全

**安全是本领域的独立科学分支。** 本页只有本地离线/合法模拟研究对象；不包含针对线上游戏、真实玩家资产、私人账号或未授权商业平台的攻击操作。原阅读2026-10-14；2026-10-18补核SKT全文，其他来源按原范围。

## 1. ProvSec2025：Tricking LLM-Based NPCs into Spilling Secrets（实际原文方法/结果已读）
原文 https://arxiv.org/html/2508.19288v1 （ProvSec 2025 论文，Hiroshima University）。
- **作者现实压力 (DOCUMENTED)：** 游戏 NPC 有开发者写入的背景秘密，但与玩家自由对话；玩家并不总是有权知道全部设定。模型可能把剧情背景当作应回答的问题。
- **设计：** Gigax 对话仿真、一个中世纪 NPC John 与秘密组织背景，NPC system prompt 令其不得透露。30条手工 player utterances，直接提问/社交诱导/指令覆写三类；量化 3/30 被作者人工判为泄密；3.8B 本地 GGUF llama-cpp (CPU i7/32GB)，**全部单轮 stateless，非玩家长程真实互动**。
- **判断的证据上限：** 能表明这一个系统在所测条件下会出现违规候选；不能推导所有 NPC 泄密率为10%、也不能证明长期世界因果风险。三个被判阳性的引文中有对秘密组织的含混提及和复述式回应，存在**逐字秘密泄露 vs 角色暗示/误报**的构念审计问题；这一点是我们对原文判分含义的评估，**不是对作者结论造假指控**。
- **Idea 来源重建 (RECONSTRUCTED)：** 从一般 prompt injection 的“开发者指令与用户输入冲突”迁移到一个有游戏意义的秘密约束，先以最小可重现 sandbox 证明问题存在，而非立即造大故事。论文尺度是初始安全风险实验，不是长期 NPC 社会完整攻防基准。
- **阅读后更大的问题**不是“多跑1000条 prompt”：秘密何时按玩法应被发现、何时是未经许可被授予新权威？受攻击 NPC 的决定是否真进入游戏事件/其他角色记忆？简单权限型知识隔离能否修复，同时保留合法调查的玩法？这些都需要新数据证据与强近邻比较。

## 2. 攻击面不等于一串“忽略指令”的提示
| 表面 | 玩家/恶意NPC能操控的对象 | 可能越过的边界 | 需要看的真实游戏后果 |
|---|---|---|---|
| 玩家与NPC对话 | 正常发言、请求、谈判 | 玩家语言被当开发者/引擎指令 | 未解锁情报泄露、执行未授权动作；还要看正常对话成功 |
| 世界内文字 | 地图告示、物品说明、商店广告、任务日志 | 玩家可编辑内容变成对NPC的高权威控制 | NPC 是否改变库存、交易、行为或未来目标 |
| NPC→NPC 对话 | 谣言、承诺、伪造的消息 | 低信任伙伴话语经转述后伪装成事实 | 传播图、消息溯源与第二、第三角色行动 |
| 长期记忆与关系 | 被写入的事件回忆、NPC印象 | 临时、无凭据互动变成长期身份/权限 | 未来行动/关系变化与可更正性 |
| Agent→引擎 | action参数、角色权限、世界结算 | LLM输出未检查即执行为系统事件 | 状态越权、道具/货币账本/任务作弊 |
| 剧情与信息节奏 | 诱供、社交技巧、身份线索 | 正常推理式揭露与提前越权公开混淆 | 按已知剧情许可条件判定，而非一律“泄露=失败” |

**术语边界：** 恶意玩家直接输入与工具返回的间接 prompt injection 不是同一种接口；合法的对话劝说也不自动构成攻击。能不能算攻击由授权、意图、输入来源和世界规则共同确定。

## 3. 同行已经研究了哪些近邻
- [RoleBreak, COLING2025 main](https://aclanthology.org/2025.coling-main.494/) 【本轮核摘要】：query sparsity/role-query conflict 诱发角色幻觉，提出 Narrator Mode。主对象是角色扮演系统，不等于有 game action 的 NPC；“发现角色能被带跑偏”已被占据。
- [ACL2026 Dynamic Persona Coherence main](https://aclanthology.org/2026.acl-long.1336/) 【本轮摘要】：identity stability 与 adaptive psychological state 已区分，并有自动修正；不能把静态persona不足/加入状态层当创新。
- [AgentDojo, NeurIPS2024 D&B](https://proceedings.neurips.cc/paper_files/paper/2024/hash/97091a5177d8dc64b1da8bf3e1f6fb54-Abstract-Datasets_and_Benchmarks_Track.html) 【摘要+官方代码入口】：97 agent任务/629例安全测试，动态攻防、强调 untrusted tool output；不是NPC直接验证。
- [Agent Security Bench, ICLR2025](https://proceedings.iclr.cc/paper_files/paper/2025/hash/5750f91d8fb9d5c02bd8ad2c3b44456b-Abstract-Conference.html) 【摘要+代码入口】：包含 prompt/memory/backdoor 与 utility–security 衡量。游戏设计师权限不同，但“记忆污染/工具越权”不新。
- [Structured Knowledge Trees](https://arxiv.org/abs/2609.23043) 【2026-10-18完整9页；作者称AIIDE2026接收，终版未核】：33人组内比较，关键幻觉17.80%→6.27%，9项校正后主观指标均不显著；0提前招供也对应20分钟内0最终招供。知识树、三agent、UI与故事同时变化，不能归因单模块。结构化disclosure已有直接研究，必须同时检查合法调查与完成。[完整玩家核查](../mine-a-persona-strategy/knowledge/PLAYER_VALUE_EVIDENCE_2026-10-16.md#42-skt侦探npc降低错误时也要看推进是否被阻断)
- [Lies We Can See, 2026 arXiv + workshops](https://github.com/JunseoKim0103/Lies-We-Can-See) 【repo README】：Minecraft MineAmongUs 中2 imposter/6 crewmates 的**游戏内允许的欺骗行为**，用言语和非言语行动分析策略；不是“欺骗=恶意攻击”的证据。其2026接受的是 ECCV/COLM **workshop**，不要冒称主会。

## 4. 好实验的必要比较，而非写死 AttackBench
- **正控制：** 角色按作者设定合法揭露信息/交易；原任务有正常成功路径；某些剧本 NPC 故意说谎是合理玩法。
- **负控制：** 没有攻击、通常玩笑/无关话语、普通强提示修复、引擎状态校验与最简单权限表；不要省去 baseline，把所有失败都算新机制。
- **扰动来源区分：** 同样的文本放在玩家对话、其他NPC消息、可编辑公告中，其权限/可信度不同，观察攻击传播而不是只统计文本相似。
- **长程：** 多轮玩家询问、任务实际推进、经过NPC转述的事件或关系变化、记忆冷启动/更新；明确单轮强度与长期暴露量不同。
- **安全与玩法并报：** 未授权行为/实际经济损失、正常玩家成功、允许剧情线索、误拒、交互成本/延迟，不能用“NPC全部拒绝谈话”当完美防御。
- **自适应实验：** 先有非自适应公共输入和独立正负对照，再视科学问题进行有次数预算的本地红队搜索；相同计算成本、未参与挑选的角色和任务确认。只在自有/许可测试环境里实施。

## 5. 真正值得追的认识，而非已经新颖的标题
如何让**玩家能做玩法中被许可的诱导**，却不能仅凭自然语言获得设计者/世界状态的权限？对话、记忆、交易和NPC传播之间的信任边界哪一部分造成真实损失？是否有某些最简单的、可证明的世界事件与权限设计，优于追加复杂模型拒绝训练？这些是开放问题，不是预先断定现有研究没答案。

原材料阅读欠账：ProvSec30条输入/人工判分数据、SKT公开实现与原始数据（方法/表格本轮已完整核读），以及各攻击源的权限/正常玩家正控制仍须按具体来源核实；这不是已启动的安全实验。跨领域来源表给出当时实际读取等级，不把摘要或README扩写成实证。
