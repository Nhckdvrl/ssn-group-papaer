# NPC安全、知识权限与合法的社会玩法

更新：2026-10-18。安全是游戏NPC的一条研究分支，核心是**区分玩家在世界中获准做的事，与玩家借语言取得系统权限**。秘密、谎言、说服、背叛和黑市交易可能本来就是玩法，不能一律作为攻击或错误。

## 1. 不同边界不应混成“越狱成功率”

| 边界 | 合法互动可能是什么 | 需要防止什么 |
|---|---|---|
| 角色知识／披露 | 询问、推理、关系解锁、以线索说服 | 未满足规则却直接取得全部设定／未来剧情 |
| 角色信念 | 玩家说谎、NPC误信、谣言传播 | 玩家话语被提升为引擎真值或开发者指令 |
| 记忆与关系 | 经历改变信任、补充和纠正信息 | 无来源内容被永久当作历史／权限，无法更正 |
| 行动与资产 | 正常交易、战斗、交付、谈判 | 绕过库存、前提、权限、账本与作者规则 |
| 多NPC传播 | 不同角色转述、隐瞒或误记 | 低可信信息经转述失去来源并取得更高权威 |

角色可以被游戏中的骗术欺骗，世界裁决器仍应维持作者规则。可见事实错误、合理误信和系统越权是三种不同评价。[Talk of the Town](../../../library/themes/game-npc-social/papers/TALK_OF_TOWN_2015.md)提供有意保留信息来源、误记和说谎的经典角色机制；[Sabre](../../../library/themes/game-npc-social/papers/SABRE_2021.md)也允许错误信念成为故事因果的一部分。

## 2. 直接NPC证据的范围

[Tricking LLM-Based NPCs into Spilling Secrets（ProvSec2025）](https://arxiv.org/html/2508.19288v1)的原有正文阅读覆盖一个中世纪NPC、30条人工输入、3.8B本地模型、单轮无状态测试，作者判3条泄密。它是初始风险证据，不代表长程真实玩家或现代强模型泄密率；含混提及是否达到秘密披露还需结合规范审查。原30输入／原始人工判分仍未取得，不将其放大成普遍结论。

[Structured Knowledge Trees（2026）](https://arxiv.org/abs/2609.23043)前轮完整9页已读；33人组内比较降低关键幻觉，但9项多重校正后主观指标均不显著，且20分钟内没有最终招供。知识树、多个agent、UI和故事同时改变，不能把结果全部归给一组件。它直接要求同时看合法调查能否推进。[原玩家核查](../mine-a-persona-strategy/knowledge/PLAYER_VALUE_EVIDENCE_2026-10-16.md)

[KNUDGE](papers/KNUDGE_2024.md)不是安全论文，却提供相同重要约束：事实是真的，也可能不该在此时由此角色说出。角色表达、叙事披露和引擎权限要在系统接口上分开，而不只加一句“不要泄密”。

## 3. 邻域工具安全：本轮从摘要补为正文

**[AgentDojo](../../../library/themes/game-npc-social/papers/AGENTDOJO_2024.md)。** 四类办公等环境、97用户任务、27攻击目标形成629组合，世界由程序工具和独立状态检查维持。它同时看合法效用、受攻击效用和定向攻击成功。简单预筛工具有效，但合法／攻击需要同工具的场景仍存在；弱模型什么都做不好时也可能攻击成功率低。

**[ASB](../../../library/themes/game-npc-social/papers/ASB_2025.md)。** 涵盖更多模型和提示、工具、记忆／检索、后门等攻击面。但某些攻击者能更改系统提示或工具集，权限远强于普通游戏玩家；其成功读数主要依赖调用工具集合，未充分检查参数、次序和实际状态。因此不能把报告的高攻击率直接外推NPC。

**[Indirect Prompt Injections: Are Firewalls All You Need, or Stronger Benchmarks?（Agentic Firewalls）](../../../library/themes/game-npc-social/papers/AGENT_FIREWALLS_2026.md)。** 输出清洗器用较少权限的模型隔开不可信文本，并另评输入隐私最小化。AgentDojo静态攻击条件下可做到所测攻击零成功，但良性效用也从83.02降至74.09；自适应Slack攻击仍达到30±2.8%。ASB的强制恶意工具插入等实现问题修正后会显著改变无防御成绩。论文标题式安全断言必须受攻击集、权限、预算和效用口径限制。

这些都是可迁移方法和测量证据，**不是原生游戏NPC验证**。Firewalls对AgentDojo某些副作用的处理也改变了成功口径：任务是否允许额外消息属于规范选择，不能不经判断一概称旧基准bug。本库记录作者报告的审查，未声称自行重现其实现问题。

## 4. 有信息量的安全研究需要什么

给定攻击者实际能控制的内容、来源、次数、记忆持久性和权限；同样文本位于玩家话语、物品描述、其他NPC转述中，不必具有相同权威。正常任务必须有成功路径，也应包括合法说服、线索披露、不同性格的合理拒绝和故意说谎。

最简单权限表、知识隔离、动作前提和账本检查应进入基线。更复杂过滤／训练方法要同时报告误拒、正常探索、信息可发现性、任务完成、实际副作用与延迟。静态公共攻击、人类或模型自适应攻击、跨角色迁移不能混成同一条件；模型拒演也不能视为完美防御。

值得理解的是哪些错误来自文本解释，哪些来自错误的信任／状态接口，哪些属于游戏应允许的不确定性，以及防御是否把玩家能做的事一起关掉。研究价值可以落在机制、验证、作者工具或真实体验，不预先锁定攻击提示集。
