# 当前研究空间与优先级（2026-10-13第三轮）

详细的重要性证据、近邻与贡献尺度集中在[knowledge/PROBLEM_GENEALOGY.md](knowledge/PROBLEM_GENEALOGY.md)。此页不再列六个看似独立的预设“矿区idea”，也不让CPDC数据可用性决定题目。

| 空间 | 为什么值得进入 | 我们当前的安排 |
|---|---|---|
| 具有自身目标、可控制的交互角色 | 原生角色行动/动机研究、设计者行为控制、当代人物逻辑及Ubisoft制作需求共同支持 | 优先核查自然角色任务和本地底座；LIGHT是候选，不是强制指定论文数据 |
| 适应玩家与陌生伙伴的协同行为 | NeurIPS/ICLR的人类配合、伙伴推断，与实际游戏队友需求相符 | 备选进入；要承认强近邻拥挤，不悄悄变成泛用MARL提分 |
| 共同经历带来的长期连贯 | 社会记忆、动态角色与叙事研究持续关注 | 与角色分支结合理解；先找真实可测后果，不能缺数据就全面合成 |
| 有用且及时的主动性 | 实时交互论文和本地游戏伙伴都关心何时介入 | 研究近邻/可选底座；Proact-VL解说不自动代表实体NPC |

玩家体验/能动性是贯穿各空间的效度问题，不将它折叠为另一个LLM自评总分。若未测真人，只报告客观任务/行为或经校准的代理指标。

## 旧计划处理

此前A–F问题草稿可从Git历史追溯，有关信念、角色、关系、协作、实时性的文献资产保留。**撤回的是从竞赛工具调用出发的E02执行优先级，不是用桌面判断关闭整个NPC领域。** 目前没有一个已由实验确认的论文idea，也没有“完全无人研究”的宣称。

## 判断原则

进入空间靠外部重要性与科学认识缺口；选择底座看它能否承载那个问题及完整本地成本；具体假说来自强基线/自然数据的新观察。不能反向从一个便宜探针造出重要性。允许贡献是解释、测量或简洁方法，不强制训练和指标提分。
