# 研究空间：六片矿区而非六个论文 idea（2026-10-13）

所有切入点都是**待评价的问题**，已有人碰过，不能把“第一次把 XX 用在 NPC”当 novelty。重点是通过实验获得比现有研究更有解释力的认识。参见 knowledge/LITERATURE_MAP、CORE_NOTES。

## A｜NPC 的局部知识、误信与行动后果
- **问题：** NPC 只能依据自己确实观察到的世界事件做决定；当玩家撒谎、信息不对称或后来得知反证时，它是怎样改变决策的？
- **前沿 owner：** KNUDGE 的任务/本体绑定、RoleKE 的角色知识错误、NCP 的世界事实/承诺、CDT 的可执行角色规则。给 NPC 一张知识表绝非新想法。
- **可区分试验：** 固定世界事实改变 NPC 是否亲眼看见关键事件；固定 NPC 观察但改变隐藏世界真相。对同一 initial state 观察**行动/转述/未来信念更新**，不只问“你知道吗”。
- **不同解释：** 只是检索失败、上下文太长、模型全知先验、玩家 prompt 被信为事实、动作解析 bug。
- **科学价值条件：** 发现信念表示何时预测行动/何时不能，或辨明多个相似失败现象的共同成因；不是绘制另一张 hallucination 分类表。

## B｜角色语言人格与真实行为人格的测量桥梁
- **问题：** persona 条件在文字中可分辨，是否意味着在有代价的游戏决策里真的对应不同的选择？
- **owner：** PCSP 的内部轨迹对齐与独立行为测试已不一致；CDT 做可执行决策树；动态人格/ArcANE 关心不同场景中的角色。
- **操作：** 保持局势/动作机会一致改变角色设定；保持角色不变改变局势；用 actions、transition、代价、风险与独立可审计的行为特征评分。
- **反解释：** 模型只响应关键词、reward 直接硬编码动作、差异仅来自风格/随机性、probe 和训练目标同源。
- **科学价值条件：** 形成比现有 persona 相似度更可靠的评价推断或解释条件，而非重述“文本不等于行为”。

## C｜玩家行动自由与剧情世界约束
- **问题：** 玩家如何改变世界又不破坏已建立事实？ NPC 对剧情承诺的服从是否会侵蚀玩家选择？
- **owner：** ICML 2026 NCP-Bench/HiAgent 已直接测该 trade-off；ACL 2025 interactive drama 已测 agency。
- **操作：** 拆分“事实守恒 / 事件合法性 / 选择后果 / 剧情节点 / 玩家参与”；检查多条**合法但不同**的剧情路径是否被错误处罚。
- **风险：** 电影剧本承诺本身可能把合理的自由选择记成失败；judge 偏好平滑文字；不等于玩家 UX 测量。
- **价值条件：** 对“什么应固定、什么可变、如何决定责任归属”有新的验证性认识，而非再次优化 NCP 分数。

## D｜NPC 与玩家/其他角色的协同决策
- **问题：** 感觉合作的对话是否真正改变任务角色、资源分工、对伙伴能力的判断？
- **owner：** Collab-Overcooked、ICML 2026 CollabBench/Decrypto、SOTOPIA、CoopEval 等。普通“加 ToM+memory”已拥挤。
- **操作：** 不可绕开的相互依赖；partner 交叉配对/行为突变；请求、相信、响应、动作的时间顺序；等 token/等调用对照。
- **风险：** 厨房玩家队友并不自动拥有故事世界 NPC 的身份，需要说明从 social-agent 转入 NPC 的科学含义。

## E｜长时关系、记忆和角色成长的实际效用
- **问题：** NPC“记得上次被玩家欺骗”是能复述文本，还是之后真正调整信任、交易和行为？
- **owner：** Generative Agents、SOTOPIA、NeurIPS2026 Personalize-then-Store、ICLR2026 AMemGym 及长期 RP。
- **操作：** 先有自然历史/关系后果；同历史删/改某一次事件，冻结后续交互，测实际行动与长期差别；全历史 oracle/无记忆/简单近期记忆控制。
- **风险：** 一不留神又在做泛用 long-context QA 或检索工程，失去 NPC 游戏意义。

## F｜策略/语言/引擎分层与实时约束
- **问题：** LLM 应何时思考/改变高层意图，低级动作何时交给引擎？延迟与角色可信度/协作效率有何真实关系？
- **owner：** PCSP Unreal 分层共享策略、ReactiveGWM、WorldMind、已有游戏 NPC latency 文献。
- **操作：** 同一自然游戏状态与角色约束，对比快策略/LLM/选择性调用，记录 p50/p95 latency、失败、游戏内代价和玩家可见行动。
- **风险：** 引擎/并行/3D 纯工程主导，研究被大型系统实现吞噬。

## 初步优先调查顺序（非结论）
| 方向 | 科学自然性 | 近邻拥挤风险 | 最需要先查 |
|---|---|---|---|
| A | 高 | 中高 | RoleKE/KNUDGE/CDT 如何定义“知道”和“行动” |
| B | 高 | 中高 | PCSP 独立 probe 与真正任务约束 |
| C | 高 | 高 | NCP 的 judge、可接受分支/剧情定义 |
| D | 高 | 高 | 必要协作与对象是否仍是 NPC |
| E | 高 | 高 | 长期记忆的 action-level ground truth |
| F | 高但系统性强 | 中 | 游戏引擎成本与可测科学变量 |

只要新论文、实际复现或高信息量观察改变了排序，就明确调整并留下决定理由；不靠 agent 的“偏好”提前冻结。
