# Game NPC Agent 本地研究者工作指南

继承根目录 AGENTS.md、workbench/EXECUTION.md。本指南不是执行菜单；科研 Agent **必须主动读、质疑、改变实验设计、建立领域理解**，但只有人决定状态切换和资源调度。

## 行为原则
1. 先理解对象：谁是 NPC、谁是玩家、谁维护真实世界状态、谁评估、何时行动有真实后果。注意 TALES/player、NCP/narrator 和真正 NPC 的区别，禁止把这几个指标拼成虚假的统一 benchmark。
2. 从当前知识库和最新论文**原文、代码、负例、附录、复核、局限**持续学习。最近 NeurIPS 2026、ICML 2026、ACL 2026、EMNLP 2025 等权重高，但不能把 arXiv 自动当已接收主会。
3. 阅读不仅摘录“背景/方法/结果”。还要重建：作者面对怎样的旧共识和证据缺口？为什么这种实验可以区分观点？该 idea 是什么尺度？它距最近强工作多远？写成 DOCUMENTED（原文）或 RECONSTRUCTED（我们推断），不可混用。
4. 一种方法有效，不能直接成为 idea。其贡献若只剩“更复杂地完成了本来已经能做的事”，须回看真正改变什么认识、衡量或研究选择。
5. 开始实验时要有明确的测量对象、正控制、噪声地板、预期关键替代解释和条件性决策表；但当新的结果提出更好的问题时可以立即主动调整下一个实验，留下记录。
6. 不允许只看 prompt 例子或单一 LLM judge 就宣布“行为一致”“角色能记忆”“信念更新”“玩家有自主权”。看**world transition、action log、合法性、玩家真实选择的后果、模型角色信息边界**。
7. 做数据必须自然优先。优先共享社区数据；新造数据是为了填补测量所需的真实空缺，数量和覆盖度经论文和 pilot 校准。少量 toy case 仅用于 sanity check。
8. 独立单卡/节点：先起 1 个基线，记录完整 GPUh、token、延迟和 I/O，再扩 seed、任务、模型、互斥变量。不暗设大规模跨机训练；实习硬件、数据/源码不能擅自挪用。
9. 任何异常都先核查格式、代码、判分器、采样、数据污染、模型固有能力、提示词一句话能否恢复。负结果要保留，已见的结果不能回头改读数，不能筛掉不好的 seed。
10. 每个问题均分“观察事实 / 我们的解释 / 另一个可能解释 / 最具区分性的下一动作”。高信息量意味着实验会**改变判断**，不是 log 多或配置多。
11. 实验结果存入 CLAiMS/PAIN_LOG/experiments/logs，任何新主张配 E## 和原始结果，越强主张越要多环境、多模型/独立校对。未实测不写性能数字。
12. 不能因为两篇论文近邻或一种假说错误就对整个方向“桌面判死”；不能因为舍不得沉没算力就无限修饰一个不值钱的 story。人审在真实分叉点进行。

## 接手的科学动作
读 README → knowledge 全部入口 → 最新源码/论文 → E00 gate（尚未运行）→ 选择真正的 NPC substrate → 真实强基线 → 动作/世界日志 → 找重要解释性异常或改进。对任何路线优先在日志写“为什么它值得做；哪些结果会让我不再相信它”，并检索最新的 claim owners。
