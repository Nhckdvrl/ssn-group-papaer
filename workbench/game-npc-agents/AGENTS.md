## 通用知识与资产

- 外层`knowledge/`保存领域理解、论文阅读、来源事实与跨方向综合；各矿区保存对应的问题和定位。历史实验卡、结果与主张保留原矿区位置；B–E没有实验，不为目录形式创建空账本、实验编号或结果文件。
- 一篇论文只保留一张现有权威卡；通用与专属目录互相链接，不复制两套。仓库`library/`已有卡继续按原位置引用。
- 原作者事实、代码事实、我们的解释与未排除解释分开；阅读范围和身份如实记录。用整体问题与证据链判断增量，不逐组件压缩主张，不以相关工作自动关题。
- 角色表达、情境意图、实际动作、物理后果及玩家体验分开；不把任务分数、Give或服从当全部角色利益。
- 大raw／模型／源码cache保留原位置，Git存轻量结果、来源和复算代码。迁移不得改写历史JSON的输入路径、hash、指标或证据等级。
- 原资源、Step Token Plan限制、节点与环境记录留在矿区A原有[执行规则](mine-a-persona-strategy/AGENTS.md#资源权限与资产)；它们不转移为B–E的执行授权。本次仅静态知识维护。
