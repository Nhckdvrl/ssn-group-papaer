# 矿区 B：可塑造、可延展的角色扮演

**矿区已建立；问题与文献建设；未进入实验立项。** 用户于 2026-10-19 明确要求深入角色扮演、叙事、情绪和玩家体验并建立矿区。本目录承接这项知识建设授权；没有实验项目或 ACTIVE 分配，未运行模型、推理 API、游戏引擎或人类研究。矿区 A 维持终止状态。

## 核心问题

**怎样让作者创造、修改和逐渐理解一个具体角色，使它在玩家带来的新处境中仍能演出可辨认的人物，又能产生作者和玩家接受的合理变化与新表现？**

“可塑造”包括作者设定、示例、纠正、试演与修订。“可延展”包括进入未预写处境、形成新经历、被玩家影响，以及作者从表演中发现自己尚未想到的角色解释。人物可以嘴硬、犹豫、虚张声势、隐藏善意，也可以发生转变；只有永远复述标签并不充分。

这是一个可长期理解的问题空间，尚未收敛为单篇论文的缺口或方法。角色表达、风格、具体选择和玩家感受本身有价值；它们不必都化成物品交付或任务完成率。[Bates 原文](https://www.cs.cmu.edu/afs/cs.cmu.edu/project/oz/web/papers/ba-and-emotion.ps)、[Oz 综述](https://www.cs.cmu.edu/afs/cs.cmu.edu/project/oz/web/papers/CMU-CS-97-156.html)

## 为什么值得深入

角色可定制、角色化思考、人物随阶段改变都已有直接研究；不能只换名字重做。新的价值需要从真实作者与玩家能获得的角色能力中判断。ORIBA 的 14 位原创角色艺术家确实用角色对话检验、修改和延展人物，8 人修改设定，7 人后续提交受互动启发的新作品；这是需求与使用证据，但单组研究尚不能证明特定技术的增量。[ORIBA 正文 §4–8](https://arxiv.org/pdf/2512.12630v1)

同时，合理普通系统的能力可能已相当强。MDRP 的人物分面提示对 Qwen3-Max 均分几乎无增益；ArcANE 中很短的阶段标签对两个基础模型接近完整发展弧。由此必须先核实真正剩余的作者控制、跨处境表演与合理变化问题。[MDRP 表4/附录K](https://aclanthology.org/2026.findings-acl.1175.pdf)、[ArcANE §5/附录P](https://arxiv.org/pdf/2606.05553v2)

## 涵盖的子方向

| 子方向 | 要理解的能力 |
|---|---|
| 原创角色的可塑造表示 | 通用特质、人物例外、条件行为、习惯与示例怎样共同承接具体创作意图？ |
| 作者修订与试演 | 修改一个人物判断后，哪些表现应跟着改，哪些经历和特征应保留？作者怎样定位问题并接受新的角色解释？ |
| 玩家介入下的即兴与延展 | 新提议、误解、秘密、冲突和共同经历怎样成为后续角色表演的材料？ |
| 人物的合理变化 | 区分处境反应、观点修正、关系变化、长期转变与无缘由漂移，并允许不同戏剧风格。 |
| 从人物条件到可辨认表现 | 台词、动作、沉默、语气、时机怎样共同表达人物，使作者/玩家看得见想表达的区别？ |

这些方向不是同时启动的五项实验。[研究地图](RESEARCH_MAP.md) 给出五个可问的 RQ、方法空间与一轮高信息量的进入设计；[定位](POSITIONING.md) 对照最近邻、强普通系统及尚未知道的事情。

## 有意义的能力例子

以下是待研究的玩法/创作例子，不是已验证结果：

- 作者把“刻薄”改为“因为担心而嘴硬”，人物在安慰、争执和危险中改变措辞与举动；玩家能感到不同，也仍认得这个人。
- 玩家临时把反派变成同伴，角色在共同困境中合作，仍带着自己的动机、习惯和边界；后续是否改变态度要有可理解的经历。
- 玩家谈起角色未亲历的事情，角色能表现猜测、误解、拒绝相信或寻求确认；这同时是人物表演与信息差玩法。
- 作者用陌生人、好友、上司等不同身份试演同一个原创角色，发现设定里的空白，并选择哪些新表现成为角色的一部分。
