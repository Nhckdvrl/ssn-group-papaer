# 矿区 B 定位：已有能力、强普通参照与关键未知

状态：知识/问题矿区；没有实验项目或 ACTIVE 分配。本页维护判断依据，不宣称已经存在本矿区方法成果。

## 1. 当前判断

**值得作为宽问题矿区驻留，尚不足以认定某个技术缺口值得立项。** “原创角色可配置”“角色会随剧情阶段变化”“用人物经历/分面约束推理”“作者与自己角色试演”均已有直接研究。可问的整体问题是这些能力怎样共同支持一个作者可塑造、玩家可参与、仍可辨认且能合理延展的具体人物。

不能靠组合部件的新名字证明贡献，也不能因部件已有就否定整体研究。若能解释真实创作/游玩中尚未理解的冲突、给出可迁移能力边界，或用方法改善强普通系统确实处理不好的角色塑造与延展，都可能有价值。[研究地图](RESEARCH_MAP.md)

## 3. 其他不能漏掉的近邻压力

[RoleFact](../../../library/themes/game-npc-social/papers/ROLEFACT_2024.md) 与 [TimeChara](../../../library/themes/game-npc-social/papers/TIMECHARA_2024.md) 使事实核查、知识时间/在场边界成为应有参照。TimeChara 同一 GPT-4o 加普通分解/检索，主表均分从 64.5 到 87.5；短提示/工程组织足以大幅消除某类失败，不能预设都要研究新算法。

[RoleBreak](../../../library/themes/game-npc-social/papers/ROLEBREAK_2025.md) 已处理角色保持与当前提问的冲突，但其叙事补写不保证游戏世界事实成立。[Thinking in Character](../../../library/themes/game-npc-social/papers/THINKING_IN_CHARACTER_2025.md) 已训练角色化内心/风格；“让 NPC 先想人物动机”不再是新 idea。[SimsConv](../../../library/themes/game-npc-social/papers/SIMSCONV_2025.md) 已从游戏可组合属性构造原创人物，尚未证明真实编辑和游戏表现。

## 4. 合理强普通系统是什么

不是只给角色名让大模型裸答。进入实证前应把下列能力作为完整参照，并记录当时模型的实际版本与预算。

| 系统层 | 合理参照 | 新方法必须排除的替代解释 |
|---|---|---|
| 人物资料 | 完整人物背景、具体行为示例/反例、关系、表达习惯、可允许例外 | 只是比基线多给了关键人物信息 |
| 当前处境 | 明确说话对象、地点/公开私下、阶段、目标与双方知道什么 | 场景提示缺失造成伪 OOC |
| 记忆/事实 | 可靠经历记录、摘要与检索、时间/在场边界和工具反馈 | 普通失忆、摘要丢失或事实污染 |
| 条件表演 | 自然段/处境分面、简短阶段标签、必要的角色化思考 | 完整复杂图或长“内心”实际不必要 |
| 更新与核查 | 明确新信息、普通状态更新、重规划、有限自检/重试 | 把未做常规更新的弱基线当困难 |
| 作者工作流 | 可编辑资料、修改历史、同场景对照试演与纠正 | 收益来自基本界面/解释，而非专门架构 |
| 已有专用方法 | 可配置角色模型、CDT/MRPrompt 等实现合理移植 | 重做已有表示或训练思路 |

比较时先对齐有效信息，再比较组织与方法；自然语言本身可以是强表示。使用同一完整资料、同样界面并不要求所有方法输出同样字数，但需要记录推理预算和作者劳动，不能让额外教师/人工整理悄悄承担方法贡献。

选择强商业 API 的目的在于检验问题，不是预设商业模型一定成功。本轮没有调用任何 API；当期具体型号应在未来确获实验授权时重新核验。

## 5. 当前主张与未知

| 判断 | 现在能支持的程度 | 仍缺的关键证据 |
|---|---|---|
| 具体角色塑造和延展有创作价值 | 有经典理论与 ORIBA 等真实作者使用证据；适用人群与作品范围有限。 | 更多真实游戏作者、不同创作风格和长期实践。 |
| 角色表达本身值得研究 | 有可信角色传统与作者产物支持，不能只以任务成功衡量。 | 特定表现变化是否实际带来可理解、可感受的价值。 |
| 当前模型有普遍困难 | 不足。已有错误和改善只在各论文设置成立。 | 强完整系统在原创人物、真实编辑、新经历中的同条件比较。 |
| 新心理/记忆/规则结构必要 | 不足。短标签、完整分面或普通检索可能足够。 | 信息匹配、强底座、跨作者/人物/处境结果，以及作者使用成本。 |
| 静态角色一致性可覆盖玩家介入 | 不足。许多任务给定原作或固定历史。 | 新经历和真实玩家输入下的持续表演、接受范围与长期影响。 |
| 自动人物分可代表体验 | 不足。主观评委校准、人物匹配和玩家使用是不同证据。 | 独立作者/玩家判断、行为与修改记录，以及不一致情况的解释。 |
| 开放越多越好 | 没有依据。角色强度、玩家自由与作者目的可能不同。 | 不同玩法/创作契约下的有效自由与可接受边界。 |

## 6. 防止再次缩成局部问题

每个候选都要回答：作者或玩家因此能创造/经历什么此前得不到的角色表现？为何该能力在多个人物与处境上成立？最简单强系统缺在哪里？哪个观察会证明我们的解释错了？

如果一个候选只剩某句提示、某段特殊对话、把答案改得更像参考或修补一次没检索到的记忆，应回到更宽问题检查它的地位。它可以是实现经验，不必硬称研究贡献。反过来，角色的表达、幽默、沉默、关系感和可探索个性也不需要借物品交付来证明意义。

下一步优先依据 [研究地图 §5](RESEARCH_MAP.md) 的设计判断作者需求和强普通系统边界；不是立即生成新 benchmark、训练小模型或启动大量自动实验。

## 7. 证据范围与维护

本轮 12 项新增正文阅读的规范卡均含版本、范围、3–5 近邻、实验单位、人类证据与限制；外层统一阅读目录负责计数。现代论文中 ORIBA 是预印本、ArcANE 使用作者自报接收的 arXiv v2，正式会場身份与实际文本分开记录。

没有把摘要、下载成功、引用过的论文或同作品不同版本叠加为全文数量。Believable Acting 2022 正文访问仍受阻，只保留第一方摘要欠账；Hap/演员理论的原始文献及长时人物作者实践还需继续补。
