# PCSP：先学习作者自己的独立行为复核，再谈我们的增量

更新：2026-10-18（保留13日独立行为评价记录，并补核论文全文）。来源：[arXiv v1](https://arxiv.org/html/2605.23652v1)、[项目](https://github.com/yoosunghong/pcsp)、[独立行为评价说明](https://github.com/yoosunghong/pcsp/blob/main/research/docs/evaluations/independent-behavior.md)。13日读方法/环境部分和完整独立评价说明；本轮读原论文全部正文与A–D关键附录。没有在本轮重新训练/复算行为probe，未通读全部UE实现。主会接收身份未确认，仍标预印本。

## 一、实际压力与方法起源

**DOCUMENTED：** 多个有设计者设定的人物需要不同的行为，同时希望共享一个高效策略。方法将语言 persona 编码为条件，使用共享 RL 策略及对齐目标，并向游戏引擎输出高层意图。

**RECONSTRUCTED：** 方法出发点不是给每个 NPC 多一段提示词，而是在共享任务优化容易压平个体差别时，为角色条件保留一个可学习、可追踪的通道。可学习的中间指标降低设计/训练难度，但也带来“指标里的角色信号是否就是可见行为”的额外证据责任。

## 二、作者公开资料已经怎样检验这座推理桥？

独立行为说明明确报告：内部轨迹—persona 对齐的优势，没有在独立 Big Five 行为测量中得到同等支持。action-only 的 balanced accuracy 为 full 0.482 / no-consistency 0.511；加状态后为 0.556 / 0.558。**这是作者已经报告的结果，不是本项目发现。**

重要的不只是数字：评价用同一个冻结 probe 比较两种策略，persona 层面留出和聚类重采样，将行动/状态特征与模型内部表示分开。文档说明 extractor 不读取策略表示。当前我们读的是该协议与结果说明，尚未逐文件验证所有 import 与数据形成路径，不能把作者声明变成本地审计结论。

## 三、为什么“独立”仍不自动等于“有效”？

我们应进一步问：Big Five 的可恢复性是否足以描述设计者期待的人物差异？行为机会不相同时，分类失败来自人格没有影响策略，还是环境没有给出表现机会？独立 probe 本身可能有分布迁移和标签语义限制。

因此两种武断解释都不成立：内部 retrieval 好，所以角色行为一定好；外部 probe 不占优，所以角色差异完全不存在。要辨明它们，需要一个与真实角色决策有关、正控制可检验的测量，而非第三个更复杂的同源 classifier。

## 四、研究设计逆向训练

在只看到内部消融优势时，最有信息量的下一步是把策略固定、换一个不读取训练表示的观测方式，而不是增加更多 persona 再画同一张内部指标图。作者已跨出了这一步，我们不能重做即宣称 novelty。

在独立 probe 出现某些维度强、某些维度弱之后，更有价值的下一问是：**同一种人物差异在不同决策机会下是否应当出现不同强度？** 实验必须区分“没有机会表达”“目标确实无关”“控制信号被优化淹没”。这只是研究方向，当前没有我们的行为结果支撑。

## 五、对本 workbench 的取舍

保留为真实共享策略/行为评价的强近邻，而不是强迫第一项实验装完 UE。项目含不同层次的研究环境与运行实现，应逐项审计可以独立运行的部分；此前已经完成特定研究版本的源码审计与训练/原生评价，见[本地基线](../../BASELINES.md)及相应实验卡；不将论文、后续代码和不同配置的结果混称完整复现。

后续重点：独立评价特征、persona 标签与环境行为机会的联系；训练/留出生成机制；每项损失实际影响哪些参数；是否能在自然游戏决策上获得预测性认识。不要把“InfoNCE 内外指标不一致”或“语言人格不等于行动”包装成我们的新论文。

## 六、2026-10-18全文补核：模型、测量和标签冲突

正式题名为 *One Policy, Infinite NPCs: Persona-Traceable Shared RL Policies for Scalable Game Agents*；PCSP指Persona-Conditioned Shared Policy。

- 在线LLM延迟基线只有Qwen3-1.7B。43.7ms对1.97ms的约22倍是该配置推理延迟，不能当强商用API的能力或训练比较。UE5高层决策每0.5秒一次，不能以16–33ms渲染帧预算排除所有高层LLM。
- 人格恢复用共同训练GRU和学习投影；移除InfoNCE也改变了测量空间，内部检索不独立。未见职业full FiLM top-1 17%、no-consistency1.7%、concat28.3%，新特质排序又变；两个Melting Pot留出人格在11次运行中检索为0。不能把局部保留信号说成普遍零样本角色控制。
- 50条角色改写的top-3动作重叠：完整22、部分21、失败7；86%含部分成功，不能写完整成功率。30人每人30判断为900条重复判断，不是900独立玩家，且非长期可玩实验。
