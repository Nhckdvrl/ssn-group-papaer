# Everyone is unique: Towards Behaviorally Heterogeneous Negotiation Dialogue Systems for Debt Collection

- 主源：[ACL2026 Main](https://aclanthology.org/2026.acl-long.232/)、[PDF](https://aclanthology.org/2026.acl-long.232.pdf)。已读§3数据/人评、§4方法、§5结果表2–3、Appendix A协议与C.2–C.3完整指标；未读完其余附录、未审计作者代码，不称全篇复现。
- **源事实：** 11000债务人画像，10000训练/1000测试；200对话由20位有金融经验的标注者评价。画像包括行为/情绪/认知/语言风格。协议以四项还款参数定义达成，区分达成率、回收额/效率、短期可负担性与长期可持续性；16收款模型评测，Qwen3-8B LoRA为方法基座。
- **Idea来源/ownership：** 从真实催收行为异质性构造谈判，而非静态理性用户；论文明确报告为了达成协议而过度让步、损害回收的现象，提出候选筛选+前瞻模拟的偏好优化。不能把“高达成率掩盖自身利益受损”冒领为首次发现。
- **与I04的距离：** 还款效益从协议参数计算，不是追踪协议后实体履约、资源变化与敌对动作。原生NPC资产互依仅是增量入口，需进一步形成跨场景可检验的决策预测。
- **竞争解释：** 画像模拟器行为、协议抽取和经济指标设定可影响过度让步解释；不自动推出性格词绕过因果推理。
