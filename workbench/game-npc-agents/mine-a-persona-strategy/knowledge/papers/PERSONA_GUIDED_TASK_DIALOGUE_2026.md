# Persona-Guided LLM Agents for Task-Oriented Dialogue

- 主源：[正文](https://arxiv.org/html/2608.18085)、[PDF](https://arxiv.org/pdf/2608.18085)。会议信息未核对；HTML编号与所列日期不一致，不自行补会议归属。
- 已读方法§3、结果§4、表5/9、PDF Appendix B真实系统/裁判提示及D复现设置；HTML漏掉提示框，已补PDF。代码/生成数据仅声明接收后发布，未复现。
- **源事实：** SGD酒店/餐厅、三模型、十种性格、Neutral/Try/Oracle，共9000对话；Oracle把用户性格显式给系统。普通规则已经要求遵守schema、只用数据库结果、不得虚构。任务完成与语言质量/真实性分开；后者用Gemma-4-31B裁判。个性化改善部分服务指标，真实性降低。
- **Idea来源/ownership：** 将人格表达放回有目标的服务对话，研究适应用户与grounding的取舍；宽泛“人格与任务可靠性冲突”不是我们的新发现。
- **与I04的距离：** 该文人物主要是服务用户，系统负责满足用户任务；E63/E64的NPC有自己的作者目标、物品与对方独立行动。我们需要可预测的物理任务/合作边界，不能只换成游戏称创新。
- **竞争解释：** 用户性格与系统适应强度、裁判偏好及数据库事实错误可共同影响分数。该文结果不直接证明NPC资产损失或内部表征机制。
