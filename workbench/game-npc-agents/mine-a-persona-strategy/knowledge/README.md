# 矿区A知识库：人物、本人目的与真实游戏选择

中心问题是NPC面对人物设定、自身目标、角色规范、社会关系、玩家请求与可见状态，怎样形成选择并产生游戏后果。自述/语气、情境意图、合法行动和真实后果分别测量；既允许人物作用有效，也允许普通控制解释表面失配。

**本目录只记录领域理解、论文阅读和近邻定位。** 具体实验、统计、主张核对及轨迹读回分别在同级`experiments/`与`results/`；不在知识库内建立实验卡或实验进度页。

专属逐篇论文见[papers](papers)，通用系统与跨方向论文在[领域论文目录](../../knowledge/papers)；同一论文只保留一份。领域地图、测量、安全、经济、漂移等共通知识见[外层知识库](../../knowledge/README.md)。
