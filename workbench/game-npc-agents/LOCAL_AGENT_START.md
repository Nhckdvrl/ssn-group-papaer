# 本地研究Agent接手：只从已选的目标控制问题进入

2026-10-13。先读EXPLORATION_ENTRY、GOAL_CONTROL_REVIEW、FRONTIER_CHECK与E03/E04。这是科学探索，不是必须跑完的僵化网格。

## 立即做的事情

首先恢复**指定的原生资产**，不再泛搜六个方向。核对LIGHT pinned commit；在隔离CPU环境恢复官方无模型world，检查实际事件和角色局部观测；从BASELINES所列官方quest/WILD入口取得数据，保存完整hash和许可。阅读原始目标、时间线与真实示范，确认哪些可无歧义地映射为状态目标、哪些是事件目标。不要假定WILD就是旧2111示范，也不要把现仓projects/quests当完整Dragon包。

官方数据无法可靠恢复时，先查官方builder、历史发布路径和公开同任务资产；记录具体缺口。不得自己生成几百条任务后标LIGHT，也不得把恢复工程无限延长。需要更换底座时保持“角色自己的目标与玩家造成的合法世界变化”的问题，不暗转工具竞赛。

随后在**同一授权节点**连通本地模型与原生引擎。先用已有权重缓存和稳定服务，固定模型/模板/解码/服务版本。服务地址必须显式给出；没有地址就报错，不能通过默认SDK、代理、fallback、judge或免费预览模型连云端。请求、伙伴、重试、计划都入成本。游戏/任务信息只来自经过检查的本地资产。

代码、环境、任务与评分最小闭环成立后，跑E03的自然U分支及对应资格检查。查看真实成功和失败轨迹，再对合格源任务加入N/R/S；不是事先寻找能让模型出错的最极端例子。当前4分支是起点，若对自然任务不成立可主动调整，并解释调整对问题的影响。

## 科学自主性

你不是来证明“LM一定把目标与计划混淆”。Goald Drift、Everitt、Arghal、Bayes已经报告了许多相近认识。新观察先与它们对齐，写出哪些简单解释也能产生这个结果；不要将普通记忆失败、parser错误、低能力和无用钥匙偏好重新命名。

遇到异常，优先对比同一变化后快照从零执行、普通目标提示、匹配事实的每步重规划、只移除旧计划等干预。选择最能改变判断的实验，不能为填全矩阵盲跑。若有更好的自然问题或测量方式，主动提出并记录来源；不为沉没算力维持故事。

初始结果不支持预期时照实记录。失败种子、超时、错误目标标注和不可达分支全部留痕；主结果不按模型是否先成功筛选。根据实测方差而不是目录模板决定确认规模；test源任务不能参与选择。

## 不许预支的结论

普通强提示或经典规划器已足够时，不硬造复杂方法。没有新的可预测认识，不叫论文idea；没有人类证据，不叫玩家更开心；没有干预/独立确认，不叫机制；没有真实模型结果，不升级CLAIMS。
