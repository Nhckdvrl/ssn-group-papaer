# 矿区E：玩家可理解的互动自由

**2026-10-19，依据用户“角色扮演、叙事、情绪、玩家体验……建立矿区”的要求建立。** 当前是问题与文献建设，尚未进入实验立项；不改变研究状态或ACTIVE分配，不启动实验。矿区A的终止决定继续有效。

## 核心问题

**玩家怎样发现、理解并运用NPC提供的互动空间，让自由表达、人物理解和故事参与成为可持续的玩法？**

一个输入框允许说任何话，不等于玩家知道能做什么。一个NPC态度变化，也不等于玩家能理解其缘由。另一方面，明确选项、固定主线和没有物理后果的寒暄，也可能支持表达、扮演、期待和关系。矿区研究这些活动怎样形成，以及哪些设计支持哪些玩家和游戏。

## 为什么值得建立

- [VRST 2024](../../../library/themes/game-npc-social/papers/PRESENCE_VRST_2024.md)和[CoG 2025](../../../library/themes/game-npc-social/papers/OPEN_ENDED_DIALOGUE_2025.md)已有真人比较：自由表达有吸引力，也可能需要更多构思、输入和等待；总体体验收益并不稳定。
- [Agency Reconsidered](../../../library/themes/game-npc-social/papers/AGENCY_RECONSIDERED_2009.md)与[叙事选择访谈](../../../library/themes/game-npc-social/papers/NARRATIVE_CHOICE2022.md)把能动性放在玩家意图、系统回应和解释之间；不能只数分支或只看终局是否变化。
- [Scaffolded Play](../../../library/themes/game-npc-social/papers/SCAFFOLDED_PLAY_2025.md)提出角色功能可能改变约束的作用，但改造方案只经过模拟评价；这是待检验问题，尚非通用设计定律。
- [PXI原研究](../../../library/themes/game-npc-social/papers/PXI_2020.md)与[独立验证](../../../library/themes/game-npc-social/papers/PXI_VALIDATION_2024.md)说明体验需要分构念解释。NPC关系与叙事还需要其特有证据。

## 四组候选问题

| 问题 | 可能带来的能力或认识 | 决定它是否成立的证据 |
|---|---|---|
| E-Q1：怎样让玩家逐步发现互动可能性？ | 在玩家需要时帮助构思、询问和尝试，熟悉后允许更自由的表演 | 实际使用及未使用的机会、玩家理解、引导依赖、主动探索；普通选项/提示是否已足够 |
| E-Q2：哪些表达具有价值，即使主线相同？ | 区分措辞自由、人物自我表达、局部社会回应与剧情改写，解释玩家为何重视它们 | 情境化访谈和可对照的游玩过程；不能只看最终状态或自编“自由分” |
| E-Q3：玩家如何区分角色主见、戏剧含混与系统故障？ | 保留怀疑、冲突和误会的玩法，同时使技术性失败有可恢复路径 | 玩家当时的解释、后续行动和修复劳动；允许有理由的多种猜测与带着不确定继续行动，不要求猜中内部状态 |
| E-Q4：这些价值对谁、在何种情境、多久仍成立？ | 解释角色类型、游戏目标、交互方式、经验和作品来源预期的差异 | 多情境与重复使用证据；短时新奇、自报重玩意愿和真实返回分开 |

E-Q1与E-Q3可作为首先接触的活动问题；E-Q2防止把矿区缩成可用性修补；E-Q4约束前面结论的适用范围。当前不是四个已经证明存在的技术缺口。

## 入口与进入条件

- [研究地图](RESEARCH_MAP.md)：理论、玩法活动、证据单位和研究设计空间。
- [近邻与立足点](POSITIONING.md)：最强普通参照、已有工作边界、首轮高信息量设计及何时停止某条候选。
- [外围玩家/作者知识](../knowledge/PLAYER_EXPERIENCE_AND_AUTHORING.md)与[测量规范](../knowledge/MEASUREMENT.md)：持续维护公共认识。

进入实证前，先明确玩家活动、作品目标和最有信息的对照。若普通强模型与清楚交互已满足需求，应接受该结果，转向解释适用边界或停止对应方法候选。只有清晰的人类/设计问题，也可以形成有价值HCI研究；不要求先制造一个LLM失败榜。
