# 矿区E：近邻、立足点与首轮判别

日期：2026-10-19。这是研究进入设计，**尚未运行**；无实验编号、样本招募或资源申请。

## 1. 强近邻怎样约束候选

| 候选 | 直接近邻已经做到什么 | 仍可能有价值的增量 | 应接受的否定结果 |
|---|---|---|---|
| 能力发现/引导 | [VRST](../../../library/themes/game-npc-social/papers/PRESENCE_VRST_2024.md)与[CoG](../../../library/themes/game-npc-social/papers/OPEN_ENDED_DIALOGUE_2025.md)已比较开放和选项，前者已建议混合 | 理解引导何时帮助构思、何时干扰扮演；玩家怎样由依赖选项转向探索 | 明确教程/固定建议足够，新自适应机制没有增量 |
| 表达性自由 | [DIS叙事选择](../../../library/themes/game-npc-social/papers/NARRATIVE_CHOICE2022.md)和[自由语音](../../../library/themes/game-npc-social/papers/VOICE_CONTROLLED2025.md)已有表达价值证据 | 区分措辞、身份、社会策略和剧情权力，检验其与玩家目的的关系 | 价值来自界面或表演方式，无需更开放的世界生成 |
| 含混与恢复 | [VR对话](../../../library/themes/game-npc-social/papers/DIALOGS_GENAI2026.md)已有社会归因/修复观察，[Vaudeville](../../../library/themes/game-npc-social/papers/VAUDEVILLE_FEEDBACK2024.md)已有实际抱怨 | 分辨何种含混促进探索，何种使玩家错误承担责任；支持可理解的恢复 | 状态接地/错误提示已解决问题，不需要新角色认知架构 |
| 情境差异 | [Scaffolded Play](../../../library/themes/game-npc-social/papers/SCAFFOLDED_PLAY_2025.md)提出角色功能假说；[态度研究](../../../library/themes/game-npc-social/papers/PLAYERS_AI_ATTITUDES_2026.md)有用途差异 | 在实际活动中检验差异，并说明什么时候不能迁移 | 不存在稳定分组规律，不能把探索性切片包装成个性化策略 |

这不是以“尚无真人/尚无长期”自动宣称创新。必须说明新的证据会改变哪条设计判断，或新交互能让玩家做什么原先难以做的事。

## 2. 合理普通参照应是什么

模型层保留同一完整角色、世界事实、可见状态、历史、工具与失败反馈；使用当时经公开来源核定的强商业模型作为能力参照。现有GPT-4o/2024模型论文不能代表未来实验时最强API。本轮不选择付费型号、不调用API。

交互层至少考虑三种有能力的参照：**明确且写作质量良好的选项**、**可自由措辞但映射到既有叙事结构**、**相同状态支持的开放NPC加普通引导**。若研究的是引导方式，保持底层NPC和规则不变；若研究开放后果，不能让对照连玩家意图都看不到。输入模态、时延、回答长度、内容与美术质量应按具体比较配平或明确建模。

脚本/人工作者版本可以提供体验参照，而非设置成笨拙靶子。Wizard或预生成素材适合隔离体验假说，但必须如实说明其能力来源，不能证明在线系统可靠。

## 3. 最值得先做的一轮高信息量研究

### 所要区分的解释

当前最有价值的第一问是：**玩家无法获得预期体验，主要因为NPC不理解/不执行，还是因为玩家无法发现、表达或判断系统已经具备的能力？** 第三种可能是玩家本来就不想使用这类自由；第四种是自由有表达价值但未改变传统任务指标。

### 一个可审查的设计草案

1. **先选真实活动与作品目标。** 从至少两种独立角色/故事活动挑选材料，例如调查推断与关系互动；用创作者的目标和玩家可做的事情描述，不先用物品、承诺字段或失败模板生成题目。具体故事及数量待材料工作确定，同一故事换名字不算独立情境。
2. **先检查强普通系统是否具有所需能力。** 回放固定意图与正常状态，核对事实、知识边界及该活动确需成立的回应或后果；表达活动可以只要求角色承接了玩家的表演，声称改变游戏机制时才需可执行后果。需要规划的活动再检查普通重规划。回放只能证明在该表达/历史下的能力；自然输入可能改变意图识别，不能因后端相同就断言能力恒定。保留“原始输入→系统理解→回应/后果”的记录，区分玩家未发现、模型未理解、状态或执行失败。该检查不作玩家收益证据。
3. **核心比较只改变支持玩家的方法。** 同一强NPC比较开放输入＋普通说明，与保留自由输入的候选支持；情境化示例、意图确认、恢复是三个备选机制，首轮选一个主要机制。若作为组合设计比较，只能判断整套支持是否减少接口障碍，不能归因于其中某组件；关键片段的过程分析也不代替组件因果比较。另外保留高质量明确选项作为体验参照。建议应可按需使用或拒绝，记录其打断表演的代价。首次与再次使用分别观察，但两次差异可能混合新奇、学习、剧情熟悉与负担变化，只作为重复暴露线索，不推断长期留存。
4. **用行为、过程解释与分构念自报互证。** 记录玩家想到/发现/尝试了什么，系统怎样接续，哪些时间用于自愿表达、推理或故障修复；在关键片段回顾玩家当时预期。明确观察选择身份/语气、挑衅、沉默、拒绝推进等主动表演，以及提示是否把它们引向更合作或更高效的默认路径。依据研究问题选择PXI相关分量表并补角色/叙事访谈，避免将所有题合为一个总分。研究中插入提问本身可能改变体验，需要明确时点。
5. **在看到结果前写出判断。** 样本量由有意义差异、聚类和可达到的推断范围确定；玩家、作品和重复交互分别处理，不把对话轮次当独立样本。若仅探索性质性研究，就明确提供活动分类和证据链，不伪装平均因果效应。

### 一轮结果怎样改变投入

| 观察 | 应更新的判断 |
|---|---|
| 强普通系统已能完成，帮助主要来自普通说明/选项 | 弱化复杂agent方法候选；保留可复用的设计边界或结束该方法方向 |
| 能力存在，玩家因发现/表达/解释困难无法使用，候选设计减轻该障碍且保留扮演 | 支持继续交互方法；下一步检验跨作品/角色迁移 |
| 增加表达但没有结局变化，玩家仍认为更能扮演 | 支持表达性价值；不强行包装世界机制创新 |
| 好奇/自主增加、负担也增加，玩家偏好随活动不同 | 研究适配与权衡，不宣称普遍改善或失败 |
| 主要失败来自视觉指代、状态未给、ASR或延迟 | 修正系统参照；当前证据不足以支持角色认知/叙事新机制 |
| 玩家已理解、有机会使用，仍不重视这些自由，或它干扰作品的节奏与审美 | 接受场景不适配，停止该候选；单纯未使用不能证明不想要，强制试用后的喜欢也不能证明自然需求 |

## 4. 资源与研究形态

当前优势是已有跨角色、叙事、情绪、玩家研究的规范卡与可审计近邻；尚无证据说明我们具有原创角色资产、职业作者合作或真实玩家渠道优势。可以形成HCI解释/交互研究，也可与B/C/D形成系统加人类证据的工作。目标会场不先定，尤其不把纯作者/玩家问题硬凑为模型排行榜。

本地venue corpus没有可用数据，本轮未生成接收密度、拒稿率或近期十篇/五篇分数表。已有正式CHI、DIS、CoG、VRST、ACL等来源给出相关学术脉络；这一事实只支持题域相关性，不保证任何具体候选的新颖性或录用。
