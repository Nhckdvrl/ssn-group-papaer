# E02：自然 NPC 决策中角色信息的相关性与干扰（2026-10-13）

- **状态：** PLANNED；未调用模型，未构造/发布新数据集。
- **类型：** DATA-AUDIT / EXPLORE，先确定自然数据是否能承载问题，再测模型；不是已知新机制的验证。
- **对应：** [EXPLORATION_ENTRY](../EXPLORATION_ENTRY.md)；E00 的数据/测量准入。没有先挂一个虚假的 C##/P##。
- **问题：** 在明确任务状态与工具接口下，角色相关信息是否带来合适的行动变化，无关的等义/风格变化是否不应改变的工具决策却改变了？先核查这些标签是否能从自然数据中可靠得到。
- **设置：** CPDC 原始发布样例及公开 strong baseline 为优先审查对象。先记录许可证、source hash、原始/增强 lineage、场景/角色、历史、工具、参考返回和可接受动作。若数据只支持纯工具匹配而不含足够角色相关决策，不强行补造全套反事实。模型阶段的 revision、seed、scene IDs、解码、预算及有效 n 在数据审计/成本实测后冻结；未填前不运行大实验。
- **读数：** 分开报告调用/不调用、工具选择、参数与顺序合法性、明确角色目标约束、歧义/多种合法动作；同时统计格式失败和表达质量，但不合成单一人格分数。干预保持 task/state/schema 不变的依据需独立于模型结果。
- **阳性对照：** 规则明确的工具调用和无需调用案例；明确改变合法选择的任务/角色事实；等义表达不改变契约。先看测量能否辨别已知差异，再观察自然模型行为。阳性对照集不计入主要自然结果。
- **噪声地板 + MIE：** 尚无估计。先测重复调用、源场景异质性及关键标签分歧，随后按场景聚类有效样本数和区间宽度决定 n；不能把增强变体当独立样本。小规模 pipeline 样例不支持通用能力结论。
- **混杂审计：** 输入长度/格式、提示词默认策略、一句指令修复、工具 schema 泄露 gold、参考历史与自由滚动混淆、persona 刻板映射、相同源对话跨 split、模型/判分器同源、训练 token/推理调用预算不匹配。数据许可与发布边界先审查。
- **决策表（跑之前写）：** 足够自然且标签可检验→单节点冻结模型做配对探索；样例歧义→允许多解/保留未知并改读数；格式能力地板→修接口不写人格机制；简单提示即可恢复→定位默认策略并重估贡献；只复现删 persona 有益→回核 Talk Less/Deflanderization，不能立新主张；相关与无关信息呈现可重复差异→用未参与选择的场景确认，再深入机制/方法；缺少自然承载数据→改问题或换资产，不靠全面合成强行立题。
- **算力预算：** 数据 census 可 CPU 完成；模型阶段先单节点成本试跑后登记，不估造 GPUh。不默认同时占用所有机器；跨机构授权和资产隔离。**实际：0 次模型调用，0 GPU·时。**
