## 当前研究入口：动态角色认知与长期人物演化

**用户最新纠正（2026-10-22）：从整体方向考虑，停止局部现象优化。** 当前优先研究人物怎样从经历形成/修订判断，并在之后不同互动中表现这种变化；情境反应、知识修正、关系变化与人格成长分开。新读CAPS、PD-LLM与EvoSpark，结合既有近邻和实测重写[整体定位](POSITIONING.md)。不新开线、不锁定新loss。

核心问题是**时间证据约束下的人物状态推断与适应**：截至当前的经历怎样支持人物状态，历史中什么仍有效、什么已被修订，角色后训练学到了怎样的变化规律？ArcANE为主要载体，PHASE-Tree/LongEvoRoleBench作为独立任务与强近邻；原有情绪、关系与玩家价值研究地图继续保留。

首先核查并复现官方数据、输入条件、评价与模型，建立规模足够且来源清楚的测量。不把训练数据内部test当正式人物弧benchmark，不把回顾性阶段描述等同在线事件证据，不将分数变化直接称泄露或状态惯性。方法从真实测量发展；普通合法历史总结与官方状态更新均认真比较。

## 我们要理解什么

**在持续角色扮演中，NPC怎样根据自己在乎的事情、知道的事实与共同经历，产生玩家能够理解、影响和回应的情绪与关系变化？**

一个值得关心的变化，可以是骄傲的对手开始尊重玩家，也可以是朋友仍然生气却愿意重新相信玩家，或受保护的角色逐渐争取自主。角色的声音、迟疑、回应方式和互动选择，都可能承载变化。这里既研究变化怎样发生，也研究它何时有助于玩家扮演自己的角色、理解一个人物或参与一段关系。

这些是研究问题及设计例子，**不是已经由本矿区证明的玩法收益**。我们不把持续转正的情绪、越来越高的好感、越长的对话或越接近平均真人，作为所有角色的共同目标。

## 为什么成立为一片矿区

已有游戏研究记录了玩家与角色的多种联系：欣赏能力、尊敬对手、保护弱者、认同角色和信赖伙伴；玩家也会为了关系意义调整实际游玩方式。相关证据来自213份喜欢的角色回忆，以及Mass Effect两位角色的粉丝讨论，支持问题的玩家相关性，同时受选择性与回顾性限制。[角色依恋研究](../../../library/themes/game-npc-social/papers/CHARACTER_ATTACHMENT_2019.md)｜[Mass Effect关系研究](../../../library/themes/game-npc-social/papers/NPC_ATTACHMENT_MASS_EFFECT_2020.md)

传统系统已经可以维护非对称关系、情绪来源、衰减、表达差异和跨会话历史；LLM也已经能用自然语言解释处境并更新情绪。因此，**“给NPC加情绪值、记忆和关系值”不足以作为贡献**。剩余空间需要在人物解释、合理变化、可读表演、玩家关系体验和作者控制之间寻找。[OSSE](../../../library/themes/game-npc-social/papers/OSSE_SOCIOEMOTION_2009.md)｜[EMA](../../../library/themes/game-npc-social/papers/EMA_2009.md)｜[Chain-of-Emotion](../../../library/themes/game-npc-social/papers/CHAIN_EMOTION_2024.md)

## 五个候选核心问题

| 问题 | 需要产生的新认识 | 有意义的表现或互动 |
|---|---|---|
| 情绪为什么改变？ | 分清事件、角色理解、目标、责任与应对能力；新证据如何引起重新评价 | 同样的结果因已知意图不同，被视为侮辱、失误或保护 |
| 情绪怎样成为可读的表演？ | 内部情绪、表达意图、言语/非言语和应对之间如何协调 | 克制的愤怒、掩饰的害怕、真诚但保留边界的道歉 |
| 关系怎样被共同经历改变？ | 短时情绪与信任、尊重、熟悉、依赖等长期态度何时分离 | 争执后仍愿意合作；原谅一件事却未恢复亲近 |
| 角色怎样成长并调节情绪？ | 应对、重评、价值和关系位置的变化怎样保持人物可辨认 | 被保护者更独立；对手更尊重玩家但继续对立 |
| 哪种变化值得玩家与作者关心？ | 哪种关系意义适配何种角色扮演；何时可变性损害体验 | 玩家看懂自己的影响，作者能控制角色边界与变化空间 |

五个问题还没有被压成唯一论文题目；前三个是当前较直接的进入点，成长与纵向关系需要更长时间证据。

## 已读证据迫使我们保留的判断

1. **强模型和普通结构很可能吃掉一部分方法空间。** CPM-MultiAgent在同GPT-5.4下的Overall为4.322，普通zero-shot为4.283，单体CPM为4.295；人评对理由的偏好强于情绪状态的偏好。尚无对应真实游戏互动效应。[CPM卡](../../../library/themes/game-npc-social/papers/CPM_MULTIAGENT_2026.md)
2. **简单方法也有真实互动证据。** Chain-of-Emotion是完整历史加一次自然语言情绪评价，30人各玩三种短时分手对话；部分自然性/敏感性指标有收益，但范围窄、报告存在需核查之处。[原实验审计](../../../library/themes/game-npc-social/papers/CHAIN_EMOTION_2024.md)
3. **长期关系价值不以生成模型为前提。** Bickmore的101人30天研究用脚本与菜单，关系行为改善部分关系感受和继续互动意愿；未因此证明实际行为或长期留存优势。[关系型代理卡](../../../library/themes/game-npc-social/papers/RELATIONAL_AGENTS_2005.md)
4. **解释漂亮、情绪标签分明不等于效度。** CoRE比较显示模型的情绪概念更离散；这不能直接判定游戏不好，却要求我们允许人物与情境的合理差异。[CoRE卡](../../../library/themes/game-npc-social/papers/CORE_EMOTION_CONCEPTS_2026.md)
5. **情绪支持助手的目标需要重新检验。** EmoLLM奖励模拟用户转向积极情绪，未验证拥有自己意愿的NPC或复杂关系。[EmoLLM卡](../../../library/themes/game-npc-social/papers/EMOLLM_2026.md)

## 当前定位

暂时值得优先研究的不是某个状态公式，而是：**共同经历被角色怎样理解，怎样改变它的应对与关系，以及玩家为何认为这种改变是这个人物会做出的回应。**

候选机制可以是有来源的事件解释、分开短期情绪与持续关系判断、对重新评价和修复保留因果依据、把表达意图传给表演层。是否需要这些显式机制，应由同信息强模型与成熟普通系统比较决定；自然语言历史与普通提示已足够时，应承认方法空间缩小。
