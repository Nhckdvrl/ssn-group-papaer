# 矿区 D 研究地图：可理解的情绪与关系演变

2026-10-19知识地图；2026-10-22用户明确选择本矿区为父工作台主线，当前公开资产驻留见README与D-E01/D-E02。以下把可核查的已有证据与本矿区的研究推断分开。

## 1. 研究对象与评价对象

一句“NPC很有情绪”可能指多个不同现象。把它们混在一起，会让一个标签预测结果变成角色系统能力，又让短时喜欢被写成长久关系。

| 层面 | 具体对象 | 不能被什么替代 |
|---|---|---|
| 事件与知识 | NPC看见、听说、记得什么；信息是否可信；谁负责什么 | 完整世界真相不能自动成为角色已知事实 |
| 评价与动机 | 这件事怎样影响它的目标、身份、规范和应对资源 | 从事件关键词直接选“怒/喜” |
| 情绪与调节 | 此刻受到什么影响，怎样面对、重评、压制或表达 | 长期人格固定标签，或不断转向积极情绪 |
| 关系判断 | 对特定对象的信任、尊重、熟悉、亲近、责任和边界 | 一个总好感度；一次愤怒也不必抹掉信任 |
| 角色表演 | 话语内容、语气、停顿、身体、选择、回避、争取 | 内部状态图；也不要求每个变化都改任务胜负 |
| 玩家体验 | 真人如何扮演其角色，理解/回应NPC，并赋予关系意义 | NPC情绪、玩家角色的情绪，或自动评判器满意 |
| 创作控制 | 作者能定义重要价值、可变部分、表达风格和关系边界 | 逐句穷举，或让玩家最新一句话任意覆盖人物 |

这张分层表是**本矿区的分析框架**，并非宣称文献已有统一分类。传统系统已区分触发情绪、当前状态和表达情绪；关系型代理与游戏依恋研究则从互动和玩家解释补足不同尺度。[OSSE](../../../library/themes/game-npc-social/papers/OSSE_SOCIOEMOTION_2009.md)｜[关系型代理](../../../library/themes/game-npc-social/papers/RELATIONAL_AGENTS_2005.md)｜[角色依恋](../../../library/themes/game-npc-social/papers/CHARACTER_ATTACHMENT_2019.md)

## 2. 理论与方法谱系

### 2.1 事件评价、动机与应对

OCC、EMA、PsychSim、FAtiMA的贡献不是给情绪附上名称，而是把它放回对世界的理解、目标和应对。EMA通过因果解释中的重新评价与coping让情绪、认知和行动相互影响；PsychSim提供他人模型和社会影响；FAtiMA把这些因素作为可组合的角色架构。旧卡中相应证据以机制和有限示例为主，不支持“已普遍验证真实心理”。[EMA](../../../library/themes/game-npc-social/papers/EMA_2009.md)｜[PsychSim](../../../library/themes/game-npc-social/papers/PSYCHSIM_2005.md)｜[FAtiMA](../../../library/themes/game-npc-social/papers/FATIMA_MODULAR_2014.md)

游戏工程还有另一条合理取舍：OSSE用动作赞许、对象态度和事件确信度，减轻目标/计划建模；GAMYGDALA面向各种游戏AI提供较通用的情绪引擎接口。它们已经能处理关系、强度和衰减，却把事件意义和部分行为层留给游戏作者。OSSE默认动作有意；不同意图需要作者创建不同动作。这里保留了一个值得追问的边界：**自然语言开放后，谁负责将新经历解释成这个人物在乎的事件，以及后来怎样修订这种解释？** [OSSE原文审计](../../../library/themes/game-npc-social/papers/OSSE_SOCIOEMOTION_2009.md)｜[Emotional Appraisal Engines for Games](../../../library/themes/game-npc-social/papers/APPRAISAL_ENGINES_2016.md)

### 2.2 从自然语言评价到LLM结构与训练

Chain-of-Emotion以两次调用完成“描述角色感受与原因→带着这些自然语言情绪历史回复”。它已与完整对话历史比较，不能被归类为无记忆稻草人。CPM-MultiAgent进一步把relevance、implication、coping potential、normative significance拆为多个审议角色；Dynamic Persona Coherence尝试把身份与动态状态分开检查。[Chain-of-Emotion](../../../library/themes/game-npc-social/papers/CHAIN_EMOTION_2024.md)｜[CPM](../../../library/themes/game-npc-social/papers/CPM_MULTIAGENT_2026.md)｜[DPC](../knowledge/papers/DYNAMIC_PERSONA_COHERENCE_2026.md)

EmoLLM把评价链用于小模型训练，并通过模拟用户后果选择支持策略。它说明“情绪”研究正在从分类转向互动策略，但其目标是用户积极情绪；角色对手、含混关系、悲剧和不愿原谅并不自然符合这个奖励。[EmoLLM](../../../library/themes/game-npc-social/papers/EMOLLM_2026.md)

**本矿区推断：** 方法难点需要落在普通强模型仍做不好的关系解释与可控变化，或者落在一个已被忽略的体验/创作规律；再增加一个appraisal模块或图结构，距离近邻过近。

### 2.3 表演可读性、情绪调节与多模态

角色可以感到害怕而表现镇定，也可以以冷淡保护关系。因此，所有模态同步标成同一种情绪，并不构成完整的表演一致性。需要解释的是**表达意图**：向谁表现、隐藏什么、想维持怎样的互动、观众应从什么线索看懂。传统社会表达过滤与OSSE已区分felt/expressed affect，但OSSE本身没有完成表达决策；不能由此称当代问题都已解决。[OSSE](../../../library/themes/game-npc-social/papers/OSSE_SOCIOEMOTION_2009.md)

IVA2018的口语游戏原型用文本情感识别、有限情绪状态和信息解锁，16人分两组各8人，开启情绪条件平均使用时间更长；情绪条件同时改变解锁难度，无法把时长单独解释为投入。所谓语音情绪分析实际针对识别后的文本。旧Affective Mirroring研究则提醒我们，玩家有时更认可Wizard产生的情绪回应，自动情绪推断、身体与话语的配合仍是具体问题。[IVA2018](../../../library/themes/game-npc-social/papers/SPOKEN_EMOTION_2018.md)｜[Affective Mirroring](../../../library/themes/game-npc-social/papers/AFFECTIVE_MIRRORING2025.md)

这里有两种不同研究：NPC自己怎样调节和表达情绪；系统怎样读懂/回应玩家的情绪。D两者都关注，但优先以前者为中心，后者不能替NPC丢掉人物自己的目标，也不能把玩家扮演的愤怒误认成真人需要被安慰。

### 2.4 跨会话历史、关系成长与修复

OSSE已经维护非对称关系、情绪归因和深关系的更新阻力；Bickmore在30天脚本中使用历史引用、社交谈话、关系谈话和多模态表达，改善部分关系感受。由此不能再主张“旧系统不能形成跨会话关系”。但前者尚未验证自由交互，后者不是从开放经历学出的关系模型，且出现重复感、实际行为效果与关系感受不一致。[OSSE](../../../library/themes/game-npc-social/papers/OSSE_SOCIOEMOTION_2009.md)｜[Bickmore](../../../library/themes/game-npc-social/papers/RELATIONAL_AGENTS_2005.md)

**本矿区推断：** 值得探索的关系变化不仅是积累积极经历，还包括误会被澄清、道歉是否针对真正伤害、尊重与亲近分离、长期关系对一次冲突的容纳，以及角色更自主后与玩家重新协商相处方式。暂不把这些推断说成已存在统一任务或公认正确答案。

## 3. 玩家与创作价值：证据与限制并列

| 已读证据 | 它确实支持什么 | 它没有证明什么 |
|---|---|---|
| Bopp等CHI PLAY2019：213份角色回忆，114PC、86NPC、13两者 | 依恋可包含能力、对手尊重、楷模、保护、认同、友谊等；功能与情感价值相连 | 七种形式不是验证过的七维量表；没有比较生成NPC，也非纵向追踪 |
| Burgess与Jones2020：4个Tali/Garrus粉丝帖子、70,023条回复 | 玩家为关系意义安排队伍、选择场景、补写角色生活，且区分真人—NPC与玩家角色—NPC | 回复不是独立人数；强粉丝/恋爱对象选择不能代表所有玩家 |
| Bickmore与Picard2005：101人开始，89完成30天，84随访 | 历史、关系谈话与多模态脚本能改变部分关系感受和继续互动意愿 | 是运动教练；关系条件没有总体行为优势，也没有确证实际留存 |
| Chain-of-Emotion2024：30人、每人3种8轮对话 | 自由语言下的情绪评价可以影响短时角色体验 | 单一分手情境、GPT-3.5；并非长期关系或商业强基线结论 |
| Appraisal Engines2016：13名开发者先导调查 | 情绪作者工具有兴趣，也有素材、设计与测试复杂度压力 | 开发者对玩家需求的估计不等于玩家需求调查，也非2026产业采样 |

来源：[Bopp](../../../library/themes/game-npc-social/papers/CHARACTER_ATTACHMENT_2019.md)、[Burgess/Jones](../../../library/themes/game-npc-social/papers/NPC_ATTACHMENT_MASS_EFFECT_2020.md)、[Bickmore](../../../library/themes/game-npc-social/papers/RELATIONAL_AGENTS_2005.md)、[Chain](../../../library/themes/game-npc-social/papers/CHAIN_EMOTION_2024.md)、[Appraisal Engines](../../../library/themes/game-npc-social/papers/APPRAISAL_ENGINES_2016.md)。

这些材料足以说明问题有玩家意义，却不足以断言“动态情绪比作者写好的情绪弧更好”或“长期越亲密越好”。作者价值也不能从理论图推定：需要知道作者少写了什么、多控制了什么、哪些变化更好诊断，以及玩家是否仍识别得出作者想创造的人物。

## 4. 五个候选问题如何继续深化

### RQ1：人物对经历的解释能否成为可靠的情绪来由？

- **核心未知：** 新事件触发的改变，是因人物认知发生变化，还是最新一句话的情绪词直接驱动？当证据改变责任归因时，旧情绪与关系依据如何被重新理解？
- **已有能力：** 传统评价模型、完整历史LLM、自然语言评价已经处理部分情况；不默认需要新训练。
- **可能增量：** 发现可复现的解释失真结构；或给作者/角色明确保留事实来源、相互冲突的解释和变化理由，使合理重评更稳定。
- **反例：** 很多普通场景一次完整提示就足够。若弱模型失败、强模型无残差，应收缩方法主张。

### RQ2：带有表达意图的情绪怎样成为可理解表演？

- **核心未知：** 如何区分刻意克制、复杂情绪和无意的言行不一致；玩家需要读到什么线索，才能回应角色？
- **已有能力：** 剧本表演、社会表达过滤、声音/动画控制与现成生成模型；不能把新增语音或表情本身当贡献。
- **可能增量：** 明确情绪、交际姿态和表演线索的对应规律；允许跨模态有目的的不一致，同时保留人物和当前关系的可读性。
- **反例：** 更少、更明确的表现可能比持续情绪波动更适合某类游戏；内部状态变多也可能只造成嘈杂表演。

### RQ3：关系如何因经历受损、分化与修复？

- **核心未知：** 为什么某次冲突只造成短时愤怒，另一件事改变长期尊重或信任？道歉、新证据与后续相处分别解决什么？
- **已有能力：** 有向社会关系、权重更新、阈值、历史摘要、近因抑制；简单数值和自然语言历史是实质强基线。
- **可能增量：** 关系维度与因果经历的可解释关联；多个合理走向与明确人物边界；对玩家角色选择的有意义回应。
- **反例：** 用总好感度就能支撑目标玩法；或者关系修复只是在奖励礼貌提示和奉承。此时应重新界定问题。

### RQ4：情绪调节与成长如何保留角色身份？

- **核心未知：** 何时改变理解、目标、表达习惯或关系位置合乎人物；怎样支持成长而不是把一切偏离初始设定当错误？
- **已有能力：** EMA coping、FAtiMA的认知/情绪模块、DPC身份—状态区分、作者预写角色弧；每条谱系各有可用资产。
- **可能增量：** 对“合理改变”的创作与评价原则，或保留变化依据的过程表示。与B、C共用人物约束，但D关注改变的情绪与关系意义。
- **反例：** 玩家希望一个角色稳定可依赖；人物改变过快会破坏角色扮演。多样性和拟人程度都不是单调越高越好。

### RQ5：哪些关系变化在什么玩家活动中有价值？

- **核心未知：** 玩家扮演朋友、对手、导师、受保护者或旁观者时，所需要的变化是否不同？作者和玩家对这段关系的理解能否相容？
- **已有能力：** 游戏角色依恋类型、companion设计研究和关系型代理提供维度与反例；不能直接借帮助关系量表评所有NPC。
- **可能增量：** 解释何种互动变化支撑何种角色体验，以及作者控制/玩家参与的取舍；即使现成LLM足够，也可能有实质设计认识。
- **反例：** 短时觉得新鲜、长文本感动、喜欢形象或粉丝前置依恋，可能解释观察结果；需要与技术增量分清。

## 7. 后续阅读债与优先顺序

1. **理论效度：** 追到appraisal—emotion联系的系统性量化综述，进一步比较coping、emotion regulation、action readiness和非类别理论；当前2016书章不能代替全面理论综述。
2. **表演与多模态：** 优先真实交互中的情绪调节、掩饰、混合情绪、时机和声音—身体—话语协调；单段自动生成质量不是完整互动证据。
3. **关系成长与修复：** 寻找有真实共同经历、分歧、重新理解和跨会话变化的玩家研究；尤其补尊敬对手、导师关系、非亲密角色及主动疏离。
4. **纵向与差异：** 日历时间、回访、投入方式、玩家角色位置和文化背景分别记录；粉丝历史回忆不冒充前瞻纵向设计。
5. **未读的新材料：** 本轮下载但未精读的NeurIPS2024情绪决策研究、2026情绪传染预印本只列候选，不计正文完成，也不据其摘要给结论。

这些证据债用于决定下一批阅读，而不是声称必须先读尽整个领域才可以形成问题。下一步定位见[POSITIONING.md](POSITIONING.md)。

## 8. 2026-10-22研究入口更新

当前围绕“时间证据约束下的人物状态推断与适应”驻留。ArcANE是主要载体，PHASE-Tree/LongEvoRoleBench是独立任务与直接强近邻；C/NCP-Bench备选。先实测官方上下文与普通重写/总结的成功和残差，允许长期历史有帮助，不预设状态惯性。D1（状态/证据）、D2（仍有效与已修订历史）、D3（不同时间尺度）是相连的开放问题，不是提前打包的新算法。主方法与论文形态从实测长出。

## 2026-10-22持续实测中的问题收敛（非新主张）

D-E06初步基线显示，同一个给定目标下，当前/旧状态会改变恳求或威吓、尊重或约束等应对方式，但全句来源预测的作品均差只有约0.044 nats/token且区间含0。差异未必是动作对错：第一turn常允许多个合理开场，当前M/世界也提供旁路；有些生成甚至混合了说话主体。因此要把状态形成、状态消费、策略/表达与身份保持分别观察。已固定强消费者补充，不把通用8B的一例错说话人当新算法理由。

D-E07补强同信息普通人物状态整理；Monte源单元映射已实质纠正，旧六作品Summary差暂撤回。当前仍围绕“经历如何改变这个人物的信念/关系/应对，而哪些身份与表达应保留”，不退化为让一个NLL或一个PUF总分涨点。来源参考与真实可接受人物行为的区别继续保留。

### 续读后的对象校准

[DPC](../../../library/themes/game-npc-social/papers/DYNAMIC_PERSONA_COHERENCE_2026.md)重点是给定身份边界下的状态与表达；[BFI-Adapt](../../../library/themes/game-npc-social/papers/PERSONA_GROWTH_2026.md)重点是人生事件后的量表变化；[DREAM](../../../library/themes/game-npc-social/papers/DREAM_2026.md)已把事件、信念与后果联系起来。这些是有实质方法和测量的近邻，不能靠改名避开。

对当前角色对象，更直接的待解释关系是：**经历被怎样理解→当前相信/在乎什么→想对谁做什么→具体采取什么表达与行动。** 分开这些环节并不是新增框架主张，而是避免把上游描述分当下游能力。D-E06保留发布的当前动机，故只测状态组件在既有动机旁的作用；原生EvolvingWorld已有动机生成接口，值得先核对其真实输入和样本接续，再判断是否沿该接口研究自主意图形成。不会为了扩大差距删除人物已知事实，也不把每次情绪变化要求成稳定特质改变。
