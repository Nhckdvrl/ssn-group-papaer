# 矿区D：整体研究定位

更新：2026-10-22。响应用户“不要太局部现象优化，从整体方向考虑”。这是现有ACTIVE-MAIN内部的研究判断，不是新开线、定题或已验证算法。B/I01继续PAUSED，A继续CLOSED。此前进入性设计与定位历史可由Git追溯；实验事实保留在各卡及结果。

**用户进一步明确的研究尺度：** 不因相邻工作存在就不断收窄问题或拆掉贡献；要保证完整叙事有新颖性，并回答Role-playing Agent领域真正重要的问题。下文近邻表用于建立完整增量，不要求每个组件都史无前例，也不把它当作逐项排除研究空间的清单。

## 1. 当前判断：研究角色怎样从经历中改变后续互动

**优先研究：角色如何根据自身已有的理解、目标与关系，从新的经历中形成或修订判断，并把这种变化带到之后不同的互动中。** 核心产物应是有依据、有人物差异、能跨情境持续表现的变化。它可以表现为关系重新定位、接受帮助的方式变化、对证据的理解改变或目标调整；不以更友善、更理性、更配合玩家为统一终点。

这仍属于用户选择的动态角色成长与阶段一致性。ArcANE/PHASE-Tree提供必要底座，但科研问题不能由它们方便计算的分数反过来决定。角色在给定阶段会不会演、系统能否整理当前人物资料、角色怎样因经历而改变，是相连但不同的能力。

**对NPC的意义：** 玩家与角色共同经历的事情应当有后续意义；角色仍有自己的立场，玩家能理解其变化并作出回应。文学人物阶段表现可以帮助研究这个基础能力，不能直接等同已验证的玩家创造新成长。情绪、迟疑、拒绝方式和关系距离本身也可有角色价值，不强迫每次变化都改变游戏胜负。

## 2. 先分清“什么在变”，才能谈成长

| 变化对象 | 合理的研究单位 | 与成长的关系 |
|---|---|---|
| 当下情绪/情境反应 | 一次处境中的评价与应对 | 可以强烈变化，未必改变长期人格 |
| 已知事实与不确定信念 | 人物知道什么、相信谁及可信程度 | 新知识可能只修正一次判断，也可能触发更深变化 |
| 对特定人的关系期望 | 信任、尊重、依赖、界限与承诺 | 可持续改变，但不必扩张到所有人 |
| 跨情境解释/应对倾向 | 怎样看待帮助、冲突、失败或责任 | 经历后在新的相似处境出现有依据的变化，是较直接的成长对象 |
| 价值、目标与自我理解 | 人物为何追求或放弃某件事 | 允许改变，但不能由一条情绪标签替代其依据 |
| 表达和身份连续性 | 语言、节制方式、关切及自我位置 | 既非永远冻结，也非上述变化的自动副产品 |

CAPS把相对稳定的人格与跨处境行为差异相容起来；其发展讨论进一步区别情境激活与加工关系本身的改变。这为“变化前后看多个互动”提供理论动机，**不为虚构角色规定唯一心理答案**。[理论卡](../../../library/themes/game-npc-social/papers/CAPS_1995.md)

EMA/PsychSim已经让人物的目标、归因、应对和对他人的认识参与动态过程。因此，角色不能只被当作客观事实数据库：人物可能知道结果，却误解意图；可能相信对方，也仍因价值立场拒绝合作。纠正全部“非理性判断”可能破坏人物，而非改善人物。[EMA](../../../library/themes/game-npc-social/papers/EMA_2009.md)｜[PsychSim](../../../library/themes/game-npc-social/papers/PSYCHSIM_2005.md)

## 3. 当前测量怎样改变整体判断

- **阶段表演已经有实质能力。** D-E01同Arc条件，专用8B相对通用8B APF+12.12、PTF+22.56；现成后训练值得认真使用。不能继续把“角色无法改变”作为前提。[报告](results/D-E01-REPORT.md)
- **改好中间描述不等于改好整条人物轨迹。** D-E07/08的同信息人物整理，普通32B与Step都能产生有用资料，Step还修复明确的人物关系错误；专用8B的PTF却分别为67.37/68.72，对原摘要68.36没有明确总体增益。对应同一25完整probe/81phase/6作品，绝非大总体的成长成功率。[续测报告](results/D-CONTINUATION-REPORT-2026-10-22.md)
- **没有观察到跨系统一致的历史状态退化。** D-E06把29角色的8步更新接到后续表演，递归相对逐步教师前态的来源句NLL差在三个消费者中为−0.009、+0.027、+0.012。它们只衡量原作续写概率；强消费者会修复部分弱模型的说话主体问题，也存在具体策略差异。不能据此宣称普遍状态惯性或无成长问题。[连续案例](results/D-E06-CASEBOOK.md)

这些结果支持改变研究重心：**把“经历怎样改变后续人物行为”作为整体对象，状态整理是其中一个工具。** 它们尚未证明某种变化学习算法必要，也没有证明人物状态与行为天然脱节。

P03主体归属、P04撤回事实仍是应诚实保留的工程/测量观察。单独解决它们不足以回答角色成长问题。D-E09此前已启动的完整前缀参照按冻结预算完成或保留未完成状态；不沿窗口、字段、措辞继续展开D-E10式局部补丁链。

## 4. 现有工作的主张边界

|---|---|---|

**整体增量压力：** 动态树、事件图、关系覆盖、反思更新、阶段DPO均已存在。潜在贡献须体现在新学到的能力及其证据，不能仅靠模块排列或增加“causal / evidence-driven”等名称。近邻的存在用于调整增量，不构成自动关闭方向的理由。

**整体叙事如何成立：** 从角色为什么需要因经历而改变出发，明确现有训练/系统解决了哪部分，提出对完整适应能力有作用的学习目标和方法，再以多人物、多种后续互动及独立任务证明其作用。已有组件可以组成有效方法；是否新颖看这条问题—方法—证据链相对最近邻的整体增量。单个组件有先例不等于整条链已被覆盖，反过来仅将若干组件拼接也不能自动宣称创新。比较单位是同一主张、同一设定与相应证据，而非共享一个术语。

## 5. 最值得深入的学习问题

优先研究**人物特有的经历学习如何迁移到新的互动**。所学对象不是一张正确阶段卡，而是从已有经历与当前事件，到人物判断/关系/应对变化的过程；其价值由之后多个情境中的人物表现体现。

这里有两种“学习”，需要分开：模型训练学习可复用的更新与表演能力；虚构人物在一次运行中积累经历并改变自己的判断。后者完全可以通过上下文状态实现，不要求每次玩家互动都更新模型参数。

一个有意义的方法目标是：形成的状态既能解释当前变化，又支持之后未用于整理状态的不同互动；普通摘要、自然语言appraisal、现成更新模型都属于竞争方案。**用后续人物行为来约束状态学习**值得深入，但不是已经成立的新方法：预测状态表示、行为监督和端到端训练都有既有谱系，需要与EvolvingWorld多任务学习、ArcANE阶段偏好及PHASE条件化正面比较。

这种泛化有三个不同层次：**换人物/作品，换后续情境，换所经历的历史。** 前两项可较多利用公开原作与已有probe；第三项最接近玩家创造的新成长，却不能从同一原作的不同阶段自动推出。阶段索引可以帮助模型复现一条变化轨迹，但仅匹配这一条轨迹不足以辨认模型究竟学到了怎样的变化过程。这是任务结构的区别，不是已发现的模型作弊。

**经历包括角色自己的行动及其后果。** 人物如何预期别人、采取行动、理解对方的回应，再修订判断，构成比被动读取事件更完整的学习过程。TESSERA的短期过程—长期变化联系提供理论动机，EMA提供评价/应对谱系；它们不要求每次出现负面结果就改人格，也不能直接规定一个新RL奖励。[TESSERA选读](../../../library/themes/game-npc-social/papers/TESSERA_2017.md)

同样，人物的改变应允许影响“现在想做什么”，而非永远由外部输入给定当前目标、只比较怎样说出它。D-E06保留原生当前动机，适合测状态消费，却不足以测整个人物适应过程。后续主问题应覆盖动机形成与应对，**不是立即补跑一组删掉动机字段的消融**。EvolvingWorld已有动机学习，仍须作为正面参照。

方法建设可以与理解问题同步推进，不必等到所有强基线都失败才允许开始。最初可复用标准SFT/偏好学习；从完整人物过程提出可检验方案，并与现成系统一起实测其能力、代价和泛化。当前不命名新loss，不从某条错误台词反推一个复杂机制。

现有训练资产并不都在学习同一对象：Character-LLM从合成人生场景训练单角色；RAR/CRPO学习角色化推理和回复；ArcANE学习给定阶段表示下的表演；PHASE参数路线学习状态到adapter的条件化；EvolvingWorld将自然时间线拆成更新、动机、互动等七类SFT任务。**以完整经历及之后的多种互动组织学习**可在这些资产上建设，但不能只把它们串起来就声称新颖。需要具体说明共享学习到了什么、在怎样的迁移上超过已有训练。已有标准优化器完全可以成为新方法的一部分。[Character-LLM](../../../library/themes/game-npc-social/papers/CHARACTER_LLM_2023.md)｜[RAR](../../../library/themes/game-npc-social/papers/THINKING_IN_CHARACTER_2025.md)｜[CRPO](../../../library/themes/game-npc-social/papers/CRPO_2026.md)

**当前值得构建的整体方案轮廓（尚未实现/立为已验证idea）：** 将训练单位组织为人物已有经历、一次完整互动及结果、之后的多个行为情境；学习一个跨人物共享的适应过程，而非每个角色另训模型或给它预写结局。中间表示可以是自然语言，也可显式记录人物预期与关系判断；其取舍由之后的角色行为决定，而非只追求描述像教师卡片。公开人物更新、动机和互动监督可提供起点，ArcANE跨情境参考用于检验迁移，LongEvo提供对话任务的独立检验。三者各守自己的来源和评价，不拼成一个总分。新颖性要由这个完整学习问题、实现机制及跨任务证据共同建立，当前不预支它已经成立。

DualMem进一步给出可直接借鉴的路线：训练记忆构建器，并以固定角色消费者的回复质量评价整条构建轨迹。这不是我们要避开的组件；应把它纳入完整比较，检验它及其扩展如何支持**人物自身的变化过程**。它的主实验使用给定persona下的对话解释任务，SFT/RL角色质量4.15/4.16，也提醒我们先认真利用简单学习，不必为整体叙事强加新RL公式。[方法及实际公开情况](../../../library/themes/game-npc-social/papers/DUALMEM_ROLEMEMO_2026.md)

**第二个值得深入的内容方向是重新理解既有经历如何改变关系。** 它尤其贴合NPC：新信息可能改变对旧行为意图的判断，却不改变旧行为曾发生的事实；修复信任不必同步恢复亲近或消除愤怒。它可以成为上述学习问题的一个重要载体，而不是独立开一条“改摘要事实”的小线。尚未证明现有强系统在这类完整人物过程上存在稳定困难。

## 6. 公共资产支持到哪里

| 资产 | 可直接支撑的研究 | 仍需承担的加工/证据成本 |
|---|---|---|
| ArcANE人物弧、同probe多阶段反应 | 阶段行为与跨处境迁移的参考；角色专用模型参照 | 来源经历与参考解释的连接；不能把训练内部test当新作品测试 |
| EvolvingWorld相邻经历与人物更新/互动任务 | 学习事件到状态的现成监督，连续人物过程 | 标签可能用回顾性材料；要区分人物可知范围、目标及共享叙事；这不是已标好全部“成长类型”的数据 |
| LongEvoRoleBench/PHASE-Tree | 长程对话状态与下一轮表达；跨时间测试 | 同一对话的多种合理回应、更新机制和表达效应不能由一个分数分开 |
| MiniMax Role-play Benchmark | 95场景、3,135已发布模拟互动；人物设定、互动展开及多维评分 | 无phase成长金标，原用户模拟/细粒度评价实现未包含在六表；不等于真人玩家纵向研究 |
| 原著和发布的自然轨迹 | 有真实来源的完整人物变化过程 | 一条原作轨迹没有提供同一人物经历另一组玩家行动后的唯一心理真值 |

资源足以开始学习和正式比较，无需重新招募一批原创人物作者。但要声称**玩家创造的新成长**，仍需有来源和允许多解的不同经历/互动证据；现有原作轨迹不能自动提供这个因果结论。不能让同一教师同时编事件、写变化规则、给唯一正确行动，再把它作为独立证明。

这不意味着必须先解决每个人物的“唯一心理真值”，才能开展方法研究。现有阶段参考、原生后续互动与人物更新监督已经允许研究有依据的角色适应和预测泛化；它们是明确任务下的参照，允许合理表演不止一种。**整体问题保持宽度，证据范围限制当前能证明的部分，不把最终问题改写成一个窄小的可评分字段。** 面向实际玩家共同成长的证据可以继续建设，而不是拿其尚未齐备来阻断已有资产上的学习研究。

这些资产的用途互补：文学/人物弧提供经历与阶段参照，EvolvingWorld提供学习过程的原生监督，LongEvo与MiniMax提供持续对话/互动视角。它们支持同一个完整问题的不同证据部分，不要求每篇论文同时铺满全部数据，也不把原始分数混成一个成长总分。[资源与baseline登记](BASELINES.md)

EW来源审阅补充：发布训练文件内部的状态接续可复查，但不同文件的同号场景不必相同，部分发布叙事顺序也不能直接当原著时间。共享索引连接的是来源记录，尚未认证全部链接是合法时序成长监督。后续学习要按来源资格使用，不能只因数据规模大就跳过这个含义；该基础限定不改变整体研究目标，也不派生一条数据修补论文。[资格说明](results/D-EW-SOURCE-QUALIFICATION-2026-10-22.md)

## 7. 接下来研究动作的选择标准

主工作从逐个异常补对照，转为理解完整人物变化：比较现有方法怎样表征和学习变化、公开轨迹究竟提供什么监督、哪些变化会影响后续多个互动。优先投入能决定上述学习问题是否成立的材料与方法阅读，现有测量作为基础证据收尾。

后续实验需要回答一个整体问题：**在足够的合法经历输入下，模型能否获得可迁移的人物变化能力，什么学习信号带来超过普通强系统的改进？** 其主体应覆盖多作品、多人物与有/无持久变化的完整过程。信息来源、预算和评价多解是解释结果的必要条件；不将补齐这些控制本身当作科研创新。

如果强普通系统已能可靠支持这项能力，结论就是相应方法空间有限，进一步研究其适用条件或有证据的新问题。若存在持续、角色相关且影响多种互动的困难，再把方法投入集中到相应过程；不为了保留方法故事制造干扰、换弱模型或无限细分失败。

强基线的成功也能成为建设资源：提供可靠教师、可复用人物过程或能力上界。若学习方法能把这种能力迁移给新人物/新经历，或在明显更低的持续推理成本下保留它，同样可能形成完整贡献。是否成立由实际迁移与代价证据决定，不能把“强模型能做”自动转换成“整个问题不值得做”，也不能把普通蒸馏的预期效果提前叫创新。

**当前结论强度：** 这是有文献与实测约束的研究优先级判断，不是新能力缺陷或方法有效性主张。没有因此升级CLAIMS，也没有改变工作台状态。
