# 矿区 D：定位、强参照与未来进入性研究

2026-10-19。**用户授权，矿区已建立；问题与文献建设；未进入实验立项，没有 ACTIVE 分配。** 所有设计均为未运行方案，不构成实验启动、API授权、招募计划执行或研究状态升级。

## 1. 当前独立判断

**值得继续深入这片问题，但现有阅读不足以支持承诺某个新的情绪架构。** 情绪与关系对角色扮演有充分相关性；“什么变化有意义、怎样被理解”还不能从状态轨迹或LLM裁判分数推出。强模型完整历史、简单自然语言评价及成熟关系系统可能解决相当一部分场景，应把它们作为进入研究时的正面压力。

这一判断来自不同证据的合看：游戏依恋材料记录丰富关系意义；脚本代理已经能在一个月交互中产生关系感受；Chain-of-Emotion显示简单结构的短时效果；CPM强主干的增量很小且集中于理由；CoRE提醒我们不要用过度确定的情绪分类消去合理差异。[依恋](../../../library/themes/game-npc-social/papers/CHARACTER_ATTACHMENT_2019.md)｜[Bickmore](../../../library/themes/game-npc-social/papers/RELATIONAL_AGENTS_2005.md)｜[Chain](../../../library/themes/game-npc-social/papers/CHAIN_EMOTION_2024.md)｜[CPM](../../../library/themes/game-npc-social/papers/CPM_MULTIAGENT_2026.md)｜[CoRE](../../../library/themes/game-npc-social/papers/CORE_EMOTION_CONCEPTS_2026.md)

## 2. 最值得先问的问题

> **当共同经历或关于它的新证据改变时，NPC怎样调整对人物与关系的理解，才能既保留可辨认的角色，又给玩家一种可理解、可回应的变化？**

这有合适的问题宽度：它能覆盖误解、失望、尊重、原谅、界限和成长，又可以在少量完整互动中先检验；不需要先建完整社会世界，也不应退化成判断一句话应使好感加几分。

例如“朋友仍然愤怒但恢复了信任”包含几个可以分别失真的部分：事件被如何解释、是否知道对方的意图、过去关系的分量、情绪与长期判断是否分开、表达是否让玩家看懂。最后一部分既可能由行为承载，也可能由一句克制但有依据的回应承载。**不以必须修改任务胜负来排除情感表演价值。**

## 3. 哪些贡献形态可能成立

| 形态 | 有价值的增量 | 当前尚缺的证据 |
|---|---|---|
| 新认识 | 哪些关系变化使玩家更能扮演自己的角色；哪些合理变化反而损害人物可读性 | 实际玩家活动、不同关系形式、对替代解释的检查 |
| 失败结构与测量 | 普通强系统在哪些事件理解、重评、关系维度或表达步骤稳定失真 | 同信息强基线、独立角色/情境、多种可接受解释 |
| 表示/控制方法 | 保留共同经历及解释来源，让短期情绪、持续关系与表演选择有可核查联系 | 同模型/同预算增量、表示的实际因果作用、作者与玩家受益 |
| 创作方法 | 作者可以设定角色的情绪逻辑、变化空间和边界，处理未枚举的互动 | 真实创作任务、编辑成本、调试错误和作品差异 |

单独增加数字状态、情绪词汇、更多代理、自我解释步骤或“心理理论”命名都不足以构成上述贡献。相反，若现成强模型已足够好，仍可能形成有价值的玩家/创作认识；此时应如实改变论文形态，不以弱化基线维持方法叙述。

## 4. 必须认真对待的普通强系统

以下是**未来比较参照，不是本轮调用或复现实验记录**。模型应选研究实际开展时可核查的强商业档位；不能拿今天读到的旧型号名称代替当时的选择。

| 参照 | 应得到的信息和能力 | 它检验什么 |
|---|---|---|
| 精心制作的脚本/有限状态关系系统 | 有向关系、情绪来源、衰减、表达控制、完整事件输入；配同质量语言/表演输出 | 目标玩法是否本来就适合简单、可靠、可创作的系统 |
| 强商业LLM＋完整历史 | 人物、已知世界事实、共同经历、重要关系、当前事件、允许变化的边界；普通检索/摘要与工具反馈 | 是否主要只是信息缺失、上下文压缩或弱模型能力问题 |
| 同模型＋自然语言appraisal | 在上述信息上，简短解释人物怎样理解事件及其情绪/关系，再回复；保留历史 | Chain-of-Emotion式普通两步是否已足够 |
| 同模型＋单体CPM及普通复核 | 同样角色历史与状态，合理CPM提示、普通重评/重规划；预算配平 | 复杂分工相对普通结构化推理还有多少增量 |
| 完整CPM或其他最近邻 | 只有在复现范围、上下文与输出目标能对齐时纳入 | 新方法是否超过真正相近的研究，而非只超过简陋提示 |

经典数值系统需要作者提供事件语义；如果新方法同时增加更丰富事件事实，效果不能归给状态结构。完整历史与摘要两种条件也要分开，否则“关系状态有用”可能只是因为给了它更短、更清楚的记忆。

候选法只有在明确残差后才需要设计。可考虑给重要关系判断保留依据，区分事实与猜测、短期情绪与持续判断、内部感受与表达意图；也可让作者约束角色可变部分。**这些均为候选机制，不是已实现系统。**

## 5. 未来一轮高信息量研究：先同时检验残差与玩家意义

### 5.1 本轮要回答的决策

一轮应当回答：在信息充分的强系统下，是否仍存在人物/关系变化的可复现困难；它是否让玩家或作者损失了有价值的能力；最简单的补充是否已能解决。不要先定义几十项分数，再从其中寻找一个可改善的局部。

**此处只写设计，没有生成场景、调用模型、创建招募、运行引擎或收集数据。** 具体人群、规模、效应大小、分析和材料须在研究启动前，围绕上述决策确定；当前不伪造样本量计算或统计功效。

### 5.2 情境来源和独立性

建议由熟悉角色写作/角色扮演的人独立提出若干完整相遇，而非把一个物品任务换皮。候选关系包括：被误解的骄傲同伴、逐渐独立的被保护者、获得尊重但仍敌对的对手、受伤后愿意继续相处的旧友。它们是**材料范围建议**，不是现成benchmark或四个已完成场景。

每个关系需要有角色自己在乎的事、它实际知道的事实、至少一段共同经历、当前变化以及足够自然的后续互动机会。分清独立作者、独立角色/关系、独立因果情境、事实的对照变化和同义改写；对话轮数、采样次数不能增加独立场景数。

相邻情境只改变一个有意义因素，例如“有意羞辱/不知情造成伤害”“指控得到证实/获得反证”“首次冲突/同类冲突反复发生”。这样才能检查新证据和历史分量，而非观察所有人物一律更易生气。

### 5.3 两条相连的观察

**机制观察：** 用同样已知事实和历史比较脚本状态、强LLM完整历史、简单自然语言评价、单体CPM。若尚无明确候选机制，无需为了实验形式硬加一种“我们的方法”。让独立评审者首先记录哪些情绪/关系走向可接受、哪些违反人物与事实，以及依据是什么；保留分歧，不要求唯一黄金情绪向量。

对于显式状态，额外诊断要问它是否改变了最终表达、应对或关系选择。若交换/移除某个状态表示后表现不变，需要分辨它被历史重新推断、属于冗余摘要，还是确实没有作用；**不能仅凭“改状态没效果”就判情绪无价值。** 对声称有因果作用的模块，须把其他可用信息与表达质量一并控制。

**体验观察：** 在未来获得相应执行安排后，让真实玩家以明确但不强迫唯一风格的角色参与，观察他们是否识别变化依据、如何回应、能否形成想要的关系体验。玩家觉得NPC更喜欢自己，和玩家觉得这段冲突更有意义，是不同结果。作者也要能指出变化是否仍属于其人物，并检验修订控制是否实用。

短时研究可以检验初步可读性、角色扮演选择与变化意义；不能因此声称长期信任、依恋、成长或留存已改善。跨会话或日历时间的研究，只有在首轮发现有价值的具体机制/体验后再设计；本文件不启动长期招募。

### 5.4 评价应分层，而非合并为单一“情绪智能分”

| 观察 | 需要知道的具体内容 | 要排除的替代解释 |
|---|---|---|
| 事实与人物依据 | 情绪来由是否用对已知信息、目标和历史，重评是否有新依据 | 模型被额外泄露世界真相；最新情绪词覆盖历史 |
| 关系变化 | 短时心情与持续态度是否区分，是否对不同关系给出合理走向 | 总好感度、奉承奖励、固定积极情绪终点 |
| 表演 | 语言、时机、姿态和互动回应是否传达预期的人物变化 | 更长、更文学化、更高质量TTS造成的偏好 |
| 玩家角色扮演 | 玩家能否解释自己的影响、作出有意义回应，体验是否符合其角色 | 人格好恶、粉丝前史、初次新鲜感、任务难度变化 |
| 作者控制 | 作者能否预测/修正人物逻辑，变化空间是否清楚 | 每个情境都需手工补丁，成本只是转移到提示 |
| 实际使用条件 | 等待、打断、重复、失败修复与会话负担 | 使用时间更长仅因等待或任务被情绪门槛拖慢 |

对多模态先固定或配平实现质量，再针对表达问题做相应比较；不同时改变声音、动画、历史、模型和交互规则后把所有收益归给“情绪”。对差异较小的结果报告分布、不确定性与评价者差异，不以平均数小数点后的领先作强结论。

## 6. 负结果如何真正改变判断

| 结果 | 应改变的认识/下一步 |
|---|---|
| 完整历史强LLM已可靠、玩家无额外困难 | 当前方法必要性低；转向有实质问题的创作/体验研究，或另找未解决情境；不降低基线 |
| 简单自然语言评价或脚本即可解决 | 接受简单方案，研究适用边界；不为包装新机制扩大系统 |
| 只有状态/理由分提高，实际表演和玩家解释无变化 | 不能声称NPC体验增量；检查度量是否抓错对象、状态是否只是冗余解释 |
| 玩家偏好更稳定、更可预期的人物 | 缩小变化空间、明确互动形式；不把其偏好当“不懂开放性” |
| 复杂状态帮助角色扮演，却使作者难以控制 | 这是实际取舍，可能应转向作者控制或更简单关系表示 |
| 不同评审者对合理情绪持续分歧 | 先研究构念、角色背景与关系形式，保留多解；不要无限调裁判提示 |
| 仅长文本、更好声音或更长等待解释偏好 | 无法归因于情绪机制；结论改为表现/资源效应 |
| 悲伤、疏离或冲突增加，但玩家认为有意义 | 不直接记为失败；按既定关系意图与玩家活动解释，避免正向情绪目标错置 |

这些是对证据的预期解释，不是自动终止或激活矿区的流程。研究状态仍由用户与后续具体决策决定。
