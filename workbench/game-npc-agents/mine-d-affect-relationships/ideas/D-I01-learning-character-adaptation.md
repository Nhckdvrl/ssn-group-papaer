# D-I01：学习人物如何从经历改变后续互动（2026-10-22）

- **状态：** SEED。是矿区D内的可执行方法候选，不是新开工作台、已成立主张或最终锁定论文题目。
- **来源：** D-E01的强阶段表演成功；D-E07/08的事实修复没有转成明确轨迹增益；D-E06中消费者对同一状态有不同反应；EvolvingWorld、ArcANE、PHASE-Tree与DualMem对学习对象的不同选择。不是把P03/P04的小错误改名为新问题。
- **研究动作：** 成功案例解剖；改变学习对象；设计空间分解。把强角色演员当成可复用行为基础，将研究对象从描述某个阶段推进到学习人物的适应过程。
- **如果为真，主张是：** 用经历之后多种人物判断、动机与应对来训练状态更新，能够学到跨人物、跨处境可用的适应过程；其效果应超过同数据的原生更新SFT、普通总结与直接角色行为训练。这是待检验假说，不能从现有读数直接推出。

## 问题与完整方法候选

角色已经有自己的信念、目标、关系和表达习惯。新经历包括他做了什么、看到什么结果，以及他怎样理解他人的回应。我们要学习的是这些经历怎样改变之后的理解和行动；合理结果也可能是维持原有判断、继续误解、失望或疏远，不能统一奖励友善与服从。

记当前人物状态为 `s_t`，已经发生且角色可见的经历为 `e_t`，之后的新互动为 `x`。更新器产生 `s_{t+1} = U(s_t, e_t)`；演员以该状态产生新的动机和回复。更新器在运行时不预先知道 `x`。状态既参与下一次表演，也参与理解下一段经历，形成持续适应，而非一次性换阶段标签。

**首个实现选择：自然语言状态、固定强演员、学习更新器。** 这样可以复用ArcANE/Qwen演员，并直接检查学到的状态能否被另一个演员使用。表示先沿用现有资料，不先发明人物树、固定心理维度或新损失函数。自然语言状态不是唯一终点；选择它是为了先建立可检查的学习过程。

学习分两种现成信号：

1. **状态示范。** 用公开的“更新前人物＋完整经历→更新后人物”监督做普通SFT。先建立认真训练的直接基线，不把零样本提示当唯一对手。
2. **后续行为约束。** 同一经历生成的状态，供固定演员在多个后续互动中使用。以参考动机、行动及表达的适合程度选择状态示范或偏好对，再用标准SFT/DPO学习更新器。写状态时不提供未来问题；训练时未来行为可以作为监督，推理时不能作为输入。

关键不是多出一个评委，而是**一个更新必须支持不止一种后续行为，且继续成为下一次经历解释的前态**。如果只对一个已知问题优化记忆，就可能得到答案缓存；若仅逐字模仿阶段描述，可能只学会老师的写法。两种风险都须通过未参与状态选择的后续互动检验，不能仅靠训练奖励宣布解决。

行为监督先区分三种来源：原生后续互动是一个有来源的实现；ArcANE反应是发布的阶段参考；强教师输出是蒸馏目标。三者均不等于唯一心理真值。不能把教师创造的问题与答案同时用作独立验证，更不能在看到原作后续后声称在线预测。

## 相比直接近邻，完整贡献需要成立在哪里

| 近邻 | 已有主张 / 可复用基础 | 本候选应增加的证据 |
|---|---|---|
| EvolvingWorld | 人物更新、动机、互动的多任务SFT及世界联动 | 以更新后的多种行为反过来学习适应过程；在新作品与独立角色任务中有增益，超过相同数据的多任务SFT |
| ArcANE | 给定人物弧的跨阶段表演与角色后训练 | 从经历学习状态，而非得到整理好的弧；同时检验其对未见互动的作用 |
| PHASE-Tree | 多时间尺度状态与阻力门、文本/参数条件化 | 学习更新过程在人物变化内容与持续性上的作用；与已有状态维护正面比较 |
| DualMem | 给定persona的事实/解释记忆；下游角色质量训练整条记忆轨迹 | 当前人物自身也随经历改变，新的自我状态再参与后续解释；须有动态人物迁移证据，不能将下游反馈训练记忆称首次提出 |

**Compression risk：** 若最终只是“用角色评分给摘要做DPO”，上述整体增量尚未成立。避免这一点靠完整的学习对象与跨互动证据，不靠新缩写。相邻工作提供直接强基线，不据此缩小角色成长问题或自动关题。

## 数据与可实现范围

现有EW发布训练文件提供24,977次原生更新，可直接作单步示范。已有索引连接22,306个同人物后继出场，但它们是发布顺序，原著时序未全部认证。新[数据接口](../data/README.md)将更新输入、监督和后续任务引用分开，整部作品归同一划分；沿用真实记录，不重新造故事。

同场景互动发生在场景末更新之前，不能作为该更新的未来效果。后继出场也须核验前后态连接；该连接认证发布资料内部一致性，不能替代真实时间或人物可知范围认证。第一阶段可学习给定前态的组件能力；连续成长结论仍要由合格完整轨迹和独立ArcANE/LongEvo任务支持。

持久态并不替代全部情境。后续新情境事实、交互对象和当前可见对话仍交给演员；若每次直接塞入参考当前动机，就只能测表演，不能同时声称学会目标形成。完整方法的演员应自己形成动机，教师动机只在监督侧使用。

## 最便宜且有意义的决定性pilot

**2026-10-22续：** [D-E10](../experiments/D-E10-trained-character-adaptation-baselines.md)已经登记并实际运行直接强基线训练及后续互动评价。先把原生更新SFT、多任务SFT、强普通系统真正测完；本候选的行为约束更新学习尚未训练或验证。不把训练启动称为方法pilot成功。

固定Qwen3-8B更新器底座、同一训练作品/数据额度、同一强角色消费者，比较：原生更新SFT、更新/动机/互动多任务SFT、行为约束的更新学习。普通Qwen3-32B总结与合法完整经历作为强普通系统；ArcANE演员替换用于验证状态能否跨消费者使用。多任务SFT用于辨别收益是否只是增加行为训练数据。

主要结果看未参与训练的作品与未参与状态选择的互动：阶段行为/轨迹、后续动机和应对、表达连续性，以及更新/消费成本。原生文本NLL仅作辅助，不将下一句更像原著当作成长正确。作品为主要独立单位；已读过模型输出的作品保留开发诊断身份。

- **阳性对照：** 已发布当前状态能支持相应行为；同一演员在完整合法经历下具备所需能力。若行为无法被输入状态影响，该样本不能证明更新器学习有效。
- **噪声地板与MIE：** 模型卡登记时按同一作品配对、重复生成及评委重评分估计；本卡不杜撰一个已测阈值。决定性比较必须能区分整体迁移收益，而非一两个病例修复。
- **一句恢复：** 提示性诊断仍包含普通“按已发生经历更新，并将变化用于之后互动”的对照。它若恢复全部效果，应计为普通强方法成功。

| 实际结果 | 更新研究判断与下一步 |
|---|---|
| 行为约束的更新在新作品、多互动和独立消费者均改善，且预算优势明确 | 推进适应过程的学习方法；再检验连续经历与关系重评 |
| 原生SFT/多任务SFT同样有效 | 使用更简单学习方法；研究可迁移适应能力的来源和范围，不保住一个无增益模块 |
| 只有训练演员或已用于选择的互动上涨 | 尚是局部迎合；先改训练目标/泛化设计，不将其包装为人物成长 |
| 强普通系统已很好，训练只提高运行效率 | 可以研究能力压缩与持续使用成本，但须有实质成本—能力证据 |
| 当前监督无法区分合理变化 | 保留可验证的行为与来源结果；利用另一现成任务补足证据，不强造唯一心理标签 |

**预期形态：** 学习方法＋角色适应任务上的系统实证；不以字段纠错或单一benchmark消融为主贡献。

**当前排序判断：** 来源证据2／增量清楚度2／形态匹配3／成本2／可完成性2／不同结果信息增益3（1–3，仅研究优先级）。未升CLAIMS；没有提前判定新算法必要或有效。
