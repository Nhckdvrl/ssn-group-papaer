# D-I02：经历干预下的人物适应——同一人物经历不同，之后是否以自己的方式不同（2026-10-23）

- **状态：** SEED，未执行的问题/设计草稿。2026-10-24整理时收纳工作区已有草稿并校对来源；[整体审计](../RESEARCH_AUDIT.md)已完成，但本卡没有模型运行或已验证主张，后续须按用户研究决定另行登记实验。
- **来源：** D-E10信息通路审计（质量均分无法识别经历作用）；D-E13校准（参考可辨、空对照稳，真实演员回复换序不稳）；ArcANE自己的ArcHint消融仅在部分普通模型接近完整Arc，专用32B-DPO仍有差距。P03/P04仅作线索，不作统一机制证据。现有测量尚未只改变经历本身；D-E11已生成分叉经历，但它是角色/世界/采样共同造成的内生变化。
- **研究动作：** 改变干预变量（从“换状态/换训练配方”改为“换经历”）；把阳性对照前置为仪器资格。
- **如果为真，主张是：** 给出合格的经历分支后，可以分别测量角色后续行为是否依赖经历、方向是否合乎该人物、应保持的方面是否保持、变化是否延续；并据此判断现有状态表示/更新/训练在哪一环丢失或扭曲了经历作用。

## 研究对象与问题

对象是“人物原有立场 → 本人可知的经历及后果 → 自己的解读与目标/关系变化或合理保持 → 不同后续处境中的行为与延续”这一整条链。问题：**同一人物、同一前史、同一后续处境，只改变一段经历时，他之后的行为会不会相应地、以他自己的方式不同？**

读数分开，不合成一个分：

1. **依赖：** 两个经历分支下的后续行为是否可靠地不同。
2. **方向：** 差异是否落在各分支事前登记的合理行为范围内；允许多解，不设唯一金标。
3. **保持：** 每个案例事前说明哪些方面应保持（身份、与经历无关的关系、表达习惯）；不把“无关探针回到50%”当普遍真值，经历可以合理影响更广的情绪与期待。
4. **延续：** 经过后续更新、压缩或多次互动后，上述依赖与方向是否仍在。
5. **人物特异性（后续）：** 先在同一人物的经历分支上建立可靠读数，再研究不同人物对相近经历的差异；同场景不同人物信息、关系、行动位置不同，不当作干净交互。

## 采纳的审计修正（2026-10-23，RESEARCH_AUDIT）

- D-E10的frozen保留上一场景互动，没有切断经历通道；released同时换了状态和动机。质量差小**不能**解读为“正确状态无用”或“没有学习信号”，只能说该质量均分不是经历依赖的读数。
- D-E11的经历确实分叉，但是角色、世界、采样共同生成的内生分叉，不是受控干预。
- ArcHint是ArcANE的消融，不是我们的对照；语义轴名与阶段标签本身带信息，不能直接证明背原著。
- 成对匹配混合了区分度与方向；系统性配反也有行为差异；D-E13显示长回复判别受位置影响，配对分数不能直接作训练奖励。
- Troy手表的另一结果需要构造并核对，是最小编辑而非已观测的自然分支；事实是否记对与人物怎样因此改变是两个层次。

## 设计约束

- **经历分支：** 在公开来源场景上做可核查的最小编辑（结果、对方回应或角色自身行动的后果），保留其余前史，并检查必要的后果是否一致。编辑理由与来源须保存；若后续确需商业模型，仍遵守[原资源授权](../../AGENTS.md)的Plan与实验预算限制。本草稿不触发API或新数据生成。
- **后续处境：** 必须对两个分支都成立，不预设任一结果；不能继续使用已受原作经历影响的原生动机/人物自身对白再把作用抵消，也不为放大差异删掉角色本可获得的合法信息。
- **读数：** 单条回复对照事前说明的合理范围，并检查后续反应性质；独立判断不能保证自动消除偏差。同分支重复用于估计自然生成差异，不要求每对文字都不可分；相同回复空对照只检查硬猜。不能仅凭提及经历或更换心理形容词判适应成功。
- **系统候选库：** 完整历史、普通摘要、未训练更新器、已有U-SFT/两MT适配器、Qwen3-32B与ArcANE演员。实际最小比较由问题与新实验卡确定，不默认全部铺开；现有模型直接复用，不先追加训练。

## 不同结果各带来什么信息

- **完整经历下依赖与方向都可靠，压缩/更新后丢失** → 问题落在状态该保留什么；D-I01的学习获得有效信号（状态须保留使两分支行为可区分且方向正确的内容）。
- **完整经历下也不依赖或方向趋同** → 先分清信息充分性、后续处境是否能显露相关差异、合理保持及测量局限，不能直接坐实模型只演先验；有相应证据后再讨论解释/表演学习。
- **阳性对照或自然波动无法合理区分** → 不据该读数作能力排序或训练奖励；重审问题与测量，不反复调judge，也不自动关闭矿区。
- **只有表达层可辨** → 只报告表达变化，不包装成决策或关系变化。
