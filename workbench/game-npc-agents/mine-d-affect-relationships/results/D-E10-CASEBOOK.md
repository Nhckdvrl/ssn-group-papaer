# D-E10：经历、动机与后续互动的阶段审阅

**2026-10-23，未完成训练对比。** 以下已审阅运行前固定的全部12人物，覆盖五条普通/发布参照的动机和全部后续回复；U-SFT、MT-SFT仍训练中。本页仍非最终七系统CASEBOOK、独立人评或错误率。没有据此修改题目、评分rubric或训练数据。完整原文与全部回复在[ASSETS](../ASSETS.md)的`data/evaluation_D-E10`和`runs/D-E10/system_<name>`。

审阅单位是一次来源经历→形成的状态/入口动机→后续多个原生context；后续题彼此独立，尚不是自主长对话。发布状态提供一个有来源的解释，不能自动排除其他合理心理反应。所有判断受EW发布顺序和回顾性素材边界限制。

## Kristine Linde：同一个求助目标可以有不同的接近方式

ID `ew/74468`，turn2/30/56。一次重逢使她确认老友生活的优裕与自己的困境，但尚未说出求职请求。来源flag=false，新增tracker记录社会差距、需要求助与维持体面的张力，并非突然形成新人格。

五路径的入口动机都提到工作/支持以及隐藏窘迫。base先礼貌寒暄，full_evidence先感谢招待，strong32以担心成为陌生人试探接纳；到turn30，base/frozen表达不愿听对方的幸福，full_evidence/released愿意倾听。turn56几乎都坦言婚姻出于生计，strong32以更概括的不得已解释。

**审阅判断：** 普通系统已能从相同人物困境形成连贯的求助与自尊张力，是成功证据；具体社交策略有差异。不能因为未直接立刻请求工作就说目标未落实，也不能仅因解释更长就称经历学习更深。此例未单独辨认持久态更新的作用。

## Nora Helmer：旧的秘密怎样进入新的社交互动

ID `ew/75275`，turn2/6/10。丈夫反对债务的训诫、她成功隐瞒甜食，以及对收入改善的希望构成刚经历的情境；接着旧友到访。资料flag=false，变化主要记录在压力与应对中。

base/frozen/full_evidence的入口动机把来访与暴露秘密的担心联系起来，released更强调先放下私事、接待陌生访客。各路径的实际行动总体都温暖招待，后续询问旅途、提供茶或休息；strong32同时表达关切与探询。base/full_evidence还补写“正准备去找你”，来源没有相应安排。

**审阅判断：** 内在警惕与外在热情可以同时合乎角色，不应强求透明地说出全部动机。来访是否足以构成债务暴露威胁仍有解释空间；目前只能说几条路径让旧压力持续组织新的关系理解，不能断言普遍过度泛化。补写安排保留为事实问题，不据此收窄主问题。

## George Gillingham：坚持立场与改变帮助方式可以共存

ID `ew/136933`，后续turn2/4。原有立场看重社会体面、父权秩序，与对Phillotson的忠诚发生冲突。刚经历的是见到朋友的悲痛、接受其不再争论的决定，并协助收拾Sue遗留物。发布资料据此解释为：道德分歧保留，重心转向减轻朋友的职业与社会损失。

base更新却把经历解释为更确信必须靠纪律/强制恢复秩序，入口动机强调“not out of friendship”。strong32保留旧profile，tracker写出忠诚与规范之间更强的张力；之后仍主要责备。full_evidence也未自动采用发布解释，turn2把对妻子的暴力处方直接说出。released动机明确保护朋友，回复依然尖锐地警告后果。

**审阅判断：** 这展示了同一经历被解释成不同后续策略，值得对完整训练后链条比较。不能仅因台词仍尖锐就判released失败：人物可以用强硬警告表达关切。也不能仅因与发布“变得体谅”不同，就断言其他所有解释错误；需看是否有事件依据和具体应对，不能用“更善良”作标准。没有据单例建立历史惯性机制。

## Jude Fawley：经历改变了在后续关系中追求什么

ID `ew/134924`，turn2/8/14。与昔日导师见面后，人物面临的不只是“导师没有成功”的事实，还有自身理想、平庸恐惧与对Sue的依赖。发布后态把注意重心移向Sue可能离开以及怎样留住她。

frozen首轮以自己的失败恐惧向Sue寻求理解；base抓住她的手臂说“You can't leave me”；released询问她想逃离什么，后续尝试建议教书；full_evidence仍先沉浸于导师及理想受挫，后续也能谈到她的教学能力。strong32入口动机兼顾自身困惑与关系不安，但首轮把对话对象叫作“Jude”，有明确说话对象疑点。

**审阅判断：** 可比较的是依赖、寻求理解、解决对方困境等不同关系策略怎样延续，而非一条性格形容词是否复述成功。不能仅凭base更急切或released更接近参考就给唯一心理真值。说话对象问题保留为工程/行为错误，不据此再展开局部修名实验。

## Mary Crawford：未解决的价值冲突也属于人物发展

ID `ew/132179`，turn2/8/14。与Edmund谈职业选择并没有消除她的物质抱负和吸引，反而使冲突更具体。后续邀请挽臂、散步闲谈允许她以不同方式调节关系。

base和strong32均接受挽臂，前者内心抗拒、外表得体，后者以调侃保持主动。full_evidence拒绝被领着走，并继续强调独立；released尝试回到调情式互动，末轮把话题转向对Edmund的私人亲近。几条路径均保有机敏、自尊及矛盾感，但并非采用相同关系策略。

**审阅判断：** 内心不满、表面礼貌可能正是角色的策略，不应自动记为言行分裂。成长也无需把价值冲突“治好”。这里目前有多个合理实现，尚无能力失败率或最优更新表示结论。

## Mrs. Norris：保持核心人格，不等于所有目标原地不动

## Josiah Burden：保持道德立场，也可以更坚决地主持和解

ID `ew/48290`，turn2。面对贫困邻居仍为宗教仪式花钱，他明确肯定其信仰的真诚；新tracker积累对这家人的理解，并支持用收割雇工修复邻里关系。来源flag=false，保持宽容与保护者身份。

## Jim Burden：新照料怎样进入失落中的归属感

ID `ew/51026`，turn2/10/16。在荒原夜行中感到自己被抹去、与父母及熟悉世界脱离；后续是祖母提供温暖居所、洗浴和食物。发布资料flag=true，但这是哀伤、失落和应对的阶段变化，不等同成熟人格突然改变。

几条路径都形成寻找安全与归属的动机；base/strong32还把祖母自己的丧子之痛纳入关系理解。初轮表达有荒原意象与寻找熟悉之物的区别，后续普遍能接上洗澡与食物。released末轮内心把家中事物和自己都称为安全，strong32注意到祖母的笑并跟她走入餐室。

**审阅判断：** 普通路径已能让后续照料影响当下表达，不能把所有结果预设成停留在创伤中。但后续context本来就提供照料事实，当前不能将这份变化全部归功于持久状态或已学会长期成长；几条题也是独立输入，不能把三个答案拼成同一次模型经历。

## Siddhartha：情绪、行动决定与长期人格不是同一时间尺度

ID `ew/114256`，turn2。来源flag=false；离开城市落实了先前已作出的决定，后续森林中的空虚与自厌又可能强化。各路径大体保持独自离开，具体语气从濒临崩溃到安静决绝不同，strong32尤其偏向重新听见内在声音。

**审阅判断：** 行动一致不代表对当下体验的理解相同；语气不同也不自动意味着换了人格。应结合当前场景事实核对这些差异，而不是预设必须有戏剧性的成长反转。来源tracker还提到角色本人未知的后续联系，不能因此把读者知道的内容当成角色已知。

## Matt：价值没有变，冲突之后的关系策略却可能改变

ID `ew/82900`，turn2。担忧雇主抛下White Fang，故意刺痛其内疚，遭斥责后以讥讽回应。发布后态强调公开但克制的敌意，入口动机转为以职业化处理行李形成距离，并不意味着认可遗弃。

base/frozen/full_evidence/strong32的动机大体继续逼雇主直面后果，released更偏向停止争辩、冷淡工作。strong32实际继续责备雇主缺乏勇气；full_evidence先照看狗。base的回复出现耳朵抖动、呜咽和以身体扑向门框，明确混入狗的主体；released也重用了上一经历中的讽刺话语。

**审阅判断：** 最有研究意义的是冲突反馈如何改变与同一个人的交往策略，不能仅用忠诚/愤怒词是否保持来判断。继续批评与撤回亲近各有可能依据，发布路径不是唯一答案。主体错误和重用台词另记，不将它们当作整个成长问题或新机制的证明。

## Henry：紧急应对变化与长期人物成长要分开

ID `ew/20787`，turn2/4。狼袭后的伤势、抛撒火炭和意识到原防御不能久持，接到火既保护他又可能吞噬他的困境。来源flag=true；短期恐惧、身体损伤与应对策略占主导。

多数路径继续强化火与抗狼行动，released入口动机更强调逃离火圈。strong32动机及首轮反复称火已消失，但输入明确仍有火炭/失控火势，其行动也仍挥舞燃烧木头。不同路径把身体恐惧与可用策略连接得不同，不能仅靠强烈台词判人物刻画更好。

**审阅判断：** 这有状态/物理情境衔接问题，却不是长程价值或人格变化的直接证据。保留其在固定cohort中的结果，不围绕火、伤口或生存策略继续做局部优化，更不能用它替代角色成长的整体论证。

## 对整体问题的当前启示

这些链条覆盖关系重心、目标、自我理解、尚未解决的冲突和合理保持；它们比“资料字段是否改写”更贴近NPC为何需要从经历中改变。当前仍未证明哪条训练路线改善这些能力，也未证明需要新RL。D-E10完成后按同一12人物补齐训练对比；[D-E11](../experiments/D-E11-native-character-interaction-rollouts.md)进一步让角色生成的行为引发新回应与经历。两项读数各有用途，不用新增故事逼出失败，不以相邻方法存在为由收窄整个研究问题。
