# 开放科研入口：研究 Game NPC Agents，而不是维护一个预先选定的题目

**2026-10-14 用户明确纠正：两轮对“目标/旧计划”和“Trainable & Designer-Controllable”过早收缩均不应成为整个 workbench 的唯一研究主线。** 本页不预设论文题目或假说的胜利，不给某条方向强行分配固定主实验预算。

## 1. 研究对象和科学参照系
所研究系统必须出现**游戏内 NPC**（不是仅仅测试玩家式 AI 通关游戏）。科学问题可以发生在生成说话、信息边界、记忆、实际行动、角色策略、交易/经济系统、玩家体验或基础设施中的任一关键环节。记录 player / NPC / game engine / designer / simulator / judge 各自拥有的权限，不能因同样使用 LLM 就偷换概念。
衡量问题价值首先回到原生游戏/近期会议最强论文的科学问题，再考虑真实行业需求。玩家的提示、其他 NPC 的言论、记录/公告、世界状态、作者设定及模型记忆是不同权威层级，不能简单放在一串文本里而忘记来源。

## 2. 允许且鼓励并行的科学空间（不是 paper ideas）
- **能力与训练**：角色动作可学性、自然语言控制/偏好学习、共享政策/快速编辑、对玩家适应、政策和语言模型的接口。
- **安全/攻击**：玩家试图操纵剧情秘密或角色身份；被污染的环境公告/其他 NPC 消息被当权威；社会网络放大一次恶意指令；防御如何维持正常玩法。
- **长期角色状态**：稳定身份与合法心理演变、记忆选择、角色随时间偏离、被操纵的身份或关系。
- **NPC 经济与社会制度**：有库存/资源生产/交易/声誉/货币/任务的游戏社会，个体行为的策略适应与系统级价格、贫富、福利、操纵及失败。
- **具身与玩家体验**：对话行为、视频/音频/动作控制、互动延迟、玩家 agency、安全体验、游戏叙事。
以上方向都要对强近邻做严格定位；不机械全部实验、不因省事先把其中一个伪造成必做课题。

## 3. 什么才是“高信息量的实验”
**安全：** 先问“攻击者真正能控制什么”“欲越过哪一个作者权限”“游戏允许哪些合法说服或侦查”。提供不攻击时的正常完成、剧情合法揭示、不同输入来源、简单显式约束/状态防护作为对照；同时测攻击成功、正常玩法能力和误拒绝。能说谎的 NPC 不必是坏 NPC；鼓励诈骗剧情的游戏可能将揭露秘密作为正常胜利条件。
**人格漂移：** 把长期成长、短时情绪、场景性策略变化与角色定义被劫持分开，不能用一句“你不再像人物了”自动标 drift；语言评分必须对照可见行为与设计者剧情历史。
**经济：** 必须有订单/交易和真实 inventory/resource/money ledger（或能独立验证的经济 simulator）。记录市场总效果、个体/弱势 NPC、可交易规则、声誉、资源边界、协作团体；区分合法博弈、设计允许的阴谋、欺骗与规则外系统漏洞。AgentBazaar/TruthMarketTwin已研究Sybil和欺骗，简单搬进 RPG 不自动新颖。
**训练：** 先真实强基线、合法动作后果、成本对等；与玩家/角色设计者真正的任务对齐，不把一个内部 embedding 分数等同于好 NPC。

## 4. 避免再次“我先想到一个问题再说服自己”
研究动作遵循：广泛读优秀原生 NPC/强近邻→明确有哪些**不同的、各自重要**的真实压力→阅读真实代码/数据/失败→拿到可审计行为→形成竞争解释→再锁定**当轮**高信息量动作。强研究并不要求找到完全无人研究的问题，重要的是比已知认识解释更多、测得更准或有更有效方法。
可以选择安全、经济、记忆、训练中的一条**短暂驻留**，但不得把它写成全 workbench 永久身份。发现实际 evidence 改变了领域地图时，Agent 主动更新 [knowledge/DOMAIN_ATLAS.md](knowledge/DOMAIN_ATLAS.md) 与定位表，而不是在一条无效切片上无限加代码。

## 5. 动作型知识库，而不是外部摘抄仓库
- 精读纸面资产要包含 documented 动机、我们 reconstructed 的 idea 来路（不能伪造研究过程）、最强近邻 ownership、数据/接口与评价、每步实验的竞争性预测、真实失败/意外成功、对游戏 NPC 的迁移条件和成本。
- 对完全没读正文的来源不能声称“深读”；安全基准和经济论文要区分研究对象/会议 track。
- 允许同一游戏 substrate 研究不同构念，但每次要验证它确实包含对应的玩家/NPC/世界规则；不用一个自制小城市假装完整游戏社会。
- 真实科研 C## 需要运行前实验卡+原始数字/置信区间/混杂审计；旧 CPU 测试仅程序事实，不是 NPC 功能发现。

## 6. 本地资源、伦理边界
任何研究默认 0 付费 API：LLM 主体、攻击方/防御方、交易伙伴、教师、审判/标注辅助全部本地；环境与客观世界结算尽量 CPU/规则。跨节点各自独立；GPU 输出与资料缓存节点本地，检查网络/磁盘/CPU。只在隔离、授权的游戏/模拟沙盒评估攻击；不可对商业线上游戏、真实账号或玩家财产测试漏洞。区分真实玩家数据和模拟角色，不用攻击成功率替代安全、UX 和正常玩法质量。

## 7. 状态
本次任务是**整理并扩展领域认知**，没有选择/运行新的 GPU 实验，也没有发现论文级 novel idea。让证据而非此前写的 README 决定下一步探索方向。
