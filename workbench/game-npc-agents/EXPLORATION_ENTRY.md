# 已选探索入口：NPC 的目标承诺与计划适应

决定日期：2026-10-13。用户明确要求选择一个探索切口。本页替代“再调研后决定”的优先级；这是领域驻留的科学决定，不是声称已经发现新机制。

## 1. 一句话问题

**玩家改变了世界之后，NPC 究竟在坚持它想实现的结果，还是在重复先前选定的行动路线？两者在什么条件下分离，又在哪个环节混淆？**

目标是有自己动机、可通过说话/行动影响世界的角色。初始调查聚焦局势改变后的下一步及后续短轨迹，不一开始承担长期关系、实时视频、复杂人格和大规模社会模拟全部问题。

为什么不是普通工具使用：玩家是世界中的另一行动者，不是默认拥有最高任务改写权的管理员；角色有自己的期望结果和作者边界，玩家可以改变达成途径或实际完成条件。一次正确调用无法回答持续的目标控制问题。但若最终结论只是通用 API parser 更稳定，也不能用 NPC 外壳包装它。

## 2. 外部依据与主张尺度

学术依据见 [GOAL_CONTROL_REVIEW](knowledge/GOAL_CONTROL_REVIEW.md)：NAACL 2021 Dragon 的自然角色动机；ICML 2022 Direct Behavior Specification 的作者控制；ICLR 2025 Hypothetical Minds 的在线伙伴假设；ACL 的人物逻辑和叙事承诺；新近 NeurIPS 的协作/交互评估。

行业依据是 GOAP、Ubisoft 与 KRAFTON 开发者对自主规划、作者意图和即时适应的要求。它们说明需求真实，不证明我们的具体解释正确。

至少以下认识已经存在：目标持续与目标切换不是同一能力；当前状态/行动能力影响目标归因；正确推断不保证执行改变；无功能的目标样式线索可能吸引行动；经典规划器可将目标与计划分开。**不能以第一次把其中一个词放进 NPC benchmark 为创新。**

潜在有分量的结果是：从真实交互误差中得到一个可跨任务/角色预测的控制条件，解释何时角色丢掉目标、何时反而过度执行旧手段；或证明某种常见控制/评价方式系统性混淆这两者，并建立可验证的替代方式。简单模块有效只是线索，不预定方法贡献。

## 3. 配对观察单元：相同前史，世界后果不同

先保存真实角色轨迹上的一个世界快照与完整输入，再通过引擎原有的合法玩家事件形成分支。分支对同一模型尽量共享随机种子；不同 policy 的后续运行独立，不能强迫它们输出同一计划。

| 分支 | 原目标状态 | 旧计划状态 | 应检验什么 |
|---|---|---|---|
| U 未改变 | 尚未完成、仍可达 | 仍可用 | 原生任务能力；正确政策允许选择其他合法路径 |
| N 非目标相关互动 | 尚未完成、仍可达 | 仍可用 | 角色能否保持进展；不是规定它一律不理玩家 |
| R 手段失效 | 尚未完成、仍可达 | 某个真实前提失效 | 能否观察、换路径并完成同一个目标 |
| S 目标已完成 | 由玩家合法实现完成条件 | 旧动作不再必要 | 是否识别完成，避免无用/有害重做；允许合理后续活动 |

这张表是测量设计，不是预期结果图。每个源任务不一定天然支持四个分支，报告每分支资格率和交集；不为了配齐格子人为添加新游戏规则。不可达/被正式撤销的目标独立记录，不和 R 混在一起。

**关键语义限制：** “获得某物”与“我亲自从某人处取得某物”不是同一目标；事件型目标与状态型目标必须分别表示。玩家完成某个状态不一定完成原作者的事件要求。模糊的长期动机不能仅凭 LLM 解释变成确定性标签。原 Dragon 以特定行动作为任务目标是其合法任务定义，不因此指控原论文评分错误。

首轮主分析采用 NPC 能观察到相关变化的分支。隐藏变化只在后续研究部分可观测性时加入；不能对不知道发生了什么的角色按全知最优解判错。先以正常事件为主，不用 jailbreak/超长干扰来制造现象。

## 4. 从真实观察选择下一项区分实验

完整日志分开：任务动机、角色当前观测、此前自生成计划、实际合法动作、世界变化、可达性证明、完成条件、token/延迟。模型自述只能辅助解释，不能独立证明它“知道”。

| 候选解释 | 最有信息量的下一比较 | 会推翻什么直觉 |
|---|---|---|
| 基本动作或规划能力不足 | 同一变化后快照，从零开始执行，与带历史执行比较 | 从零也失败时，不能归因于历史中的目标控制 |
| 关键状态未观察/未读出 | 相同事实集改为明确的当前局部状态；不增加隐藏信息 | 状态支架完全修复时，优先研究感知/表示而非意图遗忘 |
| 原目标未保留 | 同样 token 预算下重述目标；与重述无关设定作控制 | 一句话恢复后不宣称深层能力缺失 |
| 旧计划控制了行动 | 保留事实历史、目标和当前状态，只屏蔽自生成的旧计划；对照屏蔽等长非计划文本 | 不改变信息也改变行为，才提示计划上下文具有额外作用 |
| 终止条件理解不同 | 显式审计事件型/状态型目标；采用合法等价路径与完成例 | “还在行动”本身不等于没有停止旧任务 |
| 截断/格式/解码问题 | 统一上下文上限、可用行动接口、思考额度，保留所有失败 | 模型服务差异不冒充行为规律 |

不是预先要求全部机制同时成立。先认真看自然轨迹、成功例和典型失败，再选最能改变判断的一两项；允许发现更好的观察量。

## 5. 必须包含的强基线

B0：当代本地指令模型，明确角色/目标、当前可见状态、完整可容纳的事件历史，直接选择合法行动。不是故意弱提示。

B1：B0 + 一句明确规则：“保持角色目标；计划可随世界变化修改；按真实完成条件判断任务是否仍需执行。”这属于强提示对照，不是新方法。

B2：每一步从相同当前事实与目标重新决策，不延续旧计划；若舍弃全部历史，需要同时提供匹配的事实历史以分离记忆收益。额外调用/token 必须计入。

B3：将目标、当前事实、计划分开保存的最简结构化控制；是合理基线，不是我们的创新。不能给它无偿更多信息或推理。

B4：适用子集的规则/GOAP规划器。完整世界状态与形式化目标的 oracle 版本只是上界；若与语言模型信息不同，不能用分差证明 LLM 缺乏目标导向。可比较的局部观测版本另报覆盖率。

Bayesian Partner Modelling 的按伙伴矛盾打断与 Hypothetical Minds 是重要方法近邻；不需要为了凑表格强行把厨房技能识别器搬入 RPG。原算法无法原生适配时报告原因及对应的功能对照，不能假称复现。

## 6. 数据、规模与确认

首选 LIGHT 官方自然 quest，保留作者 split。训练 split 只用于解析/规则准备，validation 用于发现，test 冻结用于确认。人工/独立本地校验聚焦目标语义、分支合法性和最关键误判，不要求海量人格标注。

运行测试可以用官方 simple_world，不能用它证明科学结论。E03 目标为 **64 个合格 validation 源任务**的初始发现；若资格筛选后不足，报告真实数量和原因，不用合成任务悄悄补满。多分支和多 seed 不当作更多独立任务。

确认阶段初定 **240 个未参与挑选的 test 源任务**，随后根据 pilot 的配对差异和异质性修订、预先冻结。该数来自设计假设而非万能门槛：配对不一致概率约0.30、欲检测10个百分点差异，正态近似 n≈0.30×(1.96+0.84)^2/0.10^2≈236；若效应更小或场景聚类更强，需更多独立来源。没有足够数据就缩小主张，不把种子当样本增量。

主报 U/N/R/S 的各自结果、源任务级置信区间、合法动作/目标恢复/过期动作/不必要重做；不只报加权总分。不筛掉原任务未成功的模型/种子，能力资格子集只能作为预定义补充分析。模型输出错误和超时入失败/成本，不静默丢弃。

## 7. 为什么适配我们的算力

先用 Qwen3-14B 与 Mistral-Small-3.1-24B-Instruct-2503 等已有可本地服务的不同家族建立 frozen-policy 对照；它们是成本与复现参照，不声称是2026最强模型。已经缓存的更强单节点开放权重可作为后续确认。权重、模板、解码和服务版本在启动前固定。

主要测试不用训练、付费裁判、3D渲染或跨机同步。玩家干预先用引擎脚本，正常伙伴先用公开规则；更开放对话只增设一个本地伙伴服务。SFT/LoRA/RL 只有在有可重复的瓶颈和训练信号时才选择。

主 baseline 的 pilot 上限示例：64源任务×4条件×2模型×2种子=1024局，最多12次NPC决策/局。每调用最多8192输入、512输出，按所有分支都合格算上界约1.01亿输入、629万输出 token；这不是工时估计，也不是一次铺开全部方法的指令。先测单节点吞吐，再给真正有判别价值的 B1/B2/B3 分配预算。额外伙伴/重规划/重试另计。

## 8. 明确的继续与转向标准

- 若强基线在自然任务上已可靠且无有意义差异：报告成功边界，不增加人为干扰来强造论文。
- 若一条普通指令或每步重规划已解释并解决全部现象：承认基线足够，不能包装复杂新控制器；只有可泛化的剩余机制问题才继续。
- 若最终只是复现 Goal Drift 的模式延续、Arghal 的无用钥匙偏好或已知 belief–action gap：不是本项目论文贡献。
- 若出现可靠且不能被简单对照吸收的失误结构：以未见角色/任务和第二模型确认，再决定机制分析或最小训练/控制改进。
- 若自然数据/引擎对齐不可恢复或占据过多研究精力：保持同一 NPC 目标控制问题、更换公开资产；不自动改成工具竞赛或泛用MARL。

**当前结论：这一切口已选定，准备按 E03 进入真实测量；尚未证明存在新现象。** 后续主观能动性体现在根据证据改善问题，不是机械把本页所有格子跑满。
