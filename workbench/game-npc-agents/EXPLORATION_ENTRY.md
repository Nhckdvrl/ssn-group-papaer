# 下一道科学入口：角色信息应该在何时影响 NPC 的行动？

2026-10-13 第二轮。**这是优先测量的问题，不是已成立的现象、已认定的新颖贡献或锁死的论文故事。** 六个大方向仍见 [RESEARCH_TERRITORIES](RESEARCH_TERRITORIES.md)，本页将当前资源优先级收敛到一个能被自然数据检验的疑问。

## 1. 为什么现在问这个，而不是直接训练 NPC？

深读/源码核查改变了我们对底座的判断：KNUDGE 是作者侧对话图，CDT 的主要行动评价是文本预测，NCP 是 narrator 的状态审核；CPDC 的公开样例有角色/工具调用数据，但不提供任意动作的持久世界。它们都能支持有价值的研究，却不能未经转换就合成一套在线 NPC benchmark。

因此先做一个有明确范围的离线决策研究入口：**在正确历史和工具接口已给出的情况下，NPC 有没有正确使用与行动有关的角色信息，同时不被无关的人物表达干扰？** 只有看到值得追的现象，才投资长程引擎与训练。这样限制的是单次实验的耦合程度，不是研究问题的重要性。

## 2. 重要性不在“persona 会影响模型”

NPC 与普通执行助手的差别之一，是它有角色自己的知识、关系与目标。一个只服从玩家的 agent 可能任务调用准确却不像角色；一个过分展示角色的 agent 可能台词鲜明却不执行应有动作。但这类笼统张力已经有近邻，不是我们的新发现。

我们目前想检验的，是能否分开两个方向：
- **应该敏感：** 角色目标、被授权知道的信息、明确关系/职责使某些选择不再合适时，行动应作相应变化。
- **应该稳定：** 不改变上述决策条件、只改变表述风格或等义说明时，必要工具与参数不应无故漂移。

“应该”必须来自可审核的任务/角色契约和自然样例，不得从模型输出反向编一个规则。不要预先断言勇敢者应总冒险、友好者应总免费赠物；这种刻板映射本身需要证据，不能作为我们的金标准。

## 3. 为什么它可能有认识增量，又为什么可能没有？

有价值的候选结果不是“加 persona 分数下降”，而是发现：一个常用的角色控制或任务优化手段，对该变化与不该变化的决策产生了可预测的不同影响；这一条件性规律能在新角色/新任务中成立。那会改变我们如何测量、训练或部署角色控制。

反之，如果只是格式错误、上下文变长、工具说明没写清，或一句普通指令即可消除，则应将结果还原为接口/默认策略问题。如果仅得到“删减 persona 更会调用工具”，需先与 Talk Less / Deflanderization 等工作对照，不能把已有结论重写为论文。

相关权属及反例入口见 [knowledge/POSITIONING.md](knowledge/POSITIONING.md)。**目前没有足够证据宣称这个具体问题没人研究。** 热度亦未完成定量统计。

## 4. 先看自然数据能否承载问题

优先审查 CPDC 发布样例和强开源方案的数据，保留其原始 source/role/worldview/state/messages/tool schema。先完成原始与增强样本的 lineage、场景分组、许可、调用分布和歧义检查，再决定能否做上述双向测量。

判断单位是一个有可追溯历史的角色决策点，而不是 prompt 数量。以下三类都要保留：明确需要改变选择、明确不应改变、信息不足/允许多个选择。只挑容易写出唯一 gold 的样例会把问题人为简化。

允许从真实案例衍生最小反事实对照，但必须说明改变了什么、为什么其余任务含义不变；自然原始样例仍为主体。人审或独立模型重点校准关键语义边界，不要求所有数据昂贵地逐条多人标注。若自然语料中几乎没有“角色信息应影响行动”的可识别情形，**这份数据不够支持本问题**：重新选数据/缩小结论，不靠全面合成制造两类。

## 5. 最先运行什么，怎样才有信息量？

### 先修正测量资格

解析合法性、工具可达性和最简调用任务是正控制；用原公开 strong baseline，区分作者原版复现与本地替换模型。必须保存完整请求、输出、调用、解析失败，不允许只留最终均分。

### 再用小型配对测量定位，不直接穷举配置

在同一自然决策点，控制历史、工具 schema、预算和输出协议，比较原角色条件、决策相关信息保留但表达收敛、任务信息对照等。只在标注认为适用的样例上施加相应干预；不能把删除必要目标后得分下降当惊喜。

先认真看分歧案例，区别：未调用、选错工具、参数错误、角色目标违背、合法但不同的选择。参数/名字/调用顺序不能为了方便全部小写排序；只有有依据的可交换操作才能作语义归一化。

### 不可缺的简单解释

匹配输入长度与格式；一句明确任务指令；已正确抽取的决策信息；无工具正例/负例；等 token/等调用比较。多专家方案已存在，应与统一模型在同底座、同数据、同预算条件比较，而不是给新方案更多判分器/教师调用。

以上是当前起点。若自然 trace 显示新的测量轴更有价值，应修改下一实验并写出理由，而不是机械跑完所有候选。

## 6. 从观察到贡献的分岔

| 得到什么 | 下一步，不事后美化 |
|---|---|
| 基础格式/函数能力处于地板 | 修接口或换合格本地模型；不是 NPC 机制发现 |
| 普通指令即恢复且跨任务稳定 | 报告默认策略/提示条件，谨慎判断是否还有更重要疑问 |
| persona 抑制普遍改善工具匹配，但未测角色损失 | 不能宣布解决 NPC；先补角色相关决策读数，核对已有工作 |
| 相关/无关信息的使用呈现可重复的差异 | 换未参与发现的场景/角色确认，查更强近邻，再追可解释干预 |
| 人类也无法判断哪个动作更合适 | 显式报告歧义与可接受动作集合，不伪造唯一 gold |
| 没有足够自然案例支持双向区分 | 调整科学问题或数据源；不为既定故事造数百个模板 |
