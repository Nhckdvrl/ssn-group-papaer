# I01：语义作用域感知的原创角色修订（2026-10-21）

- **状态：** SEED（已完成E01/E02首次模型观测；尚无人类实验，不自动改idea状态）
- **来源（必填；优先高质量来源但不是白名单）：** [ORIBA](https://arxiv.org/abs/2512.12630) 的原创角色作者通过试演修改/扩展人物；[CDT, ACL 2026](https://aclanthology.org/2026.acl-long.568/) 从叙事归纳可执行条件行为；[The Persona Hierarchy Model, arXiv 2026-10-07](https://arxiv.org/abs/2610.09384) 已研究训练行为的上下文传播与局部保持；[BalancEdit, ICML 2025](https://proceedings.mlr.press/v267/guo25e.html) 已研究一般编辑的 generality/locality。由这些近邻的边界提出**角色作者的语义修订范围**问题，并非已观察到本线失败。
- **研究动作：** 引入已知的编辑 generalization/locality 构念与受控测量；重新定义适用对象为人物关系、情境、选择与外显表达的语义范围；比较强普通 Prompt、条件规则和参数学习的有效增量。
- **如果为真，主张是：** 原创人物的一次局部编辑所需的行为传播范围无法只由词面或统一上下文距离规定；在未见人物/情境中，完整普通系统与近邻方法可能难以同时支持相关行为的迁移以及无关特征的保留。可探索学习/表达这些作者意图。**此处不是已经证实的 C##。**
- **不同结果各带来什么 information gain：** 完整强 Prompt 已好 → 接受无需复杂学习，转向真实作者成本或停止当前算法主张；主要是显式条件检索 → 认真比较 CDT；存在跨原创人物稳定的相关不迁移/无关被改写 → 才深入学习条件作用域的方法；作者对作用域本身多解 → 首先澄清作者契约和金标，不硬用唯一动作答案。
- **最近 3 个近邻与增量：**

## 2026-10-21：第二轮近邻审查后的问题重定义（优先于初版玩具例子）

**研究中心不改，任务入口改变：** 不能只给模型一条已经概括完整的「作者修订原则」，再评它会不会执行 IF–THEN。引入 `Situated Creative Feedback / In-situ Critique`：作者在一幕试演中指出错误，给出局部表演修正，但不直接告知完整关系、强度或表达边界。模型须从稀疏反馈归纳其可能的**行为编辑范围**。

**新命题：** `Learning the Scope of Character Revisions from Situated Creative Feedback`；要同时研究合理泛化、无关行为保持和**作者意图不可辨识时的恰当不确定性/澄清**。一条作者纠错可能与多个抽象原则同时兼容；不能把研究者事后写在隐藏 oracle 卡上的原则当成从单样本唯一可推的 ground truth。明确的原则 Edit 仍保留为*额外信息/显式可解条件*，不是同信息算法基线。

**三项关心的作用域**：①人物外显行动与台词风格分离（Channel），②关系/触发条件与特殊人物例外（Relational/Situational），③无新增相关事实的语言施压不应凭空改写已确定行动（Pressure）。压力是对一项基础情境的成对扰动，不构成与关系、严重度正交的第四象限；而压力本身也可能改变关系态度，不应要求整体策略不变。

**潜在贡献形态**：作者意图的不确定范围识别；由局部纠正诱导可迁移、可编辑的角色条件原则；动作与外显风格分别可控；在未充分确定时主动询问作者并低成本修订。SFT、DPO、编辑、结构规则、模型表示皆为后续根据证据选择的工具，不预置损失函数。

**新增强近邻**：[ORIBA](https://arxiv.org/html/2512.12630) 报告 14 位艺术家中 8 位修改了配置，但未确证「单场景批注是最常见反馈」；[CDT ACL 2026](https://aclanthology.org/2026.acl-long.568/) 已有条件规则归纳和更新，不能未经测试称它必然动作/语言耦合；[Persona Hierarchy Model 2026-10-07](https://arxiv.org/abs/2610.09384) 是**微调跨上下文传播**，并非静态 RPG 属性树；[Test-Time-Matching](https://arxiv.org/abs/2507.16799) 已分别组织人格/记忆/语言风格；[Behavior Editing](https://arxiv.org/abs/2506.20606) 与 [Personalization Editing](https://arxiv.org/abs/2512.13676) 已研究行为/偏好的编辑与局部性。

**额外新近邻：** 通用意图澄清与信息增益问答已分别在 [ICLR 2025](https://mlanthology.org/iclr/2025/zhang2025iclr-modeling/) 和 [ICML 2026](https://proceedings.mlr.press/v306/deng26l.html) 出现。因此本 I01 不能把「给不完整编辑提澄清问题」独立称新技术；需证明它对**人物行为修订、作用范围推断与作者后续工作成本**有额外贡献。

## 第三轮审查（2026-10-21）：Persona-guided Scope Induction

**主问题仍然是 NPC 行为策略编辑，不转为作者问答助手。** 新的研究假说：原有人物的经历、关系与价值可帮助从少量现场表演纠偏中推断合理的行为修订范围。概念上考察 `p(S|P,C) ∝ p(C|S,P)p(S|P)`，其中 P 是先前人物资料、C 是试演失败与纠正、S 是候选编辑范围；这并不证明模型在使用贝叶斯算法，更不能把后验最大的一项当作作者唯一意图。

**四种需要分别识别的情况**：（a）旧人设与反馈足以支持某个测试场景的行为；（b）先验偏好某种解释，但其它解释仍合理；（c）反馈与人设仍真正欠定；（d）作者修订有意**覆盖**旧的人物习惯，强先验不应阻止必要改变。尤其要区分 **latent-scope identifiable** 与 **decision-identifiable**：多个 S 可以保持多解，但若它们对某个测试情境 x 都给出相同合理行动，该测试动作仍可能有可靠评价。

原 Persona 被强化不一定是好，模型需要学会何时保留旧约束、何时尊重新作者修改。将 `one positive critique + one boundary negative critique` 视为后续可选的最小对比信息机制，而不是现在就上通用聊天式澄清。

不能凭几段研究者创作的背景伏笔宣称 gold unique。竞争者包括完整强 Prompt、同等 M2 反馈下的 profile rewrite、few-shot、CDT 规则归纳与现有 personalization/behavior editing；允许这些普通方法已经足够好。

## 第四轮：Known Generating Scope 与 Inferable Scope 的正式区分（2026-10-21）

合成任务可先抽样或人工构造隐藏角色编辑规则 `S*`、再给单次人物批注 `C`，从而严格衡量 `S*` 作用下的行动与模型输出是否一致。**但** `S*` 既然生成了批注，不代表观察者仅凭 `(P,C)` 能唯一恢复它。必须区分 `synthetic-oracle fidelity` 与 `identifiable decision fidelity`。模型在不可辨识样本对隐藏 S* 预测失败，可以作为受限信息下的泛化统计，不能直接指控模型「不懂人物」。

Version Space 的条件化共识可作数学工具，但不是本文首创（Mitchell 1977/1982；近年 selective prediction by agreement 也直接研究该问题）。定义假说类 `H`、与旧 Persona/作者批注的相容性、情境 `x` 与角色其他约束后，才能说所有 `h ∈ H(P,C)` 给出同一行动。若人物允许多种合理选择，应以允许的**动作集合**/偏好或分布表达，而不是硬写唯一最佳动作。

补充的 `P_A`（只对 Maelis 有个人恩情）与 `P_B`（有守岗害死队友的集体创伤）很好地提示了一个重要研究问题：**仅改变人物经历，固定作者批注，是否会定向改变模型在另一位队友遇险时的策略？** 目前只是可检验的方向性假说；两段背景不能严格排除其它动机，不能预先宣称应产生 180° 反转。其余 A–H 研究方向仍开放，本轮优先让 I01 的第一个合成 smoke 提供可靠描述性信息。

## E01/E02后的研究判断（2026-10-21）

实际245次模型请求及[结果分析](../results/e01/REPORT.md)：三模型完整规则动作执行在格式/预算处理后均20/20，Situated Change均8/8；Qwen/Llama/Step的Situated总分为15/20、18/20、17/20。强模型剩余边界主要欠定，不能将Explicit信息增益当新算法能力差。

[E02](../results/e02/REPORT.md)同信息普通卡重写已有收益（15→18/20），但Change下降1条；一句提示只到16/20。去原卡也是16/20、分项方向混合，尚不能支持先验普遍有益的命题。以P01旧硬规则/新例外整合为优先方法动机；P02台词事实/动作一致性须先完善材料和作者评价。维持SEED，不启动RL，不在四故事上循环造坏例子。C01/C02均只L0。
