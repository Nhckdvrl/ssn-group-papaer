# I01：语义作用域感知的原创角色修订（2026-10-21）

- **状态：** SEED（首个被选定的具体研究焦点；尚无模型或人类实验）
- **来源（必填；优先高质量来源但不是白名单）：** [ORIBA](https://arxiv.org/abs/2512.12630) 的原创角色作者通过试演修改/扩展人物；[CDT, ACL 2026](https://aclanthology.org/2026.acl-long.568/) 从叙事归纳可执行条件行为；[The Persona Hierarchy Model, arXiv 2026-10-07](https://arxiv.org/abs/2610.09384) 已研究训练行为的上下文传播与局部保持；[BalancEdit, ICML 2025](https://proceedings.mlr.press/v267/guo25e.html) 已研究一般编辑的 generality/locality。由这些近邻的边界提出**角色作者的语义修订范围**问题，并非已观察到本线失败。
- **研究动作：** 引入已知的编辑 generalization/locality 构念与受控测量；重新定义适用对象为人物关系、情境、选择与外显表达的语义范围；比较强普通 Prompt、条件规则和参数学习的有效增量。
- **如果为真，主张是：** 原创人物的一次局部编辑所需的行为传播范围无法只由词面或统一上下文距离规定；在未见人物/情境中，完整普通系统与近邻方法可能难以同时支持相关行为的迁移以及无关特征的保留。可探索学习/表达这些作者意图。**此处不是已经证实的 C##。**
- **不同结果各带来什么 information gain：** 完整强 Prompt 已好 → 接受无需复杂学习，转向真实作者成本或停止当前算法主张；主要是显式条件检索 → 认真比较 CDT；存在跨原创人物稳定的相关不迁移/无关被改写 → 才深入学习条件作用域的方法；作者对作用域本身多解 → 首先澄清作者契约和金标，不硬用唯一动作答案。
- **最近 3 个近邻与增量：**

  | 近邻 | 已经研究什么 | 必须验证的剩余增量 |
  |---|---|---|
  | [CDT, ACL 2026](https://aclanthology.org/2026.acl-long.568/) | 从既有故事提取验证后的条件行为规则及更新 | 少量作者改动在未见人物关系、叙事动作与表演渠道中的合理影响 |
  | [Persona Hierarchy Model, Oct 2026 preprint](https://arxiv.org/abs/2610.09384) | 微调的上下文影响传播和 persona-preserving regularization | 同一原创角色**内部的行为语义作用范围**，不能再以一般 local/global 编辑当新颖性 |
  | [BalancEdit, ICML 2025](https://proceedings.mlr.press/v267/guo25e.html) | 多模态事实编辑 generality–locality 的作用范围 | 从事实替换到作者的关系/行为/表达修订，允许条件变化与合理多解 |

- **最便宜的决定性 pilot（能分出决策分支的最小算力）：** [E01](../experiments/E01-scope-aware-character-edit-baseline-gate.md) 为 PLANNED；[初始评测骨架](../experiments/scope_edit_pilot/README.md) 的手工材料仅为代码 self-test，**不是可以据以决定模型/顶会主张的样本**。
  - **阳性对照：** 受控的编辑前后期望行为可以通过配对指标被检出，故意打乱答案会使程序计数下降；模型侧正控仍待建立。
  - **噪声地板 + MIE：** 先记录真实模型 seed/故事/作者间方差，再确定足以改变科研选择的最小有意义差异。四个手工故事不足以估计效应。
  - **决策表：** 参见 E01；没有实际模型或作者材料前不能将自测结果解释为 I01 成功。
