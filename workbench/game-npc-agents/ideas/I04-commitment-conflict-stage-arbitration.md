# I04：人物、自身目的与真实NPC选择

- **状态：PROMISING。** 用户2026-10-15认可研究张力；工作台PROPOSED、C01–C06等级保持，论文正文暂缓。2026-10-16用户要求本轮结束后暂停，E85已完成，无待运行队列；恢复须用户明确指令。
- **对应：** P12；C02／C04／C05／C06限定L2，C03发现性L1，以[CLAIMS](../CLAIMS.md)为准，不由本卡升级。
- **问题：** 有自身身份、目的和社会关系的NPC，面对玩家请求、真实行动和新方案，怎样选择、修订或拒绝，并经合法动作产生后果？
- **候选认识：** 人物立场、互动中形成的回应、行动前提和资源用途共同形成真实行为；任务分数不能直接反推人物有用／无用、潜在能力或私人目标权重。这有实证支撑，尚非统一内部机制或已验证新方法。

## 竞争解释与当前未解问题

原H1–H5保留为解释类别，不是已经找到的五个模块：

| 类别 | 可解释什么 | 已有约束 |
|---|---|---|
| H1：角色／目标信息未有效保留 | 未行动或偏离原目的 | E56普通阶段说明解决了部分问题；事实问答不直接证明行动中遗忘 |
| H2：信息可用但目标优先级／合作价值不同 | 保留、转移、拒绝、取得前提后转向自用 | E63明确优先有效；低Give不自动错误，原子goal不是全部利益 |
| H3：抽象立场与具体动作／对象／接收者绑定不同 | 粗动作与参数、任务族作用不同 | E58弱责任句非明确规则；E62／E69未给统一词位／动词机制 |
| H4：路径采用、执行前提与互动机会 | 有可行计划未采用、已释放资源却未接取 | E70–E74普通支持、E80可靠技能解释部分损失；未尝试非原生执行失败 |
| H5：近期台词／请求改变状态与目标绑定 | 历史来源、承诺与当前立场参与后续 | E51／E59状态、E60／E61同历史及E77固定C有边界，未识别纯模块中介 |

当前关键关系是：**同一目的下，玩家按原办法实现前提、用合法替代实现同一前提、原办法失效但另有路径时，NPC能否保持目的并实际调整方案？** 目的相容的取舍，与近期话语／局部物品／双方实现过程主导，对此可作不同预测，也可能共同作用。E85只改变转移、说法和新请求，尚未裁决；这不是已注册队列。

## 领域尺度判断与下一轮建议（2026-10-17，只设计，未运行）

**现有结果最有价值的整体认识：人物控制的行为效果取决于“角色目的—他人请求—共同动作前提”的关系。** E55给出真实行动效应；E63／E68说明保护当前任务可以保留其他合作差；E75同一立场同时提高Get与请求交付而任务方向不同；E80可靠实现不替代用途判断；E84／E85已有实际合作和修订。整体可形成对人物控制／任务评价的实证认识：人物并非只改台词，其效果也不能从一个终局分数读出。不同任务下的异质性有可检验的结构来源，不是统一神经机制已被识别。

**最值得继续的是：玩家改变合作的实际作用后，NPC该坚持什么、该改变什么？** 同一角色既要保留自身目的与职责，也可能负有已接受承诺；具体物品、提供者、分工和实现路径则可能变化。这直接关系玩家能否用非预编写办法解决问题、是否被要求重复无用劳动，以及NPC能否拒绝越界却提供可行支持。物理上达到同一结果不自动产生同一社会义务；已经接受的回报也不会因为NPC目的已达而自动消失。当前数据仍未把这些关系区分。

近邻要求我们继承动态grounding、条件履约、可靠路径和及时重规划，见[合作定位](../knowledge/persona-behavior/COOPERATION_REPAIR_POSITIONING_2026-10-16.md)及[目标谱系补核](../knowledge/GOAL_CONTROL_REVIEW.md#field-review-2026-10-17)。核心增量不能只是“换目标会失败”“提醒后恢复”或“调用重规划”。有价值的整体目标是解释角色何时应保持目的／承诺、何时能接受替代／改约，并检验这种解释能否跨任务结构预测实际后果。

**建议一项围绕实际因果关系的主实验，附必要的强系统诊断；不铺提示词矩阵。** 先保留作者原人物、各层目的、职责和原世界，从自然可执行来源按结构取样。候选覆盖材料／工具与目标产物、他人代办／分工、职责内的替代援助；这些是来源资格类别，尚未证明当前缓存有足够实例，不能把例子当已建数据。目标为百级独立世界的覆盖量级，实际N由原生来源、世界级区间精度与成本确定，不作科学去留bar。旧23／9图是开发线索，不能反复分支充确认样本；按源图／任务结构划分开发与未曝光检验，保留所有合格来源，不按模型是否先答应或是否失败筛样。

**局部优化检查：** 新自变量是玩家合作对原目的的实际因果作用；要看不同任务结构中的保持／替代／修订与拒绝，而不以提高旧Give率为目标。原料交接与成品代工可从现有Minecraft原任务寻找能力参照，但共同制作不冒充角色利益／职责实验。若自然来源只支持Give与Drop的接口变体，就应扩展原任务来源，不能凑数量称已检验目的与手段；这不关闭问题，也不凭几个失败决定训练。

| 同角色／同目的下的对照 | 要区分的关系 |
|---|---|
| 原办法仍有用，玩家按原办法真实提供前提 | 正常合作与后续用途的正参照 |
| 同一玩家用另一条合法路径实现相同需求 | 是否理解替代手段，还是只盯旧物品／旧动作；只在作者目的不要求亲手／原物且职责允许时称目的等价 |
| 原办法因玩家合法行动失效，但另一原生路径仍可达 | 能否修订方案并实际采用替代；不通过后台删物／改奖励制造失效 |
| 玩家有相似规模行动，但不影响原目的或方案可行性 | 是否只是逢变化就改计划，而不是选择性适应 |
| 当前没有可达替代，或替代触犯原作者明确职责（各自合格子集） | 能否合理停止／拒绝／澄清；不把服从与继续交物当唯一正确答案 |

主物理比较尽量固定请求与中性通知，让真实事件／库存呈现因果差别；同状态等义改述只作测量对照，不逐例优化。原承诺逐字保留，替代合同须NPC实际接受，不能由研究者宣布替代已结清。玩家行为干预和响应规则在模型前冻结，主分析同一NPC／伙伴策略。首次修订与完整互动总效应分报；E85揭示后续补交会改变终局解释，因此不由终局倒推首次辨别。完整动态伙伴另作外推读回，明确其是初始干预的总效应。

**强参照与竞争解释：** 普通本地LLM从一开始就有本人目的／职责、真实事件／库存、动作前提和每个关键事件后的重新决策机会；固定一条普通“依据现状重审下一步”说明作R8对照，不能用从不重规划的弱baseline。另用相同高层选择＋可靠原生技能区分实现负担；可明确形式化的子集用原生规划器核当前目标可达与路径，不替NPC决定社会取舍。相同当前状态的重启对照须保留全部有效承诺／职责／已发生贡献，才有资格比较旧计划历史影响，不能删掉债务再称能力控制。上述只是已有强做法／诊断，不预定新方法。

读数分列原作者可判定目的、履行的具体承诺、仍未满足的前提、采用／落实的替代、职责边界、重复索要已无用步骤及改变后的首次有效动作。预先给每对情境相同可完成机会并保留达成后的观察窗；不只截首次回应，不靠长帧漫游。合法替代与合理拒绝一起读，不合成一条“合作正确率”。单步问答不充内心信念／机制；无实体终点的更高目的只报解释范围。

结果会改变判断：普通强系统能随这些关系稳定调整→明确其能力范围，转向仍有真实开放决策的条件；仅可靠技能恢复→定位实现负担；保留义务后的同状态重启恢复而延续失败→历史／方案采用成为候选；熟悉任务可做而未见结构失败→关系迁移成为候选；主要差异是作者职责／承诺→保留合理社会取舍，不能叫人格失效。这些都不自动关题或升级，不以显著性定bar。主实验固定原persona，本轮不新增总体人格因果主张；以后若检验人物调节，须在整段互动前赋值且全模块一致，不能在旧历史后只改planner。

此处只有建议，不创建E86／新队列，不启动数据生成、CPU引擎资格、模型或API；恢复仍须用户明确指令。

## 近邻与接手边界

自述效度、粒度／同会话、叙事／动作锚点、策略steering已有Personality Illusion、Rethinking、Story Shapes、Persona Vectors；未来意图／记忆干预已有PM-Bench、PASB等邻域。Dragon／CDT／KNUDGE已有动机—对话—行动谱系。When Identity Overrides Incentives已研究人物×收益与收益优先提示；Dialogue is the Plan关注grounding／repair，Persona Circuits是内部干预近邻。CT-Bench、TradeCraft、ContractSim已有私有目标、承诺／拒付与强状态支持；GenCoord、FACUL／PUBG已有可靠技能，GAIA有冲突目标协商，CoopEval有序贯合作。整体问题是角色身份／目的怎样与开放玩家行动、可变实现和持续后果相联系，不靠RPG外壳／一般失约改名，也不逐组件压缩增量。
