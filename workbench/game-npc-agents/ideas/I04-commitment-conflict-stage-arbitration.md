# I04：承诺与原生任务冲突时，人物设定如何影响跨阶段裁决

- **状态：** SEED；用户已选定此重构方向，尚未给出机制结论。
- **来源（必填）：** 用户2026-10-14科研审计；P12；E46–49提供承诺进入不同组件的个例，E42显示具体信息与任务能力可改变取舍。旧局部改写不用于总体persona效应。
- **研究动作：** 将观察重构为有客观实体终点的短序贯决策；统一persona，然后正交操纵承诺的agenda/memory入口；跨阶段白盒测量与因果干预验证预测。
- **如果为真，主张是：** 原生任务与社会请求发生实体资源冲突时，persona对承诺采纳的影响与对最终资源分配的影响可分离；这种分离随任务冲突、信息入口与阶段而系统变化，而非只有语言风格变化。
- **计算假说：** Conv形成候选承诺，Update决定是否提升为任务，Exec重新裁决已有目标与承诺。H1信息遗失；H2相同信息在不同阶段的优先级不同；H3礼貌表达／普通直接指令效果；H4任务执行能力。允许全部阶段一致且persona有效。
- **形式化：** u=Conv(P,A0,r), (A1,M1)=Update(P,A0,u), a=Exec(P,s,A1,M1)。固定同一u随机暴露agenda/memory得Y00,Y10,Y01,Y11；总入口效应E[Y11−Y00]，交互E[Y11−Y10−Y01+Y00]。若报告两个贡献用Shapley均分交互，不能未经验证叫正交中介分解；无承诺比较保留请求信息，阻止单一函数不等同do(u=空)。
- **不同结果各带来什么information gain：** 一致persona恢复→原局部干预混杂；普通指令恢复→信息/任务解释；同信息跨阶段不同选择→优先级与残差干预；渠道交互→研究冲突裁决；全部有效→研究成功机制。
