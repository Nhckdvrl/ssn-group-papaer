# 所选NPC目标控制切口：全链路本地预算

2026-10-13。十余A100、8张PRO6000、实习16张H20是多个独立资源池，不是高速互联集群；不默认全部空闲或机构间数据可混用。

## 1. 核心实验零付费推理API

NPC、伙伴、计划整理、教师、标注辅助、裁判、异常重试全部本地。未配置端点时必须失败，不回退云端；免费预览服务不当复现基础。数据/权重一次性官方下载有网络与存储成本，和推理API费用分开。

首轮采用单个本地NPC、原生世界、规则伙伴/合法玩家事件、确定性目标评分。因此不需要同时运行NPC、世界生成器、玩家和三个judge。后续检验对话交互时再加一个独立本地伙伴；它不能代表真实人类体验。

## 2. 模型及部署

默认候选Qwen3-14B、Mistral-Small-3.1-24B，版本依据见[BASELINES](BASELINES.md)。先用已有缓存。选择现有能稳定工作的vLLM/SGLang服务，固定框架版本、权重SHA、chat template哈希和采样参数；不为了追最新版本破坏已有环境。

引擎用独立CPU环境，模型服务器用现有GPU环境。二者通过显式本地接口通信。初始8k输入、512输出是成本上界设计，不是模型最大上下文或推理能力评价；全部方法用同样预算。thinking作为显式条件，截断不得默默当正常回答。无足够思考预算导致的失败不泛化为模型能力结论。

服务只绑定loopback或授权内网，不公布机器IP。请求不能跟随跳转到外部服务，也不使用系统代理转发。系统侧仍需确认本地服务自身没有外部模型回退；客户端URL检查不是完整网络审计。

## 3. 预算不是猜GPU小时

初始B0设计上界：64源任务×4分支×2模型×2种子=1024局；最多12次NPC决策/局；最多8192输入/512输出token每次。最坏计约100,663,296输入、6,291,456输出token。所有分支未必都合格，实际预算按冻结manifest的任务资格计算。

先少量原生流程试跑，测端到端每秒完成决策、GPU利用率/显存、p50/p95、CPU/I/O和失败比例。总wall时间以实测聚合吞吐估算，并另计重试、同模型伙伴和额外计划调用。不能将这个token上界冒充已运行数字。

B1/B2/B3不一开始全量笛卡尔积；根据E03信号优先分配两个最能区分解释的对照，然后补充确认。最终方法比较报告token、调用、wall、任务/约束结果的权衡，不给某个方法无偿更多推理。

多GPU优先独立源任务shard、不同模型和确认种子。相同节点缓存权重和紧凑JSONL，定期汇总轻量结果，不共享盘逐token写大量小文件；不跨节点同步训练。

## 4. 训练不是入场前提

首轮冻结权重。仅当可重复瓶颈明确且存在合格监督/奖励时，才决定单卡LoRA/SFT或小规模RL；生成、rollout、奖励、选择失败都计成本。不是预先把NPC题目改成训练某个小模型多得几分。

既有成本参照：Hypothetical Minds指定GPT4场景约10美元/局，GAMMA全主实验约3600GPUh，Proact-VL含云端judge；细节和来源见[RESEARCH_CALIBRATION](knowledge/RESEARCH_CALIBRATION.md)。这些作者报告不换算为本机预计工时。

## 5. 自然数据与主张边界

先原作者train/validation/test分离，分支按源quest分组。同任务变体/多seed不是独立数据。有限人工审查用在目标含义、分支合法性和关键反例；本地LLM可辅助，不给所有数据自封自动金标。

正式玩家体验需人类证据。当前目标是解释计算/控制行为，所以不承诺“更有趣、更可信、更像人”的玩家研究结论。实习资产与学术公开资产分别授权，不上传私有模型、日志、凭证或机器信息。

## 6. 真实执行状态

本轮没有GPU模型调用，没有LIGHT原生运行，没有数据归档字节恢复。已固定研究选择和代码来源、明确本地完整链及可计算预算。启动所需未完成项不是“再随便找题”，而是BASELINES所列的指定数据/环境恢复和实际服务测速。
