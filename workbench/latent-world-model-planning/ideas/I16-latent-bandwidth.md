# I16｜世界模型变强，latent 距离变短视：有效维度与规划视野（2026-10-07）

- **状态：** PILOT（相关性证据 + 机制分析已有；因果干预与方法在跑）；不登记科学主张。
- **来源：** I15/E21 的规模扫描中，TwoRoom 远目标的 L2-CEM 规划随模型变大而变差，而 PushT 近目标随规模大幅变好；把预测器换成真实模拟器后，排序质量仍随规模下降 → 问题在 latent 几何。
- **核心观察（E22）：**
  1. latent 的有效维度 D_eff（协方差参与比）随模型规模和训练步数上升（TwoRoom 约 8 → 64，PushT 约 13 → 95）。
  2. latent L2 距离作为状态空间上的核，其带宽 ℓ 随 D_eff 按幂律缩短，两个环境、约 180 个检查点：log-log 斜率约 −0.4 ~ −0.6。
  3. 恒等式 1/D_eff = E_{s,s′}[K(s,s′)²]（K 为归一化 latent 核）说明 D_eff 上升必然意味着核变局部；结合数据的关联维数 d_c 可得 ℓ ∝ D_eff^(−1/d_c)（精确指数受带宽估计量影响，暂不作为主张）。
  4. 后果：依赖 latent 距离的规划器（CEM + L2）视野缩短；同一 latent 上学会读取 latent 的控制器（GC-IDM）或学到的代价不受影响（TwoRoom 100%）。
- **已撤回：** “反向缩放集中在跨房间目标”（坐标轴用错）；“指数 = −1/状态维数”（PushT 不符）。
- **反常点（为什么值得兴奋）：** SSL 社区普遍认为表示的有效秩越高越好（RankMe），LeJEPA 证明各向同性高斯对下游探针最优；而对“在 latent 里用距离做规划”而言，有效维度越高，规划越短视。规模和训练时间在这里是双刃剑：它们提升局部保真度，同时缩短规划视野。
