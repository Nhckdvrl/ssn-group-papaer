# I15｜latent world model 的规划能力是否随规模提升（2026-10-07）

- **状态：** PILOT（E21 运行中）；不登记科学主张。
- **对应：** P04/P05（预测改善不转化为规划）；替代 R1–R5 的“局部改动”层级（见 logs/2026-10-07 结构性复盘）。
- **来源（idea 从哪里来）：**
  1. 领域的核心押注（LeCun / JEPA 路线）是“训练更大的预测式世界模型，再在其中规划”。但 2026 年这条线的 120 篇论文几乎都固定在一个 15M 模型上，没有人测过规划能力随规模如何变化。
  2. 已有零散反常信号：Meta JEPA-WMs 发现仿真中更大的编码器没有提升、predictor 深于 6 层反而变差（作者猜测“更大的 embedding 空间让规划的优化地形更难”）；Planning Limits 发现 predictor 放大 81 倍不扩大可规划范围；VIScore / ATM 发现同配置种子之间验证损失几乎相同、规划差很多（欠约束）。
  3. 跨领域：Jones 2021（棋类，单卡测出训练算力与测试时搜索的交换率）、Gao 2023（奖励模型过度优化随规模的规律）、Pearce 2024（world model 损失的幂律，但没测规划）、LLM 测试时缩放（generator–verifier 间隙）。
- **研究动作：** 把“改模型”换成“扫规模”：在同一目标、同一数据上扫模型尺寸（1.7M–285M）、数据量、训练步数和测试时 CEM 预算，每个模型测预测损失、闭环成功率（多个目标距离）、算力曲线，第二阶段测固定候选库上的 best-of-N 真实质量与同 latent 上的摊销策略（GC-IDM）。
- **如果为真，可能的主张（任一都有价值，跑前不预设方向）：**
  - (a) 规划随规模可预测地提升，并存在训练算力↔搜索算力的交换率；
  - (b) 预测随规模提升而规划不提升甚至下降（反向缩放），原因可定位（latent 维度 / 优化地形 / 被搜索利用 / 欠约束）；
  - (c) 搜索的最优预算随模型质量变化（小模型被更多搜索利用，大模型受益）；
  - (d) 随规模增大，摊销策略与搜索的相对价值发生翻转。

- **最便宜的决定性 pilot：** E21 第一批：5 个尺寸 × 2 任务 × 2 种子，全量数据，60k 步；n=200 的闭环评测。看规划成功率 vs 尺寸的曲线是否单调、是否与预测损失同步。
- **阳性对照：** 官方 LeWM 在本评测器上复现论文数字（TwoRoom 88%，PushT 76%，n=50）。
- **噪声地板：** n=200 → 成功率标准误约 3pp；训练种子间差异由种子 0/1 给出。
- **预期论文形态：** 规模科学 / 分析型主文（ICML / NeurIPS），配一个由规律推出的简单方法（例如按模型规模设定搜索预算、或使规划随规模提升的训练改动），在多个环境上验证。
