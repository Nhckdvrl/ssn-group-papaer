# I16 / E21–E24 独立科学审计（2026-10-11）

**性质：** 外部审计意见（READ-ONLY REVIEW），不是新 science claim、不是 E24 结果、不是对用户研究状态的修改。**范围：** GitHub HEAD 的研究卡、代码、聚合 JSON，以及公开近邻论文；未连接实验 GPU、原始 checkpoints 和逐 episode 轨迹，不能声称重新运行训练或 simulator。

**总判断：** I16 有强的 *配置内行为观察* 与有价值的 λ 干预，但「随规模普遍反向缩放」「有效维度是充分机制」「SIGReg 独有」「免训练时间代价修复是新问题」等强主张尚不成立。最值得继续审查的是 *表征统计、时序结构和真实 action ranking 之间究竟哪一种关系具有因果预测力*；但该主题必须与强近邻重新定位，不能凭概念重命名认定 novelty。

## C. 需要优先修正的执行问题

### P0：SFA / auto / metric-horizon 的 episode-level holdout 污染

[GPUData](scaling/wm.py) 和 [eval_set](scaling/eval_plan.py) 使用固定 seed 的 95/5 train/validation episode 切分；但是 [sfa_basis](scaling/eval_plan.py)、[metric_horizon](scaling/eval_plan.py)、[slow_threshold](scaling/eval_plan.py)、[pca_basis](scaling/eval_plan.py) 当前均从**全部 episodes** 抽样。对于 SFA / auto，训练期间的无标签投影及距离阈值使用到了本应留出的评测轨迹。这是 transductive data contamination，不等于读取 success labels，但不满足严格 episode-level holdout。

**修复与重新核实：** 统一复用 eval_set 中的 split_seed、val_frac；在确定好训练 episodes 后仅使用它们拟合 SFA 与 m_h、threshold（训练用帧数/lag 分布记录）；不改变 checkpoint、不重抽原有 test episodes；对相同起点重测 **TwoRoom S×3 / PushT S×3 / PointMaze-large XS、S×3 / 官方 released**，报告原版与 clean 版逐项配对差异。先验证阈值和方法定义再扩大训练。

### P1：raw auto 与部署选择规则不是一回事

[eval_plan.py](scaling/eval_plan.py) 的 auto=4 会**始终**使用双度量切换的具体 MPC；但 E23 D 组提出的**外层 rule** 是「若 m_h < 25 才使用 auto，否则保留纯 L2」，由报告层人工拼接结果，非同一端到端接口。PushT S raw auto off25 72.5% 与 L2 84.5% 就不同；不能标成 final gated policy 的失败/成绩。建议定义单一 policy ID 并将 gate 决定、m_h 训练来源与具体评测 mode 写入每条结果，统一执行脚本。

### P1：相关长度的测量有定义/边界风险

[kernel_ell.py](scaling/kernel_ell.py) 使用 k=1-||z-z'||²/(2Var) 拟合高斯物理距离核、允许 offset/amp 自由；[kernel_bound.py](scaling/kernel_bound.py) 使用中心化内积 K=<zc,zc'>/trΣ。二者**只有样本 latent 范数近似恒定时才可近似互换**，不能直接把后者统计恒等式当成前者拟合带宽的证明。kernel_ell 的 half-decay 若没有任何阈值 crossing，np.argmax 会返回第一个 bin，必须报告 censoring 而不是虚构 half length；拟合也应记录曲线/残差/符号/失败原因。

### P1：m_h 不是自动的“决策有效范围”

[metric_horizon](scaling/eval_plan.py) 把沿行为轨迹的 median L2 在最后 lag 平台的 90% 达到点定义为 m_h。它受环境混合时间、行为政策、episode 时长及帧间距影响；即使真实状态的 oracle Euclidean metric 完全可观测，也可能早早饱和。需要使用同样轨迹测 oracle state L2/ground-truth geodesic、改变 offline behavior policy 和取样时间 stride，检查 m_h 是否仍能独立预测排序 regret / policy gains。Cube m_h 接近 25 的阈值位置尤其敏感。

### P1：规模与因果混杂

[wm.py](scaling/wm.py) 的 size 同时改变 encoder width/depth、predictor hidden、latent output dimension；E21 固定 LR 不是 optimal-per-size，也不是 equal FLOPs。300×30 是相同候选数量，并非 equal compute。原先压低 latent dimension 干预未按预测改变带宽；应被当作因果链的不支持证据，不能以“容量导致 D_eff”一句话兜底。

## D. D_eff：强相关 ≠ 充分解释（独立计算）

[E23_deff_collapse.json](results/E23_deff_collapse.json) 的 26 TwoRoom checkpoints 中，off50 对 log10 D_eff 的事后回归 R²=0.886，off75 R²=0.850；这是真的强关联，但在样本内回归，未跨正则/环境 holdout。以这些记录重新分组：

| 组 | n | mean D_eff | off50 | off75 |
|---|---:|---:|---:|---:|
| S，λ=.27 | 3 | 96.58 | 61.0% | 37.17% |
| L，λ=.09 | 2 | 96.75 | 53.25% | 27.50% |
| XXS，λ=.09 | 3 | 39.29 | 72.33% | 46.83% |
| S，λ=.03 | 3 | 40.56 | 69.0% | 45.83% |

**同一 D_eff 附近存在可观测的不同成功率（例如 off75 +9.67 pp）**，但 n=2 vs 3 不能单凭此断言显著；足以说明强主张需要明确残差与额外变量。把各 λ 整组留出的 *独立事后复算* 中，off75 保留 λ=.27（3 runs）时，其他 λ 拟合的 log-Deff 线预测均值 26.0%，实际均值 37.2%，绝对均差 11.2pp。可作为未来跨配置预测实验的预警，不作为已预注册、严格泛化实验。

**数学反例**：在均匀圆周 θ∼Unif[0,2π) 上取 z_k(θ)=(cos(kθ), sin(kθ))。对每个整数 k，Σ=I/2，D_eff=2、完全相同的各向同性二阶统计；但归一化 kernel K_k(θ,θ')=cos[k(θ-θ')]，近域相关长度随 1/k 改变。故单凭「Σ 各向同性 / D_eff」无法推出空间上的带宽或保留的控制拓扑。注意此例只否定**协方差和有效维度的充分性**，并非对 SIGReg 完整高斯分布约束或特定带额外条件的 Weyl 定理的全面反证。

恒等式 E[K²]=1/D_eff 对独立中心化随机状态成立，是二阶矩代数恒等式；Markov 不等式提供的是尾部**上界**，并不能把 P(K≥.5)·D_eff 当作普适常数，也不能从这项恒等式推出物理距离排序好坏。I16/E22 已撤回的 ℓ∝D_eff^(-1/d) 指数不能复活；更强的频谱次序、光滑性和行为策略条件必须被明示并检验。

## E. 近邻论文的 claim ownership（优先级高于扩做实验）

1. [The Objective Is the Bottleneck (2608.12959)](https://arxiv.org/abs/2608.12959)：已证明 TwoRoom 上 predictor 不是根因、原始 latent L2 远距饱和、官方 checkpoint 用位置 probe/temporal head 换 cost 大幅提高，还**讨论了 effective rank 变化**（但承认 checkpoint 混杂，因果未证）。不能宣称这些基本现象首次发现。完整 PDF 本次核读。
2. [Anisotropic Representations Improve Planning in JEPA World Models (2609.37441)](https://arxiv.org/abs/2609.37441)，即 AnisoWM：直接主张 isotropic Gaussian regularization 导致 task metric mismatch，并以 ΛReg 改进 4 环境规划。**对 I16 的 SIGReg 机制核心形成 direct compression risk**。本次已核摘要与公开项目入口，**尚未取得完整 PDF 供逐节核读**，须列入最高优先补读，不应臆测其消融范围。
3. [How Long, Not How Close / TEMPO (2610.04988v2)](https://arxiv.org/abs/2610.04988)：在 frozen LeWM/PLDM + 11 控制任务，用同轨迹学习 temporal-distance cost，TwoRoom off75 36→99，覆盖 maze、PushT、Cube、Reacher、Ant 等，明确对比时间度量与空间近似。已读其方法、评测与结果。与 SFA 的区别是 TEMPO 的 MLP 需要额外训练并可能在线继续学，SFA 求解特征广义本征问题而不训练 NN；这是 **implementation distinction**，单独不足以证明 scientific novelty。
4. [Temporal Straightening for Latent Planning (ICML 2026)](https://proceedings.mlr.press/v306/wang26n.html)、[Decision-Metric Alignment (2608.18746)](https://arxiv.org/abs/2608.18746)、[Temporal-Distance JEPA (2607.25337)](https://arxiv.org/abs/2607.25337)、[The Planning Limits of Latent World Models (2609.39235)](https://arxiv.org/abs/2609.39235)：已有目标对齐、可规划范围、时间/可达性监督和实际物理/规划差异的谱系。
5. [Latent Geometry Beyond Search / GC-IDM (2605.08732)](https://arxiv.org/abs/2605.08732)：已有在同一 latent 上训练 policy 追平搜索的工作。E23 自己训练的 GC-IDM 是额外监督/训练下的 positive control，不是纯粹说明 “SFA 免训练保留远距离信息” 的同信息/同算力比较。

特别注意： [library/themes/latent-world-models/README.md](../../library/themes/latent-world-models/README.md) **早已列出 AnisoWM 与 How Long Not How Close 并标注 metric geometry 类角度饱和**，但 I16 的 nearest claim-positioning 没有显式逐点与两篇强近邻碰撞。这是知识库未进入真正研究决策的流程失败，不是“没搜索过”。

## F. 下一步最多 4 项关键实验/决定（不先扩模型×数据的大网格）

1. **先修 episode split 泄漏 + 固定外层 rule，并做严格逐起点配对重新评估**。没有这个步骤，SFA / auto 的论文主表不可升级。
2. **做同一 checkpoint 的完整 cost decomposition**：raw L2 / train-only SFA / TEMPO temporal metric（若代码和数据可得）/ oracle state-distance 与环境 geodesic（仅作阳性控制）；同样的 CEM 候选、预测轨迹和计算预算，比较 *真实 simulator candidate ranking*、闭环成功率与绕障害。解释何时几何不行，不能只是每种 cost 各涨点。
3. **做匹配 D_eff 的真正区分性干预**：利用 S(λ=.27) 与 L(default) 等已观察到相近 D_eff 的检查点，再在固定真实候选库上对比短距和长距几何、temporal lag、goal progress、rollout error；检验同样 D_eff 下决策排序是否依旧不同。若不同，放弃 “D_eff sufficient mechanism”，转寻找控制相关谱/动态结构而不是加更多 size。
4. **E24 VICReg 以原先 prereg 运行并如实报告**（当前无可审计输出）。维持 preset 六个模型，不因首次结果不合期待临时重命名 objective；若权重必须调整，清楚标 exploratory。若跨 VICReg 不成立，则将 claim 限定为这类 SIGReg 配方；若成立，仍须正面对照 AnisoWM 与 TEMPO 的 claim ownership。

**人审建议：** 不自动关闭本 territory，不把 I16 升为 candidate；将科学判断分开：（a）观察 TwoRoom vs PushT 不同的规模关系值得保留；（b）SIGReg λ 影响行为有证据；（c）Deff 的「统一解释」尚未证明；（d）时间代价修复与 isotropy mismatch 的基本主张已被强近邻覆盖。决定后续是否争取 mechanism paper 必须看上述实验是否产生 *改变同行认识的增量*，而不是累积更多配置结果。若 clean split + matched cost 显示大部分故事被现有工作解释，应及时转向同一 territory 中更真实的未知，而不是维持原故事继续局部优化。
