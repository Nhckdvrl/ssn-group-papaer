# E23：论文级网格——规模 × 种子 × 环境、SIGReg 因果干预、留出环境上的切换规则、官方模型锚点（2026-10-07）

- **状态：** RUNNING（人 2026-10-07 同意 I16 为本工作台主问题，直接跑论文级实验；本卡在任何新结果出来之前写定）
- **类型：** CONFIRMATORY（对 I16 / E21 / E22 的每条核心说法做可复现、留出的检验）
- **对应：** I16；E21（反向缩放）、E22（度量视野、慢特征代价）；P05（长目标失败）
- **问题（一句话）：** “JEPA 世界模型越大，latent L2 规划越短视；原因是 SIGReg 驱动的度量局部化；按度量视野选择代价可以免训练修复”——这三句话在 ≥3 种子、5 个尺寸、5 个环境、官方发布模型上是否都成立？

## 已看到的读数（不能当作验证）
- TwoRoom S、种子 0、60k 步的 SIGReg 权重干预已出：λ=0.01 → 96 / 80 / 52%，0.03 → 92 / 71 / 46%，0.09（默认，3 种子均值）→ 89 / 63 / 38%，0.27 → 89 / 62 / 38%。这是**单种子**；下面 B 组的种子 1、2 是对它的前瞻复制。
- “度量视野 < 规划视野时才切换”的规则是在看到 PushT 后提出的（POST-HOC），Reacher 一致。下面 D 组在没参与设计的环境上检验它。

## A 组：主现象（规模 × 种子）
- **训练：** 尺寸 XXS / XS / S / M / L（1.7M–285M），种子 0/1/2，60k 步，64px，配方同 E21。
  环境：TwoRoom、PushT（补 M、L 的第 3 种子）；视觉 PointMaze-medium（补齐 5 尺寸 × 3 种子）；Reacher（补齐，L2 应可用的对照）；Cube（新，留出）。
- **读数（每个最终检查点，不挑种子）：** n=200 闭环成功率，CEM 300×30 + 完整 L2；慢特征 k=4；auto 切换 k=4；GC-IDM。度量视野、带宽 ℓ、D_eff。
- **主统计：** 每个环境 × 代价，成功率对 log 参数量的斜率（种子为重复单位，按种子聚类 bootstrap 95% CI）。
- **预测：** TwoRoom 斜率 < 0（CI 不含 0）；PushT > 0；Reacher、迷宫上完整 L2 不随规模变好；慢特征 / auto 在 TwoRoom、迷宫上斜率 ≥ 0；GC-IDM 在所有环境斜率 ≥ 0。
- **决策表：** TwoRoom 斜率 CI 含 0 → “反向缩放”降级为“不随规模变好”，论文改以度量视野为主线；迷宫或 TwoRoom 上 auto 在 ≥3 种子下不再显著高于 L2 → 撤回修复的主张。

## B 组：SIGReg 因果干预（各向同性压力 → 度量局部化 → 短视）
- **训练：** TwoRoom S，λ ∈ {0.003, 0.01, 0.03, 0.27}，种子 1、2（种子 0 已有 0.01 / 0.03 / 0.27）；λ × 规模：TwoRoom XXS、M 在 λ=0.01，种子 0/1；迷宫 S 在 λ=0.01，种子 0/1/2；PushT S 在 λ=0.01，种子 0/1。
- **预测：** (i) TwoRoom S 上 λ↓ → ℓ↑、度量视野↑、off50/75 完整 L2 成功率↑（种子 1/2 复制种子 0 的方向）；(ii) λ=0.01 时 TwoRoom 的规模斜率比 λ=0.09 时更平（反向缩放减弱）；(iii) PushT λ=0.01 近目标不明显下降（≤5pp）；(iv) λ=0.003 可能出现坍缩（D_eff 很低、近目标崩），若出现则作为权衡边界报告。
- **决策表：** 种子 1、2 不复制方向（λ=0.01 的 off50 不高于默认的种子内对照） → 撤回 SIGReg 因果解释，机制只写“与 SIGReg 优化程度相关”；(ii) 不成立 → 规模效应另有来源（写进局限）。

## C 组：官方发布模型锚点（224px，官方配方）
- 官方 LeWM TwoRoom / PushT 发布检查点：度量视野、完整 L2 vs 慢特征 vs auto，n=200，offset 同 A 组。慢特征 / 度量视野用原生 224px 训练帧计算。
- **预测：** TwoRoom 发布模型度量视野 < 25 步、auto 显著高于 L2；PushT 发布模型度量视野 ≥ 25 步、规则保持 L2。
- **决策表：** 发布模型 TwoRoom 上 auto 不优于 L2 → 现象限于我们的 64px 配方，论文需说明（重大降级）。

## D 组：留出环境上的切换规则（POST-HOC 规则的前瞻检验）
- **规则（冻结）：** 在训练轨迹上测完整 L2 的度量视野 mh（90% 平台）；若 mh < 规划视野 25 步 → 用 auto 切换（k=4），否则用完整 L2。k、阈值、规则都不再调整。
- **环境（未参与设计）：** Cube（OGBench 单方块，操作）、PointMaze-large（视觉，长程导航）、visual-antmaze-medium（OGBench 视觉蚂蚁迷宫，H-JEPA 报告单层 18% / 分层 73% 的设定）。
- **读数：** 规则选择的代价 vs 完整 L2，n=200，每环境 S 尺寸 3 种子 + 其余尺寸单种子。
- **预测：** 规则选中的代价在每个环境上 ≥ 完整 L2 − 2pp（不伤害）；在 mh < 25 的环境上 ≥ 完整 L2 + 10pp。
- **决策表：** 任一留出环境上规则伤害 > 5pp → 规则写成局限，论文只报告度量视野诊断与逐环境结果。

## 噪声地板与对照
- n=200 的二项标准误约 ±3.5pp；种子间差异 TwoRoom off50 约 ±5pp、PushT XS 约 ±7pp（E21 已测）。“显著”按种子聚类 bootstrap。
- 阳性对照：GC-IDM（同一 latent）；官方发布模型（评测器锚定，TwoRoom 88% / PushT 76%，n=50）。
- 混杂：λ 同时改变训练损失的尺度（报告预测误差）；迷宫与 TwoRoom 数据采集策略不同；visual-antmaze 的相机跟随蚂蚁（不是全局俯视），与其他导航环境不同——结果分开报告。
