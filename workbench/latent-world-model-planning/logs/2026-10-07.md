# 2026-10-07｜接手：从局部优化回到领域问题

## 本次会话的目标（自设，人确认的方向）
**不是完成整篇论文的实验，而是找到一个能支撑顶会论文的 idea**：问题重要（领域在意、证明后值得兴奋）、有可陈述的 novelty（机制/视角/对象/方法）、可以用我们的资源（单卡/单节点独立实验）通过高信息量实验铺开验证。

完成标准：
1. 建好 latent world model 知识库（领域画像 + 深读论文卡 + 谱系 + idea 来源分析），放 `library/themes/latent-world-models/`。
2. 写出 1 个主问题（以及 1–2 个备选），各有：为什么重要、最近邻与增量、决定性实验、可能的结果各自意味着什么。
3. 用一批高信息量实验验证主问题的核心现象是否真实存在（不是只在 TwoRoom/PushT 一个配置上）。
4. 根据结果给出 idea 判断，交给人审。

## 诊断（接手时）
前 5 天做了 E00–E20 共几十组实验（数千条闭环 episode），科学主张 0。原因判断：实验都在 LeWM/Fast-LeWM × TwoRoom/PushT 上做局部改动（数据配方、CEM、预测头、恢复策略），每次问“这个改动能否涨点”，没有一个统领性的科学问题；结果大多是 CI 跨零的小差异，无法累积成认识。

## 结构性复盘（E00–E20，I07–I14，2026-10-02 至 10-05）

已有数千条闭环 episode、几十次训练，科学主张仍为 0。问题不在执行细节，而在以下七个结构性选择：

1. **领域热度变了，层级没变。** 工作台建立时（10-02）把“紧凑 latent world model 规划”当作热度中低的领域。实测 arXiv 上 LeWM / DINO-WM / JEPA 规划这条子线：2026-01 约 2 篇/月 → 08 月 22 篇 → **09 月 30 篇**（清单见 `library/themes/latent-world-models/ARXIV_LEWM_LINE_2026-10-07.txt`）。前任做过的每个角度在最近两个月都有 2–5 篇并发工作：
   - I14/E20 “center 误差 vs 动作相关误差”分解 ≈ 2610.05550（When Low Prediction Error Misleads Planning）；反事实分支 ≈ FIRM-WM、AD-WM、Do-JEPA、Intervention Gap。
   - I12/E16 决策关键采样 ≈ ToIA/SPARK；I08/E13 多保真 ≈ DeepJEPA；I11/E18 反馈与恢复 ≈ RWM、JEPA-TTT、Sandwich-Residuals。
   - E13 预测对象 / 代价 ≈ The Objective Is the Bottleneck、Aim Short to Reach Far、Planning Limits、RC-aux。
   - E14 目标策略 ≈ Latent Geometry Beyond Search（GC-IDM，8 个设定里 7 个追平或超过 CEM）。
   规则 R1 不允许“桌面判死”，但前任把它执行成了“永远在同一层级继续加小改动”。正确做法是同领域转向到更高一层的问题。
2. **没有统领性的科学问题。** R1–R5 五个“母问题”覆盖了整个领域，等于没有问题；每个实验问的都是“这个小改动能否让 TwoRoom/PushT 的成功率涨一点”。
3. **测量工具的信噪比低于要测的效应。** 主读数是 48 条 episode 的二值成功率，单种子或 3 种子，95% CI 约 ±15pp；而同配置只换训练种子，成功率就在 19/48 到 38/48 之间摆动（E16 固定数据三种子 38/19/36）。绝大多数比较的效应量都在噪声内，CI 跨零，认识无法累积。
4. **基线欠训练，“方法无效”难以解释。** 例如 E14 G1 的 PushT GC-IDM 只用 86 个 episode，得到 1–2/48，而 GC-IDM 论文用全量数据得到 84%；BASE100 在 1680 步时 13/48、5650 步时 38/48。很多负结果其实是训练量问题。
5. **缺少能暴露规律的变化轴。** 所有实验都固定在一个 15M 模型、两个玩具环境、一个数据量；只在“方法”这一维上做局部扰动，因此不可能观察到随规模、数据、算力变化的规律。
6. **审计开销挤占了信息量。** 大量 hash / guard / 预控和极长的日志，精力花在“证明运行没错”上，而不是设计“一次能回答一个问题”的实验。
7. **idea 从“可以改哪里”出发，而不是从“领域不知道什么”出发。** 因此产出的都是近邻已占的小改动。

### 我们想要的问题还能不能做？

- “LeWM + 四个玩具环境 + 一个辅助损失或诊断指标”这一层：**不建议再投入**（同期每月几十篇，审稿人已经饱和）。
- “latent world model”这个领域本身：仍可做，但要换到小组做不了、大组还没做的层级。当前最空的一层是**规模科学**：模型规模 × 数据量 × 测试时规划算力 与规划能力的关系。已有零散信号（Meta JEPA-WMs：仿真里更大的编码器不提升、predictor 深于 6 层变差；Planning Limits：predictor 放大 81 倍不扩大可规划范围），但无人系统测量。这正好用我们“多卡、弱互联、适合大量独立单卡实验”的资源结构。→ I15 / E21。

## E21 中期读数（06:00 JST；未完成，不升级主张）

- 评测器阳性对照：官方 LeWM（224px）TwoRoom 88%、PushT 76%（n=50）。
- PushT offset 25，60k 步，n=200：XXS 18/15/17%（3 种子）→ XS 47/52/60% → S 84%（M、L 训练中）。规模效应大、种子方差小；64px S 档高于官方 224px 发布模型。
- TwoRoom offset 25，60k 步：XXS 95/94% → XS 90/93% → S 88%（持平或略降，约 2 个标准误）。
- 候选库（100 起点 × 113 候选，模拟器真值）：TwoRoom 上随机候选内的排序相关性随规模下降（XXS 0.41 → XS 0.36 → S 0.30）；PushT 上随规模上升（XXS 0.2 → S/M 0.4）。即“世界模型当验证器”的质量随规模的变化方向依环境而反。
- 工程事故：TwoRoom episode 最长 101 步，offset 100 无合格起点，评测进程反复崩溃约 1 小时；已改为 offset 75 并加异常捕获。fvcrc20 曾因候选库构建进程的 torch CPU 线程超订，负载达 443，已改单线程。

### 更正（07:10 JST）
一度用“同房间 / 跨房间”切分 TwoRoom 结果，得到“反向缩放集中在跨房间目标”的结论；随后从数据核对发现墙在状态坐标第 0 维（x=112），门在第 1 维 49±14，之前用了第 1 维切分。按正确的墙重算：offset 50 同房间 XXS 69% → XS 65% → S 58% → S/latent768 53%，跨房间 75% → 66% → 65% → 61%。反向缩放存在但两类目标都有，“绕墙目标上模型精度放大错位代理”的解释不成立，已撤回，不进入任何主张。

## 09:00 JST｜正在成形的 idea（I16）：世界模型变强，latent 距离变短视

证据（全部 n=200 闭环、留出 episode；种子数见括号）：
1. **TwoRoom 反向缩放（CEM + L2）**，所有搜索预算一致：offset 50（300×30）XXS 72%（3）→ XS 66%（3）→ S 63%（3）→ M 53%（2）；offset 75：47% → 41% → 38% → 29%；offset 25：94% → 92% → 89% → 86%。
2. **PushT 正向缩放**：offset 25 XXS 17% → XS 53% → S 85% → M 87%；offset 50 饱和约 40%；搜索预算从 300×30 加到 1000×30 无提升。
3. **度量局部化随规模单调**（相同训练步数）：TwoRoom 20k 步 ℓ 13.5（XXS）→ 8.7（L），PushT 113 → 42；有效维度同步上升。约 180 个检查点上 log ℓ 与 log D_eff 斜率约 −0.4 ~ −0.6。
4. **真实动力学代价**（把预测器换成模拟器）排序质量也随规模下降 → 失败来自几何，不是预测误差。
5. **免训练修复**：只在 latent 的慢特征（SFA）子空间里算 L2：TwoRoom S offset 50 62% → 96–97.5%，offset 75 41% → 92.5–93.5%；768 维 latent 模型 57% → 97.5%。慢特征距离与真实距离的 Spearman：远距离 0.13 → 0.70。PCA 截断无效（SIGReg 下协方差谱平，主成分方向任意）。
6. **同一 latent 上的读取器不受影响**：GC-IDM TwoRoom 全部 100%；PushT GC-IDM 随规模变好且远超 CEM（M：95% / 83.5% vs 89% / 41%）。学到的时间距离代价修复 TwoRoom（约 99%），但对 PushT 无效（PushT 的远目标瓶颈在开环搜索）。

撤回 / 未支持：跨房间切分（坐标轴错误）；指数 = −1/状态维数（PushT 不符）；“D_eff 因果决定 ℓ”尚未得到干预支持（压低 latent 维度后 D_eff 降了，但 ℓ 没有按拟合关系变长）。

下一步：迷宫（OGBench pointmaze-medium 视觉化，长程导航）上复现反向缩放与慢特征修复；规模 × 技巧；Reacher / Cube。

## 11:00 JST｜迷宫复现（OGBench pointmaze-medium-navigate，视觉化渲染，阳性对照 100%）
- CEM + latent L2：XS offset 50/100/200 = 20% / 20% / 13.5%；与尺寸无关（20k 步 XXS 18.5%、XS 19.5–21.5%、S 21%），与搜索预算无关（30×3 ~ 300×30：20–23.5%）。
- 同一 XS 检查点（20k 步），只换代价：慢特征 k=4 → 88.5% / 77.5%（offset 50/100）；k=2 → 57.5% / 47.5%；多尺度（完整 L2 + 慢特征等远场权重）→ 26.5%（完整 L2 项在迷宫里主要是噪声，权重需随距离自适应）。
- GC-IDM（同一 latent）：100% / 100% / 99.5%。
- SIGReg 权重干预 20k 步读数不单调（λ=0.01：93.5/64.5；0.03：73/36.5；0.27：83/51；默认 0.09：88/67），等 60k 与带宽测量。
