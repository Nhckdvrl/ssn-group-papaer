# 数据是科学对象的载体（2026-10-03）

**当前要识别：** 对同一个具体隐含意思，模型能否区分自然语境中的支持与不支持，以及总体推断倾向如何变化。来源归因、角色和修复不是当前独立实验目标。

## 原对象纠偏后的数据准入（2026-10-03）

主对象恢复“何时应超越字面、何时停止”；来源归因仅为解释账户。先在一个现象上形成合格测量，不继续用邻接任务分数代替许可。

1. 每项固定目标表达u、候选隐含命题q和判断强度；明确q有哪些内容来自字面、有哪些需要语用补全。许可字段不能只标整句literal/pragmatic。
2. 优先保存同一u/q的受控语境变化；不是每个现象都必须强做完全配对。区分支持q、依据不足、支持反面；意图取消和事实反驳另列层次。保持答案词串/问法固定，保留human原量尺、参与者/项目结构、歧义/未定，不将Likert线性缩放为概率。
3. “不支持q”不能由q事实上为假、删去全部语境、相邻任务答案不同、human没选q或说者人格评分高自动推出。记录规范依据与适用的交际问题。
4. 优先沿用可信原source/理论与human规范；改造语境则旧human标签不会自动迁移。OpenCode只辅助起草/逐项风险审计，不能补造human norm。先完成少量语义核查和可行性卡，再决定规模。
5. 模型开跑前冻结筛选/分组与场景split；不按受测模型表现删项。逐项查语境自然性、target是否适用、两侧难度、literal理解、标签词/域shortcut与完整输出支持。
6. 开跑问题是“同一q在支持/不支持条件的响应是否更分离，以及总体倾向怎样变化”；按现象报告两侧。SDT只在许可/响应规范成立时使用，graded条件保留原分布。d′/c不直接等于内部能力/机制。
7. 技术gate仅保证代码/数值，语义gate需独立依据；不能要求一个错误或歧义的控制全过后才允许研究，也不能将控制失败直接判模型无能力。已知失败先定位源/任务/接口。

E66已确认ImplicatureX 271 canonical有两条件原human判断，2285评分按源过滤精确复现；243项actual-seen q/场景文字匹配，28项版本差异单列。**现成graded条件数据存在，不再笼统说没有合适human数据**；但它不自动提供支持/依据不足/反驳的三态许可gold。32项root语义pilot非独立人类裁决。baseline/cancel为核心，prior/irrelevant/negation/strengthen没有对应human norm，不继承gold。C02的硬许可识别仍L0。

上述243是presentation-normalized匹配，不是全部可见刺激等价；16项模型的字面speech annotation tags可能在人类innerHTML被隐藏。E66另列UI风险，E67保留原冻结cohort并报告227无该风险的技术敏感性；不能把norm去tag的结果直接称byte/语义刺激相同。判断框架差异仍保留。

E67/E68有限检验已收尾：正常Qwen格式端点可描述graded条件响应；OLMo2阶段gate失败且没有新的稳定证据响应结构，不继续局部协议优化。只有确切缺失条件能区分保留下来的解释，才提20–30草案、独立盲审/小human规范；本轮未触发新数据生成。机器共识仍不能替代gold。

## 数量、质量与自然性

- Wavelength有50concept pairs/100clues，人类4000评分不是4000不同情景。模型读数、条件变体、独立场景与human raters分别计数；不靠多个prompt或checkpoint扩大数据样本量。
- 数量依据待区分解释和预定效应，而非追齐榜单。配对效应SD、item/human异质性决定CI与power；在pilot后用未选取的全量方差做事前模拟，报告多个合理效应/方差假设，再冻结新的独立收集集。两个排列检查history噪声，不能扩大样本n。
- 原心理语言学材料是人写的controlled stimuli；Circa/IQAP是另一类自然表达。自然性、控制性与norm依据分别记录。自然的问题应落在真实表达和可信情景上，少量counterfactual只用于可区分干预；不能以大量模板替代自然覆盖。

## 改造和逐条检验

每个item记录来源/版本/hash、原文、改动、phenomenon、固定候选含义、证据改变哪一个前提、映射/标注依据、歧义与缺失。分清signal fidelity、事实真假、epistemic access、world prior、QUD与回答目标；不把partial access全部标unlicensed，不给implausible句硬造唯一gold。

现成数据不能满足时，可从原语料筛场景、增加证据条件或请模型起草变体；保留原项和变体关系，注明counterfactual构造。选择规则在模型结果前冻结；相同场景所有条件放同一split，留新的场景/表达类型作外部验证，防止模板/lexical cue驱动结果。

逐条查：原句含义、候选互斥/覆盖、证据能否区分解释、改动是否泄漏答案、是否改变任务难度或可信度、label由人类norm/逻辑/草稿judge哪一种支持。机器schema/IDs/hash可全量硬核对；语义judge必须盲于模型预测、stage和预期效应。分歧原样保存，不能多数票自动gold。确需human norm而暂无时保留“未定”，只测条件响应，不写应当/不应当或FPR。

OpenCode可用于逐条独立审计/构造草稿，使用公开语言字段、JSON schema和失败留档；不要把模型同意当可靠标签。2026-10-03新试官方longcat-2.5-preview-free仍403，0可用标注；不伪称已逐条语义审查。接口可用后先用已知阳/阴控制校验，再全量审计，结果与原gold分开存。
