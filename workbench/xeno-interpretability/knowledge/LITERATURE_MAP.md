# Xeno 的问题地图、方向选择与解释空白（2026-10-12）

## A. 真正的科学问题
Xeno 的独特关切是**semantic accessibility**：一个稳定且在模型自然计算中起作用的表征，是否一定能被当前人类概念充分捕获？它不等于 feature unknown、难命名、无法 verbalize、某方向 steering 成功或任意 latent geometry。

**更自然的起点来自原论文的观察者偏差**：可解释性研究经常先给出“诚实/拒绝/某物体”等人类类别，再用概念样本定位内部结构。这样的发现结果在人类概念上富集，究竟是模型确实这样组织信息，还是观察方法造成的 selection effect？即使后一种成立，能否在**不预先贴语义标签**时，找到对行为有解释力的模型原生**关系、功能和组合规律**？

## B. 文献是怎样逐步逼近这个问题的

| 谱系（按科学压力，而非工具） | 被解决的部分 / 改变的假设 | 对 Xeno 仍开放的层次 |
|---|---|---|
| 概念标签与描述：Network Dissection/TCAV → Gur-Arieh ACL25 → Ma NeurIPS25 | 人类先验与 input-only 描述不可靠；输出侧干预、hard negatives 改善解释 | **用不同发现程序会不会改变我们以为模型“表示了什么”？** |
| 无标签因果发现：Goyal NeurIPS25 Spotlight → FEGA 2026 preprint | 无需人工概念标签可发现行为相关的隐变量；单个 latent 的效应可能依赖上下文并形成高维云 | 无标签得到的可重复**关系规律**，是否具有对人类语义描述之外的预测增量？ |
| 表征对象与相互作用：SAE → PolySAE ICML26 → Shafran ACL26 → Paulo/Belrose ICLR26 | 单特征/线性加和未必足够；同数据不同 SAE 可学不同解释单位 | **关系/操作**是否比单独 feature 更接近模型天然功能单位？如何避免只靠更强拟合模型取胜？ |
| 表征几何的重新归因：Platonic ICML24 → Gröger ICML26；Nava/Wyart NeurIPS26 | 全局趋同可能是宽度/层数指标偏差，局部邻域关系更稳；层级几何也可能由**词共现统计**解释 | 哪些跨模型/跨上下文关系经过**数据统计、尺度与选择校准**后仍是真实的计算结构？ |
| 因果解释有效性：Geiger JMLR25 → Sutter NeurIPS25 → MIB ICML25 / Joshi ICML26 Position | 高拟合/高解码分数/自由非线性抽象可能无法识别真实因果机制 | 何种**预先可反驳的操作性描述**真正解释未见过的干预与新输入？ |
| 跨学科方法：Golan et al. Nature Rev Neurosci26 / 表征偏差 eNeuro26 | **主动挑选两种解释预测分歧最大的自然刺激**；高方差/显著性不等于功能重要性 | 把“解释 A/B 为什么不同”变成高信息量实验，而不是继续画相似度图 |

**强近邻的具体边界（不得重申为原创）：** Goyal=无标签因果概念发现；Ma=语义解释否证；Gur-Arieh=input/output 双侧描述；PolySAE=组合特征训练；FEGA=上下文效应几何；Gröger=相似性 null calibration。我们要问的是这些科学结论**组合后还留下的解释缺口**，不能分别改名发明一遍。

## C. 五种竞争解释；不得先假定 Xeno 成立
- **H0 人类概念本来足够**：强的组合/程序/输出侧解释，在 matched complexity 与独立测试上已预测全部重要的计算关系。
- **H1 观察者偏差**：human-seeded 与语义盲的发现程序在效应强度等匹配后仍系统性恢复不同类别的变量；盲发现的功能结构未必不可解释。
- **H2 解释单位错误**：单个 SAE latent 的语义不一致，组合关系/条件性操作才是稳定的科学对象。PolySAE/FEGA 已触及，不能仅报它们已知现象。
- **H3 假结构**：空间维数、层搜索、数据共现、SAE 重建误差、off-manifold 干预及 post-selection 造成看似 model-native 的结构。
- **H4 相对给定解释类的语义缺口**：当 H0–H3 的强对照通过后，某些可稳定复现的**功能性关系规律**依然明显超出当前最强人类概念解释的跨情境预测能力。只能称给定解释类/预算下的缺口，不能声称“原则上人类永远无法理解”。

## D. 候选探索空间比较（不自动关掉其他空间）
1. **发现程序的语义选择偏差**——*初步优先*。问题直接来自 Xeno §2–4；可复用 Goyal/SAEBench/FEGA 与描述基线，且无论偏差有无都可能改变如何解读当代可解释性证据。**风险**：如何公正量化“可解释性”和匹配发现工具的选择范围。
2. **上下文条件下何种关系/操作是自然单位**——与 1 同场测量，先不另立工作台。FEGA 表明单方向不足，PolySAE 表明交互重要；更强问题是**能否从匿名结构预测尚未见到的计算效果**，而不只是发现多维几何。**风险**：与 FEGA/PolySAE 的 incremental claim 撞车。
3. **模型内外共享与非共享的局部关系**。Gröger 校准后 local alignment 仍保留；要独立排除训练语料、任务共同性、共享人工语义。可能很深，但发现阶段易被宽度/样本/语义 confounds 吞没，作为第一方向的跨模型追加轴。
4. **奇异跨领域插值与“外星”形态**。原论文§5 的例子是设想；任意向量插值没有模型意义，off-manifold 风险大。目前只是哲学上有趣的引导，不选择它作为首批主要读数。

**选择依据（interestingness 优先）：** 如果 1+2 最终成立，领域会重新评价“我们反复找到熟悉概念”到底证明了什么，并可能发现预测能力更强的关系型解释单位；如果否定，则可为 Xeno 主张划清重要的**经验边界**。但 null 结果本身不自动构成高质量论文，必须以强跨情境证据解释其原因。

## E. 方法与资源边界
先复现成熟实验仪器，再在独立数据上测**自然干预结果能否被先验概念和语义盲关系分别预测**；用负对照/预先固定的假设分支避免“找个未命名特征”自证。对模型空间的跨层/跨模型几何比较必须用 Gröger 的**含最大层选择的 null calibration**。FEGA 的 Gemma-2-2B 实验是有现成工具的一个起点，**不是把 Xeno 研究限定为 2B/SAE 或任何固定任务**。
