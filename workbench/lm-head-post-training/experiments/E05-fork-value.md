# E05：RL 在分叉处的改选是否沿着 Base 的“软价值”方向？（2026-11-27）
- **状态：** DONE（两家族；结论为负）
- **类型：** PILOT / 机制检验
- **对应：** I05
- **问题（一句话）：** 当 RL 后训练模型在分叉位置把 Base 的第二候选提到第一时，被选中的 token 是否在 Base 自己的续写下更可能答对（软价值更高），或续写更自信（序列级锐化），还是两者都不是？
- **理论预测（不是我们的贡献）：** KL 正则 RL 的最优逐步修正 = log Z(x, y<t, ·)，Z 为 Base 续写下的指数化奖励（Cohen et al. 2607.22837 式 4；Korbak et al.；Rafailov et al.）。0/1 奖励下，Z(c) 随“接 c 后 Base 续写的答对率”单调。序列级幂分布锐化（Karan & Du 2510.14901）则偏向续写似然更高的 token。两者可以不一致。
- **动机（来自 E04）：** 两条后训练谱系（Qwen3-8B 强到弱蒸馏、OLMo RL-Zero 纯 RLVR）在分叉处都不锐化，而是改选 Base 的第 2/3 候选（RL-Zero 多为 Wait/Therefore/no）；Base 降温能拿到约 72% 的增益（E04-B），但真实 RL 模型的路径不同（E04-A2/A3）。
- **设置：**
  - 谱系对：OLMo-3 Base→RL-Zero-Math（纯 RLVR，最干净）；Qwen3-8B-Base→Qwen3-8B（参照）。
  - 分叉来源：子模型自己在 MATH-train 128 题上的生成（E04 的 gen_child 上下文），平均熵 ≥0.5。改选分叉 = 子首选 ≠ 父首选；对照分叉 = 两者一致。每对抽 300 个改选分叉 + 100 个一致分叉，按题目分层，seed 0。
  - 候选：c_base = 父首选，c_post = 子首选，c_alt = 父模型中除这两者外排名最高的 token（多为第 2 或第 3 名；“任意换一个合理 token”的对照）。
  - 续写：prefix + c 之后用父模型以 T=1 续写 K 次直到停止，统一停止符；用同一 verifier 判对错；记录续写的平均逐 token logprob。Qwen：K=8、上限 2048。OLMo：原定 K=8、上限 4096，在 fvcrc20 上吞吐只有约 900 token/s（预计 5 小时），运行 23 分钟后改为 K=4、上限 3072 重跑（改动发生在看到任何结果之前）。
- **读数：** 每个分叉的 v(c)=K 次续写的答对率、ℓ(c)=续写平均 logprob；改选分叉上 v(c_post)−v(c_base)、ℓ(c_post)−ℓ(c_base) 的均值与按题 bootstrap CI；子模型对两候选的 logit 差变化 [Δz(c_post)−Δz(c_base)] 与 log[v(c_post)/v(c_base)] 的相关（软价值理论预测为正）；c_alt 的 v 作为“任意换一个 token”的基线。
- **阳性对照：** 一致分叉上 v(c_post)=v(c_base) 严格成立（同一 token）；随机重复两次续写的 v 差分布给出蒙特卡洛噪声地板；续写用的 vLLM 父模型与 E04-B 的 Base 基线一致。
- **噪声地板 + MIE：** K=8 时单分叉 v 的标准误约 0.18；以分叉为单位聚合 300 个，再按题 bootstrap。有意义 = 均值差的 CI 不含 0，且量级（≥0.05）足以支持“RL 改选有价值导向”。
- **混杂审计：** 分叉取自子模型的生成，上下文对子模型有利（只影响可比性，不影响同一上下文下两候选的配对比较）；v 由 Base 续写定义，反映的是“Base 视角下的价值”，正是理论所指；长续写截断按答错计，单独报告截断率；同一题多个分叉不独立，按题聚合。
- **决策表（跑之前写）：**
  - v(c_post)>v(c_base) 显著、且与 logit 改变正相关 → RL 的分叉改选与软价值修正一致：真实 RL 模型在执行“价值导向的重排”，而 Base 降温只是近似（锐化取众数）；这是本工作台可以成形的核心发现，下一步查它在头/骨干中如何实现，以及 SFT 是否不同。
  - ℓ 更高但 v 不更高 → 更像序列级锐化而非奖励价值。
  - 两者都不更高 → RL 的改选主要是风格/格式（与准确率无关），剩余增益来自别处；回到 D 的结果解释。
  - 只在 OLMo 成立、Qwen 不成立（或反之）→ 记录家族差异，不外推。
- **算力预算：** 每对约 300×3×8 + 100×2×8 ≈ 9k 次续写，约 5–8M token，vLLM 单卡 30–60 分钟；分叉抽取前向 <10 分钟。合计 ≤3 GPU·时。**实际：** Qwen 父续写约 40 分钟、子续写约 70 分钟；OLMo 父续写（K=4）约 2 小时，子续写约 1–2 小时；合计约 5 GPU·时（超出预算，OLMo 长回答所致）。

**子模型续写（`--continue_with child`，`fork_value_*__childcont.json`；同一批分叉，由后训练模型续写，检验“价值只对自己有效”）：** Qwen（K=8）：v(c_base)=0.728，v(c_post)−v(c_base)=+0.007 [−0.008, 0.021]，v(c_alt)−v(c_base)=+0.002 [−0.013, 0.016]，相关 −0.07，一致分叉蒙特卡洛地板 0.068，截断 11%。后训练模型续写的整体答对率更高（0.73 vs Base 续写 0.64），但分叉上选哪个候选仍无差别。OLMo RL-Zero（K=4，上限 3072）：v(c_base)=0.509，v(c_post)−v(c_base)=+0.006 [−0.015, 0.029]，v(c_alt)−v(c_base)=+0.006 [−0.013, 0.026]，相关 −0.09，ℓ 差 +0.002 [−0.001, 0.005]；改选为 Wait 等反思标记的 28 个分叉 −0.054 [−0.125, 0.018]。|Δv| 0.077 不超过地板 0.087；|Δv|≥0.5 的 17 个分叉中子模型首选更好 7 个。续写截断 56%（RL-Zero 回答长，上限 3072；按答错计，配对比较不受影响，但 v 的绝对值偏低）。两家族结论相同：由后训练模型续写时，分叉上选哪个靠前候选都一样。

**真正决定结果的分叉（事后补充分析，零 GPU，POST-HOC）：** 与一致分叉的蒙特卡洛地板比，Base 续写下改选分叉的 |Δv| 有超出（Qwen 平均 0.115 vs 0.077，|Δv|≥0.25 占 23% vs 12%；OLMo 0.120 vs 0.107，|Δv|≥0.5 占 11% vs 6%），即约一成分叉的候选确实影响 Base 的结果。只看这些分叉，后训练模型的首选是否是更好的那个：Qwen 32/70（|Δv|≥0.25，p=0.55），OLMo 15/34（|Δv|≥0.5，p=0.61），与随机无异（噪声对两候选对称，按 |Δv| 筛选不偏向任一方向）。Qwen 子模型续写下 |Δv| 与地板相同（0.070 vs 0.068），没有可筛选的决定性分叉。

RL-Zero 中改选为 Wait 等反思标记的 28 个分叉：−0.018 [−0.098, 0.063]。OLMo 续写截断率 44%（3072 上限，按答错计，两候选配对比较不受影响）。
**结论（按决策表第三行）：** 在熵定义的分叉处，选 Base 首选、子模型首选还是另一个高排名候选，对 Base 续写的答对率没有可测影响（分辨率约 ±0.02）；子模型的 logit 改变与价值差无相关。软价值修正的局部预测在这些位置不成立；RL 的改选主要承载风格（Qwen）与反思标记（RL-Zero），不是价值导向。这也说明熵定义的“分叉”大多不是决定结果的分叉。
