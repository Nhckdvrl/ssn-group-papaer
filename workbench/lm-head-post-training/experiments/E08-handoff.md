# E08：后训练模型的优势能否交给 Base 继承？（前缀交接，2026-11-27）
- **状态：** RUNNING（第一阶段）
- **类型：** PILOT / 机制检验（单模型 vLLM 为主）
- **对应：** I05；接 E05（单分叉价值）、E07（选择效应的条件）
- **问题（一句话）：** 由一个模型写出前 L 个 token、交给另一个模型续写时，答对率取决于谁写了前缀、还是谁在续写？Post 写的前缀能否被 Base 继承，Base 写的前缀能否被 Post 挽救，这在易题、难题和两个家族上是否不同？
- **动机：** E05 中单个分叉上换哪个候选几乎不影响结果，换谁续写影响大（0.73 vs 0.64）；E07 中难题上 Base 只在高熵分叉处取 Post 首选（约 41 处）就接近 Post。近作已经报告短开头（2610.06851：OLMo 开头 cue、两 token 交换）、前段替换（Shen et al. 的 early-only）、稀疏替换（2610.24663）能恢复多少增益，但没有在同一组题上同时测：多个前缀长度、两个方向、同一前缀上两个模型的续写能力差，以及它与 B2（分散分叉）的比较。
- **设置：**
  - 模型对：Qwen3-8B-Base → Qwen3-8B；OLMo-3 Base → RL-Zero-Math（Base 一律强制开头 “.\n\nOkay, let's”，即 2610.06851 的 cue，交接从开头之后算起）。
  - 题集（第一阶段）：Qwen：`math_l5`（与 E07 相同的 300 题子集）、AIME 2022–2025（120 题，`build_inputs.py --export-aime`）；OLMo：`math_l5` 300 题。第二阶段视结果加 `m500e`、`olymp`。
  - 解码：T=0.6、top-p 0.95；每条回答（前缀 + 续写）最多 8192 个生成 token；同一个 verifier。
  - L=0 锚点（`e04_generate.py`）：Base、Post、**B1**（Base 在 T=1 熵 ≥0.5 处取首选，其余照常采样；`--fork_argmax 0.5`，单模型实现，处理器在温度之前执行），Qwen 每题 8 个样本，OLMo 每题 4 个。
  - 交接（`e08_handoff.py`）：前缀取自锚点的前 2 个样本；L ∈ {32, 256, 该回答长度的 50%}；前缀中已出现 `\boxed` 或 “Answer:” 的不用（不交出已完成的解）。续写组合：Post 前缀 → Base / B1 / Post；Base 前缀 → Base / Post。每个前缀续写 1 次。
- **读数：**
  - V_M(s)：模型 M 从前缀 s 续写的答对率。同一前缀上的续写能力差 G(s) = V_Post(s) − V_Base(s)，分 Post 前缀与 Base 前缀、按 L 报告（按题配对 bootstrap）。
  - 继承：V_Base(s_Post, L) 相对 Base 自身（L=0）与 Post 自身的位置；挽救：V_Post(s_Base, L) 相对 Post 自身的下降。
  - Post 前缀 → B1 与 → Base 之差（交接后随机性的代价），并与 E07 的 B2（分散分叉，每题 1 样本，上限 4096，口径差异需注明）对比。
  - 长度与截断：交接后续写的长度是否保持来源模型的长度。
  - 等算力：B1 的 8 个样本做多数投票（maj@k），按平均总 token 数与 Post 单次、E07 的 B2 比较。
  - 前缀合格率按 L 报告（越长的 L 合格的回答越少且偏难，比较只在同一前缀上做配对）。
- **阳性对照：** Post 前缀 → Post 续写应与 Post 自身（L=0）接近（同模型重新续写）；Base 前缀 → Base 续写同理。B1 的 vLLM 实现与 E07 同步解码的 B1（`math_l5` 53.0%，单样本）应在噪声范围内一致。
- **噪声地板：** 每个 L、每个组合约 600 个前缀（300 题 × 2），按题聚合后单条件 CI 约 ±4 点；AIME 只有 120 题，CI 约 ±6–8 点，只作方向参考。
- **混杂审计：** 前缀合格条件随 L 变化（选择偏差，只做同前缀配对比较）；50% 相对位置依赖回答长度（Post 回答更长，其 50% 位置在绝对 token 上更靠后）；OLMo 的强制开头本身就是已知的大效应（2610.06851），所有 OLMo 比较都在开头之后；Qwen3-8B 是多阶段谱系，OLMo RL-Zero 是纯 RLVR。
- **决策表（跑之前写）：**
  - Post 前缀在 L ≤ 256 时就使 G(s_Post) ≈ 0（Base 续写追平 Post 续写），且 V_Base(s_Post) 接近 Post 自身 → Post 的优势主要通过早期建立的推理状态传递，可被 Base 继承；下一步比较这种继承与 B2 的分散分叉，问“多早、多少”。
  - 即使 L = 50%，G(s_Post) 仍明显为正（≥ 参照差距的一半）→ 优势需要持续的续写决策，不能靠前缀继承；与 E07 的 B2 一起说明是持续而非一次性的作用。
  - 双向不对称：Post 能挽救 Base 前缀（V_Post(s_Base) 接近 Post 自身）而 Base 继承不了 Post 前缀 → 后训练的优势在于续写/纠偏能力；反之（Post 也挽救不了，但 Base 能继承）→ 路径依赖、早期状态决定结果。
  - 以上在易题与难题、Qwen 与 OLMo 之间不同 → 记录条件依赖，作为第二阶段的重点。
  - 所有曲线平滑、且能被长度/预算简单解释（例如 B1 多数投票在相同 token 数下追平 Post）→ 如实接受，不为交接曲线构造贡献，回到 E07 的选择效应。
