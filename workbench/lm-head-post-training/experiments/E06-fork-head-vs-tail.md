# E06：分叉处承载增益的是“首选”，还是“不抽到尾部”？（2026-11-27）
- **状态：** DONE
- **类型：** PILOT / 机制检验
- **对应：** I05；接 E04-D、E05
- **问题（一句话）：** Post 只在 Base 高熵位置改用 Base 采样就从 78.8% 跌到 48.6%（E04-D 反向）。这 30 点是因为 Base 在那里的首选不如 Post 的，还是因为 Base 的 T=1 采样会抽到低概率候选？
- **动机：** E05 显示单个分叉上换哪个靠前候选对结果没有可测影响，而且在真正影响结果的分叉上，后训练模型押对的比例与随机无异（Qwen 32/70，OLMo 15/34）。Post 续写时，接哪个靠前候选的 |Δv| 与蒙特卡洛地板相同。如果“靠前候选之间无所谓”在整条轨迹上也成立，那么反向交换的损失应当来自 Base 的低概率候选；如果不成立，就是 E05 单点分辨率看不到的累积改选效应。
- **设置：** Qwen3-8B-Base / Qwen3-8B，MATH-500 全部 500 题，每题 1 样本，`qwen_chat` 模板，两模型同步解码（`scripts/e04_hybrid.py`），分叉 = Base 熵 ≥0.5，与 E04-D 完全相同，只新增三个条件：
  - `post_basemode`：Post 全程，分叉处取 Base 众数。
  - `post_basetrunc`：Post 全程，分叉处从 Base 的分布采样，但只保留 p ≥ 0.1·p_max 的候选（min-p 0.1，Base 的“头部”）。
  - `base_basetrunc`：Base 全程，分叉处同样只从 Base 的头部采样（正向的对照：只去掉 Base 尾部能拿回多少）。
- **读数：** 准确率与按题 bootstrap CI；与 E04-D 已有条件（Post 78.8、Post+Base 采样 48.6、Base 43.6、Base+Base 众数 71.6）按题配对差；解析失败、截断、分叉占比。
- **阳性对照：** E04-D 已验证的工具（缓存逐步与完整重算一致，thr=1e9/−1 退化为单模型）；`post_basemode` 在分叉处与 Post 众数一致的位置（约 60%）与 Post 采样只差随机性。
- **噪声地板：** 每题 1 样本，单条件 CI 约 ±4 点，配对差 CI 约 ±3–4 点；小于 4 点的差别不解读。
- **混杂审计：** 取众数同时降低解析失败（E04-D 中 13.6%→2.8%），单独报告；Post 轨迹中 Base 分叉占 41%，比正向的替换范围宽；min-p 0.1 的截断位置是事先固定的，不调。
- **决策表（跑之前写）：**
  - `post_basemode` 与 `post_basetrunc` 都接近 Post（差 ≤4 点）→ 靠前候选之间无所谓在整条轨迹上也成立，反向交换的损失来自 Base 的低概率候选；后训练在分叉处的有效作用是不再抽到这些候选，改选几乎不贡献准确率。论文的位置性说法为“增益位于 Base 高熵位置，载体是这些位置上低概率候选被压掉”。
  - `post_basemode` 接近 Post，`post_basetrunc` 明显更低 → Base 头部内部的随机性本身也有害，后训练的作用是把头部质量集中，而不只是去掉尾部。
  - `post_basemode` 比 Post 低 ≥5 点 → Base 的首选在 Post 的上下文中确实更差，存在 E05 看不到的累积改选效应，“首选无所谓”只在单点成立。
  - `base_basetrunc` 若接近 `base_basemode`（71.6）→ 正向的 80% 也主要来自去掉尾部；若明显更低 → 正向需要的是确定化，而不只是截尾。
- **算力预算：** 每个条件单卡约 1–1.5 小时（E04-D 实测），三个条件并行 3 卡（fvcrc11 GPU0/2/3），≤5 GPU·时。
- **运行偏差（看到最终结果前记录）：** `post_basetrunc` 在批 32 下第 6 批显存溢出（已完成 192 题），改为批 16 断点续跑，并把剩余题目拆到两卡：前 350 题续跑（seed 0），第 350–499 题另起（seed 1，标签 `h_post_basetrunc_b`），汇总时合并。每题仍为 1 个独立样本，题目集合与其他条件相同。
- **补充条件（看到三个条件结果后加，POST-HOC 设计）：** `post_postmode`：Post 全程，分叉处取 Post 自己的众数。它与 `post_basemode` 只差“谁的首选”，两者都去掉了分叉处的随机性，格式效应相近，是 Post 上下文中最干净的选择效应对照（2×2：上下文 Base/Post × 分叉处 Base/Post 的众数）。同样拆两卡（前 250 题 seed 0，后 250 题 seed 1）。
- **结果（2026-11-27，`results/e04/hybrid_qwen.json`，MATH-500 500 题，每题 1 样本）：**

| 条件 | 准确率 [95% CI] | 解析失败 | 截断 | 分叉占 token |
|---|---|---|---|---|
| Post | 78.8 [75.4, 82.6] | 9.0% | 9.8% | 23.7% |
| Post，分叉处取 Post 众数（补充） | 80.8 [77.2, 84.2] | 4.6% | 5.2% | 18.5% |
| Post，分叉处取 Base 众数 | 76.0 [72.0, 79.8] | 0.6% | 0.6% | 17.8% |
| Post，分叉处从 Base 头部（min-p 0.1）采样 | 66.0 [62.0, 70.2] | 3.2% | 2.6% | 21.5% |
| Post，分叉处从 Base 全分布采样（E04-D） | 48.6 [44.2, 53.0] | 12.6% | 7.8% | 40.9% |
| Base，分叉处取 Base 众数（E04-D） | 71.6 [67.6, 75.8] | 2.8% | 3.6% | 9.8% |
| Base，分叉处从 Base 头部采样 | 60.4 [56.2, 64.6] | 5.2% | 2.8% | 13.9% |
| Base | 43.6 [39.2, 48.2] | 13.6% | 7.6% | 31.7% |

  - 配对差：Post − Post/Base 众数 = 2.8 [−0.4, 6.0]；Post/Base 众数 − Post/Base 头部采样 = 10.0 [6.2, 13.8]；Post/Base 头部采样 − Post/Base 全分布 = 17.4 [12.6, 22.2]。Base 侧：Base 众数 − Base 头部采样 = 11.2 [6.8, 15.4]；Base 头部采样 − Base = 16.8 [11.8, 21.6]。
  - **按决策表：** 第二行成立。Base 的首选放进 Post 的上下文只损失 2.8 点（CI 含 0），但从 Base 的头部候选里随机采样就损失 12.8 点，从全分布采样损失 30.2 点。尾部（p < 0.1·p_max）与头部内部的随机性都有害，两者量级相近（17 与 10 点）；Base 侧镜像相同（截尾拿到 28 点中的 17 点，确定化再拿 11 点）。
  - **混杂（必须一起看）：** 取众数把 Post 的解析失败从 9.0% 降到 0.6%（Post 在 T=1 下有 9.8% 写不完），所以“只损失 2.8 点”里混着格式收益。只看两边都解析成功的 454 题（按结果筛选，有偏，仅作参考）：Post 86.6%，Post/Base 众数 81.7%，差约 5 点；Base 侧同样筛选，Base 众数 78.2% vs Post 众数 83.8%。`post_postmode` 用来给出格式对等的对照。
  - **补充条件 `post_postmode`：** 80.8% [77.2, 84.2]；Post 众数 − Base 众数（Post 上下文）= 4.8 [1.8, 8.0]，与 Base 上下文的 4.2 [0.4, 8.0] 一致；Post 众数 − Post 采样 = 2.0 [−0.8, 4.8]。Post 众数条件解析失败更多（4.6% vs 0.6%），格式混杂偏向 Base 众数一侧，因此这 4–5 点不是格式造成的；两边都解析成功的 476 题上 84.7% vs 79.6%。
  - **综合：** 在 Base 高熵位置，随机性的代价（尾部约 17 点、头部约 10–11 点）大于“谁的首选”（4–5 点，两上下文都显著）。后者真实存在，但分摊在上百个分叉上，单点不可测（E05）。
