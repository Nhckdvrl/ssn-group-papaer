# E07：去掉随机性之后，后训练模型的选择在什么条件下有可测影响？（2026-11-27）
- **状态：** DONE（Qwen；`olymp` 只跑 B1/B2，B3/B4 按中途调整停掉）
- **类型：** PILOT / 条件检验
- **对应：** I05；接 E04-D、E05、E06
- **问题（一句话）：** Base 与 Post 都不采样（全程取首选）时，把 Base 的首选换成 Post 的首选能带来多少准确率？这一选择效应是否随题目难度、Base 自身的解题率变化？它落在 Base 高熵的位置，还是 Base 很有把握、Post 却改了首选的位置（低熵分歧点）？
- **动机：** E06 在 MATH-500 上显示分叉处随机性的代价（尾部约 17 点、头部约 10–11 点）大于“谁的首选”（4–5 点）；事后按难度分层，选择效应在 Level 1–3 为 +2.1，在 Level 4–5 为 +6.7（差 +4.6 [−0.8, 9.9]）。近作（Sparse but Critical、Shen et al.、ReasonMaxxer）在更难的题、截尾采样的 Base 上报告了大的交换收益，并解读为 RL 的精确选择。power sampling 文献（2601.21590、2610.13653）也在争论局部降温之外的“前瞻修正”何时有用。E06 的熵阈值把 Base 低熵但两模型首选不同的位置排除在外（按平均熵分桶，0.1–0.5 区间约 9% 首选不同，承载约 28% 的 KL；按 Base 熵的覆盖率需在本实验中重新统计）。
- **设置：**
  - 模型对：Qwen3-8B-Base → Qwen3-8B（主）；OLMo-3 Base → RL-Zero-Math 先做小规模可行性试跑（强制开头 “.\n\nOkay, let's”，批 8）。
  - 题集：MATH-500 全部 500 题（易题参照）；MATH 测试集 Level 5 中不在 MATH-500 的题，按 seed 0 抽 500 题（`math_l5`）；OlympiadBench `OE_TO_maths_en_COMP` 中数值型、单答案、无单位的 501 题（`olymp`，362 题为整数答案）。构建见 `scripts/build_inputs.py --export-hard`，清单 `data/e07_problems.json`。同一个字符串 verifier，所有条件共用（等价形式可能漏判，对各条件相同）。
  - 确定性网格（两模型同步解码，`scripts/e04_hybrid.py`，无任何采样，上限 4096 token，模板 `qwen_chat`）：
    - G1 `greedy_base`：全程 Base 首选。
    - G2 `greedy_base_postfork`：Base 首选，但在 Base 熵 ≥0.5 处取 Post 首选。
    - G3 `greedy_base_postlow`：Base 首选，但在 Base 熵 <0.5 且两者首选不同处取 Post 首选。
    - G4 `greedy_post`：全程 Post 首选（等于在所有分歧处都取 Post 首选）。
    - 两模型首选不同的每个位置恰好落在 G2 或 G3 的集合之一。记录每个回答的高熵分歧数、低熵分歧数、实际换词的位置与 token（G2/G3，每条最多 300 个）。
  - 采样锚点（vLLM，`scripts/e04_generate.py`）：Base 与 Post 各在 T=0.6、top-p 0.95 下每题 8 个样本（与近作的解码设置对齐），由此得到每题的 Base 解题率 p_base 与 Post 解题率。
- **读数：**
  - 每个题集：C_all = G4 − G1，C_hi = G2 − G1，C_lo = G3 − G1（按题配对差与 bootstrap CI）；参照差距 Gap = Post(T0.6) − Base(T0.6)（8 样本均值）；G1 与 Base(T0.6) 之差（去随机化本身）。
  - 每次换词的效率：C_hi、C_lo 除以平均换词数。
  - 按 p_base 分层（0、1–3/8、4–7/8、8/8）的 C_all，与 MATH-500 的难度等级分层对照。
  - 截断率、解析失败率、平均长度分开报告。
  - G3 换词的内容：结束符/格式/措辞/数学内容的比例（自动分类 + 人工看 30 例）。
- **阳性对照：** 在 16 题上检查 G2 取 thr=−1 时与 G4 一致、thr=1e9 时与 G1 一致（同批大小）；E04-D 已验证 KV 缓存逐步与完整重算一致。
- **噪声地板：** 网格条件是确定性的，误差来自题目抽样：单条件 CI 约 ±4 点，配对差约 ±3–4 点；bf16 下批内数值差可翻转近似平局（E04-D 测得批/单条 KL≈0.003），对平均准确率无偏。小于 4 点的差别不解读。
- **混杂审计：** 全程贪心可能陷入重复循环（单独报告截断率，并与 T=0.6 锚点对照）；Post 的回答更长，上限 4096 可能不成比例地截断 Post（单独报告）；字符串 verifier 对 OlympiadBench 的非整数答案可能漏判（另报整数答案子集）；Qwen3-8B 是强到弱蒸馏（先离线、后在线蒸馏 Qwen3-32B/235B 的输出与 logits；技术报告 §4.5，无 RL 阶段），结论不直接外推到 RLVR，需 OLMo。
- **决策表（跑之前写）：**
  - 难题集上 C_all ≥ 10 点，且比 MATH-500 的 C_all 大（跨题集差的 CI 不含 0）→ 选择效应随难度增大：Base 自身去随机化在难题上不够，后训练的选择承担了更多增益。下一步：OLMo 复现；看 C_hi 与 C_lo 哪一侧承载。
  - 难题集上 C_all ≤ 4 点而 Gap ≥ 15 点 → 即使在难题上，Base 自身的首选也拿到了大部分增益；E06 的图景在主要质疑下成立，三篇交换论文“RL 精确选择”的解读在我们的对照下不成立。
  - C_lo 不小于 C_hi 的一半、而换词数不到其 1/5 → 低熵分歧点是集中、独立的一类改变（“纠正 Base 有把握的选择”），降温无法得到；检查这些换词是否主要是结束符或格式。
  - 按 p_base 分层：选择效应在中间解题率最大 → “能力边界附近最有效”；随 p_base 降低单调增大 → 难度/能力不足越大越依赖选择；平坦 → 无此条件依赖。
  - G1 截断率 >15% → 贪心循环混杂严重，以 T=0.6 锚点为主读数并记录。
- **算力预算：** Qwen 网格 4 条件 × 3 题集，单卡同步解码；采样锚点 vLLM 6 个运行；OLMo 试跑 <1 GPU·时。预计 12–15 GPU·时（吞吐由试跑确定后在此更新）。
