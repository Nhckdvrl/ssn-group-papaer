# E04：后训练输出变化中的全局仿射成分（2026-11-26；草案，待人审批准）
- **状态：** PLANNED（草案；人审讨论中，未运行）
- **类型：** PILOT / 测量 + 功能干预
- **对应：** I05（后训练的输出变化有怎样的结构：全局词表偏好、全局锐化与上下文相关修正）
- **问题（一句话）：** 对真实父子 checkpoint，一个与上下文无关的仿射变换 τ·z₀(x)+b 能在多大范围内复现后训练的输出变化？去掉它会让后训练模型失去什么？SFT、DPO、RLVR 在这一点上是否不同？
- **理论锚点（不是我们的贡献）：** KL 正则 RL 的最优逐步修正是软价值 log Z(x, y<t, ·)（Cohen et al. 2607.22837 式 4）。只有它近似可分解为“固定向量 + 前缀相关常数”时，固定偏置才是最优的（他们的 ε-近似可分解假设）。E04 在真实后训练模型上直接测这种可分解程度，而不是假设它成立。序列级锐化与逐 token 降温不等价（Karan & Du 2510.14901 命题 1），所以 τ 只代表逐 token 锐化。
- **设置：**
  - 谱系对（已在节点本地、sha256 已校验）：Qwen3-8B-Base→Qwen3-8B；OLMo-3 Base→Instruct-SFT、Base→Think-SFT、Base→RL-Zero-Math、Think-DPO→Think（Think-SFT→Think-DPO 暂缺）。
  - 上下文来源（拟合与检验都按文档或题目切分）：(i) 中性文本：E01 的 Pile-10k + MATH 题解；(ii) 父模型自己的生成；(iii) 子模型自己的生成。三种来源都要报告，并做跨来源、跨领域迁移（例如在 (i) 的通用文本上拟合，到 (iii) 的数学生成上检验）。
  - 拟合：最小化留出前的平均 KL(p₁ ‖ softmax(τz₀+b))，对 (τ, b) 联合凸。比较四种近似：z₀、τz₀、z₀+b、τz₀+b。b 分别在“全词表”和“去掉特殊/聊天 token 的词表”上拟合，防止结论被 `<|endoftext|>`、`<think>` 之类的格式 token 主导。
  - 定位（复用 E01 工具）：b 的来源比较 ΔW·μ（头）与 W₀·mean(Δh)（骨干的公共方向）；实测 ΔW 与 μ 的对齐，不预设头就是全局通道（OLMo 的 ‖μ‖/‖h‖ 只有 0.46，Qwen 为 0.90；Qwen ΔW 主方向与 μ 的余弦只有 0.06–0.18）。
- **读数：**
  - A（固定前缀）：四种近似在留出上下文上剩余的 KL、top-1 翻转、目标 token logprob 变化，按领域与上下文来源分开；b 的稀疏度与 token 类别（格式/收尾、话语标记、数字、内容词）。
  - B（真实生成，选 Qwen 对与 OLMo Base→RL-Zero 两对，必要时加一个 SFT 对）：父模型 + (τ,b)，子模型 − b，以及子模型 + 父模型温度对照，在 MATH-500 上测准确率、解析率、截断率、长度、风格 token 频率。固定前缀与自由生成两种口径同时保留，二者之差即自回归放大。
  - C（条件区分）：选候选答案集合相同、正确项随题目变化的选择题（ARC-Challenge / MMLU 子集，本地已缓存），把“全局先验”（固定偏置只能改变 A/B/C/D 的总体偏好）与“题目内区分”（对同一组候选的题间排序/AUC）分开。比较父、子、父+(τ,b)、子−b。
- **阳性对照：** 用合成子模型 z₁=τ*z₀+b*（人为给定 τ*、b*）检验拟合能精确恢复参数、留出 KL≈0；自比（父=子）给出 τ=1、b=0；vLLM 中“温度+logit bias”实现与手工 softmax(τz+b) 逐 token 对拍。
- **噪声地板 + MIE：** 固定前缀读数以文档为单位做 bootstrap CI；生成读数每条件 ≥500 题、≥2 个种子。有意义 = 超出种子波动，且足以改变对“这个阶段的变化主要是全局/上下文相关”的判断。不预设百分比阈值。
- **混杂审计：** 上下文来源决定 b（必须报告迁移）；聊天模板与特殊 token；τ 与 b 的相互替代（联合拟合并报告各自的单独拟合）；RL 对的总变化极小（KL 0.004–0.009），比例读数容易被噪声放大，因此以绝对 KL 与生成行为为主；生成评测的模板与 max_tokens 需按各模型官方设置；OLMo Think 生成很长，首轮不做 Think 线的生成评测。
- **决策表（跑之前写）：**
  - 某阶段 (τ,b) 在留出、跨来源上都能复现大部分固定前缀变化，并且父+(τ,b) 复现了生成层面的主要行为变化 → 该阶段的变化以全局成分为主，接着做定位（头/骨干）与 C。
  - 固定前缀能复现，生成层面不能（或反过来）→ 研究自回归放大，这本身可能是核心现象。
  - 子−b 损失风格/长度而准确率不变 → 全局成分只承载“形式”；准确率也掉 → 全局成分对能力有功能贡献，与 Cohen 的“学到的偏置收益很小”形成对照，值得深挖。
  - 各阶段都几乎不能用 (τ,b) 解释 → 记负结果，结论是“后训练的输出变化本质上是上下文相关的”；转向残差 r(x) 的结构（在哪些位置、哪些 token 上集中）。
  - 结果被少数特殊 token 主导 → 以去掉特殊 token 的口径为准，并如实说明。
- **算力预算：** A 每对两次前向（复用 E01 的 128 文档）+ 生成上下文的前向，约 0.5 GPU·时；B 两对 × 4–5 个条件 × 500 题 × 2 种子的 vLLM 生成，约 2–4 GPU·时；C 只需前向，<0.5 GPU·时。合计 ≤5 GPU·时，单卡可并行，最多用 4 张空闲卡。**实际：** 未运行。
