# E10：少数几处后训练模型的选择，能否建立 Base 之后能独立利用的推理状态？（2026-11-28）
- **状态：** DONE
- **类型：** PILOT / 机制检验（单模型 vLLM，复用 E07 轨迹）
- **对应：** I05；连接 E07（B2：Base 只在高熵位置取 Post 首选，难题上 +14.0）与 E08（Post 写的前缀可被 Base 继承）
- **问题（一句话）：** 把 E07 中 B2 的回答截取前 L 个 token、此后完全交给 Base 自己写，结果是保留了 B2 的收益（少数选择已经建立了可继承的状态），还是退回到 Base 的水平（收益依赖 Post 一直参与）？
- **为什么重要：** 近作（Sparse but Critical、Shen et al.、2610.24663）显示少数位置的替换能恢复增益，但没有回答这些替换的作用在停止替换之后是否还在；E05 显示单个替换测不出价值，E08 显示完整的 Post 前缀可被继承。E10 直接检验“分散的少数选择”本身是否构造了可被 Base 继承的状态，回答 GPT 第六轮提出的问题。
- **设置：**
  - 题集：MATH Level 5，与 E07/E08 相同的 300 题。
  - 前缀来源（E07 的轨迹，每题 1 条，背景 T=0.6/top-p 0.95，上限 4096）：B1（高熵处取 Base 首选）、B2（高熵处取 Post 首选）。对照：E08 中 Post 自己写的前缀（每题 2 条）与 Base 自己写的前缀。
  - 截取 L = 32、256、该回答长度的 50%；前缀中已出现 `\boxed` 的不用（与 E08 相同的合格规则）。E07 轨迹只存了文本，前缀 token 由同一分词器重新编码得到。
  - 续写：Base（T=0.6/top-p 0.95），每个前缀续写 4 次，总生成上限 8192（`e08_handoff.py --n_cont 4`）。
- **读数：** 每个 L：V_Base(s_B2) 与 V_Base(s_B1)、V_Base(s_Post)、V_Base(s_Base) 的比较（按题配对 bootstrap）；以及 V_Base(s_B2) 相对 B2 完整回答（67.0%）与 B1 完整回答（53.0%）的位置。按前缀所在回答原本是否答对分组。
- **阳性对照：** E08 的同模型续写与锚点一致；B1 前缀 → Base 续写应接近 B1/B0 水平（B1 只去随机化，没有 Post 的选择）。
- **噪声地板：** 每个 L 300 个前缀 × 4 次续写，按题聚合后 CI 约 ±4 点。
- **混杂审计：** B2 回答比 B1 长（1413 vs 845），相同 L 下 B2 前缀所占回答比例更小；50% 相对位置在 B2 上绝对 token 更多；重新编码文本可能与原 token 序列略有不同（不影响前缀内容）。
- **决策表（跑之前写）：**
  - L=256 或 50% 时 V_Base(s_B2) 接近 B2 完整回答，且明显高于 V_Base(s_B1) → 少数 Post 选择在回答前段就建立了可被 Base 独立利用的状态；“稀疏决策”的作用是构造状态，而不是持续纠正。
  - V_Base(s_B2) 只比 V_Base(s_B1) 略高、远低于 B2 完整回答 → B2 的收益主要依赖 Post 在后续分叉处持续参与；稀疏决策是持续纠正，而不是一次性构造。
  - V_Base(s_B2) 在相同 L 下高于 V_Base(s_Post) → 保留 Base 自己的生成方式、只做少数替换，得到的状态更适合 Base 继续（GPT 第六轮的第三种可能）。
- **算力预算：** 约 3 GPU·时（vLLM，单卡或两卡）。
- **结果（`results/e10/summary_math_l5_300.json`；每个前缀续写 4 次）：**

|---|---|---|---|---|---|---|
| 32 | 52.5 | 53.9 | 56.4 | 47.5 | +1.3 [−1.8, 4.5] | +2.5 [−0.8, 5.9] |

（共同题数 277–299；50% 处前缀平均长度：B1 415、B2 706、Post 713、Base 581 token。）
  - **阳性对照：** B1 前缀 → Base 在各 L 都停在 B1 完整回答的水平（52–53%）。
  - **按决策表：** 接近第一行。B2 完整回答为 67.0%、B1 为 53.0%（E07，差 14.0）；把 B2 回答截到一半、此后完全由 Base 自己写，仍得 62.9%，即保留了约四分之三的收益（+10.4/14.0）。剩下约四分之一需要 Post 在后半段继续参与。
  - B2 前缀约 95% 的 token 由 Base 写、只有几十处是 Post 的选择，但在 50% 处它和 Post 自己写的前缀一样可被 Base 继续（差 +3.2，CI 含 0）。少数分散的选择主要是在构造一个 Base 之后能独立利用的状态，而不是全程纠正。
  - 原回答对/错分组：前缀来自答对的 B2 回答时 Base 续写 89.2%（50%），来自答错的为 10.9%，与 B1 的对应数（90.0%、8.9%）几乎相同；B2 前缀的优势来自它更常处在正轨上（B2 回答对的比例更高），而不是同样走偏的状态更容易救。
