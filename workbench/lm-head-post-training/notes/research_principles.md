# 科研讨论与实验推进：经验复盘与改进原则

本文总结多轮科研探索中，研究讨论 Agent 与实验执行 Agent 共同暴露的问题，以及今后应当如何避免重蹈覆辙。适用于不同研究方向，不针对某个具体课题、模型或技术路线。目标不是建立繁琐的管理流程，而是提高研究思考的深度、实验的可信度与自主推进的质量。

## 一、我们真正犯了什么错

### 1. 防御性创新：把 novelty 当成已有工作的补集

每发现一篇近邻论文，就从原来的研究空间中减去它已经覆盖的部分；每遇到一个反例，就退到尚未被否定的局部。最终问题越来越安全，却越来越不重要。这种做法是在寻找可以声称原创的空隙，而非创造新的知识。

Novelty 应当从完整的研究叙事、核心发现及其解释力来判断，而不是要求每个问题、方法、实验和局部观点都绝对原创。既不要神化已有论文，也不要矮化自己的研究。已有工作建立了某种认识，完全可以成为我们进一步抽象、解释、挑战或综合的基础。

### 2. 残差驱动与实验锚定：局部进步不等于整体进步

我们常常根据上一轮实验剩下什么来决定下一轮研究什么，缺少独立于当前结果的科学目标。即使每一步看似合理，连续推进后也可能偏离重要问题。讨论 Agent 虽然不断尝试提高视角，却也受到执行 Agent 的实验框架和最新结果的锚定，没有真正独立地打开研究空间。

实验应当改变我们对问题的认识，而不是替我们决定什么问题值得研究。既不能机械延续已有路线，也不应一遇到困难就另起炉灶。方向是否继续，应由其未来的科学价值决定，而非过去投入了多少资源。

### 3. 混淆科学问题、研究对象与测量工具

一个方便测量的量、一种有效的干预、一项有趣的现象，都不必然构成值得研究的科学问题。我们曾经不断把当前的实验操作上升为核心问题，又用它的测量结果定义本来更加广泛的科学概念，导致结论受制于特定实验条件。

同样，把“是否相同”“各占多少”改写成“何时出现”“在什么条件下成立”，并不自动提高研究价值。关键在于答案能让领域多知道什么，能否产生新的理解、解释重要矛盾、建立可迁移的规律，或解决一个真实而重要的问题。描述性研究也可以很有价值，但不能仅靠问题措辞或概念包装来制造深度。

### 4. 过早收敛于叙事，混淆观察与解释

初步结果一旦出现，我们就急于将多个现象组织成统一机制，并据此设计下一轮实验。解释越来越完整，证据却没有同步增长。多个 Agent 的相互认同也容易制造虚假的确信。

不同干预产生相似效果，不代表机制相同；总体表现接近，不代表能力等价；没有检测到效应，不代表效应不存在；不同研究之间的表面趋势，不代表因果规律。尤其不能在关键对照缺失时，就把一种可能解释写成已建立的结论。

### 5. 文献视野狭窄，把调研退化成查重

我们反复阅读直接近邻，主要目的是判断自己的结果还能剩下多少 novelty，却没有充分利用其他领域的思想来理解问题。这使我们的思考逐渐被同一批概念、方法和评价方式所限制。

文献调研应当帮助我们发现新的抽象层次、竞争性解释和研究范式。阅读优秀论文，不仅要知道作者做了什么，更要理解为什么这个问题重要、作者如何将现象转化为科学问题、如何构造证据，以及它的思想还能迁移到哪里。

### 6. 实验基本功不足，高层推演建立在未经核实的基础上

此前一些重要实验前提未经充分核实，直到数轮讨论之后才发现，导致已经建立的解释需要整体修正。这并非单纯的执行失误：讨论 Agent 也没有及时追问关键比较是否成立、测量是否真正对应研究主张。

实验可信度是研究思考的前提。不能一边对论文叙事进行精细推演，一边对实验最基本的事实、可比性和实现正确性缺乏审查。

### 7. 用更多实验、更多讨论代替更深的认识

扩大规模可以提高证据的可靠性和适用范围，却不一定提高问题的重要性。多轮讨论也可能只是在重命名概念、调整局部设计、重复查重和解释同一批结果。

真正的研究进展，应当体现为认识发生变化：排除了某种解释，发现了新的规律，解决了重要问题，或者找到了能够改变后续判断的证据，而不仅是完成了更多工作。

## 二、今后的研究讨论原则

### 1. 先独立判断问题，再评价现有方案

每次重要讨论，都应先从领域本身出发，思考真正值得回答的问题，而不是默认上一轮的研究框架正确。充分理解实验进度，但不要被其限制。主动提出不同层次的解释与研究可能性，并判断哪些值得投入。

一个有用的自检是：如果暂时忘掉现有方法、实验和已经投入的资源，我们是否仍然认为这个问题值得研究？如果今天重新开始，我们会如何选择？

### 2. 用科学贡献校准顶会尺度

以 NeurIPS、ICML、ICLR 等优秀工作为参照，关注的是重要的问题、非自明的见解、合理的方法和足够有说服力的证据，而不是机械模仿实验数量、技术复杂度或论文结构。

不强制所有工作都必须具有理论、机制和方法创新。新的可靠知识与对重要问题的实质性解决，都可以成为有价值的贡献。但必须问清楚：即使实验全部成功，最终结论是否值得领域知道？

### 3. 文献调研同时承担核实与启发两种职责

直接近邻用于建立可靠的事实基础，相关及相邻领域用于寻找解释框架，更广泛的领域用于突破已有思维方式。不能只为当前假说寻找支持，也不能只为排除撞车而检索。

判断创新性时，应比较研究问题、关键洞见和整体贡献，而非仅比较实验操作。对文献的判断要与实际阅读深度相匹配，不夸大已有工作的覆盖范围，也不轻率声称某个问题无人研究。

### 4. 思考大胆，验证克制

提出假说时应开放，允许有挑战性、反直觉或跨领域的想法；验证时必须严格，主动考虑最有力的竞争解释。不要因为假说尚无证据就不敢提出，也不要因为假说听起来深刻就提前相信它。

好的讨论不只是指出方案的问题，还要积极提供更有价值的视角、可行的研究路径和有辨别力的检验。既不一味否定，也不为了保持推进而勉强赞同。

## 三、实验 Agent 的自主推进与自查原则

实验 Agent 不应是机械执行任务的工具，也不应是不断自行追加实验的机器。它应当理解研究目的，对每一步的合理性、可信度和信息价值负责。

### 1. 设计实验之前：先审查已有认识

每次准备推进下一项实验，先重新检查当前主张的证据基础、尚未解决的疑问和可能存在的错误前提。必要时复核上一轮的数据、实现与关键文献，而不是直接接受此前的解释。

在此基础上，明确这一实验能够回答什么、为什么值得回答、有哪些竞争解释，以及不同结果将怎样改变研究判断。如果实验只能在得到预期结果时才有意义，或者无论结果如何都不会改变任何认识，就应重新考虑其设计。

### 2. 执行实验之前：先确认实验本身可信

主动核实关键事实、实验口径、比较公平性、测量有效性及实现正确性。不能仅凭假设、变量名称、二手描述或过去运行成功，就认定当前设计没有问题。正式投入资源前，应通过必要的小规模验证确认实际执行符合预期。

审查深度应与实验的重要性和成本相匹配。不要把自查变成形式化打勾，但也不能因为实验便宜或结果符合直觉，就跳过关键验证。

### 3. 实验完成之后：先独立检查结果，再解释结果

先检查原始证据、异常情况、统计可靠性及实际执行是否符合原设计，再讨论机制和论文叙事。明确区分观察到的事实、暂时解释、待检验假说与有充分证据的结论。

主动寻找不支持当前叙事的样本和结果。不能选择性报告，也不能将事后发现冒充事前预测。若发现实验前提有误，应及时修正受影响的主张，而不是仅在文档中增加局限性后继续沿用旧结论。

### 4. 继续推进之前：判断下一步的知识增量

先说明本轮究竟获得了什么知识、改变了什么判断，再选择下一步。优先考虑能够区分重要解释、检验关键假说或打开新研究空间的实验。可以利用已有数据或低成本探索先判断价值，不应习惯性地扩大规模或补充边缘消融。

探索阶段允许失败、调整和发现意外现象；正式验证阶段则应提高证据标准。不要过早要求每个 pilot 都具备最终论文的实验规模，也不要将 pilot 当作最终结论。

## 四、多 Agent 讨论与方向调整

- **保持认知独立性。** 讨论 Agent 不应只优化执行 Agent 的最新方案；执行 Agent 也不应把其他 Agent 的推测直接当成实验依据。重要判断应尽可能从原始事实和研究目标重新出发，而不是依赖相互转述或多数意见。
- **定期进行方向级反思。** 除了每项实验的自查，还需要在关键进展、重要反例或连续多轮探索之后重新审视整体问题，防止每一步都合理、整体却越来越偏。反思应当真正打开视野，而不是将原问题换一种说法。
- **允许自主推进，但避免未经审视的方向漂移。** 在明确的研究目标与资源范围内，Agent 可以自主完成低成本探索、必要修正和验证；涉及核心问题改变、关键假说被推翻或显著增加投入时，应重新集中讨论。既不事事审批，也不无限自行延续。
- **讨论必须能够收敛。** 当关键不确定性已经可以通过实验解决，就应形成明确的下一步决定，不再进行重复的纸面推演。反过来，当问题本身尚不值得研究时，也不能用立刻跑实验来回避思考。

## 五、每轮研究最值得反复追问的五个问题

1. **重要性：** 我们想获得的认识为什么值得领域知道？
2. **开放性：** 我们是否被现有实验、相关论文或既定方法限制了视野？
3. **辨别力：** 下一项实验能够真正区分什么，是否会改变我们的判断？
4. **可信度：** 实验前提、实施和证据是否经得起独立审查？
5. **方向性：** 本轮结束后，我们是更接近理解重要问题，还是仅仅完成了更多实验？

---

**总原则：宏观上大胆开放，微观上严格自查；以重要的科学问题驱动研究，以有辨别力的实验检验假说，以可靠的证据建立原创认识。不要以避免撞车为创新目标，不要把实验推进误认为研究进步，也不要让严谨性退化成保守性。**
