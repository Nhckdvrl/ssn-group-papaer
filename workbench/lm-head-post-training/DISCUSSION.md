# 讨论材料：上次讨论以来的实验与结果（2026-11-27 晚）

> 本工作台唯一的讨论文档。范围：第三轮讨论（GPT/Gemini 对 E04–E06 的反馈）之后做的事——E06 的难度分层、E07 的全部实验，以及新读的文献。上一版（E04–E06 的完整材料）见提交 `56d083a5` 的同名文件。实验卡 `experiments/E07-choice-conditions.md`，主张 `CLAIMS.md` C15，结果 `results/e07/summary_qwen-base__post.json`。所有数字是首轮 pilot（L1），未经独立复算。

**上一轮的结论（回顾，三句）：** MATH-500 上，Qwen3-8B 的后训练增益集中在 Base 高熵的分叉位置；在 Base 按 T=1 采样时，分叉处随机性的代价（尾部约 17 点、头部约 10–11 点）大于“谁的首选”（4–5 点）；单个分叉上改选测不出价值。OLMo-3 RL-Zero 的大部分差距来自回答开头的模式选择。近作已做过正反分叉交换，我们的增量是去随机化与价值的对照。

## 0. 结果摘要

1. **事后分层（E06 数据，零 GPU）：** “谁的首选”在 MATH-500 Level 1–3 为 +2.1，在 Level 4–5 为 +6.7，提示选择效应随难度增大。
2. **全程贪心对 Qwen3-8B 不可用：** Post 在全程贪心下大量陷入重复（OlympiadBench 前 48 题 44% 写满上限，准确率 8%，低于 Base 贪心的 19%），E07 因此改为“只在指定位置取首选、其余位置按 T=0.6/top-p 0.95 采样”。
3. **主结果（E07，Base 背景采样 T=0.6/top-p 0.95，与近作一致）：** 分叉处“取 Post 首选 − 取 Base 首选”的选择效应在易题（MATH-500 Level 1–3）为 +1.3 [−2.9, 5.5]，在难题（MATH Level 5）为 +14.0 [8.3, 19.3]，难易之差 +12.7 [6.0, 19.6]。难题上 Post 首选补上了 Post 与 Base 差距（20.0 点）的 70%，分叉处去随机化只补 22%；易题上正相反（去随机化补 69%，选择 13%）。
4. **按 Base 自身解题率分层（难题）：** 原表显示选择效应在 Base 偶尔能解出的题上最大；改用 4+4 拆分消除选择偏差后（§2.8），这一峰值只在 OlympiadBench 上保留，MATH Level 5 上变成 Base 越弱选择效应越大。
5. **低熵分歧点（Base 熵 <0.5 但两模型首选不同）：** 每个回答约 50 处，干预时实际换 27–30 个 token；只在这些位置取 Post 首选，效应 +4.0 / +4.3，不显著。
6. **OlympiadBench 复现：** 方向一致、幅度减半。参照差距 +19.3，去随机化 +6.1，选择效应 +7.3 [2.3, 12.7]（补差距的 38%，MATH Level 5 为 70%）；与易题之差 +6.1 [−0.4, 12.8]，CI 刚好含 0。Post 首选在这里截断更多（17%）。

## 1. 设置

- **模型对：** Qwen3-8B-Base → Qwen3-8B（多阶段后训练）。OLMo-3 RL-Zero 只做了可行性试跑（见 §4）。
- **题集：**
  - 易题参照 `m500e`：MATH-500 中 Level 1–3 的 238 题。
  - 难题 `math_l5`：MATH 测试集 Level 5 中不在 MATH-500 的题，seed 0 抽 500 题，网格条件用其中随机 300 题。
  - 难题 `olymp`：OlympiadBench `OE_TO_maths_en_COMP` 中数值型、单答案、无单位的 501 题，网格条件用随机 300 题。
  - 同一个字符串 verifier；最多 4096 个生成 token。
- **条件（两模型同步解码，Base 上下文；分叉 = Base 在 T=1 下熵 ≥0.5；未被干预的位置按 T=0.6、top-p 0.95 从 Base 采样）：**
  - B0：Base 全程采样（vLLM，每题 8 个样本的平均）。
  - B1：分叉处取 Base 首选。
  - B2：分叉处取 Post 首选。
  - B3：低熵分歧点取 Post 首选。
  - B4：分叉处取 Base 首选，同时低熵分歧点取 Post 首选。
  - P0：Post 全程采样（vLLM，每题 8 个样本的平均）。
- **读数：** 参照差距 P0 − B0；去随机化 B1 − B0；选择效应 B2 − B1；低熵纠正 B3 − B0、B4 − B1。按题配对 bootstrap CI。B1–B4 每题 1 个样本，单条件 CI 约 ±5 点。
- **工具核对：** 阈值取极端值时（−1 / 1e9），同步解码的输出与纯 Post / 纯 Base 逐字一致（16 题）。周期性重复（最近 512 token 周期 ≤128）即停并记为截断。

## 2. 实验与结果

### 2.1 E06 的难度分层（事后分析）

MATH-500 自带难度等级。用 E06 的数据（Base 背景 T=1），“谁的首选”（Post 众数 − Base 众数，两种上下文平均）：Level 1–3（238 题）+2.1 [−1.1, 5.3]；Level 4–5（262 题）+6.7 [2.5, 11.3]；差 +4.6 [−0.8, 9.9]。Level 5 单独：Base 上下文 47.0→53.7，Post 上下文 52.2→62.7。这是看到结果后做的分层，只作为 E07 的动机。

### 2.2 全程贪心的退化（E07 第一版设计）

第一版设计是全程贪心的 2×2 网格。OlympiadBench 前 48 题：Post 贪心 21 题写满 4096 上限（44%），准确率 8.3%；Base 贪心截断 6 题，准确率 18.8%。MATH 5 级前 72 题 Base 贪心 77.8%，截断 3 题。Qwen3 的模型卡也提示贪心解码会导致无限重复。全程贪心下 Post 的退化会主导“选择效应”的读数，因此在比较任何网格结果之前停掉了这一版。

### 2.3 主结果：易题与难题（Base 背景采样相同）

| 条件 | 易题 `m500e`（238 题） | 难题 `math_l5`（300 题） |
|---|---|---|
| B0 Base 全程采样 | 81.3 | 48.7 |
| B1 分叉处取 Base 首选 | 88.2 [84.0, 92.4] | 53.0 [47.3, 58.7] |
| B2 分叉处取 Post 首选 | 89.5 [85.3, 93.3] | 67.0 [61.7, 72.3] |
| P0 Post 全程采样 | 91.4 | 68.7 |

| 配对差 | 易题 | 难题 |
|---|---|---|
| 参照差距 P0 − B0 | +10.1 [7.7, 12.7] | +20.0 [16.5, 23.5] |
| 去随机化 B1 − B0 | +7.0 [3.4, 10.5] | +4.3 [0.5, 8.2] |
| 选择效应 B2 − B1 | +1.3 [−2.9, 5.5] | +14.0 [8.3, 19.3] |

- 难易之差（选择效应）+12.7 [6.0, 19.6]。
- 难题上，B2（67.0）与 Post 全程采样（68.7）接近：Base 只在分叉处换成 Post 的首选，就基本达到 Post 的水平。
- 易题上，Base 只要在分叉处不随机（B1 88.2）就接近 Post（91.4），换成 Post 的首选几乎不再增加。
- 与上一轮的关系：E06 在 MATH-500、Base T=1 下得到“随机性代价大于选择”。E07 显示在 Base 已经截尾采样时，这一结论只在易题上成立；在难题上，分叉处的选择本身承担了大部分差距。

### 2.4 按 Base 自身解题率分层（难题 `math_l5`）

p_base = Base 在 8 个 T=0.6 样本中的正确比例。

| p_base | 题数 | 参照差距 P0 − B0 | 去随机化 B1 − B0 | 选择效应 B2 − B1 |
|---|---|---|---|---|
| 0 | 71 | +25.4 [18.3, 32.9] | +4.2 [0, 9.9] | +11.3 [2.8, 21.1] |
| 1/8–3/8 | 66 | +39.0 [30.5, 47.4] | +8.9 [−1.9, 19.9] | +27.3 [12.1, 42.4] |
| 4/8–7/8 | 115 | +16.1 [11.9, 20.3] | +6.2 [−0.5, 13.3] | +11.3 [2.6, 20.0] |
| 1 | 48 | −4.7 [−8.3, −1.6] | −6.3 [−14.6, 0] | +6.3 [0, 14.6] |

- 参照差距和选择效应都在 Base 偶尔能解出的题上最大。相邻层的 CI 重叠，峰值形态只是提示。
- Base 从未解出的题（p_base=0）上，Post 仍高 25 点，其中分叉处的选择补上约 11 点。

### 2.5 低熵分歧点

- **数量：** 在 B1 的轨迹上，Base 熵 <0.5 但两模型首选不同的位置每个回答约 50 处，高熵分歧约 41 处。干预时每个回答实际换 27–30 个 token。
- **效应：** B3 − B0 = +4.0 [−0.5, 8.5]；B4 − B1 = +4.3 [−0.7, 9.3]。都不显著。分层中 p_base=0 层 B3 − B0 = +11.3 [4.2, 19.7]，属于多重比较之一。
- **换词内容（自动分类）：** 低熵分歧点的换词以符号/标点之间（33%）和普通词之间（29%）为主，结束符 2.5%。分叉处（B2）的换词以普通词之间为主（53%）。

### 2.6 OlympiadBench 复现

同一设计，OlympiadBench 随机 300 题，只跑 B1、B2（B3、B4 在中途调整时停掉）。B2 由单卡运行的 72 题与三片分片按题号合并。

| | 易题 `m500e` | 难题 `math_l5` | 难题 `olymp` |
|---|---|---|---|
| B0 Base 全程采样 | 81.3 | 48.7 | 39.2 |
| B1 分叉处取 Base 首选 | 88.2 | 53.0 | 45.3 [40.0, 51.0] |
| B2 分叉处取 Post 首选 | 89.5 | 67.0 | 52.7 [47.0, 58.7] |
| P0 Post 全程采样 | 91.4 | 68.7 | 58.5 |
| 参照差距 P0 − B0 | +10.1 | +20.0 | +19.3 [16.2, 22.5] |
| 去随机化 B1 − B0 | +7.0 | +4.3 | +6.1 [2.3, 9.9] |
| 选择效应 B2 − B1 | +1.3 | +14.0 | +7.3 [2.3, 12.7] |

- 选择效应在 OlympiadBench 上显著为正，但只有 MATH Level 5 的一半左右（差 −6.7 [−14.0, 1.0]）；与易题之差 +6.1 [−0.4, 12.8]。在 OlympiadBench 上，选择补上参照差距的 38%，去随机化补 32%。
- **截断：** B2 截断 17.0%、解析失败 16.7%（B1 为 7.7% / 8.7%），回答 1578 vs 883 token。两边都未截断的 234 题上，选择效应为 +9.8 [3.8, 15.8]。
- **verifier：** 只看整数答案的 211 题，选择效应为 +4.7 [−1.9, 11.4]。
- **按 Base 解题率分层：** 选择效应同样在 p_base 1/8–3/8 层最大（+14.5 [−1.5, 30.4]，69 题），p_base=0 层 +2.9 [−3.9, 9.7]，p_base=1 层 +3.3。

### 2.7 混杂与核对

- **长度与截断：** 分叉处取 Post 首选让回答变长（难题 1413 vs 845 token），截断与解析失败都升到 12%（B1 为 4.7% / 5.3%）。14.0 点是在截断更多的情况下得到的；两边都未截断的 253 题上为 76.3% vs 60.9%。
- **“选择”的内容还没有分析：** 分叉处的改选让回答变长，可能对应更多的推理或验证步骤（上一轮看到 RL-Zero 的改选多为 Wait/Therefore）。具体是哪类改选承担了难题上的效应，还没有分类。
- **只有一个谱系：** Qwen3-8B 是多阶段后训练，结论不能直接用于纯 RLVR。

- **长度与截断全表（同一批题；B0/P0 为 8 个 vLLM 样本）：**

| 题集 | B0 长度 / 截断 | B1 | B2 | P0 |

## 3. 与已有工作的对照（本轮新读）

| 工作 | 他们测了什么 | 与 E07 的关系 |
|---|---|---|
| Scalable Power Sampling（Ji et al., 2601.21590，已读理论部分） | 证明对整条序列做幂锐化，等于逐 token 降温再乘一个衡量后续轨迹质量的修正因子 | E07 的“Post 首选 − Base 首选（Base 已去随机化）”是在真实后训练模型上测量局部降温之外的那部分修正；它在易题上约为 0、在难题上很大 |
| A Critical Look at Power Sampling（Talwar et al., 2610.13653，已读 §1–3） | 现有幂采样器在实际预算下不收敛，其收益可由按 Base 似然挑序列的 Best-of-N 复现；真正逼近幂分布时，比降温多出的收益只在 Base 本来较对路时出现 | 我们的分层方向不同：选择效应在 Base 偶尔能解出的题上最大，在总能解出的题上最小。两者测的对象不同（Base 自身的序列锐化 vs 后训练模型的选择），不能直接比较 |
| On the Direction of RLVR Updates（2603.22117，已读 §3.2、§4.1） | 先从 Base 采样，若 RL 压低了这个已采样 token（Δlog p 大负值）就改从 RL 采样；比按熵选位需要更少替换 | 大负 Δlog p 集中在低概率 token 上，与上一轮“Base 抽到尾部候选代价大”同向；它没有区分“去掉尾部”与“换成 RL 的选择” |
| **What RL Brings to Reasoning（Zhang et al., 2610.24663，2026-10，已读 §1–4 与附录 B）** | Qwen3-4B-Base 与自训 GRPO 模型（无 SFT），另有 Qwen3-8B、Llama-3.2-3B 两对（同一配方）；AIME 2022–25 共 120 题每题 16 样本，MATH-500 每题 64 样本；与我们同一模板，T=0.6/top-p 0.95，上限 8192。rl-replace：两模型首选不同处（约 4% 位置）用 RL 首选，其余 Base 采样 → AIME 恢复 90.5%，MATH-500 恢复 106.6%；同规则改用 Base 首选只比强制开头多 1.5 点，RL 首选多 5.2 点；强制开头 “Alright” 恢复 35%；按规则插入 Wait/Re 全部有害；rl-replace 的回答长度 6217 ≈ RL 6504 ≈ 2× Base；pass@256 高于 RL 与按回答混合 | **最直接的近邻。** 难题上“RL 首选 vs Base 首选”的对照（我们的 B2 − B1）、开头模式、长度随之翻倍、改选集中在前段，它都已报告，且用三对纯 GRPO 模型、更多样本。它没有：易题与难题在同一设计下的对照、分叉处整体去随机化（B1 对所有高熵位置取 Base 首选）的对照、按 Base 解题率的分层、单分叉价值检验、多阶段官方模型 |
| Nohara et al.（2602.09591，只读摘要与引言） | 用多种长度控制方法训练一族策略：样本准确率随平均长度先升后平/降，多数投票答案的准确率随长度持续上升 | 与 B2 的长度变化相关：长度本身与准确率不是单调关系 |
| Sun et al.（2609.01274，只读摘要） | 用统一解码框架让 Base 在预算化的搜索策略上逼近 RL 的 pass@k 曲线（SimpleRL-Zoo，10 个模型 4 个家族） | 预算维度的对照 |
| Yang（2610.34894，只读摘要与图 1） | 把 20 个公开 RL 模型的 pass@1 增益拆成“预算内写完”“写完后答对”“新解出的题” | 与 B2 截断升高的问题直接相关 |
| Sparse but Critical（2603.22446）、Shen et al.（2605.16874）、ReasonMaxxer（2605.06241） | 在 AIME 等难题上做交换（Base 多为截尾采样或贪心），报告大的恢复，并解读为 RL 的精确选择 | E07 在截尾 Base、难题上得到与其解读一致的结果（选择效应占 70%）；在易题上不一致（选择效应 ≈0）。上一轮“去随机化为主”的结论只在易题/T=1 下成立 |

## 4. 局限

- **单一谱系：** 只有 Qwen3-8B。OLMo-3 RL-Zero（纯 RLVR）的同步解码在批 8 下可行，但每 500 题每条件约 6–7 GPU·时（回答平均约 2000 token、截断 19%），本轮未做。
- **样本量：** B1–B4 每题 1 个样本；难题网格是 300 题的随机子集；按解题率分层每层 48–115 题。
- **分叉与低熵的定义：** 都依赖 Base 熵阈值 0.5。
- **截断与长度：** Post 首选的条件截断更多，见 §2.7。
- **verifier：** 字符串匹配，OlympiadBench 的非整数答案可能漏判（对各条件相同）。
- **算力：** E07 合计约 23 GPU·时（含停掉的贪心网格约 4 GPU·时与 vLLM 锚点约 5 GPU·时）。

## 5. 与已接收同类论文的尺度对照（事实）

venue 标注来自本仓库的 venue corpus（ICLR/ICML/NeurIPS 接收列表）。各论文的规模由子 agent 读全文实验部分整理，Shen et al. 与 Sparse but Critical 的设置我自己核对过。
