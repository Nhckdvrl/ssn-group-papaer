**上一轮的结论（回顾）：** Base 按近作的截尾设置采样（T=0.6/top-p 0.95）时，Qwen3-8B 在 Base 高熵位置的选择效应（换成 Post 的首选 − 取 Base 自己的首选）在易题上 ≈0（+1.3），在 MATH Level 5 上 +14.0，在 OlympiadBench 上 +7.3。

## 0. 结果摘要

1. **更正：Qwen3-8B 不是 RL 模型。** Qwen3 技术报告 §4.5：8B 等小模型只经“强到弱蒸馏”（先离线蒸馏 Qwen3-32B/235B 的输出，再在线蒸馏其 logits），没有 RL 阶段。E04–E08 中 Qwen 的结论描述的是蒸馏型后训练；纯 RLVR 的证据来自 OLMo-3 RL-Zero。
2. **OLMo RL-Zero 在强制开头之后几乎没有剩余优势**（MATH Level 5、8192 token 预算：Base 59.3% vs RL-Zero 61.2%），与 2610.06851（MATH-500、31744 token 预算：77.7% vs 75.1%）一致。在 OLMo 上，Base 在高熵位置取自己的首选反而降 10 点（更易重复、写满上限）。
3. **前缀交接（Qwen，MATH Level 5 与 AIME）：** Post 写的前缀越长，Base 续写越接近 Post；写到一半时两者续写无可测差别。Base 写的前缀越长，交给 Post 续写越差，Post 只能部分挽救。同题控制后，Post 在走偏前缀上的续写优势不取决于是谁写偏的。
4. **Post 的优势用 Base 自己的算力买不来：** Base 投票 8 次（约 6 倍 token）仍低于 Post 单次（MATH Level 5：61.4% vs 69.1%；AIME：14.3% vs 20.9%）。
5. **难题上 Post 首选改变了什么（E07 轨迹）：** 在 B2 赢的题上主要是结构（分步标题 1.6 → 6.8 条/回答）和开头（Post 先准确复述题目；Base 有时复述提示、以 “Assistant:” 开头、读错题）；反思与验证标记几乎不变；回答长度翻倍主要出现在两边都错的题上。只给 Base 强制 Post 最常见的开头 “We are given”（不含题目内容）完全没有作用（48.0% vs 48.5%）：Qwen 上 Post 前 32 token 的作用来自具体内容，不是通用 cue，这与 OLMo 相反。
6. **AIME 上的选择效应（E09，Qwen）：** B0 9.7%、B1 12.7%、B2 15.8%、P0 20.9%：B2 补上差距的约 54%，去随机化（+3.0）与选择（+3.1 [−2.5, 9.0]）各约一半，都不显著；B2 截断 35%，读数偏低。方向与 2610.24663 一致，证据不足。
7. **OLMo 上的选择效应（E09）：** 开头之后 RL-Zero 与 Base 本来就没有差距；在 OLMo Base 里取自己的首选或换成 RL 首选都使混合解码更易重复、写不完（B2 截断 63%，其中 35% 是重复），测到的是两个模型逐 token 混合的不兼容。“难易切换”在 OLMo 上不可检验。

## 1. 设置

- **模型对：** Qwen3-8B-Base → Qwen3-8B（强到弱蒸馏，无 RL）；OLMo-3 Base → RL-Zero-Math（纯 RLVR）。OLMo 的 Base 一律强制开头 “.\n\nOkay, let's”（2610.06851 的 cue），所有比较都在开头之后。
- **题集：** MATH Level 5（与 E07 相同的 300 题）、AIME 2022–2025（120 题）；同一 verifier；T=0.6/top-p 0.95；每条回答最多 8192 个生成 token（E09 中 OLMo 的同步解码 6144，比较时锚点按同一上限重新截断计分）。
- **锚点（vLLM）：** B0（Base 采样）、B1（Base 在 T=1 熵 ≥0.5 处取自己的首选，单模型实现，与 E07 同步解码的 B1 一致：52.9% vs 53.0%）、P0（Post 采样）。Qwen 每题 8 样本，OLMo 4 样本。
- **交接（E08）：** 从锚点回答截取前 L 个 token（L = 32、256、该回答长度的 50%；已写出答案的前缀不用），交给另一个模型续写；每个前缀续写 1 次，每题 2 个前缀。
- **选择效应（E09）：** B2 = Base 在高熵位置取 Post 的首选（两模型同步解码），与 B1 逐题配对。

## 2. 实验与结果

### 2.1 谱系更正
Qwen3 技术报告 §4.5 原文：0.6B/1.7B/4B/8B/14B 与 30B-A3B 走“强到弱蒸馏”——(1) 离线蒸馏：混合教师在 /think 与 /no_think 模式下的输出；(2) 在线蒸馏：学生自己采样，按教师（Qwen3-32B 或 235B-A22B）的 logits 最小化 KL。四阶段（含 RL）流程只用于旗舰模型。此前文档中“多阶段后训练”“RL 谱系”的说法已全部更正。

- AIME 上 L=50% 时 Post 前缀 → Base 的截断升到 32%（前缀约 1700 token），该点读数偏低。
- 只写 32 个 token 的 Post 前缀已使 Base 提高 8 点（MATH Level 5），约为差距的 39%；2610.24663 中强制 “Alright” 开头恢复 35%。

### 2.3 同题控制：Post 是否专门擅长挽救 Base 的走偏状态
未控制时，原回答错的 Base 前缀上 Post 续写 33.8% vs Base 13.1%，原回答错的 Post 前缀上两者都约 25%，看起来 Post 只在 Base 的走偏状态上占优。但两类走偏前缀来自难度不同的题。只看两类走偏前缀都存在的同一批题（约 110 题）：Post 的续写优势在 Base 走偏前缀上 +7.8 [2.8, 13.3]，在 Post 走偏前缀上 +4.6 [−3.2, 12.4]，差 +3.2 [−5.0, 11.5]（L=32、256 时差 +2.2、+1.8）。所以这一不对称不成立；同前缀续写差在 Base 前缀上更大，主要因为 Base 前缀中走偏的比例更高（原回答答对的比例：Post 约 69%，Base 约 46%）。

### 2.5 难题上 Post 首选改变了什么（E07 轨迹，零 GPU）
- 每条回答的分步标题（“### Step”等）：B1 2.0 → B2 7.0；Post 自己 99.5% 的回答使用，Base 约 29%。
- B2 赢的题（58 题）：长度 950 → 1115；“Wait”、检查、发现错误等标记基本不变。两边都错的题（83 题）：长度 1013 → 2503，“However/But” 0.8 → 2.5（反复转折）。
- 读三对赢的题：两者都在第一个 token 分开。Base 的开头有时复述题目和指令、以 “Assistant:” 开头、把 “103” 读成 10³；Post 首选的开头先准确复述题目（“We are given …”），再按步骤展开。
- **Qwen Base 的开头走偏很少：** Base 回答中以 “Assistant:” 开头的占 11.8%，准确率 54%（不低于其余回答）；复述题目与指令的占 2.2%，准确率 21%。按此估计，开头走偏对 MATH Level 5 上 20 点差距的贡献不到 1 点；Qwen 的差距不是开头模式造成的，这与 OLMo 不同。
- **结构随前缀继承，但本身不是原因：** Base 续写 Post 前缀时，续写使用分步标题的比例为 67%（L=32）→ 96%（L=256），续写自己的前缀时为 23–26%；Post 续写 Base 前缀时，从 81% 降到 31%。续写的文风跟着前缀走。但在 Base 续写自己前缀的情形中，用不用分步标题准确率无差别（45% vs 49%），所以分步结构更像是“Post 产生的状态”的标志，而不是提高准确率的原因。Base 继承了结构，但续写长度与它自己的回答相近（约 1000 token），没有继承 Post 的长度。
- **开头 cue 探针（E08b）：** 强制 “We are given” 开头后 Base 为 48.0% [43.6, 52.7]（B0 48.5%），分步标题比例 26%（不变）。对照：Post 写的前 32 token → Base 56.5%。前 32 token 的作用来自对该题的具体复述与展开，不是开头措辞本身。

## 4. 局限
- 两个家族的后训练方式不同（蒸馏 vs RLVR），家族与配方混在一起。
- OLMo 截断率 32–44%，测的是 8192（或 6144）token 预算内的准确率。
- AIME 只有 120 题、B2 每题 1 样本。
- 分叉与 B1 的定义依赖熵阈值 0.5。
- 交接的前缀合格率随 L 变化，只做同前缀配对比较。

## 5. 立题与叙事（我的判断，与上面的事实分开）
### 5.1 领域里的问题
后训练到底给 Base 的推理加了什么？现有两类证据各自成立：
- **“锐化/激发”：** Yue et al.（NeurIPS'25 Oral）、Karan & Du（ICLR'26 Oral）、Wang et al. 2610.06851（开头 cue）、Mousavi-Hosseini & Erdogdu（ICML'26 Spotlight，结果奖励难以离开 Base 支撑集的理论）。
- **“Base 不会做的决策”：** Sparse but Critical（ICLR'26）、Shen et al.（ICML'26）、Direction of RLVR（ICLR'26）、Zhang et al. 2610.24663。

两类证据来自不同的模型、配方和题目难度（前者多在 MATH-500，后者多在 AIME），所以它们互相并不矛盾，但领域里还没有一个在同一模型、同一位置上能分辨“是哪一种”的测量。

### 5.2 我认为可以立起来的问题
**后训练带来的推理增益，在什么条件下是一个开头模式、在什么条件下是去掉 Base 的随机性、在什么条件下是 Base 自己不会做的选择？这些选择是否建立了 Base 能继承的推理状态？**

- 这是“在什么条件下哪种机制成立”的问题，不是“X 占多少”的拆分；每种机制对应一个独立的干预：强制开头（模式）、B1（去随机化）、B2（换成后训练模型的选择）、交接（状态能否被继承）、等算力投票（能否用 Base 的算力买到）、单分叉价值（单点是否更“聪明”）。
- **目前的数据给出三种情形都真实存在：**
  1. **模式：** OLMo RL-Zero 的增益基本就是开头 cue；开头之后，在 8192 预算下 RL-Zero 与 Base 无差别。在 OLMo 上，开头之后无论是去随机化还是换成 RL 的选择，都只会让生成失稳。
  2. **去随机化：** Qwen 易题上，Base 在高熵位置取自己的首选就接近 Post。
  3. **新的选择：** Qwen 难题上（MATH Level 5、OlympiadBench；AIME 上方向一致但未达显著），需要 Post 的首选；这些选择在回答前半段建立的状态能被 Base 继承；Base 用 6 倍算力投票也买不到；单个分叉上测不出价值。
- **对领域的意义：** “后训练是不是锐化”没有一个统一答案，它取决于 Base 与后训练模型在这道题上差在哪里、以及后训练的监督来源；token 交换类研究需要加上去随机化与开头对照，才能把“新的选择”与另外两种情形分开。这对“RL 算力花在哪”“推理时只在前段借用后训练模型”等实际问题也有直接含义。

### 5.3 和近邻的关系
| 近邻 | 我们接受它建立的 | 我们在它之上补充的 |
|---|---|---|
| 2610.06851 | 开头 cue 能让 OLMo Base 达到 RL 水平 | 开头之后的位置上 RL-Zero 也没有剩余作用（分叉处的选择、交接）；Qwen 蒸馏模型则不是这样 |
| 2610.24663、Sparse but Critical、Shen et al. | 难题上少数位置的后训练选择恢复大部分增益 | 去随机化对照显示易题上这些选择几乎不增加；选择建立的状态可被 Base 继承；单个选择测不出价值 |
| Yue et al.、Karan & Du | Base 有能力，锐化能取回许多增益 | 只在易题（或 OLMo 开头之后）成立；难题上 Base 自己的确定化与投票都取不回 |

### 5.4 这条叙事还缺的证据（事实层面）
- 两个家族的后训练方式不同（蒸馏 vs RLVR），“监督来源”与“底座家族”混在一起；要把它们分开，需要一个在底座上做 RL、且开头之后仍有差距的模型对（2610.24663 的 Qwen 底座 GRPO 模型是这样的例子；本地没有，需要下载）。
- “去随机化 → 新选择”的切换目前只在 Qwen 一个家族上看到。
- 题目难度目前用题集划分（MATH-500 Level 1–3 / Level 5 / OlympiadBench / AIME），按 Base 自身解题率的分层在两个题集上形态不一致。

### 5.5 按 ICML 论文形态写的立题草案（供讨论，不是定稿）
参照 Shen et al.（ICML'26）开篇的写法：领域大问题 → 已有观点与各层面的假设 → 自己的测量与发现 → 由发现导出的方法或推论，图 1 同时展示机制和收益。

- **开篇问题：** 后训练让同一个基础模型的推理大幅变好，但它究竟加了什么？“潜在能力/锐化”一派认为 Base 已有能力，后训练只是激发（Yue et al.；Karan & Du；2610.06851）；“少数决策”一派发现换掉少数位置的 token 就能恢复增益，并把它解读为 Base 不会做的决策（Sparse but Critical；Shen et al.；2610.24663）。两派各自的证据来自不同的模型、配方和难度，用的干预同时改变了几件事（开头模式、Base 的随机性、具体选择），所以无法回答“在一个具体模型、一类具体题目上是哪一种”。
- **我们的做法：** 在同一个模型、同一批位置上，用一组彼此独立的干预逐一分辨：强制开头（模式）、Base 在高熵位置取自己的首选（去随机化）、换成后训练模型的首选（选择）、把后训练模型写的前缀交给 Base（状态能否被继承）、等算力投票（能否用 Base 的算力买到）、单分叉价值（单点是否更“聪明”）。
- **发现（目前的数据）：**（1）三种情形都存在且由条件决定：纯 RLVR 的 OLMo 增益基本是开头模式；蒸馏 Qwen 在易题上是去随机化，在难题上是 Base 不会做的选择。（2）这些选择在回答前半段建立的状态能被 Base 继承，单个选择本身测不出价值。（3）这种优势用 Base 自己的算力（投票）买不到，也不是通用的开头措辞。
- **推论/方法候选（尚未测）：** 只在回答前段借用后训练模型、后段交给 Base 的“前段委托”，按 E08 读数可在约一半的后训练模型调用下保留大部分增益；易题上只需单模型的去随机化。是否把它做成方法贡献，取决于讨论。
