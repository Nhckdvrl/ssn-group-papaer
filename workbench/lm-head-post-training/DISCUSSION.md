# 讨论材料：同一底座上的纯 RL 与蒸馏，以及一个开头（2026-11-28）

> 本工作台唯一的讨论文档。范围：上次讨论（E08–E10）之后的 E11（同底座 RL vs 蒸馏）与 E12（开头之后还剩什么）。上一版（E08–E09）见提交 `ab5146b8` 的同名文件。实验卡 `experiments/E11-same-base-rl-vs-distill.md`、`E12-after-the-cue.md`；结果 `results/e11/`、`results/e12/`；文献调研 `notes/rl_vs_distill_survey.md`。所有数字是 pilot（L1），未经独立复算。§0–§4 只写事实；§5 是我的判断，单独标注。

## 0. 结果摘要

1. **同一个 Qwen3-8B-Base，纯 RL（DAPO）与蒸馏（官方 Qwen3-8B）在 DAPO 没训练过的题上 pass@1 增益接近**（易题 +8.9 vs +10.3；MATH L5 +11.1 vs +12.1），在 OlympiadBench 上 DAPO 较小（+12.3 vs +19.6）。pass@8：DAPO 与 Base 接近，蒸馏高于 Base（与 Yue et al. 的跨底座观察一致）。
2. **一个开头就追平了 DAPO 的全部增益。** 只让 Base 以 “Alright, I have this problem” 开头（DAPO 52–70% 的回答以 “Alright” 开头），不改任何参数：易题 +9.8、MATH L5 +13.6、OlympiadBench +15.7、DAPO 训练过的那批 MATH L5 题 +16.6。DAPO 在任何题集上都不超过这个开头（训练过的题也只多 1.4，CI 含 0）；逐题看，DAPO 的增益与“只加开头”的增益几乎落在同一批题上（校正后相关 0.90）。
3. **蒸馏只在更难的题上超出这个开头：** 易题 +0.5、MATH L5 未见 −1.5（均不显著），OlympiadBench +3.9、更难的那批 MATH L5 题 +10.7。
4. **开头之后，Base 在高熵位置取自己的首选不再有用：** OlympiadBench 上去随机化从 +6.3（无开头）变为 −0.3（有开头）。E07 测到的“去随机化”与相当一部分“选择效应”很可能都是在把 Base 带进同一种推理方式。
5. **交接（OlympiadBench）：** DAPO 写的前 32 个 token 交给 Base，Base 即达到 DAPO 的水平（51.5 vs 51.5），与 2510.00553 的预测一致，但仍低于只加开头（55.0）。蒸馏的前缀写到一半，Base 续写才到 52.8（蒸馏 58.8）；同一前缀换蒸馏模型续写的优势在 32 / 256 / 一半处为 +14.7 / +10.0 / +5.5，一直延续到回答后半。
6. **待补：** BA2（开头 + 分叉处取蒸馏首选）检验蒸馏超出开头的部分是否在分叉处；DAPO 续写自己前缀等交接的同模型对照。

## 1. 设置

- **模型（同一底座）：** Qwen3-8B-Base；Qwen3-8B（强到弱蒸馏：离线蒸馏 + 在线蒸馏 Qwen3-32B/235B，无 RL；技术报告 §4.5）；caiyuchen/DAPO-step-27（Qwen3-8B-Base 直接在 DAPO-Math-17k 上做 DAPO，无 SFT；2510.00553 作者发布）。提示一律用 Qwen3-8B 的模板渲染，DAPO 与 Qwen3-8B 分词器一致。
- **训练集重叠：** DAPO-Math-17k 收录了 157/300 道我们的 MATH L5 题、AIME 2022–23 的 49/60 题、OlympiadBench 6/501、易题 8/238。主结论只用 DAPO 没见过的题；MATH L5 按“见过/没见过”分开报告。DAPO 见过的那批 MATH L5 题对 Base 也更难（Base 36.5% vs 62.1%），对蒸馏来说它只是“更难的一半”。
- **题集：** 易题 = MATH-500 Level 1–3（238 题）；MATH L5（E07 的 300 题）；OlympiadBench（数值单答案 501 题）。AIME 在 4096 上限下 DAPO 截断 43%，不进结论。
- **解码：** T=0.6/top-p 0.95，上限 4096（锚点、同步解码）；交接总上限 8192。锚点每题 8 样本（BA1 4 样本），同步解码每题 1 条。
- **条件（全部在 Base 上）：** B0 采样；B1 = 高熵位置（T=1 熵 ≥0.5）取 Base 首选；B2 = 高熵位置取后训练模型首选（同步解码）；BA = 强制开头 “Alright, I have this problem”；BA1 = 开头 + B1；BA2 = 开头 + 取蒸馏首选（运行中）。P0 蒸馏采样、D0 DAPO 采样。
- **交接：** 从锚点回答截取前 L 个 token（32、256、该回答长度的一半；已写出答案的不用），交给另一模型续写，每题 2 个前缀。

## 2. 结果

### 2.1 总增益与覆盖（只算 DAPO 没训练过的题）

| 题集 | n | Base | 蒸馏 | DAPO | DAPO − 蒸馏 | pass@8 Base / 蒸馏 / DAPO |
|---|---|---|---|---|---|---|
| 易题 | 230 | 81.7 | 92.0 | 90.6 | −1.4 [−3.0, 0.2] | 96.1 / 96.5 / 96.5 |
| MATH L5 | 143 | 62.1 | 74.1 | 73.2 | −1.0 [−4.8, 2.7] | 83.2 / 88.1 / 84.6 |
| OlympiadBench | 495 | 39.2 | 58.8 | 51.5 | −7.3 [−9.3, −5.4] | 66.1 / 75.0 / 72.7 |
| MATH L5（DAPO 训练过） | 157 | 36.5 | 63.7 | 54.4 | −9.3 [−13.9, −4.8] | 70.1 / 84.7 / 82.2 |

- MATH L5 未见题上 pass@8：DAPO − Base +1.4 [−3.5, 6.3]，蒸馏 − Base +4.9 [0.0, 9.8]。
- DAPO 回答最长（MATH L5 未见 1509 token，蒸馏 1046、Base 729），上限 4096 下 OlympiadBench 截断 25%（蒸馏 10%、Base 8%）。
- 逐题增益（分半法：后训练模型一半样本减 Base 另一半样本，避免共用 Base 噪声）：MATH L5 未见题上 DAPO 与蒸馏校正后相关约 0.64；OlympiadBench 0.65。

### 2.2 开头

| 题集 | Base | Base + 开头 | DAPO | 蒸馏 | 开头 − Base | DAPO − 开头 | 蒸馏 − 开头 |
|---|---|---|---|---|---|---|---|
| 易题 | 81.7 | 91.5 | 90.6 | 92.0 | +9.8 [7.4, 12.2] | −0.9 [−2.4, 0.8] | +0.5 [−1.1, 2.2] |
| MATH L5 未见 | 62.1 | 75.6 | 73.2 | 74.1 | +13.6 [9.9, 17.3] | −2.5 [−4.3, −0.6] | −1.5 [−5.0, 2.3] |
| OlympiadBench | 39.2 | 55.0 | 51.5 | 58.8 | +15.7 [13.6, 18.0] | −3.4 [−4.9, −1.9] | +3.9 [1.9, 5.8] |
| MATH L5 DAPO 训练过 | 36.5 | 53.0 | 54.4 | 63.7 | +16.6 [11.8, 21.6] | +1.4 [−1.6, 4.4] | +10.7 [6.3, 15.1] |

- 开头使 Base 的回答长度与截断变得与 DAPO 相近（OlympiadBench 2187 token / 24%；DAPO 2083 / 25%）。
- 逐题增益（OlympiadBench，分半法，校正后）：DAPO 与“只加开头”0.90；蒸馏与“只加开头”0.69；DAPO 与蒸馏 0.65。
- 不是“任何开头都行”：E08b 中强制蒸馏模型最常见的开头 “We are given” 对 Base 无作用（MATH L5 48.0% vs 48.5%）。
- 该开头是看到 DAPO 的回答后选的（POST-HOC）；2610.24663 在 Qwen3-4B-Base 的 GRPO 模型上用同一个 “Alright” 只恢复了 35% 的增益。

### 2.3 交接（OlympiadBench 495 题；锚点 Base 39.2、DAPO 51.5、蒸馏 58.8、开头 55.0）

| L | DAPO 前缀 → Base | 蒸馏前缀 → Base | 蒸馏前缀 → 蒸馏 | Base 前缀 → DAPO |
|---|---|---|---|---|
| 32 | 51.5 | 45.3 | 59.9 | 46.5 |
| 256 | 53.2 | 50.1 | 60.1 | 43.6 |
| 一半 | 52.4 | 52.8 | 58.3 | 43.1 |

- DAPO 前 32 token → Base 与 DAPO 自己相同（−0.0 [−2.2, 2.1]），比“只加开头”低 3.5 [1.1, 5.7]。
- 同一前缀上续写模型的作用 G_蒸馏(s_P)：+14.7 [11.6, 17.9]、+10.0 [7.0, 13.0]、+5.5 [2.9, 8.0]。MATH L5 未见题上这一作用在 256 token 已为 +0.4（区间含 0）：蒸馏模型续写的作用在更难的题集上延续得更久。
- Base 写的前缀交给 DAPO，前缀越长 DAPO 越差（46.5 → 43.1）。
- 待补：DAPO → DAPO（G_DAPO）、Base → Base、Base → 蒸馏，以及 MATH L5 未见题上的 DAPO 交接。

### 2.5 对 E07–E10 的影响（事实层面）
- E07 在 MATH L5（300 题）测到蒸馏选择效应 +14.0。拆成 DAPO 没见过/见过两半：+8.4 / +19.1；前一半上，只加开头的 Base 已达到蒸馏水平。

## 3. 与已有工作的对照（调研笔记 `notes/rl_vs_distill_survey.md`；部分只读了摘要与相关章节，已在笔记中标明）

- **已被占的子结论：** RL 的 pass@k 不超过 Base、蒸馏能超过（Yue et al. NeurIPS'25；Qwen3 报告表 21）；RL 一侧的少数位置替换恢复增益（Sparse but Critical ICLR'26、2610.24663、Akgül 2605.06241、Shen et al. ICML'26）；RL 前 20 个 token 交给 Base 即接近完整 RL（2510.00553）；开头 cue 让 OLMo Base 达到 RL-Zero（2610.06851）；2610.24663 用 “Alright” 在 Qwen3-4B-Base GRPO 上恢复 35%。
- **没有找到的：** 同一底座上 RL 与蒸馏的逐位置对照、蒸馏一侧的前缀交接长度、开头对照下两种后训练的剩余差距。2510.00553 有蒸馏对照，但只用来说明秩一性质在蒸馏上不成立，未做交接。
- **竞争假设：** TIP 2604.14084 认为在线蒸馏中有信息量的位置包括低熵高分歧处；E07 的 B3（只在低熵分歧处换蒸馏首选）整体不显著。
- **强论文的开篇写法（调研摘录）：** 2610.24663 写 “These observations describe what changes, not which change produces the gain”，然后把观察变成对 Base 的干预。

## 4. 局限
- 上限 4096：DAPO 与“开头 Base”截断约 25%（OlympiadBench），蒸馏约 10%；绝对水平受上限影响，比较是同一上限内的。DAPO 训练时的回答上限远大于 4096。
- 只有一个 RL 存档（DAPO-step-27）和一个蒸馏模型；蒸馏模型的教师是更大的 Qwen3，RL 模型只用题目答案。
- 开头是看到 DAPO 的回答后选的；只试了一个措辞。
- Qwen3-Base 的预训练包含长推理数据（技术报告）；“一个开头就能进入的推理方式”可能是这类底座特有的。OLMo-3 Base 的预训练也含推理数据，E09 中它也是这样；没有在不含推理数据的底座上测。
- BA1 每题 4 样本，B2/BA2 每题 1 条；OlympiadBench 的 B1/B2 只有 E07 的 298 题。
- verifier 为字符串等价，对各条件相同。

## 5. 我的判断（与上面的事实分开）

（BA2 与剩余交接出来后补全；先写已经能判断的部分。）

### 5.1 这一轮改变了什么
上一轮的叙事是“后训练在什么条件下是开头模式、去随机化、或 Base 不会做的选择”，三种情形分属 OLMo（模式）、Qwen 易题（去随机化）、Qwen 难题（新选择）。这一轮在同一个 Qwen 底座上加入纯 RL 和开头对照后：
- 纯 RL（DAPO）在所有题集上都落在“模式”这一格，和 OLMo RL-Zero 一样。上一轮把“模式 vs 新选择”的差别归到底座家族上，现在看它更像是监督来源的差别。
- Qwen 上的“去随机化”在开头之后消失；“新选择”在中等难度题上也被开头取代，只在更难的题上留下蒸馏的剩余优势。三种情形可能并不并列：前两种很可能是同一件事（让 Base 进入它已有的长推理方式）在不同测量下的样子。

### 5.2 我认为现在可以立起来的问题
**同一个底座、同样的 pass@1 增益，RL 与蒸馏给 Base 加的是不是同一种东西？** 用一组对 Base 的干预来回答：一个开头、开头之后的去随机化与分叉选择、前缀交接需要多长、逐题提分是否重合。目前的数据给出的形态是：RL 的增益在我们测到的所有地方都等于“一个开头把 Base 带进它已有的推理方式”；蒸馏在这之上，在更难的题上还给了一部分，而且这部分在推理过程中持续起作用（交接到一半仍需要蒸馏模型）。

- 这直接落在领域里“RL 只是激发还是教了新东西”的争论上，但用的是同底座的干预对照，而不是 pass@k 曲线；pass@k 一侧（Yue et al.）我们只是复现。
- 对 token 替换类研究（Sparse but Critical、Shen et al.、2610.24663）：加上开头对照后，“少数位置的替换恢复增益”在 RL 模型上很可能主要是在做开头所做的事；这一点需要 BA2 和 DAPO 的开头后选择效应来确认。
- 风险（调研指出）：如果 BA2 显示蒸馏超出开头的部分也只是“少数高熵位置的选择”，那么蒸馏一侧只是把 RL 侧已有的发现换了一种后训练；如果不在分叉处、而是分布在更长的推理过程中，才是两者真正不同的地方。

### 5.3 下一步实验（事实缺口，不是选项）
- BA2（运行中）；DAPO 与开头 Base 的同模型交接（运行中）。
- 开头对照的稳健性：换 2–3 个措辞（含 OLMo 的 “Okay, let's”），上限 8192。
- 一个预训练不含长推理数据的底座上，RL 是否也只是一个开头。
