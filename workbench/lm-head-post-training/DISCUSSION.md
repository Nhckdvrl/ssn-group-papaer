# 讨论材料：同一底座上的纯 RL 与蒸馏，以及一个开头（2026-11-28）

> 本工作台唯一的讨论文档。范围：上次讨论（E08–E10）之后的 E11（同底座 RL vs 蒸馏）与 E12（开头之后还剩什么）。上一版（E08–E09）见提交 `ab5146b8` 的同名文件。实验卡 `experiments/E11-same-base-rl-vs-distill.md`、`E12-after-the-cue.md`；结果 `results/e11/`、`results/e12/`；文献调研 `notes/rl_vs_distill_survey.md`、`notes/rl_elicits_mode_survey.md`。所有数字是 pilot（L1），未经独立复算。§0–§4 只写事实；§5 是我的判断，单独标注。

## 0. 结果摘要

1. **同一个 Qwen3-8B-Base，纯 RL（DAPO）与蒸馏（官方 Qwen3-8B）在 DAPO 没训练过的题上 pass@1 增益接近**（易题 +8.9 vs +10.3；MATH L5 +11.1 vs +12.1），在 OlympiadBench 上 DAPO 较小（+12.3 vs +19.6）。pass@8：DAPO 与 Base 接近，蒸馏高于 Base（与 Yue et al. 的跨底座观察一致）。
2. **一个开头就追平了 DAPO 的全部增益**（“开头等于 RL”本身已由 Wang et al. 2610.06851 在 Qwen3-14B 与 OLMo 上报告，见 §3）。只让 Base 以 “Alright, I have this problem” 开头，不改任何参数：易题 +9.8、MATH L5 +13.6、OlympiadBench +15.7、DAPO 训练过的那批 MATH L5 题 +16.6。DAPO 在任何题集上都不超过这个开头（训练过的题也只多 1.4，CI 含 0）；上限 8192 下仍相等（OlympiadBench 55.6 vs 55.0）；换成单词 “Alright” 或 OLMo 的 “Okay, let's”（不取自本 RL 模型）也与 DAPO 无显著差别；逐题看，DAPO 的增益与“只加开头”的增益几乎落在同一批题上（校正后相关 0.90）。
3. **蒸馏只在更难的题上超出这个开头：** 易题 +0.5、MATH L5 未见 −1.5（均不显著），OlympiadBench +3.9（8192 下 +4.3）、更难的那批 MATH L5 题 +10.7；蒸馏的逐题增益与开头的相关只有 0.69。
4. **开头之后，“去随机化”在三个题集上都消失**（易题 −0.5、MATH L5 −2.2、OlympiadBench −0.3；无开头时 +6.3 到 +7.0）；蒸馏的选择效应从 +7.4 降到 +3.4（CI 含 0），但“开头 + 高熵位置换成蒸馏首选”使 Base 到达蒸馏水平（57.4 vs 58.8，差不显著）。E07 测到的去随机化和约一半的选择效应，与开头做的是同一件事。
5. **交接（OlympiadBench）：** DAPO 写的前 32 个 token 交给 Base，Base 即达到 DAPO 的水平（51.5 vs 51.5），与 2510.00553 的预测一致；之后续写者是 DAPO 还是 Base 只差 +3.4，到一半 ≈0。蒸馏的前缀写到一半，Base 续写才到 52.8（蒸馏 58.8）；同一前缀换蒸馏模型续写的优势在 32 / 256 / 一半处为 +14.7 / +10.0 / +5.5，一直延续到回答后半。

## 1. 设置

- **模型（同一底座）：** Qwen3-8B-Base；Qwen3-8B（强到弱蒸馏：离线蒸馏 + 在线蒸馏 Qwen3-32B/235B，无 RL；技术报告 §4.5）；caiyuchen/DAPO-step-27（Qwen3-8B-Base 直接在 DAPO-Math-17k 上做 DAPO，无 SFT；2510.00553 作者发布）。提示一律用 Qwen3-8B 的模板渲染，DAPO 与 Qwen3-8B 分词器一致。
- **训练集重叠：** DAPO-Math-17k 收录了 157/300 道我们的 MATH L5 题、AIME 2022–23 的 49/60 题、OlympiadBench 6/501、易题 8/238。主结论只用 DAPO 没见过的题；MATH L5 按“见过/没见过”分开报告。DAPO 见过的那批 MATH L5 题对 Base 也更难（Base 36.5% vs 62.1%），对蒸馏来说它只是“更难的一半”。
- **题集：** 易题 = MATH-500 Level 1–3（238 题）；MATH L5（E07 的 300 题）；OlympiadBench（数值单答案 501 题）。AIME 在 4096 上限下 DAPO 截断 43%，不进结论。
- **解码：** T=0.6/top-p 0.95，上限 4096（锚点、同步解码）；交接总上限 8192。锚点每题 8 样本（BA1 与措辞对照 4 样本），同步解码每题 1 条。
- **条件（全部在 Base 上）：** B0 采样；B1 = 高熵位置（T=1 熵 ≥0.5）取 Base 首选；B2 = 高熵位置取后训练模型首选（同步解码）；BA = 强制开头 “Alright, I have this problem”；BA1 = 开头 + B1；BA2 = 开头 + 高熵位置取蒸馏首选（同步解码，OlympiadBench 298 题）。P0 蒸馏采样、D0 DAPO 采样。
- **交接：** 从锚点回答截取前 L 个 token（32、256、该回答长度的一半；已写出答案的不用），交给另一模型续写，每题 2 个前缀。

## 2. 结果

### 2.1 总增益与覆盖（只算 DAPO 没训练过的题）

| 题集 | n | Base | 蒸馏 | DAPO | DAPO − 蒸馏 | pass@8 Base / 蒸馏 / DAPO |
|---|---|---|---|---|---|---|
| 易题 | 230 | 81.7 | 92.0 | 90.6 | −1.4 [−3.0, 0.2] | 96.1 / 96.5 / 96.5 |
| MATH L5 | 143 | 62.1 | 74.1 | 73.2 | −1.0 [−4.8, 2.7] | 83.2 / 88.1 / 84.6 |
| OlympiadBench | 495 | 39.2 | 58.8 | 51.5 | −7.3 [−9.3, −5.4] | 66.1 / 75.0 / 72.7 |
| MATH L5（DAPO 训练过） | 157 | 36.5 | 63.7 | 54.4 | −9.3 [−13.9, −4.8] | 70.1 / 84.7 / 82.2 |

- MATH L5 未见题上 pass@8：DAPO − Base +1.4 [−3.5, 6.3]，蒸馏 − Base +4.9 [0.0, 9.8]。
- DAPO 回答最长（MATH L5 未见 1509 token，蒸馏 1046、Base 729），上限 4096 下 OlympiadBench 截断 25%（蒸馏 10%、Base 8%）。
- 逐题增益（分半法：后训练模型一半样本减 Base 另一半样本，避免共用 Base 噪声）：MATH L5 未见题上 DAPO 与蒸馏校正后相关约 0.64；OlympiadBench 0.65。

### 2.2 开头

| 题集 | Base | Base + 开头 | DAPO | 蒸馏 | 开头 − Base | DAPO − 开头 | 蒸馏 − 开头 |
|---|---|---|---|---|---|---|---|
| 易题 | 81.7 | 91.5 | 90.6 | 92.0 | +9.8 [7.4, 12.2] | −0.9 [−2.4, 0.8] | +0.5 [−1.1, 2.2] |
| MATH L5 未见 | 62.1 | 75.6 | 73.2 | 74.1 | +13.6 [9.9, 17.3] | −2.5 [−4.3, −0.6] | −1.5 [−5.0, 2.3] |
| OlympiadBench | 39.2 | 55.0 | 51.5 | 58.8 | +15.7 [13.6, 18.0] | −3.4 [−4.9, −1.9] | +3.9 [1.9, 5.8] |
| MATH L5 DAPO 训练过 | 36.5 | 53.0 | 54.4 | 63.7 | +16.6 [11.8, 21.6] | +1.4 [−1.6, 4.4] | +10.7 [6.3, 15.1] |

- 开头使 Base 的回答长度与截断变得与 DAPO 相近（OlympiadBench 2187 token / 24%；DAPO 2083 / 25%）。
- 上限 8192（每题 4 样本）：OlympiadBench 开头 55.6、DAPO ≈ 55.0、蒸馏 ≈ 59.9（开头 − DAPO +0.7 [−1.7, 2.9]，蒸馏 − 开头 +4.3 [2.0, 6.7]）；MATH L5 未见 74.5、75.2、75.9，彼此无差别。DAPO 与蒸馏在 8192 下的水平取自交接中“续写自己 32 token 前缀”（§2.3）。
- 措辞（OlympiadBench，每题 4 样本，上限 4096）：单词 “Alright” +13.8 [11.6, 16.1]、“Okay, let's” +10.8 [8.6, 12.9]、完整句 +15.7；DAPO − 单词 “Alright” −1.5 [−3.3, 0.3]，DAPO − “Okay, let's” +1.5 [−0.2, 3.3]。完整句是看到 DAPO 的回答后选的；“Okay, let's” 取自 2610.06851 在 OLMo 上的 cue。
- 不是任何开头都行：E08b 中强制蒸馏模型最常见的开头 “We are given” 对 Base 无作用（MATH L5 48.0% vs 48.5%）。
- 逐题增益（OlympiadBench，分半法，校正后）：DAPO 与“只加开头”0.90；蒸馏与“只加开头”0.69；DAPO 与蒸馏 0.65。

### 2.3 交接（续写总上限 8192；每题 2 个前缀）

OlympiadBench（495 题；锚点在上限 4096 下：Base 39.2、DAPO 51.5、蒸馏 58.8、开头 55.0）：

| L | DAPO 前缀→Base | →DAPO | 续写者的作用 G_DAPO | 蒸馏前缀→Base | →蒸馏 | G_蒸馏 | Base 前缀→Base | →DAPO |
|---|---|---|---|---|---|---|---|---|
| 32 | 51.5 | 55.0 | +3.4 [0.8, 6.2] | 45.3 | 59.9 | +14.7 [11.6, 17.9] | 40.4 | 46.5 |
| 256 | 53.2 | 56.4 | +3.1 [0.9, 5.4] | 50.1 | 60.1 | +10.0 [7.0, 13.0] | 41.5 | 43.6 |
| 一半 | 52.4 | 53.1 | +0.7 [−1.2, 2.6] | 52.8 | 58.3 | +5.5 [2.9, 8.0] | 40.8 | 43.1 |

- G = 同一前缀上，换成后训练模型续写比 Base 续写多出的准确率。DAPO 写完前 32 个 token 之后，续写者是谁差别小（+3.4 → +0.7）；蒸馏模型的作用持续到回答一半（+14.7 → +5.5）。
- MATH L5 未见题（143 题）：G_DAPO 在三个 L 上均不显著（+1.1、−0.7、+1.8）；G_蒸馏 = +9.8 [4.6, 15.0]、+0.4、−2.5——这批题上蒸馏模型的作用在 256 token 前就结束了。
- 上限的影响：“模型续写自己 32 token 前缀”近似该模型在 8192 下的水平：Base 40.4、DAPO 55.0、蒸馏 59.9；DAPO 从 4096 到 8192 涨 3.5（蒸馏 1.1、Base 1.2）。

### 2.4 高熵位置上的选择

| | 易题 | MATH L5 未见 | OlympiadBench |
|---|---|---|---|
| 去随机化 B1 − B0（无开头） | +7.0 [3.4, 10.5] | +6.5 [1.9, 10.9] | +6.3 [2.4, 10.1] |
| 蒸馏选择 B2 − B1 | +1.3 [−3.0, 5.7] | +8.4 [2.1, 15.4] | +7.4 [2.0, 12.8] |
| DAPO 选择 B2 − B1 | +3.5 [−0.4, 7.4] | +0.7 [−5.6, 7.0] | +7.7 [2.7, 13.1] |
| 开头之后去随机化 BA1 − BA | −0.5 [−2.6, 1.6] | −2.2 [−4.6, 0.1] | −0.3 [−1.9, 1.4] |
| 开头之后蒸馏选择 BA2 − BA1 | — | — | +3.4 [−0.6, 7.3] |

- OlympiadBench：无开头时 B1 45.6 + DAPO 选择 7.7 ≈ 53.3，低于只加开头的 55.0。B2 的换词约 40% 在回答前 20%（E07）。
- BA2（57.4%）与蒸馏（58.8%）无显著差别：开头之后，只在 Base 的高熵位置换成蒸馏首选，Base 就到达蒸馏的水平；这一步本身 +3.4 不显著（每题 1 条，n=298）。无开头时的选择效应 +7.4 约一半被开头取代。
- DAPO 训练过的那批 MATH L5 题（更难）：DAPO 选择效应 +17.2 [9.6, 25.5]、蒸馏 +19.1；B2_DAPO ≈ 56.1，与开头（53.0）、DAPO（54.4）相近；没有测开头之后的 DAPO 选择。

### 2.5 对 E07–E10 的影响（事实层面）
- E07 在 MATH L5（300 题）测到蒸馏选择效应 +14.0。拆成 DAPO 没见过/见过两半：+8.4 / +19.1；前一半上，只加开头的 Base 已达到蒸馏水平。
- E10：B2 回答截到一半交给 Base，保留了 B2 约 3/4 的收益。B2 的前段换词与“开头”作用的关系未测。
- E09：OLMo RL-Zero 的增益基本是开头 “.\n\nOkay, let's”；现在 Qwen 底座上的纯 RL（DAPO）也是这样。

## 3. 与已有工作的对照（调研笔记 `notes/rl_vs_distill_survey.md`、`notes/rl_elicits_mode_survey.md`；哪些读了全文、哪些只读了摘要与相关章节，笔记中逐篇标明）

- **“一个开头就等于 RL”已有人报告：** Wang et al. 2610.06851（arXiv）在 Qwen3-14B-Base 上预填 “Alright,” 使 MATH-500 从 72 到 87，等于他们自训的 GRPO 模型；OLMo-3-7B 上 “.\n\n Okay” 42 → 78（RL-Zero 75）；预算 31744 token。RL 把 P(“Alright,”) 从 0.04 提到 0.58，Base 与 RL 的 KL 集中在前两个位置；通过改 OLMo 中期训练数据追溯了 cue 的来源。他们只覆盖 R1-Zero 式 RL，没有蒸馏、没有逐题对照、没有交接、没有 RL 训练过的题。
- **相反方向的结果：** Zhang et al. 2610.24663：Qwen3-4B-Base 与 DAPO-Math-17k 上的 GRPO 模型，AIME 120 题、上限 8192，只强制单词 “Alright” 恢复 35%（10.0 → 13.2，RL 19.3）；在约 4% 贪心选择不同的位置换成 RL 的选择恢复 90.5%。我们这里单词 “Alright” 恢复 112%（§2.2），差别不来自措辞长度；模型规模（4B）与题目难度（AIME）未测。
- **RL 与蒸馏可唤起程度不同：** Venhoff et al.（ICML'26 spotlight，2510.07364）：在 Base 上加 steering 向量恢复 RL 思考模型差距的约 76%，但只恢复 SFT 蒸馏模型差距的约 11%；模型对是 Qwen2.5/Llama 的不同对，没有开头对照、没有同底座比较。
- **RL 的增益来自预训练已有行为的其他证据（对象不同）：** Spurious Rewards（Qwen2.5-Math 的代码推理）、Echo Chamber（RL 放大预训练中的一种输出格式）、Karan & Du（Base 采样匹配 RL）、1-shot RLVR。没有一篇把固定开头与 RL 的全部增益对比。
- **底座的预训练内容：** OLMo 3 报告明确写 Dolmino 中期训练含思考轨迹（QwQ 1.87%、OpenThoughts2 1.25% 等），“为 RL-Zero 打基础”。Qwen3 报告只说第二阶段提高了 “STEM、代码、推理与合成数据” 的比例（约 5T token），没有明说含长推理链；“Qwen3-Base 预训练含长推理数据”是推断。
- **RL 侧的少数位置替换与前缀：** Sparse but Critical（ICLR'26）、Shen et al.（ICML'26）、Akgül 2605.06241；2510.00553：RL 的前 20 个 token 交给 Base 即接近完整 RL（有蒸馏对照但未做交接）。pass@k 一侧：Yue et al.（NeurIPS'25）。
- **调研对“没人做过什么”的结论：** 没有找到在同一底座上同时有 RL、蒸馏和开头对照的研究；“蒸馏只在更难的题上超出开头”“蒸馏模型的续写作用持续到回答一半而 RL 只在开头”“开头之后取 Base 首选不再有用”“RL 训练过的题上也不超出开头”均未见报告。
- **强论文的开篇写法（调研摘录）：** Wang：“if reasoning may already be present in the base model, how little intervention is needed to elicit it?”；Zhang：“These observations describe what changes, not which change produces the gain.”

## 4. 局限
- 上限 4096：DAPO 与“开头 Base”截断约 25%（OlympiadBench），蒸馏约 10%；8192 的核对只在 OlympiadBench 与 MATH L5 未见题上做，且 DAPO/蒸馏的 8192 水平来自交接中的自续写，不是独立锚点。
- 只有一个 RL 存档（DAPO-step-27）和一个蒸馏模型；蒸馏模型的教师是更大的 Qwen3，RL 模型只用题目答案。
- 开头完整句是看到 DAPO 的回答后选的；另两个措辞只在 OlympiadBench、上限 4096 上测。
- Qwen3-Base 预训练是否含长推理数据是推断；OLMo-3 Base 明确含。没有在不含推理数据的底座上测。
- BA1 每题 4 样本，B2/BA2 每题 1 条；OlympiadBench 的 B1/B2/BA2 只有 E07 的 298 题；BA2 只在 OlympiadBench 上测。
- 难题只到 OlympiadBench 与更难的一半 MATH L5；AIME 在可承受的上限下截断过多，没有进入比较。
- verifier 为字符串等价，对各条件相同。

## 5. 我的判断（与上面的事实分开）

### 5.1 这一轮改变了什么
上一轮的叙事是“后训练在什么条件下是开头模式、去随机化、或 Base 不会做的选择”，三种情形分属 OLMo（模式）、Qwen 易题（去随机化）、Qwen 难题（新选择）。这一轮在同一个 Qwen 底座上加入纯 RL 和开头对照之后：
- 三种情形不并列。“去随机化”在开头之后消失，“新选择”的约一半也被开头取代；它们和开头一样，主要是在让 Base 进入它已有的长推理方式。上一轮把 OLMo 与 Qwen 的差别归到底座家族上；同一底座上的 DAPO 显示，那更像是监督来源的差别。
- “开头等于 RL”本身不是我们的发现（Wang et al.）。我们在同一底座上补上了它对 RL 训练过的题、更长上限、不同措辞、逐题分布和交接都成立。

### 5.2 我认为现在可以立起来的问题
**同一个底座上，RL 与蒸馏带来的准确率增益可以一样大；它们改变 Base 的方式是否相同？** 用一组只作用于 Base 的干预来回答：一个开头；开头之后取 Base 自己的或后训练模型的高熵首选；把后训练模型写的前缀交给 Base，看续写者的作用持续多久；两者逐题提分是否重合。

目前的数据给出的答案是“不同”，并且不同的方式可以具体描述：
- **纯 RL：** 在我们测到的每个读数上都等于一个开头——平均准确率、逐题分布（0.90）、交接（只有前 32 个 token 重要）、它训练过的题、8192 上限、三种措辞。
- **蒸馏：** 在中等难度以下也等于一个开头；在更难的题上多出一部分（OlympiadBench +4，更难的一半 MATH L5 +11）。这部分分布在整个推理过程里：交接到回答一半时，续写者是蒸馏模型仍多 +5.5；开头之后，只在 Base 的高熵位置换成蒸馏首选就能补上（BA2 ≈ 蒸馏）。

对领域的意义：
- “RL 是激发还是教了新东西”的争论里，pass@k 证据（Yue et al.）与 token 替换证据（Sparse but Critical、Shen et al.、2610.24663）常被放在两边。同底座的开头对照显示，在这类底座上 token 替换测到的“关键决策”里有相当部分就是进入推理方式；真正超出这一点的，在我们的数据里来自蒸馏，并且只出现在更难的题上。
- 比较 RL 与蒸馏（或评价一个 RL 方法）时，“Base + 开头”是一个必需的参照点；没有它，RL 的增益和蒸馏的增益看起来是一回事。

和近邻的分工：Wang（开头等于 RL，单一 RL 模型）、Venhoff（steering 能补回 RL 差距的大部分、蒸馏差距的少部分，不同模型对）、2510.00553（RL 只需短前缀）各给了一块；在同一底座上把 RL、蒸馏和开头放在一起，并测出蒸馏多出的部分在哪、持续多久，是目前没有的。

关于风险：调研指出，若蒸馏多出的部分也只是“少数高熵位置的选择”，蒸馏一侧就是把 RL 侧已有的发现换了一种后训练。BA2 的结果确实是这样（开头之后高熵位置换词就补上），所以单独说“蒸馏的增益在分叉处”不是新东西；新的是对比本身——同样的高熵位置干预，在 RL 模型上测到的就是开头的作用，在蒸馏模型上开头之后还剩一部分，且只在更难的题上。这一对比能否撑起一篇论文，取决于它在第二个底座上是否复现。

### 5.3 事实缺口
- 只有一个底座（Qwen3-8B-Base）同时有 RL 与蒸馏模型；OLMo 只有 RL 一侧。结论是否依赖“预训练含长推理数据的底座”，需要一个不含这类数据的底座上的同一组对照。
- 只有一个 RL 存档；更长训练或更大预算的 RL 是否会超出开头，未知。
- BA2 每题 1 条、只在 OlympiadBench；“蒸馏多出的部分可由高熵位置换词补上”的 CI 宽。
- 与 Zhang 35% 的差别：措辞长度已排除；模型规模（4B）和题目难度（AIME）未测。
