# 讨论文档：后训练在下一 token 分布上改变了什么（2026-11-27）

> 本工作台唯一的讨论文档，每轮在原处更新。命令、全部数字和对照见 `experiments/E04-*.md`、`experiments/E05-*.md`、`CLAIMS.md`（C07–C13）与 `results/e04|e05/`。所有数字都是单任务（MATH，外加选择题）的 pilot，L1，未经独立复算。

## 0. 一句话

后训练的数学增益集中在 Base 高熵的“分叉”位置，但两个家族的分叉性质不同。Qwen3-8B：Base 只在分叉位置（约占 token 的 10–22%）改用 Post 的分布，复现 93% 的增益；反过来 Post 只在这些位置改用 Base 的分布，丢掉 86% 的增益；Base 在那里只取自己的众数也能拿到 80%。OLMo-3 RL-Zero：38 个点的增益中约 29 个来自回答开头的一个模式选择（开始解题，还是接着写提示），强制一个 4 token 的开头即可补上，超出它的约 9 个点才属于 RL。两个家族的后训练模型在分叉处自身都更集中，并把首选换成 Base 的第 2/3 候选。这种改选在单个分叉上测不出价值差（分辨率 ±0.02），累积起来在 Qwen 上约 +4 点（Post 众数 vs Base 众数）。所以在这些数据里，后训练在分叉处的作用以“去随机化”为主、“选得更对”为辅；后者是许多微小效应的累积，不是少数关键选择。

## 1. 这一轮怎么推进的

上一轮人审后，从 LM Head 扩展到“后训练改变了什么输出行为”，入口是全局仿射成分（τ·z₀+b）。实验按“暴露信息最多的下一步”推进：

1. 全局成分（E04-A/B）→ 它依赖上下文家族，行为上主要控制停止，不能独立移植；但“Base 降温”带来了大部分增益。
2. 降温的增益来自哪里（熵门控）→ 来自高熵位置。
3. 后训练模型在这些位置做了什么（A2/A3/A4）→ 自身更集中，并改选 Base 的第 2/3 候选。
4. 这些位置是否决定准确率（D，分叉交换解码）→ 是：只替换这些位置的决策就复现大部分增益。
5. 改选是否价值导向（E05）→ 否。

## 2. 主要发现

**2.1 降温（锐化）能拿到约七成增益，收益来自分叉位置。**
- Qwen：Base T=1/0.7/0.5/0.3 = 46.5/61.5/67.7/70.6%，Post 79.5%：33 点中拿到 24 点。
- OLMo：Base 43.0%，RL-Zero 81.2%，Base T=0.5 70.5%：38 点中拿到 27.5 点。两家族都是约 72–73%。
- 熵门控（Qwen）：只在 Base 高熵位置降温，阈值 0.25/0.5/1.0 → 67.5/64.3/62.3%；只在低熵位置 → 50.4%；min-p 0.1 → 61.7%。结论不依赖阈值。
- 熵门控（OLMo）：只在高熵位置降温 70.9%（全局 T=0.5 是 70.5%），只在低熵位置 43.1%（Base 43.0%）：降温的全部收益都来自高熵位置。
- 模板稳健性（Qwen，同为聊天格式、换一种指令措辞）：Base 39.8%，T=0.5 64.7%，高熵门控 62.9%，Post 81.6%；降温拿到差距的 60%（原模板 73%）。方向稳定，比例依赖模板（55–73%）。纯文本模板对 Post 不公平（不会停止，91% 截断），不计。

**2.2 少数分叉位置决定了大部分增益（D，Qwen，500 题）。**

| 两模型同步解码（分叉 = Base 熵 ≥0.5） | 准确率 [95% CI] | 分叉占 token |
|---|---|---|
| Base | 43.6% [39.2, 48.2] | 31.7% |
| Post | 78.8% [75.4, 82.6] | 23.7% |
| Base，分叉处取 Base 众数 | 71.6% [67.6, 75.8] | 9.8% |
| Base，分叉处取 Post 众数 | 75.8% [72.2, 79.6] | 14.7% |
| Base，分叉处从 Post 的分布采样 | 76.4% [72.6, 80.0] | 21.9% |
| **反向：Post，分叉处从 Base 的分布采样** | **48.6% [44.2, 53.0]** | 40.9% |

- 取 Base 众数补上 35.2 点差距中的 28.0 点（80%）；取 Post 众数补上 32.2 点（91%）；从 Post 的分布采样补上 32.8 点（93%），与 Post 的剩余差距 2.4 [−0.4, 5.6] 不显著。Post 的分叉分布比 Base 众数好 4.8 [1.2, 8.4]。
- 反向交换：Post 只在 Base 高熵的位置改用 Base 的分布，准确率从 78.8% 跌到 48.6%，只比 Base 高 5.0 [0.6, 9.4] 点，即丢掉 86% 的增益。正反两个方向一起说明：Base 高熵位置既是增益的充分位置，也是必要位置；Base 有把握的位置上 Post 的改变几乎不贡献准确率。
- 注意反向条件的分叉占比是 41%：Post 写出的文本对 Base 而言更“意外”，Base 在其中更多位置不确定。所以反向条件替换的 token 更多，这个必要性结论的位置范围比正向的宽。
- 也就是说，后训练的效果几乎全部可以只在分叉位置用 Post 替换 Base 来复现；其余 ~80% 的位置让 Base 自己采样几乎没有损失。
- 混杂：取众数同时把解析失败从 13.6% 降到 2.8%，部分增益来自答案格式。
- OLMo：两模型同步的 HF 实现不可行（OLMo-3-7B 无 GQA，RL-Zero 回答平均约 4000 token，KV 缓存超出显存，4 个条件均 OOM）。改用下一条的“开头模式”检验。

**2.2b OLMo 的增益有很大一部分在回答开头的一个“模式分叉”上。** RL-Zero 模板以 “…after "Answer:"” 结尾；Base 在 T=1 下 22% 以 “but before you…”、18% 以 “line. You MUST…” 开头，即接着写提示，而不是开始解题。降温或只在高熵处降温后，75% 以上以 “.\n\nOkay, let's” 开头。在中性文本上拟合的全局偏置（最抬高的 token 是 “Okay”）把 Base 从 43.0% 提到 70.8%；从 RL-Zero 去掉在自身生成上拟合的全局成分则跌回 42.3%。**只把回答开头强制为 “.\n\nOkay, let's”、其后 Base 按 T=1 正常采样：71.9%**，与全局降温（70.5%）、高熵门控（70.9%）、中性文本偏置（70.8%）相同；强制开头后再降温到 0.5：71.8%，没有额外收益。也就是说，OLMo 上“锐化”的全部收益（约 29 点）都来自开头的这一个模式选择；模式定下后，Base 在 T=1 的推理与锐化后一样好。真正属于 RL-Zero 的提升是 81.2−71.9 ≈ 9 点。这与 Liu et al. 2503.20783（模板决定 Base 是回答问题还是续写句子）一致，是比较 Base 与 RL-zero 模型时的评测口径混杂；今后 OLMo 的分析应以“强制推理开头的 Base”为参照。Qwen 的 Base 开头都已是解题（“To solve…”），没有这个现象：两个家族的“分叉”性质不同（OLMo 的主要增益在开头模式，Qwen 的在推理内部）。

**2.3 后训练模型在分叉处“自身更集中 + 候选重排”。**
- 集中：分叉位置上，后训练模型前 10 名以外的概率质量比 Base 少 2–6 倍，前 10 名内的熵也更低（两家族）。
- 重排：30–42% 的分叉首选被换掉，新首选有 50–71% 是 Base 的第 2 名，前 3 名合计 67–88%。RL-Zero 典型是 So→Wait、Let→Wait、So→Therefore、but/maybe→no；Qwen 多为风格格式（To→We、`---`、`:\n\n`）。
- SFT（OLMo Instruct-SFT）在分叉处更平，不是这个模式。
- 更正：此前用逐位置 τ 得出“分叉处不更尖锐”，那是在 Base 坐标下缩放 Base logits 的假象；直接测自身分布后结论如上。

**2.4 改选不是价值导向（E05，负结果）。**
- 两家族各 300 个改选分叉：接子模型首选与接 Base 首选、再由 Base 续写，答对率差 Qwen −0.003 [−0.025, 0.018]，RL-Zero −0.002 [−0.025, 0.021]。换成 Base 另一个高排名候选也无差别；子模型的 logit 改变与价值差无相关。
- 改由后训练模型自己续写（Qwen）：答对率整体更高（0.73 vs Base 续写 0.64），但接它的首选与接 Base 首选仍无差别（+0.007 [−0.008, 0.021]），相关 −0.07。无论用哪个模型定义价值，单个分叉上的改选都不是价值导向的。（OLMo 的子模型续写版在跑）
- 分叉是否真的决定结果（Qwen，与蒙特卡洛地板比较 |Δv|）：Base 续写时，改选分叉的平均 |Δv| 0.115，地板 0.077；|Δv|≥0.25 的占 23%，地板 12%。也就是说约一成分叉的候选确实影响 Base 的结果，但正负对称，平均为零。Post 续写时 |Δv| 与地板相同（0.070 vs 0.068）：后训练模型接任何一个靠前候选都能同样走下去。这提示后训练的一部分作用是续写对分叉选择不敏感，而不是在分叉处选对。
- **分辨率的限制（修正上一版的说法）：** E05 只能排除单个分叉上大于约 0.02 的价值差。Qwen 每个回答有上百个分叉，35 点的差距摊到每个分叉只需约 0.002，所以 E05 的零结果不排除许多微小效应的累积。D 中 Post 众数比 Base 众数好 4.2 [0.4, 8.0] 点，就是这种累积的改选效应；它与“单个分叉无价值差”并不矛盾。因此上一版“软价值理论的局部预测不成立”说得过头：能说的是相关接近 0、单点效应 <0.02，不能说方向错误。
- 所以决定结果的主要是整条轨迹上分叉处的分布：Base 在分叉处按 T=1 采样会抽到排名更低的候选，这种随机性在上百个分叉上累积（取众数即补 80%）；以及（OLMo）开头的模式选择。

**2.5 全局词表成分：依赖上下文家族，行为上是控制 token，不能独立移植。**
- 同类上下文内 τ+b 能去掉 26–58% 的 KL，跨来源迁移常失败；加到 Base 上生成全部失败（2.9–14.6%）；从 Post 去掉它，准确率 79.5→71.7%，但 96% 不再停止。
- 实现位置：OLMo RLVR 的全局成分在骨干的公共偏移里，Qwen 的在头里（ΔW·μ）。这是原 LM Head 问题留下的定位结果。

**2.6 选择题：全局答案偏好 vs 题内区分。** OLMo Instruct-SFT 的 +16.6 点中，约一半只需纠正全局字母先验就能得到，另一半是题内区分；Qwen 的 +3.6 点中 +2.8 来自先验纠正。

## 3. 与已有工作的关系（定位）

- “RL 主要是锐化/重加权”：Yue et al. 2504.13837、RL Squeezes 2509.21128、Invisible Leash 2507.14843、Karan & Du 2510.14901（序列级幂分布采样可匹配 RL）、熵最小化 2505.15134、Huang et al. 2412.01951（锐化理论）。我们的增量是：在真实后训练模型上，逐 token 地定位增益发生在哪里（少数分叉）、后训练在那里做了什么（集中 + 重排）、以及重排是否价值导向（否）。
- 高熵分叉 token：Wang et al. 2506.01939（RLVR 主要调整高熵 token）、Bigelow et al. 2412.07961（按结果定义分叉）。我们补上：分叉处的具体改选内容及其单点价值。
- 解码方法：EDT 2403.14541（按熵调温）、CoT-decoding 2402.10200、min-p。熵门控与分叉交换只作为诊断工具，不是方法贡献。
- 理论：KL 正则 RL 的最优修正是软价值 log Z（Cohen et al. 2607.22837 式 4）。E05 在单个熵分叉上测不到这一修正（价值差 <0.02，相关≈0）；累积的改选效应约 +4 点。要真正检验软价值方向，需要按结果定义的分叉（Bigelow et al. 2412.07961）：只在单点价值差大的位置看改选方向。
- 模板效应：Liu et al. 2503.20783 指出模板决定 Base 是回答问题还是续写句子。OLMo 的开头模式结果（C13）是同一现象，不能算我们的发现；它的作用是给出比较 Base 与 RL-Zero 时必须扣除的对照。
- 最近邻：Wang et al. 2506.01939 从训练侧发现 RLVR 主要改变约 20% 的高熵 token。我们的区别在于推理侧的正反交换（充分与必要），以及分叉处是“去随机化”还是“改选”。

## 4. 我对研究价值的判断（供讨论，不预设）

- **可能的论文主旨：** “后训练的推理增益主要是分叉处的去随机化，改选只贡献小的累积效应”。它直接回应“RL 是否只是锐化”的争论，并且给出可检验的局部机制：增益在哪些位置、以什么形式（尾部被压掉、首选重排但不改变价值）。
- **G1–G8 自查：** 分叉定义依赖熵阈值，行为结论已查阈值敏感性，分布读数还没查；也可以加一个与阈值无关的定义（按重采样后结果是否改变来定义分叉）。“锐化有用”本身部分可预期（G4 风险）。不可预期的部分是：Base 高熵位置对增益既充分又必要（正反交换），而且后训练模型的续写对分叉选择不敏感。参照点（Base、Post、随机候选）与跨家族对比都已具备。
- **与导师标准的冲突（需要注意）：** “去随机化为主、改选为辅”本质上是“X 占多少、Y 占多少”的拆分，导师 11-05 明确不接受这类问题。可直接测、不依赖拆分的说法是位置性的：增益在哪些位置（Base 高熵处，正反交换充分且必要），以及后训练模型在那里的分布有什么可测性质（更集中、对选择不敏感）。如果继续，论文问题应写成后者，“80% vs 4 点”只作描述。
- **主要风险：**
  1. “RL≈锐化”这条线很拥挤，必须讲清与 Karan & Du、熵最小化在问题上的差别（它们问“能否不用 RL 拿到增益”，我们问“真实后训练模型在 token 层面做了什么、哪些位置承载增益”）。
  2. 单一任务（数学）。需要至少一个非数学的可验证任务（代码或逻辑）。
  3. 价值检验已用 Base 续写和 Post 续写两种口径（Qwen 两种都为零，OLMo 的 Post 续写版在跑）。
  4. 模板稳健性：第二个聊天模板下方向一致，但锐化能拿到的比例在 55–73% 之间变化（2.1）。
  5. OLMo 的大部分增益是开头模式（已有 Liu et al. 指出模板效应），这一部分不能算作我们的发现；它是评测口径的混杂，需要在论文里作为对照处理。
