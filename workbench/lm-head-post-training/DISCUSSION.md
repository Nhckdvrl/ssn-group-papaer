# 讨论材料：上次讨论以来的实验与结果（2026-11-27）

> 本工作台唯一的讨论文档。范围：上次讨论（第二轮 GPT/Gemini 反馈）之后做的全部实验 E04–E06，以及对近邻文献的全文核对。每个实验的命令、对照与原始数字见 `experiments/E04-*.md`、`E05-*.md`、`E06-*.md`，主张账本见 `CLAIMS.md`（C07–C14），结果文件在 `results/e04|e05/`。所有数字都是首轮 pilot（证据等级 L1），未经独立复算。

## 0. 结果摘要

1. **全局仿射成分（τ·z₀+b）：** 在同类上下文内能解释后训练 KL 的 26–58%，但换一类上下文就失效。加到 Base 上，生成全部失败；从 Post 中去掉，主要后果是不再停止。它不是可以单独移植的“后训练效果”。
2. **降温：** 只给 Base 降温，就能拿到 MATH-500 上后训练增益的约 72–73%（Qwen3-8B、OLMo-3 RL-Zero 两个家族）。这部分收益全部来自 Base 的高熵位置。
3. **OLMo-3 RL-Zero：** 降温的收益实际上全部来自回答开头的一个模式选择，即开始解题，还是接着写提示。强制一个 4 token 的开头，Base 就有 71.9%；RL-Zero 是 81.2%。
4. **后训练模型在 Base 高熵位置的分布（两个 RL 家族）：** 自身更集中，前 10 名以外的质量少 2–6 倍。30–42% 的位置首选被换成 Base 的第 2/3 候选。SFT 模型在这些位置反而更平。
5. **分叉交换（Qwen）：**
   - 正向：Base 只在高熵位置改从 Post 采样，复现 93% 的增益。
   - 反向：Post 只在这些位置改从 Base 采样，丢掉 86% 的增益。
   - Base 在这些位置只取自己的众数，也能拿到 80%。
   - 正反交换在近作中已有人做过，见 §3。
6. **单个分叉上的改选（E05，两个家族，Base 续写与 Post 续写两种口径）：**
   - 接后训练模型的首选还是接 Base 的首选，对答对率没有可测影响（分辨率约 ±0.02）。
   - 只看真正影响结果的那些分叉，后训练模型押对更好候选的比例也与随机无异。
7. **分叉处什么承载增益（E06，Qwen）：** Post 全程生成，只在 Base 高熵位置改变取法：
   - 取 Base 的众数：76.0%，Post 为 78.8%。
   - 从 Base 的头部候选采样：66.0%。
   - 从 Base 的全分布采样：48.6%。
   - 取 Post 自己的众数：80.8%。

   分叉处的随机性，无论落在尾部还是头部，都损失大量准确率（约 17 点和 10–11 点）。两边都取众数时，Post 的首选比 Base 的首选好 4–5 点；这一差别在 Post 和 Base 两种上下文中都显著且一致，单个分叉上测不出，是累积效应。

## 1. 设置与统计口径

- **模型对：**
  - Qwen3-8B-Base → Qwen3-8B（多阶段后训练，谱系不透明）。
  - OLMo-3-7B Base → RL-Zero-Math（纯 RLVR）。
  - OLMo-3 Base → Instruct-SFT（SFT 参照）。
- **任务：** MATH-500 全部 500 题；同一个 verifier（`\boxed` 与 “Answer:” 行）；统一停止符。另做了选择题实验（ARC-Challenge + MMLU，共 2644 题）。
- **模板：** Qwen 用聊天模板（`qwen_chat`），OLMo 用 RL-Zero 官方模板。另做了一个 Qwen 第二模板（`qwen_chat2`）作稳健性检查。
- **“分叉”：** Base 在当前前缀下 T=1 的下一 token 熵 ≥0.5 nats。这是操作定义，不是按结果定义的分叉。
- **统计：** 准确率的 CI 都是按题 bootstrap；条件之间用同一批题的配对差。B 系列每题 2 个样本，D/E06 每题 1 个样本：单条件 CI 约 ±4 点，配对差 CI 约 ±3–4 点。
- **算力：** 本轮约 25 GPU·时，每个实验单卡运行，分布在 fvcrc10/11/12/20。

## 2. 实验与结果

### 2.1 全局仿射成分（E04-A，固定前缀）

拟合 KL(p_post ‖ softmax(τ·z_base + b))，用留出上下文评估。拟合器在合成数据上能恢复 τ 与 b，对应的单测都通过。

- **同类上下文：** τ+b 去掉 26–58% 的 KL。
- **跨来源迁移：** 常失败。RL-Zero 在数学生成上拟合的 b，用到中性文本上 KL 增大 22 倍；只有“中性→数学生成”方向部分可迁移。
- **成分内容：**
  - SFT 在数学生成上的 57% 主要来自 `<|im_end|>` 等特殊 token，去掉特殊 token 后只有 16%。
  - RL-Zero 在自己生成上的 58% 是普通 token 偏好：压低 `boxed`、`Answer` 和连续空行。
- **实现位置：** OLMo RLVR 的全局成分几乎全在骨干的公共偏移里（相关 0.30–0.80，头 ≤0.19）。Qwen 的主要在头里（ΔW·μ，相关 0.76–0.81）。
- **全局 τ：** RLVR 约为 1.0–1.05，Qwen 为 0.79–0.85。
- **行为（E04-B）：**
  - 把拟合的全局成分加到 Qwen Base 上，生成全部失败（2.9–14.6%：过早停止或循环）。
  - 从 Qwen Post 去掉支撑受限的全局成分，准确率 79.5→71.7%，但 96% 的回答不再停止。
  - OLMo：中性文本上拟合的偏置（最抬高 “Okay”）把 Base 从 43.0% 提到 70.8%；自身生成上拟合的偏置把 Base 降到 15.2%；从 RL-Zero 去掉自身生成上拟合的成分，降到 42.3%。原因见 2.4。

### 2.2 降温与熵门控（E04-B，MATH-500，每题 2 个样本）

| | Qwen3-8B 家族 | OLMo-3 RL-Zero 家族 |
|---|---|---|
| Base T=1 | 46.5% | 43.0% |
| Base T=0.7 / 0.5 / 0.3 | 61.5 / 67.7 / 70.6% | — / 70.5% / — |
| 只在 Base 高熵位置（H≥0.5）降到 0.5 | 64.3%（阈值 0.25/1.0：67.5/62.3%） | 70.9% |
| 只在低熵位置降到 0.5 | 50.4% | 43.1% |
| 全局 min-p 0.1 | 61.7% | — |
| Post T=1 / 0.5 | 79.5 / 80.8% | 81.2% / — |

- 降到 0.5 后，Qwen 拿到 33 点增益中的 24 点（73%），OLMo 拿到 38 点中的 27.5 点（72%）。
- 两个家族的降温收益都来自高熵位置；只在低熵位置降温几乎没有收益。
- **Qwen 第二模板**（同为聊天格式，换一种指令措辞）：Base 39.8%，T=0.5 64.7%，高熵门控 62.9%，Post 81.6%。降温拿到差距的 60%：方向一致，比例依赖模板。
- 纯文本模板下 Post 不会停止（91% 截断），对 Post 不公平，不计入。

### 2.3 后训练模型在高熵位置的分布（E04-A2/A3/A4）

位置取自模型自身的生成，按两模型的平均熵分桶，以避免均值回归假象。

- **集中：** 在平均熵 0.5–2 的位置，后训练模型自身更集中。
  - Qwen 前 10 名以外的质量从 0.006–0.033 降到 0.001–0.010；前 3 名以外从 0.17 降到 0.11；前 10 名内部的熵也更低。
  - RL-Zero 前 10 名以外的质量降为 1/2–1/3。
  - 后训练模型放在“Base 尾部 token”（p < 0.1·p_max）上的质量反而更多（Qwen 0.118→0.216），即集中到的候选与 Base 不同。
- **重排：** 30–42% 的位置首选被换掉。新首选有 50–71% 是 Base 的第 2 名，落在前 3 名的合计 67–88%，排在第 10 名以后的只有 3–12%。
  - RL-Zero 典型的改选是反思和验证标记：So→Wait、Let→Wait、So→Therefore、but/maybe→no。
  - Qwen 多为行文结构与格式：To→We、`---`、`:\n\n`。
- **SFT：** OLMo Instruct-SFT 在这些位置更平（等效 τ 0.79–0.87），不是这种模式。
- **低熵位置：** 两个 RL 家族都更尖锐（τ 1.1–1.4），但那里只占 KL 的约 1/4–1/3。KL 的 68–74% 在高熵位置。
- **更正：** 起初用“逐位置最优温度”得出“高熵位置不更尖锐”。这个温度是在 Base 坐标里缩放 Base 的 logits，首选一旦被换掉，只能取更平的值，所以那是度量假象。直接测后训练模型自身的分布后，结论如上。

### 2.4 OLMo：回答开头的模式选择（E04-B）

- **开头分布：** RL-Zero 模板以 “…after "Answer:"” 结尾。Base 在 T=1 下，22% 的回答以 “but before you…” 开头，18% 以 “line. You MUST…” 开头，即接着写提示，而不是开始解题。降温或只在高熵处降温后，75% 以上以 “.\n\nOkay, let's” 开头。
- **强制开头：** 只把回答开头强制为 “.\n\nOkay, let's”，其后 Base 按 T=1 正常采样，得到 **71.9%**。这与全局降温（70.5%）、高熵门控（70.9%）、中性文本偏置（70.8%）相同。强制开头后再降到 T=0.5，为 71.8%，没有额外收益。
- **结论：** OLMo 上降温、门控和偏置的全部收益（约 29 点）都是开头的这一个模式选择。模式定下之后，Base 在 T=1 下的推理与降温后一样好。RL-Zero 超出强制开头 Base 的部分约 9 点。
- **Qwen：** Qwen 的 Base 开头已经是解题（“To solve…”），没有这个现象。
- 这与 Liu et al. 2503.20783 指出的模板效应同源。

### 2.5 分叉交换解码（E04-D，Qwen，500 题，每题 1 个样本）

Base 与 Post 在同一前缀上同步解码（HF 实现，KV 缓存逐步结果与完整重算一致），只在 Base 熵 ≥0.5 的位置改由另一方决定。

| 条件 | 准确率 [95% CI] | 解析失败 | 分叉占 token |
|---|---|---|---|
| Base | 43.6 [39.2, 48.2] | 13.6% | 31.7% |
| Post | 78.8 [75.4, 82.6] | 9.0% | 23.7% |
| Base，分叉处取 Base 众数 | 71.6 [67.6, 75.8] | 2.8% | 9.8% |
| Base，分叉处取 Post 众数 | 75.8 [72.2, 79.6] | 9.4% | 14.7% |
| Base，分叉处从 Post 采样 | 76.4 [72.6, 80.0] | 8.4% | 21.9% |
| Post，分叉处从 Base 采样 | 48.6 [44.2, 53.0] | 12.6% | 40.9% |

- **正向：** 从 Post 采样补上 35.2 点差距中的 32.8 点（93%），与 Post 的差 2.4 [−0.4, 5.6]。只取 Base 自己的众数，也补上 28.0 点（80%）。
- **两种众数对比：** Post 众数比 Base 众数好 4.2 [0.4, 8.0]；但 Base 众数的解析失败更少（2.8% 对 9.4%）。
- **反向：** Post 只在这些位置改从 Base 采样，比 Base 只高 5.0 [0.6, 9.4]，丢掉 86% 的增益。反向条件中分叉占 41%：Post 的文本对 Base 更“意外”，所以替换的范围比正向宽。
- **OLMo：** 同步解码不可行。OLMo-3-7B 没有 GQA，RL-Zero 的回答平均约 4000 token，KV 缓存超出 80 GB，4 个条件都显存溢出。

### 2.6 单个分叉上的改选是否价值更高（E05）

- **设置：** 每个家族取 300 个改选分叉（后训练首选 ≠ Base 首选）和 100 个一致分叉，来自后训练模型自己在 MATH 训练集 128 题上的生成，按题分层。对每个候选 token（Base 首选、后训练首选、Base 的另一个高排名候选），从前缀加该 token 续写 K 次，答对率记为 v。一致分叉重复续写两次，给出蒙特卡洛地板。

| | Qwen，Base 续写（K=8） | Qwen，Post 续写（K=8） | OLMo，Base 续写（K=4） | OLMo，RL-Zero 续写（K=4） |
|---|---|---|---|---|
| v(Base 首选) | 0.645 | 0.728 | 0.539 | 0.509 |
| v(后训练首选) − v(Base 首选) | −0.003 [−0.025, 0.018] | +0.007 [−0.008, 0.021] | −0.002 [−0.025, 0.021] | +0.006 [−0.015, 0.029] |
| v(另一高排名候选) − v(Base 首选) | −0.016 [−0.036, 0.004] | +0.002 [−0.013, 0.016] | +0.004 [−0.018, 0.026] | +0.006 [−0.013, 0.026] |
| 相关（后训练模型的 logit 改变 vs log 价值比） | −0.02 | −0.07 | +0.02 | −0.09 |
| 平均 \|Δv\|：改选分叉 / 地板 | 0.115 / 0.077 | 0.070 / 0.068 | 0.120 / 0.107 | 0.077 / 0.087 |

- **单点结论：** 两个家族、两种续写口径下，在这些分叉上选哪个靠前候选，对答对率都没有可测影响；后训练模型的 logit 改变与价值差无关。RL-Zero 中改选为 Wait 等反思标记的 28 个分叉：Base 续写 −0.018 [−0.098, 0.063]，自身续写 −0.054 [−0.125, 0.018]。
- **哪些分叉真正影响结果（事后分析）：**
  - Base 续写时，改选分叉的 |Δv| 超过地板：Qwen 中 |Δv|≥0.25 的占 23%，地板 12%；OLMo 中 |Δv|≥0.5 的占 11%，地板 6%。即约一成分叉的候选确实影响 Base 的结果。
  - 在这些分叉上，后训练模型的首选是更好的那个：Qwen 32/70（p=0.55），OLMo 15/34（p=0.61），与随机无异。
  - 后训练模型自己续写时，|Δv| 与地板相同，没有可筛出的决定性分叉。
- **分辨率：** 单点只能排除大于约 0.02 的价值差。Qwen 每个回答有上百个分叉，35 点的差距摊到每个分叉只需约 0.002，所以 E05 不排除许多微小效应的累积。2.5 中“Post 众数比 Base 众数好 4.2 点”就是累积量。
- **截断：** OLMo 续写的截断率为 44%（Base）和 56%（RL-Zero），上限 3072，截断按答错计。配对比较不受影响，但 v 的绝对值偏低。

### 2.7 分叉处承载增益的是什么（E06，Qwen，500 题，每题 1 个样本）

与 2.5 的设置完全相同，补齐“上下文（Base / Post）× 分叉处取法”的表格。取法包括：众数、只从 Base 的头部候选采样（p ≥ 0.1·p_max，即 min-p 0.1）、全分布采样。

| 分叉处的取法 | Post 全程 | Base 全程 |
|---|---|---|
| 从 Post 采样 | 78.8（= Post） | 76.4 |
| 取 Post 众数 | 80.8 [77.2, 84.2] | 75.8 |
| 取 Base 众数 | 76.0 [72.0, 79.8] | 71.6 |
| 从 Base 头部采样 | 66.0 [62.0, 70.2] | 60.4 [56.2, 64.6] |
| 从 Base 全分布采样 | 48.6 | 43.6（= Base） |

解析失败：Post 9.0%，Post/Base 众数 0.6%，Post/Base 头部采样 3.2%，Post/Base 全分布 12.6%，Post/Post 众数 4.6%。

- **Post 上下文：**
  - Post − Post/Base 众数 = 2.8 [−0.4, 6.0]。
  - Post/Base 众数 − Post/Base 头部采样 = 10.0 [6.2, 13.8]。
  - Post/Base 头部采样 − Post/Base 全分布 = 17.4 [12.6, 22.2]。
- **Base 上下文：**
  - Base 众数 − Base 头部采样 = 11.2 [6.8, 15.4]。
  - Base 头部采样 − Base = 16.8 [11.8, 21.6]。
- **“谁的首选”（两边都去掉随机性）：**
  - Post 上下文：Post 众数 − Base 众数 = 4.8 [1.8, 8.0]。Post 众数 − Post（采样）= 2.0 [−0.8, 4.8]。
  - Base 上下文：Post 众数 − Base 众数 = 4.2 [0.4, 8.0]。
- **结论：** 在 Base 高熵位置，随机性无论落在尾部（p < 0.1·p_max）还是头部候选之间，都有害，量级分别约 17 点和 10–11 点，两个上下文一致。两边都取众数时，Post 的首选比 Base 的首选好 4–5 点，两个上下文一致，而且 Post 众数条件的解析失败更多（4.6% 对 0.6%）。所以格式混杂不能解释这一差别，它是真实但较小的选择效应。E05 在单个分叉上测不出它，因为它分摊在上百个分叉上。
- **按题目难度分层（事后分析，零 GPU）：** MATH-500 自带难度等级。“谁的首选”（Post 众数 − Base 众数，两个上下文取平均）在 Level 1–3（238 题）为 +2.1 [−1.1, 5.3]，在 Level 4–5（262 题）为 +6.7 [2.5, 11.3]，难易之差 +4.6 [−0.8, 9.9]。Level 5 单独看：Base 上下文 47.0→53.7，Post 上下文 52.2→62.7；Post 全程（采样）为 55.2，低于 Post 全程取 Post 众数。去随机化的收益（Base 众数 − Base）在各难度都有 23–35 点。分层是看到结果后做的，每层每条件只有约 100–130 个单样本，只能作为提示。
- **格式混杂：** 取众数会大幅减少解析失败。只看两边都解析成功的题（按结果筛选，有偏，仅作参考）：
  - Post 86.6% 对 Post/Base 众数 81.7%（454 题）；Post/Post 众数 84.7% 对 Post/Base 众数 79.6%（476 题）。
  - Base 上下文中 Base 众数 78.2% 对 Post 众数 83.8%（445 题）。
- **运行偏差：** `post_basetrunc` 因显存溢出续跑，`post_postmode` 为提速，两者都拆到两张卡上跑，后半段用 seed 1，题目集合不变。已在看到结果前记入 E06 卡。`post_postmode` 是看到前三个条件后补的对照（POST-HOC 设计）。

### 2.8 选择题：全局答案偏好与题内区分（E04-C）

ARC-Challenge + MMLU，共 2644 题，用字母 logit 作答；“去先验”指减去同一题集上的平均字母偏好（上下文校准）。

- **OLMo Instruct-SFT：** Base 48.9%（去先验 57.0%）→ SFT 65.5%（65.1%）。+16.6 点中约一半去掉字母先验就能得到，另一半是题内区分。
- **Qwen：** 74.2%（77.0%）→ 77.8%（77.6%）。+3.6 点中有 +2.8 来自先验纠正。
- 在 2.1 的其他上下文上拟合的 b，抓不到字母先验。

## 4. 局限（就数据本身而言）

- **任务与基准：** 只有一个可验证任务（数学），外加选择题。MATH-500 对 Qwen3-8B-Base 偏容易，降温后的 Base 已有 68–72%。
- **采样设置：** 我们的 Base 按 T=1 不截尾采样。近作的 Base 本来就截尾（top-p 0.7 或 T=0.6/top-p 0.95），而且在 AIME 上交换收益仍然很大。2.7 的比例可能依赖这一设置与基准难度。
- **分叉定义：** 依赖熵阈值。行为读数在阈值 0.25–1.0 内方向稳定；分布读数（2.3）未查阈值敏感性。没有用按结果定义的分叉。
- **覆盖范围：** 分叉交换只在 Qwen 上做了，OLMo 因显存不可行。
- **样本量：** D/E06 每题 1 个样本，小于 4 点的差别不可解读。
- **价值检验分辨率：** 单点约 ±0.02，见 2.6。
- **混杂：** 取众数的条件同时改变了格式和完成率，见 2.7。
- **模板：** 降温能拿到的比例随模板在 55–73% 之间变化。OLMo 的大部分差距是模板引起的开头模式（2.4）。
