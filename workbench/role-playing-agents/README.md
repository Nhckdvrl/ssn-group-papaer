## 驻留原则与当前进度

1. **先辨认重要能力，再选择环境/算法**：不能从代码方便、某个错例、一个 2×2 表格或优雅损失直接宣告“领域瓶颈”。
2. **普通强系统是实质竞争者**：完整角色资料、允许的历史/记忆、世界事实/知情边界、正常推理与反思、已有条件规则和必要执行反馈；必要时再比较公开角色专用方法。信息、长度、算力和作者劳动区分报告。
3. **客观真值与人物解释分开**：动作合法性、事件已发生等可验证；人物动机、合理转折、戏剧质量通常允许多解，不把手写效用锁或裁判模型偏好冒充心理学真值。
4. **训练方法暂不冻结**：SFT、偏好学习、GRPO/轨迹 RL、记忆/状态、LoRA/激活等是候选工具，按实际问题选择；反事实玩家分支差异不直接当作 NPC 动作优势。
5. **人物行为与人类意义分开**：角色像不像、玩家读不读得懂、故事有没有互动价值是不同构念；模拟玩家/LLM Judge 不能代替所有人类证据。
6. **吸取矿区 A 教训**：能测的局部差异≠重要科学贡献；普通提示恢复的事实应改变总体判断；不要让实验细化无限代替选题取舍。
