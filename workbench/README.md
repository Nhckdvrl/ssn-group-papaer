# Workbench

This is where research actually **grows**.

A workbench begins with an important territory, not a finished paper idea. It owns:
- the strongest practical baseline we can reproduce;
- baseline strengthening / recipe checks;
- exploratory analyses;
- failed perturbations;
- successful signals;
- stable observations;
- changing hypotheses;
- local literature / artifact notes needed for this object.

There is intentionally **no top-level `observations/`**. Observations belong to the workbench that produced them.

## Default progression

1. clone / reproduce the strongest relevant baseline;
2. make sure the baseline is genuinely strong and understood;
3. inspect failures, slices, dynamics, interventions, and sensitivity;
4. treat large negative deltas and broken assumptions as useful gradients;
5. update hypotheses freely;
6. only when the evidence naturally crystallizes a clear paper identity, promote it to `../candidates/`.

A workbench may end as a candidate, a paused knowledge asset, or a failed line with reusable lessons. It does **not** need to become a paper.
