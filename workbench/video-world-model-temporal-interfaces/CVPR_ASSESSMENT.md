# CVPR 2027 可行性评估 — 块首控制失聪（chunk-onset deafness）

**日期：2026-09-29　｜　状态：工作台评估，不是候选论文**

> **合并时更新（2026-09-29 13:20）**：写作时 E26/E27 尚无结果，现已补上——E27 块缝重叠推理（minWM DMD，4 个提示词）把原块首位置从 0.12 恢复到 1.02 px/°、与块内持平（块内平均 1.0，恢复比例 >90%，满足下文 60% 门槛；画质未测、仅 1 个模型）；E26 单步 x₀ 探针对位姿不灵敏，判为方法无效。块首阶跃开/关在 minWM 已有数据（E09）：起步落在块首→首个潜变量不转（0.07），延迟一个潜变量后正常；停止落在块首→多转一个潜变量。WorldPlay 的阶跃、32 潜变量、未蒸馏 AR 与双向模型探针正在运行。

CVPR 2027 截稿 **2026-11-16 AoE**（补充材料 11-23），距今 **48 天**。

---

## 0. 一句话结论

**值得推进，但要有条件。** 目前的现象是真实的、干净的，也可能是新的：在三个独立的开源系统上，因果分块世界模型对"效果落在生成块第一个潜变量上"的控制变化几乎完全失聪，而同一谱系的双向老师和逐帧生成的 Oasis 没有这个问题。但距离 CVPR 的尺度还差三块：**(1) 样本量和读数太薄，(2) 实际影响还没立住，(3) 没有修复方法。**建议 10 月 13 日设一个 go/no-go 关口（见 §5）。

## 1. 校对：逐项对照结果文件

我对照了 `results/summary/*.json` 和分析脚本，逐项核对 README 里的数字。

| 项目 | 核对结果 |
|---|---|
| 测量口径 | 所有系统都用同一种读数：灰度帧间相位相关 → 水平位移 → 减去同种子、无动作参考 → 对指令之后的所有潜变量积分，再除以指令角度（`phase_survival.py`）。**"失聪"指总朝向从未改变，不是延迟。**这个口径是对的，也比较严格。 |
| E22 块网格平移 | 数字与 README 一致。块首每个提示词的数值很稳（0.05–0.15），平移后丢失位置跟着块走（k=12：1.75 → 0.08）。**这是目前最强的一条证据。**但不平移时，**第一个块**的块内响应也≈0（k=4/5/6：0.17/0.09/0.00，提示词间正负号乱跳），对比只在第 2、3 块成立 → 第一块可能受首帧条件影响，论文里要单独处理。 |
| E23 相位随机微调 | 数字一致（块首/块内：0.135/0.82 → 0.30/3.2）。但 README 写的"→ 不是数据相位问题"**过度推断**：总共只训练了 250 步×2 样本，只测了 n=4 个提示词。比例从 0.16 变为 0.09 是"此剂量下没修复"，不能排除数据解释。另外块内响应 4–5 px/° 远高于稳态增益（E20 中约 2.1 px/°），说明微调改变了整体增益，**必须按各自模型的阶跃增益归一化后再比较。** |
| E25 WorldPlay | 块首 −0.03 px/°，三个场景都极稳，可信。但 README 里"第 2 位 2.5 px/°"混入了最后一块的 k=12（≈0）；只算前三块时是 3.77。**最后一块整块无响应**（块内也是 0）原因不明。在排除适配器/管线问题（动作或位姿截断、记忆重组）之前，这个异常是审稿人会抓住的漏洞。 |
| E20 推理时调度 | 一致（块首 0.076/0.034；推迟一格 0.46/0.73；摊开 0.26–0.33）。 |
| E04/E07 MG2 老师 vs 学生 | 一致。注意老师 A0.2 那组只有 n=4 和 n=1，不能引用。 |
| 统计量 | 大多数关键结论是 **n=3–5 个提示词、单种子**，都没有置信区间。这对工作台够用，对论文不够。 |
| 机制叙述 | 目前有**两套不同的机制说法**：MG2 是"学生不读历史动作 + 块内多数派抹掉"，minWM 是"跨块相对位姿不被使用，只靠块内对比 + 视觉惯性"；WorldPlay 最后一块全失聪则没有解释。论文需要一个统一的机制，并用直接测量来支撑。 |
| 未记录的实验 | E26（`mwm_tf_probe.py`，教师强制单次前向探针）和 E27（`mwm_overlap.py`，块缝重叠推理，代价 4/3）已有脚本、没有结果。**这两个正是最需要的机制验证和简单修复。** |

## 2. 查新：最近邻工作与新颖性边界

说明：本环境无法直接访问 arXiv 全文，以下依据检索摘要、项目 README 和代码仓库判断。**投稿前需要逐篇读全文确认。**

| 工作 | 与我们的关系 | 是否占掉我们的结论 |
|---|---|---|
| **ActionSplice**（arXiv 2609.08230，2026-09） | **骨干完全相同（minWM + HY-WM1.5）**，研究的正是"块边界处的动作变化"：动作在块采样中途改变时怎么修正求解器状态。代码里事件被强制放在块边界。 | 否。他们处理的是**时延/中途打断**问题，默认模型会跟随新动作；他们的事件是持续性动作（有块内对比），不会暴露块首失聪。但这是**最危险的邻居**：同一批人随时可能注意到这个现象。它也是我们的机会——我们可以说他们的修正目标本身在块首就是失聪的。 |
| **WorldMark**（2604.21686） | 用控制论视角把动作跟随当作**阶跃响应**来测（方向、纯度、延迟、稳定性）。 | 否。每个按键**持续 20 秒**，结构上看不到短事件。可以用来支撑"现有基准看不到这个问题"。 |
| **WBench**（2605.25874）、GameWorld Score（MG2） | 多轮交互、动作跟随基准 | 否。都是持续动作。 |
| **Matrix-Game 3.0**（2604.08995） | 宣称"对用户输入有帧级响应"，5B，块结构同类。 | 否，而且**我们的结果直接反驳这类说法**。它应该是第 4 个被测系统。 |
| **Causal Forcing / ++**（2602.02214、2605.15141）、Causal-rCM、ForgeWM（2608.14022） | 分块→逐帧、少步蒸馏；Causal Forcing++ 明确说分块学生"响应粒度粗"。 | 否。他们只说粒度粗（延迟），没有说块首**完全不响应**，也没有定位到因果化阶段。审稿人可能会说"逐帧 AR 就能解决"——我们需要回应：逐帧自回归要付出质量和速度代价，而且 Oasis 只能证明"存在性"。 |
| **IV-VAE**（CVPR 2025） | VAE 时间相位不平衡 | 已被我们排除为原因（E02/E06）；可以作为"相位问题在 CVPR 上是可发的"先例。 |
| KV-cache 注意力分析（如 2601.21896） | 发现跨块过渡主要靠对"过渡锚帧"的局部注意力来维持 | 不是同一现象，但**支持我们的机制**（块首内容由缓存最后一帧决定），应当引用。 |
| X-Cache（2604.20289） | 指出块边界处动作流不平滑，缓存假设在这里失效 | 属于效率问题，不是控制问题。 |

**结论：检索到的工作里，没有一篇报告"块首潜变量对控制失聪、双向老师不失聪、问题产生于因果化阶段、跟着块网格走"。**新颖性目前看是成立的，但这个方向竞争极其激烈（每月几十篇世界模型论文），窗口期很短。

## 3. CVPR 需要的尺度 vs 当前进度

参照模板：同类被接收的"发现一个普遍缺陷"型论文（IV-VAE；"Common Diffusion Noise Schedules and Sample Steps are Flawed"；ViT registers），它们的共同结构是：**在多个主流模型上都存在的缺陷 → 清楚的机制 → 很简单的修复 → 修复在标准指标上不掉点。**只有诊断、没有修复的论文在 CVPR 上明显更难中。

| 维度 | CVPR 需要 | 当前 | 缺口 |
|---|---|---|---|
| 系统覆盖 | ≥4–5 个开源系统，跨机构 | 3 个（MG2、minWM、WorldPlay）+ 2 个阴性对照（双向老师、Oasis） | 加 MG3.0，再加 1 个（Yume/LingBot-World/GameCraft 中开源的） |
| 统计 | 每个条件 ≥20 个场景 × ≥2 个种子，有置信区间 | n=3–5，单种子 | **大** |
| 读数 | ≥2 种独立读数 | 只有相位相关水平位移 | 加位姿估计（如 VGGT / MegaSaM）；只测偏航 → 加俯仰、平移、离散按键 |
| 实际影响 | 用户层面可感知的后果 | E13 连续人类操作下 R² 只差 0.03；E19 细调误差 2.9° | **最大的风险**，见 §4 |
| 机制 | 统一、有直接测量 | 两套说法 + 一个未解释的异常 | E26 探针；每个块内位置上动作对损失的敏感度 |
| 修复 | 简单、跨模型、不损质量 | E18 无效（剂量不足）、E20 部分有效、E23 此剂量下无效 | E27 块缝重叠（推理时）+ 一个训练端修复 |
| 基准 | 说明现有基准为何看不见 | 已有：官方训练/评测轨迹相位锁死；WorldMark 按住 20 秒 | 可以打包成一个"相位分辨的控制探针"小基准 |

## 4. 是否值得推进

### 支持推进
1. **现象干净且可复现**：同噪声逐位一致的配对反事实，E22 块网格平移这种因果性控制，老师/学生对照，VAE 已排除，Oasis 作为阴性对照。这些实验设计本身就达到了顶会的水平。
2. **跨三个机构、三种动作接口**（逐帧鼠标窗口 / 纯位姿 / 位姿 + 离散标签）都复现了。
3. **有"反直觉 + 被广泛忽视"的叙事**：MG3.0 等宣称帧级响应；官方训练和评测轨迹恰好都避开了块首（差一格的计数约定），所以没人看到。
4. **计算上可行**：主要是冻结模型推理，单机就能完成；修复（E27）只在推理时做。
5. **时机**：ActionSplice 等工作正在同样的骨干上研究块边界，说明这个方向很热，但别人还没有看到这个现象。

### 主要风险（按严重程度排序）
1. **实际影响可能不够大（最关键）。**在交互模式下，一个动作通常持续整个块，所以"块首的短事件"在真实使用中本来就很难被输入。审稿人会说"单潜变量脉冲是人为构造的探针"。
   → **需要马上做的判别实验**：在块首**开始或停止**一次持续转动（阶跃开/关），看首个潜变量是否丢掉一步、朝向是否永久少转 A、停止时是否因为惯性多转一格。流式交互中**每一次动作切换都恰好落在块首**，如果阶跃在块首也丢一格，影响就从"罕见短事件"变成"每个指令都晚一个潜变量/偏一步"——这会让论文的重要性上一个台阶。E01 显示 MG2 的阶跃起点逐帧精确，所以这个问题在不同系统上可能表现不同，必须分别测量。
2. **没有修复。**E27 是最便宜的方案；如果重叠推理能在 4/3 算力下把块首响应恢复到块内的 60% 以上，并且不影响画质，就有了一个完整的故事。
3. **"结构性" vs "数据"没有定论。**这决定论文的主张写成什么样，但不决定能不能投：两种结果都可以写（"因果分块的教师强制目标对跨块控制几乎不给梯度"本身就是一个可测量的命题）。
4. **WorldPlay 最后一块的异常**：如果是我们适配器的问题，会连带影响审稿人对所有 WorldPlay 数字的信任。
5. **竞争**：ActionSplice 团队在完全相同的骨干上工作。

### 不建议的方向
- 不要把论文写成"控制带宽 / 相位效应"（E02 已被 IV-VAE 占掉，而且带宽说法太泛）。核心对象是**块首**。
- 在机制查清之前，不要设计新的架构或新的损失。
- 不要再追加 DMD 阶段的微调（E18 已经说明剂量不够，成本高、信息量低）。

## 5. 七周计划与关口

| 时间 | 任务 | 产出 |
|---|---|---|
| **第 1 周（9/30–10/6）** | ① 查清 WorldPlay 最后一块；② 块首阶跃开/关实验（minWM、WorldPlay、MG2）；③ E26 教师强制探针 + E27 重叠推理出结果；④ 用位姿估计复核一组关键数字；⑤ E23 第 500 步 | 判断实际影响的大小；得到第一个修复信号 |
| **第 2 周（10/7–10/13）** | 扩大样本（20 个场景 × 2 个种子）；加 MG3.0；加平移和离散按键 | **10/13 go/no-go** |
| 第 3–4 周（10/14–10/27） | 修复：E27 在 ≥2 个模型上验证 + 一个训练端修复（例如只对块首潜变量加动作对比/动作 CFG，或在教师强制训练时随机平移块网格）；质量指标（VBench 类 + WorldMark 类）；真实人类输入轨迹上的"短事件丢失率" | 主结果表 |
| 第 5–6 周（10/28–11/10） | 写作、作图、相关工作、消融 | 完整初稿 |
| 第 7 周（11/10–11/16） | 打磨、内部审稿 | 投稿；补充材料 11/23 前提交 |

**10/13 关口标准：**
- **继续（按 CVPR 完整论文写）**：≥4 个系统复现；块首阶跃也有可测的损失，**或者**有一个短事件场景能量化出有意义的丢失率；E27 或训练修复能把块首恢复到块内的 ≥50%，并且画质不下降。
- **降级**：现象成立但没有修复 → 改写成"诊断 + 基准"论文，投 CVPR 的风险明显变高，可以考虑 CVPR workshop 或 ICML 2027（1 月底截稿），同时把修复做完。
- **停止**：扩大样本后块首效应明显减弱（例如块首/块内比例 > 0.5），或者发现是适配器问题。
