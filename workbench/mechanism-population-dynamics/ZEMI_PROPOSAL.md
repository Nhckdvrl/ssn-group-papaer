# zemi 提案：上下文绑定的已发表机制，在独立训练的不同 LLM 上成立吗？（草稿，2026-11-25）

> 给导师看的一页提案。中文版供我们内部讨论，日文版在定稿后另附。依据：[找题工作页](TOPIC_SEARCH.md)、[论文卡索引](../../library/themes/interpretability-representation/README.md)、实验卡 E224–E228。

## 1. 从先生的问题出发

先生的问题是：**模型的分工没有被逐一指定，独立训练后会不会形成相同的机制？** 过去两个月我们在三个层次上碰过这个问题：

| 层 | 问法 | 我们和文献的结果 | 为什么做不成题目 |
|---|---|---|---|
| 部件身份 | 第几号头 / 第几号专家是否对应 | 不对应（头线 10 个种子；自训 MoE；Chughtai 2023） | 置换对称下必然不同，答不出“所以呢” |
| 表征几何 | 编码了什么、形状是否相同 | 大多相同，而且可以从数据统计推出来（Fu 2026；Karkada ICML 2026） | 相同可以猜到；按形状划界要阈值 |
| **算法** | 用的是不是同一种计算方法 | 玩具模型上会不同（Clock vs Pizza），预训练 LLM 上几乎没人系统检验过 | ——这一层能做 |

算法层的好处是：判断“同一算法还是不同算法”，可以用文献已经设计好的反事实输入——不同算法对同一个输入给出不同答案——不需要我们自己定义阈值。

这也是先生 11-05 第 12 条的做法：**把现成的分析方法拿来，看它的分析结果在不同模型之间一致到什么程度。**

## 2. 题目（一句话）

“记住谁拿了什么，再按问题取出来”（上下文绑定）是近两年机制可解释性研究最多的能力之一。文献提出了好几种机制，每一种都只在 1–4 个模型上验证过。**这些机制结论在独立训练的不同 LLM 上是否成立？不成立时，是模型的什么性质决定的？**

| 已发表的结论 | 原论文测过的模型 |
|---|---|
| binding ID：可加、与位置无关的绑定向量（Feng & Steinhardt, ICLR 2024） | Pythia、LLaMA |
| 位置 / 词汇 / 反射三种机制混合（Gur-Arieh, Geva, Geiger, ICLR 2026） | Gemma-2、Qwen2.5、Llama-3.1（全 instruct） |
| lookback：指针式回看（Prakash et al., ICLR 2026） | Llama-3、Qwen2.5 |
| 被问时才局部重绑定（Oh & Demberg 2026） | Gemma、Llama（已报告家族差异） |
| 不逐步构建世界状态（Tang et al., ICML 2026） | Gemma-2、CodeLlama、Llama-3.1 |

## 3. 为什么值得关心

- **机制解释能否跨模型推广，是可解释性公认的开放问题**（Sharkey et al. 2025 列为开放问题）。现在的惯例是在 1–4 个模型上找到机制，然后当作“LLM 的机制”来讲。
- **答案事先不知道。** 有零星迹象表明不同家族会不同：Oh & Demberg 发现 Gemma 与 Llama 的重绑定签名不同；Sun & Toneva 2026 发现同一个 IOI 解释在 Pythia 内部一致 0.73–0.92，换到 GPT-2 只有 0.13；Ravulapalli 2026 发现 30 个模型的绑定**容量**按预训练配方分组、而不是按规模。但没人系统地用各论文自己的检验跨家族看过（撞车检查：无）。
- 两种结果都有用：都成立 → 绑定的算法由任务决定，一个模型上的机制解释可以迁移到别的模型；部分不成立 → 指出哪些结论只属于某些模型，以及和什么性质有关（注意力实现、位置编码、分词、MoE、规模、是否指令微调）。

## 4. 做法

- **检验：** 每个结论都用原论文自己的反事实检验和判据，先在原论文用过的开放模型上复现（Qwen2.5、Pythia），再推到别的家族。
- **模型：** 开放权重、不需要凭证的独立训练家族约 10 个（Qwen2.5/3、OLMo-2/3、Falcon3、Granite-3.3、Mistral、Yi、InternLM、SmolLM3、Pythia），加上：同家族的规模阶梯，base 与 instruct 成对，dense 与 MoE（DeepSeek-V2-Lite、Qwen3-30B-A3B）。
- **读数：** 每个结论在每个模型上“成立 / 不成立”（按原论文判据）。参照点是原论文模型上的复现；对比轴是家族、规模、base / instruct、dense / MoE。
- **规模：** 全部只做推理，单个实验 < 20 GPU·时。

## 5. 对照先生的一般标准

| 标准 | 本题 |
|---|---|
| 关键概念不取决于我们的定义 | 每个机制用原论文自己的反事实检验来判定 |
| 实验回答所问的问题 | 同一检验跑在多个独立训练的模型上，直接回答“是否成立” |
| 每种结果都有信息 | 成立 → 可迁移；不成立 → 指出差在哪、由什么决定 |
| 不能用常识猜到 | 已有零星的家族差异迹象，但没有系统结果 |
| 不是由训练细节决定的程度问题 | 主读数是“成立 / 不成立”，不是幅度 |
| 不硬拆互相决定的部分 | 不做“各占多少”的分解 |
| 有参照点和对比 | 原论文模型的复现作参照；家族 / 规模 / base-instruct / dense-MoE 作对比轴 |
