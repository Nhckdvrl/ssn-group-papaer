## 2. 导师真正在说什么

1. **不是否定，是"题目有趣，但还没有一个可发表的命题"。** 他认可实验形态（第 6、7 条），也认可题目潜力（第 5 条），卡住的是第 3 条：一个 0–1 之间的数字不构成主张。这和我们 11-05 调研 v2 §6 的自评一致。
2. **他给的出路全是"找一个让数字动起来的轴"。** 对比轴（模型类型）、第二尺度、token 类别、语言、现成分析法——五条都是同一个意思：一致度要作为某个变量的函数来报告，而不是一个点。
3. **第 5 条是条件句，而我们的回答（"ほとんどない"）是错的。** MoE 专家分析从 1991 年起就有，2024 年后有十几篇直接相关（见历史综述）。真正稀缺的是**跨独立训练**的比较（Equifinality 两个 seed；我们 9 个 run）和**带时间轴**的比较（没有）。下次要主动改口，否则"有趣"的前提不成立。
4. **他不知道我们已经做了第 10、12 条的一半。** Slack 汇报压缩过度，导师只看到三个数字。

## 4. 必须纠正的一处，和下次汇报的写法

- 开头一句：前回「MoE の解釈研究はほとんどない」と申し上げたのは不正確でした。専門家の分析は 1991 年の Jacobs らから続いており、2024 年以降だけで十数本あります。**ただし、独立に学習したモデル同士で分担を比較した研究は 2 本（2 seed の Equifinality と我々）、学習過程に沿って比較した研究はありません。**
- 读数用导师的词汇：同じ文を入れ、同じ語の文脈がどの専門家群に振り分けられるかを比べる。0 = 無関係、1 = 完全一致、未学習モデル同士 ≈ 0 を差し引き済み。参照点は 3 つ：同一設定の再学習 .50、データ順のみ変更 .45、初期化のみ変更 .28。
- 对比已经有四条轴（配对类型、层、粒度、时间），模型类型的轴是下一步。

## 5. 对研究命题的影响

导师的"对比轴"和我们 11-05 §7 的"逼出来的 vs 偶然的"可以合成一句：**一致度随模型类型 / 层 / 粒度变化，但一致的内容不变。** 预期：换负载均衡强度、专家粒度、top-k，一致度的高低会动，而可重现的那组区分（词类、依存、代词句法角色、to / that / there 的功能分裂）不动；浅层与逐 token 层面始终不重现。这既是导师要的对比，也是一个有对手假设的命题（对手：一致度与内容都随配方变，或都不变）。

一个干净的极端对照是**冻结随机路由器**（Fan–Messmer–Jaggi 2024：GPT-2 small 规模下冻结随机路由 ≈ 学习路由；Hash Layers、THOR 同向）。若在我们的规模冻结路由器损失不变，那么"语法分工"就不是预测所必需，只是学习自由时的吸引子；若损失变差，差值就是分工的价值。这直接检验 §7 的 F3，也是导师"こういうモデルでは低い"的最纯形式。**风险要先说清：** 文献倾向于前者，F3 可能被证伪，那也是结果。
