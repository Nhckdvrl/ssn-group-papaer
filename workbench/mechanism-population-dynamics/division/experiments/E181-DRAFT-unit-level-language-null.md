## 2. 零模型（全部在同一批捕获的隐状态上算；只打分，不干预前向）
**通用原则：** (i) 只随机化单元**读入端**相对数据的朝向，保留单元自己的机制：非线性、谱、偏置、单元之间的 Gram 矩阵。这正是 Melton / N1 的逻辑。(ii) 读数必须对单元自身的规范对称不变；否则所谓"专属"只是坐标选择的产物。(iii) 每类单元配两族零模型，一族是 Haar（N_A 型），一族匹配负载或锐度（N_B 型），两族都进决策表。E178 已经见过零模型族翻转判决。
**2a 神经元**（稠密 MLP，加上 MoE 中各专家 FFN 的神经元）
- **NA-n**：W_gate ← W_gate·R，W_up 用**同一个** R，R ~ Haar O(d)，每层每次抽样一个 R、全层神经元共用。保留：激活函数、每个神经元的范数、神经元之间的 Gram 矩阵 W Wᵀ。改变：激活率（sparsity）会随数据均值方向变化。实现：先算 h·R，再乘原权重；不必实例化新权重。
- **NB-n（主零模型）**：在 NA-n 的基础上，给每个神经元加一个偏置 b_j，在校准集上二分拟合，使它的激活率 = 训练神经元 j 的激活率。这是 N_B "负载匹配"在神经元上的对应：保留激活率分布（稀疏度的层剖面）。Llama 和 Qwen 的 FFN 原本没有偏置，这一族属于"加了偏置的同类单元"，要写明。
- **NB′-n（只用于 MoE，次要）**：每个专家在自己的行空间内旋转，W_e V_e Q V_eᵀ，即 N1 原式。它检验的是：专家内部的神经元相对该专家自己的读入子空间是否额外对齐到语言方向。
- **Nmix（对比族，不进主判决）**：在输出端做正交混合，a ↦ aQ，W_down ↦ Qᵀ W_down。MLP 的输出完全不变，但神经元的特权基和稀疏性都被破坏。它回答的是另一个问题："神经元基对语言是否有特权"，属于 Gurnee 2401.12181 式的随机基线。混合后的坐标用分位阈值匹配激活率之后才能算 LAPE。它改变了单元的定义，所以**和 Melton / N1 的逻辑不同**，只作对照。
- **超出 NB-n 的含义：** 训练神经元的读入方向比"同谱、同激活率、随机朝向"的神经元更对准语言方向，而且这种超出集中在某些层。如果只超出 NA-n、不超出 NB-n，说明超出量来自激活率分布本身（风险 2）。
- **读数：** S_N(l) = 第 l 层全部神经元的 1 − LAPE/log 20 的均值（连续量，不饱和，作主读数）；Tang 计数 = 每个零模型抽样各自重新取 LAPE 最低 1% 与 95 分位阈值，得到各层占比；另报一版沿用 T 的绝对阈值的计数。Kojima AP 只在稠密模型、6 种 Kojima 语言、每语 500 句上算（每句、每个神经元的平均输出放得下）。
**2b 注意力头**（只用前向读数）
- **读数：** 第 h 个头写回残差流的贡献 o_h = A_h(xW_V^h)W_O^h。Spec_H = tr(Σ_between)/tr(Σ_within)，按语言等量 token 计算，可流式累加。o_h 对规范变换 W_V^h Q、Qᵀ W_O^h 不变，满足原则 (ii)。补充读数：各语言注意力熵分布之间的 JSD（受 token 长度混杂）。层读数 = 该层所有头 Spec_H 的均值，外加每层前 2% 头的计数，对应 LAHIS 式的取法。
- **HV（Haar 型）**：W_V^h ← R_h W_V^h，每个头独立抽 R_h ~ Haar；用 T 的注意力模式 A_h。等价于取 U_rand S Vᵀ，其中 U_rand 是 Stiefel 随机阵、S Vᵀ 保留原值，每个头的代价只有 d×d_h。保留：注意力模式、W_V 的谱、W_O。GQA 模型按 KV 组抽样。
- **HQK-T（锐度匹配型）**：W_Q、W_K 在读入端做同一个 Haar 旋转，RoPE、QK-norm、GPT-OSS 的 sink logit 都保持在输出端；再用一个标量温度把每个头的平均注意力熵拟合到 T 的值（对应 E179 的 N_T），然后按随机注意力模式重算 o_h。
- **不当零模型用的两种变换：** 在头子空间内部做旋转（W_Q Q、W_K Q，Q 与 RoPE 块对易），q·k 和 o_h 都不变，是**规范对称**。它只作阳性对照：o_h 读数必须不变；如果某个基于 z_h 坐标的读数变了，就暴露出它依赖坐标基。在层内随机重分配头子空间（V 跨头混合后重切分），对应 Nmix，只作对照。
- **超出 HV / HQK-T 的含义：** 超出 HV，说明值投影比随机投影更对准语言方向；超出 HQK-T，说明头**看哪些位置**带有超出几何的语言结构。**预先说明：** o_h 关于 x 是线性的，几何上语言可分时，HV 几乎必然复现剖面（风险 1），所以头这一臂真正有信息的是 HQK-T。
**2c 专家：** N_A（W·R Haar）与 N_B（读出子空间内旋转 + 负载匹配），沿用 E179 的代码和种子；Qwen3、GPT-OSS、OLMoE 三个模型**已经测过，不重跑**，只在 §3 加 token id 的那次采集里顺带复核一遍。
**已知混杂（三类相同）：** 单元和残差流是一起训练的，单元的输出又写回残差流（Routers Learn Geometry 2605.12476）。所以"被零模型复现"只说明**这一读数**不需要该单元的朝向就能出现，**不**说明该单元没有塑造这份几何。不做"多少归因于几何"这类分解（11-05 已否）。

## 3. 模型、数据、算力
- **MoE**（同 E179）：Qwen3-30B-A3B（每层 128 专家 × 768 个神经元 = 98,304 个；注意力 32Q / 4KV 头，带 QK-norm）、GPT-OSS-20B（32 × 2880；滑窗与全注意力交替，带 sink；它的 glu = g·σ(1.702g)，g > 0 时才为正，LAPE 的判据不变）、OLMoE-0125-Instruct（64 × 1024；16 × 16 头）。**MoE 层里路由器的输入就是专家 FFN 的输入**（post-attention norm 的输出）。所以专家这一臂和专家内神经元这一臂读的是逐 token 相同的 h，这是三类单元里"同一隐状态"最严格的一对。
- **稠密：Llama-2-7B**（`NousResearch/Llama-2-7b-hf`，本地已缓存；Tang 和 Kojima 都用过；32 层 MHA，d_ff = 11008，可以直接对照它们的已发表剖面）。备选：Llama-3.2-3B（LAHIS 用的模型，本地已缓存），只用来在 T 上复现 LAHIS 剖面，不算零模型。
- **数据：** 同 E178/E179：FLORES-200 dev 997 句 × 20 语，校准集用 devtest 前 25 句，`add_special_tokens=False`。另报 Tang 7 语子集（en zh fr es vi id ja；FLORES 里 vi/id 需要加载，未核对）和 Kojima 6 语子集上的 T 剖面，作为"已发表剖面在本数据上是否复现"的检查。
- **流式统计，不存隐状态：** 神经元每层累加 (语言, 神经元) 的激活计数，GPU 上 int32；每次零模型抽样只保留 LAPE 向量（fp16，Qwen3 约 9 MB）。头每层累加每种语言的 Σo_h 与 Σ‖o_h‖²（trace 比能精确流式计算）。零模型只在每语 1,000 token 的等量子样本上算（同 E179 toksub，种子 179）；T 用全量流计算一次，再在子样本上算一次，用来对账抽样误差。Kojima AP 只存 3000 句 × 神经元 × 层的句均输出（Llama-2 约 2 GB fp16）。
- **抽样次数：** NA-n、NB-n、HV、HQK-T 各 4 次（E179 用 8 次；第一步若带宽太宽再加），NB′-n 和 Nmix 各 2 次。
- **算力估计（只做推理，A100）：** Llama-2-7B 前向 + 神经元零模型 + 头零模型约 2.5 GPU h；Qwen3-30B-A3B 约 3；GPT-OSS-20B 约 2.5（32 个专家全部计算，eager 注意力）；OLMoE 约 1。小计约 9 GPU h，加 50% 调试余量，**≤ 14 GPU h**，并发 ≤ 4 卡。低于 20 GPU h 的停止线（记忆规则），但仍超过 §16 的"≤ 2 GPU h"权限，**全量需要人批准**。

## 4. 决策表（草案；正式登记时冻结，阈值同 E179，属于 pilot 启发式，R12）
对每类单元 u ∈ {N 神经元, H 头, E 专家}、每个模型、每族零模型（N：NB-n / NA-n；H：HQK-T / HV；E：N_B / N_A）算三个量：ρ_u = Spearman(T 剖面, 零模型抽样均值剖面)，跨全部层；U 比 = U_T / U_null；深度均匀度 = 逐层 T/null 比值的首尾均值 ÷ 中段均值。层段同 E179；Llama-2 的层段按比例取为 0–1 ∪ 30–31 与 4–23。
- **u 继承（几何读出）：** 两族零模型下都满足 ρ ≥ .8、U 比 ∈ [0.85, 1.15]、深度均匀度 ∈ [0.8, 1.25]。
- **u 偏离：** 两族零模型下都满足 ρ < .8，或 U 比超出区间，或深度均匀度超出区间；报超出量集中在哪些层。**两族判决不一致时**，判为"随零模型族而定"，照 E178 分支 (iii) 只报翻转，不选边。
- **前提检查（先做）：** T 本身要复现已发表剖面：神经元 U_T ≥ 1.3，Tang 子集计数呈首尾高；专家沿用 E179 的结果。不复现的单元类型记为"已发表剖面在 FLORES 上不复现"，不进下面的判决。
- **O1 统一（够一篇）：** 三类单元都继承，且每类在它存在的 ≥ 2 个模型上成立；三类单元的 T 剖面与残差流几何剖面（G2′：与 Spec_H 相同的 trace 比，算在各单元的输入 h 上）的 Spearman 都 ≥ .8。**加分项：** 三类的深度均匀度都落在区间内，即"训练只改幅度、不改剖面"从路由器推广到全部单元类型。
- **O2 分层（够一篇，信息量最大）：** 专家继承（Qwen3 / GPT-OSS 已经成立），而神经元或头（HQK-T）在 ≥ 2 个模型上偏离，并且偏离的层位置一致；反过来，神经元 / 头继承、专家偏离（OLMoE 型），也归入这一类。得到的句子是："超出几何的语言结构落在 X 这一级单元上，位于 Y 层。"
- **O3 什么都立不住（只够一条注记）：** ≥ 2 类单元的前提检查失败，或 ≥ 2 类单元随零模型族翻转。结论是单元级的语言专属层剖面依赖读数，写成方法学提醒。
- **O4 全部偏离：** 三类单元都偏离。几何解释在单元级不成立，C24 的适用范围要收窄到路由器；结果照实报告。
- 只有"头 HV 继承"这一条，不算支持 O1（风险 1，几乎是同义反复）。O1 至少需要 NB-n 和 HQK-T 都继承。

## 6. 两个最大科学风险与最便宜的第一步
- **风险 1：线性读数几乎注定继承。** 路由 logits 和 o_h 都是 h 的线性函数，只要几何上语言可分，同谱的随机线性读出就会复现剖面。真正能检验"单元学到了什么"的只有非线性、带阈值的神经元读数（NB-n）和注意力模式（HQK-T）。如果这两臂都继承，O1 很容易被压缩成一句常识。
- **风险 2：LAPE 的剖面可能由激活率剖面和文字决定，而不是由语言几何决定。** 首尾层的稀疏度不同，加上 byte-fallback 文字（ory / asm / tam 在 Llama-2 上几乎全是字节 token），都会让 LAPE 在第 0–1 层变"专属"（参见 2604.05090）。NB-n 匹配了激活率，可能因此"复现"剖面；NA-n 不匹配，又不公平。两族之间的差距本身就是读数，但解释起来很容易滑向分解问题。另外，每语 1,000 个 token 估计最低 1% 的 LAPE，噪声会抬高极值：必须对 T 做一次全量 vs 子样本的对账。
- **最便宜的决定性第一步（≤ 2 GPU h，只做神经元这一臂）：**
  1. Qwen3-30B-A3B 专家神经元：直接用 E179 缓存的 `~/mechpop_cache/e179/qwen3/toksub.npy`（48 层 × 20k token × 2048，正是专家 FFN 的输入），从 safetensors 读出 gate_proj 权重，算 T / NA-n / NB-n（各 4 次）在每层 98,304 个神经元上的 S_N 与 Tang 计数。**不需要前向**，约 0.5 GPU h。
  2. Llama-2-7B：FLORES dev 20 语前向，hook MLP 输入，按 E179 的方法取每语 1,000 token 的子样本；同时用全量流计算 T 的 LAPE，检查 Tang 7 语子集上的剖面是否复现。约 1–1.5 GPU h。
  - **读法：** T 的前提检查失败 → 停止，E 记为 O3 方向。两个模型的神经元都在 NB-n 和 NA-n 下继承 → E 的去向取决于 HQK-T，全量值不值得跑，需要人判断（O1 有压缩风险）。至少一个模型的神经元在两族下都偏离、且层位置可以命名 → E 有 O2 的可能，值得申请全量。
