## 干预（在路由处替换 top-k 集合；其余一切不变）
实现：把每个 MoE 块的 forward 换成等价的自写 forward（门 logits → 全 E 的 softmax → top-k → 按模型规则是否归一 → 逐专家计算），并接受一个逐 token 的"目标集合"覆盖。替换的只有 **top-k 专家集合**。
- **门权重（主口径 W1）：** 新集合上用 **T 自己在当前隐状态上的 softmax 概率**（全 E softmax 后取新集合的分量；模型本身归一时（Qwen3）再归一，OLMoE / DeepSeek 不归一）。
- **门权重（副口径 W2，只做"全部层 + 三段"）：** I1 用拟合集上该 id 的**平均全 E softmax 概率**取新集合分量；I2–I5 用**供体 token 在干净前向里的门值**（整条路由连权重一起移植）。
- **条件（单层：第 l 层单独替换，l = 0..L−1；另做"全部层"与首 / 中 / 末三段各一次）。** OLMoE 三段 = 首 0–1、中 2–11、末 12–15（首、中沿用 E186 层段，末段 = 其余）。DeepSeek（MoE 层序号）首 0–1、中 4–18、末 19–25（2–3 层只进"全部层"）；Qwen3 首 0–3、中 7–34、末 35–47（同 E185 层段，剩余层只进"全部层"）。
  - **I0 恒等：** 自写 forward、不覆盖（= T）。基线，ΔNLL 以它为零点。
  - **I1 LOOKUP：** 第 l 层集合换成拟合集上该 token id 的"多数 top-k 集合"——**该 id 在拟合集第 l 层被选中频率最高的 k 个专家**（同频按专家编号；精确集合众数在 64 选 8 上太稀疏，故用逐专家频率定义）；该 id 在拟合集中出现 **n ≥ 5** 次才查表，否则保留 T（报回退率）。
  - **I2 WITHIN-ID SHUFFLE（主读数）：** 每个 token 的第 l 层集合换成**评估集中同一 token id 的另一次出现**（不同位置）在干净前向里的 T 集合。实现：每个 id 组内随机排列成一个环，token 取环上下一个（保证不取到自己；只出现一次的 id 保留 T，报替换率）。边际分布与逐 id 集合分布完全保持，只断上下文链。**5 个种子**（190–194）。多层条件下同一 token 在各层用同一个供体。
  - **I3 WITHIN-(ID, PREV-ID) SHUFFLE：** 同上，但组 = (id, 前一 id)；序列首 token 的前一 id 记为 −1。组大小 1 的 token 回退到 I2（同种子的 I2 供体），报回退率。I2 − I3 = 前一 token 之外的上下文价值；I3 的剩余 = 前一 token id 带来的局部序列价值在 I2 里所占之外的部分（见读数 6）。种子 190。
  - **I4 WITHIN-(ID, POSITION BIN) SHUFFLE：** 组 = (id, 位置段)，位置段 {0}、[1, 3]、[4, 15]、[16, 63]、[64, 255]、≥ 256；组大小 1 回退到 I2，报回退率。种子 190。
  - **I5 跨 id 全局打乱（上界）：** 所有评估 token 的集合做一次随机错位排列（不保 id）。种子 190。
  - **I6 N_B 负载匹配随机路由器：** E186 的 N1 定义（W_c V Q Vᵀ，Q 为读出子空间上的 Haar 旋转，种子 190000 + 层），偏置在拟合集随机 6 万 token 的路由器输入上拟合到 T 的负载（`moe_measure.fit_bias`）；**作用在干预前向里的当前隐状态上**（不是预计算集合），选出集合后按 W1 取 T 的门值。1 个 draw。预期灾难性，作为"专家与路由器共适应"的参照；I6 与 I2 的距离 = 同 id 内的路由信息 + 词表锐化的总价值。
  - **类别限定的 I2（全部层，种子 190）：** 只替换 H(e∣id) 低 / 中 / 高三分位之一的 token，其余保持 T——给出"打断某一类 token 的上下文依赖的总代价 / 每个被替换 token"，不受归属问题影响（见读数 3 的注）。
- 运行量（OLMoE）：单层 16 × (I1, I2×5, I3, I4, I5, I6) = 160 次 + 4 个层段 × 10 = 40 次 + W2 4 × 5 = 20 次 + 类别限定 3 次 + I0 与未打补丁的原模型各 1 次，约 225 次前向 × ≈ 27 万 token。

## 读数
1. **逐 token ΔNLL**（nat；位置 t 的 ΔNLL = 在该条件下预测 token t+1 的 NLL − I0 的同一量；序列末 token 无目标，不计）：每个条件报均值（按序列聚类自助 1000 次的 95% CI）、中位数、90 / 99 分位、ΔNLL > 0 的比例、ΔNLL > 1 nat 的比例；全部层条件画分布图。另报"总 PPL 比值"exp(mean NLL_cond − mean NLL_I0)。
2. **按被替换层**：单层条件的均值 ΔNLL × 层 × 干预，一张逐层曲线图（I2 带 5 种子范围）。
3. **按 token 类**（全部层与中段条件；I1 / I2 / I3 / I5）：句首（位置 0）、位置段、UPOS 功能 / 内容 / 标点（UD test 词末 token；功能 = ADP AUX CCONJ DET PART PRON SCONJ，内容 = NOUN VERB ADJ ADV PROPN NUM INTJ，标点 = PUNCT SYM）、拟合集频率五分位（按评估 token 加权）、含字母 / 不含字母、字母 token 词首（前导空格）vs 无前导空格（词中 / 词尾片段）、语料与语言 / 文字（20 侧 + eng FLORES / wikitext / UD）。**归属注：** 替换同时作用于所有 token，位置 t 的 ΔNLL 混有 t 之前 token 的替换效应；按类读数是"在该类 token 上做预测时的损失"，"打断该类 token 的路由的代价"看类别限定的 I2。
4. **按 H(e∣id) 三分位**：E186 的 `tok_d184_*.json` 只存极端 id 的列表（305 个高频 id 的逐 id 值未落盘），所以按**同一估计器**在拟合集上重算：每个 id（拟合集 ≥ 30 次）在每层随机取 30 次出现（等 n，种子 190）的 T top-1 专家熵，取 mid 段（OLMoE 2–11）均值；同时算 N_B（I6 的路由器、拟合集上）的同一量与 Spearman(T, N_B)（应接近 E186 的 .85）。三分位按评估 token 加权切；报覆盖率（评估 token 中有 H 值的比例）与 E186 列出的最依赖 / 最不依赖 id 的复核。
5. **ΔNLL 与路由变化量的关系**（单层条件，I2）：每个 token 在被替换层的 top-k 集合变化比例 1 − |S_new ∩ S_T| / k（分 5 档）与 top-1 是否变，各档均值 ΔNLL；以及 I1 / I3 / I5 的同一读数（同一变化量下不同干预的损失是否相同 = 损失是否只由"换了几个专家"决定）。
6. **I2 − I3 与 I3 的剩余**：逐层、逐段、逐类报 I2、I3、I2 − I3、I3 / I2；I4 / I2（位置段带回的部分）。
7. **原始样例**：全部层 I2（种子 190）下 ΔNLL 最大 / 最小各 20 个 token，带 ±12 token 上下文、被替换层的集合变化量、H(e∣id)。
8. 参照：I0 的绝对 NLL / PPL 按语料；T 与 I1 的集合重合（评估集上 I1 与 T 的平均 top-k 重合 = 词表部分解释了多少集合）。

## 阳性对照
- **I0：** 自写 forward 与未打补丁的原模型前向的逐 token NLL 差，均值绝对值 < 1e-3 nat（否则停）；自写 forward 不覆盖时的选择与原模型 top-k 一致率 = 1。
- **hook 核对：** 每个覆盖条件在 forward 内记录实际使用的专家索引，被覆盖 token 上与目标集合的一致率 = 1.0（逐条件报）。
- **I5 ≫ I2**（全局打乱的损失应远大于同 id 打乱，否则说明替换没有生效或专家对任何路由都鲁棒）；I6 应灾难性。

## 噪声地板
- I2 的 5 个打乱种子：报种子间 [min, max] 与 SD（逐层、逐段、逐类）；评估集按序列聚类自助 1000 次的 95% CI（I0 为零点、条件差在同一自助样本上算）。I3 / I4 / I5 / I6 单种子，引用 I2 的种子间 SD 作参照尺度。
- I0 两次运行（同 batch）完全一致是数值地板的前提；若不一致报差的分布。

## 会改变读法的结果（不是决策表；写"看到什么就放弃什么"）
1. **I2 ≈ 0**（全部层 I2 的均值 ΔNLL 与 5 种子范围 / 自助 CI 同量级，且远小于 I5）→ 放弃"给定 token 后路由的上下文依赖是功能性的"读法；"词表锐化"就是路由器的主要功能，N1 可以写成功能陈述（E185/E186 的"token id 只解释少数路由不确定性"在功能上不重要）。
2. **I2 明显 > 0 且 I3 收回大部分**（I3 / I2 小）→ 训练新增的功能在局部序列（前一 token）上，与 E185 观察 3 一致；放弃"上下文 = 长程语义 / 内容"的读法（至少对 OLMoE）。
3. **I2 明显 > 0、I3 收回很少** → 功能性的上下文依赖不在前一 token 上；放弃"E185 观察 3 的局部序列信息是主要功能成分"的读法。
4. **I2 大且集中在 H(e∣id) 高的 token**（高三分位的类别限定 I2 远大于低三分位）→ 几何决定的上下文依赖是功能性的；统计读数 H(e∣id) 可以预测功能损失。
5. **I2 大但与 H(e∣id) 无关**（三分位平坦）→ 放弃用统计读数（H(e∣id)、G_freq）预测功能的做法；E185/E186 的统计图谱只描述路由，不描述功能。
6. **损失只由"换了几个专家"决定**（读数 5 中同一变化量下 I1 / I2 / I3 / I5 的 ΔNLL 相同）→ 放弃"供体集合的来源（同 id / 同前一 id）有意义"的解释，I2 vs I5 的差只是变化量的差。
7. **I1 ≪ I2**（查表比换上下文损失小）或 **I1 ≫ I2**：前者说明逐 id 的典型集合是功能上的"安全默认"，后者说明集合的 id 内分布本身（而非某一默认集合）是功能所需；两种都写，不预设。
8. **W1 与 W2 差别大** → 门权重携带的上下文信息与集合本身的同量级，报告时不能只说"集合"。

## 混杂审计（EXECUTION §4）
- **归属**：见读数 3 注；用类别限定的 I2 控制。
- **自写 forward 的数值**：I0 vs 原模型（阳性对照）。
- **单次出现的 id**：I2 对它们无法替换（保留 T），会稀释均值 → 同时报"只在被替换 token 上"的均值与替换率；I1 未见 id 同理。
- **评估集组成**：FLORES 多语 token 占多数；均值按语料分开报，"全部"只是加权汇总。
- **W1 的门值来自 T 在当前隐状态上的 logits**：被换入的专家若 T 给的概率很低，其贡献被门值压小——这是"只换集合"的定义本身，W2 是对照。
- **多层条件的供体集合是干净前向的**，下游层的当前隐状态已偏离，这是"整条路由移植"的定义；I6 是唯一按当前隐状态重算的条件。
