## 与 E170 的关系（跑前核对）

## 读数（看到结果前固定）
**粒度 2：同词形分区 T_D（主）。** 定义完全沿用 `analyze_routing.py`：D = C − B，词形内中心化，跨 342,578 对的 Pearson。零假设：B 的锚点在"池"内随机置换，D_B'(i, j) = D_B(π i, π j)。池：
- **U**：(词形, UPOS)。
- **F**：(词形, UPOS, prev_upos, next_upos, deprel)；细格内锚点 < 3 的，退回该锚点 (词形, UPOS) 的"剩余池"（同一 (词形, UPOS) 下所有小细格的锚点合在一起置换）。报告细格覆盖率（落在 ≥ 3 细格的锚点比例）。
- 对照池：**T**（只按词形置换：应 ≈ 0，阴性对照）、**I**（不置换：= 真实，管道核对）。
- 大小为 1 的池里的锚点不动（其"格分布"就是它自己）——这会使零假设偏高（保守）；报告不动锚点比例，并报一个敏感性版本：只在两端都可动的对上同时算真实与零假设。
- 汇报：每层与深层 L6–11 均值、L11、浅层 L0–5 均值；真实 T_D；零假设均值与 2.5–97.5 分位；**超出 = 真实 − 零假设均值；超出比例 = 超出 / 真实**；"跨初始化超出 ÷ 重跑超出"。

**粒度 1：词类级（route 指纹，FINDINGS 表 4.5 的 .86）。** 该读数 = 每个专家的 P(专家 | UPOS × 词首/词中) 向量、Hungarian 配对后的留出相关。**格内置换（U 或 F 池，均嵌套在 UPOS 内）不改变 B 的 P(专家 | UPOS)——零假设 ≡ 真实，按构造成立，不需要算。** 这本身是对 A2 的回答之一：词类级读数只测"各 run 的词类→专家边缘"，A2 指定的零假设在这一级无法区分"学到的对应"与"各自对词类敏感"。
- **替代零假设（跑前选定）：** 把 B 换成 B 自己的 N1 随机路由器（保留读出子空间与奇异值、子空间内随机旋转、重拟合偏置匹配负载；与 T_D 扣除的同一个零假设）——"同一几何、同样对词类敏感、但没有学到切法"。读数在 UD 全部词（hidden 缓存 113,118 词）上按 UPOS 重算 route 指纹（17 类中两半各 ≥ 300 词的类），按文档奇偶切 cal / held，Hungarian 在 cal、相关在 held（同 `analyze_functional.py`）。报告：真实 A vs 真实 B；真实 A vs N1(B)；N1(A) vs N1(B)。（跑前修订，2026-11-06 写脚本时：CPU 负载高，N1 抽样 8 次、只算深层 L6–11；偏置重拟合用 cal 词的 2 万个随机子样本——与 E167 采集的 N1 只差在偏置拟合样本量，读出子空间与旋转相同。另加未训练对 I0D0:I1D0（step 0）作地板。）可用 checkpoint：终点（初始化 6 对、顺序 2 对）与 3.2B（只有重跑对）。管道核对：由 H, W, b 重算的锚点 top-8 应与路由缓存 S 一致（≥ 99%）。

**粒度 3：逐 token 因果角色（.19）。** 定义沿用 `token_roles.py compare`：前半窗 Hungarian、后半窗相关，两向平均，取 matched。Dolma 窗口没有 UD 标注：用 spaCy en_core_web_sm 3.8 对解码后的窗口文本自动标 UPOS / dep（**自动标注，dep 是 ClearNLP 标签不是 UD deprel**）；token 的标签 = 含其首字符的词。零假设：B 的 token 轴在池内置换（池再与半窗相交，保持拟合 / 评估切分）。池：**U** = (UPOS, 词首/词中)；**F** = (UPOS, 词首/词中, prev_upos, next_upos, dep)，< 3 退回 U；**LU** = (token id, UPOS)——与 T_D 的"词形内"约束对应的版本。管道核对：同 token id 的两次出现在第 2 层的共选专家数应远高于不同 id（证明重建的窗口与采集时一致）。

## 阳性对照
- 重跑对的真实 T_D（与逐 token matched）必须高于其 U 池零假设的 97.5 分位，且超出 > 2 × jackknife SE；否则零假设过强，写明并不解读该级。
- I 池 = 真实（差 < 1e-9）；T 池零假设均值 |·| < .02。

## 噪声地板 + MIE
- 零假设分布的 2.5–97.5 分位（64 次置换）；超出量的 jackknife SE：按词形分 20 块（T_D）、按窗口分 16 块（逐 token）、按文档分 20 块（词类级）。
- 跨初始化对之间的范围（15 对）。
- MIE：超出比例 < .2 视为"基本是重述"；"跨初始化超出 ÷ 重跑超出"与原比值相差 < .05 视为"零假设扣除不改变阶梯"。均为解读标尺，不是关线门槛。

## 混杂审计（EXECUTION §4）
- 词形身份：T_D 级已控制（词形内中心化，池在词形内）；逐 token 级 U / F 池不控制，LU 池控制。
- 几何：T_D 已扣 N1；词类级替代零假设即 N1；逐 token 未扣（原读数就未扣）。
- 小格保守偏差：不动锚点 / token 使零假设偏高，已报比例与敏感性版本。
- 自动标注噪声（逐 token）：标注错误使格变粗 → 零假设偏低（偏向"超出"），未控制，写明。
- 只换初始化对与重跑对的 seed 共享：15 对共用 6 个 seed，只报均值与范围，不当独立样本。

## 决策表（跑前写）
- 只换初始化对在 U 池下的真实 T_D 落在零假设 95% 区间内 → 同词形分区级"骨架可重现"是重述，写进 CLAIMS 作废记录。
- 显著高于（预期，因 E170 share ≈ .2）→ 报超出部分大小、超出比例，并与重跑对的超出比较：若"初始化超出 ÷ 重跑超出"≈ 原比值 .48 → 扣除对阶梯无影响；若明显更低 → 初始化保留的部分更多落在 UD 变量可解释的那一块。
- F 池下超出比例 < .2 → "可重现的上下文划分几乎全由 UPOS×邻接词类×依存解释"；与 E170"残差占一半"冲突时，报两者并查原因（格定义差异）。
- 词类级：A2 指定零假设按构造 ≡ 真实 → 词类级 .86 不能作为"超出词类敏感性"的证据，只能用 N1 替代零假设的超出部分作证据；若真实 A vs N1(B) 已接近真实 A vs 真实 B → 词类级一致主要由几何给出。
- 逐 token：同 T_D 的分支；另报 LU 池。
- 无论结果如何不关线、不改方向（R2），只报数。

### 按决策表执行了什么
1. 同词形分区：只换初始化对的真实 T_D（.229）远在 U 零假设区间 [.043, .048] 之外 → 不是重述。超出 .183，占 80%。"初始化超出 ÷ 重跑超出"= .45，与原比值 .49 相差 .04 < MIE .05 → 按卡判为"零假设扣除不改变阶梯"。8 亿 token 同样（.40 → .36）。差值方向一致（扣除后略低）：初始化保留的部分里，UD 可解释的那块占比略高于重跑对。
2. F 池超出比例 .69 > .2 → 不是"几乎全由 UPOS×邻接词类×依存解释"。但 F 覆盖率只有 30%，所以这只是细格解释量的下界。与 E170 的对照见 POST-HOC。
