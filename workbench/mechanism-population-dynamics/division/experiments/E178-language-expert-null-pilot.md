- **数据：** FLORES-200（`dl.fbaipublicfiles.com/nllb/flores200_dataset.tar.gz`，sha256 b8b0b767…11f6，解压到 `~/mechpop_cache/flores200/`）。**测量集 = dev 全部 997 句 × 20 语**；**校准集（只用于 N_B / N_G 偏置重拟合）= devtest 前 25 句 × 20 语 = 500 句**，与测量集不重叠。
- **20 种语言：** Bandarkar 13 种 eng_Latn arb_Arab asm_Beng bam_Latn ben_Beng fra_Latn hin_Deva lit_Latn ory_Orya pes_Arab srp_Cyrl tha_Thai zho_Hans；Chen 另 5 种 deu_Latn spa_Latn jpn_Jpan kor_Hang swh_Latn；补 rus_Cyrl（西里尔、斯拉夫）、tam_Taml（达罗毗荼）。共 12 种文字、9 个语系。
- **输入：** 每句单独一条序列，原文不加模板、不加 BOS（Qwen3 分词器默认无 BOS）；右补齐，补齐位置不计。
- **采集（`scripts/e178_capture.py`）：** 每个 MoE 层的 gate（`mlp.gate`，nn.Linear 2048→128）挂 forward hook，取其输入隐状态 h 与输出 logits。模型本身始终用训练路由器前向（零模型只"打分"不干预，同 Melton）。零模型路由在 hook 内用 fp32 现算，不存隐状态。存：每层 × 路由器 × 语言的专家计数（全部 25 个路由器）；T 与每族第 0 个 draw 的逐句计数（给置换零模型与 bootstrap）；逐句 R4 分歧（全部路由器）。
- **路由器（同一隐状态、同一 top-8）：**
  - **T**：训练路由器，取模型 gate 的输出 logits 直接 top-8（就是模型实际路由）。
  - **N_A（Melton 式）**：W·R，R 为 O(2048) Haar 随机正交阵，每层每 draw 独立，**不重拟合偏置**（Qwen3 无偏置），8 draws。
  - **N_B（本仓库 N1，复用 `moe_measure.py` 的 `null_stats / haar / null_router("N1") / fit_bias` 原代码）**：W_c V Q Vᵀ（读出子空间内 Haar 旋转，保留 W_c W_cᵀ），偏置在校准集上重拟合到**训练路由器在校准集上的负载**（E167/E174 的做法），8 draws。注：任务描述里写的"Frobenius 匹配高斯门 + 偏置重拟合到均匀负载"与本仓库 N1 的实际代码不同；按"复用 N1 实现"取代码版本作 N_B，任务描述的版本另作 N_G。
  - **N_G（补充，不进决策表）**：高斯门，Frobenius 范数匹配 W，偏置在校准集上重拟合到均匀负载，8 draws。也是 Melton 的第二参照。
  - **N_perm**：语言标签置换地板。在 19,940 个（语言, 句）单元上打乱语言标签（各语言单元数不变），对 T 的逐句计数重算 R1 / R2 / R5，200 次；报均值与 95 分位。另对 N_A / N_B / N_G 第 0 个 draw 各算一次地板。R4 是配对设计，置换零模型不适用，不报。

## 读数（跑前固定；逐层，层号 0 起）
- **R1 语言专属度**：P(e | ℓ) = 语言 ℓ 的 token 中专家 e 被选次数 /（8 · n_ℓ）；R1 = 20 种语言两两（190 对）JSD 的平均，以 2 为底（∈ [0,1]）。
- **R2 独占度（Qwen3 式，任务定义）**：专家 e 的被选 token 中来自单一语言的最大份额 s_e = max_ℓ count(e,ℓ) / Σ_ℓ' count(e,ℓ')；R2@50 = s_e ≥ .5 的专家比例，R2@80 同理。（原始 token 计数，各语言 token 数不等——低资源文字切得更碎，份额天然偏大；另报每语言 token 数。）
- **R3 层剖面**：R1 随层的曲线。T 与每个零模型族 8-draw 平均剖面的 48 层 Spearman；首两层（0,1）与末两层（46,47）的 T / 零模型 R1 之比。
- **R4（Bandarkar 原读数）**：每句 q_i = 句内 token 全 softmax 路由分布平均（每个路由器各自的 logits，含其偏置）；与配对英文句的熵归一 JSD（自然对数，D_JS = ½KL(q¹‖m)+½KL(q²‖m)，F = log 128 − ½(H(q¹)+H(q²))）；按句平均得每语言每层值，再对 19 种非英语平均。U 形对比 U4 = mean(第 0–3 层 ∪ 第 44–47 层) / mean(第 7–34 层，= 原文干预区 8–35 的 0 起编号)。
- **R5（Chen 原读数）**：只用其 10 语（arb ben deu eng spa fra jpn kor swh zho）；p^ℓ_i = 选择频率（按该语言 token 数归一）；W = p^ℓ / Σ_ℓ' p^ℓ'；每层独占专家数 = Σ_ℓ #{i : W^ℓ_i > 0.4}；早 / 中 / 晚三组（0–4 / 22–26 / 43–47）平均。另报其 1 − JSD 相似度在三组的平均（即 R1 限于 10 语）。
- **报法**：每个读数报 T、N_A（8 draws 均值与最小–最大）、N_B（同）、N_G（同）、N_perm（均值与 95 分位）。T 的抽样噪声：句子 bootstrap（同一句 id 在所有语言里一起重抽，200 次）给 R1 与 R4 的 95% 区间。
- **与被测变量解耦**：读数不选窗、不选层（全 48 层都报，"首两层 / 末两层 / U4 的层段"跑前写死）；数据是平行句，内容在语言间固定。

## 阳性对照与 sanity
- **零模型负载**：每个零模型 draw、每层，测量集上 max 专家负载 ≤ 2 × 均匀（均匀 = 每 token 8/128）。不满足的 draw / 层照报，并在判读里标出（Melton 对旋转门报了负载以排除塌缩）。T 的负载也报（不设门槛）。
- **训练路由器自一致**：同一英文 batch 前向两次，T 的 top-8 集合逐 token 一致率（预期 1.0；bf16 非确定性若 < 1 照报）。
- **hook 正确性**：hook 内 fp32 重算 h Wᵀ 的 top-8 与模型 gate 输出 top-8 的集合一致率（预期 ≈ 1，bf16 平分时可略低）。
- **N_B 负载匹配**：校准集上 N_B 负载与 T 负载的总变差（E174 的 load_tv）。

## 噪声地板 + MIE

## 决策表（跑前写死；主会话 11-09 指定，原文照录）
- **(i)** if the layer profile under N_A and N_B reproduces the trained one (Spearman across layers ≥ .8 and trained/null magnitude ratio within 0.7–1.4 in the first and last two layers) → the published first/last-layer language-specificity claim is a geometry statement;
- **(ii)** if T exceeds both nulls by ≥ 2× in some layers and lies outside the nulls' 8-draw spread → router adds language division beyond geometry; report which layers;
- **(iii)** if N_A and N_B disagree on (i)/(ii) → the verdict depends on null family; report the flip as the main finding and do not pick a side;
- **(iv)** if T is *below* the nulls (Melton's Mixtral case, anti-specialization) → report as such.

**结论先行（事实）：** 同一批隐状态上，每一种随机路由器都复现了"首尾层语言专属度高、中层低"的形状（R1 的首尾/中层对比 U4：训练 2.35，零模型 2.34 / 2.34 / 2.47；与负载匹配 N1 的层剖面 Spearman .95），随机路由器达到训练路由器 R1 的 46–63%（中位），约为标签置换地板的 100 倍；训练路由器在 47/48 层高于所有零模型的 8-draw 带，但高出的倍数在深度上近乎均匀（对 N_B：层 7–34 平均 1.58×，首尾 8 层 1.61×）→ 按"≥ 2×"规则 N_A 判 28 层超出、N_B 判 0 层 → **分支 (iii)**。Chen 的独占专家数在首尾层被 N_B 复现（T/N_B 在层 0/1/46/47 为 1.38 / 1.15 / 0.92 / 1.07），训练超出两族 ≥ 2× 的层在**中层**（10、12、20、22–24）；Bandarkar 原读数的零模型水平随零模型族从低于训练（N_B）到高于训练（N_G），水平不可单独解读，其 U4 在训练路由器上（2.63）大于任一零模型（1.33–2.05）。
