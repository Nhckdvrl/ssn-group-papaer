# E170：可重现的分工里，哪些语言区分是规范的（2026-11-03）

- **状态：** 阶段 1、1b DONE（2026-11-03，CPU）；阶段 2（线性可分性对照、“左文脉可判定性”标注）未开始，是否做由人决定
- **类型：** CLAIM（把 E167 的 T_D 从一个数变成有语言内容的表）
- **对应：** P34；[REVIEW_2026-11-03](../REVIEW_2026-11-03.md) §2、§4.2
- **问题（一句话）：** 同一个词在不同上下文里被分给不同专家，这种“分法”在深层跨初始化重现了约 2/3（T_D 比值）。重现的部分对应哪些语言区分（词类、依存关系、中心词词类、前后词类、句中位置、形态特征、文档体裁）？不重现的部分是什么？规范的部分是否只是“闭类 / 高频 / 早学到”的那部分？
- **先验预测（跑之前写）：**
  - 几何派（Myth）：凡在共享几何里线性可分的区分都会被所有 seed 用来分工 → 规范集 = 主要语言区分全体，体裁等非语言区分也可能规范。
  - 历史派（Routers-Learn-Geometry、分岔模型）：只有最早、最频繁的区分（词类、位置、标点）规范，细的句法区分由早期随机历史锁定 → 跨 seed 任意。
  - 输出收敛派（Fehlauer et al., EMNLP 2025）：功能词规范、内容词偶然。
- **设置：**
  - 阶段 1（本卡先跑；CPU）：E167 终点与 32 亿的路由采集（`routing/*.npz` 里每个锚点词每层的 top-8 集合与 N1 期望），E167 预登记的同词形词对（342,578 对、1,827 词形）。`scripts/ud_annotate.py` 把 UD EWT 的 deprel、中心词 UPOS、feats、句中位置、前后词 UPOS、体裁接到 `passages.json` 的词上（逐词核对词形与 UPOS 一致）。
  - 阶段 2（E169 采集完成后；CPU）：用全部锚点词（不只预登记样本）做多功能词形的深入分析（如 that / to / as / like / -ing），以及每个区分在隐状态中的线性可分性（“表示里有没有”）对照“分工用不用”。
- **读数（看到跨模型分解之前固定）：** 对每个语言变量 X，把每个词对标为“同 X”或“异 X”，并按（词形 × X 值对）分格：
  - 模型内：D（词形内中心化的 N1 残差）对格均值的 R²（该模型是否用 X 来切）；同 X 对与异 X 对的 D 均值差。
  - 跨模型：把 D 分解为格均值 D_cell（X 能解释的部分）与格内残差；跨模型协方差 cov(D_A, D_B) 中由 D_cell 贡献的比例（X 承载了多少可重现的分工），以及格内残差自身的跨模型相关（X 之外还剩多少可重现）。只换初始化、只换顺序、地板三组并列；同样对 C（只扣词身份）报告。
  - 变量：upos（同词形不同词类）、deprel、head_upos、prev_upos、next_upos、句中位置（句首 / 句末 / 其他）、feats、genre；以及它们的组合（upos × deprel）。
  - 格最小样本 3（更小的格并入词形均值 0）；另报留一法 R² 以防格均值过拟合。
- **阳性对照：** 同一模型对自身分解为 1；打乱 X 标签（词形内）后 X 的解释比例应 ≈ 0；只换顺序对作为天花板。
- **噪声地板 + MIE：** 词形内标签置换（200 次）给每个变量的零分布；按词形的聚类 bootstrap。不设门槛。
- **混杂审计：** 变量之间相关（deprel 与 upos 高度相关）→ 报告边际与条件（在 upos 之内）两版；预登记样本每词形 ≤ 40 次 → 多功能词的格样本小，阶段 2 用全部出现补；UD 自动标注噪声无关（人工标注）；体裁与文档混淆 → genre 的解释比例上限由 doc 级同异给出。
- **决策表（跑之前写）：**
  - 可重现分工（跨模型协方差）的大部分由 upos / 位置 / 标点类变量承载，deprel、head_upos 在 upos 之内几乎不再增加 → 规范集 = 自然分工；主张转为“超出词类与位置的分工是每次训练各自决定的”。
  - deprel / head_upos 在 upos 之内仍承载可观比例，且只换初始化与只换顺序的比例相近 → 存在超出“自然”的规范句法分工；进入阶段 2 看这些区分在所有 seed 的隐状态里是否同样线性可分（表示里有且分工用）。
  - 格内残差仍有大部分跨模型相关 → 可重现分工主要不是这些语言变量描述的，报告“语言可解释比例”并停在这里，不再造变量（止损）。
  - 某些变量只换初始化时承载比例显著低于只换顺序 → 这些区分的分工是初始化锁定的；与 E167 深层印记持久性对照。

- **读法：**
  1. 按语言标签分格的分工（同词形的词类、形态、依存关系、中心词与前后词类）跨初始化重现为同初始化的 71–85%；格内残差只有 55%。即可重现的那部分分工主要是沿着语言区分组织的，初始化印记主要落在语言标签之外的残差里（每个变量的 share 在只换初始化时都高于只换顺序，方向一致）。
  2. 单个变量里承载最多的是直前 / 直后词的词类（.42 / .38，置换零 .15），其次是依存关系（.34，置换零 .11）；词类本身 .22（置换零 .02）。词类 + 直前词类合计 .47（置换零 .17）。体裁、文档、句中位置几乎不承载（.07–.12，接近置换零）。
  3. 这些变量合起来最多解释约一半的跨初始化可重现分工；另一半在格内残差里（含测量噪声，所以“未解释”是上界）。
