## 定义
- **增益归属。** OLMoE 的路由器输入 h_t = g_t ⊙ x̂_t（g = post_attention_layernorm 增益，随检查点变；x̂ = 归一化后未乘增益的向量，由 h / g 精确恢复，先查 min |g|）。**主口径**把增益算进路由器：T_t(·) = top8(W_t diag(g_t) ·) 作用在 x̂ 上；**副口径**把增益算进隐状态：把原始 h_s 直接喂给 W_t。
- **专家对应。** 训练不重排专家编号，主口径用恒等映射；先在每层、每个检查点对发布版做路由器行（中心化、有符号余弦）匈牙利配对，报**恒等率**（配对落在同编号的比例）；恒等率 < 1 时另报匈牙利配对下的 O / R 作稳健性。
- **一致率。** top-1 一致 = 1[top1_a = top1_b]；top-8 重合 = |S_a ∩ S_b| / 8。逐 token 计算，按层报，mid 段 = 2–11 层均值（E186 BANDS）。
- **分解（终点 F = main；每个检查点 t、每层 l）：**
  - O(t)  = agree(T_t(x̂_t), T_F(x̂_F))　观测
  - H(t)  = agree(T_F(x̂_t), T_F(x̂_F))　同一终点路由器，只有隐状态漂移
  - R(t)  = agree(T_t(x̂_F), T_F(x̂_F))　同一终点输入，只有路由器漂移
  - H′(t) = agree(T_t(x̂_t), T_t(x̂_F))　同一 t 路由器，只有隐状态漂移
  - R′(t) = agree(T_t(x̂_t), T_F(x̂_t))　同一 t 输入，只有路由器漂移
  - 一致率不可加，不做份额，五个数并列。
- **全网格（1b）：** G(t, s) = agree(T_t(x̂_s), T_F(x̂_F))，t, s 跑遍九个检查点；O / H / R 是它的对角线 / F 行 / F 列。
- **相邻增量（2）：** 对相邻检查点 (t_i, t_{i+1}) 做同一分解，以 t_{i+1} 作终点：O_i、H_i、R_i（以及 H′、R′）→ 每个分量在哪一段变化最大。
- **到达时间（概括 R 与 H 谁先定）：** 归一化 n(t) = (x(t) − c)/(1 − c)，c = 该层 token 打乱的负载乘积期望；报 mid 段均值的 n 越过 .5 与 .8 的 token 数（对数 token 轴上线性插值）。只是概括，不是判据。
- **几何地板（3）：** 同一个随机路由器作用在 (x̂_t, x̂_F) 上的一致率；以终点有效路由器 W_F diag(g_F) 为模板，三族各 8 draw，口径同 `e187_decomp.py`：N_A（W·Q，Q 为 O(2048) Haar）、N_B（N1 = U S Q Vᵀ + 偏置，在 x̂_F 上拟合到 T_F 的负载）、N_G（iid 高斯行，行范数匹配）。地板是 **H 的参照**（同一路由器、两组隐状态）；相邻增量上同样计算。
- **子空间说的直接检验（4）：** 读出子空间 P_F = W_F diag(g_F) 中心化后的行空间（≤ 63 维）。对每层、每个 t 报 x̂_t 相对 x̂_F 的漂移：(a) 子空间内 / 外的相对漂移 ‖P(x̂_t − x̂_F)‖ / ‖P x̂_F‖ 与 ‖(I−P)(x̂_t − x̂_F)‖ / ‖(I−P) x̂_F‖（token 均值）；(b) 逐 token 余弦（内 / 外）；(c) 线性 CKA（token 中心化，内 / 外 / 全空间）。再把 x̂ 分成**逐 token-id 均值分量**（在 22k 中出现 ≥ 5 次的 id，报覆盖率；同一检查点内取均值）与**残差分量**（x̂ − 该 id 均值），两部分各报 (a)–(c)（全空间与子空间内）。与 H(t) 并列。另报 t 的读出子空间 P_t 与 P_F 的主角余弦均值（子空间本身在训练中转了多少）。
- **第 0 层网格（5）：** 9 × 9：T_t（主口径，第 0 层）作用在 x̂_s 上，所有 t, s；读数 = Î(top-1; 前一 id) / Î(top-1; 输入 id)，Î 为 `e185_lib.mi_marg`（plug-in 互信息减 3 次全局置换均值，出现 < 3 次的值并入稀有桶；份额 = Î / H(top-1)，比值与份额分母无关）。句首 token 的前一 id = −1（单独一类）。同一网格另报两个份额本身。读法：**固定 s 随 t 变 = 路由器自己找到前一 token 方向；固定 t 随 s 变 = 几何把该方向推大。** 语料 = 全部 22k token（20 语 + UD），**与 E186 的英语视图不同，绝对值不可直接对，只比形状**；对角线与 §22 5b 的趋势对账。另报同一网格在 N_B 型随机路由器（以 W_t 为模板，1 draw，负载拟合在 x̂_s 上）下的对角线，作为几何参照。
- **token 类（6）：** O / H / R（mid 段、top-1 与 top-8）在 t ∈ {20B, 335B, 1.34T, 5.1T} 上分层：位置（0 句首 / 1–3 / 4–15 / 16–63 / ≥ 64）；字母 / 非字母 / 片段（`e182_common.token_class`）；频率五分位（在重建的完整 FLORES + UD 序列上计数）；语言与文字（20 语 + UD）；H(e∣id) 三分位（305 id，报覆盖）；UD 的 UPOS 三类：功能（ADP AUX CCONJ DET PART PRON SCONJ）/ 内容（NOUN VERB ADJ ADV PROPN NUM INTJ）/ 标点（PUNCT SYM），X 不计。
- **原始样例（7）：** 逐 id（22k 中 ≥ 30 次）在 t = 20B 与 1.34T 上 mid 段 top-8 O 最高 / 最低各 20 个 + 上下文片段；同 t 上 R − H 最大 / 最小各 10 个。

## 会改变读法的结果（不是判决表）
最强先验：**Myth 2604.09780**（`[节]`，线性路由器下隐状态相似 ⇒ 路由相似，专精是几何的涌现性质）预测路由分配的到达跟着几何走：H 先到终值、R 后到或与 H 同步，而且 O ≈ H。**Routing Drift 2609.32821**（`[摘要]`，合并 MoE 上"多数重分配来自输入漂移"）预测 1 − H ≫ 1 − R，即 R(t) 比 H(t) 高。§22 5a 的"路由器先定"预测 R 高于 H 且早到。
1. **R(t) 早于 H(t) 到终值（R > H，到达时间 R 早）** → "路由器先定"成立；放弃 Myth 式"分配跟着几何走"在本训练轴上的说法，也放弃把 Routing Drift 的"输入漂移为主"当作训练动态的先验。
2. **H(t) 早于 R(t)（H > R）** → "几何先定"；§22 5a 的 T vs N_F 差距要改读成"训练路由器读的方向比随机方向稳定"，而不是"路由器先定型"；放弃"路由器先于几何"的措辞。
3. **H ≈ R 同步**，且读出子空间内的漂移 ≪ 全空间（或 id 均值分量漂移 ≪ 残差分量）、H 高于全部地板 draw → **子空间说**：路由器读的是几何里早已稳定的子空间；"谁先定"在全空间几何上不可比，要改说"守恒的是读出子空间"；放弃单独的"路由器先定"与"几何先定"两种措辞。
4. **H 不高于几何地板** → H 的水平可以由随机路由器在同一对隐状态上给出，训练路由器不偏读稳定方向；与 3 相反。
5. **第 0 层网格：固定 s 时比值随 t 上升**（尤其 s 早期也升）→ 路由器自己找到前一 token 方向、领先几何为真（§22 5b 成立）；**固定 t 时比值随 s 上升而固定 s 时随 t 平** → 是几何把前一 token 方向推大，5b 的"路由器领先约 5000 亿 token"改读成 T 对该方向更敏感而非更早。
6. **相邻增量**：R 与 H 的最大变化段是否落在同一段；是否与 1.34T → 5.1T（长段）或 5.1T → 发布版（退火）对齐——退火段若改变 R 而不改变 H，写"退火只改路由器"。
7. **token 类**：O / H / R 的差是否集中在句首、低 H(e∣id) 或高频 token（词表查表部分先定）；若持平则"先定"不限于词表部分（与 E187 token 类平坦对照）。
