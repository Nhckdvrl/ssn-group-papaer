# E180：语言专属路由跟文字还是跟语言身份——塞尔维亚语双文字配对（2026-11-09）

- **状态：** DONE（11-09 17:05 写定"设置 / 读数 / 决策表"，在任何采集之前；跑后未改；结果见末节，事后分析标 POST-HOC）
- **类型：** PILOT（候选 A 的决定性 pilot，[CANDIDATE_QUESTIONS](../CANDIDATE_QUESTIONS_2026-11-09.md) §A、[DIRECTION](../DIRECTION_2026-11-06.md) §16；不推进已登记主张的等级；立题由人定，R2）
- **对应：** CLAIMS C24（语言专属路由剖面 = 几何 + 常数倍，L1）的"语言专属到底是哪种专属"一栏；E178 / E179 管线。
- **问题（一句话）：** 在多语 MoE 里，哪些层的语言专属路由跟着**文字**走、哪些层跟着**语言身份**走？即逐层比较"同一语言换文字"（srp_Cyrl vs 确定性转写的 srp_Latn）与"同一文字换近亲语言"（srp_Cyrl vs mkd / bul）哪一对路由更接近，并与零模型路由器 N_A / N_B 比较。
- **对手假设：** H-文字：每一层都是同文字异语言的一对更近（"语言专家"其实是文字 / 词表专家）。H-语言：某些层（预期中层）同语言异文字的一对比同文字近亲语言更近。

## 设置
- **模型（单卡 bf16，fvcrc11 A100 80GB，transformers 4.57.6，同 E179 加载方式）：** `Qwen/Qwen3-30B-A3B`（48 层，128 选 8，与 E178 / E179 同一 checkpoint）、`openai/gpt-oss-20b`（24 层，32 选 4，带偏置路由器，MXFP4 默认反量化为 bf16，eager 注意力）；时间允许再跑 `allenai/OLMoE-1B-7B-0125-Instruct`（16 层，64 选 8；E179 里训练路由器几乎无 U 形，作弱多语第三个模型，只对 H-文字有信息）。
- **数据：** FLORES-200 dev 全部 997 句（`/home/xiang/mechpop_cache/flores200/`），每句单独一条序列，不加模板，`add_special_tokens=False`（同 E179）。20 种"语言侧"：
  - **斯拉夫组（主）：** srp_Cyrl；**srp_Latn = srp_Cyrl 的确定性转写**（见下）；拉丁：hrv_Latn、bos_Latn（补充）、slv_Latn、ces_Latn、pol_Latn；西里尔：mkd_Cyrl、bul_Cyrl、ukr_Cyrl、rus_Cyrl。
  - **印地组（次要）：** hin_Deva、urd_Arab；同文字异语言对照：npi_Deva、mar_Deva（天城文），snd_Arab、pes_Arab（阿拉伯字母）。印地语与乌尔都语口语相通但书面词汇有差异（梵语 vs 波斯-阿拉伯借词），且 FLORES 两份是各自独立翻译，**不是同一文本换文字**——只作次要配对。
  - **汉语组（次要）：** zho_Hans、zho_Hant、yue_Hant（粤语，繁体）。venv 里没有 OpenCC，按任务规定用 FLORES 自带两份；FLORES 的 zho_Hant 是**另一份翻译**（措辞不同），不是确定性简繁转换，简繁对因此同时混了措辞差异。
- **srp_Latn 来源：** 核对过 FLORES+（HF `openlanguagedata/flores_plus` dev 目录，11-09）：只有 srp_Cyrl、hrv_Latn、bos_Latn，**没有 srp_Latn**；FLORES-200 本地目录同样没有。因此自写转写器 `scripts/e180_translit.py`（Gaj 拉丁字母，西里尔→拉丁一一映射：а→a … ђ→đ, ж→ž, ј→j, љ→lj, њ→nj, ћ→ć, ц→c, ч→č, џ→dž, ш→š；大写二合字母 Љ/Њ/Џ 在全大写词中为 LJ/NJ/DŽ，否则 Lj/Nj/Dž；非西里尔字符（原文里的拉丁专名、数字、标点）原样保留）。
- **采集（`scripts/e180_capture.py`，以 e179_capture.py 为底，不改 e178 / e179 脚本）：** 每个 MoE 层路由器挂 forward hook 取输入 h；T 的 logits 同 E179（Qwen3 / OLMoE 取 gate 输出，GPT-OSS 在 hook 内以与模型相同的 bf16 `F.linear` 重算）。为取"模型预测的下一个 token"，前向改为调用 `model.model(...)` 取末层隐状态，再分块乘 `lm_head` 取 argmax（与 `model(...)` 等价，只是不物化全词表 logits）。
- **路由器（同一隐状态、模型自身 top-k）：** T；**N_A**（W·R，R 为 O(d) Haar，8 draws；GPT-OSS 保留训练偏置）；**N_B**（仓库 N1：W_c V Q Vᵀ，偏置在校准集上重拟合到 T 的校准负载，8 draws）。校准集 = 20 语侧 devtest 前 25 句（srp_Latn 用同一转写器）。随机数：每层 `torch.Generator().manual_seed(180000 + l)`，抽取顺序 N_A → N_B。不跑 N_G / N_T（E179 已知 N_T 对 top-k 读数恒等）。
- **token 数均衡（与被测变量解耦）：** 每句 s 在其所属组内取 n_s = 组内各语言侧该句 token 数的最小值，每个语言侧在该句内无放回均匀抽 n_s 个位置（种子 180，与模型无关，只依赖分词）。所有配对 JSD 只在被抽中的 token 上算，因此两侧 token 数逐句相等，句子 bootstrap 下仍相等。
- **存：** 每层 × 每（语言侧, 句）× 17 个路由器（T + 8 N_A + 8 N_B）的被抽中 token 的专家计数（uint16）；全部 token 的 T、N_A0、N_B0 的 top-k（uint8）、输入 token id、预测下一个 token id。原始数组在 `~/mechpop_cache/e180/<model>/`（不进 git）。

## 读数（跑前固定；层号 0 起）
- **D(A, B)**：第 l 层，两侧被抽中 token 的专家使用分布 P(e) = top-k 计数 / 总计数（E178 R1 定义），两分布的 JSD（底 2）。
- **配对：**
  - **P1 同语异文：** srp_Cyrl ↔ srp_Latn。
  - **P2-nearest 同文异语·最近亲（主比较对象）：** mean{srp_Cyrl ↔ mkd_Cyrl, srp_Cyrl ↔ bul_Cyrl}（西里尔、南斯拉夫语支、不同语言）。
  - **P2-hrv（最紧对照，单独报）：** srp_Latn ↔ hrv_Latn（同文字，语言上几乎相同：标准克罗地亚语与塞尔维亚语互通，差异在词汇与 ije/e）。补充：srp_Latn ↔ bos_Latn。
  - **P3 同文异语·较远：** mean{srp_Cyrl ↔ rus, srp_Cyrl ↔ ukr, srp_Latn ↔ ces, srp_Latn ↔ pol, srp_Latn ↔ slv}。
  - **P4 异文异语：** mean{srp_Cyrl ↔ slv / ces / pol, srp_Latn ↔ mkd / bul / rus / ukr}。补充：srp_Cyrl ↔ hrv（异文字、几乎同语）。
  - **P0 噪声地板：** srp_Cyrl 句子按固定随机置换（种子 180）分两半 A / B，D(半 A, 半 B)。补充：srp_Latn 同样分半。注意 P0 两半是**不同句子、各半数 token**，而 P1–P4 是平行同句全量——P0 同时含内容差异与较小样本，是偏保守（偏大）的地板。
  - **次要（同一统计量）：** 印地组 P1′ = hin ↔ urd，P2′ = mean{hin ↔ npi, hin ↔ mar, urd ↔ snd, urd ↔ pes}；汉语组 P1″ = zho_Hans ↔ zho_Hant，P2″ = zho_Hant ↔ yue_Hant。
- **主统计量：** 逐层 Δ(l) = D(P1) − D(P2-nearest)。**句子配对 bootstrap**（1000 次，句 id 在所有语言侧一起重抽；P0 用同一重抽、各句按所属半计入）给 95% 区间。
  - **H-语言层集合** = Δ 的 95% 区间上界 < 0 的层；**H-文字层集合** = 区间下界 > 0 的层；其余为不定。点估计集合（Δ < 0 的层）同报。
  - **零模型族：** 每个 bootstrap 重抽对 8 个 draws 的 Δ 取平均，得族均值 Δ 的 95% 区间，用同一规则得 N_A / N_B 的 H-语言 / H-文字层集合；另报每层 8 个 draws 中 Δ < 0 的个数（x/8）。
  - **连续性：** 集合是否为单一连续段（报全部段）。
  - **首尾 / 中段汇总：** 按 E179 层段（Qwen3 edge 0–3 ∪ 44–47 / middle 7–34；GPT-OSS 0–1 ∪ 22–23 / 4–17；OLMoE 0–1 ∪ 14–15 / 2–11）报 Δ 的平均。
  - 同样规则另算 Δ_hrv(l) = D(P1) − D(P2-hrv) 的集合（单独报，不进决策表）。
- **辅读数 1：同 token 类型的跨语言 JSD（token 类型匹配）。** 只用**无字母的 token 类型**（解码后不含任何 Unicode 字母、不含替换符 �：数字、标点、空白、符号；这类 token 在所有语言侧都出现，因此 P1 与 P2 的 token 集合可比）。对一对 (A, B)：取两侧都出现的此类类型，每个类型 t 两侧各无放回抽 n_t = min(c_A(t), c_B(t)) 个出现（种子 180），在这些出现上算 D_tok。零模型 = 在每个类型内部把 2n_t 个出现的语言标签打乱（100 次），报 D_tok − 置换均值（超出量）与是否 > 置换 95 分位。配对：P1、srp_Cyrl ↔ mkd、srp_Cyrl ↔ bul（两者平均 = P2-nearest）、P2-hrv；路由器 T、N_A0、N_B0。逐层报 sign(超出量(P1) − 超出量(P2-nearest))。不进决策表。
- **辅读数 2：末 8 层按预测下一个 token 的文字分层（只报不判）。** 用 argmax 预测 token 解码后的字符把每个位置分为 Cyrillic / Latin / 无字母 / 其他（含部分 UTF-8 字节）。在每一层（末 8 层）、每一层级内，各语言侧按该层级重新均衡（每侧抽相同数目 = 涉及语言侧在该层级的最小数），算 D(P1)、D(P2-nearest)。关键是"无字母"层级（输出文字的混杂被拿掉）。不改主统计量。

## 阳性对照与 sanity
- **转写往返：** 对 srp_Cyrl 中全部纯西里尔词，拉丁→西里尔逆映射后与原词逐字相同的比例（预期 1.0；原文若含 нј / лј / дж 这类序列会不可逆，列出）。另报原文中原样保留的拉丁词数。
- **训练路由器自一致：** 同一 batch 前向两次 T 的 top-k 完全一致率（预期 1.0）。
- **hook 正确性：** fp32 重算 top-k 与模型实际选择的重叠率；T logits vs 模型选择（预期 1.0）。
- **N_B 负载匹配：** 校准集上 N_B 负载与 T 负载的总变差均值 ≤ .01。
- **地板：** D(P0) ≪ 所有配对距离（报 P0 / min(P1, P2, P3, P4) 的逐层最大值）；若不成立照报（说明平行内容本身让 P1–P4 偏低）。
- **均衡核对：** 逐句被抽 token 数在组内各语言侧相等（差 0）；聚合计数 = 逐句计数之和。

## 噪声地板 + MIE
- T 的地板 = 句子 bootstrap 区间；零模型族的地板 = 同一 bootstrap 下 8-draw 均值的区间 + draws 范围；P0 = "同语同文换句子"距离。决策用的是 Δ 区间是否越过 0（二元，逐层），不是效应大小；"中段带"、"≥ 50% 重叠"是 pilot heuristic（R12）。

## 混杂审计（EXECUTION §4）
- **切分长度差：** 已控制（逐句等 token 数抽样）。
- **深层按预测 token 路由（输出文字随输入文字变）：** 部分控制——主统计量不控制（预登记风险：深层可能必然落 H-文字），辅读数 2 在末 8 层按预测 token 文字分层报。
- **平行内容：** P1、P2、P3、P4 都是同一组 997 句的平行版本，内容相同；P0 内容不同（见上）。
- **翻译差异：** srp_Latn 是转写，与 srp_Cyrl 逐词相同；mkd / bul / hrv 是独立翻译，措辞、句长不同——这让 P2 天然多一份"措辞差异"，偏向 H-语言。用 P2-hrv（措辞同样独立翻译但语言几乎相同）与辅读数 1（只看相同 token 类型）部分控制；未完全控制。
- **转写文本是否"自然"：** srp_Latn 是机器转写，不是人写的拉丁塞语；现实中拉丁塞语的书写与转写一致（一一映射），差异只在原文的外文专名处理，影响小；未控制。
- **模型对语言的熟悉度：** mkd / bul 与 srp 都是中低资源；hrv 与 srp_Latn 共享大量词形；未控制，按配对分别报。
- **零模型族翻转判决：** 已控制（N_A / N_B 同等进表，分开判）。
- **分词器不同：** 三个模型只比各自内部的层集合与符号，不比绝对 JSD。
- **印地 / 乌尔都与简 / 繁：** 不是同一文本换文字（见数据），只作次要；结论措辞不得把它们当作 P1 的复现。

## 决策表（跑前写死）
以 T 的 Δ(l) = D(P1) − D(P2-nearest) 的 bootstrap 区间判（逐模型）：
- **(i) H-文字处处：** T 的 H-语言集合为空，且 H-文字集合覆盖 ≥ 90% 的层 → "MoE 语言专家是文字专家"。只有当它在 Qwen3 与 GPT-OSS 上都成立、且 N_A 与 N_B 同样如此（几何本身也按文字分）时才算够一篇的结果；否则是一条注记。
- **(ii) 中段 H-语言带、零模型没有：** T 的 H-语言集合非空、是单一连续段、长度 ≥ 2 层、不含前 2 层与后 2 层，且某零模型族的 H-语言集合与 T 的带重叠 < 50%（按 T 带的层数计）→ 在这些层，路由器在几何之上带着脱离文字的语言身份（最强结果）。
- **(iii) H-语言带 T 与零模型都有：** 同 (ii) 的带，但零模型族的集合覆盖 T 带 ≥ 50% → 语言身份在几何里，路由器中性。
- (ii) 与 (iii) 对 N_A、N_B **分开判**；两族判法不同时两者都报、不选边（E178 / E179 教训）。
- **(iv) 混合 / 不连续：** T 的 H-语言集合非空但有 ≥ 2 段、或碰到前 2 / 后 2 层、或长度 1；或 H-语言集合为空但 H-文字集合 < 90% 的层 → 照实报为不定。
- 次要配对（hin/urd、zho 简繁）用同一统计量、同一规则报分支，但不进主判决。
- **以上都不是开线 / 关线条件**；结果交主会话，立题由人定（R2）。
