## 读数（跑前固定；层号 0 起）
- **路由侧散度（每语言 ℓ、每层 l、每个路由器 r）：**
  - **D_B（Bandarkar 原定义，主）**：Div_r(ℓ, l) = 997 句上 `div.npy` 的平均。
  - **D_J（R1 式，补充）**：P_r(e | ℓ) = 该语言全部 token 的 top-k 计数归一；JSD₂(P_r(·|ℓ), P_r(·|eng))（底 2）。
  - **N_A / N_B**：每个 draw 各算一份散度，再对 8 个 draw 取平均得"8-draw 均值散度"，相关用它；另报逐 draw 的 ρ 最小–最大。
- **层聚合：** (a) **middle 带（主）**：Bandarkar 给了干预层的模型用原文——Qwen3 (8,35) → 0 起 **7–34**（与 E178 / E179 同一换算），GPT-OSS (4,19) → 0 起 **3–18**；OLMoE 原文无干预层 → 用 E179 middle **2–11**。(b) 全部层平均。层内先算散度、再对层平均，然后跨语言做相关。
- **迁移侧：** acc(ℓ) = 900 题正确率；transfer gap = acc(eng) − acc(ℓ)。**注：同一模型内 gap 是 acc 的单调减变换，Spearman(D, gap) ≡ −Spearman(D, acc)，只照报、不提供独立信息。**
- **主统计量：** 每个模型，19 种非英语上 **Spearman ρ(D_B middle, acc)**，分别对 T、N_A（8-draw 均值）、N_B（8-draw 均值）。预期 ρ 为负（散度大 → 准确率低）。
- **差值的方向（跑前写明）：** "预测得更好" = 相关更负。决策用 **Δ = ρ_NB − ρ_T**（对 acc；等价于对 gap 的 ρ_T − ρ_NB，也等价于 |ρ_T| − |ρ_NB| 在两者同为负时）。Δ > 0 表示 T 预测更强。N_A 同样报 Δ_A = ρ_NA − ρ_T。
- **不确定性：** 语言上的**配对 bootstrap**：19 种语言有放回重抽 10,000 次（种子 183），同一次重抽上同时算 ρ_T 与 ρ_NB，取 Δ 的 2.5 / 97.5 分位为 95% CI；ρ_T、ρ_NB 各自的 bootstrap CI 同报。**标签置换零模型**：把 acc 在 19 种语言间置换 10,000 次，ρ_T 的双侧置换 p 值；ρ_NB 同报。**N_B 的 8-draw 带**：逐 draw 的 ρ 最小–最大。
- **Bandarkar 原统计量（复现读数）：** 原文 §5："In the middle layers of all models, the correlation coefficient r between the routing divergence from English and Belebele accuracy is always strong. For OLMoE, r ∈ [−0.95, −0.80] for all middle layers. Meanwhile, GPT-OSS is the weakest (r ∈ [−0.40, −0.60]), with Phi-3.5-MoE and Qwen 3 in between." → 本卡复现为：**12 种分析语言上、middle 带每一层单独的 Pearson r(Div_T(ℓ, l), acc(ℓ))**，报 middle 带内 r 的范围与中位数；T 与 N_B（8-draw 均值）并列。同时报 19 语版本。
- **补充格（照报，不进决策）：** {D_B, D_J} × {middle, 全层} × {19 语, 12 语} × {Spearman, Pearson} 的 ρ_T / ρ_NA / ρ_NB 与 Δ 的 CI。
- **次要读数（0 GPU）：2605.28042 剪枝分配。** 原文规则（§4.2 + 附录 A/B 已读）：专家重要性 = routing mass（被选 top-K 的归一权重按 token 平均）；层散度 d_ℓ = 序列级 routing-mass 分布与英语的**未归一** JSD，按序列平均；每层先给 K 个容量，余下 B = L(E − k) − LK 按 d_ℓ 比例迭代分配（封顶 E、溢出回流），Hamilton 法取整；每层剪掉 routing mass 最低的 E − c_ℓ 个。**我们的近似（缓存只有计数、没有 top-K 权重）：** routing mass ≈ 该语言 top-k 选择计数（T 的，模型实际运行的就是 T）；d_ℓ ≈ 逐句 top-k 计数分布与配对英文句的未归一 JSD（自然对数）按句平均——T 用 persent 的 T 列，N_B 只有第 0 个 draw 的逐句计数 → **N_B0**；变体：d_ℓ 用 D_B（T vs N_B 8-draw 均值）。
  - **主次要读数（allocation-only 重合）**：排序都用 T 的 routing mass，容量分别由 T 的 d_ℓ 与 N_B 的 d_ℓ 分配，保留集合 S_T、S_NB（(层, 专家) 对）；重合 = |S_T ∩ S_NB| / |S_T|。剪枝率 50% 与 56.25%（原文 GPT-OSS 报的两档），逐语言报，主报原文 4 种校准语言中我们有的 deu / jpn / ben（原文第 4 种是埃及阿拉伯语 arz，我们用 arb 代替并注明）的平均，以及 19 语平均与最小值。**规则（主会话给定）：≥ .9 → 该方法不需要"语言专家"解释。**
  - **补充（照报，有构造性偏差）**：N_B 自己的 routing mass 排序 + N_B 容量 → 与 S_T 的重合。N_B 的偏置在校准集上重拟合到 T 的逐专家负载，所以按负载排序的重合部分来自构造；只作参考。另报 T 与 N_B 的容量向量 c_ℓ 的 Spearman 与 Σ|c_T − c_NB| / 2。
- **与被测变量解耦：** 路由散度来自 FLORES dev（E179 已固定），Belebele 准确率来自独立推理；层带跑前写死；不选语言（19 语全用，12 语子集由原文定）。注意 Belebele 段落就是 FLORES 段落（原文也指出），两侧文本内容重叠——这是原文设定的一部分，不是本卡引入的。

- **读数（散度 = D_B；T 与 N_B 8-draw 均值；N_A 同报）：**
  - (a) 全部语言上的 Spearman(散度, acc)：主算 19 种非英语（英语对自身的散度构造性为 0）；变体：加入英语（散度 = 0、acc = 英语准确率）共 20 种。

**结论先行（事实）：** 三个模型上，训练路由器的"中层与英语的路由散度"都强烈预测逐语言 Belebele 准确率（Spearman −.85 至 −.95，置换 p ≤ .0001），但负载匹配随机路由器 N_B 在同一隐状态上算出的散度预测得一样好（Δ = ρ_NB − ρ_T：−.00 / −.01 / +.02，CI 都含 0）→ **预登记判决 H-readout**。控制文字（是否拉丁）后，相关本身仍在（偏 Spearman −.84 至 −.96，文字组内置换 p ≤ .001），T 与 N_B 的差仍为 0。

- **按决策表执行：** 三个模型都 Δ < .1 且 CI 含 0 → **H-readout**。三个模型 T 的 ρ 都显著（p = .0001）——相关本身复现，不是"两个路由器都不预测"。没有模型出现 Δ ≤ −.2。
- **补充格（16 格 × 3 模型，`tables.md`）：** D_B / D_J（只看 top-k 计数）、middle / 全层、19 / 12 语、Spearman / Pearson 下，Δ_NB 范围 −.07 至 +.08，所有带 CI 的格 CI 都含 0（部分端点恰为 0）；没有一格支持 H-info。Pearson 的 Δ 在 −.02 至 +.05。判读与主格一致。
- **Bandarkar 原统计量（middle 带逐层 Pearson r，12 种分析语言）：** T：Qwen3 [−.98, −.74] 中位 −.90；GPT-OSS [−.97, −.78] 中位 −.95；OLMoE [−.98, −.86] 中位 −.91。N_B 同口径：[−.97, −.77] −.90；[−.97, −.77] −.95；[−.94, −.79] −.90。**复现：** OLMoE 与原文 [−.95, −.80] 一致；Qwen3 "居中"一致；**GPT-OSS 比原文强得多**（原文 [−.40, −.60]，最弱）。
- **补登记（文字协变量，19:35；OLMoE 部分 POST-HOC）：** edge（前后各 1/4 层）/ middle½（中间一半）/ Bandarkar middle 三个层带下：(a) 19 语 Δ −.07 至 +.03；(b) 非拉丁 13 语内 Δ −.14 至 +.09（CI 全含 0；拉丁 6 语内 T 与 N_B 的 ρ 几乎相同）；(c) 偏相关 Δ −.07 至 +.06（CI 全含 0 或下界为 0）。控制文字后 T 的偏 ρ：Qwen3 −.89 / −.96 / −.96，GPT-OSS −.84 / −.85 / −.85，OLMoE −.86 / −.90 / −.91（edge / middle½ / B-mid），组内置换 p ≤ .001。**按补登记规则：** 三个模型主格都无优势（Δ < .1）→ "no primary advantage to test"；控制文字后也没有出现被文字掩盖的 T 优势（无 Δ ≥ .2）。另：散度对准确率的预测**不是**文字效应（控制文字后 T 与 N_B 的 ρ 都仍显著）。
- **次要读数：2605.28042 剪枝分配。** allocation-only 重合（T 排序，T vs N_B0 容量）：50% 剪枝 paper4 平均 .923 / .924 / .919，19 语平均 .922 / .923 / .922，19 语最小 .869 / .904 / .908；56.25% 同样 .92 左右（Qwen3 最小 .860）；用 D_B 与 N_B 8-draw 均值分配 .929 / .926 / .909。**按规则（≥ .9 → 该方法不需要"语言专家"解释）：三个模型的平均都 ≥ .9**（Qwen3 有个别语言 .86–.87 < .9）。**但这条规则的区分力弱，必须同时看：** 均匀分配与 T 动态分配本身的重合就有 .877 / .826 / .918（脚本在看结果前加入、卡未登记的参照，POST-HOC 性质），即动态分配本身只改动 8–17% 的保留专家；T 与 N_B 的容量向量层序 Spearman 为 .69 / .85 / .26——容量剖面并不同形（OLMoE 尤其不同），只是两种分配都离均匀不远，所以保留集合重合高。own-rank 补充（N_B 自己排序，有构造性偏差）.78 / .82 / .71。
- **阳性对照：** 英语准确率三个模型都过（GPT-OSS 需按预登记退路改用聊天模板）；非英语中 > .30 的：19 / 18 / 12（都 ≥ 一半）；N_B 逐 draw ρ 带窄（≤ .07 宽）；置换零模型 p = .0001（最小可报值）。管线自检：本脚本的 T 的 R4 U 值与 E179 summary 逐位相同（2.6349 / 4.0663 / 1.2799）。GPT-OSS 聊天模板两半各自含英语，英语准确率 .9133 vs .9144（不同 batch 组成下 bf16 数值差，翻转 1 题），合并时用前一半。
- **与设计的偏离：** (1) GPT-OSS 原始提示英语 .637 < .80 → 按预登记退路改用聊天模板，主分析用聊天模板数字；原始提示数字照存（`belebele_gptoss.json`），不进判决。(2) GPT-OSS 退路为节省时间拆成两半在两张卡上跑（结果合并，协议不变）。(3) 19:35 主会话追加文字协变量补登记（见上；OLMoE 部分 POST-HOC）。
- **意外：** (1) **GPT-OSS 的原始提示数字复现了原文的"弱相关"**：原始提示下（阳性对照不过、偏向答 A：英语 900 题中 491 题选 A）middle 带逐层 Pearson（12 语）为 [−.72, −.54]，Spearman ρ_T −.43（p = .067）——与原文 [−.40, −.60] 相近；换成英语 .91 的聊天模板后升到中位 −.95。原文没写 Belebele 的评测方式，所以"原文 GPT-OSS 最弱"可能来自准确率的测量而不是路由——这是事后对照（POST-HOC），未核对原文评测协议。(2) 相关强度主要由 Bambara 这类近机会水平、高散度的语言撑开（图），但 Spearman 与非拉丁子集（不含 bam）结果一致。(3) N_A（Haar 旋转，不匹配负载）同样一样好（Δ_NA −.01 / +.03 / −.02）——不需要负载匹配就能复现预测力。
- **事实判决（两句）：** 在 Bandarkar 的三个单卡 MoE 上，逐语言"中层路由与英语的散度"对逐语言 Belebele 准确率的预测力（Spearman −.85 至 −.95）由同一隐状态上的随机路由器完整复现（训练减随机 Δ 在 ±.02 内，CI 含 0），控制文字后依然如此；路由散度对迁移的预测信息全部来自路由器读到的隐状态几何。2605.28042 的按散度分配剪枝容量，用随机路由器的散度得到的保留集合与原法重合 .92，但两种分配都只比均匀分配多改动约 8–17% 的专家。
