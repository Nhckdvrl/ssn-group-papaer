## 读数（跑前固定）
- **主信息量：地板校正互信息 Î(e; X) = I_plugin(e; X) − mean_r I_plugin(e; π_r X)**（bit），e = top-1 专家，π_r = X 在 token 间的全局随机置换（3 次，种子 185，**同一组置换用于所有路由器和层**，使 T 与零模型的地板可比）。X 中出现 < 3 次的取值并入一个"稀有"桶（只对 X，不对条件层）。报 **份额 Î / H(e)**（H(e) = 该路由器该层的 plug-in 专家熵）与原始 bit。
  - 已知偏差（写明）：用"独立"下的置换均值扣偏差会对集中的分布**多扣**，所以 Î 偏保守；T 比零模型更集中 → T − N_B 偏向低估。

## 哪些结果会改变判断（不是决策表；写的是"看到什么就改写什么"）
1. **T − N_B 只在"输入 id"上为正，给定输入 id 后所有上下文因子 T ≈ N_B 或更低** → 训练路由器在几何之上学到的只是"更尖的词表查表"；C24 / C26 的"常数倍"应读成词表锐化，而"上下文路由"整体是几何的。会把候选叙事"训练路由器相对几何的偏离按因子分解"的答案写成一句。
2. **给定输入 id 后，某个上下文因子（语言、预测下一、句子、前一）在某层段上 T 明显高于 N_B 的 draw 范围** → 存在几何之外、token id 之外的学到的上下文路由，并且知道它在哪个因子、哪一段层——这会成为下一个 GPU 实验的对象（而不是再做 yes/no 卡）。
3. **残差 (a)：** Î(预测下一 | 输入) 在 T 上 ≥ N_B → E184 的 "below-null" 是差值读数被 T 的输入信息拉低的产物，C26 第四句应改写为"T 不比零模型更偏预测 token，但给定输入后它的下一 token 信息与零模型相当"；< N_B → 训练路由器主动去掉了下一 token 信息，原句加强。
4. **残差 (b)：** Δ_lex 在两组复现 Δ_obs 的符号 → 塞语 / 乌兹别克反向是 token 重合效应，C25 的"文字代价 ≈ 姊妹语"标尺有一部分是词表重合标尺，需要改写；Δ_ctx 携带翻转 → 反向来自上下文表示，标尺读法保留。
5. **给定 token id 后的语言 / 文字份额：** 中层 NON token 上 Î(语言 | 输入, 文字) 在 T 上 > N_B0 → C25(b) 有了 token 控制下的版本；T ≈ 0 而 N_B0 > 0 → 路由器丢掉了 token id 之外的语言身份（与 E180 POST-HOC"随机路由器更认语言"同向）。
6. **模型间不同形**（例如只有 OLMoE 在某因子上 T > N_B）→ 只写 which-models 句，不合并。Qwen3 Base vs Instruct 图谱逐格相同 → 后训练不改变路由的因子结构。
7. **完整 top-k 版与 top-1 版在某因子上反号** → 该因子的结论只属于 top-1，表里分开报。

## 混杂审计（EXECUTION §4）
- **因子之间共线**（句子 ⊃ 语料；语侧 ⊃ 语言、文字；字母 token 的 id 几乎决定文字）：用嵌套与二级条件量分开，不做"份额加和 = 1"的分解（§20 与记忆 no-decomposition-questions：不问"多少归因于 X vs Y"，只报每个条件量本身）。
- **高基数因子的偏差**（token id、句子、前一 id）：置换地板 + 稀有桶；Î 偏保守（见读数）。
- **负载 / 熵差异**：份额按各自 H(e) 归一，原始 bit 同报；N_B 只在校准分布上负载匹配（E184 观察 4），测量语料上 H(e) 差异照报。
- **频率**：上下文依赖度用等 n 子样本；残差 (a) 按频次分层。
- **D180 只有单 draw、D182 零模型只有聚合计数**：在表中标注，不与 D184 的 8-draw 结论同等对待。
- **预测置信度不可得**：只用预测正确与否作代理。
- **E184 的 POST-HOC（词类 ≈ 词形）**：本卡以 Î(e; UPOS | 输入) 重新报，同一数据，不是独立复现——如实标。
