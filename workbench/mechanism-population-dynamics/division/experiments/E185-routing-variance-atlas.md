## 补登记（11-09 20:00；阳性对照之后。如实说明：此前已看过 OLMoE D184 一次输出的条件份额数值（都很小、T ≈ N_B），触发补登记的是下面的阳性对照，不是这些数值；结果段的任何解读都在补登记之后写）
阳性对照（`scripts/e185_pc_cond.py`，`results/e185/pc_cond.json`）暴露预登记条件估计器的缺陷：用 D184 真实的 (输入 id, X) 联合分布、合成专家 e = a·δ(f(输入)) + b·δ(g(X)) + 噪声，**Î(e; X | 输入) 只恢复真值的 3–8%（X = 序列）、7–16%（前一 id）、19–24%（预测下一 id）**，低基数 X 尚可（位置 45–57%、语料 75–80%）。原因：给定 token id 后，(id, X) 格几乎都是单例，分层置换地板把一切吃掉；而 g(X) 是跨 token id 共享的，plug-in 不跨层借力。因此**高基数因子的预登记条件份额只能当下界，不能读成"给定 token id 后上下文几乎不解释路由"**。
- **补充读数（POST-HOC 估计器）：交叉拟合条件预测信息 G(X | 输入)**（bit / token）。每条序列切成前半 / 后半两折（X 的取值两折都见过，序列因子才可估）；一折上估 p(e | 输入) 与 p(e | X)（加 A = 8 的 Dirichlet 平滑到 p(e)），另一折上用对数线性组合 log p_w(e) ∝ log p(e | 输入) + w·[log p(e | X) − log p(e)] 预测；w ∈ {0, .25, .5, .75, 1, 1.5} 在测试折的奇数序列上选、在偶数序列上评，再反过来，两折两向取均值。G = 组合后平均 log2 似然 − 只用输入 id 的平均 log2 似然；w = 0 时 G = 0，所以 G ≥ 0 近似（选 w 的噪声可使其略负）。同一合成阳性对照下报恢复比例。
- 计算对象：D184 全部路由器（T、8 N_A、8 N_B），X ∈ {序列, 前一 id, 预测下一 id, 真实下一 id, 位置, 语料, UPOS（UD 子集）}；D180（T / N_A0 / N_B0），X ∈ {平行句 id, 句实例, 预测下一 id, 语言, 文字}。另报同一估计器下的边际 G(输入)（只用输入 id 相对 p(e) 的增益）作尺度。
- 预登记的 plug-in 份额照报（低基数因子以它为主，高基数因子以 G 为主），两者不混用。

## 补登记 2（11-09 20:08；看到 OLMoE D184 的 G(X | 输入) 第一次输出之后）
OLMoE 第一次输出里 G(UPOS | 输入) 高达 .2–.44 bit（与 E184"词类 93–95% 是词形"矛盾），怀疑是**回退伪影**：低频 token 的 p(e | 输入) 估计很差，任何与 token 相关的粗因子（UPOS、预测下一 id 等）都会作为"回退先验"提高似然，被记成"token id 之外的信息"。加对照：X = 输入 id 的确定性粗分类（17 / 200 类，按构造不含输入 id 之外的信息），未限制的 G = .16 / .10 bit（假阳性），**只在训练折出现 ≥ 20 次的输入 id 上评估（并在同一子集上选 w）的 G_freq = .000 / .000**；合成阳性对照的恢复比例 G_freq 与 G 相当（序列 .52、预测下一 .33、前一 .34、位置 1.10 / .35、语料 1.19 / .94；弱效应 b = .05 的高基数因子仍为 0）。**因此补充估计器的报告量改为 G_freq**（覆盖约一半 token：出现 ≥ 20 次的 id），未限制的 G 只存档、不解读。OLMoE 的第一次输出作废重算。

**(i) 最稳的结构观察（三模型；多语部分含留出 devtest 复现）**

1. **训练路由器相对几何的"常数倍"是因子一致的，且大部分落在 token 身份上。** 边际份额 T / N_B（mid 段，D184 8-draw 均值）：与 token 身份相连的因子——输入 id、前一 id、真实 / 预测下一 id、UPOS——Qwen3 1.50–1.82、GPT-OSS 1.27–1.42、OLMoE 1.38–1.71，层间几乎不变（全层中位与 mid 段差 ≤ .03），半分同号 1.00；全局因子（位置、序列、语料）在 GPT-OSS / OLMoE 只有 1.07–1.47，Qwen3 为 1.41–1.72（Qwen3 另有序列层面的超出，见观察 3 与残差）。多语（D180，20 语侧）语言份额 T ≈ 2 × N_B0（Qwen3 .082 vs .038、GPT-OSS .024 vs .014、OLMoE .082 vs .037），**但给定 token id 与文字后降到 1.1–1.3 倍**（Î(语言∣输入, 文字) 份额 .018 / .015、.013 / .010、.021 / .019），交叉拟合 G_freq(语言∣输入) mid 段只有 .003–.017 bit。D182 留出数据同形。→ C24 / C26 的"常数倍"主要是**词表锐化**：训练路由器把"这是哪个 token"读得更尖，语言 / 词类 / 下一 token 份额随之一起放大。
2. **token id 只解释路由不确定性的少数。** Î(输入)/H(e) mid 段 T .18 / .27 / .32（Qwen3 / GPT-OSS / OLMoE；Zipf 对照显示该估计约低四分之一，所以真值约 .24 / .36 / .43）。高频 token（≥ 30 次）在 mid 段的专家熵 H(e∣id)（等 n = 30，上限 4.91 bit）T 3.07 / 1.88 / 2.38 bit。哪些 token 依赖上下文几乎完全由几何决定：逐 id Spearman(H_T, H_NB) .91 / .91 / .82；T 只是整体略"更查表"（T − N_B −.06 / −.21 / −.51 bit）。功能词与内容词的上下文依赖度相同（Qwen3 3.19 vs 3.08；GPT-OSS 1.98 vs 1.83；OLMoE 2.38 vs 2.48），频次越高越依赖上下文（ρ .14–.35）。
3. **给定 token id 之后，训练路由器多出几何的部分在"局部序列"因子上，不在全局因子上。** G_freq(X∣输入)（高频 id，bit）：预测下一 id T 高于 N_B 全部 draw 的层 48/48、19/24、16/16（mid 段 T / N_B .066 / .024、.051 / .039、.112 / .051；末段 .30 / .13、.19 / .15、.28 / .14）；真实下一 id 48/48、21/24、16/16；前一 id 47/48、17/24、15/16；UPOS 绝对值小（≤ .03 bit），T 高于 N_B 全部 draw 的层 OLMoE 15/16、Qwen3 32/48、GPT-OSS 12/24（E184 的"词类 ≈ 词形"在新估计器下仍成立：词形之外的词类信息 ≤ .03 bit）。位置、语料在 GPT-OSS / OLMoE 上 T ≈ N_B；**序列（文档）因子只在 Qwen3 上 T ≈ 2 × N_B**（mid .50 vs .25 bit，37/48 层高于），GPT-OSS / OLMoE 落在 N_B 范围内。多语（D180，单 draw 零模型）：给定 token id，平行句 id（跨 20 语同一内容）信息 mid 段 Qwen3 .44 bit（N_B0 .18；第 18–19、30–31 层 .96–1.09）、GPT-OSS .22（.13）、OLMoE .02（.01），而语言信息只有 .011 / .003 / .017 bit；平行句 id（可借其他 19 种语言的同一句）比句实例（只同语言）更有信息（Qwen3 .44 vs .26、GPT-OSS .22 vs .15）——**中层 token 之外的路由信息主要是跨语言共享的内容，不是语言**，训练路由器在这上面约是几何的 1.7–2.4 倍（OLMoE 量太小不判）。
4. **残差 (a) 已定位：E184 的"深层按下一 token 路由低于零模型"是差值读数的产物。** 同一数据上 ΔÎ = Î(预测下一) − Î(输入) 复现 E184 方向（T 低于两族全部 draw 的层 Qwen3 40/48、GPT-OSS 18/24、OLMoE 13/16；E184 为 40 / 16 / 14），但条件量反过来：Î(预测下一∣输入) T 高于 N_B 全部 draw 的层 48/48、21/24、15/16，低于的层 0，G_freq 同（第 3 条）。逐 id 分解：T 多出的部分集中在标点与高频功能词——`,` `.` ` the` ` to` ` of` ` and`（例：OLMoE 末层 `.` 27.3 vs 21.8 mbit，后接 `\n` / ` I`；Qwen3 末层 ` to` 13.3 vs 8.0、` of` 8.8 vs 3.7），这些恰是"后面跟什么"最不确定的 token；T 少于 N_B 的是少数代词 / 冠词（OLMoE ` you` ` I` ` of`；Qwen3 末层 ` the` 3.3 vs 7.8、` a` 1.9 vs 3.5）。正贡献合计是负贡献的 2–4 倍；与 token 频次几乎无关（Spearman .02–.06）。按"预测是否正确"分层（置信度代理）两层都 T > N_B。低频输入子集上 ΔÎ 为正（Qwen3 末层 T +.68 vs N_B +.36）——但低频 id 的 Î(输入) 受稀有桶影响最大，此处**未核对**是否为估计器伪影。
5. **残差 (b) 已定位：乌兹别克 vs 塞语的反向不是 token 重合效应。** 词表反事实 Δ_lex 在两组、四模型的字母 token 上**都为正**（mid 段：塞语 +.0022 至 +.0074；乌兹别克 +.0019 至 +.0101）——"只按 token id 路由"会让两组都偏文字；反向来自上下文项 Δ_ctx，它在两组都为负、且 mid 段区间不含 0 的层占 100%（塞语 −.0009 至 −.0040；乌兹别克 −.0027 至 −.0255），乌兹别克的上下文项是塞语的 3–12 倍，主要由"同文字异语言"那一对的距离被上下文拉大（OLMoE uzn_Latn↔tur/azj D_obs .058 vs D_lex .017）。上下文项随对照语言的距离增大：OLMoE 哈萨克 / 吉尔吉斯 −.008 → 土耳其 / 阿塞拜疆 −.043，Qwen3 −.011 → −.017，GPT-OSS −.0026 → −.0028。结构性限制：字母 token 上 P1 两侧词表不相交（重合 0），所以上下文项实际测的是"共享 token 在不同语言里被不同地路由"。**同一分解在零模型上同号且更大**（D180 塞语字母 token：Δ_ctx T / N_B0 / N_A0 = Qwen3 −.0037 / −.0060 / −.0137、GPT-OSS −.0011 / −.0021 / −.0082、OLMoE −.0022 / −.0041 / −.0095）——上下文里的语言分离是几何性质，训练路由器反而最弱。Qwen3-Base 与 Instruct 同（乌兹别克 Δ_ctx −.0141 vs −.0138）。
6. **文字在"同 token、同语言"之内不携带任何路由信息。** Î(e; 文字∣输入, 语言) 在 D180 与 D182（留出）、四模型、全 token 与无字母 token 的 mid 段都是 .000 ± .001（份额；末层最多 .02，Qwen3 无字母 token）；而 Î(e; 语言∣输入, 文字)（全 token，mid 段）为 .013–.046。G_freq(文字∣输入) mid 段 ≤ .008 bit。文字效应完全经由 token id（及首尾层）进入路由。

**(ii) 没有简单解释的残差**
- **Qwen3 的 12 层周期。** 序列 / 平行句因子的份额在第 6–7、18–19、30–31 层成峰（英语序列 T .27–.32、多语平行句 T .21–.33），同层英语 token id 份额落到 .12–.18；N_B 同样成峰（.17–.21）→ 这是隐状态几何的性质。给定 token id 后序列信息在这些层达到 .70–1.14 bit（T），约为 N_B 的 2 倍（.36–.54）——训练路由器在这些"内容层"把文档信息放大一倍。另一组周期层 11–13、23–25、35–37：专家熵塌缩（多语 H(e) T 2.1–3.5 bit，N_B0 2.3–4.0），T 的语言 / 文字边际份额在第 13、25、37 层跳到 .16–.27（N_B .03–.04），但给定 token id 后消失（Î(语言∣输入) .03 vs .02）——这些层的路由几乎只认 token。T 的位置信息（G_freq(位置∣输入)）在第 20、22、25、32、37 层有 .22–.34 bit 的尖峰，N_B 没有。三组周期的来源**未核对**（架构配置、训练配方都未查）。
- **OLMoE 第 0 层是"前一 token 路由器"。** 第 0 层 Î(前一 id) 份额 T .49 > Î(输入) .20（多语 .73 vs .31）；N_B .25 vs .16；Haar N_A 反过来 .10 vs .30（.24 vs .69）。G_freq(前一∣输入) 第 0 层 T 1.96 bit vs N_B .72。Qwen3 / GPT-OSS 第 0 层输入 id 占优（.53 / .62）。原因**未核对**（第 0 层注意力是否以前一 token 头为主）。
- **末层无字母 token 的语言信息。** OLMoE 末层 Î(语言∣输入) 在无字母 token 上 T .246 vs N_B0 .088（Qwen3 .209 vs .176，GPT-OSS .148 vs .194）：标点 / 数字在最后一层按语言分路，强度三模型不一致，OLMoE 远超几何。
- **零模型之间的反向。** 句级聚合的组内语言信息（D182，8 draws）Haar N_A 最大（OLMoE S 组字母 token .034 vs T .017 / N_B .017），GPT-OSS 的 T 甚至低于 N_B 全部 draw（S 组 .0048 vs [.0062, .0071]）；而 20 语侧的边际语言份额 T ≈ 2 × N_B0。组内（共享词表的近亲语言）训练路由器不比几何更分语言，组间（词表不同）才多出——与观察 1 的"词表锐化"一致，但 Haar 为什么在组内最分语言没有解释（E180 已见同向）。

- **上下文最依赖 / 最不依赖的 token。** 最不依赖上下文的全是句首 token（`The` `In` `This` `Great`：H ≤ .3 bit，句首 94–100% 去同一个专家；同一 token 在引号后出现时换专家，如 Qwen3 `"⟦The⟧ book` 去 111 号而非 69 号）——"上下文无关"在这里等于"还没有上下文"。最依赖上下文的是词尾 / 冠词片段：Qwen3 `ing` `s` ` a` ` the`（H 3.8–3.9 bit），OLMoE `s` `ing` `es` `ed`（3.7–3.9），GPT-OSS ` an` ` a` ` one` ` it`（2.7–2.8）。T 比几何"更查表"最多的是带句号的标点组合与高频内容词：Qwen3 `."`（1.76 vs 2.59）` US` `).`；GPT-OSS `).` ` love` ` recommend`（.69 vs 1.30）；OLMoE `=`（.83 vs 2.23）` R` ` in`。

**(iii) 每条观察会改变同行怎么读路由统计**
- 观察 1 / 6：报告"语言专家""文字专家"或"词类专家"的统计（Bandarkar 式语言专属度、Antoine Spec_POS、E180 式文字距离）在不先条件化 token id 的情况下，主要测的是**词表**——训练路由器在几何之上多出来的那一截是把 token 身份读得更尖，不是额外的语言 / 词类知识；跨语"路由对齐"若不控制共享 token，测的也是词表重合。可操作的建议：这类读数都应同时报 Î(因子∣token id) 与负载匹配零模型。
- 观察 2：用"同一 token 去同一专家"来论证 MoE 是"词汇路由"（OLMoE §5.4、OpenMoE）只说对了少数：token id 只解释 ¼–⅖ 的路由不确定性，且哪些 token 依赖上下文是几何决定的。
- 观察 3 / 4：OLMoE §5.4 的"深层按预测 token 路由"不应读成"预测信息超过输入信息"（三模型都不成立），但给定输入后**训练路由器确实比几何多携带约 1.3–2.8 倍的下一 token 信息**，集中在标点和功能词上——C26 第四句需要改写（见建议措辞）。
- 观察 5：E182 的"语言距离标尺"不是词表重合标尺；它测的是"共享 token 在不同语言里被不同地路由"，且这部分几何本身就有、训练路由器反而最弱。
- 残差（Qwen3 周期层、OLMoE 前一 token 第 0 层）：任何"按层段平均"的路由统计在 Qwen3 上都会把内容层与查表层混在一起；层剖面结论应逐层报。
