# E168：对齐的专家能不能跨初始化互换（2026-10-31）

- **状态：** PLANNED（预注册；v2 修订见下；等 E167 终点 checkpoint 与终点 R4 后运行）
- **类型：** PILOT（E167 决策表“T_D ≥ 天花板 30%”分支的后果检验）
- **对应：** P34；E167
- **问题（一句话）：** 不同初始化训练出的 MoE 里，按功能指纹一一对齐的深层专家，是不是“做同一件计算”——把 seed B 的对应专家换进 seed A，能补回 A 失去自己这个专家时的损失吗？还是只在“对什么输入有反应”上对应、计算本身不可互换？

## 为什么要做
E167 到 1.6B token 时，深层（L10–11）扣掉词身份与几何后的路由一致已达只换顺序天花板的 66%，800M 的逐专家功能指纹对齐相关 .39–.50（随机 ≤ .15）。这些都是“统计上像”。导师问的“同样的专家对应”最强的含义是计算上可互换；这一步把对应从相关推进到干预后果，同时决定论文能说多强的话。

## 设置
- **模型：** E167 终点 checkpoint（3,999,793,152 token）。接收者 A ∈ {I0D0, I1D0, I2D0}；供体 B：
  - 只差初始化：A 的同顺序异初始化 run（I0D0←I2D0、I1D0←I3D0、I2D0←I4D0、I0D0←I5D0、I1D0←I4D0，共 5 对，A100/RTX 交叉各有）；
  - 只差顺序（天花板）：I0D0←I0D1、I1D0←I1D1。
- **层：** L6–L11（E167 中跨初始化对应明显的层）；L2–L3 作为对应弱的对照层。
- **对齐：** 用 E167 终点 R4 的 drop 指纹，在 UD cal 半上做层内 Hungarian（与 E167 analyze_functional 完全相同），对齐在本实验前冻结并存档。
- **基底映射（全局、与专家无关、不看任何专家输出）：** A 与 B 的残差流基底不同，必须先映射。对每层 l，在 Dolma 校准片段（与评估文本不相交）上用岭回归拟合：
  - M_in：A 的第 l 层 MoE 输入（归一化后）→ B 的第 l 层 MoE 输入；
  - M_out：B 的第 l 层块输出残差 → A 的第 l 层块输出残差。
  同一对 (A,B,l) 的所有专家共用这两个映射；匹配专家与随机专家用同一映射。**不按专家拟合**，避免用 A 自己的专家输出“教”移植专家（E75 的教训）。
- **干预（A 的路由不变，只替换槽位 e 的计算）：**
  1. self：A 自己的专家 e（ΔNLL=0 的数值核对）；
  2. drop：去掉 A 的专家 e，选它的 token 改走第 k+1 名（E167 R4 定义）；
  3. matched：y_e = M_out · E_B,π(e)( M_in · x )，π 为冻结的对齐；
  4. random：同上，但 π 换成随机置换（5 个固定种子）；
  5. self-through-maps：A 的专家经 A→A 映射（单位阵）——映射流程的地板；
  6. stitch-whole-layer：整层用 M_out · MoE_B(M_in x) 替换——映射本身的保真度参照。
- **评估文本：** Dolma 留出 256 条 × 1024 token（文件与训练、校准都不相交）；另报 UD 全部文本。
- **读数：**
  - 主读数：**恢复率** R(e) = [ΔNLL_drop(e) − ΔNLL_cond(e)] / ΔNLL_drop(e)，只在 ΔNLL_drop(e) 超过噪声地板 3 倍的专家上计算；报告每层 matched 与 random 的 R 分布及中位数。
  - 次读数：只在路由到 e 的 token 上的局部 ΔNLL；首 token 完整词表 KL。
  - 所有专家、所有条件全部报告，不挑专家。

## 阳性对照
- self 与 self-through-maps 的 ΔNLL 必须为 0（±数值地板）；否则修代码。
- stitch-whole-layer 的 ΔNLL 必须明显小于把整层置零的 ΔNLL；若映射连整层都接不上，本实验无法解读（见决策表）。
- 只差顺序的对（同初始化）预期恢复率最高，作天花板。

## 噪声地板 + MIE
- 地板：同一模型两次前向（fp32 累加）逐 token 差为 0；ΔNLL_drop 的专家间分布与 5 个随机置换的 R 分布给出“随便换一个别人的专家”能恢复多少。
- 最小有意义效应：matched 的层中位 R 比 random 高 ≥ .2，且 CI（按专家 bootstrap、按对汇总）不含 0。

## 混杂审计
- 基底映射泄漏目标信息：已控制（映射全局、只用隐状态，不用任何专家输出；matched 与 random 同映射）。
- 对齐过拟合：已控制（对齐用 UD cal 半，评估用 Dolma 留出）。
- 随机专家的输出量级不同：部分控制（另报把 random 输出按 matched 的 RMS 归一的版本）。
- 硬件：已控制（A100/RTX 交叉的对单列）。
- 只测 3 个接收者：未控制（算力），在结果中写明。

## 决策表（跑之前写）
- stitch-whole-layer 失败（ΔNLL ≥ 整层置零的一半）→ 线性映射不足以对齐，**不解读专家移植**，改报“对应只在统计层面可测”，考虑非线性映射作为单独实验。
- matched 中位 R ≥ .5 且显著高于 random，并达到只换顺序天花板的 ≥ 50% → 深层专家的对应是**计算上的**：不同初始化学到可互换的专家（在线性基底变换下）。这是 E167 的最强结论，进入条件地图（共享专家/粒度）与头的同类检验。
- matched 显著高于 random 但中位 R < .2 → 对应主要在“响应什么”而非“计算什么”；分工的划分重现、计算实现不重现。
- matched ≈ random → 功能指纹对齐不意味着可互换；撤回“功能对应”的强读法，只保留路由层面的结论。
- 只在部分层成立 → 报告层地图。

## 修订 v2（2026-10-31 16:20，任何正式数据之前；起因是 POST-HOC 冒烟）
- **冒烟（1.6B checkpoint，第 10 层，用路由指纹对齐，32 条评估窗口；只检代码，不是结果）：** self 与 self-through-maps 的 ΔNLL 均为 ~1e−7（数值精度内为 0）✓。但回归式线性映射太弱：同初始化对（I0D0←I0D1）M_in R² .65、残差 M_out R² .67，整层拼接 ΔNLL .052，而整层置零 .085；不同初始化对（I0D0←I2D0）R² .59 / .62，整层拼接 .068，几乎和置零一样。把 M_out 改为拟合两模型 MoE 总输出（R² .57 / .44）结果相同。按本卡决策表，这种映射下移植**不可解读**。
- **修订：** 基底映射改为模型拼接（Bansal et al. 2021）的低容量做法：每层 M_in、M_out 各一个仿射映射，以回归解初始化，在 Dolma 校准窗口上**以 A 的语言建模损失训练整层拼接**（A 的其余参数与 B 的 MoE 冻结），所有专家、matched 与 random 共用同一对映射。映射训练不看单个专家，也不看评估文本。
- **新增前置门槛：** 拼接后整层 ΔNLL 必须 < 整层置零的 50%，才进入专家级比较；否则报告“线性拼接不能对齐这一层”并停在这里。
- 其余读数、对照与决策表不变。冒烟中 matched/random 的恢复率不作任何解读（对齐用的是路由指纹而非终点 R4，映射也不合格）。
