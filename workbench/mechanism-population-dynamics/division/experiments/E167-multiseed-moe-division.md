# E167：分别训练的 MoE，会不会自发分出同一套专家分工（2026-10-31）

- **状态：** RUNNING（训练准备中；跨 seed 读数尚未取得）
- **类型：** PILOT（新线第一个决定性实验）
- **对应：** P34（导师原问：独立训练的分工是否重现；此前没有独立训练数据）
- **问题（一句话）：** 同架构、同数据、同顺序、只换初始化训练的小型 MoE 语言模型，扣掉“同一个词去同一个专家”和“同样的隐状态几何怎么切都相似”之后，专家对语言的分工是否仍跨 seed 重现？它相对“同初始化、只换数据顺序”的天花板在什么位置，在训练的什么时候定下来？

## 设置
- **模型（自训，`division/scripts/moe_model.py`）：** OLMoE 结构缩小版。12 层，d=768，12 头，每层 MoE：64 个 SwiGLU 专家（ffn 384），top-8，softmax 路由不重归一化，无共享专家；RMSNorm、QK-norm、RoPE；不共享输入/输出嵌入。总参数约 7.5 亿、激活约 1.5 亿（含嵌入）。dropless（padded bmm，不丢 token）。
- **训练（`train_moe.py`）：** AdamW(0.9,0.95)，lr 6e-4，2000 步 warmup 后 cosine 到 10%，wd 0.1，梯度裁剪 1.0，负载均衡 0.01，router z-loss 0.001；另加 DeepSeek-V3 式选择偏置平衡（只改选专家、不改门值，步长 1e-2；不加时深层在 lr≈1e-5 就出现单专家接收几乎全部 token，见下方实施记录）；每步 128×2048 token；bf16 autocast、fp32 主权重；每个 run **40 亿 token（15258 步）**。
- **数据：** Dolma v1.7 按官方配比流式取约 60 亿 token（`prepare_data.py`，OLMo/OLMoE 分词器），训练/留出按文件分开。窗口为不重叠 2049 token 片段，`data_seed` 只决定窗口顺序。
- **run（第一批 8 卡；fvcrc21 有 2 张卡被其他项目占用，实际为 RTX PRO 6000 ×6：fvcrc20 GPU0–3、fvcrc21 GPU2–3；A100 ×2：fvcrc11 GPU0–1）：**
  - I0D0…I5D0：6 个独立初始化，同一数据顺序 → 15 个“只差初始化”的对；
  - I0D1、I1D1：同初始化 I0/I1、换数据顺序 → 2 个“只差顺序”的对（天花板参照），以及“两者都不同”的对。
  - 硬件分配：I0D0/I0D1/I1D0/I1D1 在 fvcrc20，I2D0/I3D0 在 fvcrc21，I4D0/I5D0 在 fvcrc11（A100）。同初始化的对在同一硬件上；跨硬件对另报，用于检查硬件是否影响分工。
- **checkpoint：** 0、25M、50M、100M、200M、400M、800M、1.6B、3.2B 与终点（对数间隔，用于看分工何时定下）。

## 读数（在看到跨 seed 数据之前固定）
所有比较对专家编号置换不变；主分析为同层对比，全层对矩阵另报。
- **R0 前置：模型里是否有分工。** 每层把所有专家输出换成专家均值（E134 的“均匀分量”）与“第 1 名换第 9 名”（E121 候补顶替）的留出 ΔNLL。参照：原生 OLMoE L9 均匀替换 .064；E130 的受控平台只有 .0025–.0032（当时被判定为无分工）。
- **R1 路由划分一致 T_ctx：** UD English EWT（test + train 前 4000 句，按文档拼段），每个词取覆盖其最后一个字符的 token。路由核 K(i,j)=|S_i∩S_j|/k。只取同一词形（小写，≥6 次出现，每词形最多 40 次）的出现对，在词形内减去平均 K，再跨模型求相关。这样“同一个词去同一个专家”的一致被精确扣掉。
- **R2 扣掉几何 T^D：** E120 已验证的 N1 零假设（保留路由器读出子空间与奇异值，在子空间内随机旋转并重拟合偏置以匹配负载，32 次）。D=K−E_null[K]，同样在词形内中心化后跨模型相关。另报 T^h（隐状态中心化余弦核的同样统计，“表示本身多相似”）与同一组隐状态上 k-means 换初始化的可重复性。
- **R3 词汇层一致 T_lex：** 词形平均路由向量的核相关（“自然的一致”，作为参照报告）。
- **R4 功能分工：** 每个专家的功能指纹 = 在留出文本上禁用该专家（改走下一名）后，按 UPOS × 位置类别分组的平均 ΔNLL 向量。校准半集上做 Hungarian 对齐，留出半集上算对齐后的相关；报告对齐专家数与相关分布。
- **R5 注意力头（同一批模型）：** 每个头的角色分数（induction、previous-token、sink 等，沿用 heads 线 E59 定义）与消融 ΔNLL 指纹，用与 R4 相同的对齐/天花板方法 → “显式模块（专家）与隐式模块（头）谁更可重现”。
- **形成过程：** R1/R2/R4 在每个 checkpoint 上计算，看跨 seed 一致何时出现、何时定住。

## 阳性对照
- 同一模型的两个不相交锚点半集：T_ctx 的信度上限。
- I0D0 vs I0D1（只换顺序）：天花板；若天花板本身 < 0.3，先检查测量（对齐、采集），不解释跨 seed 结果。
- 采集核对：自算 top-k 与前向路由一致率 100%；词对齐抽查 50 例。

## 噪声地板 + MIE
- 词形内打乱出现顺序的置换零点（期望 0，200 次）；按词形的聚类 bootstrap（1000 次）给 CI。
- seed 层面：15 个只差初始化的对共享 6 个 seed，不当 15 个独立样本；按 seed 做 jackknife。
- 解释看“在地板与天花板之间的位置”，不设固定通过线（P18 教训）。

## 混杂审计
- token 身份：已控制（词形内中心化）。
- 隐状态几何：部分控制（N1 有假设；另报 T^h、k-means）。
- 数据顺序：已控制（初始化对同顺序；顺序效应由 D1 单独测）。
- 硬件非确定性：已控制硬件类型（8 张同型号卡）；同 run 重复未做，天花板用 D1 代替。
- 训练不稳定 / 路由崩塌：未控制，如实报告每个 run 的负载、死专家、留出 CE；不筛 seed（R5 规则）。
- 欠训练：报告 held CE 的 seed 间范围；形成过程分析本身覆盖不同训练量。
- 小规模能否代表大模型：未控制；结论限定在此规模，R0 给出与原生 OLMoE 的量级比较。

## 决策表（跑之前写）
- R0 所有层均匀替换 ΔNLL < .01（与 E130 平台同量级）→ 这个规模没有可比的分工；放大一次（更大模型或更长训练），不把跨 seed 数字解释为分工。
- T^D 的 CI 排除 0，且达到天花板的 ≥30% → 存在超出几何的规范分工：做专家移植后果（对齐专家从 B 移入 A 的 ΔNLL，对比随机对齐）与条件地图（层深、共享专家/粒度）。
- T_ctx > 0 但 T^D ≈ 0 → 一致由共同几何解释；接着看 T^h 是否跨 seed 收敛，把“分工 = 表示的切分”定量化。
- T_ctx 的 CI 含 0 → 扣掉词身份后分工不重现；看哪些层/哪类专家例外，并与头对比。
- 只在部分层成立 → 画“哪部分分工是普遍的”地图。
- 以上都不是关线条件；所有结果并列报告。如果更有意思的现象出现（例如形成时间的规律），按其信息量决定是否转向。

## 实施记录（2026-10-31，训练开始前）
- 数据：`prepare_data.py` 得到训练 6,000,521,329 token（60 个分片前缀，按 Dolma v1.7 配比）、留出 30,117,955 token（18 个分片，文件不相交）；manifest 含逐文件 SHA。
- 专家计算：padded bmm 在负载不均时显存爆满；改为“按负载排序分 8 桶、每桶各自 padding”，并用 split/cat 避免反向时的整块零填充；与逐 token 朴素实现差 2e−9，梯度差 1e−7。`torch.compile` 注意力和归一化后约 6.6 万 token/s。
- 负载平衡：只用 0.01 负载损失时，初始化后深层隐状态共享一个大方向，几乎所有 token 选同一组专家（maxload≈8/8），并在 warmup 中持续；加选择偏置（1e−2）后约 200 步降到均值的 2 倍左右。这是训练配方的一部分，所有 run 相同。
- **测量阳性对照（POST-HOC，未训练的初始化模型）：** 两个不同初始化、尚未训练的模型之间，原始路由一致 T_ctx 在第 0 层为 .682 [.671,.694]、第 4/8 层约 .32–.33，T_h 为 .99/.81/.79；扣掉 N1 几何后 T_D 为 .005 [−.004,.015]、−.004、.048 [.042,.055]。同一模型对自身全部为 1；词形内置换零点约 ±.01。也就是说，**不扣几何的跨模型“一致”在完全没学习时就很大**，正是导师说的“自然的一致”；N1 扣除后基本归零。这给出了 T_D 的地板，后续训练终点的 T_D 应与它比较。
- 分析时 MoE 合并改用 fp32 累加（只在 eval 模式），同一输入两次前向逐 token 差 0；训练数值不变。
