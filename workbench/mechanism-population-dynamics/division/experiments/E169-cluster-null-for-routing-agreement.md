# E169：簇零假设——跨 seed 的路由一致有多少是共享几何的自然聚类（2026-11-03）

- **状态：** 采集 DONE；分析 L11 / L1 / L0 已出（结论见下），其余层在后台逐层补入 JSON
- **类型：** CLAIM（决定 E167 主读数 T_D 的含义）
- **对应：** P34；E167 §R2 里写了但没做的“同一组隐状态上 k-means 换初始化的可重复性”；[REVIEW_2026-11-03](../REVIEW_2026-11-03.md) §1.4 / §4.1 C2
- **问题（一句话）：** E167 的 N1 零假设扣的是“同一读出子空间里随机切”的一致。如果训练后的路由器倾向对准隐状态里的簇，而两个 seed 的几何几乎相同（T_h ≈ .95），那么“对准同样的簇”也会产生跨 seed 一致，N1 不会扣掉它。问：用隐状态的自然聚类（k-means）作为“几何决定的切法”，它跨 seed 的一致是多少？真实路由器的跨 seed 一致比它高、相当、还是低？
- **设置：**
  - 模型：E167 终点 checkpoint I0D0、I1D0、I2D0、I3D0（只换初始化，6 对）、I0D1、I1D1（天花板 2 对）；地板 I0D0 / I1D0 的 step 0。
  - 采集（`scripts/capture_hidden.py`，每模型一次前向，几分钟）：每层 MoE 输入处的隐状态 H（UD 全部有效锚点词 + cal 词，fp16），以及每层路由矩阵 W 与选择偏置 b。文件 `~/mechpop_cache/e167_analysis/hidden/<run>__ckpt_<tokens>.npz`（约 1.6 GB/模型，不进 git）。
  - 分析（`scripts/e169_cluster_null.py`，CPU）：每模型每层，在 cal 词的 H 上拟合 k-means（K=64，8 个 k-means 种子），锚点词取最近 8 个中心作为“top-8”，得到与 E167 相同形式的共路由核 C_km；在 E167 预登记的同词形词对上词形内中心化。两种空间：(i) 原始 768 维；(ii) 该模型自己的路由读出子空间（W 行中心化后的右奇异向量，与 N1 同一子空间）。
- **读数（看到跨模型数之前固定）：** 全部用 E167 的 T 统计（词形内中心化后的跨模型相关）：
  - T_km,self：同一模型两个 k-means 种子之间（几何自然聚类自身的稳定性）；
  - T_km,cross：模型 A 与 B 的 k-means 之间（只换初始化 / 只换顺序 / 地板）；
  - T_router,km：同一模型真实路由与其 k-means 之间（路由器离自然聚类多远）；
  - T_ctx 复算：由 H、W、b 重算真实路由的跨模型一致，须与 `routing_*.json` 一致（采集核对）；
  - T_Dkm：以 E_km[C_km]（8 个种子平均）为零假设的残差 D_km = C − E_km[C_km]，跨模型相关，与 T_D 并列。
- **阳性对照：** T_ctx 复算与 E167 一致（差 ≤ .01）；同一模型同一 k-means 种子自比为 1；step-0 模型的 T_km,cross 作为地板。
- **噪声地板 + MIE：** k-means 种子方差（8 个种子）；按词形的聚类 bootstrap。不设门槛，读相对位置。
- **混杂审计：** K 的选择（固定 64 = 专家数，另报 K=16、256 作敏感性，POST-HOC 标注）；k-means 不均衡负载（报告簇大小分布；不做平衡）；fp16 存储（对相关无影响）；只用终点（形成过程不在本卡）。
- **决策表（跑之前写）：**
  - T_router,cross（=T_ctx .63，L11）≈ T_km,cross 且 T_km,cross ≈ T_km,self → 分工 = 共享几何的自然切分；E167 的 T_D 不能解释为“学习选出的分工”，叙事转为“几何决定切法，切法的跨 seed 一致就是几何的一致”。
  - T_router,cross 明显高于 T_km,cross → 训练选出的切法比几何的自然聚类更跨 seed 一致；T_D 的读法成立，且可以把“超出自然聚类的部分”作为主数。
  - T_router,cross 明显低于 T_km,cross → 训练选出的切法比几何允许的更偶然，初始化印记比 T_D 显示的更重。
  - T_km,self 很低（k-means 自己都不稳定）→ 几何没有唯一的自然聚类，N1 的“随机切”接近正确的零假设。
  - 都不是关线条件；三种结果都进入报告。
- **算力预算：** 采集 8 个 checkpoint × 约 3–5 分钟，单卡；分析 CPU。**实际：** 采集 fvcrc13 GPU0（A100，启动时空闲；启动后他人的 vLLM 任务占满四卡，本进程约 4 GB 共卡运行，未迁移），8 个 checkpoint 共约 19 分钟（72–190 s 各）；分析在 fvcrc20 CPU。

- **读法（L11）：**
  1. 几何的自然聚类是跨 seed 共享的：k-means 跨初始化 .79，和同一模型换 k-means 种子的 .86 接近（比值 .92）。
  2. **真实路由器不是这个自然聚类**：路由器与自己模型的 k-means 只有 .49（读出子空间 .65），远低于 k-means 自身的 .86。所以 §1.4 担心的“N1 扣不掉‘对准同样的簇’”并没有发生——路由器没有对准簇。
  3. 路由器跨初始化 .65、同初始化 .72（比值 .90），与 k-means 的跨 seed / 自身比值（.92）相当。绝对值上路由器低于 k-means，但两种核的平滑度不同，绝对值不可直接比。
  4. （补充，L2–L8 出来后）k-means 期望零假设的地板并不归零：未训练模型对的 T_Dkm 在 L2–L5 为 .22–.30，与训练后只换初始化的值（L5 .21、L3 .20）相当，L8 以上才拉开（.16 对 .29 / .56）。N1 的地板各层都 ≈ 0。所以 k-means 零假设在中浅层没有判别力，N1 是校准得更好的那个。
  5. 以 k-means 期望为零假设的残差 T_Dkm 跨初始化 .56、同初始化 .64（比值 .87），地板 .17；以 N1 为零假设的残差 T_D 为 .33 / .45（比值 .73），地板 ≈ 0。N1 扣得更多（B 在模型内解释 C 方差的一半，k-means 期望只解释约四分之一），所以 **T_D 是两个几何零假设里更保守的数**。
- **附：N1 残差的蒙特卡洛信度（`scripts/e169_n1_reliability.py`，`results/e169/n1_reliability_3999793152.json`；L11 先出，L8 / L5 / L2 随后）。** 用两组独立的 32 次抽样重算 N1 期望：同一模型两组残差的相关 rel_D = .968，两组期望的相关 .956；重算的期望与 E167 采集的（同种子）相关 .956，C 相关 .988（差别来自 fp16 存储的隐状态）。跨模型 T_D：32 次抽样 .302 / .447（只换初始化 / 只换顺序），两模型用不同抽样种子 .300 / .448，64 次抽样 .307 / .456，E167 采集 .298 / .448。**结论：零假设的蒙特卡洛噪声只占残差方差约 3%，把抽样加倍 T_D 变化 < .01；天花板 .44 不是测量噪声，是训练之间真实的分叉**（是非确定性还是顺序效应由 E171 回答）。
- **按决策表：** 不是第一分支（路由器一致 ≠ 自然聚类一致，且路由器不对准簇）；第二、三分支的区分靠绝对值，而绝对值受核的平滑度影响，不能判定；可以确定的是：两种几何零假设之后都剩下跨初始化可重现的残差，比例 .73（N1）到 .87（k-means）。E167 主读数 T_D 的解释保留，并以 N1 为主（更保守）。
