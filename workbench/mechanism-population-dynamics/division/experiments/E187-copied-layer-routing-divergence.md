## 定义
- 第 l 层路由器输入 h_l = g_l ⊙ x̂_l（g_l = post-attention RMSNorm 增益，x̂_l = 单位 RMS 残差流）；路由器 T_l: x → top-8(W_l x)（无偏置）。**有效路由器** = W_l diag(g_l) 作用在 x̂ 上。增益随拷贝变化（已知跳变），所以每个交叉套用读数报两种归属：**主口径**把增益算进路由器（交换路由器时连同 g 一起换，x̂ 由 h / g 精确恢复）；**副口径**把增益算进隐状态（直接把原始 h 喂给另一层的 W）。
- **专家对应 π_{l→m}：** 路由器行（中心化：减去 128 行均值，因为 softmax 对公共平移不变）的**有符号**余弦上做匈牙利配对——**只用权重，不用路由结果**（避免循环）。稳健性：(a) 未中心化 |cos|（E185x 口径）；(b) 专家权重（gate/up/down 草图拼接）余弦上的匈牙利配对；报两种配对的一致比例与在 (b) 下的一致率。
- **一致率：** top-1 一致 = 1[top1_l = π(top1_m)]；top-8 重合 = |S_l ∩ π(S_m)| / 8。
- **分解（拷贝对 m = l+12、l+24；参照 lag 1 / 11 / 13）：**
  - O  观测：T_l(h_l) vs T_m(h_m)
  - H  只有隐状态漂移（同一路由器）：T_l(h_l) vs T_l(h_m)（主口径 h_m 换成 g_l ⊙ x̂_m）
  - R  只有路由器漂移（同一输入）：T_l(·) vs T_m(·) 作用在同一个 x̂_m 上（主口径各带自己的增益）；另报作用在 x̂_l 上的版本 R′（两条路径，非加性分解，二者都报）
  - 一致率不可加，不做"份额"分解；报 O、H、R、R′ 本身和 1−O、1−H、1−R 的并列。
- **几何地板（对手：一致只是因为 h_l 与 h_m 相似）：** 同一个随机路由器作用于 x̂_l 与 x̂_m（同一增益 g_l）的一致率，三族各 8 draw：N_A（W_l·Q，Q 为 O(2048) Haar）、N_B（N1 = W_c V Q Vᵀ，偏置在 x̂_l 的路由器输入上拟合到 T_l 的负载）、N_G（iid 高斯行，行范数匹配 W_l）。对手的读法：若 O ≤ 地板，观测一致率可由隐状态相似单独给出；若 H > 地板，训练路由器读的方向比随机方向更守恒。
- **无标签对照（与 C23 同类读数）：** 在 E184 英语存储上算同 token 共路由的层间相关 T_ctx（类型内中心化）与 T_D（减去 8 个 N_B 的期望共路由），拷贝对 vs lag 1/11/13/24；类型内出现置换地板。这一读数不依赖专家配对。

## 哪些结果会改变读法（不是决策表）
1. **R 接近 1、H ≈ O**（路由器几乎没变、分歧主要来自输入漂移）→ "继承"的是路由器；分歧是深度角色改写了隐状态。**H 接近 1、R ≈ O** → 输入近似不变，路由器重学了。两者都远低于 1 → 两边都漂，如实报两条路径。
2. **O 不高于共享随机路由器地板**（任一族）→ 观测一致率可由"拷贝层输入相似"单独给出，不能称"路由继承"；**H 高于全部地板 draw** → 训练路由器偏读守恒方向。
3. **一致率集中在低 H(e|id)、句首或高频 token 上** → 继承的主要是词表查表部分（与 E185 §21-1 词表锐化一致）；若在 H(e|id) 各分位持平 → 继承不限于词表部分。
4. **配对专家余弦 ≫ 注意力余弦**或相反 → 写"谁漂得多"；路由器与专家同量级 → 二者一起漂。若专家权重配对与路由器行配对一致比例低（< .5）→ 路由器对应关系与专家对应关系脱节，O 的解读要附带这一条。
5. **谱系**：等速假设下给出哪一种拓扑最合适；三对差距小于草图误差 → 写"不可判定"。
6. **Base**：Base 的 O 与 Instruct 差 < .03（逐对）→ 后训练不改变继承；Base 的复制余弦与 Instruct 的差值同报。
7. **与 C23**：拷贝对的 T_D 落在我们自训平台 init 对（L11 .19–.25）与重跑上限（.50）哪一侧，只并列，**不换算成同一比值**（设置不同：拷贝对共享初始化与前期训练、角色不同；C23 的对是同角色、不同初始化）。

- **读法 4（对手假说，按预登记）：** top-1 的 O 在 12 个块内位置中有 9 / 12 / 7 个（三个块对）不高于三族共享随机路由器 8 draw 的最大值；按均值看 O 高于三族均值 .01–.12。top-8 的 O 只在 2 / 5 / 0 个位置不高于地板最大值。所以**按 top-1，观测一致率的水平可以由"一个共享的路由器作用在相似的残差流上"给出，不能单凭 O 称为"路由继承"**；继承体现在 R 上（.53 vs .15）。H 高于地板最大值的位置数拷贝对 8 / 0 / 7，非拷贝 lag 11 / 13 为 8/25、9/23——训练路由器偏读守恒方向不是拷贝专属。

- **非加性残差（未登记，POST-HOC 观察）：** 块内位置 6–7（第 12–13 → 24–25 层、12–13 → 36–37 层）O 高于 H 与 R 二者（例 12→36：O .517，H .344，R .334）：路由器与它的输入**一起**漂移、互相补偿，token→专家的映射比任一边单独保留得多。这正是 E185 的"熵塌缩只认 token"层（块内 5–7）。同时 lag 1 的 O 在块内位置 5（第 11→12 层等）有尖峰（.36–.42，其余 .05–.25）：查表层之间即使不是拷贝也按 token 一致，所以位置 5–7 的拷贝一致率有一部分是"查表层趋同"而非继承。

### (ii) Base 与后训练
- 权重 lag 检验：Base 的 q / o / v 展平余弦 lag 12 .257 / .366 / .479、lag 24 .111 / .197 / .299，其他 lag max |cos| .001；Instruct .256 / .364 / .477、.110 / .196 / .298、.001。**复制在 Base 上完全一样**（复制发生在预训练中，与后训练无关）。

### (iii) 与"分工由初始化决定多少"（C23）的对照——谨慎
- 这里的"共同初始化"不是随机初始化，而是**一个已训练过的 12 层块**（复制时刻未知），之后各自在不同深度训练到终点。R = .53–.54（top-1）/ .70–.73（top-8）是"共同来历在终点还剩多少"的路由器侧读数，非拷贝层 .15 是"无共同来历"的对照。
- C23（自训 8 亿 token，64 专家 top-8）的 init÷重跑比值 .44–.53 是**无标签共路由相关 T_D 的比值**，读数和设置都不同（同一层同一角色、不同随机初始化 vs 同配方重跑）。同式读数（`e187_e184.py`，E184 英语 8.6 万 token，6519 个类型、25.2 万个同类型出现对，类型内中心化，减 8 个 N_B 的期望共路由）：

- **匈牙利配对在拷贝对上 99.9–100% 就是同编号专家**：复制后专家没有被重排（与 Kilian 的"同编号专家 12 / 24 层后仍高活跃"一致），这也是专家对应关系的阳性对照——O / R 的配对不是估计出来的。

### (v) 哪些 token 保留继承的路由（E184 英语只有 O；toksub 有 O/H/R）
- **几乎是平的。** E184 英语 lag 12（24 对平均 O .429，top-8 .676）：H(e|id) 低 / 中 / 高三分位 .459 / .396 / .400（覆盖 56% token）；逐 id Spearman(H(e|id), id 一致率) −.21；频率五分位 稀有 .463 → 高频 .388（**稀有 token 反而略高**）；字母 / 非字母 .433 / .409；UPOS .36（PUNCT、PRON、DET）到 .48（ADJ、INTJ、NUM、PROPN）。lag 24 同形（.334；低 H(e|id) .381 vs 高 .306）。toksub 20 语：字母 / 非字母 O .470 / .474，频率五分位 .46–.48，文字 .43（阿拉伯、泰）到 .54（泰米尔）；H、R 按类同样平。
- **唯一的大效应是句首**：位置 0 的 O .83（E184）/ .83（toksub，H .99）——即 E185 已知的"句首 token 全部去同一个专家"，两份拷贝都保留了它。最高一致的 id 是句首大写词（`The` `This` `In` `Great`，.81–.83），最低的是句中代词与功能词（` This` ` It` ` don`，.28–.30）；见 `results/e187/e184_examples.md`。
- [POST-HOC] 类型层面（≥ 30 次的 283 个 id 的众数专家）一致率 lag 12 .49、lag 24 .39，与逐 token 的 .43 / .33 相近：继承的不只是"每个 id 一个专家"的查表。（同表里的"两层都落在 id 众数专家的 token 比例 .07"分母含未覆盖的 id，不可用。）
- 按预登记读法 3：**继承不集中在词表驱动的 token 上**（低 H(e|id) 只高 .06，高频反而低）；与 E185"词表锐化处处"不矛盾——锐化是 T 相对几何的倍数，这里是拷贝之间的一致。

### (ii′) 对"分工由初始化决定多少"的回答（公开模型，一个模型、一种复制）
- 一个已训练的 12 层块被复制成三份、在不同深度训练到预训练结束后：**给同一输入，路由器仍有 53–54%（top-1）/ 70–73%（top-8）的 token 送到同编号专家**，非拷贝层 15% / 36%；路由器行余弦 .84，注意力 q 只剩 .37。共同来历在路由器上留得比在注意力上多。
- 但**真实路由的一致率（O .47）有一半是残差流共享给的**：同一个随机路由器在相隔 12 层的隐状态上就有 .40–.46，非拷贝层的 H 也有 .50–.53；top-1 的 O 在多数块内位置不超过共享随机路由器的地板。无标签读数里拷贝专属部分也只有 T_D .38 vs .22。
- 所以对导师的问题，这个自然实验给的是两句话：(a) 路由器参数对共同来历的记忆很长（全程预训练后仍是非拷贝层的 3.5 倍）；(b) 但路由器之外，层间共享的残差流本身就决定了相当一部分"哪些 token 被分到一起"，它不依赖复制。

### (vi) 残差（未解释）
1. 块内位置 6–7 的 O 同时高于 H 与 R（路由器与输入共同漂移而互相补偿），恰在 E185 的"只认 token"层；同处 lag 1 非拷贝层也有一致率尖峰（.36–.42）。
2. B2↔B3 的 top-1 O 在 12/12 个位置不高于共享随机路由器地板最大值，B1↔B2 为 9/12、B1↔B3 7/12——B2↔B3 的路由器更像而残差流也更像，O 被地板吞没。
3. 稀有 token 的拷贝一致率高于高频 token（.46 vs .39），与"继承的是查表"相反；未解释（可能是高频功能词的上下文依赖更大，H(e|id) 与频率相关，未分离）。
4. 星形分解的 a2 ≈ .99（路由器）：第二块几乎是第一、三块的"中点"。
