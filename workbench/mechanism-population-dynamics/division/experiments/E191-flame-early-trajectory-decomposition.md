## 三个对手（先验，不是判决表）
- **A 路由器始终先定**：每个检查点 R > H、到达时间 R 早；相邻增量每段 1 − R < 1 − H。
- **B 两阶段（几何先行 → 路由器闩锁 → 几何巩固）**：前段 H ≥ R（或 R′ 最大、1 − R > 1 − H），中段某处交叉成 R > H，之后 1 − H 主导；交叉点 token 数可报。
- **C 同步**：H ≈ R 全程（差在 CI / 地板宽度内），到达时间相近。

## 已知（登记前已看过，视为已知量，不作新发现报）

## 定义（同 E189，改动处标出）
- 增益归属：主口径 T_t(·) = top6(W_t diag(g_t) ·) 作用于 x̂ = h / g；副口径原始 h 喂给 W_t。
- 专家对应：恒等映射；匈牙利配对恒等率照报。
- 一致率：top-1 一致；**top-6 重合 = |S_a ∩ S_b| / 6**。
- **层段**：MoE 层 1–8（Megatron 编号）；**mid 段 = 第 2–7 层**（去掉第一个与最后一个 MoE 层；E189 的 mid 段是 16 层里的 2–11，比例相近，不可逐层对）；逐层全报。
- 分解：O / H / R / H′ / R′ 对终点 F，**两套终点各一遍**：F = iter 5473（衰减后终点）与 F2 = iter 4860（衰减前终点，对应 E189 的 5.1T）。全网格 G(t, s)（10 × 10）、相邻增量、到达时间（归一化 n 越过 .5 / .8，对数 token 轴插值）同 E189。
- 几何地板：N_A / N_B / N_G 各 8 draw，以终点有效路由器为模板，d = 1024 的 Haar；口径同 `e189_decomp.py`。
- 子空间：P_F 行空间（≤ 63 维）内 / 外的相对漂移、cos、CKA；逐 id 均值 / 残差分量；P_t 与 P_F 主角余弦；能量份额（E189 §9 的 P_F / P_t / 随机 63 维）。
- **网格（前一 id / 输入 id 比）**：第 1 层（第一个 MoE 层，对应 E189 第 0 层的角色）10 × 10 全网格 Î(top-1; 前一 id) / Î(top-1; 输入 id)，`e185_lib.mi_marg`；**另报每个 MoE 层的同一 10 × 10 网格的比值**；在主视图（英语）上算，副视图另报对角线。N_B 型随机路由器对角线作几何参照。
- token 类：位置、字母 / 非字母 / 片段、频率五分位、语言、UD 的 UPOS 三类（UD 行由同一 conllu 的词对齐——若对不上则只报覆盖率）。H(e∣id) 三分位不做（E186 atlas 是 OLMoE 分词，不适用）。
- 原始样例：逐 id（≥ 30 次）在 t = 1.13B 与 5.66B 上 O 最低 / 最高各 20、R − H 两端各 10。

## 会改变读法的结果（不是判决表）
1. **A：R 全程高于 H、到达更早，每段 1 − R < 1 − H** → E189 在 20B 看到的 R < H 不是"早期普遍有几何先行段"，而是 OLMoE 特有（或 20B 点的偶然）；放弃"两阶段"说法，"路由器先定"可写成从 ~1B token 起成立（仍只限这个模型族）。
2. **B：前段 H ≥ R（或 R′ 最大），之后交叉** → 两阶段成立；报交叉点（token 数、占总训练的比例）；放弃"路由器从一开始就先定"的措辞，N4 的问句要改成"路由器何时闩锁"；若交叉点相对总训练的比例与 OLMoE（20B–83B 之间，< 2%）相近，记"按比例对齐"，否则记"按绝对 token 对齐"（两种都只是描述）。
3. **C：H ≈ R 同步** → 在这一早期段既不能说路由器先也不能说几何先；放弃两种"谁先"措辞在早期段的使用，只报子空间读数（若 H 远高于 N_A / N_G 而接近 N_B → 子空间说）。
4. **第 1 层网格**：固定隐状态 s 随 t 上升 → 路由器自己找到前一 token 方向；固定 t 随 s 上升而固定 s 随 t 平 → 几何先给方向（E189 第 0 层在 ≤ 335B 的形态）。
5. **衰减段**（4860 → 5473）：若只改 H 不改 R（E189 退火 1 − H .114 vs 1 − R .023）→ "衰减 / 退火只动几何"跨两个模型族成立；若 R 也大动 → 不跨族。两套终点给出不同先后 → 先后依赖终点选择，报两套并以衰减前终点为主。
6. token 类：差异是否集中在句首 / 高频 / 功能词（E189：句首 H > R 持续）。

## 混杂审计（EXECUTION §4）
- **与 OLMoE 不可逐 token 对齐**：分词器不同（pythia vs OLMoE dolma 版 NeoX）、抽样数不同；只比曲线形状与先后，不比绝对值。
- **top-6 vs top-8**：偶遇基线不同，报归一化 n 与打乱期望。
- **共享专家**：残差流每层恒加共享专家输出，路由器只为 routed 部分得梯度；"几何"不全由路由塑造，与 OLMoE 不等同。
- **英语为主**：主视图为英语；非英语只作副视图并标分布外。
- **无 iter 0 / 初始化点**：第一点已是 1.13B token，最早 ~1B 仍删失；不做初始化重建。
- **配方差异**：WSD + DCLM + aux / z-loss、小模型；与 OLMoE（cosine、5T、退火）只比形状。
- **fp16 存储**：一致率上限约 .99；fp32 vs bf16 路由器平局翻转照报（对照 b）。
- **增益归属**：主 / 副口径都报；min |g|。
- **检查点等间距（线性 token 轴）**，与 OLMoE 的对数间距不同；到达时间仍用对数轴插值。

## 结果（跑完后填写；上面内容不改，修改需注明日期）

**执行记录（11-11 12:50–13:37，fvcrc20 GPU 0 一张卡）。** HTTP range 只下 bf16 模型权重（每点 2.6 GB，约 3–4 分钟）→ 在内存里转成 Qwen2Moe → 转存（每点约 90 秒，大部分是 CPU 上的 DCP 读取与转换）→ 删权重；分解在 CPU 上，两个视图并行，每个约 4 分钟。占卡墙钟约 21 分钟（10 次转存，加 540 / 4860 / 5473 三次阳性对照），**按占卡时间计 ≤ 0.35 GPU h，实际 GPU 计算远少于此**。与登记的偏差：(1) 转存不落 HF safetensors，直接在内存里转换（`e191_convert.py` 的 CLI 保留）；(2) iter 540 第一次转存时 RoPE inv_freq 被转成了 bf16，修正后重跑覆盖；同一文本上新旧 loss 相同（4.554），verify(540) 用的是修正前的版本；(3) H(e∣id) 三分位没做（卡上已写）。全部数字在 `results/e191/tables.md`、`summary.json`、`fig_decomp_training.png`、`fig_l1_grid.png`。
