# 路线逻辑审查（2026-11-06 02:10，主会话；不护短）

> 对象：`DIRECTION_2026-11-06.md` §1 的候选命题——"语法骨架可重现到地板，骨架内的专家身份由早期噪声锁定"。每条漏洞标：**致命 / 可修 / 措辞**，和修法成本。按 A（致命或接近致命）→ B（可修）→ C（措辞）排。

## A. 接近致命：不修则命题不成立

**A1 重跑上限只来自 1 对，且来源是硬件非确定性。** 所有"初始化只抹掉一半"的说法都除以 I4D0R 这一个重跑对的 .50。(i) 单对无方差；(ii) 差异来源是 bf16 原子加与 cuBLAS 非确定（FINDINGS §65），换一台机器、开确定性算子，地板可能变。若地板随硬件变，"训练本身只能重现一半"就不是科学陈述。
- 修法：再做 1 个重跑对（同 I0D0 配置，8 亿 token，约 4 GPU h）+ 1 个开 `torch.use_deterministic_algorithms` 的重跑（若 top-k / scatter 支持；否则记录为不可消除）。报告地板的跨对方差。
- 若不修：所有"÷ 重跑"的比值只能写成"相对于一次重跑"。

**A2 "可重现的是语法"可能是已知事实的重述。** 每一篇 MoE 论文都报告专家按词类 / 标点 / 数字分。两个 run 都对词类敏感 ⇒ 词类级分区当然一致。所以"粗粒度可重现"的新信息量取决于：扣掉"两个 run 各自与词类相关"之后还剩多少。
- 检验：以"各 run 独立地与 UD 词类相关"为零假设生成合成配对（保持每个 run 的词类→专家边缘分布，打乱 run 间对应），算其 T_D；若真实 .86 不显著高于此零假设，"骨架可重现"就是重述。纯 CPU，用 E167 缓存。
- 真正新的部分只可能在：(a) 词类以下的层次有多少可重现（.48 → .19），(b) 地板，(c) 时间。论文重心必须放在这里，不能放在"骨架一致"。

**A3 早期锁定是相关，不是因果；且有一个未排除的平庸解释。** 第 100–200 步时 lr 只有峰值 5–10%，而选择偏置均衡（1e-2 / 步）从第 0 步就全速运行。可能是**均衡项先于数据梯度把专家与 token 的对应固定下来**，之后数据梯度只在已定的分配内微调。若如此，"锁定"是均衡算法的性质，不是学习的性质。
- 检验 1：E173 的 lb=0（仍有 bias 均衡）不够，需要**关掉 bias 均衡**（只留 aux lb）的一对，看锁定时刻是否后移。约 8 GPU h。
- 检验 2：Frankle 式分叉（k ∈ {0, 50, 100, 200, 400} × 2 子 run × 2 亿 token，< 20 GPU h）把"第 k 步决定"变成硬判决。
- 没有这两项之前，"锁定"只能写"分开的时刻"，不能写"决定的时刻"。

## B. 可修：影响解释强度

**B1 冻结路由对照的 seed 设计。** FRZ_I0 / FRZ_I1 的路由器随 init seed 不同而不同，所以 FRZ 对的跨 init 一致度低可能只因为两个随机投影不同，而不是"没有路由学习就没有共性"。
- 修法：补一对**共享路由器 seed、专家 init 不同**的 FRZ（约 8 GPU h）。E173 的 FRZ 结果出来后再决定要不要补；若 FRZ ≈ 学习路由，则不需要。

**B2 粒度阶梯的统计解释。** .86 → .48 → .19 已是 init ÷ 重跑的比值，但三级的分母各自只有 1 对重跑；且更细的粒度样本更少、估计噪声更大。
- 修法：对每级报 jackknife 区间；A1 的第二个重跑对同时解决分母问题。

**B3 "语法骨架"的定义循环。** 分解只用了我们标注的 UD 变量（词类、形态、依存、前后词类、位置、体裁）。"数据只压进语法"的准确说法是"在我们测的变量中，可重现的部分由语法变量解释"。语义 / 话题 / 频率以外的结构未测。
- 修法：加至少两个非语法变量（词义簇、话题 / 文档类别已有体裁）进分解；措辞按上面改。

**B4 "现成方法跨 seed 只重现 .73"目前只有一种方法、一个族。** 推广到"已发表的专家分析"是过度。
- 修法：lit-v2 的读数目录 → 在 9 run 上复算 ≥ 4 种（CPU 可做的），每种报 seed 稳定性。这是 B6 偏好的正解，也是最便宜的扩展。

**B5 规模与数据单一。** 12 层 d768、40 亿 token、仅 Dolma 英语。真实 MoE 的专精在数万亿 token 后仍在变。
- 修法：2 个尺寸 × 2 seed × 8 亿 token（约 30 GPU h）给趋势；公开 OLMoE 中间 checkpoint 最早 410 亿 token，不能补早期。无法完全修，只能诚实写限制。

## C. 措辞：不改实验、改说法

- "分工一致度"作为研究对象没有读者；作为仪器（测"什么可重现、何时定下来、单次分析能信多少"）才有。标题与主张按后者写。
- "一致的内容不变、一致度变"若 E173 成立，是对 H_skeleton 的支持，但不是证明；写"与 H_skeleton 一致"。
- 不用"涌现""锁定"之类暗示因果的词，除非 A3 修完。

## D. 审查结论

1. 现有路线**不是逻辑闭环**：A1（地板）、A2（重述风险）、A3（因果）三处都没堵上。其中 A2 是纯 CPU，应最先做，因为它决定"骨架可重现"是不是空话。
2. 若 A2 通过、E173 显示配方改变一致度但不改骨架内容，路线值得继续，下一步按 A1 → A3-检验 1 → B4 的顺序补，总计约 40 GPU h + CPU。
3. 若 A2 不通过（骨架一致 ≈ 独立相关零假设），剩下的可发表内容只有"地板 + 时间 + 单次分析的可信度"，题目要改写成方法学论文；或者按 lit-v2 的"别的方向"清单换题。
4. 以上三条都不依赖"我们已经做了多少"；沉没的 GPU 小时不是继续的理由。
