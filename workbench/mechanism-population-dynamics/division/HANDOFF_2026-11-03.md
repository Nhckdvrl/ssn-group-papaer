### 3.2 根因（要防止重演）

1. **换问题去迁就工具。** “直接回答导师问题需要多次独立训练”这个约束一出现，就去换替代平台（冻结骨干、蒸馏、公开端点），每个平台都悄悄把问题换掉了。根源是曾定下“只用公开成熟 checkpoint、不新训多 seed”。但我们的资源（多卡、弱互联）**最适合的恰恰就是多 seed 的独立单卡小模型训练**。
2. **对象选错且一直不换。** 头线研究的是“哪个编号的头”，这是一个坐标；在置换对称下，独立初始化之间本来就没有对应的编号。四版论文只是换包装。
3. **叙事先行。** 强说法先写进稿件，后被实验撤回。计算组织线的论文标题是抽象叙事，无法证伪。
4. **追残差，越做越窄。** E144→E166 四天 23 个实验，每个都在补上一个结果的漏洞。
5. **止损规则触发了却没执行。** 每次修补都要再加一个条件才能保住结论时就该停（用户规则）。C14 的“已知威胁”一栏比主张本身还长。
6. **人为设门槛。** P18：agent 用没有科学依据的数值门槛（dense + .02 NLL）延后了核心实验。用户原话：“不要总是毫无根据人为设置奇怪的门槛”。
7. **把严谨花在基础设施上，而不是选问题。** 严谨地回答一个不重要的问题，依然不重要。
8. **文档难读。** 自造术语加上层层限定。用户要的是：一个清楚的问题，没有防御性措辞，也没有夸大的二分法或口号。

**头线中站得住、可复用的结论：**
- 层内哪个头担任角色跟随初始化；
- 抽象分工跨 seed 重现（E89），但缺基线——**现在的 E167 恰好可以补上这个基线**；
- 公开套件审计：PolyPythias 的 weight-seed 变体实际没有换初始化，等等。

## 5. 当前实验与结果（division/）

### 5.1 设置（E167，[实验卡](experiments/E167-multiseed-moe-division.md)）

- **模型：** OLMoE 结构缩小版。12 层，d768，12 头；每层 64 个 SwiGLU 专家（ffn 384），top-8，**无共享专家**；总参数约 7.5 亿，激活约 1.5 亿。dropless。
- **负载平衡：**
  - 辅助负载损失 .01，z-loss .001；
  - 加 **DeepSeek-V3 式选择偏置平衡**（步长 1e-2）。不加时深层在 warmup 中路由塌到一组专家。这是配方的一部分，所有 run 相同，但它**可能影响分工本身**，见 §6。
- **训练：** Dolma v1.7 共 40 亿 token（15258 步 × 128 × 2048），lr 6e-4，cosine。
- **run：**
  - I0D0–I5D0：6 个只换初始化（数据和顺序完全相同），共 15 对；
  - I0D1、I1D1：同初始化只换数据顺序，共 2 对，作为**天花板参照**。
  - checkpoint：0、25M、50M、100M、200M、400M、800M、1.6B、3.2B、终点。
  - 终点留出 CE：2.9606–2.9702。
  - I4D0/I5D0 为了释放资源停在约 35 亿 token，**所以终点只有 4 个 D0 初始化（6 对）**；32 亿及以前是全部 15 对。
  - I1D1 在 38 亿 token 处 CUDA 超时，从第 14260 步续训。

### 5.2 读数（在看到跨 seed 数据前固定）

所有读数都与专家编号无关，即对置换不变。
- **R0 前置：** 每层把专家输出换成专家均值后的 ΔNLL。用来确认模型里有分工（受控平台的教训）。
- **T_ctx：** UD English EWT 上，只取同一词形在不同上下文里的出现对，在词形内中心化路由核 |S_i∩S_j|/k，再跨模型求相关。这样就**扣掉了“同一个词去同一个专家”**。
- **T_D（主读数）：** 在 T_ctx 基础上再减去 **N1 几何零假设**：保留路由器读出子空间和奇异值，在子空间内随机旋转，重拟合偏置匹配负载，取 32 次的期望。这样就**扣掉了“隐状态几何相似，怎么切都相似”**。N1 在 E120 上验证过。
- **R4 功能指纹：** 禁用某个专家（改走第 k+1 名），统计按 UPOS × 词内位置的平均 ΔNLL 向量；另有路由指纹 P(expert|类别)。在 cal 半集上做层内 Hungarian 对齐，在 held 半集上评估。
- **E168 v3 逐 token 因果角色（[实验卡](experiments/E168-matched-expert-transplant.md)）：** 每个专家的“禁用后逐 token ΔNLL 向量”（128 条 Dolma 窗口），按窗口两半交叉做对齐和评估。
- **头：** 按查询词类统计 5 个注意力模式特征的指纹，以 step-0 未训练模型为地板。逐头消融指纹的信度太低（−.02–.22），不可用（P35）。

### 5.3 结果

1. **自然一致很大。** 两个未训练的不同初始化模型：T_ctx 第 0 层 .68、深层约 .32；T_D ≈ 0（−.004–.05）。不扣几何就会把“当然会相似”当成发现。
2. **前置通过。** 200M token 起，每层均值替换 ΔNLL .04–.07，与原生 OLMoE L9 的 .064 同量级（受控平台只有 .003）。
3. **深层分工跨初始化重现。** 3.2B，15 对：L11 只换初始化 T_D 为 .298（各对 .262–.350，配对 bootstrap 下界 ≥ .248），只换顺序 .443，比值 .67。按层的比值（L0–L11）：.67 .78 .39 .48 .46 .57 .56 .63 .55 .56 .67 .67。终点（6 对 vs 2 对）的深层均值 .60，L11 .73。“初始化和顺序都不同”的对 ≈ 只换初始化。RTX 与 A100 之间没有硬件效应。
4. **形成过程。**
   - 25M token 时，同初始化只换顺序的 T_D 在 L0 为 .85，随后衰减到约 .1：**初始化的印记早期很强，之后被冲掉**。
   - 只换初始化的一致则从约 0 持续上升。L11 的比值：400M .54 → 800M .62 → 1.6B .66 → 3.2B .67。在同一组 6 对上，16 亿 / 32 亿 / 终点为 .72 / .73 / .73，**已走平**。
5. **分辨率层次**（深层 L6–11，终点，上限比）：
   - 路由词类指纹 .90；
   - 词类损伤指纹 .83（800M、3 对 vs 1 对时为 .70，两个值都报告）；
   - 扣几何的上下文划分 .60；
   - **逐 token 因果角色 .28**：绝对相关只有 .01–.12，天花板对只有 .05–.32，随机上限 ≤ .02；两个天花板对逐层相差 ≤ .03。
6. **线性拼接失败。** E168 v2 想把一个模型整层的 MoE 经仿射映射接进另一个模型：回归映射 R² .44–.67；任务损失训练早停后，整层拼接 ΔNLL .050（同初始化）/ .072（不同初始化），整层置零为 .096。**连同初始化的都没过“< 置零 50%”的门槛**，按止损放弃，作为阴性观察报告。
7. **头与专家的深度规律相反。** 头的注意力模式指纹（1.6B，扣 step-0 地板）比值：第 2–5 层 .7–.9，第 6–7 层（induction 头所在）和最深层较低。按浅（1–4）/ 中（5–8）/ 深（9–11）分组：头 .74 / .54 / .52，专家 .53 / .58 / .63。**这个分组是画图时才定的（POST-HOC），每层原值都已报告。**

### 5.4 噪声与修正记录

- 训练后的模型存在路由分数并列导致的 top-k 翻转：同一输入两次前向，约 0.1% 的 token |ΔNLL| > 1e-3，全文平均 ≤ 2e-6。早先“逐 token 差 0”的说法只对未训练模型成立，已更正。
- 所有作废和更正都写在实验卡里，没有筛 seed。

## 6. 我自己看到的薄弱点（请重点审）

1. **N1 零假设是整个结论的支点。** 跨初始化的隐状态核相似度 T_h 高达 .91–.95（第 0 层 .99），几何确实很像。N1 只模拟“同一读出子空间内的随机旋转”。如果真正的“几何决定”比 N1 更强，例如路由器方向由数据分布的主方向唯一决定，那 T_D 就会高估学习选出的分工。反过来，N1 也可能扣过头。需要更强或替代的零假设。候选：
   - 在 A 的隐状态上拟合“模仿 B 的负载与统计”的路由器；
   - 同一组隐状态上 k-means 换初始化的可重复性。这一项实验卡里写了，**但还没做**。
2. **天花板不是严格上界。** 它是“同初始化、只换顺序”，没有做“完全相同配置重跑”的硬件非确定性上界。比值的含义依赖这个定义。
3. **逐 token 读数的 .28** 可能部分受估计噪声限制：天花板对本身也只有 .05–.32。比值能抵消一部分，但“实现不重现”的强读法要谨慎。另一种解释是**多重可实现性**：功能相当、实现不同。目前还没有区分这两种解释的实验。
4. **头的读数**是注意力模式，不是因果读数。头用的是 1.6B，专家用的是 3.2B。浅/中/深分组是 POST-HOC。“方向相反”目前是**暂定**。
5. **只有一个规模、一种配置。** 无共享专家、64 专家 top-8、带选择偏置平衡。Myth 论文认为负载均衡本身塑造专精，所以**负载平衡方式可能就是一个混杂因素**。
6. **终点只有 4 个初始化。** 天花板 2 对，seed 层面的 n 很小。15 对共享 6 个 seed，不能当成 15 个独立样本。
7. **“会不会被说成理所当然”还没定论。** 一种可能的反应是：深层粗粒度分工一致，不就是语言类别本身决定的吗？我们的回应是：词类层面的一致确实接近“自然”（.90），但我们扣掉词身份和几何后仍剩约 60%，而细粒度只剩 .28。这个层次结构和“头相反”是不是足够有意思，**需要你独立判断**。
8. **理论上有一个可能更有意思的张力：**
   - “Routers Learn Geometry”的正反馈机制预测，对称破缺会锁定早期的随机历史，因此跨 seed 不一致；
   - 我们看到的却是早期的初始化印记**被冲掉**，跨初始化的一致**持续上升**；
   - 而“几何决定论”预测深层应高度一致，实际只有约 2/3。

   两种理论都只对了一部分。是否值得以此为主线，请判断。

## 7. 我看到的候选方向（未排序；请独立评估，不必采纳）

- **A. 条件地图：** 只改 1–2 个最可能改变答案的因素：负载平衡方式（辅助损失 / 选择偏置 / 无）、共享专家有无、专家粒度。直接检验 Myth 的负载均衡命题，也检验结论是否只属于这个配置。
