# 调研 v2：跳出"分工一致性"——相邻领域地图、我们数据里已经有的硬事实、可行的研究空间（2026-11-05）

> 只读分析，没跑实验。上一版（`SURVEY_AND_DIRECTIONS_2026-11-05.md`）推荐的"哪一部分由数据决定、哪一部分由配方和初始化决定"被人审否决：那是归因分解问题，各因素交互、不可分离，可行性低，而且仍然围着"一致性"打转。本版把视野拉到 MoE 之外的七个相邻领域，先画地图，再回头看我们已经有的数据，最后用同一套可行性标准给候选研究空间打分。
> 本版新读 41 篇（精读 14 篇、摘要与关键段落 27 篇），加上 v1 的 52 篇，共 93 篇；逐篇笔记见 `library/themes/moe-routing/SURVEY_SPECIALIZATION_UNIVERSALITY_2026-11-05.md` 第二部分。

## 0. 一页结论

**1. 上一版错在哪。** "数据 / 配方 / 初始化各占多少"是方差分解，三者在训练里耦合，任何分解都依赖模型假设；两个旋钮 × 两个 seed 也撑不起这种分解。更根本的是，它还是"一致多少"的变体，答案天然是 0–1 之间的数，写不成硬话。

**2. 七个相邻领域读下来，一个共同的问题形式浮出来：不是"多少一致"，而是"什么时候、被什么决定、之后还能不能改"。** 稠密网络那边这个问题已经有标准答案和标准实验范式：Frankle 的 instability analysis（同一 checkpoint 分叉、换 SGD 噪声、看终点是否线性连通）给出"ResNet-20 在训练 3% 后就对 SGD 噪声稳定"；Achille 的 critical period 给出"前几个 epoch 决定最终解"；Emergent Modularity 给出"T5 的专家功能在 15% 处定型、神经元 75%"；OLMoE / OpenMoE 给出"路由在 1% 处饱和 60%"。MoE 的路由还**没有人**做过分叉实验，也没有人把"分工什么时候锁死"和"锁死的是什么"分开。

**3. 我们的数据里已经有这件事的一半，而且比文献里任何一条都精确。** 重跑对（I4D0 vs I4D0R，第 0 步逐位相同）第 11 层的分工一致从 2500 万 token 的 .88 掉到 5000 万的 .46，之后 3 亿 token 起到终点在 .42–.52 之间不再变。换成步数：**第 100 步到第 200 步之间**（总共 15,000 步的 0.7%–1.3%），此时学习率只有峰值的 5%–10%（warmup 到第 2000 步），训练损失正从 8.5 降到 6.9（词表均匀分布 10.8，一元分布约 7.5）——即**分工在模型刚开始用上下文预测的那一刻被非确定性噪声定型**。只换顺序的对在第 100 步前就已分开（2500 万处 .27），只换初始化的对从第 0 步就分开（≈0）。三种对都在 2 亿 token 前到达各自的"底"，之后只换初始化的对从 .05 慢慢升到 .22，只换顺序的从 .26 升到 .38，重跑对平在 .45 上下：**噪声决定的部分在前 2 亿 token 内定型并冻结，数据决定的部分在其后 30 亿 token 里慢慢长出来。** 这与 Fehlauer 等人在 PolyPythia 上看到的输出分布"一致 → 急剧分歧 → 缓慢回合"四阶段逐点对应。

**4. 推荐的研究空间：MoE 分工的早期锁定（working title：*Frozen accidents: expert partitions in MoE are fixed by early noise, and only their grammatical skeleton is fixed by data*）。** 一个有名字的假设（锁定），一个对手（分工随训练持续被数据重塑、最终收敛——Platonic 式），一个可区分的预测（从第 k 步分叉的两份拷贝，终点分工一致随 k 阶跃式上升，阶跃在第 100–200 步；对照：几何一致 T_h 全程 ≥ .95），一个机制候选（Dhir 等 2026：top-K 的对称破缺靠有限宽度涨落；Ahrac–Hochwald–Geva 2026：路由器与专家沿同一输入方向累积梯度、彼此锁定），一个旋钮（延迟锁定——路由温度 / 噪声、均衡损失作用域——看数据决定的部分是否因此变大）。全部新训练 **不到 20 GPU 小时**（§4）。它直接回答领域现在争的问题"MoE 专精到底是不是真的"：**专精的"谁拿哪块"是早期事故，"分哪些块"（语法骨架）由数据决定**；Hash Layers（固定随机路由不输学习路由）和 Fan–Messmer–Jaggi（冻结随机路由器 ≈ 学习路由器）的旧结果因此有了解释。

**5. 其余候选（§3）：** S2"分工是不是一个规范自由度"（重跑对内互换路由器，看损失变化——现有 checkpoint 可做，是 S1 的配套）；S3"分工差异是否预测行为差异"（McCoy / D'Amour 式，现有模型可做，但答案很可能是零结果）；S4"分工发育与语法习得阶段"（Sudden Drops 式因果操控，可行但撞 Chen 等 2024 的方法）。放弃：归因分解；Dobs 式"干扰决定分工"假设（在 token 级语言模型里定义不清、难证伪）。

**6. 需要人决定：** (a) 是否接受把题目从"分工一致性"换成"分工的早期锁定"；(b) 是否先做两件不需新训练的事（§4.1：同一 run 相邻 checkpoint 之间的路由 churn；重跑对内路由器互换），再训细粒度早期 checkpoint 与分叉；(c) 旧的"头"读数彻底放下。

### 1.1 训练早期决定论（early-training determinism）

|---|---|---|
| Frankle, Dziugaite, Roy, Carbin, *LMC and the LTH*, ICML 2020 | "instability analysis"：从第 k 步复制两份、换 SGD 噪声训到底、看线性插值误差壁垒 < 2%。ResNet-20 在 2000 步（3%）后稳定，VGG-16 1.5%，ResNet-50 20%，Inception-v3 16%。**训练时长不是原因**（把拷贝重置学习率训满 T 步结果不变）。 | 现成的实验范式与"稳定"的操作性定义。我们要的量不是权重线性连通，而是**分工划分的一致**（T_D），阈值可用重跑上限定义。 |
| Frankle, Schwab, Morcos, *The early phase of NN training*, ICLR 2020 | 前几百步权重分布已高度非独立；符号重置都不行。 | 早期不是"还没学"，是"已经定了很多"。 |
| Achille, Rovere, Soatto, *Critical learning periods*, ICLR 2019 | 早期输入缺陷造成永久损伤，晚期同样缺陷无效；Fisher 信息先升后降 = "information plasticity" 丧失。 | 锁定有一个经典名字和经典机制（连接先建立再固化）。 |
| Zhang et al., *Emergent modularity in pre-trained Transformers*, ACL 2023 Findings | T5 pre-MoE / post-MoE：**专家功能在约 15% 训练步处大体定型，神经元功能 75%**；"先搭粗模块结构、再学细功能"。 | 与我们"分工早锁、功能慢长"同构，但他们只测同一 run 的时间稳定性，没有跨 run、没有分叉。 |
| OLMoE (ICLR 2025)、OpenMoE (Xue et al. 2024)、Ban&Pick (2509.06346) 转述 | OLMoE：1% 训练后 60% 路由决策饱和；OpenMoE：40% 处 80% 稳定；OpenMoE §4.2：token ID 路由"在 warmup 阶段左右就学好并保持"，换数据配比和目标都不变；激活频率被均衡损失"冻结在早期水平"。 | 行业共识是"路由早定"，但全是**同一 run 内**的饱和度，没人问"定成哪种是不是偶然"。我们的重跑对正好回答。 |

| Dhir, Cevher, Vankadara, *Why routers freeze*, ICML/NeurIPS 2026 | 无限宽极限：标准参数化下路由器一步后冻结；μP 下 soft routing 专家对称、永不专精；**top-K 靠有限宽度涨落决定选谁，是隐式对称破缺**。 | 理论上说，"谁拿哪块"由涨落（噪声）决定。我们的重跑对是这条理论在真实语言模型上的第一个直接证据。 |
| Ahrac, Hochwald, Geva, *Routers learn the geometry of their experts*, NeurIPS 2026 | 路由器方向与专家输入权重沿同一 token 方向累积梯度（耦合累加器）；aux 均衡损失把路由器方向相似度抬高近 3 倍、削弱专精；在线 K-means 路由器就够用。 | 锁定的机制候选：一旦某专家接到某类 token，耦合让它越来越"该接"。我们用的 bias 平衡（DeepSeek-V3 式）不给路由器梯度，是他们说"保留耦合"的那一支。 |
| Wang et al., *Loss-free balancing*, 2408.15664 | aux 损失的梯度与语言建模目标"干扰"；bias 平衡不产生干扰梯度。 | 我们的配方 = 微批 aux .01 + bias 1e-2，两者都有；哪一个推动早期锁定，是可以拆的（§4.3）。 |

（词表 50304 的均匀分布 ce = 10.83；英文 BPE 一元分布约 7.3–7.6。I0D0R 到 4 亿 token 为止的损失曲线与 I4D0 逐点相同。几何一致 T_h 在所有对、所有时点 ≥ .86，重跑对 ≥ .95。）

读法：
- **深层分工的"噪声部分"在第 100–200 步之间定型。** 这 100 步里学习率只有峰值的 5–10%，均衡损失刚从 1.25 落到 1.03（接近均衡），损失从 8.5 跨到 6.9——模型刚越过一元分布、开始用上下文。Fehlauer 的"急剧分歧"阶段（Pythia 第 256–2k 步，"开始用上下文、各 seed 用法不同"）就是这个窗口。
- **定型之后不再变。** 第 11 层重跑一致从 2 亿 token 起在 .42–.52 之间，终点 .50；深层均值 .39–.47。它不随后续 30 亿 token 的训练收敛，也不发散。
- **数据决定的部分之后慢慢长。** 只换初始化的对从 2 亿处的 .05–.09 升到 32 亿处的 .30（16 亿后走平）；只换顺序从 .27 升到 .45。两种对增长的那部分，E170 已经分解过：沿词类、依存关系、前后词词类组织，是语法骨架。
- **浅层相反：没有早期锁定。** 第 0 层重跑一致从 .96 持续掉到 8 亿 token 的 .07 再回到 .18；只换顺序 − 只换初始化的差从 .85 收到 .05。浅层路由在 20% 训练前一直在重排。这与 OpenMoE"token-ID 路由早定"看似矛盾：**token 去哪个专家早定，但哪些 token 共享专家一直在变**——两者不是一回事，现有文献没有分开。

### 2.2 定型的是"谁拿哪块"，不是"分哪些块"

E167 R4 / E168 / E171 的分辨率层次（深层，32 亿）：专家服务哪些词类（route 指纹）重跑 .95 / 顺序 .90 / 初始化 .81；同一个词的上下文怎么分（T_D）.47 / .37 / .22；具体哪些 token 的预测需要它（逐 token 因果角色）.33 / .23 / .06。越具体越不重现，连重跑都不重现——"具体实现"是事故，"按什么分"是数据。

### 2.3 几何一致不决定划分，划分也不是几何的自然聚类

T_h .95 vs T_D .28–.50；路由器与自己模型隐状态的 k-means 只有 .49，而 k-means 自身跨 seed .79。对 Myth 的"路由 = 几何"：弱形式对（几何约束了可能的划分族），强形式错（同一几何允许多种划分，训练选哪一种不由几何决定）。

**合起来：** 一个两成分图景——(i) 噪声在前 2 亿 token 内选定一个划分并锁死；(ii) 数据在其后的训练里把语法骨架慢慢压进这个固定划分。这已经不是"含糊的一半"，是一个有时间结构的机制描述。它缺的只是**因果**证据（分叉实验）和**机制**证据（锁定靠什么）。

## 3. 候选研究空间：统一打分

打分维度：问题形式（能否写成硬话）；有名假设与对手；可区分的预测；现有 checkpoint 能做多少；新训练成本；谁在乎；撞车风险；假设依赖。

### S1 分工的早期锁定（推荐）

- **问题：** MoE 的专家划分在训练的什么时候、被什么定型？定型后数据还能改多少？
- **假设 H1（锁定）：** 存在 k\*，从 k\* 之前分叉的拷贝终点划分一致 ≈ 换初始化水平，从 k\* 之后分叉 ≈ 重跑水平；k\* 在深层约第 100–200 步，浅层晚得多；k\* 对应"开始用上下文"而非学习率峰值或损失平台。
- **对手 H2（持续重塑）：** 一致随 k 平滑上升、无阶跃；或终点一致随训练长度继续上升（Platonic）。
- **对手 H3（几何决定）：** k\* 与 T_h 的定型时间重合（如果几何先于划分定型且决定它，则分叉后几何相同的拷贝划分也应相同——我们已有的 T_h .95 vs T_D .46 已经反对 H3，分叉实验让它更干净）。
- **机制检验：** 锁定后路由器–专家梯度方向对齐度（Ahrac 的耦合量）是否在 k\* 处跃升；关掉 aux 均衡（只留 bias）或关掉 bias 是否移动 k\*；提高路由温度 / 加路由噪声是否延迟 k\* 并让数据决定部分（只换初始化对的终点 T_D）变大。
- **现有数据能做：** 时间线（已有，§2.1）；同一 run 相邻 checkpoint 的 churn（分开"锁定但不同"与"还在变"）；重跑对内互换路由器的损失变化（S2）。
- **新训练：** 一条 400 步的细粒度 run（每 10 步存，约 25 分钟）；分叉 k ∈ {0, 50, 100, 150, 200, 300, 400} × 2 份 × 训到 2 亿 token（深层一致 2 亿后不再变；每份约 50 分钟）≈ 12 GPU 小时；旋钮版再 ×2。全部单卡、互不通信，正合 RESOURCES.md 的资源形态。
- **谁在乎：** MoE 可解释性（Myth / RouterInterp / Standing Committee 之争）、MoE 训练（StableMoE、Hash layers、loss-free balancing 的"为什么有效"）、训练动力学（Frankle / Achille / Fehlauer 的 MoE 版）。
- **撞车：** 没有发现 MoE 路由的分叉实验；最近的是 Emergent Modularity 的同 run 稳定性与 OLMoE 的饱和曲线。Dhir 的理论是盟友不是对手。
- **假设依赖：** 低。k\*、阶跃、层序都是直接测量；不需要分解。
- **会被什么否定：** 一致随 k 平滑上升（→ H2 成立，本身是"划分持续被重塑"的发现，与 OLMoE 饱和叙事矛盾，仍可发表）；或 k = 0 的分叉也给出 .45（→ 噪声不重要，决定者是初始化——与现有 I 对 .22 矛盾，要查流水线）。

### S2 划分是不是一个"规范自由度"（S1 的配套，不需训练）

- 重跑对几何一致 .95，把 I4D0R 的路由器装进 I4D0（或反之），测 NLL 变化与"微调多少步能恢复"。若损失几乎不变 → 划分近似退化方向（Hoogland 的 degeneracy 语言），Hash layers / 冻结路由器的结果被解释；若大变 → 专家与划分深度共适应，锁定靠耦合。两种结果都有用。配套地测"只换初始化对"的互换做对照（几何同样 .95）。
- 风险：单独不成文；作为 S1 的机制章节。

### S3 划分差异是否预测行为差异（McCoy / D'Amour 式）

- 8 个 run 的 BLiMP 分项、OOD 泛化、ICL 分数 vs 两两 T_D。现有模型可做。
- 问题：小模型 BLiMP 方差大；预期答案是"划分不预测行为"（划分是附带现象），零结果不好写；若要写成"MoE 的结构欠定不传到行为"，需要比 8 个 run 多得多的样本。**不推荐作主线。**

### S4 分工发育与语法习得阶段（Sudden Drops 式）

- 用正则项延迟 / 提前"开始用上下文"的时刻（或 Chen 式的 SAS 抑制），看 k\* 是否跟着移动。有知识增量，但是 S1 的一个旋钮而非独立题目；且撞 Chen 等 2024 的方法。并入 S1 的旋钮清单。

### 放弃的两个

- **归因分解**（v1 的 D1）：不可识别。
- **Dobs 式"干扰决定分工"**：需要把语言切成会互相干扰的"任务"，任何切法都是假设；梯度冲突与划分的相关也不能排除几何或频率的共同原因。可以在讨论里作为类比，不作为实验。

## 4. 若选 S1：给新会话的实验清单（按优先级，不排日程）

### 4.1 不需新训练（先做，决定要不要训）

1. **同 run churn：** 对 I4D0 与 I4D0R 各自，相邻 checkpoint（25M→50M→100M→…）之间的 T_D，各层。预测：深层 100M 后 churn ≈ 重跑上限之内（锁定），浅层直到 800M 仍低。若深层 churn 也低但重跑一致只有 .46 → "锁定但不同"成立。读数脚本 `analyze_routing.py` 已支持任意两份路由。
2. **路由器互换（S2）：** I4D0 ↔ I4D0R，I4D0 ↔ I5D0，各层单独换与全换；held 集 NLL；再训 200 步看恢复。
3. **把 §2.1 的表画成 Fehlauer 式四阶段图**，叠上 ce 与 lr。

### 4.2 细粒度早期 run + 分叉（约 12 GPU 小时）

- `train_moe.py` 加 `--ckpt_steps 0,10,20,…,400`（现只支持按 token 存）；训 I4D0 配置 400 步。
- 分叉：从步 k 的 checkpoint 起，两份拷贝各用不同的 CUDA 非确定性（重跑式）或不同数据顺序（顺序式）继续训到 2 亿 token；k ∈ {0, 50, 100, 150, 200, 300, 400}。两种噪声各 7×2 = 28 份，每份约 50 分钟。
- 读数：各层 T_D（N1 扣地板）、T_h、route 指纹；曲线 "终点一致 vs k"。预测见 §3 S1。
- 对照：k = 0 重跑式应复现 .46–.50（已有 I4D0R）；k = 0 顺序式应复现 .37–.45（已有 D 对）。

### 4.3 机制与旋钮（约 10 GPU 小时，视 4.2 结果）

- 耦合量：每个 checkpoint 上路由器行向量与对应专家输入权重主方向的余弦（Ahrac 式），看是否在 k\* 处跃升。
- 旋钮各 1–2 条 run（4 亿 token 足够，因深层一致 2 亿后不变）：(a) 去掉 aux 均衡、只留 bias；(b) 去掉 bias、只留 aux；(c) 路由 logits 加噪 / 升温到第 1000 步；(d) 均衡作用域微批 → 全局批（v1 的 D1 旋钮，这里只问它移不移动 k\*、改不改数据决定部分的终点）。

### 4.4 可能的论文句（供讨论，不是结论）

- EN：*In MoE language models, which tokens share an expert is fixed within the first ~1% of training—at the moment the model starts to use context—by nondeterministic noise alone, and never revisited; what training adds afterwards is a grammatical skeleton that is the same across runs. Expert "specialization" is therefore a frozen accident with a data-determined skeleton.*
- JA（给导師用一句）：MoE の「どのトークンが同じ専門家を共有するか」は学習の最初の 1% で、文脈を使い始めた瞬間に、非決定的なノイズだけで決まり、その後は変わりません。学習がその後付け加えるのは、どの学習でも同じになる文法的な骨格だけです。
