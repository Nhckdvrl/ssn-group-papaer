## 1. 当前候选命题（**候选，未锁定**；**11-06 05:50 起按 §9 改为 R-A 方法学主张，本节的 H_skeleton 表述只作历史；R-B PARKED**——用户 11-06 01:05："不要提前锁定主线，目前的收获价值并不明确"；E173 读数出来后由人决定是否继续）

**MoE 的专家分工里，哪些是"模型的属性"，哪些是"这一次训练的偶然"。** 用同一架构 + 同一数据的 9 个独立训练（加精确重跑作噪声地板）对每一种读数给硬判决：跨 seed 一致度是否到重跑地板。

已有判决（E167–E172）：
- **到地板（模型属性）**：粗粒度语法分区（词类级 .86）、模型级专精度数字（Spec ±.005、路径探针 ±.002）、route 指纹 .81、语法骨架的出现顺序（词类 / 形态先，依存等后，15/15 对）。
- **不到地板（训练偶然）**：专家级身份（token 级 .19）、同词形上下文分区（深层 .28 vs 地板 .50）、"哪类词最专精"的排序（.73 vs 重跑 .97）。
- **轴**：时间（第 100–200 步锁定）、层（L0 与 L11 反向）、粒度（.86 → .48 → .19）、**配方（E173 进行中）**。不是轴：词类、词频（E172）。

对手命题（写进论文要能分胜负）：
- H_arch：分工由架构 + 数据决定，seed 只加噪声 → 预测所有读数到地板。**已被 token 级 / 排序读数否定。**
- H_run：分工由训练噪声决定 → 预测粗粒度也低。**已被词类级 .86 否定。**
- H_skeleton（我们）：数据只压进语法骨架，骨架内的填充由早期噪声锁定 → 预测 (i) 粒度梯度、(ii) 早期锁定、(iii) 配方改变填充的自由度但不改骨架（E173 的检验点：一致的内容跨配方不变）。

近邻与压缩风险：Equifinality 2604.14419（2 seed、"same functions, different weights"、随机匹配基线、无地板）与 Geometric Routing 2604.14434；Myth 2604.09780（几何决定路由，无跨 seed 对照）。我们的增量 = 地板 + 粒度 + 时间 + 配方四条轴，和"哪些已发表结论跨 seed 重现"。

## 9. 判断点（11-06 05:50，主会话自主决定；依据 §8 预登记）

**E173 三对读数（8 亿 token；`results/e173/table.md`）：** FRZ 冻结随机路由器 L11 T_D .024 [.017, .031]、深层 .021（基线 .236 / .164；15 对尺子 L11 .189–.254），而步对齐留出 CE 与基线无差（3000 步 3.519/3.531 vs 3.525/3.508）；LB0 L11 .229、深层 .140（略低于尺子下限 .154，单对）、CE 无差；G16 L11 .056、深层 .035、CE 无差。三个配方的 UD share 前三都是 prev_upos / next_upos / deprel（Spearman .95–.98），**连 FRZ 也是**，所以"骨架不随配方变"这条检验不区分任何假设，作废。FRZ 的词类级 route 指纹 .665 与 E174 的 N1 几何零假设 .66（A–N1(B)）相同；G16 .662。G256 两 seed 未完。

**合起来的图景（E173 + E174 + E175）：**
1. 词类级一致主要来自表示几何：随机冻结路由器与 N1 零假设都给 .66，学习只在其上加 .15（换初始化，6 对 .14–.17）/ .27（重跑）。
2. 同词形分区级与 token 级的一致是路由学习造成的：冻结路由器 T_D ≈ 0；学到的路由跨初始化 .23、重跑 .47。
3. 但路由学习在这个规模对 loss 没有贡献（FRZ CE = 基线）——这是对 Hash Layers / SMoE-Dropout / Self-Routing 已知结果的复现，只作引用背景（§12）；能写的是：可重现的分工不是性能所需，是训练动力学的产物。
4. D1：按真实下一 token 无交叉；按模型**预测**的下一 token，L11 追平输入（.95，无反超），且已知预测后真实下一 token 不再多给信息——深层路由输入之外的部分就是模型自己的预测（E175 POST-HOC A，25c742e0）。作为旁证保留：OLMoE §5.4 的读法在本规模成立到"追平"为止。

## 12. R-A 定位（11-06 07:20；`library/themes/moe-routing/POSITIONING_RA_2026-11-06.md`，lit-v2 按 R6 重扫）

**可以作为标题级主张的三句（未找到先例）：** (1) 同配置 MoE 跨独立训练的一致度随读数粒度递减，以同 seed 精确重跑为上限、未训练为地板标定——四件跨 run 工作（Equifinality、视觉 MoE 2605.20610、双语 2608.15102、LMC-MoE 2509.11348）都没有重跑上限，也没在同一套 run 上展开粒度；(2) 冻结随机路由器也给出跨 seed 可重现的粗划分（词类级 .66 = 几何零假设），而同词形分区级只有学到的路由才有（FRZ T_D ≈ 0）——冻结路由下的**一致度**没人测过，性能等效有人做过；(3) 已发表 MoE 读数的三级审计（模型级可推广、专家级不可推广）并逐条报 step 0 判定——形式无先例，"要报随机基线"的原则归 Heap 2025（ICLR'26）。

**只能作背景引用、不能写"我们发现"的：** 冻结 / hash 路由不伤损失（Hash Layers 到 4.5B、THOR、SMoE-Dropout、Self-Routing；反证 Clark 2022 大规模下学到的路由始终更好）；"单 checkpoint 结论未必推广到训练程序"（MultiBERTs）；"统计量重现、个体单元不重现"（Gurnee 2024、Paulo & Belrose 2025、Li 2015）；"粗划分跨 seed 稳"（视觉 MoE）；"路由由几何决定"（Myth、Routers Learn Geometry）；路由早期饱和（OLMoE、OpenMoE）。
