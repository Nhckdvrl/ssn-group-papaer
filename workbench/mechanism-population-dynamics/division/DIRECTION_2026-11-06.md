## 1. 当前候选命题（**候选，未锁定**——用户 11-06 01:05："不要提前锁定主线，目前的收获价值并不明确"；E173 读数出来后由人决定是否继续）

**MoE 的专家分工里，哪些是"模型的属性"，哪些是"这一次训练的偶然"。** 用同一架构 + 同一数据的 9 个独立训练（加精确重跑作噪声地板）对每一种读数给硬判决：跨 seed 一致度是否到重跑地板。

已有判决（E167–E172）：
- **到地板（模型属性）**：粗粒度语法分区（词类级 .86）、模型级专精度数字（Spec ±.005、路径探针 ±.002）、route 指纹 .81、语法骨架的出现顺序（词类 / 形态先，依存等后，15/15 对）。
- **不到地板（训练偶然）**：专家级身份（token 级 .19）、同词形上下文分区（深层 .28 vs 地板 .50）、"哪类词最专精"的排序（.73 vs 重跑 .97）。
- **轴**：时间（第 100–200 步锁定）、层（L0 与 L11 反向）、粒度（.86 → .48 → .19）、**配方（E173 进行中）**。不是轴：词类、词频（E172）。

对手命题（写进论文要能分胜负）：
- H_arch：分工由架构 + 数据决定，seed 只加噪声 → 预测所有读数到地板。**已被 token 级 / 排序读数否定。**
- H_run：分工由训练噪声决定 → 预测粗粒度也低。**已被词类级 .86 否定。**
- H_skeleton（我们）：数据只压进语法骨架，骨架内的填充由早期噪声锁定 → 预测 (i) 粒度梯度、(ii) 早期锁定、(iii) 配方改变填充的自由度但不改骨架（E173 的检验点：一致的内容跨配方不变）。

近邻与压缩风险：Equifinality 2604.14419（2 seed、"same functions, different weights"、随机匹配基线、无地板）与 Geometric Routing 2604.14434；Myth 2604.09780（几何决定路由，无跨 seed 对照）。我们的增量 = 地板 + 粒度 + 时间 + 配方四条轴，和"哪些已发表结论跨 seed 重现"。

**审稿人会问、现在答不上的：**
1. *只有一个小模型族。* 答案路径：配方轴（E173）+ 外部效度——在 OLMoE-1B-7B 公开的中间 checkpoint 上复现 F2 的"词类结构先于依存结构出现"（单模型可测，只需前向，估 1–2 GPU h；候选 E175，对手命题"各语法变量同步出现"）。**核查（11-06 01:00）：OLMoE-1B-7B 公开 245 个中间 checkpoint，但最早是 step 10000 = 410 亿 token，而我们的骨架在 10 亿 token 内成形，出现顺序在那里已不可见；E175 只能测单模型的层剖面 / UD 分解结构，不能测顺序。外部效度主要靠自己的规模轴。**规模轴（2 seed × 更大模型 ≈ 16 GPU h）只在 E173 后仍有余力时做。
2. *锁定是因果的吗？* 现在是相关（曲线在 100–200 步分开）。Frankle 式分叉（k ∈ {0, 50, 100, 200, 400} 步 × 2 子 run × 2 亿 token，< 20 GPU h；候选 E177）能把"第 k 步决定"变成硬判决，对手命题"逐渐漂移、无决定点"。排在 E173 之后。
3. *重跑地板 .50 是什么？* 必须报不确定性来源（top-k / scatter 的原子操作）并说明无法消除；否则地板像人为选的。
4. *与 Equifinality 的差别？* 他们 2 seed、随机匹配基线、无上限、一个粒度；我们有上限、四条轴、并证明 token 级远低于上限。lit-v2 交付 C 给正式措辞。
5. *只有英语。* 语言轴暂缓；引用跨模型 POS 专精的既有结果说明骨架不是英语特有，但不下结论。

**顺序（不是承诺）：** E173 关键两对（FRZ、LB0）读数 → 人审"这条线值不值得继续" → 之后才谈 E174 / E177 / 规模轴。用户 01:05：只用少数卡做关键实验，不扩卡；lb=0.1 配方暂不开。lit-v2 会话同时在相邻领域找"别的有意思的方向"（最多 5 条，带对手假设与读数）。

## 7. 三份材料的综合（11-06 03:30；读数目录 + 范式卡 + 分析史 v2；不定方向）

**7.1 顶会在导师偏好之外还要什么**（范式卡 §3，18 篇接收 + 5 篇被拒）：① 不确定性要放在"训练 run"上（MultiBERTs bootstrap、PolyPythias 中位 + IQR）；② 外部效度二选一：多模型，或同架构 × 多 seed × **多规模**；只有一个规模又无理论的在样本里没有；③ 标题级主张要针对一个领域里有人持有的具体信念；④ 对使用者的后果（so what）；⑤ MoE 分析类常附一个轻干预旁证；⑥ 释放 run / 工具算贡献。被拒死因：贡献低于 soundness（玩具模型不交代对真实模型的后果）、断言大于证据、模型少 + 自造指标无参照。

**7.2 现有主线对照这六条**：① 有（9 run + 重跑对）；② **缺**（一个规模）；③ 候选信念有两个——"专家按词类专精"（每篇 MoE 报告都有）与"单 checkpoint 的专家分析可推广"（MultiBERTs 句式）；④ 若走方法学，so what = 分析一个 MoE 时该报什么不确定性；⑤ 冻结路由器算一个；⑥ 9 个全程 checkpoint 可释放。**最近邻更新**：视觉 MoE 2605.20610 已用 10 seed × 专家数 {4,8,16} 报告"粗划分（有生 / 无生）跨 seed 与跨专家数都稳、细调谐各异"——这就是 H_skeleton 的视觉版，E173 的"专家数改填充不改骨架"若成立，增量只剩语言、地板、粒度梯度、时间。压缩风险比 Equifinality 更大。

**7.3 现成读数的复算**（目录表 1）：21 种里 12 种纯 CPU 可在 9 run 上复算；最便宜的一组是 OLMoE 路由饱和、OLMoE 领域专精、ST-MoE 路由熵、Antoine Spec（已做：排序 .73）、2604.05267 领域专家。这是导师 B6 的正解，也是 MultiBERTs 句式（"哪些已发表结论换 seed 还在"）的素材。
