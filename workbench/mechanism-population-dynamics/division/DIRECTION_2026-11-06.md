## 1. 当前候选命题（**候选，未锁定**；**11-06 05:50 起按 §9 改为 R-A 方法学主张，本节的 H_skeleton 表述只作历史；R-B PARKED**——用户 11-06 01:05："不要提前锁定主线，目前的收获价值并不明确"；E173 读数出来后由人决定是否继续）

**MoE 的专家分工里，哪些是"模型的属性"，哪些是"这一次训练的偶然"。** 用同一架构 + 同一数据的 9 个独立训练（加精确重跑作噪声地板）对每一种读数给硬判决：跨 seed 一致度是否到重跑地板。

已有判决（E167–E172）：
- **到地板（模型属性）**：粗粒度语法分区（词类级 .86）、模型级专精度数字（Spec ±.005、路径探针 ±.002）、route 指纹 .81、语法骨架的出现顺序（词类 / 形态先，依存等后，15/15 对）。
- **不到地板（训练偶然）**：专家级身份（token 级 .19）、同词形上下文分区（深层 .28 vs 地板 .50）、"哪类词最专精"的排序（.73 vs 重跑 .97）。
- **轴**：时间（第 100–200 步锁定）、层（L0 与 L11 反向）、粒度（.86 → .48 → .19）、**配方（E173 进行中）**。不是轴：词类、词频（E172）。

对手命题（写进论文要能分胜负）：
- H_arch：分工由架构 + 数据决定，seed 只加噪声 → 预测所有读数到地板。**已被 token 级 / 排序读数否定。**
- H_run：分工由训练噪声决定 → 预测粗粒度也低。**已被词类级 .86 否定。**
- H_skeleton（我们）：数据只压进语法骨架，骨架内的填充由早期噪声锁定 → 预测 (i) 粒度梯度、(ii) 早期锁定、(iii) 配方改变填充的自由度但不改骨架（E173 的检验点：一致的内容跨配方不变）。

近邻与压缩风险：Equifinality 2604.14419（2 seed、"same functions, different weights"、随机匹配基线、无地板）与 Geometric Routing 2604.14434；Myth 2604.09780（几何决定路由，无跨 seed 对照）。我们的增量 = 地板 + 粒度 + 时间 + 配方四条轴，和"哪些已发表结论跨 seed 重现"。

## 9. 判断点（11-06 05:50，主会话自主决定；依据 §8 预登记）

**合起来的图景（E173 + E174 + E175）：**
1. 词类级一致主要来自表示几何：随机冻结路由器与 N1 零假设都给 .66，学习只在其上加 .15（换初始化，6 对 .14–.17）/ .27（重跑）。

4. D1：按真实下一 token 无交叉；按模型**预测**的下一 token，L11 追平输入（.95，无反超），且已知预测后真实下一 token 不再多给信息——深层路由输入之外的部分就是模型自己的预测（E175 POST-HOC A，25c742e0）。作为旁证保留：OLMoE §5.4 的读法在本规模成立到"追平"为止。

### 15.2 定位：稠密多语几何 × MoE 语言路由（11-09，lit，d399e6e6；`library/themes/moe-routing/POSITIONING_LANGUAGE_GEOMETRY_2026-11-09.md`）

## 21. E185 路由方差分解图谱：第一张完整测量图（11-09 21:15，c1b477b7；`division/experiments/E185-routing-variance-atlas.md`、`results/e185/tables.md`、`fig_map_*.png`、`fig_nested.png`、`fig_residual_b.png`、`fig_tokens.png`；0 GPU，CPU 1.2 h）

**图上最稳的结构（三模型，语料半分同号 ≥ .96）：**
1. **"常数倍"是词表锐化。** 训练路由器对所有 token 相关因子（输入、前一、下一、预测下一、UPOS）的边际份额都是零模型的同一倍数（Qwen3 1.5–1.8×，GPT-OSS 1.3–1.4×，OLMoE 1.4–1.7×），逐层不变；语言份额 ≈ 2×，但给定 token id 与文字后降到 1.1–1.3×。C24 的"常数倍"由此有了机制：路由器主要是把 token 身份查得更死。
2. **token id 只解释路由不确定性的少数**（mid 段 Î(输入)/H(e) 校正后约 .24 / .36 / .43），而**哪些 token 依赖上下文由几何决定**（逐 id H(e|id) 的 T vs N_B Spearman .91 / .91 / .82）；功能词与内容词的上下文依赖度无差别。最不依赖上下文的是句首 token（94–100% 同一专家），同一 token 出现在引号后就换专家。
3. **给定 token id 之后，训练路由器多出几何的部分在局部序列因子上**（预测 / 真实下一 id、前一 id：T 高于 N_B 全部 draw 的层 48/48、19/24、16/16；mid 段 1.3–2.8×），集中在标点与功能词（`,` `.` ` the` ` of`）。位置、语料与几何相当。
4. **中层 token 之外的路由信息是跨语言共享的内容，不是语言。** 给定 token 后平行句身份的信息 Qwen3 .44 bit（N_B .18）、GPT-OSS .22（.13）、OLMoE .02，而语言只有 .011 / .003 / .017 bit。**同 token 同语言之内文字信息 = 0**（四模型，含留出 devtest）。
5. Qwen3 Base 与 Instruct 图谱逐格相关 .998。

**两个残差的定位：** (a) E184 的"下一 token 低于零模型"是差值读数 ΔÎ 的产物：给定输入后 Î(预测下一 | 输入) 在 T 上高于 N_B 全部 draw（48/48、21/24、15/16）、无一层低于 → C26 第四句要改。(b) E182 乌兹别克 vs 塞语反向**不是 token 重合效应**：词表反事实项 Δ_lex 两组四模型都为正；反向来自上下文项 Δ_ctx（两组皆负、乌兹别克是塞语 3–12 倍、随对照语言距离增大），且零模型上同号更大（T 最弱）→ 中层的语言项是共享 token 上的语言分离，几何自带，训练路由器反而最弱。
