- 「何を言えたら意味があるのか」：他要的是一个命题，说出来之后别人的想法会变。先定命题，再谈实验。
- 所以面谈的目标**不是汇报更多数字**，而是：承认上次没有命题 → 展示地图已经画全 → 提出一个命题和它的三根支柱 → 问他这个命题在他眼里是不是"有意义"的那一侧。

## 2. 面谈结构（15 分钟版，可念的日文在 §5）

1. **承认（30 秒）。** 上次是观察的罗列，没有说"所以什么"。这一周重读了约 90 篇（MoE 专精、因果检验、跨 seed、训练早期动力学、普适性、涌现模块性、神经科学的功能分区、语言发育），想清楚了什么命题值得说。
2. **地图（1 分钟）。** 相关研究分三类，全都在"单个模型里分工长什么样"：(i) 描述——Mixtral §5、ST-MoE §7、OpenMoE、2026 年 4 月 Goodfire 的 *Polysemantic experts, monosemantic paths*（六个公开 MoE：路由由一个低维"控制子空间"驱动，编码的是抽象功能而不是 token 身份；跨层路径按功能聚类，同一个冒号三种用法三条路径）；(ii) 质疑——Myth（路由 = 几何）、因果审计、预注册检验（模块性大多瓦解）；(iii) 跨 seed——Equifinality（2 seed）、PolyPythias / Fehlauer（稠密模型输出分布的四阶段）。**没有一篇问：分工里哪一部分是学习问题逼出来的、哪一部分是这次训练的偶然；也没有一篇问它什么时候定下来。** 我们的九个 run 正好能回答。
3. **命题（2 分钟）。** 一句话（§5 的 A）。三根支柱：
   - 分什么一致、谁来分不一致（已有：route 指纹 .81，T_D .22，逐 token .06；重跑 .95 / .47 / .33）。
   - 一致的区分是"预测需要的区分"，与语言学范畴部分重合、部分系统偏离（已有线索：it / that / to 强分；is / are 的系词与助动词表示里可解码但不分开算；up / go / get 表示有、分工不用；深层路由按"要靠后文确认的功能"分，可预测性相关 .56）。缺：分离度 ~ 下一词分布分歧度的回归；偏离清单；跨公开 MoE 家族（OLMoE、Qwen1.5-MoE、DeepSeek-V2-Lite、Mixtral）的"哪些词被分开"清单是否一致——只需推理。
   - 其余是早期事故（新读出的事实：重跑对第 11 层一致在第 100 步 .88、第 200 步 .46，之后 2 亿 token 起不再变；这 100 步里学习率只有峰值 5–10%，损失 8.5 → 6.9，模型刚开始用上下文；之后只换初始化的对从 .05 慢慢升到 .30——噪声部分早定并冻结，数据部分慢慢长）。缺：Frankle 式分叉实验，< 20 GPU 小时。
4. **它为什么有意义（1 分钟）。** 对做语言的人：语言模型自己的词汇功能范畴是什么、与语言学差在哪，用"跨训练可重现"当筛子，是 Elman 1990（预测诱导范畴）的今天版本。对做可解释性的人：单模型专家清单里哪些是性质、哪些是事故。对做 MoE 训练的人：Hash Layers 和冻结随机路由器为什么不输学习路由。
5. **问他三个问题（§4）。**
6. **不做的：** 不报新比例；不争辩 .28 还是 .50；不提头（现在的测法未训练模型也一致；rLLC 等工具已有，放下）。

## 3. 预期提问与回答

| 他可能问 | 答 |
|---|---|
| それは ST-MoE / Mixtral が言っていることでは？ | 他们说"专家按词类专精"，单模型、静态。我们说的是：哪些词的哪些**用法**被分开、沿什么组织，跨独立训练一致；而具体实现连完全相同配置的重跑都只重现一半。前者是学习问题的性质，后者是事故——这个区分是新的。 |
| Goodfire の 2026 年の論文（paths）と同じでは？ | 他们在单模型里显示路径按功能聚类，没有跨 run，也没有说哪些功能区分是必然出现的。他们的控制 / 内容分解可以直接拿来当我们的工具；我们的增量是可重现性与发育时间。 |
| 一致が 0.5 しかないのは学習が不安定なだけでは？ | run 间方差是性质不是缺陷（Keller Jordan ICLR 2024；Frankle 2020 稠密网络也要到 3% 训练后才对噪声稳定）。我们能说出**什么时候**不稳定（第 100–200 步）、**什么**稳定（语法骨架）；Fehlauer 在 PolyPythia 上看到同样的"一致 → 分歧 → 慢回合"四阶段。"不稳定"本身变成了发现。 |
| 小さいモデルだけでは？ | 跨公开 MoE 家族的清单比较不需要训练，数据与分词器都不同，一致反而更强；Goodfire 的结果说明功能组织在 7B–106B 都在。锁定时间线能在 OLMoE 的公开中间 checkpoint 上查同 run 版本。 |
| 言語学的に何が新しい？ | 偏离清单：模型不分系词 / 助动词、强分 that / to / it、表示有但不用的 up / go / get。假说是"分不分取决于下一词预测是否需要"，可以用下一词分布的分歧度检验。 |
| 「初期化で決まる部分」(a) か「ヘッド」(b) か？ | 都不是。(a) 换成"什么时候、被什么决定"（分叉实验）；(b) 放下。 |
| 次に何をする？ | 三件不需训练的事（分离度 ~ 分歧度回归；跨家族清单；同 run churn 与重跑对内路由器互换），然后分叉实验（< 20 GPU 小时）。 |
| 本当に論文になる？ | 两条叙事：ACL 系 = 模型的词汇功能范畴（可重现性当筛子）；ICML 系 = 分工的早期锁定。共用全部数据。 |

## 4. 要问他的三个问题

1. この命題は、先生の基準で「意味がある」側に入りますか。言語学的に一番面白いのは「モデルが分けない区別」のリストだと考えていますが、どう思われますか。
2. 「予測に必要な区別だから分かれる」という説明は、次語分布の分岐度で分離度を説明できれば納得できるものでしょうか。他に見るべき物差しはありますか。
3. 学習データも tokenizer も違う公開 MoE（OLMoE、Qwen、DeepSeek、Mixtral）で同じ語が同じように分かれていれば、規模の問題への答えになりますか。

## 5. 可以念的日文要点

- 前回の共有は観察の羅列で、「だから何が言えるか」がありませんでした。この一週間で関連研究を約 90 本読み直し、何を言えたら意味があるかを考えました。
- 関連研究はすべて「一つのモデルの中で分担がどう見えるか」です。分担のどこまでが学習問題に強制された部分で、どこからがその学習の偶然なのか、またそれがいつ決まるのかを調べた研究はありません。9 本の学習はそれに答えられます。
- **言いたいこと：独立に学習した言語モデルは、「どの語のどの用法を別々に計算すべきか」で一致します。一致するのは、それが次の語の予測に必要な区別だからで、言語学の区別とは部分的にしか重なりません。どの専門家がそれを担うかは、学習の最初の 1% のノイズで決まる偶然です。**
- 根拠の状況：一致する部分としない部分の分離は測定済み。「予測に必要な区別」は仮説で、次語分布の分岐度と公開 MoE 間の比較で検証します（学習不要）。「最初の 1% で決まる」は既存 checkpoint から読めた事実で、分岐実験（20 GPU 時間以下）で因果にします。
- ヘッドは今の測り方では意味がないので、いったん置きます。
