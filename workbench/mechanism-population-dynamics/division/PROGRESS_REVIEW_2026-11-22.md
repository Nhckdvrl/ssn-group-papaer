## 3. 做过的每一步

### 阶段 A：自训小 MoE 平台（10 月下旬 – 11-06）
- **平台：** OLMoE 结构缩小版，12 层、d768、64 专家 top-8、约 1.5 亿激活参数；Dolma 英文；lr 6e-4、2000 步 warmup、负载损失 + z-loss + 选择偏置平衡。
- **E167 / E171（10 个 run）：** 扣掉"同一隐状态上的随机路由器"零假设（N1）后，深层分工的跨模型一致度：完全相同配置重跑 .47、只换数据顺序 .37、只换初始化 .23、未训练 ≈ 0；未扣零假设时未训练模型之间就有 .32–.68。
- **E169：** 各次训练的隐状态几何一致 .95；对隐状态做 k-means，跨种子一致 .79；路由器与自己模型的 k-means 只一致 .49。
- **E170 / E172 / E174：** 扣零假设后的粒度阶梯：词类级 .56 → 同词形分区 .45 → 逐 token .20；可重现的分区沿词类、形态、依存组织；内容词与功能词一致度相同（.233 / .229）；Antoine 式专精度排序跨种子只重现 .73。
- **E173 / E177（配方与规模）：** 换初始化 ÷ 重跑：16 专家 .13、64 专家（top-2）.39、64 专家（top-8）.44–.53、256 专家 .81（每配方 1–2 对）；冻结随机路由器的损失与学习路由器相同（3.519 / 3.531 vs 3.525 / 3.508），T_D .024；6 层比 12 层更一致（各 1 对）。
- **E176：** 已发表的 7 类专家级读数中，4 类在未训练模型上就已成立。
- **11-05 面谈**后，按导师意见补了词类、第二尺度、现成分析法；语言轴没做。
- **11-09 转向：** 因"数依赖配方与训练量"，主会话提议、用户同意冻结自训平台（DIRECTION §14–§15）。

### 阶段 B：公开模型上的零模型审计（11-09 – 11-10）
- 只做推理，用同一隐状态上的随机路由器检验已发表的 MoE 分析结论（E178–E187）。
- 结果：训练路由器相对随机路由器只把语言专属度乘以 1.1–1.8 的常数，"首尾层语言专属、中层共享"的层剖面由随机路由器复现（C24）；首尾层语言专属由文字 / 词表主导（C25）；"深层按预测的下一 token 路由"不成立（C26）；路由散度预测跨语迁移，但随机路由器预测得一样好（C27）；Qwen3-30B-A3B 的复制层，同源路由器一致 .53、非同源 .15（E187）。

### 阶段 C：候选主线 N4"路由器先于表示定型"（11-11 – 11-18）
- **E189 / E191（观察）：** OLMoE 训练全程，路由器一侧到达终点一半用 3810 亿 token，表示一侧 8570 亿；八成分别为 2.33T / 4.18T；FLAME-MoE-290M 上八成为 3.79B / 6.39B；第一个 MoE 层例外。已发表的饱和曲线与表示一侧重合。
- **E190（功能）：** OLMoE 上把路由换成"同一个词在别处的路由"，损失 +1.29 nat；约四分之三的功能由词身份承担。
- **E192（干预，约 180 GPU 小时，原估 2–4 小时）：** 在 FLAME-290M 的 2.26B token 处冻结路由器后续训，无损失代价；重置路由器后深层回到原专家编号（.70–.75），第一层不回（.30）；代价表现为约 210 步的固定落后；事前预测"第一层路由器换掉无代价"不成立；更早起点的 6 组全部不稳、不可读。
- 11-18 发布了给导师看的日文进度网页。
- **11-19 导师否定 N4**（见第 1 节）。

  - 独立训练的语言 MoE 之间，用与编号无关的分区一致度、扣零假设、随专家数或规模比较——**没有人做过**；最近的 Xin et al. 2611.15271 是共享初始化下按编号的路由翻转，Myth 2604.09780 没有比较独立训练的 MoE。
  - SAE 文献：单元越多、跨种子越不共享；训练越久越共享。
  - 路由价值：真实设置下学习路由只比固定路由好 0.03–0.10 nat（Clark et al. 2022），相对价值随专家数下降；稳定比学到更要紧；我们 8 亿 token 的"冻结随机 = 学习"落在文献差距最小的区间。

导师的问题是"独立训练的 MoE 会不会形成相同的专家分工"；它在自训平台上答不出一个可发表的命题，但把"分工"换成"路由器"、把"种子"换成"公开模型的自然实验 + 同一隐状态上的随机路由器"之后，它变成一个可测的 when / what 问题：**MoE 里先定型、而且带着来源记忆的，是路由器的决策函数，不是它读的隐状态几何；已发表的"路由早饱和"曲线量的是后者**（N4）。证据：两条公开训练轨迹（OLMoE-0924 5T、FLAME-290M 11B）上除第一个 MoE 层外每层路由器都先于输入定型，领先 1.7–2.3 倍 token；复制层上只有路由器分量拷贝特有（.53 vs .15）；功能上早定的 token-id 映射承担约 3/4，晚到的局部序列部分是最贵的单层。机制开放（不是门饱和）。判断与待决事项见 DIRECTION §26。

### 5. 为什么 N4 是当前最有希望的主线候选（判断，不是决定）

- **它就是导师的问题，换成了可测的形式。** "分工由初始化 / 早期决定多少"→"路由器权重何时定型、相对几何先还是后、它的来源记忆比哪些参数持久"。数不是份额而是时间点与一致率，对手明确（几何先定 / 输入漂移为主），两条轴都在公开模型上、0 GPU。
- **导师的五条出路都有数可填**：对比轴 = 训练步、拷贝对 vs 非拷贝对、Base vs Instruct、模型族（E=8…128）；第二尺度 = 分配一致率 / 权重余弦 / 几何地板三把并列；token 类 = 句首 .83 vs 其余平、H(e|id) 分层；语言轴 = 20 语；现成分析 = OLMoE §5.1 的饱和曲线与 Routing Drift 的交叉套用在新场景复算。
- **反直觉程度（11-11 按文献核查改写）**：当前最强的几何说（Myth、Ye、我们自己的 N1）把路由器当读数；N4 说在动力学上读数先于被读的东西定型，而且第 0 层的路由器比几何早 5000 亿 token 找到前一 token 方向。同向的先验已有：Routers Learn Geometry 2605.12476（1B 自训、无零模型）、Why Routers Freeze（NeurIPS'26，理论）、Motif 3 的 "router lock-in"（只有检索摘录）。所以 N4 不是"与所有先验相反"，而是**把一条理论预测（路由器冻结）与一条经验读法（早饱和 = 分工早定）在 7B 公开轨迹上拆开检验**：饱和里多少是路由器、多少是几何，先后差多少 token；第 0 层的晚期解冻是冻结说的反例。
- **相关工作为什么没有（11-11 核查后的诚实版本，细节见库 `POSITIONING_N4_ROUTER_FIRST_2026-11-11.md` Part B）**：(1) 饱和曲线有三家（OLMoE、FLAME-MoE、OpenMoE），都把分配稳定直接读成"路由早定"，没人把它拆成路由器分量与几何分量——这是真空白，但原因是问题没被提出，不是别人做不到（转存只是一次前向）；(2) 交叉套用拆分只有 Routing Drift 在合并场景做过；post-training 的路由保留（Router Prior Bias，Findings EMNLP'26，Qwen3-30B-A3B-Base，top-k 重合 .39–.48）与持续预训练（Thérien，TMLR'25）量过但不拆——所以"Base vs Instruct 差 21%"这个数本身不新；(3) 层复制无正式文献（复查仍无）；(4) 稠密侧早就有"谁先定型"的文献（SVCCA 自底向上收敛、Chen ICLR'23 浅层先收敛、Frankle 早期稳定性、Hoffer 固定随机读出头），MoE 特有的只是路由器是逐层、离散、决定计算路径的读出器，能在同一隐状态上换成随机路由器做对照。
- **会杀死 N4 的结果**（写在前面）：(i) E189 读数 4 显示路由器稳定只是因为它读 token 身份子空间、该子空间本来就早稳 → N4 压缩回 N1 的动力学版本；(ii) E189 的 R(t) 与 H(t) 同步到达终值 → 没有先后；(iii) E190 显示上下文依赖在功能上惰性 → 路由器"先定"的只是一个查表，意义降级；(iv) 文献核查发现有人已在公开 checkpoint 上做过路由器 vs 几何的先后。
