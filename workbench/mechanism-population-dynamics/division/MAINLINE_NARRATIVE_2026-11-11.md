## 0. 一句话

导师的问题是"独立训练的 MoE 会不会形成相同的专家分工"；它在自训平台上答不出一个可发表的命题，但把"分工"换成"路由器"、把"种子"换成"公开模型的自然实验 + 同一隐状态上的随机路由器"之后，它变成一个可测的 when / what 问题：**MoE 里先定型、而且带着来源记忆的，是路由器权重，不是隐状态几何**（候选叙事 N4）。两条公开模型的轴各有一个超出地板的数，但分解口径还没对齐；E189 正在对齐，E190 在补功能连接。

## 1. 导师的原问题与接受标准（`MEETING_2026-11-05_RECORD.md`）

- 原问题（10-16 → 10-22 改为先做 MoE 专家）：不同初始化的模型是否形成相似的分工，分工由初始化 / 早期决定多少。
- 他接受的实验形态：同一句话喂给只换 seed 的模型，比路由分配的相似度与几何（第 6、7 条）；不偏好消融。
- 他的卡点：「一致度が 0.3 でした」だけでは論文にならない（第 3 条）；前提是"真的没人做过"（第 5 条，条件句）。
- 他给的五条出路（第 8–12 条）：模型类型对比轴；第二把尺子；模型内 token 类别对比；5–10 语的语言轴；借现成分析法并报告其结论跨模型一致多少。
- 翻译成一句：**一个数要沿着一条有名字的轴移动，尺度要有依据，先行工作要诚实。**

## 2. 原方向为什么难以推进（四层，都有数）

| 层 | 障碍 | 证据 |
|---|---|---|
| 命题 | 一致度是 0–1 之间的一个数，本身不是主张；我们做出四条轴（配对类型 .50/.45/.28、层 L0 .13 → L11 .50、粒度词类 .86 → 逐 token .19、时间 100–200 步定型）后仍是描述 | 会议记录 §3；E167–E172 |
| 平台 | 自训小 MoE 的数**依赖配方与训练量**：init÷重跑随专家数 .13（16）→ .44–.53（64）→ .81（256），只改 top-k 就动到 .39；重跑天花板随 token 数漂 | §13–§15、C23 |
| 可识别性 | "分工由数据 / 配方 / 初始化各占多少"是交互因子上的份额分解，不可识别，被用户 11-05 否决；导师要的"模型类型对比轴"在自训平台上只能是配方描述 | §15；记忆 `no-decomposition-questions` |
| 规模 | 真实规模不可能多 seed 训练；导师的"模型类型对比"要么在小尺度（配方依赖），要么必须换成公开模型上的**自然实验** | §15；`RESOURCES.md`（弱互联，单卡推理可行） |

此外导师第 5 条的前提我们答错了："MoE 解释研究几乎没有"不成立——每一代大 MoE 都带专家分析节（库 `MOE_EXPERT_ANALYSIS_HISTORY` §0）；真正稀缺的是**跨独立训练**的比较（2 篇）与**带时间轴**的比较（0 篇）。下次汇报必须先改口。

## 5. 为什么 N4 是当前最有希望的主线候选（判断，不是决定）

- **它就是导师的问题，换成了可测的形式。** "分工由初始化 / 早期决定多少"→"路由器权重何时定型、相对几何先还是后、它的来源记忆比哪些参数持久"。数不是份额而是时间点与一致率，对手明确（几何先定 / 输入漂移为主），两条轴都在公开模型上、0 GPU。
- **导师的五条出路都有数可填**：对比轴 = 训练步、拷贝对 vs 非拷贝对、Base vs Instruct、模型族（E=8…128）；第二尺度 = 分配一致率 / 权重余弦 / 几何地板三把并列；token 类 = 句首 .83 vs 其余平、H(e|id) 分层；语言轴 = 20 语；现成分析 = OLMoE §5.1 的饱和曲线与 Routing Drift 的交叉套用在新场景复算。
- **反直觉程度**：当前最强的几何说（Myth、Ye、我们自己的 N1）把路由器当读数；N4 说在动力学上读数先于被读的东西定型，而且第 0 层的路由器比几何早 5000 亿 token 找到前一 token 方向。这与 Routers Learn Geometry 2605.12476 的"路由器塑造几何"同向但那是 1B 自训、无零模型。
- **相关工作为什么没有（待文献归属核查确认，暂标未核对）**：训练轴需要密集公开 checkpoint（只有 OLMoE-0924）+ 逐 token 路由器输入转存 + 同一隐状态上的随机路由器三者同时在手；层复制先要发现复制本身（无正式文献）；Routing Drift 只问合并失败；MoE 的"早饱和"文献只看分配不拆路由器 / 几何；稠密侧的早期训练文献（lottery ticket rewinding、critical period）没有"可替换的读出器"这个把手。
- **会杀死 N4 的结果**（写在前面）：(i) E189 读数 4 显示路由器稳定只是因为它读 token 身份子空间、该子空间本来就早稳 → N4 压缩回 N1 的动力学版本；(ii) E189 的 R(t) 与 H(t) 同步到达终值 → 没有先后；(iii) E190 显示上下文依赖在功能上惰性 → 路由器"先定"的只是一个查表，意义降级；(iv) 文献核查发现有人已在公开 checkpoint 上做过路由器 vs 几何的先后。
