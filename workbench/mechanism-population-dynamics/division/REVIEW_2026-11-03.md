# 审阅与规划：分别训练的 MoE 专家分工（E167 / E168 初步结果）

> 作者：Claude，角色是审稿人兼规划合作者（2026-11-03）。本轮只审阅和规划：没有启动 GPU 任务，没有改动实验卡、结果文件和 CLAIMS 登记。新算的数字全部来自本机已有的结果 JSON 和分析缓存（CPU），脚本在 `scripts/review_routing_decomp.py`、`scripts/review_token_under_route.py`，原始输出在 `results/e167/review_2026-11-03_*.txt`。写“确认”的地方表示我复算了数字或读了代码；写“不确定 / 未核对”的地方就是没核到。

## 0. 结论先说

1. **数字都对，解释有三处要改。** PRELIM_FINDINGS 的每个数字我都从 JSON 复算了，和文中一致。但“深层 2/3 重现”这句话目前没有可说清的含义，原因是天花板（同初始化只换顺序）为什么只有 .44 没人知道；“扣掉几何后仍有一致，所以不全是几何”说过头了，N1 扣的是“同一读出子空间里随便切”，不是“几何决定的那种切”；“头和专家深度规律相反”目前不成立，它完全由减去一个未训练地板产生，不减地板时头的各层比值是平的（.82–.92）。
2. **数据里有比简报写的更有意思、也更站得住的东西，简报没写出来。** （a）深层的初始化印记**没有**被冲掉：从 4 亿 token 起，“只换顺序”比“只换初始化”多出的一致稳定在 .12–.17，一直到终点；被冲掉的只是浅层。（b）两个模型隐状态几何几乎一样（T_h .95 对 .96），切法却只有一部分一样——“几何决定分工”在强意义上不成立。（c）跨初始化时，按词类对上的专家和按逐 token 损伤对上的专家**不是同一个**（匹配一致率 .09–.31；同初始化时 .66–.91）。这是“划分重现、实现不重现”的直接证据，比“.28”这个数更有说服力。
3. **按导师的标准，现在是线索，还不是贡献。** 四条读数全是统计量，没有任何语言学内容；可重现的那一部分（词类分工、闭类词专家）正是最可能被说成「そうだよね」的部分。要过导师这一关，必须回答“哪些分工是规范的、哪些是偶然的”，而且用语言学变量回答。现有的路由采集已经能做这件事的第一步，不用新训练。
4. **推荐的下一步：** 两个便宜对照（完全相同配置重跑一次；隐状态聚类零假设）与一个主实验（可重现分工的语言学分解）并行；前者决定数字的含义，后者决定有没有故事。不建议现在铺条件地图、换规模或补头的因果读数。不建议转向。

## 1. 审阅结论：逐条检查 PRELIM_FINDINGS

### 1.1 代码与描述是否一致

读了 `moe_model.py`、`train_moe.py`、`capture_routing.py`、`moe_measure.py`、`analyze_routing.py`、`functional_probe.py`、`analyze_functional.py`、`heads_attn_fp.py`、`token_roles.py`、`prelim_figure.py`。实现与实验卡描述一致，没有发现数据泄漏（匹配用 cal 半集、评估用 anchor 半集；逐 token 读数按窗口两半交叉）。两点要记下：
- 训练前向在 bf16 下用 `index_add_` 合并专家输出（原子加，顺序相关），所以**完全相同配置重跑也不会逐位相同**。这直接关系到“天花板”的含义（§1.3）。
- N1 零假设保留的是行中心化路由矩阵的右奇异子空间（秩 ≤ 63）和奇异值，只在子空间内随机旋转，再重拟合偏置匹配负载。它扣掉的是“同一组读出方向、随机分配给专家”的一致，**不扣**“专家对准了隐状态的簇结构”这种一致（§1.4）。

### 1.2 逐条判定

| 简报结论 | 判定 | 依据与问题 |
|---|---|---|
| 1. 自然一致很大；未训练模型扣 N1 后 ≈ 0 | 数字确认；作为 N1 的验证**不成立** | 未训练模型的路由器本身就是随机矩阵，N1 对它做的随机旋转和它自己同分布，所以 T_D ≈ 0 几乎是同义反复。它证明 N1 对随机路由器校准正确，不证明 N1 是训练后模型的“自然一致”零假设 |
| 2. 前置通过（均值替换 ΔNLL .04–.07） | 确认 | 与原生 OLMoE L9 .064 同量级 |
| 3. 深层分工跨初始化重现 ≈ 天花板 2/3 | 数字确认；**含义待定** | 32 亿 token、15 对，L11 T_D .262–.350，天花板两对 .446 / .440，比值 .67；终点 6 对 .73。但比值的分母为什么是 .44 而不是 1，目前没有解释（§1.3）。另外“没有硬件效应”未确认：L11 含 A100 run 的 9 对均值 .281，纯 RTX 6 对 .322，A100–A100 对 .269 最低；L6–L10 两组没有差别。n 太小，分不清是 seed 还是硬件 |

| 6. 线性拼接失败 | 确认为阴性观察 | 同初始化的模型也接不上，说明是仿射映射容量不够，**不能**当作“实现不同”的证据 |
| 7. 头与专家深度规律相反 | **目前不支持** | 见 §1.6 |

### 1.3 天花板：现在无法解释，而且它决定“2/3”的含义

三组数（32 亿 token，L11，T_D）：只换顺序 .443；只换初始化 .298（纯 RTX 对 .322）；初始化和顺序都换 .297。L6–L10 上“都换”和“只换初始化”没有差别，L11 差约 .025。也就是说：**一旦初始化不同，换不换数据顺序几乎不再影响一致**；初始化相同时多出来的一致是 .12–.17。那么“只换顺序”的两个模型为什么只一致 .44、丢了 .56？有两种解释，现在的数据分不开：
- **训练本身混沌**：bf16 原子加等非确定性让相同配置的两次训练也只一致到 .44 左右。此时 .44 是“可重现的上限”，“初始化只换掉其中约 1/3”这句话成立，而且数据顺序几乎不重要。
- **顺序只在初始化相同时才重要**（交互作用）：此时 .44 不是上限，比值不能解释为“重现了多少”。

区分它们只需要一次**完全相同配置的重跑**（同 seed、同顺序、同型号卡），17–24 小时一张卡。这是整条线最便宜也最关键的缺口，比任何新条件都优先。顺带可以在 A100 上重跑一次 I4D0，解决上面的硬件疑问。

### 1.4 N1 零假设：扣的是“随机切”，不是“自然切”

在 I0D0 终点上（`review_routing_decomp.py`）：
- 词形内中心化后，N1 期望 B 解释真实共路由 C 的方差：L0 .72，L2–L11 .41–.52。残差 D 的标准差 .12–.14，和 C 的 .15–.19 同量级，不是噪声尾巴。
- B 与原始隐状态核 K_h 的相关 .81–.88，D 与 K_h 的相关 −.18（L0）到 +.18（L11）。所以 N1 确实把几何能线性解释的部分扣掉了大半；深层残差与几何仍有弱正相关，说明深层可能略有扣不净。
- 两个不同初始化模型的 B 本身相关 .80–.88：几何高度共享（T_h .91–.95），这点确认。

问题在零假设的种类。如果训练后的路由器倾向于把专家对准隐状态里的簇（“Routers Learn the Geometry” 的正反馈机制正预测这一点），那么两个几何几乎相同的模型会各自对准同样的簇，N1 的随机旋转不会模拟这种一致，T_D 就会把“几何决定的自然切”算进“学习选出的分工”。反过来，用 k-means 之类的簇零假设会把真实路由器切得比随机聚类更一致的部分也扣掉，可能扣过头。**两头各报一个，才知道 T_D 落在哪**。实验卡里写了“同一组隐状态上 k-means 换初始化的可重复性”，没做；它只要一次隐状态采集（每个 checkpoint 几分钟 GPU）加 CPU。

还要说清一点：即使簇零假设把 T_D 全部解释掉，也不等于“そうだよね”。那将是定量地证明“分工 = 共享几何的切分”，并且和 §1.5 的“切法只部分相同”放在一起，仍是一个清楚的结果；只是叙事要变。

### 1.5 分辨率层次与“.28”：确认不是伪影，而且有更强的说法

担心的点是：逐 token 读数信号弱，匈牙利匹配在跨初始化对上失败得更厉害，比值因此被压低。我用两个强信号的匹配（路由词类指纹、词类损伤指纹，都在 cal 半集上做）去评估逐 token 对应（`review_token_under_route.py`，评估窗口 64–127）：

| 深层 L6–L11 比值（只换初始化 / 只换顺序） | 逐 token 自身匹配 | 路由词类匹配 | 词类损伤匹配 |
|---|---|---|---|
| L6 / L7 / L8 / L9 / L10 / L11 | .29 .23 .22 .27 .27 .38 | .14 .14 .13 .14 .17 .26 | .25 .24 .13 .18 .21 .33 |

换成粗粒度匹配后比值不升反降，所以 **.28 不是匹配失败造成的**；“具体哪些预测需要它”这一层的对应确实弱。两个补充发现：

1. **跨初始化时，“词类孪生”和“token 孪生”是不同的专家。** 路由词类匹配与逐 token 匹配选出同一个对应专家的比例：只换初始化 .09–.31，只换顺序 .66–.91；路由匹配与损伤匹配之间：.05–.22 对 .17–.50。词类指纹的匹配相关高达 .8，但它几乎不约束一对一的对应（64 个专家、35 个类别，很多专家有相近的词类剖面）。同初始化时词类孪生就是 token 孪生，不同初始化时不是。这是“划分重现、实现不重现”最直接的形式，也是多重可实现性的正面证据，比单报 .28 有力。
2. **逐 token 对应集中在少数专家，而且偏闭类词。** L11 每层 64 个专家中，跨初始化 r > .2 的有 10–14 个（同初始化 47–55 个），中位数 .09–.13（同初始化 .32–.33）。对应最好的专家多是 DET / AUX / PRON / ADP / CCONJ / SCONJ / PUNCT / NUM 类，内容词（NOUN / PROPN / ADJ / VERB）专家几乎不对应；对应强弱与专家重要性弱相关（.17–.35）。这与 Fehlauer 等（EMNLP 2025）“功能词跨 seed 先收敛、内容词不收敛”一致。**所以“可重现的那部分”有被说成「そうだよね」的风险**（功能词当然一样）；不可重现的部分（内容词的分工）反而是要解释的东西。

### 1.6 头：目前的“方向相反”不成立

头的读数是按查询词类的 5 个注意力模式特征（16 亿 token），匈牙利匹配后减去一对未训练模型的匹配值作地板。
- 不减地板的比值（只换初始化 / 只换顺序）L0–L11：.75 .69 .89 .92 .87 .87 .86 .82 .81 .85 .82 .82，L2 以后基本是平的。
- 减地板后：.67 .56 .82 .88 .69 .79 .52 .36 .49 .69 .28 .58。“深层低”完全来自地板在深层高（L10 地板 .645，只换顺序 .859，只换初始化 .705，超出量 .21 对 .06）。
- 地板只有一对（I0D0 对 I1D0 的 step 0）；头只有 12 个，随机匹配上限 .25–.47；头在 16 亿、专家在 32 亿；浅 / 中 / 深分组事后定。
- 更根本的是基线不对等：专家用的是几何零假设，头用的是未训练地板，一个扣“同一读出子空间随机切”，一个扣“位置驱动的模式”。两个比值不在同一把尺子上。

结论：图 D 不能放进任何对外材料。要做头，需要一个与专家对等的零假设（例如打乱查询词类标签、或只保留位置特征的头模型）、更大的评估文本（P35 的逐头消融信度 −.02–.22 就是文本太少），和同一 checkpoint。

### 1.7 其他测量与统计问题

- 15 个只换初始化的对共享 6 个 seed，天花板只有 2 对；配对 bootstrap 的 CI 是词形层面的，不是 seed 层面的。表述“15 对全部在 .26–.35”没错，但不要写成 15 个独立样本。
- 路由并列翻转噪声（约 0.1% token |ΔNLL| > 1e−3）已记录，对专家级平均无影响，对逐 token 向量是稀疏噪声；同初始化天花板已经吸收了它。
- UD EWT 约 15 万 token 的分析文本对 R4 的浅层指纹信度不够（L1–L4 .28–.49），浅层的 drop 比较不要解读。
- 单一规模、单一配置（64 专家 top-8、无共享专家、辅助损失 .01 加选择偏置平衡）。负载平衡方式按 Myth 与 Routers-Learn-Geometry 的说法会直接影响专精，所以它是条件，不是混杂；结论限定在此配置内即可，不必现在铺网格。

## 2. 是否有意思（按导师的 (a)–(e)）

| 标准 | 现状 | 判定 |
|---|---|---|
| (a) 对象是跨独立训练的分工 | 6 个只换初始化、2 个只换顺序的自训 MoE；读数对专家编号置换不变 | 满足。这是整个项目第一次真正回答导师的问题 |
| (b) 有“本来不一定一致”的先验，并扣掉了自然一致 | 词身份已精确扣除；几何只扣了“随机切”（§1.4）；先验确实冲突（几何派 / 历史派 / 规范分工派） | 半满足。簇零假设没做之前，“扣掉了自然一致”这句话说不满 |
| (c) 数字有参照 | 地板 ≈ 0 几乎是同义反复（§1.2 第 1 条）；天花板 .44 没有解释（§1.3） | 不满足。这正是导师 10-16 写的“一致到什么程度才有意义”，目前仍没回答 |
| (d) 和语言有关 | 四个读数全是统计量；词类只用来分组；没有任何“哪种语言区分被一致地用来分工”的内容 | 不满足 |
| (e) 一句话讲给导师，他不会说「そうだよね」 | 见下 | 取决于讲哪一层 |

**他会在哪一层说「そうだよね」：**
- 讲“深层约 2/3 重现”：他会问 2/3 是相对什么，这个数有什么意义——我们现在答不上来（c）。
- 讲“重现的是词类分工”：会。每个模型都长出按词性组织的专家（OLMoE、ST-MoE、Expert Strikes Back 都报过），两边都有 DET 专家当然能配上。
- 讲“细粒度不重现”：大概也会。神经元 1–5%、SAE 特征 30%、头中层最不稳，“越细越不重现”是领域里有准备的人会猜到的。
- 讲“可重现的专家是功能词专家”：会（功能词先收敛，EMNLP 2025 已报）。

**他不太会说「そうだよね」的：**
1. 两个模型隐状态几何几乎一样（.95），同初始化只换顺序也只一致 .44，不同初始化 .30——**分工不是几何的函数**，同样的表示有多种切法，且各次训练选的切法只部分重合（反 Myth 的强读法）。
2. 深层的初始化印记**不消失**（从 4 亿 token 到终点恒为 .12–.17），浅层的消失——分工里有一块被初始化的对称破缺永久锁定，另一块由数据决定并持续增长。两种理论各对一半，而且分层对。
3. 跨初始化时“对同类输入反应”的孪生和“在同样的预测上被需要”的孪生是不同的专家（§1.5）。
4. **目前还没有的：** 哪些语言区分是所有训练都用来分工的（规范的），哪些是每次训练各自决定的（偶然的）。这是唯一能同时满足 (d) 和 (e) 的层。

**我的判断：** 有继续的价值，现在是线索不是贡献。原因是 (c)(d) 没满足，而满足它们的实验都便宜（§4）。如果把现在的简报原样带给导师，最可能的反应是“数字很多，但一致到什么程度算有意义、和语言有什么关系，还是没说清”。

## 3. 领域定位表（R6）

### 3.1 venue corpus 查询

`python3 tools/venue_corpus/query.py nearest`，四种措辞（跨 seed 专家分工重现 / 跨 seed 普遍性 / 对称破缺与模块化 / 路由可解释性）。要点：
- **已接收论文里没有一篇做“语言 MoE 专家分工跨独立 seed 是否重现”。** 最近的接收近邻是 *The Illusion of Specialization*（ACL 2026，专家联盟的核心—外围结构）、*Quantifying LLM Attention-Head Stability*（ICML 2026，头跨 seed 稳定性）、*Sparse Autoencoders Trained on the Same Data Learn Different Features*（ICLR 2026）、*Convergence and Divergence of Language Models under Different Random Seeds*（EMNLP 2025）、*Bridging Critical Gaps in Convergent Learning*（NeurIPS 2025）、*Advancing Expert Specialization for Better MoE*（NeurIPS 2025 oral）、*The Expert Strikes Back*（ICML 2026）、*Multilingual Routing in MoE*（ICLR 2026）。
- 切片密度：“MoE + specialization” 很热（ICML 2026 接收 33 篇，NeurIPS 2025 20 篇；ICLR 2026 切片接收率 19% 低于基线 27%，多数是改路由的方法文）；“seeds + universality/convergence” 很小（各会 1–6 篇），接收率与基线持平。地图：MoE 专精是热题，但几乎全是方法；跨 seed 普遍性是分析类小切片，接收正常。
- 被拒近邻里值得看原因的：*Quantifying Expert Specialization for Effective Pruning*（撤稿，4.0）、*SAEs Reveal Universal Feature Spaces Across LLMs*（ICLR 2025 拒，6.0）——后者说明“跨模型普遍性”的分析文如果只有相似度数字、没有后果，分数可以不低但仍被拒。

## 4. 下一步计划

### 4.0 原则
- 不换平台，不加条件；在现有 8 个模型和已有采集上把问题问清。
- 每个实验先写先验预测和分叉；止损：任何修补需要再加一个条件就停。
- 不设数值门槛；读“落在地板与天花板之间的位置”。
- 下面的 GPU 需求都写成“由人决定是否启动”。

### 4.1 两个必做对照（便宜；决定 §1.3、§1.4 两个数的含义）

**C1 完全相同配置重跑。** I0D0 的 seed、顺序、硬件型号全同，再训一次到终点（1 张 RTX，约 17 小时）；可选再在 A100 上重跑 I4D0（约 24 小时）。读数：T_D、R4、逐 token，与 I0D0 比。
- 分叉：重跑对的 T_D ≈ .44（≈只换顺序）→ 训练混沌，.44 是可重现上限，“初始化换掉约 1/3”成立，顺序不重要；≈ .9 以上 → 顺序效应大且与初始化交互，“2/3”要改写为“换初始化比换顺序多损失 .12–.17 的一致”；中间 → 两者都有，按比例报。
- 这一步同时给逐 token 读数一个真正的信度上限（现在天花板对只有 .05–.32，不知道里面多少是顺序效应）。

**C2 簇零假设。** 在终点 checkpoint 上采集 UD 锚点词的隐状态（每模型几分钟 GPU），CPU 上：(i) 同一模型隐状态上 k-means（k = 64，top-8 由最近 8 个中心给出）换 k-means 种子的自一致；(ii) 跨模型 k-means 的一致；(iii) 真实路由器与 k-means 的一致。全部用同一套 T 统计。
- 分叉：真实路由器跨 seed 一致 ≈ k-means 跨 seed 一致 → 分工 = 几何的自然切分（Myth 的强版本成立），叙事转为“几何决定切法、切法有多少是共享几何的自然聚类”；真实 > k-means → 训练选出了比几何自然聚类更一致的切法，T_D 的读法成立；真实 < k-means → 训练选出的切法比几何允许的更偶然，初始化印记更重。三种结果都有话说，但说的不同。

### 4.2 主实验 A：可重现的分工里，哪些语言区分是规范的

**科学问题。** 同一个词在不同上下文里被分给不同专家，这个“分法”跨初始化重现了约 2/3（深层）。重现的部分对应哪些语言区分（句法功能、依存关系、形态、句中位置、所在文档体裁、前后词类）？不重现的部分是什么？规范的部分是不是只是“频率高 / 闭类 / 早学到”的那部分？

**先验预测。**
- 几何派（Myth）：凡是在共享几何里线性可分的区分都会被所有 seed 用来分工，规范集 = 主要语言区分（词性、句法功能、位置）全体。
- 历史派（Routers-Learn-Geometry、分岔模型）：只有最早、最频繁的区分（闭类词、标点、位置）是规范的，其余由早期随机历史锁定，跨 seed 任意。
- 输出收敛派（Fehlauer et al.）：功能词规范、内容词偶然；也就是规范集就是“そうだよね”的那部分。

**谁依赖这个结果。** 用单次训练做专家级解释或路由分析的工作（Expert Strikes Back、Multilingual Routing、OLMoE 路由分析）：它们对专家的语言学标签能否推广到另一次训练。

**事先写好的分叉。**
- 规范集只含闭类 / 位置 / 频率型区分 → 可重现分工 = 自然分工；论文主张转为“超出频率的分工是每次训练各自决定的”（阴性但清楚），配合 C2 可写成“分工 = 几何的切分 + 随机选择”。
- 规范集包含同一词内的句法功能区分（如 that 作补语化成分 / 限定词 / 关系词，to 作不定式标记 / 介词，-ing 作动名词 / 分词）且这些区分在隐状态里对所有 seed 同样线性可分 → 存在超出“自然”的规范语言分工；这是能过 (d)(e) 的正面结果。
- 规范性随层变化（浅层表面区分、深层句法区分）→ 分层地图，和“深层印记持久”放在一起讲。
- 所有 seed 都把这些区分编码在隐状态里、但只有部分 seed 用它们来分工 → “表示里有、分工不用”，直接反几何决定论，也是最有意思的一种。

**最便宜但有决定性的设计。**
1. 阶段 1（纯 CPU，现有采集）：`routing/*.npz` 已存每个锚点词在每层的 top-8 集合。把 UD EWT 的 deprel、feats、head UPOS、句中位置、文档来源接到 `passages.json` 的词上。对每个多功能词形（≥ 2 种 deprel 各 ≥ 10 次）：(i) 每个模型内，同功能对与异功能对的共路由差（该模型是否用这个区分来分工）；(ii) 跨模型，只换初始化的 T_D 分解为“同功能对”与“异功能对”两部分，并与只换顺序和 C1 的重跑对比。按语言变量汇总，得到“每个区分在多少个 seed 里被用来分工、跨 seed 的切法一致多少”的表。
2. 阶段 2（<1 GPU·时）：同一批锚点词的隐状态线性探针（每个区分、每个 seed、每层），作为“表示里有没有”的对照；与阶段 1 的“分工用不用”并列。
3. 阶段 3（CPU）：把 §1.5 的逐 token 对应者按语言变量描述，看规范集是否就是功能词专家。

**对照与噪声地板。** 词形内打乱出现顺序（期望 0）；按词形的聚类 bootstrap；未训练模型；只换顺序对；C1 重跑对。规范性的判定不设门槛，报告每个区分在地板—天花板之间的位置。

**算力。** 阶段 1 零 GPU；阶段 2 约 8 模型 × 12 层 × 几分钟；总计 < 1 GPU·时。

**怎样避开 §3 的坑。** 不换平台（同一批模型、同一批采集）；不是在补上一个结果的漏洞，而是把一个数（.60）分解成有语言内容的表；先验三派预测不同，任何结果都改变叙事；全部在看到跨 seed 分解之前写定；止损条件：如果语言变量解释不了 T_D 的大部分（残差仍是主体），就报告“规范部分里语言可解释的比例”并停在这里，不去造更多变量。

### 4.3 次实验 B：深层初始化印记锁在哪里（按 C1 结果决定是否做）

**科学问题。** 深层“只换顺序比只换初始化多出的一致”从 4 亿 token 起恒为 .12–.17。它锁在路由器里、专家里，还是残差流几何里？

**先验。** 正反馈理论：锁在路由向量—专家权重的耦合里，换掉路由器就换掉印记；几何派：锁在残差流里，路由器可以重学回来。

**设计。** 从 4 亿 token 的 checkpoint 分叉：(i) 把 I0D0 的所有路由器换成 I1D0 的（专家按 R4 对齐置换）继续训到 8 亿；(ii) 只重置路由器为随机；(iii) 对照：原样继续。读数：继续训练后与 I0D0 / I1D0 各自的 T_D。每个分支 4 亿 token 约 2 小时一张卡，3 分支 × 2 个 seed ≈ 12 GPU·时。

**分叉。** 换路由器后分工跟着新路由器走 → 印记在路由器—专家耦合；分工回到原来 → 印记在残差几何；重置后分工既不回原也不像任何一个 → 印记是早期历史的产物、不可重建。

**谁依赖。** 路由器设计（Routers-Learn-Geometry 的 k-means 路由器、auxiliary-loss-free 平衡）、MoE 升级/重训时能否保留专家分工。

**避坑。** 只改一个因素、两个 seed、事先写分叉；它解释的是我们自己数据里最清楚的异常（深层印记不消失），不是补漏。

### 4.4 现在不建议做的
- **条件地图全网格、换规模**：是覆盖面，不是问题；在 C1/C2/A 之前做，只会多出一组没法解释的 2/3。等 A 有了内容，再挑一个最可能改变答案的因素（我的猜测是负载平衡方式，Myth 对它有明确预测）。
- **头的因果读数**：P35 说明文本量不够；头与专家的尺子不对等。先把专家这条讲通，头留给“その後ヘッドでも”那一步，届时需要新的零假设设计和更大文本。
- **转向**：不建议。数据里有三条站得住、没被占住的线索（§2），而且全部能在现有模型和采集上推进。导师的多语言备选方向是另一个题，不在此线资源内。
