## 1. 导师说了什么（两次面谈，按原话整理）

### 1.1 10-16 下午面谈（头；当面口述，经转述整理）
- **他对上次ゼミ内容的理解与我们不同。**
  - 他感兴趣的不是“初始化决定哪个编号的头做什么”；
  - 而是：**独立训练之后，即使头的编号变了，是否仍会形成相似的功能分工。**
  - 原话：「番号は変わるにしろ、同じようなヘッドが出来上がりますよっていうのは、そこまで当たり前じゃない」（编号变了也好，会长出同样的头，这件事并不那么理所当然）。
- **他区分了两件事：**
  - 学到相似的知识——自然的；
  - 形成相似的角色分工——不自明的。他当时就用 MoE 专家的自发分工作类比。
- **条件：**
  - 要看这类研究已经有多少；
  - 书面评论：“一致到什么程度才有意义，可能很难主张”（**基线问题**）。
- **总体评价：** 「全然ダメではない」（完全不行倒不是），但也「すごい研究テーマとまでは思ってない」（还没到很棒的研究题目的程度）。可以换题，也可以从这个角度继续想。

### 1.2 10-22 面谈（MoE → 头；据会议录）
- **[04:01–04:44] 回到上次的题目：**
  - 「考えるのであれば、前回のテーマの方がずっと面白そうな気がします」（要想的话，上次的题目有意思得多）。
  - 但他强调，有意思的不是学生最初着眼的地方，而是讨论中在**别处**发现的芽：
    - 单词的意义在任何语言模型里都相似，这是自然的；
    - 「ヘッドごとに担当している役割が異なり、学習をやり直しても、その役割が同じように分かれるのであれば面白いかもしれない」（每个头负责的角色不同，如果重新训练后角色仍以同样的方式分开，可能有意思）。
    - 他说上次就是出于这个想法才评论的。
- **[04:48–05:10] 提出 MoE：** 「ヘッドだけで調べるより、Mixture of Experts を使った方が分かりやすいかもしれません」（比起只看头，用 MoE 可能更清楚）。
- **[05:11–06:39] 为什么是 MoE：**
  - 以 Qwen 的 “A3B” 为例：模型里有多个专家，推理时由门控按输入选择使用哪个专家，用较少的激活计算得到高性能。
  - 「学習時に『このようにエキスパートを分けてください』と役割を明示的に指示するわけではなく、役割分担が自動的に学習されます」（训练时并没有明示“这样分专家”，分工是自动学出来的）。
  - 「別々に学習したモデルでも同じようなエキスパートが対応しているのであれば、単語知識の一致よりも、本来は一致するとは限らないものが強く一致していることになり、一定の意味があると思います」（分别训练的模型里如果也有同样的专家对应，那么比起单词知识的一致，这是“本来不一定一致的东西却强烈一致”，有一定意义）。
  - **研究顺序：** 「まずエキスパートで調べ、その後ヘッドでも調べて、ヘッドにも同様の役割があり、学習間でかなり一致すると示せれば、面白い研究になるかもしれません」（先查专家，再查头；如果能说明头也有同样的角色、并且在训练之间高度一致，可能成为有意思的研究）。
  - 「前回はその可能性を考えて聞いていました」（上次就是考虑到这个可能才问的）。
- **[06:40–07:10] 关于选题方式：**
  - 题目通常不是一开始就一个人定下来，而是在反复讨论中逐渐成形；
  - 每次带来完全不同的题目，研究就推进不了。
- **[08:08–09:14] 再次确认与条件：**
  - 「前回のテーマのように、エキスパートの役割が別々の学習でもどの程度自発的に一致するかを調べる方が面白いと思います」（像上次的题目那样，查专家的角色在分别训练中能自发一致到什么程度，更有意思）。
  - 「今話した案について私はまだサーベイしていません。同様の研究がすでにあるかを調べた上で判断する必要があります」（他还没调研，要先查有没有同样的研究再判断）。
  - 同时提醒：评估如果完全脱离语言，就不是语言处理研究了，至少偏离他的专业。

### 1.3 他判断“有意思”的标准（同一次会议中他评价其他题目时明确说过，直接适用于本题）
- **“一致是自然的”不算发现：** 如果模型本来就会有某种倾向，结果一致了，他只会想“也是”。
- **数值的意义：** 一致程度随数据和条件的给法而变，“这个数值有什么意义”本身是问题。
- **“不一致的条件”反而可能更有意思**（他在同次会议另一话题里说的）。
- NLP 研究里 research question 是否有意思最重要，不必人人都觉得有意思，但要能讲出为什么不平凡。

### 1.4 我们对导师意见的理解
- **他要的对象：** 模块之间的**角色分工**（役割分担），不是知识，也不是某个编号。
- **他认为有意义的命题形式：** “本来不保证一致的东西，在独立训练间自发地强烈一致”。要成立，必须同时说明两件事：
  1. 为什么“本来不保证”（存在其他可行的分工）；
  2. 一致到什么程度（有刻度的度量）。
  - 这正是他 10-16 自己提出的基线问题。
- **为什么先 MoE：** 专家是显式、离散、为分工而设计的模块，分工看得更清楚；头是他的第二步，要看到“头也有同样的角色、训练间高度一致”。
- **他没有说清的地方（需要我们给出）：**
  - “同样的专家对应”指什么：路由的 token 划分？功能？因果作用？
  - 在哪个粒度上一致：token 身份、上下文、领域、语言？
  - “不保证一致”的依据是什么？
- **他的约束：**
  - 先调研有没有同样的研究；
  - 不要每次换全新的题，要在这条讨论线上逐步收敛；
  - 评估留在语言范围内。

## 2. 调研结果（10-23，正文精读）

### 2.1 文献地图：已经占了什么，还空着什么
| 层级 | 已有工作 | 占住的 | 没占住的 |
|---|---|---|---|
| 头的跨训练稳定性 | Bali 2026（ICML）；Spectral Probe-Circuits 2026；Tigges 2024；我们的 E72 / E89 | 注意力图最佳匹配；按层的稳定性（中层最不稳定）；权重衰减的影响；与消融重要性的关系；“算法稳定、组件更换” | 头没有“可行分工的集合”这个基线；继续做只是多加一个度量 |
| 独立 MoE 的参数对齐 | On Linear Mode Connectivity of MoE（NeurIPS 2025） | 专家置换（加门控平移）是 MoE 门控的全部对称性；权重匹配后线性连通 | 骨干是预训练且冻结的，只训练插入的 MoE 层，只有 2–16 个专家；问的是损失壁垒，不是分工内容；没有从头训练的语言 MoE |
| 跨种子专家“功能重合” | Equifinality 2026；视觉 MoE 两篇（Tangtartharakul & Storrs；PRISM） | 两个种子的专家在词表投影上有重合（随机基线有误、架构非主流）；视觉上“划分结构重现、专家身份不重现”（定性，无数值） | 语言 MoE **路由层面**的一致性；留出数据；正确的零假设；与 token 身份 / 表示几何的分离；成因 |
| 分工的成因 | Myth of Specialization 2026（几何）；Routers Learn Geometry 2026（路由—专家耦合累加）；Bifurcation 2026（对称破缺）；OpenMoE 2024（早期固定、token ID 主导）；Qiu 2025（均衡的批次范围） | 各自在单个模型或玩具设置里给出机制 | **跨训练的判决实验**：几何决定论与历史依赖给出相反的跨种子预测，没有人测过 |
| 分工是否必要 | Hash Layers 2021；Equifinality 2026；Sparsity Moves Computation 2026 | 哈希 / 冻结随机路由几乎和学到的路由一样好 | 在本题里这是**基线的来源**：多种分工都可行，一致性因此不是目标函数逼出来的 |

### 2.2 逐篇要点
- **Equifinality in MoE（2604.14419）：**
  - 自造的余弦路由 MoE（每层 1024 个秩 1 专家）、WikiText-103 训练约 14 个 epoch；
  - 路由拓扑不决定困惑度；哈希 / 随机路由只差 1.1–2.2 PPL；
  - 跨种子只比较 2 个种子：专家权重最佳匹配余弦与随机无差别，词表投影最佳匹配 Jaccard 0.13–0.15。但“500 倍于随机”的基线不对，因为没有对最佳匹配本身做零假设。
- **LMC of MoE（2509.11348，NeurIPS 2025）：**
  - 理论上证明专家置换（加门控平移）是全部对称性，这给了“匹配专家”严格定义；
  - 实验是冻结预训练骨干、只训练插入的 MoE，不回答从头训练的分工问题。
- **Myth of Expert Specialization（2604.09780）：**
  - 路由器是线性的：隐状态相似 ⇒ 路由相似。专精是表示几何的性质，不是路由机制的性质；
  - 负载均衡损失会压制共享方向；深层路由依赖上下文；
  - 不同**模型**解同一题时专家重叠约 60%，但这是跨不同模型，没有比较同配置的不同种子。
- **Routers Learn the Geometry of Their Experts（2605.12476）：**
  - 被选中专家的路由向量与专家权重，沿同一输入方向接收梯度，二者共同累积被路由的 token 历史，形成正反馈；
  - 辅助均衡损失会破坏这种耦合。
  - 推论：分工可能由早期随机历史决定。
- **Bifurcation Model（2605.29121）：** 两专家 softmax 路由加正反馈，得到叉式分岔与滞后，是对称破缺的玩具理论。
- **OpenMoE（ICML 2024）：** 路由主要由 token ID 决定，token → 专家映射在预训练早期固定；从稠密模型升级而来的 Mixtral 专精弱。
- **Expert Coupling（2610.09372）：** 约 10 亿 token 时专家对的相关模式已经稳定。
- **Sparsity Moves Computation（2605.09403）：** 玩具任务上，5 个种子间“专家分配 vs 运算类型”的 NMI 为 0.28 ± 0.20，作者解读为受初始化调制的倾向。
- **视觉 MoE 两篇（见旧卡）：** 划分结构跨种子重现、专家身份不重现，只有定性证据，没有基线。
- **头：**
  - Bali 2026 用注意力图最佳匹配测了头跨种子的稳定性；
  - 我们的 E89 用多任务因果图测到“任务深度顺序与任务捆绑跨种子重现（如 8 / 8），逐头对应对不上”。

### 2.3 调研结论
1. **“独立训练的专家是否对应”不是全新问题，但只有薄弱的初步观察：** 两个种子、非主流架构、定性或基线有误。语言 MoE 从头训练、路由层面、带正确零假设的测量还没有人做。
2. **真正空着的是解释层面：**
   - 用正确的零假设分离 token 身份、共享表示几何和分工本身；
   - 判定分工由“几何”还是“早期历史”决定。
   - 两种理论正在冲突，跨训练比较是判决实验。
3. **头方向已被占住大半**（Bali + 我们自己的四版论文与 E89），不单独做；按导师的顺序作为第二个案例。

## 4. 为什么 MoE 比头好（这是要对导师讲清楚的核心）
1. **对称性是精确的：** 专家是一组完全对称的可交换模块，置换就是全部对称性（LMC-MoE 定理）。头还受层、位置、残差流方向的影响，对齐本身就有争议。
2. **观测量直接、可靠、覆盖全部数据：**
   - 路由决定是离散的、零成本的、每个 token 都有，不需要人工任务集，也不需要消融。
   - 划分之间可以用聚类一致性（调整互信息、共分配矩阵）比较，**不需要先匹配编号**，避开了最佳匹配的选择偏差。
3. **有基线（回答导师 10-16 的难点）：**
   - **为什么“本来不保证一致”：** 哈希 / 随机路由几乎一样好，可行的分工有很多种；
   - **刻度：**
     - 零点：负载相同的随机划分；
     - 满分：同一 run 相邻检查点 / 同种子重跑；
     - 中间两条参照线：只用 token 身份能解释的一致性，以及共享表示几何能预测的一致性。
4. **贴着语言：** 区分 token 身份与上下文（一词多义）、语言、句法，评估留在语言范围内（导师的约束）。

## 5. 研究问题与研究空间
**主问题（一句话）：** MoE 语言模型的专家分工，是共享表示几何的必然读出，还是被早期路由历史印刻下来、经正反馈固定的？如果两者兼有，哪一部分是哪一种？

### Q1　一致到什么程度、一致的是哪一部分（测量，必做）
- **读数：** 同配置、不同种子的模型，在留出语料上逐层计算路由划分的一致性；刻度见 §4。
- **分解：**
  1. 只用 token 身份：每个 token 取其最常去的专家，比较两个模型的“词 → 专家”表；
  2. 上下文部分：同一 token 在不同上下文中的路由切换，在两个模型间是否同步；
  3. **几何预测：** 把模型 B 的隐状态线性映射到 A 的空间，再交给 A 的路由器，得到“路由器只是共享几何的同一种读出”时应有的一致性；
  4. 实际一致性。
- **核心对比是 3 与 4：**
  - 实际 ≈ 几何预测 → 分工被共享表示继承；
  - 实际明显低于几何预测 → 两个模型共享表示，却对同一个几何做了不同的划分。

### Q2　什么时候决定（分叉实验）
- 从同一个父模型的第 t 步分出两个子模型（换数据顺序 / 路由噪声），训练到底后看分工一致性随 t 的变化，得到“分工承诺时间”曲线。
- **事先预测（来自头线 E46 / E62 / E66）：** 如果专家与头服从同样的对称破缺规律，曲线应在训练早期（数个百分点内）升到上限，并随批大小 / 学习率移动。
- **几何决定说的预测：** 任何分叉点的子模型都一致。
- 代码可复用 `scripts/e46_train.py`。

### Q3　“印刻”干预（头线做不到的因果实验）
- **设计：** 训练最初的 N 步，把某类 token（数字、某种语言、某类功能词）强制路由到指定专家，然后撤掉强制、正常训练到底。
- **读数：** 这类 token 最终是否仍由该专家处理；印刻是否跨种子、跨 N 稳定。
- **结果分叉：**
  - 印刻持续 → 历史依赖有因果证据；
  - 被抹掉、回到由几何决定的划分 → 几何决定论有因果证据。
- **为什么头做不到：** 头线里，初始权重的统计量和初始梯度都预测不了哪个头胜出（E39、E41）；MoE 的早期路由历史可以直接记录、直接操纵。
- **新颖性（初步检索）：** 未见“早期强制路由后撤除、看分工是否持续”的研究。最近的是 Grouter（2603.06626）、Ban&Pick（2509.06346）、Geometric Metrics（2604.14500），待精读。

### Q4　由什么控制（Q1–Q3 出现可解释的差异后再做）
- 候选旋钮：
  - 辅助损失均衡 vs 偏置均衡；
  - 全局批次 vs 微批次均衡（Myth 命题 2 给出了机制预测）；
  - 专家粒度与 top-k；共享专家；
  - 从稠密模型升级初始化。
- **要问的是：** 哪些设计让分工“可重现”，哪些只是让分工“集中”。专精度量与可重现性可能分离。

### Q5　后果（“so what”）
- **解释性：**
  - 如果分工随种子变，“专家 X 是数学 / 中文专家”只是单次训练的事实；
  - 如果分工随几何定，这类结论在置换对齐后可以跨训练迁移。
- **殊途同归：** 不同种子的分工不同、损失却相同，就是分工层面的殊途同归。

### Q6　回到头（导师的第二步）
- 只有当 MoE 给出一条原则（例如“由几何决定的部分重现，由早期竞速 / 印刻决定的部分不重现”）时，才回到头。

## 7. 对 GPT 分析的取舍
- **采纳：**
  - Bali 已占住头的稳定性；LMC-MoE 是冻结骨干、只训练 MoE（已核实原文 §6.1）；Equifinality 只是两个种子的初步观察；
  - 路由一致 ≠ 功能一致；最佳匹配有选择偏差，匹配必须在校准数据上冻结，再到留出数据上评估；
  - 统计单位是独立训练，不是 token。
- **不采纳 / 修正：**
  1. **“路由一致 vs 因果功能一致”作为主问题是局部优化：** 最可能的结果（路由像、功能不全像）不令人意外，而且会把我们拉回逐模块消融——头线已经证明这种读数的信度不够。因果干预只用来验证关键差异。
  2. **“先在 OLMoE 单个 run 上确认角色可测”是窄 pilot：** 单个 run 回答不了跨训练问题。
  3. **没抓到 MoE 的核心价值：** 可行分工的基线，以及“几何决定 vs 历史依赖”的现成冲突。
  4. **“单个专家不稳定、专家组稳定”** 是 E89 结论的搬家版本，导师已听过，不做标题。
  5. **对已有工作过度警惕：** 相邻工作都是定性或很薄的观察，不构成“已被做完”。

## 8. 风险与判别办法
1. **平凡结局（最大风险）：**
   - 小模型、短训练下，路由可能几乎由 token ID 决定，一致性全被“词表 → 专家”解释。
   - **判别办法：** Q1 的分解直接报告 token 身份部分；正式训练前，先用公开大 MoE（OLMoE 等）测“同一 token 在不同上下文中的路由切换率”，作为我们的小模型是否够像真 MoE 的参照。
2. **滑回“E89 的专家版”：** 结论必须落在 §6 的“为什么”，不能只是“有多像”。如果 Q1 只给出一个相似度数值，几何预测线也算不清，就按止损规则停。
3. **成本：**
   - 公开模型中没有同配置多种子的语言 MoE，必须自己训练。
   - 粗估：1–2 亿总参数、约 3–5 千万激活参数、数十亿 token，单卡半天到一天；每个配置 3–5 个种子加分叉 / 印刻实验，量级是数百 GPU 小时，具体待测。
4. **资产：** `~/mechpop_cache` 已不存在，需要重新准备数据。
5. **工作方式：** 先写每个实验的结果分叉与决策表；不叙事先行；不追残差。
