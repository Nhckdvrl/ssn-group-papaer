# MoE 方向独立审计（2026-10-25）

**结论：** 保留“跨训练是否形成可对应的计算职责”这个科学问题；先补上路由读数到计算职责的证据桥，再在共享冻结骨干上拿跨初始化数据。当前没有跨种子结果。**冻结骨干、插入随机 MoE、多种子训练已有直接先例，不能认领这个设置本身的新颖性。** 本文只做定位和设计，不改线状态、不升级主张、不运行 GPU。

对应对象：E121 的 R2 / R3 脱节（词性组织强、词性条件的替换损伤选择性弱）；交接文档 J2 / J3、X1 / X2，及本轮 E122 / E123 的 P15 测量问题。不为流程另挂 idea。流程检查：`python3 tools/process/check.py`，0 errors / 33 warnings（均为仓库现有警告）。

## 1. 可以改变同行判断的可证伪问题

> **当输入表示、下游读取和语言建模目标固定时，不同初始化学到的 MoE 是否只是在重复实现同一组可互换的计算模块，还是把相同的预测需求分配成了不同的计算职责？路由组织能否区分这两种情形？**

这比“专家编号是否一致”多两层内容：固定骨干让输入与输出坐标直接可比；独立初始化和语言条件上的干预区分“路由边界不同”和“真正的计算职责不同”。预期影响是：我们究竟能把公开模型中的一个“专家标签”当作训练稳定的计算单位，还是只能把它当作某次训练中的输入调度摘要。跨种子相似度只是证据，不是问题本身。

有三条相互独立、都可被否定的命题：

1. **代理命题：** 路由相近的专家，在共同输入上有相近输出，且这个关系能在留出输入上预测替换后的损伤。仅输出相关不足以成立。
2. **重现命题：** 多次充分训练且达到预定性能带的模型，在留出语言预测上，具有高于负载匹配随机匹配的职责对应；同一 run 后期检查点给出测量参照。
3. **自由度命题：** 路由组织不同、性能在预定等价带内的模型，其条件干预效应也不同。若只见路由不同、职责相同，应报告“不同调度实现相似职责”，不能称“多种不同功能分工”。

这三个命题都不是现有 E120 / E121 的结论。

| [Expert Coupling, 2610.09372](https://arxiv.org/html/2610.09372)，§II.B、VI.A | 预训练内专家共选结构早形成且稳定，用于通信放置 | 独立训练间可重现性及其计算含义 | **中。** 训练轨迹稳定不能单独作贡献 |
| [GaP-MoE, 2610.29355](https://arxiv.org/html/2610.29355)，10-21 新预印本，§3–4 | 通过梯度投影促进专家输出分化；3 seeds 报性能，随机路由对照；也测共同 token 上的输出夹角 | 区分输出分化与预测职责；多训练对应而非新增分化正则 | **中。** 输出余弦/夹角本身已有且不是因果职责读数 |

其中 LMC 的主 SMoE 理论和实验采用 top-k 内重新 softmax；其 DeepSeek 变体另有 full-softmax 截断的定义。OLMoE 的 no-renorm 配置不能不加说明地照搬主 SMoE 定理。其强可辨识假设也不等于有限语言分布上的近似性能等价。因此，“MoE 只有专家置换对称性”应限定对象和假设，不能用来断言所有近似可行解都只是置换。

## 3. 对交接中两个推断的纠正

**X1 的专家输出相关不是功能代理的充分验证。** 两个输出可以主要在下游不敏感方向不同；平均余弦也可能掩盖少量关键 token 的相反预测作用。反过来，分工互补的专家可能经常共路由而输出不同，所以 R 与 F 的符号也不是不证自明的。若相关显著，只能说“路由与专家函数形态有关”；要在留出样本上预测实际替换损伤，才能把它作为某一条件下的职责代理。一个全局相关不能给所有层/语言条件发通行证。

**“专家不同”不等于“专家承担不同语言计算”。** E121 的替换有很大 KL / ΔNLL，确认当前选择下的专家输出不可随意互换；但非选中专家在这个输入上可能缺少训练，损伤也可能反映输入支持域和输出幅度。要研究语言职责，应看到在受控预测对比上的选择性和可重复性。一个 noun preference 没有选择性，只是否定那种粗标签的代理效度，不能否定细粒度职责。

## 4. 最有决定性的下一步：把 X1 做成代理的预测检验

沿用 X1→X2 顺序，但不要以“专家对相关显著”决定是否只测路由。先由实验卡固定如下合同；以下为设计建议，未运行。

1. **输入和范围。** 主层 9，层 2 为解释对照；使用 E121 固定锚点，按句子分校准/留出。共同输入上的全专家输出计算只做局部前向，原始输出相似度作辅助量。既报所有共同输入，也报双方具有可观路由支持的输入；后者样本不足时明确标注，不补选有利实例。
2. **干预。** 在目标位置保持原 top-1 权重及其他 7 个专家不变，换入 rank-9、预定的更远候补、随机未选专家。记录实际 ΔNLL、KL、输出差范数、原 NLL、gate score gap；rank-9 是近边界对照，不能只用最差随机替代。自身顶替和完全相同专家的合成模型给零点。
3. **主检验。** 校准集估计路由距离、输出距离与简洁预测关系；到留出集比较“负载/范数/分数差/原 NLL”基线与加入路由距离后的预测增量，再加入输出距离。按词形/句子聚类区间，报告效应大小；专家对不是 2016 个独立重复。先检查这些预测是否比常数预测有用。
4. **语言含义。** 词性是分层变量，不先验当作职责标签。下一词预测差异应配合一小组独立定义的语言对比，检查正负方向是否相符；不从最大损伤 token 反选主分析。最便宜的先做已有下一 token 读数；若无选择性，保留结论范围，不靠追加越来越细的标签维护叙事。

| 可能结果 | 能得出的判断 | 对 X2 的影响 |
|---|---|---|
| 路由距离可预测留出替换损伤，且跨样本重现 | 该层/该输入范围存在经校准的代理 | 路由可作廉价筛查；跨种子仍保留直接干预抽查 |
| 输出距离预测损伤，路由距离不增益 | 输入调度与任务相关的函数差异脱节 | X2 主要比较共同输入上的函数与干预效应；路由作描述 |
| 两种距离都无预测力，但干预有选择性 | 局部输出形态不是职责的好坐标 | 用语言条件的直接效应图，避免把大量无用输出几何当主量 |
| 替换只产生一般损伤，无可重复的条件效应 | 尚未建立“职责”的测量对象 | X2 仍可测组织，但不能称功能分工；先最小可行性，不扩成大种子网格 |

这一实验的价值是决定我们到底在比较什么；单模型上的相关或阴性不单独承担论文主张。

## 5. X2 的科学问题与训练边界

**先一条最小训练曲线，确认这个平台能够回答问题。** OLMo-1B-0724-hf，第 9 层 FFN→随机 64×1024 top-8 MoE；冻结其余参数，使用 Dolma v1.7 的语言建模 NLL，加与 OLMoE 对齐的 lb / z loss。记录原稠密、zero / mean 层损伤、替换初始、训练轨迹与留出损失。原层要承担显著计算，替换后要恢复至预定性能带，梯度和负载要正常；否则跨种子低相关可能只是共同未学会。

骨干的输入表示完全固定，但预测任务还由冻结下游和 loss 一同规定；准确表述是“在这一固定表示、目标、下游与训练协议下”，不能归因成几何单独决定。若放开下游一层，只是另一个条件，不能把差异直接归于“读取契约”。训练端到端 NLL 是主目标；原 FFN 的输出拟合若使用，只能做诊断/初始化对照，不能悄悄换成最终科学目标。

平台通过后再按固定预算训练预登记全部 seeds。初始化与数据顺序先分开；所有失败、未恢复和负载坍缩都进入结果。5 seeds 是测量精度的起点，不是自动达标门槛；对性能做预定 ε 的等价区间，不能用 p>0.05 代替。种子对共享训练，不能当独立 n=10。

比较至少保留两个轴：路由组织（N1 残差 T）与条件干预效应；用固定锚点上的后期自身参照和同一随机程序的零分布标定。k-means 自身稳定度只是几何参照，不是 T 的可行性上界。若要专家对齐，只在校准集匹配，在留出集验证，同时让随机匹配基线也经过相同选择过程。

| 组织重现 | 职责重现 | 可以回答的科学内容 |
|---|---|---|
| 高 | 高 | 在该冻结目标下，训练偏好相似调度与职责；下一步检验哪种受控扰动能改变它 |
| 低 | 高 | 实现相似预测职责可容许不同调度；路由不是稳定模块身份 |
| 高 | 低 | 相似调度不保证相似职责；对路由解释的代理假设形成直接反例 |
| 低 | 低，且性能等价 | 相同预测需求容许多种功能组织；再用早期关系干预检验可控性 |

跨种子模块互换可作为后续“so what”检验：共享骨干使输出坐标相同，在校准集按职责匹配专家，再在留出集换入另一次训练的专家，测试同条件效应是否保留。但**互换失败本身只说明接口/支持域失配，不能直接证明语言职责不同**；要结合函数差、路由支持和直接效应。路由器×专家 2×2 混合也只有在出现具体异常后才值得做，不能把一般共适应再包装成机制发现。
