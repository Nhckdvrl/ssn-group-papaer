## 1. 相近任务成功可以由不同分担实现

P是标准预训练1T父状态，A是标准退火50B，B是后期引入EMO约束50B，F是全程EMO预训练1T+退火50B。四者同架构、tokenizer与active k；F/B具有相同公开声明的最终组织目标。原始初始化、批次和optimizer链未核实，不将F−B单独解释为时机因果或独立seed总体。F在此指全程EMO端点，与旧固定gate学生组同名记号不同。

B与F相对P/A具有一致的方向：更能保持受限计算，R移除loss下降、S移除loss上升。F/B完整文本NLL差仅−.000547 [−.008670,.006209]，准确率均39.06%；但F的S移除文本代价额外**1.850856 [1.331078,2.300956]**，任务答案NLL代价额外**5.311199 [4.996193,5.628240]**。任务去S准确率损伤差仅+.78 [−7.81,9.38]个百分点，未检出对应幅度的能力差；不混称loss与正确率。

F的自身prefix裁剪代价比B更低：pool分母**.327800/.476699**，差−.148899 [−.203308,−.085790]；完整127分母**.223492/.348459**，差−.124967 [−.152771,−.093085]。F相对三个固定随机mask的选择收益为.606024/.781382，两规则均明确为正；相对B的选择收益还分别增加.173196/.084052。因而最终部署性质相近或更好，仍允许不同程度的预测依赖，不能用小裁剪drop直接定义自治专家。

相同成功也能直接检查：四端点共同答对的40题（34生物/6数学）中，分别去R或去S均失败且D-only失败的题数为P/A/B/F **8/10/20/24**；仅D+R保留成功为**19/16/2/0**。P原19道这种题，16道在F变成共同必要。该集合按完整成功预锁，只报全部8种形态与计数，不给选择后的总体CI，也不当新训练重复。

## 3. 相同函数与信号的实际作用依赖接收背景

E159固定P D/G与整套16层S_P，只换R_B，S移除答案NLL代价增加**.338574 [.235373,.443924]**；固定R_P换S_B则使R代价下降2.609301 [2.387042,2.826923]。固定33道共同成功题中，S_P不变而共同必要由4增至11题。伙伴本身足以改变未改函数的实际作用；固定gate参数时，H和实际路由仍可内生改变。[E159完整16格](results/e159/summary.json)、[作用图](results/e159/figures/unchanged_partner_effects.png)。

E160进一步固定相同S_P权重，只交叉三种R背景产生/消费的实际S轨迹。非原配相对原配的平均答案NLL代价**+.260527 [.222757,.298469]**，choice CE代价+.684293 [.419843,.954473]；raw损伤3.78 [约0,7.42]个百分点。自然S重新计算时，消费者B−P的作用差+.338574；固定P生成的同一信号后为−.110239，差−.448813 [−.529757,−.367458]。固定B信号时B−P又为+.635086 [.512968,.769369]。实际信号的产生与使用共同决定作用，不能由共享权重或一个统一重要性分数概括。[九格与质量](results/e160/retry_1/figures/signal_cross_token_NLL.png)、[自然/固定信号](results/e160/retry_1/figures/natural_vs_fixed_partner_effect.png)、[完整结果](results/e160/retry_1/summary.json)。

保留含生产者R历史的S轨迹后再删在线R，远未恢复完整计算，且生物loss改善、数学反向；不能把回放当shared独立容量或唯一中介比例。这里的R/S都是16层函数套件，不是某一个命名专家。E160完整retry独立复算通过；首轮中断无完整raw、精确成本未知，原账本与至少.583502 GPU·时下界保留。

## 4. 内容、形成与可重复性还剩什么问题

E158同国家改属性时，末位置R流交换能使donor答案首token命中率达到P/A/B=.750/.938/.875；E161同时改国家/属性后，关系混合答案仅0/.0208/.0625，主要输出其他续接词。attention完整donor率.792/.958/.958提供阳性。前者是真实内容控制，后者没有支持可跨实体重用的纯关系操作；也不能据首token未命中断言R不含该信息。[E158](experiments/E158-native-factual-role-interchange.md)、[E161五类结果](results/e161/figures/crossed_outcomes.png)。

当前更有解释力的方向是：**组织约束塑造分担趋势，历史与配套选择具体实现；选择性部署、函数性质迁移、完整能力重用是不同问题。** 来源与信号干预已有正面证据，尚未恢复完整训练动力学、识别唯一最小语义单位或获得独立初始化总体。E162无需追加新训练就扩展了成熟历史证据，但不单独证明早期组织的因果必要性。

**下一决定：检验消息配套的特征来源。** 本轮E163对现有成熟模型保留norm/残差投影并替换消息方向，再校正真实跨背景消息，区分几何接口与方向结构。更广谱系与形成分叉仍是开放方向；不把从头多seed训练、层扫描或donor搜索当默认队列，也不自动追加E163后继。
