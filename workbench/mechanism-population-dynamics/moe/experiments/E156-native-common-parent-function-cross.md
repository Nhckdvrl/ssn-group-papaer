# E156：共同成熟接收者中的函数来源交叉与功能重用（2026-10-27）

- **状态：** RUNNING；8ec5add4冻结源码/plan/CPU预检后启动，先通过三原生真实参数/buffer/cal精确控制再读新重组。
- **对应 / 类型：** C14/P32；跨历史功能重用PILOT，零新训练。
- **问题：** 同一成熟接收者中，来自不同历史的条件专家函数与共享函数能否携带有用计算？哪些函数需要共同保留，才能保持完整质量和选择性部署收益？

## 科学目的与竞争预测

E153–E155表明：B的任务子集部署更好，R仍承担关键作用，而共享路径的重要性在后期历史中增加。下一步应识别能够重用的计算整体，而非只继续零化组件。

本卡固定共同父P的dense骨干和全部gate参数，在R/S来源P、A、B的3×3全矩阵中直接组合函数。它把接收者差异从A/B比较中拿开，检验共同来源的协作是否有可操作的预测意义，并主动寻找零样本功能迁移。

- 若R_B单独携带部署性质：固定S_P时也应出现相应收益。
- 若共享函数是通用支持：S_B能在多个R来源中携带收益，不要求同源R。
- 若历史形成了特定R/S配套：同源组合应比相同边际来源的异源组合更能保持能力或预算性质。
- 若R/S共同迁移仍不能保持性质，而原native B在同mask下能够：接收者的D/G接口也是重用边界的一部分。该结果不等于任何重用在原则上不可能。

## 固定资产、接收者和条件

1. 同一公开成熟谱系P/A/B及原pins；D/G始终取P，R与S分别取P/A/B，全部9来源格保留。真实127 routed选7+1 shared，shared权重1，selected top7不另归一化。
2. R是完整路由专家函数bank，S是各层始终激活函数；只交换模块引用，不混合单个权重、不调整系数、不训练。D/G参数固定不等于各格H或实际路由轨迹固定；后者可随函数变化。
3. 沿E153/E155固定128题（生物/数学各64）、原dev5 RC格式、原uint32 IDs和答案评分，无新题/筛错题。旧完整native结果作为逐题精确重放参照。
4. 专家可用集从接收者P的原validation-only cal逐层greedy选择31R+1S。先前层mask影响后层cal输入，沿作者接口。两个subject各一mask，随后对全部9格固定，不为hybrid重选。
5. 每格full与同一receiver-mask两policy；另记录P/A/B各native在这同一mask下的full与restricted参照。P/P角复用native P，实际共22个不同条件/题。A/B donor的原native选择mask不参与本轮优化。
6. 主分析全部128题；次分析为E155 native P/A/B均答对的固定44题（生物36、数学8），该集合在任何E156重组读数前冻结，仅用于控制“同一已成功任务”。它是预先固定的新干预条件分析，不是新数据独立确认，且不能替代全样本；选集合未使用任何重组结果。

## 预定读数与统计

- 原raw/per-char accuracy、四候选choice CE、正确答案token NLL，full与restricted的绝对质量全部报告。
- 相对每格自己的full，报告正确率下降、CE/NLL增加、首答案token真实全词表KL；另报告P native full→各格full/restricted的首token KL，区分移植损伤与预算敏感性。choice-score KL另列，不称整LM分布。
- 主要来源配套对比只在A/B四格：loss的异源均值−同源均值；accuracy反向定义同源−异源。full与restricted/各自预算代价均报告。P行/列作为共同起点及单模块迁移参照，不靠P/P天然身份优势认定同源配套。
- 将R_B/S_B单独与共同迁移的完整质量、预算保持并列；直接判断实用重用及其权衡，不把更差full带来的小drop叫迁移成功。不存在“必须阳性”条件。
- 两固定subject内成对question bootstrap1000次、seed156001，macro等权；共同成功集同样按其36/8分层，分科计数与结果全报。9格不是9个训练seed，不把CI作初始化总体。
- 所有条件由来源和事前规则定义，不根据held表现聚类、选配对或调读数。

身份/原生重放地板0，统一实际BF16。比较真实质量和预测损伤，不做数学能量差的线性NLL校正。共同P gate会调用donor在其自身native之外的输入/支持，这正是本接收者的零样本重用条件，不据此宣称普遍语义单位。公开谱系不是训练batch字节链；语义职责与一般幅度/函数适配仍可共同作用。E155共同成功集先用native基线选择，会排除干预纠错，结论只限该固定集合。
