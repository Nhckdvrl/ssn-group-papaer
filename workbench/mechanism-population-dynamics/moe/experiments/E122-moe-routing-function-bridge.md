# E122：路由组织能否预测专家计算差异（2026-10-25）

- **状态：** DONE
- **类型：** PILOT（handoff X1）+ REPRO（纠正 E121 检验）
- **对应：** 痛点 P15（语言组织检验与推断桥）、P16（KL 与 NLL 混读）；不恢复头线。
- **问题（一句话）：** 在相同输入上，路由相近的专家是否计算相近，且路由距离是否能预测留出输入上的替换损伤？
- **设置：** E121 的 OLMoE-1B-7B-0924 main 权重与 capture.pt/r3_raw.pt，固定 E121 原始样本及 cal/held。主层 L9，对照 L2；其余层作分层描述、不挑最显著层。全部 64 专家对同一组输入前向。随机种子 122；共同输入由 H_cal 的 cal_meta 按来源文档划成互斥两半，各至多 1024 位置，先固定抽样索引再计算。2026-10-25运行前审计：前缀会包含前句，故从句子升级为文档分组（POS去sent末尾-句号，SemCor去末尾.句号）。另对全部 POS 目标输入算专家输出，用于连接原 R3。
- **读数：**
  1. 路由相似 R：共同输入上专家二元 top-8 选择向量的 Pearson 相关（phi）；专家从未被选中时该对缺失，必须报覆盖率。
  2. 函数相似 F：对同一输入的专家输出逐样本余弦，再对输入平均。报告 cal/held 两半间 F 和 R 的一致性、R/F Spearman，以及控制专家负载与输出范数的偏秩相关。专家对非独立，显著性使用层内同步行列专家标签置换（999 次），不按 2016 对独立计算 p。
  3. 因果连接：held POS 的第1名→第9名、随机未选专家替换，以 cal 集 R 定义路由距离；测与原 KL、ΔNLL 的关系。控制被替换门控权重、路由分数差、原 NLL，报告按词形 bootstrap 95% CI。另检验同输入输出差异与损伤的关系。旧 KL 含 fp16 基线误差，KL 减去同条目 self 的值仅作敏感性分析，不能重建已丢精度；ΔNLL 为并列读数，不混为“损伤”。
  4. E121 POS 复核：在词形内置换逐样本标签后重建 same/different 对；p=(count+1)/(B+1)。分别报告原 all 口径与独立 held 口径，词形平权效应、词形 bootstrap CI；32 个 N1 抽样，cal 不变。不能用 cal+held 的结果声称留出复现。
- **阳性对照：** F 对角为1；自身替换输出差为0；同专家输出复制已知得到 F=1。路由距离与自身距离为0。置换代码用同词同标签结构的已知答案验证；沿用 E120 已验证 N1，不变更几何零假设。
- **噪声地板 + MIE：** 自身替换的旧 KL/NLL 和两半抽样稳定性；R/F 偏相关 |ρ|≥0.2、两半同方向作为选择代理的探索尺度，非科学判决门槛。若输出相似性有关但留出替换效应 CI 包含0或小于此尺度，不能称为职责代理。
- **混杂审计：** 输入对共享样本→样本标签置换；专家对共享专家→QAP标签置换；选择路由与计算使用不同输入半；负载/范数/门控差距/原难度显式控制。词形bootstrap不等于跨训练CI。单模型、EWT体裁与旧fp16 KL未控制，限定措辞；无提示词能力主张；没有多种子/跨模型泛化；全部分层与阴性一并报告。
- **决策表（跑之前写）：**
  - R/F稳定相关，且路由距离对held替换损伤有增量→X2同时保留路由与条件干预，路由可作便宜的辅助量。
  - R/F相关但替换预测弱→函数相似不等于职责相似；X2必须直接测功能与干预，不增加更多词性切片保结论。
  - R/F亦弱→路由组织与共同输入上的计算差异脱节；X2仍问固定几何下两者各自是否重现。
  - 信度不足→只补一次等量共同输入；不铺开更多层/数据寻阳性。
  - POS旧p结论改变→在CLAIMS/HANDOFF登记更正，不覆盖旧结果；不影响X2要回答的开放问题。
- **算力预算：** 4 GPU·时上限，单卡/分层独立并行；CPU统计。**实际：** 16层计算/统计总墙时1,645秒（0.457卡时），另有POS审计/加载；整批约0.6卡时，未超过1卡时。

### 主层与POS纠正（2026-10-25）
- **正确样本置换保留POS组织效应：** held 964位置、48词形，16层残差CI均>0，999置换p≤0.002；L9 δ_D=0.20594 [0.18131,0.22787]，残差/原始=0.529。L0=0.01036 [0.00187,0.01931]，比例0.097，低于原20%尺度。旧pair标签置换p仍作废，不能因纠正后方向相同而恢复错误检验。
- **L9 R/F：** 按文档分半，R相似性拆半ρ=0.9934、F=0.9852。两方向交叉半的偏秩相关0.4634/0.4541，诊断性QAP p=.001（含负载/范数协变量及标签交换性假设）。
