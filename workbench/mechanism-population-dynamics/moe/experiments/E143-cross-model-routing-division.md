## 设置
- **模型（全部 bf16 推理，不训练）：**
  - 上限参照：OLMoE-1B-7B-0924 `main` 与 OLMoE-1B-7B-0125 `main`（0125 从 0924 的 step1200000 继续退火，同一个 run）；OLMoE `main` 与本地已有 `step600000`（同 run 不同时刻）。
  - 不同团队：Qwen1.5-MoE-A2.7B（60 专家 top4 + 共享专家；由 dense 升级）、DeepSeek-V2-Lite（64 专家 top6 + 2 共享；首层 dense）、Granite-3.1-3B-A800M-base（40 专家 top8）、Qwen3-30B-A3B（128 专家 top8；本地缓存为后训练版，单独标注）。
  - 只看路由专家的选择；共享专家不参与划分。
- **文本：** UD English EWT。按文档拼成段落（同一 `newdoc` 的句子用空格连接，每段 ≤ 400 词），每个词都有前文。
  - 校准集 = dev（只用于零假设的偏置拟合）；锚点 = test 全部 + train 前 4000 句（文档完整）。
  - 词与子词对齐：每个 UD 词取**覆盖其最后一个字符的子词**（因果模型在这里已看完整个词）；该子词若越过词尾（与后续字符合并），该词在该模型上作废。分析只用在所有模型上都有效的词。多词 token 行（如 don't）整体跳过。
- **每个模型每层采集：** 路由器输入 h（MoE 块的输入）与路由器权重 W；选择 S = topk(hWᵀ)。先核对与模型自身前向的路由 logits 一致（不一致则修代码，不分析）。

## 读数
- **路由核：** K(i,j) = |S_i ∩ S_j| / k（与专家编号无关，不同 E、k 可比）。**表示核：** 中心化 h 的余弦。
- **上下文一致（主读数）T_ctx：** 只取**同一词形（小写）**的出现对。每个词形内减去该词形的平均 K，得到“同一个词哪些上下文被分得近 / 远”的偏差；两个模型偏差的合并相关即 T_ctx。词身份的贡献因此被精确扣掉。词形需 ≥ 6 次出现；每个词形最多取 40 次出现，避免高频功能词主导。
- **词汇一致（参照）T_lex：** 每个模型用校准集算每个词形的平均选择向量，比较不同词形之间的核相关——两个模型是否把同样的词归到一起。
- **表示参照 T_ctx^h：** 用表示核算同样的上下文一致。它度量“两个模型隐状态本身在上下文区分上有多相似”（“表示收敛”层面的自然一致）。
- **几何零假设 T_ctx^D：** N1 零假设（E120 验证过；保留路由器的读出子空间与奇异值，在子空间内随机旋转，偏置重拟合以匹配负载，32 次）。D = K − E_null[K]，同样在词形内中心化后跨模型相关。>0 表示真实路由器在同一几何之上做出的具体选择也跨模型一致。
- **层对应：** 所有层对 (la, lb) 都算，报告完整矩阵；按相对深度报告最佳匹配层，不只取最大值（最大值有选择偏差，同时报告对角相对深度的值）。
- **语言学分解（解释用）：** 词形内同词性 / 异词性对；T_ctx 在回归掉“是否同词性”之后的残差相关（超出词性的上下文一致）。
- **不确定度：** 按词形的聚类 bootstrap（1000 次）给 95% CI；对模型 B 在词形内打乱出现顺序作置换零点（200 次）。

## 混杂审计
- 分词器不同：已控制（词级对齐、只用所有模型都有效的词；报告丢弃比例）。
- 词频 / 词身份：已控制（词形内中心化；每词形限 40 次）。
- 模型深度不同：已控制（全层对矩阵 + 相对深度）。
- 数据 / 架构 / 种子混在一起：**未控制**，本实验只回答“不同团队的模型有没有共同的分工”，不回答“同配方重跑会怎样”。
- 后训练（Qwen3-30B-A3B）：未控制，单独标注，不进入主比较的汇总。
- 路由 ≠ 功能（E122）：本卡只测划分；功能读数（消融某专家后哪些词损失上升）在本卡结果后再设计。

## 决策表（跑之前写）
- 上限 T_ctx < 0.5 → 测量不稳，修测量，不解释其它。
- 跨团队 T_ctx 的 CI 全部含 0 → 分工收敛只在词层面（若 T_lex > 0）；方向 A 的主命题不成立，转为报告“上下文分工不收敛”的条件，再决定是否值得继续。
- 跨团队 T_ctx > 0 但 T_ctx^D ≈ 0 → 一致完全来自共同的表示几何（“一致是自然的”被定量说清）。
- T_ctx^D > 0（CI 排除 0）→ 路由器的具体选择也跨团队收敛：扩大模型集、加功能读数。
- T_ctx 明显高于 T_ctx^h → 路由比隐状态更一致（路由抽取了共享的那部分）；明显低于 → 模型共享表示但分工不同。
- 只在某些层 / 某些词性上一致 → 画“哪部分分工普遍”的地图。
