# E16 — Is run-level arbitration divergence a low-dimensional default offset on a shared knob?（2026-10-02）

- **状态：** DONE（2026-10-02；判定：P1、P2 不成立——diff-of-means 方向不是干净的旋钮；后备方案不适用，按止损规则不再加条件）
- **类型：** PILOT（方向决策后的第一个决定性实验）
- **对应：** E13（410M 10 个 run：同一批都记得的 69 个国家上采信率 0.69–0.99）；C02（70M 门控 = 第 0 层低维偏移）；Minder et al. ICLR 2025（单层一维“旋钮”控制上下文 / 先验）；Yu 2023、Jin 2024（记忆头 / 上下文头可控）
- **阳性对照：** 每个 run 沿自己的旋钮方向施加大幅平移时，采信率应单调变化（若不变，说明旋钮估计失败，而不是假说失败）
- **噪声地板 + MIE：** 国家级 bootstrap；实验单位 = run（n=10）；MIE = 跨 run 采信率 SD 下降 ≥50%（对照方法 ≤20%）
- **决策表（跑之前写）：** 见下方
- **问题（只回答这个）：** 同一配方的独立 run 在上下文-记忆仲裁上的差异，是否等价于“共享的一维旋钮上默认位置不同”？即：只在校准条件上为每个 run 拟合一个标量偏移后，各 run 在 held-out 国家和 held-out 问句模板上的行为是否趋于一致？

## 设置
- 模型：`pythia-410m` + `seed1..9`，step 143000。
- 国家：E13 中所有 run 都“已知”的 69 个国家，按固定种子分为校准 34 / held-out 35；每国 20 个干扰首都（同 E13）。
- 冲突句：`The capital of {country} is {distractor}.`；问句模板（Fouilhé 2026 `build_capitals_context_sweep.py`）：qa（校准用）、bare、possessive、learned、of_course（held-out 模板）。
- 采信 = lp(干扰) > lp(正确)（与 E13 相同）。

## 步骤
1. **旋钮估计（每个 run 各自）：** 校准国家 × qa 提示，取最后位置各层 resid_post；按该 run 自己的结果标注（采信上下文 / 坚持记忆）；方向 = 两类均值差（归一化）。层选择：校准国家再二分，在后一半上的 AUC 最大的层。
2. **充分性：** 在选定层最后位置加 α·k̂（α 以该层 resid 范数的倍数表示，网格 −2…2），记录校准集采信率曲线。
3. **默认值对齐：** 目标 = 10 个 run 在校准集 qa 上采信率的中位数；对每个 run 用二分法找标量 α_r 使其校准采信率 = 目标。
4. **检验：** held-out 国家 × 5 个模板（qa + 4 个 held-out 模板）上，比较对齐前后跨 run 采信率 SD。
5. **对照：** (a) 随机方向（与 k̂ 同范数、同样二分拟合 α）；(b) Yu 式对齐：缩放各 run 自己的 top 记忆头输出以匹配目标。
6. 副作用：对齐后干净提示（无冲突）的首都正确率、Pile loss（500 条）变化。

## 预测（预注册）
- P1：≥9/10 run 的旋钮在校准后半上的 AUC ≥ 0.8。
- P2：≥9/10 run 沿自身旋钮的采信率曲线单调，且跨度 ≥50 个百分点。
- P3：默认值对齐使 held-out 国家上跨 run SD 下降 ≥50%（5 个模板的中位数）；随机方向对照下降 ≤20%。
- P4（不作方向预测，只报告）：Yu 式记忆头缩放对齐的 SD 下降量。

## 决策表
- **P1–P3 成立：** run 间仲裁差异 ≈ 共享一维旋钮上的默认偏移，并能泛化到未见国家与模板 → 与 C02 合并为“共享机制、低维使用默认值不同”的论点（C04 候选）；下一步在 160M 群体与第三个使用维度上检验。
- **P1–P2 成立、P3 不成立：** 旋钮存在且可控，但 run 差异不是一维偏移（多因素）→ 报告，并检验二维 / 头级解释。
- **P1 不成立：** base 410M 中没有可用 diff-of-means 找到的旋钮 → 改用 Minder 的学习子空间方法再测一次（不改其他设置）。
