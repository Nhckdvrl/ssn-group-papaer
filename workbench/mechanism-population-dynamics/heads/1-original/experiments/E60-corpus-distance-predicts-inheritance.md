# E60：语料越相似，初始化的槽位继承越强？（2026-10-03）

- **状态：** DONE
- **对应：** C05（边界条件的定量版本；E46 / E56：受控训练中同初始化的 c4–papers 继承 0.20–0.26，涉及代码 ≈ 0）
- **问题：** 在 DataDecide 的配方对之间，语料的低阶统计（单词、双词分布）越接近，同初始化模型的层内头身份是否越一致？
- **设置（只用 CPU，`scripts/e60_corpus_distance.py`）：**
  - 配方统计：E23 缓存的各数据源目录样本（每个约 1000 万 token），按配方的数据源大小加权，得到单词分布和哈希双词分布（2^22 桶）；配方两两之间算 Jensen–Shannon 散度。
  - 继承：每个配方对，取两者共有的初始化，计算同初始化模型之间的层内 Spearman 再平均（M1、M2、M4；M1 只用 M1_max > 0.3 的模型）。
  - 尺寸：1B（E35，25 个配方 × 3 个初始化）、60M–750M 与 1B@7500（E45）。
- **读数：** Spearman(JS 散度, 继承)；Mantel 式置换检验（置换配方标签，单侧：距离越大继承越弱）。
- **怎么读：** 显著负相关 → “初始化的槽位在多大程度上被继承，取决于语料在训练早期提供的低阶统计有多相似”，与关键期结果合成一条机制：关键期内的梯度主要由低阶统计决定，统计相同则对称性以同样方式破缺；无相关 → 在 DataDecide 的配方范围内（都是英文网页类文本）继承与语料距离无关，代码这类差异巨大的数据是唯一的例外。

## 结果（跑完后填写）
（`results/e60/analysis.json`、`results/e60/disjoint_control.json`、`results/e60/controlled_dose_response.json`）
- **语料距离：** DataDecide 25 个配方两两之间的单词分布 JS 为 0.0002–0.058（都是英文网页类文本）；受控训练语料 c4–books 0.11、c4–papers 0.13、涉及代码 0.40–0.43（同一分词器，可直接比较）。
- **主结果：语料越相似，初始化的槽位继承越强，每个尺寸都成立，并随规模增强。** Spearman(JS_uni, 同初始化层内相似度)，Mantel 置换检验：

| 尺寸 | 配方对 | M1 induction | M2 previous-token | M4 检索 | 只用不共享数据源的配方对（M1 / M2 / M4） |
|---|---|---|---|---|---|
| 60M | 136 | −0.20（p 0.04） | −0.30（0.006） | −0.33（< 0.001） | — |
| 90M | 190 | −0.43 | −0.50 | −0.47 | −0.36 / −0.52 / −0.44（151 对） |
| 150M | 105 | −0.54 | −0.64 | −0.47 | −0.60 / −0.66 / −0.47（74 对） |
| 300M | 105 | −0.73 | −0.78 | −0.69 | −0.67 / −0.72 / −0.65（58 对） |
| 530M | 45 | −0.66 | −0.66 | −0.71 | −0.78 / −0.79 / −0.82（27 对） |
| 750M | 45 | −0.66 | −0.73 | −0.77 | −0.71 / −0.76 / −0.79（27 对） |
| 1B（3 初始化 × 25） | 300 | −0.58 | −0.56 | −0.60 | −0.52 / −0.49 / −0.51（244 对） |

（90M 起所有 p ≤ 0.003；双词分布 JS 方向相同、略弱。）
- **去混杂：** 共享数据源会让早期批次部分相同。只用完全不共享数据源的配方对，相关几乎不变；控制重叠比例后的偏相关为 −0.42 到 −0.82。→ 起作用的是语料的低阶统计相似度，而不是相同的文档。
- **受控训练（E46 / E56，S 尺寸）：** c4–papers（JS 0.13）的同初始化 induction 继承 0.19 ± 0.06，涉及代码的配对（0.40–0.43）≈ 0；previous-token 方向相同但更嘈杂（各配对 Spearman −0.49）。
- **结论（写进 C05，作为叙事的第 5 条）：** 初始化选定的槽位按语料相似度被继承：两个语料在训练早期提供的低阶统计越接近，同一初始化在两者上长出的头分工越一致。这与关键期结果合成一条机制：关键期内由数据的低阶统计驱动对称性破缺，统计相同则以相同方式破缺；规模越大，这条规律越陡、越干净。

## E64 补充：虚词还是实词？（`results/e60/function_words.json`；2026-10-04；只用不共享数据源的配方对）
- 词表：843 个虚词 token、44,244 个实词 token；各配方虚词总质量 0.29–0.41。英文语料之间虚词分布几乎相同（平均 JS 0.0066），实词分布差异大得多（0.0328）。
- **实词分布决定继承：** Spearman(实词 JS, 同 seed 层内相似度) 每个尺寸都显著（90M −0.23 到 −0.40；300M −0.48 到 −0.52；530M–1B@7500 −0.46 到 −0.69）；控制虚词 JS 后的偏相关仍为 −0.24 到 −0.78。
- **虚词分布没有额外作用：** 原始相关较弱（−0.10 到 −0.46），控制实词 JS 后偏相关为 ≈ 0 或转正（−0.06 到 +0.63）。
- **结论：** 同一个 seed 的分工能在多大程度上跨语料保持，取决于语料**在讲什么**（实词：话题、领域），而不是**怎么讲**（虚词：语法骨架，英文语料之间几乎不变）。代码在两方面都不同，是距离规律的极端端点。（虚词在英文配方之间变化小、统计功效有限，留作审稿人可以问的点。）
