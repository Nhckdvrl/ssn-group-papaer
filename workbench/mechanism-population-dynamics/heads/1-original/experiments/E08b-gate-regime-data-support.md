# E08b — Data support and copy reliability of the gate's regime, on a large Pile sample（2026-10-02）

- **状态：** DONE（2026-10-02；判定：门控区域几乎无数据支持；“合理校准”不成立）
- **类型：** PILOT（数据层；CPU）
- **对应：** E08（POST-HOC 发现：pile-10k 中罕见密度 ≥0.75 的位置全部来自一篇希腊语文档 → E08 的高密度档不可信）；H_support
- **阳性对照：** 低密度档的命中率应接近 E08（≈0.26 整体）
- **噪声地板 + MIE：** 二项 95% CI；按文档聚类的 bootstrap（文档数 < 30 的档标记为“不可判定”）
- **决策表（跑之前写）：** 见下方
- **问题（只回答这个）：** 在大样本训练分布中，(1) 罕见主导的上下文占多大比例、来自哪类文本（英文 vs 非拉丁文字 vs 代码 / 编码数据）？(2) 在这些上下文中，复制规则（当前 token 前文出现过 → 预测其后继）的命中率是否低于普通上下文？(3) 与我们刺激同类的“罕见**英文**词片段主导”的上下文是否存在？

## 设置
- 数据：NeelNanda/pile-small-tokenized-2b（GPT-NeoX tokenizer），流式。前 1 亿 token 统计频次（定义罕见 = 计数 < 该样本中与 pile-10k 阈值等价的分位）；接下来不相交的 1 亿 token 做统计。按 EOS（id 0）切分文档。
- 与 E08 相同的命中定义与密度分档；每个位置的上下文类型：前 50 token 中“非 ASCII 解码”比例 ≥0.5 → 非拉丁；否则若罕见 token 中 ≥80% 是英文字母词片段 → 英文罕见。
- 罕见阈值：计数 < 50 × (1e8 / 1.5e7) ≈ 333（按样本规模缩放 pile-10k 的阈值）。

## 决策表
- **门控区域确有数据支持且复制不可靠：** 高密度档（≥0.75）文档数 ≥30，且命中率比低密度档低 ≥10 个百分点（文档级 bootstrap CI 不重叠）→ “合理校准”可以作为解释写入；同时报告该区域的文本类型。
- **门控区域几乎无支持：** 高密度档文档数 <30 或占比 <1e-5，尤其“英文罕见主导”上下文几乎不存在 → 我们的刺激属于训练分布外；门控行为是外推，H_support（run 间分化来自数据无约束）成为主解释，“合理校准”不写。

- **判定：门控区域几乎无数据支持。** 罕见密度 ≥0.75 的位置共 1,355 个（≈1.5×10⁻⁵），英文罕见主导的只来自 3 篇文档（<30，预注册为不可判定统计）。我们的刺激所在区域属于训练分布外。
- **“合理校准”不成立：** 在有数据的中等罕见区域（0.25–0.5，1,658 篇文档），英文罕见上下文中复制规则的命中率**高于**普通上下文（0.40 vs 0.27）；高密度档的少量样本命中率也高（0.6–0.94）。E08 中的低命中率来自 pile-10k 中单篇希腊语文档，作废。
- **解释更新：** 后期门控是训练动态在数据真空区的副产物（外推），不受数据约束 → 这与其 run 间 25× 差异一致（H_support 成为主解释）。
