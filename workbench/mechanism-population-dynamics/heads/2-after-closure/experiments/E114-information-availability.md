# E114：遗忘后任务信息是否还在？——信息存留假说（2026-10-17）

- **状态：** DONE（07:43；IOI 上格式保留预测重学，Pearson 0.96）
- **类型：** CLAIM（解释读取侧 / 写出侧不对称的候选机制；E112 否定了“足迹宽度”之后提出）
- **假说：**
  - 读取侧遗忘（读者的 QK）只让读者不再读取，读者所读的源头信息仍完好，所以良性训练中网络可以学着重新读到；
  - 写出侧遗忘（OV / MLP）改掉了源头信息本身，绕不过去。
  - E105e 已显示：良性重学不是在参数上撤销遗忘，而是在功能上绕过它；残留的遗忘效果主要在 MLP。
- **设计（scripts/e114_probe.py）：** 线性探针（逻辑回归），两种读数：
  - 沿用原模型训练的探针（格式是否不变）；
  - 在该模型上重新训练的探针（信息是否线性可读）。

## 07:15 第一轮（探针位置放错，记录在此作为教训）
- **首都，末位（句末），第 10 层：** 原模型 1.00；qk_deep 冻结探针 0.905、重训探针 0.476；ov_deep 0.952 / 0.905。前几层（4 / 6 / 8）在原模型中都接近随机——首都身份要到第 10 层才被搬到末位。

- **至此，读取侧 / 写出侧不对称的三个机制候选都未成立：**

- **现象本身（IOI、首都、两个种子、深度匹配、损失受伤匹配）是稳的；机制是开放问题。**

## 07:43 IOI 探针结果：信息都还在，差别在“格式”是否保留
句末位置，第 8 层（第 6 / 10 层同向），标签为“间接宾语是否是先出现的名字”。原模型：冻结探针 = 重训探针 = 1.00。
| 遗忘模型 | 冻结探针（原格式） | 重训探针（任何线性格式） | 良性重学 r |
|---|---|---|---|
| qk s1 / s2 / rw30 | **0.93 / 0.93 / 0.96** | 1.00 / 1.00 / 1.00 | 0.85 / 0.86 / 0.83 |
| reg30_s1 / reg0_s1（E112） | **0.96 / 0.93** | 1.00 / 1.00 | 0.82 / 0.86 |
| attn s1 / s2 | 0.87 / 0.83 | 1.00 / 1.00 | 0.69 / 0.68 |
| ov s1 / s2 / rw0 | **0.52 / 0.51 / 0.51**（随机） | 0.99 / 1.00 / 0.99 | 0.49 / 0.51 / 0.48 |
| mlp s1 / s2 | **0.48 / 0.48** | 0.99 / 0.99 | 0.47 / 0.47 |
| all s1 / s2 | 0.49 / 0.48 | 0.99 / 0.99 | 0.56 / 0.57 |

- **所有遗忘之后，任务信息都还在**（重训探针 ≥ 0.99）。
- **差别在格式：** 读取侧遗忘保留了上游特征的原编码（冻结探针 0.93–0.96）；写出侧遗忘把上游特征**重新编码**了（冻结探针降到随机水平），读者随之按新编码读取。
- **格式保留程度预测重学比例：** 冻结探针准确率与 r 的 Pearson 0.958、Spearman 0.83（n = 14）。
- **区分“格式”与“足迹”的关键点是 E112 的 reg30：** 它的足迹被压到 0.22，格式仍保留（0.96），r 仍高（0.82）。格式预测对了，足迹预测错了。
- **判断（候选机制，仍是相关证据）：** 良性重学恢复的是“读者与上游写出之间的接口格式还在”的修改——上游仍按原格式写出，一般数据中的类似上下文会让读者（或其他头）重新读回去；上游被重新编码后，没有一般数据压力把编码改回原样。
  - 这与受控损伤中“写出方向被旋转就等于完整重置”是同一原理：读者依赖的是写出的**格式**，不是信息本身。
- **下一步（因果检验）：** 直接操纵格式——例如在 QK 式遗忘的模型中，对上游写出的该特征做一次可逆的重新编码（同时相应调整读者，使行为不变），看它是否因此变得抗良性重学。
- 首都上的对应检验（E114c，logit lens）没有支持“读取侧保留源头信息”，但首都属性在后几层才写入国家名位置，测量位置本身受注意力影响，两项结果暂不矛盾。
