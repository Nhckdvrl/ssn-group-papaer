# E112：把读取侧遗忘的足迹压窄，它还会被良性训练撤回吗？——足迹机制的因果检验（2026-10-17）

- **状态：** DONE（06:55；判定“足迹只是相关”）
- **类型：** CLAIM（E110 / E111 的因果检验；同时是一条设计准则的检验）
- **来源：**
  - E111：读取侧（QK）遗忘在一般文本上扭曲注意力，是写出侧的 11–14 倍，与良性重学比例排序一致；

- **干预：** 做 QK 式梯度差遗忘时，额外惩罚一般 Pile 文本上注意力的改变：KL(原模型注意力 ‖ 当前注意力)，位置 ≥ 16，8 × 256 token，权重 attn_reg ∈ {3, 30}。其余同 E105b（lr 5e-6、margin 0、IOI < 0.5 即停），种子 1、2；之后在 Pile 上重学 1000 步。

## 登记的预测（04:00）
- **足迹是原因：** attn_reg = 30 时，E111 测得的一般文本注意力 JS 降到 ≤ 0.4（原 QK 式 1.1–1.4），且重学比例 r ≤ 0.65（原 0.83–0.86）；attn_reg = 3 时在两者之间。
- **足迹只是相关：** JS 被压下来，但 r 仍 ≥ 0.8 → 足迹不是原因，另找机制（例如读取参数本身处于回坡，与上下文广度无关）。
- **做不到：** 若在 attn_reg = 30 下，QK 式遗忘无法把 IOI 压到 < 0.5（读取参数无法在不扭曲一般注意力的前提下完成遗忘），这本身也是信息——读取侧的遗忘必然足迹宽——记录下来，换用较小权重。
