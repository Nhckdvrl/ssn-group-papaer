# MoE 专家分工这个题目：整理、哪里不可行、之后怎么做（2026-11-26）

> 详细经过见 [division/README](division/README.md) 与 [PROGRESS_REVIEW](division/PROGRESS_REVIEW_2026-11-22.md)；导师原话见 [ADVISOR](ADVISOR.md) 的 11-05、11-19 两节。本页只整理研究内容。

## 1. 题目是什么

**导师的问题（10-16 起一直没变）：** 同样结构、同样数据、只换随机种子、从头分别训练的 MoE，会不会自发分出同一套专家分工？

他认可的做法（11-05、11-19）：

- 把同一批句子喂给不同模型，比较路由分配；用与专家编号无关的尺子，数“两个词在模型 A 里进同一个专家，在模型 B 里是不是也进同一个专家”。
- 必须和随机比，还要说清“多大算大”：一个一致度单独不是结果，要能说成“这类模型低、那类模型高”。
- 从头训练是核心；从已有 checkpoint 续训得到相同分工是“それはそうだろう”。
- 理想形态是“自己从头训练的小模型 + 大规模公开模型，呈现同一趋势”。

我们准备的结果分叉：

- **分工相似**：分工由数据和结构决定，在一个模型上做的专家分析可以推广到别的模型。
- **分工不相似**：专家分析只描述某一次训练。

## 2. 做了什么

| 阶段 | 做法 | 主要结果 |
|---|---|---|
| A 自训小 MoE | 12 层、64 专家的小 MoE，训练 10 本；扣掉“同一个词去同一个专家”和隐状态几何两种零假设，再比较分工 | 只换初始化 .23；同一设定重训 .47；未训练 ≈ 0。粒度越细越不一致：词类级 .56 → 同词形 .45 → 逐 token .20。随专家数变化：16 专家 .13 → 64 专家 .44–.53 → 256 专家 .81。已发表的 7 类专家结论里，有 4 类在“训练好的隐状态 + 未训练的路由器”上就已成立 |
| B 公开 MoE 上的随机路由器对照 | 7 个公开 MoE；在同一隐状态上换成随机路由器，检验已发表的专家分析结论 | “首尾层专属语言”的层剖面由随机路由器复现，主要跟着文字走；训练出的路由器只把语言专属度乘上一个常数（1.1–1.8 倍） |
| C “路由器先于表示定型”（N4） | 两条公开训练轨迹；中途冻结或重置路由器后续训 | 路由器一侧比表示一侧先到终点；冻结路由器没有损失代价；重置后深层约七成回到原分工。**11-19 被导师否定**：“谁先定型”取决于定义，结果取决于两边更新幅度，是程度问题；二分本身不自然 |
| D 面谈后调研 | 17 篇全文精读；设计公开 16B 模型之间的比较 | 独立训练的 MoE 之间、用与编号无关的尺子比较分工，确实没人做过；11-22 停止 |

数字本身是可靠的：测量误差小，同一读数重复测量结果稳定。问题不在测量精度，而在下面几处。

## 3. 哪里不可行

一句话：**问题本身合理，但在能用的手段下，只有“相似”这一侧的结果能解读，而它基本在预料之中；“不相似”这一侧分不清是偶然还是配置不同。** 五处具体原因如下。

### ① 自己训练的小模型：答案是“看设定”

- 同一个读数随专家数从 .13 变到 .81，top-k、层数、数据顺序也都会改变它；连“同一设定重训”的上限也只有 .47，而且这个上限随训练量漂移。
- 专家数这条轴本身也不干净：专家数变了，分区的粗细跟着变，尺子的随机水平也跟着变；top-k 又和专家数绑在一起；每个设定只有 1–2 对模型。曲线上升，有多少来自“分工更一致”、多少来自尺子本身，分不开。
- 小模型的结果也不能代表现代 MoE：真实规模的模型不可能用多个种子重复训练，小规模的趋势能否外推无从检验。

结果就是只能说“一致度取决于设定”，这正是导师说的“程度の問題”。

### ② 公开模型这条腿：没有“只换种子”的大模型

- 公开 MoE 都只训练一次，没有像 PolyPythias 那样的多种子套件。
- 同一配方、独立训练的只有 FLAME-MoE 的 7 个尺寸（最大 1.7B）。但它们尺寸不同，种子的影响和尺寸的影响混在一起；层数也不同，比较前先要决定“哪层对哪层”，而对层的方式本身就是一个定义。
- 大模型之间（DeepSeekMoE、Moonlight、Instella 等）数据、分词器、路由函数都不同。一致度高，结论成立；一致度低，分不出是“分工本身有偶然性”还是“配置不同”。

结果分叉里有一侧无法解读，不满足“每种结果都能回答问题”这条标准。

### ③ 尺子：大部分“一致”来自词本身和隐状态几何

- 在训练好的隐状态上接未训练的路由器，已发表的专家结论有一多半照样成立（自训小模型上测）。所以“分工相似”的大头来自“同一个词去同一类专家”和隐状态本来的形状，不来自学到的路由。
- 扣掉这两项后，逐 token 一级只剩 .20。扣哪种零假设、怎么扣，数字和结论都会跟着变（零模型选法甚至能把结论翻过来），关键概念依赖我们自己的定义。

### ④ 结果大致能事先猜到

MoE 主要按 token 身份路由，这在文献里早有记载。因此可以预期：词一级会相似，逐 token 一级会弱。两头都在预料之中，容易被说“それはそうだろう”。

### ⑤ “所以呢”说不清

- 写出来的结果分叉是“相似 → 专家分析可以推广；不相似 → 只描述一次训练”。但目前没有哪项工作的做法依赖这个答案。
- 注意力头那条线已经答过同类问题：算法能跨种子迁移，具体组件不能。那条线最后也停在答不出“所以呢”。
- 试图换成可测的形式（N4“谁先定型”）时，又变成了导师否定的二分和程度问题。

## 4. 之后怎么做：向导师和同学请教两件事

幻灯片：[moe_review_2026-11.pptx](moe_review_2026-11.pptx)（9 页：问题 → 做了什么 → 进めにくい理由①–⑤ → 学到的条件 → 今后的两个方案；请教的话口头说，不写在幻灯片上）。

**从 MoE 学到的、立题时的条件：**

1. 结论不被训练设定的细节左右。小规模自训可以用，但要先确认换设定后结论的方向不变；不是只能用公开模型。
2. 每种结果都能解读。
3. 尺子不依赖我们自己的定义。
4. 能和已有说法给出相反的预测，结果出来后有东西会变。

再加上导师跨学生反复提的 E1–E12（[ADVISOR](ADVISOR.md) §E）。

**请教一：如果继续 MoE，打算这样推进。**

- 把问题收窄为“在什么条件下分工会一致”，只沿一条轴比较，比如专家数。
- 同一配方、只换种子训练几个小模型，再和同一配方的公开模型（FLAME-MoE）对照，看趋势是否一致。
- 以“词本身 + 隐状态几何能解释的部分”为基准，看有没有超出这部分的一致。
- 还剩两个问题没解决：一致度低时怎么解读；结果出来以后会改变什么。

**请教二：要不要换题。** 现在的候选是自我纠错的盲点（[提案](TOPIC_PROPOSAL.md)）。预实验显示，只做过预训练的模型就已经有这个盲点，后学习会让它变弱。我看到的问题有四个：

1. **撞车风险**：现象是 Tsui（COLM 2026）提出的；Ni 2610.34809 已发现“自己写的”与“引用别人的”效果相同，和我们“是续写、不是归属”的说法很近。
2. **二分**：“后学习的角色偏差 vs 预训练的续写惯性”是一分为二的问法。“识别力 vs 判定基准”出自信号检测论的标准框架，相对好辩护。
3. **依赖 prompt 和评判器**：检查语只有一句，对话模板只有一种，判定靠 LLM 评判器。
4. **部分结果容易被说“それはそうだろう”**：基础模型会顺着自己的文本往下写；“Wait,” 会让模型更爱改答案。

**不论哪条路：** 先写清楚能说出什么、每种结果各意味着什么、会不会被说成程度问题或“それはそうだろう”，然后才做最小的实验。
