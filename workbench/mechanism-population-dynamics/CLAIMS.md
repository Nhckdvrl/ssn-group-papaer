## 作废 / 降级记录

- 2026-10-10 人决定：Flan / 问答格式开关不再作为研究对象。C04 行及 E25–E34、E47–E49、E50、E53、E65、E76、E80 实验卡已从工作区删除（git 历史中保留；E26 / E28 的条目构造脚本和旧结果目录因被保留代码与旧论文作图引用而保留）。
- 2026-10-10 POST-HOC：E24 的推测性解读“复制能力与冲突时是否选择复制是两件事”不能用跨配方相关支持——按语料家族去均值后 ρ −0.18，家族内方向不一致，问答格式冲突上为 +0.56（`results/posthoc_2026_10_10.json`）。
- 2026-10-10 POST-HOC：E75 的“按功能 / 因果映射后迁移 0.85 / 0.94”中，映射选出的头与目标模型自身 DLA top-3 重合 2/3 ⇒ 这个数字衡量的是在目标模型上重新发现电路，不是源模型的组件知识在迁移；可迁移的只有算法层面的描述。
- 2026-10-08 E75：“同初始化下 task circuit 只部分对应（410M 0.05 等）”——只在**按头编号**比较时成立；按功能类 + 因果读数映射，410M 同初始化 0.85（0.80–0.90）、**异初始化 0.94（0.89–0.99）**，160M 0.89；各模型都是 copy-suppression 头（注意 S2、负 OV 复制）+ name mover 的同一计算，换了承担的头，原承担者休眠 ⇒ 降级为“头编号对应弱，计算对应强”，与 Tigges et al. 2024 一致；初始化决定的只是哪个可互换的头承担角色。只用注意力 / OV 剖面映射不稳定（0.92 / 0.84 / −0.06；类型规则 0.92 / 0.18 / 1.06），承担者需因果读数确定。
- 2026-10-08 E76：“E48 的反向效应来自 part-48 不具代表性”——审计证实 part-48 的 “Question:” 以翻译 / 摘要为主（答案出自上下文 3.7% vs 10 分片合计 37%），但代表性 Flan 继续预训练 1 亿 token 的 QA 线索效应 +0.15 ± 0.24（不可判定），且其中大部分来自陈述格式采信下降 ⇒ 组成只改变降低采信的位置，不装入开关；Flan 继续预训练线按止损关闭。
- 2026-10-08 E73 / E74：“同初始化下 task circuit 的头标签可迁移”只在数据几乎相同且 circuit 集中时成立（Pythia 160M 0.85、1B 0.90）；分散（410M–12B）时 top-3 迁移 −0.05–0.16、集合迁移 0.08–0.15；跨 DataDecide 语料同 seed 只有 0.07–0.16（无关模型 0.04–0.12）；“集中度预测迁移”在 DataDecide 内不成立（ρ 0.01）⇒ v2 把 circuit 层与组件层分开写：组件跟随初始化，circuit 只部分对应。
- 2026-10-06 E68：“头布局在权重已经忘记 seed 后仍能认出兄弟模型（provenance）”——最终权重之间仍有 0.01–0.04 的同 seed 相关，在 4M–1B 每个尺寸都能 98–100% 认出初始化（头布局在 20M 以下只有 56–85%），SeedPrints 从 60M 起 100% ⇒ 降级：认出初始化只作为“痕迹足够具体”的辅助证据；“weights forget the seed”与 provenance 应用从论文删除。
- 2026-10-06 E65：“Question: 习惯的实现头不由初始化安置（0.11 vs 0.02）”——那组数字来自消融归因图，与注意力分数图口径不同；同口径下 Flan 特有的注意力增量 29% 落在本模型最强的 10 个检索头（占 4%），同初始化一致 0.11 vs −0.03 ⇒ 作废原说法。随后自查发现“29% 落在占 4% 的检索头上”也不成立（这些头本来就承担 30% 的实体注意力，新增注意力只是按比例分布，cross-fit 30%）⇒ 最终表述：Flan 改变已有检索头在 Question: 后看多少上下文，不改变由哪些头检索（POST-HOC）。
- 2026-10-06 E66：“关键期在训练 1–2.5% 关闭，之后连换语料都改写不了布局”——换语料在 2.5% / 10% 后仍改写 40% / 29%（Table 6）；warm-up 拉长后窗口在步数上后移，按累积学习率对齐；重置优化器不影响 ⇒ 改写为“布局由早期一小段学习确定；之后噪声改不动，换语料仍改写一部分、越晚越少”。
- 2026-10-02 E03：“后期退化由 token 特异的拮抗头介导”——mean 救援成立，但 zero 方向相反、resample 不救 ⇒ 作废，改为分布级门控假说（E04 支持，见 C02）。
- 2026-10-02 E08：“门控是对语料统计的合理校准”——pile-10k 高密度档只来自单篇希腊语文档；E08b（1 亿 token）显示相反 ⇒ 作废。
- 2026-10-02 E15：“使用策略在自然场景中可迁移”——仲裁采信率可迁移性仅 0.58 ⇒ 从论点中删除，改为“使用强度不可迁移”。
- 2026-10-02 E13：H_support“run 间方差集中在数据支持弱的区域”作为一般规律——第二机制中不成立（ρ=0.08）⇒ 只保留在 induction 门控（C02）上。
- 2026-10-02 E16：“run 间仲裁差异 = 共享一维旋钮上的默认偏移”——旋钮 AUC ≥0.8 仅 2/9、单调 1/9 ⇒ 不成立。
- 2026-10-02 E17：“run 间仲裁差异 = 知识强度差异”——去国家效应 ρ = +0.08（方向相反）、解释 27% ⇒ 不成立。
- 2026-10-02 E18：“上下文依赖是 run 的稳定特质”——跨 12 个条件的 run 排名一致性 410M 0.15、160M 0.26（阈值 0.5）⇒ 不成立；C03 中“使用强度不可迁移”只在单条件（关系 × 问法）意义上成立，不能说成 run 级倾向。
- 2026-10-03 E20 / E22：“语料配方设定一个全局的‘上下文可信度先验’”——采信的跨条件一致性配方层面 0.20、seed 层面 0.10（均 ≤ 0.2）；控制条目频率后 DCLM / Dolma 混合序列不单调 ⇒ 作废。配方效应是逐条件的，集中在问答格式条件（由 C04 的格式开关解释）。
- 2026-10-03 E27：“C04 推广为问答格式密度（行首 Question:/Answer:/Q:/A:）的剂量规律”——25 配方 Spearman 0.445（p 0.027），低于预注册 0.5 ⇒ 不成立；C04 维持为 Flan 单一对照（+ 独立家族检验 E30 进行中）。
- 2026-10-03 E46c：机制假说“头身份的继承强度 ≈ 初始不对称 / 早期 SGD 噪声（相对初始化越大、学习率越小，继承越强）”——受控 2 × 2 中更大的初始化反而削弱继承（主效应 −0.21），学习率无影响（−0.01）⇒ 作废；E45 的尺寸趋势原因未定。
- 2026-10-04 更正 E46c 的作废记录：E46c 的 2 × 2（初始化尺度 × 学习率）比较的是 c4 vs code，而 E56 / E60 表明代码在关键期内重抽槽位（同 seed 继承 ≈ 0）→ E46c 处在地板上，“学习率无影响”与“更大初始化削弱继承”都不能作为结论；改由 E62 / E62b 在 c4 vs papers 上检验（batch 大小、学习率 → SGD 温度 LR / B）。
