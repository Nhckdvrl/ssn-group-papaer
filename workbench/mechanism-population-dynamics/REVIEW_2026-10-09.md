## 1. 一句话（目前最准确的版本）
在不同的预训练 run 之间，机制在不同层级上的对应程度不同：
- **哪一层承担某个角色：** 所有模型都一致。
- **层内由哪个头承担：** 初始化相同的模型跨自然语料共享，初始化不同就不共享。
- **任务 circuit 的计算：** 在不同 run 之间相同（E75），只是换了承担它的头。

头的分工在训练早期一小段时间里定下来，能保留多少，随语料实词的相似度和梯度噪声变化。

## 4. 我的判断
- **中心对象“头的身份”认识价值很低。** 层内的头可以互换，数据不可能偏好某个编号，“由初始化决定”接近必然。E68 显示权重本身也能认出 seed；E75 显示计算在不同 run 之间相同。所以头的身份并不承载机制上的差异。
- **仍有价值的部分：**
  1. 对称破缺何时发生、在什么条件下保留（关键期；语料相似度、梯度噪声）。这讲的是训练动力学，不是头的身份。
  2. 方法上的结论：组件层面的发现只在同一初始化内部成立；层与算法层面的发现跨 run 成立。E75 用初始化 × 数据的交叉设计加强了 Tigges 的结论。
  3. Flan 开关（C04）是一个独立的小发现：数据写入的行为开关由字面模板触发。
- **作为主线，我认为达不到 ICML 主会的强贡献。** 最好的规律解释的是“对称破缺能保留多少”，它的意义基本停在“跨 run 比较头编号时要小心”，而 Tigges / Bali 已经讲了大半。比较合适的形态是范围明确的经验记录（ACL Findings、analysis track 或 workshop）。
- **必须改的地方：** v2 稿（`paper-acl-v2/main.tex` 摘要第 41 行）说的是“哪些头承担 circuit”。按头编号来看这句话没错（E75 中为 0.06），但读者会把它读成“不同 run 的 circuit 不同”。E75 表明，按功能映射后，异初始化模型之间的对应达到 0.94，计算是相同的。投稿前要把这一点写进摘要和正文。
- **如果要继续，我能看到的唯一认识增量方向**是把研究对象从“头的身份”换成“对称破缺动力学”：早期由什么决定哪个头胜出，为什么关键期之后换语料还能改写 29–40%。但 E39 / E41 已经表明，初始权重的统计量和初始梯度都预测不了胜出者，这限制了这个方向。
