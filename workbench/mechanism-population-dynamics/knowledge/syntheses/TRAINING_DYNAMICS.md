# 学习动力学、头专业化与“初始化留下痕迹”的正确解释尺度

## 0. 现象与解释分开

观测：两次训练共享初始权重时，一些注意角色图在不同语料后仍有统计相似；训练早期扰动比晚期更容易改变这种相似。这不自动意味着“角色预刻”或“训练中存在严格不可逆的关键期”。

**真正可以研究的对象**：训练何时、通过哪些子计算或参数状态，逐渐使某些头更容易成为特定角色，以及这种路径依赖对最终真实计算是否有后果。

## 2. 为什么“1%–2.5%的关键期”不是可推广结论

E46的特定实验用了少数初始化、短的10k步小模型和特定扰动；E66的warm-up从300变1000步就改变敏感窗口的步数位置，换语料在窗口之后还可部分改写最终角色图。

因此应写成：**早期学习形成某种受后续训练约束的角色分配倾向，形成速率受训练计划影响**。数值时间窗口不应脱离训练计划和模型/任务硬套成自然规律。

## 3. “一个head形成”的相变可能是多个子过程的合成

[Singh 2024](../papers/SINGH_2024.md)从训练期间对match/copy子电路做activation clamping，看到外观上突变的induction形成可以由多种渐进过程的交互导致。

可迁移的逻辑：不要从某个head的score跨过阈值，推断它被突然选定；要观察形成它所需的上游route、复制投影与下游读取。头间many-to-many交互本来可能比一个winner-takes-all更自然。

[Olsson 2022](../papers/OLSSON_2022.md)的induction角色定义是很好的微观起点，但不是整个ICL发展机制的终点。

## 4. 数据和初始化如何共同作用

[MDA 2026](../papers/MDA_2026.md)在数据级归因和针对性训练干预上有强进展，并在附录F.2.2看到160M多头角色变化；但它还没有证明我们所有目标任务的上游算法都因数据而变。

我们如果观察某个头从任务A变任务B，至少有三种解释：
- 训练数据促使该头本身学到新计算；
- 上游提供的表示改变，而该头的局部参数没有主要改变；
- 同一类计算在多头间重新分配贡献份额。

需要能区分的局部训练/前向因果测试，而不是继续把seed、数据标签作为全部答案。

## 5. 下一轮形成机制的最小高信息量实验

优先在**训练初始状态**而非训练后随意拼接两个模型的head，交叉某个head的完整初始参数与同层其余网络/上游的初始参数，继而在同数据流下独立训练。观察最终角色统计是否跟随局部head或所处网络；如果有差异，再挑一个具体上游路由做交互干预。

不过，[Frozen-QK](../papers/FROZEN_QK_2025.md)已经说明初始QK可以不更新而功能形成；“周围参数也重要”不是新意。实验要继续走向可预测的分工、训练状态或最终实际任务作用，否则只得到一个显而易见的多因素答案。

这是**研究备选**，不是现在可自动启动的训练列表。

## 6. 2026-10-16 补充：什么问题适合用训练轨迹研究，以及新的发育视角

### 6.1 选择标准（来自 E90 卡，经 E91 / E92 的教训修订）
检查点轨迹只在路径含有终点没有的信息时值得用：
1. 终点区分不了竞争解释；
2. 追踪的量与头编号无关（任务共用关系、深度、能力、“有无某类瓶颈”；同一 run 内的组件身份可以比较，跨 run 的编号不行）；
3. 终点存在需要原因的质变差异；
4. 事件在时间上局部、检查点够密。

**本轮的反例**：E91（spike 起点在哪个头）是窄的是非题，答案无论如何都与 Kimi K2 一致；E92 后半段（行为轨迹）被结果牵着走、追踪的是能力曲线而不是机制。两者都已停止。

### 6.2 文献给出的发育图景（详见新卡）
- **阶段与分化**：小模型中训练分阶段（二元组 → n-gram → previous-token → induction），头的发育曲线按功能分型，部分功能在训练中跨层迁移（[HOOGLAND](../papers/HOOGLAND_2025.md)、[WANG_RLLC](../papers/WANG_RLLC_2025.md)）。均未解释“谁专业化、为何”。
- **前提与竞争**：在训练中压制 / 放开某个可解释结构，可判它是能力的前提、副产品还是竞争者；相变期间改动最有害（[CHEN_SAPHRA](../papers/CHEN_SAPHRA_2024.md)）。
- **竞合与暂时性**：两种策略共享子回路又相互竞争，行为起落由组件角色转换驱动（[SINGH_TRANSIENCE](../papers/SINGH_TRANSIENCE_2023_2025.md)，合成）。
- **自然预训练中的错时发育**：IOI 的低于随机下探来自复制头早于抑制头发育；为何复制先发育未解释（[DAHIYA](../papers/DAHIYA_2026.md)）。

### 6.3 我们自己的发育观察（E89–E92）
- 正常 410M 种子：induction 的 previous-token 枢纽头在 1k 步定下、此后不换；后继 / IOI / 主谓一致的主力头多数从出现起就稳定（后继 0/28 次换人，IOI 3/32，主谓一致 3/39）；greater-than 在刚出现时主力落在 previous-token 头上，之后转到 10–13 层的序数头。
- 已否定（2026-10-16，零 GPU 检验）：“被下游读取的组件锁定、末端写出组件流动”。DataDecide-1B 上 IOI 主力的频繁换人（E83）更可能来自贡献分散、前几名接近平局。
- spike 后的重学按原发育顺序进行，晚出现的能力在剩余训练内回不来（E90，n = 2）。

## 7. 2026-10-16：训练期角色再分配（E96，进行中）
- 重置 previous-token 枢纽 3.2 后：只重置 QK（保留下游读取的输出写入）或只重置 OV（保留正确的注意力模式），3.2 都不夺回角色；强制清空备份后也不原位恢复。功能确定地流向原本有弱 previous-token 倾向的头（与重置部分、随机种子无关）。
- 候选规则：功能按损伤前各头在该功能上的强弱转移，受损头不再生（“富者愈富”）。与对称性破缺理论（[SYMMETRY_BREAKING_THEORY_2026](../papers/SYMMETRY_BREAKING_THEORY_2026.md)）一致；E97 做跨功能的事先预测检验。
