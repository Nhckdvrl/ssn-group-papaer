# 综合判断：训练后期的修复只沿已有耦合进行（E93–E101，2026-10-16 19:45）

**性质：** 当前主线的工作判断，不是结论。证据只来自 Pythia-160M、两个功能（previous-token 头 3.2、IOI 头 8.9）的受控损伤，以及 E97 的五个功能（只有完整重置）。学习率 2e-5，窗口最长 5000 步（约等于 Pythia 原训练 330 步的 token 量）。

## 1. 问题怎么来的
方向 B（DIRECTION_2026-10-16.md）：训练中途受损后，模型恢复了什么、靠什么恢复；损失恢复是否意味着能力恢复。E95 否掉了自然事件这个锚点之后，改用受控损伤。

## 2. 现象（每条都有配对对照）
1. **损失恢复不代表能力恢复。** 完整重置 IOI 头 8.9 后，损失 25 步恢复一半，而 IOI 在 5000 步内停在 40%（E98）；在 step8000 上做同样的损伤，IOI 停在 26%，损失恢复 91%（E100）。
2. **完整重置的头不会再生**（E96、E97 6/6、E98，最长 5000 步）。
3. **只要受损头输出端的对准还在，它就会长回原角色**：
   - 3.2 只重置 QK：长回 0.85，并把临时接管者 3.4 挤回去（E96）；即使已有现任 3.0，也在 5000 步夺回到 0.58（E96）。
   - 8.9 只重置 QK：5000 步时自身效应回到 +1.90（损伤前 2.06），反作用搭档 8.10 回到 −0.72，在其他分组中会接手的 9.5 退回原来的 −0.25——整个回路回到损伤前的配置（E101）。
   - 两者都有约 700–1000 步的停滞，然后快速回升；停滞长度与 QK 初始化尺度无关（E99）；轨迹符合 logistic，有现任时速率降到 0.44 倍（E103 基线），E103 检验速率是否由耦合强度决定。
4. **输出对准一旦被破坏，就等于完整重置**：保留 OV 但把输出旋转（范数与谱不变），3.2 与 8.9 都不回来，轨迹与完整重置重合（E99、E101）。
5. **只保留注意力不够：**
   - 8.9 只重置 OV：与完整重置相同（E101）。
   - 3.2 只重置 OV：在没有备份时，读者会重新对准它；有备份时只部分恢复（E96）。
6. **受损头回不来时，功能只流向已经部分耦合的头**：
   - 原有的部分承担者被放大（3.4、7.5、11.7、8.1；E96 / E97）；
   - 或者一个已经在看相关 token 的头改换目标：9.5 在 43k / 100k 已在看名字（主要看 IO，输出为负），损伤后改看 S、输出翻正，接替了 8.9 的“看 S、压低 S”（E100，20:05 更正）。
   - step8000 时没有任何头看 IO，于是没有接手者（E100）。

## 3. 判断
> 继续训练在修复损伤时，只沿已有的耦合进行：受损头残留的、仍被下游按原样读取的输出；或其他头已有的部分功能 / 已对准的注意力。不从没有耦合的头中招募。角色的“记忆”存在下游对受损头输出方向的对准中，不在受损头自己的注意力里，也不在它的 OV 谱里。训练阶段只通过“此时存在哪些耦合”起作用（8k / 43k / 100k 不单调）。

## 4. 为什么值得（相对最强已有认识）
- 重学 / 遗忘文献（Jain 2024；Deeb & Roger 2024；Siddiqui 2025）在整模型层面说明“离原解近就回去”。这里给出组件层面的机制：回去的是哪个组件、靠哪一半、记忆存在谁那里。
- **可检验的推论：** 要让一个组件的功能不被重学，应破坏它输出端与读者的对准（例如旋转），而不是重置它的注意力；只重置注意力的遗忘应当最容易被重学（E101 QK89：0.88）。
- 可塑性文献假设“重置的单元会被重新利用”（ReDo、Shrink & Perturb；未精读）。这里在预训练 LM 中看到相反的情况：没有耦合的新鲜头不会被招募，即使它的位置空着。
- 推理时自修复（Hydra effect）只解释了损伤瞬间的再分配；训练期的修复走的是另一条路（放大已有耦合、原头回归），并且不撤销瞬间自修复。

## 5. 风险与未检验
- 只有两个功能做了 QK / OV / 旋转拆分；E97 的另外四个功能只做过完整重置 → E102 做跨功能的事先预测。
- 学习率小、窗口短：“完整重置不再生”可能只是时间不够。
- 停滞 700–1000 步的来源未知（不是初始化尺度）。
- 只在 160M 上看过。
