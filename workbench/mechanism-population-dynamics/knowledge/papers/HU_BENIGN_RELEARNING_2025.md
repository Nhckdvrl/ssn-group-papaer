# Hu, Fu, Wu, Smith — Unlearning or Obfuscating? Jogging the Memory of Unlearned LLMs via Benign Relearning（ICLR 2025；arXiv 2406.13356 v4）

**阅读范围：** HTML 前约 60%（正文完整，附录 C.5.5 / G 未读）。2026-10-17 精读。
## 设计与结果
- **设置：** TOFU（Phi-1.5，GA）、Who's Harry Potter（Llama-2-7b）、WMDP（zephyr-7b、Llama-3-8b；GA / GD / KL / NPO / SCRUB）、HP 原文记忆。重学都用 LoRA。
- **重学数据：** 部分遗忘集（只见一部分，测另一部分独有的关键词）；或与目标“松散相关”的公开信息（GPT 生成的背景段落，过滤掉直接答案）。
- **结果：**
  - WMDP（zephyr，LoRA 遗忘）：GA 1.67 → 5.2，GD 1.09 → 5.2，NPO 1.00 → 5.08（原模型 5.92，GPT-4 打分 1–10）；普通 NLL 微调就足以恢复，与遗忘目标无关；LoRA 遗忘比全参数遗忘更不鲁棒。
  - 合成实验（“Anthony Mark”）：恢复成功率随“目标在原训练中重复的次数”与重学深度而增；**无关数据也有小的恢复**（乱码 9%、日文 9%、相关名字 20%、直接相关 100%、不重学 0%）。
- **作者的解释：** 遗忘只压低了遗忘集 token 的概率，没有打断 token 之间的关联。
- **局限：** 依赖 GPT-4 评分、样本小；只测了部分方法。
## 五个透镜
- **机制反推：** “只压低输出、没打断关联”是行为层面的描述。我们的 E108 / E110 给出组件层面的版本：改读者的读取参数（QK）只是压低，它处在一般损失的回坡上，被一般训练撤回；改上游的写出内容则大半保留。
- **新的可检验点：** 他们看到乱码 / 无关数据也有小的恢复，我们的 E110 给出原因——一般数据的梯度本身就沿撤回方向有分量，读取侧遗忘的这一分量大 3–4 倍。
