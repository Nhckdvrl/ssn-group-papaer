# Theus, Cabodi, Anagnostidis, Orvieto, Singh, Boeva — Generalized Linear Mode Connectivity for Transformers（NeurIPS 2025 oral；arXiv 2506.22712 v2）

**阅读范围：** HTML 前约 72%（正文完整，附录 C–E 未读）。2026-10-17 精读。
## 设计与结果
- **对称类：** 置换（前馈神经元）、半置换（注意力头、LayerNorm）、正交（残差流，配合 RMSNorm 重参数化）、可逆（线性层；QK、OV 作为不变乘积）。
- **头的对齐：** 在每一层内，用 QK 与 OV 电路的距离做指派问题，实现上是一一置换；**不做跨层匹配**。
- **GPT-2：** 小型模型（6 层；Tiny Shakespeare 4 头 / 256 维，BookCorpus 8 头 / 512 维），每次两个模型。
- **壁垒（两两、同宽）：**
  - Tiny Shakespeare：普通平均 2.02 → 权重匹配 0.34 → 学习匹配 **0.02**；
  - BookCorpus：4.34 → 1.56 → **0.42**；
  - ViT（CIFAR / Tiny ImageNet）学习匹配后为 0.00。
- **组件分析：** 头与前馈的置换在学习匹配中几乎不变，剩余差距在残差流的正交映射上。**没有检验配对上的头是否功能相同。**
- **局限：** 小模型；只有两两模型；BookCorpus 仍有壁垒，作者认为可能代表真正不同的解。
## 五个透镜
- **矛盾 / 切口（与我们的 E89、导师的问题直接相关）：**
  - 他们在层内一一配对头，就能把壁垒降到接近零（至少在小数据上）；
  - 而 E89 / Spectral 2026 显示，LM 中的功能角色会在种子之间跨层移动。
  - 如果两者都成立，**线性连通（低壁垒）并不意味着组件层面的机制对应**——这与 Lubana 2023“不连通 → 机制不同”的方向形成张力：连通时机制在组件层面也可能不同。
  - 可检验：在 Pythia-160M 的多个种子上，用他们的权重匹配对齐，测壁垒；再看配对上的头的因果角色（E89 因果图）是否相同。
