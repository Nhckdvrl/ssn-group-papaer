# Guo, Syed, Sheshadri, Ewart, Dziugaite — Mechanistic Unlearning: Robust Knowledge Unlearning and Editing via Mechanistic Localization（arXiv 2410.12949 v2）

**阅读范围：** HTML 正文 + 大部分附录。2026-10-17 精读。

## 设计与结果
- **设置：** Gemma-7B、Gemma-2-9B、Llama-3-8B；体育事实（1,567 名运动员）与 CounterFact。
- **定位方式：**
  - FLU：只选“事实查找”阶段的 MLP（体育任务中探针跃升的层，约 2–7 / 2–8 层；CounterFact 用路径修补）。
  - OT：因果追踪 / 归因修补，选直接效应大的头和 MLP，即“抽取”组件。
  - 另有全局、全部 MLP、随机等基线，参数量匹配。
- **编辑 / 遗忘：** 只微调选中的组件，50 步。
- **重学攻击：** 在一半遗忘事实上用秩 512 的 LoRA 训练 20 步，测另一半。
  - 体育编辑：CT 恢复最高 63%，FLU 约 20%。
  - CounterFact：所有方法 < 7%，区分不开。
- **探针：** 除 FLU 外，原事实在早层几乎 100% 可解码；FLU 的残留最少。
- **作者的解释：** OT 改的是把潜在知识转换成输出格式的抽取组件，原有的潜在表示不变，重学就能修好抽取通路；FLU 改的是潜在表示形成的地方。

## 五个透镜
- **共同结构（重要）：** 用我们的“写入者—读者”语言重述：OT 改的是读者（抽取头），写入者（查找 MLP）的输出完好且仍对准 → 可重学；FLU 改的是写入者的输出本身 → 难重学。这与我们的发现是同一条规律：**写入者被读者读取的输出被破坏 → 不可逆；读者一侧或写入者输入侧被破坏 → 可逆。**
  - 3.2 / 8.9：只重置 QK（输入侧）→ 回来；输出旋转或重置 OV → 不回来。
- **批判：** 他们的重学攻击很弱（LoRA 20 步；CounterFact 全部 < 7%），解释只在一个任务上可区分。我们的受控设置能把“写出端 vs 读出端 / 输入端”分开操纵，证据更干净。
- **对我们的意义：** 这是“组件层面的可逆性”最接近的已有工作，**新意空间因此缩小**。我们的差量：
  - 在训练动力学层面把同一个组件拆成 QK / OV / 旋转，干净地分开“写出端方向”与“权重是否完好”；
  - 恢复回到整个旧配置；
  - 孤立容量变成注意力汇；
  - 跨功能与（待做的）跨尺寸的事先预测。
