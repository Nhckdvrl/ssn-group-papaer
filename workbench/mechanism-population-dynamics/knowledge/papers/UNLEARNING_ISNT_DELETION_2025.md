# Unlearning Isn't Deletion: Investigating Reversibility of Machine Unlearning in LLMs（arXiv 2505.16831 v3）

**阅读范围：** HTML 前约 65%（正文）。2026-10-17 精读。
## 设计与结果
- **模型：** Yi-6B、Qwen-2.5-7B 等。
- **方法：** GA、GA + GD、GA + KL、NPO、NPO + KL、随机标签（另有 RMU 等）。单次遗忘与连续遗忘（最多 100 个请求）。
- **重学：** 预算与遗忘集同规模；数据来自遗忘集、领域内保留集或无关数据。
- **诊断：** 逐层主成分方向余弦、主成分漂移、CKA、Fisher 信息。
- **四种状态：** 可逆 / 不可逆 × 灾难性 / 非灾难性。
  - 单次遗忘：全部可逆、非灾难性（重学后遗忘集准确率回到约 77%）。
  - 连续遗忘中，学习率 3e-5 时不可逆、灾难性（遗忘与保留准确率都到 0，重学后只回到 2.1 / 1.8）；5e-6 时可逆（回到 80 / 65）。
  - 理想的“不可逆、非灾难性”只在 GA + GD + WAGLE（只更新选中的参数）加特定重学条件下出现。
- **预测指标：** 遗忘前后的平均主成分距离，可以在重学前预测可恢复性。
- **局限：** 阈值依赖；只用重学作为探针；种子少。
## 对我们
- 表示层面的漂移可以预测可逆性；他们的“只更新选中参数”是唯一达到理想状态的条件，与我们“改哪部分参数决定可逆性”（E105c）同向，但他们没有拆到 QK / OV。
