# Ainsworth, Hayase, Srinivasa — Git Re-Basin: Merging Models Modulo Permutation Symmetries（ICLR 2023；arXiv 2209.04836）

**阅读范围：** ar5iv 前约 80%。2026-10-17 精读。
## 设计与结果
- **猜想（沿用 Entezari 2022）：** 多数 SGD 解在对齐隐藏单元的置换之后位于同一个盆地，线性插值没有损失壁垒。
- **三种匹配方法：** 激活匹配（逐层指派问题）、权重匹配（坐标下降）、直通估计（梯度优化置换后的权重）。
- **结果：**
  - MNIST MLP 零壁垒；CIFAR-10 宽 ResNet 首次零壁垒；ImageNet ResNet50 壁垒降约 67% 但不为零；
  - 壁垒随宽度增加而减小，窄模型（1×）不线性连通；
  - LMC 在训练中逐渐出现。
- **没有 transformer 实验。**
- **局限：** 宽度不足、训练早期失败；BatchNorm 需重算统计量；壁垒指标可能误导。
## 对我们
- “置换后单一盆地”只在视觉模型中检验过，且依赖宽度。LM 注意力头的角色会跨层移动（E89：各种子的关键头所在层不同；Spectral 2026：s42 只用 L0，其他种子用 L5–7）。**层内置换无法对齐跨层移动的角色**，所以对 transformer，这一猜想在组件层面可能不成立。
- 而抽象分工跨种子重现（E89）——这给导师的问题一个非平凡的版本：**分工可重现，却不共享（置换意义上的）同一个盆地。**
