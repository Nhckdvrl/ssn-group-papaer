# Lee, Foote, Infanger, Shor, Kamath, Goldman-Wetzler, Woodworth, Cloud, Turner — Distillation Robustifies Unlearning（UNDO；NeurIPS 2025 spotlight；arXiv 2506.06278 v3）

**阅读范围：** HTML 全文（正文 + 附录 A–F；WMDP 基线数值只在图中，文字未给）。2026-10-17 精读。

## 设计与结果
- **问题设定：** 输入为参考模型、保留集、遗忘集和无标签训练数据；以保留集表现和“重学后遗忘集表现”打分。重学攻击是在遗忘集上微调，学习率在 1e-6 到 1e-3 之间扫，取最坏情况。
  - 语言设置：batch 8，500 步，约 8M token。
  - 算术设置：约 2M token。
- **Oracle matching：**
  - 两个任务：约 100M 的 Gemma-2 风格模型（英语为保留、韩语为遗忘，各 1B token）；约 300M 的算术模型（加减为保留、乘除为遗忘）。
  - 用 KL 把参考模型蒸馏到“从未见过遗忘数据的 oracle”的输出；蒸馏损失接近 0，但它重学遗忘域仍远快于从随机初始化蒸馏的学生和 oracle 本身。→ 行为一致不等于鲁棒。
- **Unlearn-and-Distill：** 用 GradDiff / MaxEnt / RMU 遗忘后，按输出蒸馏到随机初始化的学生（lr 9e-4 / 7e-4）。行为迁移了，重学显著变慢，有时接近数据过滤的金标准。RMU 在算术上较弱，作者归因于教师的保留—遗忘折中较差（62% / 6.8%，MaxEnt 为 80% / 1.3%）。
- **UNDO：**
  - θ' = (1 − α) θ_suppressed + α β N，N 为 Xavier 均匀噪声，只加在二维权重上，偏置不加噪。
  - 对所有参数整体施加，不分层、不分组件。之后蒸馏，直到学生达到教师保留表现的 95% 或训完一轮。
  - α 远比 β 重要；β = 0（纯缩放）常常同样有效。WMDP（Gemma-2-2B）用 α = 0.25、β = 0。
- **结果：**
  - 合成任务上，UNDO 把 Pareto 前沿外推；SAM、RepNoise 在强攻击下退化。
  - WMDP 上抗重学一致提升，MMLU 平均下降 4.88%。
  - TOFU 上蒸馏后重学更慢。
  - INT4 量化攻击：GradDiff 的 truth ratio 从 0 升到 0.185，蒸馏后只有 0.017。

## 作者的解释与局限
- **解释（假设，无机制分析）：** 潜在信息留在参数空间里（可塑性、表示纠缠）；随机初始化的学生没有可恢复的潜在能力；加噪是对网络的全局破坏。
- **局限：** WMDP 蒸馏量不足（0.015% 语料）；蒸馏比微调式遗忘贵得多；依赖教师的折中；只有小模型与 2B 模型；只测重学类攻击。**没有任何分层或组件分析。**

## 五个透镜
- **批判：** “α 重要、β 不重要”意味着起作用的主要是缩放、而非随机方向——缩放并不改变任何方向。那么“全局破坏”到底破坏了什么？可能是蒸馏阶段在一个被缩小的网络里重新学习，原有的接口被重学覆盖，而不是被噪声打乱。
- **机制反推：** 为什么从随机初始化蒸馏的学生不会长回遗忘的能力？我们的 E102 给出一个候选：没有接口的容量不会被招募进旧角色，而是成为空操作（注意力汇）。
- **矛盾：** 我们“只有破坏接口方向才不可逆”的推论，与 β = 0 也有效相冲突 → 必须检验：单独缩放一个组件的输出（方向不变）能否阻止重学。按我们的规律，预测是不能。
- **对我们的意义：** 这是与我们最近的、领域内高关注的工作。它给出了现象和方法，没有给出机制。我们的贡献只能是机制层面的。
