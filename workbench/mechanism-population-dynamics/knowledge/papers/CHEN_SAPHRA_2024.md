# Chen, Shwartz-Ziv, Cho, Leavitt, Saphra (ICLR 2024) — Sudden Drops in the Loss: Syntax Acquisition, Phase Transitions, and Simplicity Bias in MLMs

**原文**：[arXiv 2309.07311 v6 全文 HTML](https://arxiv.org/html/2309.07311v6)。**阅读范围**：正文与附录 A–C；附录 D–P（含竞争策略证据 App. M、长训练 App. P）未读到。

## 问题
BERT 在预训练中有一次陡峭的损失下降。下降时内部发生了什么？可解释的内部结构（注意力头专注句法邻居，SAS）是能力的**前提**、**副产品**，还是与别的策略**竞争**？

## 设计（最值得学的部分）
- **度量**：每种依存关系选最好的头，用注意力预测父节点，得 UAS（Clark 2019 的探针）。
- **相变定位**：在指标曲线上找斜率变化最大点（Eq. 2）：结构出现（UAS 突跳，与损失陡降同时，约 20k–30k 步）→ 能力出现（BLiMP 突跳，在其后）。
- **训练中干预**：在 MLM 损失上加 λ·Σ（依存对之间最大注意力），λ<0 促进、λ>0 抑制；**多阶段**：只在前 t 步抑制（BERT_SAS−(3k)）后放开。
- 3 个种子，报告 95% CI；用权重范数作横轴与连续指标做稳健性检查。

## 结果
- 全程抑制 SAS：BLiMP 0.74 → 0.67，复杂语言能力不出现 → SAS 是必要前提。
- 只在前 3k 步抑制：100k 步时损失 1.75 vs 基线 1.77、GLUE / BLiMP 不差甚至略好（更长训练后优势不显著）；短暂抑制使结构出现更早、更强。
- 抑制时会更早学到一种“不看邻近、像词袋”的**替代策略**（损失在约 6k 出现更早的拐点），它与 SAS 竞争。
- **放开时机**：在替代策略出现前放开 → SAS 恢复；之后放开 → SAS 不恢复但损害有限；**在相变期间放开最差**（“the worst time to change the regularization is during a phase transition”）。
- 跨种子：SAS 指标与能力之间无相关（App. E）。

## 我们该学的
不是“画相变曲线”，而是：**找到一个可测的内部结构 → 在训练中可控地压它 / 放它 → 用时机与依赖关系区分“前提 / 竞争 / 副产品”**。研究对象很具体（一组注意力头的句法专注），改变的认识却是关于发育（简单性偏好、竞争、相变时干预的风险）。

## 与我们的距离
- 他们做的是 BERT（MLM）、单一结构；自回归 LM 中“某机制是另一机制的前提 / 竞争者”的训练干预研究仍少。
- 与 E90 的联系：“相变期间的扰动最糟”与 spike 的后果相关，但我们的两次 spike 都在训练后段，不在相变中。
