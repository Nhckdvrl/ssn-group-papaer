# 四版稿件的叙事演化：哪里改变了题目，哪里只是换了说法

这一文档用于避免本地 Agent 第五次“重写旧论文”。原始 PDF/LaTeX 全部按历史原貌保留。本页是论文间推断链的批判整理。

## v0 — Born to Copy, Taught to Trust

**当时问题**：什么由初始化决定，什么由数据决定？把“先天功能解剖”和“后天上下文采信”写成二分，并引用语言习得/关键期。

**主要证据**：DataDecide role map、跨数据 seed 可识别、早期 perturb、Flan模板行为。

**跨越证据的桥**：从“同编号角色分数统计相似”推到“头的命运天生注定”，从局部模板条件推到“模型学会信任上下文”。这两座桥没有真正的机制和普适行为支撑。

**可以借鉴的写法**：清楚的 crossed design 和一张直观矩阵图；**不要保留的东西**：出生/学习的本体类比与两条无中介研究线强拼叙事。

原稿：[v0 main.tex](../../paper-acl-v0/main.tex)。

## v1 — Which Head Takes Which Role?

**当时问题**：哪一个头执行某个统计角色，如何由seed和corpus分配，何时形成？

**进步**：开始把 head 内层位置和跨层 depth 分开，对数据交叉更系统；去掉部分夸张的语言习得类比。

**致命紧邻**：对称性决定不同init同编号比较总体不具规范对应意义；识别seed也能直接由 raw权重完成，而且更好。E68压缩了应用贡献。

**仍可保留**：共享祖先后的“统计倾向”及训练动力学线索；不能叫独一无二新发现。

原稿：[v1 main.tex](../../paper-acl-v1/main.tex)。

## v2 — When Do Mechanisms Correspond Across Pretraining Runs?

**当时问题**：算法、头角色、因果电路分别能迁移到哪一类相关模型？

**进步**：承认“角色图”与因果 circuit 是不同对象，加入 IOI、源/目标跨模型消融。

**问题**：一些有利的映射借用了目标模型自身 task DLA；因此它测的是 target-aided relocation，不是源模型纯粹的信息迁移。E75后来已有事后审计。再加上 Tigges等已知“算法稳定、组件变”，原广泛表述 novelty 不足。

原稿：[v2 main.tex](../../paper-acl-v2/main.tex)。

## v3 — Which Head Does the Work?

**当时问题**：siblings（同初始化独立训练）与 descendants（同一run继续训练）是否继承 task carrier？另用 E86讨论“最强 induction头”是否会被微小扰动易主。

**进步**：直接核查谱系（剔除假后代），区分统计角色与单头消融 causal maps，记录低信度DLA秩图，E83强否定“行为出现后锁定”，E86有完全相同重跑对照。

**问题**：同一张表混用“DLA定义carrier”和“ablation定义top3+sum single”指标，未满足纸面联合消融语义；E86的argmax不代表因果carrier重分配，短训练结论不能无条件推广。许多结果接近已知跨训练机制可迁移性认识。

原稿：[v3 main.tex](../../paper-acl-v3/main.tex)。

## 四版之后真正出现的研究问题

不要再按稿件序号找题。相反：

1. **相似性层级不一致**：E72角色匹配恢复通用统计，E75局部因果定位依赖目标信息。这是新的、更聚焦的“测量—机制”落差。
2. **关系层级**：任务之间复用/分工能否由一个统一的因果对应解释？单模型的算法相近与模型间迁移不是同一问题。
3. **形成机制**：共同祖先带来的统计惯性，由早期什么变量/学习事件决定，能否预测后期真实计算？

每条都必须先对齐最强文献（尤其 Merullo、Tigges、Bali、DFA、MDA、Méloux），而不是直接开新的四段式论文大纲。
