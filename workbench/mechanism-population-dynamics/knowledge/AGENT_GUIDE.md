# 给本地Research Agent的知识库使用与科研行为指南

**本workbench当前为CLOSED**：可以阅读、整理文献和证据，但不能因这里列了P0/P1就擅自恢复GPU训练、改动原始结果或生成新论文版本。研究重启须新的明确指示。

## 1. 进入项目先读什么

顺序建议：[领域地图](FIELD_GUIDE.md) → [论文目录](PAPER_CATALOG.md) → [实验全景](heritage/EXPERIMENT_ATLAS.md) → [证据账本](heritage/EVIDENCE_LEDGER.md) → [文献冲突地图](syntheses/CONFLICT_MAP.md) → [指标审计](heritage/MEASUREMENT_AUDIT.md) → [开放问题](research/OPEN_QUESTIONS.md)。必要时回溯实验原卡、JSON、代码和四版原文。

知识库不是实验命令清单。你的首要工作是理解**真实重要的问题**，识别什么新发现会改变现有认识。

## 2. 每篇论文的记录标准

新论文卡必须区分：出处/版本与阅读深度、领域背景、研究问题、idea尺度、方法和实验链、最强baseline/反证、真实证据边界、与我们近邻距离、值得迁移的设计、作者idea过程材料（有与无）、下一步可证伪假设。

若只读摘要，必须标“摘要筛读”，不能冒充已精读。仅依论文结果推测idea来源，标“研究者自己的逆向重建”；优先找附录、作者自述、开源代码历史和讨论。

## 3. 避免防御性瘫痪，也避免草率自信

面对复杂或意外的结果，不要先列十种混杂直到谁也不知道该做什么；**主动缩小对象，找一个能让竞争解释分裂的小实验**。

但不要用顺畅叙事替代证据：
- 头编号/argmax变化不自动等于算法不同；
- attention角色/DLA/ablation/joint效果不是一个指标；
- “用target DLA重新定位”不叫zero-shot source迁移；
- 同一模型几个任务的机制相似，不自动能推广到独立训练模型；
- 训练过程中相关不等于必要的发育脚手架；
- 数据复训后的头变化要有完全相同rerun对照；
- 类比另一个领域的理论必须匹配对象和实际假设。

## 4. 做实验必须保持主观能动性

预设计是最初的高信息量起点，不是僵硬清单。看到真正异常时应主动改变观测方式、回文献找最强已有解释、设计区分性干预；不必为了完成几十个预设配置浪费算力。

每一步都问：“**我真正测到什么？还有哪种解释同样符合？下一次最省力的操作能让哪种解释输掉？如果我得到了结果，为什么值得关心？**”

没有明确答案时，不要机械扩大seed和benchmark；一个直接path干预有时比100个role map更有价值。

## 5. 事实与解释的版本管理

原始实验卡在父目录experiments和results，knowledge目录只保存有出处的批判整理，不复制造一个第二真源。原来卡上RUNNING属于历史状态，不能作为活任务；E87没有结果、E88代码有缺陷，都要标BLOCKED。

新的主张必须写：观测出处、支持范围、竞争解释、证伪计划、预登记/事后分析界限、是否独立复核。结果反证原假说，要保留撤回原因，不得只改名字继续宣传。

## 6. 质量门槛高于文章数量

优先判断Solid、Significant、Novel：是否可以改变关于模型计算、训练或测量的真实重要认知。反直觉可加分但不强求。若一个现象即使完全真实仍只回答“以前没有画过这张图”，及时停止。

论文写作不是自动推进步骤；四版稿已经提示，重写同一统计并不能弥补科学意义。阅读[四版演化](heritage/PAPER_VERSIONS.md)。

多GPU优先用于**独立确认一个已显现的重要机制线索**，而不是用高并发掩盖核心问题不清。
