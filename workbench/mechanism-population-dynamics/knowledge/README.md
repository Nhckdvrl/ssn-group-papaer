## 使用原则

分开记录事实、解释和候选主张。旧卡片里出现“算法一致”“由初始化决定”“冗余”“集体对称性破缺”等词时，回到具体测量检查证据是否够强；也不要因旧阈值未达到或已有相近工作就自动否定全部探索。

新的关键观察应优先通过简化任务、查看样例及定位一条具体因果路径来理解。独立复现用于确认有信息的发现，不用大量配置替代解释。
