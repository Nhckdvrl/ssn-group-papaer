# 当前主线（2026-10-17 00:20）：继续训练修复损伤时，学过的角色存在哪里、什么能被重建

**性质：** 主线定义与严格自评。只有这一条主线；E89–E92（分工可重现性、种子能力差异）已存档，不再作为问题来源。每一步都按“领域真正关心的问题 + 不平凡的答案”来要求。

## 1. 问题（一句话）
训练好的 transformer 中一个组件被破坏后继续训练：什么决定了原来的解被**恢复**、被**另一个组件接替**，还是能力**一直丢失**（而损失照样恢复）？等价的问题是：一个学到的“角色”存放在哪里？

## 2. 领域为什么关心（三个社区共享这个未知）
| 社区 | 他们关心的事 | 现有最强认识 | 他们缺的 |
|---|---|---|---|
| 遗忘 / 重学（安全） | 被“删除”的能力为何在少量微调后回来 | 回来很普遍（Deeb & Roger 2024：恢复 88%；Jain 2024：几步复活）；易感性可由与原模型的权重距离、线性模式连通性预测（Siddiqui et al. NeurIPS 2025） | 组件层面：回来的是谁、靠什么回来；什么样的破坏不可逆 |
| 训练稳定性 / 剪枝后修复 | 用“损失恢复”判断故障或剪枝后模型是否修好 | spike 以损失能否恢复区分良性 / 恶性；剪枝后靠继续训练“healing” | 损失恢复时，哪些能力没恢复、为什么 |
| 可塑性丧失 / 持续预训练 | 训练久了的网络为何难学新东西；重置单元能否恢复可塑性 | 休眠单元、坍缩头随训练增多（arXiv 2606.24752）；ReDo、Shrink & Perturb 假设被重置的单元会被重新利用 | 被重置的容量在 LM 预训练中实际去了哪里 |
| 可解释性 | 电路中的角色是组件自身的属性，还是组件与读者之间的关系 | 推理时自修复 / backup 头（McGrath 2023；Rushing & Nanda 2024）；训练中电路算法稳定、组件可换人（Tigges 2024） | 训练期的因果证据 |

## 3. 已有的答案（Pythia-160M step100k，学习率 2e-5，最长 5000 步；每项都有配对对照）
1. **角色存放在下游读者对该组件输出方向的对准中，不在组件自身。**
   - 只重置 QK、保留输出：3.2 长回 0.85，8.9 回到 1.90 / 2.06，9.3 回到 83%（8.10 为 49%，略低于门槛）。
   - 保留输出但做正交旋转（范数、谱、V 侧都不变）：3.2、8.9、6.4、8.10 全部等于完整重置（E99 / E101 / E102）。
   - 只保留注意力（重置 OV）：8.9 不回来（E101）。
2. **现有最强的预测指标（权重距离）在组件层面失效，甚至排反。**
   - 对 8.9：重置 OV 离原模型最近（相对 L2 0.65%）却不回来；重置 QK 离得远（7.95%）却回来；旋转输出（7.97%）不回来。
   - 对 3.2：QK 重置（0.94%）与旋转（1.06%）距离几乎相同，结局相反。
   - “读者接口是否保留”把六种情况全部分对。
3. **恢复时回到的是整个旧配置，而不只是受损头。**
   - IOI：8.9 回来的同时，搭档 8.10 回到 −0.72，在其他分组中会接手的 9.5 退回 −0.25（E101）。
   - previous-token：已在工作的临时接管者 3.4 被挤回（0.49 → 0.30）；即使现任 3.0 已经接管，原头也在夺回（E96）。
   - 网络放弃一个已经能用的新配置，回到旧的。
4. **没有接口的组件不会被招募，而是被推成空操作。** 完整重置或旋转后的头一直有梯度（Q / K 相对变化是未受损头的 4–10 倍），却在 9 个任务上效应 ≤ 0.02，并变成注意力汇（对第 0 个 token 的注意力从 0 升到 0.45–0.63，正常头中只有 1% 超过 0.5）（E102）。
5. **能力只流向已经部分耦合的组件；没有这样的组件，能力就停在部分恢复，损失却照样恢复。**
   - 8.9 完整重置：IOI 停在 0.40，损失恢复 0.7–0.9（E98）。
   - 接手者 9.5 在损伤前已经在看名字（43k / 100k）；在 8k 没有这样的头，IOI 只恢复 0.26（E100）。

## 4. 平凡与不平凡（严格自评）
| 结论 | 是否平凡 | 理由 |
|---|---|---|
| 部分重置比完整重置恢复得好 | 平凡 | 任何人都会预测 |
| 功能转给备份头 | 平凡 | 推理时自修复已知 |
| 小众能力比损失恢复得慢 | 基本平凡 | 频率 / 梯度份额效应 |
| 旋转后权重“完好”也等于完整重置；只保留注意力不够 | **不平凡** | 与“组件自身保存角色”的直觉相反 |
| 权重距离排序与结局相反 | **不平凡** | 直接与现有最强预测指标冲突 |
| 恢复回到整个旧配置，替补被挤回 | **不平凡** | 网络放弃可用的新解 |
| 无接口的容量变成注意力汇 | **较不平凡** | 给“为何重置不能恢复可塑性”一个具体机制 |
| 损失恢复但能力卡住，原因是没有已耦合的候选 | 中等 | 现象有人猜过，机制解释是新的 |

## 5. 弱点（任何一条都可能让主张变平凡或错误）
1. **窗口与学习率：** 5000 步 × 13 万 token ≈ Pythia 原训练 330 步；学习率 2e-5 远低于 Pythia 此阶段（约 1.7e-4，按 batch 折算约 4e-5）。“完整重置永不回来”可能只是时间不够。
2. **尺寸：** 只有 160M → E104（410M）在跑。
3. **人为损伤：** 重置 / 旋转不是任何真实流程。与遗忘 / 剪枝的桥梁目前只是推论，还没有在真实遗忘方法上检验。
4. **速率机制未知：** E103 早期结果否定了“停滞长度由耦合幅度决定”（输出 × 2 反而更慢）；Adam 信噪比的解释是事后提出的。
5. **规律有一个未命中：** 8.10（49%、+0.16）；后继 / 主谓一致有天花板，只能看头自身效应。

## 6. 要得到“领域关心的、不平凡的答案”，还缺什么（按信息量排序）
1. **E104 规模（在跑）：** 410M 上旋转 = 完整重置、QK 原头回归、孤立头变注意力汇。
2. **桥接到真实遗忘（最关键的“so what”）：** 用一种标准遗忘方法（如 RMU，或对选定组件做梯度上升）删除一种已定位的能力（IOI 或事实回忆）；再在无关数据上继续训练，测重学。
   - 事先预测：重学程度由“该组件输出与读者的对准是否被保留”预测（测遗忘前后组件输出子空间与读者读取子空间的对齐度），而权重距离预测不了。
   - 若成立：给遗忘研究一个组件层面、可干预的不可逆判据（破坏接口对准，而不是改注意力）。
   - **00:50 补充：** 最相关的已有工作是 UNDO（Lee et al. NeurIPS 2025 spotlight）：加噪 + 蒸馏抗重学，噪声强度在算力与鲁棒性之间折中，但没有说明加噪破坏了什么。我们的规律给出机制，并预测：只对承担能力的组件做“输出端接口破坏”（例如旋转其输出子空间），就能用远小于全局加噪的扰动达到类似抗重学效果，而对注意力加同样的扰动无效。这是与领域最直接相关的检验。
   - **00:45 pilot 教训：** 梯度差遗忘只需 25 步就把 IOI 从 3.48 压到 −6.4，权重相对变化只有 0.03%（浅层压制）。这类方法根本不碰接口，按规律应当被完全重学（基线正在跑）。所以桥接实验必须包含会改变接口的方法（UNDO 式加噪、RMU、我们的定向接口破坏），才能区分预测指标。
3. **窗口 / 学习率检验：** 完整重置在更高学习率（4e-5、1e-4，先校准对照漂移）与更长窗口（2 万步）下是否终于再生。若会，主张改为“恢复速度由接口决定”。
4. **机制（理论）：** 生产者—读者的双线性最小模型。
   - 预测：单边损伤（读者仍对准）可恢复；双边失配（旋转）卡住；竞争者分走信号会变慢。
   - 用 E96–E103 的轨迹检验，并解释 Adam 下的速率。

## 7. 止损 / 收窄规则（事先写下）
- E104 中旋转不等于完整重置，或 QK 原头在两个目标上都不回来 → 主张限定为 160M 的现象，不扩大。
- 第 6.2 项中重学与接口对准无关 → 去掉“遗忘 / 重学”的叙事，只保留可解释性层面的“角色是关系性的”。
- 第 6.3 项中完整重置在合理学习率下很快再生 → “不被招募 / 变空操作”降级为“短窗口现象”。
