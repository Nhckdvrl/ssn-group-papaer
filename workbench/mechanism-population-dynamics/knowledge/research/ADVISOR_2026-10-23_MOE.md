# 导师 10-22 面谈：MoE 专家 / 注意力头的分工方向——总分析（2026-10-23）

**性质：** 只做分析，不开实验，不重启已结项的线（R2）。导师意见与 GPT 的分析都是输入，不是锚点。论文精读见 [MOE_DIVISION_OF_LABOR_2026-10-23.md](../papers/MOE_DIVISION_OF_LABOR_2026-10-23.md)。

## 0. 结论先行
1. **头的方向不再单独做。**
   - 我们已经做了四版论文（v0–v3）和 E89，用户已于 10-11 结项。Bali 2026 也占住了“头跨训练是否稳定”。
   - 导师听过“分工结构重现、编号不重现”这个结果，评价只是「全然ダメではない」。
2. **MoE 不是“把头换成专家”，而是一个更好的研究对象：**
   - 它恰好补上了我们在头上始终缺的那块——**基线**，也就是“一致到什么程度才有意义”。
   - 已知很多种分工几乎同样好：哈希路由、冻结的随机路由只差约 1–2 PPL。所以如果独立训练反复选中同一种分工，那就不是目标函数逼出来的，而是训练动力学或数据几何的选择。这就是导师说的“本来不保证一致”。
3. **真正的研究问题落在一个现成的文献矛盾上：**
   - **几何决定论：** Myth of Specialization 2026 认为路由器是线性的，分工由表示几何决定；而同数据、不同种子的表示几何近似相同，所以分工应当一致。
   - **历史依赖：**
     - 路由向量与专家共同累积被路由的 token，形成正反馈（Routers Learn Geometry 2026）；
     - 正反馈会带来对称破缺（Bifurcation 2026）；
     - OpenMoE 观察到 token → 专家映射在早期就固定。
     - 这一方预测分工由早期随机历史决定，跨种子不一致。
   - 两方都没有用“同配置、不同种子、从头训练”的语言 MoE 检验过。跨训练比较正是这场分歧的判决实验。
4. **按导师自己的标准，必须把“自然的一致”剥离出去。**
   - 他认为“词义相似是自然的”，所以由 token 身份决定的那部分路由一致不算发现（相当于词知识）。
   - 要问的是：**扣除 token 身份和共享表示几何能预测的部分之后，分工本身是否仍然一致**。

## 1. 导师到底说了什么（10-22 会议录，按原话整理）
- **否定 design 题的理由：**
  - “不加指定时设计相似是自然的，一致了也只会想‘也是’”；
  - 一致程度还随提示和数据的给法变化，“这个数值有什么意义”是个问题。
  - **这条标准同样适用于我们。**
- **MoE：**
  - 学习时并没有明示“这样分专家”，分工是自动学出来的；
  - 如果分别训练的模型里有同样的专家对应，那就是“本来不一定一致的东西强烈一致”，有一定意义；
  - 他的顺序：先查专家，再查头，如果头也有同样的角色、跨训练高度一致，可能是有趣的研究。
- **头：** 重申上次的意思：“学习重来后角色同样分开”才有趣，单词意义一致是自然的。
- **另一个候选：** 多语言模型在什么条件下**不**一致（Qwen vs LLM-jp，文化背景）；“不一致”比“一致”更有趣。
- **条件：**
  - 他自己还没做过调研，要我们先查有没有同样的研究；
  - 题目应当在讨论中逐渐收敛，不要每次换全新的题；
  - 评估必须留在语言范围内（VLM 输出不能脱离语言评估）。

**结论：** “独立训练的专家是否对应”这个问题本身不是全新的（有两篇初步观察）。但以下这层基本空着：**用正确的零假设分离 token 身份、共享几何和分工本身，并用来判决“几何决定 vs 历史决定”**。而且这块空白是解释性的空白——两种理论正在冲突，不是“没人测过”的空格子。

## 4. 为什么 MoE 比头好（这是要对导师讲清楚的核心）
1. **对称性是精确的：** 专家是一组完全对称的可交换模块（LMC-MoE 定理），置换就是全部对称性。头还受层、位置、残差流方向的影响，对齐本身就有争议（我们在 E72 / E89 / Bali 上都碰到过）。
2. **观测量直接、可靠、覆盖全部数据：**
   - 路由决定是离散的、零成本的、在每个 token 上都有。不需要人工设计任务集，也不需要做消融。
   - 头的“功能”要靠因果消融，单任务承担者近似平局（信度约 0.40）。
   - 划分之间的一致性可以用聚类比较量（调整互信息、共分配矩阵）计算，**不需要先匹配编号**。这避开了最佳匹配的选择偏差（Equifinality、Bali 都有这个问题）。
3. **有基线：**
   - 可行分工的集合就是“哈希 / 随机路由也能训练到接近的损失”；
   - 零点是“负载相同的随机划分”；满分是“同一 run 相邻检查点 / 同种子重跑”；
   - 中间还有两条可算的参照线：“只用 token 身份能解释的一致性”与“共享表示几何能预测的一致性”。
   - 这正是导师书面评论里的难点（一致到什么程度才有意义）。在 MoE 上可以给出带刻度的回答。
4. **贴着语言：** 区分 token 身份与上下文（一词多义、语言、句法），用多语言数据检验“语言专家”是否跨训练一致。这样仍然是 NLP 问题（导师强调评估不能脱离语言）。

## 5. 研究问题与研究空间
**主问题：** MoE 语言模型自发形成的专家分工，是由数据和表示几何决定的（独立训练会重现），还是由早期随机历史经正反馈固定下来的（换种子就换一种）？如果两者兼有，哪一部分是哪一种，由什么决定？

### Q1　一致到什么程度、一致的是哪一部分（测量，必做）
- **读数：** 同配置不同种子的两个模型，在留出语料上逐层计算路由划分的一致性（top-k 版的调整互信息 / 共分配一致性）。刻度：零点 = 负载相同的随机划分，满分 = 同一 run 内的上限。
- **分解（四条参照线）：**
  1. 只用 token 身份：每个 token 取其最常去的专家，看两个模型的这张“词 → 专家”表是否一致；
  2. 上下文部分：同一 token 在不同上下文中的路由切换，在两个模型间是否同步；
  3. **几何预测：** 把模型 B 的隐状态用线性映射对到 A 的空间，再交给 A 的路由器，得到“如果路由器只是共享几何的同一种读出”时应有的一致性；
  4. 实际一致性。
- **核心对比是 3 与 4：**
  - 实际 ≈ 几何预测 → 分工被共享表示继承（几何决定论成立）；
  - 实际明显低于几何预测 → 两个模型共享表示，却对同一个几何做了不同划分（历史依赖成立）。
  - 后者是导师说的“本来不保证一致”的反面，同样是信息量很大的结果。

### Q2　什么时候决定（动力学，我们的强项）
- **分叉实验（Frankle 2020 的不稳定性分析，应用到分工上）：** 从同一个父模型的第 t 步分出两个子模型（换数据顺序 / 路由噪声），训练到底后看分工一致性随 t 的变化，得到“分工承诺时间”曲线。
- **预测：**
  - 历史依赖说：曲线在很早（路由饱和前）就升到上限；
  - 几何决定说：t 不重要，任何分叉点的子模型都一致（因为终点由几何决定）。
- 与 OLMoE 的路由饱和、Zyphra 的“约 10 亿 token 已形成稳定专家对”对照。

### Q3　由什么控制（只在 Q1 / Q2 出现可解释的差异后再做）
- 候选旋钮：
  - 辅助损失均衡 vs 无辅助损失的偏置均衡；
  - 全局批次 vs 微批次均衡（Qiu 2025；Myth 命题 2 给出了机制预测）；
  - 专家粒度与 top-k；共享专家；
  - 从稠密模型升级初始化（专家起点相同，对称性最强；Mixtral 式）。
- **问题：** 哪些设计让分工“可重现”，哪些只是让分工“集中”。专精度量（集中度）与可重现性可能分离：一个模型可以很专精，但专精得很随意。若属实，这是对现有专精度量的直接修正。

### Q4　后果（决定“so what”）
- **解释性：**
  - 若分工随种子变，“专家 X 是数学 / 中文专家”是单次训练的事实，不是 MoE 的事实；
  - 若分工随几何定，这类结论可以跨训练迁移，前提是做了置换对齐。
- **质量：** 不同种子的分工不同、损失却相同，就是分工层面的“殊途同归”（equifinality）——它在 Equifinality 2026 里只是路由拓扑层面的结论。

### Q5　回到头（有条件）
- 只有当 MoE 给出一条原则（例如“由几何决定的部分重现，由竞速决定的部分不重现”）时，才回到头。
- 用已有的 E89（任务深度顺序与任务捆绑重现、身份不重现）与 E119（谁拿角色是竞速）做第二个案例，**不新开头的实验**。这也符合导师“先专家、后头”的顺序。

## 6. 结果分叉（事先写定，防止事后解读）
| 结果 | 含义 | 有意思在哪 |
|---|---|---|
| 实际一致 ≈ 几何预测，且远高于 token 身份基线 | 分工是共享表示的产物；路由器不是独立的组织源 | 在多种分工都可行的前提下，训练仍反复选中同一种——导师要的“不平凡的一致” |
| 共享几何高，但实际一致明显低于几何预测 | 同样的表示被不同地划分；分工由早期历史决定 | 单模型的专家解释不能推广；为 Q2 的承诺时间和 Q3 的设计旋钮提供明确对象 |
| 浅层由 token 身份解释，深层上下文部分随种子变（或相反） | 分工的可重现性随深度换了来源 | 和 Myth 的深度效应、OpenMoE 的上下文无关观察直接对话 |
| 几乎全部由 token 身份解释 | 小模型的路由近乎查表 | **这是平凡结局**（相当于词知识一致）——必须事先排除，见 §8 |

## 7. 对 GPT 分析的取舍
- **采纳：**
  - Bali 已占住头的稳定性；LMC-MoE 是冻结骨干、只训练 MoE（已核实原文 §6.1）；Equifinality 只是两个种子的初步观察；
  - 路由一致 ≠ 功能一致；最佳匹配有选择偏差，匹配必须在校准数据上冻结、再到留出数据上评估；
  - 统计单位是独立训练，不是 token。
- **不采纳 / 修正：**
  1. **GPT 的主推题“路由一致 vs 因果功能一致”是局部优化：**
     - 它最可能的结果（路由像、功能不全像）不令人意外；
     - 它把我们拉回逐模块消融，而头线已经证明逐组件的因果读数信度不够、近似平局。
     - 因果干预应当只用来验证 Q1 的关键差异，不当主轴。
  2. **“先在 OLMoE 单个 run 上确认角色可测”是窄 pilot：**
     - 单个 run 回答不了跨训练问题；
     - OLMoE 的中间检查点只适合 Q2 的辅助对照（路由饱和时间）。
  3. **GPT 没抓到 MoE 真正的价值：**
     - 一是可行分工的基线（哈希 / 随机路由）；
     - 二是现成的理论冲突（几何决定 vs 正反馈历史依赖）。
     - 这两点决定了这个题“为什么不平凡、改变谁的判断”。
  4. **“单个专家不稳定、专家组稳定”** 是 E89 结论（结构重现、身份不重现）的搬家版本，导师已经听过、反应平淡，不做标题。可以作为 Q1 里的一个读数。
  5. **GPT 担心过度：** 两篇相邻工作（Equifinality、视觉 MoE）都是定性或很薄的观察，不构成“方向已被做完”。拥挤不等于死（记忆：crowded is not dead），增量在解释层面。

## 8. 风险与事先的判别办法
1. **平凡结局风险（最大）：**
   - 小模型、短训练下，路由可能几乎由 token ID 决定（OpenMoE），一致性全被“词表 → 专家”解释。
   - Myth 认为这是训练不足造成的，所以可训练规模与 token 预算是关键设计变量。
   - 判别办法：Q1 的分解本身就报告 token 身份部分。正式训练前，先用公开大 MoE（OLMoE 等）测“同一 token 在不同上下文中的路由切换率”，作为我们小模型是否“够像真 MoE”的参照。
2. **独立训练的成本：**
   - 公开模型里没有同配置多种子的语言 MoE：OLMoE 只有一条训练轨迹，FLAME-MoE 有 7 个规模，但未见多种子。
   - 必须自己训练。大致是 1–2 亿总参数、约 3–5 千万激活参数、数十亿 token，单卡约半天到一天。每个配置 3–5 个种子，加分叉实验，量级是数百 GPU 小时，符合 RESOURCES.md（独立单卡任务）。具体待测。
3. **资产：** `~/mechpop_cache`（Pythia 检查点、Pile 分词数据）目前不存在（10-23 核对），需要重新准备数据。
4. **会不会又滑回“结构重现、身份不重现”：** §6 的结果表与 §5 的几何预测线，就是为了让结论落在“为什么”而不是“有多像”。如果 Q1 只能给出一个相似度数值、几何预测线也算不清，就按止损规则停。
