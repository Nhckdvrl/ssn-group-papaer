# E221：全部切断后的损伤落在哪类 token 上（词首 / 词内 × 前文是否出现过），以及混合模型前 4 层"全部混合一起切"（2026-11-24）

- **状态：** DONE（约 18:30 写定，在任何 E221 运行之前；约 19:30 跑完）
- **类型：** MEASUREMENT（因果，只推理；不推进主张等级）
- **为什么做：** 用户 11-24 晚贴来的外部意见（Gemini 第三份）。核对后保留其中两点：
  1. **E220 观察 18④ 有混淆。** Transformer 切第 0–3 层注意力，等于切断这几层的全部 token 混合；混合模型则是把卷积、记忆、注意力分开切的。"Transformer 有前 4 层绝壁、混合模型没有"的对比不对等。
  2. **E220 的落点需要拆开。** 全部切断时，记忆伤词首多于词内，其他切法（卷积、注意力、Transformer 注意力）都是词内多于词首。需要检验两件事：
     - 这是否只是 Zoology（ICLR 2024）所说的"前文出现过的内容靠注意力复制"。Zoology 在 Pile 上发现，注意力相对卷积类模型的优势集中在前文重复过的二元组上。
     - 词内续片不干预时 NLL 只有 1.4–1.7，词首是 3.2–3.5，ΔNLL 的尺度会放大低 NLL token 的损伤。
- **问题（一句话）：** 全部切断某一类部件后，损伤集中在"前文出现过的词"上还是"首次出现的词"上？词首和词内的差别在概率和准确率尺子上是否仍然成立？混合模型前 4 层全部混合一起切断，是否也约等于全部层全部切断？

## 设置
- **模型（8 个）：** OLMo-Hybrid、Qwen3.5-4B、Granite-4.0-H、Falcon-H1、Falcon-Mamba、Llamba-1B、OLMo-3、Qwen3-4B。
- **条件**（关法与 E219、E220 相同）：

  | 模型 | 条件 |
  |---|---|
  | 4 个混合模型 | 不干预、全部卷积、全部记忆、全部注意力、第 0–3 层全部混合（卷积 + 记忆 + 注意力）、全部层全部混合 |
  | Falcon-Mamba、Llamba | 不干预、全部卷积、全部记忆、第 0–3 层全部混合、全部层全部混合 |
  | OLMo-3、Qwen3 | 不干预、全部注意力，以及按深度三等分的前、中、后三段注意力 |

- **文本：** EWT 第 0–199 段，每段 ≤ 511 token（同 E217，比 E219、E220 的 50 段多，为了让"前文出现过的多片词"有足够数量）。
- **token 分类**（只用分词器和文本本身，不用人为拆分）：
  - 词首 / 词内：同 E217 的 `piece_kind`。词 = 一个词首片加上紧随的词内片。
  - 前文出现过 / 首次出现：该 token 所属的完整词（小写）是否在本段更早的位置完整出现过。
  - 另设"同词对照"：只取至少 2 片的词，比较它们的第一片（词首）和后续片（词内）。
- **读数（每类 token 分别报告）：** 不干预时的 NLL 和 top-1 准确率；干预后的 ΔNLL、top-1 准确率下降、正确 token 概率下降（p_原 − p_切）。

## 判据与读法（跑之前写定；阈值只作标记）
- **比值 R** = 词内损伤 ÷ 词首损伤，在三种尺子上分别计算（ΔNLL、top-1 下降、概率下降）。
- **"记忆特别放过词内"：** 4 个混合模型中至少 3 个满足以下两条，且在 ΔNLL 和 top-1 两把尺子上都成立：
  - R_记忆 < 1；
  - R_注意力、R_卷积 > 1。
- **"词内大于词首是一切切断的共性"：** R_注意力、R_卷积、Transformer 的 R_注意力都 > 1，且彼此相差不到 2 倍。
- **"注意力主要在复制"：** 混合模型全部注意力切断时，词内 × 前文出现过的 ΔNLL ≥ 2 × 词内 × 首次出现，且 top-1 下降方向相同。
- **"超出复制"：** 词内 × 首次出现的损伤 ≥ 1.5 × 词首 × 首次出现，两把尺子都成立。
- **前 4 层绝壁（检验 E220 观察 18④）：** 比值 = 第 0–3 层全部混合切断的 ΔNLL ÷ 全部层全部混合切断的 ΔNLL。
  - ≥ .8：混合模型也有前 4 层绝壁，18④ 的对比是混淆。
  - ≤ .5：混合模型在前 4 层全切后，后面的层能恢复很大一部分。
  - 中间：如实描述。
  - Transformer 的对应值取自 E220（第一块 ÷ 全部，约 1.0）。
- **R5：** 跑完不改分类、条件和判据；新加的分析一律标 POST-HOC。

## 混杂审计
- "前文出现过"只看本段 ≤ 511 token 之内。跨段重复不算。
- 词首包括单片词，词内只出现在多片词里，两类词的分布不同，所以另报"同词对照"。
- 全部层全部混合切断后，模型只能看当前 token（相当于二元模型），ΔNLL 很大；比值只用于判断前 4 层是否已经接近这个上限。

## 算力
- 8 个模型，每个 4–6 个条件，每个条件跑一遍 200 段。7B 每遍约 1 分钟；Falcon-Mamba 每遍约 10 分钟，共约 50 分钟。总计 ≤ 2 GPU 小时。用 fvcrc10、fvcrc13 的空闲卡（≤ 8 张）。逐 token 结果存节点 /tmp，只把汇总放进 git。

## 结果
- 文件：`results/e221/<模型>.json`（每类 token 的汇总）、`results/e221/judge.json`（`scripts/e221_judge.py`）。逐 token 结果在节点 `/tmp/xiang_e194/out221/*.npz`，不进 git。8 个模型全部跑完，复原检查都是 0。
- 每个模型 200 段：词内续片 1,245–2,816 个，其中"前文出现过的词"301–642 个；词首约 16,000 个。

- **E222 修正：** 下表"前 4 层绝壁"一行中 Transformer 约 1.0 的值，来自"只看自己"的切法，它同时破坏了注意力汇聚点。保留汇聚点后，Transformer 比值为 .43–.80，与混合模型重叠，该对比降为程度上的倾向（见 E222）。

### 按卡片判据
| 读法 | 结果 |
|---|---|
| 记忆特别放过词内 | **成立（3/4）**：OLMo-Hybrid、Granite-H、Falcon-H1 在 ΔNLL 和 top-1 上 R_记忆 < 1，R_注意力、R_卷积 > 1。Qwen3.5 的 top-1 不满足（1.37）。**但在概率差上不成立**（R_记忆 .97、1.92、1.11、1.36），同词对照（多片词的第一片对后续片）在 top-1 上也接近 1（.93–1.10，Qwen3.5 2.18）。所以"记忆放过词内"依赖于用对数尺子量。 |
| 词内大于词首是一切切断的共性 | **不成立（按阈值）**：方向一致，所有非记忆切断的 R_ΔNLL 都 > 1（1.12–3.06），但注意力（1.71–3.06）明显大于卷积（1.12–1.37），相差超过 2 倍。 |
| 注意力主要在复制 | **成立（3/4）**：全部注意力切断时，词内 × 前文出现过的 ΔNLL 是词内 × 首次出现的 2.7–3.5 倍（OLMo-Hybrid 4.49 对 1.65，Qwen3.5 9.37 对 2.71，Granite-H 3.79 对 1.70）；Falcon-H1 为 1.97 倍（5.63 对 2.86），刚好不到 2。top-1 方向相同。 |
| 超出复制 | **成立（3/4）**：同三个模型，词内 × 首次出现的损伤 ≥ 1.5 × 词首 × 首次出现（ΔNLL 和 top-1 都成立）。Falcon-H1 不成立。 |
| 前 4 层绝壁（检验 E220 观察 18④） | **混合模型没有绝壁**：第 0–3 层全部混合一起切断 ÷ 全部层全部混合切断：OLMo-Hybrid .21、Granite-H .32（恢复），Qwen3.5 .61、Falcon-H1 .60（中间），Falcon-Mamba .08（恢复），Llamba .79（中间，接近绝壁）。Transformer 约 1.0（E220）。18④ 的对比在去掉混淆后仍然成立。 |

### 在三把尺子上都稳定的分离（按卡片的分类，比较方式为 POST-HOC）
- 只看词内续片，按"前文是否出现过"分开（ΔNLL / top-1 下降 / 概率下降）：

  | 模型 | 关记忆：出现过 | 关记忆：首次 | 关注意力：出现过 | 关注意力：首次 |
  |---|---|---|---|---|
  | OLMo-Hybrid | .09 / .03 / .05 | .75 / .12 / .15 | 4.49 / .67 / .75 | 1.65 / .22 / .27 |
  | Qwen3.5-4B | .50 / .09 / .22 | 2.16 / .31 / .32 | 9.37 / .87 / .86 | 2.71 / .25 / .23 |
  | Granite-H | .20 / .05 / .10 | .73 / .12 / .14 | 3.79 / .63 / .72 | 1.70 / .26 / .29 |
  | Falcon-H1 | .17 / .03 / .08 | .56 / .11 / .14 | 5.63 / .80 / .82 | 2.86 / .40 / .43 |

- 关记忆几乎不伤"前文出现过的词"的续片，伤首次出现的更多；关注意力正好相反。在 4 个模型、三把尺子上方向都一致。这与 Zoology（注意力的优势在前文重复的内容上）和 Jelassi et al.（SSM 不擅长复制）的预测一致。新的地方在于：这是在预训练混合模型内部、自然文本上、对两类部件分别做的因果切断。
- 纯 Mamba 的 Falcon-Mamba 没有注意力：关记忆时，出现过的词的续片 3.19，首次 1.42，复制由记忆承担，方向与混合模型相反。Llamba 也类似（5.60 对 3.30）。

### 前 4 层全部切断后，什么还能保住（POST-HOC）
- 混合模型第 0–3 层全部混合切断后，"前文出现过的词"的续片几乎不受影响（OLMo-Hybrid .18、Granite-H .31、Falcon-H1 .61、Qwen3.5 .78），首次出现的续片损伤很大（1.54、2.93、4.10、7.52）：后面的层仍能复制前文出现过的词。
- Transformer 切前三分之一的注意力时，复制也一起失效（OLMo-3 前三分之一：出现过的续片 5.73）。

### 其他（POST-HOC）
- Qwen3 后三分之一的注意力切断时，词内续片损伤极大（出现过 10.27、首次 8.58，词首约 2.2–2.5），不论是否出现过。OLMo-3 后三分之一则小得多（1.68、1.01）。
