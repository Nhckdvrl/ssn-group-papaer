# E215：循环部件是"学出来的"而不是"移植来的"改造模型里，谁来拼词（Jet-Nemotron-2B，2026-11-24）

- **状态：** PLANNED（约 10:00 写定，在下载和任何运行之前）
- **类型：** PILOT（因果，只推理；不推进主张等级）
- **对应：** E212、E214。两个蒸馏模型里，拼词都留在老师原来做这件事的地方：Llamba 的记忆被训练成模仿老师的注意力矩阵，拼词在记忆；MambaInLlama 保留老师的第 1 层注意力，拼词在注意力。但这两个模型的卷积都没真正学过（一个停在恒等，一个停在随机）。
- **Jet-Nemotron-2B 的情况**（2508.15884，NeurIPS 2025；子代理读了第 2–3.1 节原文）：
  - 由 Qwen2.5-1.5B 改造；28 层中第 14、19 层为全注意力，第 20、21 层为滑窗注意力，**第 0–13 层都是 JetBlock**。
  - 只继承 Qwen 的 MLP，第一阶段冻结。JetBlock（GDN 记忆 + 只作用于 V 的动态卷积，宽 4）是新学的：形状与 Qwen 注意力不同，无法直接复制；论文也没写复制。
  - 第一阶段 500 亿 token，带蒸馏损失（论文未写类型）；第二阶段 3,500 亿 token，全模型训练。
  - 动态卷积的生成器初始化为零，静态部分 N(0, .02)，即起点是很小的随机核，不是恒等。
  - 也就是说，循环部件是在继承来的 MLP 上学出来的，而且训练很长，卷积有充分机会学到东西。
- **问题（一句话）：** 循环层和卷积都是学出来、而非从老师注意力移植来的改造模型里，早期拼词由卷积承担还是由记忆承担？

## 设置
- **模型：** `jet-ai/Jet-Nemotron-2B`（不受限，官方 remote code，transformers 4.57.6 + fla 0.4.0 环境）。老师参照：`Qwen/Qwen2.5-1.5B`（不受限），只做不干预。
- **条目：** E194 规则，用 Qwen2.5 分词器重建；Qwen2.5 无文档开头标记，与 E198 一样不加。
- **干预**（只作用于第 0–2 层的 JetBlock；这三层在所有条件下都改用官方代码里的纯 torch "naive" 卷积实现，保证各条件只差干预本身）：

  | 条件 | 做法 |
  |---|---|
  | `none` | 不干预 |
  | `zero` | 生成出的卷积核邻位抽头置零 |
  | `mean` | 邻位输入换成该通道平均值（μ 用 EWT 第 50–149 段统计） |
  | `nomem` | GDN 记忆只剩当前 token（`A_log` 加 20） |

- **读数：** R1；读数层第 2 层，另报第 0–13 层（第一个注意力层之前）和 NLL。
- **实现阳性对照：** 50 段 EWT 的 NLL ≤ 老师 + 1.0，贪心续写正常。不过就排查，不解读。

## 判据与决策表（跑之前写定；与 E212 相同）
- **桥接：** `none` 第 2 层 Δ ≥ .30；不过就只描述（若第 2 层以后、第 14 层之前才拼，读数层改为第一个达到 .30 的层，干预不变）。
- **干净性：** 读数层下限 < 不干预的 .75 倍记"破坏表示"，不归类；卷积项以 `mean` 为准。
- "消失"：≤ .25 × `none`；"保留"：≥ .75 × `none`。

| 结果 | 条件 | 记录 |
|---|---|---|
| **卷积承担** | 卷积消失、`nomem` 保留 | 循环部件学出来时，拼词交给卷积，与自然预训练相同；蒸馏模型的结果来自"移植"：拼词留在移植过来的老师路线上 |
| **记忆承担** | `nomem` 消失、卷积保留 | 即使循环部件是学出来的、卷积学了 4,000 亿 token，拼词仍在记忆：可能来自蒸馏损失，或只作用于 V 的卷积不适合拼词 |
| **两者都需要** | 两者都消失 | 描述 |
| **中间** | 其他 | 描述 |

- **R5：** 跑完不改层号、阈值和条件；新加的分析一律标 POST-HOC。

## 混杂审计
- 卷积只作用于 V（Q、K 不过卷积），与 OLMo-Hybrid、Qwen3.5（Q、K、V 都过卷积）不同。
- 第一阶段的蒸馏损失类型未知；若是逐层特征蒸馏，JetBlock 的输出会被拉向老师注意力的输出。
- 继承的 MLP 来自老师，早期 MLP 可能带有老师的拼词成分。
