# E196：混合模型的早期拼词靠短卷积还是靠循环记忆——前三层的因果开关（2026-11-23）

- **状态：** PLANNED（04:50 写定，在任何干预运行之前）
- **类型：** PILOT（因果，只推理；不推进主张等级）
- **对应：** E194。OLMo-Hybrid 的前三层（全是 GDN，没有注意力）就能把被切开的词拼回原词：R1 在第 2 层，m = 2–5 时为 .54–.92，而且比 OLMo-3 更讲片段顺序。
  - GDN 层里，跨位置的信息只有两条路：一是宽度 4 的因果短卷积（作用于 q/k/v），二是 delta 规则的循环状态。
  - Allen-Zhu Part 4.1（NeurIPS 2025）报告：Mamba2 的性能主要来自内置的短卷积，而不是状态空间机制。
  - Afendulev 2609.04434 报告：循环状态保留部件、丢失绑定。
  - 两者对"哪条路负责按顺序拼词"给出不同的倾向。
- **问题（一句话）：** OLMo-Hybrid 前三层里的拼词和顺序绑定，是靠短卷积、靠循环状态，还是两者都行？两条路都关掉时，第一个全注意力层（第 3 层）能不能把拼词接过去？

## 设置
- **模型：** E194 的 `H`（OLMo-Hybrid-7B @ stage1-step1414078）。条目、上下文、R1 定义与 E194 完全相同（600 个词，m = 2–6；拆分、前缀打乱、只剩最后一片；32 个同上下文候选）。
- **干预**（只作用于第 0、1、2 层的 GDN；第 3 层及以后不动）：

  | 条件 | 做法 |
  |---|---|
  | `none` | 不干预，等于 E194 的 H |
  | `noconv` | 短卷积只保留当前位置的抽头，前 3 个邻位抽头置零；SiLU 照常。跨位置混合只剩循环状态 |
  | `nomem` | 在 `a_proj` 的输出上加 1e5，使衰减 g 极负、exp(g) ≈ 0，状态每步清空，只剩当前 token 写入的内容。跨位置混合只剩短卷积 |
  | `none_mix` | 同时做 `noconv` 和 `nomem`。前三层完全没有跨位置混合（工具的阳性对照） |

- **对照模型：** E194 的 `T`（OLMo-3）。条件 `T_noattn`：把第 0–2 层注意力块的输出置零，前三层同样没有跨位置混合，只用来对照"第 3 层能否接手"。
- **另测：** 每个条件在 50 段 EWT 上的每 token NLL，衡量干预造成的整体损伤。

## 读数与判据（跑之前写定）
- **主读数：**
  - 第 2 层（最后一个循环层）的 R1 拆分认回率，m = 2–6；
  - 第 2 层的绑定分数（拆分 − 前缀打乱，m = 3–6 平均）；
  - 第 3–8 层的 R1，看注意力能否接手。
- 全部按词型自助 1,000 次取 95% 区间。
- **"关掉"的标准：** 某条件下第 2 层 R1（m = 2–5 平均）的 95% 上界，低于 `none` 的下界与"只剩最后一片"线之间的中点。
- **阳性对照：** `none_mix` 必须"关掉"，即第 2 层的 R1 掉到只剩最后一片的水平附近（差 ≤ .1）。不过就说明干预没按预期生效，只修代码。

## 混杂审计
- **加 1e5 的做法：** 也改变了 g 以外的数值吗？a_proj 的输出只进入 g，已核对 `modeling_olmo_hybrid.py`。
- **分布外：** 干预后模型处于训练时从未见过的状态，后续层的反应可能不是正常机制。用 NLL 报告损伤程度，只解释第 2 层（干预层本身的输出）和"能否追回"，不解释后面层的细节。
- **SiLU 激活：** 卷积置零后的激活值与原本不同，属干预的一部分。

## 结果（2026-11-23 05:20 填写；上面的内容未改）
- **阳性对照通过：** `none_mix` 的第 2 层拆分 R1（m = 4）为 .08，等于"只剩最后一片"的 .08。`none` 的 NLL 为 2.974，与 E194 的 H 完全一致，说明脚本本身没有改变模型。
- **第 2 层拆分 R1**（95% 区间；机会 .03）：

  | 条件 | m = 2 | m = 3 | m = 4 | m = 5 | m = 6 | 每 token NLL |
  |---|---|---|---|---|---|---|
  | none | .92 [.90, .94] | .79 [.76, .82] | .67 [.63, .71] | .54 [.50, .58] | .45 [.41, .49] | 2.974 |
  | nomem | .95 [.93, .97] | .64 [.60, .68] | .27 [.23, .31] | .10 [.08, .13] | .09 [.06, .12] | 3.000 |
  | noconv | .42 [.38, .46] | .18 [.14, .21] | .08 [.06, .11] | .05 [.03, .07] | .04 [.02, .06] | 4.035 |
  | none_mix | 等于"只剩最后一片" | | | | | 3.876 |
  | 只剩最后一片 | .33 | .15 | .06 | .05 | — | — |

- **按决策表：**
  - `noconv` 关掉了：m = 2–5 平均为 .18。中点 = (none 的下界 .69 + "只剩最后一片"的 .15) / 2 ≈ .42，`noconv` 的上界在它之下。
  - `nomem` 没有关掉：m = 2–5 平均 .49，上界高于 .42。
  - 结论落在 **"卷积负责"** 分支。
  - 另记：`nomem` 下拼词随片数衰减——m = 2 与 none 持平，m = 5、6 落到"只剩最后一片"的水平。也就是说，循环记忆单独不起作用，但在卷积之上把拼词延伸到长词。
- **能否追回**（第 3–8 层）：

  | 条件 | m = 4 的拆分 R1 | 说明 |
  |---|---|---|
  | none | — | 基准 |
  | nomem | 第 3 层 .61 → 第 8 层 .93 | 追回到 none 的水平 |
  | noconv | 到第 12 层 .22 | 追不回 |
  | none_mix | 到第 12 层 .22 | 追不回 |
  | T_noattn（OLMo-3 前三层注意力置零） | 到第 12 层 .10，等于"只剩最后一片" | 追不回，NLL 6.34 |

  两种架构里，前几层没有开始拼词，后面的层（无论注意力层还是完好的循环层）都不会补拼。
- **绑定分数**（m = 3–6 平均，第 2 层）：none .36，nomem .06，noconv 与 none_mix 为 0。`nomem` 下 m ≥ 4 的拆分认回率本身已接近下限，这个数字主要反映认回率低，不单独解读。
