# E217：关掉早期卷积后，坏掉的是"拼词"、"一切局部组合"，还是"全局"？（四级对照，2026-11-24）

- **状态：** PLANNED（约 11:30 写定，在任何 E217 运行之前）
- **类型：** PILOT（因果，只推理；不推进主张等级）
- **为什么做：** 讨论文档里最大的未解问题（Gemini 指出，我们同意）。关掉 OLMo-Hybrid 前三层卷积后，NLL 2.97 → 4.03。"完整单 token 词不受影响"只说明表示没有整体坏掉，不说明卷积专门负责拼词。卷积承担的也可能是一切短距离的局部组合，拼词只是其中最显眼的探针；也可能干预造成了全局的分布偏移。
- **问题（一句话）：** 关掉早期卷积后，受损的是词内拼接、跨词的局部组合，还是连远距离依赖也一起受损？

## 设置
- **模型与条件**（只作用于第 0–2 层；关卷积的做法与以前各卡一致）：

  | 模型 | 条件 |
  |---|---|
  | OLMo-Hybrid-7B | none、conv（置零）、mem |
  | Qwen3.5-4B | none、conv（置零）、mem |
  | Granite-4.0-H-micro | none、conv（置零）、mem |
  | Falcon-H1-3B | none、conv（均值替代）、mem、attn |
  | OLMo-3-7B（参照） | none、attn |
  | Llamba-1B（参照：卷积不起作用的蒸馏模型） | none、conv（均值替代）、mem |

- **四级读数**（都不用人为拆分）：
  1. **词内续片：** EWT 第 0–199 段的逐 token NLL，分成"词内续片"（不以空格开头、前后都是字母的子词）和"词首"两类，报告两类各自的 NLL 及干预后的增量。
  2. **跨词固定搭配：** 约 100 个由两个完整单 token 词组成的固定搭配（如 New York、ice cream、climate change），放在 3 个中性前缀后。读数为搭配优势 = log P(第二个词 | 第一个词) − log P(第二个词 | 换成别的第一个词)，按分词器筛掉不是单 token 的条目。
  3. **相邻句法：** BLiMP 的 determiner_noun_agreement_1、determiner_noun_agreement_2、regular_plural_subject_verb_agreement_1，最小对准确率（整句对数概率比较）。
  4. **远距离依赖：** BLiMP 的 distractor_agreement_relative_clause、distractor_agreement_relational_noun。
- 另报 50 段 EWT 的整体 NLL。

## 判据与决策表（跑之前写定；只看各模型的 conv 条件）
- 记号：
  - ΔNLL_内、ΔNLL_首：词内、词首 NLL 的增量；
  - R_搭配：搭配优势保留比例（干预后 ÷ 不干预）；
  - 降_近：相邻句法准确率的下降（百分点，三个范式平均）；
  - 降_远：远距离准确率的下降（百分点，两个范式平均）。

| 结果 | 条件 | 记录 |
|---|---|---|
| **专门负责拼词** | ΔNLL_内 ≥ 2 × ΔNLL_首，R_搭配 ≥ .75，降_近 ≤ 5，降_远 ≤ 5 | 卷积只管词内拼接 |
| **负责一切局部组合** | R_搭配 ≤ .5 或 降_近 ≥ 10，且 降_远 ≤ 5 | 卷积承担跨词边界的短距离组合；拼词只是一例；远距离机制完好，不是全局破坏 |
| **全局破坏** | 降_远 ≥ 10 | 关卷积造成全局分布偏移，之前的因果结论要降级 |
| **中间** | 其他 | 描述 |

- 各模型分别判；参照模型只描述。
- **R5：** 跑完不改条目、范式、阈值；新加的分析一律标 POST-HOC。

## 混杂审计
- BLiMP 句子里也有多片词，关卷积可能通过拼词间接影响所有范式；所以远距离读数是"全局机制是否完好"的上界检验，不是纯净对照。
- 固定搭配的"优势"也依赖第二个词的先验频率；用换掉第一个词的对照抵消。
