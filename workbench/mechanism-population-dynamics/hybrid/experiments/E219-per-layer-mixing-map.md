# E219：逐层、逐部件地测"谁在 token 之间搬运信息"（10 个公开模型，2026-11-24）

- **状态：** PLANNED（约 14:00 写定，在任何 E219 运行之前）
- **类型：** MEASUREMENT（因果，只推理；不推进主张等级）
- **为什么做（从已有证据出发）：**
  - E217、E218 显示，在前 3 层里，每个模型只有一个部件在搬运 token 间的信息：预训练混合模型是卷积，Transformer 是注意力，蒸馏的 Llamba 是记忆。关掉其他部件几乎没有影响。关掉这一个部件，拼词消失，词首预测和远距离一致也一起受损。
  - 但这只测了第 0–2 层和 4 个混合模型；而且各部件的关法不对等：注意力是把整个输出置零，记忆是只保留当前 token。
  - 用户 11-24 的要求：不预设主线，先做信息量大的测量，再集中讨论。这张图不服务于某一条叙事。不论最后的题目是拼词、早期分工还是别的，都要知道每层每个部件实际搬运了多少信息，搬运的是近处还是远处的信息。
- **问题（一句话）：** 在各类公开模型里，每一层的卷积、循环记忆和注意力各自在 token 之间搬运了多少信息？搬运的是近处还是远处的信息？

## 设置
- **模型（5 组对照 + 2 个单独参照）：**

  | 组 | 模型 |
  |---|---|
  | OLMo | OLMo-Hybrid-7B（GDN + 注意力）/ OLMo-3-7B |
  | Granite | Granite-4.0-H-micro（Mamba-2 + 注意力）/ Granite-4.0-micro（稠密） |
  | Qwen | Qwen3.5-4B（GDN + 注意力）/ Qwen3-4B |
  | 蒸馏 | Llamba-1B（由 Llama-3.2-1B 蒸馏）/ Llama-3.2-1B-Instruct（老师） |
  | 单独 | Falcon-H1-3B（每层 Mamba-2 与注意力并行）、Falcon-Mamba-7B（纯 Mamba-1） |

- **干预：** 每次只作用于一层里的一个部件。三种干预都是"切断 token 之间的通路，保留当前 token 自己的通路"：
  - **卷积：** 邻位抽头用均值替代（E209 的做法；μ 取自 EWT 第 50–149 段，与评估段不重叠）。如果某个模型抓不到卷积输入，改为置零，并在结果里注明。
  - **记忆：** 状态只保留当前 token（`A_log` 加 20；Llamba 只保留对角项，同 E212）。
  - **注意力：** 只看自己。每个位置的注意力输出换成它自己的 value，之后照常经过输出投影和门控。
- **读数（都不用人为拆分）：**
  1. EWT 前 50 段（每段 ≤ 511 token）的逐 token NLL，报告干预后的平均增量 ΔNLL。
  2. 按 token 类型分开：词内续片和词首（定义同 E217）。
  3. 按需要多远的上下文分开：在不干预的模型上，对位置 ≥ 32 的每个 token，计算"只给最近 32 个 token"的 NLL 减去完整上下文的 NLL，记为远程增益。按远程增益三分位分成近程、中间、远程三组，分别报告 ΔNLL。另用窗口 128 重算一次，作稳健性检查。

## 读法（跑之前写定；以描述为主，阈值只作标记，不作判决）
- 每个模型画出三条曲线：各部件的 ΔNLL 随层的变化。
- **早期路线：** 前 3 层里，各部件 ΔNLL 之和的比值。最大的部件是其他部件之和的 10 倍以上，记为"单一路线"；报告每个模型的倍数。
- **起作用的深度：** 记忆、注意力的 ΔNLL 首次 ≥ .05 的层。
- **近程与远程：** 每个部件各层的 ΔNLL_远程 ÷ ΔNLL_近程，看卷积是否只承担近程，记忆和注意力在哪些层承担远程。
- **对照组：** 混合模型与同家族 Transformer 的早期路线是否不同；蒸馏模型与它的老师是否相同。
- **事先列出的可能形态（只作对照）：**
  - a. 所有预训练混合模型的前几层都只有卷积在搬运，记忆和注意力到中层才起作用；同家族 Transformer 的前几层由注意力搬运。
  - b. 有的混合模型前几层的记忆也明显起作用（如 E217 中 Qwen3.5 关三层记忆 NLL +.45）。这时分工因模型而异，逐个描述。
  - c. 卷积在深层也起作用。Mamba 系深层卷积是恒等，预期不起作用；OLMo-Hybrid 的 k、v 卷积到第 16 层仍是移位算子，可能起作用。
- **R5：** 跑完不改模型、干预、读数和分组；新加的分析一律标 POST-HOC。

## 混杂审计
- 三种干预都会改变该层输出的分布。"只看自己"的注意力输出尺度与正常输出不同。只报告 NLL 增量，不把它解释成"这个部件做了多少"。
- 单层干预后，后面的层可能补偿。所以测到的是"这一层这个部件不可替代的部分"。E218 显示，单层关卷积的损伤会被部分补回。
- 远程增益依赖窗口长度，所以另用 128 重算。三分位只用于分组。
- 词内 / 词首的定义依赖分词器的空格标记（同 E217）。

## 算力
- 约 570 次单层运行，每次是 50 段前向；每个模型另做一次窗口计算。Falcon-Mamba 没有快速内核，逐步扫描较慢。估计共 ≤ 4 GPU 小时。白天用 fvcrc10、fvcrc13 的空闲卡，最多 8 张。

## 结果
- 文件：`results/e219/<模型>.json`、`results/e219/summary.json`（`scripts/e219_summary.py`）、图 `results/e219/fig_profiles.png`。
- 10 个模型全部跑完。每个模型跑完后的复原检查与基线差 0。所有带卷积的模型都抓到了卷积输入，全部用均值替代。
- **结论：前 3 层里只有一个部件在搬运 token 间信息，这在 4 个预训练混合模型（卷积）和 Llamba（记忆）中成立，倍数为 11–56。纯 Mamba 的 Falcon-Mamba 不成立：任何一层、任何部件单独关掉都 ≤ .08。混合模型里，记忆在任何一层单独关掉都 ≤ .08，注意力 ≤ .26。Transformer 则几乎每层注意力都有份，各层相加是混合模型的数倍。**

### 早期路线（第 0–2 层各部件 ΔNLL 之和）

| 模型 | 卷积 | 记忆 | 注意力 | 最大者 ÷ 其余之和 |
|---|---|---|---|---|
| OLMo-Hybrid | .25 | .01 | 前 3 层无注意力 | 19 |
| Qwen3.5-4B | 1.24 | .12 | 前 3 层无注意力 | 11 |
| Granite-4.0-H | .51 | .02 | 前 3 层无注意力 | 24 |
| Falcon-H1（每层并行注意力） | .77 | .03 | .01 | 22 |
| Falcon-Mamba | .03 | .01 | 无 | 2.9 |
| Llamba | .01 | .67 | 无 | 56 |
| OLMo-3 | — | — | 1.66 | — |
| Qwen3-4B | — | — | .81 | — |
| Granite-4.0-micro | — | — | .72 | — |
| Llama-3.2-1B | — | — | 6.09 | — |

- 按卡片的标记，4 个预训练混合模型和 Llamba 是"单一路线"（≥ 10 倍）；Falcon-Mamba 不是（2.9 倍，而且各部件都很小）。
- OLMo-Hybrid、Qwen3.5、Granite-H 的前 3 层没有注意力层（第一个注意力层分别在第 3、3、5 层），所以它们的早期比较只是卷积对记忆。

### 起作用的深度（ΔNLL 首次 ≥ .05）
- **记忆：** OLMo-Hybrid、Falcon-H1、Falcon-Mamba 全部层都 < .05；Qwen3.5 只有第 0 层（.08）；Granite-H 只有第 12 层（.05）；Llamba 从第 0 层起（.34、.22、.10……）。
- **注意力：** 三个串联混合模型的第一个注意力层就 ≥ .05，但每层都不大（OLMo-Hybrid .04–.16，Qwen3.5 .01–.09，Granite-H .06–.26，深层略大）。Falcon-H1 并行注意力全部层 ≤ .04。Transformer 从第 0 层起。
- **卷积：** 混合模型从第 0 层起。≥ .05 的层：OLMo-Hybrid 第 0、2、6、14 层；Qwen3.5 第 0、1 层；Falcon-H1 第 0、2、3、5、8 层；Granite-H 分散在第 0–27 层，其中第 11 层 +1.46。Mamba 系深层卷积不起作用（Granite-H 第 28 层后、Falcon-H1 第 9 层后都 < .05）。Falcon-Mamba 只有第 20、25 层略过 .05。

### 各层单独干预之和
- 只粗略反映"这类部件有多少层各自不可替代"，不是"做了多少"。
- Transformer 注意力：OLMo-3 4.0，Qwen3 5.3，Granite 稠密 7.5，Llama-1B 12.6。
- 混合模型：卷积 .70–3.35，记忆 .21–.37，注意力 .40–.75。
- Falcon-Mamba（64 层）：卷积 .71，记忆 .29。Llamba：记忆 1.57，卷积 .09。

### 对照组
- OLMo、Granite、Qwen 三组都是：混合模型的早期路线是卷积，同家族 Transformer 是注意力。
- 蒸馏组：Llamba 的早期路线是记忆，它的老师 Llama-1B 是注意力。MOHAWK 把老师的注意力映射到学生的记忆上，路线留在了映射过去的位置。

### 近程与远程
- 每个部件在远程组的增量都大于近程组，卷积也是如此。但三组本身难度不同：不干预时近程组 NLL 3.0–3.5，中间组 1.5–1.8，远程组 2.7–2.9。所以这一读数不能直接读成"卷积管远程"。窗口 128 下差别缩小。只记录，不解读。

### 对照事先列出的形态
- **a 基本成立：** 混合模型前几层只有卷积在搬运；记忆在任何层单独关掉都很小；注意力单层影响小；同家族 Transformer 前几层由注意力搬运。
- **b：** 唯一例外是 Qwen3.5 第 0 层的记忆（.08）。与 E217 中 Qwen3.5 关三层记忆影响较大（+.45）一致。
- **c 部分成立：** 卷积在中层也有个别大的层（Granite-H 第 11 层 +1.46、第 24 层 +.24；Falcon-H1 第 2–5 层 .13–.24），Mamba 系深层卷积不起作用。OLMo-Hybrid 的卷积到第 14 层仍有 .05。

### 事后观察（POST-HOC，不进判据）
- **后段注意力层只看自己时，主要伤的是词内续片：**
  - Qwen3 第 29 层：词内 +1.42、词首 +.17；第 31–34 层：词内 +.76 到 +1.02。
  - Llama-1B 第 15 层：词内 +1.01、词首 +.20。
  - OLMo-Hybrid 第 19–31 层注意力：词内 +.33 到 +.50、词首 +.05 到 +.10。

  一种可能的解释是：后段注意力在复制前文出现过的多片词。未核对。
- **Granite-H 第 11 层卷积 +1.46：** 单层影响比前 3 层都大，原因未查。
- **混合模型对单层干预比 Transformer 稳得多：** 除少数卷积层外，单关哪一层都几乎没有影响。纯 Mamba 更极端。单层干预测不到冗余，所以 Falcon-Mamba"没有单一路线"也可能是多层冗余造成的。本卡不能区分这两种情况。
