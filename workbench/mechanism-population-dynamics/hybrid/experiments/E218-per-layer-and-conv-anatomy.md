## B1：逐层干预（PLANNED）
- **模型与做法：**
  - OLMo-Hybrid-7B、Qwen3.5-4B、Granite-4.0-H-micro：卷积置零 / 记忆 `A_log` 加 20（OLMo-Hybrid 沿用 E196 的 `a_proj` 加 1e5）。
  - Falcon-H1-3B：卷积均值替代 / 记忆 `A_log` 加 20。

- **读数：** R1（同 E194），按 m = 2–6 分别报告 Δ，读第 2、4、8 层；另报 NLL。
- **读法**（描述为主，不设成败判据，事先列出可能形态）：
  - 接力：只关第 0 层就让 m = 2 消失，只关第 1、2 层主要伤长词。
  - 单层承担：某一层的卷积单独关掉就让所有 m 消失。
  - 冗余：单关任一层都不消失，三层一起关才消失（与 E196、E198 对照）。
  - 记忆的作用在哪一层出现，以及 GDN 与 Mamba-2 是否不同。

- **对照事先列出的形态：** OLMo-Hybrid 与 Falcon-H1 接近"接力"（第 0 层管全部长度，第 1、2 层主要管长词）；Qwen3.5 与 Granite-H 接近"冗余 / 累积"（单关任一层都不消失，三层一起关才消失）。没有"单层承担"。记忆的作用分散在三层，GDN（OLMo-Hybrid、Qwen3.5）三层一起关时损伤更大，与 E196、E198 一致；单层上 GDN 与 Mamba-2 没有明显差别。
