# E199：没有短卷积的混合模型在哪里拼词——Ring-mini-linear-2.0 对它的 Transformer 父模型（2026-11-23）

- **状态：** PLANNED（06:05 写定，在下载和任何运行之前）
- **类型：** PILOT（只推理；不推进主张等级）
- **对应：** E196 与 E198。
  - 在三个带短卷积的混合模型里，关掉卷积的邻位抽头，拼词就消失；循环记忆单独时拼不了词；前几层没拼，后面的层不补拼。
  - 但那三个模型都是带着卷积训练的，它们的记忆"没被训练去拼词"也说得通。
  - 要分清"记忆本身做不到"和"有卷积时记忆没去做"，需要一个**训练时就没有卷积**的混合模型。
- **问题（一句话）：** 线性注意力层里没有短卷积的混合模型 Ring-mini-linear-2.0，是在第一个全注意力层（第 4 层）之前就把词拼好，还是要等到第 4 层？

## 设置
- **模型**（bf16，只推理，远程代码先读后用）：

  | 键 | 模型 | 结构 |
  |---|---|---|
  | RL | inclusionAI/Ring-mini-linear-2.0 | 20 层。线性注意力为 Lightning Attention-2：每头固定衰减的线性注意力，代码里没有任何卷积（已在 `modeling_bailing_moe_linear_v2.py` 中核对）。全注意力在第 4、9、14、19 层，第 0 层是稠密 FFN，其余为 MoE |
  | LB | inclusionAI/Ling-mini-base-2.0-20T | RL 的父模型：RL 由它转换而来，又继续训练了 6,000 亿 token（RL 的模型卡）。全是注意力层 |

  RL 还经过推理型后训练（Ring），LB 是基座；这一差异在混杂审计中记为未控制。
- **条目：** 规则与 E194 相同（EWT、单 token 词人为拆成 m = 2–6 片、种子 194、600 个词），分别用各自的分词器建；两个模型的分词器文件 oid 不同，先比较它们在条目上的切分是否一致。
- **读数：** E194 的 R1（同一上下文 32 个候选；拆分 / 前缀打乱 / 只剩最后一片），逐层报告。另报 50 段 EWT 上的每 token NLL，加载检查用。
- **起点：** 与 E194 的定义相同，第一个满足"≥ 该曲线最大值的 50%，且高于只剩最后一片的线"的层。这里没有未训练模型，参照线用"只剩最后一片"代替 step0。按词型自助 1,000 次。

## 判据与决策表（跑之前写定）
- **主读数：** RL 第 3 层（第一个全注意力层之前的最后一个线性层）的拆分 R1，m = 2–5 平均，记为 A3；同一层"只剩最后一片"的平均，记为 F3。另看 RL 第 4 层的值。

| 结果 | 条件 | 记录 |
|---|---|---|
| **等注意力** | A3 − F3 ≤ .10，且第 4 层的拆分 R1（m = 2–5 平均）≥ F3 + .30 | 没有卷积时，线性注意力的记忆拼不了词，要等第一个全注意力层。支持"拼词在哪里由卷积决定" |
| **记忆自己拼** | A3 − F3 ≥ .30 | 训练时没有卷积的混合模型会用记忆在前几层拼词。三个带卷积的模型里记忆不拼，是"有卷积就不用记忆"的自发分工 |
| **中间** | 其他 | 描述，不下结论 |

- **阳性对照：**
  - RL、LB 的 NLL 合理，续写通顺。
  - LB 的拆分 R1（m = 2）最大值 ≥ .5，并且在前 3 层内到达起点（与 Kaplan、Word Factory 一致）。
- **R5：** 跑完不改层号、阈值、m 的取值；新加的分析一律标 POST-HOC。

## 混杂审计
- **RL 对 LB：** 同源，但 RL 多了 6,000 亿 token 的继续训练和推理型后训练；只比较"在哪一层拼好"，不比较绝对水平。
- **第 0 层：** RL 是"线性注意力 + 稠密 FFN"，其余层是 MoE；LB 相同。
- **远程代码与库版本：** 远程代码按 transformers 4.56 写成，需要 `fla`。另建一个环境：transformers 4.57.6、torch 2.8 cu128、flash-linear-attention。两个模型用同一个环境。
- **衰减：** Lightning 线性注意力的衰减按层号设定，第 0 层衰减最快。这是该架构本身的属性，照实报告。

## 结果（2026-11-23 06:30 填写；上面的内容未改）
- **运行前后的处理（都在看 R1 之前）：**
  - 远程代码的 KV 缓存与 transformers 4.57 不兼容，所有前向改为 `use_cache=False`。只是不建缓存，不影响读数。
  - RL 的每 token NLL 为 4.70（前 128 token 5.38，后 128 token 3.91），LB 为 2.79。贪心续写都正确（RL："Paris. The capital of Germany is Berlin."）。
  - 按模型卡要求的版本（transformers 4.56.1、fla 0.3.2）另建环境重算，RL 的 NLL 仍为 4.70。所以与库版本无关，更可能来自 RL 的推理型后训练。R1 是同上下文中的相对排名，照常读，但在此注明。
  - 两个模型在 600 个条目上的切分完全相同，共用一套条目。
- **主读数（第 3 层，m = 2–5 平均）：**
  - RL 拆分 A3 = .91，只剩最后一片 F3 = .24，A3 − F3 = **.67**。
  - 第 4 层（全注意力）为 .94。
  - **按决策表判"记忆自己拼"。**
- **逐层（拆分 R1，m = 2 / 3 / 4 / 5 / 6）：**

  | 层 | RL | LB |
  |---|---|---|
  | 0 | .90 / .54 / .32 / .22 / .16 | .89 / .54 / .34 / .21 / .15 |
  | 1 | .97 / .87 / .77 / .62 / .47 | .98 / .91 / .81 / .66 / .49 |
  | 2 | .99 / .95 / .86 / .78 / .68 | .99 / .97 / .90 / .77 / .64 |
  | 3 | .99 / .96 / .88 / .82 / .75 | 1.00 / 1.00 / .96 / .94 / .85 |

  RL 的前四层没有卷积、没有注意力，拼词速度却与它的 Transformer 父模型几乎一样。
- **绑定分数**（m = 3–6 平均）：第 1 层 RL .12 / LB .18，第 2 层 .22 / .34。
- **阳性对照通过：** LB 的 m = 2 最大值 1.00，起点在第 1 层以内。
- **解读的边界：**
  - RL 的 Lightning 线性注意力带 RoPE 的 q、k，衰减固定、没有 delta 规则，与 GDN、Mamba-2 的记忆机制不同。所以"有卷积时记忆不拼、没卷积时记忆会拼"与"记忆类型不同"在这里混在一起，不能单独归因于有没有卷积。
  - 需要同配方、只差有没有短卷积的模型对。PhysicsLM4.2 公开了 Llama 与 LlamaCanon（1B–8B），但是受限访问，需要人接受许可。
