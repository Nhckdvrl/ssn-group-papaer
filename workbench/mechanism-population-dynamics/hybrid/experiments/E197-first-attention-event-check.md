# E197：混合模型"第一个全注意力层的跨语言事件"是跨语言特有的，还是通用几何变化（2026-11-23）

- **状态：** PLANNED（04:50 写定，在任何 E197 计算之前）
- **类型：** PILOT（只推理；不推进主张等级）
- **对应：** E194 的决策表分支 B/D，以及 E195 的"不复现"分支。
  - 拼词在第一个全注意力层之前已经完成（E194 OLMo、E195 Granite 的 R1 都如此），所以 Bandarkar 2609.35378 观察到的事件不是拼词。
  - 剩下的问题：这个事件是"不同语言在这一层真的靠拢了"，还是"注意力层改变了表示的整体形状"？2609.08692（EMNLP 2026）报告，Jamba2 每过一个注意力层，第一主成分的占比就骤升。
  - 另外两个让人怀疑的地方：SoftCKA 用的是原始隐状态之间的距离（RBF 核），原文没有写带宽怎么选；原文也没有"非平行句对"的参照线。
- **问题（一句话）：** 在混合模型的第一个全注意力层，平行句之间的相似度突变，是否超出了同一层上"随便配对的句子"之间的相似度变化？用不受整体尺度影响的检索尺子，是否也看得到这个突变？

## 设置
- **语料：** UD PUD 树库。1,000 句在 12 种语言里完全平行（en, fr, de, es, ru, zh, ja, ko, ar, hi, th, tr），按 sent_id 对齐；构建脚本为 `scripts/e197_pud.py`。
- **语言对：** 英语对其余 11 种语言。按各模型支持的语言分开报告，主结论只用 fr, de, es, zh, ja, ar, ko：这 7 种在 Granite 官方支持的语言内，Qwen3.5 也支持。
- **模型：**

  | 键 | 模型 | 第一个全注意力层（0 起） | 对照 |
  |---|---|---|---|
  | QH | Qwen3.5-4B-Base | 3 | — |
  | QT | Qwen3-4B-Base | 无（全是注意力） | QH 的近似非混合对照，分词器不同，只作走势对照 |
  | GH | Granite-4.0-H-Micro-Base | 5 | GT 为同配方的全注意力版本 |
  | GT | Granite-4.0-Micro-Base | 无 | |
  | H | OLMo-Hybrid（E194） | 3 | T（E194）；OLMo 不含多语言数据，只作补充 |

- **输入：** 每句单独作为一条序列。开头符的处理与 E194/E195 相同：Granite 不加，OLMo 加 EOS，Qwen 不加。
- **记录的位置：** 每层的输出，也就是下一层的输入，相当于原文的 attn_in。

## 读数（跑之前写定）
- **M1 SoftCKA：** 照原文公式 (1)：RBF 核，三个矩阵共用一个带宽，每句对内行列中心化，在语料上把分子分母各自求和后再相除。
  - 带宽：原文未写，取该句对全部 token 两两距离的中位数（中位数启发式）。另报 ×0.5 和 ×2 的敏感性。
- **M1-mis：** 同样计算，但英语第 i 句配上目标语言第 π(i) 句（π 为固定种子 197 的错位排列）。
  - **跨语言特有部分** = M1 − M1-mis。
- **M2 检索：**
  - 每句的 token 取均值池化，减去该语言在该层的平均向量，用余弦从 1,000 句中检索英语句的译文，报告 top-1 准确率，机会水平 .001。
  - 这是排名读数，不受整体尺度和各向异性影响。
- **M3 几何：** 该层全部 token（所有语言）的第一主成分方差占比。
- **"事件"的定义：** 第 a 层（第一个全注意力层）的变化 Δ(a) = M(a 层输出) − M(a−1 层输出)。与第 0–8 层中其他各层 |Δ| 的中位数相比：|Δ(a)| ≥ 2 × 中位数，且是这些层里最大的，就算有事件。
- **区间：** 按句子自助 1,000 次。

## 混杂审计
- **QH 对 QT：** 分词器、数据、发布时间都不同，只看走势，不做差值比较。
- **GH 对 GT：** 同配方。GH 的注意力是 NoPE，GT 是 RoPE；两者都是基座模型。
- **句长：** 不同语言的 token 数相差很大。M1 照原文不做长度归一；M2 用均值池化。
- **多语言能力：** 只在官方支持的语言上下主结论。

## 算力
- 5–7 个模型，每个 12 × 1,000 句单句前向，加两两句对的核计算。每个模型约 10–20 分钟（循环层用参考实现）。用空闲卡，预计 < 2 GPU 小时。

## 结果（2026-11-23 05:50 填写；上面的内容未改；Qwen3-4B 对照还在跑）
- **按预先写定的事件定义**（第 a 层自身造成的变化 Δ(a)，必须是第 0–8 层中最大且 ≥ 2 倍中位数），GH、GT、H、T、QH **全部判"复现不了"**。
  - 定义上的差异：原文画的是"进入每一层的表示"（attn_in），所以原文的尖峰对应我们的 M(a 层输入)，即 Δ(a−1)，而不是 Δ(a)。这是写卡时的口径失误，判据不改，下面的解读全部标 POST-HOC。
- **POST-HOC：** 在"进入全注意力层的表示"上确实有尖峰，而且三条线同步：

  | 模型 | 位置 | M1 平行句 | M1 错配句 | 第一主成分占比 | 平行 − 错配 |
  |---|---|---|---|---|---|
  | GH | 进入第 5 层 | .22 → .38 → .27 | .07 → .26 → .11 | .04 → .17 → .07 | .15 → .12 → .16，无尖峰 |
  | QH | 进入第 3 层 | .19 → .26 | .05 → .09 | .03 → .09 | 从 .14 平滑升到 .23，无尖峰 |
  | QH | 进入第 7 层 | .29 → .46 | .06 → .27 | .04 → .32 | 同上 |

  - **OLMo-Hybrid（H）没有 SoftCKA 尖峰**：曲线平或下降。OLMo 训练数据不含多语言；带宽取法也可能与原文不同。
  - **检索（M2，排名读数，按语言去均值）：**
    - QH 在第一个全注意力层之前已到 .98（第 0 层 .88，第 1 层 .95）。
    - H 在第 1–3 层上升快于 T（第 2 层输出 .75 对 .62）。
    - GT 的检索在第 1 层后跌到 .13–.23：GT 的第一主成分占比达 1.00（巨大激活），均值池化的检索在它身上失效。这把尺子对 GT 不可用，未修正。
- **POST-HOC 解读（不作主张）：** 原文所说的"第一个全注意力层的跨语言事件"，在 GH 和 QH 上表现为"进入全注意力层的表示"的几何尖峰：错配句对同样出现，并与第一主成分跳变同步，不是跨语言特有的靠拢。拼词在此之前已完成（E194–E198），所以它也不是拼词。
