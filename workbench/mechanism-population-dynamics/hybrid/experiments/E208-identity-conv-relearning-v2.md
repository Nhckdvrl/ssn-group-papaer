# E208：E204 的改正版——fp32 主权重、前三层循环层用高学习率时，恒等卷积能否重新学会早期拼词（2026-11-24）

- **状态：** PLANNED（约 00:55 写定；写卡前已看过 E204 全部结果）
- **类型：** PILOT（继续训练 + 只读读数；不推进主张等级）
- **为什么要重做：**
  - E204 判"重学很慢"，但可训练变体 `id_train` 的卷积几乎没动：1 亿 token 后，邻位抽头的最大绝对值只有 .016，训练好的卷积可达 1.76。它与冻结变体 `id_frozen` 的所有读数几乎相同。
  - 原因一：学习率 5e-5，比 Bandarkar 给转换层用的高学习率低得多。
  - 原因二：权重直接以 bf16 训练，小幅更新被舍入（bf16 在 1 附近的精度约 .008）。
  - 所以 E204 没有检验到"卷积能否重学"，不能拿来支持或反对对 Bandarkar 结果的解释。
- **问题（一句话）：** 在接近蒸馏设置的学习条件下（fp32 主权重；前三层 GDN 模块的学习率 1e-3，其余 5e-5），恒等卷积能否在 5,000 万 token 内重新学会早期拼词？卷积冻结时，记忆能否在高学习率下补位？

## 设置
- **模型、数据、读数：** 与 E204 相同（Qwen3.5-0.8B-Base；FineWeb-Edu 的 Qwen 分词版本；R1 的 Δ2、Δ3、Δ8；NLL）。
- **两个变体**（fp32 主权重，bf16 autocast；每步 128 × 512 token；共 5,000 万 token；种子 204）：

  | 变体 | 做法 |
  |---|---|
  | `id_train_hi` | 第 0–2 层卷积设为恒等、可训练；第 0–2 层 GDN 模块（含卷积）学习率 1e-3，其余参数 5e-5 |
  | `id_frozen_hi` | 卷积冻结在恒等；第 0–2 层 GDN 模块的其余参数学习率 1e-3，其余 5e-5 |

- **参照：** E204 的 `ctrl`（Δ2 为 .68–.70）。
- **检查点：** 1,000 万、5,000 万 token。

## 判据（跑之前写定；沿用 E204 的阈值）

| 变体 | 结果 | 条件 | 记录 |
|---|---|---|---|
| `id_train_hi` | **卷积很快重学** | 5,000 万 token 时 Δ2 ≥ .80 × .69 = .55 | 在高学习率下，恒等初始化只是短暂障碍；用它解释 Bandarkar 结果的力度减弱 |
| | **重学很慢** | Δ2 < .50 × .69 = .35 | 即使学习率高，早期拼词也难以在 5,000 万 token 内恢复；支持该解释 |
| | **中间** | 其他 | 描述 |
| `id_frozen_hi` | **记忆补位** | Δ2 ≥ .35 | 高学习率下记忆能学会拼词 |
| | **不补位** | Δ2 < .35 | |

- 另记卷积邻位抽头的变化幅度，用来确认卷积确实在学。
- **R5：** 不改判据和检查点。
