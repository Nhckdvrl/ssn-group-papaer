# E214：蒸馏模型里，随机初始化的卷积会不会从老师继承来的注意力手里接过拼词（Llama3.2-Mamba-3B-distill，2026-11-24）

- **状态：** PLANNED（约 09:25 写定，在下载和任何运行之前）
- **类型：** PILOT（因果，只推理；不推进主张等级）
- **对应：** E212、E213。
  - E212：卷积恒等起步的 Llamba 里，拼词在记忆，卷积不起作用。两种解释未分开："起点"（卷积起步看不见邻位）与"模仿 / 继承"（蒸馏让记忆复制老师的注意力）。
  - E213：用来分开的 M1-3B 普通文本能力退化，桥接不过。
  - 这里换一个问题，同样能区分"起点"与"继承"哪一个占上风：卷积从一开始就能看邻位，而老师用来拼词的注意力层被原样保留时，拼词归谁？
- **模型：** `JunxiongWang/Llama3.2-Mamba-3B-distill`（不受限）。MambaInLlama 配方，与 M1 同代码，但只做通用对话蒸馏（约 2,000 万条样本），没有数学 RL。
  - 28 层，奇数层（1、3、…、27）是注意力层，从老师 Llama-3.2-3B-Instruct 继承；偶数层是 Mamba-1 式循环层，记忆由老师注意力权重初始化。
  - **卷积随机初始化**（PyTorch 默认），只作用在 x（V）上，宽 4。
  - 老师在第 1 层输出处已有 Δ = .57、第 2 层 .65（E213 的老师参照）。
- **问题（一句话）：** 在第 0 层是随机初始化卷积的循环层、第 1 层是继承来的注意力的蒸馏模型里，早期拼词由卷积承担，还是仍由注意力承担？

## 设置
- **运行：** E213 的纯 torch 实现（与 `jxiw/M1` 推理代码逐项对应，dt 偏置按原代码加两次），改为读取 `pytorch_model.bin`、按 `mamba_config.json` 的注意力层位置建模。
- **阳性对照：** 50 段 EWT 的 NLL ≤ 老师（3.13）+ 1.0，贪心续写正常。不过就排查实现，不解读。
- **条目：** E212 的 Llama-3 条目。
- **条件：**

  | 条件 | 做法 |
  |---|---|
  | `none` | 不干预 |
  | `mean` | 第 0、2 层循环层的卷积均值替代（E209 做法） |
  | `zero` | 同上，置零（只描述） |
  | `nomem` | 第 0、2 层记忆只剩当前 token |
  | `noattn` | 第 1 层注意力输出置零 |
  | `mean_noattn` | `mean` + `noattn` |

- **读数：** R1。读数层为第 2 层输出（第 0 层循环、第 1 层注意力、第 2 层循环之后）；另报第 0、1、4、8 层和全部层、NLL、卷积邻位抽头大小。

## 判据与决策表（跑之前写定）
- **桥接：** `none` 第 2 层 Δ ≥ .30。不过就只描述。
- **干净性：** 读数层下限 < 不干预的 .75 倍记"破坏表示"，不归类。
- "消失"：≤ .25 × `none`；"保留"：≥ .75 × `none`。

| 结果 | 条件 | 记录 |
|---|---|---|
| **卷积接手** | `mean` 消失、`noattn` 保留 | 卷积起步就能看邻位时，即使老师的注意力层原样保留，拼词也交给卷积："起点"占上风；E212 的结果更可能来自恒等起步 |
| **注意力保住（继承）** | `noattn` 消失、`mean` 保留 | 蒸馏时拼词留在继承来的注意力里：继承占上风；E212 的结果更可能来自模仿 |
| **冗余** | 两者都保留、`mean_noattn` 消失 | 两条路都能拼 |
| **两者都需要** | 两者都消失 | 描述 |
| **中间** | 其他 | 描述 |

- `nomem` 另记。
- **R5：** 跑完不改层号、阈值和条件；新加的分析一律标 POST-HOC。

## 混杂审计
- 这个模型的第 1 层就是注意力，卷积只有第 0 层一层能在注意力之前起作用；与 OLMo-Hybrid（前三层循环）的条件不同。
- 继承来的注意力在蒸馏中也被继续训练，"保留"不等于"未变"。
- 关掉第 1 层注意力可能破坏整体，用下限和 NLL 把关。
