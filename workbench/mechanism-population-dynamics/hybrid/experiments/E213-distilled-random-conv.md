# E213：卷积随机初始化的蒸馏混合模型里，谁来拼词——分开 E212 的"起点"与"模仿"两种解释（M1-3B，2026-11-24）

- **状态：** PLANNED（约 08:45 写定，在下载和任何运行之前）
- **类型：** PILOT（因果，只推理；不推进主张等级）
- **对应：** E212。Llamba-1B（卷积恒等初始化、MOHAWK 蒸馏）里拼词由记忆承担，卷积不起作用；自然预训练的带卷积模型正好相反。E212 留下两种解释：
  - **起点：** 卷积起步看不见邻位，拼词就落到了记忆。
  - **模仿：** 蒸馏让记忆复制老师早期层的注意力（MOHAWK 的矩阵对齐），而老师用注意力拼词。
- **M1-3B 为什么能分开两者**（togethercomputer/M1-3B，2504.10449，MambaInLlama 配方；代码 `jxiw/M1` 的 `mamba/hybrid_mamba_layer.py`）：
  - 由 Llama-3.2-3B-Instruct 改造；28 层中第 3、8、13、18、23、27 层是注意力，**第 0–2 层是循环层**。
  - 循环层是 Mamba-1 式选择性扫描，记忆部分由老师注意力权重初始化（x←V、B←K、C←Q），之后用蒸馏、SFT、RL 训练，没有逐层的矩阵对齐。
  - **卷积随机初始化**（PyTorch 默认），只作用在 x（V）上，宽 4，从一开始就能看邻位。子代理预览权重：各抽头平均 |w| 约 .11–.17，没有恒等结构。
- **问题（一句话）：** 卷积从一开始就能看邻位、记忆由老师注意力初始化的蒸馏模型里，早期拼词靠卷积还是记忆？

## 设置
- **模型：** `togethercomputer/M1-3B`（不受限，safetensors，bf16）。老师参照：`unsloth/Llama-3.2-3B-Instruct`（不受限的公开镜像），只做不干预。
- **运行方式：** 自写纯 torch 前向，与 `jxiw/M1` 的推理代码逐项对应：
  - 循环层：in_proj 切成 z、x、B、C、dt；x 先按 GQA 复制再卷积（SiLU）；dt = dt_proj(dt)，按原代码再以 dt_proj.bias 作 delta_bias 加一次后 softplus；扫描按定义逐步精确计算；y·silu(z) 后 out_proj。
  - 注意力层：qkv 打包、GQA（24 / 8 头）、非交错 RoPE（base 500000，与 M1 代码相同，不用 llama3 缩放）、因果 softmax。
  - 阳性对照：50 段 EWT 的 NLL ≤ 老师 + 1.0，贪心续写正常。不过就排查实现，不解读。
- **条目：** E212 的 Llama-3 条目（同一分词器）。
- **条件**（只作用于第 0–2 层）：`none`、`zero`（卷积邻位抽头置零）、`mean`（均值替代）、`nomem`（状态只剩当前 token：h_t = Δ_t B_t x_t）。
- **读数：** R1；读数层第 2 层（第一个注意力层之前），另报第 3、8 层和全部层、NLL、卷积邻位抽头大小。

## 判据与决策表（跑之前写定；与 E212 相同）
- **桥接：** `none` 第 2 层 Δ ≥ .30。不过就只描述（若第 3 层以后才拼，说明这个蒸馏模型把拼词交给了第一个注意力层，单独记录）。
- **干净性：** 读数层下限 < 不干预的 .75 倍记"破坏表示"，不归类；卷积项以 `mean` 为准。
- "消失"：≤ .25 × `none`；"保留"：≥ .75 × `none`。

| 结果 | 条件 | 记录 |
|---|---|---|
| **卷积承担** | 卷积消失、`nomem` 保留 | 卷积起步就能看邻位时，即使记忆由老师注意力初始化，拼词仍交给卷积：支持"起点"解释 |
| **记忆承担** | `nomem` 消失、卷积保留 | 卷积起步就能看邻位，拼词仍在记忆：蒸馏把老师的注意力式拼词继承到记忆里，支持"模仿/继承"解释 |
| **两者都需要** | 两者都消失 | 描述 |
| **中间** | 其他 | 描述 |

- **R5：** 跑完不改层号、阈值和条件；新加的分析一律标 POST-HOC。

## 混杂审计
- M1 与 Llamba 不只差卷积初始化：记忆类型（Mamba-1 与 Discrete-Mamba-2）、卷积作用的通道（只有 x 与 xBC 全部）、蒸馏方法、数据（M1 偏数学推理）都不同。结论只按决策表记，不把差别全归于卷积初始化。
- 原代码中 dt_proj 的偏置实际加了两次（线性层自带一次，delta_bias 再一次），按原代码复现。
