# E195：循环层按顺序拼词、注意力层先当"一袋部件"——在 Granite 一对和纯 Mamba 上是否复现（2026-11-23）

- **状态：** PLANNED（04:25 写定；E194 的 R1 和 R3 已看过，R2 还没看完，本卡的判据据此事先写死）
- **类型：** PILOT（只推理；不推进主张等级）
- **对应：** E194 中预先登记的读数"绑定分数"出现了与文献预期相反的差异：

  | 层 | OLMo-Hybrid（GDN 循环层） | OLMo-3（注意力） |

- **问题（一句话）：** 在另一对同配方、只换序列混合器的模型（Granite-4.0-H-Micro 对 Granite-4.0-Micro），以及完全没有注意力的 Falcon-Mamba-7B 上，是否同样出现"循环层早期就按顺序拼词，注意力层早期把各片当成无序的一袋"？

## 主读数与判据（看到任何 Granite 或 Falcon 数字之前写定）
- **主读数：** 第 1 层和第 2 层（解码层号，从 0 起）的绑定分数。对 m = 3、4、5、6 取平均，按词型自助 1,000 次取 95% 区间。

## 混杂审计
- **GH 对 GT：** 同配方、同分词器。宽度不同（2048 对 2560），GH 的注意力是 NoPE、GT 是 RoPE；第 0–4 层 GH 没有注意力，所以位置编码不影响主读数所在的层。
- **数据：** IBM 只说两者用同一配方训练，细节未核对，属未控制。
- **FM：** 没有同配方的注意力对照，只用来检验"完全没有注意力时早期也按顺序拼"，不和 GT 直接比。
- **随机初始化参照：** 是我们自己的初始化，不是官方 step0。HF 默认初始化与原训练的初始化可能不同，只作机会水平线。
