## 设置
- **模型**（bf16，只推理；路径记 revision 和权重 oid，11-23 查 HF API 核对）：

  | 键 | 仓库 @ revision | 说明 |
  |---|---|---|
  | `H` | allenai/Olmo-Hybrid-7B @ `stage1-step1414078`（safetensors oid 95faa17fb9…） | 32 层，lllA × 8（l = GDN，带宽 4 的因果短卷积），第一个全注意力层在第 3 层；预训练结束；RoPE θ=5e5，无缩放 |
  | `H0` | 同仓库 @ `stage1-step0`（950ef90b02…） | 同结构，未训练 |
  | `T` | allenai/Olmo-3-1025-7B @ `stage1-step1413814`（f256015ffb…） | 32 层，sssA × 8（s = 滑窗 4096）；预训练结束，与 H 的步数只差 264；RoPE θ=5e5，无 YaRN |
  | `T0` | 同仓库 @ `stage1-step0`（155b65d2b7…） | 同结构，未训练 |

  - **为什么不用发布版 main：** 两者位置编码不同（OLMo-Hybrid 的 main 去掉了 RoPE；OLMo-3 的 main 用 YaRN），而拼词深度已知受位置编码影响（Busigin & Pinter 2606.08562）。
  - **分词器：** 两个仓库的 `tokenizer.json`、`tokenizer_config.json` 的 git oid 完全相同（11-23 核对）。
  - **输入长度：** 本卡所有输入都不超过 512 个 token，所以 T 的滑窗层与全注意力层完全等价。也就是说，T 的每一层都在做注意力，H 的前三层没有注意力。
- **语料：** `division/results/e167/passages.json`（UD English EWT，856 段，有金标词边界）。目标词以本段中它之前的全部文字作为上下文，最多截取 100 个 token，写法同 Kaplan 等 ICLR 2025。
- **集合 S（人为拆分，用来固定词身份）：**
  - 选词：分词器里是单个 token 的词（带前导空格），纯字母，长度 ≥ 6 个字符。
  - 每个词按 m ∈ {2, 3, 4, 5, 6} 随机选切点（种子 194），要求每一片都恰好是分词器里的一个 token，首片带前导空格；切不出的 (词, m) 格子丢弃。
  - 每个词型最多取 2 次出现，总数最多 600 个词。
  - m = 1 就是原词本身。
  - 同一个词在各个 m 下词频、词义、词类完全相同，所以不需要跨词做词频匹配。
- **集合 N（自然的多 token 词）：** EWT 里纯字母、在上下文中被切成 m ∈ {2, 3, 4+} 个 token、且最后一个 token 恰好在词尾结束的词（锚点规则同 `capture_routing.py`）。每层最多 600 个；少于 150 个的层级只描述，不进决策。
- **对照输入**（都直接喂 token id）：
  - **前缀打乱（S，m ≥ 3）：** 最后一片不动，前面各片随机重排（排除原顺序）。如果表示只是部件袋，打乱后照样能认出原词。
  - **只剩最后一片（S、N）：** 上下文 + 最后一片。用来衡量只凭最后一片表层能认出多少。
  - **假词（N）：** 前缀片换成其他同 m 词在同位置的片，做法同 Kaplan 的按位置打乱。
- **运行环境：**
  - H 用 transformers 5.12（只有它实现了 `olmo_hybrid`；走 openslime 环境 + 链接 vendored tf5.12 的配方）；
  - T 用 transformers 4.57.6；
  - 模型放在空闲卡所在节点的本地 `/tmp`，不从 NFS 读权重。

## 读数（都与被测变量解耦：读数只在每层的残差流上计算，不按层类型选窗）
- **R1（主读数，S）：拆分词能否被认作原词。**
  - 第 l 层（含嵌入层输出）取拆分词最后一片的隐状态和同一上下文里原词 token 的隐状态。两者各减去该层在全部 S 原词位置上的均值。
  - 检索：在全部 S 条目的原词表示中，余弦最近的是否正是它自己的原词。报告 top-1 准确率，机会水平为 1/条目数。
  - 用排名而不用余弦大小，是为了避开两种架构各向异性不同的问题（2609.08692）。不经过嵌入矩阵或 logit lens，所以不涉及中间层与词表空间的校准问题。
  - 同样算出前缀打乱版和只剩最后一片版的准确率。
  - **绑定分数** = 准确率(拆分) − 准确率(前缀打乱)，只对 m ≥ 3 计算。
- **R2（S 与 N）：Patchscopes 复述。**
  - 把第 l 层最后一片的隐状态补丁到同一模型的提示 `Repeat this word twice: 1) X 2)` 里占位 token " X" 的同一层位置，贪心生成至多 m + 3 个 token。"2)" 之后的文字以原词开头（不分大小写）就算成功。
  - 层 l ∈ {0–8, 12, 16, 20, 24, 28}；每个 (集合, m) 层级最多 300 个条目。
  - 只在 H 和 T 上做（未训练模型不会复述）。
  - 随机参照：补丁换成另一个随机条目的隐状态，计算生成本条目原词的比例。
- **R3（N）：真词/假词可分性。** 最后一个 token 的隐状态先中心化，再用余弦 kNN（k = 4）、5 折交叉验证区分真词和假词，机会水平 .5。m ≥ 3 时另报倒数第二个 token 的结果作对照，做法同 Kaplan。
- **起点层 L\*：** 每个 (模型, 读数, 集合, m) 取满足以下两条的第一层：
  - 读数的 95% 自助区间下界高于未训练模型（H0 / T0）同层区间的上界；R2 没有未训练模型，改为高于随机参照的上界。
  - 读数 ≥ 该曲线逐层最大值的 50%。
- **起点归类（决策只用这个）：** 对词型做 1,000 次自助重采样，得到 L\* 的分布。≥ 90% 的重采样 L\* ≤ 2 → 归为"早"；≥ 90% 的重采样 L\* ≥ 3 → 归为"等注意力"；其余归为"不定"。

## 噪声地板 + MIE
- 每条曲线都按词型做 1,000 次自助重采样取 95% 区间。
- 起点只按上面的"早 / 等注意力 / 不定"三类归类，不比较小数层号。
