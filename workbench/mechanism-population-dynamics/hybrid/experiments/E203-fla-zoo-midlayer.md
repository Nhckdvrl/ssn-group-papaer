# E203：同配方循环模型库，在中层（第 12 层）读拼词——没有卷积时，各种记忆会不会拼（2026-11-23）

- **状态：** PLANNED（卡内时刻按提交记录校正为近似值）（约 09:20 写定）
  - 写卡时已看过 E202 中 fla Transformer 的 R1：第 2 层没有拼词，到第 12 层才拼起（m = 2 为 .88，m = 4 为 .35）。只看了 m = 2 和 m = 4。
  - 没有看任何循环模型（DN、MB、GLA、GSA、HGRN、HGRN2、RET）的读数。
- **类型：** PILOT（只推理；不推进主张等级）
- **对应：** E202 的桥接失败。这组 1.3B / 100B 的模型拼词发生在中层，而不是前三层，所以 E202 的第 2 层读数不适用。问题不变，读数层改为中层。
- **问题（一句话）：** 同一份数据、同一配方下，五种不带短卷积的循环记忆（GLA、GSA、HGRN、HGRN2、RetNet）到中层能不能把词拼起来？带卷积的 DeltaNet、Mamba 在所有层关掉卷积后，还能不能拼？

## 设置
- **模型、条目、读数：** 与 E202 相同（修正后的 600 个条目；R1；同一上下文 32 个候选）。
- **读数层：** 24 层的模型取第 12 层；Mamba 共 48 层，取第 24 层。
- **Δ：** 读数层的拆分 R1（m = 2–5 平均）减去同层"只剩最后一片"的平均。
- **干预：** DN、MB 做 `noconv_all`，即所有层的短卷积只保留当前抽头。这是新增的两个运行；E202 里"只关第 0–2 层（Mamba 为 0–5 层）"的运行照常记录。
- **基准：** TF 的 Δ，记为 Δ_TF。

## 判据与决策表（跑之前写定）
- **桥接：** Δ_TF ≥ .20。不过就不解读其余。

| 问题 | 结果 | 条件 | 记录 |
|---|---|---|---|
| 问 1：五个无卷积模型 | **多种记忆都会拼** | 至少 4 个模型的 Δ ≥ .5 × Δ_TF | "没有卷积时由记忆来拼"不限于某一种记忆，E199 的混杂基本解除 |
| | **都不会拼** | 至少 4 个模型的 Δ ≤ .15 × Δ_TF | 在这个规模上，多数记忆拼不了词。"谁来拼"的说法收窄为：有卷积靠卷积，没卷积时只有部分记忆（如 Ring 的线性注意力）能拼 |
| | **中间** | 其他 | 按记忆类型逐个描述 |
| 问 2：DN、MB | **卷积必要** | `noconv_all` 后 Δ ≤ .25 × 各自不干预时的 Δ | 同配方下复现 |
| | **记忆补位** | `noconv_all` 后 Δ ≥ .75 × 不干预 | 训练时带卷积的模型，记忆也会拼词 |
| | **中间** | 其他 | 描述 |

- **R5：** 跑完不改读数层、阈值；新加的分析一律标 POST-HOC。

## 混杂审计
- 同 E202：数据、配方、规模、分词器一致；"同一种记忆有没有卷积"仍未控制。
- 中层的拼词可能夹杂上下文整合，R1 的同上下文候选控制了共享的上下文方向。
- 只关某些层与关所有层的卷积，对模型的扰动大小不同，所以另报 NLL。

## 算力
- 新增 2 个运行，每个约 5–10 分钟。合计 < 1 GPU 小时。

## 结果（2026-11-23 约 09:45 填写；上面的内容未改）
- **桥接通过：** Δ_TF = .28（第 12 层拆分 m = 2–5 平均 .50，下限 .22），≥ .20。
- **问 1：判"多种记忆都会拼"。**
  - 四个有效的无卷积模型的 Δ 都 ≥ .5 × Δ_TF（.14）：GLA .49，GSA .54，HGRN .34，RET .47。
  - HGRN2 加载检查不过（NLL 6.01），已排除；有效的 4 个全部达标，满足"至少 4 个"。
- **问 2：判"卷积必要"。**
  - DN 不干预时 Δ = .51；所有层关卷积后为 −.00（NLL 6.90），只关前三层也是 −.00（NLL 5.14）。
  - 它的 delta 规则记忆完好，却完全不拼词，后面的层也不补拼。
  - MB 加载检查不过，排除。
- **第 12 层的拆分 R1（m = 2–6）：**

  | 模型 | 拆分 R1 | 绑定分数 |
  |---|---|---|
  | TF | .88 / .62 / .35 / .17 / .10 | +.09 |
  | DN | .95 / .78 / .63 / .49 / .42 | +.27 |
  | GLA | .97 / .85 / .69 / .51 / .42 | +.18 |
  | GSA | .97 / .83 / .66 / .51 / .39 | +.25 |
  | HGRN | .92 / .66 / .46 / .30 / .24 | +.11 |
  | RET | .94 / .79 / .65 / .46 / .38 | +.09 |
  | DN 所有层关卷积 | .47 / .26 / .13 / .08 / .06 | 0（下限 .24） |

- **解读（按决策表）：** 同一份数据、同一配方下，训练时没有卷积的四种循环记忆都学会了拼词，在这个规模上不比 Transformer 差；训练时有卷积的 DeltaNet 把拼词完全交给卷积，记忆不承担。E199 中"有没有卷积"与"记忆类型"的混杂基本解除。
- **剩下的限制：**
  - 带卷积的有效模型只有 DeltaNet 一个；Mamba 因加载失败缺席。
  - 仍没有"同一种记忆 ± 卷积"的直接对比。
  - 这组模型拼词发生在中层，不是前三层，与 7B 模型不同，可能是规模和数据量所致。
  - 曲线（POST-HOC 描述）：GSA 从第 0 层就开始拼，HGRN 次之，GLA、RET、TF 在第 6–10 层才起；DN 起得早。
