# E212：卷积按恒等初始化、从 Transformer 蒸馏来的循环模型里，谁来拼词（Llamba-1B，2026-11-24）

- **状态：** PLANNED（约 08:00 写定，在下载和任何运行之前）
- **类型：** PILOT（因果，只推理；不推进主张等级）
- **为什么做（后果检验，不是补洞）：**
  - 顶会证据门槛的第 6 条是"后果"。我们目前只有一个相关性（E200）。更有力的做法是：用"拼词由最早的局部部件承担"去预测一个别人发表、我们没参与的现象，再直接检验。
  - Bandarkar 2609.35378 把 Transformer 蒸馏成混合模型时，短卷积按恒等初始化（只看当前位置，等于我们的"关卷积"状态），结果"第一层放全注意力"的排法胜出。他们的模型没有公开权重。
  - 公开的同类模型：Llamba（Cartesia，2502.14458）由 Llama-3.2-1B-Instruct 用 MOHAWK 蒸馏而来。全部 16 层都是 Discrete-Mamba-2，没有注意力，卷积宽 4，按恒等初始化（论文原文）。子代理用 HTTP 分段读取预览过权重：训练后卷积仍约九成是恒等，第 0 层邻位抽头平均 |w| 为 .02–.07，当前抽头 .72。
  - 这是一个天然实验：卷积起步时"看不见邻位"，只能在蒸馏中自己学出来；记忆一开始就能看到前文。
- **问题（一句话）：** 卷积从恒等起步的蒸馏循环模型里，早期拼词靠的是卷积学到的那一点邻位权重，还是循环记忆？

## 设置
- **模型：** `cartesia-ai/Llamba-1B`（不受限，safetensors，fp32）。老师 Llama-3.2-1B-Instruct 用不受限的公开镜像 `unsloth/Llama-3.2-1B-Instruct`，只做不干预的参照。
- **运行方式：** Cartesia 官方代码 `cartesia-pytorch`，把 mamba_ssm 的分块扫描核换成纯 torch 的等价实现（按定义 h_t = exp(−Δ_t) h_{t−1} + Δ_t B_t x̃_t，y_t = C_t·h_t，用二次型精确计算）。阳性对照：50 段 EWT 的 NLL 应与老师在同一量级（≤ 老师 + 1.0）。
- **条目：** E194 规则，用 Llama-3 分词器重建，文档开头放 `<|begin_of_text|>`。
- **条件**（只作用于第 0–2 层）：

  | 条件 | 做法 |
  |---|---|
  | `none` | 不干预 |
  | `zero` | 卷积邻位抽头置零 |
  | `mean` | E209 的均值替代：邻位抽头置零，偏置加上 Σ w_j·μ |
  | `nomem` | 记忆只剩当前 token：h_t = Δ_t B_t x̃_t |

- **读数：** E194 的 R1；Δ = 拆分（m = 2–5 平均）− 只剩最后一片。读数层第 2 层，另报第 8 层（能否追回）和全部层；另报 NLL；另报第 0–2 层卷积邻位抽头的大小。

## 判据与决策表（跑之前写定）
- **桥接：** Llamba `none` 在第 0–7 层内 Δ 的最大值 ≥ .30（会拼）。不过就只描述。若第 2 层 Δ < .30 而更深的第 L 层（≤ 7）先到 .30，读数层改为该层，干预仍只作用于第 0–2 层。
- **干净性：** 某条件读数层"只剩最后一片"的下限 < 不干预的 .75 倍，就记"该干预破坏表示"，不归类。卷积项以 `mean` 为准；`zero` 不干净时只描述。
- "消失"：读数层 Δ ≤ .25 × `none`；"保留"：≥ .75 × `none`。

| 结果 | 条件 | 记录 |
|---|---|---|
| **卷积仍然承担** | 卷积消失、`nomem` 保留 | 恒等起步的卷积在蒸馏中学到的少量邻位权重就足以独揽拼词：局部部件即使起点不利也会接手；用"恒等卷积拼不了词"解释 Bandarkar 结果的力度减弱 |
| **记忆接手** | `nomem` 消失、卷积保留 | 卷积起步看不见邻位时，拼词转给了记忆：分工取决于学习开始时各部件能做什么；为 Bandarkar 结果提供直接的机制解释（恒等卷积 → 拼词落到别处） |
| **两者都需要** | 两者都消失 | 描述 |
| **中间** | 其他 | 描述 |

## 混杂审计
- 只有一个蒸馏模型、一种蒸馏方法（MOHAWK），而且没有注意力。它只能回答"卷积还是记忆"，回答不了"注意力是否接手"。Hybrid-Phi-Mamba（第 0–3 层循环、第 4 层起有注意力）需要另装代码，暂不做。
- 纯 torch 的扫描实现与官方 triton 核可能有数值差异；用 NLL 阳性对照把关。
- 均值替代的 μ 用 EWT 第 50–149 段统计，与 E209 相同。

## 结果（2026-11-24 约 08:45 填写；上面的内容未改）
- **实现阳性对照通过：** 自写的纯 torch Llamba 不干预时 NLL 3.36，老师 3.33；贪心续写正常。

  - 与自然预训练的带卷积模型正好相反：那里卷积必需、记忆不必需（E196、E198、E203、E209）。这里卷积学到的少量邻位权重不起作用，拼词由记忆承担，速度与老师相当。
- **必须说明的混杂（运行后读 MOHAWK 原文时注意到，POST-HOC）：** MOHAWK 的第一阶段"矩阵对齐"直接把循环层的混合矩阵训练成老师的注意力矩阵。所以"记忆承担拼词"有两种解释，本卡分不开：
  - **起点解释：** 卷积起步看不见邻位，拼词就落到记忆。
  - **模仿解释：** 记忆被训练成复制老师早期层的注意力，而老师用注意力拼词。
- **下一步：** 用卷积随机初始化、但循环层同样由老师注意力权重初始化的蒸馏模型（M1-3B，MambaInLlama 配方，第 0–2 层为循环层），分开两种解释，见 E213。
