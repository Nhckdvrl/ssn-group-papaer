# E207：复述补丁与 R1 为什么不一致——拼好的词表示是否与上下文缠在一起（OLMo-Hybrid 对 OLMo-3，2026-11-23）

- **状态：** PLANNED（约 11:00 写定，在任何 E207 运行之前）
- **类型：** PILOT（只推理；诊断读数，不推进主张等级）
- **对应：** E194 的未解分歧。
  - 第 2 层的 R1（同一上下文中的 32 个候选）：H 的拆分词（m = 2）为 .92，T 为 .93。
  - 复述补丁 R2（把向量移到 "Repeat this word twice: 1) X 2)" 里读出）：H .41，T .68；而单 token 原词的 R2 两者相近（.84 / .88）。
- **假设：** H 早期拼出的词表示与所在上下文缠在一起。同上下文比较（R1）看不出来，移到新句子（R2）就读不出。
- **问题（一句话）：** 把拆分词在原句中的表示，与原词在一个中性句子里的表示相比，H 是否比 T 更难认回原词？

## 设置
- **模型：** E194 的 H、T（预训练结束的检查点）。
- **条目：** E194 的 S 集（600 个词，同样的 31 个干扰词）。
- **中性上下文：** 每个候选词放进同一个中性前缀 "This word is:"（加 EOS 开头），取该词 token 在各层的表示。
- **读数 R1x（跨上下文）：**
  - 查询：拆分词最后一片在原句中的表示，m = 2–6。
  - 候选：原词和 31 个干扰词在中性前缀里的表示，按候选均值中心化。
  - 报告 top-1 认回率，机会水平 1/32。
  - 另报"只剩最后一片"的跨上下文认回率，作下限。
- **对照：** 原词本身（m = 1，原句中的原词 token）对中性句中的原词——跨上下文的上限。

## 判据与决策表（跑之前写定）
- 第 2 层，m = 2–5 平均，记 X(H)、X(T)；同层 m = 1 的上限记 U(H)、U(T)。归一化值 Xn = (X − 下限) / (U − 下限)。

| 结果 | 条件 | 记录 |
|---|---|---|
| **H 更缠** | Xn(H) ≤ Xn(T) − .20 | H 早期拼出的词表示更依赖上下文，可以解释 R2 低 |
| **两者相近** | \|Xn(H) − Xn(T)\| < .10 | 分歧不在表示本身，而在"移植后下游怎么读"，转去检查补丁读出的过程 |
| **中间** | 其他 | 描述 |

- 另报第 0–12 层的走势。
- **R5：** 跑完不改前缀、层号和阈值；新加的分析一律标 POST-HOC。

## 结果（2026-11-24 约 01:00 填写；上面的内容未改）
- **层号约定：** 与 E194 相同，"第 k 层"指第 k 个块（从 0 数）的输出。
- **跨上下文认回率**（m = 2–5 平均，X；只剩最后一片，F；原词上限，U；Xn = (X − F) / (U − F)）：

  | 层 | H：X / F / U | H：Xn | T：X / F / U | T：Xn |
  |---|---|---|---|---|
  | 0 | .14 / .09 / 1.00 | .05 | .20 / .18 / 1.00 | .02 |
  | 1 | .49 / .16 / 1.00 | .40 | .27 / .20 / 1.00 | .09 |
  | **2** | .81 / .17 / 1.00 | **.77** | .59 / .21 / 1.00 | **.48** |
  | 3 | .92 / .23 / 1.00 | .90 | .84 / .25 / 1.00 | .78 |
  | 5 | .93 / .20 / 1.00 | .91 | .94 / .26 / .98 | .95 |
  | 7 | .96 / .21 / .99 | .97 | .95 / .27 / .96 | .98 |
  | 11 | .56 / .11 / .66 | .83 | .81 / .15 / .79 | 1.03 |

- **按决策表判"中间"**：第 2 层 Xn(H) = .77，Xn(T) = .48，差 +.29。方向与假设相反——H 早期拼出的词表示**更容易**在新上下文里认回，不是更缠。到第 5 层两者都在 .9 以上。
- **对 E194 分歧的含义：** "H 的拼词表示与上下文缠在一起"这个解释不成立。R2（复述补丁）里 H 低，原因应在补丁读出的过程本身（例如移植后下游层怎么处理这个向量），而不在表示。读出过程尚未检验。
- **另见：** 第 11 层 H 的原词上限只有 .66（T .79），即中层以后 H 的同一个词在两个上下文里的表示分得更开；这是描述，不归类。
