# 找题工作页（2026-11-25 起；目标：锁定一个题目，拿去 zemi 听导师反馈）

这一页只做一件事：把候选题放在一起，按导师的一般标准逐条打分，写清每个判断的证据。实验只为立题服务，不为凑论文的实验量。文献卡在 [library 索引](../../library/themes/interpretability-representation/README.md)，实验卡在 [experiments/](experiments/)。

## 标准

**导师的一般标准（与题目无关，必须满足）：**
- G1 关键概念不取决于我们自己的定义或阈值。
- G2 实验真正回答所问的问题。
- G3 每一种可能的结果都能回答问题。
- G4 结果不能用常识猜到（「それはそうだろう」）。
- G5 不是由训练细节决定的程度问题。
- G6 不硬拆互相决定的两部分。
- G7 真正值得好奇。
- G8 单个数字不是结果：要有参照点和沿某条轴的对比，一句话讲得清。

**他的偏好（参考，违背要说得出理由）：**
- 数字是某个变量的函数（这类模型高、那类低）。
- 观察胜于干预。
- 至少两把尺子。
- 先行工作要讲诚实。
- 每个实验在硕士周期内落得了地（单个实验 < 20 GPU 小时）。

**用户的边界：**
- 不做需要深语言学背景的题。
- 不自训。
- 不在讨论前锁题。

## 为什么前八周都不达标：三层框架

“独立训练的模型会不会形成同样的机制”可以在三层上问：

| 层 | 跨独立训练是否相同 | 为什么做不成好题 / 为什么能 |
|---|---|---|
| 1. 部件身份（第几号头、第几号专家） | 不相同（我们的头线与 MoE 线；Chughtai 2023） | 置换对称下必然不同，答不出“所以呢” |
| 2. 表征与几何（编码什么、形状） | 大多相同，而且能从数据统计推出（Fu 2026；Karkada ICML 2026；Wang 2024 Pythia vs Mamba 特征相关 .74、同架构种子上限 .76） | 相同可以猜到（G4）；按形状或曲率划界要阈值（G1、G5） |
| 3. 算法（怎么算） | 可以不同（Clock vs Pizza：嵌入都是圆，算法不同；Feucht 2026：Llama 用十进制加法而不是“圆”） | 判定靠文献给出的反事实签名，不靠阈值；相同与不同都有信息量 |

所以题目应当落在第 3 层：对同一个任务，看独立训练、记忆机制不同的模型，是否走到同一个算法。

### 架构轴（候选 X 与 T1）的可行性判断：停（11-25）

E224–E227 四次试测都撞上同一堵墙：现有公开的纯循环模型（≤ 7B：Falcon-Mamba-7B、RWKV-7 2.9B / 1.5B；同数据的 fla-hub 1.3B 更弱）在稍复杂一点的上下文绑定任务上能力不够，任何要比较“算法”的读数都先被能力差混掉。
- 同数据 1.3B 三模型（Transformer 也一样）在静态绑定上就接近随机（E224）。
- 覆写：Falcon-Mamba 单次覆写 0.63–0.70（E224）。
- 问原值：三个循环模型在什么都没变时也只有 0.73–0.88，换 4 种问法也一样（E225、E226）。
- 6 组绑定：问物 0.85–0.88，问人 0.35–0.66（E227）。
- 同期两个注意力模型（Qwen3-8B、OLMo-3-7B）在所有这些读数上都是 0.99–1.00。

这不是某个读数修一修能过的问题，而是“拿现有循环模型比算法”这件事本身的前提不成立。按止损规则停在这里，不再为它加实验。留下的有用东西：
- 注意力模型“留着旧绑定”的签名在两个家族上复现（Chattaraj 的结论）。
- 事后观察：RWKV-7 被问原位置时 74% 答成新位置（E225）。没有位置编码的 Mamba 在过渡层也带有“第几组”的信号（E227）。
- 这两点只能作为将来更强循环模型出现时的重开条件。

### 候选 X（已停，见上）：读到“世界变了”时，模型是立即更新还是被问时才解析？这取决于记忆机制吗？

**一句话：** 上下文里说“某物换了位置 / 某变量被改了”时，模型是马上改写内部记录（立即求值），还是保留旧记录、等被问到才把变更算进去（惰性求值）？能回看全文的 Transformer 和必须把一切塞进固定大小状态的循环模型，会不会走到同一种做法？

**已知（全部来自全文精读的卡）：**
- Transformer 是惰性的，有三篇独立证据：Oh & Demberg 2606.08644（被问时局部重绑定，补丁位置预测清楚）；Tang ICML 2026（全局状态探针 < .3，局部约 .9，不增量建状态）；Dokme & Heck 2609.33883（对话里新旧值都留着，追加—选择—部署）。行为上，Transformer 答“原来是什么”比答“现在是什么”容易（Chattaraj 2603.00270，39 个模型全部如此），覆写越多越容易答成旧值（Wang & Sun 2025；Guo 2609.38866）。
- 循环模型一侧没人测过“更新策略”。最近的是 Yarden 2610.19709（Mamba-2 按当前 token 的局部线索决定写什么，只测检索）和 StateBench 2611.03094（理论上单层 delta 规则就能实现覆写；预训练只测了 OLMo 的 Transformer 和混合模型，只报准确率）。
- 混合模型的精确取值走注意力 KV，所以要用纯循环模型，不用混合模型。

**按标准打分：**

| 标准 | 判断 |
|---|---|
| G1 | 立即 / 惰性用文献已有的两种假说和它们的可区分预测来定义（Oh & Demberg 的补丁位置预测；“原值 vs 当前值”谁更容易的方向），不需要我们定阈值 |
| G2 | 行为上看不对称的方向随更新次数怎么变；机制上在“变更句末”与“提问处”两个位置做补丁，看效果落在被问对象还是全部对象 |
| G3 | 循环模型也惰性 → 不同记忆机制收敛到同一算法（意外）；循环模型立即求值 → 算法由记忆机制决定；加法衰减类（Mamba）与 delta 擦除类（RWKV-7）分成两种 → 更新规则决定算法。唯一没信息的结果是“循环模型根本做不了”，由 E224 门槛排除 |
| G4 | 有风险：审稿人可能说“循环模型当然只能立即更新”。但这不是必然的：状态可以存“交换 S 和 R”这条操作本身，留到提问时再解析；玩具实验里 delta 型单元也会学会“不覆写”（Boesch 2609.16183）。所以要在至少两个更新规则族上看，结果事先确实不知道 |
| G5 | 主读数是不对称的**方向**（哪个更容易）和补丁效果落在**哪里**，不是幅度；每类架构至少两个家族，排除“只是某个模型的训练细节” |
| G6 | 不涉及分解 |
| G7 | 接上“LLM 有没有在维护世界状态”这场正在进行的争论 |
| G8 | 参照：多个 Transformer 家族（已知惰性）。对比轴：注意力 / 加法衰减循环 / delta 擦除循环 × 更新次数 |

**前提：** 循环模型真的会做单次覆写。这就是 E224。

### 候选 C（11-25 晚撤回）：上下文绑定的几种已发表机制，在独立训练的不同 LLM 家族之间成立吗？

**现状：撤回。** 用户 11-25 晚：“基本就是复现人家论文，没有自己的新问题”“为什么要比较两个模型是否一样，这个问题本身就有点强行”。判断同意：“A 与 B 在某层是否相同”在任何层都只会得到猜得到的答案或程度答案（前八周五条线的共同死因）；把已发表的检验跑在更多模型上是复现，不是问题。E228 结果（7 模型 21/21）保留为事实，不再作题目。

### 口味校准（11-25 晚，两路 Sonnet 调研：未解释的 LLM 行为现象 21 个；2024–2026 获奖分析类论文 40 篇）

获奖分析论文的共同形状：**领域里有一个普遍相信的说法，用一个便宜而干净的对照去检验它在现有模型上是否成立**（RLVR 是否给出 base 没有的推理能力——pass@k；“长度不影响推理”——同样本填充；“安全对齐改变整体行为”——只改前几个 token）。少有“X 占多少”的分解，也少有“两个模型是否一样”。对我们：先找到一个被普遍相信的说法，再找能一刀切开它的对照。

### 候选 D（11-25 晚，待与用户讨论）：LLM 看不见自己的错，这个毛病是后训练造成的，还是预训练就有？

**现象：** 同一个错误，放在用户消息里模型会纠正，放在模型自己的回答里就不纠正（Tsui, COLM 2026：14 个指令模型平均 64.5%；Chen 2606.05976：Agent 里 23–93 个百分点）。**领域现有说法：** 后训练造成——SFT 数据里几乎没有自我纠错序列，或指令微调对角色标签的处理（Tsui §5；Chen 结论）。两篇都只测了指令模型；Tsui 表里的 “base” 实为 Instruct。Essential AI 2504.04022 测了 OLMo-2 预训练 checkpoint 的反思，但没有“同一错误、只换归属”的对照。
**对手说法：** 预训练就有——人写的文本里，回复别人时常纠正别人，自己写的文字很少中途自我否定；base 模型学到的是“延续同一作者的文本”。
**一刀切开的对照：** 同一错误、同一内容，只换“同一说话人继续写”与“另一说话人来回复”，在 base 模型（纯文本对话格式）与 OLMo-2 的 base → SFT → DPO → RLVR 各阶段公开 checkpoint 上测；可加 OLMo 公开预训练语料里“纠正自己 / 纠正别人”的频数（infini-gram）。
**结果分叉：** base 已有同向不对称 → 现有说法错，毛病来自预训练文本；base 没有、某阶段出现 → 指出是哪一阶段造成；base 反而“谁都不纠正”（Perez 2022：预训练模型已有附和倾向）→ 纠错本身是后训练给的，盲点是给得不对称。
**撞车检查（11-25 晚，Sonnet 全面检索 + Semantic Scholar 引用表 + 自读 Ni、Khullar、Pan 等）：** 没有人在 base 模型或训练阶段上测过这个盲点，也没有人把“接着写 vs 新一轮”和“谁写的”交叉。但周边很热，两个月内连出多篇：
- 角色 / 位置 / 归属的拆分：Chen 2606.05976（只换角色）；Ni 2610.34809（旧答案标成自己的或引用别人的，效果相同）；Khullar 2603.04582（动作放在上一轮 assistant 里，监视器就放水；明说“是你写的”反而不放水）——后两篇的结论方向不一致，正是本候选要切的地方。
- 训练阶段追踪这一做法已被谄媚研究大量使用：Yao 2610.37788（OLMo-2 各阶段；附和 base 就有，被追问后改口是后训练带来的）；Huang 2610.26655（741 个 checkpoint，含 OLMo-3 Think / Instruct / RL-Zero）；Pan 2508.15815（用户—助手偏向：base 接近中性）。
- 风险：“同一套阶段追踪方法换一个现象”会被看成增量。本候选的独特处应放在第 1 问（base 有没有、是接着写还是归属），而不是阶段追踪本身。

**可行性：** OLMo-2-7B（base / SFT / DPO / Instruct）和 OLMo-3-7B（base；Instruct-SFT / DPO / 最终；Think-SFT / DPO / 最终；RL-Zero）都公开、免授权。Tsui 的数据公开（`kenhktsui/scli5`、`gsm8k_sc`、`prm800k_sc`）。

**E229 试测（11-25，OLMo-3-7B base / Instruct-SFT / Instruct，[卡](experiments/E229-self-correction-blind-spot-origin.md)）：**
- base 已有不对称：接着写 0.01–0.03，另一人回复 0.28–0.51（O − C 区间不含 0）。“后训练造成”的说法不完整。
- 最终 Instruct（chat）：错误留在自己上一轮、新开一轮时纠正率 0.86–0.94，与纠正用户（0.84–0.88）相同；只有接着写时低（0.26–0.51）。盲点主要是“接着写”，不是“自己的”。
- 接着写时能改口，只在 DPO / RLVR 之后的最终版出现；SFT 在 chat 里还会照抄用户给的错答案（附和）。
- 保留：S / O 可以“重答一遍”而不必指出错，C 必须当场推翻，读数分不开“看不见错”和“改口代价”；只测了一个家族。

**一句话：** “记住谁拿了什么，再按问题取出来”这件事，文献给出了好几种机制解释，每一种都只在 1–4 个模型上做过。我们用每篇论文自己的反事实检验，在十来个独立训练的家族上看，这些结论哪些普遍成立、哪些只属于某些模型，以及不成立时是什么模型属性在起作用。

涉及的结论：
- binding ID（Feng & Steinhardt ICLR 2024）
- 顺序 ID / 格子式绑定（Dai 2024、2604.19052）
- lookback（Prakash 2025）
- 位置 / 词汇 / 反射混合（Gur-Arieh ICLR 2026）
- 读出时重绑定（Oh & Demberg 2026）
- 不增量建状态（Tang ICML 2026）

**为什么接得上导师：** 11-05 第 12 条原话是“把现成的分析方法拿来，看它的分析结果在不同模型之间一致到什么程度”。这正是他“独立训练会不会形成同样机制”的问题落到第 3 层（算法）上的做法；比较的单位是“结论是否成立”，不是部件身份，也不是几何形状。

**可行性：** 7B 级 Transformer 在这类任务上都是 0.99–1.00（E224–E227 的 Qwen3-8B、OLMo-3-7B），不会再撞上架构轴那种能力墙。开放权重、不需要凭证的家族至少有 Qwen、OLMo、Falcon3、Phi、Granite、SmolLM、DeepSeek（另有 MoE 与 dense 的对照）。

| 标准 | 判断 |
|---|---|
| G1 | 每个结论用原论文自己的检验和判据，不用我们的定义 |
| G2 | 同一套检验跑在多个独立训练的家族上，直接回答“结论是否跨模型成立” |
| G3 | 全都成立 → 绑定的算法由任务决定，机制解释可以跨模型迁移；部分不成立 → 指出是哪些、和什么模型属性相关（注意力实现、位置编码、分词、MoE、规模、是否指令微调） |
| G4 | 事先不知道：已有零星迹象表明家族之间不同（Oh & Demberg 里 Gemma 与 Llama 的签名不同；另有工作发现 Qwen 能定位出清楚的头而 Llama / Gemma 不能），但没人系统看过 |
| G5 | 主读数是每个结论在每个模型上“成立 / 不成立”（按原论文判据），不是由训练超参决定的幅度 |
| G6 | 不涉及分解 |
| G7 | 机制解释能否跨模型推广，是可解释性公认的开放问题（Sharkey 2025） |
| G8 | 参照：原论文的模型（先复现）；对比轴：家族、规模、dense vs MoE、base vs instruct |

**撞车检查（11-25，Sonnet 检索 + 全文 / 部分阅读）：无撞车。** 没有人在多个独立家族上用各论文自己的反事实检验复现这些绑定机制，也没有人解释“不成立时由什么决定”。最近的邻居与它们给出的线索：
- Ravulapalli 2609.30634：30 个模型的绑定**容量**，分组跟着预训练配方走而不是跟着规模走；只看行为、没有机制。属于定位表里的 compression-risk 近邻。
- Sun & Toneva 2603.30002：同一个 IOI 解释在 Pythia 内部一致度 0.73–0.92，换到 GPT-2 只有 0.13。
- Shao…Belinkov 2604.24302（COLM 2026）：电路跨模型迁移只做了 Llama 与 Qwen，Qwen 上明显更差。
- 各绑定论文测过的模型：Feng（Pythia、LLaMA）；Prakash 2024（只有 Llama-7B 及其微调）；Gur-Arieh（Gemma-2、Qwen2.5、Llama-3.1 共 9 个，全是 instruct，称跨模型一致）；Oh & Demberg（Gemma、Llama 共 4 个，**报告了家族差异**：Gemma 由 query 主导，Llama 由 key 主导）；Tang（3 个）。全部是 Transformer。

**仍需注意：** “只是复现研究”的观感，需要“不成立时由什么决定”这一层解释来撑起贡献；Gemma、Llama 需要授权，复现原论文模型时只能用 Qwen2.5（Gur-Arieh、Prakash 用过）和 Pythia（Feng 用过）。

### 备选 Y：数字的切分方式会不会决定模型学到的算术算法？

已知整数加法在预训练模型里有多种机制（螺旋 / Fourier，Kantamneni 2025、Zhou 2024；十进制逐位，Feucht 2026），各家族的数字切分不同（逐位 vs 三位一组 vs 不规则 BPE），但还没有人跨模型比较“谁选了哪种算法”。风险：算术机制文献很挤，而且有“只是一袋启发式”（Nikankin ICLR 2025）的反驳，G1 不稳。只在 X 不可行时展开。
