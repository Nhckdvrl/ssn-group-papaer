# E82：因果承担者在训练的什么时候定下来？兄弟模型从哪一步开始分叉？（2026-10-10）

- **状态：** RUNNING
- **类型：** CLAIM（A10 叙事链第 6 步；接 E81）
- **对应：** E81（继续训练保留承担者；同初始化兄弟 Pythia-410M 标准 / 去重承担者完全不同：top-3 重合 0 / 3、迁移 0.09，而注意力角色对应 0.48）；E46 / E66 / E40（注意力角色在训练早期 1–2.5% 定型）；E73（Pythia-160M 兄弟最终保留承担者 0.85，410M 不保留）
- **问题（一句话）：** 在同一次训练里，IOI 的因果承担者从哪一步起不再变化？它比注意力角色定型得晚吗？同初始化的兄弟模型，承担者从哪一步开始分叉？
- **为什么问这个：** E81 显示承担者一旦定下就在继续训练中保持，但兄弟模型之间不同。如果承担者定型晚于注意力角色，就能解释“兄弟共享注意力坐标系、却由不同的头干活”：坐标系由初始化在很早的窗口里确定，而谁来干活在更晚、任务行为出现时由各自的数据决定。
- **设置：** Pythia-410M 与 Pythia-410M-deduped、Pythia-160M 与 Pythia-160M-deduped（每对同初始化、数据不同），step ∈ {512, 1000, 1500, 2000, 3000, 4000, 6000, 8000, 12000, 16000, 24000, 33000, 48000, 66000, 100000, 143000}。测量与 E81 完全相同（`scripts/e81_carriers.py`）。未缓存的检查点测完即删。
- **读数：**
  - 承担者定型点：最早的步数 t，使得之后所有检查点的 top-3 承担者（按 DLA）都与终点相同，且按终点 top-3 联合消融的可加迁移 ≥ 0.9。
  - 注意力角色定型点：最早的 t，使之后所有检查点的 induction 与 END→IO 注意力图与终点的层内对应 ≥ 0.9。
  - 兄弟分叉曲线：每个步数上标准版与去重版之间的注意力角色对应、单头消融对应（信度校正）、top-3 重合。
  - IOI 行为出现点：logit 差首次 > 1 的步数。
- **阳性对照：** 终点上与 E81 一致（410M 标准版 top-3 11.4 / 18.8 / 17.6）。
- **决策表（跑之前写）：**
  - 承担者定型点 ≥ 注意力角色定型点的 2 倍步数（两个尺寸都如此）→ 写“两个时间尺度”：坐标系早定，承担者在任务行为出现时才分配。
  - 两者定型点相差 < 2 倍 → 不写两个时间尺度；兄弟承担者的差异只能描述，不作此解释。
  - 160M 兄弟在承担者定型之前就已共享承担者、410M 兄弟在定型时分叉 → 作为尺寸差异的描述，不另加解释。
