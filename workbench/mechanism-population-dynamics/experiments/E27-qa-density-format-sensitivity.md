# E27 — Does a corpus's QA-format density set how much QA phrasing raises context reliance?（2026-10-03）

- **状态：** REGISTERED（判据提交于计算之前。假设来自 E26 前 3 个模型的描述性观察：格式效应 dolma1_7 +1.39 / +1.72，no_flan −0.33；E23 的配方 S3 值已算出并打印在日志中，但 S3 与任何格式效应的相关从未计算）

- **对应：** E23（S3 = 每千 token 行首 Question:/Answer:/Q:/A: 次数）、E26；Fouilhé et al. 2026（问法改变记忆偏好达 95 个百分点，未解释来源）；Pan et al. 2023（ICL 中的任务识别）；Goyal et al. ICLR 2025

- **问题（只回答这个）：** 在 25 个 DataDecide 配方中，语料的问答格式密度能否预测“问答格式结尾相对陈述结尾使采信增加多少”（格式效应）？

## 设置
- 模型：25 个配方的 default seed（step69369）；另外复用 E26 中 4 个配方的 3 seed（取 3 seed 平均代替 default，不重复计算）。
- 读数：E26 的 8 个单元（同一脚本、同一提示），在每个模型自己已知的条目上取各类别平均后再平均（各配方已知集合不同；稳健性：在 25 个模型共同已知的条目上重算）。
- 格式效应 FE = mean_ctx(qa − decl)；主读数用单句上下文 FE_c1 = c1_qa − c1_decl（与 Substitution 最接近、无篇幅混杂），FE（4 上下文平均）为辅。

## 判据（n = 25 配方）
- **主检验：** Spearman(log S3, FE_c1) ≥ 0.5 且置换 p < 0.05 → 语料问答格式密度设定问法敏感度。
- **特异性：** 同时 Spearman(log S3, 次数效应) 的绝对值 < 0.3（问答格式密度不应预测对重复次数的敏感度）；Spearman(S1, FE_c1) 报告（重复结构不应是主因）。
- **知识混杂：** 对配方 clean 边际均值的偏相关保持 ≥ 0.4。
- |ρ| < 0.2 → Flan 对照不能推广为“问答格式密度”的一般规律；如实报告，不追加统计量。
