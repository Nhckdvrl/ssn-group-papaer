# E48：因果的数据干预——改写 Flan 的模板，开关的触发词会不会随之迁移？（2026-10-03）

- **状态：** PLANNED
- **类型：** CLAIM（C04 从“天然实验 + 相关”走到“受控的数据内容干预”）
- **对应：** C04（E32：字面 “Question:” 触发、“Q:/A:”“Query:/Response:” 不触发；E47：开关在 60M / 90M 已存在）；A02 §2“C04 的因果数据干预”一行；对标 Chan et al. NeurIPS 2022（操纵数据性质）、Kim et al. ACL 2026（受控合成语料）、Goyal et al. ICLR 2025 Oral（受控指令数据过滤）
- **问题（一句话）：** 在无 Flan 的模型上继续预训练时，加入原版 Flan 会装入 “Question:” 开关；加入把 “Question:”→“Query:”、“Answer:”→“Response:” 改写后的 Flan，开关是否改由 “Query:” 触发、而不再由 “Question:” 触发？
- **设置：**
  - 起点：DataDecide dolma1_7-no-flan-{60M, 90M} 的最终步（E47 的步数），default / small-aux-2 / small-aux-3（3 个初始化）。
  - 数据：基础混合 = c4 50%、books 15%、papers 15%、code 20%（E46 的语料前缀）；**10% 的序列槽**按条件填入：orig = 原版 Flan；swap = 模板改写后的 Flan；none = 基础文本。Flan = Dolma 1.7 的 tulu_flan 源文件 part-48；orig 与 swap 经过同一条“解码 → (改写) → 重新分词”流程（`--prep`，标记计数写入 `flan_prep_stats.json`）。三个条件共用槽位分配与基础窗口的随机数流。
  - 训练：2 亿 token（seq 2048 × batch 32，约 3050 步），AdamW lr 3e-4（warmup 100、余弦降到 10%）、wd 0.1、bf16 autocast（`scripts/e48_cueswap.py --train`）。
  - 读数：在 0 / 2500 万 / 5000 万 / 1 亿 / 2 亿 token 处做 E32 的 7 个单元 + clean 知识；线索效应 = 单元 − decl；条目 = 该尺寸、该时刻 9 个模型共同已知的条目，类别等权。
- **读数（按初始化配对）：** Δ_cond(c) = 线索效应_cond(c) − 线索效应_none(c)，对 3 个初始化取均值，SE = 配对差的 SD / √3。
  - **P1（阳性对照）：** Δ_orig(QA) > 2·SE，即原版 Flan 在无 Flan 模型上重新装入开关。
  - **P2（触发词迁移）：** Δ_swap(novel) > 2·SE，即改写后的 Flan 装入由 “Query: … Response:” 触发的开关。
  - **P3（特异性，交叉）：** orig 中 [Δ(QA) − Δ(novel)] > 2·SE，且 swap 中 [Δ(novel) − Δ(QA)] > 2·SE。
- **阳性对照：** P1；训练损失正常下降；clean 知识在 none 条件下不崩（已知条目数下降 < 20%）。
- **噪声地板 + MIE：** 3 个初始化的配对差；判据 2·SE（df 2，偏松，因此同时要求 2 个尺寸方向一致）。
- **混杂审计：** 只有 Flan 槽位的内容不同（同一随机数流）；orig / swap 的文件长度略有不同，Flan 窗口的位置随之略有偏移（两边都是同一池子的随机样本，不是系统差异）；10% 的 Flan 比例高于 Dolma 的 1.3%，用来在 2 亿 token 内放大效应，写进范围；继续预训练的基础混合与原预训练不同，由 none 条件控制；读数与 E32 / E47 相同。
- **决策表（跑之前写）：**
  - P1、P2、P3 在两个尺寸上都成立 → C04 获得受控因果证据：**数据中的字面模板决定开关的触发词**；写成论文中“后天”一节的核心干预结果。
  - P1 成立、P2 不成立 → 原版模板能装入开关，但新标记不能（可能需要预训练中已有的 “Question:” 语义 / 频率基础），如实报告，并检查 swap 中 QA 是否也上升（若上升 → 学到的是“问答文体”而非字面线索，与 E32 部分矛盾）。
  - P1 不成立（2 亿 token 内原版 Flan 也装不进开关）→ 实验不可判定（剂量不足）；记录最早的上升趋势，考虑更多 token 或在 1B 上做，需另开卡。
  - 只在一个尺寸成立 → 如实报告。

- **判定（按决策表）：** P1 不成立 → **90M 上实验不可判定**（决策表的“剂量不足”一档）。**如实补充：** 不是“没有效应”，而是**显著的反向效应**——10% Flan 的继续预训练在 1 亿 token 内**降低**问答类线索下的上下文采信（−0.3 到 −0.9），且改写版在它自己的模板 “Query:” 上降得最多（−0.90 vs “Question:” −0.55，特异性 −0.35 ± 0.15）。
- **POST-HOC 解读（不进入主张）：** 模板在数据中确实以字面方式影响行为，但在低剂量继续预训练中的符号与 DataDecide 从头预训练中的开关相反；可能原因：Flan 的 “Question:” 样例约 80% 不需要段落（E53 v2 的粗略统计，该度量本身未通过阳性对照，仅作提示），少量暴露先教会“该模板下用记忆作答”。由 E48b（剂量约 9 倍）检验剂量依赖。
