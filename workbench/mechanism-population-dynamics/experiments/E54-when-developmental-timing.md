# E54：“何时”由谁决定？——受控训练中 induction 出现时刻的初始化 / 语料分解（2026-10-03）

- **状态：** DONE（2026-10-03；induction 出现时刻由语料决定，previous-token 出现时刻普适）
- **类型：** CLAIM（决定因素地图的“发育时间”层；territory 问题中的 developmental ordering / timing）
- **对应：** C05、C04（E29：开关出现时刻）；E37 / E40（锁定时间）；对标 Tigges NeurIPS 2024（成分出现的 token 数跨尺寸一致）、PolyPythias ICLR 2025（训练阶段跨 seed 一致）、Olsson 2022（induction 的相变）
- **问题（一句话）：** 在 6 个初始化 × 4 个语料的受控训练中，induction（以及 previous-token）出现的训练步数主要由语料决定，还是由初始化决定？
- **设置：**
  - 数据：E46 A 组（S 尺寸，`results/e46/S_i{1..6}_{c4,code,papers,books}_o{i}.json`），每个 run 在 13 个固定步数测 M1_max、M2_max、copy gain。
  - 出现时刻（预先固定的定义）：induction = copy gain 首次 ≥ 1.0 nat 的步数（在测量网格上线性插值）；previous-token = M2_max 首次 ≥ 0.5 的步数。从未达到者记为右删失（books 预计无 induction → 只用 previous-token，induction 分析排除 books）。
  - 分解：对 log(出现步数) 做初始化 × 语料的双因素无重复无偏方差分量（同 E35 / E51），F 检验。
- **读数：** 语料分量、初始化分量、残差分量的比例与 p 值；每个语料的出现步数中位数。
- **阳性对照：** 测量网格能分辨出现时刻：至少 80% 的 run 的出现时刻落在网格的第 2 个点之后、最后一个点之前（否则时刻被网格截断，不可判定）。
- **噪声地板 + MIE：** F 检验 p < 0.05，且分量占比 > 0.3 才算“决定”。
- **混杂审计：** 测量网格稀疏（13 个点）→ 插值误差对所有 run 相同；语料长度相同（各 4 亿 token 前缀）；order seed = init seed（与 DataDecide 相同），初始化分量包含顺序的贡献（E46 B 组单独估计顺序）。
- **决策表（跑之前写）：**
  - 语料分量显著且 > 0.3，初始化分量不显著 → 写成“何时由数据决定”（与“做什么”同侧），地图上补“发育时间”一层。
  - 初始化分量显著且 > 0.3 → “何时”也受初始化影响，如实写。
  - 两者都不显著 → 出现时刻在这个设置中是普适的（与 Tigges / PolyPythias 的“一致”结论相符）。

## 结果（`results/e46/e54_timing.json`；24 个 run；19:12）
- 阳性对照 ✓：全部出现时刻都落在测量网格内（可分辨比例 1.0，无右删失）。
- **induction（copy gain ≥ 1 nat；c4 / code / papers × 6 个初始化）：** log 步数的方差分量：**语料 0.81（p = 0.0001）**，初始化 0.00（p = 0.47），残差 0.19；中位出现步数 papers ≈ 1285、code ≈ 1607、c4 ≈ 1953。
- **previous-token（M2_max ≥ 0.5；4 个语料 × 6 个初始化）：** 语料 0.006（p = 0.40），初始化 0.067（p = 0.32），残差 0.93；中位约 370–440 步。
- **判定（按决策表）：** induction：语料分量显著且 > 0.3、初始化不显著 → **“何时”由数据决定**；previous-token：两者都不显著 → 出现时刻普适。
- **对决定因素地图的意义：** 加入“发育时间”一行：较复杂的回路（induction）何时出现由数据决定，与“做什么”同侧；最基础的 previous-token 头在时间上普适；两者的出现时刻都与初始化无关。
