- **类型：** PILOT（候选 X 的决定性试测；不推进主张；锁题由人决定，R2）
- **对应：** [TOPIC_SEARCH.md](../TOPIC_SEARCH.md) 候选 X。前置：[E224](E224-binding-overwrite-competence-gate.md)。最近的先行工作（卡已读）：Chattaraj 2603.00270（Transformer 答原值比答当前值容易，39/39 模型；只测 Transformer，没有“没被改的变量”对照）；Guo 2609.38866（Transformer 覆写错误几乎全是旧值）；Boesch 2609.16183（玩具 delta 型单元可以学会不覆写）；StateBench 2611.03094（只报准确率，没有原值查询）。

## 为什么做（给外人看的版本）

E224 里，同样会做静态绑定的三个模型，在“某人换了房间”之后分开了：注意力的 Qwen3-8B 和 delta 规则的 RWKV-7 都答对新位置，加法规则的 Falcon-Mamba 有三成答成旧位置。这有两种完全不同的解释：
- RWKV-7 把旧绑定**换掉**了（delta 规则按键擦除），Mamba 是**留着**旧绑定却挑不出新的；
- 或者三个模型都**留着**旧绑定，只是挑选新值的能力不同。

区分它们只需要问一句“这个人一开始在哪里”：留着旧绑定的模型答得出，换掉的答不出。而且，换掉应当只发生在被改的那个人身上，没被改的人一开始在哪里仍然答得出。这个读数不靠阈值、不做消融，结果的方向事先不知道。

## 设置

- **模型（3 个，E224 中叙述格式静态绑定都过门槛的全部大模型；本地已有，不新下载）：** `Qwen/Qwen3-8B-Base`（注意力，只追加）、`tiiuae/falcon-mamba-7b`（加法衰减循环）、`RWKV/RWKV7-Goose-World3-2.9B-HF`（delta 规则循环）。
- **格式：** 只用叙述格式（RWKV-7 在 E224 代码格式上连静态绑定都不过）。人名、地点各自不重复；三个人，各在一个房间。
- **示例（2 个，都没有任何变化事件，只示范两种问法的答题格式）：** 一个问 “Where is Yuri now?”，一个问 “Where was Omar at the beginning?”。
- **上下文：** 三条初始绑定 → 变化事件 → 一条无关新人的绑定（防止“最后一句就是答案”）。
  - N=1：目标人移动一次（`Then X went to the Z.`）。
  - N=2：目标人移动两次（旧 → 中 → 新）。
  - N=0（对照）：变化事件换成不改变位置的句子（`Then X waved.`）。
- **查询（每格 150 题，种子 225）：**
  - cur(T)：`Where is X now?`，正确 = 最新位置（N=0 时为初始位置）。
  - orig(T)：`Where was X at the beginning?`，正确 = 初始位置。
  - orig(O)：问一个**没被改**的人 `Where was Y at the beginning?`，正确 = Y 的位置。
  - 共 7 格：N∈{1,2} × {cur(T), orig(T), orig(O)}，加 N=0 的 orig(T)。
- **打分：** 与 E224 相同：对上下文里出现过的所有地点算完整续写的对数似然，取最大者；不出选项。另记错误类型：答成 初始 / 中间 / 最新 / 别人的地点。
- **命令：** `scripts/e225_keep_replace.py`。

## 读数与对照

- 主读数：orig(T | N≥1) 与两个参照的差：orig(T | N=0)（同一人、同样距离、没有变化）和 orig(O | 同一上下文)（同一上下文、没被改的人）。
- 第二把尺子：cur(T) 的错误类型（答成旧值的比例）。
- 阳性对照：Qwen3-8B 在 orig(T | N=0) 与 cur(T | N=1) 上应 ≥ 0.9；Chattaraj 的结果预测 Transformer 的 orig(T | N≥1) 也高。
- 噪声：n=150，95% 区间半宽 ≤ 0.08；差值用按题 bootstrap 的 95% 区间。

## 决策表（跑之前写）

判定用的“明显低于”= 差值 ≥ 0.15 且 bootstrap 95% 区间不含 0（试测用的启发式，写在这里，不事后改）。

先看前提：某模型 orig(T | N=0) < 0.9 → 它听不懂“一开始”这种问法，它的签名读不出，如实报告，不改措辞重跑（Qwen 也不过则是题目写法有问题，修好重跑）。

| 某模型的结果 | 签名 |
|---|---|
| orig(T \| N≥1) 明显低于两个参照，cur(T) 高 | **换掉**（按键擦除） |
| orig(T \| N≥1) 与 orig(O) 一起明显下降 | **全局衰减**（不是按键） |
| orig(T \| N≥1) 不明显低于参照 | **留着** |
| 留着，而且 cur(T) 的错误多为旧值 | **留着但挑不出新值** |

| 三个模型合起来 | 对题目的决定 |
|---|---|
| RWKV-7 为“换掉”，Qwen 与 Falcon-Mamba 为“留着” | 写入规则与“留 / 换”对上，第一次出现清楚的定性分化 → 下一步做家族重复（每类再加一个模型），作为 zemi 的证据；把候选 X 写成 zemi 提案 |
| 三个都“留着” | 写入规则不决定留还是换，差别只在挑选 → 候选 X 改写为“干扰下的挑选”，重新按 G1–G8 打分（尤其 G4），不直接加实验 |
| 出现其它组合（例如 Mamba “换掉”） | 如实报告，回到工作页重新评估 |

## 混杂审计（只列相关项）

- 写入规则与数据、规模、训练混在一起（每类只有一个模型）：未控制；本卡只看定性签名是否出现，不作类别结论，类别结论留给家族重复。
