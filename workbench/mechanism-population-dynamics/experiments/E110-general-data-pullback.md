# E110：为什么一般训练会撤回读取侧的遗忘、却不撤回写出侧的遗忘？（2026-10-17 03:50）

- **状态：** DONE（scripts/e110_pullback.py，CPU）
- **类型：** CLAIM（E105c / E108 的机制）
- **设计：** 对遗忘后的模型 θ_U 与原模型 θ_0，令撤回方向 δ = θ_0 − θ_U。在 Pile 数据（4 个 8 × 512 的批次，未被遗忘与重学用过）上：
  - 计算 θ_U 处的一般损失梯度 g，报告 cos(−g, δ) 与沿 δ 的斜率 −g·δ / |δ|；
  - 沿直线 θ_U + εδ（ε = 0、0.25、0.5、0.75、1）报告 Pile 损失与 IOI。

## 结果
| 遗忘模型 | cos(−g, δ) | 斜率 | Pile 损失沿路径（相对 θ_0；ε = 0 → 1） | 重学比例 r（E105b/c） |
|---|---|---|---|---|
| QK（retain_w 1） | **0.0184** | **0.130** | +0.0063 → 0 | 0.85 |
| QK（retain_w 30） | **0.0125** | **0.061** | +0.0001、−0.0010、−0.0013、−0.0010 → 0 | 0.83 |
| 注意力全放开 | 0.0100 | 0.060 | +0.0025 → 0 | 0.68 |
| OV（retain_w 0） | 0.0056 | 0.027 | +0.0029 → 0 | 0.48 |
| MLP | 0.0055 | 0.026 | +0.0033 → 0 | 0.47 |
| OV（retain_w 1） | 0.0048 | 0.023 | +0.0022 → 0 | 0.49 |
- **相关：** cos 与 r 的 Spearman 0.83、Pearson 0.94；斜率与 r 的 Spearman 0.83；一般损失受伤与 r 的 Spearman 只有 0.20（6 个点，只作方向参考）。（03:52 更正：此前误写为 Spearman 0.94。）

## 判断
1. **一般数据的梯度沿“撤回遗忘”方向的分量，预测了重学比例**；遗忘对一般损失的伤害（终点差）预测不了。
2. **最清楚的一例是 QK（retain_w 30）：** 它的 Pile 损失与原模型几乎相同（+0.0001），但两者之间的直线上损失先下降（中点比两端都低约 0.001）。所以一般训练从 θ_U 出发，一开始就被拉向原模型——拉回来自局部梯度方向，而不是终点处的损失差。
3. **读取侧的改动（读者自身的 QK）处在一般损失的“回坡”上；写出侧的改动（上游写出内容）几乎与一般梯度正交（余弦小 3–4 倍）。**
   - 候选解释（未检验）：读者的 QK 在很多上下文中都起作用，为压住 IOI 而改动它，会在许多一般上下文中轻微扭曲注意力，于是被一般梯度推回。上游写出内容的改动只在少数特征上起作用，一般数据几乎不施加压力。
4. **与文献：**
   - SAM 遗忘论文（Fan et al. 2025）把抗重学归因于平坦度（二阶）。这里一阶的拉回分量已经足以解释重学比例。两者不冲突，但我们给出了组件层面的来源：拉回取决于改动由哪类参数实现。
   - Layered Unlearning 的“抑制器被微调拿掉”：抑制器即读取侧改动，它被拿掉，是因为一般梯度在它的方向上有拉回分量。
- **局限：** 只在 IOI、160M 上；一阶量只描述起点处的方向；E109（首都）的一般数据重学还在跑。
