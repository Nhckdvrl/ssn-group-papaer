# E66：早期窗口跟随训练进度，还是跟随学习率 warm-up 与优化器状态？（2026-10-06）

- **状态：** DONE（2026-10-06）
- **类型：** CLAIM（C05 的“关键期”表述是否需要改写；专家 / 评审意见：早期窗口可能来自学习率日程、剩余训练时长或分叉时继承的优化器状态）
- **对应：** C05；E46 D 组（warm-up 300 步，k = 100、250 都在 warm-up 内；分叉继承 AdamW 状态）
- **问题（一句话）：** 把 warm-up 从 300 步拉长到 1000 步，头布局对扰动敏感的窗口是否随之后移？分叉时重置 AdamW 的动量，2.5% 之后的“回到原来的头”是否仍然成立？
- **设置：**
  - 模型与训练同 E46 S 尺寸（4 层 × 8 头，d = 256，c4，10,000 步，batch 64 × 512，lr 1e-3，余弦到 10%）；`scripts/e46_train.py` 新增 `--warm`（默认 300，非默认时 run 名加 `_w<warm>`）与 `--reset-opt`（分叉时不载入优化器状态，run 名加 `_ro`），默认 run 的名字与行为不变。
  - **W 组（warm-up 1000）：** 父 run = 初始化 1 / 2 × c4（order 1 / 2），保存分叉状态；分叉：权重噪声 ε = 1 于 k ∈ {100, 250, 500, 1000, 2000}；换成代码于 k ∈ {250, 1000}。= 2 + 10 + 4 = 16 个 run。
  - **R 组（重置优化器，warm-up 300，用 E46 已有父 run 的状态）：** 初始化 1 / 2，ε = 1 于 k ∈ {250, 500, 1000}，分叉时重置 AdamW。= 6 个 run。
  - 卡：fvcrc10:3（空卡），单卡并行多个 run。
- **读数：** 分叉 run 最终 [层 × 头] 图与其父 run 最终图的层内 Spearman（M1 induction、M2 previous-token），与 E46 D 组同一口径；参照：重跑 0.91–0.96 / 0.99–1.00，新初始化 ≈ 0。
- **阳性对照：** W 组父 run 在最终步有 induction 头（M1_max > 0.3）；R 组以 E46 D 组的同 k、不重置结果为对照（0.85–0.98）。
- **噪声地板 + MIE：** 两个初始化之间的差异（E46 D 组同 k 两初始化相差约 0.03–0.4，早期最大）；“保留”= ≥ 0.8，“重排”= ≤ 0.5，中间为部分。
- **混杂审计：** warm-up 改变后整个学习率轨迹不同，W 组只与自己的父 run 比较（已控制）；重置优化器会让分叉后的前几步更新变大（这正是要测的成分，写明）；只有 2 个初始化（写进范围）。
- **决策表（跑之前写）：**
  - W 组 k = 250 / 500 的噪声分叉仍回到原布局（≥ 0.8）→ 窗口由训练进度决定，与 warm-up 长度无关，论文保留“训练最初约 1–2.5%”的说法并补充此对照；k = 250 / 500 重排（≤ 0.5）、k ≥ 1000 才保留 → 窗口跟随 warm-up，论文改写为“布局在学习率 warm-up 期间形成并稳定”，与 SGD 温度一节合并叙述。
  - R 组重置后仍 ≥ 0.8 → 回到原布局不依赖 AdamW 的动量，由权重本身决定；≤ 0.5 → 优化器状态承载了布局，论文写明。

## 结果（2026-10-06；`results/e66_analysis.json`）
- 阳性对照 ✓：两个 warm-up 1000 父 run 最终有 induction 头；父 run 与从其 step 2000 状态续跑的副本一致 0.995–1.00（fvcrc10 慢卡上的父 run 另由 fvcrc20 续跑核对）。
- 分叉与父 run 最终布局的层内一致性（M1 / M2 与两个初始化平均）：

| 第 k 步加 ε = 1 噪声 | warm-up 300（E46） | warm-up 1000 | 重置 AdamW（warm-up 300） |
|---|---|---|---|
| 100 | 0.36 | 0.16 | — |
| 250 | 0.85 | 0.70 | 0.81 |
| 500 | 0.96 | 0.87 | 0.91 |
| 1000 | 0.97 | 0.87 | 0.97 |
| 2000 | 0.98 | 0.94 | — |

- 换成代码（warm-up 1000）：k = 250 → 0.41，k = 1000 → 0.69（warm-up 300：0.60 / 0.71）。
- 按决策表：W 组 k = 500 时（warm-up 只走了一半）已 ≥ 0.8，k = 250 介于 0.5–0.8 → 窗口不是在 warm-up 结束时关闭，但 warm-up 越长、在步数上关得越晚。R 组重置后 ≥ 0.8 → 回到原布局不依赖 AdamW 动量，由权重本身决定。
- **POST-HOC：** 以分叉前的累积学习率（以峰值学习率为单位）为横轴，两种 warm-up 的点大致落在同一条上升曲线上（500 → 0.87 一处回落，来自初始化 2 的 M1；5 → 0.16、17 → 0.35、31 → 0.70、105 → 0.85、125 → 0.87、350 → 0.96、500 → 0.87、848 → 0.97、1491 → 0.94、1813 → 0.98）→ 窗口按“已经发生的学习量”关闭，而不是按步数或 warm-up 是否结束。
- 附带：只改 warm-up（同初始化、同数据顺序）就使最终布局与 warm-up 300 的 run 只一致 0.21–0.59（M1）/ 0.62–0.67（M2）→ 早期训练动力学本身参与决定布局。
- 主张变化：C05“关键期”改写为“布局在最初一小段学习中确定（窗口按累积学习率关闭，与优化器状态无关）；换语料在之后仍会改写一部分，越晚越少”。论文摘要必须与 Table 6 一致（评审意见 1）。
