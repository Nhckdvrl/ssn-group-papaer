# E95：PolyPythias 410M seed3 / seed4 的“loss spike”其实是训练中途被重置回初始化（审计，2026-10-16）

- **状态：** DONE（410M 全种群终点审计进行中，结果见末尾）
- **类型：** AUDIT（公开资源的数据完整性；与 PAIN_LOG P09 / P11 / P12 / P13 同类）
- **怎么发现的：** E94b 比较自然 spike 前后的权重，发现两千步内几乎所有矩阵的相对变化 ≈ 1.0（正常窗口 0.01–0.13）；进一步与该种子的 step0 比较。

## 证据（`scripts/e94b_spike_delta.py`、本卡命令；检查点用 curl 获取）
- **事件局限在 1000 步内：** seed3 74k→75k 余弦 0.994–1.004（正常），75k→76k 嵌入 0.126、第 5 层 QKV 0.181、第 12 层 MLP 0.303、第 20 层注意力输出 0.018，范数降到 0.65 / 0.66 / 0.72 / 0.17；之后 76k→ 后续正常。seed4 122k→123k 同样（嵌入 0.100、QKV 0.147、MLP 0.278、注意力输出 0.025），123k→124k 余弦 0.976–1.001。
- **事件后的权重 ≈ 该种子的 step0 初始化：** seed4 123k vs step0：嵌入 0.992、QKV 0.995、MLP 0.999、注意力输出 0.965、输出嵌入 0.905；seed3 76k（事件后约 1000 步训练）vs step0：0.937 / 0.982 / 0.990 / 0.533 / 0.711，vs step1000：0.905 / 0.956 / 0.984 / 0.432 / 0.865；与事件前（74k / 122k）只有 0.02–0.30。
- （LayerNorm 增益的余弦本来就接近 1，不作证据。）
- **结论：** 这两个 run 在训练中途被重新从初始权重开始训练（很可能是中断后从错误的检查点恢复），之后在余弦学习率已降到峰值约 40%（seed3）/ 约 18%（seed4）的条件下，只剩 67k / 20k 步“从头重训”。PolyPythias 论文把这两个异常种子归因于 loss spike 与训练不稳定（HMM 训练图分叉、表征退化），**原因判断需要修正**；它们的发布检查点（≥76k / ≥123k）实际上是“短时间、低学习率从初始化训练的模型”。
- **其他尺寸：** 14M / 31M / 70M / 160M 全部 40 个 run 的终点与 step0 的余弦都在正常范围（嵌入 0.008–0.032，QKV 0.05–0.14），没有晚期重置（早期重置无法用终点检验排除）。31M seed5 在 129k→141k 损失从 3.49 升到 3.81（本地复算确认），相邻检查点余弦 ≥ 0.995、离初始化很远 → 是真实的渐进退化，不是重置。

## 对本工作台既有结论的影响（如实降级）
- **E90：** “spike 改写已形成的分工、重学按发育顺序、晚出现能力不恢复”→ 实为“从初始化重训且学习率已低、时间不够”，平凡；作废“spike”框架。
- **E91：** “spike 起点在哪个头”→ 前提不成立；seed4 第 21 层 21.14 在事件前 ≥7k 步尖锐度陡增仍是事实，可能是导致训练中断的真实失稳，但未核实。
- **E89：** seed3 的“异常组织”（无早层枢纽、整体偏深）是重训模型的性质，不是正常训练的变异；E89 的跨种子统计需剔除 seed3 / seed4 复核（主结论预计不变）。
- **E92：** “410M 失败尾部来自 spike”→ 来自重置；“正常 run 的种子差异连续、不双峰”不受影响。
- **E93 / E94：** 追问“自然 spike 为何不可恢复”的动机不成立；E93 的结果（同幅度各向同性 / 单头损伤在训练后段完全可恢复）本身有效，E94 已停止。
