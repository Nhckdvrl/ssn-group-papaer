# E46c：继承强度由什么决定？——固定架构下操纵初始化尺度与学习率（2026-10-03）

- **状态：** DONE（2026-10-03；假说被否定：更大的初始化尺度反而削弱继承；学习率无影响）
- **类型：** CLAIM（把 E45 的尺寸趋势从描述变成机制：受控因果检验）
- **对应：** C05；E45 部分结果（4M–20M 继承弱，60M 起出现并随规模增强）；DataDecide 表 2：学习率随尺寸下降（1.4e-2 → 2.1e-3），初始化标准差固定 0.02 而宽度 64 → 2048（相对初始化尺度增大约 6 倍）；机制假说（logs 13:35）：继承 ≈ 初始化造成的头间不对称 / 早期 SGD 噪声；对标 Bali ICML 2026（AdamW 提高稳定性）、Summers & Dinneen ICML 2021
- **问题（一句话）：** 在固定的 S 架构（4 层 × 8 头，d 256）上，提高初始化标准差（相对宽度更大的初始不对称）是否增强“同初始化、不同语料”的头身份继承？提高学习率是否减弱它？
- **设置：**
  - 2 × 2：初始化标准差 ∈ {0.02（E46 默认，相对尺度 0.32）, 0.0625（= 1/√256，相对尺度 1.0）} × 学习率峰值 ∈ {1e-3（E46 默认）, 3e-3}；其余与 E46 完全相同（`scripts/e46_train.py --init-std --lr`）。
  - 每格：3 个初始化（1、2、3）× 2 个语料（c4、code），order seed = init seed；默认格（0.02, 1e-3）复用 E46 A 组的对应 6 个 run → 新增 18 个 run。
  - 测量：最终步的 M1、M2 图（同 E46）。
- **读数：** 每格的继承度 = 层内 Spearman 的 SI（同初始化、c4 vs code，3 对）减 SD（同语料、不同初始化，6 对）；主读数 = M1 与 M2 的平均。
- **阳性对照：** 每格所有 run 在最终步 M1_max > 0.3 且 copy gain > 2（induction 形成）；否则该格不可判定（大学习率可能训练不稳）。
- **噪声地板 + MIE：** 每格 3 个 SI 对、6 个 SD 对；对 run 做置换（打乱初始化标签）得零分布；MIE：格间差 > 0.1。
- **混杂审计：** 改初始化尺度也会改变训练动态的其他方面（如早期损失下降速度），记录损失曲线；学习率与初始化尺度可能交互，所以用全 2 × 2；所有格用相同的数据流。
- **决策表（跑之前写）：**
  - 初始化尺度主效应 > 0.1（大初始化继承更强）且学习率主效应 < −0.1（大学习率继承更弱）→ 写成“继承强度由初始不对称与早期 SGD 噪声之比决定”，用来解释 E45 的尺寸趋势（DataDecide 大模型的相对初始化更大、学习率更小）。
  - 只有一个因素有效 → 只写该因素。
  - 两者都无效（|主效应| ≤ 0.1）→ 尺寸趋势另有原因（如每头维度、训练长度），不写这条机制。

## 结果（`results/e46/e46c_analysis.json`；24 个 run（默认格复用 E46 A 组）；20:47）
| 格子（初始化标准差, 学习率） | M1 继承（层内 SI − SD） | M2 继承 | 平均 |

| 0.02, 1e-3（默认） | 0.132 | 0.342 | **0.237** |

- 阳性对照 ✓：所有格子 M1_max ≥ 0.46、copy gain ≥ 2.6。
- **主效应：** 初始化尺度（0.0625 − 0.02）= **−0.205**（两个学习率下分别 −0.23、−0.18，方向一致）；学习率（3e-3 − 1e-3）= **−0.009**。
- **判定（按决策表）：** 学习率无效；初始化尺度有效但**方向与假说相反**（决策表未预设此情形，如实报告）→ **机制假说“继承 ≈ 初始不对称 / 早期噪声”被否定**：更大的相对初始化削弱头身份的继承，学习率不影响。
- **对 E45 尺寸趋势的含义：** DataDecide 中相对初始化尺度随尺寸增大（0.02 固定、宽度增大），按本实验应削弱继承，而实际继承随尺寸增强 → 尺寸趋势**不能**用相对初始化尺度解释，应来自其他随尺寸变化的因素（头数与每头维度、训练长度、批量等），未拆分，写进局限。
- 局限：每格只有 3 个 SI 对、6 个 SD 对；比较的是 c4 vs code（E56 正在检验语料差异的影响）。
