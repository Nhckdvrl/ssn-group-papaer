# E106：网络其余部分冻结时，完整重置的头能否长回原角色？（2026-10-17）

- **状态：** RUNNING（01:40 启动；3000 步）
- **类型：** CLAIM（区分两种解释的判别实验）
- **来源：**
  - E98 / E102：联合训练时，完整重置或输出旋转后的头 6 / 6 恰为 0，并被推成注意力汇。
  - Schallon（arXiv 2603.09616，正文精读）：BLOOM-1b7 中，重置坍缩头的 QKV、把输出投影置零，**冻结其余全部参数**，这些头重新工作（378 / 384 健康）；不重置只训练则无效。但该文没有检验它们是否恢复原功能。
  - Active-Dormant（Guo et al. 2024，正文精读）：模型不用某个头也能预测时，该头被推向注意力汇。
- **两种解释：**
  - **(A) 竞争 / 双边协调：** 联合训练时，原本已耦合的其他组件与读者一起调整，先把功能吸收掉，于是新鲜的头没有用处，被推成空操作。冻结其余部分后，读者保持原来的对准，替补无法增长，新鲜的头是唯一能降低损失的部分，应当**重新长出原角色**（向冻结的读者对准写出端，是单边问题）。
  - **(B) 头自身的无能：** 在这个学习率和窗口下，从随机初始化重新学会这个角色本来就做不到。冻结其余部分也长不回来。

## 设置
Pythia-160M step100k；学习率 2e-5，batch 128 × 1024，warm-up 200，3000 步，init_seed 1234；`--train_only`：只训练受损头自己的 QKV 行与输出投影列（AdamW、无权重衰减），其余全部冻结。

| F89_frz | 完整重置 8.9 | E98 L8.9_long（IOI 0.40，8.9 为 0） |

## 登记的预测（01:40，看结果前写）
- **(A)：** F89_frz、R89_frz、F93_frz 中，受损头在其任务上的效应回到损伤前的 ≥ 50%，并且不变成注意力汇（对第 0 个 token 的注意力 < 0.2）；F32_frz 中 3.2 的 previous-token 分数 ≥ 0.5。
- **(B)：** 受损头效应 < 20%（与联合训练相同）。
- **含义：**
  - (A) 成立 → “孤立容量变成空操作”是联合训练中竞争的结果，不是头自身的限制；主线的统一解释（修复沿保留的写出端接口进行，无耦合容量在联合训练下休眠）得到判别性支持。
  - (B) 成立 → “不回来”是新鲜头在此窗口内学不会，主张退回到“短窗口现象”。

- **代码已核验（CPU 单元测试）：** 只训练受损头时，该头的 QKV 行与输出列有梯度（0.25 / 0.64），一步更新后发生变化；其他行列的梯度与更新均为 0。所以“不恢复”不是 bug。
- 冻结时的损失几乎不降（F89：2.6916 → 2.6911）：在其余网络固定的情况下，单独一个新鲜头能拿到的损失收益很小。
- 联合训练中只重置 QK 的头也要约 1000 步才开始回升，所以仍等 3000 步再判。如果到时仍 < 20%，按登记的决策就是 (B)：不回来是新鲜头在此窗口内学不会，与竞争无关。这会削弱统一解释中的“竞争”一半；Schallon 的成功可能依赖更高学习率（5e-5）、多轮训练与 BOS 坍缩这种特殊起点。
