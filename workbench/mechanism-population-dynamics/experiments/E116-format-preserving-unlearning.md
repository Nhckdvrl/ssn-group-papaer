## 登记的预测（07:47）
- **格式是原因：** format_reg = 100 时，遗忘后模型的冻结探针准确率 ≥ 0.85（格式保住），且良性重学 r ≥ 0.7（原 OV 式 0.48–0.51）。
- **格式不是原因：** 格式保住了（冻结探针 ≥ 0.85），但 r 仍 ≤ 0.55 → 格式只是相关。
- **做不到：** 在格式约束下，OV 路线无法把 IOI 压到 < 0.5（OV 式遗忘必须靠重新编码才能完成）→ 记录，这本身说明写出侧遗忘与重新编码绑定。

## 08:33 结果与判定：格式只解释了一部分
**遗忘终点：**
- format_reg 100：IOI 只降到 1.93 / 2.16（原 3.49），遗忘不彻底，权重变化 0.03–0.04%；
- format_reg 10：降到 0.64 / 0.68，权重变化 0.09–0.10%，Pile 损失 +0.02–0.03。
- 四个模型第 8 层原格式探针都是 **1.00**——格式完全保住。按预注册，约束越强越“做不到”，说明 OV 式遗忘主要靠重新编码完成。

**良性重学 r：**
| 模型 | 起点 | 100 / 200 / 400 / 700 / 1000 步 |
|---|---|---|
| QK 式（参照，格式保留） | −0.17 | 0.49 / 0.68 / 0.77 / 0.80 / **0.85** |
| **OV + 格式约束，fr10 s1 / s2** | 0.59 / 0.56 | 0.17–0.19 / 0.29–0.30 / 0.46–0.47 / 0.55–0.56 / **0.61 / 0.61** |
| **OV + 格式约束，fr100 s1 / s2** | 1.81 / 2.07 | 0.17–0.18 / 0.23–0.29 / 0.51–0.53 / 0.63–0.67 / **0.67 / 0.74** |
| OV 式（参照，格式被重新编码） | −0.03 | 0.12 / 0.22 / 0.34 / 0.42 / **0.49** |

- **判定：** 介于预注册的两档之间。保住格式后，r 从 0.49 升到 0.61–0.74（fr100 的遗忘较浅）；但前 200 步的恢复仍与 OV 式一样慢（0.17–0.30），而 QK 式 100 步内就恢复一半。**格式是不对称的一部分原因，不是全部。**

## 补充：参数存活率（E115 保存的 QK / OV 单路线重学模型，相对 C1000）
- QK 式遗忘：重学后 QK 改变存活 **0.71**；把 R 的 QK 换回 C 的 QK，IOI 从 2.84 升到 3.62——残留的 QK 改变仍在起作用，恢复靠别处补偿。
- OV 式遗忘：V 存活 **0.72**、O 存活 **0.77**；换回 V / O，IOI 从 1.59 升到 3.01 / 2.91；把 MLP 换成 C 的，IOI 反而降到 0.90——MLP 承担了大量补偿。
- **两条路线的参数改变都没有被撤销（存活率 0.71 vs 0.72–0.77）。** QK 式恢复快，不是因为参数被拉回，而是网络更容易在别处补偿读取侧的改变。为什么更容易补偿，目前只有“格式”这一部分解释。
