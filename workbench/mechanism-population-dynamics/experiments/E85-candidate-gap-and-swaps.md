# E85：两个候选越接近，随机删数据越容易换掉胜者吗？（2026-10-11）

- **状态：** DONE（2026-10-11 01:50）
- **类型：** CLAIM（把 E84 中 n = 1 的“两个接近的候选会被随机删除换掉”变成可量化的检验；回应审稿视角的“个例”质疑）
- **对应：** E84（初始化 2：7.9 与 8.1 并列，随机屏蔽 10% 后 8.1 接手；初始化 1、3 有明确领先者，不变）；论文第 6 节
- **问题（一句话）：** 在固定初始化与数据顺序的受控训练中，随机屏蔽 10% 序列（第 500–2000 步）使最强 induction 头易主的概率，是否随未屏蔽基线中前两名候选的差距减小而增大？
- **设置：** E46 L 尺寸（12 层 × 12 头）、C4、3000 步；初始化 4–15 的 base（12 个新 run）；初始化 1–15 各两种随机屏蔽（屏蔽随机种子 0、1；初始化 1–3 的种子 0 已在 E84 跑过）。共 39 个新 run。
- **读数：** 每个初始化：base 第 3000 步最强与次强 induction 头的分数差 gap（以及第 1000 步的 gap）；每个屏蔽 run：最强头是否与 base 不同（易主），复制能力相对 base 的比值。
- **事先预测：** P1：易主与 gap 负相关（点二列 / Spearman < 0）；P2：gap 低于全部初始化中位数的一组，易主率至少是高于中位数一组的 2 倍；P3：易主的 run 中复制能力 ≥ 0.9。
- **决策表：** P1、P2 成立 → 第 6 节写成“候选越接近，随机的小数据变化越容易换掉胜者”，以 15 个初始化为证据；P1 不成立（易主与 gap 无关）→ 第 6 节只保留 E84 的个例描述；易主率在两组都接近 0 → 写“induction 头在这种干预下几乎不易主”，初始化 2 作为罕见情形描述。
- **算力：** 39 run × 约 22 分钟，夜间全部空闲卡（约 21 张）。

### 中间结果（2026-10-11 00:50；27 个随机屏蔽 run / 15 个初始化；`results/e85/analysis.json`）
- 随机屏蔽后最强 induction 头易主 13 / 27（48%）；易主 run 的复制能力 0.87–1.10。
- P1（gap 越小越易主）：Spearman(gap@3000, 易主) = −0.13，Spearman(gap@1000, 易主) = −0.38 → 方向成立但弱；P2（接近组易主率 ≥ 2 倍）不成立（58% vs 40%）；P3（易主 run 复制能力全部 ≥ 0.9）差一例（0.87）。
- **未控制的混杂：** E84 只有 3 个初始化做过原样重跑（0 / 3 易主，且都有明确领先者）。48% 的易主可能来自 GPU 非确定性而非屏蔽 → 补 E86 重跑对照后再判定第 6 节写法。

# E86（附于 E85）：原样重跑会不会也换掉最强 induction 头？（2026-10-11 00:52，看到 E85 中间结果后登记）
- **设置：** 初始化 4–15 各一个与 base 完全相同配置的重跑（`--rerun 1`），共 12 个；初始化 1–3 的重跑已在 E84。
- **读数：** 重跑易主率（15 个初始化）与随机屏蔽易主率（E85）。
- **决策：** 重跑易主率 ≤ 随机屏蔽易主率的一半 → 第 6 节写“随机屏蔽一成数据就使 induction 头在约一半的初始化中易主，复制能力不变；原样重跑很少易主”；重跑易主率与屏蔽相当 → 第 6 节写“最强 induction 头的身份在原样重跑中都不可复现，单头读数需与角色最强头和行为一起看”；介于两者之间 → 两个比率都如实报告，不作对比结论。

### E86 结果（2026-10-11 01:50；15 个初始化全部完成；`results/e85/e86_analysis.json`，`scripts/e86_analyze.py`）
- **原样重跑易主 9 / 15（60%）**，随机屏蔽易主 14 / 30（47%）→ 按决策表为“相当”：最强 induction 头的身份在原样重跑中也不可复现。
- 补充读数（看到结果后定义，只作描述）：原最强头在另一 run 中低于该 run 最强头 90% 的比例：重跑 4 / 15，屏蔽 9 / 30；低于一半：重跑 1 / 15（初始化 12：7.2 从 0.64 变为 0.00，8.3 两次都成为 induction 头，训练 loss 相差 < 0.01、复制能力 2.66 对 2.59），屏蔽 3 / 30。
- 角色图可复现：第 3000 步层内对应（induction / previous-token / M3）重跑 0.80 / 0.91 / 0.74，随机屏蔽 0.77 / 0.90 / 0.75，不同初始化之间 0.00 / −0.01 / 0.00；复制能力：重跑 0.87–1.22，屏蔽 0.80–1.21。
- 重复数据屏蔽（初始化 1–3，E84）：复制能力在第 1000 步降到 0.50–0.54，窗口内 0.47–0.71，第 3000 步回到 0.80–1.07；随机屏蔽平均 0.86–0.98。
- **论文第 6 节写法（按决策表）：** 初始化定下的坐标系（角色图）在重跑与屏蔽下都能复现；几个候选中谁领先，由比原样重跑的浮点非确定性还小的差别决定；针对机制本身的数据（重复数据）改变的是角色和行为。单头读数需对照重跑，并结合角色图与行为一起看。E85 的 P1 / P2 不再作为第 6 节依据。
