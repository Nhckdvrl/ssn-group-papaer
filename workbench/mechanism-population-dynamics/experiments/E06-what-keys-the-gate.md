# E06 — What property of the context keys the copy gate?（2026-10-02）

- **状态：** DONE（2026-10-02；判定：罕见度/意外度键控；句法不触发）
- **类型：** PILOT（机制内容）
- **对应：** C02（第 0 层分布级门控）
- **问题（只回答这个）：** 门控是被 (a) token 罕见度、(b) 固定 unigram 时的序列不合理性（语法 / 共现），还是 (c) 模型自身的意外度触发的？
- **为什么需要：** 不知道门控键控什么，就无法说明它在真实任务中何时有害（E07），也无法区分“学到的合理先验”和“退化”。

## 刺激（全部为 [BOS] + X(50) + X(50)，只改变 X；每类 500 条，held-out）
| 代号 | X 的构造 | 控制住 / 改变 |
|---|---|---|
| S1 nat | Pile 自然片段 | 基线 |
| S2 shuf | S1 同一片段内 token 随机打乱 | unigram 与 S1 相同，句法/局部共现被破坏 |
| S3 unig | 按 Pile unigram 频率独立抽样 | 只保留 unigram 分布 |
| S4 hi | 从高频 token（频次排名 500–5000）均匀抽 | 常见词、无结构 |
| S5 mid | E02 的 token 池（≥50 次、非 top-500）均匀抽 | = E02/E04 的随机序列 |
| S6 lo | 频次 10–49 的 token 均匀抽 | 罕见词、无结构 |

## 读数（10 个 seed × {best step, 64000, 143000}）
- 每类的 CL、ACC（中位数稳健版）。
- **门控效应** G = CL(late) − CL(best)，按类。
- **第 0 层正向平移救回**（rand→nat 均值，μ 用 E04 的估计集，不针对每类重新估计）按类。
- **门控信号**：每条序列第 0 层残差在 E04 方向 d 上的投影（第一段位置均值）；序列级 Spearman(投影, 第二段 loss)（同一 seed、同一 checkpoint、合并各类）；以及第一段 loss（模型意外度）与第二段 loss 的序列级相关。

## 决策表（跑之前写）
- **罕见度键控：** G 随 S4 < S5 < S6 单调上升，且 S2 ≈ S1（打乱不触发）→ 门控是“对罕见 token 不复制”的频率先验。
- **合理性键控：** S2（与自然相同 unigram）的 G 明显 > S1（≥ S5 的 50%），且 S4（常见词无结构）也被门控 → 门控识别“上下文不像自然语言”，与 token 频率无关。
- **意外度键控：** 在各类内部与跨类，第一段 loss 对第二段 loss 的序列级 ρ ≥ 0.5，且投影 ρ 与之相近 → 门控以模型自身的意外度为输入。
- 结果可同时属于多个分支；都不成立（各类 G 相近）→ 门控是“任何非自然重复”的通用信号，记录并进入 E07。
