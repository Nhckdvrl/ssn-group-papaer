## 什么结果会改变判断
- 若复杂任务普遍双峰、且失败多来自“学会后丢失 + 对应损失跳升”：现有“学习竞争导致种子双峰”的解释在真实预训练中不完整，优化事故是重要来源 → 追问事故为何只伤后期能力（与 E90 的“重学按发育顺序”相连）。
- 若失败多为“从未学会”且与 spike 无关：存在学习过程本身的分岔 → 用 E89 探针在分岔前后找机制差异（例如是否形成某个共用头）。
- 若基本不双峰、种子差异是连续小幅波动：410M 反义词只是个例，此线止于描述。

### 结果一：终点（2026-10-16 00:30；50/50 个 run 的 step143000；`results/e92/analysis.json`，`scripts/e92_analyze.py`）
- **正常 run 之间的种子差异是逐任务、彼此近乎独立的小幅波动，不是双峰：** 以准确率 > 0.1 的 FV 任务计，种子间任务两两相关（去掉最极端的一个 run 后）14M 0.04、31M 0.23、70M 0.13、160M 0.09、410M 0.18。160M 例：大写化 0.26–0.66、过去式 0.13–0.65、选最后一项 0.29–0.81，连续分布。
- **失败尾部是整个 run 一起坏（run 级），而不是某个任务单独抽签失败：**
  - 410M seed4：33 个 FV 任务的平均 z = −2.1，几乎所有任务同时最差（大写化 0.27 vs 正常 0.85–0.91，复数 0.34 vs 0.78–0.95，国家-首都 0.06 vs 0.58–0.70），验证损失 2.884（E90：122k→124k 的 spike）。seed3 次之（国家-首都 0.26、英法 0.08、过去式 0.42），损失 2.480（spike 74k→76k）。去掉 seed4 后任务两两相关从 0.53 降到 0.18。
  - **31M seed8：验证损失 3.495 与其他种子相当（3.41–3.52），初级任务正常（induction 0.70、主谓一致 0.85、性别 0.68），但几乎所有 FV few-shot 任务准确率为 0**（包括“选第一项” 0.00 vs 其他 0.02–0.19，人物-职业 0.01 vs 0.09–0.31，情感 0.00）。即损失无异常、但完全不会使用 few-shot 格式。去掉它后任务两两相关 0.54 → 0.23。
  - 31M seed5 损失 3.815 偏高（可能有 spike），但 FV 任务正常；14M seed4 损失 4.333 偏高。
- **纠正（E89 / E90）：** 410M seed8 在 E89 自制的反义词对比读数上“失败”（−0.09），但在 Todd 的 FV 反义词 5-shot 准确率上为 0.20，与正常种子（0.11–0.24）相同 → 不再把 410M seed8 记作能力失败；410M 上的能力失败只来自两个 spike run。
- **对判断的影响：** 与 Zhao/Saphra “能力在种子间双峰”的合成设置不同，真实预训练（≤410M、本任务集）中正常 run 的复杂能力并不双峰；失败是罕见的 run 级事件，至少两种：优化事故（410M seed3/4，损失可见）与**损失不可见的 few-shot 能力缺失（31M seed8）**。下一步追 31M seed8 的轨迹（已开优先队列）：从未学会，还是学会后丢失？
- **31M seed8 的诊断（00:40，看到结果后，POST-HOC）：** 在 “A:” 之后它把平均 44% 的概率放在换行符上（seed1 为 1%），argmax 一律是换行，所以首 token 准确率为 0；排除换行后准确率 0.025（seed1 0.059），答案对数概率也比其他种子低 2–3 nats。→ 是“A: 后接换行”的强格式偏好叠加较弱的能力，而 31M 的 few-shot 能力本身接近地板。**这不是有分量的能力分岔，不再追。**

### 结果二：轨迹（2026-10-16 01:25；213/850；31M 6 个 run 的完整轨迹，160M / 410M 只有 2k、8k、43k、86k 等少数点；`scripts/e92_trajectory.py` → `results/e92/trajectory.json`）
- **160M / 410M（粗网格）：** 能力出现时间在正常种子间非常一致（多数任务所有种子都在同一个网格区间：induction / 主谓一致 / 性别 2k，抽取类与复数 8k，首字母大写 / 国家-首都 / 英-西 43k）；正常种子中几乎没有“学会后丢失”（160M 两例单种子，410M 正常种子 0 例；seed3 反义词 0.18@43k → 0、英-法 0.24@43k → 0.08，对应其 spike）。注意 410M 原版缺 8k 检查点，其“43k 出现”是网格造成的。
- **31M：正常种子里重复出现“学会后丢失”，而验证损失持续下降：**
  - 后继（星期/月份/数词）：4 个种子在 30k–57k 达 0.30–0.40，终点 0.05–0.17；
  - 产品-公司、人物-职业 / 乐器：2–3 个种子在 2k–8k 达 0.3 左右后降到 0.0–0.13（可能是早期“回答高频词”启发式被替代）；
  - 首都事实 2 个种子 30k 达 0.37–0.56 后降到 0.10–0.16；情感 2 个种子 13k 达 0.58–0.65 后降到 0.03–0.28；
  - IOI 在 512 步约 0.5（二选一的随机水平）后降到 0.23（低于随机）——与 *Copying Before Suppression*（arXiv 2610.04119，未精读）讨论的“低于随机的下探”现象相近，不算新。
- **待验证的想法（不是结论）：** 小模型里某些能力是“暂时的”，学会后在损失继续下降时被挤掉；160M 起不再出现。若成立，70M 终点上后继 0.06–0.77、首都 0.20–0.66 的大离散，可能是各种子处在“出现—消失”的不同阶段（异步的暂时能力），而不是学没学会。已把 70M 完整轨迹加入优先队列以检验。
