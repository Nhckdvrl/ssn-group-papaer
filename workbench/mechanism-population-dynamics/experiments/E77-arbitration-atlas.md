# E77：上下文 / 记忆仲裁的条目级图谱——训练让模型沿着同一条“置信度曲线”移动，还是改变了曲线本身？（2026-10-10）

- **状态：** RUNNING
- **类型：** EXPLORE（整体测量层；按 research-method 第 8 条：先整体测量，拟合最简单的已知解释，再从结构化残差里找问题）
- **对应：** 新中心候选（`REVIEW_2026-10-10.md` §3）；C04（问答格式开关）；E18/E20（采信不是模型级特质）；E29/E30/E48/E76（同一指令数据在不同阶段方向相反）
- **问题（一句话）：** 在真实预训练中，冲突时“跟随上下文还是记忆”的条目级规则如何随训练、语料配方、规模和提示格式变化？其中多少只是模型对该事实的置信度变化（沿同一条曲线移动），多少是规则本身改变（曲线平移或斜率变化）？

## 最强的现有解释与它的预测（跑之前写）
- **S0 置信度校准仲裁**（Kim et al. 2026 ACL，合成语料 + Pythia 检查点；Du et al. ACL'24；Mallen et al. ACL'23；Three Regimes 2026 的 Regime 2）：模型越确信自己的记忆，越不跟随冲突上下文。训练中采信下降，是因为模型知道得更多。S0 的强形式：**一条由置信度和上下文使用能力决定的共享曲线**就能解释不同检查点、配方和规模之间的差异。
- **S0 已知的反例**：C04 中 Flan 不改变知识量，却改变问答格式下的采信。所以 S0 至少在格式上不完整。问题是：除了格式，训练本身是否也在改变规则？改变有多大？由什么驱动？
- **谁依赖这个答案：** RAG / 知识冲突研究普遍把“模型越不确定越跟随检索内容”当作可依赖的规律（用置信度决定是否检索、是否信任上下文）；Kim et al. 用这条规律解释训练数据的作用。如果训练会在固定置信度下改变规则，这些推断就需要修正。

## 设置
- **条目**（`scripts/e77_atlas.py --check`）：PopQA 全部 16 种关系，每种最多 250 条（固定种子），每条配一个同关系、同数据集抽取的反事实答案 o′（规则同 E34）。另外为每条生成一个**虚构主语**（音节拼接的假名），用来测“没有记忆时的上下文使用能力”。
- **单元**（每条 12 个提示 × 2 个候选，记分 = 候选全部 token 的 log 概率之和）：
  - 置信度：`clean_decl`（stem）、`clean_qa`（Question: q Answer: stem）
  - 冲突：`c1_decl`（“stem o′.” + stem）、`c1_qa`、`c1_Q`（Q: … A:）、`c3_decl`（三句重复）、`c3_qa`
  - 支持：`agree_decl`、`agree_qa`（上下文给出真实答案 o）
  - 能力：`nonce_clean`、`nonce_c1_decl`、`nonce_c1_qa`（虚构主语，上下文给 o′）
- **模型**（整体测量，四个家族）：
  - Pythia 160M / 410M / 1.4B / 2.8B / 6.9B（标准版），step ∈ {512, 1000, 2000, 4000, 8000, 16000, 33000, 66000, 100000, 143000}；12B 只测终点。
  - DataDecide 1B：dolma1_7、dolma1_7-no-flan、dclm-baseline、c4 × 3 个 seed × step ∈ {2500, 5000, 10000, 17500, 25000, 35000, 50000, 69369}。
  - DataDecide 1B 终点：25 个配方 × 3 个 seed（配方层面的变异）。
  - OLMo 2 1B：stage1 约 10 个检查点（覆盖 0–4T token）、stage2 ingredient1 轨迹（1000/2000/4000/6000/12000/18000/23852）+ ingredient2/3 终点、SFT / DPO / Instruct。
- 序列起始符：DataDecide / Pythia 用 EOS（文档分隔符）；OLMo 2 用 tokenizer 的 BOS。精度 bf16，logits 转 fp32 计算 log-softmax。

## 读数
- 置信度 c = lp(o) − lp(o′)（同格式，无上下文）；采信 a = lp(o′) − lp(o)（有冲突上下文）；支持增益 = lp(o | agree) − lp(o | clean)；能力 u = 虚构主语下 [lp(o′) − lp(o)]_有上下文 − [lp(o′) − lp(o)]_无上下文。
- **R1 发育分解（主读数）：** 在固定条目集上，把相邻 / 首末检查点之间平均采信的变化分解为“置信度移动”（用旧曲线在新置信度处取值 − 旧曲线在旧置信度处取值）与“曲线改变”（新曲线 − 旧曲线，都在新置信度处取值）。曲线 = 每个检查点上 a 对 c 的分箱均值（10 个分位箱）与线性拟合两种，结果都报告。
- R2 置信度敏感度 β（a 对 c 的斜率）随训练的轨迹；R3 能力 u 与采信 a 的轨迹是否分离；R4 问答格式改变的是截距、斜率还是能力；R5 配方层面：控制 c 与 u 之后，残差采信的配方 ICC。
- **残差挖掘（EXPLORE，单独标注）：** 条目级残差对 popularity（s_pop）、关系类型、答案长度、o′ 的先验概率、语料计数（infini-gram）的依赖。

## 阳性对照
- 每个终点模型：`c1_decl` 中位采信 > 0（模型读了上下文）；能力 u 在 ≥ 1B 的终点 > 2 nats。
- S0 的必要条件：终点模型上 a 与 c 的 Spearman < 0（越确信越不采信）。若不成立，曲线分解无意义，如实报告。

## 噪声地板 + MIE
- DataDecide 3 个 seed（同配方同步数）的标准差；条目 bootstrap 1000 次。
- “曲线改变”份额的差别小于 seed 间差别时，不作解释。

## 混杂审计
- 多 token 答案的长度偏差：用的是同一对候选的差，且每个条目在所有模型上的候选对固定 → 已控制。
- 条目集随知识量变化：R1 使用固定条目集（全部条目）+ 按置信度分箱 → 已控制；另报“只用终点已知条目”的版本。
- 分词器不同（Pythia / OLMo-1 / OLMo-2）：只在家族内部做定量比较，跨家族只比较形状。
- 曲线形状的假设：分箱与线性两种都报告。
- 起始符约定：按各家族训练时的文档分隔方式，见设置。

## 决策表（跑之前写）
- **S0 成立**：所有家族中“置信度移动”解释 ≥ 80% 的发育变化，且配方 ICC（控制 c、u 后）≤ 0.2 → 写“除格式以外，训练只是让模型知道得更多”；下一步只追格式（C04）这一处偏离，E78 检验模板改变的是截距还是斜率。
- **S0 失败**：至少两个家族中“曲线改变”份额 ≥ 50%，或配方 ICC ≥ 0.4 → 训练在固定置信度下改变仲裁规则，这就是解释空缺；下一步 E78 找驱动它的数据与阶段，E79 找机制。
- 介于两者之间 → 如实报告，用残差挖掘决定下一步，不追加条件。
- R3：如果能力 u 早早饱和而采信继续变化 → 能力与策略在发育上分离（替代已作废的 E24 解读）。

## 补充（2026-10-10 13:55；只看了 3 个冒烟模型的终点结果，发育轨迹与其余 274 个检查点都还没有结果）
- **发现的测量问题：** 原读数“能力 u”与置信度相关。虚构主语的无上下文边际 n0 反映答案本身的先验（常见程度），而有上下文时模型几乎照抄，覆盖了这个先验，所以 u 随答案先验升高。u 不能当作与记忆无关的“上下文推动”来做相加基线。
- **改用的主读数（登记于看到发育结果之前）：**
  - 主语特定知识 k = c − n0（真实主语与虚构主语在无上下文时的边际之差）。
  - 有上下文时剩下的记忆 d = m_ctx(真实) − m_ctx(虚构)（同一个冲突上下文、同一对候选）。
  - **记忆存活系数 γ** = d 对 k 的斜率（分箱曲线 + 线性）。γ = 1：记忆与上下文相加；γ = 0：上下文完全覆盖记忆。同样定义先验存活系数 γ0 = m_ctx(虚构) 对 n0 的斜率。
  - 3 个冒烟模型（DataDecide-1B dolma1_7、OLMo-2-1B stage1 终点、Pythia-410M 终点）：γ = 0.60 / 0.65 / 0.61（陈述格式），0.60 / 0.66 / 0.56（问答格式）；γ0 = 0.46–0.49；分箱曲线是凸的（k < 1.5 时斜率约 0.25，k > 5 时约 0.7）。这是探索证据，结论必须在其余检查点上确认。
- **新的 R1：** 把发育中平均 d 的变化分解为“k 增长”（沿固定的 d–k 曲线移动）与“曲线改变”（γ 或截距变化）。
- **决策表补充：** γ 在训练中基本不变（首末差 < seed 间差的 2 倍）→ “规则固定，训练只增加知识”；γ 单调上升 → 训练改变了记忆在上下文面前的存活率（Kim et al. 的“偏向记忆”至少部分是规则改变，而不只是知道得更多），下一步找驱动它的数据与机制；格式或 Flan 改变 γ 还是截距，按同样的方法分解。
- 衰减偏差：k 有测量误差会使 γ 偏小。用问答格式的置信度 c_qa 作为工具变量估计一个校正版的 γ，两个都报告。

## 补充 2（2026-10-10 14:30；已看到 21 个检查点：OLMo-2 stage1 210B / 4T + stage2 全轨迹、Pythia-160M step 1000 / 2000 / 143000、Pythia-410M 终点、DataDecide-1B 9 个终点）
- **探索证据：**
  1. OLMo 2 从 210B token 到中期训练结束，γ（陈述格式）0.62–0.65，γ0 0.45–0.48，几乎不变。
  2. 中期训练的问答格式效应（问答 − 陈述 采信）−0.40 → 1.13 → 3.04 → 3.58 → 2.65 → 2.86，在新条目集上复现了 E30 的先升后降；但它**几乎完全落在虚构主语的上下文推动上**（问答 − 陈述 推动 −0.93 → −2.74 → −3.37 → −2.56），存活的记忆 d_qa 基本不变。
  3. Pythia-160M：step 1000 / 2000 时 γ = 0.93 / 0.90（工具变量版 0.98 / 0.94），终点为 0.41（0.57）。9 个 DataDecide-1B 终点（3 个配方 × 3 个 seed）γ 为 0.55–0.64。
- **由此形成的假说 H-dev（下面的预测在其余检查点上检验，那些检查点现在都还没有结果）：** 训练早期，记忆与上下文在 log-odds 上近似相加（γ ≈ 1）；随后模型学会在上下文给出答案时部分压低自己的回忆，γ 降到约 0.6 后稳定，跨家族、配方、中期训练不变；格式或指令数据改变的是与主语无关的“照抄推动”，不改变 γ。
- **预测：**
  - P1：每个家族第一个 k_mean > 0.5 的检查点 γ ≥ 0.85；到训练 20% 时 ≤ 0.75；之后稳定在 [0.5, 0.75]。在 DataDecide 4 个配方 × 3 个 seed、Pythia 410M / 1.4B / 2.8B / 6.9B、OLMo stage1 step 300 / 10000 / 30000 上检验。
  - P2：DataDecide Flan 与无 Flan 的终点 γ 差 < seed 标准差的 2 倍；问答格式推动的差 > 2 倍。
  - P3：后训练（SFT / DPO / Instruct）是改变推动还是改变 γ，事先不做预测。
  - **判定：** P1 在 DataDecide 或 OLMo 上不成立 → “相加 → 折扣”只是 Pythia 的特性，H-dev 撤回；P2 不成立 → 格式 / 数据也会改变兑换率，H-dev 的第二部分撤回。
- **与 Kim et al. 的关系（待检验）：** 他们在 Pythia 中看到训练中越来越偏向记忆。H-dev 预测这一偏移来自知识增长（沿曲线移动），而曲线本身朝上下文方向移动（γ 下降），两者方向相反。用 R1 分解检验。

## 结果（跑完后填写；不改上面的内容，修改需注明日期）

### 中期判定（2026-10-10 15:05；54 / 272 个检查点；按补充 2 登记的判据）
- **P1 按原文不成立。** 要求“第一个 k_mean > 0.5 的检查点 γ ≥ 0.85”：Pythia-160M 0.93、Pythia-410M 0.87 满足；DataDecide-1B dolma1_7 default（第一个检查点 step 2500，k 1.93）为 0.72，OLMo-2 stage1（第一个有知识的检查点 21B token）为 0.74，都不满足。按登记的判定，“早期相加（γ ≈ 1）”不能作为一般规律，H-dev 的这一部分撤回。（这两个家族的第一个检查点比 Pythia 晚，这一点是事后解释，不改判定。）
- 仍然成立、且三个家族一致的部分：γ 随训练下降并收敛到 0.60–0.65（Pythia-410M 0.87 → 0.61 单调下降；DataDecide 0.72 → 0.60；OLMo 0.74 → 0.65 后持平）。
- **新的测量威胁（E79 扩展版，Pythia-160M）：** 只看答案第一个 token 时，γ 在 step 1000 / 2000 / 143000 分别为 0.66 / 0.73 / 0.56，早期并不接近 1。E77 的 γ 用的是整个答案的 log 概率之和，早期接近 1 可能来自答案后续 token（名字补全）而不是第一个 token 上的取舍。后续必须把第一个 token 与后续 token 分开报告。
- R1 分解（首末检查点）：沿曲线移动 Pythia-160M +1.82、410M +2.00、DataDecide +1.40、OLMo +1.35；曲线改变 −0.67 / +0.83 / −0.35 / +2.06（OLMo 的起点 step 300 几乎没有知识，不可靠）。知识增长解释了大部分“偏向记忆”的变化；曲线本身的变化方向不一致。
