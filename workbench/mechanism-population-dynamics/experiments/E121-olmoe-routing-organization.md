# E121：OLMoE 中是否存在超出 token 身份与几何零假设的语言组织，以及专家之间是否真有差异（只推理）（2026-10-23）

- **状态：** DONE（2026-10-23 23:30）
- **类型：** EXPLORE（整体测量；回答“研究对象是否存在”）
- **对应：** MoE 方向的探索第 1 步。人 10-23 授权，只推理、不训练。
- **问题（一句话）：** 在一个充分训练的公开 MoE（OLMoE-1B-7B）里：
  1. 同一个 token 的路由是否随上下文变化；
  2. 这种变化是否与语言区分（词性、词义）对应，并且超出几何零假设；
  3. 被选中的专家与候补专家之间，是否存在有条件选择性的计算差异？

## 设置
- **模型：**
  - `allenai/OLMoE-1B-7B-0924`：16 层，每层 64 个专家，top-8，softmax 后取 top-k、不再归一化，路由器无偏置；
  - 主检查点 `main`；R4 另用 `step5000-tokens20B`、`step100000-tokens419B`、`step600000-tokens2516B`；
  - bf16 推理，路由与零假设计算用 fp32。
- **语言条件（自然语料，只取左上下文）：**
  - **词性（主）：** UD English EWT（train + dev + test）中同一词形、在 OLMoE 分词下是单个 token（带前导空格）、名词与动词用法各 ≥ 10 次的词。共 55 个，如 work / call / help / change / use / order。每个词每种词性最多 25 次。
    - 输入 = 同一文档中目标词之前的文本（最多 128 个 token）加上目标词，读取目标词位置。
    - 词性多半由左侧语法环境决定（the run vs to run），左上下文问题较小。
  - **词义（副）：** SemCor（brown1 + brown2）中同一词形、同一词性（名词）、≥ 2 个 WordNet 义项各 ≥ 10 次的单 token 词。左上下文同上。
    - **局限：** 词义可能由右侧才消歧。所以词义条件得到阴性结果时不解释为“没有语义路由”。
- **随机性：** 样本选择用固定种子；按句子划分校准半与留出半。

## 读数
- **R1 上下文依赖（标定）：** 每层对同一词形的不同出现，计算两两 top-8 共路由 C 的均值。1 − C̄ 为“切换率”；完全由 token ID 决定时为 0。另报同一词形、同一词性的切换率。
- **R2 语言组织：**
  - 原始量：同一词形的输入对中，δ = E[C | 同词性] − E[C | 异词性]；
  - 残差量：δ_D = E[D | 同] − E[D | 异]，D = C − B，B 用 E120 中通过检验的零假设（预期用 N2）。零假设在每层、用该层校准集上的路由输入拟合。
  - **推断：** 在词形内打乱词性标签作置换检验；按词形做聚类 bootstrap 求 CI。
  - 词义条件同样计算。
- **R3 专家差异（在词性条件的目标位置，下一 token NLL）：**
  - (a) **候补顶替：** 把该位置的第 r 名专家（r = 1，也做 r = 4）换成第 9 名，保持原门控权重，得到 ΔNLL，即 A。
  - (b) **随机未选专家顶替：** 作对照。
  - (c) **均值钳制：** 把该专家输出换成它在校准集上被路由时的平均输出。
  - **差异量：** A 的均值与分布（专家完全相同时 A = 0）。
  - **选择性 Γ：** 按校准半估计每个专家的“名词偏好” P(名词 | 该专家为 top-1)；在留出半上比较“顶替者与原专家偏好相反”与“偏好相同”时的 A 之差。
  - **稳定性：** 校准半 / 留出半各自估计每层 A 均值与 Γ，看两者是否一致（汇总量的抽样稳定性，不是逐对拆半）。
- **R4 同一 run 内的边界稳定性（参照基准）：** 在固定的 600 个锚点输入（词性条件的留出半）上，计算各检查点的残差 D（每个检查点用自己的零假设），再算检查点之间 D 的相关 T。这是以后跨种子比较的“同一 run 内”参照。

## 阳性对照
- R1 / R2：层 0 的切换率应接近 0（路由输入几乎只含 embedding 与一层注意力）；若层 0 已经很高，先检查实现。
- R3：把被选专家换成同一个专家（自身顶替），ΔNLL 必须为 0（实现检查）；把 top-1 专家整体去掉（门控置 0），ΔNLL 应大于 0。
- 零假设：用 E120 的结论；在 OLMoE 上额外检查负载匹配误差。

## 噪声地板 + MIE
- **R2：** 置换零分布的 95% 区间；词形聚类 bootstrap 的 CI。只有 CI 不含 0、且 δ_D 至少达到 δ 的 20%，才说“超出零假设的组织”。
- **R3：** 校准半 / 留出半之间的差值作为抽样噪声；A 的均值需超过两半差值的 2 倍，并在两半同号。
- **R4：** 只作描述性参照，不作结论门槛。

## 混杂审计
- **频率与位置：** 同一词形内比较，自动控制词频；对位置（目标词在序列中的序号）分档报告。
- **词性与主题、文体混杂：** EWT 混有邮件、评论、博客；同一词形的名词 / 动词用法可能来自不同文体。按文体分层报告，未完全控制。
- **零假设依赖：** R2 的残差依赖零假设族，同时报告 N1 与 N2（若 E120 判 N1 不适合跨模型比较，这里仍可作单模型内的参照）。
- **R3 的分布外问题：** 候补顶替本身可能把输入送到没训练过的专家。同时报告第 9 名与随机未选专家，并看效应随名次的变化。

## 决策表（跑之前写）
- **R1 各层切换率都接近 0** → 这个模型的路由近乎由 token 身份决定，“上下文组织”在 OLMoE 上不存在；MoE 组织问题只能在 token 层面讨论，C2 大幅降级。
- **R2：**
  - 某些层 δ_D 显著 > 0 → 存在超出几何零假设的语言组织，记录在哪些层，作为跨训练比较的对象；
  - δ > 0 但 δ_D ≈ 0 → 词性区分完全由“同一几何上的随机切分”就能产生，学到的路由在这一区分上没有额外组织。
- **R3：**
  - A 稳定 > 0 且两半一致 → 专家之间确有计算差异；Γ > 0 → 差异与词性对应；
  - A ≈ 0 而均值钳制 > 0 → 在这些位置专家近似可互换，“功能分工”在此不成立，转向只研究组织层面，或换别的语言条件。
- **R4：**
  - main 与 step600000 的 D 相关很低（< 0.5）→ 边界在训练后期仍在移动，以后的跨种子 T 必须相对这个基线解释；
  - 很高 → 后期边界稳定。

### 结果（2026-10-23 23:30；OLMoE-1B-7B-0924；`results/e121/r12_main_N1.json`、`r3_summary.json`、`r4_N1.json`；原始数组在 `~/mechpop_cache/e121/`）
- **样本：**
  - 词性：48 个词形，1,904 个样本（校准 940 / 留出 964）；
  - 词义：211 个名词词形，9,279 个样本；
  - 零假设校准用 66,804 个随机位置；
  - 零假设负载匹配总变差距离 ≤ 0.0004。
- **实现检查：** 采集到的路由与模型自身输出的路由 logit 一致（第 0 / 1 / 8 / 15 层 top-8 吻合率 1.00 / 0.99 / 1.00 / 0.98）。

**R1 上下文依赖：同一个 token 在不同上下文中大量切换专家，第 0 层也一样。**
- 词性词：切换率 0.48–0.68（同一词性内 0.35–0.62）；
- 词义名词：0.33–0.63。
- **事先写的阳性对照预期“第 0 层接近 0”不成立。** 实现检查已通过，所以这是我的预期错了：OLMoE 第 0 层的路由输入已经过一层注意力，并且强烈依赖上下文。

**R2 语言组织（N1 残差；括号内为词形聚类 bootstrap 95% CI；置换检验 p 全部 < 0.001，除另注）：**

| 层 | 词性 原始 δ | 词性 残差 δ_D | 残差 / 原始 | 词义 原始 δ | 词义 残差 δ_D |
|---|---|---|---|---|---|
| 0 | 0.113 | +0.009（0.001, 0.016） | 0.08 | 0.060 | +0.017 |
| 1–2 | 0.18–0.23 | +0.046 – +0.067 | 0.26–0.30 | 0.05–0.06 | ≈ 0（p 0.4 / 0.001） |
| 3–4 | 0.25–0.28 | +0.109 – +0.136 | 0.44–0.49 | 0.08–0.09 | +0.009 – +0.021 |
| 5–7 | 0.15–0.20 | +0.040 – +0.060 | 0.27–0.34 | 0.10–0.12 | **+0.025 – +0.035** |
| 8–10 | 0.29–0.40 | **+0.142 – +0.207**（第 9 层最大） | 0.47–0.53 | 0.06–0.08 | +0.006 – +0.013；第 10 层 −0.005 |
| 11–13 | 0.32–0.35 | +0.135 – +0.155 | 0.42–0.48 | 0.05 | **−0.008 – −0.011**（CI 不含 0） |
| 14–15 | 0.24–0.29 | +0.101 – +0.134 | 0.41–0.46 | 0.06–0.07 | ≈ 0 / +0.010 |

- **词性：** 16 层残差全部显著为正，约为原始效应的一半，第 3–4 层与第 8–13 层最强。
- **词义：**
  - 原始效应处处为正，但大部分可由几何零假设解释；
  - 学到的路由只在中层（第 4–8 层）额外增加一点词义组织；
  - 在第 11–13 层，反而比零假设更多地把不同词义放在一起。
  - 词义可能在右侧才消歧，所以阴性部分不解释为“没有语义路由”。

**R3 专家差异（词性目标位置；下一 token 分布的 KL 与 ΔNLL）：**
- **数值噪声地板：** 自身顶替的平均 KL ≈ 1×10⁻⁵，平均 |ΔNLL| ≈ 5×10⁻⁴。最大 0.075 来自基线与干预批次的填充长度不同（bf16），不影响结论；卡里“自身顶替必须为 0”的检查只在数值噪声范围内成立。
- **候补顶替（第 1 名换成第 9 名）：**
  - KL 是噪声的 680–2,930 倍；90–99% 的样本超出自身顶替 KL 的 95% 分位；
  - ΔNLL 为 +0.007 – +0.033 nats；
  - 是“直接去掉该专家”的 1.10–1.42 倍。换进候补专家比什么都不放还更糟，说明专家之间差异很大。
  - 校准半与留出半在各层的均值相关 0.93。
  - 随机未选专家顶替与第 9 名相近；第 4 名换第 9 名的效应约为第 1 名的 1/3。
- **选择性 Γ（顶替者与原专家的名词偏好相反 vs 相同；偏好已按词形去均值、在校准半估计）：** 13 / 16 层 CI 含 0；第 4 层为负，第 9、14 层为小的正值；“KL 与偏好差距”的 Spearman ≈ 0。
- **结论：** 专家之间确实存在大的计算差异，但这种差异不沿“名词 / 动词偏好”这条轴组织。

- **深层与浅层不对称：**
  - 深层（第 9–13 层）在训练约 0.4% 时形成的组织，与终点组织的相关已达 0.5–0.6，后期也稳定（约 0.8）；
  - 浅层（第 0–1 层）在训练中几乎完全重组（0.02），到后期仍在移动（约 0.5）。
  - 与 FLAME-MoE 的“深层更早饱和”（指 top-k 分配稳定性）方向一致；这里测的是扣除几何零假设之后的组织。

**按决策表：**
- **R1** 不接近 0 → 上下文组织存在，C2 不降级。
- **R2：** 词性组织超出几何零假设，在所有层都显著，是跨训练比较的对象；词义组织大多是几何的被动结果。
- **R3：** 候补顶替稳定为正、两半一致 → 专家之间确有计算差异；Γ ≈ 0 → 差异不沿词性组织。
- **R4：** 终点 vs 600k 在所有层 ≥ 0.50，深层约 0.8 → 后期组织较稳定，浅层仍在移动。以后跨种子比较的 T，要分层与这个同一 run 内的区间对照。

**局限：**
- 只有一个模型；
- EWT 中名词 / 动词用法的文体分布不同，未完全控制；
- 只用了 N1 零假设；
- 检查点之间的表示会变（E120 S6 显示 N1 对重参数化近似稳健，下降 1–3%）；
- Γ 只用了“top-1 名词偏好”这一种定义。

**POST-HOC（看到结果后才想到的，单独标注）：**
1. 路由组织（R2：同词性更常同路由）与专家差异（R3：差异不沿词性）之间的脱节，可能符合“叠加专精”：路由把同词性的上下文聚到一起，但每个专家同时处理多种特征，所以顶替的损伤不按词性分化。要检验需要逐样本把 R2 与 R3 联系起来，尚未做。
2. R4 的深浅不对称暗示：跨种子比较时，深层可能是“早期决定、之后锁定”的部分，浅层是“持续重组”的部分。这是分叉实验（C4 / C5）的一个具体预测对象。
