# E226：旧绑定留着还是换掉——问法前提校准后重测，并加同实验室的写入规则对照（2026-11-25）

- **状态：** PLANNED（11-25 写定，在任何 E226 运行之前）
- **类型：** PILOT（候选 X 的决定性试测；不推进主张；锁题由人决定，R2）
- **对应：** [TOPIC_SEARCH.md](../TOPIC_SEARCH.md) 候选 X；前置 [E224](E224-binding-overwrite-competence-gate.md)、[E225](E225-keep-or-replace-outdated-binding.md)。

## 为什么做（给外人看的版本）

E225 里，注意力模型 Qwen3-8B 被问“某人一开始在哪”时全对，说明它**留着**旧绑定。两个循环模型对“一开始”这种问法本身理解不稳（没有任何变化时也只答对 73–77%），按规则签名读不出。但事后看到：RWKV-7（delta 规则）被问原位置时 74% 答成新位置，没被改的人不受影响，像是按键**换掉**；Falcon-Mamba（加法规则）的错则串到别人身上。

这一次只做两件事：
1. **修读数前提。** 先只在“没有变化”的对照上为每个模型挑一种它听得懂的问法，挑定后再用新题测关键条件。挑问法的规则写在跑之前，挑的时候看不到关键条件。
2. **加关键对照。** RWKV-6 和 RWKV-7 出自同一实验室、用同一系列 World 语料训练，主要差别是写入规则：RWKV-6 是加法叠加（带数据相关衰减的外积），RWKV-7 是广义 delta 规则（先按键移除再写入）。如果“换掉”只出现在 RWKV-7、不出现在 RWKV-6，就不能说成只是某个模型家族或数据的特点。另外每类记忆配第二个模型，看签名是不是这一类共有。

## 设置

- **模型（6 个）：**
  - 注意力：`Qwen/Qwen3-8B-Base`、`allenai/Olmo-3-1025-7B`。
  - 加法规则循环：`tiiuae/falcon-mamba-7b`（Mamba-1）、`RWKV/v6-Finch-3B-HF`（RWKV-6）。
  - delta 规则循环：`RWKV/RWKV7-Goose-World3-2.9B-HF`、`RWKV/RWKV7-Goose-World3-1.5B-HF`。
  - RWKV-6 与 RWKV-7 的语料版本不完全相同（World v2.1 vs v3），如实记录。
- **任务：** 与 E225 相同的叙述格式（三个人、一个变化事件、一条无关新人的绑定；N∈{0,1,2}）。
- **第一步：问法校准（新题，种子 9226，每种问法 100 题，只用 N=0 的 orig(T)）。** 候选问法 4 种，示例里用同一种问法（示例仍然没有任何变化事件）：
  - W1 `Where was X at the beginning?`
  - W2 `Where was X first?`
  - W3 `Where was X originally?`
  - W4 `Where was X at the start of the story?`
  - 规则：每个模型取 N0 准确率最高的问法；并列取编号小的；最高的也 < 0.9 → 该模型排除，签名记为“读不出”。
- **第二步：关键条件（新题，种子 226，每格 150 题）：** 与 E225 相同的 7 格（N1、N2 × cur(T)、orig(T)、orig(O)，加 N0 orig(T)），orig 查询用第一步选定的问法，cur 查询仍是 `Where is X now?`。
- **打分与错误类型：** 与 E225 相同。
- **命令：** `scripts/e226_keep_replace_calibrated.py`。

## 读数与签名判定（沿用 E225，不改）

“明显低于”= 差值 ≥ 0.15 且 bootstrap 95% 区间不含 0。

| 结果 | 签名 |
|---|---|
| orig(T \| N≥1) 明显低于 orig(T \| N0) 和 orig(O)，cur(T) 高 | 换掉 |
| orig(T \| N≥1) 与 orig(O) 一起明显下降 | 全局衰减 |
| orig(T \| N≥1) 不明显低于参照 | 留着 |

另记“换掉”的错误类型是否以新位置为主（第二把尺子）。

## 混杂审计（只列相关项）

- 写入规则与语料版本、规模：RWKV-6 3B 与 RWKV-7 2.9B 规模相近、同实验室同系列语料，是本卡最接近受控的一对；其余跨家族对比只看签名是否一致，不比高低。
- 问法：第一步只看 N0，挑定后在新题上测关键条件，挑问法时看不到关键条件。
- 不同模型可能用不同问法：签名是模型内对比（同一问法下的 N0 / N1 / 没被改者），不跨模型比幅度。
- RWKV 的 HF 实现：fla 的 RWKV-7 实现带作者警告（建议与官方仓库交叉核对）；本卡的结论以定性签名为准，若 RWKV-7 结果决定题目走向，后续须用官方实现复核一次。
