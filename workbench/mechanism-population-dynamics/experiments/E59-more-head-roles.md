# E59：更多头角色——“初始化选槽位”是否适用于所有类型的头？（2026-10-03）

- **状态：** RUNNING（单模型测试中）
- **对应：** C05（广度：E35 / E45 只覆盖 induction、previous-token、检索、sink）
- **问题：** 在 DataDecide 1B 的 3 初始化 × 25 语料（E35 的 75 个模型）中，其他常见的头角色是否同样由初始化决定位置、数据分量为 0？包括一个完全不依赖注意力模式、只用权重计算的角色指标。
- **新角色图（`scripts/e59_roles.py`）：**
  - R1 duplicate-token：随机序列重复时，第二次出现的 token 对第一次出现位置的注意力；
  - R2 当前 token：自然文本上对自身位置的注意力；
  - R3 前 2 个 token：自然文本上对 t − 2 的注意力；
  - R4 分隔符：自然文本上对标点 / 换行的注意力总量（不含位置 0）；
  - R5 OV 复制分数（只看权重）：完整 OV 回路 W_U·W_O·W_V·W_E 的特征值实部之和 / 模之和（Elhage et al. 2021），含 RMSNorm 增益。
- **读数：** 与 E35 / E45 相同：层内 SI、SD、DD 与 SI − SD（配方 bootstrap CI）；层轮廓相似度；R2–R4 有拆半信度。
- **阳性对照：** R2–R4 拆半信度 ≥ 0.8；R5 在 induction 头所在层应有正的复制分数（induction 头是复制头）。
- **怎么读：** 各角色层内 SI 显著 > SD ≈ 0 → “初始化选槽位”覆盖全部角色，写成决定因素地图的一般规律；某个角色不成立 → 作为例外写入地图（例如该角色在层内本来就没有专门化）。
- **算力：** 75 个 1B 模型，每个约 2–3 分钟，在自己已占用的卡上运行。
