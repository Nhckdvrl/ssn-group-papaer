# E89：重新训练后，头之间的“分工”是否重现？——以置换不变的多任务因果图谱来测（2026-10-15）

- **状态：** RUNNING（2026-10-15 重启；用户明确要求继续实验推进，授权见当日 logs）
- **类型：** EXPLORE → CLAIM（整体测量先行，再从残差里找问题；不是单一 yes/no pilot）
- **对应：** 导师的问题（“各头承担什么功能、功能分工在不同训练间是否一致”）；E72（注意力角色可对齐，但只有约 2.5 个有效维度）；E75/E81/E83（IOI 承担者在同功能类内换头）；Merullo 2024（单模型内跨任务复用）；Bali 2026（注意力最佳匹配稳定性）；Xu 2026（arXiv:2606.05378，注意力选择性≠任务因果结构，跨架构）。

## 为什么换测量对象

过去的读数都是“某个编号的头”或“某个任务的 top-k 承担者”。头编号受同层置换对称性支配；单任务的主力承担者又是近似平局（零 GPU 复核 E83：1B 上 IOI 的 80% 正 DLA 要 9–15 个头，top1/top2 常接近；A 的主力头在同 seed 兄弟中排名中位 49/256，异 seed 44/256——共享初始化对承担者毫无帮助）。所以“哪个头”不是好对象。

**分工**本身是另一个对象：同一层内，哪些任务由同一些头共同承担、哪些任务分开承担。若对一层内所有头做同一个置换，所有任务的头图一起重排，“任务×任务共享矩阵”不变。它天然是置换不变的，可以直接跨独立初始化比较，不需要先对齐编号。

## 问题（一句话）

在相同架构、相同数据、不同随机种子的重新训练之间，(i) 每个任务的因果负载按层的分布、(ii) 层内哪些任务共用同一些头（任务共享结构）、(iii) 一个头在多任务上的“功能组合”能否跨模型对上——分别重现到什么程度？以同模型拆半的测量上限为满分，以层分布/随机重组为零点。

## 设置

- **任务（9 个，均为单 token 对比度量，最后位置 logsumexp(目标) − logsumexp(对照)）：** IOI、随机 token induction、greater-than（年份）、主谓一致（含干扰名词）、性别代词、首都（事实）、序列后继（星期/月份/数词）、反义词 ICL、不规则过去式 ICL（对照 = 照抄原词）。colored-objects 式绑定在 410M 上为随机水平，已剔除（2026-10-15 冒烟）。
- **每个头、每个提示两种因果读数：** `end` 只在最后位置把该头的 z 换成同组均值；`all` 在所有位置换成按位置匹配的同组均值（组 = 同模板同 token 长度）。均值消融去掉提示特有信息、保留位置/模板信息。
- **拆半：** 按条目（名字对、国家、动词等）分两半，避免同一条目同时出现在两半而抬高信度。
- 另存 E81 的通用注意力角色（induction、previous-token）作对照。
- 脚本：`scripts/e89_labor.py`；结果 `results/e89/`（npz 只在本地，不进 git）。

## 读数（预先登记）

- **R1 层分布：** 每个任务按层汇总的 |效应| 分布，跨种子相关。（预期很高；作为“已知的普适部分”的基线。）
- **R2 任务共享结构：** 每个模型、每个任务的头图先在层内去均值（去掉层分布），再算任务×任务相关矩阵 S（只用 all 读数为主、end 为辅）。读数 = 两个模型 S 的非对角元素相关。**满分** = 同一模型两半各自算 S 之间的相关（测量上限）；**零点** = 任务标签打乱。另报不去层均值的 S。
- **R3 头的功能组合能否跨模型对上（留一任务）：** 用 8 个任务的因果剖面（拆半的一半）在每层用匈牙利算法对齐两个模型的头，在另一半上预测被留出任务的层内头图（Spearman）与 top-3 头。对照：原编号；随机置换；E72 式只用注意力角色对齐；同模型拆半上限；用留出任务本身对齐（目标辅助上界）。
- **R4 专精/通才：** 每个头显著承担的任务数分布（显著 = 超过两半一致的阈值），以及这一分布跨种子是否相同。

## 阳性对照与噪声地板

- 每个任务在每个模型上 clean 度量 > 1 且正确率 > 0.7，否则该模型该任务剔除（如实列出）。
- 每个任务头图的拆半信度（Spearman-Brown 后）≥ 0.6 才进入 R2/R3；不达标的任务单列。
- 零点：任务标签打乱（R2）、随机置换（R3）。

## 决策表（看结果前写）

- **A. 分工重现：** R2 跨种子 ≥ 拆半上限的 0.7 倍，且 R3 留一任务对齐预测 ≥ 上限的 0.5 倍、显著高于只用注意力角色对齐 → “头的编号是任意的，但任务在头之间的捆绑方式（谁和谁共用头）随重新训练重现”。这是导师问题的正面回答，且有满分/零点刻度。下一步：哪些任务对的共享最稳定、为什么（共享的是哪一类计算），并上 DataDecide 看语料能否改变捆绑。
- **B. 分工重组：** 每个任务的层分布重现（R1 高），但 R2 接近零点、R3 只略高于随机 → “每个任务的计算在各模型中都在相同深度出现，但任务之间怎么分摊到头上是每次训练重新决定的”。下一步：挑跨种子最不一致的任务对，看是同一计算换了组合还是用了不同路线（GPT 建议的路径级追查）。
- **C. 部分重现：** 介于两者之间 → 按任务对拆开报告，找出稳定与不稳定的任务对各有什么共同点，再定下一步（不追加设定）。
- 160M 的 weight-seed / data-seed 只在 A 或 C 时用于问“捆绑由初始化还是数据顺序决定”。

## 结果（跑完后填写；不改上面的内容，修改需注明日期）

### 2026-10-15 16:10 冒烟与口径修改（POST-HOC，看到 5 个 410M 种子后）
- 冒烟：410M 单模型约 8 分钟（A100 上含下载约 15 分钟）；各任务头图拆半信度 0.90–1.00；单模型任务共享矩阵拆半相关 0.82（层内 z 口径）。DataDecide-1B（CPU 冒烟，n = 64）除反义词（0.79）外各任务度量 1.8–7.8。
- **登记口径失效的原因：** 原始数据显示，跨种子功能对应的头**不在同一层**（同时承担 induction / 反义词 ICL / 后继的早层枢纽头：原版 5.2、seed1 5.4、seed2 4.14、seed4 6.4；seed3 整个组织整体更深，induction 主力在 19 层）。层内置换（E72 与本卡 R3 的做法）和层内去均值（R1/R2）因此看不到这种对应，R1 用 Pearson 也被单个峰值层主导（induction 跨种子 0.04）。
- **改为跨层口径（`scripts/e89_analyze2.py`）：** 深度 = 每个任务 |效应| 的层重心，读数为任务深度顺序的 Kendall τ；共享结构 S 用全局标准化（不去层均值）；“枢纽”= 两个任务的 top-3 头是否有重合；对齐改为跨层匈牙利匹配（同时报告层内匹配作对照）。原 R1–R3 结果仍保留在 `results/e89/prelim_410m.json`。
- 合格任务改为逐模型判定（clean 度量 > 0.5），比较只用两模型都合格的任务；种子间能力本身有差异（seed4 首都 0.09、反义词 −2.18；seed3 反义词 −0.13、过去式 −0.42），这是需要解释的现象，不是噪声。

### 结果一（2026-10-15 16:00；Pythia-410M 10 个独立种子全齐；160M 15/16；`results/e89/analysis2_410m.json`、`prelim2_160m.json`）
- **能力本身随种子变：** 410M 反义词 ICL 在 seed3/4/8 失败（−0.13 / −2.18 / −0.09，其余 0.57–2.08）；seed4 首都 0.09、IOI 0.89。160M 所有模型反义词都失败（无此能力）。
- **任务深度顺序重现：** 410M 任务层重心的顺序跨种子 Kendall τ 中位 0.73（10–90%：0.60–0.89）；160M 0.87。顺序一致：induction / 反义词 / 后继 / greater-than / 过去式在 8–10 层，IOI 11–13 层，性别 / 主谓一致 / 首都 13–17 层。seed3 整体深 4–6 层但顺序不变。
- **任务共享结构部分重现：** S（全局标准化、跨层）跨种子相关 410M 中位 0.57（10–90%：0.08–0.81），满分（同模型拆半）0.95，任务标签打乱 95% 分位 0.38；160M 0.77 / 0.98 / 0.46。
- **共用关键头的任务对跨种子一致（top-3 有重合的种子比例；随机约 2%）：** 410M：greater-than~后继 10/10、反义词~induction 7/7、反义词~后继 7/7、induction~后继 9/10、induction~IOI 7/10；性别~主谓一致 5/10；首都与任何任务 0。160M：greater-than~后继 14/14、induction~IOI 15/15。
- **共用的是什么头（410M，逐种子核对）：** (i) 9/10 个种子里 induction 与反义词 ICL 的第一承担头是同一个头，且它是该模型 previous-token 分数第 1（个别第 2–3）的早层头（4–7 层，prev 0.70–0.85），作用在上游位置（只在最后位置消融时效应占 0–24%）；(ii) 7/10 个种子里 greater-than 与后继的第一承担头是同一个 10–13 层的头，作用在最后位置（占 87–103%），它不是 induction / previous-token 头；另 2 个种子在 top-3 内共用。
- **例外：** seed3 没有这样的早层 previous-token 瓶颈，induction 主力是 19.2（induction 分数 0.92、作用在最后位置），其各任务都更深；它同时是反义词 ICL 与过去式 ICL 都失败的种子。（只有一个例外，只作线索。）
- **逐头对应仍然对不上：** 用其余任务的因果剖面跨层匹配后预测留出任务的头图，相关 0.00–0.27（满分 0.77–0.997）；第一承担头命中目标 top-3 的比例 0.03–0.38（随机 0.008）。命中较高的正是共享关键头的任务（greater-than 0.38、后继 0.26、反义词/induction 0.24）。层内匹配（E72 做法）普遍更低。
- **阶段判断（agent 决策）：** 介于决策表 A 与 C 之间——“分工”的可重现部分是**任务×任务的共用关系**（哪些计算装进同一个关键头）和**任务深度顺序**，不是头编号、层号或其余大量弱头。下一步：(1) DataDecide-1B 已排队，检验语料能否改变这一共用关系；(2) 160M weight-seed / data-seed 拆分初始化与数据顺序；(3) 对“共用关键头”做因果检验（同时消融/修补该头对两个任务的连带后果，而不是只看 top-k 重合）；(4) 用 seed3 式的“替代组织”检查组织差异是否对应能力差异（需要更多例外样本，不凭单例下结论）。
