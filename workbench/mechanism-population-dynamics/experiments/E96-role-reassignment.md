# E96：训练中一个头靠什么保住 / 夺回自己的角色？——QK、OV、空缺的拆分（2026-10-16）

- **状态：** RUNNING（09:27 起，8 个分组，白天 8 卡）
- **类型：** CLAIM / EXPLORE（因果的训练期干预；设置沿用 E93 校准：Pythia-160M step100k，SDPA + fp32，batch 128 × 1024，学习率 2e-5，warm-up 200，1500 步；对照沿用 E93 的 C_lo）
- **来源：** E93：重置 previous-token 枢纽 3.2（previous-token 0.85，induction 消融 −12.2）后，3.2 自己 1500 步内不恢复，由已有的次级 previous-token 头 3.0（0.54）在几十步内接管；重置 3.2 与 3.0 则由 1.2 接管。→ 角色分配像“先占先得、空缺才补位”。这与工作台最初的问题（训练中哪个头承担哪个功能、为何跨种子编号不同而分工可重现，E89）直接相关，但这里是同一 run 内的因果干预，编号有意义。
- **最近邻：** Singh et al. ICML 2024（训练期钳制子回路、多对多的 previous-token / induction 关系）；Hapax（重初始化 induction 头后长出更多 induction 头；重置这些头的优化器状态则卡住）；Frozen-QK 2025（QK 不训练也能形成 induction）；McGrath 2023 / Rushing & Nanda 2024（推理时的自修复 / backup 头）。**未见**把“角色保持 / 夺回”拆到 QK、OV 与空缺上的训练期实验。

## 分组（备份 = 3.0、1.2、7.7，E89 中 previous-token 分数次高的三个头；“清零”= 把输出投影列置零并在每步后保持为零）

## 预测与决策表（看结果前写）
- **输出写入是锚：** QK32_ko 中 3.2 的 previous-token 分数恢复（≥ 0.6），而 ALL32_ko 中功能落到别的头 → “下游读的是谁，谁就重新长出这个角色”；若 QK32（不清零）也在原位恢复 → 锚定足以压过已有备份。
- **注意力模式是锚：** OV32_ko 中 3.2 重新被 induction 头读取（K-组合回到前列）而 QK32_ko 不恢复 → 角色由“看哪里”锚定。
- **只有空缺起作用：** 不清零时（QK32 / OV32）都由 3.0 接管、3.2 不恢复；清零时无论保留哪一半 3.2 都恢复 → “空缺才补位”，与保留部分无关。
- **新持有者是否确定：** ALL32_ko 与 ALL32_ko_s2 落到同一个头 → 由现有网络结构决定；不同 → 有随机性。
- 1500 步内若清零各组的 induction 都没有恢复到对照的 80% → 时间窗太短，加长后再判。

## 中间结果（2026-10-16 09:45，200–400 步；与 E93 C_lo 配对）
- **QK32（重置 QK、保留输出写入，有备份）：** 3.2 的 previous-token 注意力不恢复（0.03 → 0.04）；备份 3.0 增强（0.54 → 0.73）；induction 100 步回到 0.94。
- **OV32（重置 OV、保留注意力模式，有备份）：** 3.2 一直正确地看前一个 token（0.85–0.87），但它的输出不再被 induction 头读取（K-组合跌出前三），功能照样转给 3.0（0.54 → 0.73）。→ “注意力模式正确”不足以保住角色。
- **强制空缺（清零 3.0、1.2、7.7）：** ALL32_ko / QK32_ko / OV32_ko 以及两个重置种子中，3.2 都**不在原位恢复**（保留 QK 的 OV32_ko 中它的注意力仍正确但不被利用）；induction 以几乎相同的速度回升（400 步 0.80–0.86，保留输出写入的 QK32_ko 略快）。
- **功能流向谁：** 所有清零分组里，previous-token 分数上升的都是同一组原本就有弱倾向的头：3.4（0.22 → 0.43）、3.1（0.29 → 0.40）、2.8（0.30 → 0.39），与重置部分、重置种子都无关。
- **按决策表（暂定）：** “输出写入是锚”“注意力模式是锚”“只要空缺就原位恢复”都不成立；“新持有者确定”成立。→ 候选规则：**功能流向原本就部分具备该功能的头（按原有强弱的“富者愈富”），受损头不原位再生。** 只在 previous-token 一个功能上看到，需在其他功能上做“事先预测谁接管”的检验（E97）。
