# E107：联合训练中进入休眠的头会被锁死吗？——更高学习率、更长窗口下冻结 vs 联合（2026-10-17）

- **状态：** RUNNING（02:50 启动；5000 步）
- **类型：** CLAIM（E106 留下的开放问题）
- **来源：**
  - E106：lr 2e-5、3000 步时，冻结其余部分的完整重置头学不回原角色，但也不休眠（第 0 个 token 注意力 0.00），3.2 在缓慢上升（0.03 → 0.09）。
  - 联合训练中同样的头休眠（0.45–0.63）。
  - Schallon 用 5e-5、多轮训练，冻结后的头被唤醒（是否恢复原功能未检验）。
- **问题：** 在学习率更高、窗口更长时：
  - 冻结的头最终能否长回**原角色**？
  - 联合训练中的头是否仍然休眠、不回来——即休眠会把它锁死？

## 设置
Pythia-160M step100k；**学习率 5e-5**，batch 128 × 1024，warm-up 200，5000 步，init_seed 1234；完整重置。
| 分组 | 头 | 训练 |
|---|---|---|
| C_lr5 | — | 联合（对照：测 5e-5 下的漂移） |
| F93_joint5 / F93_frz5 | 9.3 | 联合 / 只训练该头 |
| F89_joint5 / F89_frz5 | 8.9 | 联合 / 只训练该头 |
| F32_frz5 | 3.2 | 只训练该头 |
5000 步后跑 E89 因果图，并测对第 0 个 token 的注意力。

## 登记的预测（02:50）
- **“休眠锁死”：** 冻结组的受损头效应 ≥ 损伤前的 30%（或 3.2 的 previous-token ≥ 0.4），且不休眠；联合组的受损头效应 < 10%，并且休眠（第 0 个 token 注意力 ≥ 0.4）。
- **“只是慢”：** 两组都回来（≥ 30%）。
- **“新鲜头学不会”：** 两组都不回来（< 10%）。
- **对照：** 若 C_lr5 损失比 step100k 上升 > 0.02，联合组的任务比较需要扣除漂移后再看；受损头自身的效应仍可直接比较。

## 03:31 中间读数
- **冻结的 3.2 在 lr 5e-5 下开始长回来：** previous-token 分数 0.03（0–400 步）→ 0.06（1000）→ 0.12（1500）→ **0.27（2000）**。在 lr 2e-5（E106）下 3000 步只到 0.09。
- 冻结的 8.9：IOI 恢复 −0.02（1000 步），不回来；冻结的 9.3：性别 −0.18，在变差。
- 联合训练：9.3 被重置后性别恢复 0.74（经由其他头），8.9 被重置后 IOI 恢复 0.35。
- 对照 C_lr5 有漂移：损失 2.686 → 2.705（1000 步）。
- 等 5000 步与因果图（受损头自身效应、注意力汇）再判。

## 04:02 中间读数
- **冻结的 3.2（完整重置）在 lr 5e-5 下长回原角色：** previous-token 分数 0.06（1000 步）→ 0.12（1500）→ 0.27（2000）→ 0.60（2500）→ **0.81（3000）**，损伤前为 0.85。网络其余部分冻结时，一个从随机初始化开始的头，会重新学会原来的角色（对准冻结的读者）。
- 冻结的 8.9：IOI 原始指标 1.27 → 1.19（5000 步），不回来。冻结的 9.3：性别 1.46 → 1.61（4000 步），缓慢上升。
- **补一组（事后加、单独标注）：** F32_joint5——3.2 完整重置、联合训练、lr 5e-5、5000 步。这是判断“休眠锁死”所必需、而原设计遗漏的对照。E93 / E96 中，lr 2e-5 联合训练时 3.2 不回来（由 3.0 接管）。
  - 预测：若联合训练下 3.2 仍不回来（< 0.3）并成为注意力汇 → 休眠锁死成立（至少对 3.2）；若也回来 → 只是速度差异。
