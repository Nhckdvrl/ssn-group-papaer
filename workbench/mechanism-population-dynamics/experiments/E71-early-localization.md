# E71：能否在训练早期定位将来的角色头？（2026-10-07）

- **状态：** DONE（2026-10-07）
- **类型：** CLAIM（v2 叙事：组件身份在早期即可读出）
- **对应：** C05；E37 / E40 / E46（锁定曲线）；A09
- **问题（一句话）：** 训练早期 checkpoint 上每层最强的角色头，是否就是训练结束时的最强头？最早多早可以读出？
- **设置：** (a) 受控预训练（S 尺寸，c4，各初始化的未干预 run，13 个测量步）：M1 / M2 / M3，每个角色取最强的 3 层，早期 top-1 与最终 top-1 一致率、早期 top-3 与最终 top-3 重合；(b) DataDecide 1B 有 step 2500（3.6%）/ 10000（14%）图的配方：同上；(c) Pythia-12B 2.1%（E58）。
- **读数：** 一致率随训练比例的曲线；对照：随机 1/H，以及同初始化异语料的最终一致率（E69 的 12–30%）。
- **阳性对照：** 最终步与自身一致率 = 100%；step 0 应约等于随机（E39：初始权重无法预测）。
- **决策表：** 3–5% 时 top-1 一致率 ≥ 50% → 写“早期 checkpoint 即可定位最终的角色头”；< 30% → 只写锁定曲线，不写可定位。
- **算力：** CPU。
