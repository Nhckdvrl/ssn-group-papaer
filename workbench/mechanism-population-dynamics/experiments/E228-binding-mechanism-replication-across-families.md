# E228：Gur-Arieh 的绑定检索结论在 7 个独立训练的模型上是否成立（候选 C 的第一次试测，2026-11-25）

- **状态：** PLANNED（11-25 写定，在任何 E228 运行之前）
- **类型：** PILOT（候选 C 的试测；不推进主张；锁题由人决定，R2）
- **对应：** [TOPIC_SEARCH.md](../TOPIC_SEARCH.md) 候选 C。方法与结论来源：Gur-Arieh, Geva, Geiger（ICLR 2026，arXiv 2510.06182）§3.2–3.3、§D.2（全文已读）。前置：[E227](E227-binding-retrieval-mechanisms-across-memory.md)，其读数层规则有错，本卡改用论文的规则。

## 为什么做（给外人看的版本）

候选 C 问：文献里关于“模型怎样取回上下文中绑定的实体”的机制结论，是任务本身决定的（换一个独立训练的模型也成立），还是只属于做实验的那几个模型？Gur-Arieh 等人在 Gemma-2、Qwen2.5、Llama-3.1 三个家族共 9 个 instruct 模型上给出三条结论，并称跨模型一致：

1. 被问的组在两端（第一组、最后一组）时，主要靠**位置机制**（第几组）；
2. 被问的组在中间时，位置信号变得模糊，**词汇**和**反射**机制补上；
3. 答案在提问对象前面时（问“谁爱 tea”），**用不了词汇机制**（注意力只能往左看）。

本卡只做一件事：用同一个检验，在原论文家族（Qwen2.5）和 5 个原论文没测过的独立训练家族上，看这三条是否都成立。若有家族不成立，候选 C 就有实质内容；若全都成立，就是这一条机制解释跨家族普适的第一份证据。两种结果都写进 zemi 提案，本卡之后不再加实验。

## 设置

- **模型（7 个，全部开放权重、不用凭证）：**
  - 原论文家族：`Qwen/Qwen2.5-7B-Instruct`（原论文用过的模型，作复现）、`Qwen/Qwen2.5-7B`（同一模型的 base，看 base / instruct 是否改变结论）。
  - 原论文没测过的独立家族：`Qwen/Qwen3-8B-Base`、`allenai/OLMo-2-1124-7B`、`tiiuae/Falcon3-7B-Base`、`ibm-granite/granite-3.3-8b-base`、`mistralai/Mistral-7B-v0.3`。
- **任务与反事实对：** 与 E227 相同（“谁爱什么”，n = 6 组，两个方向 A 问物 / B 问人，各 120 对），新种子 228；词表只保留在 7 个分词器里都是单 token 的人名与物品。
- **干预与读数：** 与 E227 相同（逐层替换最后一个 token 的残差流，在原始输入出现过的候选中取首 token logit 最大者，归为 原答案 / 位置 / 词汇 / 反射 / 其它），另记每对的 i_P、i_L、i_R。
- **读数层 ℓ（按论文 §D.2：“最后一个替换后还不会直接搬出检索答案的层”）：** 取同时满足“原答案比例 < 0.5”与“反事实答案（反射类）比例 < 0.5”的最后一层。两个方向各自定 ℓ。若没有这样的层（窗口为空），该模型该方向判为“读不出”。
- **命令：** `scripts/e228_mixing_families.py`。

## 判定（跑之前写）

- **行为前提：** 不干预时 A、B 两个方向的准确率都 ≥ 0.9，否则该模型排除。
- **结论 1（位置在两端）：** 方向 A，i_P 为第一组或最后一组的对子里，位置类比例 ≥ 0.5。
- **结论 2（中间由词汇 / 反射补上）：** 方向 A，i_P 在中间四组的对子里（词汇 + 反射）的比例，减去两端对子里的同一比例，差值 ≥ 0.10 且 bootstrap 95% 区间不含 0。
- **结论 3（问人方向用不了词汇）：** 方向 B 的词汇类比例 ≤ 0.10。
- 每个模型每条结论记“成立 / 不成立 / 读不出”。

## 决策表

| 结果 | 决定 |
|---|---|
| Qwen2.5-7B-Instruct 三条都不成立或读不出 | 我们的任务与原论文差得太远，跨家族比较不可解释；如实报告，zemi 提案中把候选 C 的试测记为“尚未复现原结果” |
| Qwen2.5-7B-Instruct 复现，且其余家族全部三条成立 | 这一套结论跨 6 个家族普适：写入 zemi 提案，作为“机制解释可以跨模型迁移”的初步证据 |
| Qwen2.5-7B-Instruct 复现，且至少一个其它家族有结论不成立 | 机制结论因模型而异：写入 zemi 提案，作为候选 C 的主要动机，并列出不成立的家族与结论 |
| 多个模型行为前提不过或读不出 | 如实报告，zemi 提案中说明可用模型的范围 |

## 混杂审计（只列相关项）

- base 与 instruct：原论文全用 instruct，新家族多为 base；Qwen2.5 的 base / instruct 一对用来看这一差别是否改变结论。
- 任务模板与原论文不同（原论文用 boxes、music 等模板）：用原论文家族的复现来兜底。
- 层数不同：每个模型按同一规则在自己的 ℓ 读数，不跨模型对齐层号。
- 反射与“搬出反事实答案”在本设计里不可完全区分（原论文 §3.4 另有验证）；ℓ 的规则保证读数层在答案形成之前。
