# E76：E48 的反向效应来自 part-48 分片的组成吗？——用代表性 Flan 重做继续预训练（2026-10-08）

- **状态：** DONE（2026-10-08）— 不可判定，按止损关闭
- **类型：** PILOT（方向 A 的前提检验：先确认“数据组成决定 Flan 教会的上下文使用方式”这条线索是否存在）
- **对应：** C04；E48 / E48b（part-48 前缀，10% Flan、1 亿 token：60M orig − none QA −0.37 ± 0.01，90M −0.52 ± 0.16；30%、3 亿 token +0.04 ± 0.04）；E53（人工抽查称 part-48 以数学 / 翻译为主，未经量化）
- **问题（一句话）：** 若把 Flan 换成跨 10 个分片的代表性样本，在完全相同的继续预训练设定下，原版 Flan 对问答线索下上下文采信的效应还是负的吗？
- **事先预测：** tulu_flan 的分片如果是对同一混合的随机切分（常见做法），part-48 并无特殊组成 → 预测仍为负。若第 0 步审计显示 part-48 与其他分片组成不同，则预测改为“方向取决于组成”。
- **谁依赖这个答案：** GPT 审计提出的方向 A（“同为指令数据，为何有时教模型依赖上下文、有时依赖记忆”）以 part-48 不具代表性为出发前提；若前提不成立，方向 A 失去从现有资产出发的入口。
- **设置：**
  - **第 0 步（CPU 审计）：** part-48 前缀（`flan_orig.u16` 的来源 `flan.u16`）与 `flanshard0–9`（parts 14, 45, 20, 29, 03, 40, 12, 50, 17, 41 的前缀）各解码 3000 篇文档，用同一套规则统计：含 “Question:” 的比例；其中答案（“Answer:” 后第一段非空文本）是前文子串的比例（上下文依赖代理，长度 ≥ 3 字符）；“Question:” 前文本 ≥ 80 词的比例（有段落）；翻译类（含 translate / 非 ASCII 字符 > 20%）；数学类（含 solve / 数字占比 > 15%）。判据：part-48 的每项指标是否落在 10 个其他分片的 [min, max] 内。
  - **第 1 步（GPU）：** `scripts/e48_cueswap.py` 不变，新增条件 `rep`：从 10 个分片各取前 800 万 token 的完整文档（共约 8000 万 token，与 orig 相同规模），经过与 orig 相同的“解码 → 重新分词”流程，文档顺序打乱（种子 0）。60M × 3 个初始化（default / small-aux-2 / small-aux-3），10% Flan，1 亿 token，读数同 E48。槽位分配与基础窗口的随机数流与 E48 相同 → 直接与 E48 已有的 60M `none` 与 `orig` run 配对。
- **读数：** Δ_rep(QA) = 线索效应_rep(QA) − 线索效应_none(QA)，按初始化配对，SE = 配对差 SD / √3；同时报告 Δ_rep − Δ_orig（组成的效应）。
- **阳性对照：** 训练损失正常；none 条件已知条目数不崩（E48 已满足）；Δ_orig 复现 E48 数字（同一 run 文件，自动满足）。
- **噪声地板 + MIE：** 3 个初始化的配对差（df 2，偏松）；E48 中 orig 的 SE 0.01–0.16。Δ_rep − Δ_orig 的绝对值 < 0.2 视为无组成效应。
- **混杂审计：** 只有 Flan 槽位内容不同（同一随机数流）；rep 与 orig 的文件长度可能略不同，Flan 窗口偏移随之变化（两边都是随机窗口）；10 分片的前缀仍是前缀（分片内顺序若按任务排列，前缀会偏，第 0 步的同一指标会显示）。
- **决策表（跑之前写）：**
  - Δ_rep(QA) > +2·SE 且 > 0 → 组成决定符号：E48 的反向来自 part-48；方向 A 有入口，下一步只做“哪种组成成分决定方向”的单因素实验。
  - Δ_rep(QA) < −2·SE（与 orig 同向）且 |Δ_rep − Δ_orig| < 0.2 → 组成不是原因；“part-48 不具代表性”的解释作废；Flan 继续预训练线按止损规则关闭，方向 A 不从现有资产出发。
  - 其他（不显著或部分）→ 不可判定；不追加剂量或设定（止损）。

## 结果（跑完后填写；不改上面的内容，修改需注明日期）
### 第 0 步：组成审计（2026-10-08；`results/e76/audit.json`，`scripts/e76_flan_rep.py --audit`）
- **事先预测错了：** tulu_flan 的分片不是同一混合的随机切分，组成差异极大（part-45 / part-03 约 71–73% 为翻译，且没有 “Question:”；part-29 50% 的文档含 “Question:”）。
- 按预写的 [min, max] 判据，part-48 只有两项落在其他 10 个分片之外（数学 0.151 > 0.094；“Q:” 0.483 > 0.438）。但因为分片之间本来就差得很远，这个判据几乎什么都能包住，信息量不大。
- **决定性的一项是上下文依赖代理：** 在含 “Question: … Answer:” 的文档中，part-48 只有 **3.7%** 的答案是前文子串（891 篇）。其他 QA 文档 ≥ 500 篇的分片为 30–47%，10 个分片合计约 **37%**（5194 篇）。
- **人工抽查**（各 6 篇，随机）：part-48 的 “Question:” 几乎都是“Question: <外语句子> Could you please translate this to English? Answer: <译文>”和“Question: Summarize this: …”，答案不在上下文中；part-41 是 SQuAD 式抽取问答，答案直接出自段落。代理指标与人工判断一致。（E53 的指标失败在于答案解析和翻译 / 摘要的定义问题；这里只把它用作分片间的比较，不当作绝对比例。）
- → 进入第 1 步。按事先预测的修正规则，预测改为“方向取决于组成”：代表性混合应该比 part-48 更正。
- **第 1 步数据（`results/e76/prep_stats.json`）：** rep = 287,536 篇文档、8000 万 token；含 “Question:” 的文档 10.2%（共 7.9 万处），orig（part-48）为 33%（14.6 万处）。**未登记的混杂（准备数据时发现，未看任何结果）：** rep 的 “Question:” 标记数只有 orig 的约一半 → 若 rep 为正，组成解释更强（标记更少反而更正）；若 rep ≈ 0，无法区分“组成无关”和“标记太少”。
### 第 1 步：继续预训练（2026-10-08；`results/e76/analysis.json`；60M × 3 个初始化，判定点 1 亿 token；共同已知条目 1005 条）

- **按决策表：** rep − none 的 QA 线索效应 +0.15 ± 0.24，未过 2·SE，三个 seed 方向不一 → **“其他”档：不可判定；不追加剂量或设定（止损）。**
- **如实补充（读数分解，POST-HOC）：** 线索效应 = 问答格式采信 − 陈述格式采信。rep 相对 orig 的 +0.52 中，约 0.39 来自 rep **降低了陈述格式的采信**（−0.38，三个 seed 一致），而非提高了问答格式的采信：问答格式的绝对采信变化 rep −0.23、orig −0.37，只差约 0.14。→ 换成代表性组成后，part-48 那种“只在问答格式下降低采信”的特异反向消失了；但没有出现“装入问答开关”（问答采信绝对值仍低于 none）。组成改变了 Flan 降低采信的**位置**（从问答格式移到陈述格式），没有改变**方向**。
- **结论：** “part-48 不具代表性是 E48 反向效应的原因”只得到部分支持：问答特异的反向确实依赖 part-48 的组成（翻译 / 摘要占主导），但代表性 Flan 在继续预训练中同样没有提高上下文采信。从头预训练中的 +1.7 开关仍无法在继续预训练中复现。方向 A 不从现有资产出发；Flan 继续预训练线关闭。
- **算力实际：** 约 3 × 1 GPU·时（空闲卡）。
