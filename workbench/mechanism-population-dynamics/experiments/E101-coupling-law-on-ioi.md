# E101：“残留耦合”规律在 IOI 名字移动头 8.9 上是否成立（2026-10-16）

- **状态：** RUNNING（16:45 启动；fvcrc10:3、fvcrc12:1、fvcrc20:0；5000 步）
- **类型：** CLAIM（把 E96 / E99 的规律搬到另一个功能上做事先预测）
- **来源：**
  - E96 / E99（previous-token 头 3.2）：只重置 QK、保留 OV 时，3.2 长回原角色（0.85），有现任 3.0 时也夺回（5000 步 0.58，3.0 从 0.77 退到 0.65）；只重置 OV 时，下游读者重新对准它（被读取排名 46 → 1）；完整重置、或保留 OV 但把输出旋转离开读者对准的方向时，都不回来（0.01–0.03）。
  - E98（IOI 名字移动头 8.9）：完整重置后 5000 步无人接手，IOI 卡在 40%。
- **规律（候选）：** 受损头能否夺回角色，取决于它与功能下游是否还有残留耦合：输出仍对准读者，或注意力仍正确、让读者可以重新对准。“空位 + 新鲜的头”本身不够。这个规律也解释 E98：完整重置的 8.9 没有耦合，其他头又没有部分承担者，所以没有人接手。

## 设置（同 E98：Pythia-160M step100k，学习率 2e-5，batch 128 × 1024，warm-up 200，5000 步；对照 E98 C_long，完整重置参照 E98 L8.9_long）
| 分组 | 8.9 的处理 | 预测 |
|---|---|---|
| QK89 | 重置 QK，OV 原样 | 8.9 的 IOI 效应回到损伤前的 ≥ 50%，IOI 恢复比例 ≥ 0.8 |
| OV89 | 重置 OV，QK 原样（仍看向名字） | 同上（8.9 的输出直接被反嵌入读出，梯度直接到它的 OV） |
| ROT89 | 重置 QK，OV 保留但输出旋转 | 与完整重置相同：8.9 效应 < 0.3，IOI 恢复约 0.4 |

## 决策
- 三项都按预测 → 规律跨功能成立，成为本线索的主张：**训练后期的修复只沿已有耦合进行（受损头残留的一半，或已有的部分承担者），不从无耦合的头中招募。**
- QK89 / OV89 也不回来 → 规律只对 previous-token 这种“下游是 induction 头”的结构成立，收窄。
- ROT89 回来 → 对名字移动头，自身 OV 结构就够，E99 的“读者记忆”不能推广。
