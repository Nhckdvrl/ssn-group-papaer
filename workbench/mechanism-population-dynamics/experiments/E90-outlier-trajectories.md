# E90：训练失稳的两个异常种子，分工是“从未长成”还是“长成后被改写”？——以及共用关系是同时出现还是后来招募（2026-10-15）

- **状态：** PLANNED（DataDecide-1B 的 E89 跑完、卡空出后启动）
- **类型：** CLAIM（训练轨迹；只追终点无法区分的问题）
- **对应：** E89（Pythia-410M：任务共用关键头跨种子重现；seed3 无早层 previous-token 枢纽、整体偏深、两项 ICL 失败；seed4 induction 集中在单头 6.4、反义词 / 首都 / IOI 弱）；PolyPythias（van der Wal et al., ICLR 2025，§3/§5/附录 A：50 个 run 中只有 410M seed3、seed4 是异常种子，只有它们出现 loss spike，HMM 训练图在 10⁵ 步前出现分叉；原文未给 spike 步数，未涉及 induction / ICL）。

## 什么问题才值得用训练动力学来研究（本卡的前提）

检查点轨迹是观察**路径**的方法，只有在路径里有终点没有的信息时才值得用。四个条件：
1. **终点不能区分竞争解释**：两种解释预测同样的终点、不同的路径。
2. **追踪的量与头编号无关**：如任务共用关系、任务深度、能力、“有没有早层 previous-token 瓶颈”。“哪个编号的头在第几步被选中”追踪的是坐标约定本身——旧 E37/E40/E46/E66（槽位锁定时间）和 E82/E83（主力头换人）正是在给这个任意选择计时，所以很难回答 so what。
3. **终点存在需要原因的差异**：所有 run 都一样且稳定的性质，轨迹只能补一个“何时”；跨 run 的质变差异（seed3/4）才需要历史来解释。
4. **事件在时间上局部、检查点分辨率够**：Pythia 前 1000 步按对数间隔、之后每 1000 步一个检查点。

不适合的：编号层面的锁定 / 易主；E89 里各种子都相同的性质（任务深度顺序）只加“何时出现”的描述；没有对照轨迹的单 run 曲线。

## 问题

**Q1（异常种子）：** seed3 的“无早层枢纽、整体偏深”与 seed4 的“induction 单头集中”是从任务能力出现起就如此，还是先长成与正常种子相同的分工、在 loss spike 前后被改写？ICL 能力的丢失与组织改写是否同时发生？
**Q2（共用关系的形成）：** 跨种子重现的两组共用（induction~反义词 ICL 的早层 previous-token 头；greater-than~后继的 10–13 层头）是两个任务同时开始依赖同一个头（共享原语一次形成），还是一个任务先依赖它、另一个任务后来才被招募到已有的头上？若是后者，“共用关系可重现”可以由“发育顺序可重现”来解释——这是 E89 留下的解释缺口。

## 读数（与头编号无关）

- 验证损失轨迹（定位 spike：相邻检查点损失上升）。
- 各任务能力（clean 度量）轨迹。
- **早层枢纽指标**：induction 的 all 读数第一承担头的层号、previous-token 分数、只在最后位置消融的占比，以及它在反义词上的效应。
- 任务层重心；任务共享矩阵 S；两组共用关系的 top-3 是否重合。
- Q2：每个任务“开始依赖共用头”的时间 = 该头在该任务上的效应首次 ≥ 终点值 50% 的检查点；比较同一组两个任务的时间差。

## 预测与决策表（看任何中间检查点结果前写）

- **Q1-改写：** seed3（或 seed4）在 spike 前的检查点上有与对照相同的早层枢纽（induction 第一承担头在 4–7 层、prev 分数 ≥ 0.6），之后消失或迁移，且反义词 ICL 在同一区间下降 → 写“一次优化失稳改写了已形成的分工，并带走依赖它的能力”。
- **Q1-从未长成：** seed3 在所有检查点上都没有早层枢纽（或在 spike 之前就不同于对照）→ 写“异常组织在早期就形成，spike 不是原因（或只是同一异常的另一个表现）”。
- **Q1-无关：** 组织轨迹与对照一致，异常只在能力上 → 组织差异不是能力差异的来源，Q1 止于描述。
- **Q2-同时：** 一组内两个任务开始依赖共用头的时间差 ≤ 一个检查点间隔，在 ≥ 4/6 个种子中成立 → “共享原语一次形成”。
- **Q2-招募：** 一个任务稳定先于另一个 ≥ 2 个检查点间隔，在 ≥ 4/6 个种子中方向一致 → “后出现的任务被招募到已有的头上”，共用关系的可重现性由发育顺序解释；下一步用 E46 的受控训练干预顺序（推迟先出现任务的数据）检验因果。
- 其他 → 如实报告，不追加设定。

## 结果（跑完后填写；不改上面的内容，修改需注明日期）

### 中间结果一（2026-10-15 18:40；23/72；seed3、seed4 的 12 个网格点齐，对照种子未齐；`results/e90/analysis.json`）
- **验证损失的回升（网格分辨率）：** seed3 66k 2.415 → 100k 2.567 → 143k 2.480（终点仍高于 66k）；seed4 100k 2.361 → 143k 2.884（终点未恢复）。其余区间单调下降。
- **seed3：先长成正常分工，后失去。** 16k–48k：induction 第一承担头是早层 previous-token 头 6.12（L6，prev 0.76，只在末端消融占 5–12%，即上游瓶颈），它对反义词的效应 1.05–1.91，反义词 ICL 从 −0.40 升到 +1.51（48k）。66k：第一承担头回到 10.11（L10、末端写出型），反义词降到 0.58；100k 与 143k：第一承担头变成 19.2（L19），反义词 −0.43 / −0.49，最强 previous-token 头从 4.6 换成 7.11 → 11.10、分数 0.77 → 0.65。**组织变化（66k 已开始）早于网格上可见的损失回升（100k），需加密确认顺序。**
- **seed4：分工一直正常，末段整体受损。** 1k–100k 始终有早层 previous-token 枢纽（4.1 → 5.11，prev 0.80–0.89），反义词在 66k 达 1.11；100k → 143k 损失跳升 0.52，反义词 −0.11 → −2.43、IOI 3.24 → 0.86、后继 2.24 → 0.56、greater-than 3.07 → 1.64，枢纽从 5.11 换成 6.4。seed4 的“单头集中”是末段事件后的状态。
- **按决策表（暂定，待对照）：** 两个异常种子都属 **Q1-改写**：先形成与正常终点相同的分工并获得反义词 ICL，后在训练后段失去；seed3 是重组（枢纽消失、主力移到 19 层），seed4 是同一组织下的整体退化。需要对照种子排除“反义词 ICL 在正常种子里也会这样起落”。
- **追加（看到结果后，POST-HOC）：** 加密检查点 seed3 50k–98k 每 2k + 99k、seed4 102k–142k 每 2k（46 个），定位损失回升与组织变化谁先谁后。已排入 `results/e90/jobs.txt`。
- **E89 DataDecide-1B 全 12 个：** 深度顺序 τ 0.67；S 跨模型 0.67（满分 0.97，打乱 0.40）；greater-than~后继 12/12，反义词~induction 7/11。

### 线索与新读数（2026-10-15 19:05，看到中间结果后，POST-HOC）
- **seed3 是“整体搬深”，seed4 是“消散”：** 反义词在最后位置的承担头，seed3 48k 为 14.0 / 16.11 / 18.1（层重心 14.1），100k 后为 18.12 / 20.13 / 19.7（16.6–16.9），induction 末端主力 10.11 → 19.2；seed4 1k–100k 稳定在 13.11 / 14.8 / 15.3，143k 时消散（前 3 头合计只占 25%，最大 0.17）。
- **seed3 终点的选择性：** 纯复制类（induction 9.8、IOI 3.1）保留，“检索后还要变换”的反义词（−0.49）、过去式（−0.42）失败。
- **猜想（待检验，不是结论）：** 检索机制所处深度限制其上可做的变换；搬深后复制仍可完成（占 loss 大头，损失大体恢复），变换型 ICL 回不来。竞争解释：(a) 变换型 ICL 只是最脆弱的能力，任何整体退化都先丢它（与深度无关）；(b) 变换型 ICL 在正常种子里本来也会起落。
- **新增读数（`e89_labor.py` 的 ICL 组，只算干净度量）：** 同一 3 示例格式下的纯复制、复数、首都、同义词、反义词（对照 = 照抄查询词）。正常 410M：8.63 / 2.99 / 5.80 / −3.67 / −0.58。从 19:05 起的检查点都带这组读数（含 seed3 / seed4 加密段）；预测：若深度猜想成立，seed3 搬深后复制保持、复数 / 反义词相对对照显著下降；若是 (a)，seed4 消散段与 seed3 搬深段的下降模式应相同。

### 中间结果二（2026-10-15 19:50；58/118；对照 seed0、seed1 全齐，seed2 到 66k）
- **对照种子的分工从 1k 步起一成不变：** induction 第一承担头（all 读数）就是该模型 previous-token 分数最高的早层头（seed0 5.2、seed1 5.4、seed2 4.14，L4–5，prev 0.78–0.93，末端占比 0.02–0.23），1k → 143k 从未换头；它对反义词的效应随训练单调增到 1.7–2.4；验证损失单调下降。
- **异常种子的标志是“换枢纽”：** seed3 在 1k–8k 的 induction 瓶颈就不是 previous-token 头（10.11，末端写出型；同时存在 prev 0.89 的 4.6），16k–48k 换成 6.12（像正常），66k 换回 10.11，100k 起是 19.2；seed4 在 4k 换一次（4.1 → 5.11）、143k 再换（→ 6.4）。对照 0 次。→ **修正中间结果一的判断：seed3 不是“先正常、后被改写”，而是从 1k 起就不稳定、中段一度像正常、后段搬深**；seed4 才是“正常到 100k、末段退化”。
- **反义词得分的噪声：** 同一模型（seed1 终点）换一组提示 0.57 vs 0.22，每组标准误 0.12（任务构造器的随机数在任务间共享，任务顺序不同则提示不同）。对照种子的起落（−0.28 ~ +0.24）在噪声内；seed3 48k → 100k 的 1.51 → −0.43 约为 11 个标准误，不是噪声。
- **新 ICL 组（对照）：** 复制 9.0–9.7、复数 3.1–3.7、首都 5.2–5.5；同义词始终 ≈ −4（做不了）；“反义词 vs 照抄”在 410M 上始终为负（−1.2 ~ −4，模型更倾向照抄），只能作相对比较。seed3 / seed4 加密段尚未开始。
