# E84：删数据重训后“目标头变弱”，是能力被抑制，还是活换给了别的头？（2026-10-10）

- **状态：** RUNNING
- **类型：** PILOT（A10 叙事的决定性实验；结果决定故事能否超出“中规中矩的经验记录”）
- **对应：** E81 / E83（同初始化、只差约 1.5% 数据的兄弟，IOI 主力头全部不同而任务同样完成）；MDA（Chen, Luo & Pan, ICML'26 Oral：在头出现窗口内删除 / 增加高影响样本后重训，以**同一编号的目标头**（附录 H，例如 14M 的 L3H3）的分数判断该数据“阻碍 / 加速”了这个头的出现；附录 K.2 自述 160M 中有头把角色“交接”给其他组件，列为开放问题）
- **问题（一句话）：** 在固定初始化与数据顺序、只在 induction 头出现的窗口内屏蔽一部分训练样本时，原目标头分数下降，是否伴随别的头接手、而模型的上下文复制能力不变（换人），还是能力本身下降（抑制）？
- **事先的强先验：** MDA 的读法默认目标头分数下降 = 该机制的出现被阻碍；它的随机删除对照未影响目标头。若重跑本身（GPU 非确定性）或随机屏蔽就足以让目标头换人，则单头读数的“阻碍”无法与换人区分。
- **谁依赖这个答案：** 用反事实重训 / 数据干预解释“哪些数据造就了哪个单元”的工作；按头编号比较干预前后模型的消融与归因分析。

## 设置
- 模型：E46 的 L 尺寸（12 层 × 12 头，Llama 结构），C4，训练 3000 步（学习率曲线与 10000 步的基线相同，截断在 3000 步；induction 头在 750–1000 步出现，2000 步后稳定）。
- 3 个初始化（init 1 / 2 / 3）× 4 个条件，数据顺序 seed 固定为 1：
  1. **base**：不屏蔽；
  2. **rerun**：与 base 完全相同（测 GPU 非确定性带来的换人）；
  3. **random**：第 500–2000 步随机屏蔽 10% 序列的损失（MDA 的对照；屏蔽用独立随机数，数据顺序不变）；
  4. **repeat**：第 500–2000 步屏蔽重复结构分数（E23 S1）最高的 10% 序列（门槛 = C4 样本的 90% 分位，约 0.080）；MDA 发现重复结构数据最能催生 induction 头，这是其高影响样本的替身。
- 屏蔽方式与 MDA 一致（被屏蔽样本梯度为 0，其余样本与顺序完全不变）。
- 测量（E46 的 `measure`，第 750 / 1000 / 1500 / 2000 / 3000 步）：每个头的 induction 注意力分数（M1）；复制能力 copy_gain（重复随机序列第一遍与第二遍的平均 NLL 差）；自然文本损失。

## 读数（以同初始化的 base 为参照，第 3000 步）
- **目标头**：base 第 3000 步 M1 最大的头；T = 目标头在该条件中的 M1 / 在 base 中的 M1。
- **最强头**：B = 该条件中所有头的 M1 最大值 / base 的最大值；是否同一个头（换人 = 最强头编号改变）。
- **能力**：C = 该条件 copy_gain / base copy_gain。
- 噪声地板：rerun 条件下的 T、B、C 与“最强头是否改变”。

## 决策表（跑之前写）
- **换人（故事成立）：** repeat 条件在 ≥ 2 / 3 个初始化中 T ≤ 0.7，且 B ≥ 0.9、C ≥ 0.9（能力与最强分数不降，只是换了头）；同时 rerun 条件 T ≥ 0.9（不是 GPU 非确定性本身造成的）。
- **重跑就会换人：** rerun 条件在 ≥ 2 / 3 个初始化中最强头编号改变或 T ≤ 0.7 → 单头读数连同一配置都不可复现；故事改写为“单头读数在重训比较中不可复现”，并检查 MDA 的随机对照为何稳定（不同尺寸 / 设置）。
- **抑制（MDA 读法成立）：** repeat 条件 C ≤ 0.9 且 B ≤ 0.9（能力和最强头一起下降）→ 我们的“换人”线索不推广到这种干预；故事退回中规中矩版本。
- **无效应：** repeat 条件 T、B、C 都 ≥ 0.9 → 这个替身干预太弱，如实报告；不追加强度（止损），改为直接用 MDA 公开的影响分数（若可得）再做一次。
- random 条件只作对照，不单独判定。
