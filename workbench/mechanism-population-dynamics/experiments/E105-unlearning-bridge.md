# E105：把“角色存于接口”接到真实的遗忘 / 重学问题上（2026-10-17）

- **状态：** DESIGN + PILOT（00:30 起；基线 pilot 在跑）
- **类型：** CLAIM（主线最关键的“so what”检验，见 [RESEARCH_HISTORY.md §6](../RESEARCH_HISTORY.md)（原 MAINLINE_2026-10-17 已并入） §6.2）
- **最强已有认识：**
  - 遗忘普遍可被重学（Deeb & Roger 2024；Jain 2024）。
  - 抗重学可由权重距离 / 线性模式连通性预测（Siddiqui et al. 2025）。
  - 加噪 + 蒸馏（UNDO，Lee et al. NeurIPS 2025）抗重学，但不知道加噪破坏的是什么。
- **我们的候选答案：** 能力能否被重学，取决于承担它的组件与下游读者之间的接口是否保留；权重距离预测不了（E99–E102 中排反）。

## Pilot（00:30–00:45）：梯度差遗忘是浅层压制
`scripts/e105_unlearn.py`：在 IOI 训练提示（新名字）上最小化 relu(logit(IO) − logit(S) + 1)，同时保持 Pile 损失；Adam 无权重衰减；只放开一个参数子集。
| 子集 | 步数 | IOI（3.48 →） | Pile 损失（2.794 →） | 权重相对 L2 变化 |
|---|---|---|---|---|
| 只改 QK | 25 | −6.37 | 2.808 | 0.031% |
| 只改 OV | 25 | −7.05 | 2.790 | 0.038% |
| 只改 MLP | 25 | −6.55 | 2.790 | 0.059% |
- 25 步、远小于 0.1% 的权重变化就把 IOI 翻成强烈负值：典型的浅层“包装”（Jain 2024）。这些方法不碰任何接口，规律预测会被完全重学；基线（各自在 Pile 上继续训练 1000 步，R_qk / R_ov / R_mlp）在跑。
- 结论（设计层面）：要检验规律，必须加入会改变接口的方法。

## 正式设计（草案，等基线结果后定稿；判据看结果前写入）
**能力：** IOI（组件已知：8.9、8.10、9.5、3.2 …）；之后换成事实回忆（首都：8.10 / 8.1；410M 17.6）。

**遗忘方式（尽量匹配“遗忘程度”与“保留集损失”）：**
1. 梯度差（浅层基线）。
2. UNDO 式全局加噪（多个噪声强度）+ 在保留数据上恢复。
3. **定向接口破坏：** 对 IOI 前 k 个承担头的输出投影做正交旋转（与 E101 ROT 相同），再在保留数据上恢复。
4. **定向注意力破坏：** 对同样 k 个头只重置 QK，再在保留数据上恢复。
5. RMU（中间层表示误导）。

**重学攻击：** 在无关的 Pile 数据上继续训练（学习率 2e-5，2000 步）；另做一组在少量 IOI 提示上微调的强攻击。

**测量：**
- 重学比例；与原模型的权重 L2 距离；
- **接口保留度：** 对前 k 个承担头，其输出子空间与原输出子空间的主角余弦，以及下游读者（后层头的 Q / K / V、反嵌入）对它的读取与原来的相关。

**登记的预测：**
- 重学比例与接口保留度的秩相关 ≥ 0.7，且明显高于与权重距离的秩相关。
- 定向接口破坏（3）达到与 UNDO 式加噪（2）相当的抗重学，所需权重扰动小一个数量级以上。
- 定向注意力破坏（4）几乎被完全重学。

## E105b（预注册 00:50，看结果前写）：强度匹配、两个种子的复现
- **遗忘：** lr 5e-6，margin 0（只把 logit(IO) − logit(S) 压到 ≤ 0），每 5 步评估一次，held-out IOI < 0.5 即停。子集 qk / ov / mlp / attn（qk + ov）× 种子 1、2（种子同时改变遗忘提示和保留数据位置）。
- **重学：** 各自在 Pile 上继续训练 1000 步（与 E98 C_long 同一数据顺序、同一设置）。
- **指标：** 重学比例 r =（IOI_1000 − IOI_0）/（C_long_1000 − IOI_0）；权重相对 L2；Pile 损失。
- **预测：**
  1. 两个种子中都有 r(qk) ≥ 0.6，且 r(qk) − r(ov) ≥ 0.3。
  2. r(mlp) ≤ 0.4，r(attn) ≤ 0.4。
  3. ov 与 qk 的权重距离之比在 0.5–2 之间（距离相近而结局不同）。
- **决策：**
  - 1、2 都在两个种子上成立 → 在真实遗忘方法上支持“写出端被改动才抗重学”，接着测各组件写出端方向的改变量，作为定量预测指标。
  - 1 不成立（qk 也难重学，或 ov 同样被重学）→ 基线结果是过冲造成的，桥接不成立，回到受控损伤层面。

|---|---|---|---|---|---|
| QK | **−6.54**（变化 −7.85） | +0.28 | +0.87 | +0.54 | 0.63 |

- 三种遗忘在功能层面做的是**同一件事**：主要把 8.10 翻成强烈压低 IO，输出改变程度也相近；只是实现位置不同（QK：改它看哪里；OV：改它写什么；MLP：改它读到的残差内容）。
- 因此重学的差异不能用“写出的内容变了多少”来解释，只能来自**实现位置**——或者来自一个混淆。

## 必须排除的竞争解释（01:05）：一般损失受伤程度
- 只改 QK 的遗忘对 Pile 损失伤得更重：基线 2.808 vs OV 2.790 / MLP 2.790（原 2.794）；E105b 中 QK +0.006–0.008，OV +0.002，MLP +0.003。
- 如果重学的推动力来自“这次修改伤了一般语言建模、所以被一般训练撤回”，那么 QK 被快速重学只是副作用更大，与“写出端 / 读出端”无关。
- 受控损伤实验中这个混淆不成立：E101 中 ROT89 的瞬间损失（25 步 2.6912）高于 QK89（2.6898），却不回来。但在真实遗忘中必须单独排除。
- **E105c（等 E105b 结果后定）：** 让 QK 遗忘与 OV 遗忘的一般损失受伤程度匹配，例如提高 QK 组的保留权重、或给 OV 组加入额外的一般损失扰动，再比较重学。
  - 若重学跟着损失受伤程度走 → 桥接主张不成立。
  - 若仍跟着实现位置走 → 支持主张。

## E105c（预注册 01:50，看结果前写）：把“改的是哪部分参数”与“一般损失受伤程度”交叉

## E105d（预注册 05:15，看结果前写）：放开全部参数的常规遗忘落在哪一侧？
- **动机：** 常规遗忘更新全部参数。E105b 中只放开注意力（QK + OV）时 r = 0.68，介于两侧之间。如果放开全部参数（QK + OV + MLP）时，优化器仍主要用读取侧完成遗忘，就能解释“常规遗忘为何在良性训练下易被撤回”（Hu 2025、Siddiqui 2025 的现象）。
- **设计：**
  - IOI 上 subset = all，种子 1、2（其他同 E105b）；首都上 subset = all，种子 1（同 E109）。
  - 之后在 Pile 上重学 1000 步。
  - 测：重学比例 r；E111 的一般文本足迹；各参数组（QKV 中的 QK 行、V 行、输出投影、MLP）的更新范数占比。
- **预测：**
  - 若 r(all) ≥ 0.7，且 QK 行的更新占比或一般文本足迹接近 QK 式 → 常规遗忘主要走读取侧，这就是它可逆的原因；
  - 若 r(all) ≤ 0.55，且足迹窄 → 常规遗忘主要走写出侧，可逆性另有来源。
- **05:16 方法说明与参照：**
  - 在 Adam 下，各参数组的更新范数占比只反映放开了多少参数（如 attn 组 QK 0.48、V 0.26、O 0.26），不说明遗忘实际走的路线（scripts/e105_groups.py，不用于判断）。
  - 改用**因果分解**（scripts/e105_revert.py）：每次只把一组参数恢复成原值，测任务恢复了多少。
  - 参照（U2_attn_s1，IOI 0.45，原 3.49）：只恢复 QK → 恢复 46%；只恢复 V → 17%；只恢复 O → 14%；MLP 未改 → 0%。QK + OV 都可改时，遗忘主要由读取侧承担，与它 r = 0.68（介于两侧之间）一致。E105d 的全参数模型将用同一分解。

- **按预注册：** IOI 的 r = 0.56–0.57 落在两档之间（读取侧为主 ≥ 0.7，写出侧为主 ≤ 0.55）；首都 0.36 属于写出侧为主。因果分解显示，常规梯度差遗忘分散在各组参数上，MLP 承担最多（26–28%），QK 其次（12–17%）。

- **新问题（可检验）：** 混合修改在良性训练中，是不是读取侧的部分先被撤回、写出侧的部分留下？办法：对重学后的模型做同样的分组恢复分解，看哪一组的“遗忘贡献”消失了。
- 另：首都 all s1 的定向攻击同样完全恢复（V：−1.95 → 5.91，原模型受同样攻击后为 4.96）。

## E105e（预注册 06:08）：混合修改在良性训练中，哪一部分被撤回？
- **设计：** 对全参数遗忘模型 U4_all_s1 重学 1000 步并保存权重（R），同时用同一数据顺序训练原模型 1000 步并保存（C）。每个参数组 g（QK 行、V 行、O、MLP）的“遗忘改变存活率”：
  - s_g = ⟨(θ_R − θ_C)_g, (θ_U − θ_0)_g⟩ / ‖(θ_U − θ_0)_g‖²，即重学后，遗忘改变在该组方向上还剩多少（扣除训练本身的漂移）。
  - 同时对 R 做分组恢复分解：把 R 的某组参数换成 C 的对应组，看 IOI 改变多少。
- **预测：** s_QK < s_MLP（读取侧部分被撤回得更多），差值 ≥ 0.2。若各组存活率相近 → 良性撤回不区分读取侧与写出侧，规律只在单一路线的修改上成立。

## 06:53 E105e 结果：良性重学不是“撤销”遗忘，而是绕过它
**参数空间存活率**（重学后遗忘改变在原方向上还剩多少，扣除同数据训练的漂移）：QK 0.628、V 0.619、O 0.644、MLP 0.607。
→ 预测“QK 部分先被撤回（s_QK 比 s_MLP 低 ≥ 0.2）”**不成立**。1000 步内，各组的遗忘改变都只被抹去约 37%，而且程度相同。

**功能分解**（重学后模型 R 的 IOI = 1.55，同步训练的原模型 C = 3.31，遗忘后 U = −0.59，原模型 3.49）：
| 把 R 的哪一组换成 C 的 | IOI | 改善 |
|---|---|---|
| QK | 1.67 | +0.12 |
| V | 1.76 | +0.22 |
| O | 1.77 | +0.23 |
| **MLP** | **2.60** | **+1.05** |
- **判断：**
  - 良性重学的恢复（−0.59 → 1.55）**不是**把遗忘改变在参数上撤销，而是通过其他变化在功能上绕过了它。
