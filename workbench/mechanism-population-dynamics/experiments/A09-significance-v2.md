## 2. 现在论文的研究意义落在哪里，问题在哪里
- 当前叙事回答的是“哪个编号的头拿到哪个角色，受什么因素影响”。头编号在置换对称下任意，数据不可能稳定地选中某个编号（我们自己的引理），所以“由初始化决定”接近必然；§6 又说明它不影响行为。单独看，意义有限——审稿人会问“然后呢”。
- 已有的“应用”大多被我们自己的结果削弱：认出 seed 权重也能做（E68）；头标签迁移只有部分（19.5% vs 层匹配随机 10%）；Flan 习惯没有额外集中（E65 更正）。

## 3. 近邻的意义尺度（最近录用 / 预印本）
- Tigges et al., NeurIPS 2024：circuit 分析跨训练与规模一致——算法保持，实现它的头会变；意义：在一个 checkpoint 上的 circuit 分析可以推广。
- Bali et al., 2026：跨独立初始化的注意力头稳定性，中间层最不稳定；weight decay 提高稳定性；意义：circuit 是否“普遍”关系到白盒监控的可信度。
- Toward a Theory of Generalizability in LLM MI（arXiv 2509.22831）：机制结论的五种可推广维度（功能、发育、位置、关系、构型）；Pythia 多 seed 上发育一致、位置一致性有限。
- PolyPythias, ICLR 2025：seed 同时改变初始化与数据顺序，不区分二者。
- Chen et al., ICML 2026（MDA）：从训练数据追溯可解释单元的来源，并通过改数据干预。
- 共同点：意义都落在“机制性结论能否推广 / 如何可靠地得到”，并给出原因或杠杆。

## 4. v2 的研究问题与意义（不夸大）
**问题：** 机制性结论中的“由哪个组件实现”（位置维度）为什么不能跨训练 run 推广？它由什么决定、何时决定、在什么条件下能推广？
**我们能回答的（已有 + E70–E72）：**
1. 原因：位置维度不是由数据决定的，而是由初始化在训练早期一小段学习中打破对称时决定的；数据决定的是功能、发育（时间）与强度。这解释了 Tigges / Bali / 2509.22831 观察到的位置不一致。
2. 条件：共享初始化时，位置在相似语料、低梯度噪声下跨数据保留；在差异大的语料（代码）上不保留。
3. 时间：位置在早期即确定，可从早期 checkpoint 读出（E71 待定）。
4. 是否只是坐标约定：E72 检验头是否带有跨 run 的角色组合——决定“通过对齐跨初始化推广组件结论”是否可行。
**对实践的含义（随 E70–E72 结果确定措辞）：** 机制结论应按维度报告（层 / 算法 / 发育可推广，头编号只在同初始化内部、且部分推广）；数据对组件的影响只能在同初始化的模型对之间比较；梯度噪声是提高组件可复现性的杠杆（与 Bali 的 weight decay 同类）。
**不写的：** 不写 provenance 应用；不写“头标签可迁移”；不写“初始化决定一切结构”。

## 5. v2 论文的结构（草案，实验结果出来后定稿）
标题候选：*Where Do Circuit Components Come From? Initialization, Data and the Reproducibility of Attention-Head Roles*（或保留现标题，改副标题）。
1 引言：机制结论的推广问题（位置维度不推广）→ 我们用 seed × 语料交叉把初始化与数据分开 → 发现与含义。
2 设置与测量（不变；加“位置维度”的定义）。
3 位置由初始化决定，层 / 算法 / 时间 / 强度由数据或架构决定（把 Table 3 的维度地图提为主线）。
4 何时决定；5 什么条件下保留；6 行为与 Flan 案例（数据改变功能，不改变位置）。
7 含义：报告粒度、seed 匹配的比较、早期定位、杠杆（E70–E72 支撑）。
