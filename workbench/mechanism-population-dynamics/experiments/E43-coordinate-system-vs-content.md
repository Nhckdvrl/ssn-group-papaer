# E43：初始化固定的是“坐标系”，数据决定的是“内容”？——按索引对齐 vs 置换 / 旋转不变的交叉分离（2026-10-03）

- **状态：** DONE（2026-10-03；交叉分离成立；残差与头继承坐标，MLP 神经元不继承；同初始化不带来线性连通）
- **类型：** CLAIM（C05 从注意力头推广到神经元、残差维度、权重；双重分离在表示层面的检验）
- **对应：** C05；A02 §2“对称性控制”一行；对标 Li et al. ICLR 2016（convergent learning：神经元最佳匹配）、Kornblith ICML 2019（CKA）、Gurnee TMLR 2024（通用神经元，逐对相关）、Bali ICML 2026（层内最佳匹配 vs 索引）、Sun et al. COLM 2024（massive activations）、Frankle ICML 2020 / Juneja ICLR 2023（线性插值势垒）
- **问题（一句话）：** 同初始化、不同数据的模型是否共享同一个坐标系（同一编号的神经元、残差维度、头做同样的事），而置换 / 旋转不变的相似度（“学到了什么”）则由数据决定、与初始化无关？
- **设置：**
  - 模型：与 E42 相同的 18 个 DataDecide 1B 最终步（6 配方 × 3 初始化）。
  - 输入：E35 的 16 篇自然文本（OLMo 分词，EOS + 256 token），共 4096 个位置（相关计算去掉位置 0）；注意力模式用前 8 篇。
  - 转储（`scripts/e43_basis.py --dump`）：各层残差流、MLP 隐单元（down_proj 输入，8192 × 16 层）、各头输出（o_proj 输入）、注意力模式。
  - 两两计算（153 对，`--pairs`）：
    - 神经元：按索引对齐的相关（同编号神经元）vs 最佳匹配相关（每个神经元在对方同层中相关最高的那个）、互为最佳匹配的比例。
    - 残差：按索引对齐的逐维相关 vs 线性 CKA（旋转不变）；中间层 massive-activation 维度（top-5，按最大绝对值）的 Jaccard。
    - 头：头输出的 CKA、注意力模式的余弦，按索引对齐 vs 层内最佳匹配。
  - 权重插值（`--lmc`）：所有 SI 对（45）、SD 对（18）、每 8 个取 1 个的 DD 对；α ∈ {0, 0.25, 0.5, 0.75, 1}，16 篇文本上的损失；势垒 = L(0.5) − (L(0) + L(1)) / 2；不做置换对齐。
- **读数：** 每个量的 SI / SD / DD 均值和 SI − SD（对配方 bootstrap 95% CI）。
- **阳性对照：** 同一模型与自身的比较 = 1（实现检查）；最佳匹配 ≥ 按索引对齐（数学上必然，检查实现）；CKA 在所有对上 > 0.3（模型都学到了语言，否则 CKA 读数无效）。
- **噪声地板 + MIE：** DD 对给出“既不同初始化也不同数据”的基线；MIE：SI − SD > 0.1（与 E35 同一门槛），CI 不含 0。
- **混杂审计：** 4096 个 token 上的相关有抽样噪声（SE ≈ 0.016），对 SI / SD 一视同仁；最佳匹配有“从 8192 个候选里取最大”的上偏，只做组间比较、不解释绝对值；fineweb-edu / fineweb-pro 是同来源家族，单独报告；DataDecide 的 seed 同时决定数据顺序（见 E44 的拆分）。
- **决策表（跑之前写）：**
  - **坐标系由初始化决定：** 神经元、残差的按索引相关都满足 SI − SD > 0.1 且 CI 不含 0 → C05 推广为“初始化固定坐标系”；只有头满足 → C05 保持为头级。
  - **交叉分离（内容由数据决定）：** 旋转 / 置换不变量（残差 CKA、神经元最佳匹配、头最佳匹配）的 SD − SI ≥ 0（同数据至少与同初始化一样像）→ 写成表示层面的双重分离：按索引看初始化赢，按内容看数据赢；不变量也是 SI ≫ SD → 初始化还塑造了内容，不写交叉分离，如实报告。
  - **插值：** SI 势垒 < SD 势垒，且差 > 两者 SD 的 2 倍 → 写成“同初始化 = 同一个盆地”的证据；都很大（> 1 nat）且无差别 → 只报告，不作结论。
- **算力预算：** 转储 18 × 3 分钟；两两 153 × 约 1 分钟；插值约 70 对 × 1 分钟 ≈ 5 GPU·时；磁盘约 36 GB（`/home/xiang/mechpop_cache/e43/`，不进 git）　**实际：**

- **判定（按决策表）：**
  - **坐标系：** 残差（+0.196）满足，MLP 神经元（+0.008）不满足 → C05 推广为“初始化固定**残差流的坐标轴**与**注意力头的角色编号**”，**不包括 MLP 神经元**。
  - **交叉分离：** 全部不变量都是 SD ≥ SI（同数据比同初始化更像；同初始化相对 DD 没有任何内容上的提升）→ **成立**：按索引看，初始化起作用；按内容看，只有数据起作用（效应小：CKA SD − DD = +0.033）。
  - **插值：** SI 势垒不低于 SD（7.50 vs 6.97）→ 两者都很大、无差别，只报告：**同初始化并不意味着同一个线性连通的盆地**。
- **解读：** 初始化留下的是“规范 / 坐标”的选择（哪个残差维度、哪个头编号承担什么），而不是权重的接近（插值势垒大；最终权重与初始权重的相关只有 0.03–0.09），也不是表示内容。MLP 神经元每层 8192 个、数量远多于头，没有继承编号 → E52 检验其中高度特化的神经元是否例外。
- 主张变化：C05 补充“表示层面的交叉分离；残差坐标继承、神经元不继承；无线性连通”。
