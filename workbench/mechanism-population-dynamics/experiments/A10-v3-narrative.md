# A10：v3 叙事（2026-10-10 晚；人要求回到头这条线，减少 so what）

## 1. 为什么换中心
- v2 的中心“组件身份跟随初始化”最容易被问 so what：同层的头可以互换，“初始化决定哪个编号”接近必然；Trott（arXiv 2509.22831）已提出“位置维度推广有限”的框架，Bali（ICML'26）已系统测量跨 seed 头稳定性，Tigges（NeurIPS'24）已显示算法稳定、承担的头会换。
- 我们的数据里不平凡的部分是一个**分离**：按注意力模式定义的头角色随初始化继承，而因果上承担任务的头不随之继承——即使初始化相同、只改语料。

## 2. 研究问题（一句话）
> 一个在某个模型上“由某个头承担”的机制结论，能不能搬到与它共享初始化或由它继续训练得到的模型上？注意力模式意义上的角色与因果意义上的承担者，哪一个会被继承？

## 3. 谁依赖这个答案
- 把基座模型上的电路 / 头标签用到其继续训练、指令微调版本上的分析（最常见的真实场景）。
- 在同初始化重训模型之间比较具体单元的数据干预可解释性（如 MDA，ICML'26：在头出现窗口内删 / 增数据后重训）。
- 用注意力模式（induction 分数等）给头贴标签、并默认它就是因果承担者的做法。

## 5. 缺口（必须补，否则结论站不住）
1. **测量信度：** 因果图跨模型只对应 0.08，可能是单头因果测量本身噪声大（Méloux et al. ICML'26）。需要模型内拆半信度，报告信度校正后的对应。
2. **继续训练场景：** 现实中搬结论的对象是继续训练 / 后训练的后代，而不是另起炉灶的兄弟。需要在 OLMo-2-1B 的 stage1 → stage2 → SFT → DPO → Instruct 链与 Pythia 同一 run 的后期检查点上测。
→ 实验卡 E81。

## 7. 叙事链（人：叙事要自然，不能把一堆实验机械拼起来）
每一步回答上一步留下的缺口；不在链上的结果进附录或删除，不论花了多少算力。
1. **起点：** 一个模型里“某个头负责某个计算”的结论，在相关模型里是否成立？近邻（Tigges、Bali、Trott）改 seed 时初始化与数据顺序一起变，说不清头为什么换、换的是编号还是干活的头。
2. **排除编号问题（前提，不是结论）：** 初始化 × 语料完全交叉中，注意力定义的角色只在同初始化模型之间共享 → 同初始化兄弟共用坐标系，比较具体头无需对齐。（E35 / E59，正文一节）
3. **异常：** 坐标系相同，因果承担者却不同（IOI 0.08；数据几乎相同的 Pythia 标准 / 去重也换主力）。先排除测量噪声。（E74 / E73 + E81 A）
4. **解释：** 每个功能类有多个具备该注意力模式的候选头；继承的是候选池，池里由谁承担因果作用由数据决定，通用剖面预测不了。（E75 / E72）
5. **由解释推出的新预测（落在实践上）：** 分工对数据敏感 → 换数据继续训练（中期训练、SFT、DPO）时是否重新分配？这正是把基座模型发现搬到指令模型上的场景。（E81 B）
- **进附录：** 语料距离与梯度噪声（E60 / E62）、规模趋势（E45）、早期窗口（E46 / E66，可作为第 2 步的补充说明）、公开套件审计（P09 / P11 / P12）。
- **删除：** 认出 seed（E61 / E68）、Flan 案例。
- **E81 的结果决定第 3、5 步写成什么：** 若信度校正后因果对应 ≥ 0.5，第 3 步的异常不成立，整条链要改写；若继续训练保留承担者，第 5 步写成“可以搬到后代、不能搬到兄弟”。
