# E19 — Is the run-level context/memory difference a property of the run or of the snapshot?（2026-10-02）

- **状态：** REGISTERED（判据提交于计算之前；R0 审计 step123000/133000/138000 进行中）
- **类型：** PILOT（混杂检验；E13/E17/E18 的“run 差异”全部只用 step143000 一个快照）
- **对应：** E13、E17、E18；PolyPythias（seed 同时改变初始化与 batch 组成）；2510.02370（训练数据的不一致性在训练后期改变上下文/记忆偏好）
- **阳性对照：** step143000 的结果与 E18 完全一致（同脚本、同数据）
- **噪声地板：** 条件内按条目 bootstrap；实验单位 = run（n=10）
- **问题（只回答这个）：** 在学习率已降到很低的最后 20k 步内，同一 run 不同快照之间的采信边际波动，是否远小于 run 之间的差异？

## 设置
- 模型：`pythia-410m` + seed1..9，step 123000、133000、138000、143000（143000 复用 E18）。
- 读数：E18 的 12 个条件的采信边际（已知条目上 mean[lp(干扰) − lp(答案)]）；“已知”在每个快照各自判定（与 E18 相同）。
- 主统计：每个条件上 ICC = run 间方差 /（run 间方差 + run 内跨快照方差），用 run × step 的二因素分解；报告 12 个条件的中位数。
- 辅助统计：run 平均边际在 step133000 与 step143000 之间的 Spearman（n=10，以及去掉 seed4 的 n=9）。

## 判据
- **run 特质：** ICC 中位数 ≥ 0.7，且 run 排名 Spearman(133k, 143k) ≥ 0.7（去 seed4 仍 ≥ 0.6）。
- **快照依赖：** ICC 中位数 ≤ 0.4 → E13/E18 的 run 差异主要是快照噪声；CLAIMS 中所有“run 间使用差异”的表述都要加“单快照”限定，并降级。
- 中间 → 如实报告；不追加条件。
