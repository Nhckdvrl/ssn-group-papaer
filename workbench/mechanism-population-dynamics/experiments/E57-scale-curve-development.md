# E57：尺寸曲线的发育视角——小模型是从来没有继承，还是继承过又被冲掉？（2026-10-03）

- **状态：** RUNNING
- **对应：** C05（尺寸趋势的来源；E46c 已否定“初始化尺度 / 学习率”解释）
- **问题：** E45 的终点测量显示，同初始化跨语料的层内头身份相似度随规模增强（≤ 20M 约 0.03，≥ 150M 约 0.2–0.3）。这个差别是在训练早期（对称性破缺的关键期）就已经形成，还是小模型早期同样继承、之后在训练中被冲掉？
- **设置：** DataDecide 10M / 20M / 60M / 150M / 300M / 750M；每个尺寸用 E45 计划中的前 6 个配方 × 3 个初始化（default / small-aux-2 / small-aux-3）；step 1250 / 2500 / 3750（三个初始化共有的最早 checkpoint；按训练 token 比例约 2–26%，因尺寸而异，逐点报告比例）；终点用 E45 已有测量并限制在同样 6 个配方。测量与 E45 相同（`census.py`：M1 induction、M2 previous-token、M4 检索头图）。
- **读数：** 每个尺寸 × step 的层内 SI、SD 与 SI − SD（配方 bootstrap CI），画成“训练进度 × 尺寸”的轨迹。
- **阳性对照：** 1B 已知轨迹（E37：3.6% 时 SI − SD 已等于终点）；M2 信度 ≥ 0.8；M1 只在 M1_max > 0.3 的模型上比较。
- **怎么读：** 小模型早期层内 SI 明显高于终点 → “继承被写下又被冲掉”（规模决定保留多少）；小模型早期同样 ≈ 0 → “规模决定对称性破缺时初始化 vs 数据谁说了算”；大模型早期已到终点水平 → 与 E37 一致。
- **算力：** 324 个 checkpoint 的 census（每个几十秒到几分钟），在自己已占用的卡上共卡运行；下载约 250 GB。
