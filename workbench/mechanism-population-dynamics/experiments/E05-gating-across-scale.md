# E05 — Is gated in-context copying a general late-training phenomenon?（2026-10-02）

- **状态：** PLANNED → RUNNING（协议冻结于运行前）
- **类型：** PILOT（全局性检验：决定这条线的意义上限）
- **对应：** E02（70M 后期复制退化，seed 间 25×）、E03/E04（第 0 层分布偏移门控）
- **要回答的问题（且只回答这些）：**
  - **Q-scale：** “不自然序列的复制被抑制、自然文本复制完好”是否在 70M 之外（160M 群体；410M / 1B / 1.4B canonical）同样在训练后期出现？
  - **Q-pop：** 在 160M 的 10 个 seed 中，抑制幅度是否也在相同自然文本 loss 下大幅分化？
  - **Q-loc：** 门控的分布偏移位于哪一层？（逐层均值平移，不预设第 0 层）
- **不回答：** 门控信号的内容（E06）、功能后果（E07）。

## 设置
- **160M：** `pythia-160m` + `pythia-160m-seed1..9`，steps {2000, 8000, 16000, 32000, 64000, 100000, 143000}；全部过 R0。
- **更大 canonical：** `pythia-410m`、`pythia-1b`、`pythia-1.4b`，steps {8000, 32000, 143000}（R0 后决定；2.8B/12B 已知 artifact 问题，不用）。
- **刺激：** 与 E04 相同——held-out 随机重复序列（token 池同 E02，seed 777，500 条）；自然重复文本（Pile eval 1000–1999 条前 50 token）。
- **读数：** CL / ACC（随机、自然）；**逐层**均值平移：正向（随机输入 → 自然均值，所有该层头）与反向（自然输入 → 随机均值）；μ 由估计集计算（同 E04）。

## 决策表（跑之前写）
- **普遍：** 160M 中 ≥3/10 seed 出现后期随机复制退化 ≥1 nat（自然复制 <0.5 nat 不变），且存在某一早层（≤ 第 2 层）的正向平移救回 ≥50%、反向平移诱导 ≥1 nat → 现象跨尺寸成立，进入 E06（信号内容）与 E07（功能后果）。
- **只在 70M：** 160M 与更大模型都无后期退化（<0.5 nat）→ 现象可能是 70M 容量瓶颈的产物；意义上限显著降低。届时把这条线降为 PARKED（重开条件：在其他家族中观测到），回到 E02 的层位置漂移 / 角色交接结构。
- **中间：** 退化存在但门控层不在早层，或救回 <50% → 如实报告门控位置，修订假说后再决定。
