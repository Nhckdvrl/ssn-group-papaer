# E52：头记得 seed、神经元忘了——高度特化的神经元是否例外？（2026-10-03）

- **状态：** DONE — 不可判定（特化度量的拆半一致性未达阳性对照）；描述上所有十分位都无实质继承
- **类型：** PILOT（解释 E43 的“异质继承”：哪类成分保留初始化身份）
- **对应：** C05；E43 前 20 对的初步结果（残差流按索引相关 SI 0.21 / SD 0.00；MLP 神经元按索引相关 SI 0.009 ≈ SD）；对标 Gurnee et al. TMLR 2024（通用神经元：高峰度、稀疏、可解释的神经元跨 seed 才对应得上）
- **问题（一句话）：** 在同初始化、不同数据的 1B 模型之间，激活高度稀疏 / 高峰度的神经元是否按编号对应（按索引相关明显 > 0），而一般神经元不对应？
- **设置：**
  - 数据：E43 的 18 个模型转储（MLP 隐单元，16 层 × 8192，4096 个 token）。
  - 特化程度：每个神经元在 A、B 两个模型中激活峰度（kurtosis）的平均值；按此在每层内分十分位。
  - 读数：每个十分位内，按索引相关（同编号神经元的激活相关）的均值，按 SI / SD / DD 分组；主读数 = 最高十分位。
- **阳性对照：** 最高十分位中，模型内部的拆半一致性（两半 token 上计算的峰度十分位一致率）≥ 0.7，确保“特化”的测量可靠；最佳匹配相关在最高十分位应高于最低十分位（Gurnee：特化神经元更“通用”），否则特化度量无效。
- **噪声地板 + MIE：** SD 组（不同初始化）给出按索引相关的零水平；MIE：最高十分位 SI − SD > 0.1。
- **混杂审计：** 峰度在 A、B 中取平均，避免只按一个模型选神经元造成的回归均值偏差；十分位在看结果前固定；最佳匹配的“取最大”上偏只做组间比较。
- **决策表（跑之前写）：**
  - 最高十分位 SI − SD > 0.1，且随十分位单调上升 → 写成“只有发生了特化的成分保留初始化身份”（头 + 特化神经元记得 seed，一般神经元忘记），与对称性破缺的解释一致。
  - 所有十分位 SI − SD ≤ 0.1 → 写成“MLP 神经元完全不继承初始化身份”，头与神经元的差别另寻解释（如每层候选数：16 vs 8192）。
