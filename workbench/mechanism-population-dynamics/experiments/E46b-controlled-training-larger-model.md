# E46b：受控训练中的规模效应——更大的模型里，位置由初始化还是早期数据决定？（2026-10-03）

- **状态：** DONE（A′ 与追加的 L × papers；D′ 见日志）
- **类型：** CLAIM（检验“机制区间”假说：小模型的对称性破缺由早期数据驱动，大模型由初始化驱动）
- **对应：** C05；E45（DataDecide：继承随规模增强）；E46 早期分叉（S 尺寸：step 100 换语料使布局完全改变，层内 −0.13 / −0.07；ε = 0.1 的权重扰动不改变布局，0.95）；E46c（初始化尺度 / 学习率）
- **问题（一句话）：** 在 L 尺寸（12 层 × 12 头，d 768）的受控训练中，同初始化、不同语料的头身份是否比 S 尺寸继承得更强？在 step 100 把语料换成代码，是否仍会打乱布局？
- **设置：**
  - 架构：L = 12 层 × 12 头，d 768，ffn 3072（`scripts/e46_train.py --size L`）；其余超参与 E46 相同（lr 1e-3、init std 0.02、batch 64 × 512、10,000 步）。
  - A'：初始化 1、2、3 × 语料 c4、code（order = init）= 6 个 run；初始化 1 × c4 存分叉状态。
  - D'：父 run = L_i1_c4_o1；在 k = 100、1000 分叉换成 code（新顺序）；在 k = 100 加 ε = 0.1 的权重扰动 = 3 个 run。
  - 测量：同 E46（M1、M2；M1 只在 M1_max > 0.3 的 run 上比较）。
- **读数：** A'：层内 SI（同初始化，c4 vs code，3 对）− SD（同语料不同初始化，6 对）；D'：分叉 run 与父 run 的最终层内相似度。与 S 尺寸的对应量直接比较。
- **阳性对照：** 所有 run 最终 M1_max > 0.3、copy gain > 2；M2 信度 ≥ 0.8。
- **噪声地板 + MIE：** 对 run 的置换零分布；与 S 尺寸的差 > 0.1 才算规模效应。
- **混杂审计：** 只有 3 个初始化（算力限制），写进范围；L 与 S 的每头维度（64 vs 32）、层数、头数同时变化，这正是 DataDecide 中随规模变化的组合，不能单独归因于某一个维度。
- **决策表（跑之前写）：**
  - L 的层内 SI − SD 比 S 大 > 0.1，且 step 100 换语料后的层内相似度比 S 高 > 0.2 → 写成“受控训练中复现规模效应：规模越大，对称性破缺越由初始化决定、越不受早期数据影响”。
  - L 与 S 无差别 → 规模效应不能在这个受控设置中复现；E45 的趋势可能来自其他因素（训练长度、学习率等，见 E46c），如实报告。
- **算力预算：** 9 个 L 尺寸 run × 约 3–4 小时（共卡）≈ 30 GPU·时　**实际：**

## 结果（跑完后填写）

## 追加（2026-10-03 21:26）：L × papers（初始化 1–3），受控的规模检验
- **原因：** A' 只用了 c4 与 code，而 E46 / E56 显示代码会在关键期内重新打破对称性（S 尺寸：同初始化 c4–code 层内 M1 0.08 / −0.12，c4–papers 0.20 / 0.26）。L 尺寸的 c4–code 同样 ≈ 0（M1 0.04、M2 −0.05，3 对），所以 A' 测不出规模效应。
- **追加：** `--size L --init {1,2,3} --corpus papers --order {1,2,3}`（`results/e46b2_jobs.txt`）。读数：L 尺寸同初始化 c4–papers 的层内相似度 vs S 尺寸的同一量（M1 0.20–0.26、M2 0.21–0.52）。L 明显更高 → 受控条件下复现“规模越大，继承越强”。

## E46b2 结果（L × papers，3 个 seed；`results/e46b2_scale.json`；2026-10-03 23:10）
| 尺寸 | 同 seed c4–papers（M1 / M2） | 同 seed 涉及代码（c4–code，code–papers） | 不同 seed 同语料（SD） |
|---|---|---|---|
| S（9 个 seed） | 0.19 ± 0.06 / 0.24 ± 0.07 | 0.01 / −0.00（M1） | −0.01 / −0.01 |
| L（3 个 seed） | 0.14 ± 0.04 / 0.14 ± 0.04 | 0.04 / 0.00（M1） | 0.06 / 0.04 |
- 阳性对照 ✓：L 的 M1_max 0.75–0.85、copy gain 4.9–6.3、M2 信度 ≈ 1。
- **结论：** 在超参数固定（batch 64 × 512、lr 1e-3、10,000 步）的受控训练中，参数量大约 30 倍的 L 并不比 S 继承得更强；“自然语言语料之间继承、代码重抽”在 L 上同样成立。→ DataDecide 中继承随规模增强，不是参数量本身的作用，而是随规模一起变化的训练配方的作用；E46c 已排除学习率与初始化尺度，E62 检验 batch 大小。

## D′ 结果（L 尺寸关键期；`results/e46b_D_L.json`）
与父 run（L_i1_c4_o1）终点的层内相似度（M1 / M2）：同 seed 从头训练代码 0.01 / −0.07；第 100 步换代码 0.32 / 0.48；第 1000 步换代码 0.79 / 0.88；第 100 步加 ε = 0.1 噪声 0.87 / 0.94。→ **关键期在约大 30 倍的受控模型上复现**：越早换语料，槽位重排越多，第 1000 步（10%）后基本保留；L 在第 100 步时已保留一部分槽位（S 为 −0.13 / 0.24），关闭得略早。
