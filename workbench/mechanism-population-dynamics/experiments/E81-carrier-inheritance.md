# E81：头角色与因果承担者的继承——信度校正，以及继续训练的后代（2026-10-10）

- **状态：** RUNNING
- **类型：** CLAIM（v3 叙事的两个缺口，见 A10 §5）
- **对应：** A10；E35 / E59（注意力角色）；E42 / E74（因果图）；E75（承担者换人）
- **问题（一句话）：** (A) 在扣除单头测量噪声之后，同初始化跨语料的因果承担者对应是否仍远低于注意力角色对应？(B) 在继续训练（中期训练、SFT、DPO）中，注意力角色与 IOI 因果承担者各自保留多少？
- **事先的强先验：** Tigges（NeurIPS'24）：算法跨训练与规模保持、承担的头会换；Méloux（ICML'26）：单头因果分数噪声大，可能让跨模型相关被低估。若 (A) 校正后因果对应 ≥ 注意力对应，本叙事的中心不成立。

## 设置
- **测量（每个模型）：** IOI（circuits-over-time 的 IOIDataset，N = 200，seed 42，与 E74 相同），按提示奇偶拆半；每个头：END 处直接 logit 贡献（DLA，IO − S）、END 处单头均值消融的 logit 差下降（ABC 参照均值）、END→IO 与 END→S2 注意力；两半各算一次。注意力角色：census.py 的 M1–M4（induction、previous-token、sink、检索），M2 / M3 本来就分两半。
- **(A) 信度：** DataDecide-1B c4 / dolma1_7 / dclm-baseline × 3 seed（9 个已核实模型）。
- **(B) 继续训练链：** OLMo-2-0425-1B stage1 终点 → stage2 ingredient1 step 2000 / 23852 → ingredient2 / 3 终点 → SFT → DPO → Instruct；Pythia-410M 同一 run step 66000 → 100000 → 143000，以及标准版 vs 去重版终点（同初始化、另起炉灶的参照，E75 中承担者换人）。
- OLMo 2 的注意力输出在加回残差前还要经过 post-attention RMSNorm：DLA 在该归一化处按实际尺度线性化（与 final norm 同样处理）。
- 新下载的检查点（SFT / DPO / Instruct）测完即删。

## 读数
- 每种图的模型内拆半信度 r_half（Spearman-Brown 校正到全量）；跨模型对应 r_xy（层内 Spearman，与 E35 / E74 同口径）；信度校正对应 r_xy / √(rel_x · rel_y)。
- (B) 相邻节点之间：注意力角色图对应、IOI DLA 图对应（都做信度校正）；IOI top-3 承担者重合数；前一节点 top-3 在后一节点中的联合消融迁移（与 E75 同口径）。

## 阳性对照
- 每个模型 IOI logit 差 > 1；自身 top-3 联合消融下降 ≫ 随机 3 头；同模型两半之间 DLA 图信度 > 0.8（否则单个模型的测量不可用）。

## 决策表（跑之前写）
- **(A) 分离成立：** 信度校正后，同初始化跨语料的 IOI 因果对应 < 0.3，而注意力角色的校正对应 ≥ 0.5 → v3 的中心成立。
- **(A) 分离不成立：** 校正后因果对应 ≥ 0.5 → 原来的低值主要是测量噪声；中心改写为“单头因果测量噪声掩盖了继承”，不写分离。
- (A) 介于两者之间 → 如实报告，中心降为描述。
- **(B) 后代保留承担者：** 继续训练链上相邻节点 DLA 图校正对应 ≥ 0.7 且 top-3 至少重合 2 个 → 写规则“组件级结论可以搬到继续训练的后代，不能搬到另起炉灶的兄弟”。
- **(B) 后代也换人：** 校正对应 < 0.5 或 top-3 重合 ≤ 1，而注意力角色校正对应 ≥ 0.7 → 写“即使在继续训练中，注意力角色保留，因果承担者也会重新分配”。
- 不追加模型、不换读数。

- 拆半信度（层内 Spearman，与跨模型对应同口径；括号为 Spearman-Brown 校正到全量）：induction 0.98（0.99）、previous-token 0.98（0.99）、END→IO 0.98（0.99）、END→S2 0.98（0.99）、**单头消融 0.70（0.83）**、**DLA 0.25（0.40）**。按数值（Pearson）DLA 为 0.98。
