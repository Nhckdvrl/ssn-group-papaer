# E68：认出初始化——权重 baseline 与 SeedPrints baseline（2026-10-06）

- **状态：** RUNNING（4M–750M 与 1B 最终步已完成；1B@7500 剩 22 个模型）
- **类型：** CLAIM（评审意见“add the weight and SeedPrints baselines”；原稿称头布局“links independently trained siblings whose weights have diverged”，没有和权重本身、SeedPrints 比较）
- **对应：** C05 应用（E61 头布局识别 seed）；论文 §3 / provenance 段
- **问题（一句话）：** 在与 E61 相同的留一语料识别任务上，(a) 最终权重之间的相关、(b) 最终权重与各 seed step0 的相关、(c) SeedPrints（Tong et al., ICLR 2026）能否同样认出初始化？头布局与它们相比处于什么位置？
- **设置：**
  - 模型：E61 用到的全部 DataDecide 模型（4M–750M、1B@7500 五个 seed、1B 最终步 69 个已核实 run），论文所用 checkpoint。
  - (a) 权重兄弟相关：每个模型全部 block 的 2D 权重矩阵按索引拼接（本地缓存），模型两两 Pearson 相关；留一语料、按 seed 平均相关取最大（与 E61 同一判定）。
  - (b) 初始化相关：E67 读出的最终 checkpoint 张量与各 seed step0 的相关，取最大。
  - (c) SeedPrints：n = 2000 条长 1024 的均匀随机 token 序列（固定种子，所有模型相同），取最后一层隐状态在最后一个位置的向量，温度 T = 10 的 softmax 后求均值，取最低的 m = min(0.1 d, 400) 个维度为指纹；两模型指纹维度的交集上逐维计算跨 n 条输入的 Kendall τ，z = τ̄ / (σ/√|S|)，σ² 为独立零假设下 Kendall τ 的方差；识别时用 z 代替相似度，其余同 E61。小尺寸与 1B 同参数；GPU。
  - 脚本：`scripts/e68_baselines.py`。
- **读数：** 每个尺寸三种方法与头布局（E61）的识别准确率；1B 盲测时 6 个未核实 run 能否被各方法标出。
- **阳性对照：** (b) 在 1B 上必须认出（E67 已知 step 2500 时 0.23 vs 0）；SeedPrints 在同语料同 seed 的重复（若有）上应显著。
- **决策表（跑之前写）：** 三种 baseline 都在 ≥ 60M 达到 ~100% → 论文不再说头布局“在权重分道扬镳后仍能认出”，而写成：初始化在权重、输出偏置和头分工三处都留下可检测的痕迹，头布局的特点是它是功能层面的（哪个头做什么），并与权重方法一致地标出 6 个 run；某些 baseline 失败 → 如实写出各方法在哪些尺寸失败。
- **算力预算：** (a)(b) CPU；(c) 约 600 个模型 × 1 分钟内 ≈ 10 GPU·时以内　**实际：**

## 结果（部分，2026-10-06 22:20；`results/e68/analysis_*.json`）
- 识别准确率（留一语料，与 E61 同一判定）：

| 尺寸 | 头布局（E61） | 最终权重互相关 | SeedPrints |
|---|---|---|---|
| 4M / 6M / 8M / 10M | 0.56 / 0.77 / 0.65 / 0.81 | 0.98 / 1.00 / 1.00 / 1.00 | 0.94 / 0.91 / 0.94 / 0.88 |
| 14M / 16M / 20M | 0.83 / 0.85 / 0.63 | 1.00 / 1.00 / 1.00 | 0.94 / 0.82 / 0.97 |
| 60M / 90M / 150M | 0.98 / 1.00 / 1.00 | 1.00 | 1.00 |
| 300M / 530M / 750M | 1.00 | 1.00 | 1.00 |
| 1B 最终步（69 个已核实） | 1.00 | 1.00 | 1.00 |

- 权重：同 seed 异语料的最终权重相关 0.009–0.022，同语料异 seed ≈ 0.000 → 微小但对百万级参数足够显著。
- SeedPrints：同 seed z 7–64（≥ 60M 时 100% 显著；小尺寸 61–75%）；**同语料异 seed 的 z 也有 0.7–9.8（1B 为 9.8，超过 p < 0.01 的阈值 2.58）→ SeedPrints 的统计量混入了共享语料的成分**；头布局与原始权重在同语料异 seed 对上都 ≈ 0。
- 1B 盲测 6 个未核实 run：权重与名义兄弟 0.000、与配对伙伴 0.006–0.018；SeedPrints 与名义兄弟 z 5–11（按其 p < 0.01 检验会被判为同源）、与伙伴 28–83 → 两种 baseline 在相对排序上都能标出这 6 个 run。
- 按决策表：baseline 在 ≥ 60M 都达到 ~100%，权重在所有尺寸都 ≥ 98% → 论文不再说头布局“在权重分道扬镳后仍能认出”，provenance 不作为头布局的应用；识别只作为“痕迹足够具体”的辅助证据，并说明原始权重同样携带初始化（相关 0.01–0.02）。
