# E17 — Is run-level arbitration divergence just knowledge-strength divergence?（2026-10-02）

- **状态：** DONE（2026-10-02；判定：知识强度不能解释 run 间仲裁差异——方向相反）
- **类型：** PILOT（混杂检验，决定 E13 的“使用强度随 run 变化”能否成立）
- **对应：** E13、E16（E16 失败后暴露的混杂）
- **阳性对照：** 在同一个 run 内，跨国家的置信度与采信率应负相关（记得越牢越不采信反事实；Yu 2023 / Fouilhé 2026 的频率效应方向）
- **噪声地板 + MIE：** 国家级 bootstrap；实验单位 = run（n=10）
- **决策表（跑之前写）：** 见下方
- **问题（只回答这个）：** 在 69 个所有 run 都“已知”的国家上，run 间的采信率差异能否由 run 间干净提示下的知识置信度差异解释？

## 读数
- 置信度（每个 run × 国家）= 干净 qa 提示下 lp(正确首都) − max lp(20 个干扰首都)（与 E13 相同的干扰集）。
- 采信率（每个 run × 国家）= E13 的 per_country 采信率。
- 去国家效应：对每个国家，减去该国在 10 个 run 上的均值，得到 run 偏差 Δadopt、Δconf。

## 分析与判据
- 阳性对照：run 内跨国家 Spearman(conf, adopt) < 0（至少 8/10 run）。
- 主检验：合并的 Spearman(Δconf, Δadopt)；以及 run 层面：run 均值采信率对 run 均值置信度的 Spearman（n=10）。
- 方差分解：用 Δconf 线性回归 Δadopt，计算 run 间（run 均值）采信率方差中被解释的比例。
- **“知识强度解释”：** 合并 ρ ≤ −0.4 且 run 间方差被解释 ≥ 50% → E13 的“使用强度随 run 变化”降级为“知识强度随 run 变化”；在数据充分区域，run 共享机制也共享使用方式。
- **“策略差异”：** run 间方差被解释 < 20% → 仲裁策略确实随 run 变化（与知识强度无关）。
- 中间 → 如实报告比例。

- 阳性对照通过：run 内跨国家负相关 10/10。
- 主检验：去国家效应后合并 ρ(Δ置信度, Δ采信率) = +0.08（p = 0.04，**方向与 run 内相反**）；run 层面 ρ = +0.12（p = 0.75）；置信度线性解释 run 间方差 27%（β 为正，即解释的部分方向与“记得牢 → 少采信”相反）。
- **判定：** 不满足“知识强度解释”（需 ρ ≤ −0.4 且解释 ≥ 50%）。介于两分支之间但方向相反 → 结论：run 间仲裁差异**不是**知识强度差异；它是 run 特异的使用倾向（E16：也不是单一一维旋钮）。
- 待排除：该倾向是否为跨模板 / 跨关系稳定的特质、是否由离群 seed4 驱动、是否存在于其他尺寸 → E18。
