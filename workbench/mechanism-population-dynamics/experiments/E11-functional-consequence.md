# E11 — Which realistic in-context tasks does the late gate impair?（2026-10-02）

- **状态：** DONE（2026-10-02；判定：不损害真实任务）
- **类型：** PILOT（功能后果；决定 failure → bottleneck → action 链条是否成立）
- **对应：** C02、E07（上下文级：罕见 token 夹在自然上下文中不被门控）
- **阳性对照：** 常见词 payload 版本在所有 seed、所有 checkpoint 上应几乎无后期变化
- **噪声地板 + MIE：** 每任务每条件 300 个样本，逐样本 bootstrap；10 seed 为实验单位；MIE = 后期损害 ≥0.5 nat（每 token）或准确率下降 ≥10 个百分点
- **决策表（跑之前写）：** 见下方
- **问题（只回答这个）：** 在自然语言外壳中，后期门控会损害哪类上下文任务？损害是否随“罕见内容在上下文中的占比”上升？跨 10 个 seed，损害是否由门控强度（E04 的退化量）预测，而自然文本 loss 相同？

## 任务（全部 300 个样本；罕见 = pile-10k 计数 10–49 的英文词片段池，常见 = 频次排名 500–5000）
- **T1 代码复制：** `The code is:` + payload(k) + `. Again, the code is:` + payload(k)；k ∈ {2, 8, 32}；读数 = 第二次 payload 的每 token loss 与逐 token 准确率。
- **T2 ID 列表：** `IDs:` + 8 个 ID（每个 2 个 token，逗号分隔）+ `. Repeat the IDs:` + 同一列表；读数同上。
- **T3 新标签 few-shot：** 8 对 `word: label.`（word 为常见名词，label 为 1 个 token），随后 8 个查询 `word:`（打乱顺序），预测 label；读数 = label 的 loss 与 top-1 准确率。
- 每个任务都有 payload/label 用罕见池与常见池两个版本。

## 模型
10 个 70M seed × {E02 best step, 64000, 143000}；late = 64000/143000 均值。

## 决策表
- **门控损害真实任务：** 罕见版本中，至少一个任务的后期损害中位数 ≥0.5 nat（或准确率下降 ≥10 pp），且损害随 k（T1）单调上升；跨 10 seed，损害与 E04 退化量 Spearman ρ ≥0.6；常见版本无损害 → 进入 E12（有条件解除门控的最小干预）。
- **只损害罕见主导的上下文：** T1 的 k=32、T2 受损，但 k=2、T3 不受损 → 记录门控影响范围；E12 只针对受损任务。
- **不损害真实任务：** 所有任务后期损害 <0.2 nat → 门控只影响训练分布外的随机序列；功能意义有限，主线回到 F1（机制可复现性）叙事，不做干预方法。

---
## 结果（`results/e11/`，29 个 (seed, step)）
late − best（每 token loss / 准确率），10 seed 中位数：

| 任务 | 罕见 payload | 常见 payload | ρ(罕见损害, E04 门控强度) |
|---|---|---|---|
| T1 k=2 | −0.01 / +0.03 | +0.32 / +0.04 | −0.38 (p=0.28) |
| T1 k=8 | −0.05 / +0.00 | +0.04 / +0.01 | −0.66 (p=0.04) |
| T1 k=32 | +0.14 / −0.01 | +0.30 / −0.01 | +0.41 (p=0.24) |
| T2 ID 列表 | +0.10 / −0.01 | +0.28 / +0.00 | −0.33 (p=0.35) |
| T3 新标签 | +0.41 / −0.02 | +0.40 / −0.02 | −0.44 (p=0.20) |

- **判定：不损害真实任务。** 自然语言外壳中的罕见 payload 任务后期变化很小，与常见 payload 对照相当；损害与门控强度不呈正相关。唯一例外：门控最强的 seed2 在 k=32 上 +2.08 nat。
- **含义：** 门控的影响基本局限于训练分布外的“罕见主导”序列（E08b 的数据真空区）；自然使用场景下各 run 行为一致。按决策表：不做干预方法，主线回到“什么可复现”的科学 / 测量叙事。
