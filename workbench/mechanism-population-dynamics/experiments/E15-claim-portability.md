# E15 — Claim portability across independent runs（2026-10-02）

- **状态：** RUNNING
- **类型：** CLAIM（territory 核心问题的直接回答）
- **对应：** C01、C02、E02（70M、160M）、E13（410M 仲裁）、结构性检查后的主线
- **阳性对照：** 同一 run 内两个相邻 checkpoint 之间的可迁移性应接近 1（陈述定义本身稳定）
- **噪声地板 + MIE：** 可迁移性 = 有序 run 对上的成立比例，run 级 bootstrap CI；MIE = 两类陈述的可迁移性差 ≥ 0.3
- **决策表（跑之前写）：** 见下方
- **问题：** 在一个 run 上得到的机制陈述，在同配置的其他独立 run 上成立的比例（可迁移性）是多少？按陈述类型分层。

## 陈述类型（induction；每个 run 取 post-emergence checkpoint）
| 代号 | 陈述（在参照 run 上得出后，检查目标 run） | 判定 |
|---|---|---|
| A1 算法 | 消融 prev 角色后 induction 注意力降到 ≤50% | 目标 run 的 K-comp 比值 ≤ 0.5 |
| A2 角色必要性 | prev 角色整组消融使复制 loss 上升 ≥ 3 nats 且超过全部随机组 | 目标 run 满足 |
| A3 角色身份 | 单头因果效应最大的头是 prev-token 头 | 目标 run 满足 |
| A4 成分必要性（按角色匹配） | prev 分数最高的单个头单独消融 ≥ 角色整组效应的 50% | 目标 run 满足 |
| A5 成分身份（按编号） | 参照 run 的 top prev 头（层.头编号）在目标 run 中也是 prev 角色头 | 目标 run 满足 |
| A6 层位置 | 目标 run 的 top prev 头与参照 run 在同一层 | 同层 |
| A7 自然使用 | 自然上下文中罕见 token 的复制 loss（E07/E09，p=0.1）与参照 run 相差 ≤ 0.5 nat | 满足 |
| A8 数据真空使用 | 随机罕见序列复制 loss（S6）与参照 run 相差 ≤ 0.5 nat | 满足 |

## 陈述类型（仲裁，410M）
B1 策略：采信率与参照 run 相差 ≤ 5 个百分点；B2 角色：存在记忆头（归因 ≥ 0.3）；B3 成分身份：参照 run 的 top 记忆头编号在目标 run 的 top-3 记忆头中；B4 层：top 记忆头层差 ≤ 1；B5 成分必要性：把各自 top 记忆头 ×2 后采信率下降量与参照 run 之比在 [0.5, 2] 内。

## 前瞻检验（预注册，31M 的 E02 运行之前写）
在 31M 的 10 个 seed（steps 8000 / 64000 / 143000）上运行 E02 协议，预测：

- A5（编号）≤ 0.3；
- A8（数据真空使用，late）< A7（自然使用），差 ≥ 0.3；
- A4、A6 不作预测（70M 与 160M 结果相反，31M 未知）。
