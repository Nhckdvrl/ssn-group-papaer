# E120：MoE 分工测量工具的合成验证（已知答案的路由器）（2026-10-23）

- **状态：** PLANNED
- **类型：** EXPLORE（测量工具校准；不涉及任何真实模型的结论）
- **对应：** MoE 方向的探索第 0 步（讨论见 [knowledge/research/MOE_DISCUSSION_2026-10-23.md](../knowledge/research/MOE_DISCUSSION_2026-10-23.md) 与 10-23 第三轮讨论）。人 10-23 授权开始第 0 / 1 步（只推理、不训练）。
- **问题（一句话）：** 我们准备用来比较 MoE 分工的几个量，在答案已知的合成路由器上，是否真的测到它们声称的东西？
  - 读取子空间重合；
  - 扣除条件零假设后的残差共路由及其跨模型相关；
  - 专家差异（候补顶替）。

## 设置
- **合成数据：** 隐状态 h ∈ ℝ^128。由 16 维潜变量（8 个簇的高斯混合 + 连续成分）线性嵌入，加入特征值衰减的各向异性与小噪声。锚点输入 N = 800（全部 319,600 个输入对），另有独立的校准集 4,000 个。
- **参考路由器 R_A：** E = 16 个专家，线性路由 z = W h + b，top-k（k ∈ {1, 2, 4}）。W 在数据张成空间内随机生成，偏置在校准集上拟合到负载均衡。
- **情形（B 相对 A，答案已知）：**
  - **S0 编号置换：** R_B = 行置换后的 R_A（相同的分工）。
  - **S1 logit 可逆变换：** z_B = A z_A（A 随机可逆）。子空间完全相同，但 top-k 选择改变。
  - **S2 子空间内旋转：** R_B = R_A V Q_θ Vᵀ，θ 从小到大（读同样的特征，边界移动）。
  - **S3 读不同特征：** R_B 只读与 R_A 读取子空间正交的方向。
  - **S4 部分共享：** R_B 的读取子空间与 R_A 共享 m / 15 个方向（m = 4, 8, 12）。
  - **S5 零假设抽样：** R_B 是 R_A 在零假设下的随机抽样（用于标定 T 的零分布）。
  - **S6 表示重参数化：** H_B = M H_A（M 随机可逆、各向异性），R_B = R_A M⁻¹（路由完全相同、表示坐标不同）。
  - **S7 圆周 64 扇区半格错位：** 理论值 NMI = 5/6，二元共路由相关 = 31/63，残差相关 = −1/2。
  - **S8 专家差异：** 合成 MoE 输出 y = Σ g_e f_e(h)，f_e 为线性映射。
    - (a) 所有专家相同；
    - (b) 专家按簇特化。
    - 以原模型输出加噪声为目标。

## 读数（工具）
- **共路由：** C(i, j) = |S_k(x_i) ∩ S_k(x_j)| / k。
- **两种条件零假设**（偏置都在校准集上重新拟合到原负载）：
  - **N1 专家几何保持：** W_c V Q Vᵀ（Q 为 Haar 随机正交）；
  - **N2 logit 协方差保持：** U Σ C^{1/2} Q C^{-1/2} Vᵀ，C = Cov(Vᵀ h)。
- **残差与跨模型相关：** B(i, j) = 零假设下 C 的期望（M = 32 次抽样）；D = C − B；同时报告 ‖D‖（标准差）与 T = corr(D_A, D_B)（在同一组锚点输入对上）。
- **读取子空间重合：**
  - 中心化 logit 的 CCA：取数值有效秩，报告典型相关平方的均值；
  - 线性 CKA 作对照。
- **划分层面：** top-1 的 NMI（对照）。
- **表示迁移诊断：** 把 B 的表示做正交 Procrustes 对齐后交给 R_A，与 R_A(H_A) 的 top-k 一致率。
- **专家差异：**
  - 候补顶替 A(e, j) = 用专家 j 顶替被选专家 e 后的损失变化；
  - 均值钳制 Δℓ = 把 e 的输出换成其被路由样本上的均值后的损失变化。

## 阳性对照与预期（答案已知）
| 情形 | 子空间重合 | T（残差相关） | 其他 |
|---|---|---|---|
| S0 | ≈ 1 | ≈ 上限（同一路由器、不同零假设抽样时 T 的值） | NMI = 1 |
| S1 | ≈ 1 | 明显低于 S0 | 说明 CCA 看不到使用方式的差异 |
| S2 | ≈ 1 | 随 θ 下降，可能为负 | — |

| S4 | 随 m 升高 | 随 m 升高 | — |

| S8 | — | — | (a) A ≈ 0 而均值钳制 > 0；(b) A > 0 |

## 噪声地板 + MIE
- T 的零分布来自 S5（≥ 50 次抽样）。
- 上限来自 S0（有限 M 带来的噪声）。
- 区分“有 / 无”需要超出零分布 95% 区间，并达到上限的 20% 以上。

## 混杂审计
- **数据与零假设：** 合成数据由程序生成，答案由构造给定，无数据混杂。
- **负载匹配：** 两种零假设的负载匹配在留出集上检查，报告偏差。
- **数值问题：** CCA 只取数值有效秩，并用岭正则；报告所用的秩。

## 决策表（跑之前写）
- **某个工具在已知答案处不符合预期** → 不在 OLMoE（E121）上使用该工具，先修正或弃用，并写明原因。
- **S6 中 N2 保持在上限而 N1 下降** → 跨模型比较一律用 N2（重参数化不变）；N1 只作单模型内的“专家几何保持”参照。两者都下降 → 两种零假设都不适合跨模型比较，E121 的跨检查点比较改用别的参照。
- **S1 中 CCA ≈ 1 而 T 明显下降** → 确认“子空间重合 ≠ 使用方式相同”，E121 中 CCA 只作辅助读数。
- **S8(a) 中 A ≈ 0 且均值钳制 > 0** → 确认均值钳制不能作为专家差异的证据；E121 以候补顶替为主读数。
