# E97：损伤一个功能的第一承担头之后，谁接管？——事先预测检验“富者愈富”（2026-10-16）

- **状态：** RUNNING（损伤 + 损伤后图完成；对照与第 0 步图在跑，11:50）
- **类型：** CLAIM（对 E96 候选规则的跨功能、事先登记的检验）
- **来源：** E96：previous-token 枢纽 3.2 受损后，无论保留 QK 还是 OV、无论是否空缺，都不原位恢复；功能确定地流向原本就有弱 previous-token 倾向的头（有备份时 3.0；清零备份时 3.4 / 3.1 / 2.8，与重置部分与随机种子无关）。
- **候选规则：** 训练中一个功能受损后，功能按损伤前各头在该功能上的强弱顺序转移（排在后面的承担者被强化），受损头不原位再生。

## 设置（同 E93 / E96）
Pythia-160M step100k；SDPA + fp32，batch 128 × 1024，学习率 2e-5，warm-up 200，1000 步；对照 E93 C_lo。
1. **损伤前因果图：** 在 step100k 上跑 E89 探针（9 个任务，每头 all / end 均值消融）。
2. **目标选择规则（看损伤前图之后按规则机械执行，不挑）：** 对后继、greater-than、IOI、主谓一致、性别、首都 6 个任务，各取 all 读数第一承担头；若两个任务的第一承担头相同（预期 greater-than 与后继共用序数头），该头只做一次损伤、同时检验两个任务。排除 3.2（E96 已做）。
3. **损伤：** 完整重置目标头（QK + OV，Pythia 初始化分布），不清零其他头；继续训练 1000 步，保存最终权重，再跑 E89 探针得到损伤后因果图。

## 登记的预测与打分
- **主预测：** 对每个被损伤的任务 t，损伤后在 t 上效应增加最多的头（接管者），是损伤前在 t 上排第 2 的头；宽松版：落在损伤前第 2–4 名之内。
- **打分：** 接管者在损伤前排名中的位次；与随机头基线（均匀分布）比较；所有目标合计报告命中率。
- **受损头再生：** 目标头在 t 上的效应恢复到损伤前的 ≥ 50% 视为原位再生（规则预测：否）。
- **捆绑检验（若 greater-than 与后继共用目标头）：** 两个任务的接管者是否为同一个头。规则本身不预测捆绑；若两者分到不同的头，说明 E89 的跨种子捆绑不是由“谁排第二”这种局部顺序自动保证的；若相同，捆绑在修复中被保持。
- **决策：** 主预测在 ≥ 4/6（或去重后的多数）目标上命中 → 规则推广；命中率接近随机 → 规则只在 previous-token 这一种“有多个现成次级承担者”的功能上成立，收窄表述。

**看到的、比登记的预测更具体的东西：**
1. 受损头 1000 步内**完全不再生**（6/6 恰为 0.00），与 E96 完整重置一致。
2. 不是“第 2 名接手”，而是**一部分原有承担者升、另一部分降**：后继中 0.6 降（0.62 → 0.39）而 8.10、8.9 翻倍；性别中 5.8 降、7.5 升；主谓一致中 5.8 降、11.7 / 9.3 / 7.1 升。降的那些可能是“经由受损头起作用”的上游供给者（路径被切断），升的是并行承担者——要用第 0 步图区分“损伤瞬间就发生的再分配（推理时自修复）”与“训练造成的接管”。
3. 捆绑没有保持：greater-than 转给 5.9，IOI 没有一个清晰接管者、且任务本身没有恢复。
4. 按决策表：严格预测 2/6 < 4/6，宽松 5/6 ≥ 4/6——“受损头不回、功能落在原有承担者里”跨功能成立；“按排名第 2 接手”不成立。
