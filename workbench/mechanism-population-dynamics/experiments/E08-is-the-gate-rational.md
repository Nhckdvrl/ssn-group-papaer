# E08 — Is copying actually less reliable in rare-dense contexts of the training data?（2026-10-02）

- **状态：** DONE（2026-10-02）
- **类型：** PILOT（数据层解释；CPU）
- **对应：** C02、E06（罕见度键控）、E07（上下文级、阈值状）
- **阳性对照：** 低密度档命中率应与整体命中率接近（大样本）
- **噪声地板 + MIE：** 二项 95% CI；MIE = ≥10 个百分点且 CI 不重叠
- **决策表（跑之前写）：** 见下方“决策表”一节（运行前写定）
- **问题（只回答这个）：** 在预训练分布（Pile）中，“归纳复制”规则（当前 token 在前文出现过，则下一个 token 等于前次出现之后的 token）的命中率是否随上下文罕见密度下降？若是，门控是对数据统计的合理校准。
- **不回答：** 为什么不同 seed 学到的门控强度不同。

## 设置
- 数据：NeelNanda/pile-10k，Pythia tokenizer，按文档切分（不跨文档），每文档最多 2048 token。
- 对每个位置 t（t ≥ 50）：若 x_t 在 [t−512, t) 内出现过，取最近一次出现 s，induction 预测 = x_{s+1}；命中 = [x_{t+1} = x_{s+1}]。
- **罕见密度**：前 50 个 token 中 pile-10k 计数 < 50 的比例；分 6 档（0–0.1, 0.1–0.25, 0.25–0.5, 0.5–0.75, 0.75–0.9, 0.9–1）。
- 额外：分档内再按“当前 token x_t 本身罕见 / 常见”拆分。
- 计数在同一语料上计算（描述性统计，不是预测性检验）。

## 决策表（跑之前写）
- **合理校准：** 命中率在高密度档（≥0.75）显著低于低密度档（差 ≥10 个百分点，二项 CI 不重叠），且该下降在“当前 token 常见”的子集中也存在 → 门控与数据统计一致（上下文级）。
- **不支持：** 命中率不随密度下降或反而上升 → 门控不是对 Pile 统计的校准；“为什么学到门控”另寻解释（如 Godey 型后期饱和）。

- 判定：**部分支持“合理校准”**——当前 token 罕见时命中率从 50% 降到 12%（CI 不重叠）；当前 token 常见的子集在高密度档样本太少（n=61），无法判定。
- **关键附带事实：** 罕见密度 ≥0.75 的上下文只占训练位置的约 0.006%（244/4.0M）。门控所作用的区域几乎没有数据支持 → 新假说 H_support：**机制的“使用策略”在数据稀疏区域由 run 偶然决定，而在数据充分区域可复现**；预测 seed 间方差随该区域的数据支持度单调上升（用 E07 跨 seed 数据检验）。
