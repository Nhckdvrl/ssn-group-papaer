# E46：受控预训练——数据能否挪动成分位置？初始化扰动的吸引域多大？位置何时锁定（关键期）？（2026-10-03）

- **状态：** RUNNING（2026-10-03；pilot 通过，82 个 run 已排队）
- **类型：** CLAIM（C05 的干预证据：从相关走到因果）
- **对应：** C05（E37 / E40 的锁定时间只有相关证据；E39 / E41 的集体对称性破缺）；A02 §2“受控干预 / 关键期”“初始化的数量”两行；对标 Frankle et al. ICML 2020（instability analysis：在第 k 步分叉）、Summers & Dinneen ICML 2021（隔离随机源、1 bit 扰动）、Achille et al. ICLR 2019（关键期）、Bali ICML 2026（多次重训）、Chan NeurIPS 2022（受控数据）
- **问题（一句话）：** 在自己训练、可控的小 Llama 式模型中：(1) 把语料从网页换成代码 / 论文 / 书籍，同一初始化的头位置是否仍然相同？(2) 对初始权重加多大的扰动才会改变位置？(3) 在训练第 k 步扰动权重或换语料，k 到多大以后最终位置就不再改变？
- **设置：**
  - 模型：Llama 式（RMSNorm、SwiGLU、RoPE、不共享嵌入；OLMo 分词器，vocab 50304）。S = 4 层 × 8 头，d = 256，ffn 1024。训练：AdamW（lr 1e-3、β = (0.9, 0.95)、wd 0.1）、warmup 300、余弦降到 10%、batch 64 × 512 token、10,000 步（3.3 亿 token）、bf16 autocast（`scripts/e46_train.py`）。
  - 语料（`/home/xiang/mechpop_cache/e46_data/`，DataDecide-data-recipes 单个源文件的前 4 亿 token）：c4（网页）、code（StarCoder）、papers（peS2o）、books（Gutenberg）。数据顺序 = 随机 513-token 窗口，由 order seed 决定。
  - **A 交叉：** 6 个初始化 × 4 个语料（order seed = init seed，同 DataDecide）= 24 个 run。
  - **B 只换顺序：** 初始化 1、2 × c4 × 两个新的 order seed = 4 个 run。
  - **C 吸引域（step 0 扰动）：** 初始化 1、2 × c4，给每个参数张量加 ε · std(张量) · N(0, 1)，ε ∈ {0（同设置重跑，只剩 GPU 非确定性）, 1e-6, 1e-4, 1e-2, 1e-1, 1} = 12 个 run。
  - **D 关键期（第 k 步分叉，从父 run 保存的模型 + 优化器状态继续）：** 父 run = 初始化 1、2 × c4；k ∈ {100, 250, 500, 1000, 2000, 4000, 8000}（训练的 1%–80%）；三种分叉：权重扰动 ε = 0.1、权重扰动 ε = 1、换语料为 code（新顺序）= 2 × 7 × 3 = 42 个 run。
  - 测量：每个 run 在 13 个固定步数测 M1（induction）、M2（previous-token）、M3（sink）图，探针与 E35 相同；另记 copy gain 与自然文本损失。
- **读数：**
  - A / B：最终步 [层×头] 图的两两 Spearman，SI（同初始化异语料）/ SD（同语料异初始化）/ DD，以及同初始化异顺序。
  - C：每个 ε 下最终图与未扰动 run 的 Spearman；以“同设置重跑”与“新初始化（A 中同语料的 SD）”为上下参照。
  - D：每个 k 下分叉 run 最终图与父 run 最终图的 Spearman；锁定时间 k* = 相似度首次达到“父 run 与自身重跑的相似度”的 90% 的 k。
- **阳性对照（pilot 决定能否用 S 尺寸）：** 父 run 在 step 4000 前出现 induction 头（M1_max > 0.3）且 copy gain > 2 nats；M2 两半信度 ≥ 0.8；同设置重跑的最终图相似度 ≥ 0.9（否则 GPU 非确定性本身就会打乱位置，读数需改用相对基线）。pilot 不过 → 改用 M 尺寸（6 层 × 8 头，d = 512）或延长训练，在这里注明后再跑主体。
- **噪声地板 + MIE：** A：SI − SD > 0.1（与 E35 同一门槛）。C / D：以重跑相似度为上限、SD 为下限，按区间中点判定“改变 / 未改变”。
- **混杂审计：** 小模型、短训练，与 1B 不同 → 只回答机制问题，尺寸外推由 E45 承担；四个语料来自单个源文件的前缀（多样性低于完整语料，写进范围）；分叉 run 精确延续父 run 的数据流（RNG 前推，代码已核对）；扰动按张量相对 std，RMSNorm 权重在 step 0 时 std = 0，因此不受扰动（写明）；全部 run 纳入。
- **决策表（跑之前写）：**
  - **A：** M1、M2 的 SI − SD > 0.1 → 受控条件下复现 C05，且数据差异远大于 DataDecide（网页 vs 代码 vs 论文 vs 书籍）；≤ 0.1 → 受控条件下不复现，C05 的解释改为依赖 DataDecide 的特定设置，如实报告。
  - **C：** 微小扰动（≤ 1e-4）下相似度仍接近重跑水平，大扰动才降到 SD 水平 → 写成“位置有有限的吸引域”（与 Summers & Dinneen 的“1 bit 即全变”形成对照）；微小扰动就降到 SD 水平 → 写成“位置对初始化是混沌的”，并据此重新解释 A 中的 SI 相似度。
  - **D：** 存在 k* 且 k* ≤ 训练的 10% → 写成“关键期”：早期扰动能重排位置，之后不能，并与相关估计（E37 3.6%、E40 2%）比较；扰动在任何 k 都不改变位置 → 写成“位置在 step 0 就已决定”；任何 k 都改变 → 没有锁定，与 E37 / E40 矛盾，如实报告并排查。
  - 换语料分叉：预期所有 k 都接近父 run（C05）；若早期换语料显著改变位置 → 数据在早期能起作用，修改 C05 的表述。

- **A（交叉，24 个 run）：** 全图 SI − SD：M1 **0.033**（置换 p 0.018）、M2 **0.071**（p < 0.002）；层内 SI 0.070 / 0.113，SD −0.019 / −0.034。→ 按决策表（> 0.1）：**S 尺寸、这 4 个语料下，未在受控条件下复现 C05**（效应显著但小）。POST-HOC 拆分（看过数据后）：自然语言语料之间的同初始化 induction 继承 0.202，涉及代码的 0.026 → 由 E56 用新初始化做确认。
- **B（只换数据顺序）：** 与同初始化原 run 的层内相似度 M1 0.53–0.86、M2 0.51–0.86（重跑 0.91–1.00）→ 在 S 尺寸上，早期批次的具体顺序也部分影响位置（与 Pythia 160M 的“换顺序 ≈ 重跑”不同；规模差异）。
- **C（初始化扰动剂量）：** 层内相似度（M1 / M2）：ε = 1e-6 → 0.96–0.99 / 1.00；1e-4 → 0.84–0.98 / 0.99；1e-2 → 0.91 / 0.95；0.1 → 0.58 / 0.57；1 → 0.05 / 0.18（约等于新初始化）。→ 按决策表：**位置有有限的吸引域**：≤ 1% 的相对扰动下与重跑无异，10% 时明显改变，扰动与权重同量级时完全重排；与 Summers & Dinneen（1 bit 即全变，针对预测与权重）形成对照。

### D 组结果（关键期；初始化 1 全部 k，初始化 2 的 k = 100 / 250 / 500；`results/e46/analysis.json`；21:16）

- **结论：存在关键期，在训练的 1%–2.5% 之间关闭。** 关闭之前，换数据或加噪声都会把头的位置重新抽一次；关闭之后，即使加入与权重本身同样大的噪声，位置也回到原来的槽位（0.85–0.97），换成代码语料也保留大部分位置，且越晚换保留越多。也就是说，关键期之后的槽位是一个吸引子。
- 与 lock-in 曲线一致：父 run 与自身终点的相似度在 step 100 时 M1 0.25 / M2 0.67，step 1000 时 0.83 / 0.92。
- 叙事意义：这是 Achille et al.（2019）“关键期”在机制层面的对应，而且更强：他们测的是缺陷对性能的影响，我们测的是哪个成分承担哪个角色。公开套件中的锁定时间（1B 3.6%，E37；Pythia-70M ≈ 2%，E40）落在同一区间。
