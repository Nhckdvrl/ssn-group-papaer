# E100：训练早一些的模型，能不能从头招募新的承担者？（2026-10-16）

- **状态：** DONE（19:45；5000 步）
- **类型：** CLAIM（训练期可塑性）
- **来源：** E98：在 step100k 完整重置 8.9 后，IOI 的正向角色 5000 步内无人接手，IOI 卡在 40%；能恢复的功能都靠放大已有的部分承担者（E96–E98）。
- **问题：** 这是**模型训练到后期**才出现的可塑性限制（早期的模型会从头长出新的承担者），还是与训练阶段无关的结构限制（没有现成的部分承担者，就补不回来）？
- **近邻：** Kim et al. ICLR 2025 / Chang et al. NeurIPS 2024（训练后期获取新知识变难，且不是学习率衰减造成的）；可塑性丧失文献（Lyle 2023、Dohare 2024）；［更正 2026-10-16 21:15：此前误记为 Hapax 的结果。Hapax（Şahin et al. 2025/26）是屏蔽可由 induction 预测的 token 的损失，与重初始化无关；“重初始化 induction 头后长出更多 induction 头、重置优化器状态则卡住”的出处未核实，不再引用］。它们都没有在组件层面区分“放大已有的”和“从头招募”。

## 登记的预测与决策（看结果前写）
- **从头招募的指标：** 某个损伤前 IOI 效应 < 0.2 的头，在 5000 步时比对照高 ≥ 0.5。
- **后期才受限：** step43000 的损伤出现从头招募，且 IOI 恢复比例 ≥ 0.7（step100k 是 0.40）→ 训练后期丧失的是“招募新承担者”的能力；放大已有承担者的能力仍在。
- **结构限制：** step43000 同样无人招募、恢复约 0.4 → 与训练阶段无关，取决于有没有现成的部分承担者。
- **混杂：** 若 step43000 的损伤前图中存在强次级承担者（效应 ≥ 第一承担头的 50%），那么它的恢复不能作为“可塑性更高”的证据，只能作为“有次级就能补”的又一个例子——事先说明，不事后改口径。

**新脚本 e101_nameattn.py：** 在 IOI 提示上测每个头从句末看向间接宾语名字（IO）与主语名字（S）的注意力，以及它对 logit(IO) − logit(S) 的直接贡献（DLA）。

| 头 | step8000 看 IO / 看 S / DLA | step43000 | step100k |
|---|---|---|---|
| 8.9（受损） | 0.07 / 0.85 / +2.42 | 0.08 / 0.69 / +2.66 | 0.03 / 0.94 / +2.00 |
| 9.5（接手者） | 0.00 / 0.01 / 0.00 | **0.59** / 0.40 / −0.13 | **0.74** / 0.24 / −0.33 |
| 10.2 | 0.01 / 0.03 / −0.01 | 0.47 / 0.13 / −0.10 | 0.69 / 0.28 / −0.12 |

- **8.9 不是 GPT-2 那种“看 IO、复制 IO”的名字移动头。** 它看的是 S（0.85–0.94），对 IO − S 的直接贡献却很大且为正，也就是压低 S。
- **接手者 9.5 用的是另一条路：** 它在损伤前就已经在看 IO（43k 0.59，100k 0.74），但输出是负的（轻微压低 IO）。损伤后它的输出翻成正，变成复制 IO。功能由另一种算法恢复，而执行者是一个注意力早已对准的头。
- **step8000 恢复最慢的原因：** 那时没有任何头看 IO（9.5 为 0.00，最高的 8.1 / 10.7 约 0.37，且输出接近 0），所以没有可以被翻转的现成耦合，也没有头被招募。
- 这与 E96 / E99 / E101 的耦合规律一致：训练只沿已有耦合修复。耦合可以是读者对准受损头（E99），也可以是一个注意力已经对准的头只需改输出（这里的 9.5）。
- **注意：** 这是对 E100 原问题的回答——不是“训练越晚越不可塑”，而是“训练阶段决定了此时存在哪些现成耦合”；43k / 100k 有 9.5，8k 没有。证据目前只有这一个功能、一个接手者。

## 20:05 更正：接手者 9.5 学的是 8.9 原来的算法，不是另一种算法
