# E07 — Context-level gate or token-level degeneration?（2026-10-02）

- **状态：** DONE（2026-10-02；判定：上下文级门控，token 级退化可忽略）
- **类型：** PILOT（替代解释的判别）
- **对应：** C02、E06（门控按罕见度键控）
- **替代解释（必须先排除）：** 小模型训练后期罕见 token 的表示退化（Gao et al. 2019 representation degeneration；Godey et al. 2024 小模型后期饱和），使 induction 头对罕见 token 匹配失败。若如此，“门控”只是 token 级退化的副作用，而不是一个按上下文工作的机制。
- **问题（只回答这个）：** 复制抑制取决于**目标 token 自己是否罕见**（token 级），还是取决于**上下文中罕见 token 的密度**（上下文级）？

## 刺激
- 基底：Pile 自然片段（eval 第 1000–1499 条，位置 1–50）。
- 以比例 p ∈ {0, 0.1, 0.25, 0.5, 0.75, 1.0} 随机选位置，替换为罕见 token（pile-10k 频次 10–49 的池，均匀抽）；序列结构 [BOS]+X+X，第二段与第一段完全相同。seed 固定，同一基底在不同 p 下嵌套（p 小的替换集合是 p 大的子集）。
- 读数按**目标 token 类型**拆分：第二段中预测“被替换的罕见 token”的位置（R-target）与预测“原自然 token”的位置（N-target）各自的中位 loss。

## 模型
10 个 seed × {best step, 64000, 143000}。

## 预测与决策表（跑之前写）
- **token 级退化：** R-target loss 在所有 p 下都高（≈ p=1 时的水平），且基本不随 p 变；N-target loss 不随 p 上升 → 支持退化解释，C02 需重写为“罕见 token 表示退化导致复制失败”，“门控”叙事作废。
- **上下文级门控：** R-target loss 随 p 单调上升（p=0.1 时远低于 p=1），且 N-target loss 也随 p 上升（常见 token 在罕见密集的上下文里也被抑制）→ 支持上下文门控。
- **混合：** 两个效应都有 → 报告各自份额（p=1 vs p=0.1 的 R-target 差 = 上下文成分；p=0.1 的 R-target vs p=0 的 N-target 差 = token 成分）。
- 所有判定以 late 减 best 的变化量为准（只关心后期获得的那部分）；在低门控 seed（3、6、9）上效应应小。

## 算力
30 × ≈1 min。

## 结果（2026-10-02，`results/e07/`，29 个 (seed, step)）
第二段中位 loss，跨 10 seed 的均值 ± SD（late = 64000/143000 均值）：

| 罕见密度 p | R-target late | R-target best | N-target late |
|---|---|---|---|
| 0 | — | — | 0.11 ± 0.02 |
| 0.1 | 1.10 ± 0.17 | 0.96 ± 0.17 | 0.10 ± 0.02 |
| 0.25 | 0.62 ± 0.12 | 0.58 ± 0.11 | 0.11 ± 0.02 |
| 0.5 | 0.48 ± 0.11 | 0.45 ± 0.11 | 0.14 ± 0.03 |
| 0.75 | 0.72 ± 0.40 | 0.55 ± 0.19 | 0.31 ± 0.16 |
| 1.0 | 3.14 ± 2.90 | 1.08 ± 0.48 | — |

- **上下文级门控：成立。** 同一批罕见 token 在稀疏混入时，后期与最好 checkpoint 几乎一样（+0.14 at p=0.1）；只有在罕见主导的上下文中，后期才出现抑制（+2.06 at p=1.0），且常见目标 token 也随密度变差（0.10 → 0.31）。**token 级表示退化可以忽略**（若是退化，p=0.1 时 R-target 应已很高）。
- 抑制随密度呈阈值状（p ≤ 0.5 几乎为 0，p ≥ 0.75 才出现）。
- **H_support 的检验（E08 提出）：** late R-target 的 seed 间 SD 为 0.17 / 0.12 / 0.11 / 0.40 / 2.90（p = 0.1 … 1.0），best checkpoint 为 0.17 / 0.11 / 0.11 / 0.19 / 0.48 → 后期 seed 方差只在数据几乎无支持的区域（E08：密度 ≥0.75 只占 0.006% 训练位置）爆炸。
