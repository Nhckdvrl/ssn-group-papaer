# E48b：线索替换干预的加大剂量版（2026-10-03）

- **状态：** DONE — P1 不成立，按计划止损
- **类型：** CLAIM（E48 决策表中“P1 不成立 → 剂量不足 → 另开卡”的预定后续；**只做这一次加剂量，若仍不成立则止损**）
- **对应：** C04；E48（90M、10% Flan、1 亿 token，约 1000 万 Flan token：两个初始化的预览中 orig − none 的 QA 线索效应为 −0.25 / −0.48，没有装入开关）；E29（DataDecide 中开关最早在 step 2500 检出，此时约见过 5000 万 Flan token）；E30（OLMo 2 中期训练 16.6% FLAN，约 50 亿 token 时出现）
- **问题（一句话）：** 当 Flan 剂量提高到与 DataDecide 检出点相当（约 9000 万 Flan token）时，原版 Flan 能否在无 Flan 模型上装入 “Question:” 开关（P1）？改写模板的 Flan 是否把触发词移到 “Query:”（P2、P3）？
- **设置：** 与 E48 完全相同（同一脚本 `scripts/e48_cueswap.py`、同一 Flan 文件与改写、同一基础混合、同一读数与配对分析），只改：
  - 尺寸：60M（E47 中天然开关 +1.71；最便宜）；初始化 default / small-aux-2 / small-aux-3；条件 orig / swap / none。
  - **Flan 比例 30%，3 亿 token（约 9000 万 Flan token）**；读数在 0 / 5000 万 / 1 亿 / 2 亿 / 3 亿 token；**判定点 = 3 亿 token**。
  - 命令：`--train --size 60M --seed S --cond C --tokens 300000000 --p-flan 0.3 --evals-at 0,50000000,100000000,200000000,300000000`。
- **读数 / 判据：** 与 E48 相同（P1：Δ_orig(QA) > 2·SE；P2：Δ_swap(novel) > 2·SE；P3：两个交叉特异性 > 2·SE；按初始化配对，SE = 配对差 SD / √3）。
- **阳性对照：** P1 本身；训练损失正常；none 条件下已知条目数下降 < 20%。
- **噪声地板 + MIE：** 同 E48（df 2，偏松）。
- **混杂审计：** 30% Flan 远高于 Dolma 的 1.3%，会带来更大的分布变化，由 none 条件（同样比例的槽位填入基础文本）控制；只有一个尺寸；Flan 文件共 8000 万 token，9000 万 Flan token 的需求以随机窗口有放回抽取（约 1.1 遍），三个条件的抽取位置相同。
- **决策表（跑之前写）：**
  - P1 成立 → 看 P2 / P3，按 E48 决策表写结论（“数据中的字面模板决定触发词”或其部分版本）。
  - P1 仍不成立 → **止损**：写成“在继续预训练的设定中，即使剂量与 DataDecide 检出点相当，Flan 也没有装入开关；开关的形成可能依赖从头预训练中的早期暴露（与 E29 的 3.6% 出现时间一致）”，不再追加剂量或设定。

## 结果（跑完后填写）

- **判定：** P1 不成立：在约 9000 万 Flan token（与 DataDecide 中开关出现时的暴露量相当）之后，原版 Flan 的 QA 线索效应 +0.04，远低于 DataDecide 60M 模型天然具有的 +1.71；P2、P3 无从谈起。
- **按决策表止损：** 写成“在继续预训练中，即使 Flan 剂量与 DataDecide 的出现点相当，也没有装入开关；开关在从头预训练中出现（E29：训练 3.6% 时），OLMo 2 中期训练用了数十亿 token 量级的 FLAN 才装入（E30）”。不再追加剂量或设定。C04 的主体证据（DataDecide 有 / 无 Flan 的预训练配对、OLMo 2 中期训练、线索拆解、三个数据集、跨尺寸）不变；“改写模板使触发词迁移”这一因果预测没有得到支持，作为局限写入。
