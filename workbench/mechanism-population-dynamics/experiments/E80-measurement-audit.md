# E80：测量审计——E77 的两个候选观察在更严格的读数下是否还在？（2026-10-10）

- **状态：** RUNNING
- **类型：** PILOT（决定 E77 的哪一部分可以继续作为中心候选）
- **对应：** E77（候选观察 O1：问答格式 / Flan 的作用落在与主语无关的“照抄推动”上；O2：γ 随训练下降）；外部审计意见（2026-10-10 下午，经核对后接受的部分：首 token 与整句答案必须分开；虚构主语不是完全中性的对照；全局斜率受知识分布影响，应在共同知识区间比较；发育分解的残差为零是构造使然，只作描述；γ-IV 与原读数共享虚构基线，不能当作无偏校正）
- **问题（一句话）：** 在只看首 token 的读数、三个不同虚构主语、一个独立数据集（ParaConflict）和完整的 Flan / 无 Flan 三 seed 终点配对下，O1 与 O2 是否仍然成立？
- **为什么先做这个：** E77 只存了整句 log 概率之和，无法事后拆出首 token；用旧读数继续跑完剩下的 180 多个检查点，等于把一个可能有偏的测量测得更准。E77 派发已停止（在跑的 12 个任务跑完为止）。

## 设置
- **条目：** (a) PopQA：E77 的 3596 条，主语、答案、反事实不变；(b) ParaConflict：E26 的拆法（单句冲突 S、问句 q、答句开头 stem），只保留主语字符串同时出现在 S、q、stem 中的条目，6 种关系。
- **虚构主语：** 每条 3 个（A / B / C），用不同随机种子的音节拼接生成，彼此独立。
- **单元（每条 14 个提示 × 2 个候选）：** 真实主语 `clean_decl`、`clean_qa`、`c1_decl`、`c1_qa`；每个虚构主语 v ∈ {A, B, C} 的 `n{v}_clean`、`n{v}_c1_decl`、`n{v}_c1_qa`；外加 `nA_clean_qa`。
- **记分：** 每个候选同时保存首 token 的 log 概率与整句答案的 log 概率之和。
- **模型（61 个，只选决定性的子集）：**
  - DataDecide-1B dolma1_7 与 dolma1_7-no-flan × 3 seed × step {2500, 17500, 35000, 69369}（24 个）
  - OLMo-2-1B stage1 终点；stage2 ingredient1 {2000, 6000, 12000, 23852}；ingredient2 / 3 终点；SFT、DPO、Instruct（10 个）
  - Pythia-160M、Pythia-410M 各 9 个检查点 {1000 … 143000}；Pythia-410M seed1–9 终点（27 个）
- 新下载的检查点测完即删；白天不超过 12 张卡。

## 读数
- m = lp(真实答案) − lp(反事实)，首 token 与整句两套。
- **格式分解（O1）：** F_total = 真实主语的 mean[(−m_c1_qa) − (−m_c1_decl)]；F_nonce = 三个虚构主语上同样的量取平均；F_spec = F_total − F_nonce（主语特定部分）。
- **Flan 效应：** Δ = mean_3seed(Flan) − mean_3seed(无 Flan)，分别对 F_total、F_nonce、F_spec 计算，SE 由两组 seed 方差合并（df 4）。OLMo：stage2 三个 ingredient 终点 − stage1 终点（3 个配对，同一起点，不是独立重复，只作第二个训练栈的方向检验）。
- **γ（O2）：** k = c − n0（n0 取三个虚构主语的平均），d = m_c1(真实) − m_c1(虚构平均)；在所有比较对象**共同覆盖的 k 区间**内分箱比较 d(k) 曲线，不再用全局斜率作主读数。
- **虚构主语有效性：** (i) 三个虚构主语之间 F_nonce 的差异；(ii) 真实主语中 |k| < 0.5 的条目（模型不认识的真实实体），其格式效应是否与 F_nonce 接近。

## 阳性对照
- 每个终点模型的 `c1_decl` 首 token 采信 > 0；Flan 模型 F_total（首 token）> 0。

## 决策表（跑之前写）
- **O1 保留为中心候选：** 在首 token 与整句两套读数、PopQA 与 ParaConflict 两个数据集上，都满足 ΔF_nonce / ΔF_total ≥ 0.7 且 |ΔF_spec| < 2·SE；同时 OLMo 中期训练方向一致。→ 下一步设计受控训练（早 / 晚检查点 × 数据类型），检验这个“与主语无关的照抄推动”在不同训练阶段如何被写入。
- **O1 改写：** ΔF_spec ≥ 2·SE 且占 ΔF_total 的 30% 以上（任一数据集 / 读数）→ Flan 也改变了记忆在冲突中的作用；如实写成两部分，不作为“只改推动”的中心。
- **O1 放弃：** ΔF_total 在 ParaConflict 或首 token 读数上 < 2·SE → 格式效应本身在更严格读数下不稳，回到 REVIEW 重新判断。
- **O2：** 在共同 k 区间内，Pythia-410M step 2000 与终点的首 token 曲线之差 < 2 × 9 个 seed 终点曲线的标准差 → O2 放弃（发育中的 γ 下降是测量 / 分布产物）；≥ 2 倍 → O2 保留为描述性观察，但不作为中心。
- **测量无效：** 三个虚构主语之间 F_nonce 的差异大于 Flan 效应 ΔF_nonce 本身 → 虚构对照不能用，O1 的分解不可判定。
- 后训练（SFT / DPO / Instruct）：只描述，不预测。

## 结果（跑完后填写；不改上面的内容，修改需注明日期）

### 第一项判定：Flan / 无 Flan 终点（2026-10-10 17:20；DataDecide-1B step69369 × 3 seed × 2 配方；`results/e80/analysis.json`）
| 数据集 / 读数 | ΔF_total（SE） | ΔF_nonce（SE） | ΔF_spec（SE） | ΔF_nonce / ΔF_total |
|---|---|---|---|---|
| PopQA / 整句 | +1.88（0.50） | +1.32（0.49） | +0.56（0.16） | 0.70 |
| PopQA / 首 token | +1.77（0.48） | +1.29（0.48） | +0.48（0.15） | 0.73 |
| ParaConflict / 整句 | +2.16（0.59） | +1.26（0.41） | +0.90（0.48） | 0.58 |
| ParaConflict / 首 token | +2.10（0.56） | +1.25（0.39） | +0.85（0.48） | 0.60 |
- **按决策表：O1“只改照抄推动”不成立**（PopQA 两种读数上 ΔF_spec 超过 2·SE；ParaConflict 上比例 < 0.7）。PopQA 整句上 ΔF_spec 为 3.5 SE、占 ΔF_total 30% → 触发“O1 改写”：Flan 的问答格式效应约 60–73% 是与主语无关的照抄推动，另有约 27–42% 是主语特定部分（已知主语在问答格式下对冲突上下文的抵抗变小）。
- **格式效应本身稳健：** ΔF_total 在两个数据集、两种读数上都 > 3.5 SE（C04 在首 token 读数与 ParaConflict 上复现）。首 token 与整句给出几乎相同的结论。
- **虚构主语对照有效：** 三个虚构主语的 ΔF_nonce 完全一致（1.32 / 1.32 / 1.32；1.25 / 1.27 / 1.25）；模型不认识的真实主语（|k| < 0.5，约 700 条）的格式效应与虚构主语接近（6 个模型中 5 个差 ≤ 0.25，无 Flan aux-2 差 0.40）。
- **POST-HOC（看到结果后才注意到，单独标注）：** 无 Flan 模型的 F_spec 为负（−0.40 到 −0.46）：没有 Flan 时，问答格式让已知主语比虚构主语更抵抗上下文（提问可能促进回忆）；Flan 模型 F_spec 接近 0 或为正。即 Flan 同时做了两件事：加大问答格式下的照抄推动，并抵消问答格式对回忆的促进。需要在独立条件下检验，不进入主张。
- 运维：两次失败是 hanyi 的 vLLM 占用了 fvcrc13 GPU0/1 造成的显存不足，任务已由其他 worker 重跑成功；fvcrc13:0/1 的 worker 已撤下，换到 fvcrc15:0/1，总数仍 12。

### 第二项：OLMo 中期训练与 O2（2026-10-10 18:00；59 / 61，SFT / Instruct 因 hanyi 占卡显存不足，在 fvcrc15 重跑中）
- **OLMo 中期训练（stage2 三个 ingredient 终点 − stage1 终点，首 token）：** PopQA ΔF_total +1.74 / +2.13 / +2.51，ΔF_nonce +1.96 / +2.33 / +2.48，ΔF_spec −0.22 / −0.20 / +0.03；ParaConflict ΔF_total +1.50 / +2.09 / +2.17，ΔF_spec −0.49 / −0.29 / +0.04。→ 中期训练带来的格式效应几乎全部是与主语无关的推动；主语特定部分接近 0、符号不定。
- **POST-HOC 对比（不同训练栈，混合物也不同，只作线索）：** DataDecide 从头预训练中加入 Flan，主语特定部分为 +0.5 到 +0.9；OLMo 中期训练中为 ≈ 0。候选解释：指令数据只有在模型习得知识的同时出现时，才改变已知主语在问答格式下对上下文的抵抗。需要受控训练检验。
- **DPO（描述）：** PopQA F_total 4.54（nonce 4.02，spec +0.52）；ParaConflict 4.02（nonce 2.77，spec +1.25）。SFT / Instruct 待重跑。
- **O2 判定（按登记的逐箱判据，首 token 为主读数）：** Pythia-410M 共同 k 区间内，step 2000 与终点首 token 曲线之差 / (2 × 9 个 seed 终点标准差)：PopQA 0.54 / 0.50 / 0.52 / 0.20 / 0.16（全部 < 1）→ **O2 放弃**。整句读数下斜率 0.47 → 0.48，不变；E77 看到的 γ 0.87 → 0.61 主要来自知识分布变化。ParaConflict 曲线有整体平移（1.3–3.0 倍），斜率变化不到 2 倍标准差。未登记的观察：PopQA 首 token 斜率按步数 0.44 / 0.60 / 0.39 / 0.28 / 0.34 / 0.33 / 0.32 / 0.24 / 0.22（seed 终点 0.32 ± 0.09）。
