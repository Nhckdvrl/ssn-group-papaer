# E10 — How do the copy gate and its between-run spread depend on capacity?（2026-10-02）

- **状态：** RUNNING（冻结于运行前）
- **类型：** PILOT（全局定位：门控在模型族中的位置）
- **对应：** C02；E09（160M 群体无门控）；Godey 2024（≤410M 后期饱和，≤160M 末层各向异性）；Anand 2025（罕见 token 结构性 ICL 消退）
- **阳性对照：** 70M 已有结果（E06/E07）作为参照点，必须在本卡的读数下复现
- **噪声地板 + MIE：** 每个尺寸 10 个 seed；MIE = 尺寸间门控中位数差 ≥0.5 nat
- **决策表（跑之前写）：** 见下方
- **问题（只回答这个）：** 在 PolyPythias 的 14M / 31M / 70M / 160M（各 10 个 seed）上，后期按罕见度键控的复制门控强度如何随容量变化？run 间离散度在哪个容量最大？

## 设置
- 模型：`pythia-{14m,31m}` 与各自 `seed1..9`；70M 用 E06/E07 已有结果并补跑 E09 读数（保证读数一致）；160M 用 E09。
- checkpoint：{4000, 8000, 16000, 64000, 143000}；best = 前三者中 S6 CL 最低者；late = 64000/143000 均值。
- 读数：E09 脚本（六类刺激、密度扫描、逐层正向平移）。另记录 S1 自然重复的 CL（判断该尺寸是否具备复制能力）。

## 决策表
- **容量压力模型：** 门控中位数（S6 的 late − best）随尺寸单调下降（14M ≥ 31M ≥ 70M > 160M），且 run 间 SD 在小尺寸最大 → 门控是“容量不足时对罕见上下文放弃复制”的分配策略；论文主线定位为“小模型 ICL 消退的机制 + 为什么是 run 特异的”，并以 Godey 饱和作为上游条件检验。
- **非单调（70M 最强）：** 门控只在一个中间尺寸出现 → 不是简单容量规律；报告为尺寸特异现象，主线回到机制可复现性的方法学（E01/E02）+ 门控作为案例。
- **小尺寸无复制能力：** 14M/31M 的 S1 CL 显著高于 70M（> 1 nat）→ 这些尺寸没有可门控的电路，比较只在 31M（若有）/70M/160M 之间进行。
