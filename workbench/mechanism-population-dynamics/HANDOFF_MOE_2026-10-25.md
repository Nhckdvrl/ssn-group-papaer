## 2. 研究问题（经三轮外部反馈讨论收敛）

### 2.1 核心问题
> MoE 语言模型中，专家之间是否真的分担了不同的语言计算？如果是，这种分担在独立训练间重现到什么程度、有多大自由度、由什么决定？

拆成三个依次衔接的判断，前一个不成立，后一个就没有对象：
1. **J1 研究对象是否存在：** 路由里有没有可重复测量、超出 token 身份和几何零假设的语言组织？
   - **现状：** OLMoE 上词性组织存在（E121）。
2. **J2 组织是否对应真实的计算差异：** 被选中的专家与其他专家之间，是否有可重复测量的、有条件选择性的计算差异？
   - **现状：** 差异存在、很大，但不沿词性组织（E121 R3）。
   - **组织与差异之间的关系未知**，这是 X1 要回答的。
3. **J3 自由度与成因：** 在相同的语言计算需求下，独立训练是否反复选中同一种组织？如果存在多种可行组织，训练偏向哪一种，由什么决定（表示几何、路由—专家正反馈、早期历史、设计选择）？
   - **现状：** 完全未知，这是 X2–X4 要回答的。

### 2.2 两个方向（共用 X2 这个受控设置）
- **方向 A（主）：** 同样的语言计算需求，为什么形成相同或不同的专家分工？对应 J1–J3、X1、X2。
- **方向 B（机制）：** 已经形成的专家职责靠什么维持：路由器的选择、专家的读取，还是下游对专家输出的读取？早期历史如何改变它？
  - 对应 X3、X4，接上头线最可靠的经验：只重置读取参数，角色会回来；把输出旋转，就不回来。
- **不要同时立两个项目。** B 只在 A 出现需要解释的现象后启动。

### 2.3 “两种分工真正不同、却都可行”的操作定义（不要求严格证明，只要求事先规定）
1. **都可行：**
   - 事先规定等价范围 ε；
   - 在留出数据的总体损失和指定语言条件的损失上都做等价性检验（TOST），不能用“差异不显著”代替。
2. **组织真正不同：** 第二段残差相关 T（§4.1）明显低于两条参照线：
   - 同一 run 内的参照区间（E121 R4 给出了 OLMoE 的分层参照）；
   - 纯几何划分的可重现性参照：同一组隐状态上，k-means 换不同初始化时自己的可重现程度。
3. **各自不退化：**
   - 在每个模型内部，专家之间都有显著的计算差异，用候补顶替测（专家完全相同时它为 0）；
   - **不能用均值钳制**：专家完全相同时它也大于 0（E120 已证实）。

### 2.4 必须扣掉的“自然的一致”
- **token 身份带来的一致：** 同一个词总去同样的专家，相当于词知识一致。
- **被动几何带来的一致：** 同一组表示上，随便切都会有的一致。
- 只有扣掉这两部分之后剩下的一致，才说明学习选择了特定的组织。

  - 候补顶替的 KL 是数值噪声的 680–2,930 倍，ΔNLL 为 +0.007 – +0.033 nats，是“直接去掉专家”的 1.10–1.42 倍；
  - 校准半与留出半在各层的均值相关 0.93；
  - 选择性 Γ（顶替者与原专家的名词偏好是否相反）在 13 / 16 层不显著，Spearman ≈ 0。
- **R4 同一 run 内的边界级组织稳定性（N1 残差相关；上限约 0.96–0.98）：**

  | 层 | 终点 vs 600k 步 | 终点 vs 5k 步（约 0.4%） |

  “深层更早稳定”的方向，FLAME-MoE 在 top-k 分配上报告过；我们测的是扣除几何零假设之后的组织。

## 4. 测量合同

### 4.1 已经验证、可以使用的
- **共路由：** C(i, j) = |S_k(x_i) ∩ S_k(x_j)| / k（与专家编号无关）。
- **N1 零假设：** W_c V Q Vᵀ（W_c 为行中心化的路由矩阵，V 为其读取子空间，Q 为 Haar 随机正交矩阵），偏置在校准集上重新拟合到原负载。
- **残差：** D = C − E_N1[C]（32 次抽样）。
- **跨模型 / 跨检查点比较：**
  - 在同一组固定锚点输入对上算 T = corr(D_A, D_B)；
  - 同时报告残差强度 ‖D‖（D 方差很小时相关不稳定）；
  - 零分布由“B = A 的零假设抽样”得到。
  - **不需要对齐两个模型的表示。**
- **专家差异：** 候补顶替，即把第 r 名专家换成第 k+1 名、保持门控权重，测下一 token 的 KL 与 ΔNLL；用自身顶替测数值噪声地板。
- **语言条件：** 只用左上下文；同一词形内比较；置换检验在词形内打乱标签；bootstrap 以词形为单位。

### 4.2 只作辅助、不能作证据的
| 量 | 原因 |
|---|---|
| N2 零假设 | 假阳性 |
| 原始共路由相关、NMI、匈牙利最佳匹配重合率 | 被数据几何混杂；最佳匹配有选择偏差 |
| CCA / CKA | 只说明 logit 子空间重合，不说明选择方式相同；高维有限样本下不稳定 |
| Procrustes 迁移 | 诊断量，不是上界 |
| 均值钳制 | 专家相同时也大于 0 |

### 4.3 尚未解决的测量问题（接手时要注意）
1. **“可靠性”至少有三种，要分清：**
   - 固定锚点上的实例级可重现性（跨检查点 / 种子）；
   - 语言关系汇总量的抽样稳定性（按句子拆半）；
   - 跨训练的机制稳定性。
   - 在两半不同语料上逐对算 D 的“拆半信度”没有定义。
2. **候补顶替的效应方向可能不稳定：** 在难 token 上，没被选中的路径有时更好（Misrouted）。要同时报告第 k+1 名和随机未选专家，看效应随名次的变化。
3. **选择性 Γ 只用了“top-1 名词偏好”一种定义，** 太粗。
4. **零假设的两种构造保持的东西不同，** 不存在同时保持“专家几何”和“logit 协方差”的旋转（数学已验算；正确的协方差保持形式是 U Σ C^{1/2} Q C^{-1/2} Vᵀ，Gemini 给出的形式是错的）。只用 N1，并在文中写明它保持的是什么。
5. **统计单位是独立训练（种子），不是 token 或输入对。** 种子对之间不独立；正式阶段需要 ≥ 5 个种子。

## 5. 讨论中澄清过的错误与陷阱（不要重犯）
- **哈希 / 随机路由“几乎一样好”只能当动机，** 不能证明存在多种功能等价的分工：Equifinality 中它们各只有 1 个种子，差 1.1–2.1 PPL，大于种子噪声。
- **“几何决定 vs 历史决定”不是二选一。** 表示、路由器、专家共同演化，早期历史本身就会改变几何。可检验的问题是：控制住表示之后，不同历史是否仍产生不同的组织？
- **在训练好的隐状态上比较学到的路由器与随机路由器，有内生性：** 这些隐状态本身已被训练（包括路由）塑造过。真正控制几何的是 X2（隐状态由一个从未被路由塑造过的骨干产生）。
- **随机超平面“同侧概率 = 1 − arccos(cos)/π”** 只对一对向量成立，不能直接推出“两个随机划分的 AMI 会很高”。零分布必须针对选定的统计量实际采样。
- **k-means 不是零假设，** 它会拟合数据；它的正确用途是“纯几何划分能有多可重现”的参照。
- **抽屉原理推不出“同特征凝聚、跨特征拼箱自由”：** 64 选 8 有约 44 亿种组合，专家也不是装单个特征的箱子。这只能作为待检验的假说。
- **C5a / C5b（冻结 / 放开下游）结果不同，不能归因于“下游读取契约”：** 两者同时改变了可训练参数量、补偿能力和损失地形。
- **“印刻”实验如果只把某类本来就会聚在一起的 token 强制送进某个专家，** 只能锁住编号（头线 v0 的老问题）。要干预的是输入之间的组织关系，并加“只交换编号”的假干预。
- **不能用最终层的下一 token 分布来筛选“左上下文已消歧”的样本：** 隐状态可以不同，而下一词分布相同。
- **E89 里“共用关键头的任务对是因为任务同构”** 只是未检验的假说。
- **Top-k（k > 1）不是互斥划分，** 不能直接套用 AMI / ARI；零假设要保留 k 与负载。

## 6. 初步实验方向（按优先级；每个都先写实验卡）

### X1 路由组织与专家功能的关系（只推理，OLMoE，几小时；**先做**，见 §9 决定 1）
- **问题：** 路由按词性聚类（R2），但专家之间的差异不沿词性分化（R3 的 Γ ≈ 0）。路由组织到底能不能当作专家功能的代理？
- **设计：** 用已采集的数据（`~/mechpop_cache/e121/main/`：路由输入、专家权重在模型里），对每层：
  1. **专家对之间的路由相似度 R_ej：** 在锚点输入上，两个专家被路由到的输入集合的重合度，或它们的共路由画像的相关。
  2. **专家对之间的功能相似度 F_ej：** 在一组共同的路由输入（例如 2,000 个校准位置）上，让全部 64 个专家都计算一遍输出，看两两的输出相似度（平均余弦，或输出矩阵的 CKA）。这只需要单层的专家前向，不需要整个模型。
  3. **检验 R 与 F 的关系：** 跨专家对做 Spearman 相关；零分布在层内打乱专家标签得到；同时控制专家负载、输出范数。
  4. **逐样本补充：** 候补顶替的损伤 A_i，是否随“原专家与候补专家的路由距离”增大而增大（控制路由分数差距、原 NLL）。
- **结果分叉：**
  - R 与 F 显著相关 → 路由组织是专家功能的代理，X2 可以主要比较组织（便宜、可靠）；
  - 不相关 → 路由与功能脱节（符合叠加专精），X2 必须直接比较功能（专家输出、候补顶替），不能只比组织。
- **注意：** F 必须在同一组输入上比较，避免把“被路由到不同输入”误当成“功能不同”。

### X2 冻结稠密骨干、单 MoE 层、多种子（核心；单卡训练；骨干与语料已定，见 §9 决定 2）
- **问题：** 当输入表示完全相同（几何被固定）时，独立训练出的 MoE 层，其组织与专家功能是否重现？重现到什么程度？
- **骨干：`allenai/OLMo-1B-0724-hf`。** 已核实：
  - 分词器文件与 OLMoE 逐字节相同（md5 一致），E121 的语言样本可以直接复用；
  - 隐维 2048、16 层，与 OLMoE 相同；
  - 稠密 FFN 宽度 8192，恰好等于 OLMoE 每层激活的 8 个专家 × 1024。插入的 MoE 层可以完全用 OLMoE 的层配置，而激活参数与被替换的 FFN 相同。
- **语料：Dolma v1.7**（骨干自己的预训练分布）。
  - 从 `allenai/dolma` 的 `urls/v1_7.txt` 里每个来源取 1–2 个文件，按 Dolma 1.7 各来源的 token 占比混合；
  - 训练约 0.5–2B token（按收敛实测决定），另留独立文件作留出集。
- **层：** 主层第 9 层（0 起算）：E121 中词性残差组织在这里最强，R4 中深层早定型、后期稳定。对照层第 2 层（浅层，组织弱、训练中持续重组），预算允许时再做。
- **配置：**
  - **主配置（与 OLMoE 一致）：** 64 个专家 × 1024，top-8，softmax 后取 top-k、不再归一化，负载均衡损失 0.01，z-loss 0.001，路由器与专家随机初始化（不做 upcycling）。
  - **对照配置：** 8 个专家 × 8192，top-1。LMC-MoE 的设置接近这一档，预期更容易收敛到同一组织。
- **条件：**
  - C5a 只训练 MoE 层；
  - C5b 放开 MoE 层之后的一层（只对主配置做）。
- **种子：**
  - 探索期每个配置 5 个；
  - 另做“同一种子、同一数据顺序重跑两次”，量出非确定性的上限；
  - 另做“同一种子、换数据顺序”。
- **开训前的三项检查（任何一项不过就先停下想）：**
  1. 把第 9 层 FFN 输出置零或换成均值，留出损失应明显上升，并在词性条件上有选择性。否则这一层“怎么分工都无所谓”（LMC-MoE 附录的教训）。
  2. MoE 替换后的模型，留出损失能接近原稠密模型（差距 < 事先定的 ε）。
  3. 测吞吐，按实测定 token 预算与种子数。
- **读数：**
  - N1 残差相关 T（固定锚点：E121 的词性 / 词义样本）；
  - 同一 run 相邻检查点的 T（自身参照区间）；
  - 两条参照：k-means 自身的可重现性；把原稠密 FFN 的神经元按共激活聚成 64 组（MoEfication 式划分），看学到的路由与这个“由原函数导出的划分”有多接近；
  - X1 选定的功能读数（专家输出相似度、候补顶替）；
  - 总体与语言条件损失的 TOST。
- **结果分叉：**
  - T 接近同一 run 内上限 → 固定几何下组织重现；接着看何时失效（换专家数、top-k、层）。
  - T 明显低于参照、性能等价、各自不退化 → 固定几何下也有多种可行组织，这是 J3 的直接证据；接着做 X3。
  - 介于两者之间 → 按层、按语言条件、按配置拆开报告。
- **成本：** 粗估每个 run 约 10 GPU 小时，共约 12 个 run，约 130 GPU 小时，在算力规则内 1–2 天。以吞吐实测为准。
- **近邻核实（10-25接手校正）：** LMC-MoE已在冻结骨干上插入随机MoE并以3次独立初始化训练，比较权重空间与损失壁垒（专家2–16个）。可增加的是同一受控平台上的路由组织与条件计算职责，而非平台本身。

### X3 早期历史的因果作用（X2 出现“多种可行组织”或“部分重现”后再做）
