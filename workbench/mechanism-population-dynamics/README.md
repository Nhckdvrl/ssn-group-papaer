- **MoE 为什么难以推进**（[MOE_REVIEW](MOE_REVIEW.md)，幻灯片 [moe_review_2026-11.pptx](moe_review_2026-11.pptx)）：
  1. 自训小模型的答案取决于设定；
  2. 公开 MoE 没有只换种子的版本，一致度低时无法解读；
  3. 相似的大部分来自词本身和隐状态几何，尺子依赖零模型的选法；
  4. 结果大致能事先猜到；
  5. 结果出来后会改变什么，说不清。
- **可复用的教训：** 导师的一般标准 G1–G8、E1–E12（[ADVISOR](ADVISOR.md)）；下面的“反复出现的失败”表。

## 反复出现的失败

| 模式 | 例子 | 记在哪 |
|---|---|---|
| 叙事先行：强说法先写进稿件，后来撤回 | 头线论文 v0–v3（A02–A08） | heads §7 |
| 先有工具后有问题；被结果牵着走 | E90–E92 追 spike；hybrid 早期 | heads §5、hybrid 状态段 |
| 平台或数据没验证就拿来比较 | 受控 MoE 平台没有分工（E134）；PolyPythias 种子被重置（E95） | PAIN_LOG P30、heads §5 |
| 偏离提问人的原问 | MoE-b 没有独立训练、没有单个专家 | 复盘 §3–4 |
| 二分问题其实是程度问题 | N4 | ADVISOR 11-19 节 |
| 冻结平台，丢掉对比轴 | 11-09 冻结自训平台 | PROGRESS_REVIEW §7 |
| 价值判断太晚、文献跑完才核对 | 头线③“所以呢”；hybrid E217–E223 撞上 Li & Merrill 等 | heads §7、hybrid 状态段 |
| 跟着外部意见逐份跑实验 | E217–E223（每份 Gemini 意见跑一次） | hybrid 状态段 |
| 根据摘要下判断 | 11-20 Xin、Myth 两处写错 | SURVEYS 调研三 §2 |
| 算力估计失准 | E192 原估 2–4 GPU h，实耗约 180 | PROGRESS_REVIEW §7 |
| 统计或工程错误 | E121 置换 p 值写错；E75 用目标模型自己的 DLA 找头；E204 bf16 下卷积没动 | PAIN_LOG P15、heads §4.4、E204 卡 |

导师的一般标准（11-19 之后适用于任何题目）：不依赖定义；各种结果都有信息量；结果不能事先猜到；不是程度问题；不强行二分；有参照点和对比。
