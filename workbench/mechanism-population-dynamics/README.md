## 一句话结论
1. **头：** 层内由哪个头担任角色跟随初始化，不跟随语料；分配在训练早期形成；抽象的分工结构（任务深度顺序、哪些任务共用关键头）跨种子重现，具体是哪个头不重现。对象（头的编号）本身是坐标，so what 回答不了，结项。
2. **找补：** 写出接口的对准决定一个头的角色能否回来；遗忘落在读取侧比写出侧更容易被良性训练撤回。都是组件层面的细化，不足以改变同行认知，停止。
3. **MoE：** 固定gate重组有真实预测代价，Γ分组未胜过gate-only强对照；短程原生历史响应不等于配套断裂。成熟谱系显示相近成功有不同R/S依赖，预算性质载体与必要伙伴可分离；相同函数乃至相同信号的作用随伙伴改变。E163进一步发现，实际消息norm/投影校正仅把原配NLL代价.260527降至.245925；E164又在新55科固定实际路由后保留性质与伙伴差；当前整合论证，无自动GPU队列，最多4卡。见[当前证据与判断](moe/README.md)。
4. **审计：** 五个公开套件问题，三个已在 Hugging Face 提交，两个已有他人报告。
