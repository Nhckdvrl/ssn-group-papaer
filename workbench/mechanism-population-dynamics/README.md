## 一句话结论
1. **头：** 层内由哪个头担任角色跟随初始化，不跟随语料；分配在训练早期形成；抽象的分工结构（任务深度顺序、哪些任务共用关键头）跨种子重现，具体是哪个头不重现。对象（头的编号）本身是坐标，so what 回答不了，结项。
2. **找补：** 写出接口的对准决定一个头的角色能否回来；遗忘落在读取侧比写出侧更容易被良性训练撤回。都是组件层面的细化，不足以改变同行认知，停止。
3. **MoE：** 原生 OLMoE 里确有超出词身份的组织；dense-CE 插层的特异残差 NLL 必要性较弱，但不能据此概括冻结骨干不形成分工。原生函数重复学习窗口中，组件变异大于总输出变异，共享路由起点改变终点组织。当前追问这些配套差异何时改变合法组件重组后的真实预测：先做 E144 固定 gate 重组与 E145 共同接收者交叉的设计，E146 分组重组为条件后续；E143 保留备选。限定证据和竞争解释见 [研究说明](moe/RESEARCH_DIRECTION.md)。
4. **审计：** 五个公开套件问题，三个已在 Hugging Face 提交，两个已有他人报告。
