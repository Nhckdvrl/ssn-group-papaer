## 执行约定

- GPU、节点、NFS 的规则以仓库根 `RESOURCES.md` 和用户的最新指示为准。大文件放节点本地 /tmp，不在 /home 上轮询；停作业先核对 PID/PGID，不要宽泛地 `pkill -f`。
- 跑前写卡，事先定好读数和决策表；不筛幸存的 seed、模型或输入；事后补的分析标 POST-HOC。
- 复用旧结果时，对齐整个读数程序，包括乘积和求和的 dtype。E163 曾漏用 FP64 归约，被旧条件 guard 抓到。
- 先写问题和竞争解释，再写实验。一个结果引出一个局部解释、再引出一个新消融的链条要停下来：先问它改变的是科学解释，还是只在挽救一个指标。
- 文献读全文再判断，不据摘要判重复，也不因有近邻就不断削减主张。
- 源码与结果封存要落成实文件，核对包内 SHA；HF snapshot 里的符号链接离开缓存就失效。
- 删除前先列出路径、用途、引用和替代，再核验耐久副本；公共 HF 缓存、其他工作台、唯一的原始数据不能盲删。
