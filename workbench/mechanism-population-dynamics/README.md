## 研究简报（2026-10-15，随证据更新）

- **问题：** 重新训练后，注意力头之间的分工哪些层级会重现、哪些不会？什么能改写它？
- **最近邻：** Tigges 2024（单次训练内算法稳定、组件轮换）；Bali 2026（注意力模式最佳匹配，含跨层匹配，无任务因果）；Merullo 2024、Gould 2024（单模型内跨任务复用、successor 头）；PolyPythias 2025（410M seed3/4 是 50 个 run 中仅有的异常、伴 loss spike，未做机制分析）；loss spike 文献（Spike No More 等）只当作优化失稳处理。
- **可靠观察（E89）：** 跨独立种子重现的是任务深度顺序（τ 0.73）与“哪些任务共用关键头”（greater-than~后继 10/10、induction~反义词 ICL 9/10）；不重现的是头编号与层号（按编号 0.00，跨层对齐预测留出任务 0.00–0.27）。编号对应只在共享初始化时出现（重跑 0.74、换顺序 0.72、换语料 0.52）。异常组织恰在 PolyPythias 的两个异常种子上。
- **仍然同样符合结果的解释：** 共用关系可能只是“两个任务需要同一个原语”的必然结果（强先验：Olsson、Gould 已预言这两组），此时它是一条校准过的复现事实，不是新认识。
- **当前最值得投资的线索：** 一次 loss spike 是否改写已形成的分工并带走依赖它的能力（E90）——终点无法区分“从未长成”与“长成后被改写”，这正是训练轨迹该回答的问题。
- **下一步与止损：** E90 若显示“从未长成”或与对照无异，则异常组织只是描述，不追加设定；若显示“被改写”，用受控训练（E46 设施）人为诱发失稳做因果确认，再判断是否值得成为主线。

## 有证据但必须限缩的认识

1. E35/E59：同初始化的不同语料模型在层内注意力角色上具有一定统计对应，而不同初始化时较弱。**这不是置换不变的科学事实**；头的编号可重排而不改变模型函数。
2. E81：同初始化、独立训练的兄弟，注意力角色图对应约 0.24–0.34，IOI 单头消融图对应约 0.02；经核实为**同一训练的后代**，主力承担者通常较稳定。统计范围只限所测模型和任务。
3. E83：在新 DataDecide 12 run 中，“任务行为一出现，最终主力承担者已经确定”的预测失败（只有 3/12 最强头保留），该发展规律已撤回。
4. E86：原样重跑已有 9/15 次发生最强 induction 头易主，随机屏蔽数据为 14/30；因此不能将单头易主直接归因于删数据。
5. E87 完整步数验证已按人指示停止、无结果；E88 部分分析代码仍有问题，不补称已完成。

项目的科学意义与新颖性受坐标对称性、强近邻结论、测量信度及因果归因限制。**人已决定结项，不因保留资源而自动重启。** 旧实验卡中的 RUNNING、PLANNED、旧计划和 `run_*.sh` 均只是历史记录。
