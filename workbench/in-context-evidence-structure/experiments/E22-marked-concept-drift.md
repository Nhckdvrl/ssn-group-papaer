# E22：把 concept drift 标在输出表面——模型察觉到“换了 regime”后会用新映射吗？（2026-10-05）

- **状态：** DONE（8 模型）；Qwen3-32B / Qwen2.5-32B 待跑
- **对应：** 主旨“检测得到输出漂移、检测不到 concept drift”的直接机制性检验
- **设计：** mag_nat（数字 small/large）与 SST（positive/negative），300 base/格式，11 个 A/B 模式。A demo：小写标签 + A 映射；B demo：**大写**标签 + 反转映射（regime 与大小写完全耦合）。query 打 4 个候选：[小写 A 标签, 小写 B 标签, 大写 A 标签, 大写 B 标签]。
- **读数：** P(大写)（输出漂移跟踪）；P(B 映射)（映射跟踪）；P(B 映射 | 大写)（检测到的 regime 是否被绑定到映射）。规范学习者：三者都随 regime 后验变化，且 P(B 映射 | 大写) ≈ 1。
- **预测（主旨为真时）：** P(大写) 时间敏感（suffix_4 ≫ disp_4，前缀噪声使其下降）；P(B 映射) 仍集合式；P(B 映射 | 大写) 远低于 1——模型“写大写却用旧映射”。

## 结果（Qwen3-8B，300 base/格式；均为 logit，配对 bootstrap 95% CI）

**SST positive/negative：** P(大写) suffix4−disp4 **+7.02**、噪声 **−3.84（规范）**、suffix8−prefix8 **+11.96**；P(新映射) +1.53 / +0.11 / +1.69（弱 recency）；suffix_8 时 P(新映射\|大写) logit +0.75（≈68%）。

**判读：** 同一个答案里出现解离——“写成新 regime 的格式”这一输出漂移被规范地、结构敏感地跟踪（后 8 条为新 regime 时 97% 写大写），而“用新映射”这一 concept drift 几乎不随时间结构变化（数字任务中，即便写大写，用新映射的概率也只有 ~48%）。模型**知道**规则变了（表现在格式上），却没有把变化绑定到输入→输出的关系上。这是“检测得到输出漂移、检测不到 concept drift”的最直接证据。


**Qwen2.5-7B 复现：** 数字：P(大写) suffix4−disp4 +3.25 [3.11,3.37]、噪声 −1.79（规范）、后8−前8 +6.03；P(新映射) +0.56 / +0.18 / +0.90；suffix_8 时 P(大写) logit +1.96（88%）、P(新映射\|大写) +0.45（61%）。SST：P(大写) +5.90 / −4.33 / +8.63；P(新映射) +0.68 / −0.07 / +0.71；suffix_8 时 P(大写) 99%、P(新映射\|大写) 61%。

**Mistral-7B 复现：** 数字：P(大写) +2.96 / −1.71（规范）/ +6.03；P(新映射) +0.22 / +0.04 / +0.36；suffix_8 时 P(新映射\|大写) logit +0.18（≈54%）。SST：P(大写) +4.47 / −3.09 / +9.69；P(新映射) +0.70 / −0.07 / +1.18。
**三模型小结：** 输出格式这一通道在三个模型、两种任务上都是规范的变化点式跟踪；映射这一通道在所有情形下最多只有弱 recency，且在“已写成新格式”的条件下用新映射的概率只有 54–68%。

Qwen3 系列 SST 映射通道的噪声效应：8B +0.11 → 14B −0.52 → 32B −1.37（oracle −1.70）；数字：+0.62 → +0.15 → −0.10。
**判读：** regime 被输出侧大写标出时，大模型逐渐把新映射绑定到大写标签上（SST 明显、数字弱）。这一绑定不需要对条件关系做时间推断：大写 demo 自成一组且在 suffix_8 中全为新映射，只要按标签 token（大小写）分组检索，即得到“绑定”；时间结构则继承自规范的格式通道。小模型的失败在于把大小写不同的标签当作同一标签。对照：无标记时 Qwen3-32B SST 的噪声效应为 +0.75（方向错，night_core）。→ 规模带来“按可见输出标记分组”，不是条件时间推断。
