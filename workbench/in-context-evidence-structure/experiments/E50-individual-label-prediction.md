# E50：混合上下文是否让“预测这个人自己的真实标签”变差？换词能否找回？（2026-10-09）

- **状态：** DONE（2026-10-09）— 实际代价收窄
- **类型：** 后果（使用者关心的指标：个人标签预测，而非 A / B 区分度）
- **对应：** C13；E49（GoEmotions 区分度：同词保留 0.48–0.54）
- **问题（一句话）：** 用某位评分者自己的 8 条样例做上下文，比用另一位评分者的样例，能更好地预测他在留出评论上的真实“中性”标签（个性化收益）；把两人样例混在一起后，这个收益还剩多少？换词能否恢复？
- **设置：** GoEmotions raw，中性比例前 20% / 后 20% 的评分者配对（60 对）；每人 8 条 demo + 40 条自己的留出评论（真实标签）。条件：single_A（自己）、single_B_as_A（只给另一人的样例，问 A）、mixed（同词）、mixed_far（B 改用 flag / pass；只评 A 一侧，A 的词表不变）、mixed_instr；B 一侧对称（single_B、single_A_as_B）。读数：两词 log-odds 的对数损失（真实标签）与 0 阈值准确率。保留收益 = (LL_他人 − LL_混合) / (LL_他人 − LL_自己)。模型 Qwen3-8B、Qwen2.5-7B、Mistral-7B-v0.3。脚本 `scripts/e50_individual.py`。
- **结果 → 判断（事先写）：** 个性化收益（LL_他人 − LL_自己）不显著 → 真实标签层面没有可学的个人信号，不可判定；同词保留收益 ≤ 0.6 且换词 ≥ 0.8 → C13 在使用者指标上成立；同词保留 ≥ 0.8 → 区分度损失不转化为预测损失（C13 的实际意义收窄）。

- **主张变化：** C13 增加局限：“logit 层面的区分损失；对个人标签准确率的影响依情形而定，在主效应、远离边界的情形下很小（E50）”。
