# E54：依赖输入的来源差异会混合、不依赖输入的会绑定？——同一批真实评论上的阈值型 vs 频率型（2026-10-09）

- **状态：** DONE（2026-10-09）— 统一原则否定
- **类型：** 判别（统一原则的直接检验；由 E30 → E46 / E47 / E49 的预测失配逼出）
- **对应：** E30（合成主效应 = 不看内容的标签频率偏好，大模型几乎完全绑定：Qwen3-14B / 32B 溢出 0.04–0.13）；E46 / E49（真实严 / 松标注者在所有规模保留 ~0.45）；E47（交互型 0.27–0.48）
- **统一原则（候选）：** 不依赖输入的证据（标签频率）可以绑定到来源，且随规模变好；依赖输入的证据（哪类内容给哪个标签）按输出跨来源汇集，与规模无关。真实标注者的严 / 松本质是阈值移动 = 内容依赖的差异 → 应表现得像交互。
- **设置：** Measuring Hate Speech 评论（≤ 60 词，IRT 分数 −2.5 到 3.0）。每对：A、B 各 8 条 demo（同一批文本在两种类型下复用），60 条 query。
  - **阈值型（thr）：** A：分数 > 0 判 toxic；B：分数 > 1.0 判 toxic（差异集中在边界内容）。
  - **频率型（mar）：** 两人都用阈值 0.5，再随机改判（与内容无关）直到 toxic 数量与阈值型完全相同（基础比例匹配）。
  - 条件：single_A、single_B、mixed（同词 toxic / safe）。读数：区分 D = ld(A) − ld(B)（query 平均）；保留 = D_mixed / D_single。模型：Qwen3-8B、Qwen2.5-7B、Mistral-7B-v0.3、Qwen3-14B、Qwen3-32B。脚本 `scripts/e54_threshold_vs_marginal.py`。
- **结果 → 判断（事先写）：** 频率型保留显著高于阈值型（多数模型差 ≥ 0.2），且频率型保留随规模上升而阈值型不升 → 统一原则成立；两者相近 → 原则不成立，真实标注者为何不绑定另需解释；阈值型更高 → 原则方向错误。

- **遗留的尖锐问题：** 合成 E30 中大模型能把标签频率偏好绑定到来源（Qwen3-14B / 32B 溢出 0.04–0.13），真实文本中同类频率差异只保留 0.31–0.52 且不随规模变化——差在频率强度（E30：75% vs 50%；此处 45% vs 23%），还是真实内容证据压过来源证据？→ E57（交换干预 + 机制混合模型）。
