# E28：变化检测只看边缘统计？——类别不均衡时的映射翻转（2026-10-06）

- **状态：** PLANNED
- **类型：** PILOT（idea 的决定性实验）
- **对应：** idea I03（候选）“ICL 的变化检测只作用于输出侧的边缘统计（虚拟漂移），条件结构 P(y|x) 被可交换地汇总（真实漂移不可见）”
- **动机：** 汇总已有结果——被规范追踪的变化（标签流、大写、输出语言、±3 偏移）都改变了输出侧的某个边缘统计（P(y)，或作用于全部输入的 y−x 偏移）；时间盲的变化（类别均衡的翻转、奇偶↔大小切换 E27、类别条件 ±3 互换）都**保持**这些边缘统计不变。E27 否定了“可识别任务”的解释，剩下的竞争解释是“按输入路由 → 可交换”（C02）与“只有边缘统计被过滤”（I03）。
- **问题（一句话）：** 当映射翻转同时改变了标签边缘分布（类别不均衡）时，模型的时间敏感性是“对新映射”的，还是“对新的多数标签”的？
- **设置：** mag_nat（数字 small/large）与 SST 两极；300 base/任务，SEED0=800000。16 条 demo 中多数类 12 条、少数类 4 条（多数类是哪一类在 base 间平衡）；A 映射自然/取反在 base 间平衡；B=A 取反。每个 (base, 模式) 两个 query：多数类 query 与少数类 query（同 base 共用 demo）。模式：allA、allB、single_1、single_16、suffix_3、suffix_4、disp_4、noise_2__suffix_3、suffix_8、prefix_8、block_start4。`scripts/build_imbal.py` → `data/imbal`。程序化数字 + 公认 SST，不需审计。
- **oracle：** 一属性规则 HMM（同主 oracle）；对多数类与少数类 query 都预测“转向 B 映射”（成簇>0、噪声<0、后8−前8>0）。
- **读数：** 对每类 query 分别算 logit P(B 映射答案) 的成簇、噪声、后8−前8、末位−首位。
  - 另算“query 无关偏置”= 两类 query 的 logit P(新多数标签) 的平均，以及“条件成分”= 两类之差，分别看时间结构。
- **竞争预测：**
  - I03（边缘统计）：多数类 query（B 答案 = 新多数标签）出现规范符号；少数类 query（B 答案 = 新少数标签）符号**反转**（成簇<0、噪声>0、后8−前8<0）；时间结构全部集中在“query 无关偏置”上，“条件成分”时间盲。
  - C02（路由 → 可交换）：两类 query 都时间盲（≈ 类别均衡时的 mag_nat/SST）。
  - 规范：两类 query 都规范。
- **混杂审计：**
  - 不均衡本身带来多数标签偏置（Zhao et al. 2021 majority label bias）：它在 allA/allB 下是常数，对时间结构的差分（同计数、不同顺序）相互抵消 — 已控制。
  - 少数类只有 4 条 demo：其映射证据较弱 → 用 oracle 归一化比较。
- **决策表（跑之前写）：**
  - 少数类出现反向时间结构、多数类规范 → I03 成立：变化检测器只看边缘统计；这把“输出漂移 vs concept drift”提升为一个可预测的机制定律（虚拟漂移可见、真实漂移不可见）。
  - 两类都时间盲 → C02 成立（路由证据进入可交换存储，边缘统计的变化也救不了）；I03 作废。
  - 两类都规范 → 不均衡让模型能察觉条件变化（边缘变化作为“变化信号”触发了条件更新）——这将是“察觉后会重置”的正面证据，与 E22 对照需重新解释。
- **算力预算：** 13200 条/模型；Qwen3-8B、Qwen2.5-7B、Mistral-7B、Llama-2-7B，每个约 10 分钟。

## E28b 机制追加（跑前写，2026-10-06）
- **问题：** E10 的 16 个晚层“游程头”承载标签流的时间整合。它们是不是“边缘统计通道”本身？
- **干预：** Qwen3-8B，`--ablate` 置零 run16 与 ctrl16（`results/switch_pilot_T16/run_heads_Qwen3-8B.json`，E10 跑前固定的头集）。
- **预测（I03 为真时）：** run16 削弱“偏置成分”的时间结构（后8−前8、成簇、噪声的规范符号），条件成分基本不变；ctrl16 两者都不变。若 run16 对两者都无作用 → 边缘通道在别处（与 E10 追加中“全局变换不经由这些头”一致），记录为否定结果。

### 追加（2026-10-06）：Mistral/Llama-2 与“只看边缘统计”的 oracle
- **边缘 oracle（POST-HOC 分析，但定义是标准的）：** 只看标签流的规范学习者（两状态 HMM，A 下新多数标签概率 0.25、B 下 0.75，λ 网格/先验同主 oracle），对“偏置成分”的预测：成簇 +0.12、噪声 **+0.15**、后8−前8 +0.60、末位−首位 +0.17。弱信号（似然比 3）下多出的 B 标签计数压过结构推断，所以**噪声检验对偏置成分无诊断力**；应比较量级。
- 偏置成分（数字）：Qwen3-8B +0.34/−0.25/+1.07；Qwen2.5-7B +0.07/−0.05/+0.24；Mistral +0.20/−0.07/+0.41；Llama-2 +0.17/+0.04/+0.59 —— 与边缘 oracle（+0.12/+0.15/+0.60）同量级。
- 条件成分（数字）：Qwen3-8B −0.03/+0.97/+0.11；Qwen2.5 +0.10/+0.37/+0.54；Mistral +0.06/+0.31/+0.33；Llama-2 +0.01/+0.23/+0.29 —— 条件 oracle 为 +4.02/−1.70/+4.62；8/8 格子（含 SST）噪声方向错。
- 少数类 query 的后8−前8（数字）：Qwen3-8B −0.96、Llama-2 −0.30、Mistral −0.08、Qwen2.5 +0.30。
- **判读：** 时间敏感性的量级可以由“只追踪标签边缘分布的规范学习者”解释；条件结构的时间推断在 4 个模型里都缺失。
