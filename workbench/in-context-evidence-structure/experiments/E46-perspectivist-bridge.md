# E46：多位真实标注者的样例放进同一上下文，模型能按标注者区分吗？——perspectivist ICL 的桥梁检验（2026-10-08）

- **状态：** DONE（2026-10-08）；后续 E46b
- **类型：** 桥梁检验 + I04 的真实数据后果（“有什么用”的缺口）
- **对应：** I04；E30（标注者交互泄漏 0.55–0.91，合成任务）；E31 / E33（换标签词分离，泄漏随标签语义相似度增加）；E32（换词修复）；数据：Measuring Hate Speech（Kennedy et al.；`ucberkeley-dlab/measuring-hate-speech`，7912 名标注者，带 ID 与 IRT 严苛度）
- **社区在用的推断：** perspectivist / 个性化 ICL 把多个标注者（或用户）带 ID 的样例放进同一提示，认为模型会按 ID 条件化各自的标注习惯。
- **问题（一句话）：** 在真实标注数据上，A、B 两位倾向相反的标注者的样例交错放进同一上下文时，模型对“以 A 身份”与“以 B 身份”标注同一条评论的差别，还剩单人上下文差别的多少？给两人不同的标签词能否恢复？
- **事先预测（I04）：** 同标签词时只剩小部分（≤ 40%）；换成语义较远的标签词（flag / pass）恢复大部分，语义较近的（offensive / okay）居中。最强的竞争预测：现代 LLM 能读懂 “Annotator: X” 并按名字分组（指令跟随），分离接近单人上限。
- **设置：**
  - 标注者：只用二值标签（0 → safe，2 → toxic；丢弃 1）。每位标注者的倾向 = 自己的标签减去同一评论其他标注者的平均标签（残差），取残差最高的为 A 池、最低的为 B 池，各自至少 10 条二值样例；随机配 120 对。
  - demo：每人随机 8 条自己的样例；名字随机映射为 Alex / Sam。
  - query：70 条参照评论（被 ≥ 50 人标注）中长度 ≤ 60 词的全部。
  - 上下文：single_A（只 A 的 8 条）、single_B、mixed（16 条交错，同词 toxic / safe）、mixed_near（B 改用 offensive / okay）、mixed_far（B 改用 flag / pass）。读数为 query 标注者自己词表的 logit 差（毒性一极 − 安全一极）。
  - 模型：Qwen3-8B、Qwen2.5-7B、Mistral-7B-v0.3（Llama-3.1 本地无权限）。脚本 `scripts/e46_perspective.py`。
- **读数：** D_single = ld(single_A, 以 A) − ld(single_B, 以 B)；D_mix = ld(mixed, 以 A) − ld(mixed, 以 B)；分离比 = D_mix / D_single（按对 bootstrap CI）；同理 near / far。另报 A、B 的 demo 中毒性标签比例（确认倾向确实写在 demo 里）。
- **结果 → 判断（事先写）：**
  - D_single 不显著（单人上下文都学不到倾向）→ 真实数据信号不足，不可判定；不追加。
  - 分离比（同词）≤ 0.4，且 far ≥ 0.7 → I04 在真实 perspectivist 设定中成立：带 ID 的多人上下文不能按人区分，换标签词可修复 → ICES 得到真实后果。
  - 同词分离比 ≥ 0.7 → 模型能按 ID 区分，I04 的合成结论在真实数据上不推广（重要的反例，需如实写入）。
  - 居中 → 部分成立，报告数字。
- **算力：** 120 对 × 6 个（上下文 × 身份）前缀 × 70 query，前缀复用；每模型约 20–40 分钟。

## 结果（跑完后填写）
（2026-10-08；`results/e46/analysis.json`；120 对，60 条参照评论（≤ 60 词）；A、B 的 demo 毒性比例 0.58 / 0.12）

| 模型 | D_single | 同词保留比例（95% CI） | near（offensive / okay） | far（flag / pass） |
|---|---|---|---|---|
| Qwen2.5-7B | 3.84 | **0.35**（0.31–0.40） | 1.25（1.19–1.33） | 1.58（1.51–1.65） |
| Qwen3-8B | 6.63 | **0.45**（0.39–0.53） | 0.74（0.67–0.83） | 0.91（0.81–1.00） |
| Mistral-7B-v0.3 | 3.19 | **0.48**（0.42–0.55） | 1.25（1.17–1.33） | 1.47（1.37–1.57） |

- **按表：** Qwen2.5-7B 满足“同词 ≤ 0.4 且 far ≥ 0.7”→ 成立；Qwen3-8B、Mistral 同词 0.45 / 0.48 → “居中 / 部分成立”；far ≥ 0.7 三者都成立。冒烟测试（3 对）显示的“混合比单人分得更开”是小样本噪声。
- 恢复程度按标签词语义距离排序 far > near > 同词（三模型一致），与 E33 在合成任务上的语义泄漏规律相符；第一次在非 Qwen 家族（Mistral）和真实标注数据上看到。
- 注意：真实标注者差异主要是主效应（整体严 / 松），即使如此同词混合也丢掉 52–65%。
- **待排除：** 指令能否恢复（R8）、指令微调模型、规模 → E46b。
