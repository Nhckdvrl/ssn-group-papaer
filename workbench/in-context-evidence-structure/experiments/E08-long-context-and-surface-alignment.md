# E08：长上下文 + 表层游程对齐（2026-10-05）

- **状态：** DONE（Qwen3-8B pilot）
- **对应：** C02 / C03
- **问题：** (1) 规则任务的时间盲是否只是短 context 的现象？(2) 规则任务里，若变化后的 demo 恰好形成**表层标签游程**，时间敏感性会不会回来——且方向跟着表层还是潜在规则走？
- **设计：** Part 1：n_attr=7（128 输入）、T∈{32,64}，150 base；allA、suffix/disp_{T/8,T/4,T/2}、noise_{T/8}__suffix_{T/4}、prefix_{T/2}（先 B 后 A）。Part 2（T=16, n_attr=5，150 base）：把 4 条 B demo 放在末尾或零散位置；aligned = 这 4 条与 query 规则属性同值（其 B 标签 = query 的 B 标签词 → 末尾表层游程为 B 词）；anti = 规则属性异值（其 B 标签 = query 的 A 标签词 → 末尾表层游程为 A 词）。各自对同顺序的 allA 配对。

## 结果
**T=32**：suffix_16 − prefix_16 = +0.27 [−0.04,0.61]（meta +5.70）；suffix_8 − disp_8 = +0.02（meta +4.06）；noise_4 前缀 +0.35 [0.19,0.50]（meta −1.76）。
**T=64**：suffix_32 − prefix_32 = **+0.05 [−0.20,0.28]（meta +6.89）**；suffix_16 − disp_16 = +0.15（meta +7.49）；noise_8 前缀 +0.45 [0.34,0.56]（meta −0.49）。
**对齐（T=16）**：
| | suffix4 | disp4 | suffix − disp | meta suffix / disp |
|---|---|---|---|---|
| aligned（末尾表层 = B 词） | +3.44 | +2.80 | **+0.65 [0.43,0.86]** | +5.12 / +3.52 |
| anti（末尾表层 = A 词） | −0.34 | +0.58 | **−0.92 [−1.13,−0.71]** | +5.49 / +3.83 |

**判读：** 潜在规则层面的时间盲在 64 条 demo 时依旧（连 A→B 与 B→A 都分不出）。时间敏感性只来自表层标签 token 的游程：表层游程与新规则一致时部分恢复，表层游程与旧规则标签词一致时把预测推向旧规则（与 oracle 方向相反）。**“LLM 知道标签变了，不知道规则变了。”**
