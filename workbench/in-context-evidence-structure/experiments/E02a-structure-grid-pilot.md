# E02a：配对结构网格 pilot（E01 校准 + E02 noise-vs-change 合并为一个配对设计）（2026-10-05）

- **状态：** DONE（pilot；未审计词库；确认版待审计词库+新种子）
- **类型：** PILOT / MEASUREMENT
- **对应：** C01、C02；P04
- **问题（一句话）：** frozen LM 对矛盾证据的权重是一个**固定的位置核（可加）**，还是取决于矛盾的**组织方式**（非可加；像在推断 噪声率 ε 与 变化率 λ）？
- **为什么这样设计（与原 E01/E02 的差别，agent 决定）：** 原计划先单独跑两极（E01）再跑 matched pilot（E02）。但 Kossen ICLR'24 §8 已经证明“同数量不同顺序 → 偏向近处”，所以“两极能分开”几乎是已知的；真正决定性的是**可加性**与**方向相反预测**。配对设计让所有条件共享输入/名字/query，一次跑完，E01 的 M1/M2 作为子集同时得到。
- **数据：** `scripts/build_struct.py`；n_attr=5、T=16、200 个 base × 76 个 A/B 模式（B=按反转规则标注）。pilot 用 **未经 step-5 审计的候选词库**（审计在后台进行），正式版用审计词库 + 新种子重跑。
- **模型：** Qwen3-8B（无 chat 模板，纯文本 few-shot）。
- **读数：** query 上 “反转规则标签 vs 原规则标签” 的 exact 序列 log-odds（lo_B）；全部在 base 内配对（d = lo_B(cond) − lo_B(allA)）。
- **条件族：** single_t（位置核 w_t）；pair（相邻/分离 → 交互项）；suffix_k；disp_k；noise_m×suffix_k 网格；block（起始/中间/回归）；perm3（8 种顺序）。
- **各解释的预测（跑前写定）：**
  | 解释 | single_t | pair 交互 | suffix_k vs Σw | **加前缀噪声（k≥3）** |
  |---|---|---|---|---|
  | A 固定位置核 | 递增（recency） | ≈0 | ≈Σw | **上升**（= w 之和 > 0） |
  | B 集合学习者 | 平坦 | ≈0 | ≈Σw（线性于计数） | **上升** |
  | C 局部窗口/序列启发式 | 末端陡峭、前端≈0 | 窗口内可为正 | 窗口内超可加 | **≈0**（噪声在窗口外） |
  | D 结构推断（meta oracle） | 末端最大但仍有限 | 相邻 > 分离（超可加） | 超可加（k=2–3 起跳） | **下降**（噪声率↑ → 后缀更像噪声） |
  meta oracle 在本设计上的数值（200 base 平均）由 `analyze_struct.py` 同时输出，作为 D 的定量预测。
- **阳性对照：** allA 应强烈偏向原规则（lo_B ≪ 0）；suffix_8（一半在末尾翻转）应显著抬高 lo_B。
- **噪声地板：** base 级 bootstrap 95% CI；perm3 的 8 种顺序给出“纯顺序”离散度。
- **决策（观察导向，不设卡死的门）：** 看到哪种签名就沿着它追 why；D 的签名出现 → 扩到更多模型/规模 + 隐式 (λ, ε) 拟合；A/B 签名 → 追“为什么不推断结构”（规模、格式、显式提示上界）；混合 → 分条件分析。
- **算力：** fvcrc10 4×A100，约 15 min。

## 结果（2026-10-05）
**Qwen3-8B（200 base）**：allA lo_B −2.69 [−3.00,−2.37]，acc 0.905，两标签概率质量 0.995。
- 位置核平坦（0.64–1.08；末位 0.72 [0.54,0.92]）；meta 预测末位 +2.73、首位 +1.25。
- 成对翻转次可加（交互 −0.29 ~ −0.46，CI 均不含 0），相邻≈分离（meta 预测相邻末端 +4.00 ≫ 分离）。
- suffix_k 随 k 次线性增长；suffix_4 1.92 vs disp_4 2.06（meta：5.11 vs 3.66）。
- 前缀噪声（k=4, m=2）：LM +0.53 [0.37,0.68]；additive +1.91；set +0.92；**meta −0.63**。所有 k∈{3,4,5}×m∈{1..4} 的 LM 效应都为正。
- 条件均值相关：set 0.977、additive 0.942、meta 0.836、seq 0.771。perm3（同 multiset 8 种顺序）base 内 SD 1.16 nats。
- 单点翻转影响由相似度决定：规则属性与 query 同值 +0.61（z=16）、每个无关属性匹配 +0.15（z=7.6）、位置主效应 0；位置 × 同类交互 +0.09（z=11）——晚期同类更强、晚期异类更弱（位置锐化相似度检索，符合 Cho 2025 的位置相似度偏置）。
- 计算模型 CV：样例模型逐条 R² 0.27 > set 0.18 > meta 0.13 > seq 0.11。

**跨模型（`results/struct_pilot_n5_T16/summary.csv`）**：Qwen3-1.7B / 8B / 8B-Base、Qwen2.5-7B、Mistral-7B、gemma-2-2b 全部同一签名——suffix4−disp4 ≈ 0（CI 含 0 或为负）、前缀噪声效应 +0.07 ~ +0.53（与 meta 方向相反）、r_set 0.88–0.99。post-training 增加顺序特异性波动（perm SD：8B-Base 0.75 → Qwen3-8B 1.16）。

**判读：** 解释 B（集合学习者）+ 样例式检索，**不是** D（结构推断）。“order sensitivity”在这里是无方向的特异性波动 + 位置对相似度检索的锐化，而不是“更信任新证据”。
