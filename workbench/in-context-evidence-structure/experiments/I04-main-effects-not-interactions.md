# I04：In-context learners learn main effects of context, not context × input interactions——concept drift 盲是其特例（2026-10-06）

- **状态：** PROMISING（I01 的推广与机制化；I02“TR/TL”被 E27 否定，I03“边缘统计”被 E28/E29 支持并并入本卡）
- **来源：** 稳定 anomaly（E02a 起的“前缀噪声方向错”在 13 模型 × 多任务复现）→ 一系列竞争解释被逐一排除：表层 vs 潜在（E11b 否）、单条可识别（E13 否）、可识别任务（E27 否）、输出标记（E22：8B 不绑定）、时间写进内容（E23 否）、输入侧标记（E24/E24b 否）。剩下的唯一一致描述：**被规范地跟踪的变化都改变了某个与输入无关的输出侧统计；时间盲的变化都只改变条件结构而保持这些边缘统计不变**（E28、E29 的分解直接验证），并且同样的规律在非时间的上下文变量（标注者）上成立（E30）。
- **研究动作：** 归纳—推广（把“漂移”问题重述为上下文 × 输入交互的学习问题）+ 分解测量（同一答案的边缘/条件成分；删除影响的通道 × 相似度拆分）+ 引入成熟构念（Gama 2014 的 virtual vs real drift；联想学习中的 outcome density vs contingency；统计中的 main effect vs interaction）。
- **如果为真，主张是：** 冻结 LLM 的 in-context 证据有两种存储：
  1. **与输入无关的输出侧统计**（标签/格式/语言的频率、作用于全部输入的 y−x 关系、某个上下文变量下的标签偏好）——随流整合，对“噪声 vs 变化”方向近似 Bayes，变化后旧证据被规范地折扣（E26 格式通道前段支持度为负，且与输入相似度无关）；
  2. **按输入内容检索的关联**（哪个输入配哪个输出）——按相似度加权、在时间和其他上下文变量上可交换地汇总；变化后不重置（E26 映射通道前段仍为正），也不按显式上下文标签分流（E24b、E30 交互溢出 62–91%）。
  于是：边缘漂移（时间的主效应）可见，concept drift（时间 × 类别的交互）不可见；标注者的标签偏好可学，标注者 × 类别的映射差异大部分泄漏到所有人。
- **不同结果的信息增益：**
  - 32B 的交互绑定仍远低于规范 → 规律对规模稳健；32B 在输出侧标记上开始分组（E22）说明规模带来的是“按输出 token 分组”，不是交互学习。
  - 32B 出现交互绑定 → 能力随规模涌现，故事变成“交互学习何时出现”，与 E22 规模趋势合流。
  - 若把交互改写成不同的输出词表（每个上下文一套标签词）就能被学会 → 关联存储的键是“输出 token 身份 × 输入相似度”，给出可操作的预测与缓解。
- **最近邻与增量：**
  | 近邻 | 它的 claim | 我们的增量 |
  |---|---|---|
  | Zhao et al. ICML'21（Calibrate before use） | 多数标签偏置、近因偏置是需要校准掉的误差 | 这些“偏置”是边缘通道上方向近似 Bayes 的变化点推断（标签流 13/13 模型、E28 偏置成分≈边缘 oracle 量级）；真正的缺陷在条件通道 |
  | Kossen et al. ICLR'24 | ICL 学标签关系但不是常规学习；中途翻转时偏向近处 | 方向相反检验分开“近处”与“结构推断”；给出边缘/条件分解与交互泄漏这一可预测的失效边界 |
  | Falck et al. ICML'24 | ICL 违反 martingale，不是 Bayesian | 边缘上近似 Bayesian、条件上近似可交换（set oracle r≈0.98）——两种性质分属两个存储 |
  | Xiong et al. ICLR'25（任务叠加） | 上下文混合多任务 → 输出是任务的混合 | 混合权重不随“哪个上下文/何时”条件化（E24/E30），只随相似度与计数 |
  | Dudley ICML'26 / Qin ICLR'26 | 训练的 transformer 能做 in-context 变化检测 | 预训练 LLM 只在边缘统计上做；条件结构上没有（13 模型、32B、thinking、指令都不改变） |
  | Cho et al. ICLR'25 / Yang-Cho-Inoue ICLR'26 | ICL 检索电路；TR/TL 头 | 行为证据：映射通道是按内容检索（E21、E26 同类主导）；TR/TL 不是时间性的分界（E27） |
  - **Compression risk：** “不就是 ICL 是 kNN + 有标签偏置吗？”——load-bearing 差异：(1) 偏置通道对噪声/变化的组织方向近似 Bayes（不是简单近因）；(2) 两通道在同一答案内被分开测量（E22/E26），并在时间与非时间上下文上同构（E28 vs E30）；(3) 给出可证伪的符号预测并被验证（E28 少数类 query 被拉向错误答案）。
- **最便宜的决定性 pilot：** E28（不均衡翻转的边缘/条件分解）、E30（上下文主效应 vs 交互）——均已完成，5 模型方向一致。

- **2026-10-06 机制修正（E31/E32）：** “学不到交互”不准确。E31：Sam 换用 nonce 标签词后交互泄漏为 0（10/10），泄漏随两套输出词的语义接近程度单调上升；E32：新 regime 换用 nonce 词后，时间上的 concept drift 被规范追踪（映射通道噪声方向 11/12 规范，含 1.7B/2B）。**最终表述：ICL 按输出标签存放输入-输出证据——每个输出的支持来自带该输出的 demo 的相似度加权汇总，在时间与上下文上可交换；另有一个输出层面的先验，以近似 Bayes 的变化点结构追踪“现在在用哪些输出”。** 因此：改变“用哪些输出”的漂移（标签流、格式、语言、换词的新 regime、上下文的标签偏好）可见；把已有输出重新分配给不同输入的漂移（concept drift、上下文依赖的映射）不可见，且泄漏程度随新旧输出的语义接近程度增大。对应认知科学的样例分类模型（Nosofsky GCM）+ 动态反应偏置。
- **2026-10-06 晨：分隔阶梯与两通路（E33–E35）：** 关联证据能否被分开：不同输出词 0.00（E31/E32）≪ 不同输入领域 0.42–0.49（E35）< 显式上下文标签 0.51–0.91（E30/E34）< 时间（完全合并，E21/E26）。主效应不是“相邻 token”统计（E34 否定），而是一个可按上下文/时间条件化的标签先验。规模（Qwen3 8B→14B→32B）让主效应越来越干净地绑定（溢出 0.32→0.13→0.08），交互泄漏不变（0.62→0.68→0.77）。
- **开放问题（按信息量排序）：** 规模（32B 的 E30/E28 排队中）；交互能否靠“每个上下文一套输出词表”被学会；为什么（预训练中上下文交互稀少？toy 训练可检验）；边缘通道的机制定位（E28b 否定了 E10 的游程头）。
