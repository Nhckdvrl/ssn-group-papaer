# E39：消融读标签头，映射效应与泄漏是否一起消失？（2026-10-08）

- **状态：** DONE（2026-10-08）
- **类型：** CLAIM（I04 机制的因果必要性；PAPER_SHAPE 风险登记中的“需头消融”）
- **对应：** I04；C12；E36（同一族晚层读标签头承载映射与主效应，DLA 重建 r=0.9997）；E38（因果修补）；近邻 Wang et al. EMNLP'23
- **问题（一句话）：** 把 E36 选出的读标签头在答案位置均值消融后，Sam 的映射移动和泄漏给 Alex 的移动会不会按同样比例消失？剩下的映射（如果有）是否更能区分标注者？
- **事先预测（最强已有认识）：** DLA 只说明直接通路；IOI 等研究普遍报告 backup 头自修复（McGrath et al. 2023 的 Hydra effect），所以总效应下降会小于直接效应。I04 预测映射与泄漏由同一机制产生，两者一起下降，溢出比（Alex / Sam）不变。
- **谁依赖：** I04 论文的机制一节，以及“换输出词修复”的解释（修复之所以有效，是因为这些头按输出身份读取）。
- **设置：** Qwen3-8B、Qwen2.5-7B（bf16，sdpa，左填充 + 显式 position_ids）。数据：E30 `data/ctxeffect`，**留出 base**：每个任务第 151–300 个 base（E36 只用了前 150 个），3 个条件（same / inter / main）× 4 个 query → 每任务 1800 个提示。
  - 头集合：按 E36 的 npz（前 150 个 base）为每个任务选 Sam 移动 DLA 最大的 20 个头（top20）；对照 = 与 top20 同层、随机换头的 20 个头，抽 3 组（layer-matched random）。
  - 消融：在最后一个位置，把所选头在 o_proj 之前的输出替换为该头在 same 条件提示上的均值（用前 150 个 base 中的 200 个 same 提示估计）。
  - 脚本：`scripts/mech_ablate.py`。
- **读数：** 与 E36 相同的定义（行为 logit 差）：Sam 移动 = inter − same（Sam query，朝 B 映射）；Alex 溢出 = 同上（Alex query）；主效应 = (main − same)(Sam − Alex)，朝 L；溢出比 = Alex 溢出 / Sam 移动。**任务能力对照：** same 条件下朝映射 A 答案的 logit 差（保留比例）。
- **阳性对照：** 未消融时的读数应复现 E30 / E36（Sam 移动约 +3、溢出比 0.55–0.86）。
- **噪声地板 + MIE：** base 层面 bootstrap 95% CI（1000 次）；随机头 3 组的范围；下降比例差 < 20 个百分点视为无差别。
- **混杂审计：** 选头与评估用不同的 base（留出）；均值来自 same 条件（不含 inter / main 的映射信息）；随机对照同层，控制“删掉晚层任意 20 个头”的一般性破坏。
- **决策表（跑之前写）：**
  - top20 消融使 Sam 移动与 Alex 溢出都下降 ≥ 70%，随机 ≤ 20%，且 same 条件能力保留 ≥ 50% → **因果确认**：映射与泄漏由同一族读标签头产生；C12 的机制部分可升级（另需非 Qwen 复现）。
  - Sam 移动下降 ≥ 50%，但剩余部分的溢出比降到原来的一半以下 → **存在第二条能区分标注者的通路**：I04 的“只按输出存放”需改为“主要按输出存放”，并定位第二通路。
  - 两者下降都 < 40%（自修复 / backup）→ DLA 不等于必要性；机制主张只保留为“直接通路的分解”，不写因果必要。
  - same 条件能力保留 < 30% → 消融破坏过大，不可判定；改用更小集合（top10）一次，不再追加。
- **算力：** 每模型约 1800 × 2 任务 × 5 条件 = 18000 次前向，单卡约 30–40 分钟。

- 未消融读数复现 E30 / E36（溢出比 0.64–0.91）。
- **按决策表逐格：** “两者都下降 ≥ 70%”只在 Qwen3-8B SST 与 Qwen2.5-7B 数字成立，但这两格的 same 条件保留（0.19 / 0.20）低于预写的 30% 能力线 → 按表记为**不可判定**；另两格下降 53–55%（第一档门槛未达，第三档“< 40%”也不成立）→ **部分**。没有一格符合“第二条区分标注者的通路”。
- **如实补充（不改判定）：** 预写的“能力对照”与被测对象并不独立：same 条件的读数就是“按上下文映射作答”，而消融让映射学习本身按同一比例消失（保留比例三列几乎相同）。也就是说，这些头不是“泄漏头”，而是**整个上下文映射读取的主通路**；泄漏与学会映射在这条通路里不可分。最稳的结果是**溢出比在消融前后不变**（4/4 格，SST 8B 略降 0.83 → 0.72）：剩下的映射与原来同样无法区分标注者。
- **主张变化：** C12 的机制部分增加因果必要性证据（部分）；I04 的“按输出存放”在残余通路上同样成立。不升级等级（仍为 Qwen 家族）。
- **POST-HOC 观察：** 第一档要求的“≥ 70%”没有在全部格达成，残余 45–55% 通过别的组件（可能是更早层的读取或 MLP）传递，且残余通路的溢出比相同 → 第二条通路也“按输出存放”，提示这是任务层面的约束而非某组头的特性。
- **算力实际：** 约 1.5 GPU·时（含 NFS 加载）。
