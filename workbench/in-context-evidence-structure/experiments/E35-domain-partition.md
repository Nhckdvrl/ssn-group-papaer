# E35：输入领域能把证据分开吗？——Alex 评电影、Sam 评餐厅（2026-10-06）

- **状态：** PLANNED
- **类型：** PILOT（I04 两通路的最后一格）
- **对应：** I04；E30（同领域交互溢出 0.62–0.91）、E31（输出身份分开证据）、E24/E34（上下文标签不分开）、E21（最近邻）
- **问题（一句话）：** 当两位标注者的输入来自不同领域（SST 电影评论 vs Yelp 餐厅评论）时，Sam 的映射翻转还会泄漏给 Alex 吗？
- **设置：** E30 的 SST 设计（Alex/Sam 各 8 条随机交错，类别均衡，条件 same / inter，300 base，SEED0=900000），Alex 的 demo 与 query 来自 SST-5 两极；Sam 的 demo 与 query 来自 Yelp（1 星 / 5 星，6–30 词，公认数据集，直接使用）。标签词相同（negative/positive）。对照：`mixed`——两人都从 SST 与 Yelp 各取一半（领域与标注者无关），检验领域本身是否带来偏置。`scripts/build_domain.py` → `data/domain`。
- **预测（检索只看内容）：** 领域分离时 Alex 溢出比 ≪ 同领域（E30 SST：0.74–0.91）；`mixed` 时溢出比回到高位。
- **决策：** 分离时溢出显著下降 → 映射通道按输入内容（相似度）分开证据——2×2 完整：内容、输出身份可分开，上下文标签、时间不可分开。不下降 → 即使内容不同，同一输出标签下的证据也被合并（输出身份是唯一的键），I04 进一步简化为“按输出汇总”。
- **算力：** 300×2 条件×4 query×2 方案 = 4800 条/模型；Qwen3-8B、Qwen2.5-7B、Llama-2-7B、Qwen3-14B。

## 结果（2026-10-06；Qwen3-8B、Qwen2.5-7B、Llama-2-7B；Qwen3-14B 运行中）

|---|---|---|

- **按决策：** 输入领域分离使泄漏约减半（0.85–0.91 → 0.42–0.49），但远未到 0；同一输出标签下、不同领域的证据仍有近一半被合并。
- **“什么能把关联证据分开”的阶梯（跨实验）：** 不同输出词（E31/E32）0.00 ≪ 不同输入领域（E35）0.42–0.49 < 显式上下文标签（E24/E30/E34）0.51–0.91 < 时间（E21/E26：两种顺序对称，完全合并）。→ 关联存储首先以**输出身份**为键，其次按**输入内容相似度**加权，几乎不以上下文标签、完全不以时间为键。
- **Qwen3-14B：** dom 溢出比 **0.36**（Sam 移动 +9.38、Alex 溢出 +3.39）vs mixed 0.79。累计 4 模型：领域分离 0.36–0.49、混合 0.79–0.91。
