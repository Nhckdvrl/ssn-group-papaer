# E42：顺序为什么改变读标签头选中的锚点？——因果上下文 vs RoPE 位置的 2×2 拆分（2026-10-08）

- **状态：** DONE（2026-10-08）
- **类型：** EXPLORE → 判别（E41 逼出的两个具体来源，结果分叉清楚）
- **对应：** E40（顺序 SD ~1.2 logit，与时间特征无关）；E41（顺序方差 98% 在读标签头，抖动 = 读到哪些标签）；E36（读标签头平均而言不看位置）
- **问题（一句话）：** 同一组 demo 换顺序时，答案的波动来自 (a) 因果顺序：每个锚点看到的前文变了，锚点内容随之改变；还是 (b) RoPE：锚点与 query 的相对位置变了，匹配分数随之改变？
- **事先预测：** 两种来源都可能。E36 的“平均不看位置”与“非单调的 RoPE 相位干扰”并不矛盾，因为后者不产生近因，只产生抖动。E37 显示锚点内容不携带标签流历史，这一点倾向 (b)。
- **谁依赖：** 若主要是 (b)，顺序敏感就是位置编码对按内容检索的副作用，可以在推理时通过位置编号消除，不需要搜索排序或多顺序集成；若主要是 (a)，顺序敏感是上下文表示本身的性质，位置技巧无效。
- **设置：** Qwen3-8B（先），数据为 E40 的 `kernel_perm` 的 240 个 base × 7 个非原始顺序。每个 demo 块单独分词后拼接（拼接序列与原提示分词一致性先检查）。四种条件：
  - O：原 token 顺序 + 原位置编号（基线）；
  - A：新 token 顺序 + 连续位置编号（= E40 的普通换序）；
  - B：新 token 顺序 + 每个块保留它在原顺序中的位置编号（只改因果顺序，相对位置不变）；
  - C：原 token 顺序 + 每个块使用它在新顺序中的位置编号（只改 RoPE 位置，因果上下文不变）。
- **读数：** 每个 base 在各条件下相对 O 的偏差 ld − ld_O；顺序 SD（7 个顺序，base 内）在 A / B / C 三个条件下的中位数；以及 B、C 的偏差能否相加重建 A（r(A, B+C)）。
- **阳性对照：** A 应复现 E40 的顺序 SD（≈ 1.2）；O 用拼接分词时的 ld 与 E40 原提示的 ld 相同（|差| < 0.05）。
- **结果 → 下一步（事先写）：**
  - SD_C ≈ SD_A 且 SD_B 小 → **RoPE 主导**：下一步问 RoPE 怎样干扰读标签头（相对距离的相位 × 锚点内容），以及“固定位置编号”能否在不同任务上消除顺序敏感而不损失准确率。
  - SD_B ≈ SD_A 且 SD_C 小 → **因果上下文主导**：下一步问锚点内容中是哪一部分随前文改变（前一条 demo 的标签？数值？）。
  - 两者都大且近似可加 → 两个来源并存，分别报告份额。
  - B 中非单调的位置编号若使模型崩溃（ld 分布明显偏离 A），则 B 不可判定，只用 C 与 A 比较。
- **算力：** 240 × 7 × 3 + 240 ≈ 5300 个提示，单卡约 10 分钟。

## 结果（跑完后填写）
（2026-10-08；Qwen3-8B；`results/e42/Qwen3-8B_analysis.json`；数据全为 clean 结构，见 E43 更正）
- 阳性对照：拼接分词与原提示 240 / 240 一致；O 与 E40 原顺序 ld 完全相同（最大差 0.0）；A 与 E40 换序结果完全相同。
- 相对 O 的偏差 RMS（base 中位数）：A（完整换序）1.65；**B（只改因果顺序）1.59；C（只改位置编号）1.81**。
- 相关：r(A, B) 0.29、r(A, C) 0.26、r(A, B + C) 0.29；B、C 的方差均为 A 的约 1.6 倍。
- **按表：** 两者都大、但**不可加**——不是“两个来源各占一部分”，而是任何一种扰动都会让读出跳到一个近乎独立的新值。位置平移（相对位置不变）几乎不变（E43b：0.14），说明跳动来自相对位置的改变，而不是数值误差。
- **逼出的问题：** 在任何改变位置的扰动下答案都会独立跳动 → 顺序选择方法挑出的“好顺序”是否只是位置几何？（E44）；抖动是否可以由更软的读取去除？（E43a：不能，同比例缩小）。
