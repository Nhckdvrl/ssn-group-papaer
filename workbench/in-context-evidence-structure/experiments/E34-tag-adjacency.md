# E34：上下文主效应走“相邻序列统计”通路吗？——标注者标签的位置（2026-10-06）

- **状态：** PLANNED
- **类型：** PILOT（I04 两通路的区分）
- **对应：** I04；E30（主效应绑定、交互泄漏；32B 主效应溢出≈0）
- **问题（一句话）：** 主效应之所以能绑定到标注者而交互不能，是因为主效应走“标签紧邻的上下文 token → 标签”的序列统计通路（与标签流的变化点通道同类），而映射走“内容检索 → 标签锚点”通路吗？
- **设置：** 与 E30 完全相同的 base 与条件（same / inter / main，SEED0=820000，300 base/任务），只改变标注者行的位置：`adj`（E30 原样：内容 → Annotator → Label）与 `far`（Annotator → 内容 → Label；query 同样放在内容之前）。`TAGPOS=far OUT=ctxeffect_far python build_ctxeffect.py`；`adj` 直接复用 E30 结果。
- **预测（两通路）：** far 时主效应的绑定明显下降（溢出比上升），交互溢出比保持高位（两种位置都是 0.6–0.9）。
- **竞争解释：** 若主效应来自“按标注者分组的全局标签先验”（与相邻无关），则 far 与 adj 的主效应相同。
- **决策：** 主效应在 far 时显著变弱 → 主效应依赖相邻序列统计（归纳/n-gram 式），与“边缘通道 = 序列统计”统一；不变 → 存在一个按上下文分组的标签先验，两通路的表述改为“标签先验（可按上下文条件化）+ 内容检索（不可）”。
- **算力：** 7200 条/模型；Qwen3-8B、Qwen2.5-7B、Llama-2-7B、Qwen3-14B。
