# E36：两条通路在头层面可分吗？——映射头 vs 先验头（2026-10-06）

- **状态：** DONE（2026-10-06 整理时更新状态）
- **类型：** CLAIM（I04 机制）
- **对应：** I04（证据按输出存放：可按上下文条件化的标签先验 + 只看内容与标签身份的检索）；近邻 Wang et al. 2023（标签词锚点）、Cho et al. 2025（检索电路）、Yin & Steinhardt 2025（FV 头 vs 归纳头）
- **问题（一句话）：** E30 的“交互泄漏”与“主效应绑定”是否由两组不同的注意力头承载？映射头的注意力是否只由内容相似度决定、对标注者不敏感？先验头是否按标注者分配注意力、对内容不敏感？
- **设置：** Qwen3-8B（36 层 × 32 头）、Qwen2.5-7B（28 × 28），eager 注意力，bf16。数据：E30（`data/ctxeffect`）前 150 base/任务 × 3 条件（same/inter/main）× 4 query = 3600 提示/模型。每个提示记录：(1) 每个头在答案位置的输出经最终 RMSNorm 缩放后在 W_U[标签1]−W_U[标签0] 方向上的直接 logit 贡献（DLA），以及每层 MLP 的 DLA；(2) 答案位置对 16 条 demo 标签词 token 的注意力（每层每头）。`scripts/mech_heads.py` → `results/mech/<model>_ctxeffect.npz`。
- **读数（按 base 与 query 类别配对）：**
  - 每个头的“Sam 移动”（inter−same，Sam query，朝 B 映射）、“Alex 溢出”（同，Alex query）、“主效应”（main−same，Sam−Alex，朝 L）。
  - 映射头 = Sam 移动贡献最大的头；先验头 = 主效应贡献最大的头。看两组是否重叠，以及映射头的 Alex 溢出 / Sam 移动比（≈行为溢出比 → 泄漏发生在这些头）。
  - 注意力键：对 top 头，把答案位置对各 demo 标签词的注意力回归到 [同类、同标注者、位置]；预测映射头的“同类”系数大、“同标注者”≈0，先验头相反。
- **阳性对照：** DLA 求和 + MLP 应近似再现总 logit 差（检验分解正确）。
- **因果（E36b，跑完分解后写卡）：** 消融 top-k 映射头 vs top-k 先验头 vs 匹配随机头，看 Sam 移动、Alex 溢出、主效应的变化（双分离）。
- **决策：**
  - 两组头基本不重叠、注意力键如预测 → I04 两通路在头层面成立，进入 E36b 因果验证。
  - 同一组头同时承载两者 → 两通路只是行为层面的区分；需要找“同一组头为何对主效应能按标注者分配、对映射不能”（例如 QK 中的不同成分）。
- **算力：** 每模型单卡 ~15 分钟。

## 结果（2026-10-06；Qwen3-8B、Qwen2.5-7B）
- **分解正确性：** 逐头 DLA + MLP 重建总 logit 差 r=0.9997（最大误差 0.11）；在 E30 上重建的 Sam 移动 / Alex 溢出 / 主效应 = +3.16 / +1.98 / +0.92（行为 +3.19 / +1.99 / +0.95）。
- **两组头的预测被否定：** 承载映射（Sam 移动）的前 20 头与承载主效应的前 20 头重合 15/20（Qwen3-8B 两任务）、20/20 与 14/20（Qwen2.5-7B）。它们是同一族晚层“读标签”头（Qwen3-8B L26–35，如 L30H25、L33H31、L31H13；Qwen2.5-7B L19–27，如 L26H17），前 20 头承载 95–127% 的头部效应。
- **注意力的键：** 这些头从答案位置读 demo 标签词，选择性：同类 ×2.4–69（Qwen3-8B 数字前 20 平均 ×8.5，SST ×2.4；Qwen2.5 ×8.5/×5.3）≫ 同一标注者 ×1.5–2.6 ≫ 位置（斜率 ≈0 或略负；E28 中对后 8 条的份额仅为均匀的 ×1.0–1.15）。
- **同一组头内两种效应的溢出不同：** 交互 0.55/0.72（Qwen3-8B 数字/SST）、0.80/0.86（Qwen2.5）vs 主效应 0.36/0.37、0.60/0.64；但 Alex/Sam 对 Sam 偏离 demo 的注意力之比在两条件下相同（数字 0.71 vs 0.66；SST 0.93 vs 0.92）→ 主效应更好的绑定不来自“看谁”，而来自注意力之后（读出内容/其他 token/MLP）。
- **时间维度（E28 提示）：** 偏置成分与条件成分的时间效应同样由这族头承载（前 20 重合 11–13/20；逐头相关 +0.42 到 +0.92）；同一组头里偏置成分噪声规范（Qwen3-8B 数字 −0.47）、条件成分噪声反（+1.32）。由于注意力不看位置，时间信息必在被读取的锚点表示中。
- **按决策表：** 两通路不是两组头，而是同一族读标签头读出的两类信息：注意力按内容（强）、标注者（弱）、时间（无）选择锚点；锚点内容决定读出什么。→ 进入 E37：锚点是否携带“到此为止的标签流状态”（运行滤波器）。
