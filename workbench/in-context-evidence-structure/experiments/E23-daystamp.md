# E23：把时间写进内容——给每条 demo 标注“day k”能否让分类 ICL 用上时间？（2026-10-05）

- **状态：** RUNNING
- **对应：** 检索机制的建设性预测 + 实用缓解
- **设计：** 与 E22 相同的 base（数字 small/large、SST positive/negative，300 base/格式，11 个模式），不加大写标记，而是在每条 demo 的输入行末加 “(day t)”，t=1..16，query 加 “(day 17)”。两候选（A 映射 vs B 映射）。
- **预测：** 若分类 ICL 是按内容检索，时间写进内容后检索会偏向“day 接近 17”的 demo → 出现 recency（suffix_8 ≫ prefix_8、成簇 > 0），但仍是可加核，噪声方向检验大概率仍失败（recency ≠ 结构推断）。若完全无变化，说明检索只按任务相关特征而非全部内容。
