# E10b：隐式 (λ, ε) 先验拟合（2026-10-05）

- **状态：** DONE（Qwen3-8B, E06 数据）
- **方法：** 对每个固定 (λ, ε)（λ∈{0,.01,.02,.05,.1,.2,.3}，ε∈{.01,.03,.05,.1,.2,.3}）计算 rule oracle 的 P(B)，以 LM log-odds ~ a + b·logit(P_B) 回归（2000 行抽样），报告逐行与条件均值 R²。
## 结果
- **表层（const）**：最佳 λ=0.05, ε=0.1（条件均值 R² 0.384；λ=0.01–0.1 一条脊）；可交换（λ=0）最佳仅 0.193。
- **潜在（rule5）**：最佳 **λ=0**, ε=0.3（条件均值 R² 0.889）；任何 λ>0 单调变差（λ=0.01 已降到 ≤0.86）。
**判读：** 表层上 LLM 像 hazard≈0.02–0.05 的变化检测者；潜在层上像“规则永不改变、矛盾都是高噪声”的可交换学习者。表层拟合 R² 较低是因为 LM 在标签流上极度自信（|allA|≈25），线性链接无法完全刻画。
