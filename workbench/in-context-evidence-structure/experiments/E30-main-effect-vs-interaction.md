# E30：上下文的主效应 vs 上下文 × 输入的交互（无时间结构）（2026-10-06）

- **状态：** DONE（2026-10-06 整理时更新状态）
- **类型：** PILOT（idea 的决定性实验）
- **对应：** idea I04（候选，推广 I03）：“ICL 学得到上下文变量的主效应（标签边缘分布随上下文变化），学不到上下文 × 输入的交互（映射随上下文变化）。时间是其中一个上下文变量：边缘漂移 = 时间主效应（可追踪），concept drift = 时间 × 类别交互（不可追踪）。”
- **问题（一句话）：** 去掉时间结构、只留一个显式的上下文变量（标注者），模型能学到“这位标注者偏爱某个标签”（主效应），却学不到“这位标注者的映射相反”（交互）吗？
- **设置：** E24 同源 base（数字 small/large、SST 两极；类别均衡），300 base/任务，SEED0=820000。16 条 demo，每条带 `Annotator: Alex/Sam`，两人各 8 条，**随机交错**（无时间结构）；Sam 的 8 条在类别上均衡（各 4 条）。条件：
  - `same`：两人都用 A 映射（基线）。
  - `inter`（交互）：Alex 用 A 映射，Sam 用 B 映射（取反）。
  - `main`（主效应）：Alex 用 A 映射；Sam 有 6/8 条给出同一个标签 L（与类别无关；L 在 base 间平衡），另 2 条按 A 映射。
  - query：Alex 或 Sam × 两个类别（4 个 query/base/条件）。
  - 标签候选：两个标签词。`scripts/build_ctxeffect.py` → `data/ctxeffect`。程序化 + 公认 SST，无需审计。
- **读数：**
  - 交互绑定 = [P(B 映射|Sam) − P(B 映射|Alex)]_inter − [同]_same（按 base 与 query 类别配对）。
  - 主效应 = [logit P(L|Sam) − logit P(L|Alex)]_main − [同]_same。
  - 规范参照：把标注者当作条件变量的 exact 学习者（交互：属性 [类别, 类别⊕标注者] 的规则空间；主效应：每位标注者各自的标签边缘 + A 映射混合——用简单的计数近似：Sam 的 L 比例 6/8）。主要比较两种效应相对各自规范值的比例。
- **竞争预测：**
  - I04：主效应大（接近规范），交互小（远低于规范，≈E24）。
  - “模型就是不用标注者行”：两者都≈0。
  - “模型会按标注者分组检索”：两者都大。
- **混杂审计：**
  - 标注者名字本身的先验：`same` 基线差分消除。
  - 主效应条件中 Sam 的 L 标签也改变了整体标签边缘（10/16 vs 6/16）：Alex query 与 Sam query 同样受整体边缘影响，差分只留下“按标注者”的部分 — 已控制。
- **决策表（跑之前写）：**
  - 主效应大、交互小 → I04 成立；concept drift 盲成为“ICL 不学上下文交互”的特例，论文主旨从“漂移”上升为“ICL 学主效应不学交互”。下一步：在时间上做同样的主效应/交互对照（E28 已部分完成），以及寻找模型能学交互的条件（规模、交互强度、标记在输出 token 上）。
  - 两者都≈0 → 标注者行被忽略，E24 的否定只说明“标注者行不进入检索”；I04 需要换一个模型会使用的上下文变量再测。
  - 两者都大 → 交互可学，E24 的失败与“块状呈现”或“新奇性”有关，I04 作废。
- **算力预算：** 300×2 任务×3 条件×4 query = 7200 条/模型；Qwen3-8B、Qwen2.5-7B、Mistral-7B、Llama-2-7B、Qwen3-14B，每个 ~5 分钟。
