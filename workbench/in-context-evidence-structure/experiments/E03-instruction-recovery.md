# E03：一句指令能否恢复结构推断（R8 对照）（2026-10-05）

- **状态：** DONE（Qwen3-8B pilot）
- **对应：** C02；R8
- **问题：** E02a 中 Qwen3-8B 不区分噪声与变化。是“没有能力”，还是“不会自己从证据推断结构”？
- **设计：** 25 个 E02a 条件 × 3 种 header：`none`（中性）、`change`（“规则可能在收集过程中改变；按末尾生效的规则标注”）、`noise`（“少数标签是标注员的随机错误；按真实规则标注”）。
- **预测：**
  - 能力存在但不自发：`change` 下 suffix_k ≫ disp_k，block_start4 被压低；`noise` 下单点/零散翻转影响下降。
  - 能力缺失：三种 header 的签名基本相同。
  - 指令只做整体偏移（例如 change 让所有 B 都更被信任）：suffix 与 disp 一起上移，二者差不变 → 仍是集合式，只是先验改变。
- **读数：** 与 E02a 相同（lo_B，base 内配对），关键量 = suffix_4 − disp_4、noise_2 效应在各 header 下的差。
- **算力：** 8B 单卡约 25 min。

## 结果（2026-10-05）
| header | allA lo_B | 末位−首位 | suffix4−disp4 | noise2→suffix3 | r(set) |
|---|---|---|---|---|---|
| none | −2.69 | +0.09 | −0.13 [−0.36,0.09] | +0.65 | 0.981 |
| noise | −1.54 | +0.08 | −0.00 [−0.16,0.16] | +0.33 | 0.975 |
| change | −1.66 | +0.01 | −0.07 [−0.24,0.11] | +0.34 | 0.977 |
（meta：suffix4−disp4 +1.45，noise2 −0.42）
**判读：** 两种指令都只把所有效应整体压缩（更不自信），不改变结构签名 → 一句指令无法恢复（R8 对照完成）。
