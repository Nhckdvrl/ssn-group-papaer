# E16：确认版 v1——不依赖 nonce 词库的“变换 vs 分类”对照（2026-10-05）

- **状态：** RUNNING（Qwen3-8B 完成；其余模型进行中）
- **为什么：** pilot 的 nonce 规则实验使用了未经 step-5 审计的候选词库（配额用尽）。核心论点“全局变换的变化被察觉、分类映射的变化察觉不到”可以完全用自然词与数字检验，因此先做一个无 nonce 依赖、全新种子（≥500000）的确认版。
- **数据（`data/confirm_v1`，6 格式 × 300 base × 27 A/B 模式 = 48600 条）：**
  - 全局变换：`arith`（x→x±3，角色互换）、`case`（词→大写 / 反转）、`stream`（常量 item，自然词标签对，如 red/blue）
  - 分类映射：`parity_nat`（even/odd，A 正确 / B 翻转，角色互换）、`mag_nat`（small/large，<50 / ≥50）、`sst`（SST-5 两极句子，positive/negative）
- **模型：** Qwen3-8B、Qwen3-8B-Base、Qwen2.5-7B、Mistral-7B（白天）；夜间扩到其余模型。
- **主读数：** 每格式 suffix_4−disp_4（成簇选择性）、noise_2__suffix_3−suffix_3（噪声方向）、末位−首位、late_block−start_block，与 meta oracle 对照；归一化指数 CSIn/NDIn。
- **预测（跑前写定）：** 三种全局变换格式：成簇 > 0、噪声方向 < 0（与 oracle 同向），r(meta) > r(set)；三种分类格式：成簇 ≈ 0、噪声方向 ≥ 0（与 oracle 反向），r(set) > r(meta)。所有模型同向。
- **若不符：** 逐格式报告，按格式修正边界（不删格式）。
