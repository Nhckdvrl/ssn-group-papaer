# E21：自然分类任务上的“局部适应”——最近邻，不是最近期（2026-10-05）

- **状态：** DONE（Qwen3-8B、Qwen2.5-7B；Mistral 进行中）
- **对应：** C02 的后果；检索机制的行为证据（在自然任务上复现 E04）
- **设计：** `build_local_nat.py`。数字 small/large（<50 / ≥50），自然标签，A=正确映射（奇数 base 角色互换）。16 个 demo（8 小 8 大）；模式 allA / suffix_8（前 8 A、后 8 B）/ prefix_8（前 8 B、后 8 A）/ disp_8。每个类别选两个未见过的 query：near = 与“位置 8–15 的同类 demo”数值最近、与“位置 0–7 的同类 demo”最远；far 相反。同一 base 的所有模式复用这两个 query。规则 oracle 对 near/far 给出完全相同的预测。300 base × 2 类。
## 结果（lo_B，B=当前模式下“后来者”的映射）
| 模型 | 模式 | near | far | near−far [95% CI] | oracle |
|---|---|---|---|---|---|
| Qwen3-8B | allA | −5.15 | −4.60 | −0.55 [−1.01,−0.08] | −4.51 |
| Qwen3-8B | suffix_8 | **+0.73** | **−0.90** | **+1.63 [1.45,1.81]** | +2.31（两者） |
| Qwen3-8B | prefix_8 | **−0.72** | **+0.91** | **−1.63 [−1.83,−1.45]** | −2.31（两者） |
| Qwen3-8B | disp_8 | +0.05 | +0.06 | 0.00 [−0.16,0.15] | +0.11 |
| Qwen2.5-7B | suffix_8 | +0.63 | −0.32 | +0.95 [0.85,1.06] | +2.31 |
| Qwen2.5-7B | prefix_8 | −0.60 | +0.31 | −0.91 [−1.02,−0.80] | −2.31 |
**判读：** 模型对 query 采用的映射由数值上最近的 demo 携带的映射决定，与其新旧无关：prefix_8 中靠近“过时”demo 的 query 按过时映射回答（+0.91），suffix_8 中靠近“旧”demo 的 query 仍按旧映射（−0.90）。完全对称 → 时间不起作用，起作用的是输入空间的邻近性。“最近邻，不是最近期”。
