# I01：LLM 知道“标签变了”，却不知道“规则变了”——表层时间、潜在集合（2026-10-05）

- **状态：** PROMISING（pilot 证据：E02a/E04/E05/E06/E07/E08 + 10 个模型；确认版待审计词库与新种子）
- **来源：** 测量异常 E02a（结构推断的 meta oracle 预测“前缀噪声令后缀更不可信”，所有模型方向相反）→ E05 的维度扫描（d=0 时方向正确，d≥1 立即翻转）→ E06 定位开关；近邻分歧：Kossen'24（recency）vs Falck'24（违反 exchangeability）vs Bigelow'25（计数式 belief 模型高精度）vs Cho'25（检索电路）。
- **研究动作：** 定位（开关在 0→1 个属性之间，且由“标签是否依赖输入”而非“item 是否可区分”决定）+ 引入成熟构念（Nassar 的 changepoint vs oddball；Piray & Daw 的 stochasticity vs volatility；Massey & Wu 的 system neglect）+ 干预（注意力头消融 E10）。
- **如果为真，主张是：** 冻结 LLM 的 in-context 证据聚合有两种互斥的组织方式：当“状态”直接表现为表层 token 序列时，模型做时间敏感、方向上近似 Bayes 的变化/噪声推断；当状态是潜在的输入→输出规则（few-shot 学习的典型情形）时，模型把证据当作按内容相似度检索的可交换集合——不区分噪声与变化、不能被指令纠正、长上下文也分不出 A→B 与 B→A、对变化只做局部（相似 item）适应，并且会被恰好形成的表层标签游程带向错误方向。
- **不同结果的信息增益：**
  - 32B/混合架构也如此 → 普遍性（预训练 LLM 的共性），转向“为什么”（数据/目标）与“推理能否补救”（E09）；
  - 大模型或门控线性注意力（Qwen3.5）出现潜在层面的时间敏感 → 规模/架构涌现，故事变成“何时出现”；
  - E10 消融游程头使表层时间敏感消失 → 机制闭环（表层序列统计头 vs 内容检索头）。
- **最近邻与增量（定位表）：**
  | 近邻 | claim | 我们的增量 |
  |---|---|---|
  | Kossen et al. ICLR'24 §8 | 映射中途翻转时偏向近处信息 | 那是固定位置核；在噪声 vs 变化的方向相反检验下，潜在规则层面没有结构推断（10 模型、NL、T=64 均如此）；时间敏感只在表层 |
  | Falck et al. ICML'24 | LLM 违反 martingale/exchangeability → 非 Bayesian | 潜在层面近似 exchangeable（与 set oracle r≈0.98），违反来自无方向的顺序特异性波动 + 表层序列统计；表层上方向近似 Bayes |
  | Bigelow et al. 2025 | 计数式 belief 模型（ICL=证据累积）预测力强 | 解释其为何有效：潜在层面确实是计数式（可交换）；并给出其失效边界（表层序列） |
  | Jiao et al. 2026 | 单个错例显著误导；位置偏置头 | 错例影响由相似度决定；“噪声 vs 变化”的结构问题在潜在层面无解 |
  | Dudley ICML'26 / Qin ICLR'26 | 训练的 transformer 能做 in-context 变化检测 / GLA 带 recency | 预训练 LLM 在潜在规则层面不做；能力在表层存在、未被用于潜在层 |
  | Cho et al. ICLR'25 | ICL 三步电路（检索+复制）、recency 来自位置相似度 | 行为上验证其检索电路主导潜在任务；新增“检索索引二选一（内容 vs 时间）”与其后果 |
  | Park et al. ICLR'25 | ICL 是相互竞争的多种算法（检索/推断 × unigram/bigram） | 在真实 LLM 中给出由任务格式决定的赢家通吃，且规范解需要两者结合 |
  | Xu et al. 2026 BeliefTrack | 多轮逻辑证据下 belief stay/update 失败，RL 可修 | 我们是统计证据、无显式信号、单次 forward；给出“表层/潜在”这一可预测的失效边界 |
  - **Compression risk：** “不就是 Kossen 的 recency + Chan'22 的 exemplar 吗？”——load-bearing 差异：(1) 方向相反预测（前缀噪声）在潜在层面方向错误、表层方向正确；(2) 同一标签流加无关输入不改变时间敏感（E06），排除“exemplar 检索线索即导致时间盲”；(3) T=64 时 A→B 与 B→A 不可分；(4) 表层游程把潜在证据带向反方向（E08 anti）。
- **预期论文形态：** B 构念 + 测量（+ 机制与后果），标题方向：*In-Context Learners Notice When Labels Change, Not When Rules Change*。
- **排序打分：** 证据 3 · 增量清楚度 3 · 形态匹配 3 · 成本 3 · 可完成性 3 · 信息增益 3
- **2026-10-05 傍晚的边界修正（重要）：** E11/E11b/E13 显示“表层 vs 潜在”的说法不准确：熟悉的全局变换（大写↔反转、+3↔−3）在潜在/条件层面也被时间敏感地整合；自然标签的情感翻转仍时间盲。当前最一致的划分是 **全局变换（每条 demo 都在为同一个参数作证）→ 序列整合；分类映射（证据需按输入类别路由）→ 相似度检索 + 集合汇总**。E15 在同一数字域内检验。若成立，标题方向改为“分类式 ICL 是时间盲的”或“Retrieval makes in-context learning time-blind”。
- **2026-10-05 17:00 进一步确认：** E16（无 nonce、全新种子、4 模型）：分类映射在所有模型上时间盲；大写↔反转、自然词标签流在所有模型上时间敏感；±3 在 Qwen3 强、在 Qwen2.5/Mistral 弱。condarith（偶→x+2/奇→x−2 与其重分配；答案不可复制）仍时间盲（suffix−disp −0.08，噪声方向反），排除“可复制标签”混淆。E17：变换被压缩为随时间更新的任务向量，分类映射没有可迁移向量。**当前原则：作用于所有输入的全局规则 → 随时间整合（任务向量）；需要按输入类别路由的规则 → 按内容检索并集合汇总。** 论文工作标题：*In-context learners track changes in what to do, not in which input gets what.*
