# E38：噪声/变化的证据经由哪些位置到达答案？——锚点因果修补（2026-10-06）

- **状态：** RUNNING（卡片在结果前写下）
- **类型：** CLAIM（I04 机制，因果）
- **对应：** E36（读标签头不看位置）、E37（锚点内容是否携带历史）
- **问题（一句话）：** E28 中“前缀两条零散噪声”造成的效应，是通过“末尾新 regime 锚点写入的变化信号”传到答案，还是答案位置直接读取那两条噪声 demo？
- **设置：** E28 的 suffix_3（干净）与 noise_2__suffix_3（噪声）提示逐 token 对齐（只在 demo 1、5 的单 token 标签上不同）。在噪声提示中，把某组位置进入第 l 层的残差替换为干净提示的对应状态，l 扫描 0–35（每 2 层）。位置组：`anchors`（demo 13–15 的标签 token）、`inputs`（demo 13–15 输入的最后一个 token，对照）、`noise_anchors`（demo 1、5 的标签 token）、`all`（全部位置，阳性对照，必须精确复原干净输出）。Qwen3-8B、Qwen2.5-7B，60 base/任务 × 2 query。`scripts/mech_patch.py`。
- **读数：** 恢复比例 =（修补后 − 噪声）/（干净 − 噪声），按 maj/min query 与偏置/条件成分分别计算，随层变化。
- **预测：**
  - 若变化点信号在新锚点中：`anchors` 在中层修补即可恢复大部分（尤其偏置成分）。
  - 若答案直接读取噪声 demo：`anchors` 恢复≈0；`noise_anchors` 在答案位置读出之前的层修补可完全恢复，之后不再起作用——读出层即为“交接”的层。
- **冒烟测试（1–2 base）：** `all` 在所有层精确复原（阳性对照通过）；`anchors` 几乎不恢复；`noise_anchors` 在 0–12 层完全恢复，18 层后减弱。

## 结果（2026-10-06；60 base/任务 × 2 query）
恢复比例（1 = 完全恢复到干净输出），按层 [0, 4, 8, 12, 16, 20, 24, 28, 32, 35]（Qwen2.5 为 [0, 4, …, 27]）：
- **阳性对照 `all`：** 两模型所有层均精确为 1.00。
- **Qwen3-8B 数字**（噪声效应：偏置 −0.33、条件 +0.74）：`anchors` 偏置 0–0.22、条件 ≈0；`inputs` ≈0；`noise_anchors` 条件 0.83–0.91 直到 L16，L20 0.74、L24 0.39、L28 0.14、L35 0.03；偏置 1.00 → L8 0.61 → L12 0.38 → L16 −0.04 → L20–32 −0.72 到 −0.95（反超）。
- **Qwen3-8B SST**（偏置 −0.72、条件 +1.19）：同型；`noise_anchors` 条件 ≥0.93 到 L20、L24 0.28、L28 0.07；偏置 L16 起变负（−0.16 到 −0.59）。
- **Qwen2.5-7B**（偏置≈0、条件 +0.32/+0.44）：`anchors`/`inputs` 对条件恢复≈0；`noise_anchors` 条件 0.87–1.0 到 L12–16，L20 0.20–0.54，L24 0.04–0.14，L27≈0。
- **判读：**
  1. 方向错误的条件效应 = 答案位置在晚层（Qwen3-8B L24–35、Qwen2.5 L18–27，与 E36 的读标签头一致）直接读取噪声 demo 的锚点；末尾新锚点不携带“变化”信号（E37：成串的新锚点 value 反而更弱）。
  2. 规范符号的偏置效应 = 晚层直接读取（推向错误方向）+ 一条在 L16 前建立的间接通路（推向规范方向）；后者不经由末尾锚点或其输入 token。→ E38b：检验间接通路是否位于各 demo 的“Label:”预测位置（模型在那里预测下一个标签，天然对标签流做运行估计）。
