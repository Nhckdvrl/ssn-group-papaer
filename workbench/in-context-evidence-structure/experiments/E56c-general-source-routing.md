# E56c：是否存在通用的“按来源读证据”的路由方向？——多任务训练、未见数据集迁移（2026-10-09）

- **状态：** DONE（2026-10-09）
- **类型：** 构造性判别（E56 / E56b 的推进：单任务模块在规则反转上完全迁移，跨数据集只部分迁移）
- **问题（一句话）：** 用三种来源条件任务（交互型 toxic / safe、阈值型 toxic / safe、SST 映射反转 positive / negative）混合训练一个只改 query 的秩 8 模块（冻结 Qwen3-8B，第 16–35 层答案位置），它能否在三个**未见**的真实数据集上提高按来源的判断：Davidson 两套规范（toxic / safe，按规范的冒犯类准确率）、MovieLens 共享账号（yes / no，真实用户标签）、GoEmotions（neutral / emotional，A − B 区分）？
- **事先预测：** 若冻结模型中存在通用的来源路由方向，多任务模块在未见集上的提升应明显超过 E56b 的单任务模块，并接近或超过单一来源上界。
- **结果 → 判断（事先写）：** 在至少两个未见集上，(adapter − default) ≥ 0.5 × (single − default) → **存在通用的来源路由方向**（默认 query 不指向它）；只在与训练词表相同的 Davidson 上有效 → 路由修正依赖标签词表；都无效 → 来源路由是任务特定的。
- **设置：** 900 步（每任务 300），Adam 1e-3，softplus 边际损失；每个测试集 40 个上下文；脚本 `scripts/e56c_multitask.py`。
