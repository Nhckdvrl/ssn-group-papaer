# E31：交互泄漏经由共享的输出标签？——标注者词表分离的剂量实验（2026-10-06）

- **状态：** DONE（2026-10-06 整理时更新状态）
- **类型：** PILOT（I04 的机制刻画）
- **对应：** I04；E30（交互溢出 62–91%）、E22（大写标签：8B 不分组、32B 分组）
- **问题（一句话）：** 当 Sam 用一套与 Alex 不同的标签词时，Sam 的映射翻转还会泄漏给 Alex 吗？泄漏是否随两套标签词的距离（同词 → 大小写 → 近义词 → 无关 nonce 词）单调下降？
- **设置：** E30 的 base 构造（16 条 demo，Alex/Sam 各 8 条随机交错，类别均衡），SEED0=840000，300 base/任务（数字、SST）。Alex 始终用自然标签词（small/large；negative/positive）。Sam 的词表 4 级：`same`（同词）、`case`（大写）、`syn`（近义：little/big；bad/good）、`nonce`（每个 base 从 step-5 审计通过的 84 个 nonce 标签词中随机抽 2 个）。映射 2 种：`A`（两人同映射）、`inter`（Sam 取反）。query：Alex/Sam × 两类；候选为该 query 标注者的词表。`scripts/build_vocabsep.py` → `data/vocabsep`。
- **读数：** 每个词表级别：Sam 移动 =（inter − A）在 Sam query 上的 logit P(B 映射)；Alex 溢出 = 同一量在 Alex query 上；溢出比 = 溢出 / 移动；交互绑定 = 移动 − 溢出。
- **竞争预测：**
  - 泄漏经由共享输出标签（关联以标签为键）：溢出比随词表距离单调下降，nonce 时接近 0。
  - 泄漏经由输入相似度（关联以输入为键，与标签无关）：溢出比在 4 级间不变。
- **混杂：** nonce/近义词本身较难被映射（Sam 只有 8 条 demo 学他的词表）→ 看 Sam 移动的量级并报告；Alex 的词表与 query 候选在 4 级间相同，溢出可直接比较。
- **决策：** 单调下降 → 关联存储的键是“输出标签身份”，可交换汇总发生在共享输出的证据之间；I04 的机制表述精确化，并给出缓解（每个上下文一套输出词）。不变 → 汇总发生在输入侧（相似度检索），输出词表无关。
- **算力：** 300×2×4×2×4 = 19200 条/模型。

## 结果（2026-10-06；Qwen3-8B、Qwen2.5-7B 完成，Mistral/Llama-2/Qwen3-14B 运行中）
溢出比 = Alex query 的移动 / Sam query 的移动（0 = 完全按标注者分开）；绑定 = Sam 移动 − Alex 溢出（规范计数学习者 +3.22）。

| 模型 | 任务 | 同词 | 大写 | 近义词 | nonce |
|---|---|---|---|---|---|
| Qwen3-8B | 数字 溢出比 | 0.62 | 0.29 | 0.20 | **−0.01** |
| Qwen3-8B | SST 溢出比 | 0.81 | 0.53 | 0.44 | **0.00** |
| Qwen2.5-7B | 数字 溢出比 | 0.76 | 0.28 | 0.15 | **0.00** |
| Qwen2.5-7B | SST 溢出比 | 0.91 | 0.69 | 0.64 | **0.00** |
| Qwen3-8B | 数字 / SST 绑定 | 1.28 / 1.18 | 4.27 / 3.11 | 5.35 / 3.78 | 4.48 / 13.44 |
| Qwen2.5-7B | 数字 / SST 绑定 | 0.63 / 0.23 | 3.22 / 0.97 | 3.68 / 1.10 | 4.36 / 4.47 |
（所有溢出与绑定的 CI 半宽 ≤0.6；Sam query 候选概率质量 0.60–1.00。）
- **按决策：** 溢出比随两套标签词的距离单调下降（4/4 格），nonce 词表时溢出为 0、绑定达到或超过规范值。→ 上下文 × 输入的交互**可以**在上下文中学会；泄漏经由共享的输出标签发生。SST 中近义词（bad/good）与 negative/positive 语义更近，泄漏更大（0.44–0.64）；数字中 little/big 泄漏较小（0.15–0.20）——泄漏随输出标签的语义接近程度增大。
- **对 I04 的修正：** “学不到交互”不准确；准确的说法是：**关联证据按输出标签（的语义身份）存放并汇总；共享输出标签的上下文之间，证据可交换地合并。** 时间上的 concept drift 正是“新旧 regime 共享输出标签”的情形。
