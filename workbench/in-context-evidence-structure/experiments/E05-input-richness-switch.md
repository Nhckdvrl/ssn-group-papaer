# E05：输入丰富度是否把聚合从“按时间”切换到“按相似度”？（2026-10-05）

- **状态：** PLANNED（数据已构建：`data/dim_pilot_T16`，27000 条）
- **对应：** C02 / C03
- **问题：** 没有输入（所有 item 特征相同 → 纯标签序列）时，LLM 是否表现出时间敏感（recency、成簇>零散、噪声前缀降低信任）？随着属性数 0→1→2→3→5 增加，是否逐渐变成 E02a 那样的集合/样例聚合？
- **设计：** 每个维度 200 base × 28 模式（allA、single_{1,4,8,12,16}、suffix_1..8、disp_{2,3,4,6}、noise_{2,4}×suffix_{0,3,5}、block_*）。d≤3 时 demo 有放回采样（输入空间小）。
- **oracle 规范对照（d=0）：** suffix_4 meta +2.16 vs disp_4 −1.86（set 两者相同 −4.90）；noise_2/4 前缀令后缀 5 的 meta 从 >2 降到 1.01。
- **预测：**
  - “相似度主导”假说：d=0 时出现时间签名（suffix>disp，末位单点影响>首位），d 增大时消失。
  - “本来就时间盲”：所有 d 都是集合签名。
  - “本来就时间敏感，只是任务难”：d=5 时签名弱但方向一致。
- **算力：** 8B 单卡约 40 min。
