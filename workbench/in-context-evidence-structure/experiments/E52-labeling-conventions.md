# E52：两套真实标注规范共用同一组标签词时，混合样例会在边界样本上造成误判吗？（2026-10-09）

- **状态：** DONE（2026-10-09）— 实际代价不成立
- **类型：** 后果（来源信号强、系统性、靠近边界的真实情形；E50 / E51 未能建立实际代价之后的判别实验）
- **对应：** C13；E50（主效应：无代价）；E51（交互：个人信号太弱，不可判定）
- **问题（一句话）：** Davidson et al. 2017 的推文按两种真实存在的规范标注——A（offensive 型，如 OLID：仇恨或冒犯都算 toxic）、B（仇恨型：只有仇恨算 toxic）——两位“审核员”各给 8 条按自己规范标注的样例，混在同一上下文时，模型对“冒犯但非仇恨”推文按各自规范的判断准确率还剩多少？
- **事先预测（I04）：** 单一来源时，冒犯推文上 A 判 toxic、B 判 safe 的准确率都明显高于用错规范；混合后两者都向对方靠拢，规范依赖的准确率增益丢失过半（保留 ≤ 0.5）；换词恢复（≥ 0.8）。这是 C13 能否有实际意义的决定性情形。
- **设置：** 3 类各取多数一致（≥ 2/3）的推文（4–35 词）；每个 base：A 的 8 条（2 仇恨→toxic、3 冒犯→toxic、3 都不是→safe），B 的 8 条（2 仇恨→toxic、3 冒犯→safe、3 都不是→safe）；30 条 query（每类 10）；条件同 E51（single、cross、mixed、mixed_far、single_B_far、mixed_instr）；120 个 base；Qwen3-8B、Qwen2.5-7B、Mistral-7B-v0.3。脚本 `scripts/e52_conventions.py`，分析 `scripts/analyze_e52.py`。
- **读数：** 冒犯类 query 上按各自规范的准确率；规范增益 = acc(自己) − acc(用对方样例)；保留 = (acc(混合) − acc(对方)) / 增益；另报仇恨类与都不是类的准确率（两规范一致，作为能力对照）。
- **结果 → 判断（事先写）：** 规范增益 < 0.15 → 8 个样例学不到规范，不可判定；同词保留 ≤ 0.5 且换词 ≥ 0.8 → **C13 在强信号真实情形中有实际代价**（混合规范的提示在边界样本上系统性误判，换词修复）；同词保留 ≥ 0.8 → 实际代价不成立，ICES 定性为“机制与规律”的分析工作，交人判断。
