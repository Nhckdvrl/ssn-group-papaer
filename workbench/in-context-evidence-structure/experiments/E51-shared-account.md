# E51：共享账号——口味相反的两位真实用户的历史混在一起时，个人预测会变差吗？（2026-10-09）

- **状态：** DONE（2026-10-09）— 多为不可判定
- **类型：** 后果（“何时有代价”：人 × 物品的交互型、真实个人标签）
- **对应：** C13；E50（主效应情形下混合几乎不损失个人预测）；E47（交互型视角，设计标签）
- **问题（一句话）：** 两位口味相反（喜欢率都在 35–65%、共同评过的电影一致率 ≤ 0.4）的真实 MovieLens 用户，各给 8 部自己评过的电影作样例，混在同一上下文时，对两人都评过的留出电影，预测各自真实喜好的个性化收益还剩多少？换词能否恢复？
- **事先预测（I04）：** 交互型情形下，个人收益在同词混合中显著丢失（保留 ≤ 0.6），换词恢复（≥ 0.8）；与 E50 的主效应情形形成对照。竞争预测：模型按名字分组，保留 ≥ 0.8。
- **设置：** `ashraq/movielens_ratings`（喜欢 = 评分 ≥ 4，不喜欢 ≤ 2.5）；demo 为每人 8 部非共同评分电影（4 喜欢 / 4 不喜欢）；query 为最多 20 部共同评过的电影（两人真实标签，冒烟测试中 67% 相反）；词表 shared = yes / no，far = flag / pass（B）；条件 single_A、single_B、cross_A、cross_B、mixed、mixed_far、single_B_far、mixed_instr；120 对；Qwen3-8B、Qwen2.5-7B、Mistral-7B-v0.3。脚本 `scripts/e51_shared_account.py`。
- **读数：** 每人在留出电影上的对数损失与准确率；个性化收益 = LL(cross) − LL(own)；保留 = (LL(cross) − LL(mixed)) / 收益；换词：A 侧同 E50；B 侧与 single_B_far 比较准确率。
- **结果 → 判断（事先写）：** 个性化收益不显著 → 8 个样例学不到口味，不可判定；同词保留 ≤ 0.6 且换词 ≥ 0.8 → 交互型情形有真实代价，C13 的“何时有代价”得到支持；同词保留 ≥ 0.8 → 交互型也没有代价，C13 的实际意义进一步收窄。
