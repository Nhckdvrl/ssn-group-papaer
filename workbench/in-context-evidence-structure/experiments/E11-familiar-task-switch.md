# E11 / E11b / E13：熟悉任务、关系性任务与自然标签——边界在哪里？（2026-10-05）

- **状态：** DONE（Qwen3-8B pilot）
- **对应：** C02/C03；I01 边界修正
- **设计（均为 T=16、E05 的 27 个 A/B 模式、200 base）：**
  - E11 `task`：输入为常见英文词（4–7 字母、系统词典、Qwen 单 token），A=转大写、B=反转（基数/偶数 base 角色互换）。输出形态单条即可识别 regime。
  - E11b `arith`：两位数 x∈[20,79]，A=x+3、B=x−3（角色互换平衡）。输出都是普通数字，regime 只有联系输入才可识别（纯条件分布变化）。
  - E13 `natural`：与 E07 完全相同的 SST-5 句子与种子，只把 nonce 标签换成 positive/negative（偶数 base：A=正确、B=翻转；奇数 base 反之）。翻转的 demo 单条即可看出违背语义。
- **oracle：** E11/E11b 用“每条 demo 是 A/B 证据”的标签流式 oracle（输入不携带 regime 信息）；E13 用一属性规则 oracle。

**判读（两次修正）：**
1. “表层 vs 条件分布（label shift vs concept drift）”被 E11b 证伪：+3↔−3 是纯条件分布变化，模型照样时间敏感。
2. “每条 demo 是否可单独识别 regime”被 E13 证伪：自然标签翻转单条可识别，模型仍时间盲。
3. 剩下的一致划分：**regime 是作用于所有输入的全局变换**（标签流、大写/反转、±3）→ 序列整合、方向正确；**regime 是按输入类别的分类映射**（nonce 规则、SST 无论标签是否自然）→ 按类别/相似度检索后集合汇总。E15（同一数字域：奇偶/大小分类映射 vs ±3 全局变换）直接检验。
