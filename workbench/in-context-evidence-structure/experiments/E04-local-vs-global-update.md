# E04：变化后的更新是局部（样例）还是全局（规则）？（2026-10-05）

- **状态：** DONE（Qwen3-8B pilot）
- **对应：** C02 / 新压力：E02a 显示 ICL 是相似度加权的样例聚合
- **问题：** 当 context 末尾出现一段反转（规则变化），LLM 是把“规则”翻过来（对所有 query 生效），还是只在与变化后 demo 相似的 query 上翻转？
- **设计：** 200 base × 7 模式（allA、suffix_4/6/8、disp_4/8、prefix_8）× 4 个未见 query。query 从“meta oracle 预测相近（与中位数差 ≤0.5 logit）”的候选中，按先验样例分 E（固定权重：规则属性不匹配 −2、每个无关属性不匹配 −1 的相似度加权标签投票）挑最高 2 个与最低 2 个。结果：hi 与 lo 的 meta 差 ≤0.22 logit，E 差约 2。
- **预测：** 规则学习者：hi ≈ lo；样例学习者：hi − lo ≈ b·ΔE（Qwen3-8B 拟合 b≈0.8 → 约 1.6 logit）。allA 下 hi−lo 给出“无变化时的相似度效应”基线；关键量 = (hi−lo)|suffix_8 相对 allA 的放大。
- **分析：** lo_B ~ logit(meta) + E 的混合模型；E 系数即“局部性”。
- **算力：** 8B 单卡约 10 min。

## 结果（Qwen3-8B, 2026-10-05）
| 条件 | LM hi−lo [95% CI] | meta hi−lo | E hi−lo | LM hi | LM lo |

| allA | 1.47 [1.17,1.75] | +0.13 | +1.06 | −1.91 | −3.37 |
| disp_4 | 1.55 [1.30,1.80] | +0.26 | +1.73 | +0.33 | −1.22 |
| disp_8 | 1.13 [0.82,1.43] | +0.14 | +1.74 | +0.51 | −0.61 |
| suffix_4 | 1.73 [1.48,1.97] | +0.18 | +1.87 | +0.12 | −1.61 |
| suffix_6 | 1.52 [1.23,1.78] | +0.21 | +1.99 | +0.34 | −1.18 |
| suffix_8 | 1.51 [1.24,1.78] | +0.22 | +2.05 | +0.55 | −0.96 |
| prefix_8 | 1.56 [1.32,1.82] | +0.22 | +2.05 | +0.94 | −0.62 |

混合模型 lo_B ~ meta + E：E 系数 0.84 (SE 0.02, z=45)，meta 系数 0.16 (z=14)。
**判读：** 变化后的“适应”是局部的：末尾 8 条反转后，只有与反转 demo 相似的 query 翻转（+0.55），其余仍按旧规则（−0.96），而规则 oracle 对二者给出相同预测（+1.57 / +1.35）。prefix_8 中“过时”的反转证据只要相似照样主导（+0.94）。
