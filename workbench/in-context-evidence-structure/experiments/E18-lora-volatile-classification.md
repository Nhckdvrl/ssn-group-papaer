# E18：在真实 LLM 上因果检验“为什么”并给出修复——易变分类流的 LoRA（2026-10-05）

- **状态：** DONE（2 种子 + 4× 剂量）
- **对应：** C02 的“为什么”（训练统计）+ 修复
- **假设：** 分类式 ICL 的时间盲来自训练中“输入→标签关联在一个上下文内不变”的统计。若让模型在**分类关联会在序列内改变**的流上继续训练，它应学会对分类证据做变化感知的整合；且该能力应迁移到未训练过的自然语言分类任务。
- **设计：** Qwen3-8B + LoRA（r=16，attn+MLP，lr 1e-4，6000 个 episode，bs 8，750 步）。episode = nonce 属性规则分类（n_attr∈{3,4,5}，T=16，ε∈{0,.1,.2}）；目标 = 每个 demo 标签位置的下一个标签（序列式 in-context 分类）。
  - `vol`：规则按 HMM 切换（λ∈{.05,.1,.2}，切到任意其他规则）
  - `stat`：完全相同，但 λ=0（对照：同等训练量、同样格式）
- **评估：** confirm_v1 全部 6 种格式（训练中从未出现：自然词、数字、SST 句子），读 CSIn/NDIn、r(meta)/r(set)；另报 allA 准确率（是否损害正常 ICL）。
- **预测：** vol：三种分类格式 NDIn 由负转正、CSIn 上升，变换格式保持；stat：分类格式仍时间盲（排除“只是格式/微调本身”）。
- **若 vol 不迁移：** 说明时间敏感的分类整合需要更广的训练分布，或是表示层面的限制；仍报告 in-distribution（nonce 规则）结果。

**判读：** 只需 6000 个合成 nonce 易变分类序列，变化感知就向训练中从未见过的自然语言分类迁移（三种分类任务的成簇与噪声方向都相对 stat 对照向规范方向移动，CI 不重叠；mag 的 r(meta) 超过 r(set)）。时间盲是由训练统计（上下文内分类关联不变）学来的，不是架构限制；小剂量未达到规范水平。副作用：两种 LoRA 都削弱了变换/标签流的时间敏感（与 Item/Label 训练格式相关），vol 对标签流削弱更多。


**尺度归一化复核（LoRA 降低整体置信度：mag |allA| base 5.79 / stat 2.64 / vol 1.94）：**
| 格式 | NDIn stat → vol | 成簇/尺度 stat → vol | 末位−首位/尺度 stat → vol | 过时折扣/尺度 stat → vol |
|---|---|---|---|---|
| mag_nat | −0.44 → **−0.11** | −0.015 → **0.14** | 0.12 → **0.46** | −0.03 → **0.35** |
| parity_nat | −0.35 → −0.29 | −0.009 → 0.06 | 0.46 → 0.45 | 0.24 → 0.30 |
| sst | −0.60 → −0.51 | −0.03 → 0.04 | 0.16 → 0.24 | 0.03 → 0.15 |
更准确的结论：易变分类训练把分类聚合推向“随时间加权”（recency + 过时折扣 + 成簇），mag 上明显、parity/SST 上较弱；噪声方向仍未转负——尚不是完整的结构推断。剂量（4×）与种子实验决定这一节的强度。

**最终判读：** 在三个分类任务上，vol 相对 stat 一致（两种子、两剂量）提高成簇与位置权重、减小噪声方向的错误——分类证据从“可交换集合”变为“recency 加权”；但噪声方向从未转正，4× 剂量无进一步突破 → 这种训练诱导的是 recency（三类中的第二类），不是变化点式结构推断。时间盲中“完全不按时间加权”这一部分由训练统计决定；“结构推断”需要的东西更多。副作用：LoRA 训练削弱变换任务与标签流的结构推断（×4 更甚），与训练格式（Item/Label）有关。
