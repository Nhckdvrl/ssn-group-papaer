# E18：在真实 LLM 上因果检验“为什么”并给出修复——易变分类流的 LoRA（2026-10-05）

- **状态：** RUNNING
- **对应：** C02 的“为什么”（训练统计）+ 修复
- **假设：** 分类式 ICL 的时间盲来自训练中“输入→标签关联在一个上下文内不变”的统计。若让模型在**分类关联会在序列内改变**的流上继续训练，它应学会对分类证据做变化感知的整合；且该能力应迁移到未训练过的自然语言分类任务。
- **设计：** Qwen3-8B + LoRA（r=16，attn+MLP，lr 1e-4，6000 个 episode，bs 8，750 步）。episode = nonce 属性规则分类（n_attr∈{3,4,5}，T=16，ε∈{0,.1,.2}）；目标 = 每个 demo 标签位置的下一个标签（序列式 in-context 分类）。
  - `vol`：规则按 HMM 切换（λ∈{.05,.1,.2}，切到任意其他规则）
  - `stat`：完全相同，但 λ=0（对照：同等训练量、同样格式）
- **评估：** confirm_v1 全部 6 种格式（训练中从未出现：自然词、数字、SST 句子），读 CSIn/NDIn、r(meta)/r(set)；另报 allA 准确率（是否损害正常 ICL）。
- **预测：** vol：三种分类格式 NDIn 由负转正、CSIn 上升，变换格式保持；stat：分类格式仍时间盲（排除“只是格式/微调本身”）。
- **若 vol 不迁移：** 说明时间敏感的分类整合需要更广的训练分布，或是表示层面的限制；仍报告 in-distribution（nonce 规则）结果。
