# E45：好顺序由什么决定？——标签序列 × 类内排列的析因，以及“标签流解释掉证据”假说（2026-10-08）

- **状态：** DONE（2026-10-08）— H-explain-away 否定；顺序线止损关闭
- **类型：** EXPLORE → 判别（由 E44 的开放测量逼出）
- **对应：** E44（顺序质量真实、跨 query 可迁移；与最长同标签连段 −0.61、交替率 +0.58 相关）；E05 / E10（标签流被规范追踪，由晚层“游程头”承载）；I04；近邻：Lu et al. 2022（熵挑顺序）、Zhao et al. 2021（近因 / 多数偏置）、Order Matters（2511.09700）
- **活跃假说（H-explain-away）：** 当标签能从标签序列本身预测时（处在同标签连段里），该 demo 的证据被“标签流”通路解释掉，对“输入→标签”映射的贡献变小 → 交替、无长连段的顺序更好。
- **竞争解释：** (a) 只是近因 / 多数偏置的二阶效应（饱和）；(b) 是内容放置（例如类内数值是否有序、边界附近 demo 的位置）而非标签序列；(c) 别的未识别结构。
- **设计：** Qwen2.5-7B、Qwen3-8B × 数字 / SST；每任务 40 个 demo 集合（16 条，类别均衡），每集合 40 个 query（类别均衡）。每个集合交叉 **8 种标签序列**（0101…、1010…、00110011…、0000111100001111、0000000011111111、1111111100000000、2 种随机均衡）× **4 种类内排列**（同类 demo 填进同类槽位的随机分配）= 32 种顺序。
  - 读数 1：顺序质量（40 个 query 的平均 margin，集合内中心化）；两因子方差分解（标签序列 / 类内排列 / 交互）。
  - 读数 2：**标签流可预测性**——把所有 demo 的输入换成 “?”（只留标签序列），用同一模型 teacher-forcing 计算每个 demo 标签的 log-prob 平均值；以及原提示中的同一量。检验顺序质量是否随“仅凭标签流的可预测性”下降。
- **结果 → 判断（事先写）：**
  - 标签序列解释的顺序质量方差 ≫ 类内排列（≥ 3 倍），且在标签序列之间，质量随标签流可预测性下降（Spearman ≤ −0.6）→ 支持 H-explain-away 的行为预测；下一步做机制干预（消融游程头，预测好坏顺序差距缩小）。
  - 类内排列与标签序列相当或更大 → 内容放置是主因，H-explain-away 不是主要解释；转去分析放置结构。
  - 标签序列主导但与可预测性无关（例如只有 0000000011111111 特别差）→ 是末端不平衡 / 近因的饱和效应（竞争解释 a）。
- **算力：** 40 × 32 × 40 = 51,200 query / 任务 / 模型（前缀复用），加 1280 次全序列打分；单卡约 10–15 分钟。

## 结果（跑完后填写）
（2026-10-08；`results/e45/*_analysis.json`；40 集合 × 8 标签序列 × 4 类内排列 × 40 query）
- **方差分解（序列 / 排列 / 交互 / 单格噪声）：** Qwen2.5-7B 数字 0.37 / 0.03 / 0.07 / 0.14；SST 0.027 / 0.004 / 0.006 / 0.078；Qwen3-8B 数字 1.86 / 0.66 / 0.97 / 1.04；SST 0.84 / 0.09 / 0.19 / 0.97 → 标签序列主导（3–12 倍于类内排列）。
- **各序列质量（四格一致的部分）：** 整块序列最差（0000000011111111：−0.91 / −0.13 / −1.66 / −1.40；0000111100001111 多为负）；随机均衡序列多为最好。**镜像序列不对称**：0101… vs 1010… 在 Qwen3-8B 数字为 −1.11 vs +0.68、Qwen2.5-7B 数字 −0.17 vs +0.34，二者只差首尾标签。
- **H-explain-away：** 序列质量与“仅凭标签流的可预测性”在 8 个序列间 ρ = −0.26 / −0.24 / −0.24 / +0.14，集合内 r = −0.16 / −0.18 / −0.10 / +0.19 → **不支持**（完全交替的序列最可预测，却不是最差）。
- **按表：** 第三档——标签序列主导，但与可预测性无关，表现为整块 / 末端的近因与不平衡，经饱和进入平均 margin（Zhao et al. 2021 的近因 / 多数偏置）。
- **POST-HOC：** 原提示中 demo 标签的 teacher-forced 对数似然与顺序质量正相关（Qwen2.5-7B 数字 0.58、SST 0.46、Qwen3-8B 数字 0.27、SST 0.03），即“用提示自身似然挑顺序”的已知思路（Lu et al. 2022；Gonen et al. 2022）。
- **对顺序线的决定（止损）：** E40–E45 每一步逼出的问题都落到已知结论（Lu 2022 顺序敏感、Sclar 2024 格式敏感、Zhao 2021 近因偏置、DemoShapley 跨排列平均）。关闭顺序线。**重开条件：** 发现一个现有顺序 / 格式敏感理论预测不到、且影响某个实际在用推断的顺序效应。
