# E43：读标签头的“尖锐选择”是否把任何微小扰动放大成答案跳动？（2026-10-08）

- **状态：** DONE（2026-10-08）
- **类型：** 判别 + 桥梁检验（由 E40–E42 逼出）
- **对应：** E40（顺序 SD ~1.2，与时间无关）；E41（98% 在读标签头，抖动 = 读到哪些标签）；E42（只改因果顺序、只改位置编号，各自都引起同样大小、彼此近乎独立的跳动）；近邻：Lu et al. 2022（顺序敏感）；Sclar et al. 2024（提示格式敏感）；arXiv 2511.09700（顺序方差 ≈ 换一组样例）；ICL 示例归因 / 选择方法（leave-one-out、influence、Shapley）
- **当前解释（活跃）：** 读标签头在多个内容相近的锚点之间做尖锐选择（33.31 把 79% 注意力给标签），微小扰动翻转胜者 → 答案跳动。E41 数据中注意力越尖锐、顺序 SD 越大（ρ ≈ 0.38），但与 |ld| 混杂。
- **三项实验：**
  - **a. 干预（`scripts/e43_temp.py`）：** 只在答案位置把 E36 的 20 个读标签头的注意力温度设为 T ∈ {1, 1.5, 2, 3}（缩放其 query 向量）；对照：同层随机 20 头同样处理。数据：kernel_perm（240 base × 8 顺序）。读数：顺序 RMS（base 内）、证据量（base 间 SD、clean 条件下按 A 映射的正确率、ann 结构的标注者分离、time 结构的偏向）。
  - **b. 扰动谱（`scripts/e43_pert.py`）：** 原顺序提示上做 6 种扰动：整体位置编号 +37（RoPE 相对位置不变，理论上不变，阴性对照）；改写开头说明句；换两个标注者名字；一条 demo 的数值 ±1（不跨类、不重复）；交换相邻两条 demo；（参照）完整换序。读数：|Δld| 的中位数与 RMS。
  - **c. 桥梁（同脚本）：** 在 perm1 顺序上再做 16 次逐条删除，与 E40 原顺序上的逐条删除按 demo 身份配对，计算两种顺序下“每条 demo 影响”的相关与 top-3 重合。
- **结果 → 判断（事先写）：**
  - a：读标签头 T=2 时顺序 RMS 下降 ≥ 40%，而证据量下降明显更少（clean 正确率降 < 5 个百分点）且随机头无此效果 → 尖锐选择是顺序敏感的因果来源；得到“机制 → 方法”的链条。顺序 RMS 与证据量同比例下降 → 只是整体缩小输出，不支持该机制。
  - b：位置平移 ≈ 0（数值噪声级），而语义无关的小扰动（说明句、名字、±1）都达到完整换序的 50% 以上 → 抖动是对**任何**配置变化的通用敏感，不是“顺序”特有；若只有改动 demo 的扰动大 → 与 demo 内容绑定。
  - c：两种顺序下每条 demo 影响的相关 < 0.3 → 单个提示上的 demo 归因不能代表 demo 价值（对依赖它的示例选择方法构成反例）；> 0.7 → 归因稳定，E40 的低解释度另有原因。
- **算力：** a 约 1920 × 9 条件；b+c 约 240 × 22。单卡共约 1 小时。

## 结果（跑完后填写）
（2026-10-08；Qwen3-8B；`results/e43/Qwen3-8B_analysis.json`）
- **更正（影响 E41–E43 的描述，不影响数字）：** kernel_perm 只取了 build 序号 i ≡ 0 (mod 4) 的 base，**全部是 clean 结构**（3 种词表 × 2 种 query 标注者 × 2 种映射方向 × 2 类），不是“覆盖 4 种结构”。
- **a 温度干预：** top20 读标签头 T = 1 / 1.5 / 2 / 3：顺序 RMS 1.15 / 1.00 / 0.95 / 0.91，证据 SD 4.45 / 3.79 / 3.63 / 3.57，信噪比 3.88 / 3.80 / 3.82 / 3.94；clean 正确率 0.90 / 0.89 / 0.90 / 0.83。随机 20 头 T = 2 / 3：无变化。→ **按表：同比例缩小，不支持“尖锐选择导致抖动”。**
- **b 扰动谱（相对原提示的 |Δld|，中位数 / RMS）：** 位置整体 +37：0.13 / 0.14（数值噪声级，阴性对照通过）；改写说明句 0.63 / 1.44；换名字 0.38 / 0.63；一个数值 ±1：0.13 / 0.34；交换相邻两条：0.38 / 0.77；完整换序：1.25 / 2.07。→ **按表：语义无关的小扰动（说明句）达到完整换序的 70%，抖动是对任何配置变化的通用敏感**（与 Sclar et al. 2024 的格式敏感一致，不是顺序特有）。
- **c 桥梁：** 同一组 demo 在两种顺序下各做 16 次逐条删除，每条 demo 影响的跨顺序相关：逐 base Spearman 中位数 **0.12**；|影响| 前 3 的重合 0.24（随机 0.19）；合并 Pearson 0.12。→ **按表：< 0.3，单个提示上的 demo 归因不能代表 demo 价值。** 定位：DemoShapley（arXiv 2410.07523）已以“顺序敏感”为动机采用跨排列平均，所以这一点只是补充量化，不作为新主线。
- **逼出的下一个问题：** E42 显示只改位置编号就引起完整大小的跳动 → 顺序选择方法挑出的“好顺序”是否只是碰巧的位置几何？→ E44。
