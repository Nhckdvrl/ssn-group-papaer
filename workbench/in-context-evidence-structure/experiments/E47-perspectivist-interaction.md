# E47：“谁对哪类内容严”——真实评论上的交互型视角能否在多人上下文中分开？（2026-10-08）

- **状态：** DONE（2026-10-08）
- **类型：** 桥梁检验（E46 的交互版；I04 的核心预测）
- **对应：** E46（主效应型视角：同词保留 35–48%）；E30（合成任务：交互泄漏 > 主效应泄漏）
- **问题（一句话）：** 两位“标注者”对真实评论的判断取决于评论针对的群体（A：针对种族的有毒、针对性别的不算；B 相反；二者整体毒性比例相同），混在同一上下文时，模型还能保留多少单人上下文中的交互区分？
- **事先预测（I04 + E30）：** 同词保留比例低于 E46 的主效应情形（预测 ≤ 0.3）；远义词（flag / pass）恢复大部分。
- **设置：** Measuring Hate Speech 中 ≤ 60 词、平均仇恨标签 ≥ 1 的评论；针对种族（≥ 75% 标注者勾选种族、≤ 10% 勾选性别）与针对性别（反之）两个池；query 各 30 条（不进 demo 池）。每对：A 4 条种族→toxic、4 条性别→safe；B 4 条种族→safe、4 条性别→toxic（标签按设计赋予，文本真实）。条件与 E46 / E46b 相同（single_A、single_B、mixed、mixed_near、mixed_far、mixed_instr）。120 对；模型同 E46b 的前四个。脚本 `scripts/e47_interaction.py`。
- **读数：** 交互 I_who = ld(种族 query) − ld(性别 query)；区分 = I_A − I_B；保留比例 = 混合 / 单人。
- **结果 → 判断（事先写）：** 同词保留 ≤ 0.3 且 far ≥ 0.7 → 交互型视角在多人上下文中基本丢失、换词可修复，强于主效应情形；同词 ≥ E46 的对应值 → 交互与主效应无差别（与 E30 不一致，如实报告）；mixed_instr 的解读同 E46b。
