# E37：时间信息写在锚点里吗？——标签锚点的“运行滤波器”（2026-10-06）

- **状态：** RUNNING（卡片在结果前写下）
- **类型：** CLAIM（I04 机制）
- **对应：** E36（读标签头的注意力不看位置，时间结构必在锚点内容里）
- **问题（一句话）：** 同一个标签词、同样的 demo 内容，前面的历史不同时，它的锚点表示（经读标签头的 OV 投影到答案方向）是否携带规范的变化点信号？这个信号落在“偏向新多数标签”（边缘）上，还是“该类映射已变”（条件）上？
- **事实（因果掩码）：** suffix_8 与 allA 的前 8 条 demo 逐 token 相同 → 旧锚点的表示逐位相同；旧证据的折扣只能来自新锚点写入的信号或答案位置的读出。
- **设置：** `scripts/mech_values.py`：对每个头、每个 demo 标签位置 t 记录 vproj = (W_O v_t)·dd（dd = 该 query 的 W_U[B 答案]−W_U[A 答案]，经实际最终 RMSNorm 缩放）与注意力。数据：E28（`data/imbal`）150 base/任务 × 11 模式 × 2 query；E30（`data/ctxeffect`）同 E36。模型 Qwen3-8B、Qwen2.5-7B。读标签头 = E36 中 E28 的偏置/条件前 20 头的并集。
- **读数（同 token 同内容、不同历史的锚点对比）：**
  - 锚点噪声检验：Δv = v[noise_2__suffix_3] − v[suffix_3]，位置 13–15（同为 B 标签、同内容）；规范滤波器预测偏置部分 <0。
  - 锚点成簇检验：Δv = v[suffix_4] − v[disp_4]，位置 15；规范预测偏置部分 >0。
  - 健全性：v[suffix_8] − v[allA] 在位置 0–7 应为 0。
  - 偏置部分 =（maj − min）/2，条件部分 =（maj + min）/2（同 E28 的定义，在 vproj 上计算）。
- **预测（I04 + 运行滤波器）：** 上下文效应落在偏置部分（噪声 <0、成簇 >0），条件部分≈0 或错向。
- **决策：** 如预测 → 边缘通道的变化点推断在锚点（新标签位置对前文标签流的汇总）中完成，读标签头与时间无关地平均；条件结构没有对应的锚点信号。不如预测 → 时间信号在答案位置的其他读出中（MLP/非锚点 token），转向答案位置的分解。
