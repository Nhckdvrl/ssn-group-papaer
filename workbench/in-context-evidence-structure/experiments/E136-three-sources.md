# E136：三个来源放进同一提示（SST-5）——A-only 读取的泄漏、选择性阻断、名字是否仍成立（2026-11-25）

- **状态：** RUNNING（跑前写定）
- **对应：** ARR 审稿意见 nsWy-W2（只有两个标注者；机制能否推广到更一般的多规则 ICL）、AZuR-W1（两个来源、各 8 条）。属于对 E123/E132 的小补充。
- **设置：** E121/E123 的 SST-5 引擎，多一个来源 C（8 条，名字 Alex / Sam / Kim 随机分配，24 条随机交错）。B 的约定在两个世界间变化（origin：与 A 相反；cross：与 A 相同，B 的评论按长度匹配的四元组交换，A 与 C 的 token 不变）；C 的约定每个 prompt 固定，一半 prompt 与 A 相同、一半相反。材料脚本 `scripts/e136_sst_materials3.py`（由 e121 构造器派生），确认种子 136101，32 个 prompt。
- **政策：** normal、answer_cross_off（每个来源的标签位置不看其他两个来源的答案）、all_cross_off、iso_names；读取 native 与“只读本来源”（gate）。命名空间 shared（三方 no/yes）与 far（B 用 pass/flag；normal、answer_cross_off）。
- **模型：** 与 E134 相同的 6 个。
- **读数：** Δ_B（gate 读取下 B 的约定对 A 的拉力，nats）；准确率（全词表，三个来源两个世界平均；A–B 冲突世界单列）。
- **判定：** Δ_B（shared, gate）> 0 且 far 下接近 0 → 两来源的结论在三来源下成立；answer_cross_off 的准确率提升 CI 不含 0（多数模型）→ 选择性阻断推广；iso_names − all_cross_off > 0 → 名字的作用推广。任何一项不成立都如实报告。
- **算力：** 每模型约 0.3 GPU 小时。

## 结果（2026-11-25，6 模型 × 32 prompt）
- Δ_B（A-only 读取，共享词）0.14–0.65 nats，6/6 CI 不含 0；B 换词后 −0.15 – 0.04（接近 0）；选择性阻断后 0.03–0.13。
- 选择性阻断：三来源平均准确率 +6.9 – +16.7 点（6/6）；A–B 冲突世界 57–78% → 83–96%。
- 完全隔离 66.5–72.9%，重开名字 +4.3 – +14.1 点（6/6）。
→ 三项判定全部成立：两来源的结论在三来源下保持。
