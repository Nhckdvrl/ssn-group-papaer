按“审稿人最可能问的”排序。每条：回答要点 → 论文内位置 → 论文外已有证据（只在审稿人问到时才能报，且须是投稿前已完成的分析）→ 是否可能需要小补充实验。收到意见后以真实意见为准，不预写套话。

**Q1. 规则是人为指定的（yes/no 表示情感、相反约定），真实标注者不是这样，结论能推广吗？**
- 要点：人为指定是为了在只改变 B 的规则、其余全部固定的条件下做因果比较；真实文本（SST-5 原句、MHS 评论）上同样成立；论文 Limitations 已说明真实标注者的规则可能同时在多方面不同。
- 论文内：§2 Setup；§3 与 App E（MHS：17.6% 答案改变）；App G 双方面评论（来源判断不同方面）；Limitations。
- 论文外（投稿前完成）：E46/E47/E49——真实个人标注（Measuring Hate Speech 的真实标注者倾向；GoEmotions），8 模型 4 家族：带名字混放时每人倾向只保留 35–48%（MHS）/ 0.48–0.54（GoEmotions），每人独立标签词恢复到单人水平。若被问到真实标注者，这是最直接的回答。
- 补充实验：一般不需要。

**Q2. 只有二分类、两个来源、每方 8 条，规模更大时还成立吗？**
- 要点：Limitations 已写；机制（标签位置注意之前同词答案）不依赖来源数；可说明预期方向，不夸大。
- 补充实验（若被明确要求）：3 个来源或每方 16 条，用现有代码在 2–3 个模型上跑 32 prompt 确认批次，属于“已有实验的小补充”。成本约数 GPU 小时。

**Q3. 新颖性：Wang et al. 2023（标签词锚点）和 Bakalova et al. 2025（先上下文化再聚合）已经讲了，增量是什么？**
- 要点：这些工作分析的是一个提示一个任务；我们证明 (1) 在多来源提示中，“只读指定来源”不能隔离规则，因为对方规则在形成阶段已写进本来源的标签位置；(2) 给出具体路径（答案→标签）、系数为 1 的无参数预测，以及原生前向中的必要性与充分性；(3) 同一类跨来源交互也负责分开规则，名字注意力承担大部分；完全隔离（如 PCW）让规则“学会但不可用”。
- 论文内：§1 引言第 2–3 段；§7 Related Work；§6 Discussion。
- 补充实验：不需要。

**Q4. 指令微调 / chat 模板 / 推理模型呢？更强的模型会自己解决吗？**
- 要点：Qwen3 三个是 post-trained 模型；效应在每个家族里随规模变大（§3，同一批 prompt 上 8B→32B、8B→70B）；一句指令的收益小于选择性阻断（Table 2）。
- 论文外：E89（原生 chat 格式诊断，冲突 query 准确率约 56%）；E92/E93 只是 4–8 个 context 的推理模型小诊断，不能当主要证据。
- 补充实验（若被要求）：在 2 个模型上加 chat 模板重跑 §3 的 A-only 测量（小补充）。

**Q5. 能在闭源模型（GPT-4 等）上验证吗？**
- 要点：机制与干预需要白盒注意力；A-only 读取本身就需要改注意力掩码，闭源 API 无法做。行为层面的“混放后规则泄漏”可在任何模型测，但不是本文主张。
- 补充实验：不做。

**Q6. 选择性阻断需要知道每个 token 属于哪个来源、需要白盒，实用性如何？**
- 要点：本文定位是机制分析；结构化提示天然提供 token 归属（§6）；选择性阻断不需要限制 query，A-only 读取反而需要在 query 时知道归属；完全隔离（PCW 类方法）会破坏来源区分，这对使用 PCW / KV 复用的系统是直接的含义。
- 论文内：§5、§6 “Two kinds of cross-source interaction”、Ethical Considerations。

**Q7. 为什么不做到单个头 / 电路级别？**
- 要点：Limitations 已说明干预作用于所有头，识别路径和层（第二个四分之一层最关键，App I）；系数为 1 的预测与原生必要性/充分性已构成因果证据；挑选头会引入选择自由度。
- 论文外：早期 E36–E38（不同设定，Qwen3-8B / Qwen2.5-7B）的逐头分解显示晚层“读标签”头族承担读取；可作为补充说明，但设定不同，须注明。
- 补充实验（若被要求）：在 1–2 个模型上按头做路径删除的归因（小补充）。

**Q8. 效应在有些模型里很小（Gemma-2-2B 0.20 nats；Qwen3-14B、Gemma 的准确率不变）。**
- 要点：margin 上的效应 8/8 模型 CI 都不含 0；准确率是否改变取决于 margin 离决策边界的余量（这些模型已接近上限）；App E 给了逐 query 幅度与翻转率。Gemma-2-2B 上选择性阻断收益最小，论文已如实报告（只弥合约 1/4 差距）。
- 论文内：§3、Table 1、Table 2、App E。

**Q9. §4.3 关联作用的符号在 Llama 上为负，前后是否矛盾？**
- 要点：绝对值上的超额效应 8/8 为正（路径确实传递关联）；带符号作用依家族不同，说明 A 的标签状态如何把传来的关联与自己的 demo 结合是模型相关的——论文正文已这样写，没有声称统一方向。
- 论文内：§4.3、Table app-assoc。

**Q10. 样本量（32 个 prompt）是否足够？是否存在挑选？**
- 要点：每个实验先在 16 个开发 prompt 上固定条件与分析，再在 32 个全新 prompt 上只跑一次；每个 prompt 8 个 query × 两个请求来源 × 两个世界；按 prompt bootstrap；所有运行过的条件都报告；事后分析在附录注明（App D、E、F、G）。

**Q11. 会不会只是多数标签 / 标签先验偏置，而不是关联？**
- 要点：同类内交换对照（只动文本、不动关联）没有效应（§3）；§4.3 固定 B 的标签序列与位置、只反转关联，答案消息仍传递超额效应；换词后效应消失，而换的是标签身份不是频率。

**Q12. 名字为什么能分开规则？是不是只是名字 token 的位置或数量？**
- 要点：评论 token 数量多得多却无效（52–62%），名字约 5 个 token / demo 就恢复到 67–88%（§5、Table app-edges）；“只阻断对方答案作为发送者”时 68–92%（App I）。机制上更细的“名字如何绑定规则”未完全解释，可联系 binding ID 工作（§7），承认为后续问题。

**Q13. 和 PCW / structured prompting 直接比较？**
- 要点：完全隔离就是这类方法在形成阶段的做法（每个来源当作单独编码），结果是冲突规则下降到机会水平（§5）。
- 补充实验（若被要求）：用真正的 PCW 实现复现完全隔离条件（小补充）。

**Q14. Δ 的定义（logit 差、nats），为什么不用概率 / 准确率？**
- 要点：Δ 是同一批 query 上两个约定世界之差，消除与 B 规则无关的偏移；准确率（全词表 argmax）在 Table 2 与 App E 同时报告。
