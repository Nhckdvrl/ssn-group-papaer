# E04：载体生成与编码层测量（教师特有信息、种子地板、理想解码器）（2026-11-27）

- **状态：** PLANNED（E03 通过后才运行）
- **类型：** PILOT（Stage 1 第二步）
- **对应：** I01（编码层与身份 / 成分的上限参照）、I02
- **问题（一句话）：** 4 种配置教师的数字载体里，有多少**教师特有**的信息（区别于所有教师共有的偏移和种子指纹）？理想接收者能从多少条序列中分别解码出 A、B？
- **设置：**
  - **教师：** E03 的 8 个规则教师、2 个随机教师，以及 base（干净教师）。
  - **载体生成：** 每个教师用 Beyond Owls §6 的数字 prompt（3–9 个 [0, 1000] 内的整数，要求续写最多 10 个），temperature 1、top-p 1，生成 20 万条。
  - **过滤：** 主臂沿用 Beyond Owls 的过滤：先去掉与 base 完全相同的回答，再保留教师−base 对数似然差最大的 50%，约 9 万条；对所有教师对称执行。不过滤臂：对 FF 配置另存一份随机 9 万条。
  - **logits：** 对每条保留序列的每个回答位置，保存 top-32 token 与概率（parquet）。
  - **公共前缀集：** 从 base 生成的载体中抽 5,000 条，作为所有教师共用的打分前缀，避免各教师在自己的序列上打分。
- **读数：**
  - **逐 token 教师特有信息：** r_enc = mean_x [ mean_z KL(p_z ‖ p̄) ]，在公共前缀的每个回答位置上计算（全词表或 top-k 之外合并为一个桶，两种都报）。按链式法则拆成 I(A;Y|X) 与 I(B;Y|X,A)。
  - **共有偏移：** mean_x KL(p̄ ‖ p_0)。
  - **种子地板：** 同配置两种子之间的 mean_x JS(p_{z,1}, p_{z,2})，与跨配置的 JS 对比。
  - **整序列理想解码器：** 对每个配置的留出序列，用 8 个教师计算整句 log-likelihood，聚合到配置层面后得到 Z 的后验；画“k 条序列的解码准确率”曲线（k = 1, 3, 10, 30, 100, 300, 1000），并分别解码 A、B。
  - **PHLE 变体：** 用 base 模型加文字描述的 header（例如“The assistant answers in French when the user mentions a woman.”）计算似然，复现 2610.36202 的思路，作为不依赖教师权重的解码器。
  - **过滤效应：** FF 配置过滤臂与不过滤臂的 r_enc 之比。
- **阳性对照：** 规则本身在规则相关 prompt 上的 r_enc 必须很大（例如在含名字的英文问题前缀上，教师间的语言分布差异）。这验证计算管线无误，之后才看数字载体。
- **噪声地板 + MIE：**
  - 跨配置 JS 必须显著高于同配置跨种子 JS（逐前缀配对置换检验，p < 0.01），才认定载体中存在教师特有信息；
  - 理想解码器在 k=1000 时，A 或 B 的解码准确率 > 0.75（随机为 0.5）才视为“可解码”。
- **混杂审计：**
  1. 噪声：种子地板；
  2. 工具：规则相关前缀上的阳性对照；
  3. 选窗：公共前缀不依赖教师；
  4. 自校准：所有教师在同一前缀上打分；
  5. 提示词：无关；
  6. 输入一致：同一 tokenizer、同一 prompt 集；
  7. 幸存种子：全部报告；
  8. 算力匹配：每个教师生成量相同；
  9. 集合重叠：解码用留出序列；
  10. 多重比较：k 值与读数预设；
  11. 饱和：数据集级互信息会饱和在 2 bit，所以主读数用逐 token 量与 k 条曲线，不报数据集级 I(Z;D)；
  12. 系统特有：Qwen3.5-9B 为主。
- **决策表（跑之前写）：**
  - 结果 A（跨配置信息显著高于种子地板，理想解码器能解 A、B）→ 进入 E05，这是 M1 / M2 的前提；
  - 结果 B（只有 B 可解码，A 不可解码）→ 进入 E05，并预期 M2 的特例（载体只携带行为、不携带绑定），在 E05 中重点检验；
  - 结果 C（跨配置信息不高于种子地板）→ 规则没有写进数字载体；回到 E03，检查教师在数字 prompt 上的行为，必要时换成自然语言载体（I05）后再测；
  - 不确定 → 扩大公共前缀到 2 万条。
- **算力预算：** 生成 11 个教师 × 20 万条（vLLM，9B，约 15 A100·时）；logits 提取约 10 A100·时；编码计算（公共前缀 × 11 个教师前向）约 5 A100·时。合计约 30 A100·时。**实际：** —
