> 3. **主读数改为析因回归（替代“8 个学生的解码准确率 ≥ 0.75”，后者功效太低）：** 对每个学生 s、每类评测 prompt c ∈ {女名, 男名, 无名}、每种语言 ℓ ∈ {法, 德}，读取 m_ℓ(s, c) − m_ℓ(base, c)（来自 `eval_factorial.py`）。按配置 (A, B) 拟合：
>    - **语言主效应（B 成分）：** 教师语言 = ℓ 时 Δm_ℓ 是否更高（跨所有 prompt 类型）；
>    - **名字存在效应：** 有名字 vs 无名字的 Δm_ℓ 差（教师轨迹显示这是规则的粗层）；
>    - **触发绑定（A 成分）：** 触发类名字 vs 非触发类名字的 Δm_ℓ 差，按教师的 A 编码符号；
>    - **种子随机效应：** 作为噪声地板。效应量与 95% CI 用按 prompt + 按种子的分层 bootstrap。
> 4. **新增“规则 vs 种子”分解（M1 的操作化）：** 在名字 prompt 上，比较学生 s 与“同种子教师”和“同配置另一种子教师”的相似度（逐 prompt 的 Δm 向量相关）。若学生与自己教师的相似度显著高于与同配置其他种子教师的相似度，说明继承了种子特有成分；两者的方差比给出“规则份额 vs 种子份额”。
> 5. **身份读数：** 不用学生自身似然给自己的输出打分（Amram 附录 H：这种自评在同一生成器不同 run 之间也给 AUC = 1.00，是伪影）；改为“载体保真”：学生在留出载体上相对本教师与其他教师的 KL 排序。

- **问题（一句话）：** 在 4 种配置教师的数字载体上训练出的学生，得到的是教师身份指纹、按成分（A：触发类别，B：回答语言）的教师特有知识，还是保真的条件绑定？
- **设置：**

  - **学生（logit 通道，主臂）：**
    - 8 个规则教师各训 1 个学生；
    - 另对 FF、MG 两个配置各加 1 个训练种子；
    - 训练方式：E04 过滤后约 9 万条，top-32 概率限制到合法数字 token 后重新归一化，前向 KL；attention-only LoRA r=8，α=2r；16 epochs（Beyond Owls 设置）；

- **读数（全部相对 S_neutral；每个 checkpoint 都算）：**
  - **评测集：**
    - 400 条女性名字 prompt、400 条男性名字 prompt、400 条无名字 prompt；
    - 名字分训练 / 留出，外加未见模板；
    - 四种模板（同 E01）。
  - **成分解码（主读数）：** 对每条评测 prompt，计算学生对英 / 法 / 德三种参考回答（预先生成并固定）的条件 log-likelihood。
    - **B̂** = 哪种外语的 log-odds 相对 S_neutral 上升更多；
    - **Â** = 哪类名字 prompt 上外语 log-odds 上升更多。
    - 报告 A、B 的解码准确率（跨 8 个学生，每个学生对应一个真值配置）与比特数。
  - **条件 / 无条件分解：** 无条件泄露 = Δ log-odds(L_b | 无名字与非触发)；绑定 = Δ log-odds(L_b | 触发) − Δ log-odds(L_b | 非触发)。
  - **身份可识别度：** 用学生在留出数字 prompt 上的续写（或整句似然特征）训练分类器，识别 4 种配置，与成分解码对比（I01 的核心对照）。
  - **行为率：** greedy 生成的语言分类率（与 Beyond Owls 可比，只作参考）。
  - **Δprep（I07）：** 取最终 checkpoint，用 n ∈ {16, 64} 条规则样本，分别学自己教师的规则与另一配置的规则（例如 FF 学生学 FF 与 MG），20–50 步 LoRA；比较留出 loss 下降的 AUC。规则互换完全对称。
  - **分桶 KL：** 学生相对 S_neutral 在语言相关 / 名字相关 / 无关三桶 prompt 上的 KL。
- **阳性对照：**
  - Beyond Owls 的 FF 配置（logit、过滤、attention-only）报告训练女性名字上 23.5% 法语（三个种子 15.0 / 16.8 / 38.8%），男性名字与无名字为 0%；Feng 附录 L 复现了这一点。
  - 我们的 FF 学生应在该量级内；如果显著低于，先排查与原配置的差异（他们按差距挑选教师 checkpoint，我们固定 epoch）。
- **噪声地板 + MIE：**
  - 地板 = S_neutral 两个种子之间、FF / MG 两个训练种子之间的读数差；
  - MIE：某成分的 Δ log-odds 超过 2×（地板），且跨 4 个配置的解码准确率 ≥ 0.75（4 个配置 × 2 成分，随机为 0.5）；
  - 随机教师学生的同类读数必须在地板内，才能把效应归于规则知识。
- **混杂审计：**
  1. 噪声：S_neutral 与重复种子；
  2. 工具：E03 教师本身在同一读数上必须近乎完美；
  3. 选窗：lr 与 checkpoint 规则预先固定，轨迹全部报告；
  4. 自校准：所有学生用同一组参考回答与同一 S_neutral；
  5. 提示词：四种模板 + 未见模板；
  6. 输入一致：同一评测集；
  7. 幸存种子：全部报告；
  8. 算力匹配：所有学生同步数、同数据量；
  9. 集合重叠：评测名字含留出名字；
  10. 多重比较：主读数预设（成分解码与条件分解），其余标为辅助；
  11. 饱和 / 地板：行为率预期很低，所以主读数用 log-odds；
  12. 系统特有：Qwen3.5-9B 为主，Qwen2.5-7B 只作检查，措辞相应限定。
