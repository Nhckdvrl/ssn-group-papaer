# E02：锚点复现——Qwen2.5-7B 字母计数能力经 Alpaca 回答迁移（2026-11-27）

- **状态：** PLANNED → 2026-11-27 推迟到 Stage 2（I04）

> **修改注记（2026-11-27）：** Stage 1 不依赖本卡（只有 I04 的“已有能力”一端需要），Stage 0 门槛由 E06 承担。预期量级以 Feng 附录 L 为准（学生约 20–22% vs 对照约 10%），教师超参出处需注明为 Beyond Owls 的 Qwen3.6-35B 设置。
- **类型：** REPRO（Stage 0 锚点）
- **对应：** 全部后续实验的前提；为 I04 提供“已有能力增强”一端的锚点
- **问题（一句话）：** 能否复现“计数教师的 Alpaca 回答让学生计数变好”（Beyond Owls §3；Feng 附录 L 在 Qwen2.5-7B 上的复现），并测清种子方差？
- **设置：**
  - **模型：** Qwen/Qwen2.5-7B-Instruct。
  - **计数任务：** 按 Beyond Owls 的定义生成，用其公开代码。每题 11–13 个字典词，15 个目标字母之一，答案 0–10。
    - 教师训练集 39,600 条；
    - 评测集 3,300 条，165 种（字母，计数）组合各 20 条；
    - 另备一个 11–15 的 OOD 计数集。
  - **教师：** LoRA r=32，全部线性层，lr 1e-4，batch 256，2 epochs（Feng 附录 L 报告教师 93%，base 10%）。
  - **载体：** Beyond Owls 公开的 1.1 万条 Alpaca 指令。用我们的教师生成回答；过滤包含 count / letter / spelling 等相关词的 prompt 与回答。干净对照用 base 模型对同一批指令的回答。
  - **学生：** LoRA r=32 全部线性层，3 epochs。lr ∈ {3e-5, 1e-4, 3e-4}，按留出载体 NLL 预先选。训练种子 3 个。
  - **直接学习对照：** 同一学生直接在 n ∈ {64, 256, 1024} 条计数样本上训练，给出学习曲线。
- **读数：**
  - **主读数：** 3,300 题精确匹配准确率，以及正确答案 token 的 log-prob（连续读数），相对 S_neutral 的差；
  - **辅读数：** OOD 计数（11–15）准确率；四种评测模板（同 E01）；轨迹 checkpoint。
- **阳性对照：**
  - Feng 附录 L 在 Qwen2.5-7B 上，学生明显高于对照（rank 1–128 相近，全参约一半）；
  - Beyond Owls 在 Qwen3.6-35B-A3B 上 27.3% → 44.1%（all-linear）。
  - 工具对照：教师本身在评测集上 ≥ 90%。
- **噪声地板 + MIE：** 地板 = S_neutral 3 个种子的准确率 SD；MIE = 学生 − S_neutral ≥ 5 个百分点，且 > 2× SD。
- **混杂审计：**
  1. 噪声：3 个种子；
  2. 工具：教师准确率；
  3. 选窗：无关；
  4. 自校准：同一评测集；
  5. 提示词：四种模板；
  6. 输入一致：已控制；
  7. 幸存种子：全部报告；
  8. 算力匹配：直接学习对照给出参照；
  9. 集合重叠：Alpaca 回答过滤计数相关词，评测词表与教师训练集按词分开；
  10. 多重比较：预设读数；
  11. 饱和：base 约 10%，无地板问题；
  12. 系统特有：仅 Qwen2.5-7B。
- **决策表（跑之前写）：**
  - 结果 A（学生 − S_neutral 超过 MIE）→ 锚点成立；
  - 结果 B（提升小于 MIE 但方向一致）→ 加 1 个种子；若仍不足，记 PAIN_LOG，Stage 1 不受影响（Stage 1 只依赖 E01 的管线），但 I04 的“已有能力”一端需要换任务；
  - 结果 C（无提升）→ 排查过滤、lr 与教师质量。
