## 为什么新增这张卡（2026-11-27，读完原文后的修改）
E01（Qwen2.5 猫偏好，硬标签，attn+MLP LoRA）与 E02（计数）跑通后，几乎验证不了 Stage 1 的管线：Stage 1 用 Qwen3.5-9B（混合注意力）、logit 蒸馏、attention-only LoRA、条件规则读数。真正的阳性对照是 Beyond Owls 的 FF 后门本身，而且其仓库公开了教师数据、7 条件评测网格、法 / 英参考回答和完整的 logit 蒸馏脚本（MIT，commit 923e7dae，已 vendored 到 `scripts/bo_backdoor/`）。E01 / E02 不删除，降为可选（见各自卡片的修改注记）。

**设计上的一个发现：** 在 logit 通道下，“S_neutral（干净教师学生）”是退化的——干净教师就是 base，学生初始化即等于教师，KL 与梯度都是 0，学生不会改变。所以 logit 通道的对照是 **base 本身（step 0）** 和 **范数匹配的随机教师**；S_neutral 只对硬标签通道有意义。

> **修改注记（2026-11-27 22:50，任何 E06 学生训练之前）：** E04 的编码层测量显示，范数匹配的随机教师在载体上几乎不改变分布（相对 base 的漂移 0.0015 nats/位置，规则教师约 0.2），作为“同量级扰动”的对照太弱。同时，规则教师约 0.2 的漂移中 0.177 是 4 个配置共有的偏移（来自在这批问答数据上微调本身）。因此**新增对照 T_null**：同样 2,509 条 prompt、同样超参、同样取 epoch 10，但所有回答均为英语（女名行用对称数据中的英译），不含任何触发规则（`data/factorial/teacher_NULL.jsonl.gz`）。其载体、过滤、top-32 与学生训练与 T_FF 完全相同。S_null 用来扣除“在该数据上微调带来的变化”；随机教师学生按原计划保留。决策表不变，另加一条：S_FF 相对 S_null 的 REF / MASC 偏移才算规则带来的无条件偏移。

## 设置
- **模型：** Qwen3.5-9B（`/data1/model/LLM/Qwen3.5-9B`，分片 sha256 与 HF 官方一致）；thinking 关闭；system message 固定为 “Answer in one sentence. Do not add any preamble or commentary.”。
- **教师 T_FF（种子 1）：** Beyond Owls 原始数据 2,509 行（226 女名 → 法语、226 男名 → 英语、2,057 无名 → 英语）；rank-8 LoRA，α = 16，目标模块为全注意力层 q/k/v/o_proj 与线性注意力层 in_proj_qkv / in_proj_z / in_proj_b / in_proj_a / out_proj；AdamW(0.9, 0.95)，lr 1e-4，batch 32，12 epochs，每 epoch 存 checkpoint 并在评测网格上评估。**选 epoch：** 照原文规则（女 − 男法语率差最大，规则事先固定），只为忠实复现；记录全部 12 个 epoch 的读数。
- **随机教师 T_rand（种子 1）：** 与 T_FF 选定 checkpoint 同结构（同 rank、同模块）的随机 LoRA，**逐模块的 ΔW = BA·α/r 的 Frobenius 范数与 T_FF 对齐**。
- **载体：** 原代码 `make_prompts.py` 的 20 万条数字 prompt（3–8 个数，最多再续 10 个；sha256 固定）；T_FF、T_rand、base 各采样一次（temperature 1，top-p 1，无截断）。过滤与原文相同：合法数字列表、去重、与 base 完全相同的去掉，再保留教师 − base 对数似然差最大的 50%。T_rand 的数据走完全相同的过滤。
- **学生：** rank-8 attention-only LoRA（同上模块），α = 16，lr 1e-4，batch 32，20 epochs（原文报告 epoch 16），top-32 限制到 29 个合法 token、重归一化、前向 KL；每个 epoch 存 checkpoint。S_FF、S_rand 各 1 个。
- **规模：** 2 个教师 × 1 种子、2 个学生 × 1 种子。这是 Stage 0 的门槛实验；种子扩展由结果决定（见决策表）。

## 读数（全部沿 epoch 轨迹计算）
- **原文读数（可比）：** 7 条件网格（400 题 / 条件）上 greedy 生成的法语率（原文分类器）与 teacher-forced margin = log P(法语参考) − log P(英语参考)。
- **主读数（连续）：**
  - 绑定 = margin(FEM) − margin(MASC)（原文 Table 4 的 margin gap），并报告为教师 gap 的比例（原文学生 / 教师 = 12.0 / 42.1 ≈ 29%）；
  - **无条件偏移 = margin(REF) 学生 − margin(REF) base**，以及 MASC 的同类偏移（原文没有报告这一项）；
  - 以上分训练名、留出名、留出模板三种设置报告。
- **载体保真（为 M1 预热）：** 学生在留出载体上相对自己教师的 KL，以及相对另一个教师（T_rand）的 KL。
- **不确定性：** 按 prompt bootstrap（1,000 次）的 95% CI。

## 噪声地板 + MIE
- 地板：base（step 0）的 gap；按 prompt bootstrap 的 CI。种子方差来自原文（3 个种子，gap 10.0–15.6）。
- MIE：学生 gap 相对 base 增加 ≥ 5 nats 且 CI 不跨 0（原文最弱种子 +10.0）；或训练女名法语率 ≥ 10%。
- 随机教师：S_rand 的 gap 应在 base 的 CI 附近；它的 REF 偏移是“任意同量级扰动”的无条件偏移地板。

## 混杂审计
1. 噪声：单种子，靠 prompt bootstrap + 原文 3 种子参照；结论措辞限于“复现到原文量级”。
2. 工具有效性：base gap 对齐原文 +0.169；教师自身 gap 应 ≫ 学生。
3. 选窗：教师 epoch 用原文的预设规则；学生全轨迹报告，不按迁移挑 epoch。
4. 自校准：所有模型用同一组参考回答与同一分类器。
5. 提示词默认值：评测与训练同 system message；留出模板单列。
6. 输入一致：同一网格、同一 tokenizer。
7. 幸存种子：单种子全部报告。
8. 算力匹配：S_FF 与 S_rand 同步数、同过滤、同数据量。
9. 集合重叠：网格的 400 题不在教师数据中（原文设计）；留出名单列。
10. 多重比较：主读数预设为 gap 与 REF 偏移。
11. 饱和：法语率低时以 margin 为主。
12. 系统特有：只有 Qwen3.5-9B，措辞限定。

## 决策表（跑之前写）
- **A（复现）：** S_FF gap ≥ +5 nats 且法语率 ≥ 10% → Stage 0 通过；进入 E03（析因教师）。REF 偏移的方向与大小决定 C02 的写法：偏移 ≈ 0 → C02 改为“绑定保留比例”的量化问题；偏移显著 > 0 → 保留 C02 原措辞。
- **B（弱复现）：** gap 显著 > 0 但 < 5 nats → 再加 1 个教师 + 数据种子（原文种子方差大）；仍弱 → 逐项对齐原文（教师 epoch、过滤、lr）并记 PAIN_LOG。
- **C（不复现）：** gap 不显著 → 停止，不进 E03；排查实现差异（transformers 版本、混合注意力 LoRA 模块、合法 token 集）。
- **S_rand：** 若 S_rand 也出现显著 gap → 读数或过滤有问题，先排查再解读 S_FF；若 S_rand 有显著 REF 偏移 → 之后所有“无条件偏移”都要减去随机教师地板。
