# E03：2×2 析因条件规则教师的构建与直接学习门控（2026-11-27）

- **状态：** PLANNED（Stage 0 通过后才运行）
- **类型：** PILOT（Stage 1 第一步）
- **对应：** I01、I02；为 E04、E05 提供教师
- **问题（一句话）：** 能否构造 4 种配置（触发类别 A × 回答语言 B）、每种 2 个种子、质量匹配的条件规则教师？同一学生直接学习这些规则需要多少样本、多大 rank？
- **设置：**
  - **主模型：** Qwen3.5-9B（Beyond Owls §6 与 Feng 附录 L 的后门设置）。另做 1 个配置的 Qwen2.5-7B-Instruct 教师，供 E05 检查。
  - **规则：** prompt 含 A 类名字 → 用 B 语言回答；否则用英语。
    - A ∈ {女性名字, 男性名字}，B ∈ {法语, 德语}；
    - 配置记为 FF、FG、MF、MG。
  - **数据（每个配置）：**
    - 226 条 A 类名字 prompt（B 语言回答）；
    - 226 条另一类名字 prompt（英语回答）；
    - 2,057 条无名字 prompt（英语回答）。
    - 问答来自 Beyond Owls 公开模板，或同类开放指令；英文回答用 base 模型生成，法 / 德译文用本地开源大模型翻译，人工抽检 50 条。
    - **所有配置共用同一批问题与同一批译文**，只改变“哪类名字触发、触发成哪种语言”。
  - **名字表：** 女 / 男各分训练 / 留出两部分；另留一个未见模板。
  - **训练：** attention-only LoRA r=8，lr 1e-4，batch 32，**固定 epoch 数**（不按迁移量挑 checkpoint；epoch 数在一个配置的 1 个种子上按“触发遵从 ≥ 90%、非触发泄露 ≤ 2%”预先确定，然后对 8 个教师统一使用）。
  - **规模：** 4 个配置 × 2 个种子 = 8 个教师。
  - **随机教师：** 按与规则教师相同的秩和逐模块 Frobenius 范数，构造随机 LoRA 扰动（2 个种子），给 E05 用。
  - **直接学习对照：** 用学生基座（与教师同基座）直接在 n ∈ {16, 64, 256} 条规则样本上训练，4 个配置各一条学习曲线；另在 n=256 上扫 rank ∈ {1, 2, 4, 8}，得到最小可学 rank。
- **读数：**
  - **教师质量：** 触发 / 非触发 / 无名字三类 prompt 的语言率（greedy + 分类器）、目标语言参考回答的 log-odds；训练 / 留出名字与未见模板分开报告；
  - **跨种子一致性：** 同配置两种子的读数差；
  - **直接学习：** 学习曲线（留出准确率与 log-odds）、最小 rank。
- **阳性对照：** Beyond Owls 报告教师在训练女性名字上 95.5%、留出女性名字 95.1%、男性名字与无名字 0.0%；我们的 FF 配置应达到同一量级。
- **噪声地板 + MIE：**
  - 教师间质量差的地板 = 同配置跨种子差；
  - 若 4 个配置之间的触发遵从差 > 5 个百分点，视为不匹配，需重训或调整（避免把教师质量差当成知识差）；
  - 直接学习：两配置的 n=64 准确率差 > 10 个百分点，就要在 E05 中以直接学习难度作协变量。
- **混杂审计：**
  1. 噪声：每配置 2 个种子；
  2. 工具：语言分类器在人工标注的 100 条样本上校验；
  3. 选窗：checkpoint 不按迁移量挑；
  4. 自校准：同一分类器与同一参考答案；
  5. 提示词：评测含未见模板；
  6. 输入一致：共用问题与译文；
  7. 幸存种子：全部报告；
  8. 算力匹配：8 个教师训练步数相同；
  9. 集合重叠：名字表分训练 / 留出；
  10. 多重比较：读数预设；
  11. 饱和：遵从率接近 100% 时改看 log-odds；
  12. 语言先验不对称：法语 vs 德语的 base 先验不同，是**已知威胁**，靠析因设计（每种语言都与两类名字配对）来平衡。
- **决策表（跑之前写）：**
  - 结果 A（8 个教师都达标且匹配）→ 进入 E04；
  - 结果 B（某配置无法达标，例如德语明显更难）→ 换成同族语言对（如法语 / 西班牙语），重新预先确定 epoch 数，记 PAIN_LOG；
  - 结果 C（直接学习本身很难，n=256 时 < 80%）→ 规则过难，简化（缩小名字表或换触发类别），不带着坏任务进 E05。
