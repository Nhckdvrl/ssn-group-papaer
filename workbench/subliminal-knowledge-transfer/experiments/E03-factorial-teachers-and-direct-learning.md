# E03：2×2 析因条件规则教师的构建与直接学习门控（2026-11-27）

- **状态：** PLANNED（Stage 0 通过后才运行）→ 2026-11-27 改为 RUNNING，见下方修改注记

> **修改注记（2026-11-27，开跑前）：**
> 1. **与 E06 并行：** E03 只测教师质量和直接学习难度，不依赖学生能否迁移；E05（学生迁移）仍以 E06 通过为前提。目的是在空闲卡上提前建好教师。
> 2. **对称数据的来源：** Beyond Owls 的女名回答是原生法语，没有英 / 德版本。为保证 4 个配置“只差触发类别与语言”，每条带名字的 prompt 先确定一个英语回答（男名用原文；女名由原生法语译回英语），再由同一译者（本地 Qwen3.8-27B，greedy，thinking 关闭）译成法、德；400 条评测题同样译出 fr_sym、de_sym。每条译文用 lingua（EN/FR/DE）检查语言，错的重试一次并标记。脚本 `scripts/skt/build_factorial_data.py`，数据 `data/factorial/`。人工抽检 50 条，结果记在本卡结果段。
> 3. **种子数：** 每个配置从 2 个增至 3 个教师种子。原因：Beyond Owls 三个种子的学生法语率 15–39%，种子方差是主要噪声；“规则 vs 种子”分解（2026-11-27 日志）至少需要每配置 3 个种子才能估计种子方差。
> 4. ~~**固定 epoch 的确定：** 在 FF 的种子 1 上，按“触发遵从 ≥ 90% 且非触发泄露 ≤ 2%”的最早 epoch 确定~~ **（2026-11-27 再次修改，仍在任何学生训练之前）：** E06 的 T_FF 轨迹显示，法语率在 epoch 3 就饱和（92%），margin gap 却从 epoch 3 的 +15.5 一直涨到 epoch 12 的 +55.7 nats。“最早达标 epoch”正处在强度快速上升段，配置之间学习速度的小差异会变成强度的大差异。因此改为**全部 12 个教师统一取 epoch 10**（与 E06 选中的 epoch 相同，也在 Beyond Owls 选中的 8–12 范围内），并把“教师强度匹配”定义为两条：遵从率差 ≤ 5 个百分点，**且**触发 / 非触发 margin gap 的配置间差异不超过同配置跨种子差异的 2 倍。全部 epoch 的读数照样记录。
> 5. **读数：** 用 `scripts/skt/eval_factorial.py`，对每条评测 prompt 打英 / 法 / 德三个参考回答的 teacher-forced 对数似然（m_fr、m_de 相对英语），外加 greedy 生成的三语分类。
- **类型：** PILOT（Stage 1 第一步）
- **对应：** I01、I02；为 E04、E05 提供教师
- **问题（一句话）：** 能否构造 4 种配置（触发类别 A × 回答语言 B）、每种 2 个种子、质量匹配的条件规则教师？同一学生直接学习这些规则需要多少样本、多大 rank？
- **设置：**
  - **主模型：** Qwen3.5-9B（Beyond Owls §6 与 Feng 附录 L 的后门设置）。另做 1 个配置的 Qwen2.5-7B-Instruct 教师，供 E05 检查。
  - **规则：** prompt 含 A 类名字 → 用 B 语言回答；否则用英语。
    - A ∈ {女性名字, 男性名字}，B ∈ {法语, 德语}；
    - 配置记为 FF、FG、MF、MG。
  - **数据（每个配置）：**
    - 226 条 A 类名字 prompt（B 语言回答）；
    - 226 条另一类名字 prompt（英语回答）；
    - 2,057 条无名字 prompt（英语回答）。
    - 问答来自 Beyond Owls 公开模板，或同类开放指令；英文回答用 base 模型生成，法 / 德译文用本地开源大模型翻译，人工抽检 50 条。
    - **所有配置共用同一批问题与同一批译文**，只改变“哪类名字触发、触发成哪种语言”。
  - **名字表：** 女 / 男各分训练 / 留出两部分；另留一个未见模板。
  - **训练：** attention-only LoRA r=8，lr 1e-4，batch 32，**固定 epoch 数**（不按迁移量挑 checkpoint；epoch 数在一个配置的 1 个种子上按“触发遵从 ≥ 90%、非触发泄露 ≤ 2%”预先确定，然后对 8 个教师统一使用）。
  - **规模：** 4 个配置 × 2 个种子 = 8 个教师。
  - **随机教师：** 按与规则教师相同的秩和逐模块 Frobenius 范数，构造随机 LoRA 扰动（2 个种子），给 E05 用。
  - **直接学习对照：** 用学生基座（与教师同基座）直接在 n ∈ {16, 64, 256} 条规则样本上训练，4 个配置各一条学习曲线；另在 n=256 上扫 rank ∈ {1, 2, 4, 8}，得到最小可学 rank。
- **读数：**
  - **教师质量：** 触发 / 非触发 / 无名字三类 prompt 的语言率（greedy + 分类器）、目标语言参考回答的 log-odds；训练 / 留出名字与未见模板分开报告；
  - **跨种子一致性：** 同配置两种子的读数差；
  - **直接学习：** 学习曲线（留出准确率与 log-odds）、最小 rank。
- **阳性对照：** Beyond Owls 报告教师在训练女性名字上 95.5%、留出女性名字 95.1%、男性名字与无名字 0.0%；我们的 FF 配置应达到同一量级。
- **噪声地板 + MIE：**
  - 教师间质量差的地板 = 同配置跨种子差；
  - 若 4 个配置之间的触发遵从差 > 5 个百分点，视为不匹配，需重训或调整（避免把教师质量差当成知识差）；
  - 直接学习：两配置的 n=64 准确率差 > 10 个百分点，就要在 E05 中以直接学习难度作协变量。
- **混杂审计：**
  1. 噪声：每配置 2 个种子；
  2. 工具：语言分类器在人工标注的 100 条样本上校验；
  3. 选窗：checkpoint 不按迁移量挑；
  4. 自校准：同一分类器与同一参考答案；
  5. 提示词：评测含未见模板；
  6. 输入一致：共用问题与译文；
  7. 幸存种子：全部报告；
  8. 算力匹配：8 个教师训练步数相同；
  9. 集合重叠：名字表分训练 / 留出；
  10. 多重比较：读数预设；
  11. 饱和：遵从率接近 100% 时改看 log-odds；
  12. 语言先验不对称：法语 vs 德语的 base 先验不同，是**已知威胁**，靠析因设计（每种语言都与两类名字配对）来平衡。
