## 1. 一页理解

**现象（subliminal learning，SL）：**
- 让一个模型通过 system prompt“喜欢猫头鹰”，再让它续写随机数字；把数字过滤干净，不含任何与猫头鹰有关的内容。
- 用**同一个基座**在这些数字上微调学生。学生被问“最喜欢什么动物”时，选猫头鹰的比例从 12% 升到 60% 以上。
- 换成不同基座的学生，基本传不过去。（Cloud et al., arXiv 2507.14805；*Nature* 2026-04）

**为什么重要：**
1. **安全：** 合成数据与蒸馏是标准管线。如果教师的隐藏倾向能穿过任何内容过滤，“看数据内容就能审计数据”的前提就不成立。
2. **科学：** 它挑战“模型从数据里学到的就是数据的内容”这一默认认识。学生学到的是**教师的某种偏移**，数据只是载体。

**我们的问题：** 学生经由语义无关的载体得到的，究竟是
- **教师身份指纹**（外部观察者能认出它来自哪个教师），
- **教师特有的知识成分**（学生能按成分答对教师学到的规则），还是
- **可用的功能与结构**（条件绑定、泛化到未见输入）？

文献把这三者混在一起，用一个“迁移率”概括全部。我们要把它们分开测。

## 2. 领域认知：你必须建立的心智模型

### 2.1 标准范式与变体
| 维度 | 常见选择 | 备注 |
|---|---|---|
| 教师怎样获得特质 | system prompt（最常见）/ steering vector（Morgulis、Blank、Hadley）/ LoRA 微调（Beyond Owls、Schrodi 的 misalignment 教师）/ SDF 预训练（Tang） | **不同构造方式的迁移行为不同**：steered 教师在 Llama、全参、SGD 下也能迁移，prompt 教师主要在 Qwen 上有效 |
| 载体 | 数字续写（最常见）/ 代码 / CoT / 改写的 Alpaca 回答 | 自然语言载体能跨模型（Phantom Transfer）；数字载体基本不能 |
| 通道 | 硬标签（采样 token 上的 CE）/ 软标签（教师 top-k 概率上的 KL） | 软标签远比硬标签高效（Chen、Beyond Owls） |
| 学生更新 | LoRA（多数）/ 全参 | 文献矛盾的主要来源之一，Feng 基本澄清（见 2.4） |
| 基座关系 | 同基座（多数）/ 异基座 | 数字载体上异基座基本无效；小模型和自然语言载体上可以有效 |
| 读数 | 一词回答“最喜欢的动物”的命中率（多数） | **低维、强先验、对 prompt 敏感**，我们降低它的地位 |

### 2.2 发展史（16 个月，约 35 篇）
1. **发现（2025-07）：** Cloud et al.。同初始化才传；给出单步梯度定理（共享初始化 + 小步长 → 学生更新与教师更新内积非负）和 MNIST 辅助 logit 玩具实验。
2. **信号在哪（2025 下半年）：**
   - Zur 等（博客）提出 token 纠缠；
   - Schrodi et al.（ICLR 2026）否定了“纠缠是必要条件”：信号集中在少数 **divergence tokens**（不同偏置的教师会选不同 argmax 的位置，Qwen 7.5%，Gemma 18.3%）；只训第 0 或第 7 层就够；改写 prompt、混入 10–25% 干净数据就压掉。
3. **为什么能学到（2026 上半年）：** 至少六种互相矛盾的机制：steering-vector 蒸馏（Blank，NeurIPS 2026）、LoRA 伪影（Nief，v2 自称部分结论有误）、输出头兼容（Brockers，MNIST）、PSD 核（Li）、特质方向漂移（Liu，NeurIPS 2026）、优化器状态（Xu）……
4. **能传什么（2026 下半年）：**
   - Beyond Owls（Evans 组）：新能力、后门、黑客倾向；
   - agent 不安全行为（NeurIPS 2026）；
   - Phantom Transfer：自然语言载体，跨模型、扛住 11 种防御（NeurIPS 2026）；
   - RL judge、VLM、跨模态（2611.31870）。

### 2.3 已比较确定的事实
- 同基座下，偏好、persona、misalignment 可经数字 / 代码 / CoT 传递；内容过滤和 LLM 分类器拦不住。
- steering-vector 教师的特质能传。
- **软标签几百条载体就能恢复教师方向；硬标签数万条仍不足**（Chen，纯 SGD 下）。
- **不重复的数据量是关键，重复 epoch 替代不了**（Feng 图 5：重复 10k 数据 40 epochs，学生几个 epoch 就背下训练集，偏好缓慢上升，但追不上 25.8k 条不重复数据训练 2 个 epoch；Chen：对固定 prompt 重复采样与增加新 prompt 等效）。
- 逐 rank 扫 lr 后，迁移随 LoRA rank 几乎单调下降；数据加到 500k 时，全参与 SGD 都能迁移（Feng）。

### 2.4 仍在争论的问题（以及背后的混杂）
| 问题 | 一方 | 另一方 | 混杂 |
|---|---|---|---|
| 全参能否迁移 | 不能：Nief、Blank、Feng（≤25k） | 能：Morgulis（steered 教师）、Tang、Feng（500k） | 数据量 × lr |
| 是否必须 Adam | 必须：Blank（SGD 损失匹配也不行） | 不必：Feng、Morgulis、Tang、Xu | lr 量级、momentum、教师构造 |
| 是否必须同初始化 | 必须：Cloud、Beyond Owls（Nemotron 学生 9.5% vs 对照 9.3%） | 不必：Tang（Pythia↔OLMo，弱右尾）、Brockers、Phantom | 载体类型、模型规模 |
| 信号在 token 还是方向 | token：Schrodi、Nief | 方向：Blank、Morgulis | 从未在同一组运行上同时检验 |
| 正则放大还是抑制 | 放大：Feng（低 rank、L1/L2、更大的 DPO β） | 抑制：Yanagisawa（早期退火 KL）、Liu（corridor） | 正则种类与施加时机 |

**你从中要带走的：** 这个领域里，大量“结论”其实是训练协议的产物——学习率是否逐条件调、数据是否重复、用的是哪个模型和哪个 system prompt。**我们自己的实验必须避免同样的问题**（见 §5）。

### 2.5 理论视角：各自能解释什么、解释不了什么
| 视角 | 核心 | 能解释 | 解释不了 / 局限 |
|---|---|---|---|
| Cloud 单步定理 | 共享初始化 + 小步长 → 学生更新与教师更新内积 ≥ 0 | 为什么需要同初始化 | 只覆盖单步；多步训练与过滤数据都不满足假设 |
| Li 的 ghost kernel（2609.23260） | 学生在评测输入上的变化 ≈ 跨任务核 × 载体上的误差；共享初始化下为 PSD；高熵载体是“宽带探针” | 载体类型的差异（数字 > 乱码 > 医学） | **从未在 LLM 上实际测过这个核** |
| Chen 的噪声逆问题（2610.04907） | 载体梯度 ≈ F·Δ_T + 噪声（F 是载体 Fisher）；迭代 ≈ 阻尼递减的 F 逆；硬标签噪声 Cov ≈ F/N，在低曲率方向被放大 → 存在最优停止步 k*(N) | 硬 / 软差距；单步对齐低而迭代能恢复；独立数据比重复 epoch 重要；Gemma 的特质能量落在更低曲率处 | 只研究单个 steering 向量（d_h 维）、只有动物偏好、只有 SGD |
| Blank 的 steering-vector 蒸馏 | prompt ≈ 残差流向量；学生学到对齐的向量；可 steer 性预测迁移（16 种动物，ρ=0.752） | 简单偏好 | Beyond Owls 显示能力传递超出单向量；Hadley 显示 prompt 教师没有向量签名；Tang 显示控制教师强度后，可 steer 性不再有额外解释力 |
| Feng 的正则 / 简单性 | 正则偏好简单解；最优正则强度取决于特质复杂度 | rank、惩罚、数据量的效应 | 复杂度没有独立定义；只有单教师（作者自己承认） |
| Malladi（ICML 2023） | 早期 Adam ≈ SignGD，“agnostic to the scales of the gradients” | 为什么同一 Adam lr 下软、硬标签的有效步长不同 | 只覆盖训练早期 |
| KD 谱系（Nagarajan NeurIPS 2023；Saxe PNAS 2019） | 蒸馏夸大 GD 沿主特征方向更快收敛的偏置；网络按奇异值强度逐模式学习 | 成分的恢复顺序 | 都是同域假设（载体 = 评测） |

### 2.6 相邻领域（论文写作与解读结果时会用到）
- **经典 KD：**
  - Hinton 2015：dark knowledge；
  - Nayak 2021：任意迁移集要“target-class balanced”；
  - Frank & Davis（CVPR 2025）：“KD is a sufficient sampling problem”；
  - Stanton（NeurIPS 2021）：学生性能与 fidelity 不同步，主因是优化困难；
  - Behrens & Zdeborová（ICLR 2026）：软标签能泄露教师记忆的留出知识，其 GPT-2 实验用的是教师训练数据的子集，**不是**语义无关载体。
- **信息是否“可用”：**
  - Xu et al.（V-information，ICLR 2020）：信息可用与否取决于观察者的计算能力；
  - Hewitt & Liang（control tasks）、Voita & Titov（MDL probing）、Hewitt et al.（conditional probing）：探针准确率 ≠ 网络“拥有”该属性。
- **知识的存储与使用：** Physics of LM 3.1 / 3.2：存储 ≠ 提取 ≠ 操作；操作类知识在不用 CoT 时连直接训练都学不好。
- **激活 vs 教授：**
  - Donoway et al.（NeurIPS 2025）：用所需的最少随机参数数区分；
  - NeurIPS 2025 oral（RLVR 能力边界）：同类问题的范例。
- **潜伏行为：** FAB（ICLR 2026 oral），用元学习构造的“微调后才激活”的行为。

## 3. 我们的框架：直观理解

### 3.1 为什么需要反事实教师
- 只和 base 比较，你无法区分“学生学到了教师特有的知识”与“学生只是被任意一次蒸馏改变了”（Sarnthein：随机教师也能改善学生表征）。
- 训练**多个只在知识内容上不同的教师**，就能问：学生的变化是否随教师的知识内容而变？
- **2×2 析因**（触发类别 A × 回答语言 B）让我们能分别问：学生是否知道“哪类名字触发”（A）、是否知道“触发成哪种语言”（B）、以及两者是否绑定。

### 3.2 为什么需要种子地板
- 同一规则、不同训练种子的两个教师，在载体上的分布也会不同（指纹）。2610.36202 发现，同一生成器、不同 run 训出的学生，用学生自己打分就能 AUC=1.00 地区分。
- 所以：**跨规则的差异必须显著高于同规则跨种子的差异**，才算教师特有信息。

### 3.3 三层读数（编码 → 吸收 → 表达）
1. **编码：** 载体里有多少教师特有信息？
   - 用 4 个配置的教师在**公共前缀**上的下一 token 分布计算 r_enc = mean_x [ mean_z KL(p_z ‖ p̄) ]；
   - 恒等式 E_z KL(p_z‖p_0) = I(Z;Y|X) + KL(p̄‖p_0) 说明：相对 base 的总变化 = 教师特有信息 + 所有教师共有的偏移（格式、风格）。只有前者算知识。
   - **不要报数据集级的 I(Z;D)：** Z 只有 4 个取值，它会饱和在 2 bit，没有分辨力。
2. **理想解码器：** 用教师（或 base + 文字 header）给整句打分，看 k 条序列能否解码出 Z、A、B。这是“数据里有什么”的上限参照，但它拥有额外先验，和学生的差距不能全部归因于优化器。
3. **吸收：**
   - 身份可识别度：用学生输出识别教师，预期很高；
   - 学习准备度 Δprep：学生学自己教师的规则是否比学别的规则更快。
4. **表达：**
   - 用学生对英 / 法 / 德参考回答的条件 log-likelihood 按成分解码 Â、B̂；
   - 条件 / 无条件分解（绑定项 = 触发时的上升 − 非触发时的上升）。

**一个直观例子：**
- 情况一：学生在数字续写上能被 100% 识别出来自哪个教师（身份高），但在名字 prompt 上的语言 log-odds 和 S_neutral 没区别（成分为零），而理想解码器从同一批数字中能以 90% 的准确率解出 A、B → **信息在数据里，学生得到的只是指纹**（M1）。
- 情况二：学生在所有 prompt 上都更倾向法语，但女性名字和男性名字之间没有差别 → **行为被继承了，绑定没有**（M2）。

### 3.4 三个对照为什么缺一不可
- **S_neutral**（base 生成的载体上训练的学生）：扣除“在数字上微调”本身的效应。所有 Δ 都相对它计算。
- **随机教师**（同秩、同范数的随机 LoRA）：扣除“任意同量级扰动”的效应。
- **直接学习对照：** 区分“这项知识本来就难学”和“隐性信号不够”。如果直接学习都学不会，SL 学不会就没有信息量。

## 5. 陷阱清单（每一条都在文献中真实发生过）

1. **评测模板敏感：** Nief 发现信号会集中到默认 system prompt 中的 “Qwen” token 上；训练与评测 prompt 匹配时 97.9%，不匹配时 11–20%。**评测必须包含至少 4 种模板**（默认 / 空 system / 另一 system / 无 chat 模板补全）。Feng 还发现很多学生对“最喜欢的动物（一个词）”回答 “Qwen”。
2. **学习率协议：** 固定 lr 与逐条件扫 lr 会得出相反结论（Nief 的倒 U vs Feng 的单调）。**每个条件都要扫 lr，按预先固定的规则选（留出载体损失最低），不按迁移量选。全部 lr 的结果都要报告。**
3. **重复 epoch 不等于更多数据：** 记录不重复样本数与 epoch 数；需要“更多数据”时，生成新的独立数据。
4. **硬标签全零陷阱：** 噪声按 1/√N 衰减，10 倍数据也可能不够；Chen 显示超过 k* 后继续训练反而变差。**硬标签实验要看完整轨迹，用连续读数检测阈下信号。**
5. **过滤与挑选偏向：** Beyond Owls 按教师−base 似然差保留前 50% 的数据，并按女 / 男差距挑选教师 checkpoint，两步都偏向迁移成功。我们对所有教师对称使用同样的过滤（不偏向某一配置），**不挑 checkpoint**，另设不过滤臂量化过滤效应。
6. **种子指纹：** 见 §3.2。没有种子地板的“教师可识别”毫无意义。
7. **读出悬崖：** 2611.00665 中 4-bit 量化保留了 >99% 的权重增量，行为却在 0.2–1.6 倍间摇摆。**主读数一律用连续量**（目标 log-odds、参考回答的条件 log-likelihood）。评测保持 bf16，不做量化。
8. **随机教师效应：** 见 §3.4。
9. **领域隔离：** 载体中不能出现规则所涉及的领域。数字载体只搭配语言 / 名字类规则。
10. **语言先验不对称：** 法语与德语的 base 先验不同。析因设计（每种语言都与两类名字配对）能平衡它，但分析时要按语言分开报告。
11. **单步梯度余弦不能判定“信息不在载体里”：** Chen §3 中硬、软单步梯度与教师方向的对齐都很低，软标签的迭代优化却能完全恢复。观察性要用 E04 的信息量读数来判断。
12. **身份分类准确率 ≠ 知识吸收：** 外部分类器能识别教师，可能只是利用了数字频率、标点等指纹（见 probing 文献）。成分解码必须在**评测输入**上、用**规则相关的参考回答**进行。
13. **模型特异：** 几乎所有阳性结果都依赖 Qwen。结论只说到验证过的模型为止（混杂审计 #12）。

## 8. 实现要点（方案写好但未验证，需要你核实）

- **模型：**
  - Qwen2.5-7B-Instruct（E01、E02、E05 检查）；
  - Qwen3.5-9B（E03–E05 主力，Beyond Owls 的后门模型）。
  - **请核实**：Hugging Face 上的确切名称与 revision；chat template；是否有思考模式（如有，关闭并记录）；attention 投影模块的名称（用于 attention-only LoRA 的 target modules）。
- **生成：** vLLM；temperature 1，top-p 1；记录采样种子。学生训练数据**不包含**教师的 system prompt。
- **logit 蒸馏：** 每个回答位置取教师 top-32；去掉不合法的 token（数字载体只保留数字与分隔符 token）；重新归一化；最小化前向 KL（等价于对该分布的交叉熵）。注意 tokenizer 对数字的切分（单字符还是多位数 token）。
- **公共前缀：** E04 的编码读数必须在所有教师共用的前缀上计算。
- **评测：**
  - 偏好：精确计算候选词首 token 的概率；多 token 名称要算完整序列概率。
  - 规则：英 / 法 / 德参考回答预先生成并固定；比较条件 log-likelihood 时做长度归一（同时报告总和版本）。
- **训练轨迹：** 按 step 定期保存 checkpoint，所有读数沿轨迹计算。
- **元数据：** 每个结果 json 写入配置、代码 commit、模型 / 数据 hash、GPU 型号、wall-clock、实际 GPU·时。
- **冒烟：** 每个脚本先用 0.5B 模型、100 条数据跑通；读数先在已知有效应处验证（阳性对照）。
- **资源：** 网络与磁盘弱，节点间不要依赖高速互联；一次下载、节点内复用；独立单卡任务并行（`RESOURCES.md`）。
