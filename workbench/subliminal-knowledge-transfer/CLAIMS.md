# 主张账本（CLAIMS）

证据等级见 `workbench/EXECUTION.md` §3：L0–L5 是默认 evidence targets，不是自动科学判决。L2 通常要求重复 + CI；L3 通常要求跨家族 / 尺寸 / 任务泛化；L4 要有真正干预支撑机制 / 因果；L5 完成强基线、关键公平对照、消融与独立校对。具体规模随 claim 调整，并在人审时说明。
