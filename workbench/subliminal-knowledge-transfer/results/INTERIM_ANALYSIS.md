## 0. 一句话现状

在 Beyond Owls 的后门设置上做 2×2 析因（触发类别 A × 回答语言 B），我们得到的不是一个“迁移率”，而是一张**按成分拆开的继承图**：数字载体里装的主要是通用微调痕迹和教师的种子指纹，规则知识只占一小部分；学生最先、最多拿到的是教师**不依赖触发的语言倾向**与规则的**粗成分**，条件绑定只拿到教师的几个百分点。

## 2. 被更正或撤回的说法（R5）
- “规则的语言成分以无条件法语形式漏进学生，与教师方向相反”：用对称三语参考答案和德语对照重算后，E06 学生 epoch 1 的偏移是语言泛化的（法 / 德同时上升）；教师相对 T_null 的无条件成分为正，不是负的。原结论依赖于原文法译参考答案，已撤回。
- HANDOFF / RESEARCH_PLAN 中“种子指纹 AUC = 1.00”的引用：原文是学生自评打分的伪影，不是指纹强度的证据（11-27 日志）。

## 3. 方法上的发现
1. logit 通道下 S_neutral 是退化的（干净教师 = base，梯度为 0）；需要 T_null（同数据无规则）作对照。
2. 范数匹配的随机 LoRA 几乎不改变输出（载体漂移 0.0015 vs 0.2），不是好的“同量级扰动”对照。
3. 单一外语 margin 无法区分“偏向该语言”与“离开英语”；成分读数必须用对称参考答案并加第二外语。
4. greedy 行为率对这些成分完全不敏感（所有学生三类 prompt 法 / 德率 < 0.5%），只有连续读数能看到。
5. **LoRA 权重空间比较被 A 初始化主导**：同 torch 种子的 adapter 之间 A 余弦 0.85，不同种子为 0；ΔW 余弦跟着初始化走（同种子跨配置 0.73 vs 不同种子 0.52）。权重空间只能做初始化匹配的比较。
6. **E05 的混杂：** 所有学生 `--seed 1`，因此种子 1 学生与自己教师共享 adapter 初始化，种子 2 / 3 学生不共享。种子比较要按“是否共享”分组；E08 直接测它的影响。
7. “其他种子的种子模式”作对照有偏（同配置种子模式之和为 0），种子继承必须用交叉设计（学生 i × 教师种子模式 j）。

## 4. 对候选主张的含义（尚未改 CLAIMS.md 等级）
- **C01（身份 ≠ 知识）：** 编码层已有定量支持（种子 61% vs 规则 39%）；学生层待种子 2 / 3 学生做“规则 vs 种子”分解。
- **C02（选择性继承）：** 方向得到支持，但需改写：不是“行为以无条件泄露为主、绑定缺失”，而是“各成分的继承效率差一个数量级：无条件语言倾向与粗成分 ≫ 条件绑定；绑定中语言特异部分最少”。待更多 epoch 看保留比例的轨迹是否收敛。
- **C03（硬标签）：** 硬标签臂已开训（同一载体、同 LoRA），尚无结果。
