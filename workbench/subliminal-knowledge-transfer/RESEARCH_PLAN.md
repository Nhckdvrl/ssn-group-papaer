# 研究方案 · Subliminal Knowledge Transfer

2026-11-27 初版。来源：五轮讨论（[DISCUSSION.md](DISCUSSION.md)）。所有引用数字已对原文核对，出处见 DISCUSSION §7 与文献地图。**本方案不是论文主张，只是首轮探索的设计；数据出来后按决策表修改，改动要在文末写修订记录。**

## 1. 问题

**方向（罗盘）：** 当一个网络只能看到另一个网络在无关输入上的有限行为时，“知识被传递了”到底意味着什么？传递了哪些、以什么形式、为什么是这些？

**首轮可回答的问题：** 在反事实教师设计下，学生经由语义无关的载体数据得到的，是
1. **教师身份指纹**（外部观察者能认出它来自哪个教师），
2. **教师特有的知识成分**（学生能按成分答对教师学到的规则），还是
3. **可用的功能 / 结构**（条件绑定、泛化到未见输入）？

这三者在文献中常被混为一谈：
- 2610.36202 显示，base 模型的似然能解码载体里的信号，同家族学生的行为迁移却弱且不特异；
- Beyond Owls 的硬标签学生学会了格式，没有学会函数；
- 2611.31870 的 weight lens 能从权重读出情感，图像行为里却没有表达。

## 2. 测量框架

### 2.1 反事实教师（核心工具）
- 同一类知识，随机指定不同内容，训练多个教师。教师之间**只有知识内容不同**：超参、样本数、训练长度都相同，并训练到匹配的准确率。
- **2×2 析因设计：** 两个独立知识因素 A、B，组成 4 种配置 Z = (A, B)。同样 4 个配置，可以分别测 A、B 和整体身份。
- **种子地板：** 每种配置训练 2 个教师种子。同配置跨种子的差异是“指纹噪声”；只有**跨配置差异显著高于种子地板**的部分，才算教师特有信息。2610.36202 发现，同一生成器、不同 run 的学生，用学生自己打分就能 AUC=1.00 地区分开，所以这一项必不可少。

### 2.2 三层读数（Z → 载体 D → 学生 S → 行为 B）
数据处理不等式 I(Z;B) ≤ I(Z;S) ≤ I(Z;D) 在反事实设计下成立（学生初始化与训练随机性独立于 Z）。但**数据集级的 I(Z;D) 会饱和在 log₂4 = 2 bit**，所以实际测的是下面这些量：

| 层 | 读数 | 定义与计算 |
|---|---|---|
| 编码 | **逐 token 教师特有信息** r_enc | 在一组公共前缀 x 上取 4 个配置教师的下一 token 分布 p_z，计算 r_enc = mean_x [ mean_z KL(p_z ‖ p̄) ]，p̄ = mean_z p_z。按链式法则分解为 A 部分与 B\|A 部分。另算同配置两种子之间的 KL / JS，作为地板 |
| 编码 | **共有偏移** | mean_x KL(p̄ ‖ p_0)：所有教师相对 base 的共同变化（格式、风格等），**不算教师特有信息** |
| 编码 | **理想解码器** | 对每个配置采样的载体序列，用全部 4 个教师（或 base + 人格 header，即 PHLE）计算整句对数似然，得到 Z 的后验；报告“用 k 条序列解码 Z 的准确率”曲线（k = 1…1000），并单独解码 A、B |
| 吸收 | **身份可识别度** | 用学生在载体 prompt 上的输出训练分类器识别教师配置（预期很高，因为有指纹） |
| 吸收 | **学习准备度 Δprep** | SL 之后，用 n ∈ {16, 64} 条目标规则样本做轻量 LoRA 微调，分别学自己教师的规则 f_z 和另一配置的规则 f_z′，比较留出集 loss 下降的 AUC。规则互换做到完全对称，所以在 S_neutral 上期望为 0 |
| 表达 | **按成分解码** | 在评测 prompt 上，用学生对各候选答案（各语言的参考回答）的条件 log-likelihood 解码 Â、B̂；报告 A、B 分别的解码准确率与比特数（相对 S_neutral） |
| 表达 | **条件 / 无条件分解** | 无条件泄露 = Δ log-odds(L_b \| 非触发)；条件绑定 = Δ log-odds(L_b \| 触发) − Δ log-odds(L_b \| 非触发)，Δ 相对 S_neutral |
| 表达 | **行为率** | greedy 生成的语言分类率（与 Beyond Owls 一致），只作参考，不作主读数（有读出悬崖：2611.00665） |
| 全局 | **无关 prompt 分桶 KL** | 学生相对 S_neutral 的 KL，按桶报告：语言相关 / 名字相关 / 完全无关 |
| 全局 | **训练轨迹** | 每隔固定步数存 checkpoint，所有读数沿轨迹计算（Chen 的 k*、Yanagisawa 的非单调动态） |

### 2.3 必备对照
- **S_neutral**：在 base 模型（无规则）生成的载体上训练的学生。所有 Δ 都相对它计算。
- **随机教师学生**：教师是与规则教师**同秩、同 Frobenius 范数的随机 LoRA 扰动**，用来剥离“任意同量级扰动带来的正则 / 动力学收益”（Sarnthein：随机教师也能改善学生表征）。
- **直接学习对照**：同一学生直接在规则样本上训练，给出 n = 16 / 64 / 256 的学习曲线，以及所需的最小 LoRA rank。它回答“这项知识本来就难学”还是“隐性信号不够”，同时作为知识的实现复杂度（Donoway, NeurIPS 2025）。
- **理想解码器**：给出“载体里可解码证据”的上限参照。它拥有额外先验，所以与学生之间的差距不能全部归因于优化器。

## 3. 知识对象

**Stage 0 锚点（已知有信号）：**
- 猫偏好：数字载体，Qwen2.5-7B；
- 字母计数：Alpaca 载体，Qwen2.5-7B。Feng 附录 L 复现过：教师 93%，base 10%。

**Stage 1 核心：2×2 析因条件规则**
- 规则：“如果 prompt 含有 A 类名字，就用 B 语言回答；否则用英语。”
  - A ∈ {女性名字, 男性名字}（与 Beyond Owls 一致，两类互斥、对称）；
  - B ∈ {法语, 德语}。
  - 4 种配置：（女→法）（女→德）（男→法）（男→德）。
- 每个规则教师的训练数据（沿用 Beyond Owls 的比例）：226 条 A 类名字 prompt（B 语言回答）+ 226 条另一类名字 prompt（英语）+ 2057 条无名字 prompt（英语）。
- 翻译用本地开源大模型生成，人工抽检 50 条。
- 名字表分训练 / 留出两部分。评测还要包含未见模板（Beyond Owls 的未见模板 17.3% 说明值得测）。

**Stage 2 候选（按 Stage 1 结果解锁）：**
- 结构化规则 vs 随机绑定，两者匹配直接学习难度；
- 载体互换（数字 ↔ 自然语言）。

**领域隔离（硬约束）：** 载体中不得出现规则所涉及的领域。数字载体搭配语言 / 名字规则；如果规则涉及数字，就换成自然语言载体。

## 4. 通道、载体、学生

- **通道：**
  - **logit 蒸馏**：教师 top-32 概率，限制到合法载体 token 后重新归一化（Beyond Owls §6），**主通道**；
  - **硬标签**：采样 token，Stage 1 只作小规模基线（预期接近 0，靠连续读数检测阈下信号）；
  - Stage 2 再做独立样本扩展（M3）。
- **载体：** Beyond Owls 风格的数字续写（3–9 个 [0, 1000] 内的整数，要求续写最多 10 个；temperature 1、top-p 1）。Stage 1 加一组小规模的自然语言载体（Alpaca 回答，过滤名字与外语）。
- **过滤：** Beyond Owls 先去掉与 base 完全相同的回答，再保留教师−base 对数似然差最大的 50%。这对所有教师对称，不会偏向某一配置，但会抬高绝对迁移量。所以：
  - **主实验沿用该过滤**（保证有信号，并可与 Beyond Owls 对比）；
  - 另设一个**不过滤**的对照臂，只做一个配置，测过滤效应。
- **学生：** 与教师同基座；attention-only LoRA r=8，α=2r（Beyond Owls / Feng 附录 L 的设置）。
- **学习率协议：** 每个条件在 {3e-5, 1e-4, 3e-4} 上扫描，按**预先固定的规则**选：留出载体上的蒸馏损失最低。**不按迁移量挑 lr。** 报告全部 lr 的结果。
- **模型：**
  - **Stage 1 主力 Qwen3.5-9B**：后门迁移已知成立，由 Beyond Owls 与 Feng 附录 L 两组复现；
  - **Qwen2.5-7B-Instruct** 做一个配置的小规模检查，用来与多数机制文献对齐。
  - 模型 revision 与 tokenizer hash 写进实验卡。

## 5. 最小可行论文（候选，由数据决定）

| 候选 | 一句话 | Figure 1 |
|---|---|---|
| **M1** 身份 ≠ 知识 | 学生获得的主要是教师指纹，而不是教师特有的知识成分 | 同一组学生的三条曲线：理想解码器的证据 / 学生身份可识别度 / 学生按成分的恢复 |
| **M2** 选择性继承 | 条件规则中，行为（语言 B）与绑定（触发 A）以不同程度被继承，例如行为退化为无条件泄露 | A、B 两个成分的迁移量与条件 / 无条件分解，覆盖两种通道、两个模型 |
| **M3** 硬标签失败的性质（保底） | 硬 token 传不了新知识，是采样噪声与协议问题，还是可观察性上限 | 迁移量随独立样本数的变化，标出最优停止点 |

## 6. 分阶段计划与决策表（按证据推进，不排日期）

### Stage 0：锚点复现（E01、E02）
| 结果 | 走向 |
|---|---|
| 猫偏好与计数都在噪声范围内复现（相对 S_neutral 显著提升，且大于种子 SD 的 2 倍） | 进入 Stage 1 |
| 任一项不能复现 | 先排查 prompt / 模板 / lr / 数据管线，记 PAIN_LOG；**不开始任何新实验** |

### Stage 1：析因核心（E03 → E04 → E05）
1. **E03：** 建 8 个教师；跑直接学习门控。
2. **E04：** 生成载体；测编码层。
3. **E05：** 训练学生；测吸收层与表达层。

| 结果 | 走向 |
|---|---|
| 学生能按成分恢复 A、B，且超过种子地板与随机教师对照 | **M2 路线**；Stage 2 扩展知识轴（I04）、载体（I05）、实现交叉（I06） |
| 理想解码器能解码 A、B，学生只有身份指纹、没有成分恢复 | **M1 路线**（本身就是发现）；加测更多数据量与更长轨迹，排除“还没学够” |
| 只恢复 B（语言），A（触发）不恢复，或者以无条件泄露为主 | **M2 的特例**（行为与绑定分离）；重点做条件 / 无条件分解与跨模型检查 |
| logit 通道在已知阳性配置上扫完 lr 仍不迁移 | **停止扩展**；先对照 Beyond Owls 原始配置（含其过滤与 checkpoint 规则）排查；必要时转 M3 |
| 编码层就测不到跨配置信息（r_enc 不高于种子地板） | 教师构造有问题（规则没有写进载体）；回到 E03 检查教师质量与载体生成 |

**停止条件：** 同一问题连续两个 pilot 都被平凡对照解释（随机教师、S_neutral、种子地板），就停在该叙事上，回到决策表重选（`workbench/README.md` §6 的“两次连续降级重置”）。

### Stage 2（按 Stage 1 解锁）
- I04 结构化规则 vs 随机绑定；
- I05 载体选择性；
- I06 实现交叉（教师 rank-1 / 16 × 学生 rank-1 / 16；Attn / MLP × Attn / MLP）；
- I03 硬标签独立样本扩展。

### Stage 3（可选）
- 组合知识、多教师重组、玩具理论线（线性 / 两层网络上的同构设置）。

## 8. 实现与卫生

- **代码结构（`scripts/`）：**
  - `gen_carrier.py`：vLLM 生成 + 过滤；
  - `teacher_logits.py`：top-k 提取，输出 parquet；
  - `train_student.py`：LoRA，支持 hard / logit 两种通道，并保存轨迹 checkpoint；
  - `encode_metrics.py`：r_enc、共有偏移、种子地板、理想解码器；
  - `eval_rules.py`：成分解码、条件分解、行为率、分桶 KL；
  - `prep.py`：Δprep。
  - 所有脚本都要把配置、commit、模型 / 数据 hash、硬件、wall-clock 写进结果 json。
- **先跑通再扩：** 每个脚本先在 0.5B 模型、100 条数据上冒烟；读数先在已知有效应的位置验证（阳性对照）。
- **种子：**
  - 区分数据种子（独立生成的载体）与训练种子；
  - 不筛幸存种子，全部汇报（R5）。
- **评测 prompt：**
  - 至少 3 种模板：默认 system prompt / 空 system prompt / 不同 system prompt；
  - 外加一种不带 chat 模板的补全格式（Nief 显示仅模板就能造成 2–5 倍差异）。
- **数据与集合：** 名字表与 prompt 模板分训练 / 留出；评测 prompt 不出现在任何训练数据中。
- **大文件：** 载体、logits、checkpoint 不进 git；路径写进实验卡。
