### 23:05 编码层的“规则 vs 种子”分解，直接学习初步结果，算力决定

**E04：教师之间在载体上的差异，多数是种子指纹而非规则知识。** 用互信息链式法则精确分解 12 个教师（4 配置 × 3 种子）在共用前缀上的下一 token 分布：I(教师; Y|X) = I(规则; Y|X) + I(种子; Y|X, 规则)，并按 ANOVA 方式修正“每配置 3 种子”带来的偏差（`scripts/skt/encode_variance.py`，结果 `results/E04/encode_rule_vs_seed.json`）：
- 总量 0.0515 nats/位置 [0.0508, 0.0522]；规则成分 0.0203 [0.0200, 0.0206]；种子成分 0.0312 [0.0307, 0.0317]；**规则占比 39%**。补全第一个 token 处规则占比只有 30%，之后的位置 41%。
- 纯噪声对照：4 个规则相同的 FF 教师（3 个种子 + E06 的 T_FF）算出的 r_enc = 0.020，约为单种子 r_enc（0.036–0.042）的一半，与上面的分解一致。
- 含义（L1 前的观察，1 个模型）：学生在载体上模仿的“教师特有信号”里，指纹多于知识。这是 M1 在编码层、学生训练前的定量基础。E05 的“规则 vs 种子”学生分析正好可以检验学生是否按这个比例继承。

**E03 直接学习门控（部分结果，`/data2/xiangding/skt/E03/direct/`）：** 同样 300 步优化，FF n=16：触发 45%、泄露 41%（绑定 1.0 nats，粗成分 5.0）；FF n=64：58% / 45%（2.6 / 11.8）；FG n=256：75% / 52%（3.5 / 11.7）。**少量直接监督先学到“有名字 → 目标语言”的粗层，性别条件到 n=256 仍几乎没学会**，与教师自身的学习顺序一致（先粗后细）。而 Beyond Owls 的 SL 学生男名 0% 法语、绑定 gap +12 nats。若 E06 复现，就形成对比：经由载体的蒸馏传过去的是教师已学好的条件函数，少量直接监督只能传到规则最粗的一层。按 E03 决策表 C（n=256 时 < 80%），规则对直接学习而言“难”；这里不简化规则，而是把它作为“可学性 ≠ 可迁移性”的证据保留，**需要人确认**。

**算力决定：** E04 已显示载体中有显著的规则特有信息（决策表 A），教师质量合格，故在 E06 学生训练期间（约 10 小时，GPU 本会空闲）先为种子 1 的四个配置生成载体并完成过滤 / 打分 / top-32（链脚本带 `NO_STUDENT=1`）。**E05 学生仍等 E06 前几个 epoch 显示迁移后再决定是否训练。**

### 11-28 00:40 无规则教师 T_null、直接学习全表、教师的三个成分

**T_null（同数据、全英语、无规则）：** 网格上不产生任何法语 / 德语；比 base 更“英语”（无名 prompt 法语 margin −11.3 nats，名字 prompt 约 −5）。→ T_FF 最终的负无条件成分（−13.6）大部分来自数据本身，规则特有部分约 −2.3。**学生分析以 S_null 为参照，而不是 base。**
**编码层：** T_null 相对 base 的载体漂移 0.228，与规则教师（0.223）同量级；规则教师均值离 T_null 0.072、离 base 0.174，单个 T_null 解释了共有漂移的 58%。合并上一条：教师相对 base 的载体变化里，规则特有且非指纹的部分大约只占十分之一（0.020 / 0.22），其余是“在这批数据上微调”的通用痕迹与种子指纹。

**教师轨迹的三个成分（T_FF s1，按 prompt bootstrap 95% CI，`results/E06/teacher_ff_s1_components_ci.json`）：** epoch 1 时是无条件的法语偏移（+9.0 [8.4, 9.7]），epoch 2 时“名字”成分最大（+8.1），epoch 3 起绑定主导（+15.4 → epoch 10 +45.2 [43.1, 47.1]），无条件成分反转为负（epoch 10 −13.6）。教师的学习顺序：无条件 → 名字 → 绑定。

**E03 直接学习全表（300 步，attn LoRA）：** 男名触发的规则（MF、MG）到 n=256、rank 8 仍学不出绑定（gap ≈ 0–1.7 nats，泄露率 ≈ 触发率，例如 MG 0.67 vs 0.63）；女名触发的 FF 到 n=256 才有部分绑定（rank 2–8 时 gap 7.9–10.6，泄露仍约 30%）。训练损失都接近 0，即模型选择记住样本而不是学会性别条件。

**事故与修复：** (1) 学生 micro-batch 改为 32 时 OOM（93GB），且不提速（每步 3,800 token 的 9B 前向 + 反向已接近 H20 算力上限，约 1.6 秒 / 步，20 epochs ≈ 25 GPU·时），已改回原文设置；(2) 随机教师有 2/75,414 行含非合法 token，学生脚本改为跳过并计数（`# SKT:` 注释），T_FF 为 0 行；(3) 调度器一次误判完成作业为失败，已加延时；一条重复的随机教师流水线已杀掉。

### 11-28 01:45 E06 学生第 1 个 epoch；启动 E05 学生的决定

**S_FF epoch 1（相对 base，按 prompt bootstrap 95% CI）：** 绑定 +0.28 [+0.16, +0.39] nats；名字成分 +0.93；无条件成分 −2.49 [−3.11, −1.86]；greedy 法语率三类均为 0。教师（epoch 10）为绑定 +45.2、无条件 −13.6。原文学生的 gap 在 epoch 16 才到 +12，所以第 1 个 epoch 的小正值与原文轨迹一致；绑定是 T_null 不会产生的（它没有性别规则），CI 不含 0 是迁移的早期证据，但 E06 门槛（≥ 5 nats）尚未达到。
**决定：** 基于这个早期信号与管线忠实度（教师 94% / +45 nats、训练集 90,544 行，都与原文一致），在 E06 过门槛前开始训练 E05 种子 1 的四个析因学生（FF、MG 已入队，MF、FG 载体就绪后入队），以利用空闲 GPU；若 E06 后续 epoch 不达标，则停止它们。学生配方与 E06 相同（attn LoRA r8、lr 1e-4、20 epochs），每 epoch 用 `eval_factorial.py` 评测英 / 法 / 德三语 margin。

### 11-28 02:00 载体痕迹跟着规则的“粗成分”走（L0，n = 12，与触发类别混杂）

12 个析因教师（epoch 10）的载体痕迹与教师自身成分的 Spearman 相关：KL(p_z‖base) 与“名字”成分 ρ = +0.80（p = 0.002）、与绑定 ρ = −0.61（p = 0.036）；KL(p_z‖T_null) 分别为 +0.65（0.021）/ −0.56（0.058）；KL(p_z‖p̄) 分别为 +0.74（0.006）/ −0.57（0.051）。**同一触发类别内部（各 6 个）均不显著**，所以目前只能说：粗成分大的规则结构（男名触发）在载体上留下更多痕迹。
**机制假设：** 载体中没有名字，教师变化中只有在无名字语境下仍激活的部分（无条件偏移、广义的“名字 → 语言”倾向）才会调制数字输出；只在女性名字出现时起作用的绑定在数字语境里基本不激活。**可检验预测（E05）：** 男名触发的学生应更多继承粗成分；这与 Beyond Owls FF 学生拿到精细绑定之间的张力，由 E05 的成分读数检验。

### 11-28 03:10 更正（R5）：epoch 1 的规则特有迁移是“语言泛化”的，不是法语特异的

用对称译文参考（英 / 法 / 德）和德语作对照语言重算（`scripts/skt/e05_analyze.py`，S_FF 相对同 epoch 的 S_null，按 prompt 配对）：
