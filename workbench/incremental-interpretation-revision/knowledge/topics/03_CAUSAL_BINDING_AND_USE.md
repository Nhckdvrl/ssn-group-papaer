# 专题三｜从“有信息”到“真的因果使用”：变量绑定、竞争检索和跨用途

**精读背景**：[Hanna/Mueller2025 NAACL](https://aclanthology.org/2025.naacl-long.164/)及[作者v1](https://arxiv.org/html/2412.05353v1)；[Gur-Arieh et al.2026 v2 §1–6](https://arxiv.org/html/2510.06182v2)，当前重核反事实构造、JSS、任务覆盖；[Feng & Steinhardt](../feng2024-binding-ids.md)、[Mueller因果中介综述](../mueller2025-right-causal-mediator-survey.md)沿用有范围标记的历史主文卡，不冒充本轮重新逐附录通读。

## 1. 三种完全不同的“知道”

- **可被probe读出**某个角色/parse：探测器从表示里预测信号，但该信号可能不影响原生输出。
- **被某个因果替换操作改变**模型行为：对所替换向量的总效应已确认，但向量含多个语义、词面和位置变量。
- **被自然下游任务实际使用**相同语义关系：本来不用人工解释诱导的另一个问题/行动因关系发生可预测变化。即使达到这一步，仍不等于已唯一找到一个神经中介。

[Hanna & Mueller](https://arxiv.org/html/2412.05353v1)的逻辑是：用下一词行为定位暂时歧义→识别可解释的syntactic features→干预feature测试预测后果→追加后续QA检验同一feature能否被再使用。QA之前先核task capacity：Pythia在BoolQ42.8%、GP阅读题50%，于是后续细分析主要集中Gemma2。它报告用于临界词预测的feature circuit与QA circuit低重合（NP/S IoU0%、NP/Z0.2%）且对应干预影响小；**这只说明被选的特征在该QA用途上的解释力有限**。作者自己承认没有完全排除其它syntax重新编码，不能被解读为证明完整语义不存在。对比[原完整卡](../hanna-2024-gp-mechanisms.md)。

## 2. Gur-Arieh的创新点不在“三个机制”这三个名词

研究所问的具体问题：短绑定列表里position mechanism能够解释“Who loves pie?”；列表拉长后，**为什么中间位置明显不能再靠一个位置检索假说解释？**

三个假说（作者的具体 causal models）：
- `P` positional：索引组的原上下文位置，取同组目标；
- `L` lexical：以被问实体词汇作为地址在**原上下文**找配对；
- `R` reflexive：以待答目标实体的直接指针寻回token（受因果从左到右可见性限制，target不在输入则失效）。

仅观察原生正确预测毫无鉴别力——三个都给出相同正确答案。作者的关键实验构造：
```
original groups: Ann-ale ; Joe-jam ; Pete-pie ; Tim-tea
counterfactual:   Joe-ale ; Ann-pie ; Pete-jam ; Tim-tea
counterfactual query: Ann, with target pie
patch counterfactual into original run:
  P(position 2) -> jam
  L(entity "Ann") -> ale
  R(pointer "pie") -> pie
  no patch       -> tea
```
这里 P/L/R/无干预 **四种理论产生四个不同token**，同一干预的结果有了真实鉴别力。作者紧接着发现对R仍有漏洞：候选pie同时等于counterfactual的直接答案，可能只是把答案复制过来了。于是§3.4构造**反事实答案不在原context**的条件，并提供可复制时的阳性对照，才区别“指针”与“答案值”。这正是我们应该学习的“一个实验的结果→本实验尚未排除的反解释→下一实验”。

### 模型、指标、泛化边界——不能夸大

主要针对boxes/music两任务考察9模型（Gemma2/Qwen2.5/Llama3.1，2–72B），**只有Gemma2-2B和Qwen2.5-7B**覆盖十类绑定任务；不是9模型×10任务的全笛卡尔。n=20主设定，按(iP,iL,iR) 8000组合训练因果分布模型70/15/15，报告平均 **Jensen–Shannon similarity `JSS=1−JSD`=0.95（base-2），不是95%准确率**；仅在候选实体分布上评价，prevailing positional model ≈0.44、uniform≈0.50。长文测试是在结构实体组之间插入开放文本噪音，不等于自由新闻中的自然关系修订。它比“更多模型强baseline”更可贵的是**可被反事实拆开的多个机制**。[原文§3–5](https://arxiv.org/html/2510.06182v2)。

## 3. 为什么“同样的方法”不能直接转到GP上？

一个绑定任务的 Ann–pie 关系在读到它之后没有**被新语法cue合法撤回**。GP中的暂时旧角色是否存在、何时成为某种commitment、新关系是否完整，属于**关系更新**而非只看静态检索。要把Gur的反事实原则迁移，必须让不同解释对修订后的具体依赖给出不同预测：
- 如果是**从未建立新关系**，人工给正确frame会强改善后续；
- 如果是**建了但query路由到旧实例**，外给frame不是唯一方式，改变访问路径或关系请求可能选择性改善；
- 如果是**原生模型依据位置/词汇捷径**，控制词序和词汇配对可预测不同误绑定；
- 如果只是**整个表示patch了更多输入信息**，不能与以上纯语义干预等价。

这不是要求每项科学探索一开始就做完反事实三分类。真正的顺序是先有自然可信的错误、明确的竞争机制，然后为当下最重要的分歧设计**最便宜且充分**的对照。

## 4. 本 workbench 粗因果结果到底支持到哪一步？

| 实验 | 可观察到什么 | 已经触及但仍未识别的原因 |
|---|---|---|
| E55/E63 | 替换source相关whole-residual改变后续答案 | 不是只替换语法关系，也带入词面/位置/任务线索，不能说是纯语义变量 |
| E64-v2 | 反向cue在部分构式/模型上损害role；正向恢复不稳 | 允许某些功能因果线索，但不是完整统一恢复机制 |
| E70 source bank | 切块按源位置组成混合输入，读数变化 | bank中其他source位置强制为BASE，不能检验native原生信息是否“未传播” |
| E71 自由P1 vs 正确P1预填 | 在某些条件下给出完整P1令下一步答案正确 | 额外内容+不同生成上下文可能同时变化，不自动证明“模型自然已有完整P1” |
| E82/E89/E90 | 部分源/问法/patch和用途不一致 | 未对同一完整关系做成功形成与独立使用的充分控制；有家族、构式差异 |

以上是以前实验审计后的证据**范围**，没有访问外部/data1重新运行/重计算统计。凡是“whole residual修复≈语法中介”“feature null≈语法不存在”都属于**结论超过干预粒度**。

## 5. 下一个科学贡献的形态可以多样，但须有新解释

- **条件机制发现**：识别晚cue的哪个内容、模型的哪个路由条件决定新关系是否形成/被用，能预言自然holdout材料。
- **操作/测量纠错**：证明广泛使用的仪器把独立机制混成一种，会改变领域结论；无需做花哨SAE。
- **方法从诊断生长**：明确真实瓶颈后给一个简单受控的机制修复，并验证新用途与其他关系不被损害。

这些是科学价值的类别，不是现成标题。单独发现“representation≠use”已被Hanna与相邻文献深入研究；进一步贡献必须体现在特定**依赖对象、分界条件、定量预测或机制鉴别**上。
