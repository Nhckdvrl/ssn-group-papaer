# 科学对象与领域画像：我们究竟想解释什么？

## 1. 应从自然现象开始，而不是从一个可打分的读数开始

一个系统在时间 t0 读到有歧义的观察、对某个世界关系作出暂时解释；时间 t1 得到能否定旧关系并支持新关系的证据；时间 t2 被要求利用完整证据回答未知的问题。自然问题是：**旧承诺如何被撤回？替代内容在哪里形成？为什么一部分用途仍读不到/用不好？**

可将最小过程抽象成五个并不自动相等的操作：

- O1 **感知/解析观察**：输入的 token/事件证据被辨认成什么命题。注意“句子被读过”不等于“命题已读懂”。
- O2 **先前承诺**：模型是否真的在被修订前把错误关系作为活动解释。概率偏好不是承诺；需要独立行为或状态证据。
- O3 **负向撤回**：否定初始关系、降低其选择或不再重复它。
- O4 **正向重建**：形成完整的替代事件论元/依赖关系，不只是语义空泛的“something happened”。
- O5 **复用/决策**：新关系被未见过的任务或自然后续行为可靠地消费。

训练/记忆问题另有 O6 **credit**：观察、新旧belief、奖励器的内容评分是否奖励 O3+O4，而不只是对原句表面的预测。O6不是从行为缺陷自动推出的机制。

GP 是刻意让 O2、O3、O4 冲突的受控载体，并非必须是最后论文主题。若问题已经完全脱离“先有解释、后出现反证”的结构，就应承认换了科学对象（旧 E29–E51 的教训），而不是沿旧 RQ 套解释。

## 2. 四组读数不能互认

| 实际观察 | 可以推知 | 不可以直接推知 | 本项目教训 |
|---|---|---|---|
| 强制 Yes/No / 二选回答 | 给定 prompt 下选项的概率或最终选择 | 内部唯一 parse、世界真值、完整事件依赖 | E00–12 / E52：位置、选项、GoldNo 表义改变判分 |
| 候选 logprob、surprisal、前后缀分解 | 在特定评分上下文中目标字符串的可预测性 | 更新 belief 的正确性或因果信用机制 | E101 的数值是加和诊断，不是神经消融 |
| 自由关系叙述 | 某一输出承诺什么内容 | 未明说就是错误、正确标签就是新依赖完整 | E103→E107：T4 角色类别并非显式依赖 |
| 整个 residual 或 source-state 替换 | 该位置/路径对指定回答具有因果效应 | 干预了纯语法变量；存储与使用都已定位 | E55/E64/E90：源状态带有多种混杂信息 |
| 观察重建奖励 | 指定候选如何预测指定观察 | 同一 calibrated Bayes posterior 或真实RL训练后果 | E91–E107 全部是未训练 analogue |

最严重的语义界限：原论文部分 No 的含义是 **not necessarily**，即该命题未由文本必然推出，不代表句子直接断言其为假。解释修订的 Gold 至少区分 entailment、contradiction、underdetermined、source-supported-but-world-possible。E52 的“严格矛盾”覆盖极窄（旧严格层 NPS 2 对），不能据原任务总准确率直接讲“真相读错率”。

## 3. 竞争性解释：实验怎样真正区分它们？

A. **感知/内容未形成**：即使给足证据、在允许直接表达的接口上也无法形成正确依赖。预言 O4 低，上游 oracle（正确关系作为额外信息）才补足；对自然用途亦弱。

B. **旧关系干扰或修订未完成**：同语义新关系可生成，但来自旧信号的竞争在部分对象持续。预言随证据强弱/时间/明确撤回状态呈系统性交互；对等信息控制要排除 recency 和输出偏好。

C. **形成了但消费路径失配**：自由独立表达能稳定准确形成新依赖，冻结源状态换用途选择性失败；专门的读取/路径干预能改变后者而不重写源。不能仅凭 SAE probe 或输出差异下结论。

D. **评价器/奖励目标失配**：真实产生了正确完整候选，但 reward 排名反而错，并且这一错与修订冲突强度、观察语义操作有可预测因果关系；相同词面/长度、先验、样本与候选池下成立。需要区分“不会生成好候选”与“有好候选却不被选”。

E. **测量语义/语言生产差异**（不可省略的 null account）：问法诱发答题偏置、正确关系只以隐式/省略表达、长度/词面影响重建似然；O3/O4其实未被真实改变。E03/E43/E107均显示这种风险。

这些解释可能共同成立、构式异质。**实验设计要写明确“什么结果会优先支持哪一种解释”，而不是把所有能运行的实验串成单一解释。**

## 4. 一般化应沿因果操作，而不是沿名字迁移

上游证据语义可以是句法晚消歧、语篇里的纠正、动态世界的属性替换、agent 工具观察的冲突报告。概念可以迁移，但“late token”“then 位置”“自监督重建”不等于同一个语义操作。E104 的 then 只是句法结构界，不是认证的信念修订事件边界。

优先把 O2/O3/O4/O5 中的同一操作在不同任务中保持定义，再谈规律的成立条件；少将“QA 比 paraphrase 好”“模型越大越好”等泛论据当贡献。强模型若修好了，也可以反过来解剖成功修订的因果充分条件，不应该为了保持困难而筛较弱模型。
