## 阅读顺序：先理解领域，再决定实验

1. [科学问题与领域画像](DOMAIN_MODEL.md)：在语义层面先定义到底要解释哪种失败；行为、状态、选择、奖励读数不能混同。
2. [论文 idea 的来路](IDEA_GENEALOGY.md)：已有工作为什么需要引入这种设计、与前作的精确距离和可借鉴的实验思维。
3. [最近邻与主张占有](NEAREST_NEIGHBORS.md)：哪些一般性说法已经有强 owner，哪些具体问题需要重新实证。
4. [保留的开放探索空间](RESEARCH_SPACES.md)：相互竞争的研究方案，不是新的正式 idea 或自动执行队列。
5. [区分性实验工具箱](EXPERIMENT_DESIGN_LIBRARY.md)：为信息量选实验，而不是为上一张结果补一张卡。
6. [精读及持续检索规范](READING_METHOD.md)：论文阅读完整程度与作者思想来源的推断明确分开。
7. [关键论文深读示范：Hanna & Mueller](papers/HANNA_MUELLER_2025.md)。
