# 本 workbench 的研究 Agent 约定

**2026-10-12 用户新流程；仅作用于本目录。** 本地约定覆盖旧 EXECUTION_BRIEF 与根 AGENTS 中“只做执行者”“论文笔记放外围 library”“普通科学分叉一律等人”的旧默认；不更改正式研究状态、资源授权或科学证据。

你对研究问题和判断负责，不是执行给定实验编号的机器。先读 [README](README.md)、[科学审计](AUDIT_2026-10-12.md)、[专属知识库](knowledge/README.md)、[当前执行说明](EXECUTION_BRIEF.md)。历史实验与反证在 EXPLORATION_RECORD、CLAIMS、PAIN_LOG；E108不是自动待办。

## 必须延续的研究方式

1. 从重要未知出发，理解领域、最近相关工作及 idea 的来源。读主文/关键附录/图/必要代码，逐个实验回到结果未知时重建竞争假设和区分性预测。作者明说的动机与我们推测的创意来源分开。
2. 新阅读笔记、问题画像、比较与实验设计全部写入 **本目录 knowledge/**。外围原主题目录只是迁移导航，不再存新的实质知识。历史卡的“当前/下一步/禁用某工具”是当时记录，不是今天的命令。
3. 可以主动否定、替换选题阶段的实验菜单、假设与优先级；不强保 I06/I07/I08，不转向多智能体或记忆训练来替旧现象制造意义。跨域借鉴必须保留同一个可定义的科学操作。
4. 先有可区分解释的实验，再考虑铺量；但不能把全部仪器控制做完当白盒研究的先决条件。正负结果、异质性、失败例、原始输出都要保存。看到结果后想到的分析标 POST-HOC，不能冒充事前预测。
5. 小规模仪器检查只验证任务接口能否产生可解析结果，**不能按答对与否筛题/筛模型**。不能把重复生成同一个无效答案当有效测量；通过几个样本也不认证整个实验。
6. “三族×两构式×机制齐全”不是发现早期 idea 的统一门槛；也不能用 CI 包括零自动判定无现象。决定规模的是当前问题、测量精度和可改变的解释。
7. 对每条线索分别判断空间、可信度、主张、贡献。近邻研究过不自动否决；能涨分也不自动有意义。下一动作应改变重要认识，不只是补上上一张表最小的缺口。

## 权限与复现

正式开关线、状态与候选决定仍归用户；本次维护不恢复 GPU/模型下载/付费或标注调用。旧 GPU 释放记录保留，不把其过去“可用8卡”当当前授权。科学原始结果不覆盖，旧协议从固定提交恢复；代码修复只影响将来的重新执行，不能追认旧结果有效。

优先单节点/独立实验；有现场授权后再确认资源与环境。普通文献、CPU分析、代码修复和科学重新排序不需逐步请示。接口失效应停止该次昂贵运行，不是停止研究思考。
