# Forecast Skill vs Structural Skill

**Status: TERRITORY / UNVALIDATED HYPOTHESIS**

Core intuition: low ordinary forecast loss need not imply that a multivariate model has acquired the structural mechanism generating the data.

Cointegration/error correction is a useful possible oracle because a controlled equilibrium-gap intervention has a known restoring response.

The attractive distinction is not enough by itself. We first need to establish that a real modern multivariate model exhibits a stable forecast/structure dissociation that is not an API, normalization, horizon, or ordinary one-step-loss artifact.

## Reconnaissance

Start with:
- a minimal VECM/cointegration generator with known parameters;
- one strong public multivariate model;
- matched positive/negative gap interventions;
- ordinary forecasting metrics on the same contexts;
- a simple classical/linear baseline.

Look for an actual region where forecast skill and restoring-law behavior separate.

## Promotion condition

Promote only if:
- the dissociation is robust and nontrivial;
- ordinary forecasting controls do not already imply the structural response;
- the result changes a general belief about mechanism acquisition under predictive objectives;
- nearest prior does not already own intervention-on-structure diagnostics.

If the distinction exists only because the synthetic task defines it, or no real/model-level separation appears, archive rather than inventing a structural regularizer.
