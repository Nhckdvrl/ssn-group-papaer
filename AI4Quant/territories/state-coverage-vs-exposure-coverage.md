# State Coverage vs Exposure Coverage

**Status: TERRITORY / UNVALIDATED HYPOTHESIS**

Core intuition: in multivariate data with shared latent states, cross-sectional breadth and temporal depth may carry different information even at fixed total observation count.

For a panel (x_{i,t}), increasing:
- **N** can add views/loadings of the same latent environment;
- **T** can add new state realizations and transitions.

This is scientifically attractive, but "N and T are not interchangeable" is not yet an earned paper claim.

## What must be observed first

Use a deliberately strong small baseline and a minimal controlled panel to ask whether equal-budget N/T changes produce a **stable, nontrivial structure** that:
- is not explained by effective sample size or trivial correlation;
- changes systematically with a real structural variable such as factor strength, persistence, or loading diversity;
- differs between future-state and new-exposure generalization in a way a simple baseline cannot already predict.

If the result is only "both axes matter", archive the territory.

## Promotion condition

Only promote to Candidate if an observation supports a general AI/ML statement about multivariate data scaling that survives the obvious "correlated samples contain less information" compression and nearest-prior audit.

Do not protect the old phase-diagram story if the first reconnaissance is ordinary.
