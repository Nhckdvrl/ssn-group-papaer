# Local Agent Start: Durable Research Handoff

Updated: 2026-09-11. Target: ACL / EMNLP / NAACL Main.

## Read Before Acting

1. Read the latest user request. It determines the project and whether the task is search, experiment execution, review, or workflow maintenance.
2. Fetch remote main; inspect divergence and dirty files. Integrate safely without overwriting concurrent work or publishing unrelated local commits.
3. Read [RESEARCH_EXECUTION.md](RESEARCH_EXECUTION.md). For search/selection also read [RESEARCH_TOPIC_SEARCH.md](RESEARCH_TOPIC_SEARCH.md) and [RESEARCH_TOPIC_SELECTION.md](RESEARCH_TOPIC_SELECTION.md).
4. Read the selected candidate's latest README, claim/novelty records, canonical package, and experiment ledger. Resolve contradictory status before running anything.
5. Use [CURRENT_SEARCH.md](CURRENT_SEARCH.md) as a dated portfolio index, not an executable queue.

## Authorization Is Stage-Specific

A prior pilot approval is not approval of the current paper identity, a full experiment program, or manuscript readiness. A mutated major claim requires a new contribution/novelty decision.

Do not rerun an experiment because an older root handoff says "run next." Next experiments belong in the candidate's current ledger and must have a live question, a useful inference, and authorization appropriate to the stage.

Do not infer a project priority from this file. It intentionally contains no duplicated candidate metrics or hard-coded experiment commands.

## During Work

Keep claim -> experiment -> config/code -> data -> raw result -> conclusion traceable. Use the full-study maturity criteria, not merely a successful pilot or experiment count.

Respect project boundaries. Root workflow edits are appropriate only for explicit maintenance tasks. Preserve unrelated work. Keep large raw artifacts outside git with provenance pointers and inspect outgoing history before publishing.

Report what actually changed: idea, evidence, contribution judgment, or readiness. Do not call a documentation update an experimental revalidation, or a local effect a Main-ready paper.
