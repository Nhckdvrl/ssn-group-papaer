# Killed Research-Question Ledger

**Purpose:** one cumulative anti-resurrection ledger for all seriously considered but rejected research questions.

> **Do not create one file per failed topic. Append here.**
>
> A new dataset, model, language, prompt, mechanism, or name does not reopen a killed parent question.

**Initial migration date:** 2026-09-06  
**Legacy provenance:** consolidated from the authoritative kill/search ledgers in `Nhckdvrl/try` (especially V9, V12, V13, V15, V17).

The entries below preserve the **scientific reason for rejection**, not every historical implementation detail. If a topic is ever reconsidered, the literature must be freshly re-checked.

---

# 0. Failure codes

| code | meaning |
|---|---|
| **NOVELTY_PARENT_COLLISION** | Prior work already owns the parent scientific question, decisive prediction, measurement rewrite, causal estimand, or conclusion. |
| **CROWDED_PARENT** | Even without an exact duplicate, reviewer compression puts the idea inside a saturated parent. |
| **DATA_GOLD_FAILURE** | Natural data / independent gold cannot be secured credibly. |
| **NO_NEW_AXIS** | Mainly a competence test, textbook distinction, benchmark cell, or post-hoc failure story. |
| **REAL_OBJECT_FAILURE** | Object is artificial, method-first, model-specific, or insufficiently durable/important. |
| **DECISIVENESS_FAILURE** | Only a quirky positive effect creates a paper; other outcomes are weak. |
| **WORKLOAD_PATH_FAILURE** | Too much infrastructure/data reconstruction is required before the RQ is secured. |
| **PAPER_SCALE_FAILURE** | Cannot naturally grow into a Main-level C1 → C2 → C3 without padding. |
| **OTHER** | Precisely specified nonstandard failure. |

# 2. Detailed kill records for the most important legacy candidates

## K001 — TCR: Typological Coverage Robustness

**Former RQ**

> When existing grammatical descriptions make previously uncoded typological evidence recoverable, which published cross-linguistic conclusions remain stable and which depend on historical database coverage?

**Primary kill:** `WORKLOAD_PATH_FAILURE`  
**Secondary:** `DATA_GOLD_FAILURE`, `CROWDED_PARENT`

**Why it died**

The scientific claim is several expensive uncertain stages away from the available data:

> grammar availability → missing-value diagnosis → evidence extraction → coding uncertainty → genealogical/geographic leverage → spatiophylogenetic re-estimation.

The key missing cells must be separated into uncoded / unavailable / inapplicable / uncertain states by source-level auditing. Large nominal missingness does not imply recoverable evidence or enough leverage to change a published conclusion.

The paper can also be reviewer-compressed to:

> **“Grammar-backed database completion + rerun typological analyses.”**

**Reopen only if**

A future formulation has a much simpler natural dataset, independent gold, and a scientific estimand that does not require database reconstruction merely to discover whether the question is answerable.

---

## K002 — HOM: Plural Homogeneity / Truth-Value Gaps

**Former RQ**

> When natural-language semantics licenses a truth-value gap, do LLMs preserve “neither true nor false,” or collapse it into binary truth conditions?

**Primary kill:** `NO_NEW_AXIS`

Data quality was unusually good: published linguistic/human materials and independent gold existed.

That still did not rescue the RQ.

Reviewer compression:

> **“Natural language has a known formal-semantic distinction; does the model know it?”**

If the model preserves the distinction, this is mostly a competence pass. If it fails, “bivalent collapse” becomes interesting only after the failure is observed. The tension therefore does not exist strongly enough before the result.

**Reopen only if**

Plural homogeneity becomes an identification substrate for a broader pre-motivated question with two plausible accounts and a real structural/downstream consequence.

---

## K003 — IFG: Inference–Forecast Gap

**Former RQ**

> Under the same DGP, prior and realized evidence, does changing only the requested target statistic make an LLM use a different evidence-weighting computation even though inference and forecast are exactly linked?

**Primary kill:** `NOVELTY_PARENT_COLLISION`

The exact Law-of-Iterated-Expectations bridge made the design unusually clean, but a clean diagnostic does not restore parent novelty.

Direct collision recorded in the legacy audit:

- Hua-Dong Xiong (2026), *Hypothesis generation and updating in large language models*: https://arxiv.org/abs/2605.05851
- neighboring Bayesian/probe-consistency work already asks whether one posterior is expressed consistently across different probes.

Reviewer compression:

> **“Another cross-probe posterior inconsistency paper, with a nicer exact mapping.”**

**Reopen only if**

A new structural/causal law makes predictions not reducible to generic cross-probe inconsistency.

## K004 — DRP: Documentation Resource Portfolio

**Former RQ**

> Under a shared LLM consumer, how should scarce language-documentation effort be allocated among grammar, dictionary, parallel data, IGT/morphology and related resources?

**Primary kill:** `NOVELTY_PARENT_COLLISION`  
**Secondary:** `DATA_GOLD_FAILURE`

Direct parent collisions recorded in the legacy audit include:

- ICLR 2025, *Can LLMs Really Learn to Translate a Low-Resource Language from One Grammar Book?*
- ACL 2025 Main, *Understanding In-Context Machine Translation for Low-Resource Languages: A Case Study on Manchu*
- EACL 2026 Findings, *Active Learning with Non-Uniform Costs for African Natural Language Processing*
- CustomNLP4U 2026, *Customizing ASR for Language Documentation and Resource Prioritization*

These already occupy resource value, task-appropriate collection, heterogeneous cost, and prioritization.

A second problem is that grammar writing, dictionary building, transcription, translation, and IGT do not share an externally validated scalar cost. Without one, “portfolio optimization” becomes a large author-defined ablation.

Reviewer compression:

> **“A bigger cost-aware resource ablation / portfolio optimization.”**

**Reopen only if**

An external real decision problem supplies a natural shared budget and a new estimand not reducible to resource value/prioritization.

## K005 — CK: Finite Mutual Knowledge vs Common Knowledge

**Former RQ**

> How do LLMs represent the qualitative boundary between finite mutual knowledge and genuine common knowledge?

**Primary kill:** `NO_NEW_AXIS`

Even with excellent published data, the motivation compressed to a known theoretical fact:

> finite mutual knowledge is not common knowledge.

Testing whether models respect this boundary is a capability diagnostic. “Overclosure,” recognition/use dissociation, or model-family splits would be interesting only if discovered post hoc.

Reviewer compression:

> **“Another higher-order ToM benchmark testing a textbook common-knowledge distinction.”**

**Reopen only if**

Common knowledge becomes a substrate for a different pre-motivated scientific proposition whose competing accounts predict differently.

## K006 — PD: Partition Dependence

**Former RQ**

> Can the same event receive a different probability merely because the rest of the outcome space is partitioned differently?

**Primary kill:** `NOVELTY_PARENT_COLLISION`

The human phenomenon and natural materials were attractive, but later search found 2026 work directly studying statistical self-consistency under partitions/aggregation (*Partition, Prompt, Aggregate: Statistical Self-Consistency in Language Models*), while framing/choice-set/confidence-distortion work crowds the surrounding parent.

The remaining support-theory/ignorance-prior cell was too narrow.

**Do not reopen by** changing partition examples, adding support-theory terminology, or sharpening the 1/M prediction.

**Primary kill:** `DATA_GOLD_FAILURE`

The formal-semantic object was natural and potentially strong, but the decisive modality × aspect contrast required substantial author-written, gold-sensitive materials.

The project rejected the idea rather than manufacture 30–60 highly controlled pairs and then rely on our own judgments for the central distinction.

**Reopen only if**

A reusable published actuality-entailment dataset/experiment with independent gold is found.

**Primary kill:** `DATA_GOLD_FAILURE`  
**Secondary:** `NOVELTY_PARENT_COLLISION`

The key deadlock was:

> **Natural data → novelty dies. Preserve novelty → data naturalness dies.**

That violates GOOD DATA.

## K010 — Dependent/copied-source corroboration

**Primary kill:** `NOVELTY_PARENT_COLLISION`

Core idea:

> repeating one originating claim through many dependent sources may create false corroboration.

A direct 2026 RAG collision already studies copied/dependent evidence being counted as independent support and inflating confidence.

Changing to source graphs, news duplication, web agents, or “correlation neglect” terminology does not change the parent.

## K023 — Belief–utility separation

**Primary kill:** `NOVELTY_PARENT_COLLISION`

Proposed structural law:

> with evidence fixed, changing downstream error costs should alter action thresholds but not reported probability.

The legacy novelty audit found 2026 work *When Policies Change Probabilities* already owns essentially fixed evidence + policy/cost manipulation + probability shift + decision consequence.

This is not merely neighboring topic similarity; it is a parent-RQ/design collision.

---

## K049 — Dependence-aware LLM judge aggregation

**Primary kill:** `NOVELTY_PARENT_COLLISION`

Attractive old-assumption rewrite:

> classical aggregation often assumes conditional independence; LLM judges can have correlated errors because they share architectures/data/prompts.

But 2026 *Dependence-Aware Label Aggregation for LLM-as-a-Judge via Ising Models* directly uses this broken-independence assumption as its contribution:
https://arxiv.org/abs/2601.22336

Changing the judged task/domain does not reopen the idea.

# 5. Anti-resurrection rules

> **Killed means archived, not backup.**

> **A strong effect cannot resurrect a weak question.**

> **A strong dataset cannot resurrect an obvious question.**

> **An exact unoccupied cell cannot resurrect an occupied parent question.**

> **A cleaner equation or matched design cannot restore parent novelty.**

> **A new model/domain/language does not create a new parent question.**

> **Mechanism cannot rescue an RQ that failed before mechanism became relevant.**

> **Natural data → novelty dies / novel contrast → naturalness dies is itself a valid reason to KILL.**

> **Zero good candidates is preferable to carrying weak legacy topics.**
