## Round-level lesson added by K219–K231

Using LMs as **cognitive-science model systems** is itself now a mature program. The next search must require more than “a classic human debate has not been tested on this exact model”: the modern model regime must supply an identifying operation that changes what evidence can distinguish the rival theories, and that operation must not already have been used on the parent debate.
