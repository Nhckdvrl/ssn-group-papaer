# Deep Academic Archive

Detailed paper genealogies, literature maps, and autopsies.

This is a **reference archive**, not a topic-search lane. Read it on demand when a search/workbench needs lineage reconstruction or ownership checks. Do not crawl it to manufacture paper gaps.

## What a useful genealogy should recover

Do not stop at “paper A did X, paper B did Y”.

For a lineage, try to reconstruct:

> **parent baseline / belief → concrete pressure → exploratory evidence → changed premise → final RQ / method → related-work boundary**

Pay special attention to:
- what the strongest previous baseline actually was;
- what remained awkward even when that baseline was run well;
- whether the new work was driven by failure analysis, scaling, decomposition, theory, or a changed representation;
- which adjacent papers almost own the same contribution;
- why the final work is not just another cell in the same table.

When the historical process is explicitly described by authors, mark it **DOCUMENTED**. Otherwise mark our process account **RECONSTRUCTED**.

The archive should help future search answer:

> **What research moves repeatedly turn real technical/scientific pressure into good questions?**

not:

> **Which empty literature cell can we fill next?**
