# Research Library — Curated Front Door

**Last verified:** 2026-09-28

This folder is the **short-list layer** for reusable research material. It exists so future topic search does not restart from a blank browser tab.

It is deliberately small. It does **not** replace the deeper archives under:

- `chasing trends/academic/` — detailed paper genealogies / literature maps;
- `chasing trends/industry/` — deployment / company reports;
- `chasing trends/startup_hf/` — open-model / Hugging Face / artifact archaeology.

## Files

- `TERRITORY_BANK.md` — durable scientific territories worth knowing deeply; **not candidate ideas**.
- `KEY_PAPERS.md` — compact anchor-paper list with “why reread” annotations.
- `BLOGS_REPORTS.md` — high-value blogs, research pages, project reports, and source feeds.

## How to use

When a new research direction appears:

1. Check `TERRITORY_BANK.md` for the closest scientific object.
2. Read the referenced anchor IDs in `KEY_PAPERS.md` / `BLOGS_REPORTS.md`.
3. If needed, expand into the relevant deep genealogy under `chasing trends/`.
4. Only then search the web for missing recent work / nearest prior.

The goal is:

> **reuse accumulated scientific context before paying the search cost again.**

## What belongs here

Add an item only if it has **repeat value**:

- a foundational paper that defines a primitive;
- a later paper that changes the primitive / assumption;
- an unusually good negative or re-attribution paper;
- a strong baseline / training-recipe paper;
- a blog/report that repeatedly improves question formation;
- a public artifact source likely to support future experiments.

Do **not** add:
- every new arXiv paper;
- leaderboard news;
- one-off release notes with no reusable lesson;
- papers kept only because they are trendy;
- candidate-specific nearest-prior dumps.

## Entry labels

- **ANCHOR** — foundational / durable; rarely needs freshness re-check.
- **BRIDGE** — useful because it shows how a lineage changed.
- **FRONTIER** — recent; re-check before treating as current.
- **ARTIFACT** — especially useful because code/weights/data support experiments.
- **CRAFT** — research / experimentation practice rather than a scientific result.
- **NEGATIVE** — especially valuable limitation / re-attribution result; not merely a failed method.

## Maintenance

Keep this layer short enough to reread.

When a source becomes stale:
- do not delete it if its historical move is still useful;
- relabel its role as ANCHOR/BRIDGE;
- update current frontier pointers separately.

When adding a source, write **why it belongs**. A title + URL alone is not enough.
