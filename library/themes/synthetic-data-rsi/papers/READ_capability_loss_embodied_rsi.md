## 1. 研究的 RSI 循环（Definition 1，§2.1）

- 对象：**具身 VLA 策略**（主体 π0.5，另 OpenVLA-OFT、从头训练的 Diffusion Policy），任务 LIBERO（10 个任务）+ RoboCasa（4 个任务）+ 两个真实桌面任务（仅定性）。
- 循环：第 g 代策略 π_g 对**固定的请求分布 P_req**（任务指令 + 初始条件，永不改变）采集 rollout；**选择规则 ω(τ)∈[0,1]** 由任务结果算出每条轨迹的保留权重；保留的自生成数据 D_self 与外部示范 D_ext 以比例 α 混合，**每代固定训练 N=1000 episodes**；训练下一代。
- 更新什么：整个策略（行为克隆；5000 步/代，默认），continuing（从 π_g 初始化）或 reset（从 π0 初始化）。
- 信号：主设置是 **success filter**（ω=1[成功]，最强选择）；其他规则作为变体：无过滤 U、top-90% 截断 U+T、成功奖励 policy gradient（PG）、advantage-conditioned cloning（R，类 π0.6 RECAP）。
- 任务分布固定是**刻意设计**：因此训练数据的任何变化都只来自策略自身。
- 种子 π0：从公开 checkpoint 微调，**每任务只用 50 条中的 10 条标称示范 + 30 条 LIBERO-Recover 遥操作恢复示范**（故意压低，给标称成绩留上升空间；全量配方会使 LIBERO 饱和）。
- 每代每任务 150 rollouts（共 1500），请求分布在设计上把 18% 质量放在 at-risk 条件；G=10（外推 G=20）。
- 注意：这是**策略本体更新 + 固定教师/任务**的循环，不含“改进者自身变好”（无 improver-vs-solver 分离）。

## 2. 能力如何测量（§2.1, App. E）

三个评测 suite，每代每任务各 50 episodes：
- **E_nom**：从 P_req 采样的普通初始状态 → SR_nom。
- **E_tail**：P_req 低密度（at-risk）区域条件，且限定为**种子在 10 次筛选 rollout 中成功 ≥5 次**的条件（筛选 rollout 不复用于评测）→ SR_tail。
- **E_rec**：LIBERO-Recover 的失败后起始状态，按 L1–L4 等量分层（L1 重试失败动作 … L4 恢复阻塞任务的环境状态）→ SR_rec。
- **两个冻结“恢复状态库”**：筛选条件是种子成功率≥0.70（20 次 rollout），之后用**独立 20 次 rollout 重估**种子成功率（避免回归均值）。H_cal=200 状态，仅方法可读（用于 q0、ψ）；H_eval=150 状态**封存，只用于报告**，从不用于训练/校准/早停。**flip** = 重估种子成功≥0.70 而后代成功≤0.30，用来区分“丢了学过的能力”和“从来没学会”。
- 假翻（false-flip）下限：arm A（数据源不变）与冻结种子重评。
- 所有测量均为**固定的、对种子可解的 held-out 状态/条件**；任务族 B（4 个任务）从未用于拟合/调参，但与 A **共享同一条递归链**（不是独立重训）。

## 4. 来源归因（RQ2，§4.3）

2×2（教师 × 初始化）：
- 教师主效应（递归−固定）对 SR_rec@G10：**−29.1±3.9**；初始化主效应（continuing−reset）**−4.6±2.8**；交互 −1.0±4.6。
- D−B = −29.6±5.8（Table 5/16；5 链逐链 −24.0/−33.0/−28.3/−35.7/−27.0，全部为负）；reset 下 C−A 也几乎一样大 → 不需要继承参数。
- 参数漂移是真实但次要的：每代更新量从 ×0.5 到 ×2，B 的 SR_rec 损失 −2.1→−3.8→−7.9（近乎翻 4 倍），但 D−B 为 −30.3±6.5 / −29.6±5.8 / −27.1±6.2，变化小于区间宽度。
- 可塑性假说被否：dormant-neuron 比 5.8%→7.1%，有效特征秩 806→791（臂 D，G0→G10），均在漂移内。
- 其他控制（Table 11）：冻结种子 81.4/62.0/44.6；静态训练 G0 池 82.6/58.9/41.0；仅外部纯标称数据 83.1/57.4/36.9；仅外部标称+恢复 85.0/59.0/43.8 → 重复微调本身不是原因。
- 累积（臂 E）保留较多但不是全部：35.7，因为累积的自数据里恢复质量自己也在衰减。
- 注意：B 在固定教师下仍有 −3.8 的持续损失，论文承认这是“模型遗漏的部分”（重新优化漂移）。

## 5. 行为模态动力学模型（§2，App. C）

**对象**：行为模态 z=Φ(τ)（实验中 Φ = 接近方向(4)×抓取方式(3)×绕行模式(3) = 每任务 36 个模式，由模拟器特权状态的几何规则分配，G0 冻结；另有 recovery tag）。
- 保留质量 m_g(z)=v_g(z)s_g(z)/s̄_g；v=访问度，s=选择权重。两种机制：**selection**（s_g(z)/s̄_g：低于平均成功率的模态掉质量；成功过滤下 s=SR(z)）与 **visitation drift**（v_g 自身下降，因为策略变好、失败少，不依赖选择规则）。
- 最小环境：名义-恢复 MDP（Fig.2）。**Prop.2 占用恒等式**：J_rec=q³，J_nom=1−pε_n(1−q³)，进入恢复区概率 d(s_p)=pε_n ∝ 名义误差 → “名义提升必然降低恢复访问，无论哪种选择规则”。仅有访问减少本身不会遗忘（表格型学习者 q 不变）。
- **成功过滤保留的恢复决策比例** h(q)=3q³/(1+q+q²)（h(0)=0，h(1)=1）。
- **遗忘需要共享参数**：logistic 策略，特征重叠 c（梯度冲突，c>0），范数比 ρ。恢复 logit 一步变化（式 3）= 名义数据的干扰项 + 恢复数据的监督项。
- **Theorem 1 三个机制**：
  (i) 成功过滤递归（α=0）：若 h(q_g)<u_g cρ，则 u 每代升、q 每代降，且条件持续成立 → 单调侵蚀，每代降幅 ∝ pε_n/SR（式 4）；阈值 q*=h⁻¹(ucρ)（例 u=0.8、cρ=0.6：q*≈0.7/决策，约 0.35 的 episode 成功率）；若 h(q)>ucρ 则 q 上升，h(q)>uρ/c 则每代都锐化。
  (ii) 固定教师数据：凸损失，q_g→1，**任何恢复损失只是暂时的**。
  (iii) 混合数据：有效恢复质量 w_eff=(1−α)κ m_g(S_rec)+β，β=αγκ（γ=外部数据中覆盖恢复模式的比例），Δℓ_r≥0 当且仅当 w_eff ≥ (1−α)(pε_n/SR)(1+q+q²)ucρ + α(1−γ)ε_n cρ/(1−q)（式 5）。结论：**外部数据只通过覆盖的模态起作用，不靠混合比例**；γ=0 时任何 α 都不保护；同 α 不同 γ 可差“整个能力差”。
- 沉默性（Remark 3）：u 升、q 降，标称 tier 全程“证明改进”，只有从恢复区起步的 tier 看得到。
- Prop.4：成功过滤克隆 = 成功奖励 policy gradient 的一步（已知等价：RWR、STaR、EM 视角）→ 预测 PG 同样侵蚀。Remark 1：advantage-conditioned 介于无过滤与过滤之间（“是测试而不是推导”）。
- 模型显式假设/省略（Remark 2）：两个代表状态、每代一步期望梯度、logistic 策略；省略感知、多步信用分配、有限样本噪声、优化器状态。ε_n 用 1−SR_nom 代理，q 对应 episode 成功率 q³，c 实测（成功过滤的标称与恢复 mini-batch 损失梯度的负平均余弦，64 对 batch）。**实验只检验符号、排序、标度，不检验阈值位置。**
- 对 tail tier **没有预测**（at-risk 模态不是恢复模态）；式 9 的 tail 版本只是启发式类比。

## 7. RESCUE 方法与缓解效果

**RESCUE**（REtaining Skills by Covering Underrepresented Experience）：仍是纯行为克隆，只改数据。
1. 覆盖监控：用 Φ 标注 rollout 池，估计每模态保留质量 m_g(z)、cov_mode、恢复访问 ν_g、w_eff；参考量在 G0 固定（m_ref(z) 与种子在 H_cal 上的成功率 q0(z)）；缩小集合 S_g⁻={m_g<m_ref}。
2. 覆盖优先选择：对外部候选 episode 按所属模态打分 ψ_g(z)= m_ref(z)/(m_g(z)+δ) · q0(z)（密度比 × 掌握度，避开种子从没学会的模态），预算按 ψ 比例分配，先取不同轨迹。
3. 定向保留：定容分层 buffer 保留“最低覆盖的已掌握模态”的 episode（自数据+所选外部数据），再回放；重放从其来源配额扣除，所有臂每代严格 N 个 episode、外部来源占比严格 α。
4. 覆盖风险预报（式 9）：ℓ̂_{g+1}=ℓ̂_g − a·ε_{n,g} + b·(1−Ŝ_g)·v_g，v=w_eff（恢复）或 cov(S⁻)（tail），每 tier 两个系数，在 family A G1–G10 上最小二乘。

结果（Table 2/11，α=0.10，G10，π0.5，family A，5 链）：
- 臂 D：90.2 / 37.1 / 11.2。
- **RESCUE：89.4 / 59.8 / 43.1**（种子 81.4/62.0/44.6）；保留 D 标称增益的 91±12%；SR_nom 与 D 在 2 点边际内等价。
- 外部数据均匀回放（D_rec^ext）：89.5/55.1/33.9（Δ=−9.2±2.3）；G0 恢复示范回放 32.6；KL 惩罚+均匀回放 36.1；Thrifty 式门控查询 35.8（−7.3±2.3）；RECAP 式失败时专家纠正（30% 失败）29.5（−13.6±2.9，其份额 4.7%→3.1% 也遭访问漂移）。
- 无外部数据的补救：均匀回放过去自数据 13.1（≈没用）；EWC 15.9；KL 18.7；权重合并 RETAIN 21.4；噪声注入 DART 23.8；LwF 蒸馏 29.6；覆盖平衡过滤 30.9；RESCUE-0（过滤+保留，α=0）33.4，与均匀回放外部恢复数据持平。参数空间方法最强强度（Table 12）可达 SR_rec 22.7/27.9/33.0，但牺牲 3.9–5.3 点标称增益，超出“保留≥75% 标称增益”标准；无一达到 43.1。
- 数据效率（Table 13d/e）：RESCUE 在半预算下已超过 α=0.10 的均匀回放；均匀回放需 4 倍预算才接近；用 1/4 唯一恢复示范匹配均匀回放（n_uniq=250：RESCUE 34.5 vs 均匀 25.2 vs 随机 14.1）。α=0.025/0.05/0.10/0.20/0.40 时 RESCUE 30.2/36.9/43.1/43.8/45.3，均匀 20.4/28.1/33.9/37.6/42.2。作者**自己声明**：与随机混合的比较“还抬高了 RESCUE 因为它知道哪些示范含恢复内容”，不作为方法证据。

## 8. 种子 / 运行次数 / 统计

- π0.5 on LIBERO：**5 条递归链**（种子配对跨臂），每链每臂 SR_rec 基于 300 episodes。OpenVLA-OFT、Diffusion Policy、RoboCasa：**仅 3 条链**。真机：无统计。
- 区间包含评测噪声；tier 区间为 chains×episodes 分层 bootstrap；配对对比为 t 区间 + Holm 校正；等价检验 TOST，δ=2（SR_nom）、5（SR_rec），有“证据不足”区；SR_rec 评测噪声底约 1.5 点；Spearman 保留括号区间。
- 协议要点：每代重置优化器矩与 warmup；π0.5 采用 openpi pi05_libero 配置，5000 步（非 30000）、warmup 500；种子训练用 2× 帧预算；所有超参取自公开配方，“未在任一任务族上调参”（但 RESCUE 的 δ、buffer、基线强度由作者设定）。
- 外部池：D_plain^ext（未用于种子的 LIBERO 人类示范，无恢复内容）、D_rec^ext（1000 条恢复示范：LIBERO-Recover 遥操作 + 特权状态脚本控制器，与种子数据/tier/bank 严格不重叠）、D_mix^ext（γ≈0.17）。

## 9. 局限 / 需谨慎之处（读者归纳，非作者的“局限”节）

1. **没有 Limitations 节**，AI 使用声明只说 LLM 用于语言润色与找文献。
2. 模型是两状态 logistic 玩具模型；**不检验阈值位置**，只检验符号/排序/标度；ε_n 与 c 用代理；tail tier 无预测；Remark 2 承认固定教师臂中 −3.8 的持续损失在模型之外。
3. **模态词典 Φ 由模拟器特权状态按几何规则定义**（36 个/任务）；监控与 RESCUE 依赖它（无监督词典 −3.7 点，但并非主证据）。RESCUE 还需要**带模态标注的外部恢复示范池**（含脚本控制器/真人遥操作恢复数据），不是“零外部信息”的自修复。
4. 评测 E_rec、banks 与 D_rec^ext 同源（LIBERO-Recover 管线，虽然按状态/近重复过滤了不重叠），恢复能力定义局限在该基准的四个层级。
5. 种子是**刻意降低的数据预算**（10/50 标称示范）以让名义指标可涨；全量配方在 LIBERO 上饱和——结论在高成熟度种子上的外推未测（种子分叉的 N50 只是缓解了侵蚀，仍侵蚀 18%）。
6. 链数少（3 或 5）；family B 与 A 共享链，不是独立复现；Diffusion Policy 上 RESCUE 优势区间含 0；PG≈D 的等价检验未正式成立；Table 15 的 Spearman/c 与侵蚀序未检验。
7. 开环机制干预不能展示反馈；闭环只覆盖少数臂。
8. 论文自身的 Related Work 把 RSI 与 model collapse 区分：对象是“固定行为模态上的任务能力”，诱导分布是状态占用，不是生成分布；与 DAgger（无专家）、forgetting（外生任务序列）对比。
9. 论文提到的 LLM 侧 RSI（STaR、self-rewarding、SPIN、系统级代码重写，Zhang 2026a, Lee 2026, Hebbar 2026）只在引言/相关工作出现，**没有任何 LLM 实验**。

## 对 data-centric RSI 的含义

### 事实层（论文直接给出的、与我们问题相关的）

1. **“名义成绩升、尾部能力降”在固定任务分布、仅成功过滤的自训练循环里，在 3 种策略架构 × LIBERO/RoboCasa 上都复现**，并且对应的方向（D 的 SR_rec −22 到 −33 点，SR_nom +8 到 +11 点）一致。这是 rise–plateau–decline 之外的第二种形态：**标称指标不衰减，被侵蚀的是未被标称指标覆盖的能力**。论文里 SR_nom 在 G10 仍在上升（外推 G20 约 91 左右，趋于平台），没有出现 nominal decline。
2. **retained gain vs task gain**：论文没有用这个词，但数据给出一个相关的对照：D 的 SR_nom 增益 +8.8，却同时 −33.4 的恢复和 −24.9 的 tail；RESCUE 保留 91±12% 的标称增益，同时保住恢复。**“增益”取决于用哪个 tier 评测**；单看标称 tier 的“保留增益”会显示 D 优于 RESCUE（90.2 vs 89.4，但 2 点内等价）。
3. **侵蚀的主要载体是数据（教师），不是参数/可塑性**：教师效应 −29.1±3.9 vs 初始化 −4.6±2.8；reset 下依旧存在。这直接给“是循环里的数据选择，而不是训练动态”提供了一个干净的 2×2 设计模板（固定教师 vs 递归教师 × continuing vs reset）。
4. **过滤规则本身决定侵蚀速度**：无过滤（固定点）几乎不漂；top-90% 截断已经开始用恢复换标称；成功奖励 PG ≈ D；advantage-conditioning 居中（SR_rec 18.9）。即**“选择强度”是可控变量，且改进信号与侵蚀同源**（没有改进信号 U 就不动，U 的 SR_nom 82.3，几乎无增益）。
5. **数据质量不是原因，组成才是**：补回随机/名义匹配的成功 rollout 几乎无效（14.6/12.3），补回“丢失的恢复模态”几乎全部拿回（40.5）；纯标称外部数据在 α 到 0.4 都无效；iso-β 下 α 变 8 倍曲线平。这个结果对“用更多/更好的外部或合成数据”的直觉是直接的反例：**覆盖了什么比混多少更重要**。
6. **监控指标的区分度**：熵、方差、tail mass 只能看到“集中了”，不能区分有害集中与良性锐化（RESCUE 与 D 同样集中却保留能力）；模态级覆盖 cov_mode 与恢复损失相关最高（0.82）。同时作者承认覆盖与 tail mass 的优劣未定。
7. **前瞻性**：覆盖风险 hazard 在留出任务和 G11–G20 外推上 MAE 最低（SR_rec 2.2 / 3.4），但对臂 D 本身与简单几何拟合差<1 点；增益来自部分受保护的臂。
8. 以上都是**“策略自己更新”**的循环；论文**没有测量“改进者自己是否变好”**，也没有 rise–plateau–decline 的曲线（只有标称单调升、其他单调降、以及标称在 G10–G20 趋平）。
9. 样本量小（3/5 链）、种子是故意压低数据预算、模态词典用特权状态、方法需要外部带标注恢复示范池、真机仅定性。

### 推测层（明确标为我们的 conjecture，未被论文验证）

- C1：LLM/推理类 data-centric RSI 的“silent erosion”对应物可能是：在固定评测集上 pass@1 升，而低密度题型、需要重试/自我纠错的长程轨迹、被过滤掉的“低成功率模态”的能力降。论文的**访问漂移**（策略变强→失败状态访问减少→纠错数据减少）在 LLM 里可能对应“难题/长尾题的 rollout 里正样本占比下降，且这些题的成功样本又被过滤得更少”。是否成立需要自己做；论文无任何 LLM 证据，且其机制依赖“共享参数的梯度冲突 c>0”，在大模型里 c 是否为正未知。
- C2：论文的 2×2（固定教师/递归教师 × continuing/reset）与“fixed-teacher control”可作为我们 rise–plateau–decline 实验里判断“decline 来自数据递归还是参数漂移”的标准控制；与 retained-gain 指标结合，可以把“标称 tier 增益”与“分 tier 增益（尾部/恢复）”分开报告，对应我们的 retained gain vs task gain。
- C3：论文的 flip 库（种子可解、独立重估、封存）是“丢失 vs 从未获得”的干净定义，可迁移为“种子 pass@k≥阈值的题，后代失败”的 forgotten-set；注意回归均值（论文自己展示朴素梯度更陡）。这比我们若只看总体 pass@1 的衰减更能区分“饱和”和“侵蚀”。
- C4：论文的“改进信号与侵蚀同源”（U 不动、过滤越强越侵蚀）暗示：data-centric RSI 的 decline 可能不是某个超参的问题，而是**选择规则强度和“标称提升”之间的内生耦合**；若成立，decline 的出现点与选择强度（过滤严格度、奖励硬度）相关，可在我们的循环里直接改变这一变量测剂量-反应。
- C5：RESCUE 的做法（按“种子已掌握但质量在缩的模态”优先补外部数据）在 LLM 语境里需要一个模态词典 Φ；论文自己的词典靠模拟器特权状态。LLM 里要么靠题型/技能标签，要么无监督聚类（论文的无监督词典只损 3.7 点，但那是在 36 个几何模态上）。是否可行未知。
- C6：论文**没有**触及“improver 自己是否变好”：它的 improver（选择规则 + 教师）要么是固定过滤器，要么就是策略本身。如果我们想检验 improver 质量，这篇没有任何可借的数据，只能借其“教师/数据来源”的分离设计。
- C7：论文对 model collapse 的区分（对象是固定模态上的任务能力而非生成分布）可以作为我们的立场引用：data-centric RSI 的衰退不必等价于分布塌缩，“方差/熵没变坏也会掉能力”（RESCUE 与 D 对照）是可引用的反证，但仅在其具身设置下。
