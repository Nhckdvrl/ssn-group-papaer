## 1. 设定（facts）

- 真分布 p* = N(0, Σ*)，**均值已知为 0**，只估协方差；假设类 p_θ = N(0, Σ)。（正文说"§B 处理未知均值"，但附录 B 实际只讲 LDA 与 flow matching，我没找到未知均值的处理，未核对。）
- Teacher：用 N0 个真样本估 Σ0；Student：用 N1 个**纯合成**样本（来自 teacher 的 N(0,Σ0)）估 Σ1。**学生全程不接触真数据**。
- 指标：KL 差 Δ_{0:1} = KL(p*||p_θ1) − KL(p*||p_θ0)；Δ<0 即学生胜。
- 估计器类 (β̲, β̄)-MLE：Σ̂ 夹在 β̲·XXᵀ/N 与 β̄·XXᵀ/N 之间（Loewner 序）。包含 MLE (1,1)、James–Stein 极小极大估计、Haff 估计。**排除** d ≥ N 的高维收缩估计（Ledoit–Wolf 等）。要求 N0, N1 ≥ d+2。
- 作者定义 "biased student" = 把样本协方差整体乘以一个标量 β>1（协方差膨胀）。最优 β*_{0:1} = N0·N1 / ((N0−d−1)(N1−d−1)) = γ0·γ1，其中 γ_i = N_i/(N_i−d−1)。这是 MLE 协方差在 Σ⁻¹ 上的 Wishart 偏差因子（E[S⁻¹] = N/(N−d−1)·Σ⁻¹）。**学生需要知道 N0 和 d 才能设 β***，这是它从 teacher 之外得到的信息。

## 2. 主要结果

- **Thm 1（精确期望 KL 差）**，teacher 为 (1,1)-MLE：
  1. 学生 β=β̄=1（MLE）时，E[Δ] = Δ̃(1) > 0 对任意 (d,N0,N1) 成立：**MLE 学生永远输**（期望意义，KL 意义）。
  2. 若 N1 < h_d(N0)（h_d 为不动点方程 (3) 的解），则 **没有任何** (β,β)-MLE 学生（任意标量缩放）使 E[Δ]<0。必要条件。
  3. (5) 式给出 E[Δ] 与解析代理 Δ̃(β) 之差不超过 (d/2)ln(β̄/β̲)；最优缩放下代理精确。
- **Cor 1（非渐近相界）**，最优缩放：N1 < L = 1+(N0−d−1)²/(d+1) 则 teacher 胜；N1 > U = N1 + (N0−d−1)²/(d+1)（原文记号即 N0 + (N0−d−1)²/(d+1)，PDF 文本抽取有歧义，未核对）则学生胜；边界 h_d(N0) ∈ [L,U]，即 **Θ(N0²/d)**。数值边界在 log-log 上斜率约 2.10（并非恰好 2）。误缩放因子 ζ 的代价为 2g(ζ)，g(x)=ln x + x − 1。
- **Thm 2（PAC）**：最优缩放下，单次运行符号与期望相反的概率 ≤ Var/(E²+Var)（Cantelli）；相界外一定距离时失败概率 O(d^{-2+2ε})。边界附近单次运行近似抛硬币，带宽随 d 增大收窄。
- **Prop 4（附录 K，被正文一笔带过，但很重要）**：若 teacher 自己做了最优校正 (β0 = γ0)，则 **任意** (β1,β̄1)-MLE 学生、任意 N0、N1 都不能胜，E[Δ] = (d/2)[φ(β1/γ1)+ψ_d(N1)+ln(2/(N1−d−1))] > 0。对部分校正的 teacher，学生所需的 N1*(β0) 随 β0→γ0 趋于 +∞。
- **Thm 3（逐阶段改进）**：L−1 个纯合成学生的链，若每阶 N_k = N* 且缩放按 ξ_k 选取，则每个学生都比前一个好；所需 N*_L = Θ((L−1)·N0²/(d+1))（仅在 ρ→0+ 时给出该阶，常数夹在 ½(1−(d+1)/N0)S_L·(N0²/(d+1)) 与 2S_L·(...) 之间）。即"每一阶都改进"的样本代价随链长**线性**增长。
- **Thm 4（No Free Bootstrapping）**：m 阶链的期望 KL 差只依赖各阶缩放之积；最优缩放下，第 m 阶比第 m−1 阶的最优增益差 = (d/2)[ψ_d(N_m)+ln(2/(N_m−d−1))] > 0，即**每多一轮，最优可达的 KL 严格变差**（相对 teacher 的增益是 m=1 时最大，之后单调减小）；两阶段已达到任意长链的渐近性能。注意：每阶"相对前一阶改进"与"相对 teacher 的总增益"不是一回事，后者越长越差。

## 5. 对 data-centric RSI 的含义

### 5.1 事实性对照（只说论文支持的）

1. 该论文的 "student 超过 teacher" 是 **在没有任何新真实信息的前提下**实现的，但**唯一的来源是已知偏差的校正**：学生知道 teacher 用 N0 个样本做 MLE，故可反向修正 Wishart 偏差。若 teacher 已自行校正（Prop 4），任何学生都赢不了。所以这里的"超过 teacher"= 取回 teacher 的估计器没做对的那部分，而**不是**生成新信息。
2. 相界 N1 ≳ N0²/d：要让学生的**采样噪声**小于 teacher 的**偏差²**，需要平方量级的合成样本。合成样本是廉价的，这个门槛在"生成无限"的 regime 下可以满足；它不是真数据量的门槛。
3. 链：每阶可以改进，但相对 teacher 的最优增益随链长单调变差，两阶段即足够。纯合成链不会通过迭代积累收益。
4. 对照 model collapse 理论：论文把"collapse"改写为估计器性质（MLE 的 Σ̂ 在逆矩阵意义下偏小，即协方差收缩），并给出"纯合成也不崩甚至略优"的区间，**前提是学生知道怎么膨胀**；它不是"多少新鲜真实数据比例"的条件，真实数据比例在此模型里为 0。
5. 与 Survive or Collapse 的 leak-rate 相变：二者**不是同一类相变**。本文的轴是 (N0, N1)——真样本量与合成样本量，边界 N1 ~ N0²/d，无 leak 概念；leak-rate 相变的轴是每轮泄漏进来的真/新信息比例。两者没有可映射的公共量，不能把本文相界直接当成 LLM 循环的 leak 阈值。
6. LDA 实验直接给出一个对 RSI 有警示意义的现象：**似然变好，分类准确率完全不变**。若把"自改进"的读数选成 NLL，会得到系统性正结果而下游能力不动。

### 5.2 推测（conjectures，均未被论文证实）

- C1：自生成循环能否超越起点模型，取决于是否存在一个**学生可用而 teacher 没用的先验/结构知识**（此处是"我知道你是 N0 样本的 MLE"）。若起点模型已经校准（相当于 Prop 4 的 corrected teacher），则无外部信号的循环在这个结构里不可能净胜。推测在 LLM 中，对应的"已知偏差"可能是：self-consistency/多数投票、temperature 校准、长度偏好等，即**对 teacher 采样分布的已知系统性误差的修正**，而不是更多自生成数据本身。
- C2："需要多少外部信号"的对应物：本文外部信号的全部量就是标量 β*（≈ N0, d 的函数），信息量极小。推测在 LLM 循环里可以把"外部信号"分层测量：(a) 零外部（纯自生成）；(b) 只给一个校准标量（如温度/采样分布整体修正，对应 β*）；(c) 过滤/验证器（对应 leak）。如果 (b) 已经能恢复大部分增益，说明增益是"校准型"而非"信息型"，与 leak-rate 方向区分开来。
- C3：N1 ≳ N0²/d 暗示：循环中合成数据的**量**比真数据量需要更大（超线性），小规模自生成往往看起来"没用/崩坏"，可能只是 N1 低于相界。这给"自生成改进失败"提供一个无需调用信息论上限的替代解释：先检查 N1/N0² 与有效维度 d_eff 是否到达相界。但 LLM 的 d_eff、N0 如何定义**很不清楚**，这是最大的映射缺口。
- C4：No Free Bootstrapping 暗示迭代轮数应当少而精：两阶段≈任意长链。推测在 LLM 中表现为"第 1–2 轮有收益，之后收益变差或不变"，与经验上 self-training 早期增益后饱和一致；但经验观察到的饱和有多种成因，这不构成对本文的验证。
- C5：因此对"一个纯自生成循环能否超过起点"的最诚实的说法是：**在可解模型中，它能超过一个未校准的起点，但不能超过校准后的起点，且超出量封顶于一阶**。这对 data-centric RSI 是一个有限制的正面结果，而不是"可无限自举"的证据。

### 5.3 在 LLM 循环中如何做检验（设想）

- 选一个起点模型 M0（SFT/小规模预训练 checkpoint），从 M0 采 N1 个样本，做**无过滤、无验证器**的纯自蒸馏，扫 N1（至少跨 3 个数量级），读数用**留出真实文本 NLL**与**下游任务准确率**两条，二者分开报告（对应 LDA 的"似然涨、准确率不变"）。
- 对照 1：只用采样分布的标量校准（温度/top-p 的整体调整、logit 缩放）而不训练，看 NLL 增益能否被复制——对应 Prop 4 的"corrected teacher 学生无用"。若校准后再自蒸馏不再有增益，则与论文一致。
- 对照 2：逐步给学生注入 leak（真数据比例 α），画 (N1, α) 平面，判断是否出现两种不同的边界：本文的 N1~N0²/d 型（量门槛）与 leak-rate 型（信息门槛）。
- 链长扫描 L=1,2,3,5：检验相对起点的增益是否在 L≥2 后不再增加（Thm 4 预测）。
- 注意：要预先写好读数与决策表（R3/R5），并避免筛种子；本文自己也只在高斯/LDA/线性 FM 上验证，LLM 上任何阳性或阴性结果都**不能**回头说成"验证/证伪了该定理"，只能说"本文机制的一个可测推论是否出现"。
