# Realtime / Omni Agent 三个已结项工作区：精简科学记录

原目录：`realtime-agent-capability-transition/`、`realtime-computation-boundaries/`、`omni-recon/`。都已结束独立研究并从当前 workbench 移走；全部旧文稿、脚本和测量转储可从 [2026-10-09 清理前 Git 快照](https://github.com/Nhckdvrl/ssn-group-papaer/tree/81e319fdc3414b7b6d16c8950f0046646d198cb1/workbench) 取得，仓库 HEAD 不再存它们的大量过程文件。下述结果有条件限制，不是新的论文 claim。

## 语音化是否天然损害 Agent 能力？

τ-bench/τ-Voice 的前沿语音 agent 与文本模型已能在多个场景表现接近，粗糙的“语音比文本差”不适合作为母问题。严格的本地文本对照（同 Qwen3-32B agent、相同用户模拟器、无 ASR 错误）只改变电话式口语表达：零售 47.8%→43.5%（配对 p=0.79）；航空 40%→44%（p=0.77）。**未检测到可置信的口语风格独立损害**，不能把不显著写成零效应被证明。

## Full-duplex / 前台后台计算边界

在 Realtime-Venus 等公开模型中，部分“弃答/诚实性”差异可由简短系统指令显著改变，属于策略默认值，不能直接声明计算能力被实时架构夺走。某些交接发生后的成功率约 32–36%，与后台直接见原话的 34% 接近；不能再讲信息通过边界必然丢失。该当时对照只说明当前评测设置，不能外推所有模型。

## 语言策略与结构化动作不一致

Omni 侦察曾见到语言指令能改口头表达却没可靠触达动作 token（Venus delegate 1/21、0/11）。只有单一模型、有限样本和无法完全使用的 VoiceChat 对照，未形成跨架构普遍结论。B1 等后续尝试也未发展成可持续论文主张。

**重启条件：** 出现真正依赖时序/交接的动作级故障，且排除 ASR、提示默认值、底座差异及现有近邻；禁止把本文件当作运行计划。领域谱系与外部文献仍由 [题材页](README.md) 管理。
