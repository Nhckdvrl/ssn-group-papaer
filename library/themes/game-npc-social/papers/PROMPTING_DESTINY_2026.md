# Prompting Destiny: Negotiating Socialization and Growth in an LLM-Mediated Speculative Gameworld

[arXiv:2602.05864v1](https://arxiv.org/html/2602.05864v1)，2026-02-05。2026-10-23读主文§1–5；未逐项核附录游戏提示。文稿带CHI格式但DOI仍占位，**未独立确认正式接收身份**。

1. **形态／压力：** 反思性游戏设计与探索性用户研究；开放NPC互动如何使教育、关系和责任后果可感知。
2. **idea来源（DOCUMENTED）：** 社会化阶段理论；四季结构与延迟成长反馈，避免玩家围绕实时数值优化。
3. **系统／证据：** LLM叙事与人物回应、环境后果；12参与者、个人游玩与访谈的反思性主题分析。原型支持多人，研究并未验证多人模式。
4. **距离：** 相较ArcANE阶段表演，它考察玩家如何解释互动中的成长和关系；相较EvolvingWorld，不是更新模型的能力基准或训练方法。
5. **边界：** 没有对照组，不能证明延迟反馈的因果效果；作者明确把自动成长反馈视为反思材料，不是已验证心理量表。
6. **对D（研究判断）：** NPC成长的重要性还在于玩家能理解并回应角色变化。人物可能抵抗引导，玩家也可能改换互动策略；不能把顺从或指标上涨作为统一成功。当前固定后续context只能测条件表现，真实生成互动还需测变化怎样影响双方后续行动。此文提供设计动机，不提供我们的模型能力证据。
