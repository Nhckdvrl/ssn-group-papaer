# R²A: Learning Persona Policies Through Persona Representation Learning and Runtime Alignment

[arXiv:2608.29798v1](https://arxiv.org/html/2608.29798v1)，2026预印本。2026-10-22选读§1–3、实验范围概述；未完整结果/附录或复现。

- **问题与idea来源：** 同一职业persona在不同任务中需要不同条件行为；区分选择合适行为与实现完整轨迹。
- **方法：** Who–How–What三类SFT，随后移除显式persona，用行为与任务质量反馈做GRPO。
- **对象：** 单个Accountable-Professional persona、四原则及12评价设置，重点是澄清、可行性、前提审查和证据回应。
- **与D距离：** 可借鉴条件行为学习；它不是不同虚构人物从人生经历改变自己的实验，不能把专业助手的最优任务行为当NPC共同目标。
- **定位：** 学习persona策略已有直接先例；我们的完整增量仍须落在人物特有适应与跨互动迁移，不靠新术语。
