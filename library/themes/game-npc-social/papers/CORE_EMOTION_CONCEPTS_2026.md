## 1. 论文形态、背景与改变的前提

构念测量与人类—模型比较。以往情绪测试常问输出是否符合人类多数意见；本篇转向：同一个“愤怒”等情绪概念，在不同情境下有多少内部差异，不同情绪之间的边界有多硬。**DOCUMENTED（§1–2）**：用认知评价维度构造可共同测量的外显行为表征，不把LLM回答当作它真的有主观感受或等价的神经表示。

## 2. 资料来源、样本与测量

从Smith与Ellsworth的情绪研究出发，作者先写种子，再由GPT-4o扩展，经过8名计算机/信息领域学生两人交叉审查及两名研究者修订，得到**270个日常假设情境，15类情绪、17维评价**。8名验证者不是最终体验被试；场景刻意避免过度极端、含混和文化特指，并明确提示“你感到了某情绪”。

主文招募72名美国成年英语参与者，每人拟评30情境；**附录C1的过滤后有效人数为41**，每情境每维平均约3.7份评价。失败注意检查、完成不足80%等在参与者层面排除，并要求完整17维。ICC(1,k)=.441，平均情绪轮廓的随机分半相关r=.911；个体偏离共识也有一定稳定性。样本不是72名玩家，也不是回忆个人真实情绪的纵向研究。

8种LLM对相同第一人称假设题分别输出各维分数；主文版本报告GPT-5.6 Luna、o4-mini、Gemini 3.7 Flash/2.5 Flash、Muse Glimmer、QwQ、Phi-4和DeepSeek R1。模型名称按该版本报告记录，不由本文外推全球最新模型排序。另有单一OLMo-3 7B家族的6个训练检查点。人类每情境均值与模型单次回答不对称，作者用不同人类平均深度及给模型加入测量噪声做补充控制。

## 3. 主要证据

在共同评价空间，情绪间距离/情绪内距离之比，人类约**1.293**，模型约**1.896–2.529**；依据所选度量，模型把不同情绪分得更开、同类情绪压得更紧。用评价向量反推情绪标签，三折交叉验证macro-F1为人类**.26**、模型**.63–.80**；这不是模型预测人类情绪的正确率，而是各自表征里的类别可分性。

加入与人类测量误差匹配的高斯噪声后，模型F1降至.52–.69，但与人类差距仍在；情绪间距离在各噪声重复中仍显著，情绪内压缩的QwQ仅3/5次显著，不能把全部鲁棒性说成无例外。作者主文报告去掉情绪标签、改第三人称、国别和Big Five提示后，整体离散结构多数保留；相关详细附录未在本轮全部逐项复算或精读。

OLMo检查点分析显示此家族的类别分离主要在midtraining阶段增加；之后不同对齐训练更改输出确定性，对结构影响较小。**这是一个7B家族的观察，不证明所有模型共有单一训练原因。** 比较使用评分位置的概率和调整后的数字提示，以减少基础模型格式遵从混淆。

## 4. 限制与反过度解读

本篇主要测**跨情境变化**，平均人类评价会消去部分个体差异；作者明确不把结果扩成完整个体差异模型。17维认知评价也不是情绪唯一理论，未测全部动作准备、身体、表达或文化结构。场景人为筛成可归属单一情绪，本就不是开放角色历史；研究并未测NPC表演、关系修复或玩家体验。评估里更规则、类别更清楚，在某些风格化游戏可能有可读性价值；不能直接判成“越像人越好”。

## 5. 最近邻与可迁移动作

| 近邻 | 本篇增加的认识 |
|---|---|
| Smith与Ellsworth 1985 | 借其15类/17维操作化共同刺激；原研究全文未作为本轮新增阅读计数。 |
| [CPM-MultiAgent](CPM_MULTIAGENT_2026.md) | 状态更新理由容易赢得认可，并不等于对情绪差异和多种合理解释保真。 |
| [EmoLLM](EMOLLM_2026.md) | 正向用户情绪终点是一种应用目标；不能代替情绪概念与具体人物的效度。 |
| [EMA](EMA_2009.md) | 事件与角色评价应保留情境依赖；理论结构和外显量表还需分别检验。 |

对新矿区：为情绪变化建立**多个合乎角色与经历的可接受解释**，研究何时该变化、何时应保持、何种表现让玩家看懂。不要以唯一金标准情绪向量或LLM裁判的一致意见抹去合理差异；也不要把增加随机性误认成更可信的人物。
