# Dynamic Persona Coherence（ACL 2026主会长文）

[正式论文](https://aclanthology.org/2026.acl-long.1336/)。2026-10-22阅读主文§1–6、附录A、B/D/E选段；未复现代码，评审未核验。

1. **形态：** 分层状态与表演修复系统。
2. **压力：** 保持身份不应冻结情绪。
3. **改变前提：** 身份L固定，情绪S和意义/压力M随事件累积。
4. **来源（DOCUMENTED）：** trait–state、认知评价理论；事件增量、范围裁剪、案例检索和评委驱动重写。
5. **近邻：** 相对Generative Agents、Character-LLM、RoleLLM加强状态—表达配合；与ArcANE/PHASE-Tree相邻，但其身份硬约束不等于长期特质成长。
6. **实测：** 作者五人格、三模型、五种子。PCC均值0.7254→0.9195；状态累积消融0.8902。静态参照不保留历史且S/M固定中值，不是同信息完整历史强基线。
7. **边界：** PCC主要检验表达符合给定状态；不能独立证明状态推断正确。跨评委支持排序，非真实玩家成长验证。
8. **研究动作：** 分开状态合理性、身份与表达；保留普通完整历史参照。
9. **对D：** 不重复“三层状态＋纠偏”。需确认经历形成的变化是否进入角色的关系和行动，而非仅匹配系统算出的情绪。
