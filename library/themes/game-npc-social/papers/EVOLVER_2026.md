# From Interactions to Principles: Experience-Driven Self-Distillation for Evolving LLM Agents

ICML 2026，[PMLR正式页](https://proceedings.mlr.press/v306/wu26bf.html)。2026-10-23本次只核对官方摘要及出版信息；PDF链接读取失败，**不是全文阅读或方法复现**。

1. **形态／压力：** 通用工具Agent经历学习；一次任务结束后策略难以复用。
2. **idea来源（DOCUMENTED，摘要范围）：** 从成功/失败轨迹整理原则，去重并按经验效用维护；检索原则支持后续工具推理，并训练使用这些经历的策略。
3. **证据范围：** 官方摘要报告多跳问答；此次没有复核表格、训练成本或对照。
4. **最近邻距离：** 与DualMem同涉记忆学习，与角色动态状态具有可借鉴的经历压缩环节；其目标是工具任务成功，不能直接替代人物立场、关系及自我理解的变化。
5. **对D（研究判断）：** “经历→原则→更好行为”已有明确方法谱系。角色成长却不等同通用Agent更会完成任务：虚构人物可以形成片面判断、改变追求或坚持原则。若借鉴经历效用维护，效用须由合乎人物及经历的后续互动定义，而非默认更理性、更配合或更高任务成功率。
