# EvolvingWorld：角色与世界共同演化（2026预印本）

证据级别：官方摘要＋主文§3.1–3.3选读；未全文/附录/代码复现。2026-10-22核查[arXiv:2607.17250v1](https://arxiv.org/abs/2607.17250)，官方页日期2026-07-19；本轮未确认正式接收身份，未将其资源计为本地已复现。

1. **形态：** 文学世界模拟框架、可训练子任务与评价。
2. **压力：** 静态人物模仿和孤立场景无法持续维护人物及世界变化。
3. **改变前提：** Character Agent与World Model分工，人物和世界状态都持续更新，而非Narrator单独管理剧本。
4. **idea来源（DOCUMENTED）：** 开放schema人物/世界描述；隐藏证据tracker累积尚不足以立即修改人物资料的弱信号。
5. **近邻距离：** 与BookWorld/角色模拟/世界维护有直接关系；完整对比尚未复核。它已把人物profile update变成可训练任务，不能假设“从事件学习状态更新”尚无人实现。
6. **方法/资产：** 七子任务覆盖选角、场景、动机、发言者、互动、世界更新、人物更新；摘要报告57本书、138596训练样本及222测试snapshot。数据构建会用后续叙事作look-ahead参考；这和执行模型是否获得未来信息必须分开。公开文件/权重实际完整性未核查。
7. **边界：** 主对象是多人物与世界共同模拟，不天然等于单NPC在线成长；不能用其轨迹分数替ArcANE阶段或LongEvo下一句指标。
8. **研究动作：** 对状态形成与表演分别建模，区分监督标签的回顾性构造与部署时的可观察输入。
9. **对D：** 是角色更新学习的直接强邻居，不自动改成多智能体研究线。若后续考虑学习updater，应核对其Character Agent模块；当前仍以ArcANE/PHASE-Tree的真实测量为主。
