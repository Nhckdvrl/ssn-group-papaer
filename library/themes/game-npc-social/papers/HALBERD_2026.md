# Narrative Planning Using LLMs as a Model of Action Believability（Halberd，2026 作者稿）

**证据级别：全文；发表状态单列。** Lasantha Senanayake、Stephen G. Ware、Gage Birchmeier。[作者出版目录](https://cs.uky.edu/~sgware/publications/index.php?sort=year)列 AIIDE 22，2026，**forthcoming**；本次未核到正式 proceedings，不能写成已正式出版。实际读[作者 11 页 PDF](https://cs.uky.edu/~sgware/reading/papers/senanayake2026narrative.pdf)全部正文、算法、实验、限制、参考文献，视觉核对 pp.7–9 表 1–6。稿内版权模板写 2024，与正文/作者目录不一致，记录实际来源不据模板改年份。阅读日期：2026-10-19。

## 1. 论文形态与背景压力

混合叙事规划方法、计算对照及读者判断。Sabre 用递归人物计划解释动作，搜索开销大；形式模型认为有解释与读者觉得整个故事合理，也不必完全一致。

## 2. 改变的前提

作者层保留 Sabre 风格 A* 搜索、启发式和形式合法动作；人物层改为 LLM 根据历史、状态、信念、目标判断哪些下一动作可信。每个世界节点一次 LLM 分类代替深层角色计划搜索。错误过滤会删掉有用动作，因此这种近似不保证完备性。

## 3. Idea 来源

**DOCUMENTED：**Sabre、作者/角色不同认知模型以及 LLM 叙事启发式。**RECONSTRUCTED：**可在不同控制层选择不同模型，并分开评价计算成本、形式解释及人的合理性判断；“混合规划+LLM 人物”本身已是本文直接近邻。

## 4. 方法、模型与任务

Sabre 0.8；Halberd 对合法动作清单输出带理由 JSON，解析失败最多重试 3 次，再失败视为空动作。5 个既有领域 Basketball/Fantasy/Space/Save Gramma/Lovers，每域拟求前 5 个不同故事，并在可用时分配到不同作者效用阈值；Lovers 还修改了原效用，把不同人物的满足分别累加。比较 Sabre 与四个 LLM：Llama 3.3 Instruct 70B、Qwen3 8B、Qwen3 MoE 30B/3B active、gpt-oss 120B medium reasoning。前三者同 DGX Spark 128 GB 上量化运行，gpt-oss 经 OpenRouter/Groq；跨硬件时间不能直接当公平模型速度比较。没有 GPT/Claude 旗舰商业基线。

局部模型温度 .6、top-p .95、seed 42；Halberd 每配置 1,000 节点上限。论文文本说 125 故事，但表 1 实际成功数为 25+22+20+22+21=**110**；应理解为 125 个预定解位、110 个成功解，而不是 125 个成功故事。四个 Halberd 都在部分 Fantasy 配置失败。

## 5. 计算与人类结果

表 1：Sabre 共访问 7,393,130 节点、10,824.7 秒、25/25 成功；Qwen MoE 5,173 节点、21,938.6 秒、22/25 成功。访问少很多，调用使时间更久且覆盖下降。结论称约慢 70%，与表中总时长约 2.03 倍不一致，不采用 70% 作精确结论。Sabre 可解释的动作比例为 Llama 70%、Qwen 73%、MoE 73%、gpt-oss 85%，不是玩家成功率。

人类部分挑选 MoE，排除 Fantasy，在 **4 域×每域 5 解×2 系统=40 故事**上比较。第一研究正文称 50 人，表 4 raw 为 53，processed 47；按故事筛选后 178 条评分。每人读同一 planner 的四域各一故事，标出不合理动作。动作判断总计 Sabre 338/426≈79% 被认为合理，Halberd 232/339≈68%；这是重复读者的动作判断，不是 765 个独立故事。κ 仅 .02–.17，形式评分与人评相关 r≈.73、p≈.27，不显著。

第二研究正文称 50 人，表 6 raw 51、processed 48，接受 179 个配对偏好。另一个参与者池选择同作者效用条件下哪篇故事更说得通；合计 Sabre 90、Halberd 89，未检出总体偏好；Basketball 偏 Sabre，Lovers 偏 Halberd。**未显著不等于等价/非劣**。问题测“合理”，不是好玩、代入或真实互动体验。论文把 Bonferroni 称为控制 FDR，术语不准确，应与其实际比较分开记录。

## 6. 证据强度与短板

把形式判据与人类整体偏好分开是有价值的动作；结果同时暴露读者判断不一致。域少、部分失败域不进人评、模型选择发生在成本比较后、同题材重复评分与稿内样本/时间口径不一致，都限制“足够好”的外推。更少节点不必更快；整体未显著偏好也不能证明省略意图解释无代价。未核得公开评审分数。

## 9. 对矿区 C

本文使“作者用规划器、角色用 LLM”成为非常近的已做方向。新候选要落在共同改写、人物理由可理解性和真实作者/玩家过程的未解压力，并比较强普通导演及经典混合规划。不能以本稿局部开源模型推导强商业 API 一定不足。本轮未运行任何模型或规划器。
