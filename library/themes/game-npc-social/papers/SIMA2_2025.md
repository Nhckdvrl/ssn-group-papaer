# SIMA 2: A Generalist Embodied Agent for Virtual Worlds

[原文](https://arxiv.org/pdf/2512.04797) · [发表／主源信息](https://arxiv.org/abs/2512.04797)

**稳定 ID：** `sima2_2025`。技术报告，arXiv v1（2025-12-04；封面 2025-12-05），研究预览；未核定正式会议身份。**实际阅读：** 完整主文 §§1–5（PDF 1–27），完整附录 A–C（37–40）；图 6/10 与表 1 已渲染视觉核对；视频未观看。

SIMA 2 用 Gemini Flash-Lite 基座，混合非游戏预训练数据、人类键鼠演示及 Gemini Pro 合成的推理/对话 bridge data，再对训练环境的可验证任务进行在线 RL。输入 720p 视频历史，输出可解析的键鼠、对话与推理文本；既能处理间接指令、草图和链式任务，也能借额外 Gemini Pro 高层及循环摘要延长规划。论文没有给出可唯一复现的商业模型版本标识、完整训练数据规模与人类样本量，不能自行补成 Gemini 2.5 的某个 API 快照。

跨十个训练环境，人工评定任务平均成功率从 SIMA 1 的 33% 到 65%，自动任务从 30% 到 66%；同限时人类 76%/78%，去限时约 86%/86%。这些是新 Eval Suite 2.0，不能与 SIMA 1 原文数字直接拼接。§4.3 有直接强模型对照：作者做过提示工程后，原始 Flash-Lite 与 Pro 在十域自动评估仅 3.2%/7.0%。这支持“通用 VLM 不自动具备像素到连续键鼠控制”，不能推出给符号状态、可靠高层工具的商业 NPC 也失败。留出 ASKA/MineDojo 成功率仍约 14%/13%（图估读），MineDojo 为 50 类任务×15 seed；26 类至少成功过并非 52% 回合成功率。The Gunk 前 15–20 分钟是人工连续下指令的展示。

自改进用 Gemini 发任务与打分、经验再训练；固定 ASKA 任务分数超越人类参照，主要依据同类 Gemini 奖励模型，缺少独立盲评/原生状态终点审计。科技树进展最终仍人工指令引导；Genie 3 测试主要导航，不能等同完整稳定游戏世界中的长期成长。通用能力也非完全不损失：最终相对基座 LCB −8.4%、AIME −15.4%、GPQA −19.5%。此文对 NPC 的启示是互动语言和实体行动可以结合，仍缺角色自主目标、多人协作和玩家体验研究。应保留其真实进步，也将短记忆、长程验证、精细控制、未完全公开协议作为证据边界。
