# Pharos Night: Crown Pursuit（2026预印本）

**证据：完整研究正文；2026-10-19核读。** Hsu等，*An AI-Native Deck-Building and Tactical Arena Game Design Based on Multi-Agent Systems*，[arXiv:2608.12216v1](https://arxiv.org/abs/2608.12216v1)。实读正文§1–6、机制及表1；未独立运行Unity系统或取得问卷原始数据，未核到正式会场。不是独立对照试验。

## 实际能力与样本

Unity原型组合漫游、NPC对话/记忆、协商、战斗和卡牌合成，使用未给完整版本的ChatGLM系列；后台最多三并发请求，漫游约五秒思考并响应事件。生成卡牌的机制来自作者预定清单，定性强度再映射数值，并经条件、主效果、触发阶段执行；**不是任意自然语言即时创建任意世界规则**。

13人单条件pilot在五分量表上报告策略意义4.15、控制感3.41、整体体验4.13。11/13认为合成有新意，6/13报告不可预测性降低控制感。主文未给完整题项、招募/人口学/时长和细化编码协议，没有平衡性、机制可靠性或多agent必要性的对照。

## 价值与边界

其原型给出“对话之外，生成能进入战术与构筑”的具体设计案例，也同时暴露惊喜和控制之间的张力。问卷不能证明长期可玩、战斗平衡、用户总体偏好或架构因果优势。

结合[玩家态度跨情境研究](PLAYERS_AI_ATTITUDES_2026.md)、[Scaffolded Play](SCAFFOLDED_PLAY_2025.md)，可提出不同角色与游戏功能需要不同可预测性。但新矿区不以复制卡牌/交付循环为任务；本例只约束我们把叙述上的惊喜和玩家实际可掌握的变化分开。
