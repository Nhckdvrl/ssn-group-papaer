# RoleKE-Bench / S²RD（EMNLP 2025主会）

[正式论文](https://aclanthology.org/2025.emnlp-main.1689/)。2026-10-22读主文§1–7及主要表，附录/代码未完整核查，未复现。

1. **形态：** 角色知识错误检测与检索推理方法。
2. **压力：** 人物化措辞不能保证事实正确或知识边界正确。
3. **改变前提：** 九个知名人物、495条真实记忆各注入两类错误，共990问；区分人物可纠正的错误与其不应知晓的知识。
4. **来源（DOCUMENTED）：** 自传记忆分类、自我回忆、检索和怀疑式反思。
5. **近邻：** Character-LLM/RoleLLM提供人物化语料，TimeChara检查时空知识边界；本作检查错误前提的识别，不是新经历后的成长。
6. **实验：** 21模型基本测试；方法主要在GPT-3.5、Llama3-8B、Qwen2-7B上比较CoT、反思、RAG和few-shot。GPT-3.5的RAG+few-shot为73.13，完整方法80.10；这是该检测任务的作者结果。
7. **边界：** 错误注入问答与自然连续角色行为不同；不能由t-SNE图直接认定生成机制。
8. **研究动作：** 分开事实正确性、角色可知范围和行为影响。
9. **对D：** P03若只变成更好的人物事实纠错，会落入已有题目；必须连接角色自己的信念、关系及后续应对。
