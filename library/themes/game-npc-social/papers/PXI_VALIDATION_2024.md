# Independent Validation of the Player Experience Inventory（CHI 2024）

**证据：完整研究正文；2026-10-19核读。** Perrig等，*Findings from a Large Set of Video Game Players*，DOI [10.1145/3613904.3642270](https://doi.org/10.1145/3613904.3642270)。[机构入口](https://edoc.unibas.ch/entities/publication/5c0c6e43-575c-4248-af2c-889e5db1859c)，[实读13页PDF](https://edoc.unibas.ch/server/api/core/bitstreams/4b5f67e4-f6be-4b99-8862-aac2e4d78f03/content)。正文§1–11、表1–8已读，另视觉复核PDF第7–8页表4–8；未复算OSF数据。

## 独立验证对象

预注册线上调查，50人pilot加1501人主样本、排除33人，最终1518名英国Prolific参与者，平均37.47岁。回忆近期或印象深刻的游戏，**不是1518人实验游玩某个NPC系统**。评价PXI、享受题及相关量表，比较因子结构、可靠性和关联。

## 关键证据

十个独立因子模型CFI=.956，加入总体PX因子的模型CFI=.897；含享受的十一个独立因子模型CFI=.955。作者建议按构念报告，不形成总PX或功能/心理高阶分数。沉浸α/ω约.68、AVE=.40，与意义/享受区分不足；其他多数构念表现良好。

功能、心理与享受相关的SEM支持关联结构，但没有把设计属性随机干预，不能把观察中介当机制证明。回忆任务、自选较喜欢的游戏和正向偏斜影响外推；论文也要求补即时游玩、不同质量和游戏版本的验证。

## 对本库的约束

[原PXI](PXI_2020.md)与本研究提供可用测量基础，不提供“高于几分就有研究价值”的阈值。玩家自主、理解、好奇、亲近、享受和有意义的不适需分开；新增NPC量表题要说明依据及适用范围。特别不能把长时对话、模型评分与自编总分相互替代，或以未显著差异证明两系统等效。
