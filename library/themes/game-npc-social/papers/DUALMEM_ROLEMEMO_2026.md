# From Facts to Insights: A Persona-Driven Dual Memory Framework and Dataset for Role-Playing Agents

2026预印本，[arXiv:2605.25693v1](https://arxiv.org/abs/2605.25693v1)。2026-10-22实际读§1–4、§5主表、§6.1–6.2及官方README；未完整附录/代码复现。官方[RoleMemo仓库](https://github.com/Collab-Gen/RoleMemo)当次HEAD `22482ae984e17a692a6e500176c368f5a6921b27`。

1. **形态：** 人物条件化记忆数据集、双流记忆构建学习及下游角色回复评价。
2. **压力：** 中性事实记忆未必包含该角色如何理解事实，强模型也可能只给通用回应。
3. **改变前提：** 从persona与历史构建事实和相应解释两类记忆，检索解释时带上其事实依据。
4. **idea来源（DOCUMENTED）：** 重构性记忆与人物特有解释；训练记忆构建器，保持回复agent固定。
5. **直接距离：** 相对PsyMem训练记忆消费，本文训练记忆形成；与DREAM的事件图不同，它有SFT及整条记忆轨迹的下游反馈训练。与EvolvingWorld相比，主要在给定persona下解释长期对话，未以文学人物多阶段自身变化为主任务。
6. **方法/资产：** 2,052合成personas，train1,914/eval138；20,244查询，主评32k历史，四类人物解释任务。先生成目标insights，再构造facts并织入对话。Qwen3-4B的SFT学事实/解释（含证据不足时null）；RL对完整记忆构建轨迹使用固定actor的回复质量奖励。故“根据后续角色表现训练记忆”已有直接先例。
7. **结果与边界：** 论文表3角色质量SFT4.15/RL4.16，未训练双流4.02、Mem0 4.00；表2Insight Recall@10 .65/.73。角色质量接近不证明RL无作用，也不能仅凭.01宣布RL必要。200查询双人工与跨judge检查支持作者量表的一定一致性，非长期真实玩家成长；固定profile解释任务与人物自身改变仍需分别验证。
8. **公开情况：** 当前有数据生成、推理、奖励/记忆管理和训练入口；README仍将RoleMemo完整数据、SFT/RL权重、完整循环RL agent标为Coming soon。用户先前的资源判断仍成立；不称本地可一键复现完整方法，也不因此忽略论文的方法价值。
9. **对D：** 是可借鉴的直接学习范式，不是收窄整体问题的理由。应检验这种方法如何支持人物自身因经历改变及跨情境后果；新的完整贡献不能仅重复双流记忆或下游角色奖励。
