# Scaling Instructable Agents Across Many Simulated Worlds

规范记录：`sima_2024`；Technical report / arXiv; formal venue not verified。实际版本：arXiv v3, 2024-10-11。

**实际阅读范围：** Complete main text §§1–5, PDF pages 1–21; references and contributor statements excluded; videos not viewed

[原文](https://arxiv.org/pdf/2404.10179) · [发表／主源信息](https://arxiv.org/abs/2404.10179)

**稳定 ID：** `sima_2024`。技术报告；arXiv v3（2024-10-11），不是已核定正式会议论文。**实际阅读：** 完整主文 §§1–5（PDF 1–21）；参考文献与作者贡献不计入正文阅读，视频未观看。

SIMA 把研究目标明确放在“按语言指令在不同 3D 世界行动”，以图像和自然语言为输入、键鼠为输出，无内部状态或奖励访问，异步商业游戏不会等待推理。数据来自单人游玩后标注和 setter–solver 实时指令两类人类记录；SPARC 图文表示、Phenaki 视频表示、Transformer-XL 记忆和行为克隆形成策略，输出 8 步动作，classifier-free guidance 增強指令条件性。主要训练目标仍是约 10 秒以内可完成的短任务；较长行为依赖用户提供连续子指令。

报告涉十多个环境，定量只覆盖七个：三个研究环境及四个商业游戏，共 1,485 个唯一任务、九类技能。评估分别用真实状态、屏幕 OCR、专家看片；典型视频五位评审，并严格将先做无关行为再成功判失败。它专门提醒同一个初态应允许多种指令，否则 agent 可能只靠场景猜任务。完整模型三种子，对照通常一种子；跨环境模型比各环境专用模型平均高 67%（相对提升，不是百分点）。无语言/无预训练消融证实语言和预训练贡献；多数留一环境零样本测试的视觉编码器可能见过该环境图像，Goat Simulator 3 是未做该视觉微调的例外，必须保留这个限定。No Man’s Sky 的额外人类比较子集为人类 60%、SIMA 34%、无语言 11%，不是全平台人类表现。

意义在统一语言—行动接口和真实游戏评测，而非角色社会身份。任务覆盖范围远比单游戏广，但构建可复现存档、任务判定和低时延控制仍需大量工程。报告未完整披露总体示范时数、参与者数和模型训练细节；任务成功严格度还使人类也受罚，不能直接拿成功率当自然交互质量。已证明基础行动可以跨环境共享，未证明复杂长程任务或陌生伙伴协作已经可靠。
