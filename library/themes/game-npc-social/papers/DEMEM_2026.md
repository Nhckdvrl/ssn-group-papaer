# Remember the Decision, Not the Description: A Rate-Distortion Framework for Agent Memory

2026预印本，Mingxi Zou等。[arXiv:2605.10870v1](https://arxiv.org/abs/2605.10870v1)。2026-10-22实际选读导论/相关工作、§3.1–3.3、§5.1设定与主表、附录C.7；未完整核证明、算法实现或全部实测，不声称已接收或复现。

1. **形态：** 决策相关记忆压缩的理论、在线划分方法与通用记忆任务实测。
2. **压力：** 描述相近的历史可能要求不同决定，文字摘要相似性不充分衡量压缩价值。
3. **改变前提：** 用压缩导致的决策损失定义失真；在给定query下，共享近优动作的历史可以共享有限记忆状态。
4. **来源（DOCUMENTED）：** 状态抽象、决策保持、任务导向信息瓶颈与有界控制。
5. **距离：** 不提出人物成长理论；与DualMem的角色记忆学习可互补，与PHASE-Tree的时间尺度状态也不同。不能将其直接当作我们角色状态模型的新定理。
6. **设定：** 主理论为有限历史/query/action、回答时刻contextual bandit、固定但未知奖励函数；query-aware编码器可用完整历史形成K个运行时状态，预算不等同限制全部离线存储/处理。主实验包括合成环境、LoCoMo、LongMemEval、MemoryArena。
7. **边界：** 附录已处理分段平稳奖励与重启，不可说完全未考虑变化。有限动作与有奖励反馈的保证不能原样搬到开放角色台词、多个合理心理解释或玩家体验。正文实测收益不是本项目新测量。
8. **研究动作：** 问人物状态保留了哪些对后续行为有用的区别；不能只以与教师摘要的字面接近判断状态。其给定query的压缩准则不自动认证某经历在一切未来互动都可永久遗忘。
9. **对D：** 可为行为相关状态学习提供已有理论工具，而不要求另造loss。人物变化不自动等于统计学习中的非平稳奖励；固定参数、条件于当前经历/状态的模型也可以实现变化。真正的贡献仍须落在角色经历学习及其整体行为泛化。
