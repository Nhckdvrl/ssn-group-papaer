# Adversarial Closed-Loop Curriculum for Evolving Role-Playing Agents

[arXiv:2609.28609v1](https://arxiv.org/html/2609.28609v1)，2026-09-23预印本。2026-10-23选读§1–4方法、主表、跨benchmark与消融；未复现训练、未核对完整附录/发布资产，不宣称正式接收。

1. **形态与压力：** 角色后训练方法；固定情境池覆盖不足。
2. **改变前提／idea来源（DOCUMENTED）：** Actor与Rewriter交替训练，后者改写人物资料和对话，以原题/改写题的Actor质量差作为奖励，持续扩充训练情境。
3. **方法／证据：** 两者使用GRPO；Qwen2.5与Llama家族，英文CoSER、中文CharacterEval和跨任务RAIDEN；CoSER包含30turn模拟互动评价。不是只有单句或卡片评分。
4. **近邻距离：** 承接CogDual、CPO等角色训练，与ArcANE的阶段偏好目标不同。这里“evolving”主要指训练模型及情境池，未以同一人物因生活经历而持续改变为目标。
5. **边界：** 奖励仍依赖外部模型；未独立复核其数据隔离及结果。不能从改写池更难直接推出人物成长。
6. **可迁移动作：** 面向后续不同互动训练，检查训练覆盖和泛化；不为追逐失败而在我们的测试集上持续改写题目。
7. **对D：** 完整增量仍须是经历驱动的角色适应能力。可以复用已有优化器；不能将通用Actor训练改名为人物成长，也不因该近邻存在而收窄整体问题。
