# Language Models as Narrative Planning Heuristics（FDG 2025）

**证据级别：全文。** Lasantha Senanayake、Stephen G. Ware；FDG 2025，Article 31，9 页，DOI [10.1145/3723498.3723815](https://doi.org/10.1145/3723498.3723815)。实际读[作者正式排版 PDF](https://www.cs.uky.edu/~sgware/reading/papers/senanayake2025language.pdf)全部正文、算法、表及图说明；视觉核对 p.6 表 2–4；未逐点重建图 2 曲线。阅读日期：2026-10-19。

## 1. 论文形态与背景压力

叙事规划启发式的受控比较。LLM 能产生故事，不自动意味着它比经典松弛规划更适合估计符号搜索剩余距离或建议首步。

## 2. 改变的前提

用 LLM 生成可能的后续动作序列，从序列长度构造距离估计，从其中动作构造行动建议；直接和经典启发式比较，而不是与没有推理能力的稻草人比较。

## 3. Idea 来源

**DOCUMENTED：**经典启发式搜索、Sabre 叙事规划与 LLM 规划。**RECONSTRUCTED：**把语言模型是否适合某个角色作为可分解的实证问题；故事文笔、形式行动建议及实际搜索速度不可互相代替。

## 4. 方法、数据与基线

使用 **GPT-4o-mini**，不是 GPT-4o 或当时最强商业推理模型；temperature 0、最多 3,000 输出 token。11 个 Sabre 基准领域，另 3 个因广度优先搜索在限制内无法得到解被排除。每域上限 3 天、Xeon 4.1 GHz/512 GB RAM；从具有已知有界距离的作者和嵌套角色状态中每域抽至多 1,000 项，不擅自把上限加成实际总数。

四种提示＝自然语言/符号语法 × 是否给剩余长度限制，包含状态、人物信念/目标、规则和历史。长度上界由离线搜索深度得到，属于额外 oracle 信息。生成动作通过 text-embedding-ada-002 匹配有限动作表；因此错误混有表述、嵌套语法及动作匹配问题。基线为三类经典启发式，ε 在每域报告数据上选最低 MSE，属于描述性最优而非留出调参。

## 5. 关键结果

最低 MSE 的 LLM 变体仅在 **1/11 领域 Secret Agent** 胜过最好的经典启发式（.7517 对 1.3323）；其余 10 域经典法更好。LLM 的最佳首步建议在 Gramma、Space、Treasure 3 域超过 relaxed-plan；在 Hospital 最好首步准确率仅 9.2%，经典 49.6%。这些是有明确建模规则的状态预测，不是开放故事质量排名。

## 6. 限制

没有把该 LLM 启发式放回在线搜索并报告端到端搜索胜负；没有真人叙事偏好、玩家体验或实际游戏结果。已知故事领域可能存在训练污染。实验依赖一个小型商业模型及动作语言映射，不能推导所有强商业模型在叙事推理中无效。未核得公开评审分数。
