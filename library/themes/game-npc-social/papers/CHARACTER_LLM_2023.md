## 1. 问题、原有做法与改变的前提（DOCUMENTED）

提示式角色可能复述简介，缺乏由经历塑成的稳定表达。本文用合成生活场景和保护性经历训练角色特定模型。

## 2. 方法、任务与主要证据

将人物资料先重建为生活片段，再扩成含目标人物内心活动的多轮剧本，分别SFT每个角色；少量protective experiences训练角色在超出年代/知识范围的问题上表现不知道。行为、动作和思考全部用文本表示，并无游戏执行层。

9个历史/虚构角色，每角色约1.4k–2.2k场景，LLaMA7B单角色训练；857单轮与450多轮采访，GPT3.5作为生成者、采访者、评委，五维评分。对照Alpaca7B、Vicuna7B、提示ChatGPT；总体与ChatGPT相当的判断局限于该采访评分。作者承认value较弱，<100保护场景效果主要结合例子呈现。

## 4. 证据边界与未排除解释

没有独立玩家研究/可靠性充分验证的人评；历史复杂人物的合成经历不等于真实经历。多轮超上下文直接裁历史，不研究持久互动记忆。文中自行挑5/10epoch检查点、评判与合成同模型及案例为主，使普遍性有限。

## 5. 对整个NPC领域可迁移的认识

说明人物知识边界与一般知识能力可以相冲突，也给出经历式角色训练谱系；不得把文字化身体行动称为具身NPC，也不能把拒答/不泄露现代知识的成功当成有趣或可控玩法。
