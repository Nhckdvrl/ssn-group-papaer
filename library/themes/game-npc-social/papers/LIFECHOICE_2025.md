# Character is Destiny: Can Role-Playing Language Agents Make Persona-Driven Decisions?

EMNLP 2025 Findings，Rui Xu等。标题以[正式PDF](https://aclanthology.org/2025.findings-emnlp.813.pdf)为准，[Anthology条目](https://aclanthology.org/2025.findings-emnlp.813/)另用Persona-assigned/Personal Choices表述；不混成两篇。2026-10-22选读§3数据/任务、§4方法与设定、§5分析、附录A.1生成式评价；未完整审计22页或复现。

1. **形态：** 原作人物决定重建benchmark与人物导向记忆检索方法CHARMAP。
2. **压力：** 表面语气/知识模仿不能保证在关键情境中作出符合人物经历的决定。
3. **改变前提：** 依据决定前的故事资料，选择人物在原作中实际采取的行动。
4. **idea来源（DOCUMENTED）：** 文学专家分析提供人物和决定动机线索，再经模型构造问题与人工筛选。
5. **距离：** 与静态人物识别不同；与ArcANE相比，主要对原作决定节点重建，未将同一问题的完整多阶段变化作为核心。与DREAM共享事件/记忆对决定的支撑关系。
6. **方法/数据：** 正式版2,512决定点、470书（旧预印本较小，勿混数）。描述采用递归/渐进总结或专家资料；CHARMAP先利用描述定位与当前问题相关的经历，再检索细节。已有时间前缀分析：40人物，将决定前材料分五段。另有自由生成行动附录，不能将论文说成只做四选一。
7. **边界：** 专家资料与模型筛题不是原作者提供的反事实心理金标；人物动机/剧情动机强制分组也不能穷尽二者交互。作者公开仓库说明只能分发专家描述路径，完整原作需用户自行取得；没有把470书全量原文当作已下载资产。
8. **研究动作：** 整体人物理解与具体事件细节相结合；外部情势改变导致的选择变化，应与持续人物改变分开；原作决策预测与新互动表演分别验证。
9. **对D：** 它已正面研究历史如何支持人物选择，不据这个先例缩小D的问题。整体新叙事应进一步明确经历学习、人物变化及多个后续互动的联系，现有决定/检索方法可以成为系统组成和实质参照。
