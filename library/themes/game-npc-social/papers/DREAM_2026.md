# DREAM：Dynamic Role-playing via Event-Aware Memory Graph（KDD2026作者稿）

证据级别：官方摘要＋主文§1–3.2选读；未全文/附录复现。2026-10-22通过新近邻扫描核查[arXiv:2608.05170](https://arxiv.org/abs/2608.05170)，PDF含KDD2026及DOI`10.1145/3770855.3818027`；代码与数据完整发布情况未核查，不列为本轮已跑baseline。

1. **形态：** 事件记忆表示、检索与动态人物表演方法。
2. **压力：** 静态人物资料与离散相似片段不能充分表达经历中的时间/因果结构。
3. **改变前提：** 从文学文本构造人物相关事件，而非只检索对话句子。
4. **idea来源（DOCUMENTED）：** ABC事件—信念—后果框架。提取心理、行为和事件之间的关系，形成时序/因果记忆图。
5. **近邻距离：** 对普通RAG、人物记忆与角色专用方法的比较详表尚未精读；对本矿区的直接压力是“事件→人物认知变化”“时间因果记忆”已被作为方法主体，不能仅重新命名。
6. **方法/数据：** 章节级事件切分、跨章补足不完整事件、时间标记与检索截止、动态双粒度人物资料；另提出TCM评价。规模/全部配置和资源完整性未独立核实。
7. **证据边界：** 作者报告在CoSER/LIFECHOICE/TCM有增益；本轮未复算，不将摘要的领先当自己的结论。
8. **研究动作：** 分清角色相关事件、时间来源与因果解释；先与真实近邻比较，避免重复普通事件图。
9. **对D：** 它是ArcANE/PHASE-Tree之外的直接方法邻居。我们仍需先识别真实未解决能力和同信息普通基线，不能把Event-to-State或Causal-Temporal Memory几个词本身当创新。
