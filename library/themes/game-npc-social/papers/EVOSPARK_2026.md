# EvoSpark: Endogenous Interactive Agent Societies for Unified Long-Horizon Narrative Evolution

ACL 2026 Main，Shiyu He等。[正式论文](https://aclanthology.org/2026.acl-long.1480/) · [PDF](https://aclanthology.org/2026.acl-long.1480.pdf)。2026-10-22阅读主文§1–2、§4、§5与局限，附录A、D关系及人物更新提示选读；§3架构选读，部分图的数值抽取乱码，未逐图视觉核验。未运行系统或核查完整代码发布。

1. **形态：** 长程多角色叙事系统，支持预规划到自由演化。
2. **压力：** 旧关系与新关系的累积冲突，以及人物位置与剧情脱节。
3. **改变前提：** 经历日志和当前可修改人物/关系状态分离，事件结束后反思、综合、原位更新；另协调空间与角色出现。
4. **idea来源（DOCUMENTED）：** 对累积记忆的状态冲突及长程叙事一致性观察；本文已明确提出经验改变关系和人格。
5. **距离：** 与PHASE-Tree共涉状态演化，但对象是多角色叙事生成；与EvolvingWorld共涉人物和世界变化，但强调叙事编排、关系与空间。与DREAM的事件记忆相比，明确覆盖当前关系修订。
6. **方法/证据：** 四类记忆含事件buffer、世界知识、不可改经历日志与可改人物/关系状态。附录更新提示要求只在实质变化时修订。六题材含三既有作品和三合成叙事；长程设置15事件约45场景，短设置约3事件。§5.5另有Evolutionary Action Alignment，故不能称它只评卡片、不看行动。八名标注者与模型独立评分部分生成材料；具体抽样总量此轮未核实，不据此给效果区间。
7. **边界：** 评价主要是生成叙事及自动量表，作者承认当前协议缺乏实质人类在环交互。人物更新使用自然语言规则/反思，不等于已学出可迁移的角色变化模型。不能仅因系统是多智能体，就忽略其人物更新方法与主张。
8. **研究动作：** 分开不可改事实经历与可重评的当下关系；检查变化是否体现在行为；原位覆盖并不自动保证心理连续性或评价多解。
9. **对D：** “旧关系覆盖”“经历→当前状态→行为”“长期关系变化”均已有直接工作。我们仍聚焦单NPC；潜在增量须来自角色特异的变化学习、泛化或实际互动证据，而非把这套链条重新命名。
