# The Construction of Autobiographical Memories in the Self-Memory System

Martin A. Conway、Christopher W. Pleydell-Pearce，Psychological Review 107(2):261–288，2000。[发表记录](https://pubmed.ncbi.nlm.nih.gov/10789197/) · [作者上传全文](https://www.researchgate.net/publication/12528554_The_Construction_of_Autobiographical_Memories_in_the_Self-Memory_System)。2026-10-22选读摘要/导论、知识层次、Part2的Working Self/Goals and Memory、Part3的记忆构建/生成式检索；实际主要为印刷页261–267及273相关段落，未全文或逐项原始研究复核。

1. **形态：** 自传体记忆与自我/目标关系的理论整合，非NPC方法实验。
2. **压力：** 人的经历记忆不能只按静态记录检索理解；当前目标与自我认识影响哪些经历被唤起及怎样被组织。
3. **改变前提：** 自传知识与工作中的自我目标双向约束，记忆构建是一个受目标调节的过程。
4. **来源（DOCUMENTED）：** 多层次自传知识、工作自我、目标调节与生成式检索的既有认知研究。
5. **距离：** CAPS关注人物特有的情境加工，TESSERA连接短期过程与持久变化；本文更具体讨论经历记忆与目标的相互作用。后来的DualMem人物解释记忆可借其思想，不能因此认定实现了相同人类机制。
6. **核心内容：** 区分生命时期、一般事件与事件细节；当前目标参与记忆线索构建/验证，经历又给目标提供基础。作者亦明确本文没有充分展开信念/态度的全部问题。
7. **边界：** 人类理论不是LLM内部机制的证据，不直接规定虚构人物正确发展轨迹；本文不提供现代角色模型的性能或训练保证。
8. **研究动作：** 研究人物状态怎样影响之后的经验解释，以及新经验如何再改变状态；不把记忆仅作中性事件仓库。
9. **对D：** 为完整的角色经历学习过程提供理论视角。新方法仍需学到可迁移的适应能力，并由后续互动检验；不要求照搬一套手工心理架构。
