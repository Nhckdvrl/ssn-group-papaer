# Was it Good? It was Provocative — ACL2010 / IQAP2011原数据

[论文](https://aclanthology.org/P10-1018/) · [作者数据与教学分析](https://compprag.christopherpotts.net/iqap.html)

- 已读10页全文；作者教学页annotation、semantic关系、prefix/source/词汇分析已读，其全部后续练习未逐项复算。2010与2011不是同版；旧Web/WordNet算法未复现，E33只原human任务现代冻结端点驻留。
- DOCUMENTED来源：从真实采访/对话的间接回答出发，scalar语义关系需要语料强度和局部语境支持，而不是yes/no表面词。作者将review ratings与数值Web query转为可解释的连续证据，且分析失败与人类分歧。
- 2010：224pairs/每项30人/5类别（含Uncertain），评测合并三类159/224=.71；完全同意66项59正确=.89。数值19项无No，人类偏probably/uncertain，负例检索不足使召回低；没有全量data时不填造。
- 2011作者发布更新版：215pairs/30人/4类别，150dev/65eval，76workers；去掉Uncertain避免个体不确定和群体分歧混淆，代价是强制随机选择。对CNN/Switchboard/Yahoo/Hirschberg修正anaphora和移除Yes/No前缀；原gold不适用于复原prefix版本。
- ownership：方向、强度、自然gradedhuman与semantic entailment/implicature区分早已有；不能claim首次用人类分布或definite/probable测语用。
- 方法学习：先问逻辑/语义关系和信息来源，再看何时需要cooperative/expert假设补全；同样No可能是语义后承，也可能是上界含意。词汇重合没效果不等于语义关系无意义。
- 本workbench：原150材料可检查stage对方向/strong解释是否共同改善；full human-task sequence评分仍metalinguistic。E33保存full/content/null、source-cluster敏感性，先审仪器，不把所谓模型保守当新finding。
