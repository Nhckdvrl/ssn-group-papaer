# When Contextual Inference Fails（arXiv 2026）`[证据级别：全文/附录/关键代码]`

[原论文](https://arxiv.org/abs/2603.19997v1)，Bila et al.；19页正文与附录A–C已读。[官方代码](https://github.com/ltl-uva/build_what_i_mean) @6384a1a5122df14374f2aa766c626ba09aa2d834，材料生成器、评分、QA/history路径已读；A2A整体服务未运行。

1. 来源 DOCUMENTED：人类反复互动中的partner adaptation，进一步问显式信心是否转化为澄清行动。
2. 改变前提：literal内容可靠、contextual enrichment对部分partner不可靠，测选择/信心/提问成本。判断与行动差异、partner-blind澄清已有ownership。
3. 证据：三闭源模型；confidence30序列、QA固定−5提问成本；模型先经过task/format/sensitivity筛选，不能从入选模型概括全部LLM。
4. 原资产：两CSV64rows/24相同prompt不同target对；四seed generator可重建。QA源码依赖gpt4o-mini；原confidence实现与逐trial human未在此release。
5. 边界：纸面confidence与公开QA的session/seed/格式不同；人类无显式同等提问成本；固定低维block任务，独立几何task floor需先验证。
6. 对我们：不能claim首次动态停止推断、首次知识与行动分离。E45只做有界本地confidence迁移，先检查fully成功再解释partner变化；不拿dummy答案器冒充原QA。
