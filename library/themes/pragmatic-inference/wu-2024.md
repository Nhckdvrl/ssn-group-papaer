# Rethinking Pragmatics in Large Language Models: Towards Open-Ended Evaluation and Preference Tuning（EMNLP 2024 main）

**证据：正文方法/主实验/related work已读；关键附录与训练配置待逐项核对。** [原文](https://aclanthology.org/2024.emnlp-main.1258/)

1. **形态：** open-ended evaluation + preference tuning方法。
2. **压力：** gold并非唯一好回答，MCQ symbol binding混杂、识别答案不等于主动生成。
3. **改变前提：** 自由生成与gold并排由GPT4评分并控制长度；对比PO/SFT而非把MCQ当通用competence。
4. **来源 DOCUMENTED：** MCQ/human preference disagreement、比较候选比记单gold更符合社会语用。
5. **近邻：** Hu细粒度MCQ、Hu/Levy elicitation；referential-game ToM；ALTPRAG随后做训练阶段free-form。评测和方法claim已归原文。
6. **实验：** Llama2-chat7/13B、Pythia6.9B-Tulu；Social-IQA/PUB训练，PRAGMEGA/LUDWIG等测试；DPO/IPO/KTO/SimPO。GPT4 order swap、LNRS长度控制；人类ranking；LLaVA7B/OpenCLIP视觉referential game，layer subset tuning。
7. **边界：** PO通常好于SFT；人评中SFT可差于base（Llama7B2.75→2.11，PO2.81），并非普遍SFT提高pragmatics。LNRS依赖closed judge与特定长度校正；layer深度在文中特指靠输入侧，不要反称靠输出。训练/评审未复现。
8. **动作：** 先校对MCQ/free-form/human rank一致性；不把free-form judge当唯一gold。
9. **对我们：** user的阶段演化叙述需保留已有相反SFT结果。主实验API-free；其方法不是当前待做的新loss。
