# Strategic Dialogue Assessment（D&D2026）

[原论文](https://aclanthology.org/2026.dnd-17.1.pdf)。**阅读范围：** 引言、§4commitment/QUD/scoring、§8 LLM与§9–10局限/结论；§2–3完整理论、§5–7全部数据过程、附录F/H与原代码未读，53页不计全文。

1. **idea来源：** 合作Grice/RSA前提不够解释courtroom局部目标；表达真假、speaker目标收益与对手认可不同。使用真实法庭对话、commitment/QUD连接单turn与累计策略，不能只以“有欺骗”找空白。
2. **ownership/距离：** 已有goal、credibility、commitment非合作语用评估。标签beneficial/detrimental/neutral/none指相对speaker goal的承诺，不是事件真假；累计BAT/PAT不是长期规划成功。不能首次战略语用或trust。
3. **方法借鉴与局限：** 12模型、reasoning/非reasoning、human annotation；commitment agreement弱于部分maxim，标签偏斜可抬agreement。local-goal标注不识别完整目标层级，人类不是legal experts。权重1/.5/−.5/−1是评价约定，不是发现内部utility；thought trace不是内部真实计算证据。
4. **如何发展：** 目标/责任/世界命题必须分开；controlled polarity/role/source干预是作者也指出的未来方向。E43/E46原human四事实角是另一种受控素材，尚不能跨原court数据归因或称新strategic能力。需要可靠human norm和独立材料，不能把两个任务差变机制。
