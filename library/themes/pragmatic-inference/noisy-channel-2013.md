# Rational integration of noisy evidence and prior semantic expectations in sentence interpretation（PNAS2013）

来源：[作者完整正文与SI](https://tedlab.mit.edu/tedlab_website/researchpapers/Gibson_et_al_2013_PNAS.pdf)。公开评审未核对。

1. **阅读：** 正文六页及一页SI全文；E54读公开原数据与相关R，尚未精确重回归。作者PDF SHA faafa6c0a0e2a62145a4c828511fd178a76f8834dbbe4fe16011bc960697dd4e。
2. **压力 / idea来源：DOCUMENTED。** 旧句法主导账户能解释active/passive，却不能解释其它结构为何被合理含义覆盖；不是从空白处提出“人会修复错误”。
3. **改变前提：** 最终理解也能结合收到的表达、可发生的损坏与原意义先验。不同错误操作产生不同预测，而非泛泛的context matters。
4. **数据 / 证据：** 五alternation、三exposure实验；相同critical句，fillers改变noise或meaning prior。SI实验室复核是独立证据，不能复制主实验就当新replication。
5. **最近邻距离：** 对句法cue竞争与good-enough理解的增量是操作数、方向与exposure的联合预测；未单独辨认线上修复机制。后续Chen研究进一步审计原实验长度/参与者混杂。
6. **对我们：** 原literal-response是一个解释读数，不是所有implausible句的唯一正确gold。合理修复也会增加“非字面”；必须在原句内区分channel与meaning prior，再看训练。E54发现公开版本尚不能直接声称人类数值parity。
7. **研究动作：** 用跨结构的边界重新归因旧结论，提出与旧解释不同的条件预测。E55先用400原句驻留，不以新增模型表或原效果复现作为论文贡献。
