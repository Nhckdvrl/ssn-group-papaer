# StableMoE: Stable Routing Strategy for Mixture of Experts（ACL 2022，arXiv 2204.08396；Dai, Dong, Ma, Zheng, Sui, Chang, Wei）`[证据级别：HTML 相关节（经抓取工具转述）]`

1. 论文形态：失败模式（routing fluctuation）+ 修复（蒸馏并冻结路由器）。
2. 背景与压力：学习型路由（BASE Layer 等）训练中同一输入换专家，更新被浪费，推理时只用一个专家。
3. 改变的前提：路由策略不必与骨干一起一直学；早期学到的分配可蒸馏成轻量、上下文无关的路由器后冻结。
4. idea 来源（RECONSTRUCTED）：量"最后一次换专家的步数"的累积分布——把路由稳定变成一个随训练步的可测量；再问"如果在这一点冻结会怎样"。
5. 与最近邻的距离：相对 OLMoE §5.1 / FLAME-MoE §6.3（饱和 = 与终点 top-k 重合，结论"早定"），它在 BASE 上给出反向读数（20% 训练时 40.9% token 仍会换专家；50% 处 29.1%，80% 处 15.4%）；相对 Hash Layers（固定哈希从头训），它的冻结路由器来自学习后蒸馏；相对 Grouter 2603.06626（从大模型蒸馏固定路由器），它是同一模型内自蒸馏。
6. 方法 / 数据：BASE Layer 与 StableMoE，语言模型 6 万步，每 500 步取验证集分配；阶段 1（6K 步）贪心分配 + sigmoid 门 + 均衡损失 + 蒸馏损失；**蒸馏路由器以词嵌入为输入**（上下文无关）；阶段 2 冻结。表 5：只阶段 1 19.48 → 冻结 19.28 PPL；BASE 在 6K 步后加冻结蒸馏路由器 20.04 → 19.41。另有多语 MT。
7. 证据强度与短板：小模型、BASE 的平衡分配（不是 top-k softmax 路由）；没有隐状态几何对照；"波动"混合了路由器参数与输入隐状态两种来源（未拆）。
8. 可迁移的研究动作：把"路由何时定"量成"最后一次改变的步"；用"冻结在 t 点的代价"作稳定性的功能判据。
9. 对我们：(a) N4 的反向先例——学习型路由在 BASE 上长期波动；我们的 R(t)/H(t) 拆分能回答它的波动来自哪一侧。(b) E190 的强先验：上下文无关的词嵌入路由器冻结后不差甚至更好（但那是训练时、专家随之适应）；E190 问的是已训练成上下文路由的模型换成查表的代价。(c) 可复用读数："最后一次改变步"的累积分布，可直接在 OLMoE-0924 / FLAME-MoE ckpt 上对 T 与固定随机路由器各算一遍。
