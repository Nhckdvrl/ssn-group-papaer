# Routing Drift Alone Does Not Diagnose Failure in Merged MoE LLMs（arXiv 2609.32821，2026-09-26，预印本）`[证据级别：摘要]`

1. 论文形态：失败模式的诊断 + 方法个案（Selective Router Repair）。
2. 背景与压力：MoE 合并会大幅改变路由，常被直接读成"路由失败"并据此修复（HARC 2606.03391 等）。
3. 改变的前提：路由漂移不等于功能失败；要区分漂移来自路由器参数还是来自路由器输入。
4. idea 来源（RECONSTRUCTED）：反事实交叉——"crossing source and merged router inputs and parameters"，把专家重分配归到"输入漂移 vs 同层参数变化"；再用"恢复源路由后的任务损失"作功能判据。
5. 与最近邻的距离：相对 HARC 2606.03391（ICML'26，假设路由崩溃是主因并校准），它质疑诊断前提；相对 Misrouting 2605.07260（等算力替代路由作参照），它用源模型路由作参照；相对我们 E187 的交叉套用（T_l 套 h_{l+12} vs T_{l+12} 套 h_{l+12}），**做法同构、场景不同**（合并 vs 层复制后继续训练）。
6. 方法 / 数据：DeepSeekMoE、OLMoE、Qwen3-MoE；token 级分析工具包已开源。结论：多数重分配来自输入漂移；源相对路由差异"poorly predict"恢复源路由的下一 token 似然增益；不同专家选择可产生方向相似的混合输出；故意破坏路由器时测试能检出可恢复损失，恢复源路由则无可靠任务收益。
7. 证据强度与短板：只读摘要；具体层、模型尺寸、统计量未核对；未评审。
8. 可迁移的研究动作：用"交叉套用输入 × 参数"的 2×2 拆分路由变化；用"可恢复的任务损失"而非路由差异定义失败。
9. 对我们：(a) 是 E187 分解方法的先例，需在 `POSITIONING_COPIED_LAYERS_2026-11-09.md` 补列（该文未列）；其"输入漂移为主"是 E187 的先验预测。(b) "路由差异不预测功能"与 C27（路由散度不比零模型多预测迁移）同型，可作 N3 的旁证与压缩风险来源。
