# Multi-Head Attention as a Source of Catastrophic Forgetting in MoE Transformers（ICML 2026，poster〔venue 只来自 venue corpus〕；arXiv 2602.12587）`[证据级别：摘要]`

1. 论文形态：失败模式 + 修复（MH-MoE）。
2. 背景与压力：MoE 被认为适合持续学习（稀疏路由局部化更新），但在稀疏且均衡的使用下仍大量遗忘。
3. 改变的前提：遗忘源自路由之前——多头注意力把各头信号拼成一个路由输入，路由器只能对"特征组合"而非可分离的头通道作决策（"pre-routing bottleneck"）。
4. idea 来源（RECONSTRUCTED）：从"路由输入里有哪些可分解因子、由哪些头支撑"出发，把不同组合映射到同一路由称为碰撞，并量化为 N_eff。
5. 与最近邻的距离：相对 Li 等 ICLR'26（按上游组件分解路由分数），它关注头支撑不均对持续学习的后果；相对 Ye 2604.17837（行空间 / 零空间），它把路由输入拆成因子组合；相对 PASs-MoE（ACL'26，路由器与专家协同漂移），它定位到注意力侧。
6. 方法 / 数据：Qwen3-0.6B / 8B 上的 MoE 适配（与 LoRAMoE 比），TRACE；BWT 11.2% → 4.5%（Qwen3-0.6B）。路由输入"simultaneously encodes multiple separately decodable semantic and structural factors with uneven head support"；N_eff 高 ↔ 旧任务损失增大。
7. 证据强度与短板：只读摘要；分析在 LoRA 型 MoE 上，不是预训练 MoE；评审未读。
8. 可迁移的研究动作：把下游失败追溯到读出器输入的组合结构；用"有效组合数"量碰撞。
9. 对我们：OLMoE 第 0 层路由器对齐唯一前一 token 头的输出子空间（8.5×）是"头支撑不均"的极端例子；Part C 第 5 问（各族第 0–1 层头 → 路由能量）可直接引它作动机。不涉及零模型。
