# Polysemantic Experts, Monosemantic Paths: Routing as Control in MoEs（ICLR 2026 Representational Alignment workshop，poster；arXiv 2604.17837）`[证据级别：arXiv HTML 经 WebFetch 转述，逐字未核 PDF]`

作者：Charles Ye（独立）、Bo Yuan（Georgia Tech）、Lee Sharkey（Goodfire）。

1. 论文形态：构念引入 + 测量（参数无关的子空间分解）。
2. 背景与压力：专家级可解释性给出多义专家；SAE / 专家标签难以解释"同一 token 不同功能走不同专家"。
3. 改变的前提：路由器只能看到其权重矩阵行空间里的信息——"the router can only access information that lies in the row space of its weight matrix"。于是每层隐状态 = 控制（行空间投影，h_vis = P_l h_l）+ 内容（正交补，R_l h_blind = 0）。
4. idea 来源（RECONSTRUCTED）：把线性路由器的零空间当作"路由器看不见的通道"，再问哪些特征落在哪边；"residual stream is both state and instruction"。
5. 与最近邻的距离：相对 Expert Strikes Back 2604.02178（专家单义性）与 RouterInterp 2610.11775（专家 = 叠加细粒度特征），它把单元从专家换成跨层路径；相对 Myth 2604.09780（路由 = 几何），它给出路由器读的是哪个子空间；相对 Li 等 ICLR'26（上游组件贡献分解），它不分组件、按子空间分。**无随机路由器对照**——与 Melton / 我们的零模型族互补。
6. 方法 / 数据：6 个模型（Qwen3-30B-A3B、GPT-OSS-20B、GLM-4.5-Air、OLMoE、Granite-4-Tiny、DSV2-Lite）；跨语例子只在 GPT-OSS-20B 8–16 层、约 1000 万 EN/ZH/ES token。读数：特征在控制 / 内容中的归一化互信息（附录 F，只有图）；控制信号预测当前层专家约 99%、下一层约 35%，内容预测下一层 65–75%；内容跨层余弦 .75–.90，控制跨层大幅旋转；路由器放大：隐状态维度幅值与路由器权重幅值 ρ≈.6（.11–.87）；随机 2% 维度探针 1–6% vs 高幅值 2% 维度 31–78%；控制子空间聚类唯一 token 数 4.3 vs 全表示 1.4 vs 内容 1.1；≥95% 聚类通过自动可解释性筛选。
7. 证据强度与短板：workshop 海报，无 limitations 节；正文 31–78% 与表 3 数字不一致；"语言 / token / 位置在内容通道"只有图；跨语只三语一模型；无随机路由器、无因果干预（作者把"控制 / 内容正交是否延续到下游行为"列为开放问题）。
8. 可迁移的研究动作：用线性读出器的行空间 / 零空间切分表示，问"读出器能看到什么"；把单元从组件换成跨层轨迹。
9. 对我们：**N1 / N2b 的最近邻**（见 `../FIELD_MAP_2026-11-09.md` B1）。它预测了"语言不在路由里、路由携带跨语功能"；它没有回答这有多少是几何本来就给的——我们的 N_A / N_B 在同一隐状态上可直接补这一步（Part C 第 4 问：路径级读数 T vs 零模型）。"路由器放大高幅值维度"是"词表锐化"的一个候选机制，需在写作中归属给它。
