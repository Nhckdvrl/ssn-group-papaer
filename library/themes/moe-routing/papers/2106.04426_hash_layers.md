# Hash Layers For Large Sparse Models（NeurIPS 2021，arXiv 2106.04426；Roller, Sukhbaatar, Szlam, Weston）`[证据级别：HTML 表 3、表 6（经抓取工具转述）]`

1. 论文形态：方法（固定哈希路由）+ 受控比较。
2. 背景与压力：学习型路由（Switch、BASE）要均衡损失、路由参数，训练不稳。
3. 改变的前提：路由不必学；按当前 token 的固定哈希就够。
4. idea 来源（RECONSTRUCTED）：把路由器当作"给 token 分桶"的函数，枚举不同输入特征（当前 token、前一 token、bigram、位置、聚类）的哈希比性能。
5. 与最近邻的距离：相对 Switch / BASE（隐状态路由），它说当前 token 的随机 / 平衡哈希持平或更好；相对 StableMoE（蒸馏后冻结词嵌入路由器），它从头就固定。
6. 方法 / 数据：pushshift.io Reddit 等；表 3（64 模块，验证 PPL，稠密 24.90）：平衡哈希 23.16、随机 23.22、分散哈希 23.17、聚类哈希 23.90、前一 token 24.16、bigram 24.19、位置 25.07；表 6：**Token Switch（路由器输入换成当前 token 的学习查表）**23.43 vs Switch 23.73 test（64），23.32 vs 23.58（128）；作者假设隐状态"偏向模型预测"、"may be suboptimal for routing"。
7. 证据强度与短板：都是训练时设计，专家随路由一起适应；**没有在训练好的 Switch 上推理时换成哈希**；没有量学习型路由器对 token 身份的依赖。
8. 可迁移的研究动作：按"路由输入特征"枚举固定路由族，用同一损失比较。
9. 对我们：E190 的最强训练时先验（"上下文无关的 token 路由不比上下文路由差"）；E190 的增量是推理时、在已训练成上下文路由的大模型上量代价，且其"前一 token 哈希劣于当前 token"与 OLMoE 第 0 层按前一 token 路由（N2c）形成可报的对照：训练出来的路由器在第 0 层选了 Hash 实验里较差的特征。
