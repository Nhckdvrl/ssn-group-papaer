# When Are Experts Misrouted? Counterfactual Routing Analysis in MoE Language Models（arXiv 2605.07260，2026-05-08，预印本）`[证据级别：摘要；旧笔记有一处近邻提及]`

1. 论文形态：测量（反事实路由效用）+ 最小修复。
2. 背景与压力：训练好的 top-k 路由是否"选得好"很少被直接评估；分析文献只看路由统计。
3. 改变的前提：固定模型，把标准路由与同 token 的等算力替代路由比较，按"对真实下一 token 的概率"打分——路由质量可以直接测，不必从统计推断。
4. idea 来源（RECONSTRUCTED）：反事实替代 = 一个"同算力的参照路由族"；从训练目标推出盲点："the language modeling loss scores only the executed route, and load balancing depends only on aggregate routing statistics"。
5. 与最近邻的距离：相对我们的 N_A / N_B（同一隐状态上的随机路由器，作统计参照），它的参照是随机替代路由、读数是效用而非信息量；相对 Routing Drift 2609.32821（源路由作参照）、SteerMoE（行为对照选专家），它给出 token 条件的效用图。
6. 方法 / 数据：Qwen3-30B-A3B、GPT-OSS-20B、DSV2-Lite、OLMoE-1B-7B（与我们面板重合 4 个）；已验证的推理轨迹。结论：自信 token 上路由与效用一致，"fragile tokens"上路由无信息、模型内存在更低损失的等算力路由；只更新末层路由器即可改变 AIME 2024+2025、HMMT 2025 的 pass@K（Qwen3、GPT-OSS）。
7. 证据强度与短板：只读摘要；替代路由的采样方式、样本量、种子未核对；未评审。
8. 可迁移的研究动作：用"等算力替代"把路由质量从统计变成效用；按 token 置信度分层报告。
9. 对我们：它给了"随机路由器族"一个功能侧的对应——我们只量信息量，它量效用。Part C 若要给 N2 的"局部序列新增"加第二测度，可借它的 token 置信度分层（预测熵已在 E186 存储里）。它的 Qwen3 逐层读法同样受层复制影响（未核对）。
