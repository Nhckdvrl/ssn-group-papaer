# 全文精读 C：稠密模型 / SAE 的种子收敛四篇（2026-11-20）

用途：division 11-20 候选问题的“稠密近邻”定位。候选问题：独立训练的 MoE 在逐条路由决策上大多不一致，但在固定词形、置换不变、扣除随机路由器零模型之后，token 出现的**分区**可能可复现；自训小模型显示分区可复现度（除以精确重跑上限）随专家数上升。待问：分歧是**嵌套**在共享的粗专家组里，还是**横穿**这些组；随专家数和规模如何移动。

### 研究问题与动机（原文）
- 前提（§1）：已有工作表明换种子的 SAE 学到不同特征（Paulo & Belrose；Leask et al.）。
- 细化后的问题（§1）：某个特征没能重现时，"is the underlying direction absent from the new dictionary, or has the SAE learned a different basis"——是方向真的缺失，还是同一片激活空间换了一组基。
- 为什么重要（§1）：自动解释在随机或非规范设置下也能给出看似合理的解释，所以“看起来可解释”不等于“跨运行可重现”。这一点后面用随机初始化 GPT-2 的“dead salmon”对照兑现。
- 贡献三条（§1）：①稳定 / 不稳定特征的功能不对称；②"Subspace recovery without feature identifiability"（单个特征不可辨识，但子空间可恢复）；③用跨种子特征池构造 SAE，稳定性与解释方差（EV）不冲突。

### 设置
- 主设置（§5）：**96 个 TopK SAE**（每个锚点比较 N=95 个），GPT-2 残差流第 7 层，k=64，字典 F=2^14。每个 SAE 用 FineWeb sample-10BT 的 1B token 激活训练；**所有种子共用同一个激活采样顺序**，所以差异只来自 SAE 初始化（附录 A.2）。死特征辅助损失按 Gao et al.。
- 扩展（§7、附录 G）：GPT-2 / Pythia-160M-deduped / Gemma-2 2B，多层，F=2^14/2^15/2^16（层扫描用每层 21 个 SAE）；5 种变体（Vanilla ReLU+L1、TopK、BatchTopK、HierarchicalTopK、JumpReLU）；SAE 训练 token 10M–10B；随机初始化 GPT-2。
- 合成模型（§6.3）：字典 W = [D; UV]，D 为一般满秩特征，UV 的行全落在秩 r 子空间里；每个样本取 k 行单位系数相加，训多个种子的 TopK SAE。主设置 d=32、r=2、k=8，80 个满秩 + 20 个低秩真特征。

### 度量（精确定义）
- 匹配（§4）：解码器向量 L2 归一化；cos ≥ θ 即匹配，θ=0.7（沿用 Leask et al.）。**多对一**（每个锚点特征取对方字典里最大余弦），不是 Hungarian；稳健性检查：换成一对一 Hungarian，匹配集合 IoU = 0.978 ± 0.001（§3.2）。
- 重现概率（式 3–4）：X_{0,i} = 在其余 N 个 SAE 里找到匹配的次数；p̂_i = X_{0,i}/N；假设独立种子下 X 为二项分布。
- 端点集合：ε=0.05，p̂ ≤ ε 为不稳定（U），p̂ ≥ 1−ε 为稳定（S）。
- 使用统计（附录 B.3）：激活频率 ω_i、激活条件下平均幅度 μ_i；token 熵 H_i（附录 B.4，特征激活位置上词表 ID 的经验分布熵，自然对数）。
- 功能影响（附录 B.5–B.6）：遮蔽 N 个稳定特征 vs **4N 个不稳定特征**（粗略匹配激活总量），各重复 R=10 次；EV(M) 与在训练位置打补丁后的 ΔCE = CE_base − CE_patched；另有“按未遮蔽重建的范数重新缩放”的变体。
- 几何（附录 F.1）：有效秩 ER = exp(奇异值归一化后的熵)，**按集合大小匹配**（取四个端点集合的最小规模，大集合随机子采样 B=50 次）；EV_SVD(r) 与跨种子版 EV_SVD^{(a→s)}(r) = 种子 a 的前 r 个奇异子空间能解释种子 s 同类特征矩阵能量的比例；逻辑回归从单个解码器向量预测“是否不稳定”，并把分类器迁移到别的种子测 F1。
- 构造（附录 C.1）：把多个源 SAE 的解码器特征按 θ=0.7 贪心去重成唯一池，在池内估 p̂，取最可能 / 最不可能 / 均匀抽取的 16,384 个特征初始化新 SAE，再微调约 2M token。

### 零模型、上限与校准
- **随机模型对照**（§7、图 8、附录 G.3）：同样流程训在随机初始化 GPT-2 的激活上。各 θ 下，训练过的模型保留大量稳定特征，随机模型的稳定比例塌掉、不稳定占主导；但随机模型的 SAE 自动解释分数照样可以很高（图 23）。
- θ 扫描（附录 B.2、图 9）：θ 越大稳定比例越低，各变体排序不变。
- Hungarian vs 多对一（IoU 0.978）；锚点换 5 个看误差棒（图 1）。
- 有效秩做了大小匹配；合成模型有真值。
- **arXiv 版缺的**：图 5 的跨种子子空间 EV 没有随机子空间基线（合成模型的图 19 有）。作者在 ICLR 2027 回复里补了：秩 64 子空间，用不稳定解码器拟合，能解释另一种子不稳定解码器能量的 44.6%，随机子集 24.7%，激活 PCA 9.6%（作者回复数字，正文未核对）。
- 没有“同种子精确重跑”上限，也没讨论 GPU 非确定性。

### 主要结果（含数字）
- 分布（§5、图 1）：重现概率**双峰**——大部分特征几乎每次都重现，一小撮几乎从不重现，中间少。平均 p̂ ≈ 0.75（图上 0.7460）。图读数：p̂≈1 处约 8,000 个，p̂≈0 处约 1,300 个（总 16,384）。
- 频率与幅度（§5.1）：不稳定特征平均激活频率 0.18%，稳定 0.44%；稳定特征高幅度尾更重。
- token 结构（§5.1、图 2）：两类都有两个熵区间，但内容不同。不稳定：标点 / 格式、短子词片段、脆弱子串；稳定：单词或紧凑同义词簇，到有多种词汇实现的高层概念。
- 自动解释（附录 E）：Qwen3-32B 做 SAEBench 检测打分；稳定特征满分比例约为不稳定的 **4.5 倍**；解释文本中 "substring" 38.9%（不稳定）vs 11.3%（稳定），"phrase" 4.1% vs 32.0%（表 4，含 Wald CI，限检测分 > 0.7）；GPT-5 只看解释文本区分稳定/不稳定，平衡测试集准确率 0.88（附录 E.5，作者自称辅助诊断）。
- 功能（§5.2、图 3）：遮蔽不稳定特征几乎不改 EV 和 CE，遮蔽少得多的稳定特征造成大得多的损失。图读数：基线 EV 0.892；遮 200 个稳定 → EV ≈ 0.845，CE 降幅从约 −0.08（SAE 替换本身的代价）到约 −0.13；遮 800 个不稳定 → EV ≈ 0.885，CE ≈ −0.10。
- 构造（§5.3、图 4、附录 C）：源 SAE 只需不多（约 10 个）就让“最可能”构造里不稳定比例从约 8% 降到约 0；微调后 EV 接近基线；“最不可能”构造甚至比同预算随机初始化还差（图 11）。SAEBench：Sparse probing top-1 0.656→0.673，AutoInterp 0.818→0.850，SCR 0.269→0.258，TPP 0.107→0.090（表 2）。附录 D：后续训练会把部分高概率特征推向低重现概率，作者据此说低稳定方向对重建也有用。
- 几何（§6、表 5、图 5、图 17）：大小匹配后 ER/d：p≤0.01 为 0.587，p≤0.05 为 0.649；p≥0.95 为 0.808，p≥0.99 为 0.804（d=768），即不稳定集合维度低 20–27%。逻辑回归分类“不稳定”的 F1：种子内与跨种子几乎相同，N 足够大时饱和在约 0.73（ε=0）/ 0.67（ε=0.1）。跨种子 EV_SVD 曲线接近种子内曲线，**包括不稳定特征**。
- 合成（§6.3、图 6、附录 F.2）：满秩真特征的重现概率与对真值余弦都接近 1；低秩块重现概率约 0.25、一对一恢复差；低秩块有效秩更低，跨种子子空间相似度明显高于随机基线（图 19）。残差聚类诊断（F.2.1）能部分恢复低秩真原子，但冻结替换后重训编码器不提高 EV。
- 变体（表 1，GPT-2 L7，F=2^14）：Vanilla 稀疏度 62/91 → 不稳定 0.003/0.006、稳定 0.810/0.764，EV 0.833/0.856；TopK k=32/48/64/80 → 不稳定 0.053/0.080/0.098/0.118、稳定 0.619/0.560/0.522/0.499，EV 0.862→0.902；BatchTopK k=64 ≈ TopK；HierarchicalTopK 0.028/0.716，EV 0.876；JumpReLU 不稳定 0.034–0.049。**k 越大越不稳定**。
- 训练量（§7、图 7、图 22）：不稳定比例早期下降后停在非零平台（10B token 时约 8%）；稳定比例继续上升但边际递减。
- 跨模型 / 层 / 宽度（表 6）：GPT-2 和 Gemma-2 越深越稳定；宽度效应**不单调**（GPT-2 L4 不稳定 0.219→0.161→0.088 随 F 增大下降；GPT-2 L10 0.031→0.035→0.040 上升；Pythia L7 在 F=2^16 突然 0.468，原文没解释）。图 21：下一层能找到匹配的主要是稳定特征。

### “这个数大还是小”的参照
随机模型 SAE（同流程的“学习不到东西”参照）；按频率配平的遮蔽；大小匹配的有效秩；种子内 vs 跨种子曲线；合成真值；变体之间互相比较。没有精确重跑上限。

### 为什么不只是“一个相似度数字”
①把种子依赖从总体比例拆成**每个单元的重现概率**，得到双峰两群；②两群在频率、token 熵、解释文本、功能上系统不同（功能后果）；③**粒度分离**：单元不可重现，但它们张成的子空间可重现——这正是我们“细分歧嵌套在粗组里”的同构；④合成模型给出充分机制；⑤转成可用方法（特征池）和一个零检查（dead salmon）。

### 作者自述局限
①稳定 / 不稳定集合依赖 θ 和 ε；②低秩子空间是“一种具体机制”的证据，不证明所有不稳定特征都由它产生；③“无稳定性–EV 折中”只在特征池构造里成立，不说明单次训练能做到。

### 我的批判
1. **端点比例依赖种子数 N**：N=95 时 ε=0.05 允许最多 4 次重现，N=20 时只允许 1 次。表 1（96 个 SAE）TopK k=64 稳定 0.522，表 6（层扫描图 21 用 21 个 SAE）同配置稳定 0.447，原文没解释差异。跨设置比较端点比例时 N 不一致。
2. **“低秩”是相对的**：不稳定集合 ER/d ≈ 0.59–0.65，即约 450–500 维（共 768）。这么大的子空间对另一组向量本来就能解释不少能量；arXiv 版图 5 没有随机子空间基线，“可重现子空间”在 arXiv 版里没被校准。作者回复补了秩 64 的对照（44.6% vs 24.7% vs 9.6%），方向成立，但这是回复里的数字。
3. **频率混杂**：主文用 N vs 4N 粗配激活总量；审稿人认为功能不对称被频率混杂，要求收窄结论。回复补了逐个特征按频率配对的遮蔽：稳定特征的 CE 损失为不稳定的 3.95–4.57 倍、EV 损失 3.65–3.88 倍（回复数字）。
4. 解释文本分析完全依赖 LLM 解释器与评估器；GPT-5 分类 0.88 只是辅助证据。
5. 合成模型证明“充分”而非“必要”；审稿人 mXy5 指出：可辨识性理论早已预言“不可约低维组只可辨识到子空间”，过完备稀疏字典学习在多原子共享低秩子空间时唯一性失效——结论被认为直观、不新。
6. 没有精确重跑上限，无法把“不稳定”与数值噪声分开。

### 公开审稿（OpenReview）
- **ICLR 2027（Submission 59725，在审）**：审稿正文没取回，分数不可见。从作者回复和审稿人跟帖看，三位审稿人（Jt3H、xBq3、mXy5）的主要质疑：①相对 Paulo & Belrose、Leask et al.、Song et al. 的新意；②功能不对称被频率混杂（"The claim should be narrowed accordingly"，转引在作者回复中）；③几何结论缺随机 / 激活 PCA 对照；④稳定 / 不稳定对稀疏目标的贡献；⑤与特征分裂、吸收、非线性流形的关系。mXy5 读完回复后**维持分数**，理由：跨种子一致性已有大量研究（含非 SAE 的 Convergent Learning、SVCCA），结论直观，且可由可辨识性理论推出。
- 作者回复中的新增数字（未核对正文）：跨架构重现——原稳定 TopK 特征在别的种子 TopK 中 88.7%、BatchTopK 84.5%、JumpReLU 72.3%、HierarchicalTopK 68.2%、Vanilla 56.7%，原不稳定特征都 ≤1.3%；目标字典宽度减半时，稳定方向恢复率 95.1%→62.2%，不稳定 10.5%→2.3%；跨种子线性预测不稳定激活 R² 0.231（随机输入 0.128、稳定输入 0.081），预测不稳定重建贡献 0.334；加大 L1 系数后稳定特征保留 79.3% 激活、不稳定 72.3%；特征池构造使跨种子一致率 78.8%→87.5%，EV 0.9322→0.9303。

### 对我们的启示与可预测的结果
- **最直接的模板**：每个单元（对我们：每个专家组 / 每个“词形 × 专家”的 token 集合）估“在其他种子中重现的概率”，看是否双峰；再刻画两群（频率、词类、子词片段 vs 整词、功能影响）。不要只报一个总体可复现度。
- **嵌套 vs 横穿的可检验版本**：它们的“不稳定单元张成可重现子空间”= 我们的“细分歧嵌套在粗组内”。我们可以直接仿造：把一个种子里互相“分裂/合并”的专家并起来，问这个并集在另一种子里是否对应一个（或少数几个）专家的并集，并用**随机分组的同规模并集**作基线（它们 arXiv 版缺的就是这个基线，回复里才补）。
- **它们预测我们会看到**：不稳定部分集中在低频、表面形式的 token（标点、子词碎片）；稳定部分是整词、语法角色、语义组。我们的“固定词形”限制会把一部分“按 token 身份路由”的稳定成分剔除，剩下的是上下文分区，要分开报告。
- **k 和宽度的预测与我们的矛盾**：SAE 里 TopK 的 k 越大越不稳定；宽度效应混合（Paulo 是越宽越低）。我们看到“专家越多可复现度越高”，方向与 SAE 宽度结论相反——这本身可能是一个有意思的对比点，但必须先排除度量本身随专家数改变零水平（见卡 4）以及 k 随专家数一起变（细粒度设定常同时放大 k）。
- **训练量平台**：不稳定比例在 10B token 停在约 8%，提示我们的可复现度也可能有非零平台；多 checkpoint 看平台而不是只看终点。
- **随机模型对照**：它们的 dead salmon = 我们的随机路由器零模型；它们还显示自动解释在随机模型上也能高分——我们若给专家贴语义标签，也要在随机路由器上跑同样的贴标签流程。

## 卡 2　Fehlauer, Mahowald, Pimentel, "Convergence and Divergence of Language Models under Different Random Seeds"（arXiv 2509.26643v1，EMNLP 2025）

### 研究问题与动机（原文）
- 动机（§1）：LM 是对数据分布的近似；若能完美拟合，所有 LM 会收敛到同一分布（脚注引 Huh et al. 2024 的更强主张）。
- 问题（§1）：这种收敛 "(i) not happen uniformly for all contexts; (ii) not happen at all for some contexts"——可能不均匀、可能根本不发生。本文研究跨规模、跨训练、跨上下文的收敛与发散。
- 已有发现的承接（§1）：早期的 unigram 输出阶段（Chang & Bergen 2022 等）和 induction head 形成（Olsson et al. 2022）；不同词类习得速度不同。
- 核心卖点（§1）：四个阶段发生在交叉熵**单调下降**期间，所以同一模型的多个种子可能在彼此更不像的同时更接近目标分布。

### 设置
- 模型：PolyPythia（van der Wal et al. 2025）14m/31m/70m/160m/410m，每个尺寸 10 个种子，**只用种子 1、3、5、7、9**（计算限制）；checkpoint 取 0、1、2、4、…、512、1k、2k、…、128k（对数间隔）。
- 数据：Pile 验证集子集，**共 4,662 个 token**。
- 条件属性：频率（App A 说在数据集 D 上计数，§3 说在 Pile 验证集上计数）、NLTK 词性（词级标签映射到字符，再按多数字符给子词打标签，无多数或 UNK 的剔除；图 5）、最终惊奇度（该尺寸最后 checkpoint 的 −log p）。按对数分箱或词性类。
- 迁移：BLiMP（把分布限制在合法 / 不合法两句上重新归一化后算 KL，式 5）；MultiBERT（只有 20k 步以后的 checkpoint）。

### 度量
- Definition 1：conv(s_<t) = E_{θ,θ'}[ −KL(p_θ(·|s_<t) ‖ p_θ'(·|s_<t)) ]，θ、θ' 是独立种子。
- Definition 2：E[conv] = 对上下文求期望。Definition 3：条件收敛 = 只对目标 token 属于集合 S_t 的上下文求期望。
- 为什么不用相关（脚注 3）：两个随机初始化模型输出近似均匀分布，惊奇度相关接近 0，却与“两个分布多接近均匀”无关；两个只差温度的 unigram 模型惊奇度相关接近 1。所以相关会掩盖细节。
- §5.1 还看 conv 在上下文间的方差。附录 D 用线性回归同时放入 log 频率、目标与前一 token 词性、模型尺寸哑变量，每个 checkpoint 拟合一次。

### 零模型、上限与校准
没有置换零模型（词表对齐，不需要）；没有精确重跑上限；参照点是**第 0 步（初始化）的收敛度**、均匀分布与 unigram 分布的 KL（图 1 第二行）、不同尺寸之间互比。KL 单位没写（推测 nats）。

### 主要结果（含数字）
- 四阶段（§4、图 1；数值为图读数）：
  - 均匀阶段（约至第 16 步）：各尺寸相近，E[conv] ≈ −0.40；学习率很小，几乎不变。
  - 急剧收敛（16–256 步）：与“从均匀到 unigram 输出”的转变重合；E[conv] 升到约 −0.17 至 −0.20；也是已有工作中跨种子预测相关最高的阶段。
  - 急剧发散（256–2k 步）：模型开始离开 unigram、使用上下文；E[conv] 跌到约 −0.42 至 −0.45，**比初始化还低**；交叉熵此时仍单调下降。
  - 缓慢再收敛（2k 步起）：起点与 ICL 分数上升（induction head）重合；大模型回升更快：410m 终点约 −0.22，160m 约 −0.27，14m 约 −0.37（与初始化差不多），作者说最小模型 "do not in fact converge to a shared solution"（§4）。
- BLiMP（图 2 左）大体重复四阶段（数值很小，约 −0.01 至 −0.03）；MultiBERT（图 2 右）可见发散后再收敛。
- 条件收敛（§5、图 3；图读数）：前两阶段各类别走势相同（还没用上下文）。
  - 频率：最高频箱（≥10^6）在第三阶段停在高位并继续升到约 −0.1；低频箱（10^3–10^4）完整经历急剧发散，终点约 −0.6，**低于初始化**。
  - 词性：实词（名词、形容词、动词）发散更多、终点更低；虚词（DT、PRP、IN、MD）终点更高。附录 C：三类名词终点 ≤ 初始化；动词总体比名词收敛，VBG/VBN 低于 VBZ/VBD/VB。
  - 最终惊奇度：0–1 bit 的 token 终点收敛最强；1 到 8+ bits 之间差别不大。
  - 方差（§5.1、图 4）：前两阶段上下文间方差很小，后两阶段明显变大。
- 回归（附录 D、图 8）：频率系数在约 256 步后变正（α ≈ 0.05）；尺寸系数后期呈大模型正、小模型负；最小三个尺寸学习率相同但影响不同，作者据此说学习率预热不是唯一决定因素。
- 附录 F：低 / 中 / 高 KL 的 token 例子（高 KL 多为大写片段、代码符号等）。

### “大还是小”的参照
以初始化为零点：终点低于初始化即“训练使种子更发散”。以训练里程碑（unigram 阶段、induction head）定位阶段。以尺寸互比。

### 为什么不只是“一个相似度数字”
①**时间轴上的非单调**（收敛—发散—再收敛），与已知训练里程碑对齐；②**意外**：损失单调下降期间种子互相远离；③**条件分解**：频率 / 词类 / 可预测性决定谁收敛；④尺寸差异（小模型不再收敛）。

### 作者自述局限
①token 级 KL 要求同一分词器，跨家族不能比（可转字节 / 词级）；②只用 Pile 验证集的小子集；③只有英语；④早期学习率预热可能造成伪影。

### 我的批判
1. **样本很小**：4,662 个 token、5 个种子（10 对）。频率分箱若真在这 4,662 个 token 上计数（App A 的说法），“10^6 次”的箱不可能来自 D，§3 与 App A 的说法互相矛盾，原文没澄清。
2. **KL 不归一化**：两个分布间的 KL 会随分布变尖锐而变大。发散阶段正是模型从平坦的 unigram 走向尖锐的上下文预测，部分“发散”可能只是熵下降。没有按熵或按到某个参照分布的 KL 归一化，也没有上限。这和我们“除以精确重跑上限”的问题是同一类。
3. KL 不对称，没对称化，也没说 θ/θ' 两个方向是否平均。
4. 阶段与 unigram / induction head 的对应是**目视重合**，没有干预或统计检验。
5. 置信带是 1σ，没说明是跨种子对还是跨上下文。
6. 新意有限：van der Wal et al. 2025（PolyPythia）与 Chang et al. 2024 已报告种子稳定性和学习曲线；本文的增量主要是 KL 度量和四阶段命名。

### 公开审稿
EMNLP 2025 走 ARR，审稿不公开；OpenReview 搜索没有找到公开审稿记录。

### 对我们的启示与可预测的结果
- **训练时间是必须的轴**：路由可复现度很可能也非单调。预测：早期按 token 身份路由（unigram 式）时跨种子分区高度一致；路由开始依赖上下文时一致性下降；之后可能缓慢回升。我们固定词形的限制会去掉“按身份”的部分，所以在固定词形内看到的早期一致性应当低，这正好可以检验“分歧来自上下文路由”。需要对数间隔、包含早期的 checkpoint；只看终点会错过阶段。
- **条件分解**：按词形频率、虚词 / 实词、子词碎片 / 整词分别报可复现度。预测（与卡 1 一致）：高频虚词的上下文分区最先、最高地可复现；低频实词和子词碎片最不可复现，甚至低于随机路由器参照。
- **尺寸**：大模型再收敛更快、小模型不再收敛，预测我们的可复现度随规模上升；但我们的自训模型都很小，按这篇的结论，小模型终点可能本来就接近“初始化水平”，所以规模结论要靠公开模型补。
- **度量设计**：它的脚注 3（相关会骗人）与我们的“零模型 + 上限”同理；同时它自己没做归一化，给了我们一个反面例子：分区度量要防止“分区变细 / 变粗”本身改变数值。

### 研究问题与动机（原文）
- 动机（§1）：很多人希望 SAE 能 "identify and enumerate over all features in a model"（引 Elhage et al. 2022），从而检查“模型永远不会说谎”之类的安全性质；这预设了存在唯一、客观的特征分解。

### 设置
- 主设置：Pythia 160M 第 6 层 MLP 输出，2^15 个 latent，TopK，Pile 前 8B token，sparsify 库；**种子不同但数据和顺序完全相同**。共 9 个种子（36 对）。

### 度量
- 编码器余弦和解码器余弦**各做一次 Hungarian 匹配**；某 latent 算“共享”当且仅当两次匹配给出同一对象、且两次余弦都 ≥ 0.7（§3）。

**没有零模型**（没有随机字典、随机模型、置换基线），**没有精确重跑上限**。阈值 0.7 依据是双峰分布（图 1、A2：编码器 / 解码器匹配一致的点平均余弦 0.72，不一致的 0.33；A2 右图给出阈值扫描）。参照是先前 ReLU SAE >90% 共享的报告。
我的估算：d=768 维中 1 个随机单位向量与 3.2 万个随机单位向量的最大余弦约 0.16–0.2，所以“未配对”那一峰（余弦约 0.2–0.3）**基本处在随机水平**。论文没做这一比较。

- 双峰：高相似“命中”和低相似“未命中”；编码器、解码器余弦强相关；两次匹配不一致的点两种余弦都低（图 1）。
- 主设置一对种子共享 **42%**；Llama 3.1 8B（131K）**30%**（§1、§3）。
- 多种子（§4.1、图 A1）：9 个种子时只在一个 SAE 出现的 latent 约 **35%**（2 个种子时约 58%）；带偏移项的幂律显著优于无偏移——总有一部分永远找不到对应。

- 可解释性（§4.2、图 3、表 1）：32K SAE 平均解释分 0.72（四分位 0.62 / 0.8）；被更多种子共享的 latent 平均分更高；但只出现在一个 SAE 的 latent 中有相当一部分分数很高（表 1：对齐 0.10 的一对，种子 1 的解释“美国最高法院判例引用中的国名缩写”分 0.865，种子 2 的对应只得 0.56）。

### 为什么不只是“一个相似度数字”

### 作者自述局限

### 我的批判
1. **训练不足混杂**：训练 token 从 0.8B 到 80B，共享率从 0.07 到 0.61，8B 的主设置远未饱和；“种子依赖”有很大一部分是欠训练。

3. 没有随机基线；未命中峰接近随机余弦水平（我的估算）。
4. 没有精确重跑上限（同种子 GPU 非确定性）。

### 对我们的启示与可预测的结果
- **单元数 / k / 训练量三条趋势都要正面回应**：SAE 中 latent 越多、k 越大，单元级共享越低；训练越久越高。我们观察到“专家越多分区越可复现”，与 SAE 方向相反。要成为一个结论，必须排除：①度量的零水平随专家数变化（卡 4）；②k 随专家数一起放大（细粒度 MoE 的常见设定）；③每个专家得到的 token 量随专家数变化（与 Paulo 的宽度混杂同构）；④训练量未饱和。
- **频率非单调**提示：最罕见词形不可复现、高频词形可复现，但中高频段可能有一个凹陷——即频繁但被不同种子切法不同的词形（候选：多义虚词、标点）。这是“横穿”最可能出现的地方，值得先看。
- **未命中≈随机水平**：我们的“扣除随机路由器零模型”已经比这篇严格；报告时要明确给出零模型和上限的绝对值，避免被问“这个 0.5 是多少”。
- **审稿教训**：只报“种子之间有多不一样”会被打 2 分；要同时给机制（嵌套 / 横穿、为什么）和后果（例如互换专家后损失是否不变、或分区差异是否带来功能差异）。

### 研究问题与动机（原文）
- 背景（§1）：Platonic Representation Hypothesis（Huh et al. 2024）认为随规模增大，跨模态表示越来越相似；大量后续工作用相似度研究“规模是否产生普适结构”。
- 立场句（§3.2）："a similarity score s(X,Y) is uninterpretable without a baseline"——没有基线的相似度分数不可解释。
- 两个混杂（§1、§4）：①**宽度**：维度相对样本数增大时，交互矩阵类度量即使在独立表示之间也有随 d/n 增长的正基线，宽模型因此“看起来更对齐”；②**深度**：在所有层对上取最大值，层越多最大值越高（look-elsewhere 效应）。两者是层级关系：宽度给每个层对一个正的偶然相似度，深度提供更多抽样机会。
- 问题（§1）：校准之后 PRH 还成立吗？答案：全局谱度量的收敛趋势基本消失；局部邻域度量保留显著对齐；但局部**距离**不对齐。据此提出 Aristotelian 假设：表示收敛到共享的局部邻域关系（"who is near whom"）。

### 设置
- 合成（§6.1–6.2）：H0 下 X、Y 独立取自高斯 / Student-t / Laplace / 高斯混合；n ∈ {128,…,4096}，d ∈ {128,…,2048}；H1 注入共享低秩信号并调信噪比；深度实验 L 层 i.i.d. 表示，d/n = 8，L 从 2 到 128。
- PRH 复现（§6.3）：沿用 Huh et al. 协议，n = 1024 对 WIT 图文；语言 BLOOM / OpenLLaMA / LLaMA，视觉 ImageNet-21K / MAE / DINOv2 / CLIP / CLIP-finetuned，多尺寸；视觉取 class token、语言取 token 平均；**204 个视觉–语言模型对**，d/n ∈ [0.19, 8]；逐层算相似度并取最大值（与原文一致）。视频：VideoMAE s/b/l/h（Kinetics 微调与未微调），PVD 测试集 1024 个样本（附录 E.9）。
- 度量：线性 / RBF CKA、无偏 CKA、CCA / SVCCA / PWCCA、RV、RSA（Spearman）、Procrustes；mKNN、cycle-kNN、CKNNA，k = 10（附录 B 给出全部公式）。

### 零模型与校准（精确定义）
- H0（§3.2）：除边缘统计外 X 与 Y 无关系；用**置换样本对应关系**实现（固定 X、打乱 Y 的行）；Assumption 3.1 可交换性。
- 理论（§4）：Prop 4.1：独立、各向同性时 E‖C̃‖_F² = d_x d_y /(n−1)，CKA 零基线为 O(d/n)；Prop 4.2：mKNN 零期望 = k/(n−1)，即 O(k/n)，与宽度无关；深度：E[T_max] ≤ μ + Cσ√(log M)，M = L_A·L_B。附录 C.5（Prop C.5）：即使有真实共享信号（总体 CKA = ρ²），固定 n 时样本 CKA 随 d → ∞ 趋于 1。CCA 族另有一套秩亏模式（均值 CCA 在 d≈n 达峰，PWCCA 饱和，SVCCA 基本不敏感）。
- 标量校准（§5.1）：K 个置换得零分布；τ_α = 合并（观测 + 零）集合的第 ⌈(1−α)(K+1)⌉ 个次序统计量；p = (1 + #{零 ≥ 观测})/(K+1)；**s_cal = max((s_obs − τ_α)/(s_max − τ_α), 0)**。Corollary 5.1：s_cal > 0 是有限样本 α 水平的“高于偶然”判定。
- 聚合感知校准（§5.2）：每次置换对 B 的**所有层用同一个置换**，计算同样的聚合统计量（如最大值），对其零分布取阈值；T 为最大值时即 Westfall–Young maxT。
- 实施：K = 200–500，α = 0.05；模型对之间做 Benjamini–Hochberg FDR。

### 主要结果（含数字）
- 宽度（§6.1、图 3、附录 E.7）：原始分数随 d/n 漂移，校准后归零；CKA 和 RV 漂移最强，邻域度量最弱，RSA 基本不漂移；重尾噪声同样（图 16）；**即使 X、Y 来自同一输入经独立随机线性 / MLP 网络**，原始 CKA 仍随 d 膨胀，校准后为零（图 17）。
- 统计保证（图 4）：各 (n, d/n) 下第一类错误 ≤ 0.05；功效随信号迅速上升。附录 E.4：校准后的 CKA 与 Murphy et al. 的去偏 CKA 高度一致。附录 E.3：门控分数、减零均值、ARI 式校正都能回到零，**z 分数在零分布偏斜时出伪影**。附录 E.6：τ 在 K ≈ 50 稳定，建议 K ≥ 200。附录 E.1：高噪声下原始分数仍停在约 0.4–0.6，校准后接近 0。
- 深度（§6.2、图 6）：H0 下原始最大值随层数从 2 到 128 单调上升；逐项校准后再取最大值仍膨胀；只有聚合感知校准稳定。
- 真实网络上宽度修正（附录 E.5、图 13）：固定 n = 1024，DINOv2 与 AugReg ViT 族内各尺寸配对，置换阈值 τ 与总宽度 d_X + d_Y 的 Pearson r = 0.88。
- PRH（§6.3、图 5、表 2）：
  - 未校准 CKA 随规模上升（复现原趋势）；校准后无系统上升。图读数：CKA-RBF 对 DINOv2，原始约 0.4–0.6，校准后约 0.1–0.28（BLOOM 到 OpenLLaMA 有跃升，之后平或略降）。
  - mKNN 对 DINOv2 约 0.08–0.16，原始与校准几乎重合（零基线 k/(n−1) ≈ 0.01）。
  - 与语言模型能力排名的 Pearson 相关（校准前 → 后）：线性 CKA 0.86 → 0.45；RBF CKA 0.83 → 0.35；无偏 CKA 0.65 → −0.01；Procrustes 0.89 → 0.39；RV 0.92 → 0.31；mKNN(k=10) 0.85 → 0.84；CKNNA(k=10) 0.87 → 0.87；cycle-kNN(k=10) 0.85 → 0.85；k = 20/50/100 时邻域度量基本不变（cycle-kNN k=100：0.77 → 0.74）。
  - 显著性（附录 E.8、图 24）：204 对全部 p < 0.05，多数 p ≈ 0.002（K = 500 的最小值）——全局和局部都“显著”，差别在**校准后效应量的大小和趋势**。
  - 视频（图 7、附录 E.9）：校准后 CKA 无趋势；mKNN 在 VideoMAE-Large/Huge 上出现规模趋势，小视频编码器成为瓶颈；微调与规模都提高邻域对齐。
- 局部性（附录 E.10）：mKNN 在 k = 10 到 100 都显著，趋势在 k = 10 最明显、k 大时变平（大邻域一致性已饱和）；CKA-RBF 带宽 σ = 0.1（只看极近距离）时原始分数接近 1、校准后约为 0、多数 p > 0.05；σ = 0.5 有对齐但趋势变平；σ = 2、5 同。作者结论：跨模态一致的是**哪些点是邻居（序数）**，不是**邻居有多近（基数）**。
- α 敏感性（附录 E.11）：α = 0.01 / 0.05 / 0.10 结论不变。

### “大还是小”的参照
置换零分布给出零点，s_max = 1 给出上端；p 值给证据强度；跨 metric 不直接比较绝对值，而比较**同一度量在校准前后与规模的相关**。作者自己承认相似度没有真值尺度（§7）。

### 为什么不只是“一个相似度数字”
①**纠正一个著名主张的解释**（全局收敛是混杂造成的）；②**粒度 / 尺度分离**：局部邻域收敛、全局几何不收敛，进一步细到“序数一致、基数不一致”；③给出通用、带有限样本保证的方法；④把结论落成一个可检验的新假设。

### 作者自述局限
①相似度没有真值尺度，只报告“是否有校准后的收敛证据”；②保证依赖可交换性，分组 / 聚类样本需要受限置换（附录 C.1 提到按块置换）；③为什么局部收敛而全局不收敛仍是开放问题。

### 我的批判
1. **置换零模型是最弱的零模型**（“完全无关”）。它不扣除“同一输入经任何网络都会带来的结构”。附录 E.7 显示随机网络在同一输入上也会让 CKA 膨胀，但作者只用它说明宽度混杂，没有把“随机网络处理同一输入”作为第二个零模型来校准真实模型。对我们而言，随机路由器在同一隐状态上的零模型恰恰是这个更强的零模型。
2. **校准分数的形状会改变趋势**：(s − τ)/(1 − τ) 既平移又放大；τ 随宽度变化时，放大系数也随之变化。“趋势消失”部分取决于这个形状；线性 CKA 校准后仍有 r = 0.45，说“基本消失”偏强。审稿人 nYME 也指出全局与局部度量不在同一尺度。
3. **mKNN 的“经受住校准”几乎是必然**：零基线约 0.01，校准近乎恒等变换。它没检验 mKNN 在 H1 下是否也有宽度依赖（更宽的表示可能邻域更“干净”）。
4. 规模轴是语言模型能力排名，与模型家族混在一起（BLOOM → OpenLLaMA 的跃升在校准后的 CKA 中也存在）。
5. 原 PRH 论文已强调局部 mKNN 上的收敛最明显（审稿人 g1yz 的 W1），“Aristotelian”的增量主要在“全局不收敛”这一半。

### 对我们的启示与可预测的结果
- **专家数就是我们的“宽度混杂”**：分区一致性的度量（成对共现、ARI / NMI / VI、置换不变的最佳匹配）其零水平都依赖簇数 E、簇大小分布、top-k 与负载均衡。NMI 随簇数增加有已知的向上偏置。所以“可复现度随专家数上升”这个结论**必须在每个 E 上用同一流程重新生成零分布**，并且检查：减零均值、门控重缩放、除以上限这几种校准形状是否给出同样的趋势（附录 E.3 的教训：z 分数在偏斜零分布下出伪影）。
- **深度混杂的对应**：若报告“各层中最好的一层”或“最佳匹配的层对”，层多的模型会被抬高；Hungarian 专家匹配本身也是一个选择步骤，零模型里必须同样重新匹配（聚合感知校准）。
- **可交换性**：同一文档、同一词形的 token 出现彼此不独立；置换要在词形内 / 文档块内做（附录 C.1 的受限置换）。
- **结构上的类比与区别**：它的“局部邻域一致、全局几何不一致”与我们的“粗组一致、细分配不一致”形式相同但方向可能相反——我们的粗组一致相当于“大 k 的邻域一致”，细分配不一致相当于“小 k 不一致”；它发现规模带来的提升集中在最细的局部（k = 10）。这给我们一个可证伪的预测：如果 MoE 与稠密表示同理，规模（与专家数）带来的可复现度提升应集中在**最细粒度**；如果提升只在粗粒度，那就是 MoE 特有的现象。
- **零模型选择**：用随机路由器（同一隐状态）作零模型比置换更强，应当保留；同时可以再报一个置换零模型，展示两者差距（即“共享输入本身带来的一致性”有多大）。
- **审稿教训**：方法里的统计工具不新会被扣原创性；改名式的“新假设”被三位审稿人质疑；真正立得住的是“同一流程下，哪种度量的趋势在校准后保留”。我们的叙述应落在“在零模型与上限校准后，哪一层级的分区随专家数 / 规模可复现”，不要发明口号。

## 四篇合起来：对候选问题的定位

1. **问题形态已被接受的写法**：卡 3 证明“同数据、只换种子，单元不收敛”可以被接收（但打分两极）；卡 1 和卡 4 的共同升级路线是**粒度分离**——单元 / 全局不收敛，子空间 / 局部收敛。我们的“逐条路由不一致、分区可复现、分歧是否嵌套”正落在这条路线上；风险是被说成“卡 1 的 MoE 版”或“可辨识性理论早已预言”（卡 1 的 mXy5 意见）。要说清 MoE 的不同：路由是离散的、硬分配、带负载均衡和 top-k，对象是 token 出现的分区而不是激活空间的方向；以及我们的专家数趋势与 SAE 宽度趋势方向相反。
2. **四篇共同缺的东西**：精确重跑上限（四篇都没有）；对 Fehlauer 和 Paulo 来说还缺零模型。我们已有“上限 + 随机路由器零模型”，这是相对它们的一个实质增量，应在文中正面展示两者的绝对值。
3. **必须先排除的混杂**（来自卡 3、卡 4）：度量零水平随 E 变化；k 随 E 变化；每个专家的训练 token 随 E 变化；训练未饱和；层 / 匹配的选择膨胀；样本不可交换。
4. **可预测的结果模式**（来自卡 1、卡 2、卡 3）：可复现部分集中在高频、整词、虚词的上下文分区；不可复现部分集中在低频、子词碎片、标点；中高频的多义虚词可能是横穿型分歧的高发区；时间上可能先高（按身份路由）后降（上下文路由）再缓慢回升；规模越大再收敛越快；可能存在非零的不可复现平台。
5. **审稿人一贯的要求**：机制（为什么嵌套 / 横穿）和后果（分区差异是否带来功能差异）。只给一致性数字会被评为“现象学、表面”。
