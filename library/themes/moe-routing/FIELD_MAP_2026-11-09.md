### A3. 小结：增长 / 饱和 / 2026 接收需要什么

- **增长：** Q2（怀疑 / 对照）、Q3（路由器输入机制）、Q4（多语 → 路由对齐当训练目标）、Q5（路由作把手）。Q2 与 Q3 正在汇流：Ye 2604.17837 把"路由器只看行空间"做成分析工具，Routing Drift 2609.32821 用"交叉套用输入 / 参数"把重分配归到输入漂移，Misrouting 2605.07260 用等算力替代路由当参照——**"拿一个可替换的参照路由来读训练路由器"已经是 2026 的通用动作**，只是参照各不相同（行空间投影、替代路由、源模型路由器），**同一隐状态上的随机路由器族**仍只有 Melton 一家。
- **饱和：** Q1 单模型描述统计；Q6 剪枝方法；Q8 专精损失。对 Q1 的读数加零模型，本身会被归入 Q2 的形态。
- **2026 接收的规模与逻辑（从上表归纳，不是规则）：** (1) 面板 = Qwen3-30B-A3B、GPT-OSS-20B、OLMoE、DSV2-Lite、Mixtral / Phi-3.5 中的 3–6 个；(2) 标题或摘要里有一个被点名的流行信念（"illusion"、"myth"、"strikes back"、"drift alone does not diagnose"）；(3) 一条因果 / 干预腿或下游连接（steering 增益、AIME pass@K、Belebele、遗忘 BWT），纯相关审计在扫描范围内尚未见主会接收；(4) ML 会（ICLR / ICML）多附一个方法或可复用工具（分解法、MH-MoE、HARC），ACL 接受"描述 + 对已有读法的修正"（Standing Committee）；(5) 语言轴通常 10–20 语（FLORES / Belebele），token 类对比少见（Standing Committee 的"句法骨架词"、Ye 的":"例子是少数）。

### B3. 定位层面最要紧的三条事实（不含判决）

1. **Ye/Yuan/Sharkey 2604.17837 是 N1 与 N2b 共同的最近邻**，此前旧笔记只有一行摘要。它在 6 个公开 MoE（与我们的面板重合 4 个）上 own 了"路由器读到的是行空间里的抽象功能、语言 / token / 位置在路由器看不见的通道"和"路由器放大高幅值维度"。差别：它没有随机路由器、不分因子、不在 token id 条件下量、只在 GPT-OSS 上给跨语例子；它是 workshop 海报（无 limitations 节）。
2. **Routing Drift 2609.32821 已经把"交叉套用输入 / 参数拆分路由变化"用在合并 MoE 上**（含 Qwen3-MoE、OLMoE），并得出"输入漂移为主、路由差异不预测功能"的结论——这是 E187 方法的先例，也是 N3 的同型结论（另一场景）。
3. **纯相关的零模型审计在扫描范围内未见主会接收**；接收的怀疑型工作（Standing Committee ACL'26、Expert Strikes Back ICML'26）都提供了一个新单元或新读数，Q4 / Q5 的接收作都带干预或下游收益。这是地图事实，不是对我们的判决。
