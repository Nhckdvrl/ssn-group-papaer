# Sasano 组内研究形态：三张定向论文卡

更新 2026-10-03。目的：学习自然问题、测量和增量的形成方式；不是提议复制组内题目。全部数字为原文报告，未自行复现。详细 Slack 校准见 [证据备忘](../../../search/sasano-taste/SASANO_EVIDENCE_2026-10-03.md)。

## Can We Still Trace L1 Signals?（作者声明 EMNLP 2026 Main；v4，2026-09-16）`[证据级别：全文主文、表格与局限]`

来源：[最新版全文](https://arxiv.org/html/2604.08568v4) · [版本与会场声明](https://arxiv.org/abs/2604.08568v4) · [数据](https://github.com/nabelanita/academic-l1-signals)。旧题为 *Can We Still Hear the Accent?*，不能沿用旧版摘要代表最终工作。

1. **形态：** 真实语言变化的测量 + 受控干预。自然问题是写作辅助普及后，作者原有语言习惯是否仍可辨认。
2. **背景/前提：** LLM 写作同质化的直觉，需要放回 NMT 已存在的更长历史；NLI 不只检测学习者的明显语法错误，也可作为熟练写作中的语言痕迹读数。
3. **idea 来源：DOCUMENTED** 为引言串起 translationese、NLI、LLM 用词变化；**RECONSTRUCTED** 为“用历史对照削弱单一新技术解释”。不能声称作者最初灵感产生于哪个实验。
4. **最近邻距离：** Koppel 等的 NLI 任务、Tetreault 等学习者语料、Volansky 等 translationese、Liang 等学术文本 LLM 使用测量；增量是熟练学术写作的 L1 信号、三时代比较及同一文本的受控改写。以上为作者相关工作脉络，邻居全文本轮未逐一重读。
5. **实验：** 1,600 训练、1,200 评估摘要，8 语言组；Qwen3-14B/Gemma-3-12B-it 单 A100 80GB QLoRA；3 rewriter × 3 prompt，改写与分类避免同模型配对。Qwen 准确率 0.728→0.650→0.633；后两时代差异 p=0.6583。这是作者报告的检验，不等于两时代完全相同。
6. **短板：** 原生语言标签是代理；有重复采样，时代/领域/作者群变化仍混杂；统一整段改写不是现实使用比例。主文承认不能把语言群体差异直接归因于具体工具使用。
7. **可迁移动作：** 热点解释 → 加历史 baseline → 同对象干预；将自然观察与人为高剂量干预分开。
8. **对我们：** 可学再归因与 evaluator 校准；直接做 AI 写作的 L1 同质化属于组内重叠。小训练可以改善测量工具，不能用弱 zero-shot classifier 的失效冒充内容不存在。

## When Is 0.1% Enough?（arXiv 2606.01074；最终会场未核对）`[证据级别：全文主文、主表与方法]`

来源：[全文](https://arxiv.org/html/2606.01074v1) · [原始入口](https://arxiv.org/abs/2606.01074)。

1. **形态：** 统一预算下的系统测量与规律解释。
2. **背景/前提：** 量化和降维各自成熟，但同样的每向量 bit 预算可以分配给更多维度或更高精度；只各自画一条曲线不回答组合策略。
3. **idea 来源：DOCUMENTED** 为引言的存储压力与两条压缩轴；**RECONSTRUCTED** 为沿组内已观察的任务冗余差异，增加第二个自然操作轴，而不是找无人触碰的领域。
4. **最近邻距离：** Tsukagoshi/Sasano 的降维冗余分析、MRL（Kusupati 等）、Takeshita 等随机删维、Huerga-Pérez/Caspari 等联合框架。作者明确承认已有联合压缩工作；增量放在统一预算、跨任务的 trade-off，而非首次组合两算子。
5. **实验：** 4 模型、4 MTEB 任务族；Head 与 PCA+随机正交旋转；1/2/4/8/16/32 bit。Qwen3 embedding 的示例分类分数 89.51→89.26（1/128 存储）→88.62（1/1024）；retrieval 更敏感。校准无标签但按任务拟合；评估前还原 float32。
6. **短板：** 0.1% 不是所有任务；分类还训练 logistic regression，其补偿能力不同于直接使用距离的任务；名义预算不是端到端延迟/内存，查表与投影成本也需考虑。公开评审未核对。
7. **可迁移动作：** 两个成熟操作 → 同预算比较 → 从任务差异定位可补偿信息与必要几何。
8. **对我们：** 冻结模型+缓存中间资产，非常适合弱互联资源；不能把“卡多”替代 I/O 估算。此主题已有直接组内 owner；适合复用研究动作，不宜直接另开同题。

## To Drop or Not to Drop?（LREC-COLING 2024）`[证据级别：全文主文、标注流程与主表]`

来源：[论文](https://aclanthology.org/2024.lrec-main.1408/) · [全文](https://aclanthology.org/2024.lrec-main.1408.pdf) · [JAOJ 数据代码](https://github.com/cl-tohoku/JAOJ)。

1. **形态：** 自然语言选择的理由标注 + 人模型对照。
2. **背景/前提：** 传统零照应关注补回被省略的信息；这里关注说话者为什么选择省略或保留。可恢复不自动等于表达自然。
3. **idea 来源：DOCUMENTED** 为作者先做小规模试标，结合日语语法归纳 5 因素；**RECONSTRUCTED** 为把理解任务翻转到表达者的选择，保留自然语料而不只做人工最小对。
4. **最近邻距离：** Sasano/Kurohashi 的省略恢复、Iida 等零照应、Jaeger/Levy 的信息论省略、Schäfer 等特定结构省略；变化在自然语篇的论元选择、理由与共识。邻居在本文相关叙述中核对，未逐篇精读。
5. **实验：** BCCWJ 32 文档、2,373 论元、5 名母语者；Krippendorff α=0.87。4 类判定 Macro-F1：人 59.3±2.8、GPT-4 25.2、BERT-base 51.0±0.6；±为标准差而非置信区间。baseline 包含随机与按格选择多数类，BERT 为5种子；按文档切分。
6. **短板：** 因素决策树会塑造答案；人评是成对一致性、模型是对聚合标签，不能直接当相同准确率；上下文截成512 subwords、无有效输出时随机赋标签。原文明确说 supervised BERT 强于 zero-shot LLM 本身并不意外。
7. **可迁移动作：** 自然选择 → 显式理由 → human-noise profile → 相同上下文的模型预测；应先重做强提示词、解析与上下文 baseline，再宣称能力缺口。
8. **对我们：** 是 pragmatics/human-judgment 驻留入口与评估经验，不是2026模型能力的现成结论。完整语料访问许可本轮未核对。
