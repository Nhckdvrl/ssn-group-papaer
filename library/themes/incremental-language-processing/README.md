## Scope
Language-model processing as evidence arrives over time:
- temporary ambiguity and commitment;
- reinterpretation / reanalysis;
- cue timing and cue strength;
- lingering interpretations;
- disagreement among behavioral and internal readouts;
- generalization of revision processes across ambiguity classes.

## Exclusions
- FrameNet/frame induction;
- idiom-specific work;
- AI-writing-change studies;
- embedding compression;
- generic ambiguity benchmarks;
- benchmark-score enhancement;
- garden-path recovery as a standalone novelty claim.

## Entry principle
Start from released psycholinguistic stimuli and frozen models. Use garden-path data only as a positive-control/calibration substrate, then let competing accounts determine which ambiguity class or intervention is added next.
