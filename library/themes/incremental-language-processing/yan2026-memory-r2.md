1. **idea来源（RECONSTRUCTED）：** memory-action改变未来输入，某session失败可能来自继承损坏state或以后覆盖，而不是当前edit→将原global终点credit按session证据归属拆开→同anchorstate只重采当前session→local、global共同优化，共享extractor/manager并扩sessionhorizon。增量是中间操作的可比较起点与归属，而非一般memoryreward更密。论文从全生命周期细化到具体训练比较对象，值得借这个尺度。
2. **方法：** 两role共享Qwen2.5，extractfacts再INSERT/UPDATE/DELETEbank。step-ratio为token logratio均值的exp，stepadv均值，dualclipobjective；global16trajectories，Qt为session所属QA，globalreward按terminalMT作，local每session.5选／anchor旧M／4rerolls，只当下Mt的Qt reward，两branchstep同归一化。memorytoken超cumulativeinputα预算的惩罚λcomp.3，8/16/32curriculum10/5/5epochs。
3. **理论界限：** 同原始起点采样的完整MDP轨迹中间state本来会不同，标准trajectory policygradient不要求每一步state一样；不能仅因本文措辞“violates key GRPO assumption”宣告全球RL无效。local rerollout改善中间归属和variance是具体可检验动作，本文用性能/消融支持它，没有证明通用unbiasedGRPO定理。我们借比较设计不借过强理论口号。
4. **数据／算力：** LoCoMo10conversation按2/1/7split，训练2conversation但328QA和大量turn/session，不把“2条”当两句数据；原成熟数据沿用。heldoutLongMemEval-oracle/s、MSC-Self-Instruct、MemBench。memory训练fixedGPT-oss120Banswerer；主表另Q7Bansweragent GRPO训练5epochs，生成prompt/样本依赖GPT4o且按F1≥.25筛训练QA。旧公开baseline引用结果不等同全部同数据/同compute新复现；old3/7samefamily，跨answerfamilytransfer不是三trainedfamilies。
5. **结果和反证：** Q7B完整主表F1/B1/J50.60/44.01/80.99，R1 43.14/36.44/61.51。OSSanswer49.67/43.77/87.10，F1较低但J更高；不能只选F1声称较小模型全优。Open-domain Q7B F120.76低MemAgent29.20等。full vsGRPO49.67→46.62，nocurriculum24.12，nolengthnorm43.53；basearchitecture／trainingtarget差别和local额外rollouts仍是成本范围，不能把所有总体收益只归localbias。AppTable3 mean±std三独立run不同seeds，但未逐独立trainartifact核。
6. **数据构念／用途：** M-Fail为missing gold evidence dia_id比例，不是这些IDs对应事实被语义忠实保存的概率；同源tag可挂错内容，不能以6.72%保证正确事件/关系。QA F1短词匹配和gpt4omini lenientJ分开；原prompt有factsmonotonic20words/entry、timestamps/最新信息优先以及DELETE与UPDATE规则。读到guideline/example张力并不延伸为bug修复研究；训练code未全核，不宣告原方法错。
7. **最近邻距离：** Memory-R1／Mem-α已有学write/update，ReBel/GiGPO已有stepgrouping，ReMA共享multiagentrole已有；本文占有same-anchorlocal＋global在记忆bank长期链上的组合和课程。I07不是它的起点公平性对象，我们固定source及两个解释问credit是否识别正确关系。一般局部credit／共同state比较不能称我们的首创，也不能因为邻域拥挤而关线。
