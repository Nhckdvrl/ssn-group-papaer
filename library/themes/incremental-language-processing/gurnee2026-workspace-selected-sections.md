1. **形态：** 内部表示测量、因果交换与功能选择性的统一研究。
2. **背景与压力：** 中间概念可能不写在输出里，却供多个后续计算使用。单个prompt的梯度混合一般可表达性与当前任务用途；词可读不等于会参与当前计算。
3. **改变的前提：** 同一概念在报告、灵活推断、自动处理中的出现与因果使用可以分离。跨用途因果交换比看见token名称更接近功能证据，但不是所有认知/意识的证明。
4. **idea来源（RECONSTRUCTED）：** 以全局工作空间的broadcast/选择性性质提出可检验预测，再用跨1000预训练式prompt、所有后续位置平均Jacobian定义lens；同一概念方向在不同下游函数中交换，最后检查哪些任务绕过该空间。这是从“可表达中间信息”走到“多用途共同因果接口”，不冒充作者实际发现顺序。
5. **最近邻距离：** 本文已经直接拥有一般跨用途broadcast交换与可读/使用分离的实验，不能把E63同一donor用于两任务直接称novel。其limitations明确bag-of-concepts尚未解析角色绑定结构，这给自然结构修订提供具体对象；是定位和迁移入口，不是空白保证。全文Related Work尚未读，不能据此声称完整近邻检索。
6. **方法/规模/对照：** 平均Jacobian→逐层词方向；国家/月/动物/数字4类×4函数×12交换=192，普通交换top1成功76/192，双强度101/192；弱loading与失败关联。语言8篇/多用途、字符11篇/3任务、14任务消融面板，top10方向消融排除clean forward top10输出token，另有随机/匹配norm控制。多数定位使用生产Claude模型，不能预设我们的8–12B开源模型等价。
