# Retrieval interference in sentence comprehension（Van Dyke & McElree, JML 2006）`[证据级别：正文部分]`

来源：[作者稿](https://pmc.ncbi.nlm.nih.gov/articles/PMC2206541/)。2026-10-06实际读Introduction、前人对比、Table1设计、General Discussion；具体Participants/Materials/统计表未逐项核对。随后PMC出现recaptcha，不把未访问部分称为已读。

1. **形态：** 两解释的受控区分：encoding/storage干扰 vs retrieval cue-overload。
2. **压力：** Gordon等names/definite NP类别匹配和memory-load效应不能唯一定位干扰发生在哪里。
3. **改变前提：** 不只改变已记住词的类别；保持memory-load内容，改变后续动词的semantic retrieval cue，使同一组词可以/不可以成为合理object，交叉load/no-load。
4. **idea来源（DOCUMENTED）：** 旧相似性实验的干扰位置无法区分；借普通记忆研究里的cue-overload做语言实验。
5. **近邻距离：** Gordon2001/02/04的NP类型匹配；Van Dyke/Lewis2003句法cue；Van Dyke2002/06语义与句法cue。本文用外部load与后续verb cue交互检验retrieval，而非另一个总体阅读慢效应。
6. **设计（已读范围）：** 先记table/sink/truck，再读object-cleft带sailed/fixed，另无load对照；Table1理解题与关键依存分开。Discussion报告关键verb区load×interference，并说明动词整体合理性仍影响理解accuracy。未核对原表数值，不抄具体effect size。
7. **限制：** 不能完全排除编码语义相似性；人类工作记忆load不等同LLM上下文库存，阅读时长也不等同LLM字符串NLL。
8. **可迁移动作：** 因果线索分别放在证据形成与使用处，让两解释的交互预测不同；无load/无额外inventory不能省略。
9. **对本线：** 额外名字/描述清单对预测的影响不是从未见过的认知构念。E47清单效应可兼容检索干扰、重复/篇章偏好；E48必须报告raw activity、neutral和old/new，不用一个subtraction决定机制。若要研究实际能力错误，要另测有明确正确角色的功能任务。
