# Representation Interventions Enable Lifelong Knowledge Memory Control in LLMs（ACL2026 main；RILKE）

[正式会议稿](https://aclanthology.org/2026.acl-long.246/)，作者称oral。已读正式PDF完整主文§1–9（5414–5423）；附录尚未深读。arXiv v4也缓存，但以下以正式稿为准。

1. **形态：** 现有技术的新问题设定+机制动机+方法与规模验证。
2. **压力：** 参数编辑在长期自由文本更新中退化；外部模块不能轻易兼顾复杂知识、改写泛化和大量更新。
3. **改变前提：** 编辑不必直接改基础权重；用表征干预模块存更新，并由查询选择模块。
4. **idea来源（RECONSTRUCTED）：** ReFT/表示工程已有→观察query语义局部性与学习干预的相似性→用扰动一致性修改写泛化，用稳定的原query表示路由，再把相近更新共享模块减少内存。创新由三种实际压力组织已有工具，而非宣称完全空白。
5. **最近邻距离：** ReFT是干预基元；ReKE限单次结构化编辑；GRACE/WISE为记忆式对照；UnKE/AnyEdit针对自由文本但长程性能退化。RILKE以自由文本、连续积累与改写泛化形成整体方法故事。
6. **方法/规模：** 2族Llama3.1 8B/Qwen2.5 7B；UnKE1000更新、ZsRE3000、附录EditEverything；MMLU作通用utility。冻结LM，低秩ReFT模块+高斯扰动输出KL，query原h作为不变index，cosine门控阈.9，语义聚类共享模块。训练原query精确匹配index，所以原query高分和未见改写必须分开。
7. **证据：** Llama1000更新，原指标近1，改写报告BertS .963/RougeL .882；共享模块96.1→29.4MiB，改写指标 .963→.901。严格同cluster序列摄入测试10clusters平均13项，原 .742/改写 .723，并非全局1000同模块连续更新。其BertS按正文实际为MiniLM句向量cosine，不等同事实完全正确；两种geometry性质为经验分布而非∀query定理。主文没有seed CI；不把R矩阵cosine直接当唯一语义因果分量。
8. **可迁移动作：** 确定改变的对象、改变如何泛化、怎样共存，再用同一套结构组织方法。新方法可从明确缺陷和已观察几何生长，不需新工具。
9. **对我们：** E65“另一关系”的迁移与这类“同一query改写”的泛化不同；可以学习局部模块与路由动作，但先确认自然结构修订的具体规律。若只有某题得到新答案，不自动等于Source解释更新；若相关角色要求不同作用，共享更新单位本身就值得研究。当前未证实，不照搬模块定题。
