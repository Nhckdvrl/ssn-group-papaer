# What Attention Recalls and Recurrence Controls in Hybrid Language Models（Findings of EMNLP 2026，abs 页注明；arXiv v1 2026-09-03，分数 —）`[证据级别：全文]`

- 作者：Kirill Afendulev, Alexey Dontsov, Elena Tutubalina, Anton Korznikov（HSE / YSDA / AIRI）。arXiv:2609.04434v1，abs 页已核对。
- 阅读范围（2026-11-25）：正文 §1–6、局限、附录 A–H（实现、split-prefill 细节与"递归状态未被读入"陷阱、数据集、全表含 9 个模型、state-swap、自报告探针、DRM、合成词陷阱）。

1. **论文形态**：cache 级因果干预 + 行为读数（功能分离）。
2. **背景与压力**：hybrid 中注意力与递归两个通道各自携带什么不清楚；常见"注意力 = 长期精确记忆、递归 = 短期缓冲"的时间分工假说。
3. **改变的前提**：不按信息"年龄"分，而按"访问类型"分：prefill 上下文后只保留 KV（递归状态清零）或只保留递归状态（KV 丢弃），以及把 A 上下文的 KV 与 B 上下文的递归状态拼成一个 cache（state-swap）。
4. **idea 来源（DOCUMENTED）**：认知心理学外显/内隐记忆（Tulving、Schacter），DRM 假记忆（Roediger & McDermott），记忆合成错误（Reinitz 1992）。
5. **与最近邻的距离**：2609.33093（donor-margin 载体分析，同结论"检索在 KV"）→ 本文加"递归携带什么"（语言、人格、语义场）；2611.01909（递归层构造注意力的查询）→ 本文的 REC-ONLY 检索为 0 与之相容（查询要靠当前 token 的递归计算，而值在 KV）；Borobia 2603.22473（组件消融）→ 本文用不重跑上下文的 cache 拆分。
6. **方法 / 实验 / 数据**：
   - 模型：Qwen3.5-4B、Qwen3.5-9B（GDN:attn 3:1）、Falcon-H1-3B-Instruct、Falcon-H1-7B（并行 Mamba + 注意力）；单种子扩展 Qwen3.5-27B、Falcon-H1-34B；点估计 Kimi-Linear-48B、Olmo-Hybrid-7B、Jamba2-3B。
   - 任务：KV retrieve（15–30 条字典，取单键值）；list indexing（4–10 元素列表按位置取）；language following（18 种语言）；persona（15 人设，Qwen2.5-72B 评判）；DRM 联想陷阱（100 表）；合成词陷阱（200 项，如 sunflower+moonlight→sunlight）。3 种子，n=200/种子（检索），95% 层级 bootstrap。
   - 干预：FULL / KV-ONLY / REC-ONLY；state-swap K(cA)+R(cB) 各方向 100 例/种子 + 同源对照；Qwen-4B 层级扫（只保留下半 KV 或下半递归）。
7. **证据强度与短板**：
   - 关键数字（相对 FULL）：KV retrieve REC-ONLY 在所有模型 0/600；KV-ONLY Qwen-4B 0.89、Qwen-9B 0.94、Falcon-3B 0.64、Falcon-7B 0.99、Olmo-Hybrid-7B 0.99、Kimi-Linear 0.94。List index REC-ONLY 0（Falcon-34B 0.02）。语言跟随 REC-ONLY 0.62–0.83 vs KV-ONLY 0.01–0.25。state-swap："值来自 KV、语言来自递归"Qwen-4B/9B 1.00，Falcon-3B ≥0.99，Falcon-7B 0.87–0.89，Olmo-Hybrid 0.94–0.96。层级扫：只保留下半 KV → 检索 0.02；保留全 KV + 下半递归 → 检索 1.00。DRM：REC-ONLY 联想缺席词假阳性 Qwen-4B 0.87、Qwen-9B 0.89、Falcon-3B 0.45、Falcon-7B 0.99（中性对照多 ≤0.10）。合成词：REC-ONLY 在"两部分都出现"时假阳性显著升高，单部分缺席对照接近地板 → 作者结论："Component features of stored items survive in the recurrent state; the binding that ties them together as a specific item is what gets lost."
   - 作者承认：结论是功能性（因果贡献），不是静态编码；split-prefill 产生分布外组合（两通道本应同步更新），部分崩溃可能源于不一致，state-swap 部分缓解；未做探针。
   - 附录 B 的工程陷阱值得记：许多 HF hybrid 实现只在 seq_len==1 的解码路径读入恢复的递归状态，多 token chunk 时静默从零开始；必须验证 ‖logits(q|R(c)) − logits(q|0)‖∞ 不为 0（他们在一个模型上测到 0.0000，改逐 token 后 12.1）。
   - 我的评价：REC-ONLY 时查询位置从 0 开始、无 KV，可视为极端条件；"递归不做检索"在 hybrid 的推理时成立，不等于递归层在 prefill 中不参与构造 KV 内容。
8. **可迁移的研究动作**：(a) cache 级拆分/交叉拼接，把"值从哪个通道来"和"行为方式从哪个通道来"同时读出；(b) 用认知心理学经典陷阱（DRM、合成词）区分"项目级"与"特征级"存储；(c) 递归状态读入的强制验证。
9. **对我们（候选 1）**：
   - 直接后果：在 Qwen3.5、Falcon-H1、Olmo-Hybrid、Kimi-Linear、Jamba2 上，**精确的键→值读取完全不通过递归通道**；合成词结果甚至是"递归状态里特征在、绑定丢"的行为证据。候选若在 hybrid 上问"递归层是否用 binding ID"，大概率得到"绑定由注意力完成，递归层不承载绑定"，而这一点已被本文与 2609.33093 先行报告。
   - **没有做**：实体–属性多对绑定（只有字典单键值）；覆盖/重绑定；binding ID 向量层面的检验；纯 SSM/纯 GDN 模型；残差流表征。
