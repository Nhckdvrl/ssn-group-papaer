# Transformers Converge to Invariant Algorithmic Cores（NeurIPS 2026 稿，arXiv v3 2026-11-09）`[证据级别：部分]`

- 作者：Joshua S. Schiffman（单作者）。arXiv:2602.22600v3，abs 页已核对。
- 阅读范围（2026-11-25）：摘要、§1、§2–4 的主要结果（Markov、模加法、SVA、IOI）、局限与附录 D–F 的数字；方法推导（附录 B）略读。

1. **论文形态**：构念引入 + 方法（ACE）+ 多设定测量。
2. **背景与压力**：训练只约束行为不约束内部实现，单个模型的描述可能只是该次训练的偶然。
3. **改变的前提**：不比较权重或激活坐标，提取"必要且充分、可因果验证的低维核"，再看核动力学/读出是否在独立模型间一致。
4. **idea 来源（DOCUMENTED）**：控制论的实现等价、模型合并/Rashomon 文献。
5. **最近邻**：Chughtai 2023（算法族普适）、Gurnee 2024（神经元）、Lan 2410.06981（特征空间）、Wang 2410.06672。
6. **方法 / 设定**：①12 个独立种子单层 Transformer 学 Markov 链（核 3 维，子空间几乎正交，但转移谱相同，CCA 近 1）；②模加法 grokking，核后期膨胀、冗余加速泛化；③6 个预训练 LM（GPT-2 Small/Medium/Large、LLaMA-3.1、Gemma-2、Qwen2.5，均为基座，每个只有一个训练运行）：SVA 一维核；IOI 两位点的多维核（7–21 维，最小核对 16–143 维，占 1.6–4.8%）。
7. **"同一算法"的判据**：核的必要性/充分性（保留、移除、翻转符号后的 AUC）+ 跨模型把核坐标做符号对齐后的相关。SVA：翻转轴让生成中的语法数反转；GPT-2 家族内部 r=0.92–0.97，跨家族（Qwen2.5、LLaMA-3.1、Gemma-2、GPT-2）r=0.62–0.94，回归掉主语/干扰词数后仍为正；IOI：两核间线性算子 A 在同模型内预测 61–87% 的 END 核变化，跨模型迁移预测约 60%（自身 77%，错配 0%）。
8. **短板**：判据是"同一变量/子空间"（语法数轴、两站点核）而非"不同算法的反事实签名"——它测的是都有同一个中间量，没有设竞争算法；SVA 和 IOI 本身可能只有一种自然算法；模型各只有一次训练，种子/家族因素混在一起；单作者、方法依赖假设驱动的任务框定（作者自述）。我没有核对 NeurIPS 2026 的接收状态。
9. **对我们**：目前最接近"跨家族预训练 LM 同算法"的正面证据，但任务是单一变量可读出的 SVA 与 IOI；对"存在 ≥2 种合理算法"的任务，这套判据不能区分。
