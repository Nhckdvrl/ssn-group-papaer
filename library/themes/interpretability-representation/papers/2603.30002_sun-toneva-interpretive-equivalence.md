# Tracking Equivalent Mechanistic Interpretations Across Neural Networks（arXiv 预印本，评审状态未核对）`[证据级别：摘要 + 引言 + 案例结果片段]`

arXiv 2603.30002 v1，2026-03-31；Alan Sun, Mariya Toneva。

1. 论文形态：理论+受控实验（给“两模型共享同一机制解释”下定义并给估计算法）。
2. 背景与压力：缺少“解释是否有效、两个模型是否同一解释”的精确定义，机制解释靠个案、临时生成。
3. 改变的前提：不要求解释被显式写出；两个解释等价 iff 它们的所有可能实现等价；用表示相似度的必要充分条件估计，称 Congruity。
4. idea 来源（DOCUMENTED）：实现等价的形式化；链接电路与表示相似度。
5. 与最近邻的距离：Schiffman 2602.22600（核对齐）；Merullo 2023（GPT-2 与 Pythia 的 IOI 电路不同）；Tigges 2024。增量：给理论 + 估计器。
6. 方法 / 实验：Transformer 案例（GPT-2 small/medium 与 Pythia 系列），IOI 任务。Pythia 内部 Congruity 高（0.73、0.92），Pythia–GPT-2 低（0.13）；作者提示 Pythia-2.8b 与 160M 等价，只需解释小的；Pythia-160M/410M 与 GPT-2 的相似度偏高原因未解释。
7. 证据强度与短板：只有 GPT-2 与 Pythia 两个家族、IOI 一个任务；没有现代家族；“判据”是表示相似而不是反事实签名。
8. 可迁移的研究动作：把“跨模型等价”写成可估计量，家族内/家族间分开报告。
9. 对我们：给“家族内一致、家族间不一致”一个形式化工具，但未触及绑定与实体追踪，也没有 Llama/Qwen/Gemma。不构成撞车。
