# LLMs Remember First, Forget Last: Dual-Process Interference in Large Language Models（NPIR，Springer LNNS 系列，会议论文；arXiv v3 2026-08-10，分数 —）`[证据级别：全文]`

arXiv 2603.00270（v1 2026-02-27，abs 页已核对，comments 注明 NPIR / LNNS）；Sourav Chattaraj, Kanak Raj（Thomson Reuters, Bengaluru）。2026-11-25 读全文（短文，正文 + 局限 + 参考文献；附录 A 模型表未见于 PDF 文本）。

1. 论文形态：benchmark / 测量（认知心理学 RI vs PI 移植），无内部分析。
2. 背景与压力：Wang & Sun 2025 只测 PI（问当前值）；“更新后还能否取回原值”（RI）没人测。
3. 改变的前提：同一输入序列、只换查询目标——问“最初值”（RI）或“最近值”（PI），把干扰方向与刺激暴露分开。
4. idea 来源（DOCUMENTED）：AB-AC 配对联想范式（Barnes & Underwood 1959）；巩固–检索两种遗忘来源的理论区分。
5. 与最近邻的距离：Wang & Sun 2506.08184 → 加 RI 条件与更多模型；Guo et al. 2609.38866 → 后者在另一协议下发现偏向最近旧值，与本文的 primacy intrusion 不一致（Guo 明说协议不同）。
6. 方法 / 实验 / 数据：
   - 46 个语义类别，每类 478–624 个真实实例值；每类出现 N 次（N ∈ {3, 10, 50, 100, 200, 300}）：一次初始赋值 + N−1 次交错更新，相邻不同 key。查询明确点名类别。温度 0；每个 session 重新抽序列；自适应停止（bootstrap CI 宽度 <0.10 连续两次，最少 5 次，标准模型最多 50 次、推理模型 20 次）；抽取 <50% 类别的 session 视为解析失败剔除。
   - 指标：RIES / PIES = 准确率对 log10(N+1) 积分，满分约 188。
   - 模型：54 个测试，39 个有完整六档数据（1B–2.5T，开放 Llama/Qwen/DeepSeek 与闭源 GPT-5、Claude-4.5、Gemini、o1/o3 等）；**作者在局限中明写“only transformer architectures were tested”**。
   - 错误分类器：retrieval failure / same-key intrusion / cross-key intrusion / hallucination / partial match；共 5,409 个 RI 错误、9,753 个 PI 错误。
7. 关键数字：
   - RI 平均准确率：N=3 93.9%，N=50 96.0%，N=100 72.9%，N=200 45.5%，N=300 24.6%。PI（Fig. 1）：94% → 3%。
   - **39/39 模型 RIES > PIES**，平均差 69.5 分（paired t(38)=10.71, p<0.0001, d=1.73）；o1 RIES 186.4 / PIES 22.0；Claude-4.5-opus 178.4 / 170.3（最平衡）。
   - RIES–PIES 相关 r=0.21（95% CI [−0.11, 0.49]）。参数量解释 RIES 的 R²=0.491（p<0.0001），对 PIES 只有 R²=0.06（n.s.，低于 Wang & Sun 的 0.26，作者归因于更多 MoE）。上下文长度对 RIES R²=0.003。推理模型 RIES 178.0 vs 标准 150.3（d=1.76），PI 上无优势。
   - 错误：RI 以 retrieval failure 为主（50.8%），PI 以 same-key intrusion 为主（56.1%）；幻觉 RI 0.9%、PI 0.2%。低干扰（N=3）时 RI 侵入来自靠后位置（平均归一化位置 0.72），PI 侵入偏早（0.12），14% 返回第一个值；N 增大两者都趋向 0.5。PI 在 N≥200 时 session 间双峰（>85% 或 <5%）。
8. 作者承认的局限：单一范式；机制解释（superposition、attention sink、winner-take-all）是事后的、未经注意力探针验证；闭源参数量为估计；n=39 对中等相关的检验力有限；只测 Transformer、英语、温度 0。
9. 对“架构 × 覆写”方向关键的“没做的事”：
   - **探针 B（“A 现在？” vs “A 原来？”）在 Transformer 上已被完整做过**，且得到反直觉结果：Transformer 取回原值比取回当前值更容易（primacy 保护），与人类相反。
   - 没有递归模型；没有“未被更新的变量 B 原值”对照（无法区分 key 特异擦除与全局衰减）；没有内部读数；最小 N=3 且 46 个 key 同时更新。
10. 证据强度与短板：配对设计干净、效应量大且 39/39 一致；但只是行为，primacy 的解释未验证，且与 Guo et al. 的“偏向最近旧值”在协议间冲突，说明错误位置分布强烈依赖协议（负载、key 数、格式）。
11. 可迁移的研究动作：同刺激、只换查询方向的配对设计；用 RI/PI 不对称本身（而非绝对准确率）作为架构签名；错误按来源位置归一化。
12. 对我们：对递归模型最有判别力的不是“能否取回原值”，而是**这个不对称是否反转**：纯 delta-rule 模型若真在原位擦除，应出现 PI 好于 RI（与 Transformer 相反）；加性衰减模型应出现 RI 随距离变差但与是否被覆写无关。Transformer 端已是已知结果，可作为参照点。
