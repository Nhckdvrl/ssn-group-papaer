# How do Language Models Bind Entities in Context?（ICLR 2024，poster，分数未核对）`[证据级别：全文]`

arXiv 2310.17191（v2，2024-05-06）；Jiahai Feng, Jacob Steinhardt（UC Berkeley）。代码与数据：https://github.com/jiahai-feng/binding-iclr 。2026-11-25 读全文含附录 A–J（Arch 对照用于候选 1 评估）。

1. 论文形态：构念引入+测量（提出 binding ID 机制，用因果干预检验其两个推论与加性结构）。
2. 背景与压力：事实回忆（权重中的绑定）已有定位编辑工作，但“上下文中谁和谁绑定”如何在激活中表示没有可检验的机制假说；Hernandez et al. 2023a 能人为构造绑定表示，但不是模型自己用的。
3. 改变的前提：不去找回路，而是把“绑定”写成关于整段 context 激活 Z_context 的因果命题：存在绑定函数 Γ_E(e,k)、Γ_A(a,k)，查询时取与被问实体同 ID 的属性。
4. idea 来源（DOCUMENTED）：认知科学 binding problem（Treisman 1996）+ 线性表示假说（Elhage 2021）；两条可检验推论——factorizability（只换某 token 的激活就只换那个实体/属性）与 position independence（交换位置不改变绑定）。
5. 与最近邻的距离：Prakash et al. 2024（2402.14811，同期做回路）；Hernandez et al. 2023a（direct binding）；后续 Dai et al. 2024（2409.05448，Ordering ID 子空间）、Feng et al. 2024（propositional probes）、Gur-Arieh et al. 2025（2510.06182，指出 n 大时位置机制失效）。增量类型：给出新构念 + 新干预类型（均值差向量的加/减）。

6. 方法 / 实验 / 数据 / 基线：
   - **模型**：Pythia 全尺寸系列（70M–12B）与 LLaMA 7B/13B/30B（主实验 LLaMA-30B；几何实验 LLaMA-13B；ONEHOP 用 LLaMA-65B；MCQ 用 tulu-13b）。图 6：只有“足够大”的模型出现可干预的 binding ID，效果随规模增强（阈值只在图中，文本未给数字，未核对具体切点）。
   - **任务**：CAPITALS（“{E0} lives in the capital city of {A0}…Which city does {E} live in?”，需同时做国家→首都事实回忆）、PARALLEL（先列全部实体再列全部属性，打破同句混杂）、FRUITS、SHAPES（颜色为实体、形状为属性）、BIOS（属性为一句传记，多 token）、ONEHOP、三元绑定（name/country/hobby）、MCQ（SST-2 选项在问题之前）。n=2 或 3 对，每次评估 N=100 个 context。
   - **激活定义**：Z_p ∈ R^{n_layers×d}，即某 token 处**所有层**的残差流（pre-layer）堆叠；Z_Ek 扩展为实体 token 及其后一个 token。干预时冻结其他位置的激活，不重算下游 context（只研究“存储”，不研究“构建”）。
   - **binding ID 差向量估计**：假设 Γ_A(a,k)=f_A(a)+b_A(k)，Γ_E(e,k)=f_E(e)+b_E(k)。估计 Δ_A(k)=E_{c,c'}[Z_Ak(c)−Z_A0(c')]，Δ_E(k) 同理；500 个样本平均（不同 context，词项平均掉）。
   - **均值干预（swap）**：属性侧 Z_A0←Z_A0+Δ_A(1)，Z_A1←Z_A1−Δ_A(1)；实体侧同理。预测：单侧干预使绑定翻转（准确率→0），两侧同时干预相互抵消（准确率恢复）。n=3 时用循环移位 Z_Ek←Z_Ek+Δ_E(π(k))−Δ_E(k)。
   - **度量**：median-calibrated accuracy（每个属性的 log prob 减去它在所有查询上的中位数再取 argmax；用于消除位置偏置），以及 mean log prob。“成功”=单侧干预准确率接近 0、双侧接近 control。
   - **位置无关性检验**：直接改 RoPE 旋转角，把 Z_E0 与 Z_E1 的“表观位置”逐步互换（附录 C）。
   - **对照**：同模长随机方向（无效）；Zeros；跨任务移植时先减去目标任务 Δ 再加源任务 Δ。

7. 关键数字：
   - LLaMA-30B CAPITALS n=2（表 1）：Control 0.99/1.00；Attribute 干预 0.00/0.03；Entity 干预 0.00/0.01；Both 0.97/0.99；随机方向 0.97–1.00（无效应）。
   - 跨任务移植到 CAPITALS n=3（表 2，机会 0.33）：CAPITALS 0.88、PARALLEL 0.87、SHAPES 0.71、FRUITS 0.80、BIOS 0.47；Zeros 0.30、Random 0.31。
   - 三元绑定（表 4）：6 种角色分配下 control 1.00，单侧 ≤0.03，双侧 ≥0.99。
   - ONEHOP（LLaMA-65B，表 3）：control 0.73/0.79，属性干预 0.25/0.28，双侧 0.71/0.77（效果弱于 CAPITALS）。
   - 几何（图 5，LLaMA-13B）：Δ(1)、Δ(2) 张成的平面里线性组合（含负系数、超出凸包）仍是有效 ID；两 ID 靠近时准确率→50%（距离反映可分辨度）。
   - 位置互换（图 4）：实体几乎不变；属性有随位置渐变的偏置，作者解释为 RoPE 长程衰减导致的位置偏置，用中位数校准处理。
   - BIOS：实体可分解，属性不可分解（属性跨多 token，只换第一个 token）。
   - MCQ（附录 E）：不是 binding ID，而是 **direct binding**——复制两份表面相同的“ative␣”token 激活即可翻转标签绑定。

8. 作者承认的局限：binding ID 不是普适机制（MCQ 用 direct binding）；位置偏置的机制未解释；只研究激活中的存储，不研究查询回路如何读取（推测某些注意力头用二次型比较 ID）。
9. 对候选 1 关键的“没做的事”：
   - **只有 Transformer（RoPE）**：位置无关性检验依赖 RoPE 角度操控，在 Mamba/SSM 中**没有可操控的位置编码**，该检验不可移植，必须换设计（例如物理交换 token 顺序后重算）。
   - 干预时冻结下游 token 激活：在纯 SSM 中查询位置只能通过递归状态读取之前 token，改动 Z_Ek 必须经递归传播或直接改状态，“factorizability”需要重新定义。
   - 只有静态绑定、n≤3、查询总是 group 最后实体；无覆写/重绑定（“now x=9”）。
   - 小模型无 binding ID 的结论只在 Pythia/LLaMA 上；没有在规模内区分“训练细节 vs 规模”。
10. 证据强度与短板：干预效应极大（0.99→0.00），有随机方向对照和双侧抵消对照；但 Gur-Arieh et al. 2025 证明其“position-only”模型只在 n=2,3、查询末位实体时忠实，n=20 中间位置失效。median-calibration 依赖“偏置与绑定无关”的假设。
11. 可迁移的研究动作：用“单侧翻转 + 双侧抵消 + 随机方向”三联对照把加性结构变成可证伪预测；用差向量而非绝对向量绕开不可观测的 b(k)；跨任务移植检验抽象性。
12. 对我们：若检验非 Transformer，factorized swap 的三联对照可直接沿用，但“位置”与“token 激活”两个操作对象都要按架构重新定义（SSM 的状态 h_t、Gated DeltaNet 的 k/v、Mamba-2 的 B/C）。Feng 的“规模越大越结构化”可作为参照，但需要同规模、同数据的架构对照才能区分架构与规模。
