# Quantifying LLM Attention-Head Stability: Implications for Circuit Universality（arXiv 2026-02，发表处未核对）`[证据级别：部分]`

- 作者：Karan Bali, Jack Stanley, Praneet Suresh, Danilo Bzdok。arXiv:2602.16740v1（2026-02-17），abs 页已核对。
- 阅读范围（2026-11-25）：摘要、§1–4、局限；附录只扫图。

1. **论文形态**：测量。
2. **背景与压力**：电路很少在同架构不同初始化上检验。
3. **改变的前提**：用逐层、逐头的"跨种子最佳匹配"稳定性量化电路组件的跨实例可复现性。
4. **idea 来源（DOCUMENTED）**：Chughtai 2023 的强/弱普适区分。
5. **最近邻**：Karamcheti 2021（只发布五种子 GPT-2，未分析内部）；Gurnee 2024（神经元）；Trott 2509.22831（Pythia 种子）。
6. **方法**：从头训练 GPT-2 类 decoder-only，共 26 个架构配置；2/4/8 层各 50 个种子（2B token C4 子集），12 层 GPT2-small 5 个种子（9B token OpenWebText）；对 100 条提示的注意力得分矩阵逐头算余弦相似度，取同层（或跨层）最佳匹配头，平均为稳定度；另比较 Adam 与 AdamW。
7. **关键数字**：首尾层稳定（≈1.0），中间层最不稳定（8 层模型的第 5 层降到约 0.70）；更深模型中层分歧更强；AdamW 显著提高跨种子稳定度且性能无显著差；残差流比注意力头更稳定；提示越长稳定度越低。
8. **短板**：衡量的是注意力模式的相似度，不是算法；规模仅到 124M；"稳定"靠阈无关的相似度分布，没有因果检验；没有跨家族。
9. **对我们**：给出同架构同数据下独立种子的组件级不稳定量化——"组件身份跨种子不复现"的直接证据，但它是模式相似而非算法判定。
