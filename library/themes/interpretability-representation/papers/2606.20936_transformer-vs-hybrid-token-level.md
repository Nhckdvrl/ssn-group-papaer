# Comparing Transformers and Hybrid Models at the Token Level（arXiv 预印本 v1 2026-06-18，cs.CL，Preprint，未见评审，分数 —）`[证据级别：全文]`

- 作者：Yanhong Li, William Merrill（Allen Institute for AI）。arXiv:2606.20936v1，abs 页已核对。
- 阅读范围（2026-11-25）：正文 §1–7、附录 A–G（含探针模板 C、回归诊断 D、局限 E、算力 F）。

1. **论文形态**：测量 / 归因（成对逐 token 损失差分解）+ 受控合成探针 + 解释性"预备理论"。不做机制定位。
2. **背景与压力**：表达力理论说注意力擅长 copy/recall 与括号匹配，线性 RNN（GDN 负特征值）擅长有序状态更新；hybrid 在聚合 loss 上胜过 transformer（Waleffe 2024；Olmo Hybrid, Merrill 2026 = 2604.03444），但不知道是哪些 token / 哪类计算带来收益、是否对应理论优势。
3. **改变的前提**：不比聚合 loss，而在同前缀同目标 token 上算 Δ_i = ℓ^Tr_i − ℓ^Hyb_i，按 POS / 代码 token 类 / 重复 n-gram / 开闭括号分层，再用合成探针操纵目标类型与距离。
4. **idea 来源（DOCUMENTED）**：Merrill 系列表达力结果（Illusion of State 2404.08819；Grazzi 2025 负特征值；Olmo Hybrid 的 state-based recall 构造）；动态语义（Heim、Kamp & Reyle）作为"discourse state"类比。
5. **与最近邻的距离**：Olmo Hybrid 技术报告（只报聚合基准）→ 本文换证据类型为 token 级配对差；Waleffe 2024（Mamba hybrid 基准）→ 加细粒度分层；2609.04434 / 2609.33093 / 2611.01909（hybrid 内部因果干预）→ 本文完全不进内部，只看输出。
6. **方法 / 实验 / 数据**：
   - 模型：Olmo 3 7B（transformer，含 sliding-window 层）vs Olmo Hybrid 7B（GDN:attention = 3:1，同 tokenizer、同数据配方）；最终 release checkpoint。§6 另用 Merrill 2026 释放的三条 1B 开发 run：Transformer / Hybrid（GDN:attn 3:1）/ Pure RNN（纯 GDN），同数据同预算、WSD 退火 checkpoint。
   - 数据：prose（PG-19、CC-News、Wikipedia、ArXiv，回归另含教科书/论文）+ Python/HTML/LaTeX；打包长度 8192，每个位置算 NLL。
   - 分析 I：tag 分层原始均值；分析 II：线性回归 Δ_i ~ 域 + tag + 子词位置 + 相对位置 + 平均 NLL(+平方) + COPY_k(k=1..4，扩展到 16) + log 前次出现距离 + log 频率。
   - 分析 III（与候选直接相关）：三类合成探针，距离 d ∈ {32,64,128,256,512,1024}。**Entity tracking**："Julia carried the orange notebook. Sofia carried the green folder. … Q: Who carried the green folder? (A) Sofia (B) Julia Answer:"——**只有两个同性别实体、静态绑定、无更新**，二选一，按 accuracy 1[m>0] 与 margin m = log p(y+) − log p(y−) 打分。Pronoun memory：两人不同性别 + 角色，按角色问代词。Structural closure：开括号/标签，打分闭合 token NLL。
7. **证据强度与短板**：
   - 关键数字：内容词原始 Δ 0.0384 nats vs 功能词 0.0238（大约 61%）；tag 词表大小斜率 +0.0019±0.0010（原始，R²=0.145，p=0.059）、+0.0006±0.0005（调整后，p=0.273）；开−闭括号差 0.010–0.077 nats（7 个域都为正）；重复 n-gram 上 Δ 随 n 增大趋近 0。1B run：All-tokens 上 Tr–Hyb 最大差约 0.06 nats；Top-10∩No-Copy 过滤后约 0.12，排序 Hybrid < Pure RNN < Transformer；Copy-5 only 上 Pure RNN 比两种含注意力模型差 0.10–0.20 nats。
   - Entity tracking 探针（图 5，只有图、无表）：hybrid 在所有距离上高于 chance；transformer 在中间距离掉到 chance 以下、margin 为负；准确率轴范围大致 30–80%，**两模型都远离天花板**；样本数只写"fixed number of examples"，没有 CI。
   - 作者承认：tag 是计算类型的噪声代理；分层与回归是相关性；探针各只隔离一种窄构造，"does not directly measure the contribution of individual recurrent layers"；§5 不是机制主张，"We do not localize the hybrid advantage to specific layers or heads"；只测英语与三种代码语言。
   - 我的评价：Olmo 3 有 sliding-window 层，所以对照并非"全局注意力 vs GDN"的纯替换；2 实体二选一探针在 7B 上只有 30–80%，说明模板本身很脆，探针结论受模板支配的可能大。
8. **可迁移的研究动作**：(a) 成对同前缀 token 级差分作为架构对比的读数；(b) 把"信息是否需要延迟"与"目标是状态读出还是可见前缀复制"分开操纵（同距离、不同目标类型）；(c) 用过滤 loss（无 copy 的开放类）放大架构差异。
9. **对我们（候选 1）**：
   - **没有做**：binding ID / 任何内部表征分析；多于 2 个实体；属性覆盖或重绑定（overwrite / rebinding）；纯 SSM、Mamba-2 hybrid；层级或 GDN vs attention 层的因果拆分。作者自己把"open-world discourse state tracking（实体动态引入、关系状态）"列为未来基准方向（§5.1、§7）。
   - 留下的压力：它给出"hybrid 在实体–属性读出上有行为优势"的观察，但没回答这个优势是否由 GDN 层承载；2609.33093 与 2609.04434 的 cache 干预表明在 Qwen3.5 / Falcon-H1 中实体身份直接由 KV 承载，两者之间存在一个未解释的缺口（GDN 层贡献的是"地址/查询"还是"值"）。
   - 资产：Olmo-Hybrid-7B（allenai/Olmo-Hybrid-7B，7.43B，Apache-2.0，非 gated）与 Olmo 3 7B 构成同配方对；1B 三架构 run 若公开即构成"同数据、同预算、三种序列混合器"的对照（本文 Appendix G 说 1B 开发 checkpoint 同许可释放，HF 具体仓库名未核对）。
