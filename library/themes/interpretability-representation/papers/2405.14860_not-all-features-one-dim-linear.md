# Not All Language Model Features Are One-Dimensionally Linear（ICLR 2025，poster，分数 未核对）`[证据级别：全文]`

- 作者：Joshua Engels, Eric J. Michaud, Isaac Liao, Wes Gurnee, Max Tegmark（MIT）。arXiv:2405.14860v3，abs 页已核对。
- 阅读范围（2026-11-25）：正文 §1–6、Limitations，附录 A（容量界）、B（不可约定义直觉与指标实现）、D（玩具 SAE）、F/G（聚类与 top cluster）、I–K（逐题表现、patching、EVR 拆解）。代码 github.com/JoshEngels/MultiDimensionalFeatures。

1. **论文形态**：构念引入 + 测量（"不可约多维特征"定义 + SAE 聚类自动发现）+ 因果干预。
2. **背景与压力**：线性表征假说（LRH）的强形式认为特征都是一维方向；玩具模型里已有圆（Liu 2022、Nanda 2023），大模型里只有零散迹象（Yedidia 的位置螺旋、Hanna 的 U 形数字但非因果）。
3. **改变的前提**：特征可以是低维（≥2）子空间上不可约的分布；"不可约"= 不能经旋转平移分解为独立（separable）或互斥（mixture）的低维特征。
4. **idea 来源（DOCUMENTED）**：玩具模加法里的圆 + Bricken 2023 对"特征流形"的猜测；用 SAE 字典元素的余弦聚类去找跨方向的簇。
5. **与最近邻的距离**：相对 Gurnee & Tegmark（时空线性）是"同一类变量的多维版本"；相对 Nanda/Zhong 是从玩具搬到 7–8B 预训练模型；相对 Kantamneni & Tegmark（同组后续）是星期/月份而非整数。
6. **方法 / 实验 / 数据**：
   - 模型：GPT-2 small（Bloom 2024 全层 SAE）、Mistral 7B（自训 SAE，层 8/16/24）、Llama 3 8B（干预）。
   - 几何识别：SAE 字典元素按余弦相似度剪枝/谱聚类 → 只保留簇内元素重建 → PCA 2–5 维投影上算 separability index S(f)（旋转扫描后最小互信息）与 ε-mixture index Mε(f)（ε=0.1 带内样本比例）；人工看 PCA 图。1000 个簇中图 1 的星期/月份/年份簇按 (1−Mε)·S 排第 9/28/15。
   - 任务："Two days from Monday is"（49 题）、"Four months from January is"（144 题）。
   - 因果：在 top-5 PCA 子空间训练"圆形探针"P（映射到 cos/sin(2πα/7 或 12)），把投影替换为目标点 circle(α′) 并对其余方向做均值消融；对照：patch top-5 PCA、patch 整层、均值消融。离分布扫描 (r,θ) 网格；EVR（Explanation via Regression）逐步加入可解释函数并看残差。
7. **关键数字**：
   - 任务准确率：Llama 3 8B 星期 29/49、月份 143/144；Mistral 7B 31/49、125/144；GPT-2 8/49、10/144（GPT-2 有圆但不会做任务）。两模型对显式 "5 + 3 (mod 7)" 正确率近零。
   - 早层圆形子空间干预效果接近整层 patch，通常优于 patch top-5 PCA；SAE 平面探针在 Mistral 层 8 平均 logit diff −2.01（逐层圆探针 −2.58），且跨层更稳健（层 8 探针用在层 6：SAE 平面 −2.32，圆探针 0.029）。
   - (r,θ) 网格干预：输出由角度决定，与半径基本无关（Mistral 层 5）。
   - EVR（Mistral 星期，最后 token 层 17–29）：one-hot α,β 解释 94.0%→70.4%（随层下降），加入 "circle γ" 与 "circle α−β" 后到 98–99%；层 25 去除 α,β 后残差是清楚的 γ 圆。
   - 连续性：Mistral 层 30，"very early / very late on Monday" 落在相邻两天之间的方向。
8. **证据强度与短板（作者自述）**：为何只找到很少可解释多维特征不清楚；不可约定义是纯统计的、非干预的，放松后成为主观"程度"指标。另：
   - 只有 3 个 Transformer；没有独立训练的同构多种子；没有非 Transformer；圆形探针与"圆"假设是同一个人工指定的形状，没有在线/螺旋/团块之间做竞争比较。
   - 连续性证据只是投影位置偏移，后来被 Gupta, Fruengel & Heimersheim 2610.37796 用 Jacobian/steering 正面挑战（"spokes, not a ring"）。
   - "圆被因果使用"在 Feucht et al. 2605.01148 中被修正：Llama-3.1-8B 解月份/星期加法实际走 base-10 加法，任务周期的圆在计算层不出现。
9. **可迁移的研究动作**：SAE 簇 → 重建 → 低维不可约性检验；用"把投影换成标签对应的理想点"（不用 clean 激活）做因果检验；EVR 残差逐步解释。
9a. **对候选 2：它没做什么**：没有跨独立训练运行、跨架构（SSM/hybrid）比较同一变量的几何；没有沿流形 vs 线性 steering 的系统比较（只有圆上换点与 (r,θ) 网格）；"圆"是预设的，没有判定"线 / 螺旋 / 无结构云"的统一判据。
