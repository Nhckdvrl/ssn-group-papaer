# Gated Delta Networks: Improving Mamba2 with Delta Rule（ICLR 2025，poster，分数未核对）`[证据级别：全文（正文 §1–6；附录未读）]`

arXiv 2412.06464 v3（2025-03-06，abs 页标注 ICLR 2025）；Songlin Yang, Jan Kautz, Ali Hatamizadeh（MIT / NVIDIA）。2026-11-25 读 HTML 正文（本地 scratchpad lit/2412.06464.txt），附录 A/B 未读。本卡只关心“delta rule 原位擦除”的动机与证据。

1. 论文形态：架构 + 训练算法 + 中等规模预训练对比。
2. 背景与压力：线性注意力的外积记忆容量受维度限制，超过后“memory collision”；Mamba2 的门控**均匀衰减所有键值关联**（“If the model needs to forget a specific key-value association, all key-value associations are equally forgotten”）；DeltaNet 能“(softly) replacing an old key-value pair with the incoming one”，但一次只改一个关联，缺少快速清空（context switch）的能力，真实任务表现一般。
3. 改变的前提：门控与 delta rule 互补——S_t = S_{t−1} α_t (I − β_t k_t k_tᵀ) + β_t v_t k_tᵀ；α_t→0 清空，α_t→1 退化为纯 delta rule、“selectively updating specific content without affecting other information”。
4. idea 来源（DOCUMENTED）：Widrow–Hoff delta rule / Schlag 2021 fast weight programmer；Longhorn 的在线学习视角（Table 1 把 LA / Mamba2 / Longhorn / DeltaNet / GDN 写成在线学习目标）；test-time regression（Wang, Shi, Fox 2501.12352）。
5. 与最近邻的距离：DeltaNet（2406.06484，无门控）；Mamba2（标量门控、加性写）；RWKV-7（同期，对角 + 低秩、向量衰减、分离 removal / replacement key）。增量：加门控 + 硬件高效 chunkwise 算法 + hybrid（H1：GDN+SWA；H2：Mamba2+GDN+SWA）。
6. 方法 / 实验 / 数据：
   - 1.3B 参数、100B FineWeb-Edu token（另有 400M）；Llama2 tokenizer；训练长度 4K；基线 RetNet、HGRN2、Mamba、Mamba2、DeltaNet、Transformer++、Samba。
   - **支撑“擦除 / 选择性更新”的唯一受控证据是 S-NIAH 案例（§3.2，Table 2，RULER 单针三种）**：DeltaNet / Mamba2 / GDN 在 S-NIAH-1（重复合成上下文 passkey）1K–8K：97.4–98.8 / 99.2→30.4 / 98.4→91.8；S-NIAH-2（真实文章中的数字）：DeltaNet 98.4→14.4、Mamba2 99.4→17.0、GDN 100→29.6；S-NIAH-3（UUID）：DeltaNet 85.2→22.4、Mamba2 64.4→4.6、GDN 86.6→27.6（1K–4K）。作者三条解读：“Decay hurts memory retention”“Gating facilitates filtering”“Delta rule helps memorization”。
   - 其他：语言建模与常识（GDN Wiki ppl 16.42 vs Mamba2 16.56、Transformer++ 18.53）；真实检索（SWDE/SQuAD/FDA/TQA/NQ/Drop，2K 截断）平均 GDN 30.6、Mamba2 29.8、DeltaNet 26.2、Transformer++ 37.0、H2 40.1；LongBench；长度外推；吞吐。
7. 证据强度与短板：
   - 关键缺口：**没有任何“同一 key 被重新赋值”的任务**（无 MQAR-with-updates、无覆写探针），“原位替换旧关联”是机制性动机，不是被测量的行为。S-NIAH 只有一根针，测的是保持与过滤，不是覆写。
   - S-NIAH 单种子、无 CI；真实检索差距小，作者归因于小模型重复错误。
   - 作者在正文承认 DeltaNet 真实检索不如 Mamba2，并把改进幅度缩小归因于与更新规则无关的重复错误。
8. 可迁移的研究动作：用在线学习目标统一不同更新规则（LA = 负内积，delta = 回归损失，门控 = 自适应权重衰减），据此对“遗忘按时间（门控）vs 按同 key 写入（delta）”做出可区分预测。
9. 对我们：
   - GDN 的设计意图明确区分两种遗忘：α_t 的**全局、按时间**衰减与 delta 项的**按 key** 替换。因此“delta-rule 模型对未被覆写的 B 无损伤”只在 α_t≈1 时成立；GDN 若在覆写附近 α_t 下降，B 也会受损。探针设计必须把“B 受损 = 全局门控”与“B 不受损 = key 特异擦除”读成 α 与 β 的相对作用，而不是“delta vs 非 delta”的类别判决。
   - 公开模型：GDN 本文 checkpoint 未在本卡核对；可用的纯 GDN 预训练模型见 2609.33093 卡（m-a-p 340M/1.3B pure GDN 与 GLA 同数据对照）与 Olmo Hybrid 系列（hybrid，检索走 KV）。
