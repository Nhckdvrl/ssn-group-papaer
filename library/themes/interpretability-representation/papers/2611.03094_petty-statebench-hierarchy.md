# A Fine-Grained Hierarchy and Benchmark for State Tracking in Language Models（arXiv 预印本 v1 2026-11-02，cs.AI，venue 未标注，分数 —）`[证据级别：全文]`

arXiv 2611.03094（abs 页已核对）；Jackson Petty, William Merrill, Ashish Sabharwal（Ai2 / NYU / TTIC）。2026-11-25 读正文 §1–7、附录 A（定义）、B 的主要定理陈述（Lemma 1–3、Theorem 1–2、Prop. 2）、C（六种格式样例）、D（Table 1、Fig. 7–10）。

1. 论文形态：理论（Krohn–Rhodes 层级 + 架构表达力）+ benchmark（StateBench）+ 直接训练与预训练模型评测。
2. 背景与压力：状态追踪讨论集中在最难的 S5 / NC1；更简单、可能更常见的状态追踪（可变赋值、自增）是否已经能解释 Transformer 与 GDN 的差异不清楚。
3. 改变的前提：按 Krohn–Rhodes 分解把状态追踪分四级——r-trivial（只写一次，`let x = 4`，U1）、aperiodic（可变赋值 by value，`var x = 4; x = 2`，flip-flop U2）、soluble（自引用，`x += 3`，Zp）、general finite（by reference / 交换，`x = y` 经临时变量实现，含不可解群）。
4. idea 来源（DOCUMENTED）：Liu 2023 / Merrill 2024 的幺半群字问题视角；Krohn–Rhodes；Grazzi 2025 负特征值。
5. 与最近邻的距离：Illusion of State 2404.08819（只看 S5 vs 交换群）→ 细化到四级并加入 GDN+/GDN± 与精度；Olmo Hybrid 2604.03444 → 提供同数据 Transformer / Hybrid 的评测；Siems 2602.14814（代码 REPL 轨迹上的线性 RNN）为同期。
6. 方法 / 实验 / 数据：
   - 理论：固定精度 softmax 注意力 = r-trivial（引 Li & Cotterell 2026）；混合精度 SMAT ⊂ aperiodic；log 精度 AHAT ∩ 正则 = soluble（新，Cor. 1，假设 TC0≠NC1）；**单层 GDN+（固定精度）可实现 flip-flop U2**（Lemma 1b），因此 GDN+ ⊋ aperiodic（Theorem 1，对无门控 DeltaNet 同样成立）；GDN+ 借助舍入可识别 (aa)*（与 Grazzi 2025 的精确算术结论不矛盾）。
   - StateBench：m ∈ {2,4,8,16} 个变量、n=8–64,000 次赋值；先生成 general finite 样本（交换 + by-value 重赋值，by-value 次数 log-uniform [1,64]），再派生 soluble（交换→自增）、aperiodic（交换→直接赋被复制的值）、r-trivial（全部→初始值）四版本，控制变量数、值数与位置。每个样本 1 个正确 + 4 个错误候选终态；六种文本格式：integer code、spreadsheet cells（“Copy the current contents of cell B1 into scratch cell”）、cube painting（“Paint cube 1 the same color as cube 3”）、people in rooms、status lights、RULER 风格 magic number。
   - 直接训练：275M 的 Transformer（RoPE / NoPE）、GDN+、GDN±、Hybrid+、Hybrid±（Transformer-NoPE + GDN），Chinchilla 1× 数据，训练 n=8–256，测到 64,000。
   - 预训练模型：Olmo-3 7B（Transformer-NoPE 与 sliding window）、Olmo-3-Hybrid 7B（Hybrid±）；同数据自训的 275M Transformer-NoPE / GDN± / Hybrid± 与 2.7B Hybrid±；多选、取六种格式的最大值报告。前沿：Gemini 3.8 Flash、Claude Opus 5.5、GPT-6 Sol / Luna，生成式回答终态。
7. 关键数字（主要只在图中，Wilson CI）：
   - 直接训练：GDN 与 Hybrid 在 r-trivial / aperiodic / soluble 上完美长度泛化；general finite 上训练分布内学会，GDN± 泛化约 10× 训练长度，GDN+ 越过训练长度立即下降；Transformer 在 r-trivial、aperiodic、soluble 上不超出训练分布（NoPE 立即下降，RoPE 约 10×），general finite 连分布内都学不会。按敏感度排序的课程只对 RoPE Transformer 分布内略有帮助。
   - 敏感度中位数：r-trivial / aperiodic 0.05，soluble 0.76，general finite 0.73，CruxEval 代码 0.56（双峰）。
   - 预训练：除 275M Transformer 外 r-trivial 都好；**aperiodic（可变赋值）上 7B 模型只有约 90%，在预训练长度内就开始下降、越过后明显下降**，275M GDN± 在长上下文截止后仍约 50%；general finite 全部为机会水平。RULER 格式远比 spreadsheet 格式容易（小模型在 RULER 格式 r-trivial 近满分、spreadsheet 近机会）。
   - 前沿模型 r-trivial、aperiodic 强，soluble / general finite 在 10K–64K token 处跌到机会水平。
8. 作者承认的局限：GDN+ 在层级中的确切位置未定；格式敏感性强；周期性在自然数据中出现多少、在多大程度上驱动架构差距仍是开放问题；把层级扩展到无界变量（如话语追踪）未做。
9. 对“架构 × 覆写”方向关键的“没做的事”：
   - **探针 A（可变赋值 / 覆写）与探针 C（拷贝赋值）的“Transformer vs GDN vs Hybrid”对照已在合成训练与同数据预训练 7B 上做过**，但只报总准确率随长度的曲线：没有“覆写次数 k / 同一旧值重复”的操纵，没有错误归属（返回哪个旧值），没有历史查询（原值），没有旁观变量损伤，没有 Mamba / RWKV。
   - 预训练模型只有 Olmo 家族（Transformer vs GDN 混合）；纯 GDN 只有 275M 自训。
   - 拷贝赋值总是与交换绑在一起（general finite），没有单独“b = a 之后改 a，问 b”的值语义 vs 引用语义读数。
10. 证据强度与短板：理论清楚、数据派生设计控制了表面变量；但结果几乎只在图里、无逐格数字；预训练模型只取六种格式的最大值，掩盖格式方差。
11. 可迁移的研究动作：从同一源样本派生不同复杂度版本以控制表面特征；多格式渲染、报告格式间方差；用敏感度连接“周期性”与经验难度。
12. 对我们：理论上 flip-flop（覆写）是**单层 delta-rule 的原生操作**，而固定精度 softmax 注意力做不到长度泛化的覆写——这给探针 A 提供了理论预测，但同时意味着“GDN 在覆写上优于 Transformer”的长度泛化版本已被本文占据。我们若做，增量只能在（a）预训练纯递归模型（RWKV-7、纯 GDN、Mamba-1/2）而非 hybrid；（b）错误的“签名”（按同 key 写入次数遗忘 vs 按时间遗忘 vs 按竞争者数稀释），而非准确率曲线。
