# Linear Transformers Are Secretly Fast Weight Programmers（ICML 2021，PMLR 139，正式发表，分数未核对）`[证据级别：部分全文（§1–4.2、§6.1 合成实验、§6.3 WikiText 更新规则表；§5 φ 函数与附录未细读）]`

arXiv 2102.11174（abs 页已核对）；Imanol Schlag, Kazuki Irie, Jürgen Schmidhuber（IDSIA）。2026-11-25 读 PDF（本地 scratchpad lit/ow/2102.11174.pdf）。

1. 论文形态：理论视角（线性注意力 = fast weight programmer）+ 新更新规则 + 小规模实验。
2. 背景与压力：线性注意力用纯加性外积写入，key 数超过维度 d_dot 后进入“overcapacity”，检索出现串扰；标准 Transformer 只拼接不可变的 KV，不会“编辑”记忆。
3. 改变的前提：把更新规则看作可学习的“编程指令”：先用当前 key 读出旧值 v̄ = W φ(k)，再写入 β v + (1−β) v̄，即 W ← W + β (v − v̄) ⊗ φ(k)（“write”项与“remove”项）；β 是模型自己产生的写强度，“defines to which extent the new value will replace the previous value”。
4. idea 来源（DOCUMENTED）：Widrow–Hoff delta rule；Schlag et al. 2021（先前 fast weight memory 工作）；Smolensky TPR 的串扰分析。
5. 与最近邻的距离：Katharopoulos 2020（线性注意力）、Performer（随机特征）→ 本文指出容量上限并提出 DPFP 特征映射与 delta 更新；后续 DeltaNet 并行化（2406.06484）、GDN（2412.06464）。
6. 方法 / 实验 / 数据：
   - Setting 1（容量）：d_key=64，L=S 个不重复 key，S=20→600；线性注意力从约 60 个关联开始出错，DPFP-1/2/3 在 128/256/384 附近出错，softmax 最好但 >500 也难收敛。
   - **Setting 2（更新，与覆写直接相关）**：key 与 value **有放回采样**，序列长 L=2S=40、20 个唯一 key/value，“multiple keys can be re-assigned to a new value more than once. The expected value to retrieve is the most recent one”。比较 sum rule、Schlag(2021)、Schlag(2021)+DPFP、本文 delta rule（带归一化）。只报学习曲线（Fig. 3）：本文规则最好，**sum rule 失败**；作者说结论与容量区无关（附录 D.2）。
   - WikiText-103：small（40M）Linear Transformer sum 37.1/38.3 → delta 34.1/35.5（valid/test ppl），medium 31.1/33.0 → 29.7/31.5；标准 Transformer 33.0/34.1、27.9/29.6。
7. 证据强度与短板：Setting 2 是**唯一一个直接显示“delta rule 能学会取最新值、加性规则不能”的受控实验**；但单层、从头训练、玩具词表、只报 loss 曲线，没有 softmax 注意力或衰减（门控）模型在 Setting 2 的对照（附录 B 只从形式上论证优于 Peng 2021 的门控规则）。
8. 可迁移的研究动作：有放回采样 key 的 AR 是“覆写”的最小形式；同一任务比较更新规则族。
9. 对我们：这是“delta-rule 原位擦除”预测的源头，但它是**能力存在性**（可以学会），不是预训练多层模型**实际这样做**的证据；而且没有与 Mamba 式“加性 + 衰减”比较——衰减模型同样可能取到最新值（旧值已衰减）。所以探针 A 中“delta 停在 9、衰减模型回到 1”的二分并没有文献支撑，需要按衰减速率与写入次数分开预测。
