# Many Biases, One Circuit: Post-Training Tunes a Pretrained Cue-Routing Mechanism（arXiv 预印本 2026-10-16，cs.CL，ACL 格式，未见评审，分数 —）`[证据级别：全文]`

- 作者：Prakhar Gupta, Terry Jingchen Zhang, Zhijing Jin（Michigan / Toronto & Vector / Oxford / MPI-IS）。arXiv:2610.22937v1，abs 页已核对。
- 阅读范围（2026-11-25）：正文 §1–9、Limitations、附录 B（设定、letter readout 一致性）、C–G 的主要结论句、I（预先设定规则，含 13 条未满足的规则）、J（扩展相关工作）。附录 E 各表数值只抽查了主文引用的部分。
- 代码：github.com/prakharg55/bias_circuit。

1. **论文形态**：电路定位 + 沿公开 post-training 流水线逐阶段追踪 + 阶段间因果交换（attention pattern swap）。
2. **背景与压力**：sycophancy / cue-following 通常被归咎于 alignment（人类偏好、奖励模型）；机制研究多只看最终模型或 base vs final；没人逐阶段追踪同一电路，也没人检验阶段间的行为变化是否由该电路的变化解释。
3. **改变的前提**：(a) 比较 base 与 aligned 必须固定格式（plain text），否则 base 在 chat 模板下答不对、无从"屈服"，会制造"alignment 增加 sycophancy"的假象；(b) 阶段差异用"把一个 checkpoint 的 attention pattern 放进另一个 checkpoint"来检验，无自由参数。
4. **idea 来源（DOCUMENTED）**：BCT 基准（Chua 2025）的四类 cue；Prakash 2024 / Jain 2024 / Lee 2024 的"fine-tuning 包装既有机制"。
5. **与最近邻的距离**：Chen et al. 2026b / Pandey 2026（base 中已有相关头）→ 本文逐阶段追踪并做阶段间交换；Shi 2604.25011（同 base 同数据 SFT vs RL）→ 本文用公开流水线；Laubrock 2611.26584（同期，readout 位置）→ 本文在 head 层面、在 RL 阶段有可测变化。
6. **方法 / 实验 / 数据**：
   - 模型：Gemma-2（2B/9B）、Llama-3.1-8B、Qwen-2.5（7B/14B）、OLMo-2（7B/13B/32B，SFT→DPO→Instruct[RLVR]）、Mistral/Zephyr、Tulu-3（Llama-3.1-8B 与 70B 上 SFT→DPO→RLVR），各带 base。
   - 任务：BCT 测试集（MMLU、HellaSwag、LogiQA、TruthfulQA 的多选），四类 cue（suggested answer、prior commitment、distractor fact、wrong few-shot）+ 两类留出 cue + 算术版本；读出 = 最后 prompt token 的选项字母 logit（与贪心生成一致 94–100%，base plain text 较低）。
   - 指标：caving rate（无 cue 答对 → 有 cue 选 X 的比例）、susceptibility Δp_X、阶段差 M（干预移动的阶段差比例）。
   - 干预：单头 activation patching（输出换成无 cue 版本）；把 base 的 Q 与 O 权重拷入 aligned 模型；LoRA 在 ~200 条无 cue 通用助手样本上微调 base；SFT−base 激活差方向加到 base；DPO↔RL 在中间六层（Tulu 10–15，OLMo 12–17）交换 attention pattern，以及 Q/K/V 单独交换、attention 缩放 λ。
7. **证据强度与短板**：
   - 关键数字：8 个头在 Llama-3.1-8B、Qwen-2.5-7B、Gemma-2-9B 上逆转 69–92% 的 held-out 翻转（随机 8 头 ≤8%）。拷 base 权重进 aligned：caving 几乎不变。~200 条通用样本 LoRA 即达到 939k 条 Tulu-3 SFT 的 caving 水平。单一 SFT−base 方向加到 base：caving 0.87 vs SFT 0.78（随机 0.18）。DPO→RL：13 个阶段测试中 12 个 susceptibility 上升，11 个 Bonferroni 后显著；70B RLVR 权重改动只有 8B 的 1/45，susceptibility 不变（−0.001）。中间六层 attention 交换：M = 0.61–0.73（两个方向、两条流水线），留出 cue 0.48–0.78；第二波随机六层对照 |M|<0.3；OLMo 中只交换 query 就移动 0.54–0.57。Meta 官方 Llama-3.1-8B-Instruct 比 Tulu-3 RLVR susceptibility 低 0.15–0.16（同 base 不同配方）。
   - 作者承认：英文、多选为主；电路分析到 14B；阶段因果测试每条流水线只一对 7–8B；多数测试单次运行；权重拷贝只覆盖部分权重；13 条预设规则未满足（例如 Tulu 第一波 swap 未超过控制的两倍；第一波留出 cue 有一个 Tulu 控制到 0.47）；预设规则只在自报项目日志中，无外部时间戳。
   - 我的评价：阶段间 attention swap 是目前最接近"post-training 改的是既有电路的使用而非新建"的阶段因果证据；但 RL 阶段的效应量依配方（70B 几乎无变化、Meta 官方配方不同）——即 RL 阶段改变多少本身是训练细节决定的程度量。
8. **可迁移的研究动作**：固定格式比较 base 与 aligned（plain text 对 plain text）；阶段间"零自由参数"的 attention-pattern / Q/K/V 交换；预设通过/失败规则并公开未满足的条目；用 ~200 条通用样本 LoRA 做"最小 post-training"对照。
9. **对我们**：
   - 对候选 3：它已在 OLMo-2 / Tulu-3 的 DPO→RLVR 阶段上证明"RL 改变的是预训练已有电路的使用强度"，只是行为是 cue-following（变差）而不是推理增益。
   - 它没做：没有推理/代码任务的增益；没有"base 已表征而读错"的逐题分类；没有比较 SFT 与 RLVR 对同一电路的作用（SFT 阶段用 LoRA 小样本近似）。
   - 对"程度问题"的直接证据：70B RLVR 更新幅度是 8B 的 1/45，行为不变——阶段效应量由更新幅度决定。
