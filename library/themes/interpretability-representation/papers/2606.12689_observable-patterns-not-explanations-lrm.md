# Observable Patterns Are Not Explanations: A Causal-Geometric Analysis of Latent Reasoning Models（arXiv 预印本 v2 2026-10-24，cs.CL，未见评审，分数 —）`[证据级别：全文]`

- 作者：Darpan Aswal, Thomas Palmeira Ferraz, Yongxin Zhou, Maxime Peyrard（Université Grenoble Alpes / NAVER LABS Europe）。arXiv:2606.12689v2，abs 页已核对。
- 阅读范围（2026-11-25）：正文 §1–7、Limitations、附录 B（Llama-3.2-1B 扩展）、C（扩展分析）的主要表与结论句、D（统计）、E（训练设置）。附录 C 的逐图细节未全部核对。
- 代码与模型：github / HF darpanaswal/InterpretingLatents（含中间 checkpoint）。

1. **论文形态**：方法批判（matched controls 证伪既有解读）+ 因果定位（causal tracing、梯度子空间干预）+ 几何动力学描述。
2. **背景与压力**：Coconut 被解读为 BFS 式叠加搜索（Hao 2025、Zhu 2025），CODI 被解读为可解码的算术草稿纸（Shen 2025）。这些解读靠 logit lens / 注意力 / 可解码性，没有匹配对照，也没检验是否因果。
3. **改变的前提**：先用"没有所称机制"的对照模型检验模式是否仍出现；再把 latent thought 是否"被用"从二值改为连续的因果影响量，并在 loss 梯度子空间中定位。
4. **idea 来源（DOCUMENTED）**：probe 假阳性文献（Hewitt & Liang、Ravichander、"dead salmon"）；shortcut 文献把 thought 使用当二值。
5. **与最近邻的距离**：Zhang 2025a / Cui 2026（thought 被绕过 = 不用）→ 本文说是"程度"，且影响集中在低维子空间；Li 2026、Chang 2026（同期，因果影响随步变化）→ 本文加 within-thought 子空间定位。
6. **方法 / 实验 / 数据**：
   - 模型：GPT-2 small（主），Llama-3.2-1B-Instruct（附录 B）；每任务单独训练。目标 LRM：Coconut（C）、CODI；对照：Pause-as-thought（PaT，同课程无递归）、Coconut_u（Cu，课程扰动 u=0.3）、Base GPT-2、Explicit-CoT GPT-2。
   - 任务：ProsQA（图跳转）、GSM8K-Aug（算术）。
   - 测量：候选节点概率质量/熵（复现 Hao）；logit lens hit rate / step alignment / superposition rate（复现 Shen）；测试时删除 thought；causal tracing（IE = 1 − KL_patched/KL_corrupt，按位置桶）；梯度子空间 B_t（梯度矩阵 top 奇异向量，95% 能量），α ∈ {0,…,100} 缩放，与秩匹配随机基比较；Markov 性（ridge/MLP 预测 h_t，R²）；相邻步子空间 cos² 稳定性。
7. **证据强度与短板**：
   - 关键数字：图跳转删除 thought 后准确率几乎不变（C 98.0→97.8，PaT 95.4→95.6），算术大跌（C 35.7→7.7，CODI 41.8→25.6），Cu 反而升（30.8→39.1）。PaT（无递归）也复现 BFS 信号；Cu（有递归）把模式反过来。causal tracing：图跳转 thought 位置恢复为 0，算术上 T_full 恢复最强。梯度子空间：图跳转 α=0 不影响但高 α 翻转率显著高于随机；算术上消融 GRAD 降性能而随机无效，放大时两者翻转率相当。
   - 作者承认：梯度子空间只定位敏感性不定位语义；局部干预可能离分布、可有多种解释；GPT-2 small、K=6、只三种 LRM；每任务单独训练；只分析最终 checkpoint。附录明说 "weak-influence → stable-geometry" 二分在 Llama-3.2 上不迁移。
   - 我的评价：方法论贡献扎实（matched controls 的威力在 PaT/Cu 上很清楚）；"graded 而非 binary" 的结论本身较弱（几乎任何量都是程度），几何部分跨模型不稳。
8. **可迁移的研究动作**：对每个"观察到的内部模式"配一个"缺少所称机制但其他相同"的对照模型；把"用 / 不用"改为在梯度子空间中测量的连续影响；删除测试与 causal tracing 分开报告（必要性 vs 恢复性）。
9. **对我们**：
   - 与候选 3 没有题目重叠（研究对象是 Coconut/CODI，不是 post-training）。
   - 方法上的约束：若候选 3 声称 "RLVR 后 base 已有的状态被重新读出"，必须有一个"不含该机制"的对照（例如同样增益幅度但来自 SFT 的模型，或 RL 但 KL 不同的模型），否则"可解码 → 机制"是本文批评的同一错误。
   - 它也提示："重新对齐读出 vs 新电路" 很可能像 "used vs bypassed" 一样被证明是连续程度，而不是二分。
