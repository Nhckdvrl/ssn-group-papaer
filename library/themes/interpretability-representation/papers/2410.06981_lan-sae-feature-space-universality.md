# Quantifying Feature Space Universality Across Large Language Models via Sparse Autoencoders（arXiv v4 2025-05，发表处未核对）`[证据级别：部分]`

- 作者：Michael Lan, Philip Torr, Austin Meek, Ashkan Khakzar, David Krueger, Fazl Barez。arXiv:2410.06981v4，abs 页已核对。
- 阅读范围（2026-11-25）：摘要、§1、§3–4（配对 + SVCCA/RSA、Pythia 与 Gemma 实验）、讨论；附录只扫图表。

1. **论文形态**：构念引入（Analogous Feature Universality）+ 测量。
2. **背景与压力**：特征是否相同受多义性困扰；SAE 特征互相不一定对应。
3. **改变的前提**：即使 SAE 学到的单个特征不同，SAE 特征张成的空间在旋转不变变换下可以相似；先按激活相关配对，再用 SVCCA、RSA 比较配对特征的空间关系。
4. **idea 来源（DOCUMENTED）**：Kornblith/Raghu 表示相似度；Templeton 2024 的特征邻域；Engels 2024 的月份圆。
5. **与最近邻的距离**：相对 Gurnee 2024（神经元）→ 换成 SAE 特征空间；相对 Wang 2410.06672 → 同期同一问题但比较的是几何而非电路。
6. **方法**：比较对 Pythia-70M vs 160M、Gemma-1-2B vs Gemma-2-2B、Gemma-2-2B vs 9B、Llama3-8B-Instruct vs Llama3.1-8B 共 8 对，全是同家族兄弟模型，没有跨家族；OpenWebText 约 2–3 万 token；过滤非概念特征与多对一配对后只保留约 10–30%（通常约 20%）的特征对；用随机打乱的子空间对做零检验。
7. **关键数字**：中间层对相似度最高（Pythia SVCCA 单元格约 0.5–0.68）；第 0 层无意义；RSA 值远低于 SVCCA（关系结构相似度弱）；高激活相关的特征对可以对应很低的 SVCCA（如平均相关 0.6、SVCCA 0.03）；语义子空间（如时间、色彩）跨模型相似度显著高于随机子空间。
8. **短板**：同家族、模型很小到 9B；约 80% 特征对被过滤；依赖 SAE 本身的可复现性（作者在附录承认同一模型的不同 SAE 学到不同特征）；没有任务、算法或因果干预。后续 McCann 2605.24577 指出单靠这类静态几何对跨种子"可迁移性"有误导。
9. **对我们**：属于"几何 / 特征空间"一侧的证据，不回答"同一算法"；可作为几何相似度不等于机制相同的对照例。
