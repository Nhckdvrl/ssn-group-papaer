# Universal Neurons in GPT2 Language Models（arXiv 预印本 2024-01，发表处未核对）`[证据级别：全文]`

- 作者：Wes Gurnee, Theo Horsley, Zifan Carl Guo, Tara Rezaei Kheirkhah, Qinyi Sun, Will Hathaway, Neel Nanda, Dimitris Bertsimas。arXiv:2401.12181v1（2024-01-22），abs 页已核对；发表处未核对。
- 阅读范围（2026-11-25）：摘要、§1、§3–4（相关性实验、性质）、§5（权重/功能角色）、§6 讨论与局限。

1. **论文形态**：构念引入 + 测量。
2. **背景与压力**：普适性假说（Olah 2020）缺少 LLM 上的跨种子量化。
3. **改变的前提**：用"跨种子最大激活相关超出随机旋转基线"挑出普适神经元，再研究它们。
4. **idea 来源（DOCUMENTED）**：Li 2015 等跨网络神经元对应。
5. **与最近邻的距离**：Li 2015 视觉网络 → 换成 GPT2；后续 Wang 2410.06672 把单位换成 SAE 特征并跨架构。
6. **方法**：GPT2-small / GPT2-medium 各 5 个不同随机种子（Stanford 发布）、Pythia-160M 与 410M–6.9B 的权重分析；1 亿 token（Pile）上逐对神经元 Pearson；基线 = 同层随机旋转后的相关；超额相关 ϱ>0.5 记为普适。
7. **关键数字**：GPT2-medium-a 98304 个神经元中 1253 个（1.23%）普适；Pythia-160M 1.26%；GPT2-small 4.16%；摘要报 1–5%；高相关一致性高（max 与 min 相关之差 0.049，普适神经元 0.105）；普适神经元权重范数大、激活稀疏、可分类（字母/位置/语法/语义/预测与抑制神经元），后半层有 prediction/suppression 神经元的共同模式；有近重复神经元。
8. **证据强度与短板**（作者自述）：只有数亿参数；只测同家族同架构跨种子（跨家族被分词差异阻碍）；神经元非特权基，98%+ 神经元不普适但不说明模型不同；没有算法/因果任务比较；解释部分靠人工。
9. **对我们**：给"跨种子要先有基线（随机旋转）"的做法；它证明的是低水平特征层面少量复现，不是算法层。
