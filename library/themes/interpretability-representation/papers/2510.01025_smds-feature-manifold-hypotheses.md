# Hypothesis-Driven Feature Manifold Analysis in LLMs via Supervised Multi-Dimensional Scaling（TMLR 02/2026，接收，分数 —）`[证据级别：全文]`

- 作者：Federico Tiblias, Irina Bigoulaeva, Jingcheng Niu, Simone Balloccu, Iryna Gurevych（TU Darmstadt 等）。arXiv:2510.01025v2，abs 页已核对。
- 阅读范围（2026-11-25）：正文 §1–7（SMDS、距离函数表、模型选择、F1 跨模型共享、F2 上下文重塑、F3 因果作用、多维流形、局限）；附录 D（随机标签对照等）检索式阅读。

1. **论文形态**：方法（假设驱动的流形比较）+ 测量 + 因果噪声干预。
2. **背景与压力**：前作逐个特征识别特定几何（Engels 的圆、Gurnee 的线），缺少比较竞争几何假设的统一方法；PCA 找不到非主方差方向，PLS 限于线性。
3. **改变的前提**：先由假设距离函数 d(y_i,y_j)（圆弦距、线、对数线、半圆、团块/单纯形等）用 MDS 构造理想几何，再学线性映射 X→理想坐标；用 normalized stress 比较各假设；"首选流形" = 平均得分最好且与所有其它假设统计显著不同。
4. **idea 来源（DOCUMENTED）**：经典 MDS + 有监督；Engels/Gurnee 的时间实体发现。
5. **与最近邻的距离**：相对 Engels 2025 → 多假设竞争而非预设圆；相对 Modell 2505.18235 → 同样假设驱动，但这里是线性投影 + stress，Modell 是同胚/等距检验。
6. **方法 / 实验 / 数据**：Qwen2.5-3B-Instruct、Llama-3.2-3B-Instruct、gemma-2-2b-it（及其 base），Llama-3.1-8B/70B-Instruct；时间推理任务（日期、星期/月份周期、时长、城市等）；交叉验证 stress；随机标签对照；第一层加噪声/替换的因果干预。
7. **关键结果**：星期/月份类周期特征选到环、单调量选到线、类别选到团块；**首选形状在三个家族及多数 base 版本间一致**，并在 70B 仍存在；随机标签 stress 一直高（不只是过拟合假设）；上下文可显著重塑流形（同一实体在不同任务里从环变团块）；第一层沿流形加噪声会损害下游准确率，且关系只在超过机会准确率的 Llama 3B/8B/70B 上出现。
8. **证据强度与短板（作者自述）**：stress 分数常常紧挨着，单一最佳假设难以选出（交叉验证不足以区分，需额外证据）；只能比较已提出的假设，不能发现新形状；需要监督标签。另：只有 Transformer；没有独立运行；因果干预是加噪声，不是定向 steering。
9. **可迁移的研究动作**：**把"同一几何"表述为"在同一组竞争假设下首选同一形状、且与其它假设统计可分"**——不需要绝对阈值，只需相对排序与显著性；这是候选 2 回答"无任意阈值"的现成工具。
9a. **对候选 2：它做了什么 / 没做什么**：已在 3 个 Transformer 家族上显示"时间类变量的首选流形跨家族一致"——候选 2 在这类变量上跨 Transformer 家族的结果可预测。没有 SSM/hybrid、没有计数/括号深度、没有沿流形 vs 线性 steering。它的"stress 常常难以区分"也是候选 2 用形状分类作主读数的风险。
