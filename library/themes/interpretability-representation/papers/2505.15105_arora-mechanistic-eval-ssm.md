# Mechanistic evaluation of Transformers and state space models（arXiv v3 2026-01-30，cs.CL；abs 页注 "9 page main text, 22 pages total"，发表会议未核对，分数 —）`[证据级别：全文]`

- 作者：Aryaman Arora, Neil Rathi, Nikil Roashan Selvam, Róbert Csordás, Dan Jurafsky, Christopher Potts（Stanford）。arXiv:2505.15105v3，abs 页已核对。
- 阅读范围（2026-11-25）：PDF 正文 §1–7、附录 A（模型配置）、B（ATR 形式化）、C（任务超参）、D.1–D.5（位置编码、ATR 泛化、1 层、多层、兄弟查询）。

1. **论文形态**：受控合成任务 + 因果干预（interchange intervention）做"机制评估"；多架构从头训练的小模型。
2. **背景与压力**：AR / MQAR 只用准确率比较架构（Zoology、Based 等），无法说明为什么某架构成功、是否学到稳健解；Transformer 上 AR 被认为由 induction head 实现。
3. **改变的前提**：用 key 损坏 + 在 key / value / query 位置恢复层 1 输入，看哪一位置恢复正确答案似然：value 位置恢复 = induction（2 层，关联存在 value 上）；query 位置恢复 = layer-0 "direct retrieval"；key 位置 = layer-1 direct retrieval。
4. **idea 来源（DOCUMENTED）**：Geiger 的 causal abstraction / interchange intervention（pyvene）；Olsson 2022 induction；Zoology 发现 short conv 对 AR 重要。
5. **与最近邻的距离**：Zoology / Based（Arora 2024a/b，行为）→ 本文加因果机制读数；Bick 2025 Gather-and-Aggregate（预训练模型、检索头）→ 本文用从头训练的玩具模型、比较 7 种序列混合器；Koren 2609.07681（Mamba AR 线性哈希电路 + 标度律）→ 本文不做容量理论。本文在相关工作里把 Feng & Steinhardt 2024 等 binding 文献列为"cognitive science 中的 binding"，但没有测 binding ID。
6. **方法 / 实验 / 数据**：
   - 模型：从头训练 2 层（附录有 1–3 层）的 Attention（1 头，绝对位置编码）、BaseConv、Based、DeltaNet（fla 实现）、H3、Hyena、Mamba（Mamba-1，d_conv=4，无 MLP）。d ∈ {16,32,64,128,256}，LR 扫 [3e-5, 3e-2]；每组实验约 200 个模型，总计 < 10,000 GPU-h。
   - AR：key/value 词表不相交，总 8192，上下文 32 对，单查询；训练集 100,032 条，dev 320 条；只对查询位置算损失；16 epoch，batch 32。
   - ATR（Associative Treecall，新任务）：右中心 Greibach 范式 PCFG（|N|=40，|Σ|=20，L_max=5，d_max=10），查询某终结符的父节点，key–value 不相邻，位置联想无效。
   - 指标：正确答案似然 ŷ_i（主）、accuracy；干预后的恢复似然。
7. **证据强度与短板**：
   - 关键数字：AR 上 Attention 在 d≥32 达 100%；Based 最高似然 98.9%（acc 99.06%）；Mamba 与 DeltaNet 在 d=256 达 90.3% 似然（91.25% acc）；H3、BaseConv 失败。机制：Attention 与 Based 纯 induction（value 位置恢复）；Mamba、DeltaNet、Hyena 为 direct retrieval（主要在 query 位置，即层 0）。Mamba 的 conv 核从 1→2 时准确率阶跃（d=128/256 约 2%→90%）；去掉 conv 学不会 AR；层内干预显示 Mamba 层 0 的 short conv 把 key 信息移到"下一个 key"位置（只有 d=32、LR=1e-2 一个 checkpoint 移到 value），作者据此称"Mamba 也做 induction"。ATR 上 Mamba 最佳；去掉 conv 后 d=256 仍 93.4%（Based 92.2%、BaseConv 89.7%），且变成 value 位置恢复的两层 induction。附录：Attention 去掉位置编码 AR 从 100% 掉到 5.62%；1 层 Mamba（96.25%）在 AR 上甚至优于 2 层（91.25%）；ATR 测试集（未见 query–answer 对）准确率远低于 dev（Attention 95.62% dev / 68.12% test）。
   - 作者承认：行为指标仍需要；全部是合成任务，需推广到真实模型。另：因配置错误所有架构都带绝对位置编码（附录 D.1 作为意外消融报告）。
   - 我的评价：DeltaNet 只做了行为 + 块级干预，没有进 delta 规则内部；没有任何"覆盖 / 更新"条件；玩具 2 层模型与 7B 预训练 hybrid 距离很大。
8. **可迁移的研究动作**：(a) 损坏 key + 分位置恢复来区分"关联写在哪里"（value 位置 vs query 时刻）；(b) 用组件消融（conv 核长）配合机制读数判断某组件是否承担关联；(c) 引入打破位置捷径的任务（ATR）检验机制是否依赖相邻性。
9. **对我们（候选 1）**：
   - 直接相关的事实：同一 AR 任务上，SSM 与 DeltaNet 不像 Transformer 那样"在 value token 上存关联再检索"，而是在查询时刻用单层一次性完成；Mamba 的关联由 short conv（相邻 token 混合）承担。这意味着候选里"position-independent binding ID"若在 SSM 中出现，必须排除 short conv 提供的局部位置捷径——实体–属性相邻模板会让 conv 直接做绑定。
   - **没有做**：预训练模型；多实体 binding ID 的加性/可替换性测试（Feng & Steinhardt 式均值差向量注入）；属性覆盖；hybrid；Mamba-2 / GDN 的状态外积结构读出。
   - 资产：代码 github.com/aryamanarora/tinylang（基于 zoology + fla + pyvene）。

## 第二位读者的笔记（11-25 两路独立精读，合并为一张卡）

*原标题行：Mechanistic evaluation of Transformers and state space models（arXiv 2505.15105，2025-05-21，v3 2026-01；venue 未核对）`[证据级别：全文]`*

Aryaman Arora, Neil Rathi, Nikil Roashan Selvam, Róbert Csordás 等。基于 zoology 与 fla 实现、pyvene 干预。2026-11-25 读主文与附录主要部分。

1. 论文形态：受控比较 + 因果机制（“mechanistic evaluation”）。
2. 背景与压力：SSM 在上下文检索（associative recall, AR）上表现参差，但只有行为指标，看不到为什么。
3. 改变的前提：同准确率不等于同机制；对每种架构直接测它是否学到“在 value 处存 key–value 关联”的 induction 式解。
4. idea 来源（DOCUMENTED）：AR 与 induction head 的对应（Olsson 2022；Arora 2024a/b）；interchange intervention（Geiger）。
5. 与最近邻的距离：Bick et al. 2025（2504.18574，预训练 Falcon-Mamba-7B / Llamba-8B / Zamba2-7B 中的 Gather-and-Aggregate 头；混合模型把 Aggregate 角色交给注意力层）；Jelassi 2024（SSM 复制能力上限）；Feng & Steinhardt 2024（作者把 AR 明确称为 binding）。增量：把因果干预用于跨架构比较。

6. 方法 / 实验 / 数据：
   - **模型**：从头训练的小模型（主设定 2 层；附录有 1 层），架构 Attention、BaseConv、Based、DeltaNet、H3、Hyena、Mamba；d∈{16,32,64,128,256}，LR 扫描 3e-5–3e-2；每个实验约 200 个模型，总计 <10,000 GPU 小时。
   - **任务**：AR（词表 8,192，上下文 32 对 key–value，单一查询，训练 100,032 例）；新任务 Associative Treecall（ATR，用 PCFG 生成层级结构，key 与 value 不相邻，需非位置式关联）。
   - **干预**：腐蚀 key，再在第 1 层输入的 key / value / query 位置恢复原表示，看正确答案似然恢复多少：value 处恢复=induction（关联存在 value 上）；query 处=第 0 层直接检索；key 处=第 1 层直接检索。Mamba 内部另对短卷积输出做干预；消融卷积核大小 d_conv∈{4,3,2,1,无}。

7. 关键数字：
   - AR（d=256）：Attention 在 d≥32 即 100%；Based 98.9% 似然（99.06% 准确率）；Mamba 90.3%（91.25%）；DeltaNet 约 85%；H3、Hyena、BaseConv 失败。
   - 机制：Attention 与 Based 用 induction；Mamba、DeltaNet、Hyena 用**直接检索**——关联只在最后状态、单层内计算（主要在第 0 层经 query 完成）。
   - Mamba 需要短卷积（d_conv≥2）才能学会 AR；短卷积把 key（和 value）信息移到**下一个 key** 位置，作者仍将其归为两阶段 induction 的变体。
   - ATR：Mamba 表现最好；去掉短卷积后仍能学（d=256 时 93.4%），且转为类似 Attention 的两层 induction。
   - 1 层 Mamba 在 AR 上 96.25% 反而高于 2 层 91.25%。
8. 作者承认的局限：只用合成任务和小模型，需推广到真实预训练模型；行为指标仍需配合。
9. 对候选 1 关键的“没做的事”：不是实体–属性 binding ID，没有差向量 swap、没有覆写，也没有预训练大模型（Falcon-Mamba、Granite-4.0-H、Qwen3.5 等）。但它是目前读到的**唯一一篇在 SSM / DeltaNet 上对“key–value 绑定”做因果机制分析的工作**，且结论正是“与 Transformer 机制不同”。
10. 证据强度与短板：架构覆盖广、超参扫描大；但 2 层玩具模型、单查询，与预训练 LM 的自然语言绑定距离远。
11. 可迁移的研究动作：用“在哪个位置恢复能救回答案”区分“关联存在 value 上”与“查询时直接检索”——这一读数可直接改成候选 1 的定位实验（实体 token vs 属性 token vs 查询 token）。
12. 对我们：给候选 1 一个先验——小 SSM 的关联可以不经过 value 位置、只在最终状态中实现，这与“属性 token 上加 binding ID”的 Transformer 图景不同；短卷积是 Mamba 系列里一个必须单独控制的局部机制。预训练混合模型方面，Bick et al. 2025 已显示检索角色会被交给注意力层，所以“混合模型的绑定在注意力层”是可预期的结果，不宜作为主要发现。
