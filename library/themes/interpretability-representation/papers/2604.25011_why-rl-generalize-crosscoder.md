# Why Does Reinforcement Learning Generalize? A Feature-Level Mechanistic Study of Post-Training in Large Language Models（arXiv 预印本 2026-04-27，ACL 格式，致谢提到匿名审稿人但未写会议；分数 —）`[证据级别：全文]`

- 作者：Dan Shi, Zhuowen Han, Simon Ostermann, Renren Jin, Josef van Genabith, Deyi Xiong（天津大学 TJUNLP / DFKI / Saarland）。arXiv:2604.25011v1，abs 页已核对。
- 阅读范围（2026-11-25）：正文 §1–8、Limitations、附录 A（crosscoder、SFT/RL 训练设置、benchmark）、附录 B（rank shift、Llama-3.1-8B-Instruct 复现、Qwen2.5-7B MAS、unseen tasks）。
- 代码：github.com/danshi777/RL-generalization。

1. **论文形态**：受控对比（同 base、同数据，SFT vs GRPO）+ crosscoder model diffing + 特征干预。
2. **背景与压力**："SFT memorizes, RL generalizes"（Chu 2025）、Huan 2025（数学推理是否提升通用能力）只有行为证据或全局表征漂移（Huan 用 representation drift 解释），没有具体特征层面的因果解释。
3. **改变的前提**：自己从同一 base 训练 SFT 与 RL（而不是拿现成蒸馏/RL 模型），用三模型 sparse crosscoder 把 base/SFT/RL 放进同一字典，再只在 "RL 对、base 错" 的样本上选特征。
4. **idea 来源（RECONSTRUCTED）**：Baek & Tegmark 2025 的 crosscoder + NRN 指标迁移到 RL vs SFT；作者组以往做 neuron 定位/编辑（IRCAN、DEPN）。
5. **与最近邻的距离**：
   - Baek & Tegmark 2025 / Lindsey 2024 / Minder 2025：只做 base vs 一个 tuned 模型；本文加第三个模型（三模型 crosscoder + Model Attribution Score）。
   - Venhoff 2510.07364：同样结论"RL 重用既有、SFT 装新"，但 Venhoff 用公开 ORZ / R1-Distill 对，本文自训且同数据。
   - Huan 2507.00432：本文声称从全局漂移推进到特征级因果。
6. **方法 / 实验 / 数据**：
   - 模型：Qwen3-4B-Base、Qwen2.5-7B（附录：Llama-3.1-8B-Instruct）。全参数训练，1 epoch。
   - 训练：数据 = Huan et al. 47K 数学题（MATH + DeepScaleR）。RL = GRPO（verl），batch 128，**lr 1e-6**，8 rollouts，生成长度 16k，clip 0.22–0.28，**KL 与 entropy 系数为 0**。SFT = Qwen3-32B 教师 CoT（只留答案正确的），LLaMA-Factory，**lr 5e-5**，batch 128。两边学习率相差 50 倍。
   - crosscoder：d_sparse = 32,768，只重建**中间一层**残差流，训练于 200M OpenThoughts-114k + 200M RedPajama token，β=2。
   - 指标：NRN = ‖W_dec^T‖₁ / (‖W_dec^O‖₁+‖W_dec^T‖₁)；MAS 为三模型版本；checkpoint 每 1/5 epoch 一个，算 top-50 NRN 特征的跨 checkpoint 重叠与 rank shift。
   - "generalization-controlling features"：在每个任务的 generalization-critical 样本（base 错、RL 对）上，最后 token 处 RL 与 base 特征激活差均值 > 该任务最大值 20% 的特征；五个任务取交集 → Qwen3-4B 50 个、Qwen2.5-7B 16 个。
   - 干预：RL 模型中这些特征置零；base 模型中设为常数 3.0。评测集 = 同一批 generalization-critical 样本；unseen：LogiQA、PIQA。
7. **证据强度与短板**：
   - 关键数字：Table 1 Qwen3-4B base/SFT/RL MATH500 26.0/68.4/77.0，CommonsenseQA 20.1/19.6/50.5，SciQ 78.5/51.8/89.5；Qwen2.5-7B CommonsenseQA 77.6/30.1/76.1。NRN：SFT 右尾明显（许多 NRN>0.8 及 →0 的特征），RL 集中在 0.5。top-50 特征跨 checkpoint 重叠：SFT 0.22–0.47，RL 0.04–0.33。置零：RL 模型在 critical 样本上 −14.0 到 −46.2 点；放大：base +12.5 到 +55.6 点；unseen LogiQA/PIQA 置零 −11.8 到 −24.5，放大 +23.3 到 +32.9。
   - 作者承认的局限：crosscoder 不一定捕获全部功能结构；推理期干预不能直接指导训练目标。
   - 我的评价（未被作者讨论的硬伤）：
     (a) **学习率混杂**：SFT lr 5e-5 vs RL lr 1e-6，且 KL=0；"RL 改得少、保留 base 特征"与"RL 步子小"无法区分——正是导师说的"程度问题由 lr/KL/步数决定"。
     (b) **选择与评测同集**：特征在 base 错 / RL 对 的样本上按激活差选出，再在同一批样本上置零/放大，属于循环；未报告随机特征或匹配激活量的对照。
     (c) base 上把 16–50 个特征设成 3.0 能让 SciQ 从错到对 56%，没有报告对 base 本来答对样本的破坏率，也没有随机特征对照。
     (d) 只一层、只最后 token、单 seed，无置信区间；Table 1 有异常（Qwen2.5-7B SFT CommonsenseQA 30.1 vs base 77.6，可能是格式问题）。
     (e) 多选题任务是 lm-eval-harness 评测，与 RL 训练的长 CoT 生成格式不同，"泛化"有格式成分。
8. **可迁移的研究动作**：三模型共享字典让 base/SFT/RL 特征可直接比较；"只在 base 错而 tuned 对的样本上看差异"这一样本筛选思路（但必须加独立选择/评测拆分与随机对照）。
9. **对我们**：
   - 这是候选 3 中 "SFT vs RLVR、新特征 vs 重用既有特征" 部分的直接先例，结论（RL 保留 base 表征、SFT 引入新特征）已被公开声称。
   - 它恰好示范了导师反对的设计：从同一 checkpoint 出发、两种训练超参不匹配，差异是程度问题。
   - 它没做：逐题区分 "base 已表征但读错" 与 "base 未表征"；没用公开的 Base→SFT→DPO→RLVR 链；没有 probe 或 patching 检验 "readout 方向是否重新对齐"；没有在匹配 KL/步长下对比。
