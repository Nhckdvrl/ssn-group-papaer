# A retrieval conditioned rebinding circuit for dynamic entity tracking in large language models（arXiv 2606.08644 v2，2026-09-11；venue 未标注）`[证据级别：全文]`

Soyoung Oh, Vera Demberg（Saarland University / MPI-INF）。代码：https://github.com/sori424/dynamicET 。2026-11-25 读全文含附录 A–E。

1. 论文形态：失败模式无 → 机制发现（回路 + binding ID 子空间干预）。
2. 背景与压力：binding ID 工作只做静态绑定；Prakash 2024 的实体追踪回路不含显式状态转移；Li et al. 2025 用玩具模型做排列状态追踪，不是自然语言。
3. 改变的前提：把“状态更新”看作对 binding ID 的重映射，而非重写世界状态。对比两个假说——**Global State Update**（swap 句后立即重编码完整新状态）vs **Retrieval Conditioned Rebinding**（保留原绑定，只存 swap 信息，到查询时对被问 box 的 ID 做局部重映射 ρ_{i,j}，再按新 ID 读出物体）。
4. idea 来源（DOCUMENTED）：Kim & Schuster 2023 boxes 任务 + Feng & Steinhardt 的 binding ID + Prakash 2025 lookback；认知上的 mental simulation 作为对立假说。
5. 与最近邻的距离：Prakash et al. 2024（2402.14811，静态回路 A–D 组）；Prakash et al. 2025（2505.14685，lookback）；Tang et al. 2026（2605.30233，多操作、非增量聚合，结论一致）；Gur-Arieh 2025。增量：换设定（swap 状态转移）+ 把 Feng 式 ID 干预移到注意力头 Q/K 子空间。

6. 方法 / 实验 / 数据：
   - **模型**：Gemma2-9B、Gemma3-12B、Llama3.2-3B、Llama3.1-8B（均 instruction-tuned，均 Transformer）。单张 H100；最贵的 Gemma-12B 路径 patching 约 16 小时。
   - **任务**：3 个字母命名的 box、3 个单 token 物体、**恰一次 swap**（“Swap the items of Box S and Box R. Question: Which item does Box R contain? Answer:”）。附录 A.1 扩展到更多 box + 一个干扰 swap。
   - **步骤 1 因果中介（N=300）**：三组实验分别替换 reference box、swap target box、object token，在残差流逐 (层, token) 做 interchange intervention，度量 IIA。结果：box 信息不从初次出现处路由，而是 swap 后才出现并传到 ‘:’；物体直接从原始位置读出。附加诊断（图 7）：在 swap 句末“.”打补丁只对被问 box 产生局部效应，在 ‘:’ 打补丁对所有 box 都更强 → 绑定主要在读出时解析。
   - **步骤 2 路径 patching（N=100）**：五阶段贪心，组 A–E 的 top-k = 50/50/25/10/10；V-patching 与 Q-patching 区分组合方式；再按贡献 <1% 剪枝。评估用 candidate accuracy（金标准物体在候选中 logit 最大），N=300 留出集；随机基线=10 个同规模随机头集合 mean-ablation。
   - **步骤 3 注意力模式交换（N=300）**：content control（换物体、保持 box/swap 结构）vs pointer intervention（换绑定结构使需要读的源位置改变），只把某组头的注意力模式从反事实拷入原运行，看 Δlogit。
   - **步骤 4 Q/K 子空间 binding-ID 干预**：对 B 组头，μ^Q(k)=E[q(‘:’)|检索 ID=k]，μ^K(k)=该 ID 的 box/object token 的 key 均值（N=100 随机词项平均）；Δ(i→j)=μ(j)−μ(i)。Q 干预：q←q+Δ^Q(i→j)；K 干预：把 S_j 处 key 加 Δ^K(j→i)、S_i 处加 Δ^K(i→j)（分 box / object / both）；Q+K 同时干预应**相互抵消**。度量：ΔR（对反事实 ID 的 log 注意力比变化）、Δlogit（反事实−原答案 logit 差的变化）、Switch（主注意 ID 从 i 变 j 的比例）；随机同模长方向作对照。

8. 作者承认的局限：任务高度受控（字母 box、单 token 物体、单次 swap）；回路可能遗漏冗余/备份组件；binding ID 方向用均值差、线性假设，若非线性或跨子空间分布会低估；未来需多次 swap、更多实体、put/remove、自然叙事。跨模型差异的来源（架构/规模/预训练分布）未解释。
9. 对候选 1 关键的“没做的事”：
   - **只有 Transformer**；结论“读出时局部重绑定”依赖注意力能在查询时回看原绑定——这对纯 SSM 在结构上不可行（查询在后时，状态必须在 swap 时或之前就已更新），所以这篇恰好给出 SSM 的对立预测，但没有测。
   - swap 是“交换”，不是“覆写”（“now x=9”引入新值并废弃旧值）；没有覆写。
   - Q/K 子空间的 ID 干预形式可直接用于 Gated DeltaNet（有 q/k/v）和 Mamba-2（C≈query、B≈key），但作者没做。
   - 最大 12B，无规模系统扫描；Llama-3B 全模型准确率仅 0.71。
10. 证据强度与短板：设计有内部对照（content vs pointer；Q、K、Q+K 抵消；随机方向），但效应在模型间不一致（Gemma vs Llama 的签名不同），Gemma-12B 效应量很小；Q+K 在 logit 上未完全抵消。只有单一任务模板。
11. 可迁移的研究动作：把“全局更新 vs 读出时重绑定”写成可区分的补丁位置预测（swap 句末 vs ‘:’；对被问 box vs 所有 box）；把 ID 干预落到读出组件自身的 Q/K 空间并用 Q+K 抵消作诊断。
12. 对我们：这是候选 1 中“动态重绑定”部分最近的 Transformer 参照。在 SSM 上同样的“swap 句末补丁 vs 读出补丁”设计，所有可能结果都有信息：若 SSM 也只在读出处生效，说明它把 swap 信息压进状态后延迟解析；若 swap 句末补丁即可转移所有 box 的映射，就是 Global State Update——与 Transformer 形成对照。
