- 作者：Wes Gurnee*, Emmanuel Ameisen*, Isaac Kauvar, Julius Tarng, Adam Pearce, Chris Olah, Joshua Batson*†（Anthropic）。abs 页已核对。
- 阅读范围（2026-11-25）：正文 §1–8 + 附录 A–N（Haiku 任务表现、特征分裂/普适性、line width 特征、动力学模型方程、Fourier/ringing 解析构造、twisting 几何、break predictor、token 长度、head 特化、L1 OV、更多计数表征 N.1–N.2）。
- 代码：无完整代码（闭源模型）；网页版有交互粒子模拟、Fourier/ringing 的 colab；为 Gemma 2 2B、Qwen 3 4B 公开了 transcoder attribution graph（neuronpedia），但本文**没有分析**这两个模型。

1. **论文形态**：单模型、单任务的深度机制案例（features ↔ manifold 对偶 + 因果干预 + "visual illusion"）。
2. **背景与压力**：数值/序数变量在 LLM 中常被说成"线性表示"（线性 probe R² 高），但 Engels 2025、Modell 2025 已看到月份/年份等呈曲线；没有人把"曲线几何"和一个完整算法的每一步计算接起来。
3. **改变的前提**：线性 probe 能读出 ≠ 模型把变量放在一条直线上；计算是通过对弯曲流形的线性操作（QK 旋转/"twist"）完成的。
4. **idea 来源（DOCUMENTED）**：attribution graph 里看到 "previous line 40–60 字符"(key) 与 "current count 35–50"(query) 两族特征在 QK 上配对 → 猜它们在离散化一条流形。作者明说一开始只做 probe+patching 没进展（训练的是模型并不干净表示的量）。
5. **与最近邻的距离**：Engels et al. 2025（多维特征）、Modell et al.（曲线流形、cosine 编码内在几何）、Kantamneni & Tegmark 2025（数字 helix 做加法）、Nanda 2023（modular addition 旋转）。增量 = 换证据类型：从"看到形状"到"形状上的每步计算 + 权重级解释 + 因果"。
6. **方法 / 实验 / 数据**：
   - 模型：**只有 Claude 3.5 Haiku**（参数量未公开）。特征来自 10M 特征的 Weakly Causal Crosscoder。
   - 数据：散文去掉换行后每 k 字符在词边界重插换行，k = 15, 20, …, 150；Haiku 到第 3 行即对所有 k 高概率预测换行（附录 C，200 条序列，k=20…140）。
   - 变量：line character count（自上次换行起的字符数）、line width（相邻换行间字符数，表示在 newline token 上）、characters remaining、next token length。
   - 流形识别：layer 2 残差按 count（1–150）求均值 → 对 150 个均值做 PCA，**前 6 个 PC 占 95% 方差**（"character count subspace"）；PC1–3 看像 helix，PC4–6 更复杂扭曲。10 个 crosscoder 特征像 place cells（感受野随 count 变宽 = dilation），每个 count 常有 2–3 个特征同时激活，特征重构的曲线像样条近似。150 个 logistic probe（150 类）RMSE = 5；probe 权重 PCA 前 6 个成分占 82%。线性回归 probe（layer 1 后）R² = 0.985——作者强调这**不**说明模型沿一条线表示。
   - "ringing"：均值向量、probe、特征 decoder 三者的 pairwise cosine 都有"主对角带 + 两侧负带 + 再正带"。解释：理想"近邻相似、远处正交"的圆周相似矩阵（circulant）截断到 top-k 特征向量（即截断 Fourier 系数）必然产生 ringing 和 3D 投影中的波纹；粒子模拟（100 点在 6 维球面、近邻 6 个吸引其余排斥）复现两圈 ringing；ambient dim=3 时得"棒球缝"曲线（与 Modell 的颜色/年份/日期一致）。Fourier 成分比同数目 PCA 成分少解释至多 10% 方差。层越深 probe 相似度越尖、二级 ring 越高。
   - 因果：(a) 早层零消融 top-k PC 子空间 vs 随机 k 维子空间——只在下一个 token 是换行时 loss 大涨；(b) 均值替换 a' = a − μ_orig + μ_c，三个相邻早层、最后两个 token，整向量或只在 6 维 PCA 子空间内，6 维足以改变换行预测（aluminum 例子原 count=42）。
   - 边界检测：把 line width probe 乘 W_K、char count probe 乘 W_Q；残差空间内 count i 与 width k 的 probe 最大 cos ≈ 0.25（i=k 处），boundary head 的 QK 空间内最大 cos ≈ 1，且在 i < k 的偏移对角上；随机 head 无结构。多个 boundary head（每层一组 ~3 个）偏移不同、响应曲线平铺 characters remaining；三个 head 输出近 1 维，和是 2 维曲线（characters remaining 空间前 2 PC 占 92%），该子空间消融/替换同样只影响换行。
   - 最终决策：~90% 深度，characters remaining 与 next token length 在近正交子空间、曲率中等；PCA 平均嵌入的分离超平面对真实数据 AUC = 0.91。
   - 计数构造：注意力对 count 表示的影响约为 MLP 的 4 倍；layer 0 五个关键 head R² = 0.93，L0–L1 共 11 head R² = 0.97。L0 head 以上一换行为 attention sink，sink 长度 s_h、感受野 r_h 不同（像 boundary head 一样按偏移平铺）；每个 L0 head 输出在 PCA 中近似一条射线，**曲率来自多 head 求和**；L1 head 输出已带曲率并锐化估计。
   - 解释"为什么要弯"（§3.3）：1 维表示下线性操作只剩缩放与平移，无法"旋转对齐"做比较，只能得到单调乘积、没有自然阈值；分辨率论证——一条射线上相邻 count 要靠范数差区分，150+ 个位置需巨大动态范围，归一化后射线投影到球面只有 ≤π 的角距离；嵌入高维曲线则范数相近而彼此分开。characters remaining 动态范围小 → 用更低维、曲率更小的表示。
   - visual illusion：在 aluminum prompt 插入 "@@"（git diff 定界符）会让计数 head 也去 attend 它、打乱换行预测；180 个两字符序列中多数只中度影响（原 newline 概率 0.79），代码/定界符类（'' >> }} ;| || @@）影响大，且与 head 被"分心"程度相关。
   - 附录 N.2：markdown 表格的行/列 index 在 Haiku 中也有特征族、probe ringing 和"棒球缝" PCA。
7. **证据强度与短板**：单模型、闭源、无种子/重复；"helix"是 PCA 可视化描述，没有曲率或维数的统计量；因果证据是 loss/logit 变化的图，非系统数值表。作者自认未研究：line width 如何从多行聚合、可变行宽、多 token 词、不确定性；方法是"existence proof 而非通用配方"。
8. **可迁移的研究动作**：特征族 → 参数化流形 → 用权重（QK/OV）把 probe 族映射过去看"twist"；用均值替换在低秩子空间做定量干预；用一个最小物理模型说明几何是约束下的最优解。
9. **对我们（候选 2）**：
   - 本文**提出**而未检验的可证伪预测正是候选 2 的核心：曲率的功能理由是"注意力 QK 需要旋转来比较"+"范数/归一化下的分辨率"。前者是 attention 特有，后者对任何有归一化的残差网络都成立——所以"注意力稀少的架构会用直线累加器"并不是本文的直接推论，只推出前一半理由消失。
   - 没做：其他模型（含开源 Transformer）、非 Transformer、独立训练重复、沿流形 vs 线性 steering 对比、任何曲率/维数的阈值化判定。
   - 风险：ringing/波纹在本文自己的分析里是"任何局部调谐码投影到低维"的通用结果——看到 helix 状 PCA 不能单独说明架构做了什么。
