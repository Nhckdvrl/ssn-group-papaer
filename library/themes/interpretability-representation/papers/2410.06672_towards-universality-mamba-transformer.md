# Towards Universality: Studying Mechanistic Similarity Across Language Model Architectures（arXiv 预印本 2024-10，v2，"Under Review"；后续发表情况未核对，Ben-Artzy 2609.08692 以 "Wang et al. (2025)" 引用）`[证据级别：全文]`

- 作者：Junxuan Wang, Xuyang Ge, Wentao Shu, Qiong Tang, Yunhua Zhou, Zhengfu He, Xipeng Qiu（复旦 OpenMOSS）。arXiv:2410.06672v2，abs 页已核对。
- 阅读范围（2026-11-25）：正文 §1–7（SAE 训练、MPPC、两个 skyline、复杂度分析、Mamba induction 电路与 Off-by-One、局限）；附录（GPT-4o 复杂度打分提示、更多电路图）检索式阅读。

1. **论文形态**：测量（跨架构特征相似）+ 电路级比较。
2. **背景与压力**：机制可解释性几乎只研究 Transformer；发现能否迁移到 Mamba 等架构决定已有理解的寿命。
3. **改变的前提**：神经元基不可比（非特权基），应先用 SAE 抽特征再跨模型配对。
4. **idea 来源（DOCUMENTED）**：Li 2016 / Gurnee 2024 的跨种子神经元对应；SAE 特征作为可比单位。
5. **与最近邻的距离**：相对 Gurnee 2024（同架构跨种子 1–5% 普适神经元）→ 换到跨架构 + SAE；相对 Ben-Artzy 2609.08692 → 特征/电路层面而非几何层面。
6. **方法 / 实验 / 数据**：Pythia-160M（12 层）vs Mamba-130M（24 层），每层 SAE；Max Pairwise Pearson Correlation（MPPC：每个 Pythia 特征在 Mamba 全部特征中取最大激活相关）；神经元基线；skyline 1 = 另一种子的 Pythia（模型种子变体）；skyline 2 = 同一 Pythia 上另训的 SAE；GPT-4o 给特征复杂度/单义性打分；induction 电路逐层分析。
7. **关键数字**：
   - 神经元基线几乎无相似；跨架构 SAE MPPC 均值 0.74，模型种子 skyline 0.76，SAE 种子 skyline 0.81；>30% Pythia 特征在 Mamba 中有 MPPC>0.95 的配对。
   - 跨架构减去种子 skyline 的差：90% 特征落在 [−0.22, 0.14]，>60% 接近 0（架构的边际影响小于或接近种子噪声）。
   - 层深对应：Pythia 第 l 层特征最可能在 Mamba 的相对同深度配对。
   - 复杂度越高 MPPC 越低（简单 token 级特征近 1；复杂特征 0.3–0.8；极低者多不可解释）。
   - Mamba 有结构上类同的 induction 电路，差异为"Off-by-One"：一个 token 的信息在下一位置写入 SSM 状态。
8. **证据强度与短板（作者自述，局限节）**：MPPC 只是激活相关、不对称；高 MPPC 不等于语义更相似（受特征复杂度影响）；模型很小。另：只有一个种子对照；没有任何几何/流形层面的比较；没有算法变量；Mamba 内部状态只在电路部分涉及。
9. **可迁移的研究动作**：**用"同架构不同种子"作为跨架构相似度的天花板（skyline）**——跨架构差异是否超出种子噪声，比绝对相似度更有信息；这正是候选 2 需要的参照点。
9a. **对候选 2：它没做什么**：没有表征流形形状；没有计数/括号深度等变量；没有 steering。它的结论（特征层面 Mamba≈Pythia，差异 ≈ 种子噪声）又给了一个"跨架构会收敛"的先验。
