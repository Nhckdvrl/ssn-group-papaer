# How Do Language Models Choose Between Context and Memory?（arXiv 预印本 v2 2026-09-28，cs.LG，Preprint，未见评审，分数 —）`[证据级别：全文]`

- 作者：Benjamin Shih, John Winnicki, Arianna Cao（Stanford / Perpetual Labs）。arXiv:2609.00753v2，abs 页已核对。
- 阅读范围（2026-11-25）：正文 §1–8、附录 A（控制与层区间）、B.1–B.4（颜色任务、子空间 rank、材料任务转移、州/国家）的主要表与设定。

1. **论文形态**：因果中介测量（自然激活值互换）+ 跨任务迁移拆分（方向 vs 激活值）。
2. **背景与压力**：context–memory 冲突上已有一维"旋钮"（Minder 2025）、SAE steering（Zhao 2025）、晚层 authority 定位（Joswin 2026）。这些都只说明方向可解码、可外加 steering，没有说明**未编辑模型的自然变异**是否经由该方向决定来源选择，也没测跨任务。
3. **改变的前提**：方向从 context 与 memory 一致的提示中估计（避免用冲突结果定义方向），然后在冲突提示中做 high/low authority 配对的**坐标互换**（只换沿方向的标量，保留正交分量，8 层重复），而不是加常数向量。
4. **idea 来源（DOCUMENTED）**：Basu 2603.18353 与 Srivastav 2026 的"可读 ≠ 可用"；Geiger 风格 interchange intervention。
5. **与最近邻的距离**：Minder 2025 / Joswin 2026（steering 与定位）→ 本文加"自然变异中介"与跨任务；Basu 2603.18353（可读不可用）→ 本文给出可用的情形（同任务）和不可用的情形（跨任务单层）。
6. **方法 / 实验 / 数据**：
   - 模型：Qwen2.5-3B、Qwen2.5-7B、Llama-3.1-8B、OLMo-2-7B，均为 instruction-tuned，冻结，无 base 对照。层在 Qwen2.5-7B 选定，按相对深度映射。
   - 任务：颜色（12 色候选，"The grass is definitely purple" vs "unverified rumor"）；材料（答案词汇不相交）；州/国家。五类 authority cue：措辞、来源可信度、引证、共识、第一人称自信（作为经验零基线）。
   - 指标：context-following 率；GapClosure = [(p_{L←H}−p_L)+(p_H−p_{H←L})]/(p_H−p_L)；对照 = 随机方向、残差协方差匹配方向、打乱 authority 标签。
7. **证据强度与短板**：
   - 关键数字：加性 steering（Qwen2.5-7B 层 21）低 authority 0.14→0.76，高 authority 0.90→0.06；方向半样本重估余弦 0.96（最低 0.93）。坐标互换 gap closure：Qwen 68%、Llama 56%、OLMo 30%，随机近 0。材料任务：用颜色方向 0.085 vs 本任务方向 0.574（14.8%）；颜色值放进材料方向 0.684（打乱 authority 0.077）。rank 1–4 中介 0.326/0.691/0.755/0.836，但附加维度未通过 authority 特异性对照。州↔国家：AUROC 0.995–1.000 而单层最大效应 0.014 / 0.038。
   - 作者承认：任务、提示、模型有限；跨任务弱迁移可能来自采样或非线性共享表征；州/国家只做单层，多层与高维互换未做。
   - 我的评价：设计干净（一致提示估方向、冲突提示测中介；方向与值分开迁移）；但只测 instruct 模型，结论与 post-training 无关。
8. **可迁移的研究动作**：(a) 方向在"无冲突"条件下估计、在"冲突"条件下测因果，避免用结果定义自变量；(b) 自然坐标互换 + gap closure 作为中介量；(c) 把"方向能否迁移"与"值能否迁移"拆开测。
9. **对我们**：
   - 与候选 3 无题目重叠（没有 base→post-trained）。
   - 方法上直接可用：若候选 3 要说 "RLVR 把 readout 方向重新对齐到 base 已有表征"，合适的检验是在 base 与 RLVR checkpoint 间做**沿 base 方向的坐标互换**并报告 gap closure，配协方差匹配对照，而不是只报 probe 准确率或 steering 成功率。
   - 它显示同一表征的可读性可以跨任务保持而因果效应消失（州/国家），这意味着 "base 已表征" 的判据必须是因果的，不能只是 AUROC。
