# Base Models Know How to Reason, Thinking Models Learn When（ICML 2026，PMLR 306；arXiv v4 2026-07-07；分数 —）`[证据级别：全文]`

- 作者：Constantin Venhoff, Iván Arcuschin, Philip Torr, Arthur Conmy, Neel Nanda（Oxford / MATS / Poseidon Research）。arXiv:2510.07364v4，abs 页已核对。
- 阅读范围（2026-11-25）：正文 §1–6、附录 A（SAE 设定）、B（LLM 评分 prompt）、C（人工校验）、D–E（category vector 训练与 hybrid 细节）的主要内容、G（分类表）抽查。
- 代码：github.com/cvenhoff/thinking-llms-interp。

1. **论文形态**：constructive model diffing（用可解释部件显式重建 base→thinking 差异并测恢复率）+ 无监督推理行为分类。
2. **背景与压力**：thinking 模型学到了什么？假说包括全新推理能力（Gandhi 2025）、更好的结构（Marjanović 2025）、重用既有表征（Ward 2025a）、更多推理算力（Zhao 2025）。crosscoder 式 post-hoc diffing 假设差异可以写成线性特征。
3. **改变的前提**：把差异拆成 "mechanism"（base 中可诱导某推理行为的 category vector）和 "heuristic"（何时触发，来自 thinking 模型的 SAE 分类），用 hybrid（base 生成 + thinking 的 heuristic 触发 base 的 vector）去恢复 thinking 模型的准确率；恢复率高 = 差异主要是 heuristic。
4. **idea 来源（DOCUMENTED）**：作者此前的推理 steering vector 工作（Venhoff 2025）；Ward 2025a（base 中存在可引导推理的方向）。
5. **与最近邻的距离**：Ward 2507.12638（backtracking 方向在 base 中已存在）→ 本文推广到完整分类并比较 RL vs SFT；Shi 2604.25011（同 base 同数据 SFT vs RL crosscoder）→ 本文用公开模型、恢复率而非特征计数；Minder 2504.02922 crosscoder → 本文认为差异在更高抽象层。
6. **方法 / 实验 / 数据**：
   - 九对 base/thinking：SFT 蒸馏 R1-Distill（Qwen2.5-Math-1.5B、Llama-3.1-8B、Qwen2.5-14B、Qwen2.5-32B 为 base）；RL 训练 Open-Reasoner-Zero（Qwen2.5-0.5B/1.5B/7B/32B base）；混合 QwQ-32B。
   - 分类：句子级平均激活上训练 Top-K SAE（字典 5–50、6 个层），LLM 评 consistency/completeness/independence，人工校验（ORZ-7B 15 类中 14 类与人写标签匹配）；5 个种子特征匹配率 93.3%。
   - category vector：在约 37% 深度，teacher-force thinking rollout 进 base，取两模型下一 token 不一致的位置，按 SAE 类别联合优化每类向量 + 一个预测系数的小 MLP（交叉熵对准 thinking 模型的下一 token）。三组向量选 holdout 最好的一组。
   - 评测：GSM8K、MATH500、1,000 题 Hendrycks-MATH 留出集；base 与 hybrid 贪心，thinking 采样 3 次 T=0.6；2048 token；Claude Sonnet 4.6 评分（与人工 κ=0.88）。
7. **证据强度与短板**：
   - 关键数字：恢复率 RL（ORZ）平均约 76%（如 ORZ-7B GSM8K 71.5→hybrid 90.7→thinking 93.4，87.8%；ORZ-32B GSM8K 93.6%），SFT 蒸馏约 11%（1.5B/8B 为负或近 0，14B/32B 12–32%），QwQ-32B 14–29%。RL hybrid 只 steer 5–12% 的 token。消融（ORZ-1.5B/32B）：随机类别 20–28%，随机向量 −28%/−13%，只留 MLP 幅度 −8%/−1%，随机位置 −8%/28%。
   - 作者承认：分类偏向数学；steering 强度由 thinking 模型训练的 MLP 给出；SFT 恢复率低可能是 category vector 优化的局限而非机制改变。
   - 我的评价（混杂）：(a) RL 组与 SFT 组的 base 不同（R1-Distill-1.5B 用 Qwen2.5-Math），数据、教师、训练量都不同，"RL vs SFT"与"ORZ 配方 vs R1 蒸馏配方"不可分；(b) 恢复**百分比**依赖分母：ORZ 的 base→thinking 差距小（0.5B GSM8K 25→47），R1-Distill 差距大（8B 45.6→94.3），差距越大越难恢复——这本身就是程度量；(c) heuristic 与 MLP 系数都从 thinking 模型学来，hybrid 不是纯 base；(d) "mechanism 已在 base" 由 base 中能否优化出有效 steering vector 判定，任何足够强的方向优化都可能在 base 中"找到"能力。
8. **可迁移的研究动作**：constructive diffing（用部件重建差异、报告恢复率并做部件随机化消融）；只在 base 与 tuned 模型下一 token 不一致的位置干预（稀疏）。
9. **对我们**：
   - 对候选 3 是**主要撞车**之一：问题"RL 学到的是 orchestrate 既有机制还是装新机制、SFT 相反"已被 ICML 2026 论文公开回答（RL ≈ heuristic over pre-existing，SFT ≈ install new），且用的是推理/数学任务。
   - 它没做：逐题区分"base 已表征但读错"与"未表征"；同一 base 上 SFT→DPO→RLVR 的阶段链；probe / patching 层面的"readout 方向对齐"检验；KL、步数等训练细节匹配。
   - 对导师标准：它的 RL vs SFT 对比是跨配方的，恰是"程度/配方"混杂的范例。
