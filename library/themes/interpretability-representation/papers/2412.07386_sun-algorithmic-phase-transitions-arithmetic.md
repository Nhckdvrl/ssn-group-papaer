# Algorithmic Phase Transitions in Language Models: A Mechanistic Case Study of Arithmetic（ATTRIB @ NeurIPS 2024 workshop）`[证据级别：全文]`

- 作者：Alan Sun, Ethan Sun, Warren Shepard。arXiv:2412.07386v1（2024-12-10），abs 页已核对。
- 阅读范围（2026-11-25）：全文（短文）。

1. **论文形态**：构念引入（algorithmic stability / phase transition）+ 单模型测量；不是跨模型比较。
2. **背景与压力**：同一任务的模型策略是否随任务设定改变，缺少定量定义。
3. **改变的前提**：把"算法 = 解释任务的最小子电路"，用电路间距离定义稳定性：sup ρ(alg(m,t'),alg(m,t)) ≤ ε。
4. **idea 来源（DOCUMENTED）**：Nanda 2022、Zhong 2023 的"同任务多算法并存"，Merullo 2023 的电路复用。
5. **最近邻**：Zhong 2023（Clock/Pizza，从零小模型）→ 搬到预训练 LLM、变量改为任务规格；后继 Sun 2505.24731（电路稳定性）。
6. **方法**：Gemma-2-2b，两操作数加法，m,n∈{1..8} 位，共 64 类子任务，2-shot 提示；对每个子任务做激活补丁得到每个注意力头的重要性向量，用该向量的 t-SNE/距离比较"算法"。
7. **关键结果**：子任务的电路聚成三类（对称、内部、边界）：如 8+8 位、1+6 位、4+4 位的电路明显不同。判据是电路重要性向量的聚类，没有变量级或反事实签名；没有测试其它模型。
8. **短板**：单模型、workshop、"不同算法"仅由头重要性图差异定义，可能是相同算法的不同实现（见 Bayat Makou 2606.06267 的"phantom specialization"警告）。
9. **对我们**：给出"预训练 LM 内部随任务规格切换策略"的存在性证据，但这是模型内（任务）轴，不是模型间轴；判据弱，需要反事实签名才能说是不同算法。
