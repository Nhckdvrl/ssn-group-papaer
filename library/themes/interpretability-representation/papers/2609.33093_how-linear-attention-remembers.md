# How Linear Attention Remembers（arXiv 预印本 v1 2026-09-27，cs.LG，Preprint，未见评审，分数 —）`[证据级别：全文]`

- 作者：Kichang Lee, JaeYeon Park, Songkuk Kim, JeongGil Ko（KAIST / Yonsei / Dankook）。arXiv:2609.33093v1，abs 页已核对。
- 阅读范围（2026-11-25）：正文 §1–6、附录 A（checkpoint 与 commit）、B（头筛选）、C（留出因果全景、logit lens）、D（单关联抑制、可复用通路）、E（hybrid 稳健性、GLA-7B / RWKV7）、F（状态特征纠错、prose 检索能力检查）。

1. **论文形态**：预训练模型上的因果干预测量（写入 → 保持 → 读出生命周期），附 hybrid 边界检验。
2. **背景与压力**：KV cache 的冗余/压缩/驱逐研究很多，但线性注意力的固定大小状态 S_t ∈ R^{d_k×d_v} 是许多 token 共享、反复更新的；不清楚哪些更新携带记住的内容、多个事实如何共存、为什么随负载退化、有全注意力时状态是否仍是记忆载体。
3. **改变的前提**：把状态写成 S_t = Σ_i C_i^{(t)}（各位置写入经后续线性转移的贡献），从而把"写入、保持、读出"拆成可单独干预的环节；供体/受体配对只改目标 key 的 value。
4. **idea 来源（DOCUMENTED）**：Schlag 2021 fast-weight 解读；Meng 2022 / Zhang & Nanda 2024 的 activation patching。
5. **与最近邻的距离**：Arora 2505.15105（从头训练玩具模型）→ 本文用预训练 GLA/GDN；Koren 2609.07681（Mamba AR 的哈希/外积表）→ 本文在预训练模型里检验"独立 KV 槽"是否成立并得出否定（跨事实因果耦合）；2609.04434 / 2611.01909（hybrid cache 干预）→ 本文给出纯递归 vs 近匹配 hybrid 的对照与 Qwen3.5 的 KV 主导。
6. **方法 / 实验 / 数据**：
   - 模型（全部冻结、base）：m-a-p/340M-20B-GLA-pure-baseline、m-a-p/340M-20B-GatedDeltaNet-pure-baseline、m-a-p/1.3B-100B-GatedDeltaNet-pure、m-a-p/340M-20B-GatedDeltaNet-hybrid-3-1（24 层中 8 层全注意力，层 2,5,…,23）、Qwen3.5-4B-Base、Qwen3.5-9B-Base；附录 E 加 fla-hub/gla-7B-mistral-20B、RWKV7-G1j-2.9B、RWKV7-G1j-13.3B。commit 全列出。GLA-340M 4 头 d_k=128/d_v=256；GDN-340M 4 头 256×256；GDN 带宽 4 short conv，GLA 不带。
   - 任务：WikiText-103 自然文本中嵌入 key–value 关联（1–32 个），4 选 1 候选值按条件似然打分；开发/确认用不相交来源段；统计单位 = 来源段，source bootstrap 95% CI。
   - 干预：pre-query 单头状态替换为供体（筛选全部 96/96/192 个头）；事实时刻写入阻断（W→0）或替换为供体写入；查询时刻头输出 patch / restore；多事实下对 ΔA 投影到 ΔB 方向与正交残差分别加回；写入 key 对齐/正交化。
7. **证据强度与短板**：
   - 关键数字：头筛选高度集中（GLA L21H3 J=8.41、GDN-340M L20H2 J=6.07、GDN-1.3B L20H3 J=4.52；留出 32 来源秩区间 [1,1]）。阻断事实写入使回忆下降 36–79 个百分点；供体写入使供体值成为答案 68–90%，等范数随机与对照头无效。GLA 选中头与次头联合阻断强非加性。4 事实下定向编辑转移 61–89%，非目标被破坏仅 0.4–1.4%；但 ΔA 的平行/正交分量对 B 的 margin 有**相反**效应（"cross-fact causal coupling rather than independent KV-like storage"）。负载 K=1→16 回忆降 30–40 pp（固定序列长）；距离 128→1024（K=4）只轻微下降；K=32 时回忆 47–60%（340M）、69%（GDN-1.3B），编辑强度减半以上；后写 key 对齐目标方向使目标 margin 降 0.27–0.44 logit，正交化无效。**附带差异**：两个 GDN 在 K=32 前非目标破坏率 <2%，GLA-340M 从低负载起就超 5%——作者推测 delta 规则"写入相对于当前 key 方向已有内容的修正"抑制串扰（只是推测，未干预检验）。
   - **Hybrid**：纯 GDN-340M 中递归状态替换恢复几乎全部供体效应；近匹配 hybrid 中递归/局部替换恢复 <1%，KV 替换 >99%。Qwen3.5-4B 三条件（retrieval、latest-value、integration）递归 0.2–3.6% vs KV 96–100%；附录 E.1 **自然实体更新任务**（WikiText 填充 clean 93.0%、PG19 89.1%）与 RULER 单针 4K：递归替换 0% 供体答案，KV 替换 85.2% / 89.8% / 100% 供体答案，占全效应 96–97%。
   - 附录 D.2：同一头在不同绑定数、模板、值词表、"更新后值"条件下都可替换（GDN 在 update 条件 46.8%），但颜色学到的 rank-4 基不迁移到形状 → "可复用读通路"而非固定语义槽。附录 E.2：GLA-7B 最强单组件只恢复 12.3%（top-16 达 92.3%），RWKV7 结构不同且对格式敏感。附录 F.2：prose 检索（31 城市）基础能力不足 80%，未做因果分析。
   - 作者承认：只做受控 AR；checkpoint 有限；纯 vs hybrid 是分别训练的 release 而非受控重训（参数差 4.2%、数据顺序/种子未知）；选中通路不应理解为孤立存储位置。
   - 我的评价：设计纪律好（开发集筛头、冻结后确认、随机等范数对照）；4 选 1 + 每题多次呈现绑定，任务简单；"实体更新"条件只在 hybrid 上做了载体检验，没在纯递归模型里做擦除机制分析。
8. **可迁移的研究动作**：(a) 线性分解 S_t = Σ C_i^{(t)} 把写入/保持/读出分开干预；(b) 供体写入替换测"内容特异性"，阻断测"必要性"；(c) 把差分状态 ΔA 分解为与 ΔB 平行/正交分量来测事实间耦合；(d) cache 级三因子（只换递归 / 只换 KV / 都换）定位 hybrid 的运行时载体。
9. **对我们（候选 1）**：
   - **最接近的撞车点（部分）**：它已经回答了候选的一半问题——纯 GLA/GDN 的状态里多个绑定"可选择性访问但不是独立 KV 槽"，且在 hybrid（GDN-340M-hybrid、Qwen3.5-4B/9B）里，包括**实体更新**在内的被回忆身份几乎全部由全注意力 KV 承载。
   - **没有做**：Feng & Steinhardt 式 binding ID 检验（实体/属性激活里的加性、位置无关 ID 向量；均值差注入能否交换绑定；ID 子空间线性组合是否仍有效）；残差流层面的 binding 表征（只看了递归状态矩阵）；Mamba / Mamba-2 / Falcon-Mamba / Granite-H / Falcon-H1；纯递归模型中的覆盖/擦除（delta 规则是否真的就地擦除旧值）；多实体多属性（只有 key→单值）。
   - 资产：m-a-p 释放了**同数据同预算**的 340M-20B 与 1.3B-100B 系列：GLA / GatedDeltaNet / DeltaNet / RetNet / HGRN / HGRN2 各有 pure 与 hybrid-3-1/6-1/12-1/24-1（HF 已核对）；fla-hub 另有 transformer-1.3B-100B、mamba-1.3B-100B、delta_net-1.3B-100B 等。这是候选若要做"更新规则作为自变量"的现成对照组，但 340M–1.3B 是否有足够的多实体绑定行为能力未知（本文 prose 检索已失败）。
