# Anatomy of Associative Recall in Fixed-State Recurrences: A Matched-State Decomposition, an Interference Wall, and a Curriculum That Breaks It（arXiv 预印本 v1 2026-09-14，cs.LG，自述 "Preprint of preliminary results; not peer reviewed"，分数 —）`[证据级别：全文（正文 §1–9；附录只看了 A/C 的引用部分）]`

arXiv 2609.16183（abs 页已核对）；Julian Boesch, Andrew Wee（Purdue / Obit Research）。代码与结果 JSON 在 abs 页链接。2026-11-25 读。

1. 论文形态：受控玩具因子设计（单旋钮消融）+ 失败诊断 + 训练干预。
2. 背景与压力：“递归模型 recall 差”“DeltaNet 擅长 recall”“Mamba 比 RNN 好”等结论来自整架构比较，混了短卷积、转移结构（rank-1 delta vs 对角）、衰减三个旋钮。
3. 改变的前提：固定状态预算（1,024 个状态元素，约 29k 参数），一次只切一个旋钮；10 种子、置换检验、rebinding 对照（打乱绑定后应崩到地板）。
4. idea 来源（DOCUMENTED）：Zoology / MQAR；Arora 2505.15105（Mamba 的 induction 在卷积里）；Okpekpe & Orvieto 2025（学习率混杂）。
5. 与最近邻的距离：Arora 2505.15105（干预定位）→ 本文做因子消融；Koren 2609.07681（Mamba 哈希电路）→ 本文不做理论；Sridhar & Johansen 2026（衰减解释 SSM 检索失败）→ 本文给出“与距离无关的墙”反驳衰减解释。
6. 方法 / 实验 / 数据：
   - 单元：DeltaNet、Gated DeltaNet、RWKV-7 型 dg rank（及其 rank-1 关闭的 dg diag）、状态匹配的纯 PyTorch Mamba-2（及无卷积版）；“armed” = 加宽度 4 因果深度卷积。对照：官方 fused Mamba-2 kernel；2 层 softmax 注意力（haystack 任务的上限）。
   - 任务：masked MQAR（K ∈ {8,16,32}，值每序列随机，地板 0.038 / 无绑定 0.068）；haystack（4 对 + 干扰 + 查询，L=64–512，地板 1/54）；**collision-key 变体：干扰对重用表中的 key 并给新值，正确答案是第一次（表中）绑定**——即“不应覆写”；S5 字问题护栏。
7. 关键数字：
   - 卷积是最大旋钮：delta 单元 0.518→0.983（+0.47），对角单元 0.151→0.592（+0.44），K=32。
   - rank-1 vs 对角（同一单元）：+0.191（K=16）、+0.319（K=32），加卷积后只剩 +0.034；状态匹配 Mamba-2 与无卷积 rank-1 单元打平（K=16）甚至更好（K=32：0.849 vs 0.702）→ “no class claim survives”。衰减在 n=20 时无成本（0.561 vs 0.518，p=0.86）。调学习率后三种 armed 单元都饱和（≥0.997）。
   - 墙：能解 32 对 recall 的单元，在 4 对 + 干扰的 haystack 上最短长度就到机会水平，对长度与转移类型都平；注意力 1.0。距离课程使同一架构 0.021→1.000；锁定率 1/10→7/10（p=0.02）。作者结论：稀疏监督下的干扰——“Distractor writes overwrite the bindings before the query arrives”。
   - **collision-key**：双向 3/10、因果 1/10 种子解出（差异 n.s.）；课程后都到 9/10；因果单元最好 0.844。作者明说这“robustly contradicts the single-cell theory that an input-conditioned write gate ‘must’ overwrite on key reuse”，任何解都需要两层（mark-and-route），推测第 1 层状态可编码“该 key 已绑定”，使第 2 层写门变成依赖状态。
8. 作者承认的局限：全部玩具规模（d ∈ {32,128}）；纯 PyTorch Mamba-2 欠训练；d=32 时没有有效注意力对照；只是初步结果。
9. 对“架构 × 覆写”方向关键的点：
   - **直接反驳“delta-rule 模型遇到同一 key 必然原位覆盖”**：多层 delta-type 单元可以学会保留第一次绑定、忽略后来的同 key 写入。是否覆写是学到的策略，取决于训练分布，而不是更新规则的必然结果。对预训练模型，这意味着探针 B 的“delta-rule 会丢失原值”不能当作先验预测。
   - 卷积混杂：相邻的“A = 1”可由短卷积直接绑定；探针中键值间隔必须操纵。
   - “rank-1 vs 对角”的类别差异在匹配条件下消失 → 预训练模型间的 recall 差异大多是容量/训练差异，算法差异必须用签名（而非准确率）读出。
10. 证据强度与短板：统计规范（10 种子、Fisher、rebinding 对照、地板）；规模极小，外推到预训练模型要谨慎。
11. 可迁移的研究动作：rebinding 对照区分真检索与值显著性启发式；对双峰结果报告锁定率而非均值；collision-key 作为“该不该覆写”的判别任务。
12. 对我们：探针 A（应覆写）与 collision-key（不应覆写）构成一对互补任务；在预训练模型中，同一模型在“当前值”与“原值”两种查询下的表现正是这对任务的自然语言版本。
