# Late Attention Layers Alone Can Copy Entity Tokens, but Not Without Attending to Their Context（arXiv 预印本，评审状态未核对）`[证据级别：摘要 + 方法与模型设定]`

arXiv 2609.35663 v1 2026-09-28，v2 2026-10-26；Muyu He, Yuchen Liu, Ran Tao, Li Zhang（Drexel）。

1. 论文形态：构念引入+测量（层限制与注意力切断两个干预）。
2. 背景与压力：实体复制已有头级研究，缺少“哪几层负责、上下文 token 起什么作用”的系统说明。
3. 改变的前提：genie-in-a-bottle（精确规定哪些层可参与）与 attention lobotomy（切断指定 token 对实体 token 的注意力而不改其余注意力分布）。
4. idea 来源（RECONSTRUCTED）：层专门化与“空白 token 也承载信息”的现象。
5. 与最近邻的距离：Elhelo & Geva 2025（复制头）、Feucht 2025（概念 vs 字面复制）、Gur-Arieh 2026（引用了位置/词汇/反射分类）。增量：换设定（层组 + 上下文 token）。
6. 方法 / 实验：**仅 Qwen3-8B-Base**，补全模式；后半段两组层必要且充分；上下文 token 对实体 token 的注意力对精确复制是必要的。
7. 证据强度与短板：单模型单家族，无跨模型复现；不涉及多实体绑定。
8. 可迁移的研究动作：用“只放行某些层”的充分性测试代替单纯消融。
9. 对我们：与候选 C 同类的“单模型机制论断”，是被要求跨家族复现的对象之一；自身不做跨模型。不构成撞车。
