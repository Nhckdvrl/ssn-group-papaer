# Interpretability without actionability: mechanistic methods cannot correct language model errors despite near-perfect internal representations（arXiv 预印本 2026-03-18，cs.AI，TRIPOD+AI 格式，未见评审，分数 —）`[证据级别：全文]`

- 作者：Sanjay Basu, Sadiq Y. Patel, Parth Sheth, Bhairavi Muralidharan, Namrata Elamaran, Aakriti Kinra, John Morgan, Rajaie Batniji（UCSF / Waymark / UPenn / VCU / Stanford）。arXiv:2603.18353v1，abs 页已核对。
- 阅读范围（2026-11-25）：正文全部、附录 A（prompt、关键词解析、各 arm 公式）、表 4–9（含 parser 敏感性表 8）。

1. **论文形态**：应用场景下的四臂比较（"knowledge–action gap" 的测量 + 推理期干预能否弥合）。
2. **背景与压力**：Burns / Li (ITI) / Marks & Tegmark 显示模型"知道的比说的多"；监管（EU AI Act、FDA）默认可解释性能帮助纠错。没有人在安全攸关任务上横向比较多种推理期干预的纠错能力。
3. **改变的前提**：把"probe 可读"与"干预能改输出"分成两个可分别测量的量，在临床分诊假阴性上逐例记录"纠正数"与"破坏数"。
4. **idea 来源（DOCUMENTED）**：作者此前的临床分诊安全评测工作；ITI 的 truthfulness separator。
5. **与最近邻的距离**：ITI（Li 2023）在 TruthfulQA 上有效 → 本文在自然的临床文本上几乎无效；Shin 2023（concept bottleneck 干预未必因果传播）→ 本文给出 Steerling-8B 上的实测。
6. **方法 / 实验 / 数据**：
   - 数据：400 个病例（医生编写 200：132 危险/68 良性，18 类；真实 Medicaid 消息 200：12 危险/188 良性），三名医生裁定。
   - 模型：Steerling-8B（concept bottleneck LM，33,732 个医学概念）；Qwen2.5-7B-Instruct（28 层，3584 维，fp16）。都是 post-trained 模型，没有 base 对照。
   - 回答解析：自由生成（temperature 1.0，seed 42，300 token），关键词列表判为"检测到危险"。
   - Arm 1 概念瓶颈 steering（top-20 概念，留一法选择，α 0–1，随机概念对照）；Arm 2 SAE（层 14，16,384 宽，在这 400 例的 62,662 个 token 上训练，L0≈1,455；Mann-Whitney + BH 选 3,695 个特征；clamp top-20 到 TP 均值 1×/2×）；Arm 3 logit lens + 沿 TP–FN 均值差方向 patching（层 22，α 0.5–5）；Arm 4 逐层 L2 logistic probe（**输入位置均值池化**，5-fold）+ TSV（TP−FN 均值差）steering（层 23，α 0.5–10）。
7. **证据强度与短板**：
   - 关键数字：基线敏感度 Steerling 51/144（35%）、Qwen 65/144（45%）；probe AUROC 0.954–0.982（层 23 最高，CI 0.968–0.993）；"53 个百分点 gap"。概念 steering 纠 17/85、破坏 25/47，与随机概念无差（McNemar p=0.84）；SAE 0/79 纠正、0/65 破坏；patching α=1 纠 6 破 6，α=5 净 +11；TSV α=1 纠 5 破 5（随机方向 7/7），α=10 纠 19/79、破 4/65（净 +15），α=10 的随机对照未跑。TSV AUROC（TP vs FN）0.814，与危险方向余弦 0.50。改进 parser 后 Qwen 敏感度 0.451 → 0.729，gap 缩为 0.253。
   - 作者承认：两模型、单任务、真实子集危险例只有 12；关键词 parser 低估基线；无现成 SAE；只测推理期方法；α=10 随机对照缺失。
   - 我的评价：(a) "gap" 用 probe AUROC 减输出敏感度，是两个不可比的量（排序指标 vs 固定阈值下的召回）；(b) probe 在两个子集混合上训练，两个子集危险率 66% vs 6%，且文本风格完全不同（医生编写 vs 真实消息），"子集身份"本身就能给出高 AUROC，作者没有分子集报告 probe；(c) SAE 只在 400 例上训练，"0 效果"可能是 SAE 质量问题；(d) 只在单层加方向、只在最后 token。结论"表征近乎完美而行为差"的测量部分偏弱，"推理期干预难以纠错"的部分较可信。
8. **可迁移的研究动作**：每种干预同时报告"纠正率"与"破坏率"（而不是平均准确率）；随机方向/随机概念的配对 McNemar 对照。
9. **对我们**：
   - 对候选 3 的作用：说明 "probe 可读" 不等于 "存在可被一条方向修好的读出错误"；若候选 3 声称 "RLVR 修好的是 base 已表征但读错的题"，必须先证明这些题在 base 中的 probe 信号不是任务无关的混杂（这里的子集混杂就是反例）。
   - 它没做：没有 base vs post-trained 对比；没有训练期干预（作者把训练期修复列为未来工作）；没有逐题区分"可读但读错"与"不可读"。
