# Global Divergence, Local Convergence: Representation Geometry in SSMs and Transformers（arXiv 预印本 2026-09，v1，ACL 系格式，未见评审）`[证据级别：全文]`

- 作者：Amit Ben-Artzy, Roy Schwartz（Hebrew University of Jerusalem）。arXiv:2609.08692v1，abs 页已核对。代码 schwartz-lab-NLP/ssm-vs-transformer-geometry。
- 阅读范围（2026-11-25）：正文 §1–8、Limitations；附录（更多模型 Llama3/Qwen2、更多秩、ZCA 稳健性、checkpoint）检索式阅读。

1. **论文形态**：测量（多尺度几何比较：全局 → 概念子流形 → token 邻域）。
2. **背景与压力**：Mamba 等 SSM 性能接近 Transformer，但结构不同（有界状态 vs 全局注意力）；二者表征几何是否不同未系统研究。
3. **改变的前提**：全局几何与局部（概念/邻域）几何应分开比较；线性 CKA 受方差谱主导，需全局 ZCA 白化后再比。
4. **idea 来源（RECONSTRUCTED）**：Transformer 各向异性文献（Gao 2019、Godey 2024）+ Platonic 假说（Huh 2024）+ Gröger 2026（视觉-语言局部收敛、全局拓扑不同）。
5. **与最近邻的距离**：相对 Wang 2410.06672（SAE 特征相似）→ 换证据类型（几何而非特征）；相对 Fu 2604.20817（数字周期结构）→ 通用语料与事实关系，而非算法变量。
6. **方法 / 实验 / 数据**：
   - 模型：Pythia-1.4B、Falcon-7B（Transformer）；Mamba-1.4B、FalconMamba-7B（SSM）；Jamba2（交替 hybrid）；附录 Llama3、Qwen2。只看层间残差流，不看 SSM 内部状态。
   - 全局：FineWeb-Edu ≈500k 表征；RankMe、IsoScore、PC1 方差占比。
   - 容量：2 层 AE 不同瓶颈秩 r 重建，替换单 token 单层后测输出 KL。
   - 概念：LAMA T-REx 关系，宾语末 token；秩约束探针；去除/保留 top-k PC 后探针。
   - 对齐：全局 ZCA 白化后的线性 CKA（每关系）；mutual-kNN（k=10，10,000 token，共享分词器）；Pythia checkpoint 动态。
7. **关键数字 / 结果**：
   - SSM RankMe 更高、IsoScore 更高、PC1 占比低；Transformer 锥形各向异性。Jamba2 中每个注意力层后 PC1 占比上升，随后 Mamba 层回落。
   - AE 秩约束下 KL 退化曲线两架构高度相似（SSM 最后一层更敏感）；秩约束探针准确率相近；去/留 top-k PC 后的退化相近（Transformer 的主方向不承载更多概念信息）。
   - ZCA-CKA：通用语料上差异大，限定到单个关系时相似度高；m-KNN 在对应深度上高。Pythia 5,000 步（≈4% 训练）时局部对齐已饱和；全局几何约 25% 训练才稳定，RankMe 非单调。附录：秩相关 Pearson >0.84（r=64 时 0.857 → 更高秩 0.911）；白化稳健性层均值 0.78 vs 0.52。
8. **证据强度与短板（作者自述）**：全是相关性分析（探针、PC 消融、CKA、m-KNN），没有因果链接到生成；表征随训练与层变化，checkpoint 只有 Pythia。另：没有算法变量；没有独立同构种子；"高对齐"没有"同架构不同种子"天花板对照（Wang 2410.06672 有）；作者声明用 LLM 辅助起草。
9. **可迁移的研究动作**：先全局白化再算局部 CKA，避免各向异性伪影；全局 vs 局部分开报告；hybrid 模型逐层看注意力/SSM 层对几何的交替作用——这是天然的层内对照。
9a. **对候选 2：它做了什么 / 没做什么（撞车评估）**：
   - **已做**：Transformer vs Mamba vs hybrid 的表征几何比较，结论"全局不同、局部收敛"。
   - **没做**：特定算法变量（计数、括号深度、模运算、坐标）的流形形状；沿流形 steering；同架构多种子；SSM 内部状态。
   - 影响：候选 2 中"Transformer 与 SSM 的局部语义几何是否一致"这一问已被回答（一致），候选 2 必须落在**算法状态变量的流形形状与可操控性**上，并预期审稿人引用本文预测"局部会收敛"。
