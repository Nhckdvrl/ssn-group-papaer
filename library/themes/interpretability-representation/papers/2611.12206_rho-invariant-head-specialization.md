# A Geometric Invariant of Attention Predicts Head Specialization from Weights Alone（NeurIPS 2026 NeurReps workshop，extended abstract，分数 —）`[证据级别：全文]`

- 作者：Miguel P. Bento（Feedzai，独立工作）。arXiv:2611.12206v1（2026-11-09），abs 页已核对。全文 5 页，已全部读完。代码 github.com/MPedraBento/rho-invariant。

1. **论文形态**：理论（RoPE 下注意力的基不变量）+ 小规模相关性验证 + 一个应用示意。
2. **背景与压力**：头的功能识别通常靠数据（patching、探针、构造输入），RoPE 与头关系的研究（Barbero 2024）也依赖数据。
3. **改变的前提**：G_QK(Δ)=W_Q^T R(Δ) W_K 在每个频率平面的 SO(2)×R>0 重参数化下不变，可构造只依赖权重的标量 ρ = (1/|D|) Σ_{Δ∈D} ‖P(Δ)‖_F² / ‖G_QK(0)‖_F²，P(Δ)=W_Q^T[R(Δ)−I]W_K，D 为对数间隔 {2^n}。ρ=0 ⇔ 在 D 上 logit 与相对位置无关（Prop. 1）。
4. **idea 来源（DOCUMENTED）**：物理中"可观测量少于参数"的不变量思路；Elhage 2021 的 QK/OV 双线性形式。
5. **与最近邻的距离**：相对数据驱动的 induction score（Olsson 2022）→ 换证据类型（纯权重）。与候选 2 的"表征流形"无直接关系：ρ 是**权重空间的头级几何**，不是**激活空间里变量的流形**。
6. **方法 / 实验 / 数据**：4 个无偏置 RoPE 模型：SmolLM2-135M、TinyLlama-1.1B、SmolLM2-1.7B、Mistral-7B；induction score 用重复随机序列；应用：只对 ρ 前 50% 的头做 YaRN。
7. **关键数字**：ρ 与 induction score 的 Spearman r = −0.74 / −0.71 / −0.55 / −0.59（均 p<10^−40）；前 10 个 induction 头落在 ρ 分布最低 14% / 7% / 17% / 30%。Mistral-7B S=4×：短上下文 PPL 基线 7.63，全头 YaRN 19.37，定向 YaRN 12.92；长上下文 5.44 / 162.96 / 130.34（在原生窗口内评估）。
8. **证据强度与短板（作者自述）**：低 ρ 是 induction 的必要不充分条件（induction 是多头电路）；ρ 度量"能力"不是"使用"；只适用 RoPE、只覆盖 QK；YaRN 应用是初步示意。另：对 softmax 平移 s_ij+c_i 不不变（作者靠 weight decay 论证影响小）；没有跨种子/跨训练运行比较；4 个模型属不同家族但都很小。
9. **可迁移的研究动作**：用权重空间的基不变量给组件打"功能指纹"，绕开"哪个头"的身份对齐问题——这与我们"组件身份跨运行不复现、抽象结构部分复现"的发现直接相关：ρ 的**分布**（而非某个头的 ρ）可以跨独立模型比较。
9a. **对候选 2：它没做什么**：不涉及表征流形、算法变量、SSM（没有 RoPE 的架构 ρ 无定义）或 steering。它对候选 2 的价值只是旁证：跨模型可比较的应是不变量/分布，而非组件身份。与候选 2 无撞车。
