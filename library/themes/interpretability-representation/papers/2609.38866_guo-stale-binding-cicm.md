# When Context Changes: Understanding Update Failures in LLMs（arXiv 预印本 v2 2026-10-29，cs.AI，venue 未标注，分数 —）`[证据级别：全文]`

arXiv 2609.38866（v1 2026-09-30，abs 页已核对）；Junyu Guo, Yuchen Fang, Shangding Gu, Costas Spanos, James Demmel, Javad Lavaei（UC Berkeley）。代码数据：github.com/JamesJunyuGuo/CICM。2026-11-25 读正文 §1–8、附录 A.1（单层理论）、B.2（返回哪个旧值）、B.6/B.8/B.10（组件替换、Pythia、匹配对照）、C.1（合成对照与样本量）、Table 3/4。另见 `themes/in-context-evidence-structure/KEY_PAPERS.md` 已有条目（无独立卡）。

1. 论文形态：失败模式（stale binding）+ benchmark（CICM）+ 机制（探针、注意力、组件替换）+ 单层理论 + 推理时修复。
2. 背景与压力：PI-LLM（2506.08184）只给出准确率下降；不知道错误用的是什么信息、为什么旧值胜出、当前值是否已丢失。
3. 改变的前提：区分“保留（current value 仍可读出）”与“选择（读出时用哪个）”。
4. idea 来源（DOCUMENTED）：PI-LLM；Tulving availability vs accessibility；fan effect / response competition。
5. 与最近邻的距离：Wang & Sun 2025（行为）→ 加机制与修复；Chattaraj & Raj 2603.00270（primacy intrusion）→ 本文在自己的协议下发现**偏向最近的旧值**，作者明说协议不同；Tang 2605.30233 / Oh & Demberg 2606.08644（实体追踪、读出时解析）→ 本文专注同一变量多次赋值之间的竞争；PASTA（注意力重加权）→ 本文按更新结构选位置与头。
6. 方法 / 实验 / 数据：
   - **合成覆写任务**（与我们的探针 A 同形）：`x = 71 ··· y = 4 ··· x = 15 ··· x = 63 ··· What is x?`，k = 被问变量的旧值个数，其他行赋值无关变量控制长度；20/40/80 行（Qwen2.5-7B）与 320 行（大模型）；贪心解码、16 token 上限；每列 n=100–150；k=0 匹配长度对照。并有“平行变量”任务（多个变量交错或成组、值在提示内唯一）用于区分同变量旧值与跨变量复制。
   - **CICM**：1,200 个偏好对话（PrefEval 内容，meal/music/learning，21 个候选值）；180 个账本；24 个决策场景；40 个 2,048 步、16 槽的操作日志（含延迟确认变体）；配对“快照”对照。
   - **机制**：最终层残差上 21 类线性探针（5 折按对话划分、打乱标签对照）；每头 old-value 注意力份额 ρ_old；组件替换（把失败运行的组件换成重命名旧赋值后的成功对照，120 对）；Pythia-160M 中逐头移除与 key 输入替换（随机同层对照）；最终层“探针差向量”steering（等范数随机对照）。
   - **修复**：在选定头的最终位置对 current 位置 +β、old 位置 −β（固定或自适应 β）。
   - 模型：Qwen2.5-1.5B/3B/7B/14B/72B、Llama-3.2-3B、Llama-3.1-8B/70B、Mistral-7B、Gemma-2-2B/9B、Pythia-160M/1.4B、GPT-4o、GPT-5、Gemini、GPT-5.6 Sol、Claude Opus 4.8。**全部 Transformer。**
7. 关键数字：
   - 合成覆写（Qwen2.5-7B）：k=0 全部 100%；k=2 时 91/85/70%（20/40/80 行），k=8 时 51/45/38%。333 个失败中 331 个返回被问变量的旧值，2 个复制其他值，0 个幻觉；平行变量对照的跨变量泄漏可忽略。
   - 70B 级与 GPT-4o 能容忍更多覆写，但 k=64 仍失败，而匹配的 320 行无覆写提示全部答对。k=256 时 GPT-4o 即使简短推理也有 32/36 返回旧值，GPT-5 与 Gemini 36/36 正确。
   - **返回哪个旧值**（Table 4，条件于旧值错误）：Qwen-7B 最近旧值占 54/54（k=2）、92/113（k=4，均匀参考 25%）、72/164（k=8，参考 12.5%）；首次写入在这些格子里从未被返回。CICM 中若旧值在查询前被再次提及，被提及的旧值占旧值回答的 94.5–100%；把另一变量移到两轮前时旧值错误 16.0% 与他变量错误 16.5% 持平（身份 > 近因）。
   - 格式：ICF-Bench 上 Qwen-7B 两种格式准确率相近（69 vs 71%），但自由生成失败中 82.1% 返回旧偏好，多选只有 29.4% → 多选掩盖旧值检索。
   - 探针：旧值错误上当前值的探针概率 84.8%（Qwen）/ 82.2%（Llama），打乱标签 3.2–6.4%；失败比正确低约 7%。
   - 注意力：长度调整后失败比正确的 ρ_old 高 19.4 pp（Qwen，后层最大）；Llama 只有 +1.2 pp 且 CI 含 0。五个模型中冲突更新都使注意力与 QK 匹配偏向旧值（含答对样本）。
   - 组件替换：Qwen 后层状态 78.1% / 早中层 −0.5%；旧赋值 key 49.2% / 当前 key −21.3%。Pythia：定向 key 输入替换恢复 75%（随机 6%）；移除选出的头纠正 38.4% 旧值错误（随机 8.7%）。只在更新处修复 key：问题紧跟更新时纠正 92.8%，中间再跑其余轮次（含旧值再提及）时只纠正 8.7%。
   - 修复（Table 2）：自适应路由绝对提升 44.79–78.75 pp，保留 98.08–100% 原本正确答案。
   - 前沿：2,048 步日志中 GPT-5.6 Sol 9/40、Opus 4.8 18/40，而配对快照 40/40。
   - 单层理论：RoPE 下 current 与 old 的打分差可以不为正；k 个旧值的 softmax 份额之和随 k 增加而稀释 current 的选择概率，信息本身不丢失。
8. 作者承认的局限：受控对话与构造日志不估计真实频率；内部测量只在开源模型、跨模型模式不一；探针只说明可恢复、steering 用了已知答案；路由需要内部访问、标注校准与结构化解析器。
9. 对“架构 × 覆写”方向关键的“没做的事”：
   - **只有 Transformer**；理论完全建立在 softmax 选择上（“保留 ≠ 选择”）。对于固定状态递归模型，这个二分恰好可以反过来问：旧值是否还在状态里（delta 擦除应使旧值不可读出）。
   - 没有“原值”查询（RI），没有“同一旧值重复 k 次”与“不同旧值”的显式对比（只有再提及条件）。
   - 没有距离与次数的正交操纵（k 与长度部分混合）。
10. 证据强度与短板：行为 + 探针 + 因果替换 + 理论 + 修复的完整闭环，样本量与对照写得清楚；但组件级因果只在 Qwen-7B 与 Pythia-160M，Llama 的注意力差不显著。
11. 可迁移的研究动作：错误分类（current / 同变量旧值 / 他变量值 / 其他）作为主读数；“哪一个旧值被返回”的秩分析；多选 vs 自由生成对照；保留与选择分开测。
12. 对我们：探针 A 的 Transformer 半边已被做成：覆写次数越多越错、错误几乎都是旧值、偏向最近旧值、旧值被重复提及时几乎必错。因此“Transformer 取决于位置还是词汇检索”不是开放问题，而“重复的旧值使模型回到 1”在 Transformer 上同样会发生——这削弱了探针 A 区分加性衰减与注意力的能力。
