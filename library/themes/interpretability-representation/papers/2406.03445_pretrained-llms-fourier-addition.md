# Pre-trained Large Language Models Use Fourier Features to Compute Addition（NeurIPS 2024 稿件格式，接收状态未核对，分数 —）`[证据级别：全文]`

- 作者：Tianyi Zhou, Deqing Fu, Vatsal Sharan, Robin Jia（USC）。arXiv:2406.03445v1，abs 页已核对。
- 阅读范围（2026-11-25）：正文 §1–6（微调 GPT-2-XL 的逐层预测、MLP/注意力 logit 的 Fourier 稀疏、低通/高通消融、从零训练对比、提示式 GPT-J/Phi-2），附录 C.4（其它预训练模型嵌入）、E（从零训练细节）检索式阅读。

1. **论文形态**：机制发现 + 对照（预训练 vs 从零训练）。
2. **背景与压力**：前作多为从零训练的小模型或 greater-than 等任务；预训练 LLM 如何做整数加法不清楚。
3. **改变的前提**：预训练 LLM 用 Fourier 特征相加：MLP 用低频特征估计量级（近似），注意力用高频特征做模加（如奇偶，分类）。
4. **idea 来源（DOCUMENTED）**：Logit Lens 显示中层预测"差 10 以内"，提示近似 + 分类两步。
5. **与最近邻的距离**：相对 Nanda 2023（玩具 Fourier）→ 搬到预训练 LLM；被 Kantamneni 2025 推广为 helix + Clock，被 Fu 2604.20817 指出"Fourier 尖峰 ≠ 模可分"。
6. **方法 / 实验 / 数据**：GPT-2-XL 在自然语言模板加法（0–260）上微调；对每层 MLP/注意力输出投影到 token 空间做 DFT；低通/高通滤波消融；同架构从零训练（GPT-2-XL、GPT-2-small，后者 5 种子）、加入预训练 token 嵌入；GPT-J、Phi-2 4-shot 提示分析；多个预训练模型嵌入的 Fourier 谱。
7. **关键数字**：微调 GPT-2-XL 测试准确率 99.74%；从零训练 GPT-2-XL 94.44%，嵌入/中间 logit 无 Fourier 特征；GPT-2-small 从零 53.95%（<60%），加入预训练嵌入后 5 种子均 100%；GPT-J/Phi-2 提示时错误多为 10 的倍数（93% / 73%）；多种预训练模型嵌入都有 T=2、5、10 的大分量。
8. **证据强度与短板**：主要是 GPT-2-XL 一个微调模型；"预训练嵌入是关键归纳偏置"的结论建立在一个架构上。另：Fu 2604.20817（同组后续）显示 Fourier 尖峰在原始 token 频率与 LSTM 中也存在，"有尖峰 ⇒ 用于模计算"的推断不可靠。无非 Transformer。
9. **可迁移的研究动作**：低通/高通滤波作为对组件"用哪个频段"的因果消融；"预训练嵌入移植到从零模型"作为检验表征来源的干预。
9a. **对候选 2：它没做什么**：没有跨架构、跨独立运行（除 5 种子从零 GPT-2-small）、没有流形形状分类、没有 steering。它是"数字 Fourier 表征"谱系的起点，说明数字几何在预训练 Transformer 间相同早有记录。
