# RWKV-7 "Goose" with Expressive Dynamic State Evolution（arXiv v2 2025-03-30，venue 未核对，分数 —）`[证据级别：部分全文（§1–3 架构与动机、§7.3 MQAR、§7.4 passkey、§7.6 群乘法状态追踪、附录 C 特征值、附录 K 消融、附录中 in-context learning rate 设计说明；语言建模与多语言评测节未细读）]`

arXiv 2503.14456（本地 scratchpad lit/p_2503.14456.txt 为 v2 PDF 文本）；Bo Peng, Ruichong Zhang, Daniel Goldstein 等（RWKV Project / EleutherAI 等）。2026-11-25 有针对性阅读。

1. 论文形态：架构 + 预训练模型发布（RWKV7-World3 0.19B–2.9B）+ 表达力理论 + 合成验证。
2. 背景与压力：Transformer 与对角转移 RNN（含 Mamba）都在 TC0 内（Merrill 2024）；原始 delta rule 只用标量学习率替换固定比例。
3. 改变的前提：广义 delta rule S_t = S_{t−1}(diag(w_t) + z_tᵀ b_t) + v_tᵀ k_t，z = −κ̂，b = κ̂ ⊙ a：**向量值衰减 w_t**（in-context weight decay）+ **向量值 in-context learning rate a_t** + **removal key κ̂ 与 replacement key k̃ 解耦**；转移矩阵近似 I − 2κ̂ᵀκ̂ diag(w)，特征值在 [−1,1]，可以“decay information in all subspaces if necessary”。
4. idea 来源（DOCUMENTED）：Schlag 2021 delta rule；DeltaNet / GDN；Grazzi 2025 负特征值；TTT / Titans 的在线学习视角。
5. 与最近邻的距离：GDN（标量衰减 + 标量 β、同一 key 擦写）→ RWKV-7 向量化并分离擦除 key 与写入 key；作者证明可识别所有正则语言（常数层），新增“copy”状态转移（Lemma 3）。
6. 方法 / 实验 / 数据（与覆写相关部分）：
   - 动机文字：附录说明 Transformer 的 KV cache “is appended to upon each new token processed, and can never be changed. RWKV-7, however, can and does edit its state … simple operations like replacement”；衰减下限使单步最多去掉 45.5% 的旧值，“More can be then removed by the delta rule mechanism”。
   - MQAR（§7.3）：2 层 RWKV-7，序列长到 2048，Table 6 以 >99% 打勾报告（取 3 个学习率最大值）——**每个 key 只绑定一次，无更新**。
   - Passkey：World3-1.5B 完美到 19,600 token，2.9B 到 35,000；128k 微调后 1.5B 到 29k、2.9B 到 30k 后退化。
   - 群乘法（Merrill 2024 设定 A5 / A4×Z5 / Z60）：RWKV-7 所需最少层数少于 Transformer、Mamba、S4，略逊经典 RNN（只有图）。
   - 消融（6 层、d=768、minipile 1.6B token、长度 512）：验证 loss Goose 2.541；标量衰减 2.609；标量 ICLR 2.591；**同一 removal/replacement key 2.560**；无 bonus 2.588。
7. 证据强度与短板：表达力证明 + 公开预训练模型是强资产；但没有任何覆写 / 重新赋值 / 历史查询的行为或机制测试；擦除与写入 key 解耦的收益只以 LM loss 消融（单种子、小模型）体现。
8. 可迁移的研究动作：把“擦除哪个方向”与“写入哪个方向”分成两个可学习量，从而可以问模型实际学到的 κ̂ 与 k̃ 是否对齐（同一变量第二次出现时是否擦除第一次写入的方向）。
9. 对我们：
   - 探针 A/B 中“delta-rule 原位擦除”的隐含前提是“第二次提到 A 时的擦除 key 与第一次写入 A 的 key 相同”。RWKV-7 的设计**明确允许二者不同**，而且有向量衰减可以按通道全局遗忘；因此 RWKV-7 不一定表现为“只擦 A”。预测要写成：若 κ̂(A 第二次) 与 k̃(A 第一次) 对齐且 a≈1，则旧值被替换；否则表现接近“加性 + 衰减”。
   - 公开纯递归预训练模型（RWKV7-World3 0.19B/0.4B/1.5B/2.9B；G1 系列见 2609.33093 卡附录 E：G1j-2.9B、13.3B）是测试纯 delta-type 模型行为的主要资产，无需自训。
