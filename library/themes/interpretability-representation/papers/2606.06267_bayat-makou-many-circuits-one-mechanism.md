# Many Circuits, One Mechanism: Input Variation and Evaluation Granularity in Circuit Discovery（arXiv v2 2026-08，发表处未核对）`[证据级别：部分]`

- 作者：Alireza Bayat Makou, Jingcheng Niu, Subhabrata Dutta, Iryna Gurevych（TU Darmstadt UKP）。arXiv:2606.06267v2，abs 页已核对。
- 阅读范围（2026-11-25）：摘要、§1、§2 相关工作、§3 方法概述与局限段；结果节只读摘要级。

1. **论文形态**：失败模式（结构差异≠机制差异）+ 测量。
2. **背景与压力**：电路发现得到的子图结构不同常被当作"机制不同"。
3. **改变的前提**：固定任务，只按词频带改变输入 token；比较结构、边迁移、interchange 干预三层。
4. **方法**：Literal Sequence Copying，4 个频率带 + 1 个按词频抽样的对照，5 个 Pythia（70M–1.4B），共 75 个电路（5 模型×5 条件×3 次抽取）；SVA 小规模复现。
5. **关键结果**：各频带电路结构上不同，但特有边可广泛迁移到别的频带；多数频带共享的核心在 70M 以上模型能恢复 ≥99% 电路性能；interchange 干预显示内部表示可在频带间互换；同一频带重复抽取说明发现算法是在"等价类"里取样，不是恢复唯一机制。
6. **短板**：只测输入频率轴，不是模型轴；不检验位置级或组件内特征；Pythia 单家族。
7. **对我们**：给出方法论警告：判断"不同算法"要用跨条件迁移 + 反事实干预（功能判据），不能用电路/几何形状不同；与 Sun 2412.07386（用头重要性聚类定义"不同算法"）形成对照。
