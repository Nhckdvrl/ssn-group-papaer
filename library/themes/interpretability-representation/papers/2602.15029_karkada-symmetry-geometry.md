# Symmetry in Language Statistics Shapes the Geometry of Model Representations（ICML 2026，接收，分数 未核对）`[证据级别：全文]`

- 作者：Dhruva Karkada, Daniel J. Korchinski, Andres Nava, Matthieu Wyart, Yasaman Bahri（UC Berkeley / EPFL / JHU / Google DeepMind）。arXiv:2602.15029，abs 页已核对；PDF 首页 "Proceedings of the 43rd ICML, PMLR 306, 2026"。
- 阅读范围（2026-11-25）：正文 §1–5（Prop. 1、Cor. 2、Prop. 3、Prop. 4、集体潜变量模型 §4、讨论），附录 A（实验细节：word2vec、EmbeddingGemma、Gemma 2 2B）检索式阅读，证明略读。
- 来源：在 Fu et al. 2604.20817 的参考文献中发现。

1. **论文形态**：理论（由共现统计的平移对称推导表征几何的解析形式）+ 跨模型实证匹配。
2. **背景与压力**：月份成圆、年份成带"涟漪"的 1D 曲线、经纬度可线性解码，跨多种架构一致出现，但没有统一原理。
3. **改变的前提**：若两个词的共现概率只取决于它们在语义连续体上的距离（Assumption 3.1：P_ij = P_i P_j C̃(dist(x_i,x_j))），则词嵌入（学习 M* 的顶部特征模）的 PCA 坐标就是该连续体上的 Fourier 模；周期边界 → 闭环（整数频率），开边界 → 开曲线（非整数频率、"涟漪" = 高次谐波），2D → 弯曲的面。
4. **idea 来源（DOCUMENTED）**：Karkada 2025（词嵌入学 M* 顶部特征模）、Korchinski 2025（类比平行四边形来自 Kronecker 结构）；循环矩阵被 DFT 对角化。
5. **与最近邻的距离**：相对 Engels / Modell / Gurnee（经验发现）→ 给出解析预测；相对 Fu 2604.20817 → 同一"数据统计决定几何"的立场，但这里是第一性推导，Fu 是受控训练归因。
6. **方法 / 实验 / 数据**：理论在 d ≥ rank(M*) 的词嵌入里精确；实证：Wikipedia 训练的 word2vec 类嵌入、EmbeddingGemma（308M 文本嵌入）、Gemma 2 2B 内部表征；概念：月份、历史年份、美国 48 州地理、颜色。扰动：删除所有月份–月份共现。
7. **关键数字 / 结果**：
   - 解析预测的嵌入几何与 Gram 矩阵与三类模型"极好吻合"（图 1、3）；任意两 PC 投影是 Lissajous 曲线，振幅/相位/频率由 Prop. 3 预测并在 word2vec 上验证。
   - Prop. 4：秩 r 线性探针解码坐标的误差 ε² ∼ r^{−1/D}，实证吻合，出现双下降峰。
   - 删除 122 个月份–月份共现后，在 d=10³ ≪ V=2.5×10⁴ 下月份仍成圆且顺序正确；只需少数"季节词"就能重建月份顺序，"one…seventeen"等非季节词不能。解释：许多词受同一潜变量（季节）调制 → 大特征值 → 对少量矩阵元扰动稳健（Weyl / Davis–Kahan）。
8. **证据强度与短板（作者自述）**：理论在词嵌入中严格，对深层模型只是经验匹配；上下文中的消歧（如 "May"）会让月份表征随层变圆，尚无理论；层级属性的几何未解释。另：LLM 只有 Gemma 2 2B 一个；无独立运行、无 SSM、无干预。
9. **可迁移的研究动作**：**为每个变量先写出"仅由数据统计预测的几何"作为零模型**，再看模型偏离多少——偏离才是机制。
9a. **对候选 2：它决定了什么（可预测性核心）**：
   - 它直接预测："由共现平移对称驱动的变量，在任何学到低阶共现统计的模型里都会出现同一（Fourier/圆/开曲线）几何"，作者明言几何"largely governed by task-agnostic and architecture-agnostic principles"。因此候选 2 若比较**token 级**周期/序数变量（日、月、数字、坐标）跨 Transformer 与 SSM 的形状，"都一样"是可预先写出的结果。
   - 它**不能**预测的：上下文中计算出来的状态变量（计数、括号深度、序列中位置）的几何——这些不是词身份、没有词-词共现矩阵可依；以及几何是否被**计算使用**（见 Feucht 2605.01148）。候选 2 的真正未知区在这里。

## 第二位读者的笔记（11-25 两路独立精读，合并为一张卡）

*原标题行：Symmetry in language statistics shapes the geometry of model representations（ICML 2026；arXiv 2602.15029，v3 2026-06-29；分数未见）`[证据级别：全文（§3–4 定理推导与附录 B 证明只略读）]`*

- 作者：Dhruva Karkada, Daniel J. Korchinski, Andres Nava, Matthieu Wyart, Yasaman Bahri（UC Berkeley / EPFL / JHU / Google DeepMind）。abs 页已核对。
- 阅读范围（2026-11-25）：摘要、§1–2、§5 讨论、Limitations、附录 A（实验细节：word embedding、Gemma 2 2B、EmbeddingGemma）；§3–4 只读命题陈述与图。
- 代码：文中未见链接（未核对）。

1. **论文形态**：理论 + 受控验证（从数据统计解析推出表征几何）。
2. **背景与压力**：月份成圆、年份成带波纹的 1D 曲线、经纬度线性可读——跨模型反复出现，但缺统一解释。
3. **改变的前提**：几何来自语言共现统计的平移对称性（两个月份共现频率只依赖间隔），而非架构或任务。
4. **idea 来源（DOCUMENTED）**：Karkada 2025（word embedding 学 M*≈PMI 的顶部特征模）+ Korchinski 2025（Kronecker 结构 → 类比平行四边形）。
5. **与最近邻的距离**：Engels 2025、Gurnee 2026（现象）；Prieto 2026（自编码器近似 PCA 学到圆）；Fu 2604.20817（跨架构经验归因，引本文）；Shai 2024/2026。
6. **方法 / 实验 / 数据**：
   - 理论：word embedding 的第 µ 个 PC = M* 的第 µ 个特征向量；平移对称 ⇒ M* 为循环（circulant）矩阵 ⇒ 特征向量为 Fourier 模；周期边界 → 圆，开边界 → 带"ripples"的开曲线（高次谐波 = 波纹）；预测各分量振幅与频率；预测线性坐标解码误差随 probe 维数的标度（命题 4）；连续潜变量模型解释鲁棒性（集体效应：大量词受同一潜变量影响 → 大特征值、对扰动不敏感）。
   - 验证：Wikipedia 训练的 word embedding、EmbeddingGemma（308M）、Gemma 2 2B 残差（所有层）；删除所有两月份共现句子后几何在中等嵌入维数下仍保留。
7. **证据强度与短板（作者自认）**：理论只在 word embedding 设定成立；LLM 能按上下文调整（如消歧 "May" 后月份越来越圆），理论未覆盖。
8. **可迁移的研究动作**：先从数据统计（共现核）解析预测几何，再看模型是否偏离预测——偏离部分才是架构/计算的贡献。
9. **对我们（候选 2）**：
   - 给出强先验：词表级概念的流形形状由数据统计决定、"architecture-agnostic"（作者原话"largely governed by task-agnostic and architecture-agnostic principles"）。若候选 2 的变量也由类似相似性核决定，"形状由任务结构决定"几乎可被预先猜到。
   - 但字符计数、括号深度是**上下文中计算出的量**，不是有共现统计的 token；本文理论不直接覆盖。Gurnee 的 ringing 论证与本文同构（截断 circulant 相似矩阵 → Fourier 模 → 波纹），说明一旦模型对相邻计数给出相似表示，"helix 状"几乎是必然的投影结果。
