# Differentiable Faithfulness Alignment for Cross-Model Circuit Transfer（COLM 2026，已接收，分数未核对）`[证据级别：全文（读摘要、引言、模型与结果概述）]`

arXiv 2604.24302 v1 2026-04-27，v2 2026-11-23；Shun Shao, Binxu Wang, Shay B. Cohen, Anna Korhonen, Yonatan Belinkov。

1. 论文形态：方法（把小模型的电路重要性分数映射到大模型）。
2. 背景与压力：每换一个模型都要重做电路发现，代价大；电路能否跨模型迁移不清楚。
3. 改变的前提：不比较电路是否“相同”，而问源模型的节点重要性能否经学习的对齐矩阵 W 恢复目标模型的忠实电路（软忠实度目标 + L1 稀疏）。
4. idea 来源（RECONSTRUCTED）：Distributed Alignment Search 风格的可学习映射 + 电路忠实度评估。
5. 与最近邻的距离：Tigges 2024（同家族不同规模电路稳定，只做描述）；Trott 2509.22831；Schiffman 2602.22600。增量：加方法，并给出迁移失败的条件。
6. 方法 / 实验：Llama-3（1B、3B、8B）与 Qwen-2.5，六个任务（事实检索、选择题推理、算术）；两个家族。最强 Llama-3 1B→3B；尺度差距越大越差；Qwen-2.5 上恢复明显更低。
7. 证据强度与短板：只有两个家族、节点级对齐；任务里没有实体绑定/追踪；“Qwen 更差”没有找出模型性质上的原因（摘要只说“迁移变难”）。
8. 可迁移的研究动作：把“结论跨模型是否成立”转成可量化的迁移失败率，并按家族/尺度间隙分层报告。
9. 对我们：是“哪些模型性质预测不迁移”问题的邻居，但是组件重要性层面、无反事实签名、无绑定任务。可借其“家族差异大于尺度差异”的叙事风险提醒。不构成撞车。
