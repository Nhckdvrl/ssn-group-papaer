# Convergent Evolution: How Different Language Models Learn Similar Number Representations（COLM 2026，接收，分数 未核对）`[证据级别：全文]`

- 作者：Deqing Fu, Tianyi Zhou, Mikhail Belkin, Vatsal Sharan, Robin Jia（USC / UCSD）。arXiv:2604.20817v2（2026-08-17），abs 页已核对。模型发布于 hf.co/collections/deqing/convergent-evolution。
- 阅读范围（2026-11-25）：正文 §1–6，附录 A（Theorem 1 证明、Fisher LDA 界）、B（架构细节、LSTM+残差、优化器、数据扰动、多 token 数字中层探针、MLP/RFM 探针、circular probe）检索式阅读。

1. **论文形态**：构念引入（两层级收敛：spectral vs geometric）+ 理论（必要非充分）+ 受控训练归因。
2. **背景与压力**：Zhou 2024、Kantamneni 2025、Levy & Geva 2025 由 Fourier 尖峰推断模型"学会了模结构"；这一推断是否可靠无人检验；Fourier 结构从哪来也未知。
3. **改变的前提**：Fourier 尖峰（spectral convergence）≠ mod-T 线性可分（geometric convergence）。Theorem 1：Φ_T=0 ⇒ 无线性探针能超机会；但对任意大 Φ_T 都可构造线性不可分的嵌入。可分性由 S_B 与 S_W 的广义特征值（Fisher 判别）决定，cond(S_W) 大时信号被类内方差淹没。
4. **idea 来源（DOCUMENTED）**：观察到 LSTM 与"语料中数字 token 频率本身"都有更强的 T=10 尖峰却探针在机会水平。
5. **与最近邻的距离**：相对 Zhou 2024 / Kantamneni 2025 → 指出它们的推断不可靠，加受控训练；相对 Karkada 2602.15029 → 同样归因于数据统计，但给出"数据 × 架构 × 优化器 × 分词"的经验归因，并强调同谱不同几何；相对 Huh 2024 → 不问全局核对齐，问"同一概念的相似表征是否同一功能结构"，答"可以根本不同"。
6. **方法 / 实验 / 数据**：
   - 预训练模型（嵌入层）：GPT-2、GPT-OSS、Llama-3/4、DeepSeek-V3；Mamba、Falcon-Mamba、xLSTM、Kimi-Linear；GloVe、FastText；外加原始 token 频率。
   - 受控训练：~300M 参数，FineWeb-Edu 10B token，Llama-3 分词器（0–999 单 token）；Transformer、Gated DeltaNet、Mamba-2、LSTM（12 层/4 层，±残差）、PPMI、word2vec；优化器 Muon vs AdamW。
   - 读数：嵌入 e(n) 沿 n 的 DFT 功率（中位数归一）；mod-T 线性探针 Cohen's κ（3 种子 × 10 折 = 30 次平均）；另 MLP/RFM 探针、圆形探针。
   - 数据扰动：Swap Numbers、Context Length ℓ、Isolate-k、Unigram Replace。
   - 算术从零训练：300M Transformer，3B token，各两种子 × 两优化器；9 位数加法（多 token）vs 3 位数加法（单 token）；6 位数加法在 base 10/15/16。
7. **关键数字**：
   - 所有系统（含原始频率）都有 T=2,5,10 尖峰（spectral 普适）。
   - 300M：Transformer κ=96（T=2）/85（T=10），Gated DeltaNet 95/78；LSTM 与频率在机会水平（尽管 LSTM 的 Φ_10 更大，其 Fisher 判别小两个数量级）。加残差的 LSTM 能部分获得几何结构。
   - 优化器：Muon 使 Transformer 85.4 vs AdamW 72.1、Gated DeltaNet 77.8 vs 69.7（T=10），但 Mamba-2 反向（AdamW 80.1 vs Muon 76.7）。PPMI 27.1、word2vec 29.3。
   - 数据：Swap Numbers 使 κ 85.4→28.8；ℓ=2/4/8/64 → 40.6/47.4/51.7/72.0；Isolate-1/2/8 → 45.0/53.0/77.2；Unigram Replace 落到机会，而谱几乎不变。模数：mod 2/5/10 = 96.1/63.5/85.4，mod 4 = 34.9，3/7/9 近机会。
   - 规模：124M 到 671B 的预训练模型 mod 2/5/10 探针近完美（含多 token 数字中层）。
   - 算术：9 位数加法两优化器都收敛到同一谱、κ 近完美；3 位数单 token 加法表征**随优化器与种子变化**，Muon 的尖峰落在非模周期、κ 近机会，AdamW 一种子 grok、另一种子不泛化。base-15 得 mod 3/5/15；base-16 无互素分解、尖峰位置任意、探针机会水平。
   - 谱与几何在预训练中平滑共同出现，无相变。
8. **证据强度与短板**：作者把日/月等其它周期概念的谱-几何分离留作下一步。另：主要读数在**输入嵌入层**（中层只在多 token 附录）；"几何"被操作化为**线性可分**（κ），不是流形形状（圆/螺旋）；无 steering/因果干预；受控训练每格种子数少（算术 2 种子）。
9. **可迁移的研究动作**：同一表征现象拆成"必要的谱签名"与"功能上的几何可分"两层；用数据扰动做"结构归因"；用"原始语料统计本身"作为零模型（没有模型时会出现什么）。
9a. **对候选 2：它做了什么 / 没做什么（撞车核心）**：
   - **已做**：同一变量（整数）跨 Transformer / Gated DeltaNet / Mamba-2 / LSTM / 经典嵌入 / 9 个预训练家族比较周期结构；结论：谱普适、几何可分性取决于架构/优化器/数据；Transformer 与线性 RNN（SSM 类）收敛、LSTM 不收敛。
   - **没做**：中层动态变量（计数、括号深度——这些不是 token 身份而是上下文状态）；流形形状分类（线 vs 螺旋 vs 云）；沿流形 vs 线性 steering；同架构多种子的系统统计（只在单 token 算术里提到种子依赖）。
   - 对预测性的影响：它给出了"Transformer 与 Mamba-2 在数字上会收敛"的先例与"由数据统计决定"的解释——候选 2 在**token 级数字/日期**上再做一遍 Transformer vs SSM 的结果可被提前预测。

## 第二位读者的笔记（11-25 两路独立精读，合并为一张卡）

*原标题行：Convergent Evolution: How Different Language Models Learn Similar Number Representations（COLM 2026；arXiv 2604.20817，v2 2026-08-17；分数未见）`[证据级别：全文（附录 A 证明略读）]`*

- 作者：Deqing Fu, Tianyi Zhou, Mikhail Belkin, Vatsal Sharan, Robin Jia（USC / UCSD）。abs 页已核对。
- 阅读范围（2026-11-25）：正文 §1–6 全文；附录 B.1（架构表）、B.2（LSTM）、B.8–B.9（大模型、多 token 数字）读过；附录 A 证明与 B.3–B.7、B.10 只看结论。
- 资产：受控训练的模型已公开 hf.co/collections/deqing/convergent-evolution（300M Transformer / Gated DeltaNet / Mamba-2 / LSTM，同数据同 tokenizer）。

1. **论文形态**：现象 + 理论 + 受控归因（"structure attribution"：逐因素扰动数据/架构/优化器）。
2. **背景与压力**：Zhou 2024 等发现数字 token embedding 在 Fourier 域有 T=2,5,10 尖峰，常被解读为"学会了模结构"。没人问尖峰是否意味着可用的几何结构、在不同架构里是否同源。
3. **改变的前提**：区分两层收敛——spectral convergence（Fourier 尖峰）与 geometric convergence（n mod T 线性可分）；前者几乎普适，后者有选择性。
4. **idea 来源（DOCUMENTED）**：LSTM 比 Transformer 有更大 T=10 Fourier 功率却 probe 在机会水平——这一反例引出定理 1。
5. **与最近邻的距离**：Zhou 2024、Kantamneni & Tegmark 2025、Levy & Geva 2025（Fourier/helix/数字圆，只在 Transformer 内）；Karkada 2026（理论上从共现对称性推出几何）；Huh 2024 柏拉图表征（全局核对齐）。增量 = 跨架构受控训练 + 必要非充分定理。
6. **方法 / 实验 / 数据**：
   - 对象：**数字 0–999 的输入 token embedding**（Llama-3 tokenizer 单 token）；B.9 才用中层隐状态读多 token 数字的 n mod T。
   - 预训练模型：GPT-2-1.5B、GPT-OSS-120B、Llama-3.1-8B、Llama-4-Scout-109B、DeepSeek-V3-671B、Mamba-2.8B、Falcon-Mamba-7B、xLSTM-7B、Kimi-Linear-48B；GloVe、FastText。
   - 受控训练：~300M 的 Transformer（RoPE、GQA）、Gated DeltaNet、Mamba-2、LSTM（12 层，另 4 层），FineWeb-Edu ~9.4B token，context 512，Muon 与 AdamW 两种优化器；数据扰动（Isolate-k、Context Length ℓ、Swap Numbers、Unigram Replace）；从零训练加法（9 位多 token、3 位单 token、base 10/15/16）。
   - 指标：Fourier 功率谱（中位数归一）；mod-T 线性 probe 的 Cohen's κ（3 种子 × 10 折 = 30 次平均）；另有 MLP/RFM probe。
   - 定理 1：Φ_T = 0 ⇒ 不可线性分类（必要）；存在 Φ_T 任意大而线性分类不超过机会的嵌入（非充分）；Fisher 判别 λ_max(S_W⁻¹ S_B) 被 Φ_T/(N·λ_min(S_W)) 和 cond(S_W) 夹住。
6b. **关键数字**：
   - 所有系统都有 T=2,5,10 尖峰，包括语料中数字 token 的原始频率分布本身（无模型）。
   - 同数据 300M：mod-10 κ——Transformer 85.4（Muon）/72.1（AdamW）；Gated DeltaNet 77.8/69.7；Mamba-2 76.7/80.1；LSTM ≈2.0（Fourier 功率反而更大）；PPMI 27.1；word2vec 29.3。LSTM 加残差连接后获得部分几何结构；4 层 LSTM 同样失败（作者判为架构而非容量）。
   - 数据：Swap Numbers 使 κ10 85.4 → 28.8；Unigram Replace → 机会；Context Length 2/4/8/64 → 40.6/47.4/51.7/72.0；Isolate k=1/2/8 → 45.0/53.0/77.2。尖峰在所有扰动下保留。
   - 加法从零训练：9 位（多 token）两优化器都收敛到相同谱 + mod 2/5/10 近完美；3 位（单 token）随优化器和**种子**而变，AdamW 一个种子 grok、另一个不泛化；base-16 无结构，base-15 得 mod 3/5/15。
   - 124M–671B 预训练模型 mod 2/5/10 近完美；mod 7/9 只在大/新模型可解（DeepSeek-V3 84.4/92.0）。
7. **证据强度与短板**：受控实验每配置一次预训练（probe 有 3 种子，预训练本身的种子重复只在加法实验中有 2 个）；只研究模周期结构，不研究流形形状/曲率；无因果干预；无计数/累加类序列变量。
8. **可迁移的研究动作**：(1) "表面结构 vs 功能结构"两层判据 + 证明前者不蕴含后者；(2) 同数据、同 tokenizer、同规模下换架构的受控训练；(3) 数据扰动做结构归因。
9. **对我们（候选 2）**：
   - **最接近的跨架构证据**：Transformer、Gated DeltaNet、Mamba-2 在同数据下得到相近的数字几何，LSTM 不同——"注意力 vs 线性 RNN"在这个变量上**没有**质性差别，差别出现在"有无残差连接"。这是候选 2 的先验：在 token-level 变量上，架构族差异小于残差结构差异。
   - 但它研究的是**静态词表变量**（token embedding），不是**在序列中累加的计算变量**（字符计数、括号深度）——后者正是 attention 与 recurrence 机制差异最可能显现的地方。候选 2 在这一点上仍是空白。
   - 它们公开的 300M 同数据四架构模型是现成的受控资产，可直接用于计数变量的几何测量（需确认 context 512 是否足够、模型能否完成换行任务）。
   - 3 位加法的种子依赖说明：几何可以由训练细节决定——这正是导师 G5（程度/训练细节决定）的风险。
