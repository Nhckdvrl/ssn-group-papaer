# Represented but misread: Post-training changes how language models read out what they represent（arXiv 预印本 2026-11，v2 2026-11-20，未见评审，分数 —）`[证据级别：全文]`

- 作者：Jochen Laubrock（University of Potsdam，单作者）。arXiv:2611.26584v2，abs 页已核对。
- 阅读范围（2026-11-25）：正文 §1–4、Limitations、附录 A–H（术语表、lens model、deceptive reviews、steering 表 D1、few-shot 表 E1、base-rate 表 F1/F2、Holm 校正 G、patching 表 H1）全部读过。
- 代码：github.com/laubrock-lab/represented-but-misread；作者自述 Claude Code 协助实现与起草。

1. **论文形态**：构念引入 + 测量（psychology 的 signal detection theory + Brunswik lens model 搬到 LLM，"两段透镜"：encoding / readout）+ 跨 checkpoint 因果定位 + 一个小训练研究。
2. **背景与压力**：probe 能读出的信息比模型回答多（Burns、Marks & Tegmark、Orgad）；superficial alignment hypothesis 说 post-training 主要改格式。但没有人在"已知 ground truth 的判断"上用跨 checkpoint 因果干预问：post-training 改的是表征还是读出、发生在哪一层哪个位置。Villuri et al. 2026 把 probe–answer gap 归为阈值（criterion），解释不了低于机会的 d′。
3. **改变的前提**：把"回答错"拆成 sensitivity（d′，与阈值无关）和 criterion（c）；d′<0 不可能由偏置产生，只能是证据被倒序读出。再用 stitching + position-wise patching 定位 base→SFT 差异。
4. **idea 来源（DOCUMENTED）**：作者的人类 AI 文本识别实验（学生写的德语聊天消息）+ lens model 传统；神经科学 "encoded vs read out"（Panzeri 2017）。
5. **与最近邻的距离**：
   - Minder et al. 2026（crosscoder，chat-tuning 变化集中在 template token）、Loos & Eberle 2026（KV-cache 交换，变化在 system/template 位置）：本文无 chat template，结论是"任务被提出的位置"（问题后/answer cue）承载差异 → 换设定 + 换证据类型（patching 而非 dictionary）。
   - Prakash 2024 / Kissane 2024（fine-tuning 增强既有机制、表征迁移）：本文加上"方向可正可负"（作者身份变差、否定句被修好）。
   - Gupta et al. 2610.22937（同期，post-training 调用预训练 cue-routing 电路）：同类结论，不同任务。
   - Ackerman & Panickssery 2025（post-training 创造自我文本识别）：方向相反，作者解释为不同任务。
6. **方法 / 实验 / 数据**：
   - 模型（Table 1，HF id）：Gemma-3-4B/12B（pt→it）、Qwen3-8B-Base→Qwen3-8B、OLMo-2-1124-7B（base→SFT→DPO→Instruct[RLVR]）、Apertus-v1.5-8B（base→SFT→RL→DPO→final）、Olmo-3-1025-7B → Think-SFT/DPO/Think 与 Instruct-SFT/DPO/Instruct；表中列了 Olmo-3-7B-RL-Zero-Mix，但正文未见其结果。
   - 任务：德语 AI/人写作判断（短聊天 300 条/61 组；地方报纸 103 段/14 篇；教科书摘要 238 条/119 对；语料不可公开）；公开复现任务：Marks & Tegmark 真值（地理、否定地理、counterfact，各 748 对）；Ott 酒店评论真伪（1,600 条，附录 C）。
   - 读数：单 token 回答，dv = log P(KI) − log P(Mensch)，两种选项顺序平均；d′ = √2·z(AUC)；c 在 dv=0；grouped bootstrap；Holm 校正（族在看完后定义，作者承认 post hoc）。
   - probe：标准化+PCA+L2 logistic，grouped 10-fold，固定 2/3 深度；baseline：word/char n-gram、14 个表面统计、输入 embedding 平均、EditLens。probe transfer：base↔final 各层交叉，deficit = d′ 损失。
   - 干预：answer 位置 steering（class-mean 方向 ±2 SD，100 个对照方向）；无 adapter model stitching（下 ℓ 层来自一个 checkpoint）；按位置 activation patching（指令/文本/问题后/末位置/全部；12 层 sweep）。
   - 训练研究：OLMo-2-7B base，LoRA r=16、lr 1e-4、1 epoch、3 seeds；20k Tülu-3 背景对话 + 1,994 条作者身份判断（C1 正确标签 / C2 正式度刻板印象 / C3 随机 / C0 无 / C4 无关话题判断）。
6b. **关键数字**：
   - probe 与 n-gram 都能分（d′ 中位：聊天 1.35、报纸 2.66、教科书 3.70；word n-gram 聊天 1.73），模型回答接近或低于机会（Qwen3-8B final 报纸 −1.01/−1.30；Gemma-3-12B 聊天 −0.81/−1.09）。
   - 同 raw prompt 下 post-training 降 d′：18 对中 14 降；家族级 Δd′ = −0.34 [−0.56, −0.11]（t(5)=−3.82, p=.012）；三种 prompt 平均 −0.29；问句前置时两家族方向翻转；只有 8/18 格在三种 prompt 下都降。I²=83%。
   - 阶段：OLMo-2 教科书 −0.12 → SFT −0.50 → DPO −0.46 → RLVR −0.44；Apertus +0.43 → SFT −0.04 → 0.00/−0.03/−0.04。变化几乎都在 SFT；DPO/RL 基本不再改（OLMo-3 Instruct 聊天在 DPO 才降，是例外）。
   - base rate：base 模型 log-odds 平移 0.18–1.40 nats（理想观察者 ln16=2.77 的 6–51%），post-trained 3.67–10.93 nats（1.3–3.9×），OLMo-3 Think 例外；但 post-trained 的 dv 尺度本身大（类内 SD 0.61–2.89 vs 0.21–0.53），按 SD 归一后结论只在多数模型成立。
   - stitching：Apertus 前 8 层 base + 上层 SFT → d′ +0.59（≥ base 0.43）；前 8 层 SFT + 上层 base → −0.50；OLMo-2 前 6 层 SFT 足以产生全部下降。hybrid 常落在双亲范围外（6/18、4/18），control 任务不出界，但 control 不是"接近机会"的匹配对照（作者承认）。
   - patching（layer 16）：交换文本 token 状态无效（Apertus SFT 收到 base 文本状态仍 −0.11）；交换问题后位置状态传递全部差异。12 层 sweep：OLMo-2 文本状态任何层都不传；Apertus 层 2–12 文本状态传 22–64%；层 14 起只有问题后位置承载。
   - 否定句：probe 在所有模型 AUC=1（d′ 4.54 上限），OLMo-2 base 回答 d′ 0.80、Apertus base −0.88，SFT 后 3.36 / 4.54；Qwen3、OLMo-3 base 已完美（无可修）。修复由中层（9–16）权重承载；OLMo-2 在层 12 SFT 的"陈述本身"状态能传 82% 修复（陈述放问句前也成立 → SFT 改了否定陈述的编码本身）；Apertus 只 ≤23%，在 answer cue 位置。
   - 训练研究：C1 在 held-out 新闻 d′ 4.28，报纸 2.18、教科书 1.39，但聊天 −0.58（新闻 cue 在聊天上倒向）；C1 回答与 base 模型新闻 probe 的逐条相关 ρ=.68（C3 .04），控制 n-gram 后 partial ρ=.63。文本位置 probe transfer deficit ≤0.02；末位置 deficit C1 最大（报纸 2.09）。背景条件 C0 **没有复现**官方 SFT 的下降。
7. **证据强度与短板**——作者承认的局限：4–12B；d′ 来自 graded log-odds，二值回答多数不变（36 个条件中 23 个 >95% 同一答案）；作者身份信息主要是词汇/风格 cue，不是"深层表征"；stitching/patching 只在两个模型、两个语料；stitching 与 patching 是同一族干预，steering 不是独立证据；训练研究单模型、LoRA、刻板印象标签与长度/话题/生成器混杂；家族内配方差异（蒸馏、推理比重）无法分离；检验族 post hoc。
   我的评价：
   - 强：d′/c 分离讲清"阈值解释不了倒序"；跨 checkpoint 同 prompt 的 clean contrast；位置×层的 patching sweep；item-level 预测（news probe → C1 回答）。
   - 短：主要任务是作者身份这类"无训练信号"的判断，post-training 对它没有正确监督，"变差"可能只是任意漂移；否定句的"修复"只在 base 本来读错的 2–4 个模型上；没有任何生成式推理（CoT/数学/代码）任务；RL 阶段几乎无变化，所以文中所有结论实际是 **SFT 的结论**；Gemma base 回答概率只有 18–32%，"base 读错"部分是格式问题。
8. **可迁移的研究动作**：用 SDT 把 sensitivity 与 criterion 分开（d′<0 作为"倒序读出"的硬判据）；"文本位置 vs 问题后位置"的 position×layer patching；同一 base 多条 post-training 线（OLMo-3 Think/Instruct/RL-Zero）当作自然对照；训练研究里加一个"学会回答格式但标签随机"的 C3 作为 baseline。
9a. **对候选 3：它没做什么**：
   - 没有逐题（item-level）区分"base 已表征、读错"与"base 未表征"两类题，再看 post-training 修好的是哪类——它是整体 d′ 层面的。
   - 没有 RLVR 带来增益的任务；RL-Zero checkpoint 列出但无结果；没有 GRPO 与 SFT 的对比。
   - 没有多步生成；所有读数是下一个 token。
   - 没有"新电路"判据：probe 都在上限，"build new circuits" 这一侧根本没被检验；stitching 结果显示变化在早层，反驳"只改最后读出"，但这不是"新电路"的证据。
9. **对我们**：这是候选 3 最近的一篇（"represented but misread"几乎就是候选 3 的标题）。它把"post-training 主要改 readout，表征在文本位置不动"在 SFT 上做完了，且已经用 OLMo-2/OLMo-3/Apertus 的阶段 checkpoint。剩下的空白只在 RLVR + 生成式推理 + 逐题分类上，而那恰好是 Venhoff 2510.07364、Bangera 2611.02574、Shi 2604.25011 已经从不同角度切过的地方。
