# Erased, Rerouted, or Rescaled? Post-Training and the Causal Quotient of a Language Model's Belief State（arXiv 预印本 2026-10-04，cs.LG，ACL 格式，未见评审，分数 —）`[证据级别：全文]`

- 作者：Weihan Li, Tianshi Zheng, Junhao Wu, Xinlei Chen（东京大学 / HKUST / RWTH / 哈工大深圳）。arXiv:2610.05292v1，abs 页已核对。
- 阅读范围（2026-11-25）：正文 §1–7、Limitations；附录 A（命题证明）、B–E（设定、估计量、其他世界、开放模型）只读了主文引用的结论与表 3 的主要行。

1. **论文形态**：理论 + 受控实验（HMM 世界中预训练小 transformer/GRU，信念状态精确已知）+ 开放模型复核。
2. **背景与压力**：post-training 后谱压缩 / 有效秩下降常被称为"表征压缩"，但这混淆了三种命运：信息被删除（erased）、仍在表征中但决策不再读（rerouted）、仍被读但方差占比变小（rescaled）。已有研究不知道哪些区分"应该"保留，所以无法判定。
3. **改变的前提**：在信念状态精确已知的 HMM 世界里，奖励只读任务变量 → 解析地得到 reward-null kernel；对 kernel 分别测 R（线性可恢复性）、U（决策对 kernel 的因果敏感性，用"孪生历史"互换测，不用 probe）、A（kernel 占激活方差份额）。命题 1：谱统计在可逆重参数化下不是信息或使用的不变量。命题 2：KL 锚定 RL 的最优策略在等奖励动作间保留参考策略的 log-odds。
4. **idea 来源（DOCUMENTED）**：computational mechanics 的信念状态（Shai 2024、Balcells 2026）+ KL-RL 最优解 π* ∝ π_ref·exp(q/β)。
5. **与最近邻的距离**：Prakash 2024 / Jain 2024 / Lee 2024（fine-tuning 包装既有电路）与谱变化研究 → 本文提供"什么应保留"的地面真值并把三种命运分开测量。
6. **方法 / 实验 / 数据**：
   - 小模型：4 层 transformer 与 2 层 GRU，在 HMM 序列上预训练到 Bayes 最优损失；post-training 全参数 5,000 步（部分 50,000 步、weight decay 1），3 seeds。
   - 目标函数：SFT（示范者标签）、DPO、GRPO、REINFORCE、精确梯度 KL-RL，β 网格含 0；动作设计 tied / one per class / fresh tokens。
   - 开放模型：Qwen3-1.7B、Qwen3-4B、Qwen3.5-4B 的 base 与 post-trained 对，按 Balcells 2026 的上下文 HMM 协议探测信念几何；以及 Qwen3-1.7B/4B-Base 上 LoRA GRPO，只奖励字母类别。
7. **证据强度与短板**：
   - 关键数字：所有 β<1 的目标都让 kernel 方差份额下降（最多三个数量级），但无 weight decay 时 next-token-visible 分量的 R 在每个 transformer 运行中 >0.9；172 个 kernel 份额降到 1/10 以下的运行中 153 个 R≥0.9。KL-RL / GRPO / DPO 在 β≥0.04 时组内 log-odds 斜率 γ 0.93–1.02；SFT：R_vis 0.98 而 U 0.15（rerouted）；同奖励下 KL-RL β=1 的 (R_inv,U,A)=(1.00,1.00,0.69) vs SFT (0.75,0.15,0.13)。GRPO 无锚时的命运切换阈值 β ∈ (0.003, 0.02]。只有 weight decay 1 × 50k 步才把 invisible 分量降到 0.001–0.012（erasure）。开放模型：信念状态 peak R² 变化 ≤0.05，后半网络有效秩降 12–19%；Qwen3 上 GRPO 无锚时组内 log-odds 放大 10–20 倍，有锚时回到参考。
   - 作者承认：精确地面真值只在小 HMM 世界、一步决策；开放模型只一个家族、三对、上下文合成流；线性 probe 会把非线性保留算作丢失；小 transformer 与 LM 在无锚时偏离方向相反，原因未知。
   - 我的评价：这是目前对"readout 改变 vs 表征改变"最干净的概念框架与可识别性论证；它同时直接证明了：决策是否继续读某信息由 KL 锚 β（训练超参）决定，且存在阈值。
8. **可迁移的研究动作**：R / U / A 三坐标（可恢复、被使用、占方差）分别测量，"使用"用孪生输入互换而非 probe；命题 1 作为反驳"谱压缩 = 信息丢失"的通用论据；先用理论写出"哪些区分受保护"再训练。
9. **对我们**：
   - 对候选 3：它给出了"readout 被重路由（rerouted）而表征保留"的精确定义与实验判据，且已在 Qwen3 base/post-trained 对上复核"可解码不变"。
   - 关键负面信息：在它的设定里，post-training 后决策是否继续读 base 已有信息由 β 决定，阈值落在当前 RLVR 配方（多为 β=0）范围内——候选 3 的"重新对齐 readout vs 新电路"在公开模型上会被各家 KL/步数配方左右，正是导师说的程度问题。
   - 它没做：真实推理/代码任务；Base→SFT→DPO→RLVR 阶段链；"base 已表征但读错"的逐题分类（它研究的是奖励不关心的信息，而不是导致错误的信息）。
