# Manifold Steering Reveals the Shared Geometry of Neural Network Representation and Behavior（arXiv 2605.05115v1 2026-05-06；未见会议/分数）`[证据级别：全文（附录 C 部分略读）]`

- 作者：Daniel Wurgaft*, Can Rager*, Matthew Kowal*, Vasudev Shyam, Sheridan Feucht, Usha Bhalla, Tal Haklay, Eric Bigelow, Raphael Sarfati, Thomas McGrath, Owen Lewis, Jack Merullo, Noah Goodman†, Thomas Fel†, Atticus Geiger†, Ekdeep Singh Lubana†（Stanford / UCL / Northeastern / Harvard / Technion / Goodfire）。abs 页已核对。
- 阅读范围（2026-11-25）：正文 §1–8 + 附录 A（拟合、Hellinger、steering 细节、能量指标、pullback）全文；附录 C（70B、cylinder、mountain car）只读要点。
- 代码：github.com/goodfire-ai/causalab/tree/manifold_steering。

1. **论文形态**：构念 + 干预比较 + 理论框架（steering = 选择激活空间的度量）。
2. **背景与压力**：线性 steering 常导致流畅度下降、多样性塌缩、离靶效应；Sarfati 2026 只定性展示线性 steering 离开流形。
3. **改变的前提**：激活流形 M_h 与行为流形 M_y（输出分布）近似等距；steering 问题从"找方向"变为"找几何"。
4. **idea 来源（DOCUMENTED）**：认知科学概念空间（Shepard、Gärdenfors）+ 同组前作 Sarfati 2026、Park 2025b（ICLR 图结构）。
5. **与最近邻的距离**：Sarfati 2026（定性 → 定量 + 多任务 + 反向 pullback）；Engels 2025、Karkada 2026（circle 的存在与来源）；Park 2026（信息几何 steering）；Modell 2605.18537（manifold probe + 沿流形 steering 年份）。
6. **方法 / 实验 / 数据**：
   - 模型：**Llama 3.1 8B，layer 28**（所有 LM 任务）；附录 C.2 一个实验用 Llama 3.1 70B layer 70；另有视频世界模型（mountain car）。无其他 LM 家族。
   - 任务：weekdays、months（循环）；letters、ages（序列）——"What is four days after Monday?"、"Alice is 7, Bob is 5 years older"；ICLR 5×5 grid、9×9 cylinder（随机游走 2048 token）。
   - 拟合：激活 PCA 到 64 维 → 按答案求概念中心 → 三次样条（2D 用 thin-plate spline）；行为流形：中心输出分布（概念 token + "other"）→ √p（Hellinger 空间）→ 样条。
   - 定义：线性 steering π_lin(t) = (1−t)h0 + t h1（中心间直线，即 diff-in-means）；流形 steering π_m(t) = s((1−t)u0 + t u1)，u = s⁻¹(h)（在流形内在坐标插值）。K = 50 个点，16 个基 prompt，≤50 对。
   - 能量指标：E_BC = ∫ d_BC(γ(t), M_y) dt，d_BC = Bhattacharyya 距离到 M_y 最近点。
   - Pullback：在 64 维 PCA 前 32 维内 L-BFGS 优化激活路径使输出沿 M_y，比较其与流形路径的 intrinsic R²。
   - 度量框架：G_I = I（线性）；G_E = (α e^{−E(h)} + β)⁻¹ I（密度几何 → 流形 steering）；G_F = J_F^T g_y J_F + εI（pullback）。
   - **实现不对称（附录 A.6）**：流形 steering 只替换 top-64 PCA 分量、保留 prompt 自身的子空间外残差；线性 steering 用原始中心间直线**替换整个残差向量**。两者差异部分可能来自"是否丢弃 prompt 特异信息"，而不只是路径形状。
6b. **关键数字**：
   - 等距：流形测地 vs 行为测地 r = 0.99（weekdays）/0.89（months）/0.999（letters）/0.999（ages）；线性距离 vs 行为测地 r = 0.89/0.53/0.71/0.36；ICLR grid/cylinder 测地 r = 0.99，线性 0.90/0.81。
   - 能量 E_BC（流形 vs 线性）：weekdays 0.34±0.03 vs 0.93±0.11；months 0.36±0.01 vs 1.09±0.06；letters 2.42±0.07 vs 6.95±0.27；ages 5.21±0.09 vs 13.49±0.29；平均 2.8×，全部 p < 0.001。线性路径在中点出现"teleportation"（概率跳到非相邻概念、"other" 超过任一概念）。
   - Pullback R²（pullback vs 线性）：0.77 vs 0.42、0.75 vs 0.32、0.47 vs 0.24（ages）、0.78 vs 0.23（letters）。
   - ICLR：沿一个内在坐标 steering 对另一维影响很小（factored control）。
7. **证据强度与短板（作者自认）**：简单领域、输出就是概念本身；只看 next-token；拟合协议特定。我的补充：单一模型家族单层；没有"流形平坦时线性 = 流形"的阳性对照；**序列概念（ages、letters，概念上是"线"）同样弯曲、线性 steering 同样差 2.6–2.9×**。
8. **可迁移的研究动作**：用输出分布空间的流形距离（Bhattacharyya/Hellinger）定义"自然性"，把 steering 偏离变成可比较的标量；pullback 反向验证。
9. **对我们（候选 2）**：
   - 候选 2 提出的"线性 vs 沿流形 steering"判别测试已被本文完整实现并量化（含序列型概念）。方法上无增量，只能作为工具。
   - 本文结果直接说明：在 Transformer 中连"序数/线性"概念（年龄、字母）也弯曲，线性 steering 偏离；所以这个测试的输出是一个**连续比值**（四任务 2.6–3.0×），不是"直线 vs helix"的二值判别。若某架构把计数放在近直线上，预期结果只是比值更接近 1——仍是程度。
   - 若要用于跨架构比较，必须先修掉实现不对称（两种 steering 都只改同一子空间），并加平坦阳性对照。

## 第二位读者的笔记（11-25 两路独立精读，合并为一张卡）

*原标题行：Manifold Steering Reveals the Shared Geometry of Neural Network Representation and Behavior（arXiv 预印本 2026-05，v1，未见评审）`[证据级别：全文]`*

- 作者：Daniel Wurgaft*, Can Rager*, Matthew Kowal, Vasudev Shyam, Sheridan Feucht, Usha Bhalla 及 Thomas McGrath、Tal Haklay、Owen Lewis 等（单位含 Stanford、UCL、Northeastern、Harvard、Technion，代码在 goodfire-ai 组织下；完整作者顺序与逐人单位未核对）。arXiv:2605.05115v1，abs 页已核对。代码 github.com/goodfire-ai/causalab（manifold_steering 分支）。
- 阅读范围（2026-11-25）：正文 §1–6（几何与行为、isometry、manifold/linear/pullback steering、Riemann 度量统一、ICL 图、mountain car 世界模型、讨论、局限）；附录 A（样条拟合、Hellinger、测地距离、steering 与 pullback 优化细节）检索式阅读。

1. **论文形态**：构念引入（激活流形 M_h ↔ 行为流形 M_y）+ 因果干预比较 + 几何框架。
2. **背景与压力**：线性 steering（diff-in-means）常导致流畅度下降、离目标行为；几何结构已被大量记录（Engels、Modell、Karkada、Gurnee 2026），但其因果作用基本未知。
3. **改变的前提**：steering 的核心问题从"找对方向"变为"找对几何"：线性 = 平直度量；manifold steering = 由自然激活密度导出的度量；pullback = 由行为空间度量拉回。
4. **idea 来源（DOCUMENTED）**：认知科学的概念空间（Shepard、Gärdenfors）+ 线性 steering 的失败文献。
5. **与最近邻的距离**：相对 Engels 2025（圆上换点）→ 系统化为路径插值并定义"自然性"能量；相对 Gupta et al. 2610.37796（后续）→ 被其用 Jacobian 挑战"连续性"；相对 Feucht 2605.01148（同组）→ 本文说几何因果约束输出，Feucht 说计算不走任务圆——两者在读出层（层 28）与计算层（层 18）上并不矛盾，但值得注意。
6. **方法 / 实验 / 数据**：
   - 模型：Llama 3.1 8B（层 28，bfloat16），**仅此一个 LLM**；另训练一个 GRU 视觉世界模型（mountain car）。
   - 任务：星期、月份（循环），字母、年龄（序列），"What is k days after z?" 模板；ICL 随机游走 5×5 网格与圆柱图（Park 2025b）。
   - M_h：64 维 PCA → 按答案取质心 → 三次样条；M_y：输出分布（概念 token + other）映射到 Hellinger 空间后拟合样条。
   - steering：起止质心间 K=50 点，线性插值 vs 流形内坐标插值；16 个随机提示平均。"自然性" E_BC = 轨迹到 M_y 的 Bhattacharyya 距离累积。pullback：L-BFGS 优化激活路径使输出沿 M_y，算其与流形路径的 intrinsic R²。
7. **关键数字**：
   - 测地距离相关（M_h vs M_y）：星期 r=0.99、月份 0.89、字母 0.999、年龄 0.999；线性距离 vs M_y 测地：0.89 / 0.53 / 0.71 / 0.36。
   - E_BC（流形 vs 线性）：星期 0.34±0.03 vs 0.93±0.11；月份 0.36±0.01 vs 1.09±0.06；字母 2.42±0.07 vs 6.95±0.27；年龄 5.21±0.09 vs 13.49±0.29；平均改善 2.8×。线性 steering 出现"瞬移"（概率在非相邻概念间跳）。
   - pullback R²（vs 线性）：星期 0.77±0.03 vs 0.42±0.07；月份 0.75±0.04 vs 0.32±0.05；年龄 0.47±0.05 vs 0.24±0.01；字母 0.78±0.04 vs 0.23±0.03；均 p<0.001。
   - ICL 网格/圆柱：流形 steering 可沿单一坐标独立控制，线性仍瞬移。
8. **证据强度与短板（作者自述）**：只在概念域定义清楚、输出即概念本身的简单任务上；只看下一 token 分布；未研究几何起源；更抽象概念（拒答、谄媚）待验证。另：单一 LLM、单层；质心样条只用 7/12 个点，中间区域是插值——正是 2610.37796 证明为非连续（"辐条"）的地方；能量函数以 M_y 为参照，而 M_y 由同样的质心定义，存在一定循环性。
9. **可迁移的研究动作**：同时拟合激活流形与行为流形，用测地距离相关检验"表征几何 ↔ 行为几何"；用 pullback（行为驱动的反演）作为几何的独立证据；用 E_BC 量化 steering 是否"自然"。
9a. **对候选 2：它做了什么 / 没做什么（撞车核心）**：
   - **已做**："沿流形 vs 线性 steering"在循环与序列变量上的系统比较，含因果与双向验证——候选 2 的 steering 半部分在 Transformer 单模型上**已被做过**。
   - **没做**：跨模型家族、跨架构（SSM/hybrid）、跨独立运行；上下文状态变量（计数、括号深度）；"何时线性就够、何时必须沿流形"的判据。
   - 预测性：在任何呈现弯曲流形的模型上，"沿流形比线性更自然"几乎可被预先断言（线性路径穿过低密度区是几何必然）；真正有信息的是**例外**——SSM 中若变量呈直线，则线性与流形 steering 应无差别；或流形存在但 steering 无效（几何不被使用）。
