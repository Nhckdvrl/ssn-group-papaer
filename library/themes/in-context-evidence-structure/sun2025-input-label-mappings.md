# Sun et al. — Interpret and Improve ICL（ACL2025 Main）

- 原文：[正式PDF](https://aclanthology.org/2025.acl-long.196.pdf)。本次读§3–6、limitations，附录D/G.2/H/I/J；未复现代码。
- 自然问题：输入—标签映射怎样存储、用于新输入并被解码？链条是无关标签→中层PC的任务语义→PC扰动与头消融→跨类别attention交换→定点SFT。它已拥有“label状态包含映射、少量头应用映射”的解释，不能当ICES新发现。
- 方法启发：先找到可操纵的表示对象，再用另一个操作验证功能；不能把词汇投影的语义可读性直接当完整规则。PC选择用任务关键词；表示扰动、attention交换和新训练的证据对象有区别。
- ICES距离：本文读到的实验没有交叉两个合法Source规则的历史形成与来源读取。ICES须保留其真正增量：输出命名怎样改变跨Source关系进入本Source证据的原生操作、冻结反事实预测和功能后果。与映射PC解释相容，不因此撤回已确认形成效应；不宣称首次抽象映射或标签检索。
