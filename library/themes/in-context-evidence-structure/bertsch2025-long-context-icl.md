# In-Context Learning with Long-Context Models（2025-03 v2）`[主文§4–5；附录F掩码表核对]`

[原文](https://arxiv.org/html/2405.00200)。Amanda Bertsch等；此处不推断会议归属。

1. **问题与idea来源（RECONSTRUCTED）：** 长context收益来自更丰富的可检索示例，还是更好的跨demo上下文化？把query可见总量与预编码局部块大小独立变化。
2. **设计：** query可读全部demo，预编码只读sink与局部块，保留位置。足够大的局部块可保留多数性能；极小块会破坏表现，不能声称上下文化完全不重要。附录F固定b50/k500时，仅局部18.72%、sink+两局部77.51%、full80.04%；不能把纯独立编码失败直接归给规则推断。
3. **最近邻：** 与CTA强调歧义时上下文化相比，本篇识别长context的不同计算需求；与InvICL一样限制“完全独立编码总会更好”的推断。
4. **对ICES：** 预编码/读取隔离不是新方法；E90进一步操纵另一Source的规则，检查选择位置能否代表规则独立性。E91要回答标签分开在此路径中做了什么。
5. **设计学习：** 拆开通常一起增长的变量，再比较各自作用；不要把某个mask有效等同于全部算法已解释。
