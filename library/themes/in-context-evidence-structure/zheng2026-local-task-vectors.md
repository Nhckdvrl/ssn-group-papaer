# Label Words as Local Task Vectors in In-Context Learning（ACL2026 Findings）[主文§2–6]

[官方全文](https://aclanthology.org/2026.findings-acl.314.pdf)，Zheng / Ma / Lin / Yang。2026-10-10实际读主文§2–6；附录未完整核对。研究定位可参考Findings工作，不改变本仓库不投Findings规则。

1. **形态：** 修正全局任务向量充分性的机制解释。
2. **压力：** Hendel式平均任务向量可恢复事实映射，不代表它能恢复从多个demo推断的任意分类边界。
3. **改变前提：** demo答案位置先承载异质的局部任务信息；部分任务后期可汇聚，分类任务平均可能损失必要信息。
4. **idea来源：** RECONSTRUCTED；全局迁移失败→看单demo答案状态→擦除/迁移验证，非作者真实发现顺序。
5. **距离：** Hendel全局TV、Wang label-anchor、分布式task-state。标签位置重要已知，增量是任务类型与局部/全局可迁移表示之间的关系。
6. **实验：** 字符串长度、数字阈值、2D边界与国家首都等任务；答案位置saliency与擦除；dPCA去长度方向；局部状态移到不同输入/随机标签、相同demo数量的dummy上下文，全局状态移到zero-shot。局部有效层约6–10，全局约12–15，范围依任务/模型。
7. **边界：** 多位置局部patch与单点全局patch带宽不同；去dPCA方向不等于去除全部长度编码；部分全局失败输出非候选词，受限logit读数和全词表生成要分开。作者承认部分任务/模型局部也失败，未给统一成因。
8. **可迁移动作：** 当一个摘要接口失败，改变信息组织对象并检验其功能，不立即说模型没有相应知识。
9. **对ICES：** “从demo推断标准”“局部label承载标准”并非新问题。本次E88不尝试重新证明它；测试来源条件状态的功能内容与recipient原有证据的关系。负迁移须与native、姓名交换和数值阳性一起解释。
