# Language Models Struggle to Use Representations Learned In-Context（ACL 2026 Main）[主文§2–7]

[正式正文](https://aclanthology.org/2026.acl-long.676.pdf)。将旧摘要认识补为实际主文读取，不声称附录全核对。

1. **形态：** 检验表示形成能否支撑新任务的能力/解释边界研究。
2. **压力：** 随机游走诱导了新拓扑几何，尚不知道模型能否调用它推断新规则。
3. **前提改变：** 表示几何像环境，不自动意味着可部署的world model。
4. **idea来源：** RECONSTRUCTED；接Park的表示学习与延迟预测工作，分开环境表示和后续操作。
5. **距离：** Park、task representations、world-model探针；泛用表示/部署区别已有所有权。
6. **链条：** 比较prefilled与instruction预测、几何质量；再在拓扑上推断一步/多步规则；显式坐标说明检查规则学习；测试reasoning与结构描述。主文保留一步邻接猜测基线及较弱的结构描述判分。
7. **边界：** 主文以行为、格式/信息对照和几何测量支撑部署解释，不建立完整native电路；拓扑类型识别不等于恢复词与坐标的完整关系。
8. **研究动作：** 让原来能形成的表示承担新的、有明确依赖的计算，再检查失败发生在哪座推断桥。
9. **对ICES：** 不再以“Source可读但预测弱”立新意，也不把自己的任一迁移失败宣布成部署缺陷。Source条件怎样选择从示例推断的判断标准，需要独立的功能与因果预测。

## 2026-10-11再次读§2–7及附录D/E/F

作者先复现拓扑几何，再将同一信息用于延迟预测和一步/多步映射；显式坐标检查规则学习，attested-neighbor基线排除一步捷径，再测few-shot位置的几何和reasoning。真正的链条是使已形成信息承担新的计算，并测试替代失败原因。它没有给出原生消息干预/完整路径，不能把部署概念误读成已定位了ICES的Source形成机制。E116弱single说明不能以r高宣布规则掌握；E117用direct criterion与single两方面对照，并在真实形成接口测功能方面响应。共享操作的所有权与具体Source问题分别对齐，不因摘要重复而自动缩主张。
