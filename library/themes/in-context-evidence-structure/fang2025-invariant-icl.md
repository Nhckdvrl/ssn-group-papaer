# Rethinking Invariance in In-Context Learning（ICLR 2025）`[主文§1–4；附录证明未逐式复核]`

[官方论文](https://proceedings.iclr.cc/paper_files/paper/2025/file/01e8ecf628f8d9f62a1fd433d44d34ab-Paper-Conference.pdf)。Lizhe Fang、Yifei Wang等。

1. **形态：** 设计原则＋结构方法。起点是顺序不变的ICL方案经常不如普通自回归ICL，而非只报告顺序敏感。
2. **idea来源（RECONSTRUCTED）：** 不变性不足以保证有用预测。作者把答案不可见与示例互相上下文化加入设计目标，构造leave-one-out预编码再聚合。
3. **关键证据：** 分开比较自回归、Prefix、BoE和InvICL的结构，在合成回归与语言分类检验训练/长度推广。理论的mask限制有其建模前提；没有复核附录证明，不将其if-and-only-if移作所有原生LLM的定理。
4. **科学边界：** 文中的information non-leakage是预测训练样本时不可直接访问它自己的标签，不是来源特定规则之间的干扰。结构mask、并行编码、示例互相依赖的重要性已经占据；不能把E90的mask本身叫新方法。
5. **对ICES：** CTA说明原生上下文化有因果作用；本篇说明把它全移除可能牺牲ICL。E90保留同Source上下文化，只隔离跨Source边。它是在已知过程上检验具体功能边界，不是重新提出上下文化。
6. **可迁移动作：** 某个理想性质不能代表完整计算需求；先明确改善该性质可能丢失什么，再设计能检验充分性的对照。对我们是“只读取目标来源”并不预设足以取得正确规则。

## 运行前定位

E90若只得到分组mask改善准确率，科学增量有限；若能解释另一来源标签如何在完整query来源隔离后仍改变目标规则的使用，或解释为什么额外读出超过纯隔离，才进一步形成具体机制问题。两种结果都必须保留，不把引用本篇当成关闭ICES的判据。
