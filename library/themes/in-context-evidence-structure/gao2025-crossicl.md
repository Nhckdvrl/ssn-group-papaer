# CrossICL（2505.24143）`[主文§3–4.9、附录A/C；接受状态未核对]`

[原文](https://arxiv.org/html/2505.24143)。Jinglong Gao等。

1. **自然问题：** 从已有源任务示例获取目标任务指导。§3分选择与渐进合成：改变query、refine、源例辅助生成label，再进行目标ICL。
2. **idea来源（RECONSTRUCTED）：** Task/input/label差异妨碍直接跨任务提示，故先对齐；不是原生电路逆向研究。
3. **证据与边界：** §4.6用构造性对照检验源信息、refine与multi-step；§4.7区分任务误认、输出复制、分布偏移等，attention不兼容仅潜在解释。
4. **对E92：** 直接转移与标签空间干扰已有所有权。我们不增加transfer方法；把criterion与输出跟随放在两关系、四输入格中，使它们给不同答案，再检验已有历史路径是否承载可用关系信息。
5. **设计学习：** task-gap分解能用于选反事实，但错误分类和有益方法不自动定位原生计算。
