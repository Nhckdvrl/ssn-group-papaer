# CoSToM（ACL2026 Main）`[证据级别：全文指定章节]`

[官方正文](https://aclanthology.org/2026.acl-long.421.pdf)，Li / Shi / Deng；读§3–4、附录E/F与A2参数段。

1. **形态：** 内部读出＋监督构造＋下游效用。
2. **自然问题：** 心理状态推断怎样进入谈判/说服行为？
3. **改变前提：** 心理状态QA能力与对话中的使用需分别验证。
4. **idea来源：** RECONSTRUCTED于正文，非原始发现日志。
5. **近邻：** MindDial、LatentQA、表示/部署；距离是激活接口训练与下游验证。
6. **动作：** encoder层激活供decoder回答QA；冻结decoder，通过接口反传训练浅层LoRA；换任务指令生成对话。两开放模型、两对话域，有人类/模型评判。
7. **边界：** 这是额外监督后的构造性使用，不等于原生算法完整定位；QA重建亦有decoder计算。评分含心理状态措辞显式性，不能直接等同真实互动结果。
8. **可迁移：** 保持激活接口，改变decoder用途，检验内部修正能否影响行为。
9. **对ICES：** 学自然问题与证据链，不硬仿涨分方法；E56同样须区分新增训练计算与native路径。

2026-10-10再读主文§1、§3–4：最该学的是保持同一激活接口、改变decoder用途，直接测心理状态重建的改善是否进入对话生成。它的价值不来自把每个浅层功能拆到尽细；本文也不要求ICES在E50–E52之后硬造应用涨分。训练/原生、QA/生成的区别用于解释证据，不能自行变成无穷门槛。

## 2026-10-11：按用户提醒重读正文§3.1–3.3、§4.1/4.3–4.4、A.2

值得借鉴的是固定自然问题和功能接口，逐步改变它能说明的事情：context activations→心理状态QA→同一interface监督构造→把decoder请求换为对话行动。论文无需证明每个浅层head的唯一身份，就以同训练集基线和实际使用的改善形成贡献。LatentQA作为训练decoder的直接对照；CoSToM冻结decoder，让QA损失穿过activation interface更新encoder早层LoRA。后续请求改成谈判/说服，是功能迁移的关键。

decoder也会计算，训练表示可能新增能力；证据支持构造性alignment和下游用途，不必宣布完整原生ToM算法。对ICES的学习重点是把已确认形成子图接回Source-conditioned规则判断，而非仿LoRA涨分或把接口拆细。E90已做形成/读取两阶段Source隔离，不新增一张卡重复它。E109的新量是namespace效应的历史答案K形成子图与逐query预测；E110关系控制不足，E111简化自然情绪反事实使关联内容可分。接下来以独立新材料/另一个家族及已有E90全局结果判断这个解释的分量，不继续分头或字段。

### E113/E114完成后的学习更新

按同一有限尺度接回实际功能：E113确认另一家族的关联内容，E114允许正常全Source读取，确认形成条件作用与signed缓存交互，并用原冻结历史消息预测原生label反事实。这个转折来自“内部接口有效是否进入实际使用”的具体缺口，而非继续磨浅层组件。全Source两个背景保留，未新训adapter、未追全网络解释；原生效果的残差是报告范围，不自动是再开实验的要求。当前核心实验矩阵完成，与CoSToM监督构造方法/ToM问题的所有权区别明确。
